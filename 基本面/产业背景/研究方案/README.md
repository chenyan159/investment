# 产业背景研究方案

每个子目录是一套研究方案，子目录名就是专题名，也是结果文件名的开头。`会议调研/` 是所有会议共用的一套方案。

## 目录约定

- 子目录根部恰好保留一份现行 `研究方案_yyyymmdd_hhmmss.md`，runner 只读这一份。
- `yyyymmdd_hhmmss/` 归档每个版本的同名全文和 `修改记录以及效果.md`；历史版本不会被自动选用。

## 修改或新增方案

从项目根目录运行：

`node tools/research-runner/research-plan-tools.mjs publish --plan-dir=基本面/产业背景/研究方案/<专题> --source=<完整新方案> --reason=<修改原因>`

命令建立版本子目录并替换根部现行版；目录不存在时建立该专题的第一个版本，不需要另外登记。发布后在该版本的修改记录里补充修改内容和预期效果，运行后追加实际效果。时间统一用 America/Los_Angeles。

入队时绑定方案版本，执行时读取绑定的快照；README 和修改记录不进入研究提示。
