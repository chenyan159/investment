# 特征量化目录说明

本目录把公司、行业和每日金融数据转成结构化特征、门槛结果与评分。

## 关键入口

- `特征量化索引.md`：只用于方案发现、文件管理与结果目录说明，不作为研究任务输入。
- `研究方案/`：16 个收益型特征和 3 个门槛层的独立研究方案；每个任务只使用与主题对应的一份方案。
- `量化评分/`：当前架构的正式评分结果；`备份/` 不作为正式入口。
- `备份/`：本项目的旧体系、退役框架和历史结果存档；任何研究任务不得将其作为输入。

## 工作规则

- 研究任务只读取与主题对应的单个研究方案，不把索引、其他方案或额外通用规范拼入输入。方案必须独立、自洽，不依赖隐含共同正文。
- 除当前方案文件外，研究证据只允许读取项目根目录下的 `基本面/公司调研/`、`基本面/行业调研/` 和 `金融资料/每日金融数据/`。Investment 内其他目录与文件一律禁止读取，禁止联网补充外部资料。
- 以信息实际公开和可交易时点为准，严禁事后回填；动态来源必须保留数据版本、报告期、公开时间和可交易时间。
- 输出按 `[NG]xx_名称_量化评分_YYYY-MM-DD.md` 命名，标注特征版本、形成日期、输入范围、样本数、缺失项和低可靠度项。
- 保存原始变量、单位、变换、中性化值、可靠度、区间、缺失原因和来源编号；`NA` 不得静默填零或填中位数。
- 评分与证据可靠度分开，强结论必须保留反证和来源链；不得用分数、排名或模型结论替代上游事实。
- `N01–N16` 是收益型特征；`G01–G03` 只作数据、可投资性和风险约束，不得作为收益加分项。
- 特征有效性需要时直接开展独立评估；不设置常驻 `特征评估/` 目录、自动评估队列或有效指标登记表。
- 新口径覆盖旧结果前，先移动到对应 `备份/`；备份、`tmp/` 和 `_work/` 不参与正式发现或登记。
