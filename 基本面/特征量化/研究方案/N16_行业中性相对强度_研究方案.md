# N16 行业中性相对强度研究方案

## 一、研究目标与哲学

本特征衡量股票价格相对市场与真正可比行业的持续强弱，意在提取价格对分散信息的聚合，而不是把市场上涨、行业 beta 或单次跳空误当作公司信号。价格可以比基本面资料更快吸收订单、竞争、资金和风险信息，但也会受到流动性、因子暴露、公司行为和短期反转污染。

研究应先从总回报中剥离市场、行业、国家、规模和 beta 等共同成分，再观察多期限残差动量是否一致、是否由可交易的持续走势构成。该特征是独立价格事实，不需要为价格变化编造基本面故事。

研究须覆盖 `基本面/公司调研/公司索引.md` 在研究时点列示的全部公司，并以索引中的公司—证券映射确定主要交易载体。

## 资料读取边界

除本方案文件本身外，本研究的证据输入只允许读取以下三个本地目录：

- `基本面/公司调研/`
- `基本面/行业调研/`
- `金融资料/每日金融数据/`

上述目录之外的 Investment 目录与文件一律禁止读取，包括 `基本面/特征量化/`（本方案文件除外）、`分析报告/`、`金融资料/` 的其他子目录、`技术面/`、`情绪面/`、`备份/`、`tools/`、`tmp/` 和 `_work/`。禁止联网搜索或补充外部资料；既有评分、排名、目标价、评估结果和事后股价不得作为输入。输出文件只可写入指定结果路径，不得反向读取其中的既有内容。

## 二、研究对象与边界

基本研究单元是“证券—交易日—可比组”。证券映射必须处理主要上市地、ADR、币种、停牌、退市、换码、拆股、分红与其他公司行为。

本特征关注：

- 21、63、126、252 个交易日等多期限复权总回报；
- 相对市场和细分行业的超额或残差回报；
- beta、国家、规模、波动率和必要风格暴露；
- 实现波动、跳空贡献、成交可交易性和走势一致性；
- 短期反转、重大事件跳空及拥挤导致的脆弱性。

不使用绝对涨幅直接评分，不把价格动量解释为基本面质量，也不让同一公司的多地证券重复进入横截面。流动性可影响可靠度和可交易性，但不应被误写成相对强度本身。

## 三、核心变量与信号结构

核心提取链为：

`证券总回报 → 剔除共同因子 → 波动率缩放 → 多期限合成 → 横截面中性排序`

可建立：

- `ResidualReturn_h`：过去 21、63、126、252 日累计窗口内对市场、细分行业和必要风险因子调整后的总回报，仅作诊断；
- `BucketRS`：对 `1–21`、`22–63`、`64–126`、`127–252` 日四个互不重叠区间的残差回报分别做稳健风险缩放，是主合成输入；
- `TrendConsistency`：多期限方向一致性及回报是否过度集中于少数交易日；
- `JumpShare`：总回报中由重大跳空贡献的比例；
- `DataReliability`：交易历史长度、停牌、成交稀疏和公司行为处理质量。

示意合成为：

`RelativeStrength = w1×z(BucketRS_1_21) + w2×z(BucketRS_22_63) + w3×z(BucketRS_64_126) + w4×z(BucketRS_127_252)`

四个主输入互不重叠，避免最近 21 日回报在所有累计窗口中被重复计权。中期权重通常高于极短期；可在 `1–21` 日桶中剔除最近若干交易日以降低短期反转。权重、风险模型和缺口处理应与股票池特征相适配，但不能由当期结果反向挑选。累计 21/63/126/252 日残差仍需输出，用于解释趋势持续性而不再次进入主分。

## 四、研究路径

1. 建立评分日真实可投资证券池，统一 ticker、上市地、币种、交易日历和公司行为映射。
2. 使用 point-in-time 可得的拆股、分红和资本分配因子构造复权总回报，保留纯价格回报作为诊断字段。
3. 为每家公司定义经济上合理的细分行业与国家暴露；多业务公司必要时使用收入暴露组合，而非宽泛行业标签。
4. 估计市场、行业、beta、规模及必要共同因子，同时得到累计窗口和四个非重叠区间的残差回报；避免过度中性化公司真实信息。
5. 对残差回报进行稳健波动率缩放和横截面标准化，控制极端值、稀疏交易和停牌影响。
6. 用四个非重叠区间合成多期限信号，并用累计窗口诊断走势一致性、跳空占比和最近短期反转，不把单日事件冲击等同持续趋势。
7. 对交易历史不足的新上市证券建立短历史版本并单列，不与完整期限样本直接混排。

## 五、证据与时点纪律

只使用评分时点前已经完成的交易数据；当日收盘评分不得包含收盘后修订或下一交易日信息。价格、成交、公司行为、ticker 映射、行业分类和风险因子都应记录生效时间。

不得用当前行业分类改写更早期间，也不得只保留仍存续证券。退市、并购、停牌和换码需要保留连续经济实体映射。公司行为因子发生修订时，应保存评分时点使用的版本；无法确认异常价格是否真实可交易时降低可靠度或标记 `NA`。

## 六、评分与输出

高分代表在剥离共同市场和行业暴露后，多期限风险调整残差回报持续为正、走势较广泛且数据可靠；低分代表持续负残差、趋势恶化或强度完全来自共同因子。单次巨大跳空可产生信息，但若缺乏后续持续性，应在可靠度与结构说明中体现。

评分采用 1.0—10.0，在行业、国家、规模和 beta 中性后的可比横截面内形成。输出至少包括：

机器可读结果须在开头保存 `feature_id`、`feature_name`、`feature_version`、`as_of_date`、带时区的 `score_tradable_timestamp`、`company_universe_version`、`company_count` 和 `input_scope`；逐公司保留 `raw_value`、`unit`、`transform`、`peer_group`、`z_raw`、`z_neutral`、`reliability`、`interval_low`、`interval_high`、`display_score`、`source_ids`、`missing_reason`。`NA` 必须保持缺失，不得由零、中位数或主观中性分填补。

- 公司/证券、评分日、价格截止时点、总分与可靠度；
- 21/63/126/252 日累计总回报与残差诊断，以及四个非重叠区间的残差回报、风险缩放值和合成权重；
- 行业、国家、规模、beta 暴露和中性化方法；
- 跳空占比、趋势一致性、数据异常、公司行为和证券映射说明；
- 可用交易日数、缺失字段及 `NA` 原因。

股票池逐公司列示。短历史、低流动或价格异常证券不得用不完整窗口直接与完整样本混排；如果保留分数，必须单列版本和可靠度。

## 七、常见失效模式

- 用绝对涨幅评分，实质捕捉市场或热门行业 beta；
- 使用未正确复权价格，拆股或分红制造虚假信号；
- 以当前 ticker、行业分类和存续公司回写过去；
- 将新股短窗口与完整 252 日窗口直接排名；
- 过度依赖单日跳空、极低成交价格或不可交易报价；
- 因子剥离过少导致共同暴露污染，或剥离过度抹去公司信息；
- 为价格走势强行附会基本面原因。

## 八、研究员可自由发挥处

研究员可选择稳健回归、横截面残差、行业组合或多因子风险模型，也可根据市场微观结构调整期限、短期剔除和波动尺度。自由发挥必须保证总回报可复现、中性维度经济合理、时间边界严格，并完整披露证券映射和数据异常。
