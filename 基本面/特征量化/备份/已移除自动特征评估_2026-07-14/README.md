# 自动特征评估框架退役存档

归档日期：2026-07-14

本存档保留已经退役的自动特征评估体系，仅供必要的历史追溯，不得作为新研究输入。

归档内容包括：

- 原 `特征评估/` 目录及其研究方案；
- 原 `有效指标清单_latest.json`；
- 原有效指标登记表生成脚本；
- 原 research-runner 的 `feature-evaluation` domain 与 prompt；
- 31 个旧 F01–F52 评估临时脚本。

现行架构不再设置 `特征评估/` 正式目录、不再由 research-runner 创建评估任务，也不再维护自动有效指标登记表。需要判断特征有效性时，围绕当次问题直接进行独立评估，并把评估方法与特征研究方案分开。
