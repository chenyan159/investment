# 特征前向评估研究方案

## 本次评估对象

- 特征：{feature_subject}
- 冻结评分快照：`{score_file}`
- 评分形成日：{score_date}
- 目标持有期：{return_window}

## 研究目的

本方案用于判断一个已经冻结的横截面特征，在信息形成之后是否具有可重复的未来收益排序能力。评估与特征研究彼此独立：特征可以先被定义和生产，是否以及何时评估由研究者另行决定；没有成熟前向窗口时，不得用形成日前的收益替代。

## 核心原则

- **只做真正样本外。** 特征分数、源数据和全部判断在 `score_as_of` 冻结；收益从下一可交易时点开始计算。
- **尊重可交易时点。** 动态信息使用公开时间而非报告期；盘后信息最早在下一交易日进入，未知公开时间的信息不得进入该期。
- **不把行业或规模暴露冒充选股能力。** 原始结果之外，至少报告行业中性以及行业、规模联合中性结果。
- **成本在结论之前。** 组合收益扣除换手、点差和市场冲击；流动性不足、停牌、退市与代码变更必须显式处理。
- **多期一致性优先于单期显著。** 单一形成日只能作为观察，不得据此登记为有效特征。
- **失败是有效结论。** 方向反转、非单调、仅靠少数极端值或仅在一个行业成立，都应如实记录。

## 评估对象与边界

评估输入是一份带有形成日期、逐公司分数、可靠度和证据时点的正式量化评分。门槛层结果可评估其风险筛除或交易约束价值，但不得与收益型特征混在同一有效性排名中。

主要收益口径为形成日后下一可交易时点的复权开盘价至持有期末复权收盘价；同时报告复权收盘到收盘作为敏感性口径。拆股、分红、代码变更、ADR 比率变化、退市和币种异常必须核对，原始未复权价格只能用于诊断。

持有期应与特征经济机制相匹配，可选择约 21、63、126 或 252 个交易日。尚未完整走完的持有期标记为 `immature`，不参与有效性登记。

## 单个形成期的分析

1. 冻结样本、特征版本、形成日、起止交易日和交易规则；列出无法匹配或不可交易的公司。
2. 报告 Pearson、Spearman IC、Kendall，以及行业内秩、行业中性 IC、行业与对数市值联合中性 IC。
3. 比较 Top/Bottom 10、20、30 及五分位组合；报告均值、中位数、命中率、净收益差和分位单调性。
4. 报告高可靠度子样本、主要上市地子样本、去极值和去最低流动性后的结果。
5. 用共享置换分布计算双侧 `permutation_p_value`；同一形成期、同一主持有期内，按形成时预先冻结的完整收益型特征族统一做 Benjamini-Hochberg 校正。不得根据后来新增、删除或表现优劣改变历史特征族，门槛层不进入该特征族。
6. 解释经济来源：收益是否来自预期差兑现、质量防御、行业贝塔、规模、空头挤压或少数事件，不以显著性代替机制判断。

## 跨形成期判断

至少积累三个互不重叠或经过 embargo 处理的成熟形成期，才可以讨论有效性。重点考察：IC 方向一致率、IC 均值与 ICIR、净 Top-Bottom 收益、分位单调性、换手、交易成本、回撤、行业中性后保留程度，以及不同市场状态下是否失效。

同一批特征共享样本、入场规则、收益序列、收益口径和置换随机数，避免比较口径漂移。每个特征版本必须在观察收益之前预注册一个主持有期；其他期限只能作为敏感性分析，不参与有效登记。参数、阈值、方向或主持有期一旦根据结果修改，必须形成新版本并从后续形成期重新累计，不得回写旧期。

## 机器可读登记

每份评估必须包含以下两列表，数值统一使用小数而不是百分号；缺失值写 `NA`，不得填零。`completed` 只用于持有期已经完整结束的报告，文件名中的形成日必须等于 `score_as_of`，评估日不得早于 `oos_end`。该表用于汇总前向 cohort，不替代正文分析。

| 字段 | 值 |
|---|---|
| feature_id | Nxx 或 Gxx |
| feature_name | 特征名称 |
| feature_version | 版本 |
| layer | alpha 或 gate |
| status | completed、immature 或 data_failed |
| score_file | 本次评估锁定的量化评分文件路径，必须与“本次评估对象”一致 |
| score_as_of | YYYY-MM-DD |
| cohort_id | 形成时冻结的 cohort 唯一标识；同一 FDR 批次完全一致 |
| score_snapshot_id | 本特征冻结评分快照的唯一标识 |
| score_snapshot_hash | 冻结评分文件的 SHA-256，小写 64 位十六进制 |
| score_tradable_timestamp | 带时区的 ISO-8601 时间 |
| entry_timestamp | 带时区的 ISO-8601 时间，必须严格晚于 score_tradable_timestamp |
| entry_rule | 预先冻结的入场规则标识或简明定义；同一 FDR 批次完全一致 |
| oos_start | YYYY-MM-DD |
| oos_end | YYYY-MM-DD |
| holding_period | 21d、63d、126d 或 252d |
| trading_days | 实际纳入的交易日数，必须分别等于 21、63、126 或 252 |
| is_primary_horizon | true 或 false；只有预注册主持有期可以为 true 并进入有效登记 |
| universe_hash | 排序后有效证券全集的 SHA-256，小写 64 位十六进制 |
| return_series_id | 冻结行情与公司行动序列的唯一标识 |
| return_method | 复权、分红、退市、换码、币种和缺失值处理口径 |
| n | 有效样本数 |
| spearman_ic | 原始 Spearman IC |
| neutral_spearman_ic | 行业与规模中性 Spearman IC |
| top_bottom_net_return | 扣费后 Top30-Bottom30 收益差 |
| quintile_monotonicity | -1 至 1 |
| turnover | 单边换手率 |
| transaction_cost | 已扣除的成本率 |
| permutation_p_value | 共享置换双侧 p 值 |
| permutation_seed | 同一 FDR 批次共享且可复算的置换种子 |
| fdr_family_id | 形成时冻结的完整收益型假设族标识 |
| fdr_family_members | 按字典序排列的 JSON 数组；成员格式为 `Nxx@feature_version@holding_period` |
| fdr_family_hash | 将排序后的成员按 UTF-8 以换行连接、且不加末尾换行后计算 SHA-256；小写 64 位十六进制 |
| data_quality_gate | pass 或 fail |

同一 FDR 批次的 `cohort_id`、`fdr_family_id`、`fdr_family_members`、`fdr_family_hash`、`universe_hash`、`return_series_id`、`return_method`、`entry_rule`、`entry_timestamp`、`permutation_seed`、形成日、起止日和主持有期必须一致；只有完整成员全部到齐后才能计算 q 值。特征的有效身份是 `feature_id@feature_version@holding_period`，旧版本的历史结果不得替代最新版本尚未成熟的观察状态。

## 输出结构

评估报告应包含：口径与时点、样本流失、公司行动处理、核心统计、分组表现、中性化与稳健性、交易成本、失效诊断、跨期位置（如已有其他成熟期）、机器可读登记表和明确结论。正文必须区分“本期观察”“跨期证据”和“尚不能判断”。
