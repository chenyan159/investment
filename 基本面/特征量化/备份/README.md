# 特征量化备份说明

本目录是特征量化项目唯一的长期历史存档位置，不是正式研究入口，任何特征研究任务都不得读取这里的内容。

- `特征量化重构前_2026-07-12/`：重构前的 F01–F52 研究方案、评分、评估、旧运行备份和旧登记表。
- `特征量化全面重构_2026-07-12/`：全面审计、实施说明、审计底稿和原 `_work` 执行工作区。
- `已移除自动特征评估_2026-07-14/`：退役的自动评估目录、登记表生成器、research-runner 适配代码和历史临时脚本。

当前正式入口只有上一级的 `研究方案/` 与 `量化评分/`。新口径覆盖同名正式结果前，可在 `量化评分/备份/` 保存事务性旧版本；架构级历史统一放在本目录。
