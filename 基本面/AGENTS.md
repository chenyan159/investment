# 基本面目录说明

本目录保存公司、行业和结构化评分资料。项目级分析报告与金融资料已分别迁至 `../分析报告/` 和 `../金融资料/`；这里只定义基本面内部各层分工，具体格式以子目录说明为准。

## 正式资料目录

- `公司调研/`：公司报告、公司索引和研究方法。
- `行业调研/`：行业报告、产业背景、行业索引和研究方法。
- `特征量化/`：结构化特征、评分、Signals、回归和模型验证。

## 分层边界

- `公司调研/`、`行业调研/` 和项目根目录的 `金融资料/` 是上游事实与研究资料层。
- `特征量化/` 是下游评分和验证层，不得把评分、排名或模型结论反向当作上游事实。
- 项目根目录的 `分析报告/` 可以组合上游资料形成评估和比较，但不替代原始事实来源。

根层隐藏的 `分析报告/` 和 `日度资料/` 是迁移后的旧路径兼容 junction，不是正式入口；新代码、方案和自动化不得继续写入旧路径。

## 辅助目录

- `tmp/`：执行中的临时分析、阶段性文件和可删除草稿。
- `data/`、`scripts/`：共享数据、中间数据和自动化脚本。
- 需要保留的一次性研究成品执行根目录规则，放入 `../备份/`；正式成果写入对应正式目录。
