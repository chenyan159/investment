# 横向专题

本目录集中保存跨行业专题和会议调研的研究方案及版本档案；正式研究结果统一进入 `../产业背景/`，不在本目录建立成果目录。

| 专题 | runner方案ID | 默认成果目录（相对于行业调研） |
|---|---|---|
| AI产业链全局图谱与口径字典 | `background-1` | `产业背景/` |
| AI产业链瓶颈与反证指标总表 | `background-2` | `产业背景/` |
| 全球AI需求与Token经济框架 | `background-3` | `产业背景/` |
| 数据中心建设规模 | `background-4` | `产业背景/` |
| 头部AI芯片 | `background-5` | `产业背景/` |
| 会议调研 | `conference` | `产业背景/顶级会议信息/` |

五个产业背景专题只使用外部资料独立研究；会议使用指定会议的公开资料，保留其现行证据边界。行业调研读取 `产业背景/` 及其子目录，核验、质疑和拓展其中主张，不把专题结论直接当作事实。

各专题的 `研究方案/README.md` 规定版本维护；runner的 `research-plans.json` 登记入口与输出边界。使用 `file-run` 入队，`--prompt-file` 可传方案目录。会议任务还必须在运行标识、任务说明或输出文件名中明确会议名称和年份。
