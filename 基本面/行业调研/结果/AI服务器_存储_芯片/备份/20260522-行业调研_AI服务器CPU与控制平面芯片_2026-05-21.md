## 0. 核心结论

AI服务器CPU与控制平面芯片在 2026 年的投资意义，不再是“GPU服务器的低价值配套芯片”，而是 AI Factory 从单机服务器走向 rack-scale / pod-scale 后的控制、调度、安全、I/O、内存与故障隔离层。GPU/XPU 决定训练和推理峰值算力，CPU与控制平面决定集群是否能把这些算力稳定、低延迟、可观测、可运维地释放出来。

本报告把行业拆成六个可投资子方向：

| 子方向 | 代表产品 | 2026 状态 | 投资判断 |
| --- | --- | --- | --- |
| AI主机CPU / rack CPU | AMD EPYC、Intel Xeon 6、NVIDIA Grace/Vera、Arm/Ampere/custom Arm | x86仍是开放AI服务器主力；Grace随GB200/GB300放量；Vera进入H2 2026导入 | 大市场，但单独CPU毛利受客户议价影响；绑定GPU/rack平台的一体化CPU价值更高 |
| DPU / IPU / SuperNIC / SmartNIC | NVIDIA BlueField、ConnectX、Broadcom/Marvell/AMD Pensando、Intel IPU、云厂自研NIC | 2026从“高速网卡”升级为存储、KV cache、隔离、安全、遥测控制点 | 高壁垒、高附加值；最值得跟踪平台级绑定和大客户design-in |
| PCIe/CXL retimer、switch、fabric controller | Astera Labs Aries/Taurus/Scorpio、Broadcom/Microchip/Montage/XConn、CXL控制器 | PCIe 5/6在量产，PCIe 7/8与光PCIe进入路线图；CXL从试点转向垂直优化 | 高速SerDes与合规验证壁垒强，2026-2027弹性最大 |
| BMC/MCU/安全RoT/DC-SCM | ASPEED AST2600/AST2700、Nuvoton、Axiado、OpenBMC、Caliptra、OpenTitan、TPM | BMC从远程管理变成高功率AI rack的电源、遥测、安全、固件根信任入口 | 单颗ASP不高，但AI rack安全与液冷/电源控制带来升级周期 |
| 机架级控制、遥测与power/thermal control | shelf manager、CPLD/FPGA、PMIC、clock/timing、传感器、CAN/LTPI | 1MW rack路径要求BMC与MCU管理更多电源、冷却、互连、故障域 | 价值分散，龙头在电源/模拟/时钟/嵌入式MCU中捕获稳健利润 |
| 开放标准与固件生态 | OCP DC-SCM、OpenBMC、Redfish、SPDM、Caliptra、FCSA、UALink/UEC | 2026从“可选兼容”转为 hyperscaler RFP 的安全/可维护门槛 | 标准本身不直接变现，但决定芯片供应商能否进入大客户BOM |

### 市场空间总判断

以项目内产业背景对 2026-2027 AI加速器平台释放金额为锚：2026 年 AI加速器平台金额基准/乐观/极度乐观为约 4,350-5,300 亿 / 5,750-7,050 亿 / 7,450-9,250 亿美元；2027 年约 5,900-7,600 亿 / 8,250-10,900 亿 / 11,800-15,000 亿美元。CPU与控制平面芯片不是全部平台金额，而是对 AI rack 平台的 attach 内容。本报告按 CPU、DPU/NIC、retimer/CXL/BMC/MCU/安全/遥测等合计 attach rate 约 5.5%-10.0% 测算：

| 年份 | 基准情景 | 乐观情景 | 极度超预期乐观情景 | 主要假设 |
| --- | ---: | ---: | ---: | --- |
| 2026E 行业收入 | 300-480 亿美元 | 450-680 亿美元 | 650-920 亿美元 | GB300/MI350/Trainium3/TPU Ironwood放量，控制平面attach提升 |
| 2027E 行业收入 | 420-700 亿美元 | 700-1,100 亿美元 | 1,100-1,650 亿美元 | Vera Rubin、AMD Helios、OpenAI/Broadcom XPU、CXL/PCIe 6/7进一步放量 |
| 2026E 行业综合毛利率 | 51%-61% | 56%-66% | 60%-72% | 高速SerDes、DPU、平台CPU高毛利抵消通用CPU与成熟BMC价格压力 |
| 2027E 行业综合毛利率 | 50%-62% | 56%-68% | 61%-74% | 供给若继续紧张，平台绑定芯片和retimer/CXL可维持高溢价 |

最强投资主线不是“买所有服务器小芯片”，而是抓住四类能定价的控制点：第一，和GPU/XPU平台强绑定的CPU/DPU/NIC；第二，决定PCIe/CXL/scale-up稳定性的高速SerDes与switch；第三，被OCP、云厂安全规范纳入采购门槛的BMC/硅根信任；第四，能把电源、液冷、遥测、故障隔离做成系统级闭环的机架控制芯片与固件生态。

## 1. 2026-2027 行业机会、挑战与最可能技术路径

### 1.1 2026 的机会

1. AI数据中心建设从“买GPU”转为“交付可运行AI工厂”。NVIDIA 2026 年 5 月公布 FY2027 Q1 总收入 816 亿美元、数据中心收入 712 亿美元，并称 Blackwell 需求强劲、Blackwell Ultra 系统开始供货。GPU收入已经大到单一服务器管理方式无法支撑，CPU/DPU/BMC/retimer从配套件变成平台稳定性的基础设施。
2. rack-scale CPU开始脱离传统双路主板叙事。NVIDIA Vera CPU 官方信息显示，Vera 采用 88 个 Olympus CPU 核、LPDDR5X 带宽最高 1.2TB/s、NVLink-C2C 1.8TB/s；Vera CPU rack 支持 256 个CPU、超过 22,500 个并发CPU环境。CPU正在从“喂GPU的host”走向“agentic AI环境与调度池”。
3. DPU/SmartNIC/NIC成为AI rack的控制平面。NVIDIA Vera Rubin平台把 ConnectX-9、BlueField-4、Spectrum-6 与 Vera CPU、Rubin GPU放在同一rack-scale系统叙事中；OpenAI与Broadcom 2026 年宣布 10GW 定制AI加速器合作，Broadcom不仅提供加速器，也提供 Ethernet、connectivity、rack-scale与networking解决方案。这说明控制平面芯片与AI ASIC会一起design-in。
4. PCIe/CXL从接口标准变成资本开支弹性环节。PCI-SIG 2026 资料显示 PCIe 8.0 Draft 0.5 已指向 256GT/s、x16双向约1.0TB/s，PCIe 7.0 已在 2025 年正式规范化，光PCIe/Optical Aware Retimer进入标准路径。Astera Labs 2026Q1 收入 3.08361 亿美元、同比 +93%、GAAP毛利率 76.3%，说明AI服务器高速I/O控制芯片已经在商业上验证高增长和高毛利。
5. BMC、安全RoT、DC-SCM从“远程开关机”升级为高功率AI服务器的强制门槛。ASPEED AST2700官方页面显示其为 12nm BMC SoC、四核 Arm Cortex-A35 64-bit、双 Cortex-M4、PCIe Gen4、DDR5 3200、LTPI、CAN、Caliptra安全启动；CAN用于高功率AI服务器电源管理，LTPI用于OCP DC-SCM设计。这是AI rack电源/安全/可维护性需求直接推高BMC规格的证据。

### 1.2 2026 的挑战

| 挑战 | 对CPU/控制平面芯片的影响 | 可能受益方 |
| --- | --- | --- |
| GPU平台绑定增强 | 通用CPU和通用NIC被GPU平台自带CPU、DPU、scale-up互连挤压 | NVIDIA Grace/Vera、BlueField、ConnectX；AMD Venice/Vulcano若Helios成功 |
| 高速SerDes验证难度上升 | PCIe 6/7、CXL、800G/1.6T、NVLink/UALink要求板级SI、功耗、误码率协同 | Astera、Broadcom、Marvell、Credo、Montage、Microchip、XConn |
| hyperscaler定制化 | 标准产品可能被AWS Nitro/EFA、Google Titanium/ICI、Microsoft Azure Boost、自研BMC/安全要求替代 | 能承接ASIC/NIC定制的Broadcom、Marvell、NVIDIA、AMD、Arm生态 |
| 供给链长周期认证 | BMC、RoT、DPU、retimer进入主板后验证周期长，换供应商成本高 | 已经在OEM/ODM和云厂BOM内的供应商 |
| 电源与液冷复杂度 | 500kW-1MW rack需要更密集传感、CAN/LTPI/遥测、安全关断 | BMC/MCU、PMIC、clock、传感器、power controller供应商 |
| 安全与固件责任扩大 | OpenBMC、SPDM、Caliptra、OCP SAFE可能变成采购门槛，软件/固件缺陷会影响芯片资格 | 有固件团队、开源协作能力和安全认证经验的厂商 |

### 2.2 x86 AI host CPU

2026 年 x86 host CPU 的核心矛盾是：市场规模仍大，但技术叙事的边际增长不在传统双路CPU，而在GPU平台绑定和disaggregated CPU。AMD EPYC在开放AI服务器中仍有强份额，原因是PCIe lanes、内存通道、功耗/性能和OEM生态匹配；Intel Xeon 6以P-core/E-core、CXL 2.0/1.1 Type 3支持、QAT/DLB/DSA/IAA等加速器保持企业和云厂基础盘。

关键事实：

- AMD 2026Q1 总收入 74 亿美元、同比 +36%，数据中心收入 37 亿美元、同比 +57%；AMD同时公告 MI350 系列、Oracle Cloud MI355X 等信号。AI host CPU受益于GPU服务器出货，而不是单独由CPU换代驱动。
- Intel Xeon 6官方产品资料显示，6900系列支持最多 88 条 PCIe 5.0 lanes、8/12内存通道、MRDIMM 8800MT/s / DDR5 6400MT/s，并支持CXL Type 3。其优势是企业兼容性、软件和供应链，缺点是AI平台绑定弱于NVIDIA/AMD整柜方案。
- 对投资而言，x86 CPU在2026更像“AI服务器扩张的确定性底仓”，不是最大弹性来源；若AMD Helios/Venice在2027放量，AMD CPU/NIC attach会重新获得增长弹性。

利润率判断：通用CPU长期面对云厂议价，但AI服务器高端SKU、平台验证与供给紧张可带来更高ASP。基准看 48%-60%毛利率，乐观 55%-66%，极度乐观看 60%-72%；极度乐观的前提是AI服务器订单继续挤占通用服务器产能，且高端SKU缺货。

### 2.3 NVIDIA Grace / Grace Blackwell

GB300 NVL72 官方产品页显示其包含 72 个 Blackwell Ultra GPU、36 个 Grace CPU、ConnectX-8 与液冷rack架构。这意味着 Grace CPU不是独立CPU销售逻辑，而是整柜平台不可拆的控制/主机计算部分。项目内NVIDIA GTC 2026资料把 Vera Rubin进一步升级为 “seven chips, five rack-scale systems”，显示CPU、GPU、DPU、NIC、switch、storage rack被纳入同一AI factory BOM。

投资含义：

- Grace的真实壁垒不是Arm CPU核本身，而是NVLink-C2C、NVIDIA软件栈、整柜验证、GPU供给绑定。
- 在NVIDIA平台内，传统x86 host的可替代空间变小；在开放平台外，x86仍是主力。
- Grace/Vera的CPU等效收入难以从NVIDIA披露中分拆，本报告按整柜GPU平台收入的2%-4%估算CPU等效含量，另把DPU/NIC/控制硅单独列示。

### 2.4 DPU、SuperNIC 与SmartNIC

DPU/NIC是本行业最容易被低估的方向。AI训练和推理的瓶颈不仅是带宽，还包括租户隔离、RDMA拥塞控制、存储offload、加密、telemetry、failure domain隔离、KV/context数据搬运。2026 年大型云厂订单正在把DPU/IPU从“可选加速卡”变成AI集群标配。

关键产品路径：

- NVIDIA：ConnectX-8/9、BlueField-3/4、Spectrum-X/6与NVLink/NVSwitch形成封闭或半封闭控制平面；Vera Rubin平台把 BlueField-4 与 ConnectX-9 放入下一代rack-scale系统。
- Broadcom：AI ASIC + Ethernet + connectivity + rack-scale networking，是OpenAI 10GW定制AI基础设施合作的核心供应方之一；对自研AI ASIC客户，Broadcom具备ASIC、SerDes、switch/NIC和封装协同能力。
- Marvell：与NVIDIA NVLink Fusion合作，定位在custom XPU / custom AI infrastructure silicon与NVLink生态连接。
- AMD Pensando / Vulcano：若MI450/Helios开放rack-scale路线成功，AMD的CPU+GPU+NIC attach会从板卡层提升到rack层。
- Intel IPU、AWS Nitro/EFA、Google Titanium、Microsoft Azure Boost说明云厂不会只买网卡，而是把I/O、虚拟化和安全控制平面纳入平台资产。

利润率判断：高端DPU/NIC通常具备高毛利，因为其直接影响集群利用率和可用性。基准 58%-68%，乐观 63%-73%，极度乐观 68%-78%。最能定价的是“绑定GPU/XPU平台、通过云厂集群验证、可提供软件遥测和拥塞控制”的供应商。

### 2.5 PCIe/CXL retimer、switch 与fabric controller

PCIe/CXL控制芯片是2026-2027增长弹性最大的“隐形AI芯片”。原因是每一次GPU数量、HBM容量、NVMe/KV cache、CXL内存池、accelerator scale-up增加，都会提高高速通道数量、距离和信号完整性难度。

关键事实：

- PCI-SIG DevCon 2026资料显示，PCIe 8.0 Draft 0.5 目标 256GT/s、x16双向约1.0TB/s，PCIe 7.0在2025年已发布正式规范，光PCIe/Optical Aware Retimer进入标准路径。
- Astera Labs 2026Q1收入 3.08361亿美元、同比 +93%、GAAP毛利率 76.3%；其Scorpio X-Series 320-lane AI scale-up fabric switch已开始出货，H2 2026 ramp，Scorpio P-Series多客户H2 2026、2027更大规模。Astera对merchant scale-up市场给出2030年200亿美元TAM目标。
- CXL垂直优化资料显示，Samsung S-CHMU可把应用感知延迟改善约40%，CXL-PNM在FAISS IVF Flat向量搜索中从3.5 QPS提升到19.7 QPS，Pangaea v2把有效内存容量提升约50%。这说明CXL不再只是“加内存”，而是进入推理KV cache、向量数据库、内存分层、Kubernetes调度。

利润率判断：高速SerDes、retimer、switch、CXL控制器具备三重定价权：验证周期长、故障代价高、替代供应商少。基准 62%-72%，乐观 68%-78%，极度乐观 72%-82%。若PCIe 6/7和CXL 3.x在2027提前进入AI rack BOM，利润弹性可超过传统CPU。

### 2.6 BMC、MCU与安全管理芯片

BMC是所有服务器都需要的芯片，但AI服务器使其规格从“能远程管理”升级为“能管理高功率、高密度、多故障域、强安全合规rack”。ASPEED AST2700官方信息非常关键：12nm、四核Cortex-A35、双Cortex-M4、PCIe Gen4、DDR5、UFS、CAN、LTPI、Caliptra。CAN用于高功率AI服务器电源管理，LTPI用于OCP DC-SCM模块化，Caliptra用于硅级安全根。

2026-2027 BMC升级路径：

| 路径 | 2026 状态 | 放量驱动 |
| --- | --- | --- |
| AST2600继续主流 | 当前大量服务器仍使用AST2600 | 成熟、成本低、生态强 |
| AST2700/2750高端导入 | 12nm、A35、PCIe Gen4、DDR5、LTPI、Caliptra | AI rack更多遥测、电源控制、安全启动、DC-SCM |
| Axiado secure BMC | 把AI安全、平台安全、BMC功能结合 | 云厂/政府/金融/机密计算要求 |
| Nuvoton server MCU/MPU | M7 MCU、A35 MPU用于服务器和数据中心嵌入式控制 | 电源、传感、管理控制复杂度提升 |
| OpenBMC商业固件 | Insyde等支持AST2700 OpenBMC；云厂推动开源管理栈 | 降低vendor lock-in，提高安全可审计性 |

BMC直接市场规模相对小，但战略价值在两点：第一，安全与电源控制一旦进入RFP要求，供应商具备强锁定；第二，高端BMC与secure BMC ASP可能从传统几美元到十几美元提升到数十美元级别，叠加每台AI服务器更多MCU/传感/控制芯片，板级管理硅价值显著提升。

### 3.2 NVIDIA Vera CPU与BlueField-4 STX

Vera CPU是2026-2027最重要的新CPU方向。其设计目标不是取代所有x86，而是在NVIDIA rack-scale平台中把CPU资源从传统服务器节点拆出来，形成CPU rack与GPU rack、storage rack、network rack协同。官方Vera CPU信息强调 LPDDR5X高带宽、NVLink-C2C一致性连接、超过22,500并发CPU环境，直接指向agentic AI推理中的多租户、多agent、多上下文负载。

BlueField-4 STX/CMX则把DPU从网络/存储offload进一步推向AI storage/context control。项目内GTC资料显示，BlueField-4 STX/CMX目标包括提升tokens/sec、能效、ingestion与共享context能力。对于推理集群，DPU不只是“省CPU”，而是决定KV cache、模型上下文、存储吞吐和故障隔离的核心控制器。

### 3.3 AMD Venice、Helios与Vulcano

AMD 2026 年 5 月公告称 Venice为下一代EPYC，采用TSMC 2nm N2，是面向HPC/数据中心的6th Gen EPYC，已开始生产爬坡并预计下一年发布。AMD的技术路线如果成功，2027开放AI rack可能形成“MI450/MI455X + Venice CPU + Vulcano NIC + UALink/Ultra Ethernet”的可替代平台。

基准情景下，AMD在2026仍主要依靠EPYC + MI350/MI355X开放服务器；乐观情景下，Helios/Venice在2026 H2获得更多云厂验证；极度乐观情景下，2027开放AI rack因为供应、成本和客户避免单一供应商而加速，AMD CPU和NIC attach大幅提高。

### 3.4 Arm AGI CPU与custom Arm server CPU

Arm 2026年介绍AGI CPU参考方案：192个Neoverse核心、3nm、面向自定义服务器CPU设计，目标是把设计周期最多缩短约两年。AmpereOne Aurora最高512核心、12通道DDR5、128条PCIe Gen5 lane，代表商用Arm服务器CPU的高核心密度方向。

对本行业的意义：

- Arm IP与chiplet reference降低云厂、AI ASIC厂商做custom host CPU的门槛。
- 2026出货仍不如x86和Grace明确；2027以后，在推理、区域AI、边缘云和自研ASIC配套中机会扩大。
- 最强变现场景不是独立Arm CPU公司挑战x86，而是Arm IP、Marvell/Broadcom custom silicon、云厂自研CPU与AI ASIC组合。

### 3.5 CXL垂直优化与AI推理内存墙

CXL最初被市场理解为“给服务器加便宜内存”。2026资料显示，CXL真正的增长点是垂直优化：KV cache、向量搜索、数据库、Kubernetes内存调度、NUMA tiering、near-memory processing。AI推理进入长上下文、多模态和agentic工作流后，KV cache可能成为比模型权重更不稳定、更难调度的内存需求。

本报告乐观假设：2026年CXL controller和memory expander从云厂试点进入早期生产，2027年若推理集群的HBM成本、DRAM容量和KV cache命中率压力继续提升，CXL控制器收入有机会从几十亿美元走向百亿美元级。

### 4.2 供给瓶颈

1. 先进节点与封装优先级。Vera、Venice、custom Arm、DPU/NIC、AI ASIC与GPU争抢先进节点和先进封装资源。即使BMC不用先进节点，整柜出货仍受GPU、HBM、CoWoS/advanced packaging制约。
2. 高速SerDes与板级信号完整性。PCIe 6/7、CXL、800G/1.6T、NVLink/UALink在AI rack中的距离、温度、误码率、FEC、功耗同时上升，验证失败会导致整机延迟和稳定性问题。
3. 合规与互操作测试。PCI-SIG、CXL、OCP DC-SCM、Redfish、SPDM、OpenBMC、Caliptra都需要软硬件一起验证；控制平面芯片不是“焊上就能卖”。
4. 固件和安全人才。BMC/DPU/IPU需要Linux、RTOS、OpenBMC、Rust/C、secure boot、attestation、云厂管理栈人才，人才瓶颈比晶圆更隐蔽。
5. 客户认证周期。CPU/DPU/BMC/retimer进入AI服务器BOM后，云厂和OEM需要长周期验证；一旦进入，切换成本高，但新厂商导入慢。
6. 高功率AI rack的电源与液冷耦合。500kW-1MW rack要求BMC、MCU、PMIC、传感器、CDU、PSU、breaker联动，任何芯片遥测不准都可能影响可用性。
7. 高层PCB、连接器、线缆和ABF基板。控制平面芯片自身可能不缺，但PCIe/CXL/800G连接路径受板材、连接器、retimer布局和基板影响。
8. 出口管制与区域供应链。高端AI CPU/DPU/NIC和安全芯片可能被法规影响；国产AI平台则推动本地BMC/MCU/CPU替代，但外部可投资性受限。

### 4.3 BOM与单位成本拆分

以高端8-GPU AI节点或NVL级rack折算，CPU与控制平面芯片的美元内容大致分布如下：

| 成本项 | 单节点/等效节点占比 | 定价因素 |
| --- | ---: | --- |
| Host/rack CPU | 35%-55% | 核数、内存带宽、PCIe lanes、与GPU互连绑定、软件生态 |

| 平台绑定 | 随GPU/rack一起销售的CPU/DPU/NIC更容易获得平台毛利，而不是单颗芯片毛利 |
| 供应紧张 | 高速SerDes、retimer、CXL和DPU若缺合格供应，ASP可高于历史正常水平 |
| 软件/固件闭环 | 有SDK、telemetry、OpenBMC、安全更新、云厂工具链的供应商定价更强 |
| 认证和切换成本 | 客户一旦完成整机验证，不愿为小幅降价切换控制平面芯片 |
| 价值可量化 | 能证明减少CPU占用、提升tokens/sec、降低故障率、提升内存利用率的芯片可分享客户ROI |
| 客户集中 | hyperscaler议价强，会压缩通用CPU/BMC利润；但定制ASIC/NIC/IP可通过NRE和长期供货锁定利润 |

价格传导机制：GPU平台涨价或AI服务器整柜ASP上升时，CPU与控制平面芯片并不会线性涨价，但attach数量和规格会上升；当rack稳定性、能耗、故障率成为客户瓶颈时，高速I/O控制、DPU和secure BMC能通过“避免停机/提高利用率”而定价。

## 5. 竞争格局与壁垒

### 5.1 市场结构

| 子市场 | 头部集中度 | 主要公司 | 结构判断 |
| --- | --- | --- | --- |
| AI host/rack CPU | 高 | AMD、Intel、NVIDIA、Arm生态、Ampere、云厂自研 | x86双寡头仍强，NVIDIA在自有rack内绑定，Arm/custom在云厂扩张 |
| DPU/NIC/IPU | 高 | NVIDIA、Broadcom、Marvell、AMD Pensando、Intel、AWS/Google/Microsoft自研 | 高速SerDes+软件+客户design-in决定集中度 |
| PCIe/CXL retimer/switch | 中高 | Astera、Broadcom、Microchip、Montage、XConn、Renesas、Credo、Rambus/IP厂商 | AI需求推动新龙头出现；高毛利吸引竞争但验证壁垒高 |
| BMC | 很高 | ASPEED、Nuvoton、Axiado、Microchip | ASPEED生态强；secure BMC和AST2700升级给挑战者窗口 |
| MCU/电源/时钟/遥测 | 分散 | TI、ADI、Renesas、MPS、Infineon、onsemi、Microchip、SiTime | 分散但稳定；AI rack提高规格与数量 |
| 固件/标准/安全 | 生态型 | OpenBMC、OCP、Caliptra、OpenTitan、AMI、Insyde、云厂内部团队 | 标准和固件决定硬件能否进入BOM |

### 5.2 可量化壁垒清单：为什么能定价

1. 高速SerDes能力。PCIe 6/7、CXL、800G/1.6T、NVLink/UALink不是单纯IP授权，板级SI和量产良率决定整机稳定性；能把误码率、延迟和功耗做到客户要求的厂商少。
2. 平台软件和遥测。DPU/NIC/BMC的价值来自可观测、拥塞控制、隔离、firmware update、故障定位；客户不会为没有软件工具链的低价芯片冒险。
3. 客户认证周期。AI服务器从原型到量产通常需要多个季度验证；控制平面芯片换料会影响BIOS/BMC/firmware/driver/board layout，切换成本高。
4. 安全合规。Caliptra、SPDM、OpenBMC、OCP SAFE、DC-SCM等要求使供应商必须证明secure boot、attestation、firmware lifecycle；安全缺陷可能导致整平台采购资格丢失。
5. 规模供货能力。AI rack出货需要成千上万节点同步交付，控制平面芯片要与GPU、CPU、NIC、retimer、BMC firmware、ODM产线同步；小厂即使技术好，也可能输在交付。
6. 生态锁定。NVIDIA平台内Grace/Vera/BlueField/ConnectX/NVLink互相增强；AMD若Helios/Vulcano成功也会形成开放生态锁定；云厂自研ASIC则绑定Broadcom/Marvell/Arm/IP供应链。
7. 故障代价极高。BMC、retimer、DPU问题会导致整柜不可用或性能抖动；客户愿意为已验证、低RMA、可远程诊断的芯片支付溢价。

### 5.3 价值捕获判断

长期ROIC和毛利最高的层级排序：

1. 平台级控制平面：NVIDIA Vera/Grace + BlueField + ConnectX + NVLink/Spectrum体系最强，因为CPU/DPU/NIC与GPU平台绑定，能把价值打包进整柜。
2. 高速连接与fabric控制：Astera、Broadcom、Marvell、Montage、Microchip、XConn等若掌握PCIe/CXL/scale-up关键位置，毛利和增长兼具。
3. 定制AI ASIC配套控制硅：Broadcom、Marvell、Arm生态可通过ASIC/NIC/SerDes/IP/NRE长期绑定云厂。
4. secure BMC和固件生态：ASPEED/Nuvoton/Axiado/OpenBMC/Caliptra相关供应链可受益于AI服务器升级，但单颗ASP上限低于DPU/CPU。
5. 通用电源/MCU/clock/analog：需求稳定、数量上升，但竞争更分散，通常更像稳健复利而不是爆发弹性。

## 6. 2026 关键变化：行业拐点与最可能放量子方向

### 拐点一：Blackwell Ultra / GB300把控制平面带入“整柜标配”

GB300 NVL72的公开规格显示 72个Blackwell Ultra GPU、36个Grace CPU、ConnectX-8与液冷rack。2026年随着GB300和Blackwell Ultra系统出货，AI服务器CPU和控制平面的需求不再按“每台服务器一颗BMC+双路CPU”线性测算，而要按整柜GPU数量、CPU池、网络DPU、retimer、BMC/MCU遥测一起测算。

最可能放量：Grace CPU、ConnectX-8、BlueField/Spectrum-X配套、PCIe 5/6 retimer、AI rack BMC/MCU、电源/液冷遥测芯片。

### 拐点二：Vera CPU / BlueField-4开始定义2027订单

Vera CPU和BlueField-4在2026年H2的导入意义大于当年收入。它告诉市场：下一代AI rack把CPU环境、GPU、storage/context、network、DPU作为一个整体设计。2026年投资跟踪重点是客户名单、OEM/ODM验证、机柜级功耗与供应链准备，而不是只看当季收入。

最可能放量：2026导入，2027放量；Vera CPU、ConnectX-9、BlueField-4 STX/CMX、Spectrum-6、机架级遥测/安全控制。

### 拐点三：OCP安全/模块化标准从参考规范变成采购门槛

OCP EMEA 2026资料显示，Open Data Center for AI规范将在2026年按阶段推进；OCP FCSA 2026发布，Caliptra、OpenBMC、DC-SCM、OpenSFI/SOLID等安全和模块化要求在AI数据中心中重要性提升。ASPEED AST2700已把Caliptra、LTPI、CAN写入产品能力，说明BMC供应商正在按AI rack标准升级。

最可能放量：AST2700/2750、secure BMC、OpenBMC商业固件、Caliptra RoT、DC-SCM 2.0、LTPI、服务器电源管理CAN/MCU。

## 7. 2027 关键变化：行业拐点与最可能放量子方向

### 拐点一：Vera Rubin从导入转为量产，CPU rack成为新类目

2027年若Vera Rubin按路线图放量，CPU不再只是每个GPU节点的host，而可能形成独立CPU rack，服务agentic AI、多租户推理、数据处理、控制与调度。对投资而言，传统“服务器CPU出货量”指标会失真，需要跟踪“每个AI rack的CPU环境数、DPU数、NIC端口、retimer通道、BMC/MCU数量”。

最可能放量：Vera CPU rack、BlueField-4 STX/CMX、ConnectX-9、Spectrum-6、NVLink 6相关控制芯片。

### 拐点二：AMD Helios/Venice和开放rack-scale生态进入实质竞争

AMD Venice生产爬坡和Helios/Vulcano路线若在2027获得大客户采用，将使AI服务器CPU与控制平面从NVIDIA封闭/半封闭生态转向双平台竞争。开放Ethernet、UALink、Ultra Ethernet与EPYC/Vulcano attach将提高非NVIDIA控制平面供应商的机会。

最可能放量：Venice EPYC、AMD Pensando/Vulcano NIC、UALink/UEC生态switch/NIC/retimer、开放AI rack BMC/firmware。

### 拐点三：CXL/PCIe 6/7与安全RoT进入AI推理标配

长上下文、多模态、agentic AI会持续推高KV cache和内存分层需求。2027年CXL若从数据库/内存扩展走向AI推理内存池，CXL controller、switch、retimer、memory expander会成为独立成长曲线。同时，Caliptra/OpenTitan/SoC RoT如果成为云厂硅安全要求，BMC、DPU、SSD controller、CPU/GPU都需要可验证安全链。

最可能放量：CXL 2.0/3.x controller、CXL memory expander、PCIe 6/7 retimer/switch、optical-aware retimer、Caliptra/OpenTitan集成芯片、secure BMC。

### 9.2 投资价值排序

1. 首选：平台绑定型DPU/NIC/控制平面。NVIDIA、Broadcom、Marvell、AMD Pensando/Vulcano、云厂定制供应链。原因是直接决定AI cluster可用性和利用率，客户愿意为稳定性付费。
2. 首选：PCIe/CXL retimer、switch、fabric controller。Astera等公司的收入增长和高毛利已经验证商业模式；2026-2027随PCIe 6/CXL/scale-up放量继续上行。
3. 次首选：NVIDIA Grace/Vera和AMD Venice/Helios这类绑定rack平台的CPU。单独CPU并非最高弹性，但平台CPU在整柜中有强锁定。
4. 进攻型：secure BMC、Caliptra/OpenBMC/DC-SCM升级链。ASPEED/Nuvoton/Axiado等受益于高端AI服务器换代，弹性来自ASP提升和安全门槛。
5. 稳健型：电源、模拟、时钟、传感和MCU。受益于rack功率密度提升，但公司分散、单一AI敞口不如DPU/retimer直接。

## 10. 跟踪指标与风险

### 10.1 未来6-12个月跟踪指标

- NVIDIA GB300 NVL72实际交付节奏、Grace CPU attach、Blackwell Ultra供应链瓶颈。
- Vera CPU、BlueField-4 STX/CMX、ConnectX-9、Spectrum-6的OEM/ODM客户名单和H2 2026样机/订单。
- AMD MI350/MI355X订单、Oracle/Meta等云厂信号，以及Venice/Helios/Vulcano是否提前验证。
- OpenAI/Broadcom 10GW部署节奏：H2 2026是否如期启动，2027是否形成明显AI ASIC和控制平面收入。
- Astera Scorpio X/P ramp、PCIe 6 retimer需求、CXL Leo/Scorpio客户数量和毛利率趋势。
- ASPEED AST2700/2750是否从sample/design-in转为AI服务器量产，AST2600替代速度和ASP变化。
- OCP Open Data Center for AI、Caliptra、OpenBMC、DC-SCM、FCSA、OpenSFI/SOLID是否进入云厂RFP。
- CXL在Azure、Samsung、云厂推理/KV cache/数据库中的GA节奏。
- Dell/HPE/Supermicro/Lenovo/QCT/Wiwynn等AI服务器订单、backlog、液冷和电源交付能力。
- hyperscaler 2026-2027 AI capex是否继续上修；若capex延后，控制平面芯片会跟随整机交付延后。

### 10.2 主要风险

1. GPU或电力/液冷交付延迟导致CPU与控制平面芯片出货顺延。
2. NVIDIA平台绑定过强，压缩开放DPU/NIC/CPU供应商空间。
3. 云厂自研提高，外部merchant芯片TAM低于预期。
4. PCIe/CXL/CXL memory pooling标准虽成熟但软件生态慢，CXL收入爬坡低于乐观情景。
5. BMC/security升级ASP提升不及预期，安全要求被云厂内部方案吸收。
6. 高速SerDes竞争加剧，retimer/switch毛利从当前高位回落。
7. 出口管制、供应链区域化和客户集中导致订单波动。
