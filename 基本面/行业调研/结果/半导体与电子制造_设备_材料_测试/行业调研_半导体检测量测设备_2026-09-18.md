# 半导体检测量测设备行业调研：良率学习、三维结构与生产率共同决定的价值池

研究截止日期：**2026年9月18日**。报告中的“2025、2026”等未另标明时均指自然年、全球市场、美元计价的年度流量。美元金额统一使用**十亿美元（USD bn，1 bn=10亿美元）**；人民币和日元披露值保留原币。2026全年尚未结束，全年模型均为估计，2027—2030为条件预测。

本次独立联网研究。本地研究输入仅使用允许的“产业背景”目录内资料作为检索线索；另读取根目录及目标目录的管理规则，未读取其他行业报告、公司报告、排序、估值或历史结论。正文标记：**F=披露事实；M=管理层目标/判断；C=直接计算；I=本报告推断或模型；U=未知**。厂商自述的技术性能、匿名客户采用属于有利益关系的原始披露，不等同于采购方独立验收报告。

## 一、核心判断与最重要的反证

**本行业当前更接近“需求扩张、局部交付受限、利润分化”，而非所有设备持续短缺或所有供应商共同涨价。** 支持这一判断的采购方证据，是先进逻辑和存储客户继续投入新工艺及新产线；供应商证据，是检测量测厂商的订单、资格选型和交付加速。两类证据分别列于下文，没有用供应商销售增长反推客户预算，再据此证明销售增长。

本报告识别出四个决定性机制。

1. **客户购买的是更快发现可行动缺陷的能力。** 分辨率只是条件之一；误报、漏检、取样覆盖、跨机匹配、数据解释及良率修复速度，决定设备能否进入生产控制闭环。GAA、背面供电和三维互连使更多关键结构不可直接观察，推动光学、电子束、X射线、探针和声学的组合，而非某种成像方式取代全部其他方式。[S16][s16] [S18][s18]
2. **先进封装正在吸收前道级的过程控制，但不会平均抬升所有封装设备利润。** Nova WMC已经有竞争性选型和多客户部署；Applied的新电子束平台则体现前道供应商进入封装任务。拥有既有客户数据、算法和现场服务能力的厂商，可能获取新预算，也可能挤压原有封装检测商。[S20][s20] [S17][s17]
3. **生产率是需求模型中不能省略的分母。** Lasertec宣称ACTIS A200HiT相对A150检测速度提高至三倍；Camtek披露2025年收入增长主要来自新品推高平均售价。这分别说明“更多检测≠更多台数”和“收入增长≠同幅物理扩产”。若检测频率和适用范围扩张不足以吸收生产率提高，技术进步可以压低采购台数。[S09][s09] [S21][s21]
4. **竞争优势与会计利润之间仍隔着研发、认证和营运资本。** 国际龙头有较强服务收入和固定费用摊薄能力；国内挑战者可以在订单增长时继续亏损。最新企业证据显示这种分化已经发生，不能将“卡位重要”直接转换成高ROIC。

**核心规模结论（I）**：按本报告排除电性ATE、工艺加工设备、封装曝光和一般PCB检测的边界，2025年新设备及随设备交付软件的核心市场基数约**14.5—18.6 bn**，采用的复算代表值为**16.0 bn**；相关服务与独立软件约**4.0—5.0 bn**，代表值**4.4 bn**。合计约**18.5—23.6 bn**，不是全行业审计统计。未单独识别的翻新设备交易、一般失效分析仪器及重复流转收入不额外相加。

基准代表路径的核心设备收入为2026年**20.56 bn**、2027年**24.82 bn**、2030年**35.38 bn**；加相关服务/独立软件后分别约**25.75、30.76、44.16 bn**。它们是透明参数组合的计算结果，**不是精确点预测**。例如2030年基准组合的全参数压力范围为29.65—66.40 bn，说明当前证据不足以把远期市场压缩成窄区间。悲观路径下，2030年设备收入可接近2025年水平，行业利润池明显受压；乐观路径下，三维工艺普及、覆盖增加和有效供给扩张共同推动远高于趋势的增长。完整分市场参数、价格、成本、交付缺口和经营结果见第七节及附录。

**最强反证**不是“AI需求消失”这一极端命题，而是：新增检测任务真实增加，但吞吐提升、动态取样和设备重复使用更快；客户经过良率学习后减少测量，叠加掩膜复用和国产替代压价，使单位制造能力的外购检测支出下降。该解释与半导体制造增长完全可以同时成立。2027年的检验重点应是同类流程的检测时长/覆盖增长是否超过单机生产率提升，以及新增订单能否转化为持续验收和现金，而不是只看节点路线图。

主要未解问题是：各家新机型的同规格净成交价格、客户实际测量配方和稼动率、全球合格交付台数、不同技术之间的预算迁移，以及市场统计的尾部覆盖。报告对这些未知给出可替换的条件参数，未把它们当作事实。

先进封装中的“后道”与前道晶圆制造末端的BEOL不是同义词。本报告按**客户任务**归类，不能把一家厂商宣称进入BEOL的所有收入都分给先进封装。

采购通常由资本设备采购团队组织，工艺/良率团队决定技术选型，厂务、自动化和信息安全部门参与导入，财务批准投资；验收包括灵敏度、漏检、误报、吞吐、重复性、跨机匹配和产线接口。晶圆或封装报废损失主要由制造商承担，设备商承担质保、现场支持、部分合同赔偿及后续订单损失。**客户承担的潜在损失远高于设备售价，不代表设备商可按该损失无限定价**：已有工具、第二来源、降低覆盖和推迟扩产都是买方的替代方案。

### 2.2 支付来源和不重复计数

新增产线采购是资本支出；升级换代可能替代原设备或取样流程；提高检测覆盖会从产能设备预算转移部分资本；备件、服务和订阅通常由运营预算支付。Foundry的资本支出通过芯片制造价格间接由设计公司及终端承担，但**设计公司芯片采购额、Foundry收入、设备收入不能相加为三个独立终端需求池**。

设备商外购激光、光学件、真空部件、运动平台和计算存储系统的采购，属于设备收入内的成本和上游收入；本报告将其用于解释价值分配，不再加入行业设备规模。工艺设备商捆绑的控制软件和自产传感器只有独立对外变现部分才属于本报告外购市场。

本报告不覆盖一般实验室SEM/TEM/FIB、通用X-ray CT的全部收入。其用于生产过程控制的专用部分纳入A/B/D的尾部估计，面向广泛科研及离线失效分析的部分只作相邻能力讨论。这一边界会小于某些“全部半导体分析仪器”口径。

## 四、从技术到付款：决定预算的三条采用路径

### 4.1 前道：从“看见表面”走向“约束埋藏结构”

光学检测覆盖快、能处理大面积，但微小缺陷信号受到噪声、材料响应和复杂图形背景限制；电子束提供局部高分辨率和电压衬度，但扫描面积、充电、损伤及吞吐存在约束。**技术分工更可能是快速扫描筛选候选、电子束/其他物理手段复检、软件合并解释**。某个厂商宣称更小缺陷检出尺寸，必须同时指定材料、缺陷类型、误报率和扫描速度，才可用于经济比较。

尺寸量测的核心变化是参数相互耦合：二维CD相同，侧壁角、凹陷深度、薄膜成分和应力仍可不同。OCD通过模型提取结构，速度和覆盖有优势，但模型相关性可能产生多解；SEM、AFM及X-ray等提供不同物理敏感性，价值在于减少多解和建立可追溯的校准，而不只是“更清晰”。Hitachi GT2000的低加速电压、背散射检测和跨机匹配能力，体现低损伤、三维结构和量产一致性需要同时满足。[S16][s16]

ASML多电子束和光学量测能与光刻校正相连；其2025年报说明eScan1100使用25束，不能把“25束”直接换算为客户每小时有效覆盖提高25倍，因为并行效率、对准、数据处理、配方和缺陷稀疏性均会改变结果。[S32][s32] 对设备商而言，闭环连接增强平台粘性；对晶圆厂而言，也增加避免单一供应商锁定的动机。

本报告基准假设：2026—2027年，新增关键层及取样要求快于新工具有效生产率提升的部分，主要落在B；A仍增长，但经过筛选和成熟后的取样优化，长期工作量到台数的弹性小于1。CFET等更远路线只在2030乐观及突破分支体现，不将研究路线图提前计入2026收入。

### 4.2 掩膜：高价值不意味着台数无限增长

EUV掩膜的反射多层和相位缺陷，使使用相关波长识别可打印缺陷具有特殊价值；DUV/光学检测、actinic检测、复检及可打印性验证并非完全替代品。新设计掩膜数量、检测周期、清洗后的复检频率和晶圆厂内定期监控，比单纯曝光层数更接近采购需求。单套掩膜可以服务很多晶圆，故先进节点晶圆增长与掩膜设备收入之间不存在固定倍数。

Lasertec A200HiT的三倍扫描速度提供一个有力反事实（I）：若适用任务的工作量增长50%，每台年化有效吞吐增长100%，需求台数变为原来的1.5/2=75%；即使代际ASP增长30%，相关收入也只有0.75×1.3=97.5%。只有检测频率、客户覆盖、新掩膜数、其他瓶颈或存量更换进一步拉动，收入才持续扩张。这里的100%有效吞吐增幅低于厂商峰值指标，反映混合装机与配方损耗，不是已披露客户表现。

本报告C基准路径因而允许台数/标准能力需求基本平坦，而通过机型组合、维护和应用扩展维持收入增长。悲观路径则允许生产率释放、掩膜复用和客户减少取样，使C出现结构性收缩，即便EUV晶圆总量继续增长。

### 4.3 先进封装：新增层、不可逆步骤与失败成本

封装报废会损失已完成的逻辑和存储裸片，因而检测前移有价值。但检测并不能修复所有缺陷：键合前筛除坏件、量测翘曲/高度、键合后发现空洞、最终电性测试，分别解决不同问题。“Known Good Die”也不等于之后的键合和热机械可靠性一定合格。

已采用路径包括RDL/凸点/TSV几何检查、封装晶圆形貌和材料量测；Nova WMC的厂商公告明确指出，在竞争评估后获一家全球代工客户tool-of-record资格，并已有多家存储及代工客户部署。匿名披露支持采用阶段判断，但不能推断客户身份、装机台数或实际贡献收入。[S20][s20]

更前沿的路径是键合后埋藏缺陷的高覆盖检测。imec与EVG在2026年5月报告200nm互连间距的W2W测试结构，并给出全300mm晶圆所有die的Cu pad键合后overlay向量低于40nm。这是测试载体及特定量测结果，不是所有商业芯片全流程良率，也不是D2W流程已经获得相同性能。[S19][s19] IBM的ECTC工作展示用相干X-ray方法表征细间距Cu晶粒，证明新的物理信息可获得，但没有证明全片在线吞吐已满足量产成本。[S29][s29]

**不要求混合键合全面替代焊料路线，D也能增长**：更大封装、更多RDL/TSV/凸点和更薄晶圆已经提高过程控制任务。混合键合如果延后，会改变AFM、表面颗粒、Cu凹陷和键合后检查的份额，但不会使全部封装检查消失；若混合键合减少凸点相关步骤，也会淘汰部分旧测量任务，不能把新增与旧任务永久同时保留。

### 4.4 AI算法既能增加设备价值，也能减少设备需求

AI缺陷分类、配方生成和虚拟量测的直接价值在于节约工程师时间、降低误报、缩短学习周期。若更高生产率支持检测原本经济上不可覆盖的区域，需求扩张；若工艺成熟后可用设备传感器和模型替代实测、减少复检和取样，外购设备需求下降。

算法不能在没有新物理信号和有效校准的情况下可靠发现全部未知缺陷。小样本、分布变化、漏检责任和跨厂数据不可共享，限制了“通用模型替代专用仪器”。晶圆厂控制工艺配方和失效标签，设备商控制仪器响应和跨机校准；**价值可能在双方之间重新分配，而不是全部归属软件订阅**。当前没有足够独立披露支持单列一个巨大、额外的“AI检测软件TAM”，故只在S纳入可外购变现部分。

## 五、有效供给与价格：瓶颈在能力组合，不在统一的“设备产能”

### 5.1 从厂房到客户可用工具，至少有五道转换

设计完成→部件齐套→整机装配/标定→稳定重复性能→客户工艺认证及可安装现场。名义装配能力不是有效供给；有效供给也不必在同一会计期间确认为收入。

KLA将设计、组装和测试保留在内部，外购部件与大组件，主要制造活动分布在美国、新加坡、以色列、中国和欧洲。Nova不同技术分别在以色列、美国和德国生产，新客户/产品/应用的销售周期可能超过12个月。Camtek2025年资本支出约22.5百万美元，用于产能、研发和运营；其年报确认存在单一/有限来源部件，但截至年报时仍能及时取得满足需求的组件。[S01][s01] [S22][s22] [S21][s21]

这些证据支持“供应商在扩张且认证存在时间成本”，**不支持公开可核的全球台数产能**。本报告因此使用各子池2025已实现交付能力=1的标准篮子指数；将2026—2030的装配资源增加、部件齐套、良率和客户资格转换作为供给侧假设，单独于客户需求侧估计。指数只在同一子池内可比，不把电子束设备、光学设备和AFM相加为等价台数。

### 5.2 供需交叉判断和时滞

2026基准模型的D/K（需求/可交付能力）约为：A 0.99、B 1.00、C 0.89、D 0.96，整体没有严重总量短缺；A/B紧贴交付边界，配方、地域或客户安装计划的错配足以造成排队。2027基准D/K约0.98、0.96、0.88、0.94，反映扩产逐渐释放。**这不是观察到的实际利用率**，而是独立供需参数交叉后的条件判断。

2027乐观需求超过模型合格能力的比例约为A 8%、B 8%、C 4%、D 10%；供给不足部分是当年延期/缺交的需求，不自动成为下一年收入，因为客户可能取消、重新设计或用旧机替代。悲观分支仍保留已经承诺的供应商扩张，故会出现更大闲置和价格压力，不能用需求下降自动同步削减供给来制造平衡。

时滞的研究假设为：成熟机型的增班、备料和部件扩容约2—4个季度；新工具在既有客户扩层约2—6个季度；新客户/新工艺或新物理方法往往超过4个季度，复杂情况下可达2—3年。这些范围是本报告用于建模的工程判断，Nova超过12个月的销售周期为部分支持，并非各家公司统一交期。价格通常在新订单、配置变更及年度合同中体现；在手合同不能因市场偏紧立即全部重定价。

### 5.3 价格与成本的传导

公开资料缺少同规格逐笔净成交价格。本文将未来P拆成：**同功能实际净价×产品代际/配置组合**。前者受到大客户折扣、竞标、第二来源与政策影响；后者可以随更复杂光学、电子束通道、计算硬件和量测模块增加而上涨。所有模型P均为实际收入篮子的推断，未将公司收入/季度系统数误当同型号ASP。

A/B高端价格可由节省良率学习时间支撑，但存储、计算、光学、运费或关税成本不保证全额转嫁。KLA7月材料仍提及内存价格和关税的不利影响，服务组合和制造规模对其有所抵消。[S04][s04] C的高价机型若大幅提高吞吐，客户每次扫描成本可以下降；供应商ASP增加与客户单位检测成本降低能够同时发生。D的尺寸、搬运和精度要求提高可提升配置收入，更多竞争者又可能压低同规格净价。

政策影响落实在**可卖给谁、可提供什么升级和维护、备件等待多久**。截至截止日的BIS规则仍包含先进节点及半导体设备最终用途控制；具体交易应按设备分类、最终用户、最终用途和许可判断，不能用“中国销售”一个标签一概归零。[S27][s27] 在经济模型中，受限海外产品减少可交付份额；本地替代先扩大试用和资格投入，只有验收后才成为有效供给。中国可达市场的碎片化既可能增加冗余采购，也可能导致全球工具利用率下降。

以色列相关制造、研发和现场支持在Nova、Camtek及部分大厂中有重要位置。地缘冲击的实际渠道是员工可用性、物流、供应商和客户验收，而非笼统提高所有厂商价格。本报告将其纳入K及成本的宽区间；未宣称截止日发生了未经证实的特定停产。

## 六、价值捕获：客户回报、供应商经营杠杆与竞争地图

### 6.1 一台设备的资本回收，为什么取决于漏检与误杀

以下为**研究示例（I），不是设备报价或某晶圆厂实绩**。客户购买一台检测设备，初始投资3.0百万美元，经济寿命7年，末年残值0.15百万；第4年必要更新0.4百万；每年维护、人员、占地和能源现金成本0.5百万。稳定期处理36万次与该任务匹配的晶圆检测，第一年爬坡仅50%。每次对应10,000美元可被保护的在制价值。假定设备造成的误杀损失率为0.015%，有效救回率δ表示**相对于既有检测方案实际少损失的在制价值比例**，已包含漏检、缺陷可修复性和采取行动的有效性。

年度净避免损失=检测次数×10,000×(δ−0.015%)；现金流再减运营成本与必要更新，末年加残值。用10%折现率计算：

| δ，绝对百分点 | 稳定期净避免损失/年 | 第1年净现金流 | 第2—3、5—6年净现金流/年 | 第4年/第7年现金流 | 7年净现值 |
|---|---:|---:|---:|---:|---:|
| 0.030%（3个基点） | 0.54百万美元 | -0.23 | 0.04 | -0.36 / 0.19 | -3.25百万美元 |
| 0.050%（5个基点） | 1.26百万美元 | 0.13 | 0.76 | 0.36 / 0.91 | -0.07百万美元 |
| 0.080%（8个基点） | 2.34百万美元 | 0.67 | 1.84 | 1.44 / 1.99 | +4.70百万美元 |

共同初始现金流为-3.0百万美元，表内没有把避免损失虚构成客户营业收入。当前假设的盈亏平衡δ约**0.0504%**，是研究阈值，不是行业标准。若取样任务量减半或第一年爬坡更慢，即使检测灵敏度相同，回报也会恶化；如果可保护的在制价值增加，客户可支付预算提高。对于最终封装，需改用封装件数及真正可避免的报废/复测损失，不能把全部芯片销售价作为可救回价值。

这个机制如何收敛到行业规模：每个工厂并不会为每种缺陷复制购买一台工具，而是在整个工具组合中分配测量任务。附录以客户设备投资、增加的关键层/任务量和单机生产率估计新增采购，并以独立交付能力封顶。因而上述例子解释支付阈值，行业模型约束能达到阈值的采购规模，两者没有直接把单台回报乘以全球晶圆数量。

### 6.2 谁更容易将增长变成利润

A具有高额持续研发、既有工艺数据库和客户迁移成本，龙头最容易摊薄固定费用。B中材料量测和集成量测的价值来自更强参数可识别性及独特探测手段，细分赢家可能比整个平台市场增长更快，但多家供应商仍各有不可替代能力。C集中度高而订单周期长，吞吐提高造成的台数压力不能忽略。D增长基数较小、竞争和产品迭代强，量增不代表每家同幅利润扩张。S受装机与合同覆盖支撑，服务需要人员、备件和长期系统支持，毛利不能套用纯软件口径。

本报告不报一个伪精确行业ROIC：不同公司对研发全部费用化、收购无形资产、商誉、现金及营运资本的处理差异很大，细分投入资本亦未充分披露。KLA的现金转化证明其盈利质量较强，却不能证明所有入场者都能获得同等回报。中科飞测2026H1亏损和精测电子半导体板块已盈利，恰好说明“国产厂商”也不能合并成单一经营模型。

营运资本的特别风险是：设备已发往客户、仍在试用或等待验收时占用存货与应收资金；收取预付款则改善现金但附带交付义务。订单积压没有统一取消条款，不能按“积压/当季收入”直接当作确定收入年数。扩产所需的演示机、标定工具、备件和并购现金，也不能只用生产厂房资本支出来衡量。

### 7.2 需求侧与供给侧的独立计算

设备需求指数D=预算/任务指数B×每单位预算的检测任务强度L÷有效生产率T。D表示相对2025年**年度新增采购/替换所需的标准工具篮子**，并非全行业存量装机或所有在产晶圆的测量次数。B/L已扣除继续由旧机承担的任务；复用和动态取样在T中体现。S的D则是可收费存量合同/许可证当量，直接填写，不套物理设备产能。

A/B的预算背景以2025 WFE 116.9 bn为参照。采用的2026/2027/2030预算为：

| 路径 | 2026 | 2027 | 2030 | 约束和机制 |
|---|---:|---:|---:|---|
| 悲观 | 135 | 123 | 140 | 2026仍受已执行投资支撑，2027订单消化/延期，2030仅温和恢复；成熟节点与效率节约抵消部分先进投资 |
| 基准 | 143.9 | 175.3 | 215 | 前两期接近SEMI7月预算路径；2030靠近KLA长期行业框架中心但调整为本模型预算锚，非两家口径已完全等同 |
| 乐观 | 154 | 195 | 295 | 多客户并行扩产、存储工艺/容量双增、三维路线扩展；2030明显高于已披露长期框架，需要新增采用和资本供给 |

上述是**本报告假设**，只有被标记的SEMI原值是其正式预测。公司总资本预算并不能直接转为WFE，故TSMC/Micron/韩国客户资料用于检验方向和财政承受能力，不重复相加进入这张表。

A的L反映新的关键检查层及更广覆盖；B的L反映材料/深度/应力等额外量测任务；C的B为掩膜数×复检频率×新客户覆盖的采购任务指数；D的B为封装产线扩张及每片/面板新增检测任务的合成指数。其增长上界受新产线资格、可处理面积和客户成本阈值约束，下界允许取样减少及工艺替代。具体数值全部保留在附录。

供给侧K=2025标准篮子交付基数×装配及部件资源扩张×合格转换系数。附录K由供应商产能反应、部件和认证阶段设定，**没有取D的某个固定比例**。例如2026基准A/B/C/D的K分别为1.23/1.30/1.10/1.45，对应假设资源指数约1.34/1.45/1.22/1.60，再乘约0.918/0.897/0.902/0.906的齐套与资格转换系数；这些不是企业披露产能。悲观下已经投入的资源仍会释放，乐观下资格与部件限制令K小于D。

最终可兑现收入R=R₀×min(D,K)×P。**金额增长来自篮子数量和价格/组合两个不同因素**；K不含ASP。P是相对2025的净价×配置/机型组合，不是全行业统一涨价率。

经营利润OP=R₀×{min(D,K)×[P−(1−g₀)×c]−e₀×f}。其中g₀为工作基数毛利率，e₀为研发及销售管理费用占R₀比例，c为标准篮子单位成本指数，f为年度固定/准固定费用指数。参数用于估计供应商层的营业利润，不是客户利润或整个产业增加值；主要剔除收购摊销、融资、所得税及非经常损益，持续研发、日常费用及正常人员激励应由e₀/f承担。按该经济口径，不能与各公司GAAP净利润直接比较。

### 7.3 情景含义、概率与突破

**悲观：需求消化、生产率替代和竞争压价。** 2026仍增长，2027客户削减新增设备；高端供给扩张后出现闲置。C受生产率替代最强，D虽有更多封装任务，却受到第二来源和平台报价竞争。服务增长慢于装机且客户自行维护比例提高。该路径的收入与利润方向没有被强行设置成全负。

**基准：先进投资兑现，供给逐步跟上，材料/封装占比提高。** 2026H2交付提速，2027新厂和新工艺延续，但2028以后增速放缓。检测任务增长与效率提升并存，A/B的复杂性溢价部分保留；C靠组合而非台数驱动，D增长快且利润率受竞争约束。基准由客户预算、已实现节点收入和重复采用支持，而不是上下限的平均。

**乐观：多类三维任务扩大，客户覆盖与产线扩张同时推进。** 需求超出现有合格能力，新供给经过资格后逐步交付；客户愿为信息质量和产线进度支付更高配置价格。供应链扩张和研发仍消耗现金，收入不会全部转化为利润。2030的高收入需要295 bn预算背景、更多关键检测任务和较低单位工作量替代，单纯内存/芯片价格上涨不足以实现。

情景是三套可审查条件组合，**不是互斥完备的概率分布**，不赋予合计100%的伪精确权重。以下给出有经济成功标准的主观事件概率；这些相关事件不可直接相乘：

| 事件与目标期 | 概率性质及范围（I） | 依据、主要未知与更新条件 |
|---|---|---|
| 2027核心设备收入高于2025同口径、同汇率收入至少20% | 无条件事件概率约65%—80% | 客户预算及既有订单支持；新工艺销售周期和2027订单撤回仍不确定。若连续两季客户削减资本预算且三家主要供应商新订单同步收缩，下调 |
| 2027 D收入达到至少2.7 bn，即本模型工作基数的1.5倍 | 无条件事件概率约55%—70% | WMC采用、封装流程复杂性支持；KLA扩大份额不能替代行业增长证据。若多客户复购与实际验收扩大，上调；若取样/机型效率抵消工作量，下调 |
| 2030至少一种新的键合后埋藏缺陷无损检查路线，实现≥0.5 bn/年外部设备收入 | 无条件事件概率约20%—35%；跨情景事件 | 有研究演示和专用厂商，缺少全片吞吐、客户持续部署及良率回报证据；需量产复购和每小时可检面积显著改善 |
| 上述突破已经跨过≥3家互不关联客户量产资格、可证明单位检测成本可接受后，3年内达到0.5 bn/年 | 给定上述资格与成本条件的成功概率约45%—65% | 条件概率不能当无条件概率；三家客户可能规模很小，仍须验证每家批量采购和非重复统计 |

这些概率来自本报告对已采用技术与新仪器长期资格过程的主观评估，并无可用统计样本校准，故使用宽区间。首个商业案例的概率显著高于达到0.5 bn/年规模的概率，不能混用。

**突破分支的数量桥梁**：若到2030有15—30条生产线，每条实际配置4—8台专用埋藏缺陷检测工具，净价3—5百万美元，并在2年内交付，则对应**0.09—0.60 bn/年的新增设备收入**。超过0.5 bn只靠该样本需要接近上线条数、单线配置和价格的上界，或更多客户；这解释了为何不把科研进展直接视为十亿美元市场。按毛利50%—60%、年度增量研发/应用费用0.05—0.10 bn，营业贡献可为负至约0.31 bn；客户工程支持、备货和演示机还会消耗现金。该收入属于D或B的新增任务，已有部分可能包含在乐观情景，**不能再全部加到总量**。此分支不专属于一个母情景，不做无效的条件概率相乘。

2026乐观情景的收入和利润更高，但自由现金流低于基准，原因是扩产和备货更快；这比给所有变量同时上调更符合设备供应链的经济约束。2027悲观FCF可因增长停滞和营运资本占用变化而高于2026，不能将现金改善误认为需求改善。

**主要敏感性（C/I）**：

- 在未受供给限制时，D提高10%大致使对应设备收入提高10%；已经受K封顶时只增加排队，不增加当年收入。
- 2027基准A、B的单位净价/组合P各提高1%，在成本和销量不变时，营业利润分别增加约0.108和0.079 bn。若只是更昂贵配置导致P上升，应同时提高c，不能全算利润。
- 2027基准D，T额外提高20%且客户不增加覆盖，D及收入约下降16.7%；如果客户将节省的扫描成本完全转成更多覆盖，则收入可能保持不变。两种行为是关键可证伪分歧。
- 2027基准总收入30.76 bn下，营运资本占收入比率比设定高3个百分点、而上年占用不变，会减少当年自由现金流约0.923 bn；资本支出比率提高1个百分点，减少约0.308 bn。
- 以年度折算汇率140—160日元/美元计算，1000亿日元约0.625—0.714 bn。本文未把该假设当作实际平均汇率；它仅约束C/服务分拆的量级，不能由汇率变化认定设备真实增长。
- 对所有子池，当前市场边界误差不会随着预测年份自然消失；需先获得同口径供应商拆分，再考虑收窄模型区间。

研究的竞争性假说应同时保留：

- **复杂性主导**：更多关键层和不可见结构使过程控制预算强度长期提高。支持证据是客户先进节点出货、材料量测和封装采用；反证是同流程工具小时/资本强度持续下降。
- **学习与效率主导**：新品初期密集测量，成熟后动态取样、吞吐提高和工具复用压低采购。支持证据包括新机型效率提升；反证是工艺成熟之后客户仍持续增加覆盖和重复工具采购。
- **份额迁移被误认为行业增长**：KLA等平台进入D、Onto并表、国产替代可造成公司高速增长而行业温和增长。区分方法是相同任务的供应商净收入加总，而非挑选赢家增速。
- **受限市场冗余建设**：区域分割增加试用与第二来源采购，却降低全球资本效率。需要观察本土验收后能否替代，而非长期并行占用两套工具与工程师。

### A2. 参数范围如何还原

下表列每个代表参数的上下偏移。对D/K/P采用相对变化，例如D=1.50、偏移12%，区间为1.32—1.68。R₀使用第7.1节独立基数上下界，不把基数误差归因于景气。

| 子池 | D偏移：2026/2027/2030 | K偏移：2026/2027/2030 | P偏移：2026/2027/2030 | 原因 |
|---|---|---|---|---|
| A | ±4% / ±8% / ±15% | ±5% / ±10% / ±20% | ±2% / ±4% / ±8% | 已有收入规模大，近端较可约束；长期取样和平台竞争不确定 |
| B | ±6% / ±12% / ±20% | ±6% / ±12% / ±22% | ±3% / ±5% / ±10% | 材料/参数多样、客户资格及模块组合差异 |
| C | ±10% / ±18% / ±30% | ±8% / ±15% / ±25% | ±5% / ±8% / ±15% | 掩膜复用、长验收周期及新机型速度改变工具数量 |
| D | ±8% / ±15% / ±25% | ±7% / ±15% / ±25% | ±4% / ±7% / ±12% | 新工艺、面积/覆盖、技术竞争和封装路线变动 |
| S | ±2.5% / ±6% / ±15% | ±3% / ±6% / ±15% | ±1.5% / ±3% / ±7% | 存量支持近期收入，远期受客户自维护及服务限制影响 |

c在2026/2027/2030采用±4%/±8%/±15%，f采用±5%/±10%/±20%。c上界来自配置复杂、元件/人工及供应受阻成本，下界来自设计降本与规模；f不能随销量立即下降，故保留固定费用风险。当前g₀/e₀也未审计验证；若另将g₀或e₀各改变3个百分点，营业利润约改变对应销量成本或R₀×f的3%，应在现有模型外单独检验，不暗示现有范围覆盖所有误差。

**范围定义**：下表括号是上述参数与基数误差同向叠加的条件压力上下界，不是置信区间，也不是各景气路径发生的概率范围；上下界的所有极端条件未必能同时发生。上下界重叠不表示悲观、基准、乐观被混为一类，三类区别在于客户采用、供给反应和价格机制。远期范围宽反映真实不可识别性，而不人为收窄。

还原方法：v低=min[D×(1−dD),K×(1−dK)]，v高对应加号；收入下限=R₀低×v低×P低，上限对应高值。利润下限用低销量、低P、高c、高f，再在R₀低/高两个端点取最小值；上限用高销量、高P、低c、低f，再取最大值。故当低端经营结果为负时，较大业务基数可能带来更大亏损。主表的需求未交付比例=max(0,1−K/D)。
