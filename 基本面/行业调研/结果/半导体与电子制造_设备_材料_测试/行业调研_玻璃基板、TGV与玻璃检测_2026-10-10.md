# 玻璃基板、TGV与玻璃检测行业调研：从可加工玻璃走向可交付封装，价值取决于整件良率与客户认证

**研究截止：2026年10月10日。** 研究地域为全球，重点覆盖美国、日本、韩国、中国大陆及中国台湾的半导体封装供应链。事实使用截至截止日公开的信息；2026全年、2027、2028、2030数字凡未注明“披露事实”，均为本报告条件估算。财年与自然年分别保留，不把季度收入机械年化为已实现收入。

本次独立研究只使用 `基本面/产业背景/结果/` 内资料提供检索线索，并通过外部原始材料重新核验；未使用其他本地公司、行业、排序或投资决策报告作为研究输入。公司产品网页没有公开日期时，注明“未标日期，2026-10-10访问”，只用来证明供应商提供的能力边界，不据此判断首次商业化时间。本文中“事实”是公开披露，“目标”是管理层路线图，“计算”是公式直接结果，“推断”是研究判断，“未知”意味着尚无可核验的量、价或资格认证披露。

## 一、最重要的判断与适用边界

**第一，玻璃芯大尺寸AI/HPC封装仍处于从工程验证向首批付费采用过渡的阶段；TGV本身已有商业用途。** SKC截至2026-09-22仍将嵌入式产品定位于可靠性测试、非嵌入式产品定位于年底前PoC准备。相对地，Menlo Micro在2025-11-20已披露Ideal Switch累计出货达到100万件，其技术页说明采用含铜合金TGV的密封玻璃封装。前者与后者在尺寸、孔数、热循环、客户失败损失上差异很大，不能彼此替代量产证据。[SKC最新商业进度公告](https://skc.kr/m/eng/Conmmunication/pr/newsDetail.do?gubun=&seq=1746)、[Menlo累计出货公告](https://menlomicro.com/newsroom/menlo-micro-hits-one-millionth-ideal-switch-shipment-setting-new-standard-for-switch-technology)、[Menlo封装技术](https://menlomicro.com/technology/innovation)

**第二，关键约束更可能是完整封装的良率、可靠性、认证和资金承受力，而不是玻璃熔融总量或单台激光的最高速度。** 玻璃可以改善平整度和尺寸稳定性，却增加铜与玻璃应力、边缘损伤、金属化覆盖、切割和失效筛查的工程责任。一个有5万通孔的器件，要让独立单孔致命缺陷带来的整件良率达到95%，单孔缺陷率须低于约1.03ppm；这只是研究计算，真实相关缺陷会使简化模型失效。详见第四节。

**第三，收入拐点与利润拐点可能相隔数年。** 沃格光电的湖北通格微在2026上半年披露营业收入334.07万元、营业利润-4,691.93万元、净利润-4,693.61万元；这提供了一个已经销售但远未覆盖投入的直接样本，不能外推其亏损率至整个行业。LPKF披露的扩线意向则可能使设备收入先于成品基板收入发生，相关设备并未因此获得持续复购或高资本回报的保证。[沃格光电2026半年报，第20–21页](https://static.cninfo.com.cn/finalpage/2026-08-26/1225505147.PDF)、[LPKF 2026-09-23扩线意向](https://www.lpkf.com/en/news-press/press-releases-teaser/leading-asian-advanced-semiconductor-packaging-manufacturer-selects-lpkfs-glass-processing-equipment-for-production-ramp-up)

**第四，最有依据的基准是选择性采用。** 大尺寸、高I/O、供电和翘曲成本较高的产品先采用，较小器件继续使用有机基板、硅中介层、局部硅桥或其他组合。台积电在2026年4月已经披露生产5.5倍光罩尺寸CoWoS，并把14倍光罩、约10个大计算晶粒与20个HBM堆叠的版本列为2028目标。这些方案可以与玻璃共存，也可能延长现有方案的经济寿命，公告没有把相应全部封装指定为玻璃芯。[台积电2026-04-23公告，论坛发生于4月22日](https://pr.tsmc.com/english/news/3302)

**第五，市场规模应围绕可交付产品，而不是把所有“玻璃相关”收入相加。** 本文核心量化池G1是全球**对外销售的大尺寸AI/HPC永久玻璃芯成品封装基板**，包含约定的RDL/增层，不含计算晶粒、HBM、硅中介层价格、封装装配服务和系统价格；纯内部自用不计入商售收入。原玻璃、金属化TGV芯、加工设备及检测设备分别是供应链收入池，其中多处嵌套，不能相加为终端需求。

**最强反证**是有机/硅/桥接路线持续进步，玻璃的系统收益未必覆盖切换风险和全流程成本；玻璃供应商可能先花钱、后接受客户降价。**最关键未知**是客户具体量产BOM、逐季复购、整件良率、末端逃逸缺陷、真实成交净价及生产资产利用率。它们决定本报告的条件机会能否成为企业现金流。

## 二、行业边界、采购任务和谁承担失败

### 2.1 六种“玻璃”对应不同经济活动

| 对象 | 客户实际任务和采购单位 | 商业阶段／支付来源 | 本报告量化处理 |
| --- | --- | --- | --- |
| 永久玻璃芯成品封装基板，G1 | 在大尺寸封装中支持芯粒、HBM互连和供电；按合格件、规格、增层数采购 | 先由封装设计/材料团队验证，采购与质量团队准入；进入芯片或封装BOM后，主要替代既有基板成本，部分因新功能增加预算 | 核心商售池；晶粒、HBM、最终系统支出均不加入 |
| 玻璃中介层、玻璃RDL平台 | 在芯片间或光电器件间承载更细互连、无源器件或光波导 | 可能替代部分硅中介层，也可能与硅并存；对线宽、热与组装的要求不同 | 纳入技术分析；只有其功能已含在G1报价时才含于G1，单独销售另列且不混同 |
| 原玻璃、精密薄化/抛光玻璃 | 合适的CTE、TTV、洁净度、表面和边缘品质；按m²、晶圆、面板采购 | 材料与加工费；合格牌号往往随工艺共同认证 | G1所消耗的原玻璃收入为嵌套上游池 |
| 成孔、蚀刻、种子层、铜填充后的TGV芯 | 得到可进行RDL/增层的导通结构；按合格芯/面板或代工批次付款 | 可由成品厂自制，也可采购外部芯；承包边界决定谁支付报废 | 单列外部商售金属化芯，包含其玻璃，不把纯加工费再重复相加 |
| 临时玻璃载板/carrier | 支持薄晶圆、扇出、面板加工，之后解键合；按载板、使用次数、清洗或租赁付款 | 已有商业需求；重复使用使采购量与工艺通过量脱钩 | 作为相邻成熟池分析，不算永久玻璃芯渗透率 |
| 玻璃/TGV检测、计量及设备 | 在原片、成孔、金属化、RDL、切割等节点控制缺陷与尺寸；按设备、验收、服务/软件付款 | 多为封装厂/基板厂资本预算；客户研发期已可购机 | 量化G1相关新增设备，存量和收入流量分开；不把全部先进封装检测营收归给玻璃 |

普通LCD/OLED显示玻璃、手机盖板、ABF中的玻纤布或低CTE玻纤原料，不属于永久玻璃芯封装基板的同一市场。Mini/Micro LED用玻璃线路板、RF/MEMS、医疗微流控中的TGV可以属于玻璃微加工，但终端任务和ASP差异极大，分别讨论，不用它们证明AI封装已通过认证。

半导体/封装厂是直接客户，芯片设计商通常对电气设计、可靠性和BOM拥有决定权，服务器/OEM与终端机房承担停机和现场失效成本。材料供应商先承担研发、工艺适配和资格认证费用；如果芯片已装上去后才发现玻璃裂纹，合同、失效归因和赔偿上限比原玻璃每平方米价格更影响供应商的经济责任。公开文件尚不足以判断实际各厂赔偿条款。

G1“最终需求”是本专题的终端部件支出，并非全社会最终消费。一笔成品基板支出同时形成玻璃、化学品、芯代工和设备折旧的收入；设备购买还是跨年的资本流量。本文不提供上述池的加总TAM，也不把收入当增加值。Intel等内部采用的利益可能体现在系统售价、代工服务或自身制造成本中，而不表现为可单独确认的玻璃基板收入。

### 2.2 已商业化不意味着同一产品已规模化

Menlo的商业累计出货是较小玻璃密封器件的事实证据，累计100万件**不是2025或2026年出货100万件，也不是100万片玻璃晶圆**。沃格通格微的披露是TGV相关子公司的收入，产品含多种应用，无法拆出AI大尺寸玻璃芯部分。因此全球G1当前收入仍不可从这两个样本加总得出。

临时载板已有供货产品。Corning说明先进封装载板可用于临时键合、减薄与扇出；AGC SWAN同样是工艺载板。它们的销量可能随着扇出和面板化增加，但每块载板可以重复通过工艺，不等同于每件最终封装新增一块玻璃。[Corning载板产品，未标日期，截止日访问](https://www.corning.com/worldwide/en/products/advanced-optics/product-materials/PrecisionGlassSolutions/advanced-packaging-carriers.html)、[AGC SWAN，未标日期，截止日访问](https://www.agc.com/en/products/electoric/detail/swan.html)

半导体设备工艺被基板厂认定合用，与芯片客户接受该基板的完整电气、机械、可靠性和供货责任，是两个资格门槛。LPKF公告没有公开客户名称，不能猜测为某家GPU、晶圆代工或玻璃芯企业后再增加“独立证据”。

## 四、技术如何变成客户回报：整件失效率比最好看的孔更重要

### 4.1 玻璃解决什么，又增加什么

玻璃的尺寸稳定、平整度和可调热膨胀系数有利于大面板精密图形、降低翘曲与提高叠层对位。客户愿意支付的实际价值是：在同样合格可靠性下，容纳更多计算/存储、更细线宽、更稳定组装，或降低每个可用系统的制造与运行成本。互连密度提升没有独立收入，只有它改变客户BOM、封装良率、性能或总成本时才有经济意义。

玻璃不是天然高导热散热材料。匹配硅的低CTE也未必同时匹配铜、RDL和主板；应力可能移到孔壁、铜/玻璃界面或边缘。不同玻璃成分还改变介电损耗、蚀刻选择性和金属附着。IEEE EPS先进基板技术委员会的2025年11月更新综述讨论了TGV成孔、金属化和RDL/切割应力引发裂纹的取舍；它是技术委员会综述，不是量产验收报告。[IEEE EPS技术综述，2025-11，第2–7页](https://eps.ieee.org/wp-content/uploads/2025/11/Glass_Substrates_Adv_Substrates_TC_UPDATED_Nov25.pdf)

因此，不能把“全铜填充TGV耐热循环”扩展成“整个大尺寸HPC封装在全部工作条件中可靠”，也不能把常温平整度扩展成回流焊、板级热循环和现场寿命下的同等结果。

### 4.3 可复算的良率和失败成本阈值

令每件有n个通孔，单孔致命缺陷概率d，先假设独立，则：

`Yvia = (1-d)^n ≈ exp(-n×d)；d上限 = -ln(目标整件良率)/n`

| 通孔数量n，研究示例 | Yvia≥95%时的d上限 | 解释 |
| --- | --- | --- |
| 10,000 | 5.13ppm | 即使单孔看起来非常好，累积后也有整件损失 |
| 50,000 | 1.03ppm | 大尺寸、多I/O产品对缺陷尾部更敏感 |
| 100,000 | 0.51ppm | 更高密度提高客户价值，也提高统计证明成本 |

这些n是敏感性示例，**不是所有AI封装都必须有相同孔数**；并联冗余、可修复性和非致命孔会降低要求，整板污染/边裂等相关失效会提高损失。零缺陷样本数为m时，独立同分布假设下95%单侧上限近似3/m：只展示1,000个零缺陷孔，上限仍约3,000ppm；要把上限压到0.5ppm，需约600万个独立观测。热循环的试片数量、测到的失效类型和全流程缺陷不是同一统计总体，不能拿该计算否定具体可靠性试验，也不能拿一次试验宣称量产尾部已经解决。

对买方，若晚期失效使已经装入的合格晶粒、HBM和装配价值V受损，玻璃基板增加100美元成本，则其通过降低失效率获得的简单盈亏阈值为 `Δ失效率 > 100/V`。在**假设**V为5,000–20,000美元时，阈值是0.5%–2%。这里V不是公开GPU/HBM采购报价，示例说明晚期失效风险可能高于材料溢价。客户也可能因带宽、功耗或装配功能付钱，但必须把这些收益与同一系统边界的成本比较。

这导出一个反直觉机制：降低最终缺陷需要更多检测和更严格筛除，前期会提高被报废的玻璃和芯数量，却可能降低昂贵封装的总损失。检测单位收入可以上升，同时原玻璃/芯供应商的合格件成本恶化；等过程稳定后，检测抽样和重用平台又可能减少增量购机。

### 5.2 供给估算没有用需求量倒推

G1的合格供给独立写作：

`S = C × u × f × Y × k ÷ a`

C是完整成品链的名义年投入玻璃面积；u是爬坡、维修及全年可运行时间系数，**不由订单数量反推**；f是排版/边缘面积利用率；Y是全流程良率；k是可对研究目标规格/客户交付的合格比例；a是单件面积。订单不足形成的闲置另以Q/S表示，未藏在u中。k反映已经完成资格的比例，Y反映工艺中通过的比例，两者不同。

G1供给不是把原玻璃厂、TGV加工厂、RDL厂分别的m²相加。它只计可完成并对外销售成品的链，取各必需工序中限制交付的能力。Intel未向外提供成品的内部研发能力不计商售C，三星合资原芯也不作为一条成品线再次相加。

C的代表路径为2027年2万/4.5万/7万m²，2028年4万/8万/14万，2030年8万/20万/42万。它们是**按历史12,000m²设计量级归一的完整链等效扩线组合**，并非逐厂公开产能加总。2028基准8万m²约为6.7个该量级的等效单元，2030约16.7个；只有现有厂爬坡、DNP/三星等未来环节形成完整链及后续扩线能支持这种路径。历史12,000m²原披露未说明是投入还是成品，本文把它作为量级锚点并重新定义C为投入面积；若原值是良品出厂面积，不能直接代入本文公式。该口径差异是供给模型的一项重大不可识别处。

2028基准的合格S约152万件，对D约104万件有约46%余量；若实际有客户/规格不能互换的线，仍可能局部短缺。2030基准a增至0.018m²，即约134mm边长的面积等效件，C增加却被面积、爬坡和资格折减，S约544万件，低于D的648万件。**从2028的潜在闲置到2030的规格紧张，关键不只是需求增加，还在于每件占用面积和目标资格改变。**

独立上游估计见附录B：2028基准裸玻璃合格供给7.5万m²，对实际消费约2.67万m²；金属化TGV芯合格供给约284万芯，对最终交付所需约121万芯。2030分别为20万m²对14.4万m²、918万芯对604万芯。其供给参数单独设定，未反向用销量构造“平衡”。这支持一个**条件性瓶颈迁移判断**：原玻璃/成孔与金属化供应先形成，完整RDL、边缘可靠性、组装及客户合格能力更可能限制终端放量。

整条链应最终取最小值：\`S链=min(S成品环节，ST×Ypost，S原片×f×Y/a)\`，三项均先换成件/年，再与D比较。附录代表值的上游供给均未压低成品S，故Q保持不变；压力范围的某些组合会先卡在原片或芯，届时必须缩减Q，不能保留成品表的上端交付量。CT与成品C来自不同工艺/客户组合，其平均YT不直接与Ypost相乘冒充每一条工艺线的总良率；某具体工艺链须有相同产品和同一批次的分段良率，才可连乘。

上述上游供给也没有公开全面产能统计；主要依据是多家材料商已有规格平台、芯加工环节可以独立于完整成品扩线，以及已披露的建设/验证阶段。若高品质原片、种子层或特定玻璃配方只有一条客户合格路线，上游的结构性不足可以推翻该判断。

### 5.3 原玻璃体量、价格与议价时滞

原玻璃需求量可作物理交叉检查：2030基准消费14.4万m²，假设厚0.5mm、密度2,500kg/m³，约180吨/年；乐观代表值33.91万m²约424吨/年。这不是工厂可交付吨数，只说明难点不一定是新增庞大熔融总量。薄化、TTV、洁净、边缘和合格配方若不能匹配，吨数充分也不能交付。

没有发现可核验的工业大批量玻璃芯、金属化芯或成品基板净报价序列。WaferPro公开目录中的200mm Borofloat玻璃晶圆报价73美元，对应约2,324美元/m²，是小批量目录标价，规格与批量不同，**不能写作AI玻璃原片成交价**。本文700–1,400美元/m²代表值及宽范围用于规模采购/品质加工压力测试，折价程度仍未知。[WaferPro直接供应目录，未标日期，截止日访问](https://waferpro.com/)

当存在紧张，价格可先通过加急费、预付款、最小采购量、共研费或容量保留条款表现，而非所有产品统一涨价；目前未找到相应合同可核定实际采用。成本改善通常先于年度降价谈判，客户多源认证后可把良率收益收回。本文给**6–18个月**从成本/供应变化传导至续约净价的条件时滞，不称行业标准。价格下降既可能是同规格降价，也可能是较少RDL层/较小封装或材料边界改变，应按相同产品、规格、交付单位和期间比较。

Camtek截至2026-06-30季度收入1.332亿美元、GAAP毛利率50.1%、经营利润率20.4%；这只能说明成熟先进封装检测平台可能有良好的集团经济性，**不是玻璃检测已实现同样利润率**，更不是玻璃业务收入。[Camtek 2026-08-10财报](https://www.camtek.com/news-and-events/camtek-announces-results-for-the-second-quarter-of-2026/)

成品厂利润的主要驱动是Q、净ASP、合格件变动成本v、固定现金费用与折旧。原玻璃厂更受合格规格、品质加工成本及牌号资格影响；设备商更受新增产线、替换周期、客户验收、现场支持和研发固定支出影响；检测软件/服务更受装机、使用范围和合同变现影响。不能统一套一个“m²增加×高毛利”的模型。

需求增长、合格供给释放、毛利改善还可利益相反：良率变好会降低每件玻璃/化学品损耗并减少所需检查；面板/激光效率提升减少单位件数的设备采购；新供应商进入提高买方议价权。其对终端客户有益，对卖方的单位收入或资本回报可能不利。

### 6.3 同一资产边界的资本回收压力测试

附录C设定一个**假想**完整成品厂：2.4万m²名义年投入能力，初始投资3亿美元，十年经济寿命，第六年必要更新6,000万美元，期末设备/厂房残值3,000万美元，营运资本为收入15%，同一厂的现金固定费用每年2,500万美元。三亿美元是用NIST初始项目3.43亿美元做数量级参照后采用的情景参数，**不是Absolics账面成本，也不把NIST厂房与SKC历史产能拼成实际ROIC**。

基准爬坡到2030年交付约77.1万件，260美元ASP、160美元变动成本，EBIT约2,207万美元。按简单20%税率和原始资本加当年营运资本计算，稳态税后资本收益约5.3%；不以账面折旧后的资产基数制造更高回报。即使后续售价与成本不再恶化，十年税前现金含残值与营运资本回收仍比初始投资少约992万美元，10%折现率的税前NPV约-1.676亿美元。其关键不是“毛利不够好看”，而是前期损失、资本占用、维持及更新成本。

同一爬坡与成本，若2030–2036的ASP保持约320美元，税前NPV才接近零；若买方把降本收回、寿命缩短或需要额外RDL/检测更新，条件更严格。生产能力翻倍且资本/固定费用不同比增长，也可能改善回报，但须证明相同设备支持产量、规格和寿命，不能偷换资产边界。财政补助可降低企业股东现金负担，却不消除全社会项目成本；必须区分制造补助、研发资助和股权融资。

在附录A的整个G1环节代表模型中，2028基准收入3.224亿美元仍对应EBIT约-1.264亿美元；2030基准收入14.144亿美元、EBIT约1.54亿美元。这个结果假设成熟扩线资本效率优于先行试验厂，不能与上述单厂样本强行加总。全行业未公开可加的资产和费用拆分，全球ROIC无法据此核定。

出口限制若使某个客户产品不能销售，影响N或某条产品p，而非所有玻璃需求统一下降；设备/化学品许可和当地服务影响u/k及交付时滞。利率通过认证前的现金消耗、借款成本与容量建设融资传导。本文未找到足以量化各厂具体政策豁免、贷款利率与回收条款的原始合同，不另加泛化风险溢价。

### 7.1 情景的经济机制

### 7.2 概率对象与更新规则

概率全部是截至截止日的**主观研究判断**，没有用于估计频率的可靠同类样本。依据是：已有小型TGV商业案例、多个材料/设备/封装团队投入、部分可靠性和设备工艺进展提供可行性；SKC最新资格状态、DNP较长计划、早期财务亏损和强替代路线约束速度。因此采用宽区间，不假装有统计置信度。

三条机制路径按2030实际G1商售交付量占可外购目标件池N的比例划分：低于5%归悲观，5%至30%（含两端）归基准，高于30%归乐观，因而互斥且覆盖全部结果。采用悲观25%、基准50%、乐观25%的**整条路径权重**，合计100%；这是一套主观决策分配，数值不应被用于精确期望市值。代表供给受限后的比例约为2%、15.1%、34.8%，分别符合分类。附录外包络容许独立参数极值，角点可能跨过分类边界，不能再把它当该路径的概率分位数，也不能给每个角点附同样权重。

| 事件、成功标准和目标期 | 概率类型／范围 | 上调证据 | 下调证据 |
| --- | --- | --- | --- |
| 至2028年底，至少一个外部客户产品以永久玻璃芯大尺寸成品基板实现连续两季度交付，并达到年内≥10万件 | 无条件事件概率65%–85% | 具名量产BOM、逐季订单/收入、重复采购及可靠性披露 | PoC/可靠性长期未过，量产采用改为载板或有机/硅路径 |
| 2028自然年全球G1商售交付≥100万件 | 无条件事件概率40%–60% | 至少数条产品合计百万件订单，完整链合格供给与净价证据 | 只有单一案例、当年付费交付远小于订单/名义能力 |
| 2030自然年全球G1商售交付≥500万件 | 无条件事件概率40%–60% | 2028百万件后复购、多个完整生产链、面积/良率约束受控 | 采用率长期低、面积增长过快、晚期失效率/供货赔偿抬高成本 |

这些是嵌套/相关事件，不能将各概率相乘。至少一客户成功与百万/千万件渗透不同；经营利润为正也不同于资本回报超过资金成本。

**突破子分支**：在乐观母路径中，玻璃RDL、嵌入器件或光电集成同时减少部分独立中介层/组装步骤，并达到稳定整件可靠性，使2030商售交付约2,000万件成为可能。P(突破｜乐观)=20%–40%；以乐观母权重25%换算，无条件约5%–10%，低于母情景概率。这个突破不是额外独立行业池。

示例突破参数：N=4,000万、p=50%、a=0.020m²、C=60万m²、u=0.90、f=0.84、Y=0.93、k=0.96，S约2,025万件，Q约2,000万；净价250–350美元给成品收入50–70亿美元。变动成本120–190美元，固定费用加折旧约9–15亿美元，则EBIT条件范围约-3至37亿美元。正收入甚至高交付量仍不保证所有参数组合盈利。它要求完整链扩线、成本与架构简化同时成立，不是单独将增速调高。

## 八、开放发现和覆盖缺口

小型RF/MEMS、量子低温切换、光子无源结构和微流控，不应被AI封装框架掩盖。它们的器件面积可能只有几平方毫米，百万件出货耗用玻璃面积可以远小于百万件100mm以上封装；批量、净价、认证周期和资本单位都不同。Menlo提供现有商用桥梁，Mosaic与3DGS说明非上市专业加工者有可能通过设计/工艺协作先获得现金流，再迁入更大平台。本文没有它们足以复算的年度玻璃封装收入，不把整个开关或模块售价算成玻璃收入。

玻璃光波导/CPO同样可能获得价值，但会与硅光、聚合物波导、光纤、封装/连接器方案竞争。AGC在CES 2026的原始展示包含TGV与光学集成方向；这证明技术探索，不是CPO客户采购量。若未来某种玻璃结构替代多个部件，新增玻璃销售应扣除被替代部分，不把CPO系统池全算为玻璃。[AGC CES 2026原始材料](https://www.agc.com/en/ces/semiconductor.html)

本报告的公开覆盖边界如下：

- 核心量化覆盖G1大尺寸AI/HPC商售成品、其原玻璃/金属化芯及相关新购成孔和检测设备。已商业化小型TGV、Mini/Micro LED、医疗/微流控、纯内部自用、临时载板和独立玻璃光电中介层的全球收入缺乏可审查统计，未合成一个虚假的全行业总数。
- 若2030实际采用中内部自用占10%–35%这一**额外假设**成立，G1基准544万商售件对应全部永久玻璃芯使用约604–837万件；增加的是实物使用，不自动增加外部基板收入。这也是本文无法直接估计全球玻璃相关利润总池的原因。
- 历史12,000m²规格含义、厂商真实净价、孔数量、工序良率、客户份额、存量设备复用和量产报价未公开，是误差主要来源。当前工作基数不声称覆盖未披露私营供货；实际数据若超出上界，应调整参数而非把它排除。
- 未确认具体AI/GPU代际采用玻璃BOM，未凭证券主题标签列客户。没有公开数字的主体标为能力/路线，未虚构营收或产能；分销商转载、设备商白皮书、会议议程分别保留其利益关系与证据性质。

D下/上界=N下/上×p下/上；S下界=C下×u下×f下×Y下×k下/a上，上界反之；Q上下界分别取D/S相应边界的最小值。R=Q×ASP。对EBIT，要将Q两端与贡献毛利(ASP-v)两端的四个组合都计算，取最小/最大后减去F+DA上/下界，**贡献为负时不能用错误的同向乘法**。

极值组合有相关性：高采用通常要求较好的良率，较大面积也可能获得更高ASP。A5是保守外包络，不保证全部角点都能同时实现；A2–A3代表的是相互连贯的路径。基准2030收入条件范围4.40–28.74亿美元，EBIT跨亏损与盈利，正说明不应将14.144亿美元销售代表值直接套一个固定高毛利率。

A5的S是已有目标合格投入时的成品环节能力外包络；上游独立供给按第五节最小值公式再约束整体交付。特别是上游范围低端与成品高端同时出现时，不能将A5的收入上端视作可交付结果。B5亦是各细分工作量的外包络，需符合排版、供给与实际设备验收的同一组参数才有经济可行性。

### B2. 设备数量从加工/检测工作量推导

采用面板面积Ap=0.26265m²、每年计划6,000小时。n孔数、速度r、OEE和换片/定位等附加时间在下表逐情景变化。**r是有效激光修改速度的假设，不是已验证整线节拍**，最高5,000孔/s只借厂商技术能力作边界。

- 每板激光负荷：`H = f×Ap/a×n×1.10`；额外10%为工艺/测试孔负荷。
- 每板激光时间：`τ=H/r+附加时间`；单台年投入面积 `TL=Ap×6,000×3,600×OEE/τ`。
- 检测：qph为等价整板检测次数/小时，Ipass为沿工序需要的等价全板检查次数；`TI=Ap×6,000×OEE×qph/Ipass`。一次可同时识别多种缺陷，检查次数不是通孔数。
- 激光年新增：`Lnew=1.5×[max(0,ΔC/Δ年)/TL+Cprev/TL/7]+Lpilot`。1.5覆盖专线/冗余，7年为替换寿命假设。
- 检测年新增：`Inew=h×[max(0,ΔC/Δ年)/TI+Cprev/TI/7]+Ipilot`；h为不能被既有平台复用的新购份额。
- 2027的Cprev工作基数为30,000m²；2028沿用各情景2027的C；2030取2028 C，Δ年=2。这里设备新增对应扩线能力的年平均投入预算，实际交付/验收可能错位约一年；不等于供应商当年已确认收入。
- 产能扩张而订单尚少，设备资本开支可明显高于当年成品销售；固定名义面积在买方之间转移、或现有设备效率升级，会使该公式高估新机需求。激光/检测存量设备价值未加入年度新增收入。

### B6. 临时载板和非AI用途：可识别单位，不能伪造总池

### D1. 关键计算的最小Python复算

下列代码只复算2030基准、单孔阈值和十年假想资产；其余年度/情景使用A2–A4、B1–B4的完整参数，不需要外部文件或收费数据。

```python
import math

# 全球G1商售成品，量为百万件、金额为百万美元
N, p = 36, 0.18
C, u, f, Y, k, a = 200000, 0.80, 0.80, 0.85, 0.90, 0.018
D = N * p
S = C * u * f * Y * k / a / 1e6
Q = min(D, S)
revenue = Q * 260
ebit = Q * (260 - 160) - 220 - 170
print(D, S, Q, revenue, ebit)  # 6.48, 5.44, 5.44, 1414.4, 154.0

Ap, hours, oee = 0.510 * 0.515, 6000, 0.65
holes = f * Ap / a * 50000 * 1.10
TL = Ap * hours * 3600 * oee / (holes / 4000 + 100)
TI = Ap * hours * oee * 6 / 10
Lnew = 1.5 * ((200000 - 80000) / 2 / TL + 80000 / TL / 7) + 5
Inew = 0.65 * ((200000 - 80000) / 2 / TI + 80000 / TI / 7) + 4
print(TL, TI, Lnew * 1.8, Inew * 1.9)
print(-math.log(0.95) / 50000 * 1e6)  # 约1.03ppm

npv, total, old_wc = -300.0, -300.0, 0.0
for j in range(10):
    h = min(j, 3)
    u = [0.20, 0.50, 0.70, 0.85][h]
    Y = [0.40, 0.65, 0.80, 0.85][h]
    asp = [420, 310, 280, 260][h]
    v = [330, 220, 180, 160][h]
    q = 24000 * u * 0.80 * Y / 0.018 / 1e6
    r = q * asp
    ebitda = q * (asp - v) - 25
    wc = r * 0.15
    maintain = [2, 4, 6, 8][h]
    renewal = 60 if j == 5 else 0
    terminal = 30 + wc if j == 9 else 0
    cash = ebitda - maintain - renewal - (wc - old_wc) + terminal
    old_wc = wc
    total += cash
    npv += cash / 1.10 ** (j + 1)
print(total, npv)  # 约-9.92，-167.586
```

### D2. 证据权重及后续最有信息量的披露

财务/监管数字是事实锚点；公司路线图、设备参数、白皮书、展示和会议议程是不同等级的工程/商业线索。材料来自供应商时，有销售利益关系；客户量产BOM、复购、净价与可靠性验收比供应商单独宣称“industry-ready”更能约束市场。学术预印本提供路线可能性，不直接提高量产概率到确定。本文使用第一手文件，未将同源新闻反复转载加权。

最值得更新的证据依次是：具名付费产品及两季度复购、按规格拆分的件数/良品面积、全流程和末端失败率、同规格净价与每件制造成本、工厂/设备利用率及维护更新资本开支、供应商资格与实际交付节拍。它们可以分别改变p、C/u/Y/k、ASP/v及设备复用参数，而不需先宣布行业整体方向。
