# AI产业链瓶颈与反证指标总表

报告日期：2026-07-10（America/Los_Angeles）

研究方案版本：2026-06-04

主要数据日期：公司财务与经营数据主要截至 2026Q1/各公司最近披露季度；Micron 截至 2026-06-24；电网与并网数据主要截至 2025 年末至 2026-06；市场与供应链数据主要截至 2026-06，个别价格指标更新至 2026-07-08。

估值/股价快照日期：2026-07-09 美股收盘附近的最新行情快照。估值只用于判断“预期是否拥挤”，不作为本报告产业结论的事实基础；不同公司的 GAAP 盈利、一次性损益和股本口径不可直接横比。

核心结论摘要：

1. **当前基准情景是“需求仍强、交付受约束、瓶颈逐层后移”，不是“所有环节同时短缺”。** 2026 年四家主要 hyperscaler 的 CapEx 指引中值约为 7,100 亿美元：Microsoft 约 1,900 亿美元、Amazon 约 2,000 亿美元、Alphabet 约 1,850 亿美元、Meta 约 1,350 亿美元。与此同时，Microsoft 披露 AI 年化收入超过 370 亿美元、同比增长 123%，OpenAI 披露 API 处理量超过每分钟 150 亿 tokens。需求证据仍支持乐观情景，但必须用收入、token、利用率和租赁价格共同验证，不能只看 CapEx。
2. **2026 年最硬的五组瓶颈依次是：内存复合体；先进制程、CoWoS 与测试良率；并网、输电与可调度电源；变压器、switchgear、UPS 与燃机槽位；高密度 rack 的液冷、MEP、调试与验收。** 其中内存复合体已经从单纯 HBM 扩展到高容量 DDR5/SOCAMM、HBM4 和 enterprise SSD；Dell 明确称 memory 是 AI server 的首要约束。
3. **2027 年最可能缓解的是 CoWoS 的数量缺口、部分 1.6T 光器件、rack 装配和标准化液冷组件；最不可能全面缓解的是并网、输电、变压器和可调度发电。** TSMC 仍判断 2027 年先进产能很紧，TrendForce 则预计 2027 年新增逾 60% CoWoS 产能、全球 2.5D 紧缺略有改善；这意味着“缓解”更可能表现为 allocation 缩小，而不是立即过剩。
4. **长期定价权属于技术、认证和系统责任不能被快速替代的环节；单纯扩产型短缺更容易在 2027-2028 转成价格战。** HBM4 基础逻辑裸片、先进封装、先进测试、关键光芯片、电网设备和能够承担整站交付责任的电力/冷却集成商，定价权强于普通 ODM 装配、标准连接器、普通冷板或通用铜缆。
5. **目前最容易被误判的伪瓶颈是：把 headline interconnection queue 当成可兑现负荷、把 CPO 认证期当成当期出货瓶颈、把 ODM 产线当成首要约束、把所有液冷零件都当成高壁垒，以及只用 generic DRAM/NAND spot price 推断 HBM。** ERCOT 截至 2026-06 跟踪的 large-load request 已超过 438 GW、近 89% 来自数据中心，这个数字远大于可建设规模，必须经过土地、电力、押金、客户和设备四重去重。
6. **日度判断的核心不是“消息利多还是利空”，而是消息改变哪一个状态变量。** 例如 HBM ASP 下行若伴随库存上升和 allocation 消失，是 HBM 定价权反证、但可能是 GPU/rack 交付利好；变压器 lead time 缩短是设备厂定价权下修，却是开发商、MEP 和 colo 的订单转化利好。

> 重要说明：文中标为“研究阈值”的数字是本报告为情景管理设定的触发线，不是公司指引或行业统一标准；其作用是强迫后续跟踪做出上修、维持或下修动作。标为“披露值”的数字来自所列来源。

### 1.4 一句话情景判断

截至 2026-07-10，建议维持 **“乐观、但必须由收入和上电验证”** 的基准情景。只有同时出现以下组合，才应把全局情景下修至悲观：四大 hyperscaler 合计 CapEx 指引下调超过 20%；AI/Cloud 收入增速连续两季降到 15%-20% 以下；H100-equivalent 租赁价格 60 日均值跌破 3 美元/小时且容量可即时取得；AI server book-to-bill 低于 1；电力/MEP 项目取消而非仅延期。单一 HBM、光模块或变压器价格下跌不足以证伪 AI 需求，可能只是瓶颈缓解。

## 二、研究口径、资料边界和瓶颈分类方法

### 2.1 资料边界

本报告为独立产业背景研究。除研究方案本身和最终输出文件外，未读取、引用或继承任何本地旧报告、索引、缓存、中间数据或历史结论。事实与数字来自公开公司材料、监管/政府材料、ISO/RTO、电力与数据中心机构、行业第三方以及明确标注的市场价格线索。

来源优先顺序为：

1. 公司财报、10-Q/10-K、投资者材料、正式产品/产能公告；
2. 政府、监管机构、ISO/RTO、国际组织和国家实验室；
3. 有方法和时间戳的行业第三方；
4. 公开价格页、市场聚合器和渠道线索，仅作交叉验证。

### 2.2 证据强度

| 等级 | 定义 | 可承担的结论 |
|---|---|---|
| A | 监管文件、审计/财务文件、ISO/RTO、政府或国际组织原始数据 | 当前状态、正式指引、财务和物理约束 |
| B | 公司正式新闻稿、投资者演示、产品路线图、管理层口径 | 订单、产能方向、技术路线和客户反馈 |
| C | TrendForce、LightCounting、CBRE、JLL 等有方法的行业数据 | 供需区间、价格方向、市场边界和交叉验证 |
| D | 价格聚合器、渠道、招聘、论坛或媒体转述 | 领先线索；必须等待 A-C 级证据确认 |

### 2.3 状态定义

| 状态 | 操作定义 |
|---|---|
| 严重 | 直接阻断出货、上电或验收；替代路径通常超过 12 个月 |
| 局部 | 特定规格、地区、客户或认证仍短缺，但行业总量不是全面短缺 |
| 缓解 | allocation、交期或价格至少连续两个观察期改善，且下游交付增加 |
| 过剩 | book-to-bill 低于 1、库存和折价同时上升，产能利用率持续低于约 80%-85% |
| 不确定 | 数据透明度不足，或需求与效率提升的方向互相抵消 |

### 2.4 因果链与领先/滞后口径

本报告不把“订单”“收入”“上电”混为一谈。典型链条为：

**AI 使用/合同 → CSP CapEx 与 allocation → wafer/HBM/CoWoS/光器件订单 → rack 组装 → 机房 electrical/mechanical 完工 → commissioning → 上电 → 可售 GPU 容量 → AI 收入与续约 → 折旧、现金流和再融资。**

因此：

- HBM LTA、TSMC CapEx、Eaton orders 是领先指标；
- bit shipment、rack revenue、leased MW delivery 是同步指标；
- AI 收入、折旧、GPU 二手残值和项目 ROIC 是滞后指标；
- backlog 上升但 commissioning 不动，说明瓶颈后移，不等于需求消失。

### 2.5 反证阈值的使用规则

1. 一个价格指标不能单独触发全局下修，必须与库存、利用率或订单中的至少一个共同出现。
2. “连续两季”用于过滤产品切换、季节性和客户 pull-in；日度价格通常要求至少 30-60 日均值。
3. 对 headline queue、pipeline 和 TAM 使用兑现折扣；只把有押金、土地、设备、客户和 firm service 的 MW 计入高置信度。
4. 对未公开 utilization 的环节使用租赁价格、可用性、backlog conversion、revenue/active MW 和 dock-to-live 作为代理。
5. 阈值触发后先改变瓶颈归属，再改变需求情景。例如 HBM 跌价先下修 memory margin、上修 rack delivery；只有同时看到 AI 收入和租赁利用率走弱，才下修全局需求。

## 四、需求侧瓶颈：AI 收入、token、利用率和融资

### 4.1 需求侧不是当前瓶颈，但它是所有供给瓶颈的总反证

供给紧张只能解释“为什么收入没有更快兑现”，不能永久替代 ROI。当前需求证据较强：

- [Microsoft FY2026 Q3](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q3) 披露 AI business ARR 超过 370 亿美元、同比增长 123%；Azure 同比增长 40%，需求仍超过可用容量；约 300 个 Foundry 客户预计当年各自处理超过 1 万亿 tokens，该客户数环比增长 30%。
- [OpenAI 2026 年企业战略披露](https://openai.com/index/next-phase-of-enterprise-ai/) 称 ChatGPT 达 9 亿周活、Codex 300 万周活、API 处理量超过每分钟 150 亿 tokens；[OpenAI 2026-06 的 adoption 数据](https://openai.com/index/how-chatgpt-adoption-has-expanded/) 还显示使用深度、广度和区域覆盖继续扩大。
- [Alphabet 2026Q1](https://abc.xyz/investor/events/event-details/2026/2026-Q1-Earnings-Call-2026-nW8kCrBAKS/default.aspx) 的 Cloud 收入同比增长 63% 至 200 亿美元，Cloud backlog 达 4,620 亿美元；AI solutions 是最大增量来源。
- [Amazon 2026Q1](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-First-Quarter-Results/default.aspx) 的 AWS 收入同比增长 28% 至 376 亿美元，AWS chips business 年化收入超过 200 亿美元并保持三位数增长。
- [Anthropic 2026-05 融资公告](https://www.anthropic.com/news/series-h) 披露 run-rate revenue 超过 470 亿美元；这是公司口径、未经审计，证据等级 B，仍应以主要云厂收入和合同兑现交叉验证。

需求侧最大问题不是缺少增长故事，而是 **不同口径不可相加**：ARR、run-rate revenue、Cloud revenue、API tokens、consumer messages 和 backlog 都不是同一指标。后续应建立一个“需求四联表”，只有至少三项同向才切换情景。

**日度解读规则：**

- CapEx 因 memory、transformer 或施工成本上调：利多对应供应商收入/价格，但不等量上修 GPU units 或 MW。
- CapEx 因“提前拉货”上调：上修最近 2-3 季订单，下修下一年比较基数。
- CapEx 下调但 AI 收入加速、tokens/$ 提升：可能是效率利好，不应立即转悲观。
- CapEx 下调同时 cloud growth、租价、book-to-bill 和 RPO 都下降：属于需求反证。

### 4.4 利用率：公开数据缺失时用五个代理

大多数 CSP 不公开 fleet-wide GPU utilization。建议按以下代理从高到低跟踪：

| 代理 | 观察方式 | 乐观 | 反证 |
|---|---|---|---|
| 同 SKU 租赁价格与即时可用性 | 固定 H100/H200/B200、同地区、同网络/SLA | 价格稳、等待长、配额紧 | 60 日价格跌 >25%、可立即取得、长期合约折价扩大 |
| Cloud AI 收入/AI ARR | 财报季度 | >30% 增长 | <20% 两季 |
| AI server order/revenue 与 backlog | Dell/HPE/ODM | book-to-bill >1.2、backlog/revenue >2x | book-to-bill <1 两季、backlog/revenue <1.5x |
| revenue/active MW | NeoCloud 季报 | 稳定或上升 | active MW 上升而收入/MW 下降 >20% |
| tokens/GPU、tokens/watt/$ | CSP/MLPerf/软件发布 | 性能提升被更高 token demand 吸收 | 效率增速长期高于 token 增速，且价格同步下降 |

这里的关键是“效率悖论”：效率提升既可能减少单位任务的 GPU 数，又可能因价格下降刺激更多推理。只有观察总 token、可售容量、收入和租价，才能判断 Jevons effect 是否足以吸收新增供给。

### 4.5 NeoCloud 融资与残值

[CoreWeave 2026Q1 10-Q](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000222/crwv-20260331.htm) 提供了一个可量化样本：

| 指标 | 2026-03-31 披露值 | 含义 |
|---|---:|---|
| Revenue / revenue backlog | 20.78 亿美元 / 994 亿美元 | 订单可见度极高，但 backlog 含待满足 delivery/availability 条件的估计 |
| Adjusted EBITDA / interest expense | 11.57 亿 / 5.36 亿美元 | 覆盖约 2.16x，尚可但对价格和利用率敏感 |
| Total debt | 251.49 亿美元 | 高杠杆放大执行风险 |
| Operating lease liabilities | 100.5 亿美元 | 数据中心租赁是债务之外的固定负担 |
| 未开始租赁的未来付款 | 407 亿美元 | 2026-2029 开始，扩大未来固定成本 |
| Q1 property/equipment cash spend | 76.95 亿美元 | CapEx 显著高于当季收入 |
| DDTL 4.0 价格 | 浮动 SOFR+2.25%；首批固定约 5.9% | 可作为新增项目融资成本基准 |

**融资反证阈值：**

1. interest expense/revenue 超过 30% 连续两季；
2. adjusted EBITDA/interest 低于 1.5x；
3. 新项目 all-in debt cost 超过 9%，且合同期限短于债务/租赁期限；
4. 单一客户或关联 AI lab 的合同取消、缩量超过 backlog 的 10%；
5. 同代 GPU 租价 60 日均值低于 3 美元/小时、利用率代理低于 70%，同时二手成交价同比跌超过 35%；
6. 设备折旧年限继续延长，但租赁价格和残值同时下跌——这是利润被会计寿命高估的高风险组合。

触发 1 项：把 NeoCloud 从乐观降至务实；触发任意 2 项且持续两个季度：降至悲观；若融资成本 <7%、EBITDA/interest >3x、合同覆盖债务期限且租价稳定，则可上修。

### 4.6 需求侧伪信号

| 伪信号 | 为什么会误导 | 正确验证 |
|---|---|---|
| headline token 数 | 免费流量、长 reasoning 和 cache 重用的经济价值不同 | 同看 API revenue、付费客户、tokens/$ 和 gross margin |
| headline backlog/RPO | 可能集中于少数客户、期限长、依赖未来交付条件 | 看 12/24 个月转化、最低采购、押金、取消条款和客户集中 |
| CapEx 美元增速 | component inflation 会抬高美元但不增加 units | 拆 server/GPU、building、network、lease 与价格影响 |
| headline MW pipeline | 可重复申请、无土地、无设备、无客户或无 firm power | 只认 deposit＋site control＋customer＋equipment＋firm service |
| GPU spot price 单日下跌 | SKU、网络、SLA 和可中断属性差异大 | 固定配置、取 30/60 日均值，并与即时可用容量交叉验证 |

## 五、算力与半导体瓶颈：GPU/ASIC、HBM、封装、基板、测试和设备

### 5.1 GPU/ASIC：需求强，真正约束在供应组合而非“只有 GPU die”

[NVIDIA FY2027 Q1](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-First-Quarter-Fiscal-2027/default.aspx) 披露总收入 816 亿美元、Data Center 752 亿美元；其中 compute 604 亿、networking 148 亿美元。后者同比增长 199%，说明每一美元 accelerator 还在拉动 fabric。公司 Q2 指引没有计入任何中国 Data Center compute revenue，政策仍是独立变量。

[AMD 2026Q1](https://ir.amd.com/news-events/press-releases/detail/1284/amd-reports-first-quarter-2026-financial-results) Data Center 收入 57.75 亿美元、同比增长 57%，MI350 与 EPYC 同时放量；Meta 计划部署最高 6 GW AMD Instinct，首个 1 GW 使用 MI450 系列。  
[Broadcom FY2026 Q2](https://investors.broadcom.com/news-releases/news-release-details/broadcom-inc-announces-second-quarter-fiscal-year-2026-financial) AI semiconductor revenue 108 亿美元、同比增长 143%，Q3 指引约 160 亿美元，表明 custom XPU 和 AI networking 正在分散单一 GPU 架构风险。

| 判断问题 | 当前答案 | 投资含义 |
|---|---|---|
| GPU die 本身是不是唯一瓶颈 | 否。3nm/4nm wafer、HBM、CoWoS、substrate、test、network、rack power 和 facility 必须同时齐备 | 单看 GPU units 会高估可上电算力 |
| ASIC 会不会消灭 GPU 需求 | 2026-2028 更可能是增量分流，不是零和替代 | Broadcom/Marvell/TSMC 受益；GPU 仍保留通用生态和前沿训练 |
| 多供应商是否消除 bottleneck | 降低单点风险，但每个设计仍锁定节点、封装、HBM 和软件生态 | 供给组合更复杂，验证成本上升 |
| 2027 会否过剩 | 若 power 和 memory 仍紧，wafer 缓解可能只释放积压订单；只有租价、book-to-bill、库存同时转弱才构成过剩 | 下游交付可能先受益 |

**GPU/ASIC 反证组合：** NVIDIA/AMD Data Center revenue 环比不增长连续两季；NVIDIA inventory 同比增幅超过收入增幅 20 个百分点以上；Dell/HPE AI book-to-bill <1；H100-equivalent 价格 60 日均值 <3 美元/小时。四项中出现三项，才把 compute 从“供给约束”改为“需求约束”。

### 5.2 HBM、DRAM、SOCAMM 与 memory wall

[Micron FY2026 Q1 材料](https://investors.micron.com/static-files/530bd7ed-a8c8-4687-af4a-8c129f740e09) 披露其 2026 年全部 HBM supply 已完成量价协议，并把 HBM TAM 从 2025 年约 350 亿美元上修到 2028 年约 1,000 亿美元；[Micron FY2026 Q3](https://investors.micron.com/node/50671) 称 HBM4 已对主客户大批量出货，HBM4E 预计 2027 年量产。[Samsung 2026Q1](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_1Q_conference_eng.pdf) 也披露 HBM4 和 SOCAMM2 已面向 Vera Rubin 销售，供应仍有限。

**为什么 HBM 仍是硬瓶颈，但不能永远是高毛利故事：**

1. HBM 占用更多 wafer、TSV、stacking、base die、封装与测试资源，产能不能按普通 DRAM bit 等比例切换。
2. HBM4 开始把 logic base die、foundry 和客户定制绑定在一起，认证壁垒高于通用 DRAM。
3. 但 Samsung 的追赶、Micron 扩产、TSMC/OSAT capacity 增加会在 2027 后降低 allocation；一旦 bit 增速高于 accelerator 需求，价格弹性会反向放大。
4. HBM 扩产会 crowd out conventional DRAM，因而“HBM 供给增加”与“server RDIMM/SOCAMM 仍贵”可以同时成立。

### 5.3 内存复合体状态与反证

| 子环节 | 2026 证据 | 受益 | 被压制 | 2027-2028 缓解路径 | 反证阈值 |
|---|---|---|---|---|---|
| HBM4 | 全年量价锁定、Rubin 放量 | MU、SK hynix、Samsung、TSV/test | GPU allocation、低端 DRAM | 新 wafer、良率、Samsung share、HBM4E 标准化 | ASP -10% QoQ 两季＋库存 +20%＋allocation 消失 |
| DDR5/RDIMM | server-first allocation、价格急升 | DRAM、module | Dell/HPE、传统 server、PC | 1-gamma/1c ramp、产能重新分配 | 合约价 -15% QoQ 两季＋fulfillment >90% |
| SOCAMM | 新平台高容量低功耗需求、认证集中 | memory/connector | rack platform schedule | 多供应商 qualification | 客户数增加但 ASP/毛利急降，说明认证不再稀缺 |
| CXL memory | 技术可用、生态/软件导入慢 | controller、memory expansion | 短期放量 | CPU/platform 与软件成熟 | 量产 attach 仍 <5% 且客户项目延期 >2 季：降为长期 optionality |
| enterprise SSD/KV cache | 2026Q1 eSSD 价格约涨 80%，库存低 | NAND、QLC eSSD、DPU | rack BOM、消费 NAND | 高层数 QLC、245TB、PCIe 6、新 capacity 2027H2-2028 | 价格 -15% QoQ 两季＋库存正常＋LTA 松动 |

HBM 与 generic DRAM/NAND 必须分开跟踪。generic spot price 可作为领先线索，但只有 contract ASP、bit shipment、inventory 和 OEM allocation 同向时才改变 HBM 判断。

### 5.4 先进制程与 CoWoS：2027 是“缺口变小”，不是“供应无约束”

[TSMC 2026Q1 call](https://investor.tsmc.com/schinese/encrypt/files/encrypt_file/reports/2026-04/3cef85204275f94fd111485cfdf4adb3c0263c45/TSMC%201Q26%20Transcript.pdf) 的关键信息是：

- 2026 CapEx 向 520-560 亿美元区间高端移动；
- HPC/AI demand 很强，supply 仍很紧；
- 新 fab 建设需 2-3 年，之后良率爬坡还需时间，公司判断 2027 仍会很紧；
- advanced packaging capacity 同样 very tight，需要与 OSAT 合作。

[TrendForce 2026-04](https://www.trendforce.com/presscenter/news/20260430-13028.html) 预计 TSMC 2027 年 CoWoS capacity 增加逾 60%，全球 2.5D 严重短缺将“略有改善”。这两条证据并不冲突：capacity 快速增长，但 package 面积、HBM stack 数和 ASIC 客户数量也在增长。

建议按三层判断 CoWoS：

| 层 | 指标 | 解释 |
|---|---|---|
| 数量 | monthly wafer equivalent、supply-demand gap、allocation | 决定能交多少颗 |
| 复杂度 | reticle multiple、HBM stack、interposer/RDL、yield | 决定每片 capacity 能产多少有效 package |
| 生态 | TSMC 自有与 ASE/Amkor/Intel 外溢、客户 qualification | 决定替代速度 |

只有“数量 gap <5%＋大尺寸 yield 稳定＋OSAT 客户认证完成”三者同时成立，才把 CoWoS 标为缓解。

### 5.5 基板、材料和测试

- [TrendForce](https://www.trendforce.com/presscenter/news/20260430-13028.html) 指出短缺已从 CoWoS 延伸到 T-glass、substrates、PCB、HBM 和 SSD。
- [Ibiden](https://www.ibiden.co.jp/ir/message/) 计划 2026-2028 年在电子业务投入约 5,000 亿日元，直接说明高端 IC package substrate 的扩产周期跨越三年。
- [Advantest FY2025](https://www.advantest.com/en/investors/financial-highlights/review/) 销售 11,286 亿日元、同比增长 44.7%，经营利润增长 118.8%；公司称过去数年生产能力约增至三倍，AI SoC 和 high-performance DRAM tester 是主要驱动。
- [Teradyne 2026Q1](https://investors.teradyne.com/news-events/press-releases/detail/440/teradyne-reports-first-quarter-2026-results) 收入 12.82 亿美元，其中 semiconductor test 11.11 亿美元，record result 由 AI compute 与 memory 驱动。

测试的长期价值不只来自 chip 数量，而来自 **每颗芯片 test time、thermal control、known-good-die、HBM stack 和 system-level test content**。因此即使 2027 wafer 数量约束缓解，tester 收入也可能保持强；真正反证是订单/利用率/测试时间同时下降，而不是单看芯片 ASP。

### 5.6 半导体链的伪瓶颈

| 叙事 | 判断 | 原因 |
|---|---|---|
| “所有 3nm 都是 AI 瓶颈” | 过度概括 | 不同产品的 die size、mask、package 和优先级不同；需看 AI allocation |
| “CoWoS 扩产 60% 就会过剩” | 证据不足 | package 面积与 HBM stacks 同时增长，wafer equivalent 不能直接等同 chip units |
| “ABF 全行业短缺” | 只对高层数/大尺寸/认证产品成立 | 通用 substrate 可能已不紧 |
| “测试只是后周期、没有定价权” | 低估复杂度 | HBM4 与大 chiplet 提高 test content 和良率价值 |
| “HBM spot 跌就是 HBM 需求崩” | 错误口径 | HBM 主要长协和 allocation，需看 blended ASP、inventory 和客户约束 |

## 六、系统与网络瓶颈：服务器、rack-scale、光互联、铜互联、存储和软件利用率

### 6.1 服务器与 rack：装配不是首要约束，parts 与 acceptance 才是

[Dell FY2027 Q1](https://investors.delltechnologies.com/news-releases/news-release-details/dell-technologies-delivers-first-quarter-fiscal-2027-financial) 披露：

- AI orders 244 亿美元；
- AI server revenue 161 亿美元；
- AI backlog 513 亿美元；
- demand continues to exceed supply，memory 是首要约束；
- 管理层明确称自身 assembly capacity 没有问题，约束在 parts supply。

这组数据可计算两个日后可复用指标：

- 单季 AI book-to-bill = 244/161 ≈ 1.52x；
- backlog/单季 AI revenue = 513/161 ≈ 3.19x。

[HPE FY2026 Q2](https://investors.hpe.com/~/media/Files/H/HP-Enterprise-IR/documents/q2-2026/q2-2026-earnings-presentation.pdf) 披露 AI Systems backlog 约 59 亿美元，AI systems 与 AI networking 合计 backlog 超过 63 亿美元，61% 累计订单来自 sovereign/enterprise。订单池已从单一 NeoCloud 扩散，但验收和利润率仍要单独验证。

| 信号 | 对 server OEM | 对上游部件 | 对需求判断 |
|---|---|---|---|
| backlog 上升、revenue 上升、B/B >1 | 利好 | 继续紧 | 需求强 |
| backlog 上升、revenue 不动 | 现金/验收压力 | 某部件或 facility 卡住 | 需求未必弱 |
| backlog 降、revenue 上升 | 转化加快 | 瓶颈缓解 | 对下游利好 |
| backlog 降、B/B <1、租价下跌 | 订单池缩小 | 未来价格压力 | 需求反证 |

### 6.2 光互联：2026 真实紧，2027 最需要警惕扩产后的 ASP

[LightCounting 2026-02](https://www.lightcounting.com/newsletter/en/february-2026-pam4-and-coherent-dsps-updated-april-2026-381) 预计 800G transceiver shipments 在 2026 年再次翻倍以上，1.6T 从小基数增至数千万 ports。[Coherent 2026Q3 investor presentation](https://www.coherent.com/content/dam/coherent/site/en/documents/investors/investor-presentations/2026/may-6/investor-presentation-20260506.pdf) 则计划 2026 年末把内部 InP output 翻倍，2027 年再增长一倍以上。[TrendForce 2026-06](https://www.trendforce.com/presscenter/news/20260603-13077.html) 估算 EML 与 CW-DFB laser 合计月产能在 2026 年翻倍至约 5,070 万颗。

由此得到：

1. 2026 年 laser/EML/CW、DSP、high-speed packaging 和 test 是局部硬瓶颈；
2. 2027 年 capacity ramp 很大，若 port demand 只按线性增长，ASP 压力会先于出货见顶；
3. 光模块厂收入增长不等于毛利增长，component cost、客户集中和价格年降必须分开看。

**光链阈值：**

- 乐观维持：800G/1.6T ports 同比增 >50%，供应商 capacity utilization >90%，lead time >12 周；
- 务实：ports 仍增 30%-50%，但 ASP 同比跌 10%-20%；
- 悲观/过剩：ASP 同比跌 >20%，lead time ≤8 周，laser utilization <80%，至少两项持续两季；
- 极度乐观：1.6T ports 超过原预测 20%以上，3.2T/CPO 提前量产，且上游 laser yield 不下降。

### 6.3 铜互联：短距仍有经济性，但不是无限延伸的硬瓶颈

[Credo FY2026 Q4](https://www.sec.gov/Archives/edgar/data/1807794/000162828026039474/credoq42026ex-991.htm) 单季收入 4.37 亿美元、同比增长 157%，说明 AEC/retimer 在 scale-up/scale-out 的短距连接仍有真实需求。铜互联的价值来自低成本、低延迟和成熟部署，但 reach、SerDes 功耗与 signal integrity 会在更高速度下迫使更多链路转向 optics。

因此：

- DAC/AEC 是 2026 的 **局部价格/交付瓶颈**，不是 2028 的永久硬约束；
- CPO/optical scale-up 放量会压制部分高端 AEC，但 rack 内部不同距离仍会长期共存；
- 跟踪重点是 AEC revenue、ASP、客户集中、每 XPU attach 和 copper-to-optics boundary，而不是笼统的“铜退光进”。

### 6.4 CPO 与 OCS：认证是真变量，demo 不是订单

[NVIDIA 2026-05](https://nvidianews.nvidia.com/news/vera-rubin-full-production-agentic-ai-factory) 称 Spectrum-X Ethernet Photonics CPO switch 已进入 production；[Broadcom OFC 2026](https://investors.broadcom.com/news-releases/news-release-details/broadcom-showcases-industry-leading-solutions-scaling-ai) 也披露 Tomahawk 6 CPO/102.4T 产品。CPO 已从纯路线图进入早期生产，但仍应按三阶段计入：

1. sample/demo：不计入瓶颈与收入；
2. qualified platform：计入 2027 pipeline，不计为规模收入；
3. volume ports＋现场可靠性：才计入份额和价值捕获。

OCS 的优势在于减少不必要的 optical-electrical-optical 转换和功耗，但它改变的是网络拓扑，并非简单替代所有 switch。CPO/OCS 相关消息只有在披露客户、ports、量产季度和 field reliability 时才上修。

### 6.5 存储与数据路径：从配套件变成推理效率约束

[TrendForce 2026-06](https://www.trendforce.com/presscenter/news/20260611-13092.html) 估算 2026Q1 enterprise SSD revenue 达 184.6 亿美元、环比增长 86.1%，合约价约涨 80%；库存处于历史低位，high-capacity QLC 供给不足。[Micron 2026-03](https://investors.micron.com/node/50207) 已量产 PCIe Gen6 SSD 与 SOCAMM2，[NVIDIA Rubin](https://nvidianews.nvidia.com/news/nvidia-kicks-off-next-generation-ai-rubin) 则把 context memory storage 和 BlueField-4 纳入系统设计。

这意味着 storage 的角色分为三层：

| 层 | 需求 | 瓶颈属性 | 主要受益 |
|---|---|---|---|
| 训练数据/对象存储 | 容量、吞吐、可靠性 | HDD/eSSD 价格与交付 | WDC、STX、enterprise storage |
| checkpoint/数据 ingest | 高带宽、并行文件系统 | 网络＋eSSD＋软件 | DDN、VAST、WEKA、Dell/HPE storage |
| 推理 KV/context | 低延迟、高容量、cache hit | SOCAMM/DRAM/eSSD/DPU 协同 | MU、Samsung、Kioxia、SanDisk、NVDA |

如果 enterprise SSD ASP 下降而 attach/capacity per rack 继续上升，这是 rack TCO 利好，不是 AI 需求利空；只有 ASP、bit shipment、storage attach 和 AI usage 同时下降，才构成需求反证。

### 6.6 软件利用率：最大的“隐形扩产”

- [Microsoft FY2026 Q3](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q3) 披露常用 Copilot 模型 inference throughput 提升 40%，Maia 200 tokens/$ 比当时 fleet 最新 silicon 高 30%以上，GPU dock-to-live 缩短近 20%。
- [NVIDIA Dynamo 1.0](https://nvidianews.nvidia.com/news/dynamo-1-0) 称在特定 Blackwell inference 测试中性能最高可提升 7x；这是特定模型、配置和 benchmark 的“up to”值，不应直接外推全 fleet。
- [MLPerf Inference v6.0](https://mlcommons.org/2026/04/mlperf-inference-v6-0-results/) 提供可复核的标准化 datacenter inference benchmark，可作为跨代比较基准。

软件效率既缓解硬件瓶颈，也可能削弱单位 token 所需的 GPU。建议维护：

**净算力需求增速 ≈ token/任务需求增速 − tokens/GPU 效率增速 ＋ latency/SLA、冗余和峰值容量修正。**

| 组合 | 解读 |
|---|---|
| token +100%，效率 +40%，价格稳定 | 净算力仍强，上修 utilization |
| token +40%，效率 +60%，租价下跌 | 供给可能追上，下修 compute units |
| token +100%，效率 +100%，AI revenue +50% | 单位成本下降且需求弹性强，维持 CapEx 但下修 unit economics 风险 |
| efficiency headline 很高、真实 cloud gross margin 不改善 | benchmark 未转成生产，不能上修 |

## 七、电力、冷却、工程和数据中心交付瓶颈

### 7.1 电力是持续时间最长的全局约束

[IEA 2025 Energy and AI](https://www.iea.org/reports/energy-and-ai/energy-demand-from-ai) 基准情景预计全球数据中心用电从 2024 年约 460 TWh 增至 2030 年约 945 TWh，2024-2030 年均增长约 15%；accelerated server 用电年均增速约 30%。[IEA 2026 更新](https://www.iea.org/news/data-centre-electricity-use-surged-in-2025-even-with-tightening-bottlenecks-driving-a-scramble-for-solutions) 称 2025 年数据中心用电增长 17%，AI-focused data center 更快；五家大型科技公司 2025 年 CapEx 超过 4,000 亿美元，2026 年预计再增约 75%。

物理时间错配是核心：

| 环节 | 典型时间属性 | 可压缩程度 |
|---|---|---|
| GPU/服务器生产 | 数月到一年 | 可通过预付款、allocation、设计替换压缩 |
| 数据中心 shell/fit-out | 约 18-36 月，因地区而异 | 预制化可压缩 |
| 变电站、输电和 interconnection | 常为 3-7 年或更久 | 受审批、设备、right-of-way 限制 |
| 新燃气/核电和大型输电 | 多年 | 很难与 GPU 周期同步 |

因此，2027 wafer 或 CoWoS 缓解后，全球约束更可能从“拿不到芯片”转成“有芯片但没有合适的 MW、网络和 commissioning”。

### 7.2 Interconnection queue：最大的真实瓶颈，也是最大的伪需求来源

[LBNL Queued Up 2026 Edition](https://emp.lbl.gov/queues) 显示截至 2025 年末，美国约 8,200 个发电/储能项目在 queue 中，合计 1,312 GW generation 与 749 GW storage；2025 年实际投运项目从 interconnection request 到 COD 的中位时间超过 5 年。该数据说明供电侧扩张慢，但 queue 不是未来装机的直接预测，因为大多数项目最终退出。

[PJM 2026 Load Forecast](https://www.pjm.com/-/media/DotCom/library/reports-notices/load-forecast/2026-load-report.pdf) 开始对 large-load adjustment 更严格区分：

- 近年项目需要 Electric Service Obligation/Construction Commitment 等 firm 证据；
- 长期项目因不确定性被 derate；
- PJM 此前估算 2025-2030 data center load 增量最高约 30 GW，但 2026 forecast 已下调近期 large-load adjustments。

[ERCOT 2026-06](https://www.ercot.com/news/release/06182026-puct-approves-ercots) 跟踪超过 438,000 MW large-load requests，近 89% 来自 data center；这远高于 ERCOT 系统当前峰值，说明重复申请和投机性 queue 极多。ERCOT 的 Batch Zero 把 ≥75 MW 项目集中评估，未来最重要数据不再是申请总量，而是 qualified MW。

### 7.3 Queue 质量评分

建议后续每个项目按 0-5 分计分，每一项 1 分：

| 条件 | 验证证据 | 未满足的含义 |
|---|---|---|
| 土地控制 | deed/lease、zoning | 可能只是项目期权，并不代表可交付项目 |
| 客户/承购 | named tenant、最低采购、押金 | 需求可能重复 |
| 电力 | firm service、approved study、PPA | headline MW 不可上电 |
| 设备 | transformer/switchgear/turbine reservation | COD 缺少关键设备 |
| 融资 | committed debt/equity、investment-grade sponsor | 项目易在利率或租价变化时取消 |

- 4-5 分：高置信项目，可纳入 24-36 月订单池；
- 2-3 分：pipeline，按 30%-50% 概率计；
- 0-1 分：不计入供需，只作选址意向。

**全局反证：** 若 ERCOT/PJM 新机制下 qualified/total requested MW 低于 20%，不能把 headline queue 当成需求上修；若 4-5 分项目中按期上电率仍低于 50%，说明物理瓶颈比当前假设更严重。

### 7.4 可靠电源、PPA、燃机与 behind-the-meter

[GE Vernova 2026Q1](https://www.gevernova.com/news/articles/ge-vernova-releases-first-quarter-2026-financial-results) 的 Gas Power equipment backlog 与 slot reservation 从 83 GW 增至 100 GW，目标 2026 年末至少 110 GW；Electrification 当季仅 data center equipment orders 就达到 24 亿美元，超过 2025 全年。[AEP 2026Q1](https://www.aep.com/news/stories/view/11917/) 披露 2030 年前新增负荷协议增至 63 GW，并把五年 capital plan 提至 780 亿美元；但 Texas 项目时点仍依赖第三方发电建设。

电源缓解路径按现实可用性排序：

1. 现有电网容量重分配、demand response、可中断负荷；
2. 短期燃机/reciprocating engine、BESS 与 behind-the-meter microgrid；
3. 新燃气管线、utility generation、transmission upgrade；
4. 核电重启、uprate、geothermal 和新型核电；
5. SMR 大规模贡献更偏 2030 年后，不应成为 2026-2028 基准交付假设。

| 指标 | 乐观维持 | 反证/下修 |
|---|---|---|
| PPA/发电 COD | ≥70% MW 按原计划 ±1 季投运 | 延误 >12 月或取消/缩量 >10% |
| Turbine slot | backlog/slot 持续增，客户预付款 | reservation 转订单率 <60%、取消 >10% |
| BTM power | named site、燃料、permit、设备、并网模式齐备 | 只宣布 MOU 或缺 gas/air permit |
| Capacity price | 上升但合同可由客户承担 | 价格上升同时项目 economics/lease 不能覆盖 |

### 7.5 变压器、switchgear、UPS：可量化的设备硬约束

[美国能源部供应链页面](https://www.energy.gov/oe/supply-chain-and-market-analysis) 的最新可比数据称 distribution transformer lead time 从 2019 年的 3-6 个月升至 2023 年的 12-30 个月；DOE 还指出美国存在约 80,000 种不同规格，标准化不足本身延长生产。[Eaton 2026Q1](https://www.eaton.com/us/en-us/company/news-insights/news-releases/2026/eaton-reports-record-first-quarter-2026-results.html) 提供了 2026 的同步验证：

- Electrical Americas 12-month rolling organic orders +42%；
- Electrical Americas backlog +44%，Electrical Global backlog +73%；
- Electrical business book-to-bill 1.2x；
- data center orders 约 +240%、revenue 约 +50%。

[GE Vernova 2026Q1](https://www.gevernova.com/sites/default/files/gev_webcast_pressrelease_04222026.pdf) Electrification orders 71 亿美元、organic +86%，book-to-bill 约 2.5x；equipment backlog 386 亿美元、同比 +75%（含 Prolec GE）。

这组数据说明：

- 设备供不应求仍真实存在；
- backlog 的增长远快于收入，交付能力而非订单是 2026-2027 的约束；
- 设备厂可通过 price-cost、mix 和产能利用获得利润弹性；
- 但扩产和标准化一旦成功，设备厂 ASP/增量 margin 会先于 utility 项目量见顶。

**设备状态仪表：**

| 状态 | Transformer lead time | Electrical B/B | Backlog YoY | 动作 |
|---|---:|---:|---:|---|
| 严重 | >18 月 | >1.2 | >30% | 上修设备收入/价格，下修项目 COD |
| 局部 | 9-18 月 | 1.0-1.2 | 10%-30% | 维持 |
| 缓解 | ≤9 月 | <1.0 两季 | <10% | 下修设备定价权，上修开发/MEP |
| 过剩 | ≤6 月 | <0.9 两季 | backlog 下降 | 下修设备收入与 margin |

其中 ≤9 月是研究阈值，接近标准 distribution transformer 历史区间上沿，不是 DOE 的正式目标。

### 7.6 数据中心供给、预租与建设成本

[JLL 2026 Global Data Center Outlook](https://www.jll.com/en-us/insights/market-outlook/data-center-outlook) 估计主要市场平均并网等待超过 4 年，2026 年全球平均建设成本约 1,130 万美元/MW、同比增长约 6%；[JLL 新闻稿](https://www.jll.com/en-us/newsroom/global-data-center-sector-to-nearly-double-to-200gw-amid-ai-infrastructure-boom) 称全球 occupancy 约 97%，在建 pipeline 约 77% 已预承诺。[CBRE 2026](https://www.cbre.com/insights/reports/global-data-center-trends-2026) 也强调 major hubs 的 power constraint、租金上升和 development timeline 延长。

这些数据支持 facility 紧缺，但必须防止双重计算：

- 一个 hyperscaler 可同时在多个开发商处预留；
- 预租不等于已交付 MW；
- construction cost 上升会抬高投资金额，却可能降低实际新增 MW；
- “available shell”若不能支持 100 kW+ rack、液冷、网络和冗余，不能视为 AI-ready supply。

建议把 capacity 分成四类：

| 容量 | 定义 | 计入供给的权重 |
|---|---|---:|
| Energized & sellable | 已上电、网络/冷却就绪、客户可部署 | 100% |
| Commissioning | 设备安装完成、正在测试 | 70%-90% |
| Under construction with firm power | 有设备、合同、firm service | 40%-70% |
| Announced/pipeline | 缺 firm power 或客户 | 0%-20% |

### 7.7 液冷：组件会商品化，系统责任不会

高密度 rack 使 direct-to-chip liquid cooling 从可选项转为新建 AI hall 的默认设计方向。但“液冷”不是一个单一市场：

| 子环节 | 壁垒 | 2026 状态 | 长期价值 |
|---|---|---|---|
| 冷板、软管、快接、泵阀 | 中低到中；需可靠性认证 | 局部紧 | 易扩产、ASP 可能下降 |
| CDU/heat exchanger | 中；控制、冗余与服务重要 | 局部紧 | 规模与 installed base 有价值 |
| chiller/heat rejection | 中高；facility design 与能效 | 局部 | 项目型、周期长 |
| power＋cooling integrated design | 高；跨系统责任 | 严重-局部 | 最强价值捕获 |
| commissioning/field service | 高；现场经验和故障责任 | 严重-局部 | 收入持续、ROIC 较好 |

[Vertiv 2026Q1](https://investors.vertiv.com/news/news-details/2026/Vertiv-Reports-Strong-First-Quarter-with-Diluted-EPS-Growth-of-136-Adjusted-Diluted-EPS-Growth-of-83-Raises-Full-Year-Guidance/default.aspx) 收入 26.50 亿美元、同比 +30%，Americas organic sales +44%，adjusted operating margin 20.8%、同比提升 430 bps；公司正在加速 capacity expansion。[Eaton](https://www.eaton.com/us/en-us/company/news-insights/news-releases/2026/eaton-reports-record-first-quarter-2026-results.html) 收购 Boyd Thermal，也说明 power 与 thermal 正在一体化。

**液冷反证不能只看 attach：**

- attach 上升、ASP 同比跌 >15%、供应商 gross margin 下滑：行业增长但组件定价权被证伪；
- leak/RMA >2%、首次验收 <90% 或延误 >60 天：交付风险上升；
- attach 上升、RMA <1%、服务收入和 margin 同升：系统集成商价值上修；
- rack power density 停在 <80 kW 且新平台延迟：下修高密度液冷弹性。

### 7.8 MEP、劳动力、预制化与 commissioning

[Comfort Systems USA 2026Q1](https://www.sec.gov/Archives/edgar/data/1035983/000110465926047679/fix-20260423xex99d1.htm) 收入 28.7 亿美元、同比 +57%，backlog 124.5 亿美元、同比约 +81%。[EMCOR 2026Q1](https://emcorgroup.com/investor-relations/press-releases/2026-news/emcor-group-inc-reports-first-quarter-2026-results) RPO 156.2 亿美元、同比 +32.9%。[Quanta Services 2026Q1](https://investors.quantaservices.com/news-events/press-releases/detail/396/quanta-services-reports-first-quarter-2026-results) RPO 262 亿美元、total backlog 485 亿美元，electric segment RPO 234 亿美元。

MEP 是“软硬混合瓶颈”：

- 可通过 prefab、模块化、标准设计和多班次缓解，因而不是永恒硬瓶颈；
- 但有经验的电工、pipefitter、controls engineer、commissioning team 与现场安全责任不能短期复制；
- backlog 过高可能带来固定价合同、工资、质量和 working capital 风险。

### 7.9 Backlog conversion 规则

| 组合 | 解释 | 受益/受损 |
|---|---|---|
| backlog +30%，revenue +30%，margin 上升 | 量价和执行都强 | MEP/设备商上修 |
| backlog +30%，revenue <+10%，margin 下滑 | 设备、劳动力或验收卡住 | 下修承包商，上修稀缺上游 |
| backlog 下降，revenue/FCF 上升 | 正常消化 | 上修开发商/colo，承包商中性 |
| backlog 下降、revenue 下降、取消增加 | 需求反证 | 全链下修 |

只有第四种组合能把项目取消判为全局悲观。前三种更多是瓶颈位置变化。

## 八、政策、地缘、融资和资产残值瓶颈

### 8.1 出口管制：规则放宽不等于收入兑现

[BIS 2026-01-13](https://www.bis.gov/press-release/department-commerce-revises-license-review-policy-semiconductors-exported-china) 将 NVIDIA H200、AMD MI325X 及类似芯片对华许可改为满足条件后的 case-by-case review；条件包括不减少美国客户可得的全球产能、客户合规流程和美国第三方测试。但 [NVIDIA FY2027 Q1](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-First-Quarter-Fiscal-2027/default.aspx) 的下一季指引仍假设中国 Data Center compute revenue 为零。

政策判断分三层：

| 层级 | 可观察指标 | 解读 |
|---|---|---|
| 规则 | BIS rule、ECCN、license policy | 只说明可能性 |
| 执行 | license approval、测试、客户清单、交货 | 说明可成交 |
| 财务 | 区域收入、库存/charge reversal、gross margin | 才说明需求兑现 |

**上修阈值：** NVIDIA/AMD 实际中国相关 Data Center compute revenue 连续两个季度超过 50 亿美元/季或占对应 DC compute 超过 5%，且不挤占美国客户供给。  
**下修阈值：** 连续两季收入为零；限制扩展到 HBM、先进封装、cloud access 或更多设备；产生新增 inventory/purchase commitment charge。

### 8.2 主权 AI 与数据本地化：既是摩擦，也是新订单

HPE 2026Q2 披露累计 AI order mix 中 sovereign/enterprise 达 61%；Microsoft 称 33 个国家的客户正在建设本地 cloud/AI 能力。主权要求会：

- 增加区域数据中心、合规云、on-prem/private AI 和本地服务需求；
- 降低全球统一 fleet 的 fungibility，提高小规模部署成本；
- 使 HPE、Dell、regional colo、local utility 和安全/合规软件受益；
- 使只依赖少数超大集中式 campus 的架构承担更高政策风险。

反证不是“某国宣布 sovereign AI fund”，而是 named customer、预算、power、chip license 和 COD 是否齐备。只有四项至少三项成立，才计入订单池。

### 8.3 美国许可政策：联邦提速不能替代州、地方和电网流程

[美国 Executive Order 14318](https://www.whitehouse.gov/presidential-actions/2025/07/accelerating-federal-permitting-of-data-center-infrastructure/) 把 >100 MW、用于 AI inference/training 等的数据中心定义为可加速项目，并涵盖 transmission、transformer、switchgear、发电、半导体、网络和 storage 等组件。该政策有利于 federal land 与联邦许可，但不能自动解决：

- utility service obligation 和 RTO study；
- 州 PUC、地方 zoning、水和噪音；
- transformer/turbine 的实体交期；
- 天然气管线和 transmission right-of-way；
- 社区反对与费率分摊。

政策上修必须看到 **permit cycle 实际缩短至少 25%、firm MW 增加、COD 提前**，不能只看行政命令。

### 8.4 区域瓶颈映射

| 区域 | 最主要瓶颈 | 缓解路径 | 受益者 | 反证 |
|---|---|---|---|---|
| 美国 PJM/Virginia | transmission、firm capacity、变电站、费率分摊 | 新输电、可靠容量、外移至 secondary markets | utility、PWR、ETN、GEV、secondary-market colo | large-load forecast 连续下调、项目取消 >10% |
| Texas/ERCOT | queue 质量、generation sufficiency、gas/transmission | Batch process、765kV、BTM gas/BESS | AEP、utility/EPC、generation | qualified MW <20% headline queue |
| 中国 | 高端 GPU/HBM/设备出口限制 | 国产 ASIC、旧代芯片优化、批准 H200 类进口 | 本地 ASIC、网络、光模块、数据中心 | license 无财务兑现或限制再收紧 |
| 欧洲 | grid、permit、能源价格、数据主权 | renewables/nuclear、secondary markets、regional cloud | electrical/colo/sovereign cloud | PPA/permit 延迟 >12 月 |
| 中东/主权市场 | 水/冷却、人才、网络、项目治理 | 低成本电力、主权资金、国际集成商 | HPE/Dell、power/cooling、network | 宣布金额大但 named workload/tenant 缺失 |
| APAC 新市场 | grid 与 submarine/network density、施工生态 | Johor/Batam 等新集群、区域互联 | colo、electrical、optics | vacancy 上升、prelease 下降、power allocation 延后 |

### 8.5 融资与残值风险矩阵

| 风险 | 领先指标 | 阈值 | 影响链 |
|---|---|---|---|
| 利率/信用 | 新债 coupon、spread、DSCR | all-in >9% 或 EBITDA/interest <1.5x | NeoCloud CapEx → OEM/optics/memory |

| 会计寿命 | GPU useful life 与市场价格 | 延长折旧年限同时残值/租价下降 | accounting profit 高估 |

## 九、三情景切换规则：什么时候上修、维持、下修或证伪

### 9.1 四档情景的统一定义

虽然研究要求通常称“三情景”，为满足上修路径，本报告采用四档：悲观、务实、乐观、极度乐观。当前位于 **乐观**。

| 总情景 | 需求 | 供给/交付 | 利润率 | 资本与电力 | 核心条件 |
|---|---|---|---|---|---|
| 悲观 | AI/Cloud 增速 <15%-20%，利用率和租价下降 | backlog 取消、库存上升 | 上游 ASP/毛利急降，OEM 价格战 | CapEx 下调 >20%，融资收紧、项目取消 | 至少三个独立需求指标同时反证 |
| 务实 | AI/Cloud 仍增 20%-30%，但低于 CapEx | 供应逐季改善，局部延误 | HBM/optics margin 见顶，设施链仍强 | CapEx 稳定或下调 <10%，电力仍紧 | 需求尚可，回报和节拍变重要 |
| 乐观（当前） | AI/Cloud >30%，tokens/客户扩张 | memory、CoWoS、电力和设备限制交付 | 稀缺上游和集成商量价齐升 | 四大 CSP CapEx 约 7,100 亿美元，项目融资可得 | 供给约束解释大部分未兑现收入 |
| 极度乐观 | AI/Cloud >50%、agent usage 非线性增长 | 扩产提前仍被需求吸收 | 上游高 margin 延长，下游交付也加速 | CapEx >约7,800 亿美元且 2027 guide 再升，firm MW 同步增加 | 需求增长快于效率与供给扩张 |

### 9.2 分产业链四情景

| 产业链 | 悲观 | 务实 | 乐观 | 极度乐观 | 核心反证/上修 |
|---|---|---|---|---|---|
| AI 需求 | Cloud/AI <20%，token/用户下滑，CapEx cut | 收入 20%-30%，ROI 分化 | 收入 >30%，付费使用与 backlog 强 | 收入 >50%，agent/multimodal 带来 >100% token 增长 | 收入、token、租价、CapEx 至少三项同向 |
| GPU/ASIC | inventory/discount 上升、B/B <1 | wafer 缓解、竞争压 ASP | 多架构放量，仍受 allocation | GPU＋ASIC 均超预期，供给仍紧 | DC revenue、wafer allocation、rental index |

### 9.4 多指标决策规则

为了避免被单一新闻带动，采用“2-of-3/3-of-5”规则：

- **单一瓶颈切换：** 价格、数量、库存/交期三类指标中至少两类越过阈值。
- **全局需求切换：** AI 收入、token/用户、GPU 租价/利用率、AI server B/B、CapEx 五类中至少三类反证。
- **全局极度乐观：** 需求五类中至少三类上修，同时 firm power/COD 不恶化；只有需求上修、没有电力兑现，只上修上游，不上修 facility revenue。
- **政策事件：** 规则公布只占 0.5 个信号；实际 license/shipment/revenue 才占完整一个信号。

### 10.4 长期定价权与短期供不应求

**较强长期定价权：**

- advanced node＋advanced packaging 的协同与 yield；
- HBM4/HBM4E 的客户定制、logic base die 和 stack/test；
- high-end ATE、probe/interface 与 known-good-die；
- switch ASIC、high-speed laser/material 和经过量产验证的 silicon photonics；
- transformer/switchgear 的认证、installed base、service；
- power/cooling/commissioning 的系统责任。

**更偏短期供不应求：**

- 通用 ODM 产能；
- 通用 ABF/substrate、连接器、普通铜缆；
- 标准冷板、泵阀和无差异 CDU；
- 只有 shell、没有 power/network/cooling 的数据中心面积；
- 因 panic buying 形成的 generic memory/SSD 渠道库存。

### 11.4 更新动作标准

每次日度更新只允许做以下四种动作之一：

1. **上修瓶颈强度**：短缺更严重、交期/价格/订单至少两项加强；
2. **下修瓶颈强度、上修下游交付**：供给改善但需求仍强；
3. **下修全局需求**：满足 3-of-5 需求反证；
4. **不动作、等待确认**：只有 headline、单日价格或未经验证渠道。

建议每条更新保存以下字段：

| 字段 | 内容 |
|---|---|
| observation_date | 消息/数据发生日期，不是文章抓取日期 |
| bottleneck | 对应本报告统一瓶颈名称 |
| metric | 指标与口径 |
| value / prior | 当前值与前值 |
| source_tier | A/B/C/D |
| lead_lag | 领先/同步/滞后 |
| impact_chain | 上游、下游和公司 |
| threshold_hit | 命中哪个阈值 |
| action | 上修/维持/下修/证伪 |
| verification | 已验证/待第二来源/已否定 |

### 12.2 数据质量与已知缺口

1. HBM ASP、CoWoS monthly capacity、substrate lead time、liquid-cooling attach 和 fleet-wide GPU utilization 多数不由公司完整公开；本报告使用 LTA、inventory、OEM constraint、capacity/yield、租赁价格和 backlog conversion 交叉验证。
2. TrendForce、LightCounting、JLL、CBRE 的部分完整数据在付费报告内；本报告只使用其公开新闻稿/摘要中可核验的数字。
3. CoreWeave revenue backlog 比会计 RPO 更宽，包含公司估计未来可确认的 committed contract amounts，且受 delivery/availability 条件影响；因此不能与 Microsoft/Alphabet RPO 直接等同。
4. 估值快照来自即时行情接口，可能因 GAAP 一次性项目、拆股、股本或时点产生失真；没有进入瓶颈强弱评分。
5. 所有 2027-2028 状态都是基于截至报告日期的条件预测；一旦研究阈值触发，应更新状态而不是保留旧结论。
