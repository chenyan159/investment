# 机柜级供电与服务器电源架构：功率密度、架构迁移与价值分配

研究截止日期：**2026年9月18日**。预测期间：2026、2027、2028自然年；2030仅用于固态变压器突破分支。金额如无特别说明均为名义美元，**$B=十亿美元，1B=10亿美元**。GW表示当年设备可服务的IT设计功率，不表示全年平均耗电、不表示园区接电容量，也不表示PSU铭牌功率的简单相加。

证据标记：**F**=公开披露事实；**M**=厂商、客户或机构目标/预测；**C**=直接计算；**E**=本报告研究估计；**U**=不能从公开资料识别。模型中的区间均为**参数条件范围或情景包络，不是统计置信区间**。2026全年尚未结束，不能把全年模型写成实际市场规模。

## 一、核心判断与最重要的反证

本行业正在从“卖更多服务器电源”转向“在有限空间、可维护性和电网约束下，交付更多可用计算功率”。未来两年的收入增长较有依据，但**功率增长、800V渗透、厂商利润扩张是三件不同的事**。

1. **2026—2027的主收入仍来自现有交流输入、48/54V分配和服务器端电源升级；800V已进入可执行的过渡阶段。** NVIDIA于2026-08-11披露，适配现有交流机房的800V power rack计划于2026下半年提供，行级power center预期2027可用。这使早期采用不必等待整个新园区建成；但原有进线容量、散热和行间空间仍是条件，公告不是已验收GW统计。[R01](https://blogs.nvidia.com/blog/800-vdc-power-architecture-ai-factory/)

2. **高压化可以提高单柜金额，同时压低单位可用kW的长期价格。** 整流从服务器内移到power shelf、sidecar，再移向行级或设施级；串联的两级转换不能计为两份终端用电需求。高密度电源的初期溢价来自空间、动态响应、认证和系统责任，成熟后开放接口、多个合格来源和集中采购会让部分价值回到客户。

3. **最值得警惕的市场误算，是把BBU当成所有AI功率的必配项。** 新版NVIDIA白皮书的power rack有带BBU和不带BBU选项，并把局部负载平滑与后备供电分开。小能量电容、短时电池、设施UPS和园区储能解决不同时间尺度的问题，不能全按同一GW叠加。[R03](https://dam-cdn.nvd.orangelogic.com/AssetLink/7rj0u54stc41tk6s57dbs2p0qdte5874.pdf)

4. **供给约束主要是客户认可的规格、工厂和动态性能，不能把它概括成“电源全面短缺”。** Advanced Energy（AE）2026上半年Data Center Computing收入为385.7百万美元，第二季度为191.5百万、同比增长35.2%，但环比低于第一季度194.2百万。其新泰国工厂仍在客户认证，首批生产收入目标为2026第四季度。已有需求增长与尚未形成的有效新增供给同时存在。[R12](https://ir.advancedenergy.com/media/document/811571e0-756f-4f18-ab22-e3dea8229615/assets/AEIS_2026_Q2_2026_Earnings_Press_Release.pdf) [R13](https://ir-api.eqs.com/redirect/298cec26-78b9-4b05-97b2-a8c5b38b5ccb?disposition=inline&t=1785938568453)

5. **放量不自动带来自由现金流。** 台达2026上半年资本支出披露为新台币275亿元，全年管理层估计约700亿元；扩建厂房通常需要约2—2.5年。AE上半年经营现金流79.0百万美元，购置固定资产86.1百万美元，简单相减为−7.1百万美元。这不是电源业务单独现金流，却证明“公司收入增长”不能替代资本回报分析。[R11](https://filecenter.deltaww.com/IR/download/calendar/2Q26_Transcript.pdf) [R12](https://ir.advancedenergy.com/media/document/811571e0-756f-4f18-ab22-e3dea8229615/assets/AEIS_2026_Q2_2026_Earnings_Press_Release.pdf)

**本报告最有依据的方向判断：** 普通电源更接近竞争充分、可扩供；高密度48/54V平台在换代窗口存在结构性偏紧；800V整条链的主要约束仍是资格认证与客户部署，其全球供需缺口尚无可审计统计。2027—2028即使行业继续增长，也可能同时出现旧规格降价、800V收入增加、单厂利润分化。

核心市场定义为G普通服务器转换电源、L高密度低压转换电源、V高压直流完整转换链、S配套短时备援/缓冲设备四个互不重复的最终电源子系统采购池。**不含GPU、板端稳压器、设施UPS、园区变压器、楼宇母线、电费和工程安装。** 第七节及附录给出逐项参数、供给条件、价格、成本和毛利结果。

这里的宽区间主要来自可兑现采购GW、客户成交价和规格匹配的不透明，而非统计噪声。不能把基准中点当成市场共识，也不宜将高端数值作为公司收入预测。**2028悲观路径允许核心市场低于2025估计基数；乐观上端要求远高于当前IEA中枢的设备采购强度和较快的电源认证，具有显著融资、上电与库存风险。**

最强反面解释是：算力需求继续增长，但芯片/系统能效、旧电源重复使用和集中式供电使每单位计算的电源支出快速下降；新增工厂在需求放缓时投产，最后增长主要由客户获得。支持这一解释的证据包括Meta的模块重复使用设计、OCP开放接口及新进入者提出的大幅降本目标；反对证据则是实际客户上电增长、高密度产品升级和已披露的供电器件收入。两者应通过同代产品净价、合格产能、采购功率与客户利用率区分，不能只看800V发布数量。[R18](https://engineering.fb.com/2025/10/14/data-center-engineering/design-for-sustainability-new-design-principles-for-reducing-it-hardware-emissions/) [R04](https://www.opencompute.org/index.php/blog/powering-the-next-era-of-ai-how-google-microsoft-and-nvidia-are-standardizing-and-accelerating-the-industry-transition-to-lvdc)

G/L按实际平台负载类别划分，而非只按电压划分；例如普通CPU机柜也可使用48V OCP电源。V按架构划分，其中可能包含非GPU工作负载，但本次量化将早期V集中在高密度H群，普通服务器直接HVDC增量留在覆盖缺口中。

核心市场还不覆盖旧设备独立维修渠道的全部电源替换、与当年IT交付无关的存量BBU更换、全部网络交换机电源，以及电力工程服务。本报告给出的是**主要服务器及机柜转换/配套备援硬件的可约束子市场**，不是所有“数据中心电力”产品的TAM。

### 2.3 付费任务及预算归属

客户付钱主要为了四件事：在给定机柜体积中供应连续与峰值功率；在负载骤变时维持电压和计算稳定；隔离局部故障而不扩大停机；在规定时间交付可被设施团队安全维护的系统。

这笔钱既有新增也有转移。新机房、增加算力是新增；服务器换代、PSU故障更换是替换；由机内PSU改为sidecar，可能把ODM的采购预算转给设施或系统集成团队。SST进一步落地时，预算还可能从变压器、UPS和楼宇配电迁入集成电力电子。**某家公司的收入翻倍可以来自预算迁移，不能据此判断终端电源总支出翻倍。**

最终负载的经济价值由GPU利用率、可收费服务/内部生产率和停机成本决定。普通推理节点未必需要MW机柜：若算力可以分散、网络成本可控且旧机房有空间，低密度部署可能更便宜。大规模同步训练、scale-up连接距离和机柜空间限制，才更容易产生高密度供电的支付意愿。

## 三、技术变化为何产生经济价值，又如何流失

### 3.1 三条共存路线，而非一个替换日

```text
现有低压路径：设施AC → 服务器PSU/机柜AC-DC → 48/54/12V → 板端稳压 → 芯片
过渡高压路径：现有设施AC → sidecar/行级整流 → 800V或±400V → HV DC-DC → 板端稳压
远期原生路径：中压AC → 变压整流器或SST → 800V配电 → HV DC-DC → 板端稳压
备援/缓冲：在上述适合节点旁路接入；容量、持续时间和故障边界另行设计
```

原生800V不必全部采用SST。工频变压器配整流器也是路线；SST是进一步整合中压隔离与变换的分支。把800V采用概率等同SST采用概率，会高估近期SST市场。

OCP于2026-08-11明确区分现有480VAC下的±400V/0—800V side power rack与长期中压直接转换。其“现有设施无需改变上游”的前提是**有足够交流容量和行间空间**。[R04](https://www.opencompute.org/index.php/blog/powering-the-next-era-of-ai-how-google-microsoft-and-nvidia-are-standardizing-and-accelerating-the-industry-transition-to-lvdc) Diablo 400 v0.7.0日期为2026-03-01，SST v0.3.0封面生效日为2026-06-22；后者博客发布在8月，不能把博客日期当作规范生效日。[R05](https://www.opencompute.org/documents/ocp-specification-diablo-400-v0-7-0-final-pdf) [R06](https://www.opencompute.org/documents/ocp-sst-design-specification-v0-3-final-pdf)

“HVDC”是行业对高于48V直流的常见称呼；800V在相关低压配电讨论中仍属于LVDC范围。名称相近不代表±400V与单极800V的接地、共模、连接器和保护可以直接互换。

### 3.2 物理约束：降低大电流，但不能直接宣称系统损耗下降200倍

按直流功率关系 (I=P/V)，不考虑转换损耗：

| IT设计负载 | 54V电流，C | 800V电流，C |
|---|---:|---:|
| 120kW | 2,222A | 150A |
| 250kW | 4,630A | 313A |
| 1MW | 18,519A | 1,250A |

相同导体电阻下，54V升至800V，电流降为6.75%，导体电阻损耗降为约0.456%，即约219倍差异。但真实设计会同时缩小导体截面、改变路径和增加绝缘/保护；**219倍只适用于固定电阻的那一段导体，不能用于整柜、园区或电费。** NVIDIA早期材料中的节铜、效率和TCO上限也有特定系统比较边界，不是本报告统一采用的利润假设。[R02](https://developer.nvidia.com/blog/nvidia-800-v-hvdc-architecture-will-power-the-next-generation-of-ai-factories/)

200kW不是所有48V设计的绝对物理上限。采用多母排、多个供电区、液冷母排或增加电源柜，可以延长其生命周期；代价是材料、空间、安装复杂度和可维护性。高压路线的经济阈值随机房空间价格、冗余方式和电网接入条件变化。Meta在2024年已介绍最高140kW的Catalina/ORv3 HPR；现行OCP目录仍同时保留多种机架、电源与连接器规范，支持“多代际共存”而非统一切换日的判断。[R37](https://engineering.fb.com/2024/10/15/data-infrastructure/metas-open-ai-hardware-vision/) [R38](https://www.opencompute.org/wiki/Open_Rack/SpecsAndDesigns)

### 3.3 效率收益必须比较整条路径

台达2026 COMPUTEX页面列示110kW三相AC/DC shelf效率超过97%，90kW 800→54V shelf效率98%；GTC展示的660kW高压电源柜AC/DC效率最高98%。这些是不同产品与测试条件，不能把某一阶段的98%当作从电网到芯片98%。[R07](https://www.deltaww.com/en-US/landing/Computex-2026) [R08](https://www.deltapowersolutions.com/en/mcis/news-2026-delta-exhibits-energy-saving-solutions-for-800-vdc-at-nvidia-gtc-2026.php)

**C，纯转换算例：** 98%的AC/DC串联98%的HV DC/DC，合计为96.04%。若旧路径AC→54V本身已达到97.5%，仅增加这两级转换并不会节电；高压化需要通过降低输电损耗、减少其他级数、释放计算空间或改善峰值管理来证明收益。这里的97.5%是比较假设，不是将台达不同型号直接进行实测排名。

**E，同一1MW IT负载资产的节电阈值：**

- 旧整条电力路径效率93%、新路径96%，全年平均负载率70%，电价0.08美元/kWh。
- 年节电量 (1,000×8,760×0.70×(1/0.93-1/0.96)=206,048) kWh，电费约16,484美元/年。
- 假设寿命6年，折现率10%，新增设备溢价200,000美元，额外维护2,000美元/年，第4年更新20,000美元，残值为零；节电扣维护的现值约63,100美元，再扣更新现值约13,660美元，净现值约**−150,600美元**。
- 在同样负载及效率下，电价0.05—0.15美元/kWh，对应节电约10,300—30,900美元/年；若只有1个百分点路径效率改善，回收更慢。

这些是条件算例，不是全行业统一寿命/报价。它说明：**仅节电通常不足以解释高额过渡改造溢价。** 更强的价值机制是避免机柜空间失配、缩短可用算力上线时间，或在固定进线下释放有效计算容量。这些价值若没有客户利用率和现金收入证据，不能自动资本化。原生新建若省掉旧设备，经济账又不同，必须将避免支出计入同一资产边界。

### 3.4 板端：800V解决不了最后一厘米的大电流

即使采用800V配电，芯片仍需要低压大电流。3kW核心负载在0.8V下是3,750A。将最终稳压放在处理器附近、背面或封装内，可减少低压路径损耗并改善瞬态；代价是封装、散热、良率、维修和平台绑定。

Infineon于2026年3月公布的800→50V与800→12V参考设计均为6kW TDP、10.8kW持续400微秒的峰值能力；后者披露峰值效率98.2%、满载97.1%。这证明参考设计的工程进展，不证明整个供货市场已满足该规格，也不把400微秒峰值当作连续功率。[R22](https://www.infineon.com/technology-news/2026/infpss202603-067)

垂直供电和TLVR不是同义词：前者描述供电路径/空间布局，后者主要描述多相调压耦合方式，二者可以结合。800→12V或6V直接转换可能减少一个中间级，令部分48→12V模块收入消失；因此板端模块和HV转换的市场预测不能同时保留所有旧级数。

### 3.5 储能：需要多少能量取决于时间，不只取决于功率

按 (E=P×t)：

- 1MW持续1毫秒需要1kJ，仅0.278Wh；
- 1MW持续1秒需要0.278kWh；
- 1MW持续60秒需要16.67kWh。

电池实装容量还需考虑允许放电倍率、低温/高温、循环、SOC窗口、老化、冗余和转换损耗。不能拿16.67kWh乘通用储能电芯价，就认定得到了BBU售价；也不能拿1MW乘园区4小时BESS价格。

NVIDIA新版方案中的BBU规格示例为80kW、60秒，对应输出能量1.333kWh；内置电容负责另一时间尺度的输入整形。[R03](https://dam-cdn.nvd.orangelogic.com/AssetLink/7rj0u54stc41tk6s57dbs2p0qdte5874.pdf) 2026-09-11发布的一项预印本展示400V系统、10kW缓冲功率、3,500美元BOM的有源滤波原型；它是可行性与成本结构线索，不是量产成交价，且尚不能据此推断客户认证与寿命。[R29](https://arxiv.org/abs/2609.13490)

最有信息价值的问题不是“电池是否增长”，而是**同一可靠性目标最终由软件错峰、小电容、独立CBU、BBU或设施储能中的哪种组合以最低全寿命成本完成**。软件错峰可能牺牲部分算力性能；短时硬件缓冲可能增加器件成本却减少上游超配，两种方式需用同一任务吞吐比较。

### 4.2 需求事实与模型之间的桥

IEA 2026报告估计2025全球数据中心用电485TWh、同比增长17%，2030中枢950TWh；AI专用数据中心2025用电增长50%。这些是机构估计及预测，覆盖全部数据中心电力，不能直接乘PSU价格。[R16](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary)

C：485TWh对应全年设施平均负荷55.37GW。若PUE为1.3—1.5、平均IT负载/已装IT设计功率为55%—70%（均为E），对应已装IT设计功率约52.7—77.4GW。这给服务器电源存量提供数量级约束，**并不等于2025新增出货GW**。

微软FY2026第四季度电话会披露该季度新增约1GW容量；该量包含其整体数据中心范围，未给出本报告所需的全部AI/IT电源归属，故只作为建设速度锚，不能与其租赁供应商容量再相加。[R17](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q4) IDC截至2026-07-28的材料显示第一季度服务器支出增长30.7%，台数仅增长3.3%，直接反驳“服务器金额增长等于台数增长”的假设。[R19](https://www.idc.com/promo/servers/)

本报告用**新增部署、设备刷新、交付/上电时间差**建立需求账：

```text
D_IT(y) = 新增部署所需电源功率 K(y)
        + 刷新设备中确需新电源的功率 R(y)
        + 当年设备交付领先上电的净增加 W(y)
G(y) + H(y) = D_IT(y)
H中按h分给V，其余分给L；同一功率只分一次
```

R已扣除可重复使用的PSU/shelf，W是净增加而非累计未上电资产。它们是采购功率桥，不是全球项目清单的精确加总。以下为需求模型的独立约束区间；最终G/H采用其中符合产品结构的组合，不能将所有上下界自由叠加后解释为概率。

| 年度/路径 | K新增部署GW，E | R需要新电源的刷新GW，E | W交付领先净增GW，E | K+R+W约束包络 | 模型采用G+H |
|---|---:|---:|---:|---:|---:|
| 2025历史重建 | 9—14 | 9—11 | 1—2 | 19—27 | 19—27 |
| 2026 P | 10—15 | 10—12 | 1—3 | 21—30 | 22—29 |
| 2026 B | 12—19 | 11—13 | 3—5 | 26—37 | 27—36 |
| 2026 O | 16—25 | 12—15 | 4—6 | 32—46 | 33—43 |
| 2027 P | 8—16 | 11—14 | 0—2 | 19—32 | 21—31 |
| 2027 B | 17—26 | 13—17 | 3—5 | 33—48 | 34—48 |
| 2027 O | 26—39 | 16—20 | 5—7 | 47—66 | 47—64 |
| 2028 P | 6—14 | 12—17 | 0—2 | 18—33 | 20—33 |
| 2028 B | 24—39 | 16—21 | 3—5 | 43—65 | 43—64 |
| 2028 O | 37—54 | 21—28 | 6—10 | 64—92 | 65—92 |

**约束逻辑与可信度：** 2025的52.7—77.4GW存量若约5—7年刷新、其中75%—95%的刷新需新电源，对应约5.6—14.7GW/年，覆盖所用R；未来存量扩大但复用比例上升，故R增长慢于高密度新建。K范围由IEA电量变化、客户已交付速度与工程爬坡共同约束，不能由云资本支出直接反推。2026—2028高端K要求能源供给和实际负荷显著超出平缓建设路径；2028乐观上端还需新增设备在2029以后继续爬坡消纳，不能永远靠W增长支撑收入。

G的14—18GW基准可由约1,200—1,500万普通服务器等价单元、每单元含存储/配套负载约1.0—1.2kW理解；这是E桥梁，不宣称已取得该台数的行业统计。H的13—18GW约对应86,700—120,000个150kW高密度机柜等价量，**只是统一功率的换算，绝非NVL72实际出货数**；ASIC、传统8卡服务器和不同代际均在H内。

### 4.3 采用顺序与时滞

既有成熟电源在已认证工厂增班与扩线可以快于新工厂投产；新平台则需样机、动态负载/故障测试、客户与工厂资格、整柜联调、客户接收和回款。以下为E执行假设，用于情景时间安排，不是所有企业共同披露的交期：

- 已有客户/平台的常规追加：约1—2个季度，受材料与排产影响。
- 新功率等级或新工厂转移：约2—4个季度；若客户要求重新验证寿命/故障行为，可更久。
- 800V整条链首次平台导入：约3—6个季度，从部件可用到现场验收还需跨厂协调。
- 全新厂房：以台达所述2—2.5年作为现实建设锚；已购厂房改造可能更快，但仍有设备和认证周期。
- 原生中压直流/SST：还叠加中压保护、设施保险/许可、维护和长期可靠性证据，不能仅凭芯片样品预测当年现金贡献。

采购往往早于上电；未上电的电源可以已形成供应商收入，但如果客户后续验收条件、退换货或付款没有满足，现金与收入仍可分离。

归属范围的理由：台达电源分部仍含工业/消费电源及零组件，基础设施分部又含大量不在本池的产品；LITEON云类不全是电源且含BBU；AE最接近所研究范围。其他组用于覆盖遗漏，证据最弱。上下游内部交易与转售若未剔净会高估。**这些比例不是市场份额，更不是实际披露服务器电源收入。**

供给反事实模型令H2/H1可交付工作量比为1.05—1.35、闲置/加班能力因子为1.05—1.15；按同基期产品价格估计全年潜在供货金额约8.5—16.8B。先假设其中10%—20%为S类独立备援/缓冲并剔除，避免把同一负载的电池和转换电源功率相加；再用可比转换产品平均170—350美元/可用kW折算，G+L+V物理外包络约**19.5—89.1GW/年**。这一外包络非常宽，足以说明公开分部披露**不能精确识别全球物理产能或产能利用率**，更不能据此宣布短缺若干GW。S的输出功率能力与秒数另列，不加入该转换功率总量。

附录采用的G/L/V/S有效供给工作区间是上述外包络内的**条件化规划参数E**：进一步假设不同产品线分配、认证完成和不重复转售。它们不是统计估计，不能比原始外包络获得更高证据等级。2026各需求情景采用同一供给区间，2027—2028才按认证和扩线速度分化，避免人为要求供需总能同时改善。

完整物理关系应为：

```text
S_qualified = 装配名义铭牌GW × 良率 × 客户已认证比例
              × 可按期材料齐套比例 × 当期实际可运行比例
              ÷ 冗余/降额折算
```

关键系数均未有全球公开统计。已有成熟线新增转换规格时，客户认证比例而非SMT机器数量可能成为约束；800V还受保护器件、连接器、磁性件、绝缘距离、固件联调与高功率测试制约。价格提高会扩大美元收入能力，**不会自动增加上述物理能力**。

### 5.3 供需交叉比较与现实倾向

2026基准需求：G 14—18GW、L约12.5—17.7GW、V约0.20—0.72GW；工作供给条件分别为18—26、14—23、0.4—1.2GW。G最接近充分供给，L在低端供给/高端需求组合下偏紧，V则可能是需求部署慢于供货，也可能是特定平台资格不足。整体范围相交，不能得出全行业短缺结论。

2027基准V需求1.9—6.16GW，对应3—7GW条件供给：能否完成多个客户平台和多个工厂认证，决定上端能否兑现。**若合格供给仍只有1GW，则V实际收入应降至约0.42—0.62B，而不是仍保留3.82B上端。** 该缺口不能靠多做旧款48V电源补齐；可行替代是改平台、降低密度或延期。

2028基准V需求7.56—18.9GW，对应10—20GW条件供给；此时“扩供成功但单位价格下降”比持续依靠稀缺涨价更应进入基本情景。作为起点的2026转换供给落在19.5—89.1GW外包络的哪一端仍未知，因此本报告将**结构性认证偏紧**赋予比“全市场长期短缺”更高的可信度。

需求延期会先提高库存和推迟提货，再通过季度/年度重新议价压价格；在长期定价合同下，短缺可能表现为交期延长或采购承诺，而非立即涨价。模型价格是净采购价条件，未假装取得云厂真实订单报价。

### 6.1 器件供给不能被整机供给掩盖

Infineon2026-05-06材料保留了三个不同口径：FY2025 AI服务器业务收入超过7亿欧元（F）；FY2026约15亿、FY2027约25亿欧元目标（M）；AI电源器件内容量100—250美元/kW、当前平均175美元/kW（公司口径M）。后者覆盖其所服务的电源链，**不能再作为纯GaN或纯板端稳压价格**。[R23](https://www.infineon.com/row/public/documents/corporate/investors/presentations/2026/2026-05-06-q2-fy26-investor-presentation-v01-00-en.pdf)

2026-08-05更新又提到已签或正谈判的多年容量预订合计高个位数十亿欧元。已签与谈判不可合并成确定订单，也不能把多年金额当作单年收入。[R24](https://www.infineon.com/press-release/2026/infpr202608-125)

这使“系统电源并非全面短缺”与“某些高电流器件仍需长期预订”可以同时成立。硅、GaN、SiC是组合选择：电压、频率、封装、导通损耗和可靠性共同决定BOM，成熟低压硅器件不会因800V输入而自动消失。

### 6.2 收入增长、毛利增长和现金增长的不同条件

核心电源制造商可用以下关系审查：

```text
收入 = 可交付可用kW × 净价/kW
毛利 = 收入 − 材料 − 直接制造 − 制造折旧 − 良率/保修成本
营业利润 = 毛利 − 研发 − 销售管理等期间费用
现金贡献 ≈ 税后营业利润 + 折旧 − 资本支出 − 营运资本增加
```

增长来源至少需要分开：功率数量、同代提价/降价、复杂产品占比、单位材料成本、工厂良率/摊薄与客户付款条款。台达Power Electronics在2026Q2收入NT$96,296百万、利润NT$20,142百万，对应分部利润率20.9%（C），但它不是本报告PSU毛利率。[R10](https://filecenter.deltaww.com/ir/download/calendar/2Q26_Analyst%20Meeting.pdf)

E，供应商新增10亿美元收入的现金检验：若毛利25%、新增期间费用10%，营业利润150百万；税率20%，制造折旧已含成本、取收入3%，资本支出10%—20%，新增净营运资本12%—22%，则增量现金约：
低投入组合：150×80%+30−100−120=**−70百万美元**；高投入组合：150×80%+30−200−220=**−270百万美元**。因此现金条件范围为−270至−70百万美元，不能把营业利润150百万直接称为自由现金流。

上述算例展示高速扩张初期可消耗现金；成熟年份资本支出降至折旧附近、营运资本增量放缓后现金才可能改善。没有产品线资产、应收/库存和研发分摊，本报告不编造厂商PSU ROIC。

## 七、联合情景模型：需求、有效供给、价格、成本与规模

### 7.1 统一口径与公式

模型采用全球年度最终电源子系统净采购金额、近似对应交付收入；不包含渠道重复转售、税、安装及设施级设备。p以美元/可服务IT kW表示，**已包括合理冗余、降额、柜内shelf及分配控制分摊**。S也是折算为同一可服务IT功率的当年有效能力，不能再乘一次N+1或2N。

G为普通负载、H为高密度负载；h为H中转向V的比例；aG/aH为选择独立短时备援/缓冲的功率配置率。该配置率并不意味着每台都满额60秒，也不意味着采用高压后必须购买BBU。

```text
D_G = G；D_L = H×(1−h)；D_V = H×h
Q_j = min(D_j, S_j)，j∈{G,L,V}
D_S_潜在 = G×aG + H×aH
Q_S = min(Q_G×aG + (Q_L+Q_V)×aH, S_S)
R_j($B) = Q_j(GW)×p_j($/kW)÷1,000
GP_j($B) = R_j×g_j
单位制造成本c_j = p_j×(1−g_j)
核心市场 = R_G+R_L+R_V+R_S
```

若V不够，模型不自动把未交付V改成L，因为平台、机柜和设施可能不兼容；延期量留在未满足需求。S的配套需求用已交付IT功率计算，避免给延期GPU预先加一套必然实现的电池收入。若客户为以后年度主动囤BBU，那是另一个库存场景，未作为基准支撑。

总量上下界以同一G、H、h配置计算，枚举h端点及供给封顶转换点；**L与V各自的区间下界/上界未必同时发生，不能直接将分项上下界相加复算总量**。附录保留计算算法。

### 7.2 情景机制及非对称收益

| 情景 | 客户需求和架构 | 供给和交付 | 价格、成本和价值分配 |
|---|---|---|---|
| P：采用放缓、复用增加、竞争压价 | 预算回报偏弱；新项目延迟；低密度推理与旧shelf复用；HVDC渗透放缓 | 已投建产线仍部分释放，成熟产品供给高于需求；HVDC认证项目减少 | 单位净价降得快于成本；G/L利润池收缩；客户取得低价但无电力的资产仍不能使用 |

### 7.3 价格锚与成本范围的依据

公开可直接观察的价格主要是替换渠道。Supermicro自营美国商店在截止日可见3kW电源535.19、643.38、691.07及982.14美元，即约178—327美元/铭牌kW，且有不同输出/形态与缺货状态。[R33](https://store.supermicro.com/us_en/server-accessories/power-supplies.html?product_list_limit=25&pwr_spl_output_type=766&pwr_spl_ttl_output=1271)

这些是**公开标价，非CSP成交价、非同一代际的价格序列**。本模型先作批量采购折让，再加入冗余/降额和shelf、保护、分配成本；普通G为约110—240美元/可用kW，高密度L约170—425，高压V约260—780，均按时期与情景变动。V包含两级转换与新保护/接口；不能用3kW旧电源标价精确验证它。其范围还受第三节客户支付阈值约束：超过传统路径的差价，必须有密度/时间收益或减少上游设备支出支持。

所有成本和毛利率均为E，没有假称获得厂商产品BOM。G成熟产品毛利大体8%—26%，L在10%—37%，V早期约0%—28%、成熟有条件22%—38%，S约10%—36%。范围以公司混合经营表现和产品成熟度作约束，不能拿半导体企业综合毛利替代PSU制造毛利。价格、成本和毛利的完整采用参数见附录A。

### 7.4 关键敏感性

以2027基准代表点G=17.5GW、H=23.5GW、h=16%、aG=27%、aH=55%、价格依次177.5/307.5/520/142.5美元/kW为例；若合格供给不封顶，核心市场约**13.65B**，只是演算点：

- H增加1GW，核心转换与配套S增加约0.42B；依赖实际供给和备援配置率。
- h增加10个百分点，L转V造成净增收入约0.50B，而不是把2.35GW×520美元/kW的1.22B全当新增。
- L同代净价下降10%、成本不变，约损失0.61B收入和同额毛利；若材料/良率同步改善，毛利降幅才较小。
- H备援配置率下降20个百分点，S收入减少约0.67B，GPU采购和转换电源收入可以不变。
- 若V供给由代表5GW降至2GW，约1.76GW高压需求受限；按同价及S配套，收入少约1.05B。替代方案取决于客户平台，不能预设旧电源可无损顶替。
- 同一个150kW机柜的电源价格上涨50%，但下一代每柜功率翻倍，则每kW价格实际下降25%。跟踪“每柜金额”而不跟踪额定可用功率会误判价格周期。

### 7.5 板端稳压：另列重要相邻子池

板端的最终低压转换、功率级/控制器与相关模块对结论重要，但公开资料难以拆开独立模块价格和OEM板卡增加值。附录B以**高密度H已交付功率×每kW板端方案采购价值**估计，只含中间母线之后到芯片核心/相关低压rails的电源部分；不含GPU、HBM本体、主板其余价值和已经计入V的800V转换级。

该池是E、低置信，不能与Infineon的整条AI电源链器件销售再相加。普通CPU板端稳压和所有网络设备板端电源未完整覆盖。其利润用供应商方案层面的条件毛利表示，不能转换为整机商净利。供给以能支持的H等价GW单独设定，避免默认PSU足够就等于板端芯片足够。

### 8.3 概率：事件、渗透和利润分别定义

## 九、未解决问题与覆盖边界

最重要的未知是：云厂同规格成交价、厂商按认证平台拆分的物理年产GW、V链在客户端的实际验收量、独立BBU配置率与秒数、板端电源内容价值、同一模块跨代复用比例，以及库存/应收在供应商与客户之间的转移。

因此本报告的优势是把需求、物理功率、转换级、预算归属与利润机制放在同一账内；局限是无法从公开披露得到全球逐厂逐客户的可交付能力。供给表与价格表应作为可审查的条件模型，不能对外转述为“全球已测得产能”或“市场真实成交价”。

没有将非正式产业链传言作为决定性证据，也没有按股票估值排名公司。对未上市进入者、国内平台、普通企业推理和边缘部署保留覆盖缺口；发现它们更快增长时，应调整G/H结构，而非强迫所有需求进入NVIDIA式MW机柜路线。

### A4. 可复算算法与范围性质

```python
# 每一年度/情景取A1中的G、H、h、aG、aH和A2/A3中的S、p、g。
# total上下界不能通过相加各细分上下界取得。
states = []
for end in (0, 1):  # 0=各参数低端；1=各参数高端
    G, H = G_range[end], H_range[end]
    S = [x[end] for x in S_ranges]
    candidates = [h_range[0], h_range[1], S[2]/H, 1-S[1]/H]
    for h in candidates:
        if not h_range[0] <= h <= h_range[1]:
            continue
        d = [G, H*(1-h), H*h]
        q = [min(d[j], S[j]) for j in range(3)]
        q.append(min(q[0]*aG_range[end]
                     +(q[1]+q[2])*aH_range[end], S[3]))
        rev = [q[j]*p_ranges[j][end]/1000 for j in range(4)]
        gp = [rev[j]*g_ranges[j][end] for j in range(4)]
        states.append((sum(rev), sum(gp), q, rev, gp))
# p、g、容量和配置率对总量单调；h影响L/V替代，故额外检查封顶拐点。
# 各细分最小/最大值与总量最小/最大值分别在这些可行配置中求取。
# 这是指定参数盒与供给条件下的包络，不是置信区间。
```

无供给限制时，L+V收入为H×[pL+(pV−pL)×h]/1000；这正是架构切换净增量公式。S按已交付功率收费，不能把PSU冗余铭牌、IT工作功率与受保护功率当三个终端市场。
