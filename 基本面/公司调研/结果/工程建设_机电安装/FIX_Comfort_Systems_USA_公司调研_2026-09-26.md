# Comfort Systems USA（NYSE：FIX）公司调研：规模交付、模块化扩张与预收现金的边界

研究截止日期：**2026年9月26日**。最新已披露完整经营期间为2026年第二季度及上半年；2026Q3尚未结束，不作为已实现业绩。金额默认美元；财务基线使用百万美元（M），预测使用十亿美元（B，1B=10亿美元）。自然年与公司财年一致。证券为美国Comfort Systems USA, Inc.普通股，NYSE代码FIX，不是ADR；2026年7月17日流通在外普通股35,194,329股，2026H1加权平均稀释股数35.255百万股。本文研究经营与资本后果，不依据股价、评级或目标价反推假设。[S01][S02]

标记：**F**为公开披露事实，**M**为管理层陈述或目标，**C**为直接计算，**E**为本研究假设、估算或条件结果，**U**为未知。情景范围没有统计置信区间含义。事实可靠性、条件结果与实现概率分别讨论。原始披露页码、日期及对应主张集中列于文末；正文编号可直接跳转来源。

## 一、公司判断：最重要的机会和风险都在交付组织，而非某一种冷却设备

**FIX是一家把工程设计、熟练工、设备采购、工厂预制和现场责任组织起来出售的机电承包商。当前经济实质已经明显转向大型科技设施建设，但仍不是纯AI公司、冷却设备OEM或长期租赁资产运营商。**客户购买的是满足规范、进度和运行要求的系统，FIX主要按合同工作范围取得收入。工厂化提高可复制交付量，大客户提前锁定产能改善现金条款；相应代价是项目更大、客户预算更相关、厂房投入更重。

本研究最支持的经营路径是：**2026年全年收入约12.9—13.2B，2027年在既有客户持续建设、扩产按期爬坡且并网审计未导致广泛停工的条件下，收入约14.6—16.3B，集团营业利润率约14%—16.5%。**代表性工作点为2027年收入15.50B、营业利润2.40B、净利润约1.87B、并购及分红前自由现金约1.17B。它是有明确假设的工作路径，不是管理层指引、市场一致预期或概率加权期望；下文给出分支、投入与现金计算。

**最强相反解释**不是“AI没有真实需求”，而是客户在当前紧张期抢占队伍和工厂、提前付款，而成熟项目释放了较多利润；等竞争供给、客户自研和标准化采购增加，FIX仍可扩大收入，却失去部分单位利润和预付融资。2027年出现收入11.8B、营业利润约1.13B且自由现金略负的压力路径具有经济可解释性，并不需要公司失去全部客户。

**最关键的未解问题**是：两家主要模块客户的最低采购、解约赔偿与预付退款条款；模块独立利润和工厂利用率；最终客户与具体园区的集中度；德州待并网项目的实际合同暴露；新试单能否变成重复项目。针对年报、季报、投资者材料及电话会的检索，未获得足够公开细节来精确识别这些量。它们分别限制利润持续性、现金可分配性及突破规模判断，不能统一写成“有风险”。

## 二、谁付钱，FIX控制什么，什么不归它

### 2.1 从采购到付款的链条

使用者包括数据中心运营商、工业厂房、医院、学校、政府和商业楼宇。系统规格通常由业主、咨询工程师或总包确定；FIX既可参与设计建造，也可按既定图纸竞标。直接签约付款方可能是业主或总包；机电、设施运维与调试人员验收系统。**法律客户与最终预算所有者不是同一概念**：多个总包可能服务同一云厂商，合同数量增加也可能只是一笔最终预算拆包。

合同经济单位是约定工作包及其施工进度。设备和材料通常包含在合同价内；服务业务则按工时、材料、维护期间或小项目收费。收入大多随履约确认，采用已发生成本占预计总成本的比例。实际付款依赖开票、里程碑、预付款及保留款，不等到整个园区正式运营才必然确认收入。[S01]（MD&A及收入确认附注）

客户选择FIX的合理机制是：已有队伍与项目经理、对规范和设备接口的经验、能够承担较大合同、履约记录，以及工厂和现场协调。决定收费权的却是**在客户所需时间、地点、合同责任范围内，替代承包商是否足够多且可信**。系统重要性本身不能证明长期高价格。

典型订单到现金关系为：

```text
客户资金/设计/场地明确
 → 合同或获准开工、确定可执行工作包
 → 采购与预制、现场施工（按成本进度确认收入）
 → 分阶段开票/收款，可能先收预付款
 → 单机和综合调试、整改、最终验收
 → 收回保留款，履行质保与服务责任
```

工厂可以先于场地施工，但不能消除现场接入与测试；已经收款也不意味着赚完利润。成本加成合同通常风险和利润率都较低，部分仍有最高保证价格；固定价合同则把工效、工资和未获批准的变更风险留给FIX。一般开票付款为30天，行业合同可能45—60天，实际回款常在30—90天；保留款可在完工后继续占用资金。[S01]

### 2.2 资产、技术与权益边界

集团披露两个会计分部：机械和电气。机械包括HVAC、管道、控制、异地预制等，电气包括电气系统安装与服务。**“模块化”“科技客户”“机械分部”是三条相交分类，不能加总。**模块内部也会集成电气设备，不应因为产品有电气部件就从机械分部再移出一份收入。

TAS于2020年成为全资子公司，构成重要模块能力平台；Walker、Starr等补充电气、区域队伍和异地制造能力。2020年TAS并购公告最初预计年化收入170—190M、EBITDA 15—17M，说明今天的能力有多年积累，而非最近才为AI搭建。不过2026集团模块口径不能直接当作TAS单家公司收入，两个时点也不能拿来计算同范围增长率。[S11][S27]

FIX控制子公司、厂房或使用权、人员组织、地方品牌和客户关系；主要依赖外部厂商供应冷机、开关设备、发电机等。它不拥有客户的数据中心、电力接入权、全部系统架构或最终云业务。大客户共同设计形成的知识未披露为FIX独占知识产权。**制造能力可以稀缺，客户仍可能有权让另一家生产同类模块。**

截至2026Q2披露的Hunt等收购为全资经营主体；集团财报没有需要从净利润另扣的一项重大少数股东利润。普通股取得的是履约、债务、租赁、或有对价及税后剩余经济利益，不能把预付款余额作为可直接分给股东的闲置现金。授信涉及子公司担保和资产抵押，资金调动亦受契约及经营需求约束。[S02]（Notes 5、7）

### 3.2 分部约束：不能把全部超额利润都归给模块

2026H1机械收入4.357B、营业利润0.825B，分部利润率18.9%；电气收入1.774B、营业利润0.274B，分部利润率15.5%；再扣公司费用0.055B，集团营业利润1.044B。Q2机械和电气分部利润率分别约18.6%、15.9%。以上均已含各分部相关摊销；集团未来模型不再重复扣总部费用。[S02]（Note 11；C）

这组数字支持机械业务改善很强，但不能证明“模块毛利率为某个精确数”。机械内部有现场工程、工业安装与服务，项目组合和完工估计都会影响利润。后文模块22%营业利润率是**预测分配假设**，用来检验集团模型是否合理，不是被披露的历史利润。

增长的地域组织来源也需谨慎：季报将同店增量归因于德州、印第安纳、北卡等经营单位；该披露指经营单位归属，不能自动认定每份订单的最终施工地点。

### 3.3 利润质量：改善真实，但确认时点会放大斜率

成本进度法允许工程预计剩余成本下降后，当期补记此前应得的利润。简单条件算例：合同价100、预计总成本80、已发生成本40，累计收入50；若可靠新信息令总成本降为76，累计收入变为52.63，即使当期没有新增物理进度，也会增加2.63的收入和利润。它可以反映真实工效改善，但不能每季永续重复。

2026Q2估计修订正向收入影响7.7%，对应约251.5M；2025Q2为4.4%，对应约95.6M；H1披露比例7.9%与5.0%。**这不是“净利润有251.5M是假利润”，也不能把全部修订从利润中扣掉。**修订可包含总价变更、已满足条件的奖励及成本变化，收入效应不等于同额净利润，且项目预计成本中的谨慎储备释放是业务常态。[S02]（Note 3）

与此同时，2026Q1另有约43.1M临近完工项目和变更单带来的突出有利影响；管理层称剔除所识别特殊收益后Q1毛利率约25.2%，Q2约25.9%。这既反驳“Q2毛利环比必然恶化”，又不证明新签合同都能长期做到26%毛利。[S02]（MD&A）；[S08]

真正有辨别力的是后续批次：如果新项目初始预算和最终毛利仍高、旧项目释放减少而集团利润仍稳，结构改善更可信；如果高利润必须靠修订影响不断上升，持续性应下调。以2026Q2收入规模计算，修订影响率减少3.3个百分点对应收入确认时点变化约108M（C）；其利润传导比例未知，不将108M直接作为扣减预测。

资产出售收益H1仅1.1M，不能解释利润跃升；或有并购对价重估H1约12.4M损失在营业利润以下，不能把它与模块经营成本混为一谈。2026H1税率约22.5%，前瞻用23%—24%而非永久外推一次性税益。[S02]

| 净利润 | +812.0 | 会计盈利起点 |
| 超额开票及递延收入变动 | +1,061.5 | 提前开票/收款与履约节奏，含客户预付；不是全部纯保证金 |
| 应收变化 | −633.1 | 交付增长和收款时差消耗现金 |
| 合同资产及未开票应收变化 | −49.6 | 收入确认先于无条件开票权 |
| 存货变化 | −20.7 | 采购与生产占用 |
| 应付及其他流动负债变化 | +215.5 | 供应商付款和税薪等时点 |
| 其余非现金及其他净项 | +142.7，C | 包含折旧摊销、股酬、税项与其他调整 |
| CFO | **1,528.3** | 与现金流量表闭合 |

直接计算：1,528.3−1,061.5=466.7M；再扣288.8M资本开支=177.9M，未加售产回款。**这里只是在隔离一项有利现金来源，不能称正常化FCF**，因为应收、应付、税款和季节性仍未归一化。[S02]（p.5）

6月底现金1.855B，同时超额开票与递延收入负债3.231B；后者不是同额应立即退款的银行债，却要求未来交付设备和劳动。该负债比年末增加1.111B，与现金流量表的1.062B不相等，差异包括并购等非现金流变动，不能任选一个当作“客户新付现金”。

应收质量目前没有看到已披露的大额减值：H1未确认应收/合同资产减值损失，但仍有常规坏账费用；这两个概念不矛盾。2025年底保留款506.5M，占当年收入约5.6%，同比明显上升；不能用经营现金强来跳过尾款风险。2026Q2合同资产144.6M、高于年末88.8M，应结合更快收入增长而非仅看绝对值。[S01][S02]

库存104.8M相对收入不大，核心风险也并非消费品渠道库存，而是**客户专用在制品、已采购设备、预计完工成本与暂缓接收**。公开材料没有按模块披露库龄或呆滞率，不能据低库存余额断言没有延期损失。

## 四、实际业务证据：预制、现场新建、改造与服务各有不同边界

### 4.1 模块化：从单次工程变成可重复制造，但不是无风险标准品

TAS公开产品资料显示，其模块覆盖冷却、电气、控制等组合，提供内部工程设计、BIM、厂内测试及现场安装支持。[S12]有效技术链为：将客户设计转为可制造图纸，在稳定工位完成管道、布线、设备安装和测试，再运输到现场连接。收益来自工厂与现场并行、较少天气干扰、重复设计和更稳定的劳动组织。

这不是简单把全部现场工人搬进厂房。焊接质量、管道洁净度、设备接口、控制序列、运输尺寸、吊装、检修空间和当地规范都决定最终成本。新品架构频繁变更时，预制在制品可能比现场施工更难返工；客户若未准备好场地，完成模块也可能占用面积和资金。

TAS宣传10%—15%成本节省及更快工期，但没有足以对照所有配置的项目样本、完工总工时、净成交价和最终利润。本研究仅据此识别价值机制，**不将宣传节省幅度直接加到FIX利润率**。TAS静态网站的旧面积和集团规模介绍还明显落后于2026投资者披露，因此面积预测采用有日期的电话会口径。[S12]

已经发生的商业证据强于产品介绍：H1模块约1.04B收入、Texas modular operation积压订单同比增加1.87B、环比净增510.2M；公司已投入真实资本购楼。尚缺独立客户对FIX具体模块验收数量及净价的确认，不能把管理层声称客户满意当作另一份外部验证。[S02][S07][S08]

模块业务的两条路径必须分别定价：

- **既有客户扩张**：当前大客户有实际采购历史，较容易复制设计和工序；但客户集中、多供应商和采购权强，长期不能假设FIX独供。
- **新客户项目化**：frontier labs及colo存在小额试单（M），尚未证明持续程序采购、跨站复制或付款条件。需要先做设计适配与认证，再形成年度排产；服务新客户可能占用现有工程师，早期毛利未必更高。[S08]

管理层谈及两家超大云客户支持扩产的多年数量承诺，但公开材料未展示最低采购量、未提货补偿、客户便利终止、退款、价格重置或信用支持文本。**“客户支持扩产”能提高兑现判断，不能等同于已核验的take-or-pay合同。**

### 4.2 数据中心机械与电气：架构变化增加工作，也会减少旧内容量

机械工作把设备散热任务转成可靠的水、风与控制系统。直液冷涉及设施水系统与技术冷却回路接口、流量/压降、换热、冲洗过滤、泄漏监测、故障隔离和备用切换。FIX较有机会取得设施端和系统集成收费；没有证据证明它拥有主要GPU冷板、CDU核心IP或每台AI服务器的固定授权费。

用水作物理例子，1MW热量、10K温差所需流量约23.9kg/s；温差提高至20K，流量约减半。实际必须按冷却介质、压力、材料及工况重算。**GPU功率或机柜密度增加，不能一比一推出泵、管道数量或FIX每MW收入增加。**

客户自研是实质反证。AWS已公开自研液冷与控制方案；2024年新设计公告明确提出每站提供更多算力并减少部分冷却设备。这说明客户可把设计效率和采购收益内化，FIX更可能收制造、安装和系统责任的钱，而非掌握全部系统租金。[S20][S25]

电气业务受新增电力负荷、冗余要求、布线和系统测试驱动。NVIDIA 2026年8月路线图提出混合800VDC power rack可接入已有AC楼宇系统，行级power center预计2027年；这一技术方向同时带来改造机会与减少部分传统转换/铜材/楼宇重建工作量的风险。它尚未证明FIX已经取得该架构的大额项目。[S21]

因此前瞻不能用“每Token增加→每GPU增加→每MW工程单价永远增加”的直线推导。更合理的链条是：客户需要的有效计算量→硬件效率和利用率→新增或改造IT负荷→场地和架构→可外包工作包→FIX资格和班组→净合同额。

**新用途和基础研发保留但不虚增预测。**TAS还展示两相浸没式方案，但网站未给可复核的大客户规模付费收入、长时可靠性与同配置成本；个别“无需额外能源”等营销表述也不能替代热平衡和泵功率分析。浸没可减少某些空气侧工作、增加流体和维护责任，当前不单独计入集团收入；若出现连续复购、OEM质保兼容和真实净价，再从模块或改造分支中识别增量。[S13]研发主要表现为工程、制造自动化和客户共同设计，本研究没有获得可分离的液冷研发预算，也不把R&D税收优惠当成独立产品研发收入。

### 4.3 非科技新建与改造：提供客户入口，不能完全对冲科技周期

制造业包括精密工业、食品、制药等不同终端。与数据中心相比，其工艺管道、洁净要求、生产许可和设备投产节奏不同；项目价值来自完成产线而非提供计算容量。2026H1制造收入较上年增加约146M，医院及政府亦增长，这为非科技规模提供真实支撑。[S02]（C）

另一方面，办公与教育表现较弱，利率、地方预算和房地产融资会影响新开工与翻修。制造业回流计划、政策补助或厂房公告要经过客户融资、工艺设备采购及施工进度才能形成FIX收入。没有获得足够按项目的份额和采购数据，本模型以已有工作量和区域承包能力约束，未把政策投资总额乘任意份额。

既有建筑改造可以在经济偏弱时保留必要更换需求，但节能改造、扩建和高端升级仍可延期。液冷改造可增加单站复杂度，也可能因客户改选新建而减少旧楼工作。当前既有建筑施工收入下降，是必须保留的已发生反证，不能用未来改造叙事抹去。

### 4.4 服务：有存量基础，新数据中心运维仍需重新赢单

服务业务已规模经营，主要限制是当地技师和派工密度。一次新建施工取得资格，不保证随后所有维护都由FIX承接：业主自有设施团队、原设备厂、全国设施管理公司和其他承包商均可竞争。大型客户可能把保修、日常巡检、设备维护和高级冷却服务拆开采购。

H1服务0.623B、同比约7%增长，投资者材料的“service maintenance base”为185M；后者是公司定义的维护基数，**不是全部服务收入，也不等于软件ARR或不可取消合同**。维护协议通常可自动续约并含30—60天取消通知；公司未披露服务分支净留存、流失率、获客成本或数据中心运维收入。[S01][S02][S07]

电话会称已成为一家超大云客户的服务提供商，但区域进入仍有限（M）。这足以支持“已取得入口”，不足以支持“全国存量均已转成经常性收入”。2027工作模型服务1.50B包含传统客户自然增长和有限数据中心扩展；若新数据中心服务做大，需独立显示站点、技师、付费范围和复购，不能在集团增长之外再加一份全量服务机会。[S08]

## 五、需求与供给：强需求真实存在，利润依赖谁能按期完成

### 5.1 独立需求证据及其限制

微软2026财年Q4披露Azure年度收入超过100B，且未来资本投入仍有需求支持；7月29日电话会把CY2026 CapEx调整为约175B，明确部分变化来自融资租赁转经营租赁，基础投资预期未变。[S14][S23]这提供支付能力与真实云业务增长的外部锚，但**本研究未确认微软就是FIX匿名客户之一**，也不把175B当成FIX可投标的机电预算。

CBRE于8月27日发布的H1主要市场调查给出在建容量7,481.1MW、预租80.4%，并指出电力和地方许可限制。约6.0GW在建已有租赁承诺（C），说明需求不仅是供应商自述。[S15]但它是特定批发市场样本，不覆盖所有自建；预租不是全额预付，租金也不是工程本金，净吸收不是当年FIX新订单。

最直接的公司业务证据仍是**收入、合同余量及现金发生**；最有力的需求外证是客户已有收入和已承诺建设，而非行业多个券商重复预测。短期需求强的证据可靠程度较高；2028后每个园区的经济回报和真实计算利用率远没有同样强的证据。

支付能力应分层：

- 有成熟云/软件/广告现金流的大客户可承受较长回收期，但也能强势压价和重新排项目。
- Colo依赖租户合同、股权及项目债务；租约存在不消除完工风险，信用质量与租赁取消条件仍重要。
- 新AI平台或实验室可通过融资与客户预付迅速扩张；若资金窗口收窄，FIX即使技术交付成功，也可能受停工或回款影响。
- 医院、政府、教育和工业客户有不同预算周期，可提供分散，但现阶段不足以中和科技增量集中。

### 5.2 有效供给由四个环节共同决定

**工厂/工位、合格人员、配套设备、客户可接收项目**共同决定有效交付，最弱一环约束收入。面积只代表潜在生产空间，美元backlog也不是物理产能。

人力方面，2025年底员工约22,700人，2024年底18,300人；2026年7月管理层称超过25,000人。员工存量增加并不足以解释同期收入全部增长，差额可能来自工时、并购、外购设备、模块组合、报价和估计调整。[S01][S08]由于没有同口径工时与分包占比，不能把收入/期末人数当真实生产率。

2026年9月AGC/NCCER调查仍显示数据中心拉紧建筑劳动力，同时其他施工需求较软。[S24]这意味着FIX可能吸收其他行业工人，却不能立刻增加有资格的班组长、调试工程师和管理层跨度。新增员工若先进入培训，短期成本先发生；加班、差旅和跨区域调动可放量，但侵蚀单位利润。

设备方面，年报估计直接采购商品及成品占平均项目成本约40%—45%，HVAC、开关设备和大发电机交期可超过六个月；不存在保证重要原料或部件供货的重大合同。[S01]（Business采购章节）提前采购能减少涨价风险，却把资金和客户变更风险前移。材料交期改善既可加快收入，也可能降低客户为锁定可靠供应而支付的溢价。

工厂方面，2026H1资本开支288.8M，其中购楼188.9M支持模块扩张。购楼相对租赁提高控制力，也提高退出成本。有效爬坡还包括设备布局、测试、涂装、切割、机器人和招聘，不能把买楼日当满产日。[S02][S08]

### 5.3 可复算的模块交付能力约束

缺少模块件数、平均MW和同配置成交价时，面积模型只作为**必要产出强度检验**，不冒充独立测得的MW产能：

```
模块收入 = 期内平均可用生产面积 × 每平方英尺年度收入实现强度
实现强度包含：利用率、生产周期、产品组合、设备转售与净价格
```

已知H1模块约1.04B，年度化仅用于校准生产强度。若H1平均面积为290万—330万平方英尺（E，低于/接近7月披露的350万以上），隐含强度约630—719美元/平方英尺/年。这个面积范围不是公司披露，因此不是独立生产率事实。

在年底400万、2027夏末500万目标兑现且逐步爬坡的情况下，2027年平均可用面积取420万—450万（E）。工作模型模块3.25B要求722—774美元/平方英尺/年；以440万和约739美元计算即可闭合。它相对上述校准需要适度工效/组合改善，或更高设备内容量，不要求面积增长与单价增长全部取极值。

若只有380万平均面积且实现强度650美元，收入约2.47B，低于工作点约0.78B。反过来，4.10B突破路径需要新增更早投用、超过既定空间，或更高的约900美元以上实现强度。**客户订单足够不自动解除这个产出要求。**真正支持上修的证据应是平均投产面积、单位总工时和重复验收增加，而不是又一次宣布年末面积。

### 5.4 竞争不仅来自EMCOR，还来自客户和设备平台

| 对手/替代者 | 与FIX争夺的经济环节 | 对FIX的实质约束 |
|---|---|---|
| EMCOR及其机械/电气公司 | 合格班组、项目经理、大客户工程包、并购标的 | 2026Q2收入5.15B、RPO17.14B，证明强势竞争供给；其机械分部利润率从13.6%降至12.5%，说明放量与降利润率可并存 [S16] |
| Southland、地方专业承包商及总包自营队伍 | 设计建造、预制、施工与调试 | 有模块化能力和客户入口；非上市不等于不存在，不凭上市样本推市场集中度 [S22] |
| Vertiv等设备平台 | 把供电、冷却、控制和预制设施打包 | OneCore已于2025年8月宣布全球可用，单块5—50MW；可把设备接口和系统利润留在OEM，也可能采购FIX施工 [S19] |
| 客户自研、标准化、多供应商 | 设计规范、采购、复制权和故障数据 | 可以让多个制造商做同类模块；外包生产增加但单家议价下降 [S08][S20][S25] |
| 架构简化和存量改造 | 用较少转换、铜材、楼宇工作满足同等算力 | 800VDC与更高密度可替代部分旧内容量；新的接口与测试收费要重新争取 [S21] |

FIX优势更可能持续在组织学习、项目选择、客户信任、技师网络和跨公司调配，而非不可复制的物理技术。客户诱导第二来源不一定表示FIX份额已经下降，但清楚限制“永久独占模块利润”的解释。

### 5.5 财报后的政策变化如何进入公司模型

德州审计影响的是特定接入流程中的项目，九月RFI明确覆盖尚未送电的特定大负荷及25—75MW项目。将其解释成“德州所有在建工地已停止施工”过度；反过来认为七月订单完全不受影响也不成立。[S17][S18]

传导顺序可能是接入日期不确定→客户推迟开工或设备接收→模块排产调整→工厂闲置/库存与应收增加→新增预付减少。FIX可在其他地域调配部分人力和制造，但客户专用模块未必可立即转卖。

压力算例（E）：若未来12个月计划收入13B中有15%依赖受影响项目，相关工作有三分之一从该期移出，则收入后移约0.65B。按20%—30%短期贡献利润率，未采取调整前营业利润影响约130—195M；若未来恢复，是时间损失而非永久取消。**15%不是已知德州暴露，故不直接扣入基准，只用来说明需要什么披露才能量化。**

9月16日美国众议院通过Ratepayer Protection Act，拟让大型数据中心承担相应电力基础设施成本；9月17日参议员公告显示相关推进受阻。本研究将其保留为立法进程，未作为已生效全国法律。其经济方向是提高部分客户前置资本负担，同时可能增加自备供电和园区电气工作，净效果取决于客户项目回报及接入设计。[S28][S29]国会单院通过不等于FIX已经获得新增工程，亦不等于现有合同失效。

## 六、订单与单位经济性：同一套机制解释高利润和失败路径

### 6.1 backlog不能与现金、产能承诺相加

6月底14.062B中机械10.059B、电气4.003B。RPO定义为尚未履约的firm orders交易价格，排除未行使期权；维护协议和部分短周期工作不进入backlog。预计65%—75%未来12个月确认，不应把整个余额当未来一年收入。[S02]（Note 3、MD&A）

二季度同店backlog净增约1.39B，加Hunt收购约0.217B，与总额从12.455B增至14.062B相容。[S02][S31]Texas modular的510.2M是**交付后的净增**，并非当季毛新增签单；部分二手材料把它简写为bookings会低估实际承接，也容易与交付重复计算。

正确恒等式为：

```
期末backlog = 期初backlog + 新增/变更承诺 − 已确认的backlog收入
             − 取消 + 并购带入 + 其他范围变化
```

没有全部收入流经backlog，故不能简单用集团收入加backlog变化推毛签单。忽略其他调整且用集团收入作交付上限，会得到约4.66B的二季度“净补充订单”上限型代理（14.0615−12.4547−0.2174+3.2657）；它不是公司披露bookings，也不能算取消率。真实毛签单还可能因取消而高于净值。

未来12个月9.14—10.55B既有RPO兑现，加服务、短工期及后续签约当期施工，才形成集团收入。若同期集团收入假设13.5—14.5B，则还需约2.95—5.36B来自这些其他来源（C/E）；服务年规模约1.3—1.5B只能填一部分。因此，即使订单很大，公司仍需要继续拿单和安排短周期工作。

长期数量承诺不一定全部进当期backlog；已收到的预付通常又对应订单的一部分。**面积、承诺、backlog和合同负债是同一经济链条的不同计量，不能加成四份机会。**公开披露未给毛取消、延期分布和逐客户押金条款，净增长也不能证明零取消。

### 6.2 每100美元现场合同：优势必须穿过成本与变更条款

以下是贴近当前集团利润区间的条件算例，不是FIX披露BOM，也不代表每份合同：

| 项目 | 基准金额 | 选择理由 |
|---|---:|---|
| 合同收入 | 100 | 固定工作范围与价格 |
| 设备、材料 | 32 | 约占直接项目成本74的43%，与年报平均采购比重相容 |
| 直接劳动 | 28 | 假设，检验工效及工资敏感性 |
| 分包、物流、工地管理等 | 14 | 假设，防止只算材料与工资 |
| 毛利 | 26 | 与当前组合接近，并非新签合同保证值 |
| 经营费用、摊销和总部费用分摊 | 9 | 已计完整经营支持 |
| 营业利润 | **17** | 未计税、利息及营运资本 |

在工作范围不变且未获补价时，工资/工时成本增加10%减少利润2.8；设备材料增加10%减少利润3.2。两者一起发生，利润从17降至11；若新合同净价再降低3，利润降至8、利润率约8.25%。这个联合扰动说明供给紧张既可提高投标价，也可伤害已锁价订单。

反之，若重复设计使劳动成本减少10%，客户通过下一轮采购拿走其中一半，FIX每100收入的净改善只有约1.4。机器替代工时不自动全部成为股东收益，还要承担设备、维修、培训及质量风险。

若客户直接采购原由FIX转售的20美元设备，而相应成本也减少20、集成费和责任不变，则营业利润仍17，报表收入降至80、利润率升至21.25%。**收入下降可能不代表能力衰退，毛利率上升也未必代表净价格上涨。**真正比较应固定设备归属、工作范围、风险和总工时。

固定价合同并非每年自动按通胀重定价。新投标、变更和续约可更新价格，已签部分要看成本联动、采购锁价及变更认可；公司没有披露全部收入中可及时重定价的比例，不能统一假设成本全额转嫁。

### 6.3 新增100万平方英尺模块空间：资本回报对利用率高度敏感

这是E类单元算例，用于检验管理层所称快速回收的成立条件，不是实际工厂预算。假设厂房与设备投入200M，满产收入750M/年，变动成本70%，含折旧及经营分摊的固定费用70M/年；折旧15M，年度维护更新10M，税率25%，投产后净营运资本为收入10%。

| 稳态利用率 | 收入M | 营业利润M | 税后年度现金M，投入后稳定营运资本 | 厂房设备+初始营运资本M | 简化回收年限 |
|---|---:|---:|---:|---:|---:|
| 100% | 750.0 | 155.0 | 121.3 | 275.0 | 2.3 |
| 80% | 600.0 | 110.0 | 87.5 | 260.0 | 3.0 |
| 50% | 375.0 | 42.5 | 36.9 | 237.5 | 6.4 |

公式：营业利润=收入×30%−70；年度现金=营业利润×75%+15−10；初始投入=200+收入×10%。未计爬坡时间、土地/设备残值、融资和退出损失；采用稳定税率也偏简化。会计盈亏平衡利用率约31%，但这远低于覆盖资本成本所需利用率。

客户预付款若覆盖营运资本，满产简化回收约1.65年，与管理层“一到两年”经验陈述存在相容机制；**这不是独立证实其实际回收期**。项目延期、重新设计或需买更贵厂房，会显著拉长。此处200M/百万平方英尺只是假设，受近期购楼和集团资本投入量级约束，尚无逐厂披露支持。

如果停产退出，通用厂房可处置、部分设备可转用，但定制夹具、软件工程、培训和搬迁损失未必可收回；没有当地估值与设备清单，不把账面价值当可立即兑现残值。集团模型已包含这些扩产支出，不再在净利润后扣一次本算例200M。

## 七、管理层、资本配置与失败承受力

### 7.1 分散经营的价值与控制风险

FIX的经营模式依赖地方公司经理和工程负责人，集团提供资本、并购、采购与跨区资源调度。地方团队保留客户关系有利于赢单，但施工估计、质量、安全、回款和项目选择必须通过总部审查形成约束。25,000名以上员工和51个会计经营单位，不等于有51套互不相关的风险；8月材料的206个地点又是物理网点口径，不能与51直接比较。[S02][S07]

2025年底119个大于40M的在建合同合计11.122B，占全部在建合同原始金额24.166B约46%（C）。这不是剩余backlog；却说明平均合同2.9M掩盖了大项目在经济金额上的集中。单个大型项目工效差、质量事故或客户变更，足以影响一家子公司甚至集团季度利润。[S01]（MD&A合同规模表）

Brian Lane继续担任CEO；Trent McKenna自2026年初任总裁，Craig Sasser自7月1日起任COO，Briston Blair转任首席战略与创新官。新增职责有助于扩大管理跨度，但不能仅凭头衔证明组织约束已经解除。[S10]

执行证据是已有收入、利润、订单和扩产支出同时增长；反证是更大合同与新增工厂尚未经历完整下行周期。历史上2021Q1同店收入曾下降11.8%，收购贡献7.5个百分点后总收入仍降4.3%，说明组织能力并不能使公司免疫需求变化；该历史业务结构与今天不同，不作为2027下降幅度的直接模板。[S30]

对管理层陈述分别评价：

| 陈述/决策 | 截止日已能核验的结果 | 本研究评价 |

### 7.2 激励：奖励EPS与现金，也可能强化时点偏好

2026年4月9日委托书显示，2025年度激励使用EPS与FCF；长期股权一半RSU、一半PSU，PSU含EPS与相对股东回报指标。管理层与董事合计持股约1.24%，董事多数独立。[S09]这有利于关注盈利和收现，但FCF受预付与资本开支时点影响，EPS受项目估计影响，不能替代对新项目风险和长期投入回报的审查。

2025年绩效达到最高奖励档，说明当期目标明显低于最终业绩，也说明薪酬达到封顶后额外利润并不同比增加当年奖金。2026 PSU结构拟调整为按股数计量，详情预期在2027委托书披露；不能把2025细节永久外推。[S09]

关联交易披露包括与董事任职的AECOM在普通业务中的不足250,000美元付款，量级不足以改变公司判断。2025审计为无保留意见，并对财务内控有效性给出意见；部分新并购业务的内控评价范围豁免不等于出现了重大缺陷。Q2披露法律纠纷现有预计损失不重大，但工程赔偿、保修、自保和安全事故具有尾部风险。这里采用“未发现已披露的重大失控证据”，不是声称已排除舞弊或诉讼损失。[S01][S02][S09]

### 7.3 并购：购买区域组织和客户资格，不只是买收入

2026年5月1日收购犹他州Hunt，初步总对价206.0M，包括交割现金167.2M、卖方票据15.0M、或有对价及营运资本调整。公司预计年化收入约250M，隐含对价/年化收入约0.82倍（C/M）；没有足够独立利润数据计算可靠收购PE或ROIC。进入西部地区、与现有机械团队配合是战略理由，实际交叉销售和整合费用仍需后续经营检验。[S02][S08]

2025年的Feyen Zylstra、Meisner等增加电气队伍，Century与Right Way补充机械能力。此类收购的价值取决于经理、班组和客户保留，商誉不能单独施工。6月底商誉1.101B、无形资产0.535B，合计相当于权益约51%（C）；若收购能力失去客户，减值会降低会计权益，但真正经济损失早在经营现金下降时已经发生。

H1新收购带来的营业收入约231.8M、毛利约38.5M，边际毛利率约16.6%（C，受收购时间和组合影响），明显低于集团当前毛利率。由此可见，收购短期可以增加能力同时稀释平均利润率，不能给所有外购收入套集团高毛利。[S02]

授信有抵押、担保和财务契约，6月底满足契约；可用额是当时状态，严重经营损失或担保变化下不保证全部持续可提款。历史约10%—20%业务需要履约保证，公司未披露一个可以任意扩张的无条件担保容量。[S02]（Notes 7—9、MD&A）

H1资本开支288.8M、收购净现金162.8M、偿还循环借款100M；同时分红52.8M、回购8.2M。回购较2025明显放慢，实际资本顺序偏向扩张与偿债。未来不假设任何大额未公告收购，也不假设必须为增长发股。[S02]

**资本预算判断（E）**：按管理层2026 CapEx约收入5%的口径，13.1B收入对应全年约655M，扣已发生289M，H2尚需约366M。2027工作模型600M，包括约180M维持/替换、约320M现有扩产/配套、约100M可选效率或增长投入；这三项是研究预算分解，非已披露承诺清单。设备购置与人才培训先付钱，新增利润随后产生，不能让全年收入与年末面积同步满产。

压力路径的应对也必须进入模型。2027下行情景已将CapEx降至300M，保留基本维护、在建完成与必要质量投入；冻结新增并购和回购、重新排工、转用或转租空间是可行方向，但不能即时消除所有固定成本。假设仅以2026Q2现金1.855B作静态起点，后续一年FCF−0.102B、分红约0.127B、卖方票据偿还约0.024B，现金仍约1.60B，尚未用授信；该测试不是预测2027期初现金，亦不把其他或有支付当零风险。

更严重的联合压力若多消耗1.0B经营资金并支付0.3B事故/重组现金，上述静态余额只剩约0.30B，应停止可选增长、压缩分红、优先催收并使用满足条件的授信或出售通用资产。不能假设继续扩大厂房同时无成本融资；进一步损失可能迫使股权融资并稀释股东。当前较强流动性降低近期生存风险，**不能消除回报下降**。

## 八、发展路径与统一模型：先算每个分支，再看集团

### 8.1 2026：增长已实现一半，全年取决于剩余项目进度

2026H1收入已实现6.131B。以下H2配置是代表性工作点，E，单位B：

| 分支 | H1基线 | H2工作点 | FY2026工作点 | H2为什么可达到/为何可能偏离 |
|---|---:|---:|---:|---|
| A 模块 | 1.042 | 1.350 | 2.392 | 扩产和既有订单支持；场地接收、设备齐套与爬坡影响时点 |
| B 其他新建 | 3.545 | 4.000 | 7.545 | 大项目继续推进与季节性；不能假设H1增速不变 |
| C 既有建筑施工 | 0.920 | 0.940 | 1.860 | 假设大致企稳，没有要求快速反弹 |
| D 服务 | 0.623 | 0.680 | 1.303 | 基于既有客户和技师扩张，未计大规模新DC服务 |
| 集团 | **6.131** | **6.970** | **13.101** | 四项互斥，模块不另加到科技或机械收入 |

更宽的条件区间为FY2026收入12.6—13.5B，当前最支持约12.9—13.2B；上端需要施工继续加速且政策/设备延期较少。H2营业利润率采用15.5%—16.5%而非无限上升，原因是H1已有较多有利项目结算、新厂及人员投入增加，同时较大订单仍支持报价。以H2 16%计算，全年营业利润约2.159B、净利润约1.7B；它包括已经发生的Q1特殊影响，不再从全年扣第二次。

公司7月指引为全年同店收入增长百分之三十几的中高段、CapEx约收入5%、税率约23%（M）。将同店粗略解释为35%—39%，再加入约0.35—0.50B并购口径贡献（E），对应总收入约12.64—13.15B。这是研究者桥接，不是公司直接给出的收入区间；实际同店比较范围需按并购周年调整。13.10B工作点接近此桥接上部，13.5B上行情景需要超过这组假设，不能称已被管理层保证。[S08]

若H2 CFO在0.8—1.4B、H2 CapEx约0.36—0.38B，全年未计出售资产回款的FCF约1.66—2.28B（E/C）。宽度主要来自预付和应收，而非净利润同幅变化。2026现金高点不能作为2027稳定起点乘增长率。

### 8.2 2027：本研究更支持继续增长，同时留出价格与现金回落

工作路径范围：模块3.0—3.5B、其他新建8.3—9.2B、改造1.85—2.05B、服务1.40—1.55B，合计14.55—16.30B。范围来自既有能力扩展、在手项目、短工期签约需求及当前业务分化，不是行业TAM乘份额。以下三条为互相解释的**代表性条件组合**，不构成概率全集。

**工作路径为何更受支持。**模块生产空间扩大，现有客户持续采购；其他新建较FY2026工作点增长约16.6%，明显低于最近同店增速，所需新增班组与项目管理压力仍大但不是重复50%增长。改造基本持平，服务约15%增长，保留技术客户服务入口但不要求全国铺开。利润率低于当季17.1%，由新厂爬坡、工资和供应商竞争解释，不是任意向历史均值回归。

**延期与压价路径。**大客户延后接收，已有项目继续执行而新订单预付变少；模块收入低于2026、新建收入下降，但改造和服务未一律崩塌。闲置、差旅和返工抬高单位成本，新合同降价，部分项目估计回转；资本预算主动收缩。保留正利润而FCF转负，是项目制承包商可发生的组合。

**交付突破路径。**工厂提前达产、单位总工时下降、既有客户重复包增多，且电力、设备及场地顺畅。模块4.10B超过仅按既定空间和原强度推导的工作范围，必须有额外面积/更快周转或更高净内容量；其他新建亦需新增班组。不能同时假设把所有制造效率留作利润、客户不压价且不增加资本支出，因此该情景把CapEx提高到0.85B。

非现金净调整包含折旧、摊销、股酬等的简化净额；经营租赁成本已通过经营利润/现金时点处理，不再重复减全部租赁本金。为简化，现金税与损益税差异并入现金时点参数。股酬加回只说明当期不付现金，股东仍承担稀释；没有假设回购免费抵消。若新增股数1%，每股收益在总净利润不变时约下降1%，本研究不依赖精确未来股数或每股目标价。

下行情景收入下降却需要0.9B营运资金，是因为旧预付持续交付耗用、新预付不足、应收放慢；不是反常算术。突破情景预付净释放仅0.2B，未重复2026H1的1.062B前置现金。工作路径资本支出高于历史常态、现金转换低于2026，仍可产生可观自由现金。

三个状态不做未经依据的加权平均。如果要形成数学期望，需要补齐中间状态及联合权重，尤其需要合同暴露和客户取消条款；将此表各列平均或只乘一个“保守折扣”会掩盖真正现金风险。

### 8.4 2028及以后：两条可改变规模的路线和一条有限机会

**路线一：新客户从试单转为重复模块项目。**起点是小额试单（M），门槛是客户接受设计/测试、实际付款、连续第二批采购、量产规格冻结以及独立资金来源。工作观察窗为2026H2—2027验证、2027—2028形成收入，非公司承诺日期。若两个新项目群各贡献年收入150—400M（E），2028潜在额外收入0.3—0.8B；这是“需要达到的订单规模”，没有公开证据证明已锁定两个项目群。

实现该规模大致需额外平均生产空间40万—110万平方英尺，按约700—800美元/平方英尺收入强度计算；不是在为现有客户规划的500万空间上无成本挤入。厂房设备和工程前期投入暂取0.10—0.25B、净营运资本0.03—0.12B（E）。收入0.5B、贡献率28%、新增固定/工程及总部支持60M时，营业增量约80M；早期只有0.15B收入却承担同样60M费用时，亏损约18M。若客户未复购，应停止第二阶段扩建，保留通用空间处置价值，不把已付前期成本全部收回。

本路线没有另加到2027工作表；若实际客户转化早于预计，必须同时增加产能或挤出旧业务，净增等于新增项目减被替代工程。它改善客户多样性，也可能引入更弱信用和更重定制，未必提高集团利润率。

**路线二：新建装机变为数据中心服务网络。**技术资格已有入口，商业门槛是赢得运维采购、技师地理覆盖、响应质量及续约。先从少数可服务站点开始，比立即全国铺开更可信。2028若传统服务1.45—1.60B基础上增加净DC服务0.15—0.30B，总服务约1.60—1.90B（E）；新增不是对所有已建资产机械乘费率。

规模门槛检验：如每个“整站服务当量”年度净合同1—3M，新增0.15—0.30B需约50—300个站年；若真实采购仅是局部设备维护，单站收费更低，所需站点更多。公司未披露站点和合同净价，故这是必要采用量，不是当前签约数。达到规模需提前招聘、培训、车辆、备件和派工，预算20—50M（E）并可能先拖累利润；在该支持成本已计入情况下，成熟增量营业利润率12%—16%对应18—48M。单靠此项难以抵消集团新建利润数亿美元的下滑，能改善持续性，但不是立即逆周期保险。

**路线三：能源/工业模块与新冷却架构。**TAS能力可用于中央公用工程、工业冷却及发电相关模块，长期可利用已有设计和制造组织。[S11][S12]但截至截止日未获得足以核实新增业务规模的大项目清单，不给独立收入预测。经济门槛可用一份30M合同、20%营业贡献假设检验：约6M利润，相对集团工作点2.40B只有0.25%；需要多次大规模复用才改变集团判断。既有工业收入已在A/B/C中，不能借新名称再加一次。浸没、800VDC等前沿路线亦先考察责任和净收费，避免把技术路线存在写成商业突破。

没有足够项目与合同证据约束2030集团点值，故不提供看似精确的长期复利曲线。长期规模能否显著超过2027突破点，取决于客户程序复用、现场人力复制、设备内容量及持续资本回报，而非当前backlog简单滚动。

## 九、当前取舍：结果、可能性与证据不能混写

### 9.1 哪些判断现在可以成立

**经营阶段的判断较明确：现有模块业务已经越过规模商业化门槛，现场工程也有真实放量；新增客户复制与数据中心服务则处于更早阶段。**既有业务最重要的门槛已从“技术是否可行”转为“能否在多个项目上持续复制交付、保持净价并完成现金闭环”。这使纯技术成功概率失去解释力：更值得观察的是重复采购、工时、完工利润、提货与回款。

2025年最大直接客户占收入12.8%，并占年末应收约10.2%；公司未披露其名称。[S01]（客户集中度附注）这不是两大模块客户合计占比，也不能识别同一最终客户通过其他总包采购的金额。结合科技收入贡献90%以上增量，**集团的增长相关性高于直接客户集中度表面显示的程度**，但没有证据把全部科技收入认定为同一家客户或AI训练支出。

下表为截至2026年9月26日的研究者主观判断。概率对象有明确期间；范围表达判断不确定性，不是统计估计，亦不由管理层信心或证据等级换算。事件彼此重叠，不能相加，也不能直接当作第八节三情景的权重。

| 具体事件 | 当前发生判断（E） | 支持与反对机制 | 证据可靠程度及限制 |
|---|---|---|---|
| 2027全年集团收入高于2026实际全年收入 | 约70%—85% | 大额在手工作、现有客户扩建、2026新增经营能力支持；并网延期、预算调整及2026高基数压低概率 | 收入与backlog事实可靠；2027可执行范围、取消及跨年节奏不完整。高于90%会过度忽视工期与预算共同冲击 |
| 2027全年模块收入至少3.0B | 约60%—75% | 已有约1.04B半年收入基础及新增空间计划，重复客户路径比新客户验证短；全年平均有效能力、设备齐套及提货仍是约束 | 模块占比与空间来自管理层且取整；独立客户量纲和利用率缺失，可靠性低于集团历史收入 |
| 2027全年集团营业利润率仍达15%或以上 | 约50%—65% | 当前项目工效和机械/电气利润共同改善，支持部分提升持续；竞争、保守估计释放减少和扩产固定成本可能抵消 | 历史GAAP利润可靠，但项目批次毛利、初始报价和模块利润未披露。对这一事件的把握明显弱于收入继续增长 |
| 至2028年底，至少一家目前处于试单阶段的新模块客户，在2028全年贡献不低于150M已确认收入 | 约35%—55% | 产品可交付、已有客户程序可作参考；仍需第二批采购、设计冻结、资金和新增空间，试单不能证明重复规模 | 只有管理层确认的小额试单，未见客户侧金额/复购验证，主要依赖机制判断。不能直接对0.3—0.8B条件收入乘此概率，该事件与两项目群情景口径不同 |

这些概率具有可调整性，但时间经过本身不是上调依据。如果第四项出现客户确认的重复订单和首次实质回款，同时明确新增空间及交付节奏，可提高实现概率并收窄规模区间；如果只是再次展示客户Logo或工厂面积，不能同幅上调。前三项也不能简单相乘得出“工作路径概率”，因为同一客户预算、交付及价格影响多个事件。

没有给2028全部服务收入精确概率或2030集团数学期望，原因是缺少站点收费、续约及新增站点口径；这不否定服务机会，只限制精细赋权。当前可以作出的取舍是：**近期收入增长的证据强于长期高利润率持续的证据；现有客户扩产的把握强于新客户复制；客户预收提高生存与扩张能力，但会夸大当期现金可以永久分配的程度。**

### 9.2 有经济含义的扰动

以2027工作点为基准，以下是单参数局部检验，目的在于识别决定量级的因素；多项同时发生时必须重新计算完整状态，不能直接机械叠加。

| 扰动 | 直接量级（C/E） | 如何理解 |
|---|---:|---|
| 集团营业利润率下降1个百分点，收入保持15.50B | 营业利润减少155M | 比许多小型新应用的可能贡献更大，利润持续性应比技术发布获得更多研究注意 |
| 模块营业利润率由22%降至17%，收入3.25B | 营业利润减少162.5M | 仍可商业成功，但对股东的增量盈利显著降低 |
| 其余新建收入比工作点低10%，固定投入不立即变化 | 收入减少0.88B；按边际贡献率25%假设，营业利润减少220M | 采用贡献利润检验，不能将全部成本同时按比例下降 |
| 客户净预收/收款现金时点额外不利1.0B | FCF减少约1.0B，未必同季等额降低营业利润 | 工作点1.17B FCF可压缩至约0.17B；其后才可能通过减产、停工和坏账影响利润 |

| 有效税率从23%提高到24%，工作点税前利润约2.43B | 净利润减少约24.3M | 税益变化重要，但明显小于1个百分点经营利润率或大额现金时点变化 |

这里最大的非线性来自订单冻结后的产能空置、需要退还/耗用的客户资金以及项目亏损，已经放入压力状态和资本检验；没有用平均现金余额掩盖这些断点。反之，较好需求与较低单位成本可以相互加强，但要求实际工时、良率和客户验收改善，不能只以新增面积证明。

### 9.3 最强替代解释及已经改变判断的证据

1. **替代解释：增长主要是收购和涨价。**同店收入增量、科技收入增长以及模块已形成可观交付说明收购不是主因；但未披露物理产量及净价格分解，仍不能断言增长全是数量。结论从“强需求线索”收敛为“已经实质放量、纯量价拆分仍未知”。
2. **替代解释：高利润只是完工储备释放。**电气与机械均有规模和利润提升、Q2剔除Q1特殊项目后比较仍较强，反对“完全一次性”的极端解释；估计修订影响却明显上升，支持对新签批次留出利润折让。工作点没有永续外推最新季度17.1%的集团营业利润率。
3. **替代解释：预付就等于订单不可取消。**现金和合同负债确实验证客户付出了资金，但不披露最低采购与退款条款，就不能推出全部收入不可撤销。这个区别直接导致2027工作模型没有重复计入2026H1的巨额现金前置。
4. **替代解释：空间从350万到500万即可自动按比例增加收入。**投产先后、有效工时和设备齐套决定期内产出；既有客户已占主要扩建计划，试单转大单需要新的空间或挤占既有业务。新客户路线因此被独立保留，而未全部塞进工作点。
5. **替代解释：高密度计算会不断提高FIX每MW收费。**液冷、供配电和预制可能增加特定工作包，同时设备集成、业主自研和新的供电拓扑也可能减少现场工时或改变采购归属。AWS、NVIDIA和Vertiv原始材料足以证明替代路线值得研究，却不能证明FIX已经失单。[S19][S20][S21][S25]
6. **替代解释：德州审计会使全部模块订单停滞。**制造所在地不是最终园区所在地，且审计范围取决于并网进度；当前不能量化FIX暴露。事件使交付时间分布更宽，却不足以把全部德州经营单位backlog判为无效。[S17][S18]
