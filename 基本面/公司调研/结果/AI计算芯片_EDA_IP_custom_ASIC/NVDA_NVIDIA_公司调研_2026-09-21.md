# NVIDIA（英伟达，NASDAQ：NVDA）公司调研

**研究截止：2026 年 9 月 21 日。** 本报告仅采用截至该日已公开的信息；整理完成时的日期变化不扩展信息集。金额除另有说明均为 **十亿美元（USD bn，1 bn＝10 亿美元）**，数量、功率和单价另标单位。FY27 指截至 2027 年 1 月前后的英伟达财年，FY28 大体对应 2027 年 2 月至 2028 年 1 月；FY27 为 53 周财年，第四季度有 14 周。预测不是证券价格判断，不含目标价。

## 一、当前判断：经营优势成立，扩大业务的方式正在改变资本风险

英伟达出售的是能够较快进入生产、支持多种模型并持续提高有效吞吐的计算平台。GPU、CPU、内存、互联、运行库、推理调度和机架设计共同决定客户的上线时间与每次有效任务成本。公司收费主要仍在硬件交付时实现；客户未来能否持续卖出算力、收回机房和设备投资，是下一轮采购和部分新增信用支持安排的偿付基础。

**本研究更支持“继续大规模增长，同时毛利率和现金转换承压”的路径。** FY28 工作路径为收入约 **640**，合理研究范围 **600—680**；点值对应数据中心 600、边缘业务 40，集团毛利率约 72.8%、经营利润约 416、经营自由现金流约 291。再扣假设的净战略股权投入 50，可供债务偿还、股东分配和额外安全储备的现金约 241。这是下面逐项建立的条件模型，不是披露值、统计置信区间或概率加权期望。

**最强反证**是：现有云收入和 GPU 紧张，也可能同时包含真实使用、客户战略备货、供应商资金支持和少数模型公司的融资驱动采购。若最终支付增长赶不上设备、利息和更新成本，最先恶化的可能是云租价、付费利用率及回款；随后是延期、净价格和存货损失，最后才在 NVIDIA 收入同比中充分体现。高收入增速与这条反向路径在早期可以同时成立。

最重要的未解问题有三个：客户实际付费利用率及续约价格；NVIDIA 分产品的净成交价、成本和有效产能；新增担保与容量支持在违约时的具体回收、分担和触发节奏。前两个限制规模与利润估计，第三个决定极端情形下股东实际承担多少风险。

## 二、经济边界：谁采购、谁付款，英伟达拥有什么

### 1. 收入入口与业务之间的关系

训练集群通常由云厂、模型开发商、企业或主权项目确定架构，经过预算、模型适配、网络与电力规划，由云厂、服务器 OEM/ODM、系统集成商或分销商采购。最终用户可能通过 API 或云实例付费，完全不与 NVIDIA 签约。因此，同一个最终模型公司的计算预算，可以出现在多家 NVIDIA 直接客户收入中。

硬件销售的收入确认核心是控制权转移；折扣、返利等影响净收入。与硬件可区分的软件和支持服务按相应履约期间确认，多项履约义务按相对单独售价分配。订单、发货、客户机房通电、云服务可用、最终用户付费，是五个不同节点。公司还发展容量支持及收入分成安排，其风险和回款节奏与一次性交付不同。不能假定每一笔 NVIDIA 硬件收入都等待最终模型训练验收，也不能把云商多年 backlog 当作 NVIDIA 的未确认销售。[FY26 10-K，注 1“Revenue Recognition”](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000021/nvda-20260125.htm)

本报告按经济差异拆为六个分析单元，不伪造公司分部披露：

| 经济单元 | 核心收费与控制权 | 商业阶段、协同与可能蚕食 |
|---|---|---|
| GPU 及其捆绑计算组件 | GPU、HBM、计算板和随附 CPU 等硬件净对价；软件兼容与交付可靠性支持议价 | Blackwell 已规模经营；Rubin 正爬坡。新产品提高任务吞吐，同时压低旧 GPU 的租赁价值 |
| 数据中心网络 | NVLink、InfiniBand、Spectrum-X、交换及相关 DPU 等组件与系统 | 已是大业务。随集群规模扩大而增长，但 EFA、以太网及客户自研可使 GPU 与网络份额分离 |
| 独立 CPU、存储侧增量硬件 | 不在 GPU 核心套餐内的 Vera 等计算、存储处理能力 | 部分已收费，独立部署仍在扩张；只能计真正新增出售的组件 |
| 低时延推理 LPX | 专用推理芯片和系统，可能与 GPU 配合 | 生产发布和首批合作客户阶段；未取得足够公开材料证明成熟规模利润 |
| 单独收费软件、许可及服务分成 | 企业软件、支持、接口/技术许可、运行或容量相关服务 | 增长机会存在，但捆绑与独立收费必须分开；容量支持可能先带来成本 |
| Edge | 游戏与消费 RTX、专业图形和工作站、车端、Jetson 等 | 游戏提供现金与生态；专业和边缘 AI 成长；汽车、机器人研发与量产周期更长 |

公司 GAAP 报告分部仍为 Compute & Networking 与 Graphics，数据中心及 Edge 属于另一种市场平台划分。上述经济单元用于解释经营和预测，不等于任何一张公开分部利润表。GPU 核心已经包含的 CPU、软件以及配套收益，不在其他分支再加一次。

### 2. 资产、权利和不可独占的能力

NVDA 是 NVIDIA Corporation 普通股，股东拥有集团剩余权益，没有对某个 GPU 产品线、合作机房、模型公司或 HBM 工厂的单独所有权。NVIDIA 拥有核心设计、软件和相关知识产权，依靠代工、封装、内存、整机和基础设施伙伴实现交付；Arm 架构许可不是拥有 Arm，合作方客户数据、模型收入与机房租金也不自然属于 NVIDIA。

CUDA 的经济作用是缩短开发、调试、迁移和运维周期，配合成熟库、人才存量和运行稳定性，使客户更容易把设备变成有效工作。其收费权主要体现在硬件及平台选择，而非对所有 CUDA 程序征收显性软件税。开源框架、编译器和替代后端可以绕过其中一部分成本；知识产权影响力与持续收费能力必须分开验证。

Mellanox 把公司能力延伸到集群互联，系统规模越大，这种整合越有价值。Groq 则是另一种资本配置：2025 年 12 月达成非独占技术许可并引入人员，**未购买 Groq 股权、既有产品或客户合同**。交易对价约 17，其中初始支付 13、余款约一年内支付，形成约 14.4 商誉及 2.5 技术无形资产。不能把这笔交易描述为已买下 Groq 的完整收入业务。[FY26 10-K，注 2“Business Combinations”相关交易说明](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000021/nvda-20260125.htm)

### 2. FY27 Q2 利润到现金的桥梁

Q2 净利润 59.688 中包含约 7.771 股权投资收益；经营现金流调整扣除此项后，还需承受应收增长 22.346、存货增加 5.784、预付及其他资产增加 5.497。股权薪酬 2.027、折旧摊销 1.127、应付增加 1.915 及其他调整部分抵消，最终经营现金流 24.077。Q1 净利润中投资收益更大，约 15.936。因此，用两季净利润加总再外推税后经营收益，会高估可重复利润。[Q2 现金流量表](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027)、[Q1 CFO 说明](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000051/q1fy27cfocommentary.htm)

公司定义的 Q2 自由现金流约 21.341＝24.077－2.677－0.059 融资购买资产本金；H1 对应约 69.895。与此同时，H1 股权投资现金购买 42.404、出售回收 7.241，净流出约 **35.163**。于是 H1“经营自由现金流减净股权投资”只剩约 **34.732**，还没有扣分红、回购和偿债。这项研究口径不是公司 FCF 的替代会计定义，而是衡量生态资本配置后可调动现金。

应收集中度也值得区别对待：期末五大应收对象占比合计约 70%，Q2 一个直接收入客户占 16%；部分投资级客户付款期限为 90 天至一年。账期延长可能是优质客户获得议价权，也可能是供应商主动支持部署，两种情况对坏账概率和资本占用并不相同。当前资料不足以量化逾期率或毛取消率，不能从净应收增量倒推出违约。[FY27 Q2 10-Q，注 7，客户集中与应收条款](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000075/nvda-20260726.htm)

存货结构有一个缓和信号：7 月末原材料约 11.341、在制品 13.377、产成品 6.857，年初分别为 3.807、8.822、8.774。增长集中在原料和在制品，符合新架构备料与扩产，尚不像全部由卖不出的成品驱动。但提前采购也把技术切换和需求变化风险移至自己；当期库存及采购义务准备扣除转回后约 0.808，并非零损耗。真正有辨别力的后续观察是产成品、库龄减值、发货后回款是否同时改善，而不只是存货周转率一个数。


## 四、需求是否可持续：先看付款链，再看 GPU 数量

### 1. 四类预算，不能相互替代作证

**云厂的商业算力。** 收入来自计算、存储、数据库、模型 API 等服务；采购芯片只是资本开支的一部分。能够支持 NVIDIA 复购的关键，是新增供给上线后能否被出售，以及所得现金是否覆盖设备更新和资本成本。

**广告、推荐和内部生产力。** 付费者可能是广告主或企业原有软件预算，GPU 并不直接按 token 收费。模型提高转化率、广告单价或研发效率，仍可能形成真实支付能力；但把全部广告增量归因于 AI 会高估边际回报。

**前沿模型研发与新型云。** 训练和推理有真实收入基础，也更依赖融资、集中客户和长期租赁。模型公司股权融资、云商融资、NVIDIA 投资与 GPU 销售相互连接，不代表会计收入必然不实，却意味着这些订单不是完全独立的需求样本。

**企业、政府与主权项目。** 数据权限、延迟、保密和供应安全使本地部署有价值，需求并不只服从最低 token 成本。但预算批准、招标、电力、系统集成和长期维护可能串行推进，宣布 GW 或合作框架不等于当年购买。

### 3. AWS 的追加采购同时支持规模、反驳简单的全面锁定

AWS 8 月 26 日公告计划于 2027—2028 年增加约 200 万块 NVIDIA GPU，覆盖 Blackwell Ultra、Rubin 与后续产品。这是采购方原始材料，比 NVIDIA 单方面列客户名称更接近可实现需求，但未提供完整不可取消数量、每季验收、净价格或违约赔偿表。公司出货与 AWS 对外服务上线的时间表也不同，不应把跨年计划全部计入 FY28。

条件上，如果其中 80—120 万块在 FY28 形成 NVIDIA 收入，且每块包含实际随购组件后的 NVIDIA 净对价为 5万—6.5 万美元，对应约 **40—78** 的收入。这是对计划年内转化和每单位价值的算例，不是合同金额；网络已包括在该单位价值内，不能再追加一次。这一规模足以支撑集团预测的一部分，仍不足以独立证明 640 或 700 的总收入。

同份公告明确 EFA、Nitro 等 AWS 自身技术继续发挥作用，并把 NVLink Fusion/NVHBM 引入定制芯片合作。由此得到更准确的竞争判断：AWS 可以同时增加 NVIDIA GPU、扩大 Trainium，并保留集群架构控制权；NVIDIA 则争取从客户自研中获得互联和接口收入。GPU 需求强并不意味着所有云厂都购买 InfiniBand 或完整 NVIDIA 机房栈。[AWS 追加 GPU 及下一代基础设施公告](https://press.aboutamazon.com/aws/2026/8/aws-and-nvidia-to-deliver-2-million-additional-gpus-and-next-generation-infrastructure-for-agentic-and-physical-ai)

### 4. 使用增长与资源效率的净效应

推理从短对话转向长上下文、多步骤代理、工具调用及多模态，会增加一次任务的计算、内存和调度需求。反过来，量化、缓存、蒸馏、批处理和推测解码降低单次成本。判断总需求必须写成：

**有效任务数 × 每任务所需资源 ÷ 每台设备可交付的有效资源。**

任务量若增长 3 倍、每任务资源增长 1.5 倍、设备及软件效率提高 2 倍，则所需设备资源约增加至 2.25 倍；若任务只增长 30%、效率翻倍，则即使体验改善，固定服务范围内所需设备也可能下降。两个算例均非行业预测。需要观察付费任务、用户愿付价格与总收入，而不只是 token 数，长思维链中的额外 token 未必都有同等客户价值。

高端训练、实时低延迟推理、可批处理推理、推荐和传统 HPC 的经济单位不同。NVIDIA 的可选负载多，有利于设备跨用途使用；固定且规模大的负载，则最有动力开发 ASIC。全面采用代理既可能扩大 NVIDIA 需求，也可能为专用架构提供更大、可预测的市场。

## 五、技术优势在哪里，哪些尚未完成商业验证

### 1. 通用 GPU 平台的优势是减少完整任务的摩擦

GPU 的并行矩阵计算只是起点。HBM 决定模型权重、KV cache 和带宽约束；GPU 间互联决定模型切分后的通信损失；主机 CPU、存储和网络决定数据准备、检索及代理工具调用是否让昂贵 GPU 等待；软件决定精度、批量、路由、故障恢复和实际可售吞吐。

训练更重视大规模同步、可靠性及重复迭代速度；在线推理同时约束首 token 延迟、逐 token 延迟、吞吐、质量和租户隔离。峰值 FLOPS 与单用户速度都不能直接替代这些约束下的每美元收益。英伟达可以通过平台联调缩短客户上线和优化时间，从而收取可靠性、生态和性能溢价；若客户已有足够工程团队，平台溢价就更容易被拆开议价。

### 2. Rubin：出货成立，成熟利用率仍待证明

Rubin 平台把 GPU、Vera CPU、NVLink、网络和存储侧组件共同设计。公开规格中，Rubin GPU 配置最高约 288 GB HBM4，NVLink 6 双向带宽约 3.6 TB/s；NVL72 的 72 指封装 GPU 数，不能把双计算裸片再计成 144 块 GPU。低精度性能需要在相同质量要求下比较，不能拿不同精度的峰值作统一价格依据。[2026 年技术说明，Rubin 平台结构及规格](https://developer.nvidia.com/blog/?p=111036)

5 月“进入全面生产”的公告，对应制造和供应链推进，彼时仍指向后续客户供货；8 月财报电话会确认开始生产出货。9 月 16 日 MLPerf 进一步提供特定负载的性能证据，但 Rubin 提交仍标为 Preview。这组证据支持“产品和制造关键节点已跨过、客户全面部署正在推进”，不支持“所有客户已经大规模付费满载”。[5 月 31 日生产公告](https://nvidianews.nvidia.com/news/vera-rubin-full-production-agentic-ai-factory)、[MLCommons v6.1](https://mlcommons.org/2026/09/mlperf-inference-v6-1-results/)

具体测试中，NVIDIA 报告 Rubin NVL72 相对 GB300 在 Qwen3-VL 上最高约 3.7 倍、DeepSeek-R1 上约 2.5 倍吞吐；所用软件分别涉及 vLLM/Dynamo 与 TensorRT-LLM，相关 Closed 提交编号为 6.1-0106、6.1-0074。另一项 GB300 四机架、288 GPU 的约 99% 扩展效率，是特定离线测试的规模效率，不是客户全年的付费利用率。AgentX 等更大倍数来自不同工作负载，不能替换 MLPerf 比较。[9 月 16 日具体模型、配置和提交说明](https://blogs.nvidia.com/blog/vera-rubin-nvl72-mlperf-inference/)

客户接受的门槛由四件事共同决定：模型质量和延迟合格；集群稳定性可持续；软件迁移节省的成本超过迁移投入；电力、冷却与机房如期齐套。产品迭代越快，旧设备出租收入下滑与新设备融资、适配成本越可能抵消峰值效率收益。

### 3. Groq 3 LPX：在低延迟上有价值，不能外推为整个推理市场

8 月 24 日 NVIDIA 与 Nebius 分别发布 LPX 生产及合作信息。公告中的约 3,400 output tokens/s 对应 Gemma 4 31B、特定上下文和单用户测试，并非全机架高并发吞吐或每瓦、每美元优势的通用指标。Nebius 对 LPX 机架披露 256 个 LPU、总计约 128 GB 片上 SRAM，强调在其 Token Factory 中引入服务；没有同时公开成熟付费销量、完整运维成本或大样本留存。[NVIDIA LPX 公告](https://nvidianews.nvidia.com/news/nvidia-groq-3-lpx-now-in-full-production-with-world-class-speed-for-agentic-ai)、[Nebius 客户侧说明](https://nebius.com/blog/posts/nvidia-groq-3-lpx-nebius-token-factory)

片上存储与确定性执行有利于低延迟，但容量、模型映射、跨芯片通信和支持模型范围限制通用性。更大的稀疏模型可能需要跨多个系统组织，不能把单个小模型速度照搬。LPX 的首批合理客户是愿为代理响应速度、交互体验支付更高价格的服务商。它可能扩大高端推理，也可能替代一部分 GPU 解码工作；集团净增必须扣除这种替代。

本报告保留 FY28 LPX 收入 4 的工作假设，可靠性明显低于 GPU 主营。该数可理解为约 2,000 个系统等价单位、每单位净收入约 200 万美元；数量、配置与成交价均为研究假设，未披露验证。若客户只在少数高价服务中使用，收入可以低于 1；若真正扩至可复制的大批客户，后续达到 5—10 才有经济可能。

### 4. CPU、网络与存储：突破 GPU 的空间，也有附着率风险

Vera CPU 针对代理编排、数据处理、检索等瓶颈，公开规格为 88 个核心，强调高内存带宽及与 GPU 的连接。Grace 累计出货约 250 万是商业基础，但不是 Vera 的当年独立销量；Anthropic 的评估也不能写成已经量产采购。Vera 独立 OEM 供货推进意味着机会从随 GPU 配置扩展至通用服务器预算，同时面对成熟 x86 与其他 Arm CPU。[5 月 31 日 Vera CPU 公告](https://nvidianews.nvidia.com/news/nvidia-unveils-vera-the-cpu-for-agents)

网络是已实现的高经济重要性业务。FY27 Q1 网络收入约 14.8，Q2 电话会称环比增长 18%，据此计算 Q2 约 17.5，属于取整推算而非公司精确分部值。互联可随着 GPU 数量、每 GPU 链路数和集群规模上升而增长；但 scale-up 的 NVLink、scale-out 的 InfiniBand/以太网、DPU 与客户 EFA 分工不同。客户采用开放以太网可能损害某些专有产品，也可能增加 Spectrum-X，不能把“以太网替代”一律判为公司收入流失。[Q1 CFO 说明](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000051/q1fy27cfocommentary.htm)、[Q2 电话会，网络业务段](https://investor.nvidia.com/files/content_files/TRANSCRIPT_-NVIDIA-Corp-NVDA-US-Q2-2027-Earnings-Call-26-August-2026-5_00-PM-ET.pdf)

NVLink Fusion/NVHBM 是值得保留的远期分支：通过接口和内存控制器设计参与客户自研芯片，而不是要求客户全部购买 NVIDIA GPU。8 月公告中的带宽、功耗与面积改善为特定设计目标，AWS Annapurna 为首个合作开发对象；尚无足够净授权价格、每颗收入或成熟量产良率披露。因此只在模型网络及许可分支保留有限贡献，不把客户整个 ASIC、HBM 或服务器价值归给 NVIDIA。[8 月 26 日 NVHBM 技术说明](https://blogs.nvidia.com/blog/nvlink-fusion-nvhbm-custom-high-bandwidth-memory/)

### 5. CUDA 的竞争不是静止的

AMD、Google TPU、AWS Trainium 与 Meta MTIA 分别在通用替代、内部训练推理、云服务和推荐负载上争夺业务。AMD 2026 Q2 总收入 11.5、毛利率 54%，包含 EPYC 等业务，不能全当成 GPU 收入；Broadcom FY26 Q3 AI 半导体收入 16.7 也包含网络。这些数字可证明替代生态具备经济规模，不能直接相加后推算 NVIDIA GPU 市占率。[AMD 8 月 4 日业绩](https://ir.amd.com/news-events/press-releases/detail/1295/amd-reports-second-quarter-2026-financial-results)、[Broadcom 9 月 2 日公司公告](https://www.prnewswire.com/news-releases/broadcom-inc-announces-third-quarter-fiscal-year-2026-financial-results-and-quarterly-dividend-302868129.html)

AWS 的 Trainium 性价比陈述针对自家环境与特定代际，Google TPU 8 的训练/推理解耦和 Meta MTIA 生产负载显示，模型成熟、工作负载可预测且规模足够大时，客户有能力绕过部分通用性溢价。新芯片发布仍要通过软件、良率、集群可靠性和服务可用性检验；不能反过来假定所有自研都会成功。[AWS 芯片业务说明](https://www.aboutamazon.com/news/company-news/amazon-ceo-andy-jassy-amazon-chips-business-q1-2026-earnings)、[Google TPU 8 技术资料](https://cloud.google.com/blog/products/compute/tpu-8t-and-tpu-8i-technical-deep-dive)、[Meta MTIA 300，8 月 24 日](https://engineering.fb.com/2026/08/24/networking-traffic/mtia-300-meta-training-chip-built-in-nics/)

更有辨别力的反证是 Meta 4 月公布的 KernelEvolve：生产系统使用 AI 辅助内核优化，覆盖 NVIDIA、AMD、MTIA 和 CPU，并报告特定 NVIDIA 广告推理性能提升约 60%、MTIA 训练提升约 25%。这同时提高现有 NVIDIA 设备的有效供给，并缩短其他硬件的软件适配周期。**AI 编程能力增强，可能既推动 GPU 需求，也降低 CUDA 部分迁移成本。** 这些结果局限于 Meta 所测负载，尚不足以证明整个生态壁垒消失，但足以否定“软件优势不需要持续投入”的假设。[Meta，2026-04-02，KernelEvolve 生产经验](https://engineering.fb.com/2026/04/02/developer-tools/kernelevolve-how-metas-ranking-engineer-agent-optimizes-ai-infrastructure/)


## 六、供给、可交付能力和净价格

### 1. 供应承诺不是已合格产量

英伟达的可交付能力至少同时受计算裸片、HBM、先进封装、测试良率、网络及整机齐套约束；客户侧还受变压器、冷却、电力接入、建设与运维限制。双裸片 GPU 增加晶圆与封装协同要求，更多 HBM 堆栈既增加价值，也扩大任何一个部件失配造成的库存。

HBM 的证据比精确 NVIDIA 产能更直接：SK hynix 7 月披露 HBM4 已在 Q2 开始规模供货并计划 H2 放量；Micron 披露针对 Rubin 的 HBM4 量产及后续封装、晶圆扩建进度。新晶圆厂或封装厂“首产”到 NVIDIA 特定规格的稳定合格供货，仍隔着良率、测试、客户认证和分配。[SK hynix 2026-07-29 业绩说明](https://news.skhynix.com/en/q2-2026-business-results/)、[Micron 2026-03-18 准备稿，HBM4 产品进度](https://investors.micron.com/static-files/e089f8c0-065d-47b8-9d02-bfa863cdb357)、[Micron 2026-06-24 准备稿，扩建时间](https://investors.micron.com/static-files/631b1a32-5537-46ae-8f40-82e42fc79dfe)

这些供应商同时服务多个客户。NVIDIA 的 279 供应与产能承诺能支持其提前锁定资源，但未披露可直接换算的晶圆面积、合格封装月产、HBM 分配比例及每代良率。本研究没有取得足以核验这些精确点值的材料，**不使用传闻中的 CoWoS 月产能乘任意 NVIDIA 份额作为“独立供给证明”**。

电力同样必须区分 IT 负载、设施总功率、已签约容量、接电和实际上线。HPE 的 GB300 NVL72 资料给出每 72 GPU 机架约 132—140 kW，即 GPU 加机架内配套平均约 1.83—1.94 kW/GPU，尚不能代表所有 Rubin 机房的总设施功率。[HPE GB300 NVL72 系统规格](https://www.hpe.com/psnow/downloadDoc/Accelerate%20AI%20at%20scale%20with%20NVIDIA%20GB300%20NVL72%20by%20HPE-a50014019enw.pdf?contentDisposition=attachment&form=false&hf=regular&id=a50014019enw&isFutureVersion=true&isLinearized=false&preview=false&ver=2)

9 月 21 日 DSX Ready 的电池储能和冷却资格进展，有助于减少集成风险；它证明产品与参考设计配套推进，不证明指定机房已接网、通过验收或能在同一天使用全部 IT 负载。储能可以缓解瞬时供电与爬坡，不会无成本创造长期能源。[DSX Ready，2026-09-21](https://blogs.nvidia.com/blog/dsx-ready-ai-factories-power-cooling/)

### 2. 用物理量检验收入需要什么，而不把反推当作事实

FY28 工作模型的 GPU 核心收入 468，可拆为：

**936 万块封装 GPU 等价数量 × 每块 5 万美元净收入＝468。**

“等价数量”用于吸收 Blackwell、Rubin 和不同计算板组合，5 万美元包括本分析划入 GPU 核心的 HBM、板及捆绑计算组件，不含另列网络和独立软件；它不是公司披露的裸 GPU 标价。

若平均分摊 IT 功率为 1.8—2.4 kW/GPU，则该批设备对应约 **16.8—22.5 GW 的 IT 设备功率等价量**。若每块平均配置 250—288 GB HBM，则需要约 **2.34—2.70 EB** 内存；若均采用八堆栈，需约 7,488 万个合格堆栈；若均为双计算裸片，需约 1,872 万颗合格计算裸片。最后两项是架构条件上限式核对，不代表所有组合完全一致，也不是已查证供给。

这个量级与微软、Oracle 已公布的单季扩张，以及 AWS 的多年 GPU 计划在方向上相容，但并未由这些观察独立覆盖。设备可能在旧机房替换，部分交付尚未通电，也可能从年底订单转至下一财年；因此，不能把上述 GW 再加到所有客户公布的 GW 上求“总需求”。

作为当前尺度检查，Q2 数据中心 89，扣网络约 17.5、再给独立 CPU/软件等 2—4 的研究占位，按核心净对价 4万—5 万美元估算，隐含约 **135万—174 万块季度 GPU 等价量**。这是用收入反推的诊断值，非实际出货数据。FY28 达到 936 万，需要相对这一级别的年化物理尺度进一步扩大约 35%—73%，并保住净价与组合。这里最脆弱的是单位对价及归类，后续若其明显变化，应重新计算数量，不能将收入增长机械地当成物理量增长。

### 3. 供需错配可能有两种相反方向

近期更支持先进 GPU、HBM 和配套集成存在结构性约束，而非所有通用计算都短缺。网络、功率、模型与软件资格使不同产品不能一对一替代；同时，存量 GPU 的软件提效相当于释放有效供给，竞争者的合格新系统也会压缩部分溢价。

上行的供给路径是良率改善、HBM 齐套与机房上线同步，交付增加且售后成本下降。下行不必来自晶圆不足：若电力迟到，GPU 可能已经采购并进入客户库存；若新代际提前，旧产品降价与延期会先发生；若客户资本成本上升，物理供给增加反而会恶化租价和现金回收。供需误差足以改变方向，不能只给一个全行业“短缺至某年”的结论。

### 4. 价格与价值分配

英伟达具有四种溢价来源：短期合格供给稀缺；同等服务质量下的性能与效率；按时上线、可靠性及运维；模型、库、人才和迁移积累。前两者可能随竞争和代际更新变化，后两者也要靠持续研发和服务维持。

内存供给紧张不保证 NVIDIA 利润率上升。成本先上涨、客户净价格后调整时，毛利率下降；即使涨价成功，每 GW 的硬件收入增长也可能部分只是成本传导。公开 MSRP、经销商整机价格、云实例价格与 NVIDIA 确认的净收入是不同层级，本研究没有把任意一个公开云租价反推为公司确定售价。

网络份额、独立 CPU 附着和软件收费会改变同样 GPU 数量的收入，但必须服从客户实际架构。管理层每 GW 从 Hopper 约 18、Blackwell 约 25 到 Rubin 约 40 的平台机会值，描述组件价值扩张；最高值隐含较完整配置，不适用于每个仅购买 GPU、使用自有网络的客户。模型实际每 GW 平台内容采用较低且可变的范围，防止从峰值套餐外推出统一收费权。

## 七、单位经济性：芯片很赚钱，客户资产仍要经受租价和更新周期

### 1. NVIDIA 主营的成本约束算例

FY28 工作模型将 GPU 核心净收入取每块 5 万美元、毛利率 74%，对应每块约 **1.3 万美元销售成本、3.7 万美元毛利**。这是集团财务与组合约束下的研究估算，未披露的 BOM 不能据此变成事实；材料、代工封装、测试、板件、物流、保修及正常库存损耗均需包含，持续研发另计集团费用。

若其中内存成本为每块 5,000—8,000 美元，内存上涨 25% 会增加每块成本 1,250—2,000 美元：固定净价下，GPU 核心毛利率下降约 2.5—4 个百分点。若同期净价增加 5%，毛利率约为 71.4%—72.9%，单位毛利仍可增加。这解释为何“增长强、涨价、毛利率下行”可以共存。这里的内存成本区间是敏感性假设，未把供应商的 HBM 报价当成 NVIDIA 实际合同成本。

固定 936 万等价数量时：

| 经济扰动 | 收入/利润或现金变化 | 适用限制 |
|---|---|---|
| GPU 核心净价下降 10%，单位成本暂不变 | 收入及毛利各减少 46.8；按 17.5% 税率，税后经营收益约减少 38.6 | 降价可能促量，但在客户电力固定时未必快速抵消 |
| 每块成本增加 2,000 美元、无法转嫁 | 毛利减少约 18.7 | 不是整个集团所有产品统一成本变化 |
| 同价同成本下数量减少 100 万块 | 收入减少 50、毛利减少约 37，固定研发不会同步下降 | 库存减值及最低采购损失需另外判断，不能遗漏 |
| 集团 DSO 增加 15 天 | 按 640 年收入简化计算，多占应收约 26.3 | 主要影响现金时点，不能直接等同坏账或利润损失 |

年度使用 365 天只是敏感性近似，不用于解释 FY27 多一周的具体收入。税后变化未计融资利率和税项非线性。

### 2. 买方每块 GPU 的完整现金门槛

截至 9 月 21 日可查的公开实例报价：Lambda 八卡 B200 实例约 6.69 美元/GPU·小时，Nebius B300 按需约 7.85、抢占约 4.30，B200 按需约 7.15。实例条件、网络、期限、地域与可中断性不同；GB300 NVL72 大单多需询价。这些是报价截面，不能代替大客户长期净租价、年度利用率或整个行业成交均价。[Lambda 当前实例价](https://lambda.ai/instances)、[Nebius 当前价格](https://nebius.com/prices)

为了检验客户为什么会复购，构造一个**非事实、非特定客户**的 72 GPU 资产批次：

- 初始 IT 设备和分摊机房改造投入 450 万美元，即每 GPU 62,500 美元；土地购买不计，日常机房与网络租赁成本放在运营费用。此投入包含多个供应商，不等于 NVIDIA 每块收入。
- 每 GPU 分摊 IT 功率 2.2 kW、PUE 1.2、电价 0.10 美元/kWh，全年通电电费约 2,313 美元；其他维护、人力、场地和网络费用假设每年 2,500 美元。
- 每付费 GPU·小时净收入 4.8 美元，全年付费利用率 65%；净租价假设低于部分公开按需价格，利用率没有公开样本验证。

据此，每 GPU 年收入约 **27,331 美元**，扣上述运营费用后约 **22,519 美元**，未计利息税费的简单回收期约 **2.8 年**。若经济寿命四年、期末残值零，单纯收回本金的付费利用率门槛约 **48.6%**；要求 12% 年化资本回报，按四年年金计算，门槛约 **60.4%**，且尚需覆盖未列信用损失等费用。

若净租价降至 2.8 美元、利用率降至 45%，年收入仅约 11,038 美元，扣运营费用后约 6,225 美元，简单回收期约十年，明显长于假设经济寿命。此时 GPU 技术仍可工作，但新增采购经济性已经失败。云商可能降价出售更多容量、出售旧设备、重谈融资或停止扩张，而不会无限维持原采购计划。

这组计算说明：未来能否持续增长，关键不只是“每 token 成本更低”，还包括降价带来的需求弹性、付费利用率、资产成本和设备价值消耗。旧卡继续出租可产生正贡献，不等于新卡购买也有充分回报；单用户高速度与高峰并发也不是全年付费利用率。

### 3. LPX 和软件的投资回收要求更严格

对 Groq 约 17 的交易价，若用五年、10% 回报、零残值作简化资本门槛，所需年度增量现金约 **4.48**，还未考虑税、后续研发和爬坡费用。FY28 LPX 收入 4、毛利率 55% 只产生 2.2 毛利，单靠该年硬件销售不能证明整项交易回报成立。

另一种合理机制是防守价值：如果技术、人才和产品选择帮助保住 GPU 核心 1%—2% 的原有业务，对工作模型而言对应约 3.5—6.9 毛利。该反事实无法直接观测，不能当已确认收益，更不能在已保留的 GPU 收入外再加一次。后续验证必须看独立付费增长、系统毛利及客户不再外迁的证据，而不止新品速度。

AI Enterprise 当前公开标准许可约 4,500 美元/GPU·年，批量、期限及捆绑使净额不同；部分硬件附带多年权益，软件收入也按服务期间确认。假如 100 万个**实际另行付费** GPU·年、年净额 3,000 美元，对应 3 的收入；不能对全部出货或累计装机直接乘标价。模型软件分支包含这一类收入、其他支持与控制软件及少量许可/分成，合计 8，但无单独 ARR 或 GPU 年数披露，可靠性较低。[AI Enterprise 许可定价与捆绑脚注，截止日可查版本](https://docs.nvidia.com/ai-enterprise/planning-resource/licensing-guide/latest/pricing.html)

## 八、主营之外的重要路径：计入多少、何时可验证

### 1. 独立 CPU 与代理基础设施

工作模型 FY28 独立 CPU/存储侧增量硬件收入 12，可由约 300 万独立 CPU 等价单位、平均净对价 4,000 美元表达。更宽条件范围是 200万—400 万单位、3,000—5,000 美元，即约 6—20；这不是 Vera 已有订单。达到规模需要 OEM 常规供货、非 GPU 捆绑客户真实采用，以及代理/数据处理负载收益抵消迁移成本。

此路径可能在 FY27 H2—FY28 取得量产观察，但独立销量及利润披露未知。若只是在原 GPU 系统中升级主机，增量价值应留在 GPU 核心，不能当作独立 CPU 新市场。集团已有研发费用覆盖 CPU 设计与基础支持，不再为模型中的 12 重复扣完整一套集团研发。

### 2. 主权与区域 AI：地方进入能力重要，融资是门槛

9 月 9 日澳大利亚基础设施合作提出到 2027 年最高约 2 GW 的扩张方向。相关对象和基础设施推进具有现实意义，但仍需区分电力/场地、客户预算、实际硬件采购与上线。若有 1—1.5 GW 真正形成购买，并按 24—40/GW 的不同组件范围收费，累计可捕获收入为 24—60；这属于分阶段条件算例，不能宣称已签下此金额。[NVIDIA 澳大利亚合作公告，2026-09-09](https://nvidianews.nvidia.com/news/nvidia-expands-ai-infrastructure-capacity-in-partnership-with-australias-data-center-ecosystem)

相同最终客户可能将预算从美国迁到澳大利亚，设备也可能从其他地区转配，故地区项目的毛规模并非集团净增。工作模型将已纳入的区域和主权扩张放在 ACIE，不另加“主权 AI TAM”。失败前投入主要发生在客户机房、公司备料和信用支持，融资失败可能同时影响收入与已有支持的回收。

### 3. Edge：消费现金、专业增长与物理 AI 要拆开

Edge FY27 Q2 已有 7.198 收入基础，但它不是纯机器人或汽车收入。消费游戏受新品、玩家购买力、内存和整机价格影响；工作站和本地 AI 受专业用户对隐私、延迟、模型尺寸与显存的需求驱动。相同 RTX 技术既服务游戏，也降低本地开发门槛，不能重复视为新增用户付费。

FY28 Edge 40 的研究分解可用消费游戏约 16、专业工作站及其他边缘计算约 18、车端和机器人等约 6 表达。这是用于约束增长来源的估算，不是公开平台分拆。若专业设备有 300 万套、NVIDIA 内容量 3,000—5,000 美元，对应 9—15 的规模，显示其有能力影响集团增长，但其中包含既有业务；销量与净价未获独立披露。

车端的经济单位更适合按量产车辆和单车硬件/软件内容计算。300万—500 万辆、每车 500—1,000 美元，对应硬件约 1.5—5，需真实车型销量、区域开放功能和供应份额支持。NVIDIA 对汽车企业出售训练基础设施，属于数据中心，不是车端收入；不能把管理层“汽车行业客户”口径与车载芯片收入相加。

Mercedes 的 2026 材料支持 DRIVE 在 CLA 辅助驾驶上的采用，但应按明确的 SAE L2 辅助驾驶理解，不能写成 L4 无人出租车成熟收费。车辆认证、不同国家功能开放、质量责任和后续软件付费使收入时间长于芯片发布。[Mercedes-Benz CES 2026 原始资料](https://media.mercedes-benz.fr/download/5c83bcd7-8895-4147-b001-0dc3a8b63419/pi_ces2026_fr.pdf)

机器人更早期。若未来某年 100 万台实际部署设备、每台 NVIDIA 净内容 500—2,000 美元，也只是约 0.5—2；达到这一规模之前还要跨越本体成本、任务成功率、安全、维护和客户劳动回报门槛。Cosmos/GR00T 等模型研发既可能扩大 Jetson 需求，也可以被生态免费采用而不产生同等收费。工作模型未额外加入一个巨大的机器人平台利润池。

### 4. 中国与下一代架构

当前中国受限数据中心计算不进入工作路径。Q2 中国 Hopper 收入占数据中心不足 1%，不等于中国全部业务收入不足 1%；按客户总部统计的中国收入还包含其他产品。H200 的许可证、美国境内检验及 25% 关税等安排，以及中国侧限制，共同影响可销售性，不能只看到一项许可就假定市场全面恢复。[FY27 Q2 10-Q，MD&A 及出口限制风险段](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000075/nvda-20260726.htm)

重返中国是离散上行机会，也会消耗产能且面对本土替代和较低价格。仅作规模门槛：若一年合格交付 100 万单位、净额 1.5万—2.5 万美元，则收入为 15—25；100 万不是已证实需求或可供数量。只有许可、采购、支付及验收同时有证据，才能将其转为工作预测。相反，中国生态长期独立发展可能损害国际扩展和软件标准地位，即便近期预测本就不含中国销售，仍有战略成本。

2025 年公布的 Rubin CPX 路线不与 2026 年 LPX 当前部署材料混为一谈；本次针对性检索没有取得足够材料核验 CPX 截止日的明确供货状态，因此既不宣布取消，也不把旧发布计划当成交付。更远的 Rubin Ultra、Feynman、量子协同等继续保留为技术与研发路径，但没有可验证的独立收费量时不另建收入池。[CPX 最初公告，2025-09-09](https://nvidianews.nvidia.com/news/nvidia-unveils-rubin-cpx-a-new-class-of-gpu-designed-for-massive-context-inference)

### 5. 平台扩张能否改变经济规模

真正可能超出当前 GPU 边界的组合是：通用 GPU 服务变化快的模型，LPX 服务高价值低延迟，Vera 处理代理非 GPU 任务，Fusion/NVHBM 参与客户 ASIC，软件统一运维。它可以增加每个客户的内容量，也可能因客户拆分采购而只能获得其中一部分。

在 FY28 模型中，这些机会已有有限贡献；若后来证明其规模更大，应先扣原有假设和 GPU 自我替代，再增加净额。它们共享研发、客户、供应和平台，不能把各自最大收入、最高毛利与最低投入同时相加。9 月与 Palantir 的供应链合作首先包含 NVIDIA 自身经营使用，可能改善计划与交付，目前没有证据把它认定为 NVIDIA 一条新的外售软件收入业务。[2026-09-10 合作公告](https://nvidianews.nvidia.com/news/nvidia-and-palantir-bring-sovereign-intelligence-to-critical-supply-chains)


## 九、统一经营模型：工作路径及重要偏离

### 1. FY27 从已实现收入接到 FY28

FY27 H1 已实现收入约 177.84。Q3 公司指引为 108±2%，本研究以约 106—110 作为近期条件范围；Q4 以约 116—126 为工作范围，反映 Rubin 放量、更多系统组件及该季多一周，同时保留配套延误。由此 FY27 收入约 **400—414**，工作点约 **408**。Q4 区间不是公司指引，也不是简单把 Q2 年化。

按 Q3 约 74%、Q4 约 71%—72% 毛利率及全年约 35 的费用尺度，FY27 工作点的经营利润约 265。实际净利润还会受到投资估值、税和其他项目影响，不把这些项目预测为每季重复。FY28 从这一基础继续增长，需更高物理交付、平台组合和付费预算共同支持。

客户侧交叉视图为：

### 2. 现金压力如何传导，如何停止恶化

正常路径中，279 的供应采购大部分对应未来销售成本和库存，已经通过模型毛利与营运资金反映；若再从 FCF 全扣 279，会重复计成本。只有卖不出去、无法取消且未被正常费用覆盖的净支出，才是额外损失。36 的容量支持也可能由第三方消耗抵减，不能当作所有年份全额额外运营费用。

较危险的联合路径发生在 FY29—FY30：租约已有多阶段生效，少数模型客户融资转弱，云租价和付费利用率同时下降，NVIDIA 自身硬件销售、投资资产价值与保证回收也变差。为揭示资本断点，构造以下**压力算例，非预测**：

- 假设进入该两年时有 60 的流动性安全储备，期间在额外遗留合同损失前经营 FCF 共 40；
- 仍需净投资 20，发生未含在经营 FCF 内的不可回收额外合同现金支出 50；
- 假设已生效保证责任足够大、实际触发支付 40，则现金余量为 **60＋40－20－50－40＝−10**。

这里 60 不是当前余额预测，40 的保证支付也不是从 105 上限按比例计算；只有对应阶段生效和违约条件同时发生才适用。目的在于展示：强经营历史无法保证在多个风险同步发生后仍无需调整。不能让负现金状态机械延续。

可采取的顺序包括暂停可选回购与新增生态投资、不行使额外 3.8 GW 选择权、减少尚未成为硬订单的采购并承担必要费用、协商租约转让或容量再销售。出售上市投资可补充现金，但若与 AI 融资同步下跌，不能按账面值估计回收；非上市投资更不宜默认及时退出。若再融资 25、年利率假设 6%—9%，仅利息就增加约 1.5—2.25/年，且获得融资本身有条件；若只能增发，稀释为“所需融资额÷实际发行价格”，不能预设无成本资金。

上述调整会减少未来可交付规模、延缓平台扩张，也可能使客户转向其他供给。NVIDIA 有能力在多数经营偏差下承受调整，真正的问题是是否足够早地限制共同尾部风险，而不是当前是否有现金。

### 3. 管理、激励与组织执行

黄仁勋长期保持核心技术与产品方向的一致性，GPU、CUDA、网络及整机协同的现实交付形成强执行证据。FY26 Q4 实际收入 68.127 超过此前 65 中心指引约 4.8%，Blackwell 到 Rubin 的持续迭代也支持其组织动员能力；但历史实现并不自动保证更远一年增长 70%，尤其电力、客户资金和多家供应商不完全受公司控制。[FY26 Q3 指引](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-third-quarter-fiscal-2026)、[FY26 Q4 实际结果](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-fourth-quarter-and-fiscal-2026)

2026 年代理声明披露，黄仁勋截至 3 月 23 日持股约 8.706 亿股、约 3.58%；是高度重要的创始人和决策者，但不构成多数股权控制。薪酬考核包含年度收入、非 GAAP 经营利润和三年相对股东回报，并有追回和禁止对冲等安排。H20 事件下存在事先设定的目标调整机制，实际 FY26 结果也超过原始收入及经营利润目标，不能简单描述为事后改目标以掩盖失败。[2026-05-12 Proxy，Ownership、Compensation Discussion and Analysis](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000036/nvda-20260512.htm)

研究上的治理疑问是：年度收入和利润较容易及时反映，二十年信用支持的损失可能很晚才显现。所查考核材料没有使本研究能够确认新增担保的长期风险资本回报被明确纳入同等强度的考核。因此，激励与股东利益有显著一致性，同时需要更细的项目损失、担保和投后披露；这不是认定管理层动机不当。

组织扩张的主要障碍已从单颗芯片设计延伸至液冷、固件、机架验收、客户软件、部署工程和后续维护。快速迭代要求并行维护旧架构，否则新产品节省的计算成本可能被服务中断抵消。Groq、CPU、网络与开放模型分散投入，既增强平台，又争夺人才和验证资源。模型继续提高研发预算正是为此，不能把全部新增收入当作没有持续费用的许可收入。

反垄断、出口限制、证券诉讼和知识产权均有经营作用：前两项可能限制捆绑、分配、客户投资或地域可销售性，后两项可能增加费用与管理负担。FY26 10-K 与 FY27 Q2 10-Q 披露多地监管及相关诉讼，部分事项未计提且损失范围无法合理估计。中国关于 Mellanox 的初步发现不等于本研究已查得最终处罚；控制程序被管理层认为有效，也不等于所有未来收入风险已由独立审计消除。[FY26 10-K，监管与法律风险](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000021/nvda-20260125.htm)、[FY27 Q2 10-Q，注 10 及 Controls and Procedures](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000075/nvda-20260726.htm)


## 十一、发生可能性、证据可靠程度和验证顺序

| FY28 全年收入达到或超过 600 | 约 60%—75% | 当前收入规模、客户云增长、AWS 计划、代际放量和内容量增长共同支持；仍要求相当幅度的合格供给与客户预算扩张。财务起点强，未来数量与净价证据中等偏弱 |
| FY28 全年收入达到或超过 680，接近当前管理层增长路径所需尺度 | 约 35%—50% | 需要供给、接电、融资和调价较好配合；管理层可见度有价值，但多数独立客户材料没有完整锁定全年数量。不能仅用公司信心赋高概率 |
| FY28 全年收入低于 450 | 约 10%—20% | 需要较广泛延期、净价/份额压力或支付问题，单个小产品失败不足以触发；现有客户造血和实际交付使全面骤降不是首选判断，但共同预算集中使尾部不可忽略 |
| LPX 在 FY29 单个财年收入达到或超过 5 | 约 30%—50% | 低延迟需求与首批伙伴有支持，尚缺净价、规模复购和完整 TCO；不是对 Groq 整项投资达到回报门槛的概率。技术证据中等，商业规模证据弱 |
| FY29 前后 Fusion/NVHBM 形成有意义的新增收费 | 相对更支持“取得部分收入”，不足以可靠量化集团级突破概率 | AWS 合作增加进入机会；授权净额、资格完成、替代原业务和利润分配未披露，不能直接等同完整 ASIC 收入 |

这些事件相互嵌套或相关，不能把各行概率相加。Rubin 成功也不能直接把 680 收入事件概率设为 80%—90%，因为它未覆盖融资、价格和交付总量。FY28 收入达到 600 不意味着此后每年维持或持续增长；FY29 现金可能受到之前已经获得收入的项目影响。

为何不把增长发生判断进一步提高：年内可交付物理供给、客户使用率和净成交价均缺完整独立材料，且最新 DSO、生态投入和长期信用支持表明新增规模并非无条件现金需求。为何也不降到“完全无法判断”：当前已有五季可比销售与利润、客户侧付费业务增长、明确采购方向、初始新产品交付和供应商材料，信息显著多于一个尚未商业化的技术概念。

### 3. 最强替代解释及目前取舍

**解释 A：主要是可持续计算需求扩张。** 它能解释云收入、付费软件、实际容量上线、GPU 销售和网络增长的一致方向。若客户现金收益随新供给扩大、设备利用率与净租价足以回收更新投入，则公司可持续取得高额业务。现有证据更支持这是真实且重要的一部分。

**解释 B：真实使用与融资驱动过建同时存在。** 它同样能解释当下的收入和短缺，却预言后续云资产回报、DSO 和客户集中先恶化。CoreWeave 的利息与亏损、NVIDIA 的投资和支持安排使该解释不能排除。两种解释可能在不同客户群同时成立，因此模型对 ACIE 与成熟云厂保持不同风险判断。

**解释 C：需求继续强，但价值分配向客户、自研 ASIC、HBM 和电力环节移动。** 在此路径中 NVIDIA 不必失去计算技术地位，收入仍可增长，但每单位毛利、网络附着或现金回报下降。内存成本展望、AWS 自有互联、Meta 跨架构优化已经提供部分支持。这是比“AI 全面失败”更容易发生的利润偏离。

真正区分 A 与 B 的是付费使用、客户资产回报和独立融资后的复购；区分 A 与 C 的是同质量负载下的净成交价、成本传导、部署份额与平台组件附着。更多新闻合作或更大的资本开支总额，辨别力较弱。

### 3. 交付前的模型检查

收入按六个经济单元合并，并与 Hyperscale、ACIE、Edge 的客户视图核对；该核对属于算术与口径检查，不充当独立需求证据。GPU 内捆绑组件、独立 CPU、网络、LPX 和软件分别定义；汽车企业数据中心采购不混入车端收入；主权、AWS、OpenAI 及容量项目不在已有路径外重复相加。

利润先在各状态内按产品组合计算，现金再调整投资收益、非现金费用、营运资本、资本支出及战略投资。采购承诺不重复全扣成本，已支付 Groq 对价不在未来再次支付，长期保证上限不混为当期债务。数量、净价、内存成本、账期及客户利用率的扰动均显示出符合经营机制的方向。

**最终经营取舍：** 英伟达已经证明能把先进计算平台变成巨额收入和经营利润；未来两年的主要争议在增长规模、单位价值和现金质量，而不在是否存在商业化。当前更支持 FY28 达到约 600—680 的业务尺度，但需要继续扩大合格供给、把客户计划转成付费部署，并维持成本传导。最值得持续检验的是：为扩大这份收入，公司是否正在承担超出可持续回报的客户资本风险，以及客户自研和软件效率会在多大程度上改变利润归属。报告没有当前证券定价证据，因此不据此断言股价低估、机会未被市场计入或经营增长必然产生同等股东回报。
