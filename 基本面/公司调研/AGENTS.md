# 公司调研目录说明

本目录保存正式公司调研报告、公司索引和研究方法。跨目录资料边界以 `../AGENTS.md` 为准。

## 关键入口

- `公司索引.md`：公司名称、股票代号、分类和正式报告路径的权威索引。
- `结果/`：正式报告分类目录；索引中的分类目录均相对于此目录。
- `研究方案/`：公司调研模板和运行要求。
- `研究方法/`：其他长期复用的方法文件；新增方法时保持独立、短小并明确适用范围。

## 使用规则

- 正式公司报告按 `公司索引.md` 指定的分类存放在 `结果/<分类>/` 下，不在本文件硬编码分类清单。
- 新增或调整公司分类时先更新索引，再写入对应报告目录。
- `tmp/` 只存放执行中的临时材料；`评估备份/` 只用于历史评估和备份，不作为默认公司事实来源。

研究方案版本目录以各自README.md为准，历史子目录用于追溯，不自动作为新任务入口。
