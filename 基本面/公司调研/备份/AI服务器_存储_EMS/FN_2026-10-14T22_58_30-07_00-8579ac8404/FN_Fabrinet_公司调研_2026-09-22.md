# Fabrinet（NYSE：FN）公司调研：从精密光学代工走向多平台制造，增长兑现与现金负担的分界

研究截止日：**2026年9月22日**。金额除另注明外为美元；财年按公司六月最后一个星期五结束的口径，FY2026截至2026年6月26日，FY2027截至2027年6月25日。FY2027Q1截至2026年9月25日，在研究截止日尚未结束，指引不是实际业绩。本文研究公司经营及普通股经济权益，不给目标价，也不据股价反推经营预期。

证据标记：**事实**为原始披露已发生事项；**目标**为管理层或客户预期；**计算**可从列示数据复算；**研究判断/估算**为本文条件推断；**未知**不等于零。条件规模、发生可能性和证据可靠程度分别说明。所有预测区间均非统计置信区间。

## 一、先给经营判断

**Fabrinet的经济实质是替客户把复杂设计变成可以重复交付的产品，赚制造、装调、测试和供应链管理的收益。** 客户掌握芯片、系统架构、产品品牌及终端销售；FN的强项是工艺、良率、质量记录和从新品导入到泰国批量生产的组织能力。它能够受益于多种光学架构，却不能自动获得激光芯片、DSP或系统品牌的利润率。“不与客户竞争”有助于获得外包，也限制了直接占有终端产品利润池。[S10][S11]

当前更支持的判断是：**FN已进入由DCI、计算板卡和通信系统共同推动的扩张阶段；FY2027进一步增长的可见度较高，但高速Datacom旧项目并未同步繁荣，扩产后的现金回报尚未得到验证。** 不能将其简单视为“NVIDIA收入乘AI增长率”的公司。

决定判断的几个事实与推论：

- **增长来源已变。** 按最新重列，FY2026收入46.411亿美元；Datacom旧口径全年10.696亿美元，同比约−7.5%；DCI旧口径7.331亿美元，而HPC四季度依次为0.154、0.856、1.067、1.180亿美元。新口径Data Center包含原来的DCI和部分非光业务，不能和旧Datacom直接比较。[S01][S03]
- **直接客户分散，最终预算未必分散。** FY2026 Cisco、NVIDIA、Nokia、Amazon收入占比为19.9%、16.3%、10.7%、10.5%。据年度收入和四舍五入的占比计算，NVIDIA收入约7.56亿美元，较FY2025约9.44亿美元下降约20%；Cisco约9.24亿美元，增长约48%。这说明集团增长可以覆盖原来最大客户的收缩，也说明“客户收入下降只是分母变大”不成立。各直接客户仍可能依赖相同云厂预算。[S01]（客户集中度表）
- **制造盈利稳定，尚未出现稀缺性暴利。** FY2026 GAAP毛利率约12.0%，营业利润率约10.0%；FY2025分别约12.1%、9.5%。利润杠杆主要来自规模摊薄期间费用，不是毛利率跃升。[S01][S02]
- **收入和利润增长没有同步变成可分配现金。** FY2026经营现金流2.567亿美元，现金购置固定资产2.525亿美元，二者之差仅422万美元；FY2025同口径自由现金流2.073亿美元。存货与扩产投入是关键，不能仅凭净利润评价资金回报。[S02]
- **最新净利润被两个方向相反的项目遮蔽。** FY2026Q4包含Raytek投资重估收益5,674万美元、Pillar Two相关税费5,745万美元；二者接近抵消并不使它们都成为可忽略的项目。前者没有制造业务现金流，后者在FY2027Q1指引中仍被从non-GAAP EPS剔除0.40美元，约1,452万美元。因此本文工作模型保留正常税负，不把non-GAAP税率延续到未来。[S02][S03]
- **“净现金、零债务”必须注明时点。** 6月底现金和短期投资8.751亿美元、计息债务为零；7月已购买7,690万美元美国厂房，8月17日已借入约7,500万美元泰铢贷款。成功扩张也需要资金，不能以6月底资产负债表描述9月资本状态。[S01]（Note 23）[S08]

**工作路径：** 若DCI交付持续、HPC换代和新增收发器项目按节奏爬坡、工厂认证没有大范围延期，本文较支持FY2027收入**58亿—66亿美元**，GAAP口径营业利润约**5.5亿—6.8亿美元**、保留正常税负后的经营性净利润约**4.6亿—5.8亿美元**。第七节的可复算代表点为收入63.2亿美元、营业利润6.39亿美元、净利润5.42亿美元；它不是概率加权期望值。对应现金资本开支与营运资本投入可能使自由现金流在零附近或为负。增长方向证据强于具体收入点值，产品级毛利及未来现金转换的证据最弱。

**最强反证：** DCI和HPC增长可能包含客户将制造外包给FN的份额迁移、提前备料及新平台切换，不能全部视为终端需求的永久净增；旧Datacom与NVIDIA收入下降已经表明，产业景气不保证FN保住每个项目。若连续两个季度收入低于工作路径、库存周转进一步恶化且客户压价，扩产会从增长条件变成利润和现金负担。NPO/CPO、OCS仍存在实质上行，但现有证据不支持将全部技术潜力预先计入收入。

## 二、收入、控制权与研究边界

### 2.1 谁购买，FN真正交付什么

FN面对的是光学器件及网络设备OEM、云厂直接采购团队、汽车/工业设备厂。终端网络架构团队确定规格和部署方式，客户研发与采购团队选择制造伙伴，质量团队进行工艺、可靠性与出货验收。客户为合格器件、模块、PCBA或系统支付合同价；FN不按最终GPU算力、token量或客户节省的电费抽成。

典型业务链为：

**客户设计与预测 → FN工艺开发、试制 → 工厂与产品认证 → 客户采购订单 → 备料与生产测试 → 交付/控制权转移 → 应收回款。**

FN原型和工艺开发能力包括贴片、固晶、键合、主动对准、光纤管理和测试；技术页面能证明提供这些服务，不能证明每项服务都有大规模收费或领先所有竞争者。[S11][S12]

合同普遍没有最低采购量；年期或多年框架协议不等于多年收入保障。客户专用设备可以寄放在FN，FN采购的材料又可能具有较长交期及不可取消条件。合同一般要求客户购买依其要求生产的成品，并承担符合定义的过剩/过时材料。由此形成两个不同的风险：**最终损失风险部分可向客户追偿，回款时点和在制品占用仍留在FN。** 客户信用恶化或责任争议会破坏这个保护。[S01]（Our Contracts、Risk Factors、Note 2）

收入确认依合同中的控制权转移而定，不把生产、出货、验收、回款当成同一时点。未取得各大客户逐项交付条款，因此不能建立统一“出货后30天全部回款”的假设。本文用实际应收及现金流约束模型。对废料补偿，年报MD&A与会计政策附注分别有冲减成本与确认收入的措辞差异，公开资料不能识别具体交易类别和金额；不额外创造“废料销售增长”，也不凭此断言错报。

### 2.2 普通股权益与能力归属

FN是开曼注册公司在NYSE交易的普通股，不是一个仅对应泰国工厂的证券，也不是ADR。股东拥有集团剩余权益，承担母公司担保、营运资本和资本配置的结果。客户许可的设计/IP只用于为相应客户制造，不能自由复制给另一客户；因此技术接触范围大，不等于拥有这些产品的商业权利。[S01]（封面及Intellectual Property）

子公司及制造布局的作用不同：泰国承接规模制造，美国Fabrinet West支持新品导入，Casix及VitroCom提供部分定制光学/玻璃能力，以色列提供区域制造和工程支持。研发费用没有完整独立分部披露，工艺开发人员和客户支持部分进入制造成本，部分定制光学研发进入SG&A；不能因为报表缺少醒目的R&D行，就认定没有研发投入。[S03][S11][S01]

Raytek是**少数股权投资及制造合作**，不是并表收购。2026年5月季度文件描述拟购16.0%，8月年报报告13.8%，应采用最新比例；本次没有取得足以确认差异原因的发行/股本桥梁，不擅自归因于某轮融资。FN不具重大影响，不按权益法确认其日常利润。其账面升值既不是FN营业收入，也不是能立即用于买设备的现金。[S01]（Note 7）[S07]

### 3.3 盈利改善在哪里，哪里没有改善

FY2026收入增加约12.22亿美元，毛利增加约1.43亿美元，新增收入对应毛利约11.7%；营业利润增加约1.38亿美元，对应增量营业利润率约11.3%。这是**历史增量计算**，不是新项目真实毛利率：产品组合、材料价格和旧项目效率同时在变。

SG&A从约8,747万美元到9,351万美元，增速显著低于收入，因此营业利润率改善。未来工厂建设、测试设备、技术人员和NPI增加后，制造费用与折旧先发生，期间费用不可能无限摊薄。集团毛利仍在约12%的事实，对“先进光学稀缺将直接让FN赚芯片级利润率”构成约束。[S01][S02]

Raytek重估增加资产和税前利润，Pillar Two增加当期税费及税负义务；前者不能再年化，后者不能因公司列入non-GAAP调整就永久归零。工作模型剔除投资重估、保留SBC成本，并用16%—20%的正常化税率作敏感性。这是研究估算，实际税率取决于利润所在地、税收抵免、适用规则和收益性质，不是法律税率的断言。

### 3.4 现金占用并非一句“扩产期”即可带过

FY2026末应收约10.179亿美元、存货10.212亿美元、应付贸易款10.058亿美元。应收＋存货−应付从FY2025末约7.025亿美元增至10.334亿美元，增加约3.309亿美元。存货增长约75.8%，快于全年收入35.7%；按季度末余额及当季收入/成本粗算：

| 指标，统一按91天 | FY25Q4末 | FY26Q4末 | 判断限制 |
|---|---:|---:|---|
| 应收天数 | 75.9 | 70.4 | 尚不支持集团回款全面恶化 |
| 存货天数 | 66.2 | 80.3 | 增长/备料与积压均可解释 |
| 应付天数 | 72.7 | 79.1 | 供应商提供了部分融资 |
| 粗算现金转换天数 | 69.5 | 71.6 | 应收改善与应付延长掩盖了存货增加 |

这是**期末余额法研究计算**，不是公司披露的平均周转天数，也不是库存库龄。年报现金流显示应收、存货及其他资产吸收现金，贸易应付、其他应付和应交税费提供对冲。需要跟踪的不只是净营运资本，更是其中哪些对冲不能持续。[S01]（财务表）[S02]

FY2026现金资本开支2.525亿美元，但包括应计未付项目的资本开支约2.989亿美元；资本性应付款约8,602万美元。因此FCF还受到设备付款时间影响。全年FCF没有扣除Raytek股权投资3,236万美元；把FCF视为股东可拿走的现金会进一步高估可分配额。[S01]（MD&A及现金流量表）

增长与备料是真实解释，但还未被库存最终消化验证。针对性查阅后，未取得产品代际库龄、各客户库存保障覆盖率、逾期应收分层和毛取消率；不能将净收入残差当取消率。合同负债约424万美元，相比超过10亿美元存货很小，客户预付并未在报表层面覆盖全部扩产备料。[S01]（Note 3）


## 四、从客户需求到FN可获得业务：各分支的经营机制

### 4.1 高速收发器：可以重新增长，但必须证明新项目净增超过旧项目衰减

800G/1.6T模块把高速电信号与光信号互换。采用200G每通道、不同激光/PIC、DSP或线性架构，改变功耗、距离、链路预算、散热、测试与装配难度。FN的经济单位是**在约定BOM和制造责任下交付一只合格模块**，不是“新增1Tbps就收固定价格”。

公司提供亚微米公差和五轴主动对准能力。装调需要在光功率或其他反馈下优化器件相对位置，固化后还要经过温度、老化及系统兼容性测试。优势来自稳定良率、周期、返修率和可复制工艺。不能从“对准精度高”直接得出采购价高：客户仍会比较另一条已认证产线的合格品总成本。[S10][S12]

**实际商业证据同时支持需求和反证。** 旧Datacom收入从FY2025的11.560亿美元降到FY2026的10.696亿美元，最近四季度大体停留在2.58亿—2.78亿美元。另一方面，2026年5月公司披露新增Datacom客户协议；8月管理层说云厂直接项目预计9月季先起量、一个商用客户项目12月季起量，其余于2027年初启动。前者是历史收入，后者是目标；不能因有协议就视为终端已部署。[S03][S06][S13]

**独立客户需求锚：** Cisco于8月12日披露FY2026来自超大规模客户的AI基础设施订单93亿美元、已交付相关收入约40亿美元，并预计FY2027收入75亿美元。这能支持它所服务的网络需求扩张，但包含交换芯片、系统、光学等不同内容，无法等比例转换为FN订单。NVIDIA已有光子交换产品生产发布，也不代表全部产品继续沿用FN旧收发器配置。[S14][S17]

可获得份额取决于具体设计定点、料件配额、工厂认证、交付记录及竞争者二供。FN服务更多客户有两种净效果：新终端需求；同一终端原由别家生产的份额转移。第二种对FN是真实增量，对全球端口数却不是增量。旧客户缩量与新客户放量必须放在同一模型。

**FY2027工作算例，非披露订单：**

- 旧项目全年维持约10.3亿美元：略低于FY2026，保留成熟品降价与份额损失。
- 新项目按当季FN可确认的净收入约0.10、0.60、1.10、1.90亿美元逐季爬坡，合计3.7亿美元；不是全年按第四季乘四。
- 两者形成约14亿美元收发器收入。若新增项目平均制造账单为400—800美元/只，3.7亿美元意味着约46万—93万只年内合格交付，末季年化产量显著更高。**该价格仅是反推所需物理交付的条件输入，并非已查得FN成交价；若客户供料，按净加工费计量时数量会大幅变化。**

这个推导给出的是工作路径**需要交付多少**。公开证据支持多项目进入爬坡，却没有披露模块数量、客户料件分配或收费边界，因此尚不能独立证明上述只数可实现。若有效起量晚两个季度，新增收入可能只有1亿—2亿美元，集团工作路径减少约1.7亿—2.7亿美元，而不会因为“长期需求仍好”自动补回当年收入。

### 4.2 DCI：本轮最扎实的增量之一，但不能把每条数据中心链路都算给FN

DCI连接不同数据中心/园区。相干技术以更复杂的调制、接收和DSP提高传输距离与光谱效率；客户权衡每比特成本、光纤资源、传输距离、可靠性和功耗。云厂可能直接采购相干可插拔模块，也可能通过Cisco、Nokia等系统供应商购入线卡或传输系统。FN处于被选中的制造层，不能同时收取完整网络设备价值。

旧DCI季度收入从FY25Q4的1.07亿美元升到FY26Q4的2.559亿美元；这比仅凭市场规模推断更直接。按新分类，部分DCI相关产品覆盖更广，但本文保留较窄旧集合用于可比追踪。[S03]

Nokia于2026年7月23日披露Q2 Optical Networks固定汇率收入增长20%，AI & Cloud客户销售增长105%，相关订单28亿欧元、预计约半数在未来十二个月转收入。它也指出供应制约促使客户下更长周期订单。该证据支持实际销售增长，同时提示长单可能含提前锁定供应；并非新增订单全部在FN生产。Nokia于2025年收购Infinera，因此FN客户名下的收入整合不能一概视为新客户赢单。[S15][S26]

本文FY2027工作路径为**12.5亿美元DCI收入**，来自季度约2.7、3.0、3.4、3.4亿美元的交付节奏；这里仅为避免精确幻觉而选取代表点，四季合计而非年末速度。它要求FY26Q4基础上进一步获得材料和测试能力，而不要求收入持续每季增长30%。

反面路径包括：客户先补库后消化；单位带宽升级减少模块数量；相干模块进入交换机后压缩部分独立线卡/系统内容；客户自制或换供应商。DCI增长能提高制造复杂度和收入，不保证每单位带宽的FN利润增加。本文没有将DCI增长再作为通信基础设施的同额增长重复添加。

### 4.3 HPC：新的大规模制造入口，收入质量取决于客户供料边界

HPC业务体现FN从光学向高复杂度计算PCBA延伸。重要工序包括高密度贴装、焊接、板级互联、电源和信号完整性相关制造控制，以及功能测试。CPU/AI ASIC、内存本身的设计或晶圆制造通常不是FN提供的经济能力。

FY2026HPC收入约3.257亿美元，第四季1.180亿美元，已跨越“小额试产”阶段。Amazon全年向FN贡献约4.87亿美元的估算收入，与HPC业务不是相同口径：Amazon还可能有其他项目、采购主体或产品。**不能把所有Amazon收入当HPC，也不能把所有HPC收入视为已逐笔核实由Amazon支付。** 管理层使用“主要超大规模客户”描述HPC；本文将其与Amazon集中度事实分开。[S03][S01][S13]

需求侧，Amazon的2026Q2 AWS收入422亿美元、同比增长37%，营业利润166亿美元；集团过去十二个月经营现金流1,614亿美元，而FCF为负76亿美元。它的支付能力显著强于缺乏现金流的早期算力租赁商，但投资节奏仍受资本回报约束。AWS收入包含广泛云服务，不能视为Trainium或FN板卡收入的独立点值证明。[S16]

本文FY2027工作路径HPC收入7亿美元，对应季度约1.4、1.6、1.9、2.1亿美元。需要既有项目持续复购、新平台换代不过度停线，并增加测试产能。若按每板FN净确认收入1,000—3,000美元作**收费边界算例**，全年需要约23万—70万块合格板卡；这个范围并非真实ASP或订单统计。

板卡业务存在“收入变大、百分比毛利变低”的合理路径：FN采购并转售更多高价材料，收入增长但加工环节价值增幅较小；客户供料则可能使收入减少、毛利率上升、资金占用下降。二者都不能仅从报表毛利率高低判断技术地位。由于没有公开BOM和客户供料细节，工作模型给HPC低于精密光学的毛利假设，保留7%—11%的条件范围。

Amazon认股权证是可核验的客户收益分享安排。2025年3月12日签发、行权价208.48美元、最多381,922股、2032年3月12日到期；部分随付款门槛归属，**具体金额门槛被遮蔽**。这不是公开的最低采购承诺。最大潜在股数相对约3,583万普通股为1.07%，无现金行权实际新增股数还取决于股价等条款；不能直接按最大股数再乘一个融资额。[S18] 历史收入已经包含相应抵减，不在模型中重复扣一次。

### 4.4 通信基础设施：既有现金能力，也有外包转移红利

FY2026新分类通信基础设施收入约15.464亿美元，Q4约4.129亿美元。光模块、线卡、网络系统、ROADM与部分卫星相关产品共享光学和电装能力，但面临不同资本开支周期。[S03]

系统OEM将组装、测试和采购转给FN，可以在终端需求不同比增长时提高FN收入：客户释放厂房和营运资本，FN承接系统级物料与制造。这条机制解释了为什么不能把“电信收入增长”全部推导为全球运营商预算增长。增加系统内容还可能稀释毛利率，必须同时看绝对毛利和资本占用。

工作路径18亿美元，要求季度收入由4.1亿美元基础升到约4.6亿—4.8亿美元，而非假设电信市场全面高增长。通信系统订单的独立支持来自Cisco和Nokia实际销售/订单；FN与各项目的份额仍缺少公开采购表。客户合并既可能扩大外包，也可能统一采购压价或关闭重复产线。

LEO卫星连接是需要保留的延伸：光学装调、严苛可靠性及批量制造能力可以复用，客户数量却更少，平台失败或发射延后会直接改变采购。最新公司材料列有LEO Satellite应用，但未给可核验的FN独立收入、客户份额和卫星BOM，因此计入通信业务整体范围，不另加一个“卫星TAM”。[S03]

### 4.5 汽车、工业激光、医疗与定制光学：不能删去，也不宜夸大

最新“汽车、工业及其他”FY2026约8.696亿美元，不是可忽略附属业务。旧细分Q4汽车1.353亿美元、工业激光4,900万美元、Other 5,710万美元；新旧类别归属略异，不能把旧Other中可能含的数据中心产品重复算入新分类。[S03]

汽车与充电设备取决于车型/设备项目、成本和终端销量；LiDAR不等于每辆车必备，获得设计资格不等于持续订单。工业激光来自加工、精密制造等资本开支，升级周期与AI不同。医疗、检测及传感器依靠工艺质量、可追溯性和项目生命周期，通常有较长认证和产品支持责任。公司2025责任报告列示相关质量认证，证明质量体系覆盖，不能证明所有未来产品获批。[S22]

这些分支的价值在于现金来源、共享材料/装调能力和降低对单一架构的依赖；风险是长尾客户的融资和量产计划可能比云厂更脆弱。工作模型只给FY2027约9.9亿美元，较FY26Q4年化水平温和增加；不假设汽车销量、激光资本开支与AI全部同步上行。具体产品利润未披露，因此不把集团12%毛利复制为历史分部利润。

### 4.6 NPO/CPO、OCS与Raytek：实质机会存在，但利润归属仍需跨门槛

**技术传导。** 可插拔把光模块放在面板；NPO将光学移近交换/计算芯片；CPO进一步与芯片封装紧密集成。缩短高速电通道有助于功耗和信号完整性，却引入光纤连接、散热、已知良品筛选、维修、更高价值组件共同报废的风险。若单位引擎价值提高但可替换性下降，客户对制造可靠性的要求更严。

FN已被NVIDIA列入硅光生态；NVIDIA在2026年5月31日表示Spectrum-X Ethernet Photonics进入生产。这是平台侧商业进展，**不是FN已获得某个固定份额或CPO独立收入的证明**。[S17][S27]

Raytek提供RDL、Cu pillar、TSV reveal及硅光相关晶圆级工艺，其官网披露2024年已完成12英寸硅光定制工艺开发；2026年9月SEMICON Taiwan讲者资料列出其泰国设立工作。它们支持能力互补和扩建行动，尚不能证明FN园区内相关产线已完成全部客户认证及规模出货。[S20][S21]

FN管理层8月认为NPO可能较CPO更早贡献，并称Raytek将向泰国园区增加能力。本文因此把NPO列为FY2028以后更值得跟踪的商业路径，但不将合作厂全部产能或利润并入FN。[S13] 反面证据是Jabil已有光子封装和1.6T产品服务，Coherent截至9月20日正推进PhotonLink整合平台。它们说明FN并非没有替代的封装入口；公告和展示都不能替代各自量产利润证明。[S19][S23]

**可检验的规模门槛算例：** 若FN获得一类102.4Tb/s交换平台的光引擎制造，每台采用16个6.4Tb/s引擎，则1万台对应16万个引擎。若FN每个引擎净确认500—1,500美元制造收入，年收入为0.8亿—2.4亿美元；若毛利率12%—18%、新增持续工程/支持费用800万—1,500万美元，增量营业利润大致为亏损540万美元至盈利3,520万美元。台数、结构、单价、费用均是本文条件，不是任何FN客户BOM承诺。它说明：**技术成功且拿到一万个系统的平台，并不自动变成十亿美元收入或高利润。**

要变成更大业务，必须同时提高系统实际交付、FN覆盖的制造环节或平台数，并有测试设备和人员跟上；不能把三者的最大值独立相乘。先进封装服务可能改为客户供芯片/光子裸片，FN收入低于整模块但资本回报更好，这是比单纯收入TAM更值得关注的上行。

**OCS**在光层改变连接，不等同于上述电交换芯片旁的光引擎。现有精密对准、自由空间光路或光机电组装能力适配部分OCS路线；不同MEMS、液晶或其他架构的关键良率并不一样。管理层8月确认已有小规模产品出货，尚未给有意义的独立收入数字。[S13]

Lumentum的FY2026业绩材料将OCS和1.6T云模块列为开始贡献的驱动，支持外部供应市场确实形成；不能据此认定其所有外包都交给FN。[S24] OCS的FN机会更多是客户从自制转外包与系统量增加，设备带宽提升还可能允许旧光路复用，从而压低每单位AI算力的新增采购。

OCS条件算例：若年交付5,000台、FN每台确认制造收入1万—3万美元，则0.5亿—1.5亿美元收入；12%—16%毛利对应600万—2,400万美元，仍需扣专属工程、质量和设备投入。没有公开台数和收费边界支持把此当预测。到FY2028，若该类项目能形成超过1亿美元年收入且盈利，才足以在集团模型单独替代部分“其他Data Center”假设。NPO、CPO与OCS都使用同一部分工程人才和资本预算，机会不能默认独立全部成功。

## 五、供给、竞争与单位经济性

### 5.1 厂房变大不等于合格交付立即增加

截至8月电话会，管理层披露Chonburi Building 10已认证约25万平方英尺，另约25万平方英尺计划当季认证，整栋约200万平方英尺预计2027年初完成；Pinehurst改造和Navanakorn增加空间，美国新厂服务NPI。这些是**分阶段状态和计划**，不是全楼已满产。[S13]

量产所需顺序为：建筑与水电完成 → 设备安装校准 → 人员培训和工艺稳定 → 客户审厂/产品资格 → 稳定投料 → 良品与验收。设备、材料和客户验证可部分并行，但厂房完成不能越过后面步骤。既有产线扩量一般快于全新架构导入；新平台的客户测试可能比建筑更慢。

年报项目预算约1.325亿美元、6月底剩余约3,970万美元，仅针对相关建筑项目，**不是填满200万平方英尺所需的全部设备、材料和营运资金**。[S01] 6月底现金资本开支与应计资本开支差异已经显示付款承诺在累积。

缺少设备台数、产品工时、利用率及良率，不能给出“FN有多少只1.6T年产能”的事实点值。可以检验必要条件：若每个并行测试通道完成一只产品占30分钟、年排程6,000小时、综合有效率80%，则每通道约9,600只/年；新增60万只需要约63个并行通道等价。若总测试时间变成120分钟，需要约250个通道等价。此为工程算例，具体实际工艺时间未知；它显示测试内容变化可比厂房面积更影响交付。

### 5.2 竞争有四层，稀缺性不必落在FN

| 竞争层 | 替代者/机制 | 对FN数量、收费及资本的影响 |
|---|---|---|
| 同类制造 | Jabil、Celestica、Sanmina等工程与规模能力 | 新客户定点可分流；认证完成后形成压价约束 |
| 垂直整合模块商 | Coherent、InnoLight、Eoptolink等 | 自有器件/模块及部分内部制造可能绕过FN；某些项目也可能成为FN客户 |
| OEM自制与采购整合 | 客户收回制造、合并供应链、双源 | FN收入可在终端增长时下降；旧项目退出与新项目导入并存 |
| 架构与工艺替代 | 铜互联、NPO/CPO、光学集成和自动化 | 减少某些模块/装调工序，也创造新的封装/测试需求 |

Jabil正式介绍覆盖光学制造、先进封装、设计及白牌产品，说明竞争不仅是低价装配。其与FN“不竞争客户品牌”的定位存在区别；客户会根据设计帮助、制造中立性、交付和价格选择，没有理由假定一种商业模式永远胜出。[S19]

供应紧张可能发生在激光器、DSP、PIC、基板或测试，而非FN的厂房本身。上游拿走涨价利润时，FN可能只负责增加备料并承受交付波动。只有客户愿意为更快的合格制造付费、FN可保留效率收益且其他已认证供给不足，稀缺才能转成制造溢价。最近毛利走势并未证明这种溢价很大。

### 5.3 选择“合格交付＋制造责任”作为单位

集团毛利约12%意味着每100美元收入约88美元进入制造成本，不能将12美元全当加工费。为说明价格和良率，采用如下**经集团总量约束、不是实际BOM**的代表性模块算例：

| 每只合格产品，美元 | 代表点 | 经济含义 |
|---|---:|---|
| FN净确认收入 | 500 | 不等于客户向最终买家的售价 |
| 材料、外购与预期损耗 | 360 | 需要以合同确定由谁采购和承担报废 |
| 直接人工、测试及其他变动转换成本 | 50 | 测试时间与重做影响此项 |
| 工厂固定成本和折旧分摊 | 30 | 随有效产量变化 |
| 毛利 | 60 | 12%；还未扣集团SG&A、税和资金成本 |

若收入降5%至475美元、材料成本同步降5%至342美元而其他成本不变，毛利降至53美元、毛利率约11.2%；若材料未降，毛利只有35美元、约7.4%。因此行业器件涨价可使FN收入增长却压低回报，客户大幅降价则需同步降本。

若50美元变动转换成本本来对应95%有效通过率，降至85%后同样合格数量的该部分成本按简化模型增至55.9美元，每只多约5.9美元，尚未包括报废高价裸片。若生产量下降20%、固定成本总额不变，原30美元分摊变37.5美元。这两种因素不能用“新产品ASP更高”一笔掩盖。

同样不能把全集团都当一个模块：HPC可能物料价值更高、加工毛利率更低；DCI及复杂光机电产品测试长、良率学习重要；医疗/工业长尾可能小批量工程费较高但销量不大。第七节按这些差异设条件毛利，不伪造历史分部利润。

### 5.4 增长资本回报的门槛

一个新增**1亿美元年收入**项目，若稳定毛利率12%、新增客户工程和管理400万美元，营业利润约800万美元；18%税后约656万美元。若需要设备及配套1,000万—2,000万美元、净营运资本1,500万—2,500万美元，则占用资本2,500万—4,500万美元，对应成熟税后经营回报约15%—26%。这不是公司披露ROIC，尚须考虑爬坡亏损与资本持续更新。

若毛利降至9%、同样工程投入，税后经营利润约410万美元，回报降至约9%—16%。若客户提供更多设备或材料，回报可能更好；若必须预购不可取消元件则更差。简单用资本除成熟税后利润得到约4—7年及6—11年“盈利回收年数”，不等于现金回收期；折旧加回、维护资本开支、尾期营运资金回收都要另算。

公司公布的non-GAAP ROIC使用净利润、扣现金后的平均权益/债务，并对单季利润年化。本文不把该指标视为新增工厂边际回报。资本配置是否成功，要看新增毛利能否覆盖新折旧、工程、税及营运资本机会成本，而非只看集团历史比率。[S03]（第8页）

### 6.3 诉讼、质量、税与地域风险如何进入现金

Casix诉讼涉及人民币4亿元及利息的原告请求。此前管辖权驳回不等于实体胜诉；2026年7月30日中国最高法院接受再审，尚非认定原告诉请成立。公司称暂不能量化潜在责任。它不是已确认4亿元损失，也不应在风险表只写一句“已被驳回”。按汇率仅作量级观察，本金是数千万美元级，利息和责任承担范围可能更重要；本文没有虚构诉讼概率。[S01]（Note 19）

产品缺陷风险不仅是报废本身，还可能导致停线、重新认证和客户资格受损。保修一般针对工艺、部分合同另有特定责任，不能假设所有后果都严格限于产品售价。新封装中的高价值裸片共同损坏，可把原来小额转换错误变成较大损失；这也是要求客户供料、报废责任和验收边界明确的原因。

税收方面，新旧工厂优惠不同，Pillar Two又形成额外约束。本文不把泰国税收优惠简单累加为长期零税，也不把FY26Q4所有税费视为同一年的持续季度水平。现金模型单列此前计提税费的支付敏感性，正常年度税率另外计入。

泰国生产集中使FN对当地电力、洪水、劳动力和物流中断敏感。跨境关税、出口许可及原产地规则影响交付资格和客户到岸成本，不能仅因在泰国组装就认为所有限制被消除。没有逐SKU关税和合同承担方证据，本文不列伪精确税率；冲击通过延迟出货、备料、客户转单和未能及时传递的成本进入模型。以色列及中国运营的地缘暴露也按实际资产/工艺可替代性理解，不以注册地概括全部经营地域。

### 7.4 超出普通压力的资本边界及应对

假设连续两年各约1.5亿美元负FCF，又出现约3亿美元收款/库存延误和1.5亿美元供应商信用收紧，初始875百万美元加已披露贷款75百万美元、减两年本金约30百万美元及其他融资流出后，流动性可能降到约1亿—2亿美元。这些冲击代表严重共同压力，并不赋予其高概率；库存在模型中已占用的部分不能再作为第二笔损失扣除。

届时不能继续无条件扩张。可行次序是停止回购和可选设备、推迟未承诺项目、降低投料并要求客户支付存货补偿/提供物料，再视信用条件融资或出售非核心资产。削减投入会使FY2028—FY2029产能与客户份额低于成功路径；压缩库存也可能以折价或失去订单为代价。Raytek受限股权不作为即时救急资产，授信也不视为自动足额可提款。

本文以维持约2.5亿—3.5亿美元流动性作为**研究性经营缓冲**，并非公司契约下限。低于该范围时需重新评估材料周转、工资、供应商信用和可削减支出，而不是等现金变负才设融资。

为何不是更高或更低：近期收入增长已具实收销售基础、客户财务能力与新项目目标，若把FY2027增长概率压到50%以下，需要比当前更强的反证；但把58亿美元以上概率推到90%，又会忽略采购承诺通常较短、旧项目缩量与新厂资格的不确定性。先进封装和OCS已有进入路径，不宜当零；具体规模仍缺客户合同，亦不宜当必然。

### 8.3 最强替代解释与下修规则

1. **“增长主要是外包转移而非终端扩张”。** 这不否定FN短期收入，但意味着份额迁移完成后增长可能放缓。判别需要客户终端交付与FN系统内容/份额同时跟踪，不能只看OEM订单。
2. **“新分类隐藏了旧Datacom疲弱”。** 重列确实使Data Center增长显得更强；已保留旧口径对照。真正改变判断的是收发器新项目净增、旧客户复购和毛利，而非类别名称。
3. **“库存增加是在为真实需求准备”。** 当前客户需求与扩线支持这一解释；若两季后存货天数继续升、客户排程延后且FCF不改善，就应提高积压解释权重。
4. **“NPO/CPO让FN失去可插拔组装内容”。** 即使FN在新封装有资格，单位带宽收费和所负责工序可能减少。看净制造毛利，不把新路线全部算新增。
5. **“稳定毛利率足以证明长期优势”。** 也可能是客户物料定价传递和项目组合共同作用，不能代替产品级价格证据。若增量收入主要来自高材料价值板卡，需检查资本回报是否下降。

明确的工作路径调整触发条件：两季平均收入比第七节路径低10%以上且原因不是单季物流时点；可比毛利率持续低于约11%；库存天数升至90天以上且缺乏客户付款保障；新项目推迟两个季度；重要直接客户采购减少并出现二供转移。阈值是研究观察规则，非公司契约。反之，连续批量交付、正常税后利润和现金同时改善，才支持上调可持续规模或概率。

## 附录A：核心模型复算

下列为FY2027三个代表点的最小计算，金额百万美元；预测参数均为研究假设。顺序：收发器、DCI、HPC、其他Data Center、通信基础设施、汽车工业其他。历史数据与模型假设不混放。

```python
from decimal import Decimal, ROUND_HALF_UP

cases = {
    "压力": {
        "revenue": [900, 950, 420, 100, 1550, 880],
        "gross_margin": [.10, .11, .07, .10, .108, .11],
        "opex": 115, "net_interest": 20, "tax": .19,
        "da": 75, "sbc": 43, "working_capital": 240,
        "prior_tax_cash": 57, "cash_capex": 300
    },
    "工作": {
        "revenue": [1400, 1250, 700, 180, 1800, 990],
        "gross_margin": [.122, .125, .09, .13, .125, .12],
        "opex": 118, "net_interest": 22, "tax": .18,
        "da": 80, "sbc": 45, "working_capital": 290,
        "prior_tax_cash": 57, "cash_capex": 400
    },
    "加速": {
        "revenue": [1650, 1400, 850, 230, 1970, 1050],
        "gross_margin": [.126, .13, .095, .135, .128, .122],
        "opex": 125, "net_interest": 18, "tax": .18,
        "da": 90, "sbc": 50, "working_capital": 430,
        "prior_tax_cash": 57, "cash_capex": 480
    }
}
for name, c in cases.items():
    c = {k: [Decimal(str(v)) for v in value] if isinstance(value, list)
         else Decimal(str(value)) for k, value in c.items()}
    revenue = sum(c["revenue"])
    gross_profit = sum(r * m for r, m in
                       zip(c["revenue"], c["gross_margin"]))
    operating_profit = gross_profit - c["opex"]
    net_profit = (operating_profit + c["net_interest"]) * (1 - c["tax"])
    operating_cash = (net_profit + c["da"] + c["sbc"]
                      - c["working_capital"] - c["prior_tax_cash"])
    free_cash = operating_cash - c["cash_capex"]
    print(name, *(str(x.quantize(Decimal("0.1"), rounding=ROUND_HALF_UP)) for x in
          [revenue, gross_profit, operating_profit, net_profit, free_cash]))
# 压力 4800.0 498.1 383.1 326.5 -152.5
# 工作 6320.0 757.3 639.3 542.2 -79.8
# 加速 7150.0 882.0 757.0 635.5 -191.5
```

算术闭合仅证明参数没有重复或漏加，不证明客户会采购这些数量、工厂会达到这些良率。本文不以模型合计当作第二份独立需求证据。
