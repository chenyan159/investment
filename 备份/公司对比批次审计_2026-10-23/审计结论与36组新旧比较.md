# 公司对比批次审计与36组新旧报告比较

审计日期：2026年10月23日。当前主目录：D:/investment。本文审查本轮252家公司对比的交付、目录、证据增量、模型复核和跨报告一致性。

**结论：本批runner交付完整；抽样看，新版整体更适合单家公司决策，尤其在跨报告冲突、资本归属和估值假设方面。但正式目录尚有1份池外旧报告，横向结论尚未形成一致的全局尺度，也不能由“done”推出所有经营事实及长期预测已验证。**

**二、新版是否增加了有效信息**

这里把“有效信息”限定为能改变经营、现金归属、估值、相对选择或行动门槛的信息；不把字数、网址数、目标价更高或证据标签更低当作质量分数。

244组前后报告的字符数中位数由59,480降至51,118.5，下降14.1%；204组变短。总字符数由14,391,283降至12,596,184，下降12.5%。独立URL计数的中位数仍是26。36组样本总字符数下降8.3%，24组变短。说明新版普遍压缩了篇幅，但不能据此宣称减少了同比例的重复，或增加了某个精确百分比的有效信息。

**不能把全部变化叫新事实。** APLD上调主要因未来融资价假设；ADI、PWR、CRWD的大幅“纯业务价”变化主要来自分母或固定倍数；OKLO从4.51到31.46主要来自估值覆盖范围扩到完整后续队列；CEG、CRWV、TSLA、ALNY、MRNA等新旧目标年份也有变化。它们可能增加分析价值，但不是公司已实现的收入或利润变化。

本轮还同时更新了上游公司调研、行业研究及情景模型，市场价格亦变化。因此，新版更有用是本轮成品的比较结论，不能将全部提升归因于公司对比方案本身。旧版并非没有资本纪律：MU旧版已剔除未经批准回购，CRWV旧版已把收入压力联动到债务和股数，许多旧版已有DCF与交易估值区分。

数值变化排除了每个端点不超过max(0.05美元、上游值绝对值的0.1%)的舍入差。例如IREN的48.2—70.9与48.19—70.92不算实质变化。原始精确比对有171家公司至少一个情景字段不同，这个数包括舍入、证据等级和口径变化，**不宜拿171作为“真正重估公司数”**。

复核的独立性是新版的优点，但还有两项限制。第一，许多远期目标仍靠较高倍数和很长成长持续期，证据降为中并不消除这种依赖。第二，报告里的“采用”只是本次没有足够理由推翻该条件模型，并不等于真实世界已经证明全部收入、资本和融资路径可同时兑现。

**四、最重要的剩余问题是跨报告尺度不一致**

全批有3,005条有方向的对手比较，只有524对同时出现A比B与B比A。它不是252家公司互相穷举的63,252条有向关系。大多数报告选10—14家对手；RNR选9家并说明保险池和机会成本覆盖，不应机械判成不合格，方案明确不凑数。

将反向报告的“目标占优／对手占优”翻转为同一方向后：

| 检查 | 数量 |
|---|---:|
| 双向都覆盖的公司对 | 524 |
| 至少一个偏好字段不互为镜像 | 156，占29.8% |
| 至少一个视角明确选出相反胜者 | 68，占13.0% |
| 上述68对中，两篇目标股参考价格日期相同 | 64 |
| 稳健复利明确相反／高弹明确相反／综合明确相反 | 40／29／7，三项有重叠 |

“156”含一篇相当、另一篇偏好等边界差异，不全是严重冲突。“68”是需要校准的明确相反胜者，仍不能直接叫68个事实错误：价格窗口、目标模型、评价目标和风险预算可能不同。同一参考价格日期也不保证全部对手价格完全相同。

**最清楚的例子是ETN与SBGSY。** 两篇都使用ETN368.99、SBGSY52.66，但[ETN报告](</D:/investment/分析报告/公司对比/结果/ETN_逐家公司投资思路对比_2026-10-22.md:228>)看重Schneider的PTC融资整合风险，选ETN稳健胜；[SBGSY报告](</D:/investment/分析报告/公司对比/结果/SBGSY_逐家公司投资思路对比_2026-10-22.md:228>)看重ETN美洲利润率恢复与较深受损回报，选SBGSY稳健胜。两边都有实际论据，缺的是统一取舍规则。它们不能同时变成不带条件的全局先后顺序。

另外一个结构性原因是“自己用本篇校准，别人用其上游”。[NVDA对AVGO](</D:/investment/分析报告/公司对比/结果/NVDA_逐家公司投资思路对比_2026-10-22.md:244>)引用AVGO基准704.7—860.4、当前DCF421.5，据此给AVGO稳健优势；但AVGO本篇已把自身校准至616.8—753.8、DCF369。若把不同报告的胜负直接拼接，就混入两套AVGO估值。这里不能反过来修改上游以迎合某个结果，需要先承认横评尚未统一。

综合胜者明确相反的7对为：GFS—UMC、ARM—INTC、AXTI—LITE、NVTS—POWI、BE—OKLO、ETN—SBGSY、AAON—MOD。完整正反理由保存在配套JSON。其他有代表性的稳健分歧包括NVDA—AMZN、NVDA—GOOGL、COST—AMZN及DHR—REGN；高弹分歧常源于一篇看未加权突破上限，另一篇看存活和风险调整后的赔率。**这影响将报告用于统一配置，不意味着这些报告各自没有研究价值。**

**六、下游读取分两种结果**

原生MD与本批JSON交付可读，字段检查通过；本次人工样本的执行摘要、基准复核表与JSON决策作了对应核对。但未完成3,005行正文与JSON每个胜负词的逐行语义证明。

旧[站点生成器](/D:/investment/分析报告/公司对比/生成站点数据.mjs:19)仍硬编码192家公司、六个旧评分维度，并引用不存在的旧根级研究方案路径。用PROJECT_ANANTA_OUTPUT_ROOT指向分析报告/tmp内的隔离目录运行，实际在读取索引时退出：**“公司索引应有192家，实际252家。”** 因而后面的旧方案路径和解析逻辑尚未走到，是静态风险而不是本次已触发的第二个运行错误。

已有站点数据current.json生成时间是2026年9月6日，所载报告日主要为7月14—18日，不能代表此次252家结果。但[当前方案README](/D:/investment/分析报告/公司对比/研究方案/README.md:3)明确要求“不更新站点”；所以网站不新不是本批runner违约，旧展示链不能消费新契约才是另一个兼容性问题。本次未改站点，也未发布。
