### 3. 排序方案共同条款应怎样改

**目标段替换为：**

> 分别形成研究日起3个月、6个月的候选顺序及条件建议，并解释3–6个月的确认/兑现时序。允许长期价值提前重估，但必须说明哪些新信息会使市场在此期限改变定价。前30为研究重点，不要求强行买足30只。保留最强落选反例与独立方法强推而综合未采纳的公司。

**输入段替换为：**

> 读取截止日前的公司情景经营事实与价值模型，并可回到其公司/行业原文及一手资料补证。区分原文事实、继承假设、本方法新推断；既有评级和名次不是证据。市场与价格采用批次冻结的同一输入。对历史测试，只能使用当时可得的版本；不得让未来资料进入旧建议。

25个旧入口仍要求退役评估，必须逐条迁移语义，不能仅改目录字符串。合并情景中的20个条件格不能机械当原来四情景的概率或“信心”；尚无新合同产物时只能说输入待就绪，不以旧根目录仍有文件冒充迁移完成。本条讨论的是file-run消费者责任，不改上游方案。

**判断段替换为：**

> 自行选择适合公司的估值/技术/商业模型；说明市场隐含要求、最强独立证据、每股捕获及失败路径。模型允许原创和大胆估算，重大假设须能被挑战。若用评分，事前定义其含义，不把资料齐全程度映射为统计发生概率，不把历史上涨映射为永久损失保护；不同视角可保留不同条件选择，不必强造全序一致。

**输出段替换为：**

> 分别交付研究优先级、当前可执行判断、价格/事件条件、观察或不适用身份；继承输入与新增结论只保留决定性部分。说明进入前30的理由和最强替代者、改变选择的条件及期限。事实不足时允许NA/区间，不用字母排序或中性分制造头部推荐。

N03旧严格合格集仅8只，148只同为52分；12旧A/B合格集为0仍列控制头部。这些需要改交付身份，不能拿机械Top30输赢直接判原合格建议。08、N02也不应继续把证据完整性或尾部审查当第二张收益票。详见26方案逐条表中的原文引用。

## 三、五种产业背景：怎么把回测证据传回研究方案

背景稿没有买入价格/仓位/预测目标，不能把其提到的股票任意组成“背景组合”并称收益验证。这里使用两种证据：背景是否已有关键约束；该约束在已冻结的后续排序/专项中如何被解释。机制联系不等于证明背景导致股价；没有消费记录的路径明确标为待验证。

**最值得保留的已有观点：**7/10瓶颈稿将服务器装配列为局部/可能缓解，亦明确被压制者DELL/HPE/SMCI可因供给缓解受益。七月DELL+22.92%、HPE+10.08%、SMCI+43.13%，PENG却−32.96%。这反驳“只有最硬瓶颈卖方才值得研究”的筛选偏见，但不能证明这些涨幅全部由瓶颈缓解导致。[装配约束](<D:/drive/Investment/基本面/行业调研/产业背景/AI产业链瓶颈与反证指标总表_2026-07-10.md:127>)、[缓解受益方](<D:/drive/Investment/基本面/行业调研/产业背景/AI产业链瓶颈与反证指标总表_2026-07-10.md:828>)。

### 1. 全局图谱与口径字典：保留，缩减重复判断

**回测提出的问题：**同一基础设施方向中SMCI/PENG、八月META/HPE和BE/CMI分化很大。全局“受益”标签不够支持公司选择，但不因此证明图谱分类错误。原稿已经分最终需求、CapEx、订单、物理量等账，不应再重复新增同名字典。

**修改原第三/五/六章：**对下游要引用的关键变量增加主体、产品、地域、期间、存量/流量、价值层及与其他池重叠关系。将每条跨层公式标为“在什么条件下可使用”，公司受益表写明是需求、收入、利润、现金还是普通股价值的哪一步。允许估算，缺口不强行数值化。

**修改原七/八章：**全局情景和公司映射改为四个其他背景的可对账关系与差异理由，不再自行产生又一套公司投资优劣。保留对模型冲突的原创裁决与目录外路线，删掉必须同方向乐观的前提。

**拟写入条款：**“相同需求在不同受益层不能计为独立增长来源；一个公司在某层受益不代表每股收益增加。解释哪一步尚未证明，并将这条限制随数字一起交付。”

### 2. 瓶颈与反证：保留，重点补约束转移和受益方向

**回测提出的问题：**瓶颈稿原本就有“缓解对卖方定价不利、对买方交付有利”。03/05的防守分值却不能稳定反映公司现金风险。此处不能要求背景再给统一股票风险分，而应让它输出足以被排序挑战的具体约束。

**修改原5.1/5.3/5.4及反证规则：**每个决定性瓶颈交付受益卖方、受压买方、缓解后获益者、预计解除时间；同时写当前是否已触发反证、触发后哪个估计失效。固定数值阈值须有机制依据，无法支持点阈值可给区间/定性证据；不能把“已列阈值”当“已解除”。

**新增近端问题：**“未来3个月和3–6个月，可能先确认的是缺口扩大、交付恢复、单位利润变化还是融资？谁的股价预期可能先改，哪些长期收入尚未进入当期？”

**保留反证：**原文已有悲观列和估值拥挤警告；应统一前后情景语义，不声称它完全没考虑下行。该背景负责产业约束，排序自己证明现价是否支付。

### 3. Token需求经济：保留，重点是需求质量和付费方

**回测提出的问题：**八月META+12.77%、HPE−2.53%、CRWV−1.05%是不同收入/资本回报机制，不应被同一Token增速自动同向推荐；七月META−6.08%又说明不能用八月表现永久偏向付费方。原报告已写Token不等于收入、CapEx现金回收不足，应将这些约束保留在交付摘要中。

**修改6.4、6.10和三情景：**最终付费任务、内部/免费/缓存/推理Token、成功任务成本、平台毛利、基础设施预算分开；收入不必与Token同比例。对长期回报关键的部署/付费/续费或单位经济证据给出新旧变化，缺失可以成为结论。允许需求/价格/效率出现不同方向，不强迫基准—乐观—极乐覆盖所有情况。

**修改Phase A/B：**保留独立重建来挑战旧模型；另开常规变化更新模式，明确它依赖上期、不是独立第二份证据。AI可以从ROI、用户任务、服务现金、算力小时等选择模型，不要求每次强行用FLOPs/token。

**拟写入条款：**“分别说明AI消费方和供应方的净收益方向；如果投入增加但付款方自由现金暂降，判断这是高回报投资、补贴竞争还是低效扩张，证据不足时保留竞争解释。”

### 4. 头部AI芯片：保留，拆清可交付与每股捕获

**回测提出的问题：**八月MU+8.73%、NVDA+5.50%、TSM+4.97%、AMKR−6.01%并存。产能/芯片受益链相同，不表示毛利、资本开支、客户预付款和股东捕获相同；不能用该短窗证明具体架构胜败。

**修改第一/二章及产业链展开：**清单作为搜索起点，保留原第12类开放入口；区分晶圆产出、封装良品、整架可交付、客户验收、可计费能力；美元估值明确芯片绑定价值不等公司收入。输出真正约束未来两个季度交付的单位资源及路线替代，不再对所有关联零部件重做完整行业市场规模。

**拟写入条款：**“对当前不足以精确估ASP的自研芯片，允许物理资源和成本区间，不冒称外售收入。交付增加是否转为普通股现金，交给使用该结论的投资研究单独论证；产品尚无收入不能写成公司尚无收入。”

### 5. 数据中心建设：保留，补可兑现项目和时间选择

**回测提出的问题：**八月BE+24.26%、EME−5.63%、CMI−6.85%、POWL−8.73%同属电力/交付主题。高质量积压订单、长交期、最便宜价格，各自都未保证这12天最佳回报。原稿已区分排队与投产、发票与CapEx，下一版需要让项目阶段限制到达排序/专项，而不是增加一句泛化风险。

**修改第三/四/七章：**关键项目用可复用身份，分已公告/融资/许可/供电/采购/交付/验收；以同一项目串起付款方和供应商，不加总七家backlog为七份终端需求。转化概率与资金约束可推断，但注明估算条件。项目层的收入、利润、回款时间分开。

**修改八/九章：**给出哪些3/6个月公告或验证会改变远期价值，瓶颈缓解时受益者可能更换；允许低壁垒交付商有经营杠杆，也允许高壁垒设备因已计价而无近端机会。美国/全球范围不能混算；常规更新只重估变化或争议显著部分，保留AI重新建模权限。

**这五份都不建议删除。**目前能证明的是下游股价/选择高度分化，不能证明五类知识问题没有价值。整理掉重复重建和模糊的公司推荐责任；新增一个“被下游采用/拒绝及理由”的轻量记录，使以后可以检验究竟是背景没发现、传递丢失，还是投资判断拒绝后错过。
