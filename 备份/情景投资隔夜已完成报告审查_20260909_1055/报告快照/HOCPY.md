# HOCPY：经营情景、价值传导与分期限投资决策

研究日期：2026-09-09。指定证券：HOYA Corporation 美国 OTC ADR **HOCPY**；东京普通股 **7741**。本报告为独立研究，正式输出仅此一份。

## 一、当前选择、主要分歧与研究时点

**当前主要判断：短期不建议投资，中期不建议投资；长期在年化约12%的参考标准下也不建议投资。原因是支持正常增长的证据比支持价值跃迁的证据强，而现价已要求相当持久的高利润和资本回报。不是判断公司将衰败，也不是由四行情景投票得出。** 相同经营下，采用较低资本成本、要求约8%年化的复利投资者，可以得到“谨慎参与”的条件结论；但这个选择依赖持续性与风险补偿，尚不能由一次季度增长裁决。

### 2.3 四项决定性分歧及独立裁决

**EUV：当前增长与永久稀缺分开。** Q1 LSI固定汇率增长18%、管理层EUV约20%的判断，以及缺陷改善支持较强近端增长。但AGC 2026-06-02讲稿印刷页16明确已在2nm、D1D及相移产品量产，2024年EUV销售达到40十亿日元，随后回落再恢复；问答印刷页36谈及客户组合扩展。于是本报告接受“HOYA高等级资格有经济护城河”，拒绝“没有有效供给竞争”。FY28新厂初期42，替换旧FAQ约50的规划口径，不相加；它是分阶段投资，尚不是全部合格能力。[AGC原始讲稿](https://www.agc.com/en/ir/library/bizbriefing/pdf/2026_0602esemiconductor_transcript.pdf)

截至本次截止，又核到Intel/ASML 9月7–8日新披露：超过一百万片累计处理量包括认证、研发和部分量产，当前6英寸掩模、拼接及未来6×12英寸生态分别推进。这强化High-NA工程路径，未公开指定HOYA供应份额。若某些设计由多张掩模减少为一张，高规格溢价必须补偿数量下降；数量减少20%需要净价提高25%才打平，不是机械新增20%收入。大尺寸新格式可能需要新设备和资格，不能免费复用全部当前产线。[Intel原文，事件日期9月7日，IR分发9月8日](https://www.intel.com/content/www/us/en/newsroom/news/intel-foundry/intel-foundry-asml-accelerate-industry-readiness-for-high-na-euv.html)

**HDD：玻璃渗透上升与外购份额下降可以同时成立。** 东芝M12公告为2026-03-31开始送样，11片玻璃、30–34TB SMR及后续CMR计划，证明非HAMR也有玻璃采用理由，未证明HOYA拿到全部订单。砂拉越2026-05-20议会记录PDF第29页称WD承诺再投资RM1.8bn玻璃基板厂；这是承诺、不是产线已合格，也不是HOYA的义务或担保。[东芝规格与阶段](https://www.toshiba-storage.com/wp/wp-content/uploads/2026/03/TSH223_TEE_M12-Series_EN.pdf)、[州议会原始记录](https://duns.sarawak.gov.my/web/attachment/show/?docid=U2NEenFPVkRtWjZsdE9KYUpCU05jUT09OjpC6zeTqcRg_tukkO5KEXw9)

正常路径例：近线EB×1.22、TB/片×1.12、玻璃渗透因子×1.09、HOYA份额因子×0.995、净价×0.99，合成约1.17。普通不及预期例：需求仍增长，却因自制合格/ASP与密度改善，使HOYA净捕获低10%。公司约100%玻璃子市场份额不等于100%全近线基板份额；当前约40%近线份额为公司估计。老挝12条线空间仅4条运营，余8条设备分步安装；不能把现有设备利用率当成33%，也不能把集团能力乘三。突破路径需要玻璃渗透约70%–80%、外供份额仍强、新厂快速合格和单位价不被竞争侵蚀，且EB增长、TB/片增长与资本投入相容。

**近视管理：临床优势尚不能跳过家庭预算和制造商分成。** iQ 196名完成者的一年结果来自香港4–12岁样本，年龄子组效果不同，后续持续效果、当地审批和真实依从性仍待验证。FDA对Stellest的2025年授权说明美国通路可达，同时已有竞争。参考付费副数而非全部近视儿童；渠道零售价还包含服务、保险、镜架和替换承诺，不能全部成为HOYA收入。本报告现有业务正常增长不依赖美国收入；新增区域/iQ净增量另按状态树建模。[iQ临床原始公告](https://www.hoyavision.com/about-hoya/hoya-vision-care-news/news/arvo-miyosmart-iq-12-month-clinical-evidence-hoya-vision-care-press-release/)、[FDA竞争产品授权](https://www.fda.gov/news-events/press-announcements/fda-authorizes-marketing-first-eyeglass-lenses-slow-progression-pediatric-myopia)

### 4.3 主估值与投资理念

主矩阵三期限均使用“有持续竞争优势、需要更新资本的经营现金价值”，短期侧重价格/预期差，中期侧重兑现，长期侧重复利；估值公式不换工具。估值在**各目标日**折现其后十年显式期内剩余现金，目标日前现金只通过余额和分配出现一次。显式预测统一止于2036-09-09，所以三年退出仍拥有Y4–Y10及后续现金；没有把长期价值按时间比例缩成半年价格。

主工作参数为日元名义折现率8%、稳定增长2.5%、稳定新增ROIC18%。主区间对基准/乐观/突破使用(9%,2%,16%)至(7.5%,3%,22%)，悲观为(9%,1.5%,13%)至(7.5%,2.5%,18%)。这是条件价值不确定性，非四行发生概率；悲观较低成熟增长/ROIC反映受损经营生命周期。股份融资不存在显著断点，因此公司资本成本近似权益成本；经营中的失败概率已经入现金，不再次提高折现率来扣同一风险。

这些区间的机制：高等级材料需跨代更新、现金创造虽强但客户集中与竞争有周期性；十年后仍可迭代，而当前增长和利润不能永久维持。终值=Y10税后经营收益×(1+g)×(1−g/ROIC)/(r−g)，再折现到目标日。增长再投资显式扣除，未把全部成熟利润当作可分配现金。有限产品/结构受损在悲观及较弱尾部表达；平台复用在较高ROIC、较持久增长表达，未做工具结果的简单平均。

另保留可辩护的低资本成本平台解释：r=6.5%、g=3%、ROIC22%，基准经营和资本均不变。它支持6/12/36个月价值约172/177/196美元，而r=7%、其他不变约151/155/173美元。这使长期建议对资本成本非常敏感：这是对公司现金权益所需市场风险补偿的不同估计，不能由一次财报解决；投资者8%或12%的持有要求另外比较，不因个人偏好改写公司经营或自动改变折现率。主范围未悄悄吸纳这个高端值；在当前选择中单独评价它。

用盈利倍数检查同一现金权益：基准三年目标后NTM的税后经营收益约331，现金价值中枢对应经营价值/税后经营收益约19倍；若直接用30倍，实际上增加了持续成长或降低风险补偿，不能叫作同一经营口径的独立验证。资产安全边际论点不足：必要运营现金和其他权益调整后净资产仅为市值很小一部分，不能把全部账面现金当作买价保护。

## 五、条件建议矩阵与十二格明细

## 六、当前行动、敏感性和等待代价

### 6.1 普通不及预期及独立成功参照

### 6.3 当前分歧的行动比较

不用四行整体概率：构造一个**仅用于门槛的两分支实验**——未形成核心跃迁时按基准三年财富约136美元，形成所定义核心突破时约219美元。覆盖不到主悲观、并购和未知新机会，故不是整股真实分布。在这个偏有利的二分实验中，8%年化所需突破权重约65%，12%约91%；20%要求即使100%成功也不足。当前证据有资格和需求增长，却没有足够证据将“核心突破”支持到接近九成；加入受损分支只会提高该门槛。**所以高风险理念不能仅凭最高值为现价参与辩护。** 不需要捏造精确成功概率，也能否决“只需很小概率的新机会就划算”的说法。

主标准下，在经营不变时按工作值倒算的买价约：6个月107、12个月107、36个月97美元；按主范围较弱端约89、88、81。相同公司并不因期限越长就自动值得付更高买价：在当前模型下，一部分早期增长已进入今天价值，而12%复利要求超过基准现金价值滚动速度。这些边界必须随经营重估；股价跌到100同时丧失EUV资格，不能沿用正常底稿宣称便宜。

### 6.4 等待并没有被自动证明更优

以2026-10-30财报作为最早观察，距研究日约51天，现金年化4%使每1美元变约1.0056。固定原目标日2027-03-09或2029-09-09，等待后不重新获得完整6个月或3年。下表首先比较立即买入并持有与等待后选择买入的策略差异；若双方均允许根据公开信息调整，立即买入者也能在财报后退出，但仍承担公告跳空。没有逐状态的跳空/执行概率，不能声称已定量证明这一扩展策略的优劣。下面成交价仅为算例范围，来源是当前151.12附近的重估幅度，非订单簿/一致预测。

   row={'p':p,'states':state}

def model(s,override=None,ordinary=False):

  rev=sum(rr)+oo['rev'];op=coreop-hq-hils+oo['op'];tax=.25*op

  if s=='乐观':da*=1.08
  if s=='突破':da*=1.16
  da+=oo['da']
  lastopp=(sum(opp[o][y-1]['rev'] for o in opp) if y else 0)

  cap=(basecap[y] if y<5 else basecap[-1]*(1.035**(y-4)))+oo['cap']

  # operating-cash reserve is 180 throughout; subsequent cash requirements included in working capital.

  div=divps*shares/1000
  newshares=shares-buy*1000/buyprice+.20

  result.append(dict(y=y+1,products=rr,margins=mar,coreop=coreop,hq=hq,hils=hils,opp=oo,rev=rev,op=op,tax=tax,da=da,nw=nw,cap=cap,lease=lease,cfo=cfo,fcf=fcf,divps=divps,div=div,buy=buy,buyprice=buyprice,shares_start=shares,shares=newshares,cash_start=cash,cash=cashnew))
  cash=cashnew;shares=newshares;lastrev=rev

# valuation uses identical cash rights across horizons, no method switch.
def val(m,t,r=.08,g=.025,roic=.18):

 for a in ys:

 # Terminal reinvestment = g/ROIC; post-lease cash NOPAT removes lease cash already not in cost through exact CF adjustment.
 last=ys[-1];terminal_nopat=last['op']*.75
