**重要理念分歧。** 现金安全边际论点目前不成立：融资后的现金有用途，偿债、权益购买与营运资本不创造免费价值。周期盈利交易的最强正面解释，是实际订单继续超指引、市场愿意提前按更高前瞻盈利定价；该逻辑可能赚钱，但本研究不能把这种成交价等同现金价值。长期平台复利的分歧集中在客户资格能否跨代复用、投入后ROIC能否维持，以及增长到2030年代后如何衰减；不能仅用更低折现率裁决。800V、欧洲联合设计、航天和dataMate扩张分别建模，并保留单一成功实验。

## 二、公司全貌、共用事实与决定性经营假设

### 2.1 从客户预算到Bel收入

Bel出售电源转换、保护、磁性及连接硬件，通常向OEM、ODM和分销商按产品/订单收费。它不是按GPU价格、AI调用量或军费总额抽成的公司。Enercon、Cinch、Bel Power Solutions、磁性产品和dataMate的需求机制有交叉，采购、认证和成本却不同。2026年重组后的ADRS与ITDS是管理口径，不能用两个分部取代产品经济性。

## 三、四条连续经营路径、早期机会与资本底稿

### 3.1 路径定义及为什么采用这一组工作值

**悲观/受损**是可以持续数年的经营失速，不是破产假设：数据客户提前采购结束、渠道补库停止、旧架构受替代、材料和工程费用不能及时缩减。ADRS仍有保有项目，现金缓冲仍在，普通股却可能因原价支付了过多增长而严重亏损。公司缩减可选设备和外部投入，保留质量、研发与客户资格，不能免费、即时裁掉所有成本。

**基准/正常兑现**采用当前证据最支持的解释：既有数据项目延续、军工交付和报价传导、航空缓慢恢复；不需要一份未披露800V大合同。2026全年收入825；2027核心907、早期净期望约1.9，合计约909；EBIT约173。相对公司上游915/180的工作算例，本研究单列失败前研发与机会状态，费用和贡献更透明，因此没有直接继承其最终预测。可辩护的近端区间仍约880–960，工作点不冒称P50。

**乐观/超预期**需要已有客户之外的项目接力、欧洲交付顺畅、航空停止拖累，2027两核心分部520/505。利润率改善伴随更高工程、销售和周转支出，未把全部增量毛利留给股东。高可靠产品获取溢价，但大客户采购和供给增加使2030年代利润率逐步回落。

**突破/非线性**的最少核心条件是：数据供电进入多个连续代际、军工电源与连接形成可重复的联合设计、工程与测试能力随规模增长。2027核心1070，2029核心1560，2031核心2060。这里的核心包含当下在售产品系列跨代更新；H专门计原有普通更新以外的800V净增，不再重复计一次“平台价值”。突破行假定更强工程入口和销售协同，**未假定所有早期机会商业规模成功**；商业状态仍按行内概率推进。航天或单对线失败不必否定整个突破行。证据支持强度：悲观中、基准中、乐观中低、突破低；这些标签不是发生概率。

### 3.5 概率生成方式及相关性

没有找到适用于Bel这些小类项目、公开且可重复验证的设计赢单转量产统计基础率。因此采用机制约束的主观转移区间。成熟既有业务不乘成功概率。U→P的基准年度转移E/H/S/X为40%/23%/27%/30%，P→S为32%/28%/24%/25%；欧洲资格和现成客户入口使E更快，800V需要新架构验证且竞争者领先披露使H更慢。U→F为6%/10%/10%/8%，P→F为7%/12%/10%/10%；S每年继续面对4%/6%/6%/5%的退出和4%/8%/7%/6%的退化。概率不是从价格、区间中点或愿望反算。

四情景因资源与采用环境不同，U→P和P→S乘0.65/1/1.3/1.6，失败转移乘1.35/1/0.8/0.65；保持每行剩余概率在原状态，逐年总和100%。S→P不变，防止好情景把技术更新风险完全抹去。H在2028年前不能进入P，2029年前不能进入S；E/S/X最早2027进入P、2028进入S，X的2027 S金额虽然定义存在，其主路径S概率仍为0。所有起点为2026年末U，已有存量收入在核心，主行不会凭空把首次成功提前。

合理主观敏感区间以成功转移倍率0.8–1.2、失败倍率1.2–0.8重算全路径，不把每年概率各自独立选端点。较高概率需客户采购、重复批次及单位经济证据；仅有发布和参展不支持提高至接近100%。较低概率也不应抹除已有工程、客户和产品基础。E/H/S/X不同进度保留，不因共享公司名字而使用同一个状态。

本模型各机会边际分布已经分别限制工程和销售速度；现金线性相加没有额外“相关性折扣”。如果共同资源争夺导致条件收入下降，应改状态金额与转移，不能仅乘相关系数。主路径所有现金为正，未出现必须融资的断点；第六节另检查联合失败投入的流动性。年度完整概率、收入、利润、CapEx、周转与现金见附件A；2032–2036继续递推，不把未成功项目在第五年自动成功。

### 4.3 投资论点和相容估值

**现金安全边际**：回报应来自可归属现金及便宜经营资产。六月现金减当前少数权益、养老金后约184，按B类等效已发行股数约12.8美元/股；若再留80运营现金缓冲，仅约7.3美元。现金不是清算收益估计，库存、无形资产不按账面全额变现。面对247.76，资产保护很薄，该理念当前拒绝。

**经营兑现与长期复利**：回报来自利润、现金积累和持续的增量回报。主工具为各目标日剩余FCFF折现；先扣全部研发、费用、CapEx和周转，再加一次实际留存现金。用相同工具跨三期限，可把价格采纳和现金价值分开。基准现金路径、继续更新能力和逐渐下降的ROIC不足以支持现价，当前拒绝。

**周期/里程碑交易**：回报可早于完全商业化，但需要市场在退出前采纳盈利或资格新证据。按当前约19.7倍NTM EBIT的经济报价，给六个月NTM基准177.8一个17–22倍的交易倍数算例，资本桥后可得到约225–286/B股，约-9%至+15%交易回报；这一倍数范围是围绕现价隐含水平的价格敏感性，**不是可验证的一致预期或本研究的合理价值区间**。它与DCF138–174不相容之处，意味着买方继续支付更长增长、更高资本回报或更低风险补偿；不能平均成一个更舒服的目标价。现阶段没有证据证明有利倍数会在短期占优，当前不建立交易头寸。

**高风险平台/突破**：回报来自跨代数据电源及军工组合规模化，可能有长期非线性。目标日前早期机会仍采用状态权重；已有资格里程碑不能对其后客户扩量免检。主行突破价格290–375，三年相对247.76有条件正收益，但10%持有要求位于区间内部，远期经营价值占比高。它是值得验证的论点，尚不是当前投资优势。

### 4.4 DCF参数、资本桥和剩余价值

正常、乐观、突破均采用9%–11%美元经营折现率；受损采用10%–12%，额外1%只反映未已计入收入/费用的集中经营和估值风险，取消/失速本身已进现金，不再乘一遍失败率。工作比较锚为正常/乐观/突破10%；受损区间直接报告。2026-09-08美国3个月国债约3.94%、10年约4.80%，可用作名义美元时间价值参照；4%左右现金机会成本与9%–11%经营折现之间的差额，是系统性和估计风险补偿的研究选择，并非精确CAPM测量。来源：[美国财政部当日收益率曲线](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?field_tdr_date_value=2026&type=daily_treasury_yield_curve)。

目标日剩余现金按季度重叠天数切分，剩余季度中点折现；目标日前部分进入现金。主表假设季度内经营现金均匀，实际大客户结款或收购付款不均匀，作为时间误差保留。买断用固定模型日期单独处理。现金利息税后、SBC稀释、分红、少数分配、购买款均只有一个入口。

```text
季度FCFF = EBIT × (1−22%) + D&A − 全部CapEx − Δ经营营运资本
目标日EV = Σ目标日以后季度剩余FCFF的现值 + 2037以后剩余经营价值现值
稳定核心FCFF_2037 = NOPAT_2036 × (1+g) × (1−g/增量ROIC)
稳定核心终值 = 稳定核心FCFF_2037 / (r−g)
机会剩余价值 = 各机会2036仍存续状态的现金，按各自剩余年限及衰减逐期折现
股权价值 = EV + 目标日现金 − 债务 − 未支付权益/earnout − 养老金
BELFB等效分母 = 完全稀释总股数 − 2.115263/21
BELFB每股价值 = 股权价值 / BELFB等效分母
总回报 = (每股价值 + 期间现金分红 − 247.76) / 247.76
年化 = (1+总回报)^(365.25/实际持有天数) − 1
```

未来分红按年0.28均匀近似，六个月/一年/三年约0.139/0.280/0.840；不再投资。中长期同时给累计及年化。交易费、买卖价差和个人税未计，本模型以1美元上下的微小优势不构成可执行结论。

### 4.5 重要的持久平台替代解释

同一乐观路径内，最有力的相反解释是：军工与电源客户关系不断复用，升级费用与客户流失较少，2037后仍能以约20%增量ROIC、3.5%名义增长持续；已确认跨代项目使未进入现金的风险补偿降低，经营折现8.5%–9.5%。这不是只改估值名字：更长的客户持续性要求保留工程队伍、相容再投资并证明更新后的回报。模型保持2027–2031乐观经营和资本，2032后按新的持续性衔接，不重新挑选近端利润。

主模型更有证据的原因是：公司已展示恢复与资格，并未展示整个集团的平台锁定；标准电源/磁性竞争真实、ADRS毛利并非只升、历史相邻研发有失败。替代解释没有被否定，未来客户定点、净价和更新投入数据可能支持它。**不可判定的是平台利润能延续多久、以什么增量回报，而不是当季收入是否增长。** 当前以此分歧为依据拒绝稳健参与，但不声称所有长期高风险理念都被排除。

### 4.6 反向要求与价值传导最弱处

现价所需的经营组合不是唯一解。以B类经济股权报价约3,553、六月资本桥后的EV3,368为起点：

- 若经营EV按17–22倍NTM EBIT交易，需约153–198 EBIT，基准171落在其中；这说明**当下前瞻倍数可解释价格**，不证明这些倍数由长期现金支持。
- 按现金安全/复利的目标日DCF，基准三年价值中心189.4，而10%年化要求退出含分红约329.9，价值缺口约140美元/股。差额不能由剩余20%买断或少量分红填上。
- 单独改变折现率9%–11%，基准三年仍只有173–210；单独提高四项机会的成功转移，仍只有约171–213。真正分歧在核心规模、利润持续性和回报质量，不能用一个局部成功概率掩盖。
- 突破行三年10%折现工作值326.7，累计32.2%、年化9.74%，接近但略低于10%持有要求；机会概率不变时，约2.3美元/股价值变化即可翻转门槛。这种边界比合理估计误差窄得多，不适合包装成精确正面结论。
- 用20%左右税后经营利润/收入关系作数量级检验，三年再多取得100百万经营价值约增加6.9/B股；要弥合基准140美元缺口需约2,050额外经营价值，绝非一项几十百万新收入即可补齐。

税率与利润率作用不同：2027基准每少1个百分点集团毛利率约减少9.1 EBIT，而正常税率22%变25%约减少5.2年度税后经营利润；均需沿现金和资本桥重算，不能只在EPS下随意加一项“风险折价”。

## 五、条件投资矩阵及十二格明细

### 5.1 先固定投资标准

用户未指定个人损失承受能力，以下是研究参考标准：短期以可见盈利/预期差为主，6个月要求约8%累计回报（邻近6%–12%）；中期以兑现和现金为主，12个月要求12%（邻近10%–15%）；长期以持续复利为主，三年要求10%年化、约33.1%累计（邻近8%–12%年化，对应26.0%–40.5%）。承受普通波动不等于容忍没有机制依据的永久损失；在这些理念下，估计优势应明显超过报价、股数和现金时点误差。高风险突破另以15%年化、能够承受约50%以上损失作参考，不要求所有失败路径盈利，但仍要求可信成功幅度与发生程度相配。

## 六、当前取舍、独立成功、普通偏差与等待代价

### 6.1 单项完整成功实验：新业务成功不等于全公司达到突破价值

突破行边际条件则脆弱：10%折现工作值326.66，达到10%年化持有要求需要约329.0退出价（另有0.84分红），差约2.3。把长期现金风险补偿从10%下调少量，或把某一持续经营现金贡献提高数百万，就可能由中性转谨慎；反之核心毛利少1个百分点，三年区间降至约275–356。两种风险补偿都可辩护时，不能以高端375单独给出建议投资。

### 6.3 现金、融资与损失形状

四条主行及单一成功实验在各季度均未出现现金归零，主要风险是价格支付过多、持续性判断错误和资本配置，不是当前债务即刻违约。仍应检查不在平均路径中的联合支出：

- 以突破2027-03-09约241现金为基点，若共同工程失败额外消耗80、营运资本比表内多80、原剩余权益价格再高40，同期现金仍约41；低于本研究80运营缓冲，需约39融资或缩减可选投入。借款增加39并不是股权损失39，因为取得现金，同时要扣未来利息与可能失去的项目NPV。
- 若此时额度、出口规则或客户资格阻碍融资，需以低价发行或处置资产。以150美元融资39约新增0.26百万股，必须连同实际保留现金及替代利息重算，不能把融资额同时当损失、债务和稀释三扣。上述压力条件不是已发生事实，也不是主矩阵的隐含融资。
- 不得把S/X/E各自失败造成的费用再无条件乘全公司失败率；主模型已记状态退出费用。上述200的联合冲击是**表内以外**的流动性上界实验，不再叠入主格。

可恢复延后和永久损伤的区分尤其重要：若客户一季晚提货，库存可释放、收入可追回，主要损失是延迟和额外资金；若永久失去设计位置，就要同时降低多期利润及剩余价值。受损行的60%以上价值下行主要来自后者与原价增长溢价，不是现金资产在某一天消失。

### 6.4 为什么当前不参与，以及高风险论点卡在哪里

当前最有依据的经营解释是基准附近，并允许普通失速与更快增长。去收购后增长、直销交付、积压和制造资格均支持恢复；航空分化、库存占用、下一代资格未确认和竞争供给限制长期外推。纯悲观不是最支持的预测；当前不买也不需要主张悲观最可能。

对稳健持有标准，基准、普通失速、较快机会转化都支持同方向：合理现金价值不足。对乐观/平台标准，证据尚未支持把整个核心经营升格为跨代锁定；最有力的反方已经作为持久平台路径算出，三年315–366，可以在8%或部分10%–12%要求下有吸引力。当前的取舍是保持验证，不把该解释当已证实事实。这是价值和证据不足，不能泛称“因风险大所以永远不适合买”。

对高风险突破，以15%年化需要三年含分红约376.8，已经接近或超过主突破上端。即便降低要求至10%，也不能由机会存在推出应付现价：H的完整成功而普通核心不变最高约222；若拿突破上端375作成功收益，另一条普通结果按210计算，要达到约329.9的10%要求，简单两点实验需成功权重约73%。这个数字只用于揭示要求，**不是全股真实概率、不是给四行强行赋权**；它把普通与突破压缩，遗漏中间、极端上行和灾难路径，不能直接生成期望回报。现有证据支持局部产品进入，无法支持“有七成把握同时达到该集团规模、持续性和低风险补偿”这一强主张。

还有一种相反选择是承认长期价值较低，但相信短期市场将再次按高倍数交易。本报告对其不作确定价格预测：过去一年大涨、近期回落和财报后先涨再回落说明价格弹性，不提供下一次方向。没有日期与口径可靠的一致预期，也没有独立能说明共识错到哪一步的客户证据，当前无法辨认该交易优势。其结论是“当前尚未建立优势”，不是“股价不可能上涨”。

### 6.5 等待比较：同一资金、同一目标日、相同后续信息

选最早有一定辨别力的观察——Q3及Q4指引，在2026-12-09前作一次决策更新；两策略终点均为2027-09-09。初始资金247.76，等待资金以3.94%年化计，91天后约250.16，一年约257.51。立即买入者也允许在12月用相同信息卖出或继续持有，不能用“永远不许卖”的不对称策略证明等待更好。

信息结果需要落到具体内容：支持结果指直销多个项目继续增长、毛利传导、应收周转改善；反对结果指排程削减、库存持续上升和毛利低于39%；模糊结果指销售达到指引、backlog仍高而现金问题未解。支持结果仍不能证明三年平台持续性。

### 6.6 下次更新应最先改哪些参数

1. 先更新已实现季度、实际完全稀释股数、Enercon最终对价及完成日；解除网站旧资本结构冲突。
2. 用直销客户/平台续批、取消或延期、真实净价与毛利更新核心A/B；只有backlog增量而无现金不自动提高持续性。
3. 每个新机会只在自身技术/客户门槛被跨过时调整状态转移与条件金额。已获工程资格不能直接设置商业成功100%。
4. 将库存、DSO、CapEx和研发与收入同步更新；若经营改善同时使剩余股权更贵，先通过资本桥。
5. 最后才更新目标日价值、交易采纳范围与投资标准下选择。价格变化本身不反向改变独立经营预测。

逐状态费用和现金公式（百万美元）：

```text
概率向量起点 [U,P,S,F] = [1,0,0,0]
U' = U*(1-up-uf)
P' = U*up + P*(1-ps-pf) + S*sp
S' = P*ps + S*(1-sf-sp)
F' = F + U*uf + P*pf + S*sf

状态净收入 = 状态毛收入*(1-蚕食比例)
U EBIT = -年度验证/研发；F当年持续EBIT = 0
P/S EBIT = 毛收入*自身EBIT率 - 毛收入*蚕食比例*旧业务20% EBIT率
另外一次退出费用 = (F'-F)*年度验证/研发
U CapEx = 验证/研发*30%；P/S CapEx = 毛收入*各机会CapEx率
D&A = 当年状态CapEx*40% （简化资产批次近似）
期末周转 = 净收入*各机会周转率
FCFF = EBIT*(1-22%) + D&A - CapEx - 本年周转增加
```
