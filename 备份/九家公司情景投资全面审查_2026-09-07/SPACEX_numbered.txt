4: 
5: **三个月判断：不建议在147.95美元新增投资；六个月判断：不建议投资，正常经营兑现不足以补偿当前定价。**Starlink已经有真实且增长的利润，AI外售算力也已有真实客户；问题在于当前价格为集团支付的长期经营结果，远高于这些证据正常兑现所支持的现金回报。报告没有假设成长性投入全部无效，也没有把Starship、Grok或Cursor成功当成无成本收益。

9: 最弱传导环节是**新增AI与下一代系统投入能否形成持续高资本回报，并最终归属每股权益**。真实需求→收入已部分验证；收入→扣除设备更新、持续研发和扩张后的现金，以及成功→原股东每股价值，证据明显较弱。6月底净现金仅约占当前基础股权市值3%，无法给当前买价提供厚实资产保护，但它足以显著降低未来六个月立即被迫融资的风险。

61: ### 2.2 上游判断的冲突及取舍
62: 
63: **航天行业总量不能直接作为公司收入上限。**L2将2027全球低轨运营收入估为17—26B，而L1的公司Connectivity基准约23.8B，已经接近其全行业高端；L2的2030全行业26—46B又低于L1公司上端55B。两份模型虽均含终端和部分任务，政府/军用项目覆盖仍不完全可比，且L2缺少足以逐项抵销的底表。不能同时声称两套预测均已校准。
64: 
65: 本报告优先使用已披露公司Consumer/E&G分项、服务线量价、具名采购与执行能力，自下而上保留2027公司Connectivity约20—28B的基准范围；**将行业17—26B作为需求偏弱/覆盖较窄的反证边界，而不是再强压公司数字至行业中点**。如果最终同口径全行业确实只有17—20B，且竞品仍取得可见收入，则公司的15M以上平均线和E&G路径至少一项落空，须下移经营行。没有为了估值接近147.95美元而上调公司捕获。
66: 
67: L3独立算力市场与SpaceX出售给模型公司的收入层基本相符，但供应商转售可能重复；2027年16B要求保留大客户并新增买方，不能用行业45—75B取一个市场份额乘数再加一份合同收入。L4采用终端应用净对价，Cursor财务收入可能含按成本转付模型费，故不能用Cursor收入÷应用行业规模计算精确份额。L5提供的是预算与竞争背景，不是对X增长的背书。

346: 主DCF与成熟NOPAT倍数边界分歧最大的原因是：倍数法较早给已达产NOPAT一笔完整存续价值；逐期DCF还扣除后续增长资本并限制终值增长。两者给出数倍不同EV时，报告不声称它们相互精确验证；保留外包络主要是避免用一种长周期假设制造确定性。即使允许较高的倍数边界，基准仍显著低于买价。

348: ### 7.2 交叉验证与分歧处理
349: 
350: 第二口径为**A5成熟经营NOPAT退出倍数边界**：悲观12—16B、基准25—43B、乐观50—80B、突破75—120B；这些数与第四节成熟利润范围和现金扣再投资口径衔接。用市场列的12—40倍区间折回目标日，并保留A1—A5逐期FCFF。退出倍数是研究敏感性假设，不是未取得的同业交易均值。
351: 
352: 该边界不把所有净利润可分配化；退出倍数隐含的再投资和延续增长需要接受主DCF的完整现金约束。因此它是价值边界/反证工具，**不是和DCF平权投票**。二十格同时列其EV范围。若退出倍数上端比主DCF更高，最终报告保留较宽上端并降低置信度，不简单平均；若它较低，说明主DCF依赖更长增长久期，同样必须保留该分歧。
353: 
354: 维持性经营现金收益与成长净现值的勾稽为：每年`FCFF＝经营现金收益（扣维持资本）−成长投入−其他必需投资`；把逐年的成长净现金贡献和现有经营分开求PV后，和主DCF相等。没有另加Starship/轨道AI/Cursor“期权价值”，也未将60B收购价当作资产回收底价。当前/NTM销售倍数只用于逆向约束，不能承担主估值。

364: ### 7.3 六个月研究要求回报及价格边界纪律
365: 
366: **六个月要求回报固定15%**，二十格一致。短期美元无风险收益约2%量级，其余为承担本公司经营估计误差、资本配置与永久损失尾部所需安全边际；不再按某市场列重复提高门槛。WACC已处理各市场资本成本，15%不是同一利差的第二次精确计量，而是投资选择需留出的价值误差余量。三个月如需正面投资要求约8%价值安全边际，但不把六个月事件风险线性折半。
367: 
368: 强烈建议需价值低端超过买价至少约20%，方法方向一致且资本风险无否决；建议需两种适用口径中部支持15%、低端损失约不超过10%；谨慎建议允许低端损失约25%，但两口径的中部须支持15%且有明确改善/折价修复机制。只有高端好看、低端损失超过50%的格子不标正面。中性表示价值接近买价或合理跨零而无清晰不对称；多数方法达不到门槛为不建议；价值区间绝大部分显著低于买价、或资本路径有严重损失，为强烈不建议。
369: 
370: 价格距离另使用可复算的保守边界：`P正面上限=min(主DCF中部/1.15，交叉口径中部/1.15，最终价值低端/0.75)`，并要求对应经营行成立、资本风险没有额外否决。这是固定经营条件下的最高研究买价，不是无条件挂单价，也不是把三个指标加权为分数。若实际融资/清偿风险未解决，该价格只能为候选边界，不能自动升级建议。

484: 3. **Starship连续可用部署→V3真实容量→可安装客户/地区准入→收费→更新后现金**。同一个工程前置条件支撑Mobile、政府和宽带，三条收入可按不同客户收费，但工程成功概率和投资不能重复相加。

556: ### 最小可复算模型
557: 
558: 以下代码与表内参数一致，读取的只是本报告模型常量；不调用其他公司估值、评分或价格结果。年期、单位、端点与交叉边界处理均公开。正文中的价格距离和矩阵由同一常量计算。
559: 
560: ```python
561: P0 = 147.95
562: # each row: FCFF low/high A1..A5; A6..A10 growth low/high;
563: # terminal g low/high; shares high/low; net assets low/high; A5 NOPAT low/high
564: ROWS = {
565:     "悲观": ([-42,-5,2,6,10], [-22,0,6,10,15], .02,.04,.02,.025,14.80,14.10,10,26,12,16),
566:     "基准": ([-48,-18,-5,8,18], [-28,-4,10,20,30], .08,.12,.03,.035,14.65,14.20,12,30,25,43),
567:     "乐观": ([-55,-5,15,30,45], [-33,5,25,45,65], .10,.15,.035,.04,14.90,14.35,12,32,50,80),
568:     "突破": ([-55,-5,15,35,55], [-27,10,35,60,85], .12,.18,.035,.04,15.40,14.60,6,28,75,120),
569: }
570: # market: WACC low/high; exit EV/NOPAT low/high
571: MARKETS = {
572:     "宽基风险扩张": (.09,.11,22,35),
573:     "窄幅/主题主导上涨": (.085,.105,25,40),
574:     "震荡/均值回归": (.105,.125,18,28),
575:     "有序风险收缩": (.125,.15,14,22),
576:     "流动性/信用压力": (.16,.20,10,16),
577: }
578: def pv(values,r):
579:     return sum(x/(1+r)**(i+1) for i,x in enumerate(values))
580: def dcf(values,h,g,r):
581:     a=values+[values[-1]*(1+h)**i for i in range(1,6)]
582:     tv=a[-1]*(1+g)/(r-g)/(1+r)**10
583:     return pv(a,r)+tv, tv
584: 
585: def cell(row,market):
586:     a,b,h,j,g,t,nh,nl,cl,ch,el,eh=ROWS[row]
587:     rl,rh,ml,mh=MARKETS[market]
588:     dl,tl=dcf(a,h,g,rh); dh,th=dcf(b,j,t,rl)
589:     xl=pv(a,rh)+el*ml/(1+rh)**5
590:     xh=pv(b,rl)+eh*mh/(1+rl)**5
591:     # Retain both methods' boundaries, without averaging.
592:     evl=min(dl,xl); evh=max(dh,xh)
593:     eql=max(0,evl+cl); eqh=max(0,evh+ch)
594:     pl=eql/nh; ph=eqh/nl
595:     dp=((dl+cl)/nh+(dh+ch)/nl)/2
596:     xp=((xl+cl)/nh+(xh+ch)/nl)/2
597:     buy=min(dp/1.15,xp/1.15,pl/.75)
598:     return dict(dcf=(dl,dh),cross=(xl,xh),ev=(evl,evh),eq=(eql,eqh),
599:                 price=(pl,ph),ret=(pl/P0-1,ph/P0-1),buy=buy,
600:                 terminal_fraction=(tl/dl,th/dh))
601: 
602: for row in ROWS:
603:     for market in MARKETS:
604:         print(row, market, cell(row, market))
605: ```
