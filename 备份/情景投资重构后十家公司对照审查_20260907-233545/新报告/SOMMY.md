> 研究日期：2026-09-07；信息截止：2026-09-07 22:40 PDT（2026-09-08 05:40 UTC）。目标证券：Sumitomo Chemical Company, Limited，东京4005／美国OTC SOMMY。金额除明确标注外均为**十亿日元**，股数为**十亿股日本普通股**，证券价值为**美元／ADR**。1 ADR＝5股普通股。研究独立构造模型；F＝已披露事实，M＝管理层指引／目标，E＝本研究推断或情景假设，U＝未解决信息。

## 1. 当前选择、研究时点与最重要的分歧

### 1.1 三个期限的实际研究判断

**以20.00美元／ADR作为统一买价，短期、中期、长期均为“中性／等待”；现金回报理念下目前不支持直接买入，接受利润重估和转型风险的投资者存在有条件参与理由。** 这不是认为新材料或制药没有价值，而是当前价格已要求一部分转型利益穿过投入、少数权益和现金环节。四行情景不设总体概率，不把条件矩阵中正面格数解释为胜率。

**当前最有依据的路径是正常经营修复，但现金证据比利润证据弱。** 本研究FY2026核心经营利润工作值236，高于5月旧指引215，原因是8月披露的上半年改善；这不是官方上调后的全年数，也不是统计P50。到FY2028核心业务利润282、扣行内早期机会净费用后约266，归母约121、可归属估值现金约27。主判断并不需要次世代EUV、Enzomenib、AMCHEPRY和玻璃JV全部成功。

最有力的相反选择是：通过经常利润资本化，认为未来成长投入会形成可出售、可分配的资产价值，且材料与药品推动资本效率改善，因而愿意提前买入。基准12个月NTM归母约104，11—15倍利润可对应22.9—31.2美元，明显高于现金模型。**这项分歧会改变投资选择，不能简单平均。** 本报告以扣除全部投入的现金路径为主，是因为最新季经营现金仅5.0、融资改善含少数股东出资、集团有大量有息债和担保；目前没有足够证据证明现有投入很快降至维持水平。利润重估理念若接受这种未决问题，可形成“谨慎建议投资”的个人条件选择，不能冒充稳健现金结论。

## 2. 公司全貌与决定性事实

### 2.1 经营与价值捕获

住友化学不是纯半导体材料公司。农化、ICT、药品和基础材料有不同的客户预算、收费权与现金模式；集团共同拥有合成、纯化、配方、质量和工业化能力，却不能把一个领域的需求直接搬到另一领域。

### 3.4 年度概率模型：定义、相容性和不重复扣风险

以下概率均是**条件于该经营行和当前信息的主观工作分布**。没有适配这些项目的可复核统计基础率，不能称药物行业平均成功率或公司真实胜率。每年U／P／S／F互斥并合计100%：U仍开发／资格未形成可确认收入；P有限收费或供货；S进入可重复商业路径、受当年爬坡上限约束；F该项目退出。S不是提前实现最终峰值规模。失败吸收，不能无条件复活；S仍可被替代而退出。

起点FY26剩余期间的已知小规模业务与研发已在核心，不另做彩票加值。FY27开始建立10年分布。基本转移率依次为U→P、P→S、U或P→F、S→F：

| 情景 | U→P | P→S | U/P→F | S→F |
|---|---:|---:|---:|---:|
| 悲观 | 12% | 10% | 18% | 10% |
| 基准 | 23% | 22% | 10% | 5% |
| 乐观 | 35% | 35% | 6% | 2.5% |
| 突破 | 38% | 42% | 5% | 2% |

### 3.5 年度集团与现金底稿

以下全部预测均为E。核心利润→IFRS的重组／非经常净费用G（FY26—30）：悲观40／25／15／10／10，基准30／18／12／10／10，乐观及突破25／15／10／8／8；新一轮资产转让收益不预先填入。净融资费用J：悲观22／27／29／30／30、基准20／21／22／22／22、乐观20／21／22／22／22、突破20／22／25／26／26。未来债券赎回重设和备用借款成本已进入J，不能再对同一利息扣一次估值折价。

归母利润公式为：`核心归母NI＝(核心利润−G−J)×72%−max(制药核心利润−4,0)×72%×54.2%−4`；最后的4是其他子公司少数权益费用工作值。再加四机会已按归属调整的净利润。制药内部净融资费用分配4、税率28%、其他少数权益4均有不确定性，不是财报披露点值。普通股报酬保留费用且给予小额稀释缓冲；公司当前季度稀释EPS与基本EPS相同，不虚设大额期权池。

归属估值现金使用直接股权现金法（FCFE），不是企业自由现金流：
`核心FCFE＝核心归母NI＋D×91.87%−C×95.664%−W×83.74%−租赁本金×92%−未汇回权益法利润调整−项目支持现金`，再加四机会归属现金。
其中D、C、W是基础折旧摊销、全部基础现金CapEx、营运资本及其他经营现金净占用。系数来自假设制药分别占15%折旧、8%资本投入、30%周转，并扣54.2%少数归属；不是将全部子公司现金视为可以即时上划。各子公司的真实资金限制未完整拆出，±20现金的敏感性重点覆盖此误差。

W还包含不具持续价值的其他经营现金使用，不能把它理解成纯应收加库存减应付。集团报告CFO用利润、全部折旧、集团W及未汇回权益法利润回算；这是未来报告现金流的预测，**不是已经披露的现金结果**。集团CFO减现金CapEx再减租赁，与股东可得FCFE的差距主要为少数归属、额外JV出资和支持现金。G机会按权益法并入，股权出资列投资而不是集团固定资产购置。模型暂假设成熟JV净利润可转成分配、早期追加资金同步扣除；没有确定分配条款时该假设须下降或推迟。

### 4.3 方法选择与时间一致性

主方法为**目标日直接股权现金DCF**，目标日后的全部归属FCFE折现至该目标日，再加研究日前后未重复计入的归属净现金桥。它适合本公司的混合并表、权益法和资本投入问题，并非所有非金融公司都必须改用直接股权法。所有净利息和租赁现金已经进入FCFE；不再从该股权现值减整个集团债务。

工作折现率／终值增长分别：悲观12.25%／0%，基准10.5%／1.5%，乐观10%／2%，突破10.25%／2%。区间折现率依次13%—11.5%、11.5%—9.5%、11%—9%、11.5%—9%，再与160—140日元／美元成对展示。工作值来自事前给定的资金与商业风险判断，不取估值上下限中点。它们是研究要求回报参数，不冒称已拟合的市场WACC；采用直接股权现金故用股权折现率。

独立投资门槛：6个月至少10%总回报、12个月15%、36个月45%累计，分别补偿本证券流动性、结构修复与远期执行风险；这些门槛与折现率职责不同，不是把同一项目失败重复乘概率。主格评级还要求对误差和资金需求有解释，不因高端跨线就自动推荐。

终值截至FY2036后仍保留经营，`TV＝FY2036归属FCFE×(1+g)/(r−g)`，折现到每一目标日。FY31—36已对既有药品每年−3%侵蚀并保留持续研发；终值仍需新平台补足组合、未来维护与成长成本按FCFE比例增长。它不是“所有药品永续独占”，也不是“公司只剩三年现金”。取消该替代能力或将终值增长降至0是重要反证。基准目标日剩余现金现值约48%—58%来自终值，乐观／突破约50%—62%；远期依赖使估值置信度保持低。悲观6个月终值占比超过100%，由于此前有负现金，不能把这个比率当价值确定性。

公式：
```text
每个未来季度的目标日现值
 = 该季FCFE × 目标日之后剩余天数/该季天数
   ÷ (1+r)^(剩余部分中点距目标日的年数)
基础股权经营现金价值 = 各季现值 + 终值现值
目标日股权价值 = 基础股权经营现金价值
               + (归属现金 - 160)
               - 新增净借款
# 原债务已在净利息与融资延续假设中；原现金160支持经营，不再加回
每股普通股价值 = 股权价值 / 完全稀释普通股数
每ADR价值 = 每股普通股价值 × 5 / USDJPY
总回报 = (每ADR价值 + 期间每ADR现金分红 - 20) / 20
```

分红假设为2026年12月、2027年6月等每半年8日元，税费前、无再投资，后三年共48日元；悲观停止分红。主表年化为终值等价`(1+总回报)^(1/持有年数)−1`，未给提前收到的分红计利息，非逐日XIRR。ADR存托费、投资者税率和买卖价差未计；若两次交易及累计费用1%，总回报约再减1个百分点，不能将薄边界当精确买点。

## 6. 当前决策边界、敏感性与等待的价值

### 6.1 最影响选择的边界是现金转换

当前信息支持基准附近的利润修复，对现金改善支持较弱；没有可靠证据给四行精确概率。主方法三个期限等待，候选价格带约13—15美元，其含义是**保持当前模型经营与资金假设**时才值得重启买入分析；若股价因药品现金恶化、信用受损或EUV失标下跌，须先下修价值，不能把14美元自动当买点。

完整成功参照另外计算：假设Q在FY28、Z/G在FY29、I在FY30进入S态，此前保留P态有限收入、研发与75%项目资本支出，随后保留S态全部成本和追加投入；核心仍为基准。仅I成功的三年工作值约19.49美元，仅Q成功约20.83美元，四项均沿该成功路径约22.74美元。四项全成功不是主格，也没有被当成当前最可能路径；这一额外上行参照允许高风险理念评估同时成功的价值和必要证据，而不取消前期成本。I远期100以上规模需约2,000例以上净付费治疗／年，G贡献归属净利润10需JV净利润29.4、15%净利率下约196收入。它们是门槛，不是当前订单或患者计划。没有新证据，三年后不自动将概率设成100%。

### 6.3 稳健与高风险理念的选择，以及等待代价

- **现在按20参与：** 能先获得11月新指引、临床或材料资格好消息的重估；乐观／突破条件下有较大潜在回报。代价是基准现金路径回报不足，普通现金不及预期已经能造成明显损失；OTC可执行价和价差还可能使实际成本更高。
- **等待经营确认：** 最早有价值的是半年报把现金占用、返利和转让收益分开，随后FY26年报和FY27Q1确认重复回款。若只确认基准利润、股价已经涨到24，买入后的基准三年现金回报反而约−15%；“确认”不能替代重新估价。
- **等待更低价格：** 在基准经营不变、14美元买入时，三年工作总回报约45.2%，接近门槛；若每年额外占用20的普通下修同时发生，三年含分红回报仅约6.3%，等待的价格优势大幅消失。价格和证据必须一起更新。
- **接受技术期权：** 可以对未被当前现金模型充分覆盖的平台、许可或大规模扩量持不同看法；需说明额外归属现金、投资和验证门槛。单凭“长期空间巨大”或完整成功上限，不足形成公司整体精确胜率。

需要把当前判断从等待改为正面的最小证据组合，不要求所有新技术成功：①至少两次披露支持药品净销售增长与返利／应收回收相容；②先进材料量／组合增长超过显示侵蚀，利用率使利润增量转成现金；③资本开支和支持预算没有持续上调，或可持续归属现金提升约30—40／年。若三者形成相容路径，可在股价尚未完全支付时改判；如果仅第一项收入好看、第二和第三持续消耗资金，则继续等待。

最强反证是：集团从石化资本消耗转向药品与电子材料后，仍无法提高股东现金回报——美国产品的净价／返利和研发恢复吞掉处方增长，ICT的显示降价和资格开支吞掉新材料增长，Rabigh继续吸收现金。最强正面反证是相反的真实现金结果：已投入的材料和农化渠道平台无需同量级追加资本就扩量，药品正常收费足以资助下一代产品，减少担保与低回报资产后产生持续可分配现金。本报告保留这条转向乐观的更新空间。

### 7.4 季度和机会计算规则

FY27之后基础收入季度权重（Q1—Q4）：农化0.20/0.23/0.25/0.32，ICT均0.25，先进医疗0.17/0.20/0.25/0.38，EGM均0.25，制药0.24/0.25/0.25/0.26，其他同制药。基础核心利润：农化0.13/0.21/0.26/0.40，ICT均0.25，先进医疗0.10/0.15/0.30/0.45，EGM均0.25，制药0.20/0.22/0.27/0.31，其他均0.25。增量机会收入／经营贡献按四季等分作近似，若验证事件集中年末需重新分配，不能无理由提前确认。

归母年度利润权重0.20/0.24/0.25/0.31，CFO为0.10/0.20/0.25/0.45，CapEx均0.25，FCFE为0.25/0.20/0.20/0.35，G为0.10/0.20/0.30/0.40。FY26Q1固定实际（FCFE为统一估计−25），Q2—Q4分配`(全年−Q1)×该季权重/(1−Q1权重)`。这保证各四季合计全年，季内按日线性是对付款时点未知的近似；分红则按已述半年支付点累计。

概率递推与状态内现金可按如下短代码复核；具体逐年P/S收入已经列于3.4，不需要猜客户销量。Q/Z/I/G的独立转移和不同股权归属按名称映射，不能按相邻列位置相乘：

```python
# U=未形成收费, P=有限商业, S=可重复商业爬坡, F=退出
# a=U->P, b=P->S, f=U/P->F, h=S->F；F为吸收态
def step(prob, a, b, f, h):
    u, p, s, x = prob
    nxt = (u*(1-a-f),
           u*a + p*(1-b-f),
           p*b + s*(1-h),
           x + (u+p)*f + s*h)
    assert min(nxt) >= -1e-12 and abs(sum(nxt)-1) < 1e-10
    return nxt

def annual(prob, prev_failure, rev_p, rev_s, rd, cap,
           gm, selling, prev_revenue, ownership, glass=False):
    u, p, s, f = prob
    revenue = p*rev_p + s*rev_s
    # U/P/S各付研发，退出只按新增退出概率付一次
    cost = rd*(u+p+s) + (f-prev_failure)*rd*0.5
    operating = (gm-selling)*revenue - cost
    new_capital = cap*(0.4*u+0.75*p+s)
    working_cash = 0.15*(revenue-prev_revenue)
    if glass:
        parent_profit = operating*0.72*0.34
        parent_cash = parent_profit-(new_capital+working_cash)*0.34
        consolidated_revenue = 0
    else:
        parent_profit = operating*0.72*ownership
        parent_cash = parent_profit-(new_capital+working_cash)*ownership
        consolidated_revenue = revenue
    return consolidated_revenue, parent_profit, parent_cash
```

这段线性期望现金运算仅在各主要路径都有资金、集团税损可抵扣且股权不变时成立；悲观主公司增发及突破新增借款已经在公司资本层先计算。更严重的信用冻结不属于线性模型：若悲观150融资完全不可得，须转资产出售／违约处置，普通股可能趋近零，不能沿2—4美元条件价值对外承诺底价。若突破80债务不可得，先将相应项目延期或在实际发行价格下增加股数，再算每股，不用平均现金掩盖。
