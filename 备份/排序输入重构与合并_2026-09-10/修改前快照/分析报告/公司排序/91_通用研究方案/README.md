# 通用研究方案

这里保存跨排序方法复用的历史回测资料和 file-run 方案模板。模板使用前应复制到具体版本或具体评估日期目录，填好输入与输出路径后再运行；不要覆盖历史方案。

`scripts/sync_company_sorting_management.py` 读取根目录运行注册表和当前评估指针，同步各方法的当前结果入口、当前运行状态区块、效果摘要、效果历史以及方案状态总表的当前绑定字段。脚本不修改任何研究方案或原始排序结果。

2026-09-07起，新方案与已有结果分开登记。见[新方案使用说明](2026-09-07_新方案使用说明.md)及根目录[待运行研究方案注册表](../00_待运行研究方案注册表.csv)。未运行方案不能写进已有榜单或直接发布；历史模板保留用于复现。
