# 公司调研的职责与内容补强建议

讨论日期：2026-09-08。公司调研正式方案本次未修改。依据现行方案，以及AVGO、CRWV、PSIX、SOMMY四份2026-09-07公司报告的针对性检查；除明确标明的原文核验外，报告中的经营数字按报告内容讨论，不等于本次重新验证所有公司事实。本样本用于分析研究过程，不据此推算全部报告的缺失率。

## 1. 职责判断

公司调研应承担更深入的业务事实、机制、经营预测和资本研究。它的完成标准是：独立读者能够理解公司如何经营、凭什么获得或失去收入与利润、需要承担什么投入和义务、什么证据支持未来路径，并能够使用或挑战这些判断。

不负责股票是否便宜、哪些信息尚未定价、目标股价、买入时点、投资者要求回报、投资评级或仓位。业务本身的合理前景、项目资本回报、资金承受能力属于公司研究；买入证券能得到什么回报属于投资决策。

现方案已有十个核心研究问题，覆盖产品差异、真实客户证据、供需、合理预测范围、远期机会、资本约束与管理层。下一步以深化现有章节的研究过程为主，不能把已经要求的内容当作新缺项再追加一轮清单。

## 2. 本次检查揭示的不同问题

### AVGO：已公开事实遗漏，不能用更多压力算例补足

[公司报告第306行](D:/drive/Investment/基本面/公司调研/AI计算芯片_EDA_IP_custom_ASIC/AVGO_Broadcom_公司调研_2026-09-07.md:306)将保证上限、触发条件等列为未取得，第308行以35bn融资规模的5%、10%、20%展示潜在承担损失1.75、3.5、7bn，并明确这些比例不是事实或预测。

本次重新打开该报告已经引用的[2026年6月9日10-Q](https://www.sec.gov/Archives/edgar/data/1730168/000173016826000054/avgo-20260503.htm)，其附注11及Item 5说明：6月8日的特定安排涉及五年客户租赁义务，最大敞口29bn；敞口随设备部署增加、随客户付款减少，客户违约后可通过接管租赁或出售设备降低暴露。

29bn不是当期负债余额、预计损失或所有未来融资安排的统一上限。它应与当前已启用金额、回收率及其他安排的未知分开。这是可核验的信息遗漏，而非未来不可知。公司调研应在合同、附注、期后事项与关联公告之间完成具体主张核验；下游仍有责任对决定投资选择的字段复核。

### CRWV：已有经济机制，尚需区分可支持预测与条件边界

[公司报告第234行附近](D:/drive/Investment/基本面/公司调研/云算力_IDC_AI软件平台/CRWV_CoreWeave_公司调研_2026-09-07.md:234)以100MW为单位，假设设备部署投入3.0bn、年收入1.0bn、现金成本0.4bn；用可比资产和场地数据说明量级锚点，又明确不是已披露项目财务。报告还把六年会计折旧与实际经济寿命分开，旧设备续租的0.2—0.75bn现金贡献属于条件范围。

这些内容应保留。进一步的研究应围绕资产批次、代际、合同期限、预付款、续租净价、维修更新和同一电力的替代用途寻找证据，将主要可行范围连接到公司业务。公开资料不足可以保留宽区间；不能要求AI仅凭集团资产和一个合同个案恢复不存在的精确项目账本，也不能让下游依靠自行选择续租年限决定全部长期价值。

### PSIX：权利边界正确，进入之后的商业形态还值得研究

[公司报告第364行](D:/drive/Investment/基本面/公司调研/电力_发电_能源_储能/PSIX_Power_Solutions_International_公司调研_2026-09-07.md:364)区分潍柴的SOFC许可与PSIX尚未建立的权利，并提出系统集成、分销和服务的可能角色。基准不计入收入有明确理由，这部分不能因要求更大胆而删除。

可继续比较获得分销、集成或服务权的不同进入路径：可借用哪些现有客户与能力、需要哪些认证和投入、谁承担保修与寿命责任、公司能收取哪一层收入。经营规模要受需求、供给、收费及权利约束；资料不能支持金额时交付这些条件和边界。既不提前赋予母公司资产，也不因当前没有权利而结束所有商业研究。

### SOMMY：应推广已有的业务和权益穿透，而非统一集团比例

[公司报告第15行](D:/drive/Investment/基本面/公司调研/半导体材料_化学品_基板/SOMMY_住友化学_Sumitomo_Chemical_公司调研_2026-09-07.md:15)分别讨论药品销售、付款方组合、不同合作分成、制药子公司约45.8%的母公司权益与仍然并表的关系。[第53行](D:/drive/Investment/基本面/公司调研/半导体材料_化学品_基板/SOMMY_住友化学_Sumitomo_Chemical_公司调研_2026-09-07.md:53)计算特定合资实体的穿透权益约81.9%，又明确它不等于全部药价的归母比例。

这是高信息密度的正面例子：业务销量、客户净支付、合作分成、会计并表、法律权益和现金可调动性分别有对象，并解释它们如何连接。不能为缩短研究而退回集团收入乘统一利润率或权益比例。

## 3. 应由公司调研交付的信息及研究方式

| 研究内容 | 具体应交付什么 | 如何深化现有方案 |
|---|---|---|
| 公司业务与经济权利全貌 | 产品、客户、地区、收费方式、控股与合资关系、许可和服务责任；现金来源、成长、探索、收缩业务之间的资源关系 | 第1章先形成覆盖图；按经济驱动拆分重要产品，不按披露分部或AI标签决定粒度。权益、控制、并表和资金可用性分别研究 |
| 可比经营基线与真实商业证据 | 销量、净价、组合、客户部署、付费与复购、订单转收入、利润转现金；每项的对象、日期、期间与来源 | 第2、4章按业务选择指标并追踪变化，原始观察与估算并列；单个成功客户还需判断其代表性，客户名单和条件模型不能替代实际证据 |
| 技术优势与客户采用经济性 | 相对替代方案的性能、可靠性、全成本、迁移与运维成本；客户愿付价格、供应商实际捕获、技术与商业成熟阶段 | 第3、4章以真实工作负载、客户条件和采购过程检验。公司自测、独立验证、客户付费分别标明；有效产品与有效商业模式分别判断 |
| 公司供需、交付与价格传导 | 有效合格能力、项目进度、资源分配、客户预算、份额与净价格；短缺或过剩何时传入合同、利润与现金 | 第5章将行业机制落实到本公司。共享晶圆、封装、电力、工程人员或客户预算的业务联动；核对可比单位和期间，不把收入目标反推产能当独立依据 |
| 独立经营预测与偏离路径 | 较可见路径、可辩护范围、向上与向下机制、普通延期和失败的联动后果；何种证据更支持其中一侧 | 第6章以需求与交付的独立证据形成规模，再连接价格、成本和资本。管理层目标、门槛算例与研究预测分别可辨；按经营周期选择时间尺度，无须复制投资决策的四行三列 |
| 利润持续性与更新能力 | 产品衰减、专利与许可期限、跨代资格、续约与替代、更新和研发要求；有限资产与持续平台的差异 | 第3、5章提供竞争及技术依据，第8章集中将其连到现金持续性和更新投入。经营寿命不能只由折旧年限或下游终值假设决定 |
| 资产批次、合同义务与资金路径 | 已投入、新增与维持投入的完整经济周期；承诺、余额、时点、触发条件、追索和回收；融资、税、少数权益与现金调动 | 第8章按重要项目和义务穿透。利润表、现金流和资产负债表按同一经营路径连接；只对重要未知作有证据的范围，禁止用集团净现金抹去项目义务 |
| 远期业务、进入路径与重大事件 | 现有权利与未来取得方式、技术和客户门槛、部分成功与规模成功、净增收入利润、投入与失败回收、共享约束 | 第7章保留条件研究，先探索再按可能影响筛选。可用相关商业化经验约束概率或相对可信程度，不强制精细概率，更不把它直接解释成整股上涨概率 |
| 管理层、组织与动态应对 | 战略的资源分配、研发和交付组织、质量与服务能力、重要承诺及实际执行、关联交易与控制权 | 第9章以适当完整周期中的承诺、投入和结果解释执行能力。区分外部变化、合理调整与持续失约；对缩减、合作或退出研究执行条件和成本 |
| 共同冲击、反证与未知边界 | 影响多个业务的共同需求、融资、供应和监管因素；竞争解释、已排除结果及尚不能区分的部分 | 第10章将冲击接到已有业务和资金模型，不叠加泛化风险清单。保留真正不可知，并说明对方向、规模或时间的影响 |

上述并非十套新增章节。大部分已有要求，重点是明确研究在哪一步形成可使用的判断，并让同一证据、业务机制和资本关系只完整交付一次。

## 4. 让方案具有整体性的研究过程

1. **先建立公司全貌。** 识别现有业务、技术能力、客户入口、资产、权利、组织和外部变化，包括成熟业务、衰退业务与远期路线。用可能影响范围决定深入顺序，避免先按当前收入或保守算例裁掉发现空间。
2. **形成可比事实基线。** 财务表与真实商业观察按对象、期间和口径连接。对决定公司经营的合同与权利主张追到原文；历史公开经营资料可以用于周期和执行研究，旧研究结论不成为输入。
3. **围绕业务机制调查。** 从客户采用和公司交付两端交叉约束，再连接净价、成本、资本与竞争。研究者自主选择最有价值的线索，事实有冲突时先对齐经济对象。
4. **形成未来经营认识。** 较可见路径与实质不同的替代解释均有经济边界；远期机会单独给进入、部分成功、扩量和失败的条件经济性。要求完成合理推断，允许真正未知。
5. **回到集团检验。** 检查共享资源、蚕食、税、义务、资金调度和管理层反应，判断公司能否承担成功或失败。将业务层面成立但集团无法承担的路径修回模型。
6. **以少数完整推断结束。** 重要结论交付已知事实、推导机制、范围及边界、最强反证；同一模型集中一次，其他章节引用。低影响细节可简写，重要小业务和重大失败不可因没有单独披露而消失。

输出顺序可由研究者根据公司重组，不要求机械按六步或十个问题逐项填表。信息密度来自事实与解释的相互约束，不能仅用压缩字数或增加数字衡量。

## 5. 分工与独立性

| 对象 | 公司调研负责 | 情景投资决策负责 |
|---|---|---|
| 价格 | 产品或服务的净价、重定价和利润捕获 | 股票现价、隐含预期、退出定价 |
| 未来 | 公司经营范围、可见增长、超预期与失败机制 | 四种经营情景下各持有期限的价值与实际投资选择 |
| 回报 | 客户采购经济性、项目资本回报、经营现金与融资承受能力 | 买入证券的回报、投资者持有要求与风险补偿 |
| 事件 | 事件发生条件、可能时间、证据辨别力及业务后果 | 何时可能重估、等待是否值得及交易回报 |
| 不确定性 | 公司特有机制、数据边界、可辩护经营估计与条件结果 | 将经营解释和信息结果转为不同投资理念下的选择 |

公司调研保持当前输入独立性：项目内只使用相关行业正式报告，外部独立查阅公司、客户、供应商、竞争者和监管等原始资料。不新增历史公司报告、旧情景评级、排序或其他本地资料入口，也不强制沿用下游投资期限或评级标准。下游使用公司事实与推断，但仍须验证适用性、资料时效及决定其建议的关键主张。

## 6. 修改优先级与回退风险

优先在第1、2、8章加强具体权利与义务的证据核验，在第3、5、8章连贯建立生命周期，在第6、7章完善有依据的规模范围、进入路径及条件经营结果。第4章的真实商业证据和第9章的管理执行已有好要求，应深化判断用途，避免新增重复表格。第10章将反证和未知处理贯穿前面的推断，减少结尾风险清单。

需要保留的高质量内容包括：独立产品分支、客户侧证据、共同资源约束、合理数量级与预测范围、机会不进入基准仍继续研究、税与资本及权益穿透、管理层可行应对和框架外发现。不能以加强事实为由退回纯摘录，也不能以加强预测为由削减已经取得的事实。

本次情景投资方案的静态核对不证明这些信息缺口已经在实际生成中消失。公司方案修改后的有效性，应看重要主张是否找全且范围准确、经营范围是否有独立依据、生命周期和资金是否连贯，以及必要未知是否被正确保留，而非只看报告是否更长或下游建议是否更乐观。
