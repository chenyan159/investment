## 一、当前选择：经营强劲，但现价更依赖高利润的持续期

**实际研究判断：短期中性／等待，中期中性／等待；长期按稳健现金回报理念不建议以现价新买入。** 当前经营最接近“基准／正常兑现”，而非悲观。区别在于：近期收入、利润和长约具有扎实基础，但把这种基础延伸为十年以上高资本回报，仍需要续签最低价格、客户实际消耗和技术份额的证明。对高风险技术与长期紧缺投资者，本报告保留显著上行的条件路径；目前没有足够依据把其可达性转成整股精确胜率。

### 2.4 资本、治理和损伤机制

现金4.762并非全部无负担：NBM预收与押金需交货或退还。财务保证16.5不是现金，不能与TCV相加，或当全额合同保险。报告隔离2.476已收NBM时点资金，以排除借未来交货融资制造的估值现金；这不是逐合同法律负债计量。[F1][L1]

经营还受日本前道集中、合资固定成本、约0.923租赁保证和到期采购义务制约。正常履约成本已在COGS及现金投入，不把所有最低采购额再次当净债务扣除；供货中断、客户退款与降价同时发生才可能触发额外损失。WDC税务赔偿0.128另列索取权；未动用循环信贷1.5是可借额度，不是现有现金。[F1][L1]

管理层已完成技术迁移、企业资格、长约与还债，有执行证据；但FY26利润跃升不能全部归因管理能力。董事长兼CEO、合资关联关系、奖励绩效条件和周期高点回购都值得监督。股权报酬是经济成本，未来PSU最高支付数、已授权计划数量、未归属股与加权摊薄股不可全数叠加。KPMG审计支持历史报表可信度，不验证未来80%毛利。[F1][L1]

关税、出口限制、战争与通胀通过OEM预算、物流、能源、日元成本、资本补贴与贴现率进入量价、成本和r；不使用无来源宏观事件概率。交付至中国／香港不等于相同比例最终中国消费，不能把发货地域全部视为直接损失。日本停产可能同时推高行业价格，但无货可交的公司不能享受全部涨价。

5—10年还有端侧HBF、机器人本地模型、Matrix替代其他内存等机会。当前模型只覆盖上述可提出量价门槛的产品路径，不宣称覆盖所有未知发明。三年内可以确认的主要是系统性能、设计定点、量产资格、重复采购和资本预算；三年后仍需证明下一代持续领先和收费权。

### 4.3 估值主方法与参数依据

主矩阵统一使用**各目标日对其后剩余经济现金流的DCF**，所有目标日采用同一经营序列，避免短期用高倍数、长期换低倍数制造趋势。现金随经营累积一次；新机会已合并进入现金，不另加独立期权。

\[
EV_T=\sum_{q:T_q>T}\frac{FCF_{q,\text{剩余}}}{(1+r)^{(现金中点-T)/365.25}}
+\frac{TV_{2036}}{(1+r)^{(FY36末-T)/365.25}}
\]

\[
TV_{2036}=\frac{R_{2036}(1+g)\,EM_{稳态}(1-tax)(1-g/ROIC_{稳态})}{r-g}
\]

\[
Equity_T=EV_T+经济现金_T+金融资产_T-0.128,\quad
P_T=1,000\times Equity_T/FD股数_M
\]

报告窗口：主模型FY27—36季度末按91天延续，最后现金窗口结束2036年6月底附近；现金使用季中，终值使用最后季度末。终端不是另加FY36历史现金，而是FY37起剩余经营资本化。按税后收益乘(1−g/ROIC)保证终值增长需再投资。终端EM是**经过周期正常化的可持续经济经营利润率**，不是承诺FY37某一天GAAP利润率突然跳变；它替代FY36高／低周期盈利直接永续的错误，终值对正常化时间仍敏感。

同一DCF从6至36个月基准每股工作值1,543→1,618→1,928，上升主要来自经营现金、回购和折现时间缩短；三年累计回报约11%却年化仅约3.5%。周期法从6个月1,789→一年1,931→三年2,363，表明其更愿意资本化高利润。两法都不允许把三年后现金流截断；差异来自持续期和再投资承认方式，而非期限本身证明公司变好或变坏。

高风险突破理念可接受更大的尾部损失，以长期内存层级变化和公司捕获换取数倍条件价值。其最强理由是已有NBM提供融资缓冲、HBF拥有技术与生态入口；拒绝把它作为所有投资者当前建议，是因为没有可靠依据证明从当前价格所需的路径概率已经跨过门槛，且核心受损可能同时破坏新品资金和客户预算。保留理念分歧，不把四种方法做平均或多数票。

### 4.5 反向估值：便宜的前瞻PE隐藏什么要求

研究日FD股权市值269.70B，减经济现金约6.02、金融资产1.30并加0.128索取权，经营定价约262.51。若把年度经济现金近似视作稳定永续，r=11%、g=3%，需要下一年约21.0B可持续FCF；基准近期NTM22.69确实覆盖这个数，但**其核心问题是能否持续**，而非下一年是否赚得到。

保持基准逐年核心／机会路径、g3%、ROIC21%、r11%不变，只反求终端经济EBIT率：
- 支撑当前1,740美元，需要约53.7%，高于基准终端30%—40%的范围；
- 一年达到20%累计回报、目标2,088美元，需要约63.7%；
- 三年达到15%年化、目标约2,646美元，需要约69.7%。

这些只是**其余变量固定的比较门槛**，不是市场唯一共识或预测。可用更高的收入、更多现金、较低要求回报或较高持续资本效率替代；它们需要同样的证据。管理层FY28—30约75%非GAAP营业利润目标，对近期高盈利有意义，却没有直接证明FY36以后仍能维持64%—70%的经济利润率。

## 六、当前边界、敏感性、反证与等待价值

### 6.1 最接近基准的普通不及预期

不是只有“全部成功”和“严重受损”。维持基准数量、核心成本和其他条件，仅FY28起核心净价较基准低5%，一年工作价值从1,618降至约1,514；再在FY28暂时多占用WC1、FY29释放，约1,513。这个幅度远小于主悲观，但已足以消除本来很薄的参与理由。若低价同时损伤资格或需要更多资金，损失会进一步扩大。

|---|---:|---:|---|
| 原路径 | 1,618 | — | 核心、机会和资本共用底稿 |

### 6.2 早期概率与“新机会成功、核心普通”的独立贡献

主基准HBF FY31规模状态40%。有效低概率分布可取A/B/C/D＝10/15/25/50%，有效高概率分布25/30/20/25%，都合计100%；对应FY31毛收入约1.1625／2.6500，而工作1.7625。QLC基准有效低／高分布10/30/30/30与30/40/20/10，规模状态40%／70%；Matrix可取1/2/17/80与8/12/20/60，FY36规模3%／20%。不能只改变“成功概率”却不调整其余状态到100%。

完整HBF快路径在基准核心下FY31收入8B，而主概率收入1.7625；增量还需替代、成本与资本，不能把差额直接当利润。第七节提供同一现金函数，能够将权重改成A=100%复算。此组合检验保留基准核心与资本政策，不把乐观的Edge价格或更低税率一并搬入。直接复算，在基准核心保持不变、HBF采用A快扩张路径100%且完整扣成本时，一年/三年工作价值约1,808/2,167；核心改为悲观但保留同一基准规模HBF快成功，约677/820。它证明技术成功能增加价值，同时也说明仅这一条成功仍难抵销核心受损或满足现价的收益门槛。此处没有将HBF已计入的主期望价值再加一遍。

HBF有效低/工作/高分布的一年价值约1,589/1,618/1,653，三年1,891/1,928/1,971。概率变化必须通过各状态收入、支出与剩余价值，而不是给整股机械乘一个成功率。

Matrix即使完整成功发生更晚，也须支付不同工艺投入，不能将其未定权益的科研合同当作当期股东现金。

**机会与当前选择的关系：** 删去主基准HBF正现金，一年价值约少79美元；只提高部分采用概率很难单独填平一年达到2,088美元所差的约470美元。要独立改变建议，需要更快、更大、有公司净收费证据的HBF路径，或同时验证成熟业务更高持续期。QLC已经更接近商业化，近期复购对模型区分力通常高于再展示一次HBF模拟。

### 6.3 不强配四行概率，直接展示有经济意义的选择门槛

为避免伪精确整体期望收益，只比较“普通兑现／明确持续超预期／受损”三个决策分支，以各行工作价值作边界。它们是选择算例，不宣称覆盖所有可能；突破与其他中间路径仍单列保留。

一年设持续超预期权重为u、受损权重为d、其余普通，要求期望退出价值至少2,088：
`u ≥ 20.74%＋47.22%×d`。
如果d为10%—25%，则u至少约25.5%—32.5%。三年15%年化要求下：
`u ≥ 25.58%＋45.28%×d`，
对应约30.1%—36.9%。这里的d取值是敏感性条件，**不是本报告给受损情景的发生概率**。此外，满足算术期望还不自动适合不能承受六成以上损失的投资者。

八家正式NBM、企业交付和资本能力使超预期路径有可信机制；未公开的年度最低价、客户库存和续签经济性又阻止把u精确证明为某个点。没有可辩护的路径概率时，本报告不制造精确P50、胜率或CVaR。高风险投资者若有独立客户／技术证据足以支持这些门槛，可在同一报告框架形成条件正面选择；这不改变本次证据下的稳健默认判断。

状态内公式，i为机会，y从0代表FY27，k对应A/B/C/D，s为经营行：

```text
grossRevenue = pathRevenue[i,k,y] * scenarioScale[s]
netRevenue   = grossRevenue * (1 - replacement[i])
grossMargin  = (state == S ? scaleGrossMargin[i] : partialGrossMargin[i])
R&Dsupport   = state == F
               ? (previousState != F and y > 0 ? 0.06 : 0)
               : startR&D[i] * (1 + 0.07*y) + 0.07*grossRevenue
EBIT         = grossRevenue * (grossMargin - 0.78*replacement[i]) - R&Dsupport
netCapEx     = grossRevenue*capRate[i]
               + (state == U ? 0.4*startR&D[i] : state == P ? 0.08 : 0)
deltaWC      = 0.16*(grossRevenue - previousYearGrossRevenue)
FCF          = EBIT*(1-tax[s,y]) - netCapEx - deltaWC

ExpectedRevenue/EBIT/CapEx/WC/FCF = sum_k(weight[i,s,k] * corresponding value)
GroupRevenue = CoreRevenue + sum_i ExpectedNetRevenue
GroupEBIT    = CoreEBIT + sum_i ExpectedEBIT
GroupFCF     = CoreEBIT*(1-tax) + directD&A - coreNetCapEx - coreWC
               + sum_i ExpectedFCF
```
