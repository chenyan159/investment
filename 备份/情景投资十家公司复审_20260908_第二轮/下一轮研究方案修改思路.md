# 下一轮情景投资研究方案：原则、反复问题与结构修改思路

状态：仅为讨论建议，尚未修改正式研究方案或runner。依据现行方案，以及2026-09-07的97家公司审查、当晚十家公司审查和2026-09-08两次十家公司复审。不同批次样本、报价和外部检索并不完全一致，以下是过程证据和机制分析，不是严格实验得到的模型因果结论。

## 1. 最重要的判断

下一次修改应先澄清“什么算完成投资判断”，再重新分配研究动作。当前不缺章节；最难的问题甚至已经被写进4.2、6.1、7.2和9.2。继续要求“证据充分、不要保守、做出判断”容易只增加文字。

有效修改的共同特征，是定义了可检验的分析动作与边界：同目标日重算普通偏差、核心普通的单机会成功、同信息的等待比较。效果不稳定的修改，多要求某种最终品质，却没有解决证据不足时应采用什么判断规则、哪种不确定性应由哪个阶段处理。

这不是说聪明AI不能自主判断。相反，应减少重复表格的硬性工作量，让它自主寻找最有价值的解释，并明确哪些关键推断必须完成、哪些真实不确定性可以保留。

## 3. 在写方案之前需要确定的原则

### 3.1 目标是有依据的选择，不是每个情景都预测准确

提高命中率、控制永久损失和捕捉少数巨大上行不是同一个目标。稳健现金投资可以重视较坏合理结果；高风险机会投资可以容忍多数结果不理想，但要有足够可信的有利不对称与可承受的损失。低发生率不意味着低质量研究，高置信度也不等于价格合适。

建议保持多理念目标，不设置隐藏的统一保守偏好：先说明适用投资者的回报目标、持有约束和损失承受原则，再评价该理念。公司研究不需要替下游做组合配置，却必须说清哪一类选择标准使其值得或不值得。

这一步由项目先确定表达原则。不能让每次AI独立生成一个新的12%、15%或18%门槛，再把标签变化视为经营认识变化。具体公司风险仍可影响要求，但要依据同一原则展示边界，不以单个自由门槛决定全部判断。

### 3.2 四类内容必须分开：事实、未来经营、价格认识、投资偏好

事实回答已经发生或承诺什么；经营模型回答在何种机制下会赚到什么；定价分析回答到退出时市场可能知道并接受什么；投资偏好回答这个损益对某种投资目的是否合适。

同一事实可以容纳多种远期经营；相同现金路径可以因资本价格不同产生不同估值；相同损益分布可以因风险偏好不同产生不同决策。这些分歧不都能靠更多公司新闻解决。

四经营情景是经营解释的代表路径，不是所有现实的互斥概率全集。主矩阵可以继续评价条件经济价值，但不能被当作三个月后实际成交回报预测。当前行动需要额外的信息与定价判断，不能由矩阵正面格数量生成。

### 3.3 “没有辨认优势”和“值得等待”不是同一结论

未证实买入更好，并不推出等待期望收益更高；同样，未证实等待更好，也不推出必须买入。存在真实的不可判定区域。

建议区分当前不参与的三种理由：可支持价值明显不足；损益可能有利但不符合所采用风险约束；证据无法辨认优势。只有后续信息可能改变行动、且考虑价格和机会成本后有价值，才把“等待某个节点”作为具体策略。

如果最难的不确定性是十年护城河，一季财报无法解决，就不应以“等一次财报确认长期确定性”为默认出口。研究可以得到长期不可判定，同时对近期现金、价格或某个风险取向给出明确结论。

### 3.4 高风险参与需要可辩护的信念，不需要证明成功

“支持成功概率约20%—35%的依据”与“成功本身具有较高确定性”是不同命题。高风险机会可以满足前者而不满足后者。但主观区间也不能仅由研究者觉得合理产生。

可辩护信念应从接近的可比路径、已跨越的技术/商业环节、真正有区别的客户证据和资源约束出发。没有可比基础率时，可以主要判断哪些范围难以成立，不必伪造精确概率。

稳健理念可以要求在较宽合理范围下仍有优势；高风险理念不能自动沿用“所有合理下行都需通过”的规则。后者应研究可信上行与失败代价的关系，以及在哪些信念和风险要求下成立。跨过某个阈值也不是充分推荐条件，遗漏的结果、损失承受力和模型误差仍需处理。

### 3.5 研究独立性要求独立推理，不要求每次重新发明事实

报告不读旧评级是正确的。事实反复丢失应通过当前允许的一手来源核验和上游事实质量解决，不能让旧投资报告变成新研究的答案。

把重要主张与具体原文、期间和范围连接。例如“某个初始租赁安排上限29B”“当前启用额未知”“未来批次总上限未知”是三个主张，而非一个未知字段。对下游决定性字段，应验证其实际出处；列一个10-Q链接不足以完成验证。

上游事实缺失属于资料层问题，下游有责任针对性补查，但研究方案无法保证每次生成都找齐所有原始事实。审查侧应保留历史事实回归检查，研究执行侧仍保持独立。

### 3.6 长期价值首先是经营持续性问题，不是估值参数问题

平台利润能延续多久，应由客户续用、跨代资格、竞争进入、替换成本、定价权及持续研发/更新投资推导。不能先假设前十年现金，再在DCF末尾选择一个合意g和ROIC。

建议将主要利润池的成熟化、衰减、可更新能力及管理层资本应对作为经营路径的一部分。估值阶段主要负责将这些经济权益转换成目标日价值。仍无法裁决的持续期应保持为实质模型分歧，不能通过挑选一个主模型隐藏。

研发或扩产可以创造选择权，管理层也可能停止低回报投资、改合作或出售业务。应按执行能力、合同限制和退出代价考虑，既不假设管理层永久机械投资，也不把及时纠错当作免费的完美管理。

### 3.7 投资独立判断不等于必须压缩成唯一答案

如果当前资料能明确支持一种解释，应明确采用；如果几种解释都可辩护，不应制造主次确定性。此时可以对不同投资偏好给不同选择，或者明确无法辨认优势。

真正应排除的是“尚不能裁决，但仍用一个任意工作点给出强结论”。不是排除所有等待、拒绝或分歧结论。模型重跑不必产生完全相同目标价；决定性事实、经济边界和行动依赖关系应更稳定。

## 4. 建议的新研究过程：先广泛探索，再围绕决定性分歧深入

### 第一阶段：完整理解公司，先保护发现机会的广度

沿现有业务、客户、技术能力、外部需求和潜在权利探索增长：不仅是新增产品收入，还包括原有产品提价、份额跃迁、资本效率改善、竞争优势延长及商业模式改变。

初步筛查必须用合理可能范围，而非当前保守工作点。一个尚未建好的机会在小规模假设下价值很小，不能据此停止研究。若连进入路径和有意义的上界都未建立，应写为覆盖不足，而非已证明不重要。

### 第二阶段：决定性问题先核实证据，再建立大模型

对于最影响选择的争议，先区分两种解释共同能解释的事实和真正支持某一侧的事实。比如短缺论与结构提价论都能解释当季高毛利，单靠它不能裁决十年持续性；更有区分力的是跨周期合同、扩产和客户替代经济性。

形成关键主张到具体证据的对应，尤其是会大幅改变现金或股数的合同、担保、采购、少数权益和证券条款。遇到未知先检验未知来自哪里，不直接给压力参数替代。

随后形成工作范围及有依据的替代范围。短期可识别范围窄、远期宽是正常的。各变量按经济关系联动，不能将所有保守端点相乘后叫正常兑现。

### 第三阶段：从这些经营解释构造四条路径

把量价、单位成本、资本投入和成熟化组成连续路径。四行差异应来自具体约束解除或损伤，不能只是增长率大小。

对模型选择不明确的关键持续期或资本回报，保持可见替代路径；不扩展成更多一级情景或复制全部表格。主模型只是计算锚点，不能拥有默认的证据优先权。

### 第四阶段：各期限研究不同信息，而非仅移动估值日期

对每个决定性争议问：目标日前能出现什么观察；相反解释也会不会产生这个观察；即使观察支持经营，市场是否可能已经付了价格；确认后哪种选择仍有剩余回报。

只有影响当前行动的最早观察需要做详细等待比较。不能为十个公司都机械设置三个月观察。未获得市场共识点值时，可以通过原始指引、历史同类事件和反向条件约束市场解释，但不能把反向假设写成真实共识。

### 第五阶段：估值、反求和行动在同一比较上完成

先用独立经营路径估值，再反求当前价格和持有要求的边界，比较双方可信范围。需要时返回决定性证据，而非继续堆低影响的概率小数。

按所采用的投资标准形成：有依据参与、证据支持拒绝、适合等待特定信息、或当前不可辨认优势。风险取向变化时分别呈现，不降低持有要求来让某种解释自动胜出。

### 第六阶段：检查研究链，而不是重复阅读结论

第一条链：决定性事实→原文范围→经营假设。第二条链：经营/概率→现金/资本/股数→目标价值→回报与标签。用有经济含义的变动检查结论是否按预期响应，允许管理应对或投入导致非单调结果，但需要解释。

低影响分支用数量级即可；主张会改变评级的扰动须走完结果。附录负责复算，正文用于证据、分歧和选择，不再每节重复相同现金纪律。

## 6. 哪些问题适合prompt，哪些不能指望prompt单独解决

| 问题 | 方案可做到 | 方案不能保证 |
|---|---|---|
| 字段/日期/条件定义冲突 | 明确唯一职责和语义，减少内部矛盾 | 所有生成零差错 |
| 普通偏差与成功实验不公平 | 定义保持与改变的对象，要求重要分支重算 | 所有复杂模型自动无误 |
| 已公开关键事实遗漏 | 对决定性主张查到具体段落、核对范围 | 替代完整事实资料层及持续事实维护 |
| 对未来概率缺可靠数据 | 给有依据主观范围、限制结论、分析决定性证据 | 制造不存在的经验样本或不可得客户合同 |
| 基准/长期寿命漂移 | 约束经济机制、保留真实模型分歧和行动边界 | 从同一有限信息推出唯一正确未来 |
| 评级门槛不同 | 使用项目先确定的评价原则，呈现门槛敏感性 | 猜测用户未定义的风险偏好 |
| 预测是否真的更好 | 输出可检验论点、可观察变化和失败条件 | 通过一次同日报告审查证明未来超额收益 |

## 7. 从迭代经验推导出的修改和验证方式

1. 先确定上面的判断原则，再按职责一次协调修改；不把个案改成“AVGO必须找29B”“MU采用较低HBM”的指令。事实检查样例属于审查侧，研究仍独立。
2. 保留已经有效的经济内容：产品拆分、客户权利、逐年机会现金、目标日资本桥、单项完整成功、普通偏差、公平等待。调整的是它们的顺序和用途，不为了缩短删除。
3. 对关键反复问题做少量同方案重复研究，观察事实与经济边界是否稳定；不能把两次不同版本唯一一次差异都归因于prompt。先用AVGO检验事实和主次模型，MU检验物理冲突，SNDK检验概率与持续期，ET检验不同理念和真实正面机会。
4. 审查侧固定比较时点、输入与报价，分开价格、数据、经营、估值、投资门槛的影响；保持原始研究的独立输入边界，不让旧评级进入新研究，也不为一次验证改runner。
5. 验收看是否完成关键推断：29B特定上限不退回未知；不同HBM资源口径不能同时偷用；HBF局部概率不能当整股突破概率；ET不能因新增风险清单被无理由改成全部等待；持续期未能裁决时不藏成唯一工作点。
6. 判断不确定性收敛与报告完整性分开。更少NA、更高信心、更多正面格、更多代码都不自动是成功；合理的结果可以是明确指出资料无法区分的边界，并保留可执行的条件研究。

未来收益验证另需按当时可得信息和原期限评估，不以事后结果倒改原始事实或把价格上涨等同所有论点正确。本次不设计新runner流程、自动化或研究输入接口。
