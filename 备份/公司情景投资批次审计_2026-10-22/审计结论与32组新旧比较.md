## 4. 最需要警惕的是估值假设变化

当前方案新增正常化倍数、悲观现金/资产底、目标日DCF字段，并明确DCF不是交易价的机械上限，证据等级只评价核心经营假设。新旧版本评价标准发生变化，本身就会改变目标价和证据标签。

252家有可计算基准价的公司中（剔除ATKR）：

| 指标 | 数量/中位数 |
|---|---:|
| 基准交易目标区间中点高于DCF区间中点 | 245/252 |
| 目标价中点超过DCF中点1.5倍 | 111/252 |
| 超过2倍 | 17/252 |
| 目标价中点/DCF中点的中位数 | 1.465倍 |
| 基准交易目标相对参考价涨幅中位数 | +42.3% |
| 按各自目标日换算的基准目标年化价格变化中位数 | +11.5%，不含股息 |
| 基准目标中点高于参考价 | 222/252 |
| 基准目标中点较参考价高超过100% | 30/252 |

以上是报告模型统计，不是预测实际收益。目标日跨2028—2032等不同期限，不能把区间涨幅直接当同一期收益。报告的DCF也主要是**未来目标日剩余价值**，不是今天的内在价值；未来DCF与今天参考价的比值中位数仅1.017，不能直接称“今天安全边际1.7%”。

高于DCF本身不构成错误；关键是这个差额到底依赖什么：更长增长期、更高利润率、较低资本成本、未证实资源或退出倍数。新版一些报告对此讲得很好，但“解释了条件”仍不等于“条件已被事实锁定”。

基准经营证据新版253家为强146、中103、弱4。旧版245份摘要机器提取为强4、中237、弱4；32个人工配对样本为旧强1/中30/弱1，新强19/中13。旧新总样本数不同且标签合同变化，不能把这一分布理解成经营确定性普遍大幅跃升，更不能把strong当目标价兑现概率。

三个特别有代表性的比较：

- NVDA：收入预测1,009→883.4十亿美元、DCF约349→321.95美元，交易目标359—452→541.44—657.86。经营下调而目标上调，主要需要解释定价与期限，不能称财务事实改善。
- ANET：收入24.3→22.61、DCF156.5→138.2，目标171.8—211.92→246.1—285.2。新版正常化业务价更合理，但更高交易价仍依赖长增长期。
- ETN：NOPAT8.08→8.06、FCFE6.04→5.84十亿美元，目标366—467→525.9—610。融资解释更好与目标价更积极可以同时存在。

反向例子也存在：PWR、NBIS、CRWV的目标价下调；CRWD即使经营证据升强，仍保持当前价不适合新买的判断。因此不能把全批描述成机械看多。
