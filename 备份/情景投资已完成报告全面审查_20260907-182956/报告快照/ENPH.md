# ENPH：经营情景、价值传导与分期限投资决策

## 1. 当前判断、研究时点与价格口径

**以 36.37 美元买入，现金收益与安全边际理念下，短期、中期、长期均不建议投资；里程碑交易理念下，短期保持中性 / 等待。** 这不是认定股价会跌至本报告的基准价值，而是当前最能支持的住宅业务温和恢复，加上尚未确定的新业务，无法提供足够的持续每股现金。若把 ENPH 视为未来中压电力平台，突破路径确有较大条件上行，不能因它尚非当前主路径而删除；但目前证据不足以证明该路径的可达性足以补偿现价。

**主要预期差：** 市场快照给出约 16 倍 forward PE，看上去不贵；问题在于预测对应期与调整口径未注明，持续股权报酬不是免费，微逆制造税抵也不是永久利润。2028 年还需偿还 5.75 亿美元债务。另一方面，IQ SST 已有功能验证，按零价值处理同样不合理。本报告将其概率加权收入、研发、扩产、周转及失败成本逐年并入四行情景，估值到 2036 年并保留此后的经营价值。

**关键限制：** 没有取得按产品披露的实际净价 / 毛利、完整安全港取消条款、可比终端安装序列及具名 SST 付费合同。主矩阵是条件合理价值回报，不能视为价格预测或胜率。尤其基准估值与市场价差很大，主要反映股权报酬、补贴持续期和远期盈利假设的分歧，必须与第 4、6 节的替代计算一起阅读。

### 2.3 上游输入如何进入模型，哪些冲突仍保留

1. **住宅经济：** 25D 对 2025 年末后支出的终止提高住户自购成本，TPO 转换有融资、安装和渠道摩擦；见[IRS 原始 FAQ](https://www.irs.gov/newsroom/faqs-for-modification-of-sections-25c-25d-25e-30c-30d-45l-45w-and-179d-under-public-law-119-21-139-stat-72-july-4-2025-commonly-known-as-the-one-big-beautiful-bill-obbb)。因此基准 2027 微逆 5.8 百万台、住宅电池 700MWh；后者接近 2025 已有交付量，未假设总体屋顶装机立即恢复到高峰。
2. **需求反证：** [Sunrun Q2](https://investors.sunrun.com/news-events/press-releases/detail/378/sunrun-reports-second-quarter-2026-financial-results)储能附着率 74%，但安装 332MWh 同比 -15%、订阅新增同比 -31%；[SolarEdge Q2](https://investors.solaredge.com/news-releases/news-release-details/solaredge-announces-second-quarter-2026-financial-results)收入 346.2、同比 +19.6%。不能将 ENPH 弱势全部归于行业，也不能由电池附着率推 ENPH 出货增长。欧洲 / 商业产品差异是另一解释，本模型保留恢复但不保证份额。
3. **政策双向传导：** 美国制造可支持资格及抵免，材料援助规则可能提高电芯 / 元件成本；[IRS Notice 2026-15](https://www.irs.gov/pub/irs-drop/n-26-15.pdf)和[FCC DA 26-870](https://docs.fcc.gov/public/attachments/DA-26-870A1.pdf)不支持“所有外国现有逆变器立即禁用”。基准有合格美国生产占比 82%，不是无限保护溢价；抵免从 2030 年每年减少 25%，2033 为零。后期无补贴毛利提高必须来自降本和产品组合。
4. **行业报告冲突：** 本地 SST 行业报告给 2030 SST 前端采购基准约 1,978、上界 5,400，但边界含系统功能且用 2026 不变美元。公司研究用 ENPH 硬件 100—250 美元 / kW。本文不把它们直接相除做精确份额：2030 SST 收入基准期望约 61、突破约 595；仅作预算数量级约束。若公司可得净价只有 100 而非 175，每 GW 收入减少约 43%，见第 6 节替代计算。
5. **架构冲突：** ENPH 材料中 342 模块 ×4kW＝1.368MW，与另一页 2.5MW 机架不闭合；可能是不同版本 / 并联组或规格未同步。本文以验收 GW 建模，不使用不相容参数推 BOM。OCP 规范和 NVIDIA 800V 路线证明接口需求，不证明 ENPH 必然中标；[NVIDIA 8 月路线](https://blogs.nvidia.com/blog/800-vdc-power-architecture-ai-factory/)明确允许保留既有 AC 上游。

SST 客户经济的关键边界：100MW、平均负载 75%、替代链效率 96% 与新链 98.5% 时，年节电约 17.37GWh；0.06—0.12 美元 / kWh、8% 折现五年，节费现值约 42—83 美元 / IT kW。若旧链已有 98%，只约 8—16 美元 / kW。完整硬件价还包含被替代设备价值，但“效率较高”本身支持不了无限溢价。上游报告的 UPS / 电池内容只用于功率、能量及系统责任边界，未把数据中心电池 TAM 加入住宅业务。

### 3.4 早期机会：联合状态、概率衔接与不重复折价

需要正式概率模型的两组机会是 **IQ SST** 与 **C80 / 双向充电的分布式新品组合**。G5 是现有电池换代，进入各行量价 / 毛利；Care 有商业服务基础且价值小，进入其他收入，不为它制造独立高估值概率表。家庭 AI、VPP、Kestrel 对外芯片收费均未证实独立收费权；现有降本 / 获客收益在核心经营中，额外新收费路径保留待验证，未悄悄认定绝无价值。

状态统一为 D＝待资格 / 延期（零商业收入），P＝有限 / 部分成功，S＝规模商业成功，F＝失败 / 退出。是**当年仍在商业状态**的概率，不是当年首次成功概率，也不是截至当年曾成功概率。失败为吸收态；P 可扩至 S 或退出，S 可退化至 P / 退出。下表给出每年互斥且合计 100% 的有效分布。概率由技术成熟、客户资格、采购节奏、产品替代及资金要求约束，是主观工作值，未冒称行业统计基础率或经过校准的胜率。

### 4.2 方法选择及两类真实理念分歧

主矩阵选择 **目标日剩余现金流 DCF**，原因是 ENPH 的利润被制造税抵、前置采购、持续 SBC 和早期投入明显影响，静态盈利倍数不足以表达持续期。短期用它回答“买入价格有没有价值余量”，另用调整后盈利与里程碑定价回答“市场可能交易到哪里”；二者不等同。中期以四季度经营与资产负债表验证，长期纳入 2030 税抵退坡及 2036 以后成长。

### 4.3 中期、长期与现价反向估值

中期关键是收入增长能否穿过折价、税抵收现、周转和 SBC：基准 2027 调整 EBIT约 211、报告 FCF约 174，却只剩很少可持续经济 FCF；如果四季度终端转化、G5降本和客户信用同时改善，才应上移至乐观路径。不是将短期与长期目标价平均。

长期关键是 **2030—2033 制造税抵退出，与 SST 刚开始消耗扩量资本的时间重叠**。公司可以因技术成功增长，却尚不能形成足够现金回报；反过来，如果 SST成为可重复交付的平台，三年退出价值包含三年后更多经营，不能只给2029营收乘倍数。

当前基础市值 131.80×36.37＝约 4,793.6；减 362.7 净现金，经营价值约 4,430.9；经济稀释起点 133.1 对应约 4,840.8 股权、4,478.1 经营价值。TTM收入约1,328.5，基础EV/收入约3.34倍。快照 TTM PE36.01、forward PE15.99、EV/EBITDA23.37 的口径并不等同主模型，尤其 TTM含退款且 forward期间未知。

## 5. 四行三列条件矩阵与十二格明细

### 5.1 门槛与评级原则

主矩阵短期采用现金价值 / 事件确认相结合，6 个月要求总回报约 **15%**；中期经营兑现要求 **18%**；长期持续现金要求 **12%年化，即三年40.5%累计**。这些按高波动硬件、关键经营信息稀缺及可替代投资设定的风险补偿工作门槛适用于全部四行，非预测收益；不为跨过门槛选择有利区间端点。高风险技术理念另要求约20%年化 / 三年72.8%，且须有可辩护成功概率。低端不是固定适用于所有人的最大可承受损失。

这些门槛用于比较同一路径的回报、验证时点与等待价值，不额外从现金流扣一笔同名风险罚分。局部失败已通过机会概率及投入计入；情景是否值得投资与“当前哪行情景更可信”分开。突破的条件评级没有因当前证据弱而机械压低，但其短期兑现仍受信息采纳时点约束。情景证据强度见3.1，与下表估值置信度无关，也不等于四行发生概率。

**所有主格均含本行情景内 SST、C80 / 双向机会的概率加权贡献。** 突破已假定关键系统技术演示兑现，之后客户采购 / 扩量仍有随机分支。主格不是四行情景整体加权，不代表实际预期收益；完整成功另列。主区间是固定经营路径的 r/g 敏感范围，不是统计置信区间。

## 6. 当前路径、分期限价格边界、概率敏感性与最强反证

### 6.1 当前最接近基准，不能用四行情景投票

**最能改变判断的组合是“SST重大成功，而原有业务只是基准”。** 新机会的价值不能被住宅低增长直接抹去；但基准规模的SST即使完全成功，仍未必补得上现价要求。完整突破与原业务普通的三年值约 **56.38**，失败路径约 **13.78**。以这两个互斥联合分支作简化门槛，达到12%年化需要完整突破分支权重约 **87.6%**；20%年化技术期权门槛需要约 **115.2%**。这些是反求门槛，**不是研究估计的真实成功率**，也不是3.4条件局部概率；中间规模、延迟与非二元结果会改变门槛。没有用局部P/S概率替代四行情景发生概率。

净价降到100美元的算例仍保持毛利率，实际上已经允许同步降本，是对竞争风险较温和的测试。若BOM不降，SST收入损失应更大比例穿透利润，价值更低。完整成功不与原期望贡献相加，表中是替换；完整成功的远期收入也不是第三年一次性全部确认。

20%年化的反求权重超过100%，表示在这个“原业务普通、仅SST做到既定完整突破规模”的二分支算例中，即使必然成功也达不到该回报门槛。要满足它，还需要更低买价、更大可得价值，或核心业务也明显改善；不能把115%的代数结果冒充可能的成功概率。12%门槛约88%也远高于当前证据能够确认的整条商业成功程度，因此此组合目前不产生可证明的买入优势。完整成功分支另检查到2036的季度资金路径，未出现新增融资断点，失败分支则先停止投入并承担退出费用；这与3.6叠加政策/信用冲击的融资分支不同。

最早能改变概率的证据是2026年底完整电压/功率/保护测试和2027具名付费试点。前者主要排除技术资格失败，后者排除零付费需求；有每MW成本及第二客户复购，才显著提高后续规模和持续成功。单个试点不支持把2036数十GW当作100%已知。等待代价是可能在合同公开时以更贵股价参与；提前参与的代价是付尚未验证的资格、预算与商业扩量风险。

### 6.4 最强反证与当前结论的可证伪条件

- **反对本报告偏低现金估值的最强证据**将是：收入没有高速增长时仍持续降低SBC美元成本与安装/保修支出，获得可复核的非补贴毛利，或实际SST净价 / ROIC显著好于假设。这会直接改变现金，不需要先改变倍数。一个低forward PE或股价上涨不能单独裁决。
- **反对住宅温和恢复的最强证据**是：非安全港收入和电池MWh继续下降、长应收/渠道贷款上升，且竞争者同地区更强。若只是高附着率而实际装机缩小，基准应转向受损。
- **反对SST大额潜力的最强证据**是：完整系统测试失败、具名客户长期停在免费试点、多个客户选择成熟AC架构，或需要大幅让利 / 承担系统责任后增量ROIC不足资金成本。即使800V行业继续增长，该反证仍可能成立。
- **反对资本主路径的最强证据**是：2027现金不随调整利润积累、税抵出售明显延后、贷款展期与回购同时扩大；2028本金窗口将提高融资 / 稀释的重要性。

暂无独立收费证明的VPP、家庭AI优化或芯片外售，并不因此被宣告永远零价值。若Care / 电网服务在不增加高额赔付的情况下形成10万—30万有效付费账户、年净收入300—600美元，可能增加约30—180收入；但其中基础监控和部分Care已在核心其他业务，必须只计净新增。Kestrel若有外部设计导入及收费合同，应另建芯片毛利 / IP授权、研发与内外部机会冲突。未有可服务客户和净费证据时，当前结论覆盖的是本文明确建模的路径，不能声称所有未知平台机会均已否定。

### 7.3 精简公式与必要复算参数

```text
集团收入 = 微逆百万台 × 综合USD/台
         + 住宅MWh × USD/kWh / 1000
         + 其他成熟收入 + E[SST收入] + E[新品收入] - E[旧电池蚕食收入]
概率 p[t+1] = p[t] × 4×4转移矩阵；F为吸收态
状态现金 = 状态EBIT - max(0, EBIT-SBC)×25% + DA - CapEx - ΔNWC
集团估值FCF = 报告FCF代理 - 持续SBC经济成本
现金[t] = 现金[t-1] + 报告FCF + 税后利息 - 授股代扣税
          - 债务偿还 - 净新增贷款占用；回购=分红=0
目标日EV = Σ(目标日后的季度残段FCF / (1+r)^实际年数) + 折现后的终值
终值 = (调整EBIT - 现金税 - SBC)[2036] × (1+g) × (1-g/20%) / (r-g)
目标日股权 = EV + 目标日现金 - 同日债务；股价 = 股权 / 同日经济稀释股数
总回报 = 目标股价/36.37 - 1；3年年化 = (目标股价/36.37)^(1/3)-1
```

季度中点由季度起止实际日数计算，研究和目标日边界采用统一连续时间近似；NTM为滚动12个月，展示到小数不会将1日的日内差异视为精确信号。2026H2现金与资本路径来自3.3；2027后核心参数在3.2插值，SST十年状态收入及矩阵、组合五年表及2032—2036数量均在3.4，足以复建现金，不依赖未交付的第二份数据文件。
