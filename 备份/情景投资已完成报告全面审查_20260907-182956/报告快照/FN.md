## 1. 当前判断、研究时点与主要限制

**主要预期差有三项。** 第一，增长重心已从原Datacom转至DCI、通信系统与HPC，不能用NVIDIA资本开支对FN做固定比例映射。第二，市场快照的21.79美元forward EPS没有明确年度和会计口径，本研究研究日起NTM含持续股份报酬及正常税负EPS约15.93美元，二者差距不能直接当成市场预测错误。第三，CPO/NPO可能提高制造增加值占比，同时压低材料转售额、替代旧模块收入；必须同时看毛利额和现金，而不是只看毛利率。

### 2.3 盈利质量、现金和资本权利

1. **利润率提升不等于广泛提价。** FY26收入增长35.7%，毛利率约12.0%、略低于FY25的12.1%，营业利润增长主要受规模与费用摊薄支持。未来20%以上的毛利只用于新增高增加值工序的成功状态，不能套到整个制造集团。
2. **GAAP和non-GAAP都不能原样当可持续利润。** FY26有56.743投资重估收益，也有57.447最低税拨备；一项非现金资产价格变化和一项税款义务并非互相抵销后就消失。FY27 Q1调整项为SBC每股0.31、Pillar Two每股0.40。基准税率16%，敏感区间15%—20%；SBC保留经济成本，未来投资重估设0。[指引调节表][S2]
3. **库存比应收更需要解释。** 6月末应收1,017.933、库存1,021.235、贸易应付1,005.761；简化净营运资本1,033.407。FY26应收、库存的现金占用合计702.159，应付增加仅抵消370.753。CFO/净利润约54.3%，FCF/净利润约0.9%。这可能是增长备货，也可能是重复下单、客户接受延迟和最终减值，当前不能只选一种解释。
4. **已有现金提供流动性，保护不了整股买价。** 6月末现金及短投约24.0美元／前瞻稀释股，约为407.4美元的5.9%；这还没扣经营储备、期后厂房和税款。账面净资产约67美元／36.3百万股，包含厂房和库存，不是可实现清算底价。
5. **已发生、应付、已承诺、可取消预算要分层。** 固定资产应付86.018、CapEx承诺108.1、采购及其他承诺约3,150，不能全部当成新增净债务；采购付款与模型营业成本／营运资本配对，已到货设备付款和未交付承诺在现金CapEx中去重。Building 10剩余约39.7属于相关建设余额，不能再作为额外独立承诺加一次。
6. **期后已有债务。** 8月17日约75百万贷款，初始年利率2.45%，逐笔期限5年、20季各还5%；授信2044年届满不等于该笔贷款2044年才偿还。母公司担保、契约和银行批准条件意味着备用额度不是无条件现金。[贷款8-K及合同][S3]
7. **股东权利与报酬。** Amazon认股权最多381,922股、行权价208.48美元、到期2032-03-12；FY26末已归属未行权85,942股，FY26收入抵减4.8百万。它不是独立收入增长。模型收入为净收费，保留激励抵减；基本前瞻稀释股数包含当前稀释影响，后续仅增加存量奖励／客户权利的增量，不再加满381,922股。未来持续SBC按收入0.7%计经济费用和现金中和准备，详见资本底稿。
8. **非经营资产和治理。** Raytek13.8%是少数股权、限制出售、不并表，32.36成本升至89.103账面不是可支配现金；基准/乐观/突破资本桥仅保留89.103，悲观32.36，不预设再重估。管理层激励偏收入和调整后利润率，不直接等同股东FCF目标。模型有工程与管理费用增加，不假定无成本增长。

以上更细财务、条款、税和资本分层同时参考[正式公司调研][L1]和[年报及附注][S1]，本报告的未来税率、资金占用、资产可归属值与资本配置均为A。

### 3.6 早期机会：五至十年逐年状态、投入和期望贡献

本节两项机会分别为**增量CPO/NPO封装制造**与**iPronics等增量硅光OCS制造**。已规模商业化的HPC按客户与制造内容预测，不再对FY26已实现HPC收入打商业化概率折扣；“第二、第三个HPC大项目”的可达性体现在完整经营行，不与局部概率重复相乘。既有LEO、激光和医疗增长仍在核心分支。

CPO/NPO的合理成功工作范围：FY29有限成功70百万、规模成功250百万，基准行当年分别赋33.8%、27.3%概率，收入期望91.9百万。以400美元／6.4T等效引擎的FN净制造费（A）估算，有限／规模成功需17.5万／62.5万个等效引擎。工作费率范围200—600美元：同一250百万收入需41.7万—125万个。行业2028约75万—187.5万个6.4T等效引擎的推断锚意味着“规模成功”要求显著份额及较充分工序内容，绝非必然结果；主行期望值更低。FY31基准规模成功650百万，则需约162.5万等效引擎；这要求2029—2031持续扩量，不能把2028市场静止后仍增长视为合理。

OCS合理成功范围：基准FY29有限／规模收入18/80百万，以10,000美元／等效系统制造费（A、合理范围5,000—15,000）需1,800/8,000台；若十个项目客户均摊，规模成功需每客户每年约800台，而“接触十家客户”远未证明此订单。基准FY31规模成功220百万，需要约22,000台。系统功能和端口数不同，等效系统只是FN收费门槛，不代表ONE实际售价或与其他厂商同型号。客户制造线公告和融资使部分成功具机制依据，但持续量产规模缺披露，故成功概率不接近100%。[iPronics制造线][S9]、[融资公告][S10]

为什么没有取更大或更小：只取零忽略客户确认的制造入口和FN既有工艺；直接取数十亿美元忽略平台内部制造、品牌／芯片价值、净收费与客户预算。基准FY29的两项期望收入118百万、扣替代后82百万，仅为集团约0.9%，兼容“机会真实，但还未改变全集团”。乐观／突破通过更早资格、更高净工序内容和更多扩量客户提高规模，仍扣掉旧业务替代。跨项目共享工艺和同一云预算会使成功正相关，不把两个规模成功概率独立相乘来虚构组合胜率。

### 4.4 方法、资本桥与期限一致性

**半年／一年主方法**：
`经营价值＝目标日之后NTM核心NOPAT×经营利润倍数＋目标日之后早期净项目现金DCF。`
核心NOPAT不含早期收入、利润或替代；早期DCF已扣旧业务替代，因此不会把新收入及旧模块损失加／减两遍。用NOPAT而非含利息净利润配EV；然后只在资本桥加入一次现金。

**三年主方法**：
`经营价值＝目标日之后核心全投入FCF的DCF＋目标日之后早期净项目现金DCF。`
核心FCF＝核心NOPAT＋核心D&A−全部核心现金CapEx−完整核心Δ营运资本。未来报酬经济成本已经在NOPAT中，不加回为股东收益。目标日前现金通过实际期望积累进入资本桥，未来FCF从目标日后才算；不是将今天现值冒充未来退出价。

`股权价值＝经营价值＋目标日现金及短投＋Raytek可归属值−债务−遗留索取权35。`
`每股＝股权价值/对应完全稀释股数；总回报＝每股/407.40−1；三年年化＝(每股/407.40)^(1/3)−1。`

半年与一年核心倍数依次为：悲观16—20/15—19；基准23—28/22—27；乐观27—33/26—32；突破30—37/29—36。核心倍数对应对持续增长和再投资收益的不同要求，不是同一利润只换情景名字。明确工作倍数依次为18/17、25/24、29/28、33/32；它们是可检验的持有逻辑参数，不按区间60%或75%位置取有利中枢。基准25倍要求未来数年约15%—20%经营利润成长且投入回报维持20%以上；若只剩个位数成长，应接近成熟制造现金倍数而非维持25倍。

## 6. 当前选择、价格与证据边界、敏感性及最强反证

### 6.1 最接近当前事实的路径

目前最接近**基准，但Datacom带受损证据、DCI/HPC带较强兑现证据的组合**。本研究已经在同一基准七产品路径中表达这种差异：Datacom温和恢复，DCI/HPC承担主要增量，第一年现金仍负；没有从悲观成本、乐观收入和突破估值挑有利端点，也不再建立第二套矩阵。

短期等待的是**可在窗口内确认的利润持续性与新客户**；一年等待的是**交付增长是否形成税后利润和现金恢复**；三年拒绝现价的主因是**全投入现金回报不足，尽管已给了十年发展和终值**。因此三个期限不是重复投票。若未来出现强于基准的新客户资格，一年观点可先转正，而长期仍须证明再投资收益；短期股价上行并不会自动解决长期资本回报。

### 6.3 最少证据、最强反证与等待代价

- **最早验证点**：FY27 Q1含税EPS是否守住3.39—3.54、DCI/新客户是否继续交付；若只披露新的用途分类，需能够解释原客户收入分流，否则可见度没有因分类变大而自动改善。
- **第二个决定点**：FY27半年／全年库存、设备应付款、税款支付和客户接受同步；基准从FY27约−116百万报告FCF恢复到FY28约219百万。恢复可以晚一季，但若需要持续新增融资，应重建资本路径。
- **长期必要点**：不依赖一家客户的HPC／复杂工序资格、被替代旧业务扣除后的净毛利、每个新增资本批次的回收。只有工厂面积或生态名单不足以确认。
- **最强已经出现的反证**：AI需求增加仍伴随FN对NVIDIA收入下降、Datacom下降；说明客户预算到FN份额这一环已可能断裂。
- **最强未来反证**：DCI和HPC同时减速，库存不能追偿，最低税持续，已承诺设备付款还在。这会使收入仍有同比增长、股东现金却长期落后；模型应转受损而非只降低一两个估值倍数。
- **等待代价**：真实新客户资格和平台复用可以在财报收入完全体现前改变价值预期，等待可能错过半年乐观格的一段上行；但截止日没有足够信息量化错过概率，所以不以它为立即买入的强迫理由。

**库存和非线性资本压力。** 若6月库存10%最终不可追偿，直接损失约102百万，忽略税盾约2.8美元／股；若它同时预示客户永久流失，收入、毛利和资本回收损失会更大，不能只留这2.8美元。突破的周转压力可能需要约5.5亿美元融资；按350美元、5%费用发行约1.65百万股是一条可复算的联合资本分支。发行后须减少相应债务／增加融资现金并改用新股数，不将同一融资缺口既扣EV又再全额扣现金。若市场不给融资，该行高收入时间表不成立。

### 6.5 概率门槛，不冒称实际概率

全四情景没有足够可辩护的联合发生概率，不报告精确整股期望收益或CVaR。只做两个透明的二分门槛诊断，结果不能当实测胜率：

1. 一年只允许“基准工作值492.9”或“受损工作值134.9”，要达到488.88美元（20%回报），需要基准权重约98.9%。这说明在现价把正常路径几乎视为确定，才让这种受限分布过门槛；不是说基准真实概率98.9%。
2. 一年只允许“乐观工作值791.8”或“受损134.9”，过同一门槛需要乐观权重约53.9%。这组诊断允许高风险高回报逻辑，并未因受损跌幅大直接否定；但目前不能从已披露事实证明该二分中的强成功权重达到门槛。加入真实的正常／延期分支会改变门槛，不能将两个二分结果拼成四情景概率。

对CPO局部采用较差转移矩阵，三年工作值只从388降至379；它不是整股主要赌点。即使完全成功，参考3.6的“新机会成功、旧业务受损”组合仍只有164—216美元。因此最值得等待的证据是**旧业务份额稳定＋新客户核心利润和现金可复制**，同时追踪新工序收费；不是单独一条光技术新闻。

```text
          - exit_cost[t] - displaced_core_gross_profit[t]

project_WC[t] = 0.12*expected_revenue[t] - core_WC_ratio[s]*displaced_revenue[t]
project_FCF[t] = NOPAT[t] + weighted_DA[t] - weighted_CapEx[t]
                 - (project_WC[t]-project_WC[t-1])
EV_at_T = sum(remaining_quarter_FCF / (1+r)^years_to_quarter_end)
          + terminal_FCF / (r-g) / (1+r)^years_to_FY36_end
equity_at_T = EV_at_T + cash_at_T + attributable_Raytek - debt_at_T - 35
price_at_T = equity_at_T / fully_diluted_shares_at_T
```

正常报酬、费用和客户激励按经济口径计值，集团预测EPS是可比经营估计，不承诺等于将来GAAP报表的每一项分类。已披露客户认股权抵减4.8不改写；未来存量权利的归属和行权在完全稀释股数及净收费口径中核对，不再把全部名义股数无条件追加一次。如果新奖励或新融资超出本模型，必须同时更新现金与股份，不能仅改变EPS分母。
