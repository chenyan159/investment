## 1. 当前判断、研究时点与价格口径

**当前95.80美元买入：短期不建议投资，中期不建议投资，长期不建议作为稳健复利或现金安全边际投资；高风险技术突破策略也宜等待。** 这不是认为Intel没有技术价值：18A已有商业交付，CPU盈利修复有财务基础，外部先进封装可先于外部前道代工形成收入。本研究的分歧是：**经营修复已经开始，但当前普通股价格要求的资本回报和增长持续期，远高于“恢复到一家正常盈利的CPU公司”。**

### 3.4 四项早期机会：逐年互斥状态、持续销售和失败成本

**P＝新增外部先进封装；W＝新增先进前道外部客户；G＝新增推理GPU；O＝封装内光I/O。** 存量Altera制造、已售内部18A产品、普通网络和既有定制不在这四项中。P和W可以服务同一终端芯片，但仅加不同的净制造工序费用，集团内部采购一律抵销。玻璃基板改善进入P成本与交付，不另加一份收入。

状态N＝尚无稳定可确认商业交付；L＝有限／部分采用；S＝规模且持续商业采用；F＝同一路径失败／退出。每一年度四状态互斥，概率合计100%。下表是**当年仍处于该状态的概率**，不是首次成功概率或历年营收总和；S可以退回L或退出，F为吸收态，失败不会无条件恢复。

工作值没有统计校准基础率，是受阶段证据约束的A。P已有工艺和外部客户爬坡线索，初始商业权重高于W；W必须增加外部设计生态、认证、净价与长期信任；G历史产品退出／软件迁移提高失败危险；O缺大规模客户验证，起步最晚。突破只固定**P已商业交付、内部14A工程路径**，不再对这两件事打折；其余分支仍保留客户规模、经济性和持续性风险。

**转移公式**，以2027状态分布起步，a表示N→L、b表示L→S、f表示N或L→F；S→L固定5%、S→F为f/2。每年：
`N'=N(1−a−f)；L'=Na+L(1−b−f)+0.05S；S'=Lb+S(0.95−f/2)；F'=F+f(N+L)+fS/2`。
这不是假定市场随日历相信成功；是**从今天看不同经营结果的分布**。若将来没有阶段进展，就条件到仍在N／L的分支重算，不能直接沿全体平均分布上调。

基准与突破三年退出的**2040以后终值现值占经营价值约52%／59%（11%工作参数）**。此外2030—2040也有尚未兑现现金，因此三年估值大量依赖未来能力，而非三年已赚现金。这里没有把终值低端称为资产底价。终值ROIC若降至资本成本附近且仍要求3%增长，需更高再投资比例；其影响与毛利下降相关，不宜把两项最大损失直接加成一个“概率事件”。

### 6.3 全成功参照、组合检验与融资非线性

**全成功参照采用另一条明确条件路径**：四项机会2027—28都在L、2029起持续处于S，全部相应成本与工具付款保留，核心业务仍按各自情景；不是把主表E收入替换为成功值后再保留同一资本预算。11%资本成本下2029每股约：悲观12.47、基准50.55、乐观95.21、突破142.23；仅作条件参照，**不与主值相加**。即使四项都进入规模销售，若核心普通，仍不能支持95.80。全成功突破142.23尚略低于主门槛145.70；更低资本成本或更高资本效率则可能改变这一结果。

最重要的组合检验是**旧业务按基准、新机会按突破商业树，并另增加每年5的共享支持资本**。初算三年价约46.74，但三年末现金仅13.33，低于18的流动性触发线，不能声称“平均现金还能运营所以无需融资”。按目标日缺口约4.67、发行净价50美元、2%费用计算，需新增约0.095十亿股；补足现金后每股约46.78，不能将新现金全加而不加股数。这是端点近似，实际应在最早触线时融资，若发行价仅25则新增约0.190十亿股、每股约46.0，且交易条件可能更差。判断仍不变：**新业务成功不自动补偿旧业务捕获不足及额外资本责任**。

四条主路径尚未在2029前触线，但这不意味着没有融资风险。CPU利润更低、客户押金停止、工具不能延期及相关P/W客户共同退出可能同发。压力例：基准到2029归母经营现金累计比工作路径少20，则退出前现金约6.6；为恢复18需约11.4净融资。发行价40、费用2%需约0.291十亿新股；融资后占股须逐支重算。若无法融资，应进一步削减投入、出售资产或重组，不能让模型以平均现金“穿过”断点。严重普通股损失支路可能低于悲观主格；没有把不确定的清偿残值当作正数保证。

**相关性处理。** P和W共享客户预算、厂区能力及工程人才，其大成规模与融资需求同向；G采用还可能蚕食CPU。主模型给的是条件下各路径边际期望，线性税后经营现金可以相加；融资和股数不能线性相加，所以专门做上述联合现金断点，再计算每股。由于缺少联合状态的可辩护权重，不提供一个精确全公司概率加权价格、CVaR或“成功率”。相关性对均值未必改变，但会明显改变需要融资的尾部；报告没有假装掌握这条联合分布。

### 6.4 概率门槛、最强反证与更新规则

只为显示买价要求，构造**基准与突破二分支门槛**，排除其余路径不代表它们不存在。11%工作参数下，当前基准现值约29.90、突破96.36，95.80需要约99%的突破权重才达到不亏门槛；该数**不是市场真实隐含概率，更不是本研究概率**，而是暴露当前买价依赖何种经济规模的算例。

三年要求15%年化时需145.70退出价；11%参数突破仅130.50，故二分支权重即使100%也不足。若统一改用主区间有利端（10%资本成本、资产10），基准约47.99、突破155.05，达到145.70需要约91%的突破权重；加入受损结果还会提高要求。不能将此门槛写成“实际突破胜率91%”。若采用更强的新商业模式，须明示新收入、资本和失败路径，不能仅调概率或挑区间75%位置跨越门槛。

局部成功概率再提高并非无效，只是**在当前价格下，最弱价值传导同时存在于成熟业务利润持续期和增量资本回报**。最早有价值的证据不是又一篇性能新闻，而是能排除失败解释的组合：

1. **客户侧**：具名生产采购、不可取消部分、验收节奏、预付与赔偿条款，能够排除“仅谈判或设计验证”的解释。
2. **工程侧**：同产品／节点良品成本及可靠性交付，能排除“靠昂贵高端组合、报废或额外资本维持”的解释。
3. **资本侧**：在相同产品规模下，全部设备付款、库存与合资分配下降，能排除“利润有了而股东现金一直没有”的解释。

最强反对本报告的论点是：**它低估了系统CPU／定制市场的长期扩大，并高估了维持／增长资本责任**。这项反证有机制可信度，尤其客户把AI执行放在CPU、通过模块化封装重复利用平台，可能提高收入又减少每代重建成本。若实际客户合同显示2030可持续归母EPS接近7且高增量ROIC、后续资本付款低于本模型，25倍盈利的高风险条件建议可以升级为当前谨慎建议。反之，如果销量并未持续增长，ASP只来自组合，外部业务的净价和现金无法验证，现价缺少保护，等待更合理。

报告结论覆盖普通股在当前价格下的可辩护经营路径；未声称已穷尽未来所有机器人、光内存、知识产权授权或重大资产交易。新路径需要足以影响每股价值的证据和资本预算，才值得替换当前模型。

### 7.3 复算入口及误差边界

1. 以第3.2既有业务收入和毛利率表计算核心毛利；核心Opex在第3.5表。
2. 对P/W/G/O，从2027概率行和a/b/f转移式生成2028—2035状态。用S收入序列、情景规模系数及L比例得到各状态收入。状态内算毛利、费用、资本和折旧，再加权并计当年新增退出现金。
3. 把早期期望并入集团，ΔNWC＝年度收入增加×12%，现金税＝正EBIT×18%；本模型主路径均有正EBIT。核心设备付款可由集团设备付款减第3.4各项资本得到；核心D&A同理。历史2026H1和2026H2预测绝不混同。
4. 2027—2040各年按23.5%／24.5%／25%／27%季度权重分配；26H2用独立季度表。目标日后的NTM与DCF只截取剩余季度部分。现金锚把6月27日资产负债表近似置于6月30日，未披露3天流量暂按0；若该零头净现金误差0.3，每股仅约0.05，不影响本次选择。
5. 累计目标日前归母经营现金和本金偿还，得到目标日现金／债务；FD按第2.4与3.5公式。未来授予的SBC成本与分母不得重复处理。
6. 折现2040以前剩余FCF，另计2040末终值`2040 FCF×(1+g)/(r−g)`；终值再折现回目标日。加资本桥，除FD，按95.80算回报。

关键计算的精简实现如下；经营输入来自正文表，不需要另一份外部模型文件：

```python
# 时间单位须一致；每个季度现金只按目标日后剩余比例计一次。
def advance(p, a, b, f):
    n, l, s, fail = p
    out = [
        n*(1-a-f),
        n*a + l*(1-b-f) + .05*s,
        l*b + s*(.95-f/2),
        fail + f*(n+l) + f*s/2,
    ]
    assert abs(sum(out)-1) < 1e-10
    assert out[3] >= fail
    return out

def exit_value(quarters, exit_day, r, g, fcf_2040,
               cash, debt, nonoperating, diluted_shares):
    # 日期先统一成天；year_days=365.25
    pv = 0.
    for q in quarters:
        begin = max(exit_day + 1, q.start)
        if q.end > begin:  # q.end为季度末次日，半开区间
            part = (q.end-begin)/(q.end-q.start)
            mid = (begin+q.end)/2
            pv += q.fcf*part/(1+r)**((mid-exit_day-1)/365.25)
    terminal = fcf_2040*(1+g)/(r-g)
    pv += terminal/(1+r)**((day_2041_01_01-exit_day-1)/365.25)
    equity = pv + cash - 3 + nonoperating - debt - 1.3
    price = equity/diluted_shares
    return price, price/95.80-1
```

季度和年度表按显示精度保留1—2位小数，价格按未四舍五入的状态及现金计算；独立从显示表重算存在约几美分误差，不能把微小差额当作买卖优势。2036—2040的现金回收比例过渡是估值假设，2035之后的资本效率仍是最重要估值未知；未来真实研发、租赁结构、政府现金与股份交付不同，应同步调整现金和股数。
