# CSCO：经营情景、价值传导与分期限投资决策

## 1. 当前选择、主要预期差与研究时点

**当前实际判断：按股东现金与长期资本回报要求，短期、中期、长期均不建议以109.20美元新增投资。** Cisco的经营改善是真实的，但“正常兑现”尚不能提供足够的股东现金来支持现价；现价更接近需要长期接近乐观路径的买价。这个结论不是认定公司AI业务没有价值，也不是预测股价马上跌至DCF数值。若采用近期市场继续按非GAAP盈利定价的交易理念，短期可以是**中性 / 等待**，中期在额外经营条件成立时可以转为**谨慎建议投资**；与主判断的冲突保留在4.4节，未取平均。

本研究真正不同的观点是：**最弱传导环节已从“Cisco能否拿到AI订单”，转为“买方、供应商和员工分走多少增长价值，以及剩余现金能否以足够长的时间持续”。** AI订单及交付上行、相干光学放量、校园更新和交叉销售支持收入扩张；但硬件组合、融资应收、不可轻易取消的供应承诺、持续股权报酬及Splunk净收费决定每股结果。[公司上游底稿][L1]、[FY2026年报][F1]、[最新业绩公告][F2]

### 2.4 财务质量、合同与资本索取权

1. **订单不是不可撤销现金。** 正确关系为期末未交订单＝期初＋新增−交付−取消/调整。9.3B AI订单减4B收入的5.3B不是审计backlog；RPO46.734B中短期约22.776B，递延收入29.781B又与RPO重叠，三者不相加。[F1][F3]
2. **供应义务比设备CapEx更大。** 17.165B采购承诺中约14.341B在一年内，部分不可取消或难以转用；不是17.165B当期损失，也不是要在净债务上再减一次的金融借款。库存＋采购承诺22.859B若发生真正额外且不可回收的5%损伤，税前1.143B；这是压力门槛，先扣已有准备和重复预付款。[F1]
3. **现金与利润的背离有具体来源。** FY2026库存、融资应收分别占用2.541B、1.835B，最后一笔2.3B过渡税支付结束有利FY2027同比现金恢复。利润桥直接从税后利润/折旧/营运资本推导，因此不再额外加2.3B；它只用于从旧年度现金做交叉校验。[F1]
4. **经常性盈利剔除投资重估。** FY2026其他收益净额1.245B；现金流中投资、剥离等净收益扣回1.358B。未来利润不复制这些收益。收购无形资产摊销下降可以改善GAAP，但维持研发、人才和客户关系的成本仍在费用中。[F1]
5. **净债务不是毁灭性约束，但偿债不能免费。** 债务29.533B、短债10.161B，含约6.7B商业票据；正常路径假设商业票据续作、按到期表先还FY2027约3.5B/FY2028约1B，之后可再减债。5B未动用循环授信不是现金资产。首三年现金充足，不依赖发行普通股融资。[F1]

### 3.2 新曲线的商业边界

**O1：Cisco在开放Ethernet scale-up取得新增外销系统/光学收入。** 这是现有scale-out和P200 scale-across之外的新增紧耦合域。能力基础是统一硅架构、SDK、SerDes、光学与跨平台伙伴；付费方是XPU/云平台和设备采购方。必要条件包含端点协议、故障恢复、互操作及客户总体成本，而不是G300峰值带宽。既有GPU规模并不自动变成其可服务市场。内部光学迁移、替代自身现有产品以及客户已为scale-out支付的部分先扣除，状态表金额为**净增**。公开没有可用的同类Cisco项目校准基础率，概率是受这些机制约束的主观工作值。[G300规格/发布][T1]、[开放互联行业约束][L5]

### 3.5 利润、现金与投入闭合

**报告FCF＝OCF−全部固定资产CapEx**，用于账上现金与融资；估值FCFF则从GAAP营业利润出发，保留SBC的经济成本，扣全部成长资金，排除净融资利息：

`NI=(EBIT−0.60)×80%`；`OCF=NI＋SBC＋收购摊销＋实体折旧−ΔWC`；
`估值FCFF=报告FCF−SBC＋0.48−战略投入`。

−0.60B是经常性净融资利息/现金收益代理，非非经营投资重估；+0.48只为把利息融资口径还原到企业经营价值，现金及债务在资本桥处理。战略投入为收购、合资及类似现金，未来能力收益已在经营轨迹，故必须从估值现金扣除。收购摊销只加回一次，研发与客户维护没有因摊销下降而被删除。固定费用中O1/O2的SBC经济报酬已扣，集团SBC现金加回/抵消为统一现金结算近似，不另加早期项目“免费股份”。

## 4. 三种期限的逻辑、事件、估值与价格反向检验

### 4.1 回报门槛、方法和风险计量

主矩阵采用“持续股东现金＋已扣成长投入的经营价值”理念。Cisco既有庞大现金业务，且股权报酬/营运资本足以改变结论，因此用企业FCFF折现作为**条件合理价值**主锚；短期可交易重估单列，不能由DCF自动推出市场六个月内收敛。没有预设所有公司都应由DCF主导，而是本公司报告盈利与可分配现金的显著差别使这一方法特别有解释力。

| 期限/主要理念 | 在估值计算前采用的要求回报 | 判断方式 |
|---|---|---|
| 6个月，股东现金价值与事件验证 | 累计至少6%；3个月检查至少3%，不把短期收益高倍年化宣传 | 高于同期低风险现金收益，并要求可解释的确认事件；贴近门槛且估值误差大时仅谨慎或等待 |
| 12个月，经营兑现及现金转换 | 累计至少12% | 单股风险和集中持有需要较明显优势；不能用辅助倍数上沿越过门槛 |
| 36个月，持续竞争优势与资本回报 | 年化至少10%，即三年累计33.1% | 允许增长复利，但需支付更新、研发、周转和稀释；仅接近门槛没有安全余量 |

截至9月4日美国国债6个月约3.98%、1年4.13%、3年4.45%、10年4.78%，为机会成本锚；单股门槛是研究纪律，不是预测收益率。[美国财政部期限收益率表][R1] 折现率9.0%—10.5%，工作值9.75%：低债务权重下约4.8%的长期无风险利率，加约4.5—6个百分点权益风险补偿，再考虑债务成本/税盾后取整。它表示时间价值及未在经营路径显式计入的系统性风险，**不再加一次O1/O2失败概率罚分**。情景更差不另抬高WACC，避免重复计损。

DCF逐财季折现到每个目标日，目标日前现金已经积累、付息、还本或分配，只在资本桥出现一次。FY2036后把**核心经营**与早期机会分开：核心正常化NOPAT＝（FY2036集团EBIT−O1/O2期望EBIT＋即将消失的收购摊销）×80%；终值FCFF＝NOPAT×(1＋g)×(1−g/ROIC)。核心g悲观0%—1%、基准2%—3%、乐观2.5%—3.5%、突破3%—3.5%；工作点分别0.5%、2.5%、3%、3.25%；对应增量ROIC12%、20%、24%、25%。产品更新所需R&D已在费用，g/ROIC额外支付超过维持更新的扩张。

**早期项目不按2036年的期望利润直接永久资本化。** 2037年后继续同一N/P/S/F转移，F保持吸收；P/S状态收入、固定维持费用和设备成本同时每年增长2%，变动费用率及周转比例不变，继续算状态内现金。项目残余现金逐年折现，数值计算到FY2126（100期，自2027计）以近似衰减尾部，非声称能精确预测2126年；其作用是让失败/退化持续生效。把尾部截到50期对基准每股价值影响很小，项目长期没有额外“100%成功”终值。早期资产不被同时放进核心永续价值和期权，未来失败风险亦未重复折价。

估值区间低端采用10.5%WACC与各行低g，高端采用9%与高g；同一行已列年度经营路径保持相同。它是**条件参数区间而非覆盖全部经营误差的概率置信带**，毛利、股权成本、需求与项目概率的额外误差另算，不把DCF低端当资产底价。中间工作值来自明确WACC/g/经营点，不是高低端60%或75%的位置。

### 4.4 投资理念分歧：盈利倍数能支持更高交易价，但不是同一种价值判断

同源价格快照中，CSCO TTM PE32.79、P/S6.80；Arista分别61.32、23.19，HPE为26.80、1.65。快照TTM所对应财报截止期并未逐字段标注，因此此处仅作同日原始市场字段展示，不用于精确历史横比或倍数迁移；Yahoo forward PE更因年度不明而不作为可比一致预期。[金融快照][L7] Arista截至2026-06-30单季收入3.036B、增长37.7%、GAAP营业利润率45.4%，与Cisco截至7月25日Q4不同，经济增长和利润结构足以解释明显估值差；不能简单说Cisco比Arista便宜就低估。[Arista原始季度公告][T5]

为讨论市场实际惯用的盈利法，使用**同一底稿**计算“调整EPS代理”：NTM GAAP净利润＋80%×（SBC＋收购摊销＋0.3B正常化调整项目），除目标稀释股数。0.3B是比较报表口径的调整代理，不从估值现金删除；不假称与公司未来非GAAP完全相同。该法把长期报酬成本放在倍数折价/未来回报要求里，而不是在EPS里扣除，必须意识到它的高倍数会隐含更多未来增长。

### 4.5 现价隐含要求和反向估值

109.20美元相对FY2027公司非GAAP EPS中点5.08为21.50倍，相对GAAP4.03约27.10倍；相对Yahoo未明年度5.60为19.50倍。该0.52美元差异足以令表面远期PE相差约2倍，不能当作同一期一致预期。FY2026报告FCF12.767B/快照市值430.53B约2.97%，扣SBC的经济敏感性8.937B/市值约2.08%；当前年化股息1.68美元，收益率约1.54%。这些是不同口径，不相加成“现金回报率”。[F1][F2][L7]

本模型当前基准工作价值约67.21美元；按研究稀释股数及估计当期资本桥，现价要求经营价值约446.37B，而基准经营价值约278.50B。几组可以复核的隐含组合是：

| 组合，其他条件按基准 | 支持现价所需条件 | 如何理解 |
|---|---|---|
| 同现金路径、同终值增长 | WACC约7.08% | 相对10年国债4.78%只剩较薄风险补偿，低于本研究9%—10.5%范围；不冒称市场真实折现率 |
| 同WACC与g、各期现金等比例提高 | 经营现金价值约需增加60.3% | 仅是逆向边界；若靠收入而非资本效率，需要长期规模更接近乐观而非基准，不能将成本固定后无限放大 |
| 只靠FY2027完成公司GAAP指引 | 相对本研究约多0.94B净利润，且必须持续和转现 | 一年超额约0.24美元EPS本身难填补每股数十美元经营现值差；延长持续期才重要 |
| 用市场盈利法 | 约21.5倍FY2027非GAAP盈利即可写出109美元 | 说明为何市场可以维持现价；是否值得持有取决于未来现金与持续倍数，而非当期算式成立 |

反向模型不是“唯一市场共识”。私有投资实现价值即使从2.5B提高到净账面3.676B，每股仅约增加0.30美元，无法主导结论。现金在偿债后也不能保护全部买价；模型低端是持续经营条件价值，不是清算底价。

### 6.3 条件概率门槛、等待价值与最强反证

仅为反向门槛，假设世界只有“基准整家公司”和“突破整家公司”两条、以各自工作现金价值及分红结算，三年总价值分别约87.13和174.36美元。达到年化10%所需突破权重约**66.7%**；高风险理念要求15%年化时约**90.5%**。这不是实际概率，更不是O1成功概率；它故意忽略受损行，加入永久损伤会提高门槛。当前证据不足以支持如此高的完整突破概率，因此不能从突破格的收益上限推出当前推荐。

只在基准与乐观之间做同样检查，乐观工作三年总价值约145.30美元，几乎贴近10%年化门槛，说明不能靠“乐观也可能发生”就创造充分安全余量。该两点算例不是对四行作整体概率预测，亦未给精确胜率/CVaR。

最早有价值的信息是11月12日Q1的交付、资产负债与现金，而不是再增加一份行业TAM。若收入约18.1B且库存/融资应收增速放缓，排除一部分“提前下单但最终不接货”的解释；若多个G300/P200买方复购并公开验收，降低资格/单客失败分支；若O2有明确净新增年费及第二年续约，才提高P→S和规模持续性。等待的代价是可能错过首轮估值扩张，得到的利益是减少为假增量、不可转用库存或免费软件功能付高价。

**最强反证，分别针对本研究的乐观与谨慎：**

- 针对乐观经营：AI带宽快速增加但客户通过拓扑扁平化、自研控制面、低价光学和多供应商降低采购强度；校园更新前置与Splunk单位数据折算同时压净费。若报告收入上升却持续靠客户融资和低毛利转售，Cisco获得行业价值却没有取得相称股东现金，应更接近受损/基准低端。
- 针对当前不建议：Cisco可能把跨域责任、硅与光学复用做成持续十年以上的高资本回报平台，实际收入、现金和净收费比本研究基准高约六成的经营价值要求更易达到；或者市场长期接受明显较低的资本回报。前者须用跨代多客户复购、独立年费、强现金转换证实，后者是投资理念差异而非经营事实。若这些证据出现，本报告应上调，而不是坚持旧DCF结论。
- 针对量化精度：长期毛利和费用分配、终值增量ROIC、独立平台ARPU和合同资本义务披露有限；当前市价与基准差距大于小额净债务/股份误差，但乐观行贴近门槛的结论远弱于“强烈建议”。因此未把几角钱边界当精确操作信号。
