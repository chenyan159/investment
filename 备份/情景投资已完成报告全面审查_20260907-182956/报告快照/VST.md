## 1. 当前选择、预期差与研究时点

**149.30 美元买入：短期中性／等待，中期中性／等待，长期不建议投资（以完整现金回报为主的投资理念）。** 当前最接近“基准／正常兑现”：现有电源的经营能力确实提升，Meta 重新签约和 Cogentrix 并购提供近期增量；但现价已要求其中相当部分兑现，并对三年以后的利润持续性支付了价格。这里的长期“不建议”是现价与现金回报的判断，不是判断电力需求衰退或公司没有新机会。

## 2. 公司全貌、财务质量与上游约束

### 2.1 实际拥有的收费权

VST是发电、零售电力与能源风险管理的组合，不是按受监管输配电资产基数收费的公用事业。核电、燃气与煤电对外售能量、容量和属性；零售对家庭、企业售电；内部发电与零售交易合并抵销。公司不控制全部输配电接入，也不拥有可以向所有核电运营商收取授权费的反应堆技术。

| 业务/产品 | 需求、供给与竞争约束 | 可捕获数量与价格 | 收入、利润、现金形成方式 | 核心证据及反证 |

### 2.3 资本、治理和法律风险的实际传导

合并本金等19.764（含项目债1.633）+应收融资0.300+权益回购义务0.613=20.677；不能使用公司演示中排除项目融资、再扣保证金后的17.295作为全部集团索取权。净保证金1.314是履约占款，主模型不当自由现金加回；其将来释放应通过WC现金一次处理。2.476优先股另扣，核电退役信托对应退役/监管义务，不当隐藏普通股现金。模型对关闭现金逐期扣除，因此不再把相同整笔ARO重复从EV扣一次。[Q2 10-Q债务及相关附注](https://www.sec.gov/Archives/edgar/data/1692819/000169281926000019/vistra-20260630.htm)

2026年末Nuveen应付款0.631含约0.613本金及利息；本金已经包含在开端债务，支付同时减少现金与债务，不能再减净债务一次。近端另有2026年12月0.5、2027年1月0.8、7月1.3债券到期，模型假定按投资级条件滚动融资；融资表中的“净借款”是新借款减偿还，不能解释为无需滚动这些到期款。2026-09-30商品额度到期的续期未获本次原始确认，不能把6月底6.295流动性（主要为授信）无条件延续。

治理上，回购和对价股均影响每股结果。以149.3买回与以185名义价格发行的500万固定对价股是不同交易；不会因现价低于185而自动少发股。Helix由KKR管理，VST无控制权，基金费用及关联商业条件可能转移回报；不默认平台价值100%归VST。资本配置既有Energy Harbor/Lotus整合证据，也有Moss Landing失败证据，不以单个成功并购推断每项新资本都高回报。

### 3.3 经营、全部投入与资本桥

报告CFO预测保留现金利息、现金税、净营运资本/保证金和关闭支出；不预测未实现衍生品现金流。维持资本含维护、核燃料、LTSA的经济归类；一般成长资本不含另列Helix与增容。定义：

`CFO = 核心EBITDA + 两项早期机会的状态内加权EBITDA − 现金利息 − 核心现金税 − 机会状态内现金税 − ΔWC/保证金 − 关闭现金`

`报告FCF = CFO − 维持资本 − 一般成长资本 − 两项机会自身资本`

`估值FCFF = 报告FCF + 75%×现金利息 − 0.15持续股份报酬现金等价`

FCFF的利息加回只取75%，相当于补回税后融资影响；核心现金税已享债务税盾，不能直接加回100%利息再称无杠杆现金。机会成本、税和失败支出先按状态计算再加权，未直接给期望营收套成功利润率。股份报酬在目标日前通过每年1M新增完全稀释股体现；目标日以后以0.15/年现金等价支出处理，不同时再把未来全部1M/年加进退出日股数。

### 3.4 早期机会：逐年状态、收入、投入与失败

重要早期机会只有两类单独概率化：**H＝Helix带来的额外供电净溢价及基金权益；U＝433MW核电增容**。现役Meta/AWS重新签约属于既有业务合同爬坡，Permian为已决定建设的成熟技术，直接在四行量价/资本中体现，不再对同一合同里程碑重复打成功折扣。大规模新核电/SMR技术许可业务没有VST专有收费证据，保留为未覆盖的远期选择，不声称其价值为零。

### 4.2 主方法、回报门槛与真实方法冲突

短期主理念为**可验证盈利的重估与周期租金**，中期为**盈利兑现加资本回收**，长期为**扣完再投资的股东现金及持续经营能力**。事先采用6个月总回报8%、12个月15%、36个月年化12%（累计40.49%）作为值得主动承担单公司风险的工作门槛；3个月检查用4%。这些是投资要求，不是预测收益或从输出倒推的胜率。高风险突破理念可以另要求年化15%以上；纯长约现金投资者可以接受年化8%—10%，其结论单独保留。

利率锚：美联储2026-09-04发布的H.15中最新列是**9月3日**，10年名义国债4.77%、6个月国债3.95%；不要把发布日期当收益率对应日。[H.15](https://www.federalreserve.gov/releases/h15/)。WACC是研究区间，不是公司公布值或精确回归beta推导：混合发电/零售需承担商品、运营和资本风险，长约可降低部分风险，但不能把整个集团按无风险核电债券折现。

**方法冲突没有被平均掉。** 在相同现金、投入、债务及股数下，短中期盈利法给出的价值明显高于完整DCF。要以DCF完全支持约9—10倍EBITDA，通常需要更低的资本成本、更长高利润持续期，或比本模型更强的长期单位现金回报；若选择改变未来维护/税负，就已是不同经营路径，不能暗中挪参数。纯现金投资者因此可以在短中期也“不建议”；主矩阵中的盈利重估正面格只适用于接受这种估值采纳逻辑的人，不要求现金理念服从它。

### 4.3 时间一致估值公式与十二格资本参数

经营价值先扣全部生产投入；基金另用股权现金法，以未来分配减追加资本及Y10剩余股权折现，不能给平台总资产加一次期权。经营FCFF包含H供电、U增容的状态内概率加权现金，其终值包含仍存续业务；不再乘同一成功概率，不另加完整成功项目NPV。

`EV_DCF(h) = Σ[t>h] FCFF_t/(1+WACC)^(t-h) + TV_10/(1+WACC)^(10-h)`

`TV_10 = [FCFF_10×(1+g) − g/12% × max(EBITDA_10−D&A_10,0)×75%] /(WACC−g)`

终值新增ROIC工作值12%，g/ROIC对应额外净增长所需投资；Y10一般成长仍用于替换退出能力与保持组合，终值新增投资不再用于同一已扣的具体项目。成熟税盾逐渐消耗、维持资本逐年上升，终值不让高增长免费延续。永久经营估值以延寿、替换和资本回报可持续为条件，不是说所有现有机组牌照永远有效；失败/退出及有限寿命的替代法在6节。

`股权价值_h = EV_h + 基金剩余股权现值_h + 自由现金_h − 合并债务_h − 优先股2.476`

`每股价值_h = 股权价值_h×1000/完全稀释M股数_h`

`累计总回报 = (每股价值_h + 实收期间现金分红 −149.30)/149.30`

短期3个月可能尚无全年确认或Cogentrix交割，基准滚动NTM改善幅度和可见性均低于6个月；以8.0—9.2倍当时NTM作信息不足的条件边界，价值约133—163，区间上端仍有上涨空间，但8.5倍工作参数约146，未达到3个月4%的要求回报。**3→6个月转变的最少事件**是交割完成且资本桥无重大超支、2027指导口径明确包含新增资产和Meta、并确认不是只增加EBITDA却增加等量现金需求。若发生，6个月可讨论136—174区间；若只宣布合作而无净经济条款，仍等待。这里降低3个月参数是证据与未交割资产采纳问题，不把长期价值按时间比例缩小。

长线高风险突破理念另有空间：如果投资者能独立验证多项目供电平台、可承受永久损失，并要求三年年化15%，需退出每股约224.3。突破主现金区间180—248仅高端达到，工作参数不足以稳健超过该门槛，故不能仅凭68%累计收益上限推荐。主长期12%要求对应约207退出价，突破工作值约206也只在边界附近；应保留“中性／等待”，不能把高端位置人为选作中枢。

事件依赖路径为：客户信用及合同净费 → 许可/接入 → 工程/交割 → 可用率/交付 → 收款 → 减债/回购。Helix和既有大客户PPA竞争同一电源或站址时，新增收费只取对原售电的净增量；监管要求“新负载带新供给”时，须先提高成长资本再谈收益。利好落地不涨的主要解释是净回报已经被支付、现金成本更高或估值风险补偿上升，不能自动归因“市场不理解”。

主矩阵给**条件合理价值回报**。本研究没有足够同日同口径预期分布或成交机制，不能可靠给出“必然在6个月被采纳”的统计交易回报区间。可支持的交易方向是：真实现金上修且融资不恶化时有重估条件；只有标题、延期或更高资本要求时无此证据。成交价仍可低于价值区间，8月财报日的反应已提供实际例子；因此不会把条件收益当作定时可实现收益。

## 5. 四行情景×三期限条件矩阵与十二格明细

矩阵**条件于整行情景成立**，不是四行整体概率加权收益。H供电及U增容贡献均已在行内逐年概率加权，基金按状态×投入资本分支计值；现役PPA签约和晚2026收购交割按行内时间假设处理，不再对同一里程碑扣概率。突破行当前证据弱不被用来直接压低其短中期条件评级；其长期“等待”来自前置资本、现金法工作回报和误差，不是因为突破本身发生概率低。

### 6.3 早期成功概率、规模与延期的建议边界

**成功概率不能取代公司捕获金额。** H基准Y10约48%的规模成功概率与5GW当年规模，产生的集团期望增量远小于把整个平台资本或园区营业额归VST。将Y4以后H全部改成规模成功、基金1B全额投资且按完整成功分配，并沿相同容量增长到Y10，基准三年价值约128.3（已将目标日尚未实缴部分补足到1B、相应增加资本占用），较122.7仅增加约5.7。此算例保留原有业务基准、税/配套资本和基金费用；不是从突破行拿9GW再叠回基准。

若把此“全部H成功”与原H基准作二分混合，要把价值提高到207，形式上需要约1490%的混合权重，超出概率上限。因此**在本研究可辩护的5GW/20美元净费捕获范围内，提高Helix成功率本身不足以翻转三年现金建议**。可以翻转的是更大净收费规模、更多原有气电租金或显著更低资本要求的联合路径；那必须另给电源、客户预算和投入证据，不能把概率从48%改成100%就当解决。

H供电扩量、分配和剩余权益时间统一后移一年，保留已支付首笔出资及既有追加约束，基准三年价值约122.1（这是对Y4后剩余现金的局部延迟检验，未假装全集团也延后一年）。差额不大不意味着Helix不重要，而是当前工作范围中它本来就不是整股价值的主要部分；若研究假设它主导整股，应首先证明净费和GW规模显著更大。H部分成功规模从25%降至10%或净费从20降至10美元，会减少其期望供电现金；它仍不能反向解释原有集团全部现金。

**“新机会成功、旧业务受损”组合检验**：H按上述完整规模成功，但Y4以后原有气电/零售年度EBITDA比基准少0.8B，税/必要资本相应变化按新增现金55%计算。三年价值约128.3−0.8×19.3=**112.9**。公司可以对AI供电取得商业成功，股票仍可能在149.3买价下没有足够现金回报；这不是未知机会按零，而是旧业务体量更大。

U的完全成功收入约0.30B级，单独无法补足84美元/股的基准长期回报差距；预算翻倍或首次售电推迟两年会降低项目NPV，若主要资本尚未承诺，可以取消后续批次，但早期工程、设备取消与站址成本不能无损收回。最值得等待的U证据是多机组许可+锁定预算，而不是又宣布一次433MW采购总量。Y5前已投入的预期资本均在现金表，不能因尚无售电把它删掉。

**资本联合分支**：在基准6个月债务约25.41B的付款峰值，若额外需要2B保证金、第二笔0.5BHelix提前全额调用，暂停前半年0.4B回购只能把债务需求控制在约27.51B，尚未算经营事故。其额外利息和银行额度可获得性应按真实条款重算；当前约4.4B企业循环可用额提供部分缓冲，但商品额度续期未知。把这一路径与悲观经营叠加，可能触发卖资产、再融资溢价或增发；不能用各分支平均现金假装均能融资。假设另外需要1B股权、发行价100并含5%费用，约需新增10.53M股且只收到1B净现金，加入新股前要先冲减资金缺口/债务，不能只加钱或只扣股数。本报告未将这项尚未触发融资强塞入所有四行。

没有证据支持四个完整情景的精确总体概率，因此不提供整股胜率、CVaR或精确期望回报。可作反向门槛：若仅作诊断、暂把长期结果简化为基准现金工作值123与突破高端248，要达到207需要约67%的高端权重；若失败值为35，则需约81%。这是不完整二分模型的**必要权重示意**，不是实际概率，且还省略了中间状态；它揭示仅有“大上限”不足以证明正期望，不能用于下注规模。

### 6.4 最强反证与未知的边界

最强反证是一条完整经济路径：AI与工业负荷继续增长，但可中断接入、自备电及光储扩张压低高价小时；核电长约提高稳定性却只给有限净溢价；公司为维持/替换资产、增容与园区协调持续投入；现金税和融资成本上升，回购空间低于“60%+ EBITDA转FCFbG”的表面印象。这个路径会同时改变气电单位贡献、零售采购、资本和终值，不能只在风险清单写一句。

最能推翻本研究长期谨慎结论的证据也很具体：更多跨周期、有信用、可执行的长约显示VST保留了高净费与低补购责任；2027—2029全部投入后的现金明显超过表列；新增项目税后ROIC高于资本成本且可重复；现金积累和稀释后每股收益同步提高。若这些出现，应修改经营和资本路径，而不是为维持旧判断机械压低倍数。

尚未解决的主要未知：完整PPA证券条款、Cogentrix逐厂对冲/维护、Helix基金费用和租户清单、Moss Landing最终赔偿、9月底商品额度续期、9月7日实测资本余额以及可比一致预期的定义/更新时间。本研究已给净费、投入、概率、资本口径与时间延迟的工作范围；未知仍可能产生新价值，不能把模型覆盖以外的机会称为已否定。

### 7.3 必要复算方法

每行概率更新（N/P/S/F顺序），设转移向量为a/b/c/d/e/f：
```python
next_N = N * (1-a-b)
next_P = N*a + P*(1-c-d) + S*e
next_S = P*c + S*(1-e-f)
next_F = F + N*b + P*d + S*f
assert abs(next_N + next_P + next_S + next_F - 1) < 1e-10
expected_revenue = sum(p[k] * revenue[k] for k in range(4))
expected_cash = sum(p[k] * (ebitda[k] - max(ebitda[k], 0)*0.25
                           - capex[k]) for k in range(4)) - new_failure_cost
```

H基金再跟踪`(状态, 实缴资本0.5或1.0)`，对首次符合追加条件的联合分支出资，再计算其净分配及Y10权益。不能把平均投资额乘平均成功概率，因为两者相关。以上概率以当前信息固定的转移假设计算未来分布；未来获得证据时，应更新整个条件分布，再重估剩余现金。

从业务表到集团表：先把九个核心净贡献相加，再加H/U期望EBITDA；经济收入按3.2量价/抵销公式；毛利−销管=EBITDA、EBITDA−D&A=经济EBIT；CFO−生产资本=报告FCF；报告FCF+税后利息−未来股份报酬=估值FCFF。现金、还债和回购按3.3逐季/逐年滚动，债务降到8B后的余款转入现金，不出现负债务。目标日基金价值以其后净现金和Y10权益折现，不能再加当年账面NAV。

早期机会Y10资本、净收入和状态概率继续影响终值，并通过12%ROIC约束新增名义增长投资；完整成功表仅是反向敏感性，没有与期望值相加。比值、复合回报使用未圆整参数计算；正文表保留1—3位小数供审阅，不表明预测有该精度。

### 7.4 交付校验与限制

- 四行情景历史事实相同；未来研究季与研究年EBITDA、CFO、资本、FCF闭合，首年季度资本桥与全年一致。
- 4×10×2组当年状态分布使用双精度计算均合计100%；失败吸收、成功持续/退化与追加资本按同一时间路径计算。
- 四行使用相同6/12/36个月目标日；主矩阵与十二格明细直接取同一计算结果；三年回报含现金分红并另列年化。
- Cogentrix现金、承债、5M股配对；Nuveen本金减少现金与已计债务；回购同时减少现金和股数；项目债与优先股未遗漏。
- H基金不并表；H供电是对原市场售电的净增量；U新增物理发电在原核电之外；相同PPA、容量/PTC和早期失败风险均未再加/扣一次。
- 报告FCF与估值FCFF分开，持续股份报酬、税盾消耗、维护/成长及终值新增长投入均有位置。
- 未完成的验证是合同净价与证券条款、逐项目精确预算、完整卖方共识、9月7日实测资产负债和未决诉讼最终结果；模型数值闭合不能代替这些外部事实。
