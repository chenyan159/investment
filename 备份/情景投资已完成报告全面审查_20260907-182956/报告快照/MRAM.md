## 1. 当前投资判断与研究口径

**按 16.37 美元买入，短期不建议投资，中期不建议投资；长期稳健投资不建议，高风险技术投资宜中性 / 等待。** MRAM 有真实产品资产和值得研究的新技术，问题是当前约 3.99 亿美元基础市值、约 3.88 亿美元计入存量奖励后的经营价值要求，已明显超过本报告正常兑现路径。股价较高点大幅回撤，没有消除其对新品、持续增长和股东现金的要求。

**最弱价值传导环节**有两个：从技术/客户选择到可复购的净新增产品毛利；从有期工程毛利到扣完迁移、持续研发、诉讼与奖励后仍能留下的每股现金。次要债务不是主矛盾，但多个现金支出同时发生会产生融资断点。

客户结构也不能只看长尾数量：2025 年有超过 1,405 个购买终端，前两大终端合计收入占比 33%；H1 经销商收入约占 83.6%，与终端客户集中度是不同层次。多数产品订单允许客户推迟、减少或取消；design win 不是不可撤销采购。2025 年披露 238 个定点，年报季度合计 237，差一项不影响方向，却说明不宜用此数精算转化胜率。3–18 个月导入周期支持逐步爬坡，不支持发布后瞬间铺满终端。[L1][K]

### 3.2 新机会的量价边界、状态与联合路径

**U：UNISYST 净新增器件业务。** 有利应用是更新频繁、失电成本高、独立容量不能轻易集成的系统；代码极少更新且成本敏感的客户可以继续用 NOR。完整成功的 2029 基准收入 35，相当于 175 万颗 × 20 美元净新增收入/颗；2036 为 220，相当于 1,100 万颗 × 20 美元。突破完整成功 2029 为 87.5、2036 为 550，可对应 437.5 万/2,750 万颗 × 20 美元。**净新增**已扣换代对旧 SKU 的毛利/销售占用，不再向集团重复加被替代旧品。

这些用量不是已获得订单。以每个成熟平台 5–20 万台、每台 1 颗计，2029 基准规模成功需要约 9–35 个实质量产平台；突破需要约 22–88 个。它们要从公司现有客户/设计网络转化，而不是以整个边缘 AI 装机为分母。若净增 ASP 仅 10 美元，所需台数翻倍；若 40 美元，则减半，但客户 BOM 节省需足以支付。合理工作边界为：早期若干平台年收入 1–10；多个平台重复采购后 2029 净增 15–90；5–10 年更广泛采用时完整成功 100–600。高于此范围需要消费/汽车大平台与成本资格证据；低于此范围包括工程可行但只能自我替代。规模压力也会吸引 NOR 降价和 eMRAM 集成，故没有在高数量上另加无限 ASP 和毛利上升。

**P：系统/平台净收费组合，不是一种完整 AI 芯片。** 为避免漏掉尚早但重要的路径，模型显式纳入 CXL 持久缓冲、AgILYST / BEOL / IP 与额外 TMR / 授权三个经济池：
- 有限成功时，收入约 80% 为 CXL 公司器件净额、20% 为新增商业 BEOL / IP；成熟规模时分别为 **70% / 25% / 5%**。已获资助 CHEETA、Frontgrade 工程仍在“其他”，P 只计后续商业增量。
- 基准规模毛利 60% 来自 CXL 55%、BEOL/IP 75%、新增小业务 55% 的加权；有限成功 42% 来自器件 38%、IP 58%。乐观/突破各提高约 2–3 个百分点，原因是批次与应用复用，非整机软件毛利。悲观 35% / 50% 体现试点和规模仍受压。下表另扣平台人员、研发、资本和周转。
- 基准完整成功 2031 P=30、2036 P=200，其中 2036 CXL=140。若每套系统公司净器件收入 200–500 美元，需 28–70 万套/年；BEOL/IP=50，需要有约定费率的量产芯片/晶圆，不能把合作方整机售价计入。突破 2036 P=500，对应 CXL 350、BEOL/IP 125、小业务 25，是强成功范围，不是现有合同。
- 可触达系统规模、实际净价及 IP 分成未披露。本报告收敛到**2029 商业收入 0–15、2031 规模成功 15–75、2036 规模成功 100–500**的低置信范围，基于从付费试点到可重复平台的时间和公司当前规模约束。若只能出售低价裸片、客户无需持久缓冲或软件消除瓶颈，P 接近零且仍花研发费；若拿到多个主流平台及制造收费权，上述上沿才有机制。
- “单位数量×收费”只能校验门槛，不能证明存在那些订单。本报告不给 AgILYST 最终成功添加无限 TAM；最需要的新证据是具名最终付费客户、整机掉电与工作负载结果、净收费合同、合格批次。

**采用四条共同技术/商业路径而非独立抽签。** 路径 A 失败退出、B 延期后放量、C 长期小众、D 快速规模。U 和 P 共享知识产权、工程人力与客户预算，路径相关；D 中两个机会都成功是明确的联合假设，其概率不是把独立成功率相乘。P 内不同技术只是这个组合的条件商业分配，不能把三个子市场各自上沿再相加。另在第 6 节检验“U 成功、旧业务普通”的交叉组合。

### 4.2 按期限采用的理念与预先要求回报

门槛在评级前固定：短期6个月主要路径要求至少**15%**总回报；中期12个月至少**25%**；长期高风险成长要求**20%年化，即三年72.8%**。它们是对小规模、产品/客户集中、价值确认时间和流动性误差的研究要求，不是预计收益。经营风险已经进入路径与状态，不能再以同一失败事件反复罚分。DCF的12%–15%只承担当期时间价值、系统性/估计补偿；更高的买入门槛用于保留价值识别与价格采纳余量，不再次按失败概率扣价值。

稳健现金理念通常要求更高下行保护，即使三年回报上沿很好，也不接受尚未解决的收费/资本条件。里程碑投资允许没有当期收入，但需要目标窗口确有能排除失败解释的新证据；高风险突破允许损失大，但仍须有可辩护的正期望，不能以巨大上限代替概率判断。

本报告主矩阵的短期、中期按**条件经营路径的现金价值及证据重估**，长期按**持续成长/技术商业化价值**。因此突破行若路径成立，可以得到正面评级；当前实际选择仍须评估该行是否可达。没有将12个标签投票，也没有将四行等权。

事件依赖次序为：**技术可用 → 可制造/客户认证 → 付费采购 → 复购及净毛利 → 股东现金**。诉讼、资金和团队带宽横跨各阶段；同一STT冲击不能在每一新品上当成相互独立的小概率。经营发生可能早于财报确认；投资者可以在复购证据出现后提前接受远期价值，却不能无新证据因日历前进就认定最终成功。

### 4.4 按目标日估值，保留真正的方法分歧

正常、乐观、突破的主估值是**目标日之后剩余现金流的联合路径DCF**；短期依然允许里程碑先于利润，但主格不把预计交易倍数当合理价值。使用2027–2036逐年V，目标日前已发生现金进入资本桥一次；目标年仅剩余部分进入DCF。年内现金近似均匀产生，折现用该剩余时段中点。终值在2036年末计算后折回各目标日，**三年持有不是只算三年现金流**。

参数下沿 r=15%、g=2%；工作值 r=13.5%、g=2.5%；上沿 r=12%、g=3%。工作值直接由这组明确参数与相同经营路径计算，不是取区间某个任意分位。终值 `max(0,V2036×(1+g)/(r−g))`；保留最后一年全额维持/增长资本与研发费用。高增长期到2036后降至2%–3%，没有把新品几十个百分点增长永续。负持续现金不能产生负无限终值；期间失败成本仍扣除，不把负现金简单全删。

悲观现金持续弱，主方法改为**目标日可出售/重整的经营资产权益**：经营净值12–35，另加期末现金、除已融资稀释股数。低端可由应收/专用库存/设备折价变现，加有限IP/客户关系，扣执行与承诺清理成本组成；高端要求买家愿为剩余资格和客户付费。该经营价值仅约当年收入0.2–0.6倍，是清理/转让条件边界，**并无现成收购报价或资产底价保证**。12与35不包括另加的现金，不再加账面全部资产；无法融资、重大禁售或救济额更大时可低至零。悲观的未来经营表展示继续经营后果，退出价值展示届时转让选择，不能将两者再叠加。

资本桥为：
```text
分支股权价值 = 分支经营价值 + 目标日现金 + 价内存量期权行权款
               − 未在经营/现金中计入的优先索取权
分支每股价值 = max(0, 股权价值) / 分支完全稀释股数
本行情景每股价值 = Σ 联合路径权重 × 分支每股价值
总回报 = 目标日每股价值 / 16.37 − 1
三年年化 = (目标日每股价值 / 16.37)^(1/3) − 1
```

模型内银行债/优先股为0；租赁/软件现金已扣，故资本桥额外扣款为0，不意味着义务不存在。没有现金分红、再投资分红或回购。稀释后股权价值区间按分支股权价值加权；每股价值先分支相除后加权，分支股数不同的时候不可用两个平均数直接相除。

**终值依赖很高。** 以15%/2%参数，6个月/三年经营价值中2036之后终值占比：基准约62%/65%、乐观约61%/62%、突破约65%/64%（四舍五入）。这不是有证据的资产保护。完整快速成功路径D另作上行参照，不能与主格相加，也不能拿其替换已经加权的主格。

真正会改变判断的理念分歧如下：

| 理念 | 同一经营路径下的价值来源与买入条件 | 拒绝或保留理由 |
|---|---|---|
| 现金安全边际 | 可实现现金/经营资产，持续股东现金；不依赖多年后新品收成 | 现有现金仅覆盖买价约11%；工程利润有期限。按现价三个期限均难成立 |
| 盈利持续期/特许经营溢价 | 若2029以后费用可调整、现有产品持续增长，可用前瞻EBIT/盈利交叉检查 | 以基准2029 EBIT约4.9、21%税、22倍经营收益，经营值约85，加现金约49后约5/股；到期后NTM EBIT约9.2对应约7/股，均不支持16.37。倍数为检验假设，不冒称市场同业中位数 |
| 里程碑交易 | 市场可能在样品、有利法律信息、客户验证后先接受未来收入，适用于3–6个月 | 尚无可校验事件弹性；价格可能高于DCF也可能利好落地不涨。**可能交易回报为NA**，不是条件合理回报为NA。解除限制要有付费订单/可比事件与实时流动性数据 |

## 6. 当前路径、价格边界与最强反证

for scenario in scenarios:
    for branch in branches:
        cash = cash_2026_end[scenario]
        diluted_shares = 26.584744
        old_wc_U = old_wc_P = 0
        for year in range(2027, 2037):
            # state determined by first_L, first_S, first_F; failure is absorbing
            U, P = state_economics(year, scenario, branch)
            revenue = toggle + stt + engineering + other + U.revenue + P.revenue
            gross_profit = toggle*gmT + stt*gmS + (engineering+other)*0.85 + U.gp + P.gp
            opex = core_opex + litigation + NRE + old_SBC + new_SBC + U.opex + P.opex
            EBIT = gross_profit - opex
            interest = 0.03 * cash
            tax = max(EBIT + interest, 0) * tax_rate
            NI = EBIT + interest - tax
            delta_wc = core_delta_wc + U.delta_wc + P.delta_wc
            capex = core_capex + U.capex + P.capex
            CFO = NI + DA + old_SBC + new_SBC - delta_wc
            FCF = CFO - capex
            V = EBIT - max(EBIT, 0)*tax_rate + DA + old_SBC - delta_wc - capex
            cash += FCF
            diluted_shares += new_SBC / assumed_grant_price[scenario]
            while cash < 15:
                cash += 25 * 0.97
                diluted_shares += 25 / issue_price[scenario]
            # Expected shortfall is funded at the start of that year in target-date bridge.
        # value each branch separately; source of tail cash is V, not adjusted earnings
        EV_at_target = sum(remaining_fraction * V / (1+r)**midpoint_distance)
        EV_at_target += max(0, V2036*(1+g)/(r-g)) / (1+r)**distance_to_2036_end
        share_value = max(0, EV_at_target + cash_at_target + option_proceeds) / target_shares
    scenario_share_value = sum(weight[b] * share_value[b] for b in branches)
