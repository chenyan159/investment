## 一、当前选择、主要分歧及研究时点

**当前20.12美元买入：短期不建议投资，中期不建议投资，长期在现金回报理念下不建议投资；增长持续性投资者的长期条件判断可为谨慎建议投资。** 这项分歧来自对利润转成可分配现金、2030年代增长持续期和资本成本的不同要求，不能合并成一个“综合目标价”。本研究最接近基准经营路径：航空服务、国防和动力系统继续增长，尚不足以确信集团已经进入突破路径。

**决定性发现。**

1. 民航不是普通的“卖设备再收服务费”。TotalCare按飞行小时收款，长期服务按履约成本进度确认；耐久性改善可让维修收入确认变慢，同时提高全合同利润和未来现金。2026H1净合同及经营改善收益0.497，相比上年0.288，解释了民航利润增量的约56%。真实改善与确认前移同时存在。[L1；F1]
2. 动力系统扩张证据强于“纯概念”：订单、采购渠道和扩建均有依据。但备用、燃气主供电、储能的收费权和利润率不同，不能把整个数据中心电力预算变成mtu收入。[L2；P1；P2]
3. SMR已产生早期工程收入，采用权益法；不能将SMR全收入、核电站资本开支或发电收入归到集团。UltraFan的长尾价值可能大于近期利润贡献，本研究将其现金延伸至2045年，未静默归零。[F2；N1；N2；T1]
4. 现价的主要问题是**成熟业务的现金定价已经昂贵**。按公告普通股本计算市值约167.37十亿美元，约123.82十亿英镑；以2026FCF指引中点3.9计算收益率约3.15%。不能仅凭SMR小幅增加期望价值，就填补现价与现金估值的距离。
5. 本研究利润基准并不悲观：2028集团EBIT约5.85，略高于官网7月旧一致预期5.544；但FCF约4.53，低于旧一致预期5.314。**分歧主要在现金，不是完全否认公司增长。**

### 3.3 重要早期机会的规模、资金与时间

**燃气主供电。** 基准“部分成功”2028收入0.40、“规模成功”0.90；不是概率加权后的收入。以设备归属净收入约£0.35—0.60百万/MW、少量服务计算，规模分支约需1.4—2.4GW年交付；2036规模分支4.8，扣约10%服务后需7.2—12.3GW。该上限明显高于当前可验证mtu主供电，必须新增核心件、测试、渠道和售后。按数十GW可服务年需求及10%—25%份额才可能接近；行业当前可去重订单样本不能证明2036市场点值。故基准2036期望收入约2.81，低于4.8，且仍是低证据推断。突破规模分支乘1.65至7.92，需更多全球工业/园区需求，不能只靠当前美国AI项目；同期成熟Power增长已扣除被燃气替代的备用部分。若电网提前接入或INNIO等夺单，退化和退出概率上升。[L2；P3；E]

**SMR。** U不是零收入：表示早期收费工程但未进入可复制建设；P为有限项目设计/设备包交付；S为多个场址进入重复供货、净收益改善。英国第一阶段0.359按3—4年仅约0.09—0.12/年，再加捷克与瑞典工程才能扩大；不能凭七台选择提前确认全部建设。基准2031的U/P/S收入0.21/0.61/1.10，2036为0.24/1.26/3.85。后者要求每年约1—2台等效供货、每台可归属设计设备范围£1.5—2.5bn并有少量服务；不是整站售价。突破3.85×1.5=5.775，需更多并行项目。合作方拿走汽轮机、土建等收益；净价、责任和担保未公开，规模区间为E，不能宣称官方订单预测。[N1—N4；L1]

**UltraFan。** 2028地面示范可在收入前改变定点概率；量产引擎与长期服务主要在2030年代甚至以后。基准2036 P收入0.50、S收入2.45；突破S为4.165。以每台归属净收入£3—5百万、加部分研发许可和初期服务，突破分支需要约700—1100台等价交付，已相当于一个大型平台的显著份额；并非自动获得所有窄体发动机订单。成功早期自担工程和低利润OE先压现金，2037—2045服务队列成熟后才增加现金率。本研究2036后成功分支收入按10%增长至2045，届时突破S约9.82；要求市场、产能和份额均保持，之后转2.5%永续，不永久维持10%。未被选中的设计2037关闭，不让失败项目随日历复活。[T1；E]

先进高温堆、空间微堆、氢与数字技术未可靠限定净收费范围，保留机制而不赋伪精确市值：客户出资的工业示范、场址/许可与长约是纳入独立金额的门槛；未来3年母公司可选自担额度工作上限约0.05/年，已在总部预算中，不重复加期权。若公司承诺大额自担建设，就超出本估值覆盖范围，须重建资本路径。内部AI维修优化已通过耐久与费用体现，不另外估为软件平台。

### 4.2 主估值：目标日剩余现金，而非今天现值冒充退出价

主矩阵统一采用**现金可分配能力的条件合理价值**。RR有成熟服务资产，但净利润受重估、对冲、税和权益变动干扰；报告FCF又含客户预付款和再投资，所以选择拆分后的现金DCF作主法。短期同时检查滚动NTM利润和价格采纳；不要求价格在半年内收敛至DCF。增长持续性方法独立保留，见4.3。

1. 核心营业现金已扣全部维持及成长投入、现金税、履约资金和租赁支付，包含主供电行内加权经营；从目标日到2036按年度中点折现，目标年只算剩余年分数。目标日前现金由3.7的余额或分红体现一次。
2. 核心折现率8.5%—10.0%，终值增长2.5%，均为**英镑名义研究参数**，不是当前无风险利率的事实点值。可理解为约4%长期名义基准加4.5—6个百分点系统性经营补偿；需求损伤已在情景，不能另加同一个“悲观概率罚分”。
3. 2037起税率25%，再投资=经济税后利润×g/ROIC，悲/基/乐/突ROIC为10%/16%/20%/23%。高速增长后必须留资金更新；租赁从利润与现金两端转换为经营租金口径，终值不免费使用租赁资产。
4. 核心DCF把租赁付款当经营费用，因此资本桥用**不含租赁债务的金融净现金=3.7经济净现金+1.65**，不能重复扣租赁。相反4.3的IFRS EBIT企业价值倍数桥保留租赁债务，以公司式净现金相接。养老金以现金支付计，未再扣缺口；客户合同负债也未重复扣。
5. SMR独立按归属净现金折现至2036，再仅对仍处P/S的可持续正现金接终值；其折现率9%—12%。UltraFan至2045，之后终值2.5%，折现率10%—13%。这些率反映等待与未被状态树计入的系统性资本风险，不再将同一技术失败价值乘一次成功率。
6. 机会期望NPV允许负数：这表示继续履约/研究及关闭的净支出，非“负股价”。公司可退出的分支已通过F停止后续费用，不假设永远烧钱。
7. 主矩阵两端来自同一经营路径的资本成本区间，SMR主工作折现率固定10.5%，UltraFan固定11.5%，与各自阶段和资金等待相配；9%—12%及10%—13%仅作利率敏感性。机会金额较小，全部取低端也不改变基准评级。中枢如需展示，固定核心r=9.25%，而非目标价高低端的机械中点。

主式：

```text
核心EV(t) = Σ[目标日后核心FCF / (1+r)^(现金中点-t)] + TV2037/(1+r)^(2037-t)
TV2037 = { [EBIT2036 + 租赁折旧2036 − 租赁现金2036]×75%×1.025×(1−2.5%/ROIC) − 0.10 }/(r−2.5%)

             + 经济净现金(t) + 1.65租赁口径调整 − 0.020696 C Shares

```

### 4.3 真正保留的理念冲突

现价约£14.89/普通股，IFRS风格EV约122.1；以核心现金法将租赁作为经营，所需经营价值相应少约1.65。多组反向组合而非唯一“市场共识”：

- 按22/24/26倍前瞻EBIT资本化，相同约122.1 EV分别要求EBIT5.55/5.09/4.70。2026指引已接近26倍组合，但22倍要求更高后续利润。这并未证明22—26倍本身合理。
- 按约3.2%/4%/5%股权FCF收益率，约123.8市值对应可持续FCF约3.96/4.95/6.19。管理层2028FCF目标可以接近4%收益率，不代表已经提供12%年化回报。
- 基准2036核心EBIT约10.74、核心现金约8.44，已经很大幅增长；在核心r=9.25%、g=2.5%下，三年每ADR仍约16.41。要仅让该退出价接近当前20.12，核心折现率需降至约7.9%，或提高长期现金/延长高速增长期。要再满足三年12%年化，需要更强改变；不是只把SMR概率上调一点。
- 官网7月2028FCF5.314与本模型4.53相差约0.79；若**每年**核心现金都稳定高0.79，三年价值约增加1.8美元，仍未足以让基准跨越12%年化门槛。若仅2028一次多0.79，主要经净现金增加约0.13美元；不能把一次释放永久化。

主供电的基准概率转移整体延迟两年、采用同年净价并保留验证支出，2029期望收入从约0.574降至0.340，2031从1.305降至1.022，2036从2.813降至2.757。到2036的累计折现现金及目标前余额差约-0.03/ADR，未含终值变化；这项小影响来自初期投入也延后以及后期追赶，**不适用于永久失去份额**。若主供电最终规模本身减半，须同时降低利润和终值，而非沿用“只延迟”的小损失。

SMR每年P/S概率下降时，多出的质量只能进入U或F；不能让四状态概率都取有利端点。若只是延期，U继续有工程收入也有研发支出；若失败，支付关闭成本然后停止。基准SMR2029 U约68.2%、P约20.3%、S为0、F约11.5%，说明三年内最有价值的证据是**第二阶段合同、FID和净风险分担**，而不是反应堆发电收入。将其未来正现金整体后移三年，在10.5%折现率下那部分现值约乘1/(1.105)^3≈0.741，现有前置费用不能同样延后。

### 6.3 完整成功、原业务普通与概率门槛

必须检查“新机会成功而原业务只是普通”的组合。用基准成熟业务及基准集团股数，另将SMR改为2029有限建设、2032规模供货，将UltraFan改为2029有限平台/工程、2033规模供货，均沿突破收入规模和已扣成本的成功分支继续发展；不对这些已假定成功再乘同一成功率。

在统一10%机会折现的**完整成功参照**下，2029剩余SMR归属NPV约3.48、UltraFan约7.53；合计约11.01十亿英镑，折每ADR约1.88美元。替换基准原有机会期望净值后，三年工作价值从约16.41提高至约18.2—18.3；不是16.41再加全部成功价值和原期望值两份。此组合未让成熟业务自动享受突破利润，也没有让集团免费拥有整站资产。

因此，在本研究可约束的供货和权益范围内，**SMR与UltraFan强成功也不足以单独支撑现价的三年12%要求回报**。这不否定它们创造价值，而是说明买价要得到的额外经济价值更大；若出现显著高于本工作范围的平台份额、许可收费或资本效率，应重估，而非把未知路径永久定为零。

另一反向门槛只作敏感性：假设世界仅有基准与突破两种完整路径，以固定r=9.25%的各路径条件价值及分红计算，要达到20.12×1.12³=28.27美元，突破权重约需**88%**。这是假设模型的门槛，不是本研究估计的发生概率；加入悲观会进一步提高门槛。不将局部SMR成功率、主供电规模成功率或矩阵正面格推成88%的整股胜率。

成功规模与概率有关：更大主供电份额意味着更多资本和竞争反应；更大的SMR供货范围可能伴随更低净毛利与更重担保；UltraFan更快定点意味着更早研发支出。不能一手用低投入的小成功概率、一手拿高规模完整成功收益相乘。

### 6.4 结论覆盖与解除限制

当前不能量化到精确点值的关键项是：分机型LTSA寿命/取消条款，V2500到期净收款、mtu主供电实际运行与服务收入、SMR第二阶段净供货价/保证责任、UltraFan合作权益。报告已用机制、范围和反向门槛处理，没有将未披露视为零；但它们限制估值置信度。

最有价值的新信息依次是：现金指导与真实库存释放、客户耐久性验证、主供电带现场验收和维护条款的连续订单、SMR风险分担明确的FID合同、UltraFan付费平台工程及量产份额。只需要其中对主要价值传导有作用的证据改变即可重估，不要求所有故事都成功；同样，也不要求等到2035电站发电才承认SMR有价值。
