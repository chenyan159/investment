### 2.3 行业输入实际如何进入模型

- 前道材料报告的投片、层数、材料强度和认证逻辑进入既有EM增长与Mo扩量概率。其2028市场规模预测**不直接进入公司收入**；如果行业增长来自硅片/光刻胶而非MTRN供货步骤，EM也可能只增长个位数。[L2]
- 封装/热界面报告用于检验热阻、热膨胀和可靠性要求；没有证据证明Materion取得主流GPU热界面材料大份额，故未加入GPU出货×任意BeO金额的收入。[L3]
- 连接报告说明平台认证及光/铜架构变化。光互联替代长距离铜连接，可能降低某些金属接触材料含量；公司仍可在其他高规格接点增长，但不能继承整机连接器的ASP与利润率。[L4]
- 最新核能补充：CFS在2026年6月发布更新的ARC物理基础，8月称完成前概念设计与路线图里程碑，SPARC建设接近80%；这些提高技术路径可信度，**仍不是商业电站运行或Materion大额确认收入**。2015年ARC盐库存算例只能作为实物数量级，不能充作新版最终BOM。[N4][N5]

### 2.4 财务质量、资本结构与治理

2025年集团VA仍低于2023年，2026增长部分来自恢复。PCS2025Q4约27.3质量特殊费用及2026Q1约3.5后续费用，是供应商承担失败成本的实例。收购摊销可从短期会计EPS加回，却不能删除历史并购资金；研发25.9（2025年）已进入费用，不另加一次资本化价值。客户共投也不是免费无条件赠款：设备运维、产品履约和可能返还义务仍在公司。[L1]

H1现金改善伴随应付与应计项增加；Q2单季高FCF不能年化。模型按全额厂房及矿山开支计算报告FCF，另将新增股份报酬按等额现金抵补处理，得到用于股东价值的现金。历史SBC8.635不代表现金利润；未来新增报酬既不永久加回为免费收益，也不同时使用无限制净回购提高每股价值。[F1][L1]

债务本金442.332与账面440.688相差未摊融资费，全文采用本金。长期融资租赁及退休福利另设合计32的经济索取权储备，覆盖已披露长期融资租赁12.671、退休福利23.155及折现/部分经营支付的净差；工作值合理范围25—40，差15仅约0.7美元/股。经营租赁租金已在经营费用中，不再把全部58.170长期经营租赁债务扣第二次。预收货款通过未来经营现金与履约处理，不又当免费现金或普通债务。没有已发行优先股，也未识别需单独建模的大额可转债、ATM或少数股东资本层。[F1][L1]

寄售金属505.6属表外原料安排，不能全部当有息债务；但额度总计850、到期2028年8月、当期可用344.4，足以形成资金约束。金属涨30%可占用约151.7额外额度；不可转嫁费率增加1个百分点约减少税前利润5.1。循环贷款剩余额度约232.7、主要债务2030年到期；三年退出仍应考虑其后的再融资，而非认为期限外就无影响。[F1][L1]

治理与执行重点是Jugal Vijayvargiya团队的质量系统和资本纪律。2025无年度现金激励及光学减值表明激励与股东损失并非完全脱节，但不能据此证明资本配置可靠。国防/EHS、铍职业暴露、矿山及提炼许可是维持性费用和尾部风险；模型没有假设可取消合规投入。黄金保管争议按现值约6.7减潜在保险2.5的净损失约4.2作敏感性，未将未决诉讼写成已支付款项。[L1]

## 4. 按期限估值、信息窗口与理念分歧

### 4.1 先定要求回报，再看结果

短期主理念是“有现金价值支撑的事件重估”，6个月要求总回报8%；中期为经营与现金兑现，12个月要求15%；长期为扣除所有再投资后的持续复利，要求12%年化，即三年40.5%。高风险技术/商业期权参与者可要求18%以上年化，并必须接受50%以上永久损失。门槛是本研究的投资选择标准，**不是预期回报，也不对估值再乘一次风险惩罚**。

9月4日美国国债6个月收益率3.98%、一年4.13%、十年4.78%，构成机会成本参考；股权期限回报门槛还需覆盖经营和估值误差。[R1] DCF中的系统风险以折现率体现，局部技术失败已经进入机会现金路径，不能再将整股乘一个“成功概率”。

主矩阵最终选择**各目标日剩余FCFF的DCF**。原因不是预设所有公司都用DCF，而是MTRN的客户预付款、矿山/成长投入和利润率变化，使“高增长×高倍数”与真实可分配现金严重分离。初步盈利倍数校验确实给出更高交易价格，但不能作为合理现金价值的替身。不同期限仍使用不同的退出资本、剩余现金、已获信息和投资逻辑。

DCF逐季度计算目标日后的现金，目标日前现金仅进入现金/净债务或分红一次：
`EV(T)=Σ FCFF(q, T之后部分)/(1+r)^(距季末年数)+TV2036/(1+r)^(距2036末年数)`
`TV2036 = NOPAT2036×(1+g)×(1−g/ROIC)/(r−g)`
`股权价值(T)=EV(T)−净债务(T)−其他索取权32`；
`每股价值=股权价值/目标日FD股数`。
终值增长必须以再投资率g/ROIC支付；过去已付成长费用的未来收益保留在显式预测及终值里，没有既扣全额资本又另加未扣成本项目价值。

低端参数r=11.5%、g=2%、终值增量ROIC12%；高端r=9.5%、g=3%、ROIC18%。两端是相容的估值假设，不是预测分位数。**工作值**独立采用r=10.5%、g=2.5%、ROIC15%，并非区间中点或75%分位。终值阶段不再维持十年前极高的新增资本回报，理由是客户多供应、产线扩建与核心业务成熟；若技术垄断维持到2036后，必须提供额外证据，不能仅提高上沿。

2036核心/机会已经包含在同一个现金路径中，主DCF**不再另加核能期权**。未来失败风险以状态现金反映，折现率9.5%—11.5%不因“核能成功概率低”再机械提高一档。目标日前的核能投入已在资本桥出现；只有其后的剩余投入和收入参与退出估值。

### 4.5 当前价格反向要求

研究日基准推算净债务402.3、FD约21.094，244.24对应FD市值约5151.8、含其他索取权的经营价值约5586。基准研究日NTM EBITDA约290.1，当前约19.3倍；按2026中点EPS7.0为34.9倍。原始quote的forward EPS8.43对应29.0倍，但其具体财年、调整口径与分析师更新时间不明，不当作已核实2027共识。[L5]

1. 若接受20倍NTM EBITDA，需约279 EBITDA；当前可达到，但如此倍数要靠较长增长和现金释放验证。

这说明“当前19倍EBITDA不比热门材料公司贵”可以成立，同时“当前价格缺乏足够现金收益”也可以成立，争议在收益持续期、再投资和资本回报。对没有可比会计期间的forward PE，不采用精确共识差百分比。

### 6.2 概率、成功规模和等待

B基准2031当年规模采购概率约10.1%，2036约22.8%；它们不是累计科学成功概率。对B转移做有效分布敏感性时，可把U→P与P→S分别提高/降低50%，从原状态留存概率补足，不改变F吸收；或者将所有商业状态整体延后两年，把延期期间U成本保留，不能只把收入平移而删除研发。A的关键敏感项则是客户/节点的实际增量净费和对旧材料的蚕食，单一“技术成功概率”不足概括。

有边界的强成功参照：以**基准原有业务保持普通**，在2029-09-07获得可信证据，假设A、B从2030起均达到各年S状态、之后持续到2036；加权路径被完整成功路径替换，新增周转按2029实际期望基数跳升，资本和税照扣，不能把成功收入直接加回净现值。按工作折现，增加约533经营价值、24.9美元/股，三年退出价值约**176.1**。2036对应A收入265、B收入300；它们是条件规模，未与期望值重复相加。

这项“新机会成功、原有业务普通”的组合检验很有区分力：即使如此，176仍低于244买价，更低于达到12%年化所需的约341.4退出价。若线性用该增量反求突破价格缺口，所需成功权重远超过100%，所以**单靠提高这两个局部成功概率不能挽救当前整股投资逻辑**；还需原有平台规模/利润、成功规模或资本效率大幅超模型。这个门槛不是实际概率判断。

更大胆的B路线可以超过本报告S规模，例如多个大型项目每年连续采购。但基准三年工作价值距341.4尚差约190/股、经营价值约4070；若主要靠核能在2033后产生现金，按时间价值粗算需要每年数百百万的持续净现金。按净现金率15%意味着数十亿美元材料VA，再按200美元/公斤归属加工费需要万吨级BeF₂年度交付，远高于当前实物供应和已知合同所能直接支持的量级。不是物理上永远不可能，而是需要新的矿山/高纯工序、客户共投与多电站采购证据，不能从一纸供货协议跳过。

最早能排除失败解释的证据：MTRN披露新前驱体重复收入或客户侧量产导入，可排除“只有产品目录”；CFS工程/氚系统验证与确定材料BOM，可降低“物理可行但材料路线变更”；不可撤销数量、净价格和分期预付款，可排除“终端成功而供应商收益很低”。SPARC Q>1只触及其中一层。

等待代价是真实的：如果现金与客户证据在财报前被市场提前理解，股价可能先进入辅助交易价格区间，使更好的经营对应更差的买价。但提前参与也不是自动有正期望。仅作交易分支门槛算例：一年后成功交易价430、失败85，欲达到15%回报，需要成功权重至少(244.24×1.15−85)/(430−85)≈56.8%。这不是本研究估计的胜率；目前证据不足以赋予这么精确且可辩护的整体概率。

### 6.3 估值脆弱性与资本联合分支

- **终值影响大。** 工作DCF中终值占EV的比例：基准6/12/36个月约54%/55%/61%，突破约67%/67%/70%。主格低置信度有具体原因。r、g、ROIC组合变化已产生完整区间，不能把DCF低端称资产保护。
- **资本比单季调整EPS更能裁决。** 2027—2031若每年CapEx多30且不产生额外收益，其现值约100—115、约5/股；若这些投入确实带来额外订单和NOPAT，必须同时补上收益，不能只扣成本。相反，每年少30但损害未来能力不能当纯增值。
- **单位利润变动。** 基准2029核心VA1505，每下降1个百分点贡献率，税前利润约少15.1、税后约12.6，按剩余持续期可使每股现金价值下降约6—9。公司Q2的有利组合不是永久利润率凭证。
- **税与股本。** 2027以后税率再高3个百分点，基准2030税后利润约少8—9，价值影响约4—7/股；目标FD多5%，每股价值约少4.8%。2025低税率不具永久性。
- **现金断点不能用平均余额遮住。** 在突破资本支出＋国防抵补延后65＋寄售方要求把505.6的50%改现金采购的联合分支，新增流动性需求约318；相对于约233剩余循环额度，有约85缺口。即使业务最终成功，公司也须压缩可选投资、借新钱或融资。若净募100、发行价150、发行成本5%，约新增0.70百万股，约3.3%稀释；若折价至80，约1.32百万股、约6.2%稀释。再加融资延误、资产折价/契约影响，损失会超过单纯股数百分比。
- **下行退出可行性有限。** 取消未来尚未承诺的Mo/核能试验可节省几百万/年，对现价缺口帮助小；停止国防已承诺扩产可能触发客户关系、预付款和合同赔偿，未知成本不能按零。矿山/EHS和维持性投入不能完全删除。
- **业务拆分误差。** 把PM内50 VA从20%利润的合金调整为27%的PCS，在集团VA不变时只增加3.5 EBITDA；无法解释数十亿美元价值缺口。反之PCS丢失订单并闲置工厂，不是同样的小幅重新分类。

最强看多反证应针对模型本身：一是已投入资本的经济寿命和可用余量远高于本模型，以更少新增资本支撑更多收入；二是MTRN取得难替代的工艺平台收费权，2036后仍保持高ROIC与高增长；三是市场长期资本成本显著下降。若它们被证实，本现金法的上界需要系统重建。单纯股价继续上涨只能证明价格采纳不同，不独立证明这些经营假设成立。

最强看空反证则是PCS客户永久减少采购、EM高利润率由暂时组合/一次性驱动、客户资金不按期到位，或核能工程成功却纵向整合压缩材料利润。这些足以让现价与可得价值同时朝不利方向变化。

### 7.3 可复算关键公式与补充参数

状态转移代码（p按U/P/S/F，收入和费用数组在3.4）：

```python
u, p, s, f = states
next_states = [
    u * (1-a-b),
    u*a + p*(1-c-d) + s*e,
    p*c + s*(1-e-f),
    f + u*b + p*d + s*f_exit,
]
# 此处 f_exit 为参数表最后一项；前面的 f 是已退出状态概率。
# 每年从上一年状态递推；F不重新进入U。
expected_revenue = sum(prob[k] * revenue[k] for k in range(4))
# 先计算每一状态利润、资本和税，再加权；
# 新增失败支出仅乘本年新增F概率，周转按路径收入增量计算。
```
