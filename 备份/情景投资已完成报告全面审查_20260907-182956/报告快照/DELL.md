# DELL：经营情景、价值传导与分期限投资决策

## 1. 当前判断、研究时点与价格口径

**以 524.14 美元买入：短期“中性 / 等待”，中期“中性 / 等待”，长期“不建议投资”，分别适用于事件与前瞻盈利、经营兑现、可分配现金复利的主要理念。** 当前最接近基准经营路径：AI交付增长确实发生，传统服务器和自有存储也在贡献利润；但供应短缺租金、未来融资应收投入与客户重复付费的组合，使股东现金价值落后于收入与调整后利润。长期结论针对现价和这套证据；并不否定乐观或突破经营路径的条件投资价值。

本研究与单纯“AI订单高速增长，所以应享受更高倍数”的观点不同之处，是把**传统服务器利润持续性、客户融资投入和付费附着**放在同一条价值链上。最值得观察的不是下一季又有多少标题订单，而是交付增长后，利润是否来自可重复收费，普通自由现金流能否同步改善。短中期按前瞻经营盈利有可解释的估值支持，现金复利法却明显更低，这个方法冲突保留，不取平均。

经营路径支持度：基准中高、乐观中低、悲观中低、突破低；它们不是四行总发生概率。最大限制是未单列AI产品利润、订单取消/改期和融资应收客户集中；截至本次核验未取得7月31日完整10-Q注释，最新明细会计注释止于5月1日。信息缺口进入敏感性与置信度，不写成没有风险或机会价值为零。

### 4.2 三种期限的主要理念及要求回报

估值前采用研究门槛：6个月累计12%、12个月15%、36个月年化15%（累计52.09%）。高风险突破理念可要求年化20%/三年72.8%；现金安全边际理念还要求较弱现金假设能保护本金。这是研究者的机会成本与误差补偿要求，不是预测收益或无风险利率报价；已在经营分支加权的局部失败不再叠加成功率折扣。短期股票波动和数据质量远大于股息收益，微小高于门槛不算稳健优势。

短期主理念为可见经营的重估：FY27结果/FY28指引可能在六个月内改变利润持续期判断，用目标日后NTM经济EBIT与资本桥估值。12个月主理念为经营兑现，仍用滚动盈利但要求普通FCF和客户回款确认。36个月主理念改为现金复利：从目标日计算其后七年FCFF并加相容终值，检验扩大硬件与融资资产后能留下多少股东价值；不将今天折现值冒充三年退出价。

### 4.4 主估值、现金法与方法冲突

6/12个月均用：EV＝目标日后NTM经济EBIT×倍数；股权＝EV＋目标日现金＋可实现投资2−合并债；再除完全稀释股数。悲观9—12倍、基准13—17、乐观15—19、突破17—22。倍数是研究参数：基准相当于计入税后再投资后、长期约5%左右价值增长的较强持续期，显著高于单纯装配的静态现金价值；乐观/突破需要服务与软件价值捕获，不能由AI收入金额独自支持。它们不是观测到的同业精确公平倍数，也不声称短期一定交易在此范围。

长期主估值DCF端点为两套完整参数：低端WACC11%、终值增长2.5%、终值增量ROIC12%；高端9%/3.5%/16%。工作中枢固定10%/3%/14%，非区间的任意位置。对系统性风险使用同组参数，情景经营失败已体现在路径和早期概率中，不额外再乘失败折扣。七年显式期每年末折现，目标日后第七年经济EBIT×79%×(1+g)×(1−g/ROIC)/(WACC−g)作为该年末终值，再折现七年。终值再投资率20.8%—21.9%；不让增长免费持续。

DCF把**全部DFS新增资金、全部CapEx、周转、持续SBC**计入现金，并扣全部合并债，故不能再把融资应收或未来机会单独加回来。目标日前未来SBC以发行股数和现金加回体现，目标日后在FCFF中扣现金等值，未再为同一段未来SBC增加稀释分母。这个时间分段避免双计股酬，也避免漏计目标日之后的报酬。

## 6. 当前路径、价格边界、敏感性与最强反证

### 6.1 当前三期限选择

当前无需混合行：基准本身允许AI高速增长、传统价格正常化、存储稳增和融资占款并存。乐观的量与价得到部分支持，但持续服务收费和普通FCF尚不足以把整家公司放到乐观，更不足以采用突破。四行情景的历史利润完全相同，当前判断来自未来传导，而不是下游报告的标签。

三年现金法进一步作可复核单因素压力：从FY28起AI EBIT率整条路径提高1个百分点、原有量与资本不变，10%/3%/14%三年工作价值约456美元；提高3点约528美元，仍未达到15%年化门槛。融资应收每年新增减半，收入/利润暂不变并同步少发75%对应债，约452美元。后两种改善同时发生还需客户无需融资仍愿意购买、毛利提升无需更高研发等条件，不能机械合并成无成本上行。单因素只用于识别薄弱环节：AI毛利与资金效率改善确实有价值，但基准所需变化很大。

### 6.3 新机会敏感性与组合检验

在其余基准业务普通发展时，按同一10%/3%/14%DCF，三年每股工作值为**420.29**；把早期机会收入、费用、投资整条路径一并移除，得到405.31（仅用于归因，不是认定未知为零）。让数据层FY28起每年均为基准规模S成功、承担相应成本与周转，得到**455.30**；商业化与现金整体延后一年并支付第一年验证费，得到418.53。机会已计入期望值的净贡献约14.99美元，完全成功相对工作值再增加约35.00美元，不能把完整成功价值再加到期望值上。

这就是“新机会成功而原有业务普通”的重要组合：仍不足以支持现价买入三年15%年化所需约789.60退出价。用无机会/完整成功两个端点反求简化成功门槛p＝(789.60−405.31)/(455.30−405.31)≈7.7，超过1；它是不可达的简化门槛，不是实际概率。须提高原有AI利润与资金效率或形成比该机会更大的可收费平台，才会改变当前长期判断。该检验没有证明所有未知技术路线均无价值。

概率敏感性用有效分布而非各状态有利端点拼接：每年U或P的一部分概率转至S，同时同额减少原状态，F仍吸收；反向检验将S转P/F。基准FY30 S=28.61%，若改成48.61%、由P减少20个百分点，FY30当年期望收入增加0.2×(5−1.2)=0.76bn，状态EBIT增加约0.246bn（P与S固定费差也计入），后续必须重算状态转移，不能只把FY30加一次收入后宣称永久成功。更高收费规模与成功概率正相关，必须用对应状态的成本、客户与交付能力，不使用“平均概率×平均TAM”。

最早有价值的信息是可单独核验的付费生产合同、验收/回款及第二次采购。它会排除免费beta和不可重复项目两类失败解释，改变随后年度P→S和S留存概率。等待这些信息会降低误判，也可能付出更高买价；仅产品发布或伙伴名单不足以改变概率工作值。

### 6.4 联合融资分支与最强反证

工作路径没有融资断点，不以平均现金掩盖严重分支。基准一年资本表现金约17.97bn、累计回购6.63bn。额外占款12bn且约5bn债务资金不能取得时，维持原回购只剩约0.97bn；若自冲击发生前取消该6.63bn回购，现金约7.59bn，恢复到6bn运营线以上，股数同时比工作值增加约12.74m（额外股息影响另约数千万美元）。这说明管理应对能避免部分融资损失，但会改变每股结果。

若联合资金缺口扩大到19bn，停回购后只剩约5.59bn，至少再需约0.41bn才能维持6bn运营现金。假设受损发行价300美元，约需1.36m新股；股数由约640.92m，加取消回购12.74m，再加新融资约1.36m，达到约655.02m，现金6bn。少借5bn同时减少债5bn；新增股权只补现金、不能抹掉延迟交付和取消费。上述用一年期汇总静态演示融资边界，未将压力当已发生的损失，也未将不同分支平均成同一余额。若授信与股权均不可用，应收缩采购/交付并承担承诺取消费，转入悲观经营分支；精确触发额仍受最新DFS抵押与到期资料缺口限制。

最强的多头反证是：AI实际出货和客户投运、传统现代化及自有存储同时增长，若连续两三个季度普通FCF随利润提高，且服务/支持开始体现净收费，当前对利润持续期与资本消耗的保守判断会被推翻。最强的空头反证是：公司可通过提高效率和选择性采购减少资金占用，DFS也可能是盈利金融资产；不能把每一美元应收增加解释成坏账。

反过来，最强的不利证据是传统增长大量来自ASP，库存与应付同时扩大，服务收入平淡，融资应收骤增。若供给恢复后美元收入、利润率、客户融资和供应商账期一起反转，AI行业增长仍然可能与DELL普通股严重损失并存。报告最弱传导环节依次是**非AI利润持续性与AI净捕获、增长资金/信用转换、较远收费模式的可重复性**，而不是仅因账面负权益或次要负债否定所有经营价值。

终值中的数据层采用额外明确的成熟化假设：在显式期末仍存续的客户群能通过持续研发和更新投入维持概率加权经济贡献，失败群不恢复，未将成功概率改为100%。它不是让同一产品无需更新永久增长；更新费用由OpEx与终值再投资共同负担。若认为该批产品在其后继续按原吸收链退出而没有替代产品，则该项终值会更低。6.3已给将整个机会连同收入/成本/终值一并移除的更严格对照，基准三年工作价值只减少约15美元，当前长期判断仍相同；因此此不确定性保留但不支配结论。

核心公式（均用未舍入数值）：

```text
季度流量 = 各产品当季收入 × 当年分支率 + 当季早期状态期望贡献
滚动流量[a,b) = Σ季度流量 × 重叠日数(a,b,季度)/该季度日数
经济EBIT E = 调整EBIT - SBC - 持续公司费用
NI = (E - 历史收购摊销 - 净利息) × (1-21%)
CFO = NI + 全部D&A + SBC - Δ贸易及其他周转 - Δ融资应收现金
普通FCF = CFO - 全部CapEx
估值FCFF = 普通FCF + 净利息×79% - SBC
目标日EV_DCF = Σ(其后第t年FCFF/(1+w)^t), t=1..7
             + 第7年E×79%×(1+g)×(1-g/ROIC)/(w-g)/(1+w)^7
目标日股权 = EV + 现金 + 非经营投资2.0 - 合并债务
每股合理价值 = 目标日股权 / 目标日完全稀释股数
总回报 = (每股合理价值 + 持有期间现金分红)/524.14 - 1
三年年化 = (1+三年总回报)^(1/3)-1
价格门槛 = (目标日合理每股价值+现金分红)/(1+要求回报)^持有年数
```
