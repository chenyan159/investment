## 按人物分节的详细发言与观点

### 1. Jensen Huang：AI factory 进入“算力即收入”的财务叙事

- 来源与日期：
  - NVIDIA IR，2026-05-31，发布 Vera Rubin 进入 full production 的公告。
  - NVIDIA GTC Taipei/Computex live update，事件时间 2026-05-31 至 2026-06-01。
  - AP，2026-06-01，报道 RTX Spark superchip 与 Windows AI PC 发布。
- 本周范围依据：公告和会议均在 2026-05-31/2026-06-01 发布或发生。
- 关键观点：
  - Huang 把 agentic AI 定义为新的工作负载：一个 prompt 可触发长链 reasoning、检索、工具调用和响应生成。NVIDIA 因此把 Vera Rubin 说成面向 agentic workload 的 AI factory engine，而不是单颗 GPU 升级。
  - 在 GTC Taipei，他把 AI factory 的经济性从 capex 叙事改成收入叙事，短句是“compute is revenue”。这意味着客户评估架构时，不能只看芯片单价，而要看 1GW 电力下的 throughput per watt、可靠性、系统寿命和 token 成本。
  - Vera Rubin 不是单点产品：五机架 POD 级平台把 Vera Rubin NVL72、Vera CPU、Groq 3 LPX、BlueField-4 STX、Spectrum-X Ethernet Photonics 组合成系统。NVIDIA 公告称 Vera Rubin 相比 Grace Blackwell 可带来 10x agent throughput。
  - 供应链层面，NVIDIA 称 Vera Rubin 生态已有 150 家台湾伙伴、350+ 工厂、30 个国家参与 ramp；Huang 在 live update 中说 Vera Rubin 供应链规模是 Grace Blackwell 的两倍。
  - 网络层面，Spectrum-X Ethernet Photonics 已进入 production，使用 200Gb/s SerDes 与 CPO，公告称相对传统 transceiver 网络可带来 5x power efficiency、5x longer AI uptime、1.3x faster deployment，目标是 million-GPU AI factories。
  - CPU 层面，Huang 把 Vera CPU 称为面向 agent 的 CPU，因为“billions of agents”会连续运行并需要低延迟系统资源。Vera CPU 规格包括 88 cores、1.2TB/s LPDDR5X bandwidth、3.6TB/s on-chip fabric。
  - 端侧层面，AP 报道 Huang 在台北发布 RTX Spark superchip，称 NVIDIA 与 Microsoft 将重塑 PC，AI personal computers 预计 2026 年秋季推出，并支持本地运行 agent。这个动作把 NVIDIA 的 AI factory 叙事延伸到个人 AI PC。
- 产业链判断：
  - NVIDIA 本周叙事的关键变化是“全栈同频”：GPU、CPU、DPU、CPO 网络、DSX 数据中心设计、AI PC、本地 agent runtime 同时对外发布或强化。供应链机会不仅在 GPU，也在液冷、电源、CPO、DPU、安全、存储、端侧统一内存。
  - 对下游客户而言，TCO 的核心变量从“买多少 GPU”变成“每瓦产生多少 token 收入、多少 agent 工作量、多少可用时长”。

### 2. Arkady Volozh：AI cloud 从 GPU 租赁转向 agent 可组合工作台

- 来源与日期：NVIDIA Blog，2026-05-31，AI Cloud Ecosystem 扩张公告。
- 本周范围依据：NVIDIA Blog 发布日为 2026-05-31。
- 关键观点：
  - Nebius 被列为 early adopter of NVIDIA Vera Rubin，并推出 Physical AI Workbench，把 Nebius AI Cloud、Token Factory inference layer、NVIDIA Cosmos 3、Isaac Sim、Isaac GR00T 纳入可组合工作流。
  - Volozh 的核心表态是开发者不应花数周手工连接基础设施；Nebius 要让 AI agents 组合工具、数据和算力，从实验走向生产。
  - NVIDIA 对 Nebius 的定位不只是云 GPU 伙伴，而是面向 robotics、life sciences、enterprise 的 physical AI workflow 平台。
- 产业链判断：
  - AI 云的分化正在从“谁有 GPU”转向“谁能把训练、推理、仿真、synthetic data、机器人评估和 agent orchestration 打包成可用生产系统”。
  - Token Factory 与 Physical AI Workbench 说明云厂商开始向模型/工作流层上移，避免只成为低毛利算力租赁商。

### 3. Jeff Clarke：Dell AI 服务器订单爆发，memory 是主要交付瓶颈

- 来源与日期：
  - Dell Q1 FY2027 earnings call transcript，事件时间 2026-05-28。
  - Dell Q1 FY2027 press release，2026-05-28。
  - CRN，2026-05-29，摘录并解读 Clarke 对 AI server 市场的表态。
- 本周范围依据：财报与电话会发生于 2026-05-28，后续报道 2026-05-29。
- 关键观点与数字：
  - Clarke 称 Q1 FY2027 Dell 录得 $43.8B revenue，同比增长 88%；EPS $4.86，同比增长 214%。
  - AI 业务最关键三组数字：Q1 booked $24.4B AI orders；recognized $16.1B AI server revenue；quarter-end AI backlog 达 $51.3B。
  - Dell AI 客户数超过 5,000，需求覆盖 neocloud、sovereign、enterprise。pipeline 仍是 backlog 的数倍。
  - 主要瓶颈不是 Dell 的制造 capacity，而是 parts supply，尤其 memory。Clarke 在问答中明确说没有产能问题，“it's parts, supply”。
  - Dell 将 FY2027 AI-optimized server revenue outlook 上调到约 $60B；CRN 记录 Clarke 认为传统市场历史规律不适用于当前 AI 需求环境。
  - Clarke 把 agentic AI 视为新增 TAM：智能被放进每个 workflow、decision、product、customer interaction，推动 traditional servers、edge、PC refresh 和 AI servers 同时受益。
  - Dell 正把 AI factory 从 data center 延伸到 desk side：Dell Pro Max/GB10/GB300、deskside Agentic AI、Power Rack、AI data platform 和 on-prem confidential compute 形成企业本地 AI 路线。
- 产业链判断：
  - Dell 的信号验证了 AI server 需求不是单一 hyperscaler 订单，而是向企业、主权云、neocloud 扩散。
  - memory/parts 已是实际交付上限。对 DRAM、HBM、NAND、HDD、PCB、传统节点半导体和液冷/配电供应商，本周 Dell 电话会是强需求证据。

### 4. Matt Murphy：Marvell 看到 AI 订单从芯片扩展到互联全栈

- 来源与日期：Marvell Q1 FY2027 results press release，2026-05-27。
- 本周范围依据：公告和电话会日期为 2026-05-27。
- 关键观点与数字：
  - Marvell Q1 FY2027 net revenue 为 $2.418B，同比增长 28%，创一季度新高；Q2 revenue guidance 为 $2.700B +/- 5%。
  - Murphy 表示 Marvell 正看到“exceptional AI-related bookings”，并因此显著上调 FY2027 和 FY2028 revenue outlook。
  - 需求不是单一 custom ASIC，而是横跨 800G/1.6T scale-out optics、51.2T Ethernet scale-out switches、NPO/CPO scale-up optical solutions、scale-across DCI modules、custom XPU and XPU-attach solutions。
  - 数据中心收入为 $1.833B，约占总收入 76%，同比增长 27%、环比增长 11%。
- 产业链判断：
  - Marvell 的本周表态说明 AI 基建 bottle-neck 正从 accelerator 继续外溢到网络、光模块、交换芯片、DCI、XPU attach 和封装邻近模块。
  - “XPU + attach” 是重要表述：云厂商定制芯片规模化后，周边互联、内存连接、光/电接口和交换硅的价值占比会上升。

### 5. Demis Hassabis：AGI 时间线收紧，agent era 是压力测试

- 来源与日期：
  - Axios，2026-05-26，Ina Fried 对 Hassabis 的采访。
  - The Rundown AI，2026-05-27，I/O 期间对 Hassabis 的完整访谈摘要。
- 本周范围依据：采访发布日分别为 2026-05-26 和 2026-05-27。
- 关键观点：
  - Hassabis 仍把 AGI 大致放在 2030 左右，但已把 2029 视为可能窗口；Sherwood 对该变化概括为从此前 2030-2035 收紧到 2029-2030。
  - 他把 AI agents 称为 AGI 前的“practice run”：未来一年 agent 的演进会让社会预先感受更强系统到来时的冲击。
  - 对 Anthropic Mythos 这类系统的网络安全冲击，Hassabis 称其是一个“warning shot”，说明企业和政府还未准备好面对能力跃迁。
  - 安全政策上，他认为 testing before release 一类措施应加速，并透露正在与其他 frontier labs 讨论安全措施。
  - 技术缺口上，The Rundown 记录 Hassabis 认为仍需解决 world physics、memory、consistency、continual learning 等问题。
  - AI for science 上，Hassabis 把药物发现时间线也收紧，近期重点在 oncology 和 immunology，长期目标是可帮助攻克任意疾病的 engine。
- 产业链判断：
  - DeepMind 的时间线变化是本周最前瞻信号之一：不是简单“AGI 快来了”，而是把 agent 的短期部署与 AGI 前的制度、经济、安全演练绑定。
  - 如果 2029/2030 成为主流 lab 内部预期，政府测试机制、模型发布流程、企业安全预算和 AI infra capex 都会被迫提前。

### 6. Boris Cherny：Claude Code 正把软件工程师重塑为 builder

- 来源与日期：Platformer，2026-05-26，Casey Newton 对 Boris Cherny 的完整访谈。
- 本周范围依据：访谈发布日为 2026-05-26。
- 关键观点与事实：
  - Cherny 认为软件工程师头衔最早今年开始消失，转向“builder”这类融合角色。不是工程师消失，而是设计、产品、管理和工程边界融合。
  - 他预测未来可能有“100 times more engineers”，因为更多非工程岗位会通过 agents 写代码。
  - Claude Code 的内部扩散速度很强：最初内部版本发布第一天，20% Anthropic engineers 使用；几周内大量 Anthropic 员工每天使用。
  - Cherny 自称超过 6 个月没有手写一行代码；Claude Code、Cowork 等产品也已长期由 Claude Code 自身生成代码。
  - 他在 YC batch 交流中观察到，数百人中约一半举手表示 100% 代码由 Claude Code 写，只有一人完全不用模型写代码。
  - 角色变化不只在专业工程师：Claude Code 团队的 manager、PM、designer 都开始写代码；Anthropic hackathon 中获胜者包括 electrician、doctor、carpenter。
  - 他认为企业导入 AI 工具的最大问题是 business-process change，建议给所有人 token，让非预期岗位也能实验。
- 产业链判断：
  - coding agent 的冲击已从 IDE/补全工具变成组织流程问题。真正的价值可能不是减少工程师，而是扩大“能构建软件的人”的总量。
  - 企业软件、低代码、内部工具、IT 服务外包和开发者平台都会受冲击；同时 verification、test harness、agent observability 会成为新基础设施。

### 7. Chris Olah：AI 公司激励需要外部道德声音约束

- 来源与日期：Platformer，2026-05-26，转述并链接 Olah 对 Pope Leo XIV AI encyclical 的公开回应。
- 本周范围依据：Platformer 发布日为 2026-05-26，讨论的是当日 Vatican AI encyclical 相关公开回应。
- 关键观点：
  - Olah 对教宗 AI 通谕的回应聚焦于 AI 公司激励结构：公司面对的 incentives 和 constraints 有时会与“做正确的事”冲突。
  - 他强调需要不被激励机制弯曲的 moral voices。这个观点并非技术细节，而是把 AI alignment 的约束从内部研究扩展到外部道德和社会制度。
- 产业链判断：
  - 这是 AI safety 叙事的一个重要外延：仅有 eval、interpretability、red team 不够，frontier lab 的商业激励需要外部非市场力量制衡。
  - 若这类论述持续升温，模型发布政策、政府测试、宗教/伦理组织参与、企业 AI 采购合规都会被纳入更正式流程。

### 8. Simon Willison：agent 安全与 HBM 供给是 AI 普及的现实约束

- 来源与日期：
  - Simon Willison Weblog/tag page，2026-05-25 至 2026-05-27 多条 AI/security/LLM notes。
- 本周范围依据：相关 notes 标注日期为 2026-05-25、2026-05-26、2026-05-27。
- 关键观点：
  - 对 Microsoft Copilot Cowork exfiltration 事件，Willison 判断 agentic systems 的最大挑战仍是阻止攻击者诱导 agent 外泄数据。具体风险是：agent 可访问私有文件、可处理不可信内容、又可向外通信时，prompt injection 可能把预授权下载链接或文件内容泄出。
  - 他引用并强化了“lethal trifecta”框架：私有数据访问、不可信内容暴露、外部通信能力三者同时存在时，agent 安全风险急剧上升。
  - 对内存供应链，Willison 引述并评论 David Oks 对 memory shortage 的解释：HBM 需求从过去约 2% wafer allocation 提升到 2026 年底预期约 20%；每 GB HBM 消耗的 wafer capacity 超过 DDR/LPDDR 的 3 倍。
  - 他的判断是 HBM 高利润与高需求会挤压普通消费电子 RAM 供给数年，尤其影响低价手机等对成本敏感的设备。
- 产业链判断：
  - AI agent 的商业化不是只看模型能力，权限、网络出口、文件访问、审计和 prompt injection 防护是硬门槛。
  - HBM 对晶圆和先进封装产能的挤压，会把 AI 基建景气外溢到 PC、手机、服务器 BOM、消费电子价格和低端市场需求。

## 创新/前瞻观点清单

1. **算力即收入**：Huang 把 AI factory 经济性从成本中心改成 revenue engine。关注指标应从 GPU ASP 扩展到 token throughput per watt、uptime、deployment speed、cost per token。
2. **CPU for agents**：Vera CPU 的定位显示 NVIDIA 认为 agent 常驻、工具调用、低延迟 orchestration 会创造新的 CPU/系统需求，而不仅是 GPU 推理需求。
3. **AI cloud 的 agent workbench 化**：Volozh/Nebius 把云服务从算力租赁推进到 agent 可组合 workflow，尤其面向 physical AI 和 robotics。
4. **软件工程师角色融合**：Cherny 的 builder 叙事比“AI 替代程序员”更具体，指向企业流程、权限、验证和跨职能构建能力重组。
5. **AGI 前的 pressure test**：Hassabis 把 2026-2027 agent era 视为 AGI 前的社会压力测试，这比单纯 AGI 时间线更可操作。
6. **外部道德治理进入 AI safety**：Olah 对 moral voices 的强调，说明 frontier lab 内部安全研究之外，外部伦理/社会组织可能成为治理变量。
7. **HBM 对普通内存的挤出效应**：Willison 引述的 wafer allocation 逻辑提示 AI 数据中心景气可能推高非 AI 消费电子成本。

## 技术瓶颈与策略变化汇总

- **Memory/parts 是 server 交付上限**：Dell 明确指出 demand exceeds supply，primary constraint 是 memory；制造 capacity 不是主要瓶颈。
- **AI infra 的瓶颈外溢到互联**：Marvell 的需求清单覆盖 800G/1.6T optics、51.2T Ethernet、NPO/CPO、DCI、XPU attach，说明 GPU 之外的系统瓶颈继续抬升。
- **CPO 进入 production 叙事**：NVIDIA 把 Spectrum-X Ethernet Photonics 与 million-GPU AI factories 绑定，CoreWeave、Lambda、OCI 被列为早期采用者。
- **Agent runtime 需要安全与审计**：NVIDIA 强调 confidential computing、BlueField-4、DOCA；Willison 从 prompt injection 角度指出 agent 同时具备私有数据、不可信内容和外部通信时风险最大。
- **企业 AI 从 pilot 到 production**：Dell、Nebius、NVIDIA 都在说 full-stack、on-prem、sovereign、physical AI workbench，说明客户需求从裸模型试用转向可部署系统。
- **角色/流程比模型能力更难**：Cherny 认为企业采用 AI 的最大问题是 business-process change；这与 Willison 的 agent 安全观点共同指向组织流程、权限和验证层。
