## 重点新闻深挖

### 1. Anthropic Project Glasswing：Mythos 把漏洞发现推到新量级，补丁生态成为瓶颈

**发生了什么**

Anthropic 2026-05-22 发布 Project Glasswing 初步更新。这个项目在 4 月启动，目标是在更强 AI 模型被攻击者滥用之前，先帮助关键软件生态找到并修复漏洞。官方披露的新增信息非常关键：

- Anthropic 与约 50 个合作伙伴使用未公开的 Claude Mythos Preview，已在全球系统性关键软件中发现超过 10,000 个高危或严重漏洞。
- 许多合作伙伴各自发现数百个 critical/high 漏洞，漏洞发现速度提高 10 倍以上；Cloudflare 报告在关键路径系统中发现 2,000 个 bug，其中约 400 个为高危或严重。
- Mozilla 用 Mythos Preview 测试 Firefox 150，发现并修复 271 个漏洞，数量是此前用 Claude Opus 4.6 测 Firefox 148 的 10 倍以上。
- Anthropic 扫描了 1,000 多个开源项目，Mythos 估计其中有 6,202 个 high/critical 漏洞、23,019 个总候选漏洞；1,752 个 high/critical 候选经六家外部安全研究机构或 Anthropic 审查，90.6% 被确认是真阳性，1,094 个被确认 high/critical。
- 公开的 CVD dashboard 显示，截至 2026-05-22 10:27 PT，已披露 1,596 个漏洞，覆盖 281 个开源项目；97 个已打补丁，88 个已有 CVE 或 GHSA。

**为什么重要**

过去几天的本地底稿已经覆盖 Google GTIG、OpenAI Daybreak、Palo Alto AI 扫描、CrowdStrike/Claude Compliance API 等 AI 安全主线。今天的 delta 在于：Anthropic 第一次给出足够大的、可追踪的公开统计，让“AI 能发现漏洞”从案例变成规模化产能。

这会改变安全产业的约束条件：

1. 以前缺的是发现能力。现在缺的是 triage、复现、披露、补丁、测试和部署。
2. 漏洞披露的 90 天窗口在 Mythos 类模型面前变得更危险，因为攻击者一旦拥有类似能力，发现和利用成本会同步下降。
3. 开源维护者可能成为新瓶颈。Anthropic 称一些维护者已经要求放慢披露节奏，因为他们没有足够时间设计补丁。
4. 安全产品的价值会从“发现更多问题”转向“高置信排序 + 自动修复 + 变更验证 + 资产暴露优先级 + 补丁部署闭环”。

**历史和前因后果**

Project Glasswing 的合作方包括 AWS、Apple、Broadcom、Cisco、CrowdStrike、Google、JPMorganChase、Linux Foundation、Microsoft、NVIDIA、Palo Alto Networks 等。这个名单说明 Anthropic 并不是只做模型能力展示，而是在把前沿 cyber 模型嵌入软件供应链核心节点。

同时，Anthropic 仍没有公开释放 Mythos-class 模型，理由是当前没有足够强的 safeguards 阻止严重滥用。这个判断与 2026-05-22 披露的数据形成张力：越能证明模型能大规模帮助防守，也越证明它一旦被无约束释放会降低攻击门槛。

**业内评论和反对观点**

- 支持方会认为这是“防守侧终于获得非对称工具”的开始：AI 可以把关键基础软件在被公开攻击前先扫一遍。
- 反对方会问：这些统计是否把“模型估计 high/critical”与维护者最终确认混在一起？真阳性率高也不等于每个漏洞都有现实攻击路径。
- 开源维护者的现实问题更尖锐：即使 bug 是真实的，志愿者项目也未必有资源在短时间内修复、测试和发布。

**投资含义**

- 安全软件：代码扫描、漏洞管理、AppSec、SCA、SBOM、CNAPP、SIEM/SOAR、端点检测会受益，但估值逻辑要从“告警数量”转向“修复闭环效率”。
- 平台方：GitHub/GitLab、云厂商、DevSecOps 平台、API 网关、安全数据湖和补丁管理系统的重要性上升。
- AI 模型公司：cyber 专用模型会成为企业和政府高价值产品，但必须配合访问资格、审计、用途限制和责任机制。
- 下游风险：如果 AI 生成漏洞报告大量涌入而没有验证层，客户会反感“AI 噪音”；真正值钱的是可验证修复，而不是扫描截图。

**继续验证**

1. CVD dashboard 后续按 severity 过滤后，critical/high 的实际 patch rate 是否快速提升。
2. Cloudflare、Mozilla、Microsoft、Oracle、Palo Alto 等伙伴是否披露更具体的复现、修补周期和误报率。
3. Claude Security public beta 的企业客户转化和定价方式：按席位、按 repo、按扫描量还是按修复任务收费。
4. Mythos-class 模型是否会在政府/关键基础设施白名单中先行开放。

### 2. DeepSeek：V4-Pro 价格永久下调，同时传出 CATL 入股和数据中心电力设备联动

**发生了什么**

DeepSeek 官方 API pricing 页面显示，`deepseek-v4-pro` 当前 75% 折扣价将在 2026-05-31 15:59 UTC 促销结束后“正式调整为原价的 1/4”。这意味着当前价格不再只是短期补贴，而成为新基准：

- V4-Pro cache-miss input：0.435 美元 / 100 万 tokens。
- V4-Pro output：0.87 美元 / 100 万 tokens。
- V4-Pro cache-hit input：0.003625 美元 / 100 万 tokens。
- context length：1M；max output：384K；并发限制 500。
- V4-Flash 价格为 input 0.14 美元 / 100 万 tokens、output 0.28 美元 / 100 万 tokens。

同一天，CnEVPost 援引 The Information 报道称，CATL 计划参与 DeepSeek 初始融资轮；该轮目标约 500 亿元人民币，若完成估值可能超过 3,500 亿元人民币。报道还称京东、网易等也在洽谈，DeepSeek 正考虑提高模型发布频率，并计划在内蒙古乌兰察布建设大型数据中心；CATL 则希望向大型 AI 数据中心销售电力供应设备。

**为什么重要**

今天的关键不是“DeepSeek 便宜”这个旧结论，而是便宜价格被制度化，同时出现了电池/电力设备巨头参与模型公司融资的信号。它把三条线绑在一起：

1. **模型价格战**：0.87 美元 / 100 万输出 tokens 会继续压迫 OpenAI、Anthropic、Google、Mistral 等 API 价格和毛利解释。
2. **国产算力栈**：V4 被报道为面向 Huawei Ascend 950PR 推理优化，说明 DeepSeek 不是单纯卖 API，而在形成模型-芯片-数据中心协同。
3. **电力设备商业化**：CATL 如果参与，不只是财务投资，也可能是把储能、电源设备、数据中心电力系统嵌入 AI 基础设施。

**历史和前因后果**

DeepSeek 2025 年因 R1 低成本训练和开放模型出圈；2026 年 V4 进一步把长上下文、低 API 价格和国产硬件优化结合起来。美国模型公司目前的竞争优势仍在生态、工具、企业合规和高端模型能力，但 DeepSeek 的价格基准会改变大量开发者和创业公司的成本预期。

如果 CATL、国资半导体基金、腾讯、阿里、京东、网易等共同进入 DeepSeek 股权或生态，DeepSeek 就可能从“模型公司”演变成中国 AI 基础设施枢纽：上接芯片和电力，下接云、应用和企业客户。

**投资含义**

- 模型 API：价格压缩会使纯 API 转售和薄封装应用更难获得高毛利。
- AI 芯片：Huawei Ascend、国产服务器和网络设备的需求弹性可能增强，但要看 V4-Pro 在真实负载上的吞吐、稳定性和延迟。
- 电力与储能：CATL 入局如果坐实，说明 AI 数据中心电源设备、储能、UPS、液冷和配电从“基础设施配套”变成模型公司融资故事的一部分。
- 海外供应链：美国限制下，中国 AI 栈更可能走“较低单芯片性能 + 更便宜模型服务 + 自建数据中心 + 电力优化”的组合路线。

**反对观点和风险**

- CnEVPost/Information 报道仍是“计划/洽谈”，没有正式融资公告；投资金额、估值和参与方都可能变化。
- DeepSeek 的低价是否可持续，取决于硬件折旧、利用率、限流、服务稳定性和是否由融资补贴。
- 低价不等于企业可替代：海外客户还要考虑数据治理、合规、生态兼容、延迟和地缘风险。
- 如果价格战继续，受益者未必是模型公司股东，可能是下游应用和算力租赁客户。

**继续验证**

1. 2026-06-01 后 DeepSeek pricing 页面是否维持当前 1/4 价格。
2. V4-Pro 在 OpenRouter、第三方网关和官方 API 的实际价格是否同步。
3. CATL、京东、网易、腾讯、阿里或国资基金是否有正式公告。
4. 乌兰察布数据中心的规模、芯片类型、电力来源、PUE 和资本开支。
5. V4.1 是否按报道在 6 月发布，以及是否继续强化 Ascend 优化。

### 3. Reflection AI + DOE Genesis Mission：AI for Science 走向开放模型和国家实验室平台

**发生了什么**

Axios 2026-05-22 报道，开放模型公司 Reflection AI 与美国能源部 DOE 合作，支持 Genesis Mission。报道要点：

- Reflection AI 将作为美国国家实验室的 AI model provider。
- Reflection 的目标是成为美国最先进 open-weight 模型实验室之一。
- 该公司将向 DOE 提供可按 DOE 数据定制的 AI 模型，并在 Genesis Mission 项目部署中使用 DOE 算力。
- 报道称 Reflection 将成为 DOE 17 个国家实验室的 “foundational intelligence layer”。
- Reflection CEO Misha Laskin 的核心表述是：科学家需要完全访问模型，才能理解和定制；科学发现不适合只用黑盒 closed model。

DOE 的 Genesis Mission 是 2025 年启动的国家级 AI for Science 平台，目标是连接国家实验室、超算、实验设施、AI 系统和独特数据集，面向能源、材料、量子、核安全、关键矿物、生物技术、先进制造等挑战。DOE 2026 年 3 月还宣布 2.93 亿美元 funding 支持相关挑战。

**为什么重要**

最近本地底稿已经覆盖 OpenAI 离散几何突破、Google Gemini for Science / Co-Scientist、DeepMind/Isomorphic Labs、AlphaEvolve 等 AI for Science 主线。Reflection/DOE 的 delta 在于路线不同：不是单个前沿模型突破，也不是商业云产品，而是国家实验室把开放权重模型嵌入科研基础设施。

这会把 AI for Science 的评价标准从“模型能不能给出答案”推向：

1. 模型能否被科学家拆开、复现实验、定制到专用数据。
2. 模型能否接入国家实验室的高价值私有数据和超算环境。
3. 模型能否在能源、核、材料、量子等需要可解释和审计的领域工作。
4. 开放权重能否成为主权 AI 和科学 AI 的默认形态之一。

**历史和前因后果**

过去两年 AI for Science 的主叙事多来自 DeepMind AlphaFold、Isomorphic Labs、Google Co-Scientist、OpenAI 数学/科学推理模型。DOE 路线的不同点在于，美国国家实验室拥有独特数据、实验装置和超算，但不一定愿意把核心科研流程完全交给闭源 API。Reflection AI 的切入点正是“科学发现需要模型可访问、可改造、可验证”。

**投资含义**

- 直接可投标的 Reflection AI 是私有公司，公开市场更应关注上游：HPC、GPU/加速器、存储、科学数据平台、实验自动化、EDA/材料仿真、量子/核/能源软件。
- 国家实验室和政府项目可能增加对 open-weight 模型、私有部署、模型微调、数据治理和高性能推理集群的预算。
- 如果开放模型在科学场景站稳，闭源模型公司的高端科研 API 定价会被压制，但它们仍可通过工具链、服务和安全合规保持份额。

**反对观点和风险**

- Reflection 尚未公开发布 frontier open-weight 模型，能力、许可证、训练数据和商业化细节都需要验证。
- 科学 AI 的“可解释”要求高于企业聊天和 coding agent，模型可访问不等于科学结论可信。
- 政府合作可能带来长采购周期、合规限制和政治更替风险。

**继续验证**

1. Reflection 模型何时公开，是否开放权重、训练细节和 eval。
2. DOE 17 个国家实验室中哪些项目先部署，是否有明确科研成果或成本/周期缩短指标。
3. Genesis Mission 的模型平台是否与 NVIDIA、AMD、Intel、HPE、Dell、Cray、云厂商形成硬件绑定。
4. OpenAI、Google、Anthropic、Mistral、Meta 是否对 DOE/国家实验室推出对应开放或私有部署方案。

### 4. OpenAI Codex：企业治理能力获得认可，同时容量压力暴露

**发生了什么**

OpenAI 2026-05-22 发布文章称，Codex 被 Gartner 评为 Enterprise AI Coding Agents 的 Leader。官方披露几个有用信息：

- Codex 每周有超过 400 万用户使用。
- 企业客户包括 Cisco、Datadog、Dell Technologies、NVIDIA 等。
- OpenAI 称 Codex 已随 GPT-5.5、工具使用能力、性能和企业软件开发工作流支持而显著改进。
- Gartner 认可的能力包括 agentic software development、enterprise governance、sandboxing、flexible deployment options。
- OpenAI 强调 Codex 的企业控制包括 approval gates、RBAC、customizable policies、OS-level sandboxing、auditable workspace governance。
- Cisco 使用 Codex 开发了其 AI Defense 安全平台的大部分，把交付时间从几个季度缩短到几周。

同一时间，OpenAI Status 在 2026-05-22 16:37 至 2026-05-23 10:58 报告 “Increase in users hitting Codex rate limits”，影响 Codex 5 个组件，后续已恢复。

**为什么重要**

昨天的底稿已经详细覆盖 Codex 5 月 21 日更新，包括 Appshots、Goal mode、browser annotations、locked computer use 等功能。今天的新增 delta 不在功能，而在两件事：

1. Codex 已进入企业采购和治理评价体系，不再只是开发者尝鲜工具。
2. rate-limit 事件说明需求增长和容量管理开始成为产品体验的一部分。

coding agent 的竞争正在转向“企业控制面”：

- 权限和密钥如何隔离？
- agent 执行失败是否可回滚？
- 代码、测试、审计和审批如何入企业流程？
- 多个 agent 并发时如何控制成本？
- 能不能在私有环境、on-prem 或受管云里运行？

**历史和前因后果**

过去一周已出现多条 coding agent 主线：Anthropic Stainless/MCP、Cursor Composer 2.5、Dell/OpenAI Codex-on-enterprise-data、GitHub Copilot CLI、Google Antigravity。竞争焦点从“哪个模型写代码更强”变成“谁能更稳定地进入企业 repo、CI、权限、ticket、测试、审计和开发者日常”。

OpenAI 用 Gartner 和 Cisco 案例讲的是企业采用；Status incident 讲的是容量和实际可用性。两者放在一起说明：coding agent 的需求已经足够大，但产品也开始承受任务队列、rate limit、成本和服务可靠性的压力。

**投资含义**

- AI coding agent：OpenAI、Anthropic、Microsoft/GitHub、Google、Cursor、JetBrains、Atlassian、ServiceNow、GitLab 等将围绕企业工作流入口竞争。
- 基础设施：coding agent 是高 token、高工具调用、高 sandbox、高存储访问的工作负载，会继续拉动推理算力、CPU/内存、沙盒执行和审计日志基础设施。
- 安全：企业采用 coding agent 需要 code scanning、secret scanning、policy enforcement、artifact provenance 和 access control。

**反对观点和风险**

- Gartner 认可属于商业评价，不等于所有真实工程任务成功率领先。
- 400 万 weekly users 说明使用规模，但不说明付费转化、平均任务长度、毛利率或 failure cost。
- rate-limit 事件提醒：agent 产品的体验可能被配额、排队和成本策略影响。

**继续验证**

1. Cisco AI Defense 案例是否披露更多工程量、代码比例、错误率和安全审计流程。
2. Codex rate-limit 是否只是短期拥堵，还是新功能发布后持续需求超出容量。

4. OpenAI 是否推出更细的企业用量计费、专属容量或 on-prem/private deployment。

### 5. Physical AI：Kawasaki 建硅谷中心，机器人空间推理从论文向产业落地靠近

**发生了什么**

Kawasaki Heavy Industries 2026-05-22 宣布在美国 San Jose 成立 Kawasaki Physical AI Center，合作方包括 NVIDIA、Analog Devices、Microsoft 和 Fujitsu，目标是推动 Physical AI 的社会实施。官方说明：

- 第一阶段聚焦 healthcare 和 elder care，提出覆盖到院、检查、诊断、治疗、手术、术后护理的 “hospital one-stop solution”。
- 同时计划扩展到半导体、汽车和新型移动出行。
- NVIDIA 合作主题是创建跨领域集成 AI 与机器人技术的新解决方案，以医疗为入口。
- Analog Devices 合作主题是把 AI、语音识别和 sensing 技术集成到可处理多任务机器人中。
- Microsoft 负责用 cloud 和 AI platform 能力提升可靠性和真实部署可扩展性。
- Fujitsu 侧重医疗业务系统、机器人系统和 AI 的整合。

同日，TechXplore 报道 Science Robotics 论文：香港中文大学、浙江人形机器人创新中心等团队提出 Retrieval-Augmented Manipulation（RAM）。RAM 用显式 3D object representation 给 VLM 增强空间推理能力，使机器人能把复杂语言指令转成物理可执行的 3D 子目标，并在 zero-shot 真实机器人场景中执行和自适应重规划。

**为什么重要**

Physical AI 的难点不只是大模型会不会“理解语言”，而是：

1. 感知世界是否足够稳定。
2. 语义指令能否落到 3D 空间中的位置、方向、尺寸、碰撞和顺序。
3. 失败后能否重规划。
4. 机器人系统能否在医疗、工厂、半导体等高可靠场景中持续运行。

Kawasaki 的新闻代表工业机器人和医疗机器人 incumbent 开始建立跨国 AI/半导体/云协作中心；RAM 论文代表技术层面对“语言到三维动作”的瓶颈有新进展。两条合在一起，说明具身智能正在摆脱单纯 humanoid demo，转向可部署场景、传感器、边缘算力、系统集成和安全流程。

**历史和前因后果**

NVIDIA 今年不断把 Physical AI、GR00T、Cosmos、Isaac、Jetson Thor 和机器人模拟推成下一波增长叙事；Figure AI、Tesla Optimus、Physical Intelligence、1X、Genesis AI 等公司则把资本推向 humanoid 和通用机器人。Kawasaki 的切入点更现实：医疗、护理、半导体和工厂流程，这些场景的 ROI 与合规路径比家庭机器人更清晰。

**投资含义**

- 硬件：机器人本体、伺服、减速器、传感器、工业相机、力控、边缘 AI 模块。
- 半导体：NVIDIA Jetson/Thor、ADI sensing、低功耗推理芯片、实时控制 MCU。
- 软件：仿真、数字孪生、机器人 OS、VLM 到动作规划、现场安全监控。
- 系统集成：医疗、半导体、汽车、物流场景的集成商和自动化公司比纯 demo 型机器人公司更早变现。

**反对观点和风险**

- 医疗和护理的合规周期长，责任边界复杂，短期收入未必快。
- RAM 是研究进展，不等于大规模商业部署；真实世界的遮挡、反光、柔性物体、动态人群会显著增加难度。
- Physical AI 需要大量真实世界数据，数据采集和安全试运行可能比模型训练更贵。

**继续验证**

1. Kawasaki San Jose 中心是否公布首批客户、试点医院或半导体工厂。
2. NVIDIA/ADI/Microsoft/Fujitsu 各自提供的是硬件、平台、模型还是系统集成收入。
3. RAM 是否开源、是否被主流机器人平台复现。
4. Figure、Tesla、Physical Intelligence 与 Kawasaki 这类工业 incumbent 的路线差异：通用机器人 vs 场景集成。

### 6. AI 数据中心：电力、储能、治理和液冷材料继续从“配套”变成主线

**发生了什么**

过去 24 小时里没有单一数据中心新闻能超过 Nebius/Bloom 或 Google/Blackstone 的规模，但多个增量共同指向同一个结论：AI 数据中心的核心约束继续从 GPU 扩散到电力、储能、配电、液冷、治理和施工周期。

可跟踪的新增线索包括：

- Telborg 2026-05-23 data centre briefing 汇总称，Meta/Enbridge Wyoming Cowboy Project 新阶段包括 365MW solar + 200MW / 1,600MWh battery，目标 2027 年底商业运行；这强化 hyperscaler 从“购买清洁电力”走向“承销可调度电力结构”的趋势。
- 同一 briefing 提到 Cushman & Wakefield 将 Dallas 评为全球头部数据中心市场，并称 2025 年在建容量接近 31.7GW，AI 让 power availability 和可扩展性成为选址核心。
- briefing 还提到美国 2026 Q1 新增 9.7GWh 储能，其中 utility-scale 7.8GWh，并预测 2030 年累计超过 610GWh；若许可和并网卡住，大负载客户会更倾向 “bring your own power/storage”。
- Harvard Law School Forum 2026-05-22 摘要显示，NYSCRF 在 2026 proxy policy 中新增对 data center growth environmental risks 和 responsible AI governance 的披露/投票关注。这意味着数据中心外部性和 AI 治理可能进入股东投票和董事会问责。
- Schneider Electric 2026-05-22 博客提示，PFAS 监管会影响两相浸没/两相 direct-to-chip cooling；其主推 75% water + 25% glycol 的 single-phase direct-to-chip 路线和 Motivair 组合。

**为什么重要**

AI 基础设施的可投资链条正在重新排序。2024-2025 年大家主要盯 GPU、HBM 和 CoWoS；2026 年开始，瓶颈更像一个系统：

1. 能不能拿到电力和并网。
2. 能不能用储能、现场电源、燃料电池、天然气或可再生组合缩短 time-to-power。
3. 能不能承受地方政府、居民、ESG 投资者和水资源监管压力。
4. 能不能在高密度 rack 下稳定液冷，并规避 PFAS 等材料监管。
5. 能不能把施工、涂层、防火、模块化、供应商交期等“传统工程细节”变成可控工期。

**投资含义**

- 电力设备：变压器、开关设备、UPS、母线槽、配电自动化、燃料电池、备用电源。
- 储能：utility-scale BESS、数据中心 behind-the-meter storage、电池供应链和 EPC。
- 液冷：direct-to-chip、CDU、冷板、泵阀、快接头、冷却液、监测软件、Motivair/CoolIT/LiquidStack 等生态。
- 数据中心 REIT / operators：未来估值不能只看 MW backlog，还要看电力确定性、许可风险、社区阻力和 water/PFAS 治理。
- 公用事业：Texas、Wyoming、Malaysia 等能快速扩网和签大用户合同的地区可能获得 AI 负载红利，但也承担 ratepayer politics。

**反对观点和风险**

- 部分 briefing 信息来自汇总源，仍需逐条回到 Enbridge、Meta、Cushman、SEIA/Benchmark、NYSCRF、TNB 等一手材料验证。
- 可再生 + 储能并不等于全天候供电；训练和推理负载需要的是可用功率、调度能力和电网可靠性。
- 液冷路线尚未完全标准化，PFAS 监管可能让两相技术路线受压，但 single-phase direct-to-chip 也需要供应链、维护和漏液风险管理。

**继续验证**

1. Meta/Enbridge Cowboy 项目的 PPA、tariff、battery dispatch 权利和对 Meta 数据中心的实际供电比例。
2. Dallas/West Texas 在建容量中的 AI 负载比例，以及 OpenAI/Oracle/SoftBank/Stargate、Meta、Google 项目时间表。
3. NYSCRF guidance 是否引发对数据中心运营商、云厂商和电力公用事业的股东提案。
4. PFAS 监管是否让两相浸没冷却商业化延迟，还是推动更清晰的 coolant 标准。

## 新闻口播稿

各位早上好。今天的 AI 产业链新闻有六条主线，但真正值得深挖的是前三条：Anthropic 的 Mythos 把漏洞发现推到新规模，DeepSeek 把低价模型服务变成正式价格并牵出 CATL 的电力设备线索，Reflection AI 进入美国能源部 Genesis Mission，让 AI for Science 的开放模型路线变得更具体。后面三条也重要：Codex 从功能发布进入企业治理和容量管理，Physical AI 从论文和 demo 走向工业与医疗场景，AI 数据中心继续把电力、储能、液冷和治理推到投资主线前排。

先看今天最重的一条，Anthropic 的 Project Glasswing。官方在 5 月 22 日披露，约 50 个合作伙伴已经用未公开的 Claude Mythos Preview，在全球关键软件里发现超过一万个高危或严重漏洞。Cloudflare 在关键路径系统中发现约两千个 bug，其中四百个是高危或严重；Mozilla 用 Mythos 测 Firefox 150，发现并修复 271 个漏洞，是此前用 Claude Opus 4.6 测 Firefox 148 的十倍以上。Anthropic 自己扫描一千多个开源软件，模型估计有 23,019 个候选漏洞，其中 6,202 个可能是 high 或 critical。公开披露仪表盘显示，截至 5 月 22 日上午，已披露 1,596 个漏洞，覆盖 281 个开源项目，97 个已被上游修补，88 个已有 CVE 或 GitHub Security Advisory。

这条新闻的关键不在于“AI 能找漏洞”这个结论。这个结论过去一年已经被很多安全实验和产品验证过。今天真正重要的变化是规模和瓶颈同时被量化了。以前软件安全最大的限制是找不到足够多的高质量漏洞；现在限制变成谁来复现、谁来确认严重程度、谁来通知维护者、谁来写补丁、谁来测试补丁、谁来把补丁部署到真实系统。Anthropic 自己也说，维护者已经开始感到披露节奏太快，一些人要求放慢速度，因为他们没有足够时间设计和发布修复。

这会让安全产业进入一个很微妙的阶段。防守方终于有了更强工具，可以在攻击者大规模使用类似模型之前先扫关键软件。但同一件事也说明，一旦 Mythos 级模型或类似能力扩散，攻击者发现漏洞和构造利用链的成本也会下降。漏洞披露传统上有 90 天窗口，目的是让维护者有时间修补、用户有时间更新。现在发现速度被 AI 加速，修补速度还被人类流程限制，中间这段时间就更危险。

投资上，AI cyber 不能只看谁的扫描器发现更多告警。真正有价值的是从发现到修复的闭环：高置信排序、可复现证据、自动补丁、回归测试、资产暴露优先级、补丁部署和审计记录。代码安全、SCA、SBOM、漏洞管理、CNAPP、SIEM/SOAR、端点检测、DevSecOps 平台都会受到影响，但客户愿意付费的会是“减少真实风险”，不是“生成更多报告”。这也解释了为什么 Anthropic 同时在做 Claude Security beta、Cyber Verification Program 和给合格安全团队开放更强的工具链。未来的安全预算很可能从单点扫描，转向“模型能力加验证流程加修复流水线”。

第二条是 DeepSeek。官方 API pricing 页面显示，deepseek-v4-pro 现在的 75% 折扣价，会在 2026 年 5 月 31 日 15:59 UTC 促销结束后正式调整为原价的四分之一。也就是说，这个低价不再只是短期补贴。V4-Pro 的 cache-miss input 是每百万 tokens 0.435 美元，output 是每百万 tokens 0.87 美元，cache-hit input 低到 0.003625 美元；上下文长度 1M，最大输出 384K，并发限制 500。V4-Flash 更便宜，input 0.14 美元、output 0.28 美元。

同一天，CnEVPost 援引 The Information 报道称，CATL 计划参与 DeepSeek 的初始融资轮；这轮目标约 500 亿元人民币，若完成，DeepSeek 估值可能超过 3,500 亿元人民币。报道还提到京东、网易等也在洽谈，DeepSeek 正考虑提高模型发布频率，并计划在内蒙古乌兰察布建设大型数据中心。CATL 的动机也很有意思：它希望向大型 AI 数据中心销售电力供应设备。

把这两件事放在一起看，DeepSeek 的新闻已经不只是“中国模型价格低”。它更像是中国 AI 基础设施栈的一次组合信号：模型服务用极低价格抢开发者和企业负载，模型据称面向国产推理硬件优化，数据中心选址考虑低电价和低温，电池和电力设备巨头尝试从储能、电源、配电设备切入 AI 数据中心。这条链条从模型、芯片、服务器、数据中心、电力设备一直延伸到资本。

对全球模型公司来说，0.87 美元每百万输出 tokens 会继续压低客户对 API 价格的心理锚。OpenAI、Anthropic、Google、Mistral 等公司可以凭生态、企业合规、工具链和高端模型能力保持优势，但大量价格敏感型应用、创业公司和批量推理负载，会不断把 DeepSeek 当成成本基准。低价也会迫使其他模型公司解释自己的溢价来自哪里：更强能力、更低延迟、更高稳定性、更好企业控制，还是更完整工具生态。

对投资链条来说，DeepSeek 和 CATL 这条线索要谨慎但值得盯。融资和估值现在还只是报道，参与方和金额都可能变化；低价能否持续，也取决于硬件折旧、利用率、限流、服务稳定性和是否有资本补贴。可如果 CATL 入局坐实，AI 数据中心电源设备、储能、UPS、液冷和配电就会从“机房配套”变成模型公司资本故事的一部分。中国 AI 栈可能走出一条不同路线：较低单芯片性能，搭配更便宜模型服务、自建数据中心、电力优化和国产供应链协同。

第三条，Reflection AI 与美国能源部 DOE Genesis Mission 合作。Axios 报道称，Reflection AI 将成为美国国家实验室的 AI model provider，并为 DOE 17 个国家实验室提供所谓 foundational intelligence layer。Reflection 的定位是先进 open-weight 模型实验室，它会向 DOE 提供可按 DOE 数据定制的 AI 模型，并使用 DOE 算力参与 Genesis Mission 科研项目部署。DOE 自己对 Genesis Mission 的定义，是把国家实验室、产业、大学、超算、实验设施、AI 系统和独特数据集连接起来，服务能源、材料、量子、核安全、关键矿物、生物技术和先进制造等国家级科学挑战。

这条新闻和前几天的 AI for Science 主线有关，但路线不同。前几天我们看过 OpenAI 的离散几何突破、Google Gemini for Science、Co-Scientist、DeepMind 和 Isomorphic Labs。那些新闻强调前沿模型能在数学、药物、材料或科学推理里产生新结果。Reflection 和 DOE 的重点是制度化科研平台：国家实验室拥有高价值私有数据、实验装置和超算环境，科学家希望能完整访问、理解和定制模型，而不是只通过黑盒 API 调用。

这会把 AI for Science 的竞争标准改掉一部分。科学模型要能被拆开、复现、微调、审计，还要能和实验设施、仿真软件、HPC 作业系统、数据治理流程连接起来。开放权重在这里有天然吸引力，因为国家实验室和关键科研任务不愿意把长期能力完全锁在某个闭源商业 API 里。Reflection 还没有公开发布 frontier open-weight 模型，这是最大风险点。它今天获得的是战略入口，不等于模型能力已经被充分验证。

投资上，Reflection 本身是私有公司，公开市场更应该看上游和配套：HPC、GPU 和其他加速器、存储、科学数据平台、实验自动化、材料仿真、EDA、量子软件、私有部署和模型微调工具。政府项目会带来长采购周期和合规约束，但一旦形成标准，相关平台的切换成本也会很高。未来要盯的是 Reflection 何时公开模型、是否真开放权重、DOE 哪些实验室先部署、有没有明确科研成果或周期缩短指标，以及 OpenAI、Google、Anthropic、Meta、Mistral 会不会针对国家实验室给出相应开放或私有部署方案。

第四条，OpenAI Codex。今天的新信息有两面。好的一面是，OpenAI 称 Codex 被 Gartner 评为 Enterprise AI Coding Agents 的 Leader，每周有超过 400 万用户使用，企业客户包括 Cisco、Datadog、Dell Technologies、NVIDIA 等。OpenAI 强调的能力包括 agentic software development、企业治理、sandboxing、灵活部署、approval gates、RBAC、customizable policies、OS-level sandboxing 和可审计 workspace governance。Cisco 案例里，OpenAI 说 Codex 帮助开发其 AI Defense 安全平台的大部分，把交付时间从几个季度缩短到几周。

另一面是 OpenAI Status 显示，5 月 22 日下午到 5 月 23 日上午，Codex 出现“更多用户触及 rate limits”的降级事件，影响 5 个 Codex 组件，后来恢复。把这两件事放在一起看，很像 coding agent 的成熟转折点：它已经进入企业采购和治理评价体系，同时也开始承受容量、配额、排队和稳定性压力。

昨天我们已经讲过 Codex 的 Appshots、Goal mode、浏览器标注和锁屏远程运行。今天就不重复功能清单。更值得看的，是企业为什么在意治理。coding agent 会读代码库、跑命令、改文件、访问测试环境、调用浏览器、可能触碰密钥和客户数据。企业真正要问的是：权限怎么隔离，失败怎么回滚，谁批准变更，agent 执行记录怎么审计，多 agent 并发成本怎么控制，能不能在私有环境里运行，能不能接入现有工单、CI、代码审查和安全流程。

这条线的投资含义是，开发者工具竞争会继续从 IDE 插件升级到完整工程操作层。OpenAI、Anthropic、Microsoft/GitHub、Google、Cursor、JetBrains、Atlassian、ServiceNow、GitLab 都会争这个入口。基础设施也会被拉动，因为长任务 coding agent 是高 token、高工具调用、高沙盒、高日志、高存储访问的工作负载。短期要盯 Codex rate-limit 是否再次出现，OpenAI 会不会推出专属容量、企业 SLA、更细用量计费或私有部署方案。

第五条是 Physical AI。Kawasaki Heavy Industries 宣布在 San Jose 成立 Kawasaki Physical AI Center，合作方包括 NVIDIA、Analog Devices、Microsoft 和 Fujitsu。第一阶段聚焦 healthcare 和 elder care，提出从到院、检查、诊断、治疗、手术到术后护理的一站式医院方案，后续还会扩展到半导体、汽车和新型移动出行。NVIDIA 负责 AI 与机器人方案，ADI 强调 sensing 和语音识别，Microsoft 提供云和 AI 平台，Fujitsu 侧重医疗业务系统、机器人系统和 AI 整合。

同一天，TechXplore 报道 Science Robotics 论文，香港中文大学、浙江人形机器人创新中心等团队提出 Retrieval-Augmented Manipulation，简称 RAM。这个框架把 VLM 和显式 3D object representation 结合起来，让机器人能把复杂语言指令转换成空间上可执行的子目标，并在真实机器人场景中 zero-shot 执行和重规划。

这两条放在一起，说明具身智能的叙事正在从炫目的 humanoid demo，转向更务实的系统工程。真实机器人要解决的不是会不会听懂一句话，而是能不能把语言落到三维空间里的位置、方向、尺寸、碰撞、抓取顺序和失败重试。医疗、护理、半导体、汽车这些场景的门槛高，但 ROI 和责任边界也更清晰。NVIDIA 的 Physical AI 叙事、ADI 的传感器、Microsoft 的云平台、Fujitsu 的医疗系统和 Kawasaki 的工业机器人经验，组合起来比单个 demo 更接近可部署产品。

投资上，可以看机器人本体、伺服、减速器、工业相机、力控、边缘 AI 模块、传感器、仿真、数字孪生、机器人 OS、现场安全监控和系统集成。风险也很明确：医疗和护理合规周期长，责任边界复杂；RAM 仍是研究进展，真实环境中的遮挡、反光、柔性物体和人群动态会让难度明显上升。后续要看 Kawasaki 是否公布首批医院、半导体厂或汽车客户，RAM 是否开源并被主流机器人平台复现。
