## 1. Bull/Foxconn 在欧洲制造 Vera Rubin NVL72：主权 AI 从“买云”进入“本地制造、集成、运营”阶段

Bull SAS 和 Foxconn 2026-06-17 宣布双方合作的第一个战略里程碑：在欧洲生产基于 NVIDIA Vera Rubin NVL72 的关键 AI 系统，并以 Bull 品牌商业化。公告写明，系统会先在 Foxconn 捷克工厂制造和初测，再到 Bull 位于法国 Angers 的工厂完成组装、集成和完整验证。目标客户包括 neo-cloud providers、cloud service providers，以及欧洲和欧洲以外的新一代 AI factories。Bull 同时强调会提供 AI software layer、embedded AI use cases 和 data science 专长，把制造扩展到部署、安全和优化。

这条新闻和 2026-06-15 已写过的 Schneider/Foxconn 有关联，今天的 delta 很明确：Schneider/Foxconn 解决电力、冷却、AI rack 和模块化交付，Bull/Foxconn 解决欧洲本土 AI 服务器制造、系统验证和软件运维。Foxconn 站在中间，把全球 EMS 能力同时接入电力热管理、服务器集成、欧洲主权 AI 和 NVIDIA Rubin 平台。

这对欧洲意义很大。欧洲主权 AI 过去通常落在三个层面：本土模型、数据驻留、本土云服务。今天的新层面是制造和系统集成。如果欧洲客户只买美国云上的 GPU 或美国整机，数据驻留仍会面对供应链和域外法担忧。Bull/Foxconn 的说法直接回应了这个痛点：法国和捷克承接制造与验证，让欧洲企业、AI factories 和 cloud providers 以区域内供应链取得最新代 AI compute。

产业链拆解：

- 计算层：Vera Rubin NVL72 是 rack-scale 系统，意味着整机、机柜、板卡、NVLink、CPU/GPU 协同、内存、存储、DPU、网络和液冷都要一体化验证。
- 制造层：Foxconn 捷克负责制造和初测，Bull 法国 Angers 负责集成验证，欧洲供应链会围绕线束、机柜、电源、散热、测试、运输、维保、软件部署形成新项目。
- 主权层：Outscale 和 Scaleway 的公开评论都把这件事放在欧洲数字和工业主权框架下，重点是减少非欧洲法域和技术依赖。
- 客户层：neo-cloud 与 cloud service provider 需要可采购、可运维、可审计、可融资的 AI factory 组件，制造在地化能降低部分政治和采购阻力。

投资含义：欧洲 AI 基础设施主线不能只看数据中心土地和电力，还要看本地系统集成商、EMS、服务器、机柜、液冷、电力设备、测试验证、软件运维和安全合规。Foxconn 的 AI 服务器角色继续上升，Bull 则把欧洲 HPC、AI 和量子品牌资产接到 NVIDIA 最新平台。Schneider、Atos/Bull、Foxconn、NVIDIA、欧洲云、法国电力和当地 MEP/EPC 可能形成更紧密的项目团。

需要继续验证：第一批客户名单、首批出货时间、单机柜功耗、液冷方案、欧洲本土零部件比例、是否纳入 SoftBank 法国 5GW AI 数据中心计划、Bull 软件层的真实功能、客户是否接受 NVIDIA 技术栈与欧洲主权诉求的组合。

## 2. Coherent/NVIDIA Sherman InP 工厂开工：AI 网络的下一瓶颈从交换机延伸到激光源和化合物半导体

NVIDIA 2026-06-16 披露，Coherent 位于 Texas Sherman 的扩建项目开工，核心是扩大全球首条量产级 6 英寸磷化铟（InP）产线。Coherent 同日宣布签署最高 5000 万美元 CHIPS Act 直接资助意向书，用于扩建 Sherman 的 6 英寸 InP 半导体制造设施。NVIDIA 博客还提到，Coherent 与 NVIDIA 已在 2026 年 3 月深化为多年战略伙伴关系，NVIDIA 向 Coherent 投入 20 亿美元以支持 R&D、未来产能和美国制造，并配有多年先进激光与光网络产品采购承诺。

为什么这条新闻高分：AI cluster 的网络瓶颈已经进入物理层。NVIDIA 在博客中解释，Vera Rubin Ultra NVL576 把 8 个 NVLink rack、576 个 Rubin Ultra GPU 连接成一个域；当跨越多个机柜、数百到数千英尺的数据中心距离时，铜互联需要更多 retimer 和信号调理，会把电力预算消耗在传输上。光互联的优势在于电光转换后距离成本很低。Coherent 的 InP 激光、光组件、收发器、pluggable optical module、external laser source 正好落在这个位置。

这也把 2026 年以来频繁出现的 CPO/NPO、Spectrum-X Photonics、Quantum-X Photonics、1.6T 光模块和 AI Fabric 讨论落到产线。过去投资者容易把光模块理解为可插拔模块价格和出货量，今天的消息提示更底层的变量：谁有稳定、高良率、可扩产的 InP 激光源，谁就掌握 AI networking 的更上游瓶颈。

关键数字和工程含义：

- 6 英寸 InP：NVIDIA 文章称从 3 英寸到 6 英寸的面积提升约为 4 倍，有助于降低单位成本并扩大 AI buildout 所需体量。
- 20 亿美元 NVIDIA 承诺：供应链预付款和战略投资让光学供应链进入 GPU 平台公司的资本体系。
- 最高 5000 万美元 CHIPS 支持：项目有美国制造和供应链安全属性。
- 550 个直接岗位、数千个直接和间接岗位：AI 基础设施重新工业化的政治叙事更加明确。
- CPO / external laser module：Coherent 供应接入交换机前面板的外置激光模块，连接到 NVIDIA photonics switches。

投资映射上，COHR、LITE、AAOI、光模块、激光器、InP 外延、化合物半导体设备、光 DSP/TIA/CDR、交换机、连接器、测试仪器都应提高权重。中国侧则要映射到光芯片、EML、硅光、薄膜铌酸锂、CPO 封装、光模块液冷 cage 和高速测试。项目也会影响电力侧：如果光互联可降低跨 rack 或跨数据中心传输功耗，单位 token 的能源成本和机房网络架构会被重新计算。

后续验证：Coherent Sherman 扩产节奏、CHIPS 意向书转正式拨款、NVIDIA 采购承诺的产品类别和交货窗口、Lumentum/Coherent 份额变化、CPO 交换机出货时间、1.6T/3.2T 模块价格、AI 集群中光互联占 capex 比例。

## 3. MLPerf Training v6.0：DeepSeek-V3 进入标准基准，MoE 训练效率变成云厂和 GPU 平台的公开战场

MLCommons 于 2026-06-16 发布 MLPerf Training v6.0。新版加入两个 MoE 训练基准：DeepSeek V3 和 GPT-OSS 20B。DeepSeek V3 使用 6710 亿总参数、每 token 激活 370 亿参数，是目前套件中最大的 benchmark；GPT-OSS 20B 为 210 亿总参数、每 token 激活 36 亿参数，给资源较小的组织提供入口。MLCommons 还披露本轮有 95 个独特系统、13 种硬件加速器、19 种 host processor，60% 是多节点系统；提交组织包括 AMD、Azure、CoreWeave、Dell、Google、HPE、Lambda、Nebius、Oracle、NVIDIA、Supermicro、Vultr 等 24 家。

这个版本的核心价值是把 MoE 训练从论文和单家公司 benchmark 推到公开可比体系。大模型训练的关键已不再只是 dense model 的矩阵乘法速度，MoE 训练多了 token routing、expert load balance、all-to-all communication、KV/cache 和网络拥塞问题。DeepSeek-V3 被纳入 MLPerf，相当于把开源权重大模型、稀疏激活和生产级训练效率放进标准考场。

CoreWeave 的数据最亮眼。MLCommons supplemental 显示，CoreWeave 在 NVIDIA GB300 NVL72 上训练 DeepSeek-V3-671B，8192 个 GB300 GPU 达到目标质量只用 2.02 分钟；2048、4096、8192 GPU 对应训练时间分别为 5.54、3.09、2.02 分钟，显示接近线性扩展。CoreWeave 还在 4096 GPU GB300 部署上把 Llama 3.1 405B 预训练跑到 9.77 分钟。NVIDIA 自己也披露，GB300 NVL72 在同规模下相比 GB200 NVL72 最高提升 1.6 倍，核心来自 NVFP4、更高计算密度、更大内存和更高功率上限。

投资含义：

- AI 云差异化从“有多少 GPU”进入“同样 GPU 能否稳定跑大规模 MoE”。CoreWeave、Azure、Nebius、Lambda、Oracle 这些 submitter 的技术栈、网络、存储、调度和可靠性会成为客户采购依据。
- GB300、GB200、NVLink、Spectrum-X Ethernet、Quantum InfiniBand、RAS、NVRx、CUDA/NeMo 软件优化共同决定有效训练吞吐。硬件毛利之外，软件栈锁定力继续上升。
- DeepSeek-V3 进入标准 benchmark 对国产和开放模型很重要。它让全球厂商围绕同一类稀疏大模型优化，推动 MoE 在训练基础设施采购中变成显性指标。
- 多云 AI 训练会继续壮大。MLCommons 称 cloud systems 提交数量比半年前 v5.1 翻倍以上，这说明训练任务外包正在从边缘选择变成主流采购路径。

需要谨慎的地方：MLPerf 是目标质量和标准 workload，不等同于真实 frontier training 全流程。真实训练会遇到数据清洗、长期 checkpoint、故障恢复、多周运行、模型试错和客户安全隔离。投资者应把 MLPerf 当作“最低可比性能地板”和“客户技术尽调入口”，再结合真实订单、SLA、利用率和毛利。

## 4. HPE AI Factory with NVIDIA：企业 agent 生产化开始需要 CPU、DPU、存储治理、机密计算和回滚能力

NVIDIA 2026-06-16 在 HPE Discover 期间披露，HPE AI Factory with NVIDIA 增加 NVIDIA Vera CPU、NVIDIA Agent Toolkit、NVIDIA Confidential Computing 和更完整的 NVIDIA full-stack integration。HPE ProLiant Compute DL394 Gen12 搭载 Vera CPU，将于 2027 年随 HPE Private Cloud AI 提供；NYSE 与 Redpanda、HPE 合作成为探索 Vera CPU 的早期企业客户。HPE 同时会提供 Vera Rubin NVL72 rack-scale system，并推出基于 NVIDIA HGX Rubin NVL8 的 HPE Compute XD700，单 rack 最高支持 128 个 Rubin GPU。

这条新闻的价值在软件和控制面。NVIDIA Agent Toolkit 包括 Nemotron open models、OpenShell secure runtime、NemoClaw blueprints，用于监控 agent 行为、执行治理策略、构建和运行长周期 multi-agent systems。HPE Private Cloud AI 增加本地 agent registration，客户可以在 agent 运行前审批模型、skills 和 tools，并和集中治理策略绑定。HPE Zerto 则加入检测 rogue agent actions 并通过 continuous data protection 回滚到 clean state 的能力。

这说明企业 agent 生产化的采购包正在形成：

- CPU：Vera CPU 被定义为面向 agent 的 CPU，服务 tool calls、orchestration 和 agent loop 中的实时数据处理。
- DPU：BlueField 和 DOCA 执行 in-silicon zero-trust policy enforcement、runtime threat detection 和 network encryption。
- 存储：HPE Alletra Storage MP X10000 通过 NVIDIA-Certified Storage foundation level，把 metadata 和 governance policy 自动应用到非结构化数据，用于改善 token throughput。
- 机密计算：NVIDIA Confidential Computing 覆盖 HPE AI Factory at Scale、Sovereign AI Factory 和 Private Cloud AI，用 cryptographic attestation 和 encryption 保护模型和敏感数据执行过程。
- 网络：Vera Rubin NVL72 配套 Vera BlueField-4、ConnectX-9、Spectrum-X Ethernet，Spectrum-6 switching 对 AI communication 号称较普通 Ethernet 有 1.6x 网络性能。

这和 2026-06-16 的 Arcade.dev 新闻呼应。Arcade 是 agent action layer 和授权审计；HPE/NVIDIA 是企业级私有 AI factory 中的底座。大型企业不会只买一个聊天模型，它们需要 agent 执行前审批、执行中监控、执行后审计、出错后回滚、敏感数据执行保护。AI 服务器的卖点因此从 GPU 数量扩展到“agent 运行时的可控性”。

投资方向：HPE、NVIDIA、企业私有云、DPU、网络安全、存储治理、备份恢复、agent gateway、IAM/GRC、企业数据治理、私有部署咨询。受压方向是只提供单点 agent demo、缺少治理和回滚能力的软件工具。后续要验证 NYSE 这类金融客户是否从探索进入生产、Vera CPU 的实际规格和出货、Zerto 对 rogue agent 的检测有效性、agent registration 能否和企业 IAM/GRC 体系打通。

## 新闻口播稿

今天是2026年6月17日，今天有十条AI产业链新闻。最值得先听的主线很清楚：AI基础设施的竞争，正在从“谁有GPU”扩展到“谁有光互联、谁能本地制造、谁能把MoE训练跑稳、谁能把企业agent的成本和权限管住”。

第一条，先看今天综合评分最高、投资链条最清楚的一条：Coherent 和 NVIDIA 在美国 Texas Sherman 的 6 英寸磷化铟工厂扩建开工。Coherent 同时宣布，已经签署最高 5000 万美元 CHIPS Act 直接资助意向书，用于扩建这座 6 英寸 InP 半导体制造设施。NVIDIA 也把这件事放在 AI optical backbone 的位置上讲，重点落在 AI 集群扩大后的数据移动成本：它正在成为新的成本中心。

为什么一个磷化铟工厂值得排在今天最前面？因为大模型集群的形态变了。Vera Rubin Ultra NVL576 这类系统，把多个 NVLink rack 连成一个大域，跨机柜、跨走廊、甚至跨数据中心传数据。铜线在短距离内便宜好用，但距离拉长后，需要 retimer 和信号调理，电力预算会被耗在传输上。光互联先付一次电光转换成本，后面的距离成本低得多。AI 数据中心每一瓦电都要争给 GPU，网络传输少耗一点，token 成本就会跟着变。

Coherent 的价值就在这里。它做的 InP 激光器、光组件、收发器、pluggable optical module、external laser source，正好卡在 NVIDIA AI networking 的上游。过去很多人看光模块，习惯盯 800G、1.6T、交换机端口、模块 ASP。今天这条新闻提醒我们，还要往更上游看：有没有稳定的 InP 外延和激光源，有没有高良率的 6 英寸产线，有没有美国本土制造，有没有来自平台公司的长期采购承诺。

这对投资链条很直接。美国侧，Coherent、Lumentum、光模块、激光器、硅光、CPO、交换机、测试设备、连接器都会被重新估值。中国侧，光芯片、EML、薄膜铌酸锂、硅光、CPO封装、光模块液冷 cage、高速测试、InP 和化合物半导体设备也要提高权重。更远一点看，光互联还会影响数据中心的电力模型。未来客户采购 AI cloud，除了 GPU 小时价格，还会看网络架构能不能让大规模训练和推理少掉通信损耗。

后面要跟踪三个细节。第一，CHIPS 意向书能不能转成正式拨款。第二，NVIDIA 20 亿美元承诺最终落到哪些产品，激光器、外置激光源、CPO 交换侧光引擎还是传统可插拔模块。第三，CPO 和外置激光在 Rubin 后续平台上的真实出货节奏。如果这三个问题给出明确答案，光互联这条线会从“概念受益”进一步进入订单验证。

第二条，Microsoft Copilot Cowork 改成按算力计费，并考虑在 Azure 上托管 DeepSeek V4 或其他开源模型作为低成本选项。这条新闻看起来是软件定价，实际是在告诉市场：企业agent的商业模式开始正视 token 成本了。

普通聊天机器人可以按座席收费，因为用户问一句，模型答一句，成本大致可控。agent 完全不同。一个 agent 接到任务以后，会反复调用模型、工具、浏览器、代码执行、数据库、文档检索和上下文压缩。一次任务可能拆出几十步，用户看见的是“帮我完成这个工作”，后台消耗的是一串持续运行的模型调用。Axios 报道里，Microsoft 直接说，测试显示 Copilot Cowork 很难用无限使用套餐提供，因为有用户一周跑几百个任务，成本会非常高。

这个信号很重要。第一，企业 AI 软件的毛利率以后不能只看订阅收入，要看扣掉推理成本后的真实毛利。第二，模型路由会成为标配。高价值、强推理、强安全任务用 OpenAI 或 Anthropic 这类前沿模型；大量重复、格式化、低风险的流程任务，用低成本开源模型、本地模型或小模型。第三，企业客户会要求看得见成本。谁在烧 token，哪个任务超预算，哪个 agent 调用工具过多，哪个模型足够便宜又足够稳，这些都会进入采购和审计。

DeepSeek 出现在 Microsoft 候选列表里，也有产业含义。它说明开源模型的竞争力既体现在模型榜单，也体现在企业成本结构。Microsoft 的缓冲方式是把模型完全托管在 Azure 内，客户数据留在 Microsoft 云中，并套上 Azure 的安全、合规和数据驻留控制。地缘政治争议仍会存在，但企业会接受一件事：如果高端模型成本太高，低成本模型就会被包装成可选、可控、可审计的企业服务。

投资上，受益的方向包括模型路由器、AI gateway、token cost observability、agent sandbox、权限审计、低成本推理芯片、开源模型托管、企业数据连接器。受压的方向是只卖“无限 agent 套餐”的软件公司，因为用户一旦真用起来，推理成本会快速侵蚀毛利。后续最关键的是 Copilot Cowork 的正式价格页、低成本模型最终选择、客户是否接受 DeepSeek 这类选项，以及 usage-based pricing 会不会扩展到 Microsoft 365 Copilot 更大的产品面。

第三条，Bull 和 Foxconn 宣布在欧洲生产基于 NVIDIA Vera Rubin NVL72 的关键 AI 系统，流程是先在 Foxconn 捷克工厂制造和初测，再到 Bull 法国 Angers 工厂完成组装、集成和完整验证，并以 Bull 品牌商业化。目标客户包括欧洲和欧洲以外的 neo-cloud provider、cloud service provider，以及新一代 AI factory。

这条新闻和前两天写过的 Schneider Electric + Foxconn 要放在一起看。Schneider/Foxconn 解决的是电力、冷却、AI rack 和模块化交付包；Bull/Foxconn 解决的是欧洲本土 AI 服务器制造、系统集成、验证和软件层。Foxconn 站在中间，把全球 EMS 能力同时接到电力热管理、服务器制造、NVIDIA Rubin 平台和欧洲主权 AI。

欧洲主权 AI 过去常讲三件事：模型要本土，数据要留在本土，云服务要受本土监管。今天这条新闻把第四层补上：硬件系统也要尽量在本土制造和验证。对金融、政府、医疗、国防、工业客户来说，只把数据放在欧洲还不够，供应链、维保、系统验证、软件运维也要能接受审计。Bull/Foxconn 的价值就体现在这个位置。

产业链可以拆得很细。计算层是 Vera Rubin NVL72，牵涉 CPU、GPU、NVLink、内存、DPU、网络、存储和液冷。制造层是捷克生产、法国集成，牵涉机柜、线束、电源、冷却、测试、运输、备件和现场服务。软件层是 Bull 宣称的 AI software layer、embedded AI use cases 和 data science 能力。客户层则是欧洲云、欧洲主权 AI 项目，以及需要区域内交付的企业客户。

投资含义是，欧洲 AI 基础设施不能只看数据中心土地和电力，还要看服务器系统集成商、EMS、液冷、电力设备、测试验证、合规运维和本土云。Foxconn 的 AI server 角色继续上升，Bull 则把欧洲 HPC 和 AI 品牌资产接到 NVIDIA 最新平台。后续要看首批客户是谁、出货时间、单机柜功耗、液冷方案、欧洲本土零部件比例，以及是否接入法国或欧盟更大的 sovereign AI 资金。

第四条，MLPerf Training v6.0 发布，把 DeepSeek-V3 和 GPT-OSS 20B 加入标准训练基准。DeepSeek-V3 是 6710 亿总参数、每 token 激活 370 亿参数的大型 MoE benchmark；GPT-OSS 20B 是 210 亿总参数、每 token 激活 36 亿参数，给资源较小的组织一个入口。本轮有 95 个独特系统、13 种硬件加速器、19 种 host processor，60% 是多节点系统，提交方包括 AMD、Azure、CoreWeave、Dell、Google、HPE、Lambda、Nebius、Oracle、NVIDIA、Supermicro、Vultr 等。

这件事的意义在于，MoE 训练从各家自说自话，进入公开可比的标准考场。MoE 模型的难点覆盖矩阵乘法、token routing、expert load balance、all-to-all communication、网络拥塞、checkpoint 和长时间稳定性。DeepSeek-V3 被纳入 MLPerf，相当于把开源权重大模型、稀疏激活和生产级训练效率放到一个全球厂商都能提交结果的框架里。

CoreWeave 的结果尤其抢眼。公开材料显示，CoreWeave 在 NVIDIA GB300 NVL72 上训练 DeepSeek-V3，8192 个 GB300 GPU 达到目标质量只用 2.02 分钟；2048、4096、8192 GPU 对应时间分别是 5.54、3.09、2.02 分钟，扩展性非常强。NVIDIA 也披露，GB300 NVL72 在同规模下相比 GB200 NVL72 有最高 1.6 倍提升，来自 NVFP4、更高计算密度、更大内存和更高功率上限。

对客户来说，AI 云的差异化开始从“有多少张卡”进入“同样规模能不能把 MoE 稳定跑满”。CoreWeave、Azure、Nebius、Lambda、Oracle 这些 AI cloud 和 hyperscaler，未来面对大客户时会用 benchmark、SLA、网络、存储、调度、故障恢复和真实 workload 复现能力说话。对供应链来说，GB300、NVLink、Spectrum-X Ethernet、InfiniBand、存储、冷却、RAS、CUDA 和 NeMo 软件优化都会一起决定有效吞吐。

需要提醒一句，MLPerf 是标准 workload，不等同于真实 frontier training 的全流程。真实训练会有数据清洗、长期 checkpoint、多周运行、试错、故障恢复和客户隔离。但 MLPerf 的价值在于提供一块可比地板。客户先看谁能跑过标准题，再谈真实生产任务。投资者也可以用它筛选 AI cloud、服务器、网络和软件栈的真实能力。

第五条，HPE AI Factory with NVIDIA 扩展到 agent 时代。HPE Private Cloud AI 增加 NVIDIA Vera CPU、NVIDIA Agent Toolkit、NVIDIA Confidential Computing、HPE Zerto 回滚能力，以及更完整的 NVIDIA full-stack integration。HPE ProLiant Compute DL394 Gen12 搭载 Vera CPU，计划 2027 年随 HPE Private Cloud AI 提供。HPE 还会提供 Vera Rubin NVL72 rack-scale system，以及基于 NVIDIA HGX Rubin NVL8 的 HPE Compute XD700。

这条新闻的核心在控制面。NVIDIA Agent Toolkit 包括 Nemotron open models、OpenShell secure runtime、NemoClaw blueprints，用来监控 agent 行为、执行治理策略、运行长周期 multi-agent systems。HPE Private Cloud AI 增加本地 agent registration，让客户在 agent 运行前审批模型、skills 和 tools，并绑定集中治理策略。HPE Zerto 则加入识别 rogue agent actions，并通过 continuous data protection 回滚到 clean state 的能力。

企业 agent 进入生产以后，客户买的是可治理、可审计、可回滚的生产系统。金融、医疗、制造、政府客户会问：这个 agent 能调用哪些工具，谁批准的，访问了哪些数据，执行中有没有越权，出错后能不能回滚，敏感数据在执行时有没有加密，日志能不能审计。HPE/NVIDIA 给出的组合，就是 CPU、DPU、存储治理、机密计算、模型网关、agent registry、回滚和私有部署。

这和昨天写过的 Arcade.dev 形成呼应。Arcade 是 agent action layer 和授权审计，HPE/NVIDIA 是私有 AI factory 的底座。大型企业会把 agent 生产化拆成两个预算：一个是模型和应用，一个是治理、审计、回滚、安全、数据准备和基础设施。受益方向包括 HPE、NVIDIA、DPU、企业私有云、存储治理、备份恢复、IAM/GRC、agent gateway 和数据安全。后续要看 NYSE 这类早期客户是否进入生产、Vera CPU 的实际规格、Zerto 对 rogue agent 的检测效果，以及 agent registration 能不能接入企业现有权限体系。

第六条，TSMC 再次强调 CoWoS 仍有很长的路线空间，panel-level packaging 短期不会替代 CoWoS。Tom's Hardware 报道称，TSMC 在 European Technology Symposium 上表示，CoWoS 可以通过 wafer-level processes 扩展到 14X，并集成 58 个 large reticle-sized dies。CoPoS 作为 panel-based path 会继续推进，第一条 pilot line 预计 2026 年 6 月完成，但高量产更合理的时间点落在 2029 到 2030 年附近。

这条新闻对先进封装投资很重要。市场喜欢提前交易 CoPoS、panel-level packaging、玻璃基板和超大封装，因为 AI ASIC、GPU、HBM、chiplet 都需要更大的集成面积。但 TSMC 的表态说明，2026 到 2028 年确定性最高的主线仍然是 CoWoS、SoIC、RDL、interposer、HBM stack、ABF/BT 高端基板、检测量测、临时键合、underfill、TIM、探针卡和 HBM 测试。

面板级封装的尺寸优势真实存在，310mm 甚至更大的 panel 未来会有空间。但它面临工具成熟度、互联密度、翘曲控制、良率、热管理和生态爬坡。CoWoS 已经在量产中承载高端 AI 芯片，客户、工艺、设备和设计流程都更成熟。短期投资不宜把 CoPoS 当成 CoWoS 的替代品，更适合把它看成长周期期权。
