## 9. 优先候选研究包

### 研究包 A｜Sandisk：NAND 长协从数量进入可约束现金流

- **核心事实**：8 个客户、2 次扩约、平均期限超过 4 年；底价合同值 $93.9B、RPO $91.1B、保障 $16.5B；FY27/FY28 约 50%/约 67% bits。
- **最短基线**：8/6 已讲累计 10 份 NBM 与数据中心收入/定价，条款和覆盖率为空白。
- **新增机制**：最低财务保障与结构化定价把客户需求、产能规划和周期风险放进可执行框架；RPO 仍需按终止权、交付、价格调整和会计确认拆解。
- **反证/边界**：客户未具名；八客户集中度可能很高；底价不是最终 ASP；保障不等同现金预付；FY28 毛利 80%等为远期目标。
- **写稿重点**：协议如何改变 NAND 周期弹性；合同价值、RPO、保障和实际收入的区别；为何 HBF tape-out 仍只放边栏。
- **验证问题**：客户、取消/重谈、保障工具、交付 schedule、RPO 转收入、库存与 Kioxia 供给。
- **不应重复**：8/6 已讲的 NAND 涨价、数据中心收入、公司名单和 HBF 基础架构。

### 研究包 B｜DeepSeek：正式 GA 后重写推理价格曲线

- **核心事实**：V4-Pro 正式 GA，1M/384K、并发 500；8/16 起 Pro 峰时 hit/miss/output 为 $0.044/$1.32/$3.96 每百万 token。
- **相对旧价**：hit +1,114%、miss +203%、output +355%；离峰仍分别上调约 507%、52%、128%。
- **新增机制**：静默端点阶段的低价不能外推正式 GA 后的容量与商业定价；峰谷价把 workload scheduling 直接变成推理成本变量。
- **证据边界**：benchmark 和并发由公司发布；权重、许可证、完整模型卡与独立长任务仍缺。
- **写稿重点**：价格上涨幅度、峰时窗口、与 Gemini 促销价的相反商业路径；避免重复 8/1 后训练与 DSpark 基线。
- **验证问题**：单位成功任务成本、缓存命中率、峰时 SLO、API 迁移、第三方复现、权重/许可。

### 研究包 C｜Applied Materials 与 Lam：设备收入和研发吞吐两层兑现

- **判断增量**：一个信号确认设备销售与指引，另一个信号增加工艺开发/客户 qualification 的供给能力。
- **边界**：AMAT 未拆 AI/HBM 收入；Lam 未拆站点、年度支出和转化率。两家公司均有管理层归因。
- **不应重复**：6/26 已讲 AMAT 六套 DRAM/封装系统与 memory wall 产业名单。

### 研究包 D｜Databricks：term sheet 变成资本与收入双闭环

- **核心事实**：$5B close、$190B valuation、>$7B revenue run-rate、>80% YoY；Lakehouse >$1.5B、Lakebase >$100M；1,000+ 百万美元级和 100+ 千万美元级客户。

- **边界**：私营公司没有公开审计财务；run-rate 受季末用量影响；融资可能含不同证券或流动性安排。
- **验证问题**：gross margin、net retention、burn、一级/二级、清算偏好、Lakebase/Genie/Gateway 真实客户使用。

### 研究包 E｜Gemini 3.7 Flash：能力提升由限时价格补贴加速分发

- **核心事实**：直接 GA、1M/64K、多个 agent/computer benchmark 上移；年内 $0.75/$3.75，次年 $1.50/$7.50。
- **判断增量**：产品时表继续快于旗舰 Pro，Google 用促销降低迁移摩擦；2027 价格回升使当前对比不能当永久 TCO。
- **反证**：多数 benchmark 为 Google/合作方，AutomationBench 私有；安全/拒答指标有小幅退化。
- **验证问题**：速度、cache、重试、真实 agent 成功成本、促销结束留存、sampling 参数兼容。

### 研究包 F｜NIXL：数据传输完成、通知和请求状态需要同一失败域

- **vLLM 链**：geometry hash 通过；运行时握手拒绝；成功传输为 0；API 仍返回 200+乱码。修复原型把 HMA 失败按 request ID 上送。
- **TensorRT 链**：RDMA 数据与 done notification 分离；通知丢失后 GEN 无 timeout/retry，CPU 自旋、GPU idle；UCX 可规避。
- **共同判断**：分离式 prefill/decode 的性能收益增加状态机边界；传输、通知、取消、健康和 response schema 必须端到端认证。
- **边界**：开放 issue/PR；没有生产请求比例、NIXL/fabric 完整版本与稳定修复。
- **验证问题**：block geometry negotiation、timeout、idempotency、partial transfer、connector 矩阵、stable。

### 研究包 G｜2,638 个 kernel：通过旧测试仍大量违约

- **核心事实**：39.5% 超容差、62.1% 至少一项违约；1,487 个是旧测 accept/新 verifier reject，反向 14 个。
- **为什么值得重开**：昨日 31 个真实 PR 的结果给出完整生产成功率；今日大样本把验证合同具体化并扩大约 85 倍。
- **边界**：公共系统选出的 kernel 可能有 selection bias；作者 verifier 自评仍需独立复核；GPU/算子 mix 不明。
- **写稿重点**：生成质量、测试质量和生产契约是三个层次；不能把“编译/基准通过”当成可部署。

### 研究包 H｜Google ADK：安全 release 与同日回归

- **已落地修复**：artifact/RAG/thread/app-user 隔离、stdio MCP、凭据和 trace、builder code refs、computer-use URL、代码超时。
- **回归一**：审批 FunctionResponse 变文本，远端 leaf 丢失批准态；真实工具执行计数为 0，模型仍可能生成完成表述。
- **回归二**：completion provider 与 file-upload provider 分叉，残留 key 可能把文件送往非预期公共端点。
- **判断增量**：单组件默认安全不足；跨组件结构化状态、provider provenance 与数据平面要共同测试。
- **边界**：开放 issue/PR；没有确认生产泄露或越权执行。

### 研究包 I｜Tao：proof digestion 可能成为 AI 数学的产能瓶颈

- **时间线**：5 月挑战数据由 Tao 转述；7/24 演讲；8/13 官方视频发布。
- **流程**：问题选择→生成→形式验证→人类审阅→解释/发表→canonicalization。AI 加速前两步可增加后四步积压。
- **产业/产品观察**：验证器、proof summarization、provenance、review queue 与教学工具的需求可能上升；投资映射目前弱。
- **反证**：First Proof 样本仅 10 题；near-publication-quality 需要独立评委定义；形式验证的可信基底与可读性仍分离。
- **不应重复**：泛化的“AI 会做数学”与 benchmark 排名。

### 研究包 J｜Net Power：speed-to-power 把碳捕集后移

- **核心事实**：近端转向无捕集燃气；已订约 68MW 模块化机组；捕集等客户、经济性和融资支持后再叠加；公司没有项目融资、客户保证金或伙伴资本。
- **新增机制**：AI 负荷的时间价值可以压过低碳完整方案，形成先排放、后捕集的路径依赖。
- **反证**：仍无 off-taker、PPA、FID、许可与燃机交付；$310M 流动性假设不含新增 pre-FID 设备义务。
- **验证问题**：客户、气源、排放、45Q、捕集 retrofit 成本、设备 long lead、项目融资。

### 研究包 K｜Apple 中国与 Pony/Uber：本地控制权和资产轻部署

- **Apple**：Reuters 报道自有中国模型、阿里协助训练；架构从第三方能力接入向自有控制移动。证据 B，未官宣。
- **Pony/Uber**：2,000+ 辆、5 城；技术、平台、日常运营、车辆融资/所有权可由不同伙伴承担。证据 A，未给期限。
- **共同观察**：跨市场 AI 产品会把模型/车辆 IP、合规、获客和资本资产拆给不同主体。
- **验证问题**：Apple 权重/备案/部署；Pony 城市/许可/融资/单位经济。

### 研究包 L｜运行时正确性矩阵：成功状态必须覆盖语义、吞吐和资源

- **语义**：NVFP4 非 gated MoE 流畅答错、VisualGen 坏帧、OpenVINO RoPE PPL 异常。
- **吞吐/存活**：autotune deadlock、Qwen health 200 但生成归零、NIXL notification hang。
- **资源/硬件**：OpenVINO RSS 改善、Blackwell Xid13 长稳问题。
- **下游展开**：主讲 NIXL 或 NVFP4 一组；其余作为认证矩阵，不逐 issue 念清单。
- **验证维度**：模型、GPU、精度、backend、shape、并行、网络、idle、长稳、health、response schema、语义探针。
