### 1. Google I/O 正式确认：Google 要把 Gemini 做成横跨搜索、App、开发者、Workspace、Android 和云的 agent 层

- 综合评分：9.2/10
- 分项评分：新鲜程度 8.5；AI 产业链重要度 10.0；可投资可套现程度 9.0；开创性 8.5。
- 新闻摘要：Google 5 月 19 日在 I/O 2026 正式发布 Gemini 3.5、Gemini Omni、Gemini Spark、Search information agents、Antigravity 2.0、AI Ultra 新订阅、Gemini for Science、Project Genie/Street View 等一组产品。官方总览把本次大会概括为“agentic Gemini era”：模型不只回答问题，而是通过 Search、Gemini App、Antigravity、Workspace、Android Halo 和 Cloud VM 持续执行任务。
- 发生时间：2026-05-19 PT，Google I/O 2026 第一天。
- 关键人物：Sundar Pichai；Koray Kavukcuoglu；Jeff Dean；Oriol Vinyals；Noam Shazeer；Josh Woodward；Pushmeet Kohli。
- 关键公司：Alphabet/Google、Google DeepMind、Google Cloud、NVIDIA、OpenAI、Anthropic、Microsoft、Salesforce、Shopify、Ramp、Databricks、Xero。
- 关键数字：
  - Gemini App 月活从去年 I/O 的 4 亿提升到超过 9 亿，覆盖 230 个国家/地区和 70 多种语言。
  - Gemini 3.5 Flash 已在 Gemini App、Search AI Mode、Antigravity、Gemini API、AI Studio、Android Studio、Gemini Enterprise Agent Platform 中可用。
  - Google 称 3.5 Flash 在 Terminal-Bench 2.1 达到 76.2%，GDPval-AA 为 1656 Elo，MCP Atlas 为 83.6%，CharXiv Reasoning 为 84.2%，输出速度约为其他 frontier models 的 4 倍。
  - Google AI Ultra 新增 100 美元/月档，Gemini App 和 Antigravity 用量上限为 Pro 的 5 倍；最高档从 250 美元/月下调到 200 美元/月，并提供 Pro 的 20 倍上限。
  - Axios 记录 Pichai 的大会说法：Google 每月处理约 3.2 quadrillion tokens，高于一年前的 480 trillion 和两年前的 9.7 trillion。
- 关键引述：Google 官方口径是从“AI tools that just help us write”走向“agents that help us act”。这句话的增量很明确：Google 将 agent 放到产品交互和开发者基础设施中心，而不是把它当成 Gemini 的附属功能。
- 历史背景：过去一周旧稿已经覆盖 Google I/O 预热，市场预期集中在 Gemini、agentic coding 和新模型。正式发布后的 delta 是：Google 同时给出模型、消费者 agent、搜索入口、开发者编排、订阅定价和内容安全机制，形成一个完整商业闭环。
- 前因后果：OpenAI 的 Codex、Anthropic 的 Claude Code/Cowork、Microsoft 的 Copilot/Agent 365 都在争夺企业 agent 入口。Google 的差异化是拥有 Search、Gmail、Calendar、YouTube、Android、Chrome、Cloud 和 TPU/GPU 基础设施，因此它可以把 agent 推进更多默认入口。
- 周边消息：TechCrunch 将 Gemini 3.5 Flash 解读为 Google 从 chatbot 叙事转向 agent 叙事；Axios 则指出 Google 资产最深，但需要防守的产品表面积也最大。
- 业内评论或反对观点：反对观点不是“Google 没模型”，而是“agent 广泛自动化是否足够安全、可靠、可审计”。TechCrunch 特别提到，消费者级 autonomous agents 会放大伤害风险，Google 因此强调 cyber、CBRN 和敏感问题处理 safeguards。
- 未来发展路径：短期看 Gemini Spark Beta、Search agents、Antigravity 2.0 与 Gemini API Managed Agents 的实际留存；中期看 Google 能否把 Workspace、Android、Chrome 和 Search 中的 agent 行为变成统一权限、记忆和审计层；长期看 TPU/Google Cloud 是否因此获得更稳定的 inference demand。
- 发展瓶颈：可靠性、权限边界、用户信任、长任务中断处理、企业数据隔离、成本控制、广告与内容生态冲突。
- 可能的投资方向变化：
  - 权重上调：Alphabet 作为模型+分发+云+订阅的全栈 agent 平台；云端推理、observability、agent sandbox、企业权限治理。
  - 保持关注：NVIDIA/Google Cloud 混合栈、数据中心电力与网络、推理优化软件、企业 AI 安全。
  - 谨慎：纯搜索流量套利、低壁垒 AI wrapper、无法处理权限和审计的 agent 工具。
- 需要继续验证：Gemini Spark 是否能从 trusted testers 顺利进入美国 AI Ultra Beta；Search agents 对广告点击率和出版商流量的影响；AI Ultra 100 美元档是否推动开发者迁移；3.5 Flash 的第三方基准和真实成本。

### 2. Gemini 3.5 Flash + Antigravity 2.0：coding agent 竞争从“模型聪明”转向“多 agent 执行环境”

- 综合评分：8.8/10
- 分项评分：新鲜程度 8.5；AI 产业链重要度 9.5；可投资可套现程度 8.5；开创性 8.5。
- 新闻摘要：Google 发布 Gemini 3.5 Flash，并同步升级 Antigravity 2.0、Antigravity CLI、Antigravity SDK、Gemini API Managed Agents。开发者不只是调用模型，而是可以启动带隔离 Linux 环境、持久状态、工具调用和代码执行能力的 managed agent；桌面端则支持多个 subagents 并行处理复杂工作流。
- 发生时间：2026-05-19。
- 关键人物：Varun Mohan；Logan Kilpatrick；Koray Kavukcuoglu；Jeff Dean；Noam Shazeer。
- 关键公司：Google DeepMind、Google Cloud、Firebase、Android、Salesforce、Shopify、Macquarie Bank、Ramp、Xero、Databricks。
- 关键数字：
  - Google 称 Gemini 3.5 Flash “frontier performance for agents and coding”，并且输出速度为其他 frontier models 的 4 倍。
  - Antigravity 场景中，Pichai 提到优化后的 Flash 版本可达到 12 倍速度。
  - Google 开发者博客称 Antigravity CLI 继承 Gemini CLI 社区基础：超过 10 万 GitHub stars、6000 个 merged pull requests、数百名贡献者。
  - Managed Agents 单次 API call 即可提供可恢复的远程 sandbox 和文件状态。
- 关键引述：TechCrunch 引述 Google 高管称，3.5 Flash 的组合优势是质量与低延迟；Google 的开发者博客则强调从“assists you”转向“independently navigate complex tasks”。
- 历史背景：5 月 18 日旧稿已经覆盖 OpenAI/Dell Codex 走向企业本地环境、Cursor Composer 2.5 通过后训练改善长任务行为。Google 的新增点是：把 coding agent、search generative UI、consumer Spark 和 API managed agents 放在同一 Antigravity harness 逻辑下。
- 前因后果：开发者 agent 的瓶颈正在从“是否能写代码”变成“能否长时间、多分支、可恢复、安全地执行”。这会使 agent harness、权限系统、隔离环境、日志审计、自动化队列和成本管控成为产品差异。
- 周边消息：OpenAI Codex、Claude Code、Cursor、GitHub Copilot CLI、Google Antigravity 都在争夺同一批高频工程师和企业研发组织。Google 此次把 Gemini CLI 迁移到 Antigravity CLI，说明它希望减少产品线分裂，把开发者使用面统一到一个 agent-first 后端。
- 业内评论或反对观点：模型 benchmark 仍需第三方验证；agent 在真实代码库里最难的不是生成，而是权限、安全、依赖安装、测试稳定性、跨团队规范和回滚。Google 声称有 terminal sandboxing、credential masking 和 hardened Git policies，但企业会看真实事故率。
- 未来发展路径：Antigravity 2.0 若能把 IDE、CLI、AI Studio、Firebase、Cloud Run、Workspace 和 Android 原生开发串起来，可能成为 Google 版“agent IDE + agent runtime + agent deployment platform”。Managed Agents 若被企业采用，会把推理收入从聊天订阅转为长期任务执行费。
- 发展瓶颈：agent 任务失败成本、token 预算失控、并行 subagent 的冲突合并、私有代码访问权限、CI/CD 审计、对 GitHub/Microsoft 生态依赖。
- 可能的投资方向变化：
  - 权重上调：开发者 agent 平台、remote sandbox、agent observability、代码审计和供应链安全。
  - 产业链受益：云端 CPU/GPU/TPU 推理、对象存储、日志/SIEM、企业权限管理。
  - 竞争风险：单纯 IDE 插件和缺少云端运行时的 coding assistant 更容易被平台方挤压。
- 需要继续验证：Antigravity CLI 迁移是否平滑；Managed Agents 的价格、并发和隔离强度；企业客户是否愿意在 Google 平台上运行私有代码 agent。

### 3. Search agents：Google Search 从答案页面变成常驻监控和生成式 mini app 平台

- 综合评分：8.4/10
- 分项评分：新鲜程度 8.0；AI 产业链重要度 9.0；可投资可套现程度 8.0；开创性 8.5。
- 新闻摘要：Google 在 I/O 宣布 Search 的 AI Mode 默认升级到 Gemini 3.5 Flash，并推出 information agents。用户可以在 Search 内创建和管理多个 24/7 agent，让它们持续监控新闻、购物、体育、金融和网页变化，并在满足条件时推送综合更新。Search 还将用 Antigravity 生成自定义可交互 UI、模拟器、dashboard 和 tracker。
- 发生时间：2026-05-19。
- 关键人物：Elizabeth Reid；Sundar Pichai；Shivani Mohan。
- 关键公司：Google Search、Google Shopping、Chrome、YouTube、出版商、电商平台、本地服务商。
- 关键数字：
  - Search AI Mode 推出一年后月活超过 10 亿。
  - AI Mode queries 自推出以来每季度翻倍，上季度 Search queries 达历史新高。
  - Information agents 将于今年夏天先面向 Google AI Pro 和 Ultra 用户推出。
  - 美国用户今年夏天会看到更广的 agentic booking 和“让 Google 代打电话”能力。
- 关键引述：Google 把 Search agents 描述为能在后台工作、持续监控变化、在正确时间找到信息并帮助用户行动的系统。这里的关键词是后台和行动。
- 历史背景：过去两年 Google 已用 AI Overviews 和 AI Mode 改变搜索结果页，但那仍然主要是“回答”。本次新增的是长期任务、个性化监控、行动链接、生成 UI 和 persistent dashboard。
- 前因后果：如果 Search 变成 agent control plane，用户的信息消费会更少点击网页，更多留在 Google 的综合界面里。这对出版商、SEO、广告归因和购物转化都有影响，也会把推理成本内嵌进搜索商业模式。
- 周边消息：Axios 的评论是，Google 拥有最深的资产，但也有最大的防守面积。AI-native 应用若绕开搜索、邮箱、浏览器和 YouTube，Google 的广告与分发优势会被侵蚀；Search agents 是 Google 把防守转成进攻的一步。
- 业内评论或反对观点：出版商会担心 Search agents 进一步降低点击；广告主会关注转化归因是否透明；用户会关注个性化 agent 是否过度读取 Gmail、Calendar、Photos 和浏览数据。
- 未来发展路径：先看 information agents 与 shopping/local booking 的留存，再看 generative UI 是否成为新搜索格式。如果用户习惯让 Search 持续监控任务，Search 可能从“搜索频次”转向“agent 运行时长”和“任务完成率”定价。
- 发展瓶颈：内容版权、事实准确性、广告商业模式、publisher backlash、隐私权限、agent 操作失败责任。
- 可能的投资方向变化：
  - 权重上调：Alphabet 搜索防守能力、AI 广告工具、agent commerce、内容溯源与品牌安全。
  - 权重下调：依赖 Google organic click-through 的低护城河内容站。
  - 关注：能提供结构化库存、实时价格、预订 API、本地商户数据的垂直服务平台。
- 需要继续验证：AI Mode 的 monetization；Search agents 对查询量、点击率和广告价格的影响；publisher 合作或冲突是否加剧。

### 4. Gemini for Science / Co-Scientist：AI for Science 从“论文阅读器”升级为多 agent 假设生成与验证工作台

- 综合评分：8.0/10
- 分项评分：新鲜程度 8.0；AI 产业链重要度 8.5；可投资可套现程度 6.5；开创性 9.0。
- 新闻摘要：Google 发布 Gemini for Science，并在 Nature 发布 Co-Scientist 研究。Gemini for Science 包括 Hypothesis Generation、Computational Discovery、Literature Insights 三类实验工具，分别基于 Co-Scientist、AlphaEvolve/ERA 和 NotebookLM。Co-Scientist 是一个由 Gemini 驱动的多 agent 系统，用生成、聚类、反思、排序、进化和 meta-review agents 模拟科研假设生成、辩论和迭代。
- 发生时间：2026-05-19。
- 关键人物：Pushmeet Kohli；Yossi Matias；Co-Scientist team；Gary Peltz；Ritu Raman；Ryan Flynn；Omar Abudayyeh；Jonathan Gootenberg；Clare Bryant；Matt Onsum；Katherine Labbe。
- 关键公司/机构：Google DeepMind、Google Research、Google Cloud、Google Labs、Stanford、MIT、Boston Children's Hospital、University of Cambridge、University of Edinburgh、Calico、Daiichi Sankyo、Bayer Crop Science、U.S. National Labs、BASF、Klarna。
- 关键数字：
  - Science Skills 连接 30 多个生命科学数据库和工具，包括 UniProt、AlphaFold Database、AlphaGenome API、InterPro。
  - Google 称超过 100 家机构参与新系统和工具验证。
  - Co-Scientist 在肝纤维化案例中提示的候选方向之一在实验中阻断了 91% 的 scarring-linked response。
  - 衰老研究案例中，Co-Scientist 将大规模筛选数据分析从数月缩短到数日；感染病研究案例称可能把部分实验工作从数年压缩到数月。
- 关键引述：DeepMind 对 Co-Scientist 的核心表述是：它会生成、辩论并演化复杂科学问题的新假设。对产业链来说，这比“总结论文”更接近科研生产函数本身。
- 历史背景：5 月 15 日补充稿已覆盖 AlphaEvolve 进入 TPU 设计、Spanner 优化、电网可行解搜索等基础设施场景；5 月 18 日旧稿覆盖 Isomorphic Labs 融资和 AI 制药临床化窗口。今天的新增点是，Google 把 AI for Science 产品化成可申请试用的 Labs/Cloud/Antigravity 工具，并给出 Nature 论文和多个外部实验案例。
- 前因后果：科研瓶颈一部分来自知识爆炸和假设空间太大。Co-Scientist 的价值不在替代实验，而在扩大可检索、可辩论、可排序的假设数量，然后把人类实验资源集中到高价值方向。
- 周边消息：Gemini for Science 与 Google Cloud enterprise R&D 绑定，BASF 用 AlphaEvolve 优化供应链，Klarna 用其改善机器学习模型，Daiichi Sankyo、Bayer Crop Science 和美国国家实验室使用 Co-Scientist。AI for Science 正从 DeepMind 单点成果变成 Google Cloud 企业产品线。
- 业内评论或反对观点：生物医药的验证周期长，AI 提出假设不等于临床成功；多 agent 生成假设也可能放大文献偏差、数据集偏差和不可重复结果。真正商业化需要湿实验、法规、知识产权和数据授权共同闭环。
- 未来发展路径：短期看 Labs 注册和 Cloud 私有预览客户；中期看论文验证能否转化为药物、材料、气候、电网、工业优化案例；长期看 AI for Science 是否成为 Google Cloud 面向制药、化工、能源和国家实验室的高价值垂直入口。
- 发展瓶颈：实验验证成本、专有数据接入、模型可解释性、知识产权归属、科研机构合规、从候选机制到临床/工业落地的长周期。
- 可能的投资方向变化：
  - 权重上调：AI for Science 平台、云端科研工作台、生命科学数据库、实验自动化、科学计算基础设施。
  - 间接受益：Google Cloud、实验室自动化、CRO、科学数据服务、药物发现软件。
  - 谨慎：把“AI 发现候选”直接等同于药物商业化收入的叙事。
- 需要继续验证：Nature 论文的独立复现；企业客户是否愿意为 Gemini for Science 付费；Co-Scientist 在非生命科学领域的可迁移性。

### 5. Gemini Omni 与 SynthID/C2PA：生成媒体能力升级，同时把内容溯源做成云服务和行业标准入口

- 综合评分：7.6/10
- 分项评分：新鲜程度 7.5；AI 产业链重要度 8.0；可投资可套现程度 7.0；开创性 8.0。
- 新闻摘要：Google 发布 Gemini Omni Flash，主打从文本、图像、音频、视频等输入生成和编辑视频，并强调物理直觉、场景连续性、角色一致性和对话式多轮编辑。与此同时，Google 扩大 SynthID 与 C2PA Content Credentials：SynthID 已用于超过 1000 亿张图像/视频和 6 万年音频水印，验证功能扩展到 Gemini、Search 和 Chrome，Google Cloud 还推出 AI Content Detection API。
- 发生时间：2026-05-19。
- 关键人物：Koray Kavukcuoglu；Laurie Richardson；Pushmeet Kohli；Demis Hassabis。
- 关键公司：Google DeepMind、Google、YouTube Shorts、Google Flow、OpenAI、Kakao、ElevenLabs、NVIDIA、Meta、Canva、Avid、Snap、Fox Sports、Shutterstock。
- 关键数字：
  - Gemini Omni Flash 首发到 Gemini App、Google Flow 和 YouTube Shorts。
  - SynthID 已水印超过 1000 亿张图像和视频、6 万年音频。
  - SynthID verification 已在 Gemini App 中被全球使用 5000 万次，并扩展到 Search，未来数周进入 Chrome。
  - Google 表示 OpenAI、Kakao、ElevenLabs 将把 SynthID 技术用于更多 AI 生成内容；NVIDIA Cosmos world foundation models 也与 SynthID 水印合作。
- 关键引述：Axios 引述 Demis Hassabis 对 Omni 的描述是，任何东西都可以变成创造新现实的画布。这里的产业意义是：视频生成不再只是 prompt-to-video，而是多模态输入、世界知识和持续编辑。
- 历史背景：过去新闻已覆盖 Google DeepMind AlphaEvolve 和 Isomorphic Labs，说明 Google 在“模型用于创造/发现”的技术线持续推进。今天 Omni 和 SynthID 的组合显示另一个方向：生成能力增强的同时，平台方必须补上来源证明和检测。
- 前因后果：视频生成越强，广告、短视频、电商内容、游戏预演、影视预制和品牌素材会更自动化；但 deepfake、版权和诈骗风险同步上升，因此水印、C2PA、检测 API 和平台标签会变成基础设施。
- 周边消息：Google 将 Pixel 原生相机的 Content Credentials 扩展到视频，并称 Meta 会在 Instagram 标注带 Content Credentials 的相机原始内容。这个链条如果成形，会把手机、社交平台、云 API、生成模型和检测工具连成一个 provenance network。
- 业内评论或反对观点：水印和 C2PA 不是万能防线，可能被转码、截屏、再生成、压缩或恶意处理绕过。内容溯源的商业价值取决于平台采用率和法律/广告客户是否要求。
- 未来发展路径：Omni 短期会推动 Flow、YouTube Shorts 和 Gemini App 的创作使用量；中期看品牌工作流和广告素材能否批量采用；长期看 SynthID/C2PA/API 是否成为保险、媒体、广告、社交平台和金融反欺诈的合规工具。
- 发展瓶颈：版权、肖像权、检测误报/漏报、多平台互操作、内容平台执行标准、生成视频算力成本。
- 可能的投资方向变化：
  - 权重上调：生成式媒体工作流、AI 内容检测、品牌安全、广告素材自动化、云端视频推理。
  - 间接受益：GPU/TPU 推理、视频存储/CDN、内容审核、数字水印、C2PA 生态。
  - 谨慎：无溯源、无版权控制的纯视频生成工具可能面临平台与监管压力。
- 需要继续验证：OpenAI、ElevenLabs、Kakao 具体哪些内容采用 SynthID；AI Content Detection API 的商业定价和准确率；Omni 与 Sora、Runway、Kling、Pika 等视频模型的第三方横评。

## 新闻口播稿

各位早上好。今天 AI 产业链最值得盯住的，不是一条孤立的新模型消息，而是 Google 在 I/O 2026 上释放出的一个更大的信号：AI 正在从“帮你回答问题的聊天框”，进入“替你持续执行任务的 agent 层”。

这句话听起来像产品口号，但背后其实是产业结构的变化。过去一年，大家最容易比较的是模型参数、跑分、上下文长度、价格表。但今天 Google 的动作不是只发一个 Gemini 3.5 Flash，也不是只展示 Gemini Omni 视频生成，而是同时把 Gemini 放进搜索、Gemini App、开发者工具 Antigravity、企业 API、科研工作台、订阅体系、内容溯源和 Google Cloud 里。换句话说，Google 想证明自己不是一家只有模型的公司，而是拥有入口、工具、数据、云和算力的全栈 agent 平台。

先看第一条主线：Google 正式把这次 I/O 定义为 agentic Gemini era。Gemini App 月活已经超过 9 亿，覆盖 230 个国家和地区、70 多种语言；Search AI Mode 月活超过 10 亿；Google 每月处理的 token 规模被提到大约 3.2 quadrillion，高于一年前的 480 trillion 和两年前的 9.7 trillion。这个数字真正重要的地方，不是它有多大，而是它说明推理需求已经不是实验室流量，而是被搜索、移动端、办公、开发者和消费者产品持续拉动的基础设施流量。

Gemini 3.5 Flash 在这个体系里的角色很清楚：它不是为了在演示里慢慢思考，而是为了高频、低延迟、可调用工具的 agent 场景。Google 强调它在 coding、agent、terminal、视觉推理和长任务里有 frontier 级表现，同时输出速度约为其他 frontier models 的 4 倍。对产业链来说，速度本身就是商业模式。一个 agent 如果要监控新闻、改代码、生成报表、安排预约、跑实验、反复调用工具，它消耗的是大量小步推理。模型越快，越便宜，越能把 agent 从“偶尔试一下”变成“全天候开着”。

所以今天第一层投资含义是：AI 竞争正在从“谁有最强聊天机器人”，转向“谁能把 agent 嵌进默认工作流”。Alphabet 的优势不只是 Gemini，而是 Search、Gmail、Calendar、Android、Chrome、YouTube、Workspace、Cloud 和 TPU/GPU 混合基础设施。这里的风险也同样清楚：agent 越主动，权限、隐私、误操作、审计、成本控制就越难。未来真正有价值的，不只是模型公司，还会包括 agent sandbox、企业权限治理、可观测性、日志审计、数据隔离、安全扫描和推理成本优化。

第二条主线是开发者工具。Gemini 3.5 Flash 和 Antigravity 2.0 的组合，说明 coding agent 的竞争已经从“IDE 里帮我补一段代码”，升级到“云端替我跑一个可恢复、可隔离、可审计的开发任务”。Google 这次推出 Antigravity 2.0、Antigravity CLI、Antigravity SDK 和 Gemini API Managed Agents。开发者可以启动远程 Linux sandbox，保留文件状态，调用工具，执行代码，也可以让多个 subagent 并行处理复杂工作流。

这个变化很关键。过去的 AI 编程助手，主要价值是写得快；今天的 coding agent，价值是能不能长时间处理真实代码库。真实代码库的问题不只是语法，而是依赖安装、测试失败、权限边界、私有凭证、团队规范、CI/CD、回滚和安全审计。Google 强调 terminal sandboxing、credential masking 和 hardened Git policies，说明它知道企业客户真正害怕什么。企业不是不想要 agent，而是不想让一个 agent 带着凭证在生产环境里乱跑。

这里的竞争对手也非常明确：OpenAI 有 Codex，Anthropic 有 Claude Code，Cursor 正在把 Composer 做成更强的长任务工具，GitHub Copilot 也在向 CLI 和 agent 方向推进。Google 的不同点在于，它想把 AI Studio、Gemini API、Firebase、Cloud Run、Android Studio、Workspace 和 Antigravity 接成一条线。如果这条线跑通，开发者 agent 就不只是一个编辑器插件，而是一个 agent IDE 加 agent runtime 加 agent deployment platform。

这会怎么影响产业链？第一，推理 token 会增长，而且增长来自高频工程任务，不只是消费者聊天。第二，云端 sandbox、对象存储、日志、身份权限、代码安全和供应链安全会成为配套支出。第三，只有本地插件、没有云端执行环境的 coding assistant 会被平台型公司挤压。第四，企业会更愿意为“可控的自动化”付费，而不是为“会写代码的玩具”付费。

第三条主线是搜索。Google Search 的变化可能比模型发布更影响互联网商业。Search AI Mode 默认升级到 Gemini 3.5 Flash，并推出 information agents。用户可以创建多个 24/7 agent，让它们持续监控新闻、购物、体育、金融和网页变化，在满足条件时推送综合更新。Search 还会用 Antigravity 生成可交互的小界面，比如模拟器、dashboard、tracker 和定制化 mini app。

这意味着搜索正在从“你问一次，它答一次”，变成“你交代一个目标，它持续盯着”。过去搜索的核心指标是 query、点击率、广告展示和转化；agent 化之后，可能出现新的指标：一个任务被运行多久、监控了多少来源、触发了多少行动、最终完成了多少交易。对用户来说，这很方便；对出版商和内容站来说，这可能更痛。因为如果 Google 直接把信息整合成持续更新的面板，用户点击原网页的需求会下降。

这也是 Google 的防守和进攻同时发生。AI-native 应用如果绕开搜索、浏览器、邮箱和 YouTube，Google 的广告与分发优势会被侵蚀。Search agents 是 Google 把防守转成进攻的一步。它把搜索从网页入口，升级成信息监控入口、购物入口、本地服务入口和行动入口。未来要关注的不只是 AI Mode 有多少用户，还要看它如何变现：广告是继续按点击卖，还是按任务完成、线索、购物佣金和本地服务转化来卖。

这条线对投资的启示很直接。Alphabet 的搜索护城河不能简单用“AI 会不会替代搜索”来判断，而要看 Google 能不能把搜索变成 agent control plane。受益的可能包括结构化库存、实时价格、预订 API、本地商户数据、广告自动化和品牌安全；受压的可能是依赖自然搜索点击的低护城河内容站、低质量 SEO 和没有结构化数据接口的中间页。

第四条主线是 AI for Science。Google 发布 Gemini for Science，并在 Nature 发布 Co-Scientist 研究。这个方向短期不一定像算力链那么容易兑现收入，但它的开创性很高，因为它把 AI 从“读论文、总结文献”，推向“提出假设、组织争辩、排序验证路径”的科研工作台。

Co-Scientist 是一个多 agent 系统。它不是一个 agent 说了算，而是让不同 agent 生成、聚类、反思、排序、进化和 meta-review。听起来抽象，但可以把它想成一个永不疲惫的研究组：有人负责提出新假设，有人负责找反例，有人负责整理相似路线，有人负责打分，有人负责复盘。它不能替代湿实验，也不能保证临床成功，但它能扩大候选假设空间，把人类实验资源集中到更值得验证的方向。

今天材料里有几个很有冲击力的例子：Science Skills 连接 30 多个生命科学数据库和工具；超过 100 家机构参与验证；在肝纤维化案例中，一个候选方向在实验中阻断了 91% 的 scarring-linked response；衰老研究案例把大规模筛选数据分析从数月缩短到数日。这里必须谨慎：从一个实验信号到药物收入，中间还有漫长的验证、知识产权、法规和商业化周期。但产业意义已经足够明确：AI for Science 正在从 DeepMind 的明星论文，变成 Google Cloud 面向制药、化工、能源、国家实验室和工业优化客户的垂直产品线。

这条线的投资链条要分清短期和长期。短期，最确定的还是云端科学计算、专有数据接入、实验自动化、生命科学数据库、科研工作台和企业 R&D 软件。中期，要看 BASF、Klarna、Daiichi Sankyo、Bayer、美国国家实验室这类客户是否给出真实 ROI。长期，如果 AI 能持续压缩假设生成和早期验证周期，制药、材料、能源、电网和工业设计的研发效率会被重估。但不要把“AI 提出候选机制”直接等同于“药物商业化成功”，这是今天最需要避免的叙事陷阱。

第五条主线是 Gemini Omni 和 SynthID/C2PA。Gemini Omni Flash 主打从文本、图像、音频、视频等输入生成和编辑视频，强调物理直觉、场景连续性、角色一致性和多轮编辑。它会进入 Gemini App、Google Flow 和 YouTube Shorts。与此同时，Google 扩大 SynthID 和 C2PA Content Credentials：SynthID 已经用于超过 1000 亿张图像和视频，以及 6 万年音频水印；验证能力扩展到 Gemini、Search 和 Chrome；Google Cloud 还推出 AI Content Detection API。

这组消息应该放在一起看。视频生成越强，内容生产成本越低，广告素材、短视频、电商展示、游戏预演、影视预制和品牌营销都会更自动化。但同一件事也会放大 deepfake、版权、诈骗和品牌安全风险。所以生成媒体的下一阶段，不会只有“谁生成得更像”，还会有“谁能证明来源、谁能检测、谁能被平台和监管接受”。

这就是 SynthID 和 C2PA 的商业价值。水印不是万能的，可能被转码、压缩、截屏、再生成破坏；检测也会有误报和漏报。但如果平台、手机、相机、云 API、广告客户和监管逐步接受内容凭证，内容溯源就会变成基础设施。Google 提到 OpenAI、Kakao、ElevenLabs 会把 SynthID 技术用于更多 AI 生成内容，NVIDIA Cosmos world foundation models 也与 SynthID 水印合作。这个生态如果做起来，AI 内容检测、品牌安全、广告素材管理、媒体合规和反欺诈都会出现新支出。

第六条是 NVIDIA 和 Google Cloud。今天这条新闻的分数不如 Google I/O 主线高，但它能帮助我们校准算力判断。NVIDIA 宣布与 Google Cloud 的联合开发者社区超过 10 万人，并新增 JAX on NVIDIA GPUs、Dynamo inference optimization、开发者直播和 Blackwell VM 相关路径。这不是一个大订单新闻，但它说明一件事：即使 Google 强推 TPU 和 Gemini，Google Cloud 仍然需要 NVIDIA GPU、JAX 优化、Dynamo 推理、GKE、Cloud Run 和 Blackwell 生态来服务更广泛的开发者。

未来 AI 云不会是单一硬件宗教。大客户会在 TPU、NVIDIA GPU、自研 ASIC、CPU、on-prem、neocloud 和区域云之间组合。Google 有理由推 TPU，因为它能降低成本、掌握供应链、服务自家模型；NVIDIA 也有理由继续绑定 Google Cloud，因为开发者工具、推理优化、容器、Kubernetes 和模型生态可以帮助它守住入口。对投资者来说，这不是“TPU 会不会马上替代 GPU”的简单题，而是要看不同工作负载如何分层：训练、批量推理、低延迟推理、agent 长任务、科学计算、视频生成，各自可能选择不同硬件组合。

把今天几条新闻合在一起看，结论其实很清楚。AI 产业链的重心正在从单点模型能力，转向长期运行的 agent 工作负载。agent 一旦进入搜索、代码、科研、视频、办公和本地服务，底层需求就会从一次性聊天变成全天候推理，从模型 API 变成运行时、权限、审计、sandbox、数据访问、内容溯源和云端基础设施。这个变化会继续拉动算力，但算力之外的价值链会变得更厚。

今天低分和重复消息可以快速过一遍。NVIDIA Vera CPU 首批交付 Anthropic、OpenAI、SpaceXAI、OCI，昨天已经讲过，今天没有实质新增。Dell、NVIDIA、OpenAI 的本地 AI Factory 和 Codex 接入企业数据层，昨天也已经深挖过，今天不再重复。Anthropic 收购 Stainless、Cursor Composer 2.5、IBM 和 Hugging Face 的 Open Agent Leaderboard、CrossMPI 多模态 prompt injection，这些主题都仍然重要，但今天没有新的关键事实，只把它们作为 coding agent 和 agent safety 背景。

接下来最需要跟踪五个问题。第一，Gemini Spark 和 Search information agents 夏天推出后，用户是否真的会把长期任务交给 Google。第二，Gemini 3.5 Flash 的第三方基准、API 价格和真实代码库表现能否支撑今天的高预期。第三，Antigravity Managed Agents 的企业安全细节能否经受私有代码、凭证和审计的考验。第四，Gemini for Science 的外部案例能不能继续复现，并转化成企业付费。第五，Google Cloud 里 TPU 与 NVIDIA GPU 的相对角色如何变化。

如果只用一句话总结今天：Google 正在把 Gemini 从模型产品升级成 agent 操作层，而这会把 AI 产业链的关注点，从“谁的模型更聪明”，进一步推向“谁能安全、低成本、长时间地替用户完成真实任务”。这也是今天最重要的产业信号。
