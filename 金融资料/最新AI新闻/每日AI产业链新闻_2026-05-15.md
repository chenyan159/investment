## 20 分钟口播稿

今天这期 AI 产业链新闻，表面看是几家公司发布产品、几家上市公司更新订单、几篇研究博客上线。但把它们连起来看，真正的主题只有一个：AI 正从“模型竞赛”变成“可部署智能的国家级基础设施竞赛”。这场竞赛的单位不再是参数量，也不只是 GPU 数量，而是数据中心、网络、光互联、电力、权限系统、agent 工作流、地缘出口管制，以及谁能把模型能力可靠地嵌进真实生产环境。

先讲今天最重要、也最值得反复琢磨的一条：Anthropic 发布了一篇关于 2028 年全球 AI 领导权的情景文章。它不是普通安全文章，更像一份把前沿模型、芯片出口、海外数据中心、模型蒸馏、AI 安全、国家竞争和全球采用率写在一起的战略备忘录。文章设计了两个情景。第一个情景是民主国家阵营守住优势，美国前沿模型到 2028 年领先中国 12 到 24 个月，优势还在扩大；美国实验室发布新一代模型之后，中国要到 2029 或 2030 年才接近同等能力。Anthropic 用了一个非常有冲击力的说法：关键行业里会出现“a country of geniuses in a data center”，也就是一个装在数据中心里的天才之国。这个表述比“超级计算集群”更有想象力。它暗示未来一个数据中心不只是运行软件，而是在经济、网络安全、生命科学、金融、公共治理里提供类似大规模专家人口的能力。

第二个情景更值得警惕：如果芯片走私、海外数据中心访问、模型蒸馏、半导体设备限制漏洞和美国模型访问没有被有效管理，中国实验室可能只落后美国几个月。这里的关键不是“中国有没有先进 GPU”这么简单，而是 Anthropic 把算力来源拆成了四条线：第一，实体芯片进口和走私；第二，境外数据中心远程访问；第三，通过前沿模型 API 和输出进行 distillation；第四，半导体制造设备限制是否真的能压住自给能力。这个框架比过去的芯片出口管制讨论更完整，因为它承认只卡芯片不够，模型访问、云端算力租用和训练数据式的能力抽取都会成为替代路径。

这篇文章还提出三类政策动作：堵住走私芯片、海外数据中心访问和半导体设备漏洞；限制模型访问并惩罚 distillation attacks；推动美国 AI 硬件和模型在全球采用。换句话说，前沿实验室现在不只是要求更多算力，也在要求国家帮它们定义算力边界、模型边界和全球市场边界。这是非常大的叙事变化。以前我们说“AI 是软件”，现在 Anthropic 的叙事是：AI 是战略基础设施，模型访问本身就是出口管制对象，海外数据中心本身也是战略边界。

这个叙事和当天的另一条新闻直接接上了。Reuters 报道，美国和中国代表团在北京峰会讨论 AI guardrails，重点是建立一个 best-practice protocol，防止非国家行为体利用最强 AI 模型。美国财长 Bessent 对 CNBC 说，美国保持 AI 领先“of utmost importance”，并且说美国要在创新和安全之间找到最高性能的 calculus。他还提到 Anthropic 的 Mythos 模型已经暴露重大软件安全漏洞，银行和公司正在紧急修补；同时他认为 Google 和 OpenAI 的模型也会出现类似 step-function gains。

这条新闻的独特之处不在“双方要谈 AI 安全”，而在谈判对象发生了变化。过去中美谈 AI，常见词是伦理、军事误用、自动化武器、芯片出口、数据安全。现在谈的是最强模型能力本身，以及非国家行为体使用这些能力的阈值。这里的潜台词是：模型能力强到一定程度以后，它既可以帮助银行、软件公司和政府提前修漏洞，也可能帮助攻击者找到更多漏洞。AI 安全不再只是实验室 benchmark，而是金融系统、云基础设施、企业网络和国家安全的 operational patch cycle。

紧接着是 Nvidia H200 中国许可。TNW 援引 Reuters 报道，美国已经批准大约 10 家中国公司购买 Nvidia H200，包括 Alibaba、Tencent、ByteDance、JD.com 以及 Lenovo、Foxconn 等渠道角色，但到报道时没有一颗芯片实际交付。更关键的是，每家许可上限据说可达 75,000 颗，如果 10 家全部用满，理论上是 750,000 颗 H200。这个数字非常大，但不能简单等同为收入，因为中国侧仍然要求科技公司暂停 H200 订单，等待供应链安全审查，并继续推动国产替代。

H200 的位置很微妙。它不是 Blackwell B200，也不是 H100；它低于 H100 和 Blackwell，但显著高于为中国设计的 H20。对中国云厂来说，它仍然是可用的高端 AI accelerator；对 Nvidia 来说，它是恢复部分中国市场的政策期权。报道还提到，中国占 Nvidia 收入已经从出口管制前超过 20% 降到大约 5%，而 H20 限制曾带来库存和收入冲击。所以今天 H200 的本质是“许可和需求都在，但交付链条被政治和产业政策卡住”。这不是传统半导体周期里的客户砍单，而是 policy-mediated backlog。

这个点非常重要。AI 芯片产业链现在的风险已经从“客户有没有需求”转向“订单能不能被许可证、外交、当地监管和机房政策同时放行”。如果美国批准，中国不一定让买；如果中国客户想买，美国不一定让卖；即使两边都同意，供应链排产、HBM、先进封装、光模块和电力上电还要排队。因此 H200 这个案例告诉我们，未来 AI 硬件的收入确认，要同时看技术路线、供应链和政策路线。

再看 Cisco。Cisco 这次财报是今天最硬的产业链验证之一。公司 Q3 FY26 收入 158 亿美元，同比增长 12%；total product orders 同比增长 35%；networking product orders 超过 50%；data center switching orders 超过 40%。最关键的是 hyperscaler AI infrastructure orders：年初至今已经 53 亿美元，公司把 FY26 订单预期从 50 亿美元直接上调到 90 亿美元，同时把 FY26 AI infrastructure revenue 预期从 30 亿美元上调到 40 亿美元。

这意味着什么？意味着 AI 交易正在从“只买 GPU”扩散到“买 AI factory 的全栈网络”。过去市场容易把 Cisco 看成老网络设备公司，认为 AI 主要利好 Nvidia、AMD、Broadcom、Arista 和光模块公司。但现在订单告诉我们，大型训练和推理集群需要 800G、1.6T、Silicon One、Acacia optics、scale-out fabric、scale-across、telemetry、congestion control、security 和 observability。芯片越多，网络越不是线性附属，而是指数式复杂度管理问题。一个大型 AI cluster 不是把 GPU 堆起来就能跑，它要解决节点间同步、尾延迟、丢包、拥塞、故障定位、任务调度和利用率问题。

Cisco 还披露，Acacia optics 在 Q3 的订单超过 10 亿美元，FY26 有望同比增长 200% 以上；Q3 有 5 个新的 hyperscaler design wins，其中包括两个 optics、三个 systems，系统里有 Silicon One P200 做 scale-across，也有 Silicon One G200 做 scale-out。这个信息很关键，因为它把 AI 网络拆成了三层：第一是传统交换系统，第二是光学和高速互联，第三是把网络状态和 AI job 状态关联起来的软件控制面。未来不是“谁有交换机谁赢”，而是谁能把交换机、光模块、NIC、DPU、telemetry 和 AI workload scheduler 做成一个可运营系统。

这也解释了为什么 AI 数据中心的瓶颈越来越不像单一 GPU 短缺。当前新增容量被 HBM、CoWoS、ABF、液冷、电力、变压器、800G/1.6T 光模块、224G SerDes、客户认证和 burn-in 同时卡住。Cisco 的订单上调，说明 hyperscaler 正在提前锁网络和光学供应。换句话说，即使某些 GPU 晚交，网络、光学、变压器和机电设备仍然可能提前下单，因为这些东西一旦没锁住，数据中心上电之后也跑不起来。

同一天还有一个资本市场信号：Blackstone Digital Infrastructure Trust 募资 17.5 亿美元上市，目标是购买已经建成、已经出租、受益于 AI boom 的数据中心资产。这个新闻不像芯片那么性感，但它代表另一个方向：AI 基础设施正在把金融资产类别重新定价。以前数据中心 REIT 的核心变量是云租户、互联、空置率、资本成本。现在新增变量是 AI 用电、功率密度、液冷能力、并网周期、机电升级和能否承接高密度 GPU rack。资本开始追逐“已经建成并出租”的数据中心，因为新建项目受电力和许可约束太强。算力竞赛不只是芯片竞赛，也是可用机房和电力容量的竞赛。

接下来讲 Google DeepMind 的 AI pointer。乍一听，给鼠标指针加 AI 很容易被当成产品噱头，但这条新闻的创新性在交互范式。DeepMind 的 Adrien Baranes 和 Rob Marchant 说，他们要让指针理解用户指向的是什么，以及为什么重要。传统 AI 工具住在自己的窗口里，用户必须把网页、PDF、图片、表格和代码复制进去；DeepMind 的方向是反过来，让 AI 跟着用户当前所在的界面走。你指着网页上的两个产品说“compare these”，指着 PDF 一段话说“turn this into bullet points”，指着一张餐厅照片说“show me directions”，模型通过指针位置、屏幕上下文和自然语言短句来理解“this”和“that”。

这个变化的意义很大。过去我们讨论 prompt engineering，好像用户必须学会写长提示词。AI pointer 的方向是把 prompt 变短，把上下文捕捉交给系统。人类之间说话本来就不是长 prompt，而是“把这个放到那里”“这个是什么意思”“帮我改一下这里”。未来的 agent UI 很可能不是一个聊天框，而是一个持续理解屏幕语义的操作层。它知道你指的是哪个段落、哪个表格、哪段代码、哪张图片、哪个日期、哪个地点，然后把像素变成可操作实体。

这也带来新的瓶颈。第一是隐私：如果指针背后有模型在看屏幕，哪些内容可以被看，哪些内容不能被看？第二是权限：AI 能不能只读，能不能点击，能不能下单，能不能写入企业系统？第三是错误恢复：如果用户说“move that here”，模型理解错了“that”，如何回滚？第四是企业治理：在受监管行业，屏幕语义层是不是也要审计？所以 AI pointer 不是鼠标新闻，它是 agent 从聊天窗口走向操作系统和浏览器层的早期信号。

OpenAI 今天也在做类似方向，但它的切入点是 developer agent。OpenAI 发布了 Codex mobile preview：Codex 进入 ChatGPT 手机 app，用户可以在手机上跟进远程机器、笔记本、devbox 或 managed remote environment 里正在运行的 Codex 线程。OpenAI 披露 Codex 每周使用者已经超过 400 万。这里最重要的不是“手机上能写代码”，而是长运行 agent 的协作节奏。一个 coding agent 跑半小时、两小时甚至更久，中间需要人类回答问题、审 diff、批准命令、改变方向、补上下文。手机端让人类可以在通勤、会议间隙、外出时给 agent 一个小决策，让工作不中断。

OpenAI 同时提到 secure relay layer：本地文件、凭据、权限和开发环境留在原机器，状态、截图、terminal output、diff、测试结果和 approval 通过 relay 同步到授权设备。Remote SSH 已经 GA，Hooks 也 GA，企业和商业版还有 programmatic access tokens，HIPAA 合规本地 Codex 用例也开始支持。把这些连起来看，OpenAI 正在把 Codex 从“云端模型调用”变成“跨设备、跨环境、带权限和自动化 hooks 的工程操作系统”。

这就接到 OpenAI 前一天发布的 Windows sandbox 技术文章。David Wiesen 解释，Codex 在 Windows 上需要一个真正能限制写文件和联网的 sandbox。AppContainer 太窄，适合预先知道权限边界的 app，不适合 coding agent 驱动 shell、Git、Python、包管理器和任意构建工具；Windows Sandbox 是轻量 VM，安全但不适合直接操作用户真实 checkout；Mandatory Integrity Control 看起来优雅，但会改变真实 workspace 的完整性标签，让低完整性进程普遍可写，风险太大。所以他们走向 synthetic SID 和 write-restricted token，让 Windows 在写操作时同时检查用户权限和 sandbox-write SID，从而只允许 workspace 等指定目录可写。

这篇文章的深层意义是：agent 安全不是一句“模型会小心”的承诺，而是 OS 级权限工程。未来企业部署 coding agent、office agent、browser agent，都会遇到同一个问题：模型有能力，但 harness 要能保证它不能越权。没有 sandbox、relay、approval、audit、secret scanning、hooks、MCP 权限边界，agent 越强，风险越大。

再看 Anthropic 和 PwC。PwC 与 Anthropic 扩大 alliance，目标之一是处理企业运营中超过 2 万亿美元的 technical debt。PwC 将在全球数十万员工中推广 Claude，先从美国团队开始，建立 joint Center of Excellence，并训练和认证 30,000 名 PwC 美国专业人员。Claude Code、Claude Cowork 会进入 spreadsheet、word processing、presentation 等工具，并通过 MCP 连接企业数据。PwC 还提到，Claude 已经在 ChatPwC 内部 AI assistant 中可用，并且在 Finance、Supply Chain、Deal Making 三个 AI incubation pods 中用于生产级客户 engagement。

这条新闻的核心不是咨询公司又用了一个模型，而是 agentic operating model 开始进入专业服务公司内部的交付流程。咨询、审计、交易、供应链、税务、法务这些领域有大量结构化流程，也有大量非结构化文档和客户上下文。AI 如果只能回答问题，价值有限；如果能读企业数据、写代码、更新表格、生成材料、验证假设、辅助 deal workflow，就可能改变专业服务的生产函数。但这里的瓶颈也非常现实：人要培训，流程要重写，权限要治理，客户数据要隔离，输出要审计。30,000 人认证这个数字说明，企业 AI 的扩散不是“开通账号”这么简单，而是组织能力建设。

Anthropic 今天还有一条更微观但很有启发的新闻：据 Techstrong 报道，Anthropic 恢复第三方 autonomous agent 访问，但引入 Agent SDK credit tier，实质上结束把 programmatic usage 混在普通 Claude Pro 或 Max 订阅里的 flat-rate 模式。报道举例说，Pro plan 给 20 美元 Agent SDK credits，Max 5X 给 100 美元 credits，用完以后自动化任务就不能继续，除非开启额外付费。原因是第三方工具经常没有优化 prompt cache，导致用户每月支付 20 到 200 美元，却消耗数千美元 token 价值。

这条新闻非常关键，因为它揭示了 agent 经济学和 chatbot 经济学的不同。聊天用户会停，会累，会换话题；agent 不会。一个 coding agent、browser agent、data agent 可以连续跑、反复试错、调用工具、生成大量上下文、触发长链路推理。只要 flat-rate 订阅允许 programmatic automation，就会出现 compute arbitrage。即使有 300MW 数据中心、有 220,000 颗 GPU，也不等于可以无限补贴自动化 agent。未来模型公司会越来越把交互式聊天、IDE 内助手、CLI agent、第三方自动化、CI/CD、批处理任务分开定价。最重要的指标也会从 monthly active users 转向 dollar per automated task、cache hit rate、tool-call cost、rollback cost 和成功率。

接下来讲 Recursive Superintelligence。上一轮新闻里已经说过融资和创始团队，所以今天只讲 TechCrunch 访谈里的技术增量。Richard Socher 说，Recursive 的独特路径是用 open-endedness 走向 recursive self-improvement。他特别区分了“让 AI 改进某个东西”和真正的 recursive self-improvement。前者只是 improvement；后者是整个 research loop，包含 ideation、implementation、validation 都自动化，而且最初是 AI research ideas，未来扩展到其他研究，甚至物理世界研究。更有意思的是，他说 AI working on itself 会发展出一种理解自身短板的能力。

访谈里还提到 Tim Rocktäschel 在 DeepMind 做过 open-endedness 和 self-improvement 团队，并参与 Genie 3 这类 world model。Socher 举了 rainbow teaming 的例子：不是让人类一次次找模型坏行为，而是让一个 AI 攻击另一个 AI，双方可以进行数百万轮 co-evolution，攻击者不断找新角度，防守者不断免疫。这是一个很强的叙事：未来安全不是静态红队，而是模型之间的演化生态。

Socher 还说首个产品可能是 quarters, not years。这句话比融资金额更值得注意，因为它暗示 recursive self-improvement 这类研究型公司不会长期只做实验室，而会很快找产品闭环。最后他谈到 compute：未来重要问题可能是人类愿意把多少算力分配给哪些问题。比如是先解决这个癌症，还是那个病毒？这句话把算力从企业资产变成社会资源。它和 Anthropic 的“data center 里的天才之国”其实是一组叙事：当 AI research loop 自动化以后，谁控制算力，谁就控制探索速度；谁分配算力，谁就在分配科学进步和经济权力。

最后补一条过去 72 小时仍然重要的研究信号：OpenAI Parameter Golf。这个挑战有 1,000 多名参与者、2,000 多个 submissions，规则是固定 FineWeb 数据集、16MB artifact limit、10 分钟训练预算、8 张 H100。参赛者在极小模型和极紧预算下做 held-out loss 最小化。表面上这是一个小模型竞赛，但真正值得关注的是它展示了 AI agents 参与机器学习研究后的新生态。

OpenAI 提到，许多参赛者使用 AI coding agents。agents 降低了试验成本，让更多人能快速 fork repo、理解代码、测试想法，也让强思路更快扩散。技术上，submission 里出现了 GPTQ-lite、full Hessian GPTQ、自生成校准数据、per-document LoRA test-time training、CaseOps tokenizer、Exclusive Self Attention、SmearGate、BigramHash、mini depth recurrence 等路线。最有意思的是，agent 带来的不是单纯更快 coding，而是研究竞赛的变异速度上升。一个有效技巧会被别人和 agent 迅速吸收、组合、微调；一个不合规技巧也会被 agent 复制并制造大量无效 submission。OpenAI 因此开发了内部 Codex-based triage bot，帮助筛查 submissions。

这件事对前沿 AI 研究很有启发。我们总说 AI 会自动化 AI 研究，但更现实的中间形态可能是：人类研究者提出方向，agent 快速生成实验变体，社区用 leaderboard 进行选择，另一个 agent 负责审查规则和复现。研究的瓶颈从“写代码慢”变成“问题定义、评估设计、归因、合规审查、资源分配”。这和 Recursive Superintelligence 的叙事刚好相连：recursive self-improvement 不会凭空出现，它可能先以“agent 加速开放研究生态”的形式出现。

把今天所有新闻放在一起，结论有五个。

第一，前沿模型公司正在把自己定位成国家基础设施公司。Anthropic 的 2028 情景、Bessent 的中美 guardrails、Mythos 触发银行修补，说明模型能力已经进入外交、安全和金融稳定议题。

第二，AI 硬件的核心风险从“有没有需求”转向“订单能否转为可交付算力”。Nvidia H200 中国许可证明，批准、采购、交付、当地政策、出口限制、供应链排产和数据中心上电是不同关卡。

第三，网络和光互联正在成为 GPU 之后最重要的 AI 基建弹性。Cisco 90 亿美元 FY26 AI order outlook、Acacia 超 10 亿美元 Q3 orders、Silicon One design wins，都说明大型 AI factory 的下一个瓶颈不是单卡，而是 fabric。

第四，agent 的商业化会打破传统 SaaS 定价。Anthropic Agent SDK credits、OpenAI Codex mobile、PwC 训练 30,000 人，都说明 agent 不是一个聊天席位，而是一条能持续消耗 compute、执行任务、触碰权限和改变工作流的自动化生产线。

第五，最前沿、最超出想象的叙事，是“数据中心里的智能人口”。如果一个数据中心能承载成千上万等效研究者、工程师、网络安全专家和行业分析师，那么它就不只是资产负债表上的服务器园区，而是一个可以被国家、公司和社会分配的认知资源。未来几年最核心的问题会变成：谁拥有这些智能人口，谁给它们供电，谁给它们网络，谁给它们数据，谁限制它们跨境流动，谁决定它们先解决哪个问题。

今天的投资和产业观察重点也就很清楚：继续看 GPU，但不能只看 GPU；继续看模型，但不能只看模型。要盯住 HBM、先进封装、AI Ethernet、Acacia 这类光学资产、1.6T、数据中心电力、agent 权限系统、enterprise workflow integration，以及模型访问和出口管制如何重新定义全球 AI 产能。AI 的下一阶段不是更大的 demo，而是把智能变成可审计、可定价、可交付、可治理的基础设施。
