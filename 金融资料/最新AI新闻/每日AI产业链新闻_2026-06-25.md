## 1. OpenAI / Broadcom Jalapeno：推理 ASIC 进入 OpenAI 自有全栈

### 新闻事实

OpenAI 与 Broadcom 在 2026-06-24 发布 Jalapeno，OpenAI 称其为第一颗 Intelligence Processor，定位为面向 LLM inference 的定制加速器，也是双方多代计算平台的第一颗 AI accelerator。核心事实如下：

- OpenAI 官方称 Jalapeno 从设计到 manufacturing tape-out 用了 9 个月，并使用 OpenAI 模型加速了部分设计和优化工作。
- 工程样片已在实验室以目标频率和功耗运行 ML workloads，包括 GPT-5.3-Codex-Spark。
- OpenAI 还在测量最终性能，但称早期测试显示 performance per watt 显著优于当前 state-of-the-art。
- 芯片围绕 OpenAI 自身的模型路线图、kernels、serving systems、product needs、memory movement、networking 和 scheduling 进行设计。
- Broadcom 提供 silicon implementation、Tomahawk networking silicon 等网络与连接技术。
- Celestica 参与 board、rack system integration 和 scalable production systems。
- Broadcom CEO Hock Tan 表示，这一多代路线将支持 2026 年开始与 Microsoft 和其他伙伴部署 gigawatt-scale data centers。
- 2025-10 的旧背景是 OpenAI 与 Broadcom 宣布 10GW 定制 AI accelerators 合作，racks 使用 Broadcom Ethernet 和 connectivity solutions，部署目标从 2026H2 开始、到 2029 年底完成。

### 新增 delta 和去重说明

近期底稿已经多次覆盖云厂自研 ASIC、Broadcom custom XPU、Google TPU、AWS Trainium、Microsoft Maia、Meta MTIA，以及昨天 Qualcomm-ByteDance 设计服务。今天的新增 delta 更硬：OpenAI 的自研芯片从合作框架进入具体芯片名、样片、性能方向、机架伙伴、网络 silicon 和部署时间表。它把模型公司从“算力买方”推进到“芯片架构定义方”。

这条新闻也和 OpenAI 当天发布的 agent 工作研究形成闭环。Codex 的长任务和内部使用强度说明推理请求会更长、更频繁、更依赖工具调用与环境交互。Jalapeno 的目标自然落在 inference cost、latency、memory movement 和 serving patterns 上。

### 历史背景和前因后果

AI 加速器市场过去两年最强的商业闭环是 NVIDIA：GPU、HBM、NVLink、NVSwitch、CUDA、网络、整机柜、软件服务共同构成高毛利平台。云厂和模型公司一直在寻找第二条路径：

1. Google TPU 通过内部 workload 和 Google Cloud 客户消化。
2. AWS Trainium/Inferentia 通过 Anthropic、Bedrock 和 AWS 内部需求消化。
3. Microsoft Maia 通过 Azure、Copilot 和 OpenAI 相关推理需求消化。
4. Meta MTIA 通过推荐、广告和 Llama/GenAI 内部服务消化。
5. Broadcom/Marvell custom silicon 作为 hyperscaler ASIC 的外部设计和实现抓手。

OpenAI 的特殊性在于，它原先是全球最强的模型与产品需求方之一，却主要依赖外部云和外部 GPU。Jalapeno 让 OpenAI 可以把模型设计、推理 kernel、serving 调度、硬件内存层级、网络拓扑和产品体验放进同一优化目标。OpenAI 官方把它称为 full-stack platform 的扩展，含义很清楚：模型能力竞争已经进入 token economics 竞争。

### 产业链影响

**Broadcom custom silicon 权重上调。** Broadcom 在 Google TPU 生态、Tomahawk/Jericho、SerDes、Ethernet、光/电互联和 custom ASIC 上已有强地位。Jalapeno 把 OpenAI 加入高可见度客户清单。对 Broadcom 来说，价值来自芯片实现、网络 silicon、scale-up/scale-out Ethernet、Tomahawk 交换、PCIe/SerDes/光互联 attach 的组合。

**Celestica 与机架集成被放到芯片公告内。** OpenAI 官方把 board、rack system integration 和 scalable production systems 写进芯片新闻，说明定制 ASIC 已经按数据中心平台交付，而非按裸芯片交付。Celestica、Jabil、Foxconn、Quanta/QCT、Wiwynn、Flex、Sanmina 这类 EMS/ODM 的 AI 价值映射继续扩张，但要区分高毛利设计集成与低毛利代工制造。

**推理 ASIC 对 HBM 和近存计算的要求会分化。** Jalapeno 官方没有公布 HBM、LPDDR、SRAM 或封装规格。重点在 memory movement 和 networking。未来需要观察它使用 HBM、LPDDR、custom near-memory、CXL 或其他层级。若 OpenAI 的 workload 更偏 Codex/ChatGPT/API interactive inference，内存容量、KV cache、prefill/decode 分工和网络调度会直接影响芯片架构。

**NVIDIA 的风险从单位份额转向利润池份额。** OpenAI 仍会大量使用 NVIDIA 和其他 GPU。Jalapeno 更可能先吸收可预测、高流量、成本敏感的推理任务。若这类流量从 GPU 转到 ASIC，NVIDIA 的训练和最前沿通用计算需求仍强，但推理单位 token 毛利池会被重新分配。

**Ethernet scale-up 的胜率上升。** OpenAI/Broadcom 旧合作明确提到 accelerators 和 Ethernet solutions for scale-up and scale-out。若 Jalapeno 真正进入 GW 级部署，Broadcom 的 Ethernet、Tomahawk、光互联、DSP、AEC/DAC、1.6T/3.2T 路线会获得更强客户背书。

### 投资含义

- 权重上调：Broadcom custom ASIC、Tomahawk/Ethernet switching、SerDes/IP、Celestica/EMS AI rack、先进封装、HBM/高端内存、AI inference serving software、network telemetry、AI cluster scheduling。
- 间接受益：TSMC N3/N2 先进逻辑、CoWoS/SoIC、ABF/基板、ATE/探针卡、burn-in、液冷与机架电力。
- 需要谨慎：Jalapeno 还没有详细 benchmark、die size、memory stack、封装、良率、成本、功耗、单机架配置和客户使用量。官方表述属于早期性能和路线图，不能直接换成 2026 年供应商收入。
- 交易重点：Broadcom 的 AI semiconductor revenue、Celestica AI backlog、OpenAI/Microsoft 数据中心部署节点、OpenAI 后续技术报告、是否出现 OpenAI 公开的成本/token 或 latency 改善。

### 继续验证

1. Jalapeno 的 memory hierarchy：HBM、LPDDR、SRAM、CXL、near-memory 的组合。
2. 首批数据中心地点、IT load、机架数量、是否进入 Microsoft Azure 或 OpenAI 自营/合营站点。
3. Tomahawk 网络在 scale-up 与 scale-out 中的具体角色。
4. OpenAI 是否把 Codex、ChatGPT、API、agents 分流到不同芯片平台。
5. Broadcom 是否在下一次财报给出 OpenAI 相关 AI semiconductor backlog 或 FY2027 revenue contribution。

## 2. Qualcomm / Meta / Modular：手机芯片公司公开切入数据中心 CPU 与 AI 软件栈

### 新闻事实

Qualcomm 在 2026-06-24 投资者日密集发布数据中心战略：

- Qualcomm 将 FY2029 非手机收入目标提升到 400 亿美元，约为此前目标的 2 倍。
- FY2029 数据中心收入目标为 150 亿美元以上。
- Meta 与 Qualcomm 宣布多年、多代数据中心 CPU 协议。Qualcomm Dragonfly C1000 CPU 计划用于 Meta 下一代 server fleet，生产从 2028H2 开始。
- Dragonfly C1000 是面向 agentic、general-purpose 和 AI head node workloads 的 CPU 产品族，商业可用性预计 2028 年。
- Qualcomm data center roadmap 包括 Dragonfly C1000 CPU、High Bandwidth Compute（HBC）、Dragonfly AI300 inference accelerator、connectivity products 和 custom silicon。
- C1000 采用 250+ core chiplet design，Oryon CPU cores，频率超过 5GHz，面向 agentic orchestration、general-purpose 和 XPU head node。
- HBC 是 3D-stacked near-memory computing 架构。Qualcomm 称 AI250 的 HBC Gen1 目标 133TB/s per card，有效内存带宽较 AI200 LPDDR5X 增加 18 倍；AI300 的 HBC Gen2 目标较 AI200 增加 54 倍；HBC 的 bandwidth per watt 设计目标较 HBM 高 6 倍。
- AI300 是第三代 AI inference 平台，支持 air 和 direct-liquid-cooled rack，scale-up 使用 UALink 和 ESUN，scale-out 使用 copper 和 optical，商业采样预计 2028。
- Qualcomm 宣布收购 Modular，强化从边缘到数据中心的 AI-native software foundation。Modular 的平台目标是让模型跨 CPU/GPU/NPU/custom ASIC 高效运行，减少为不同 accelerator 重写代码。

### 新增 delta 和去重说明

昨天底稿写过 Qualcomm-ByteDance 定制芯片设计服务，属于“设计服务进入 AI ASIC 供应链”的信号。今天的新增 delta 更宽：Qualcomm 把数据中心 CPU、near-memory compute、AI inference accelerator、connectivity、custom silicon、软件栈、Meta 客户和 2029 收入目标一次性公开。这是 Qualcomm 重新定义公司收入结构的事件。

### 历史背景和前因后果

Qualcomm 的手机主业面临 Apple 自研基带、安卓周期、手机 ASP 和授权模式的长期压力。公司过去几年一直把汽车、PC、XR、IoT、工业、机器人和边缘 AI 作为新曲线。数据中心曾经是 Qualcomm 多次尝试但未稳定兑现的市场。今天的差异在于三个条件同时出现：

1. AI agent 让 CPU 控制面价值上升。项目内行业调研已经多次强调，agent workload 会跑矩阵计算，也会执行代码、调用工具、读写文件、维护上下文、调度环境。CPU、内存带宽、I/O 和 orchestration latency 会成为 AI rack 的瓶颈。
2. 推理成本让 power efficiency 重新定价。Qualcomm 长期擅长低功耗 SoC、Oryon core、connectivity 和系统级集成，正好适配 tokens-per-watt 叙事。
3. 软件栈成为进入数据中心的门票。没有 CUDA/ROCm/Neuron/TPU stack 级别的软件，硬件效率无法变成客户 adoption。Modular 的价值在于给 Qualcomm 补一层 developer-facing、vendor-neutral 的运行时和编译/部署基础。

### 产业链影响

**AI server CPU 赛道变得拥挤。** NVIDIA Vera CPU、Arm Neoverse/定制 CPU、AMD EPYC、Intel Xeon、AWS Graviton、Google Axion、Microsoft Cobalt、Qualcomm Dragonfly 都在争夺 agentic control plane 和 AI head node。CPU 再次成为 AI 基建投资点，但指标会从通用 server benchmark 转向 tokens-per-watt、工具调用吞吐、低延迟 I/O、PCIe/CXL、内存带宽和 XPU utilization。

**Meta 的长期导入有战略含义。** Meta 已经在 MTIA、PyTorch/Triton、OCP、AI fabric 和大规模数据中心自建上持续投入。C1000 2028H2 才开始生产，短期收入贡献有限，但 Meta 作为第一大客户公开背书，说明 Qualcomm 至少拿到了进入 hyperscaler roadmap 的门票。

**HBC 是对 HBM 成本和功耗的一次挑战。** Qualcomm 把 HBC 定义成突破 memory wall 的 near-memory computing 架构，并强调 bandwidth per watt 和 capacity per watt。它短期不会取代高端 HBM 在训练和最大模型中的地位，但会给推理、decode、agent memory、KV/cache 和 disaggregated inference 提供新架构选项。

**Modular 让 Qualcomm 试图绕开 CUDA 锁定。** Modular 的开放软件层如果能跨 CPU、GPU、NPU、custom ASIC 运行模型，会让 Qualcomm 在云、边缘、PC、手机和机器人上形成统一开发者入口。难点是生态迁移、性能一致性、调试工具、模型库覆盖、企业认证和 hyperscaler 内部平台整合。

### 投资含义

- 权重上调：Qualcomm 数据中心长期期权、Meta AI 基础设施定制链、Arm/Oryon server CPU、chiplet、LPDDR/near-memory、CXL/PCIe、800G/1.6T connectivity、Modular/open AI compiler/runtime。
- 直接映射：QCOM 的估值将更依赖 FY2029 目标可信度、Meta C1000 验证节点、AI200/AI250/AI300 采样和客户名单、Modular 交易整合。
- 对 NVIDIA/AMD/Intel 的含义：NVIDIA 的训练平台优势仍强，AMD/Intel 的通用 CPU 份额会面对更多自研/定制 CPU 压力。Qualcomm 更可能先争 agentic orchestration 和低功耗推理侧，而非立即抢走训练 GPU 预算。
- 时间风险：C1000 生产节点在 2028H2，AI300 商业采样预计 2028。市场可能提前定价，但收入兑现需要两年以上。

### 继续验证

1. Qualcomm 是否披露 C1000 的制程、功耗、内存接口、PCIe/CXL、socket/rack 配置。
2. Meta 的导入范围：只做 head node CPU，还是进入大规模 server fleet。
3. AI200/AI250/AI300 的外部客户，尤其是否有云厂、AI lab、neocloud。
4. Modular 交易完成后，Mojo/MAX/Modular stack 是否成为 Qualcomm AI accelerator 默认软件层。
5. HBC 的真实封装良率、成本、供应商和对 HBM 的替代边界。

## 3. Micron FY2026Q3：AI 内存周期从主题交易变成合同和现金流

### 新闻事实

Micron 在 2026-06-24 公布 FY2026Q3 业绩：

- FY2026Q3 revenue 为 414.56 亿美元，上一季度 238.60 亿美元，去年同期 93.01 亿美元。
- GAAP gross margin 84.6%，non-GAAP gross margin 84.9%。
- GAAP net income 282.43 亿美元，non-GAAP net income 288.57 亿美元。
- Non-GAAP diluted EPS 为 25.11 美元。
- Operating cash flow 253.9 亿美元，adjusted free cash flow 183 亿美元。
- FY2026Q4 指引：revenue 500 亿美元上下 10 亿美元，gross margin 约 86%，non-GAAP EPS 31 美元上下 1 美元。
- Prepared remarks 披露，数据中心收入超过 250 亿美元，年化 run-rate 超过 1000 亿美元；data center SSD revenue 超过 50 亿美元，环比翻倍以上。
- DRAM 和 NAND 需求显著超过供给，公司预计 tight conditions 持续到 CY2027 之后。
- Micron 已签 16 个 strategic customer agreements（SCAs），典型期限为 2026-2030 年。部分协议带 fixed 或 floor/ceiling pricing，FQ3 末披露 RPO 超过 50 亿美元。
- HBM4 volume ramp 速度是 HBM3E 12-high 的两倍，Micron 已出货超过 10 亿美元 HBM4 revenue。
- FY2026 全年 capex 预计约 270 亿美元，FY2027 季度 capex 预计高于 FY2026Q4，其中超过一半增量来自 construction capex，用于拉动 cleanroom capacity。

### 新增 delta 和去重说明

2026-06-23 底稿已经写过 Micron 与 Anthropic 的战略协议，重点在 memory/storage architecture、Claude adoption、Series H investment。今天的新增 delta是财报级验证：收入、毛利、自由现金流、数据中心收入、HBM4 出货、SCA 数量和 FY2027 capex 规划一起出现。它把“AI 内存紧缺”从主题变成合同、价格、现金流和扩产节奏。

### 历史背景和前因后果

内存过去是典型周期行业：供给扩张、价格下跌、库存上升、利润回落反复出现。AI 改变了这轮周期的三个变量：

1. **HBM 提高单位 bit 价值。** HBM3E/HBM4 与先进封装、GPU/ASIC 平台强绑定，客户认证周期长，供应商切换成本高。
2. **AI 推理拉动 DRAM 和 NAND 层级。** Agent、long context、KV cache、RAG、checkpoint、向量库和数据预处理让 data center SSD、DDR5/RDIMM、SOCAMM、LPDDR、CXL memory 的价值上升。
3. **客户愿意签长期协议锁供应。** SCA 让 Micron 从现货价格周期切入更高可见度的长期供应模式。五年期协议如果有价格地板和客户返还机制，商业模式会更接近半导体长约供给，而非传统 DRAM 现货周期。

项目内行业调研原本已经把 HBM/高端内存列为 2026-2028 AI 产业链最高权重瓶颈之一。Micron 今天的财报给了强验证：它不仅是 HBM，data center SSD 和普通 DRAM/NAND 价格也在 AI 需求下受益。

### 产业链影响

**HBM4 成为 2027 主约束。** Micron 披露 HBM4 revenue 已超过 10 亿美元，且 ramp 速度快于 HBM3E 12-high。Rubin、MI400/MI450、下一代 TPU/Trainium/ASIC 将同时推高 HBM4 需求。后续需要比较 Micron、SK hynix、Samsung 的 HBM4/HBM4E 客户认证和份额。

**NAND 被重新定价。** Data center SSD revenue 超过 50 亿美元且环比翻倍以上，说明 AI 采购范围已经从 GPU/HBM 扩到更完整的存储层。KV cache offload、RAG、checkpoint、训练数据集、向量索引、日志和企业数据管线都会拉动高容量、高性能 SSD。企业级 SSD、NAND 控制器、QLC、PCIe Gen6、存储软件和数据管线基础设施权重上升。

**Capex 重心从设备延伸到 cleanroom 和能源。** FY2027 增量 capex 超过一半来自 construction capex，说明存储供给瓶颈不仅在机台，也在洁净室、厂务、电力、高纯水、气体、化学品、施工和关键工种。半导体厂务与洁净室链条在 AI 内存周期中获得新增订单映射。

**价格可能把非 AI 终端挤压得更明显。** Micron 披露 DRAM 价格低 60% 区间环比上涨、NAND 价格中 80% 区间环比上涨。高端 AI 抢占产能会推高 PC、手机、汽车、工业等终端 BOM。AI 需求太强时，传统终端反而成为价格传导的承压方。

### 投资含义

- 权重上调：Micron、SK hynix、Samsung 高端 HBM/DRAM/NAND，data center SSD，NAND 控制器，内存测试，HBM packaging，探针卡/ATE，先进封装材料，存储设备，半导体洁净室与厂务。

- 周期风险仍高：当前毛利率处于极强状态。若 2027-2028 扩产集中释放、客户 capex 放缓、HBM ASP 重定价，利润率会下行。SCA 可以缓冲，但不会消除周期。
- 需要把 HBM 与普通 DRAM/NAND 分开看：HBM 有更强客户认证和先进封装壁垒；普通内存价格涨幅若过快，会诱发终端需求破坏。

### 新增 delta 和去重说明

此前底稿已经写过 Meta/Crusoe 1.6GW capacity、Morgan Stanley AI data center leveraged loan、Oracle/OpenAI/Stargate、Google/Alphabet 融资等。今天的新增 delta 是跨公司、跨季度的总量和会计结构：AI 基建已经形成巨额 future lease obligations，租赁付款义务成为观察 AI capex 的核心数据。

### 历史背景和前因后果

过去市场主要盯云厂 capex 指引和 NVIDIA revenue。现在需要加入第三个表外/准表外口径：未来租赁承诺。它代表 hyperscaler 通过第三方开发商、REIT、私募资本、neocloud、基础设施基金和项目融资锁定容量，再以长期租赁方式消化。这个结构有三层意义：

1. **算力扩张速度依赖资本市场。** 自建数据中心需要公司 capex；第三方 lease 需要开发商、债务、私募信用和长期 offtake。
2. **供应商订单滞后于 lease。** Lease 先锁场地和容量，随后才转成机电、电力、服务器、芯片、网络和运维采购。
3. **AI ROI 会被长期付款义务放大。** 若 token revenue、enterprise adoption 或广告/应用增量慢于预期，lease obligations 会变成固定成本压力。

### 产业链影响

**电力和能源是 lease 背后的硬货。** 租约最终要靠 energization 才能转成收入。变压器、开关柜、PDU、母线槽、UPS、BESS、燃气发电、核电 PPA、输电线路、互联排队和 utility tariff 都会成为每个项目的尽调重点。

**未来 lease 属于长期需求信号。** 8500 亿美元不能机械换成 2026 年订单。项目可能分期、延期、取消或通过退出条款缩小规模。需要跟踪 active power、under construction MW、ready-to-serve、customer acceptance 和租金起算时间。

### 投资含义

- 权重上调：wholesale data center、AI-ready colocation、私募基础设施、长期租赁金融、MEP/EPC、变压器、开关柜、液冷、BESS、燃气和长期 PPA。
- 风险上调：表外/未来付款义务、租赁退出条款、项目融资利差、客户集中度、AI lab 或 cloud customer credit risk、租约起租延迟。
- 更好的指标：future lease commitments、RPO/backlog、active power、MW energized、preleased MW、debt spread、capex per MW、lease start date、utilization。

2. Microsoft 1966 亿美元 future commitments 与 Chevron West Texas、OpenAI/Azure、Crusoe/Abilene 等项目的关联。
3. Oracle future leases 下降是否意味着 Stargate 站点组合优化，还是项目付款节奏变化。

5. 会计披露是否开始被投资者要求更细分：AI lease、office/warehouse lease、可取消 lease 分开披露。

## 5. VPP 与 Ratepayer Protection Act：数据中心电力从“多建电源”走向“谁付款、谁可调度”

### 新闻事实

2026-06-24 有两条电网侧新闻值得合并观察。

第一条是 Sunrun、Renew Home 和 Tesla 宣布合作，汇聚超过 16GW 美国家庭侧能源资源，出售给 hyperscalers 和 utilities：

- 资源来自 Sunrun 和 Tesla 的家庭电池、Renew Home 管理的 800 多万个智能恒温器，以及车网互动设备。
- 合作方称无需新硬件、土地、水或新的 interconnection infrastructure，容量可在数月内部署。
- Virginia 有超过 300MW 可立即部署，到 2030 年至少 500MW。
- 合作方承诺参与 PJM proposed Reliability Backstop Process，若被接受，可立即释放超过 1GW，并在未来增加 peak shaving、locational grid relief 和 ancillary services。
- 这是继 Google 与 Voltus 100MW VPP 合作后，家庭侧灵活资源面向数据中心 offtakers 的更大规模案例。

第二条是美国众议院提出 Ratepayer Protection Act：

- 目标是要求 100MW 以上 large-load customers 为连接电网所需的 generation、transmission 和其他 infrastructure 自付全额成本，避免转嫁给普通 ratepayers。
- 法案要求 large-load customers 提供 financial assurances，以覆盖升级成本，即使后续减少运营或退出电网。
- 法案由 Kathy Castor 和 Gabe Evans 提出，并获得 Google 支持。
- 俄勒冈、俄克拉荷马、佛罗里达、俄亥俄、北卡、弗吉尼亚等州已经推进或通过类似 ratepayer protection 或 large-load rate class。

### 新增 delta 和去重说明

过去几天已写过 FERC/DOE 大负荷并网框架、ERCOT Batch Zero、州级成本分摊和电力排队。今天新增的是两端同时推进：一端用家庭电池/恒温器/EV 灵活性释放可调度容量，另一端用联邦法案把 100MW+ 大负荷的费用归属往客户侧推。

### 历史背景和前因后果

AI 数据中心的电力问题常被简化为“缺电”。实际更细：

1. 缺可快速 interconnect 的电。
2. 缺可按 24/7 SLA 提供的电。
3. 缺 local transmission / substation / transformer。
4. 缺可以让普通居民接受的费用分摊机制。
5. 缺能在高峰时段灵活调度 AI workload 或其他负荷的制度。

VPP 的意义在于把已经存在的 household assets 汇成可交易容量。Ratepayer Protection Act 的意义在于把大负荷的 grid upgrade 成本明确归给受益方。两者合起来，会让数据中心电力采购从“找 MW”升级为“找可调度 MW、可融资 MW、可被社区接受的 MW”。

### 产业链影响

**需求响应软件进入 AI 数据中心预算。** 如果数据中心能把训练、推理、batch job、checkpoint、低优先级任务跨区域迁移，VPP/DER/DR 可以成为降低峰值电价和获得 interconnection 的工具。但实时推理和高 SLA 任务可中断性低，需要更精细的 workload scheduling。

**家庭电池和智能恒温器有了 AI offtaker。** Tesla、Sunrun、Renew Home、Voltus、Enel X、AutoGrid、EnergyHub 等 VPP/DER 聚合商可以把容量卖给 hyperscaler 或 utility，形成新收入层。关键是计量、响应速度、可用率、客户补偿和市场规则。

**utility tariff 进入数据中心投资模型。** 100MW+ 大负荷如果必须自付 generation/transmission/substation upgrades，项目 capex 和 lease rate 会重新计算。拥有自备电、PPA、BESS、燃气、核电、快速 interconnection 和金融担保能力的项目会更有竞争力。

**Google 支持法案值得重视。** Google 作为大买方支持成本自付规则，说明头部 hyperscaler 希望建立统一规则，避免低质量开发商用隐性补贴抢项目，也避免居民反弹拖累整个行业。

### 投资含义

- 权重上调：VPP/DER 软件、家庭储能、智能恒温器、EV charging / V2G、demand response aggregators、AI workload scheduling、BESS、grid services、utility software。
- 权重上调：能提供 financial assurance、项目融资、PPA structuring、interconnection engineering 的数据中心开发商。
- 权重谨慎：依赖公共电网隐性补贴、未锁升级成本、未取得大负荷 tariff 明确性的园区。
- 关键交易指标：MW immediate deployment、dispatch performance、PJM/ISO acceptance、customer curtailment compensation、data center SLA 与 DR 兼容性。

### 继续验证

1. Sunrun/Renew Home/Tesla 16GW 中可实际用于数据中心 offtake 的 dependable capacity。
2. Virginia 300MW immediate capacity 的买方、价格和响应时段。
3. PJM Reliability Backstop Process 是否接受 1GW+ 家庭侧资源。
4. Ratepayer Protection Act 是否通过委员会、是否保留 100MW 门槛。
5. 数据中心客户是否愿意签 VPP capacity + curtailment 组合合同。

## 9. OpenAI Codex 经济研究：agent 推理需求的需求侧证据

### 新闻事实

OpenAI 2026-06-25 发布《How agents are transforming work》，核心数据如下：

- OpenAI 称 agentic AI 将知识工作的单位从单次交互推进到 delegated、long-horizon tasks。
- 截至 2026-05，抽样 individual users 中，80.6% 至少提交过一次估计超过 30 分钟人工工作量的 Codex request；70.2% 至少提交过一次超过 1 小时；25.6% 至少提交过一次超过 8 小时。
- OpenAI 内部 through August 2025，平均员工使用 Codex 的 token 少于 10%。现在 OpenAI 各部门都把 Codex 作为工作主 AI 工具，平均员工 output tokens 中 Codex 占比超过 85%，在 OpenAI 每周 output tokens 中占 99.8%。
- 非开发者 adoption 增长更快。自 2025-08 起，individual non-developer users 增长 137 倍，organizational non-developer users 增长 189 倍，OpenAI 内部 non-developer users 增长 12 倍。
- 非技术部门开始用 Codex 执行 automation、data transformation、tooling、debugging 和 structured analysis。

### 新增 delta 和去重说明

过去底稿已经写过 OpenAI Daybreak、Codex Security 和开发者 agent。今天新增的是 OpenAI 用真实产品使用数据描述 agent 工作负载长度和非开发者扩散。这条新闻不直接映射芯片订单，但它解释了为什么 OpenAI 同日强调 Jalapeno 推理 ASIC：长任务和非开发者 adoption 会让 token usage、tool calls、environment interaction、latency 和 cost become production bottlenecks。

### 产业链影响

**推理需求会从聊天转向任务执行。** Agent 会运行代码、调用工具、读写文件、执行脚本、做结构化分析。每个任务包含多个推理步骤、工具返回、检查和重试。token volume 与 compute seconds 会比单轮聊天更复杂。

**CPU、存储、网络和 sandbox 成本上升。** Codex 类 agent 需要代码执行环境、文件系统、包管理、网络访问、日志、权限、审计和安全边界。GPU/ASIC 只是推理核，完整服务还需要 CPU 控制面、SSD、对象存储、调度、容器、网络隔离、可观测性和安全扫描。

**非开发者 adoption 扩大 TAM。** 如果法律、招聘、财务、运营和营销都使用代码/数据 agent，开发者工具市场会扩展到更宽的 knowledge work automation。对应的投资方向会从 IDE 插件扩展到 enterprise agent platform、workflow orchestration、data connectors、权限治理、审计、AI observability 和 FinOps。

### 投资含义

- 权重上调：agent runtime、developer agent、enterprise workflow automation、AI sandbox、secure code execution、observability、model routing、token cost optimization、OpenAI/Anthropic/AWS/Microsoft agent ecosystems。
- 对硬件链的含义：长任务和高并发推理支持 OpenAI/Broadcom、Qualcomm HBC、TPU/Trainium/Maia/MTIA 等推理优化路线。
- 风险：OpenAI 数据来自前沿用户和公司内部，外部企业 ROI、合规、数据权限、错误责任和组织改造速度需要独立验证。

### 继续验证

2. 长任务的实际成功率、人工审查时间和错误修复成本。
3. 企业是否愿意为长任务 agent 支付高于普通聊天 token 的价格。

## 新闻口播稿

今天是 2026 年 6 月 25 日，今天筛到 9 条 AI 产业链新闻，先讲 OpenAI 和 Broadcom 的 Jalapeno 推理芯片。

这条新闻的分量很重。OpenAI 和 Broadcom 发布了 Jalapeno，OpenAI 把它称为自己的第一颗 Intelligence Processor，定位是专门面向大语言模型推理的定制加速器。官方披露的几个信息都很硬：从设计到 tape-out 用了 9 个月，工程样片已经在实验室以目标频率和功耗运行机器学习工作负载，Broadcom 负责 silicon implementation 和 Tomahawk 网络，Celestica 参与板卡、机架系统集成和可规模化生产。更早的合作框架里，OpenAI 和 Broadcom 已经讲过 10GW 定制 AI accelerator，部署从 2026 年下半年开始，目标到 2029 年底完成。今天的变化是，抽象路线图变成了具体芯片名、样片状态、网络 silicon 和机架伙伴。

这件事的重要性，可以从 OpenAI 的位置变化理解。过去 OpenAI 是全球最大的算力买方之一，它把模型训练、ChatGPT、API、Codex、企业产品都放在外部云和外部 GPU 供应体系上。现在 OpenAI 开始把模型路线、kernel、serving 系统、产品体验、memory movement、网络调度和硬件架构放进同一个优化目标。推理芯片的价值要同时看峰值算力、每个 token 的成本、延迟、并发、内存搬运、KV cache、prefill 和 decode 的分工，以及系统在高峰流量下能不能稳定服务。

为什么这个时间点很关键？因为 AI 使用方式正在从聊天转向任务执行。一个 agent 写代码、跑测试、查资料、改文件、调用工具、等待结果、再判断下一步，背后是一连串推理请求和环境交互。单次对话省下几分钱意义有限，成千上万次长任务每天运行，单位 token 成本就变成产品毛利和算力扩张速度的核心变量。Jalapeno 的核心逻辑，就是让 OpenAI 对自己最熟悉、最稳定、最有规模的推理负载做专门优化。

产业链上，Broadcom 的权重继续上调。它已经通过 Google TPU、custom ASIC、Tomahawk、SerDes、Ethernet 和互联生态证明了自己在云厂自研芯片里的位置。Jalapeno 把 OpenAI 这个最有标志性的模型公司拉进更明确的客户叙事。Celestica 被写进公告也有意义，说明定制芯片已经按整机柜平台交付，板卡、rack integration、测试、供电、散热和量产工程都成为价值链的一部分。再往上游看，TSMC 先进制程、先进封装、基板、测试、HBM 或其他高带宽内存层级、光电互联，都要随着定制 ASIC 放量被重新审视。

对 NVIDIA 的影响要讲得准确。Jalapeno 不会让 OpenAI 停止使用 NVIDIA，前沿训练、通用推理、新模型探索和生态工具仍然需要 GPU。真正会变化的是利润池结构。可预测、高频、成本敏感的推理负载，有机会逐步转向 OpenAI 自己定义的 ASIC。NVIDIA 仍然可能赚训练、最前沿推理、网络和系统软件的钱，但一部分 token 交付毛利会被 Broadcom、OpenAI 自研平台、机架集成和网络链条分走。后续最该盯的是 Jalapeno 的内存层级、封装、真实功耗、单机架配置、实际部署地点，以及 OpenAI 是否公开把 ChatGPT、Codex、API 或其他 agent 负载分流到不同硬件平台。

第二条，Qualcomm 在投资者日把数据中心战略一次性摊开。Meta 将采用 Qualcomm Dragonfly C1000 数据中心 CPU，生产计划从 2028 年下半年开始。Qualcomm 还发布了 HBC near-memory compute、AI300 inference accelerator、connectivity 产品和 custom silicon 路线，同时宣布收购 Modular，补上 AI 软件栈。公司给出的目标也很激进：2029 财年非手机收入目标 400 亿美元以上，其中数据中心收入 150 亿美元以上。

这条新闻和昨天的 Qualcomm-ByteDance 传闻相比，硬度高很多。昨天是市场报道，今天是 Qualcomm 官方路线图、Meta 客户、收入目标、CPU 产品族、near-memory 架构和软件收购一起出现。Qualcomm 过去最强的能力在手机 SoC、低功耗计算、connectivity 和系统级集成。AI 数据中心以前看起来离它很远，现在 agentic AI 把它擅长的东西重新拉进主战场：低功耗、高带宽、控制面、任务调度、CPU 与加速器协同、端到端软件体验。

C1000 的定位很值得注意。它面向 agentic、general-purpose 和 AI head node workloads。训练和大规模矩阵计算仍然由 GPU、TPU、Trainium、custom XPU 这些加速器承担，但 agent 工作负载需要大量 CPU 控制面。任务要排队，要解析工具调用，要管理容器和沙箱，要读写文件，要处理网络和权限，要把模型输出接回真实系统。CPU、内存带宽、PCIe、CXL、网络 I/O 和调度延迟会直接影响 XPU 利用率。Meta 愿意把 C1000 放进下一代 server fleet，说明数据中心 CPU 已经从普通服务器成本项，变成 AI rack 的性能变量。

HBC 这条线更远，但值得跟踪。Qualcomm 说 HBC 是 3D-stacked near-memory computing 架构，目标是提高 bandwidth per watt，缓解 memory wall。AI 推理特别怕内存搬运，尤其是长上下文、agent、多轮对话、代码和检索任务。HBM 很强，但成本高、封装复杂、供应受限。Qualcomm 如果能在某些推理场景里用 HBC 提供更好的容量、带宽和功耗组合，就可能拿到差异化窗口。当然，真实结果要等客户测试、良率、软件栈和总拥有成本验证，不能只听路线图。

Modular 收购是另一个关键。AI 加速器行业最难的地方在于完整落地：先做出一颗足够强的芯片，再让开发者愿意迁移，让模型能跑得稳，让企业能调试、监控、部署和升级。CUDA 的护城河来自软件生态和工具链。Qualcomm 收购 Modular，就是想给 CPU、NPU、custom ASIC、边缘设备和数据中心 accelerator 之间搭一层更统一的运行时和编译部署基础。投资上，Qualcomm 变成一个长周期数据中心期权；但时间风险也很清楚，C1000 和 AI300 都偏 2028 年以后兑现，市场短期定价需要后续产品节点、客户名单和真实收入来支撑。

第三条，Micron 财报把 AI 内存周期从概念变成现金流。公司 FY2026Q3 收入 414.6 亿美元，non-GAAP 毛利率 84.9%，non-GAAP EPS 25.11 美元，经营现金流 253.9 亿美元，调整后自由现金流 183 亿美元。数据中心收入超过 250 亿美元，data center SSD 收入超过 50 亿美元。Micron 还披露已经签了 16 个战略客户协议，典型期限覆盖 2026 到 2030 年，部分协议带 fixed 或 floor/ceiling pricing，季度末 RPO 超过 50 亿美元。HBM4 revenue 已经超过 10 亿美元，ramp 速度快于 HBM3E 12-high。

这些数字的意义非常直接。内存以前是最典型的周期行业，价格上涨以后扩产，扩产以后供给释放，库存上来，价格下跌，利润回落。AI 正在把其中一部分高端产品改造成战略供应品。HBM、HBM4、AI SSD、服务器 DRAM、SOCAMM、CXL memory、企业级 NAND，开始和模型公司、云厂、GPU/ASIC 平台、长期协议绑定。客户不再只在现货市场买 bit，它们要锁未来几年的容量、认证和价格区间。

最值得重视的是 data center SSD。市场平时最爱讲 HBM，因为 HBM 直接贴在 NVIDIA、AMD、Broadcom、TPU、Trainium 和下一代 ASIC 上。但 agent、长上下文、RAG、向量索引、日志、checkpoint、KV cache offload 和企业数据管线都会消耗大量高性能存储。Micron data center SSD 收入超过 50 亿美元并且环比翻倍，说明 AI 需求已经从 GPU 和 HBM 继续扩到完整 data path。以后看 AI 基础设施，内存、存储和数据搬运会越来越像核心资产。

Micron 的资本开支也透露出另一层约束。公司预计 FY2026 capex 约 270 亿美元，FY2027 季度 capex 预计高于 FY2026Q4，并且超过一半增量来自 construction capex，用于 cleanroom capacity。也就是说，瓶颈同时落在 EUV、刻蚀、沉积、测试、封装设备、厂房、洁净室、厂务、电力、高纯水、气体、化学品和施工能力上。AI 内存周期会继续向半导体设备、厂务工程、洁净室、测试和材料链条传导。

这里也要留一层风险。高毛利和长期协议会刺激扩产，客户也会优化架构、压缩 KV cache、改用更便宜的 memory tier，或者通过小模型和模型路由降低内存压力。到 2027、2028 年，如果 HBM、DRAM 和 NAND 供给释放太快，周期性仍然会回来。今天能确定的是，至少在当前节点，Micron 把 AI 内存的定价权、客户锁定和现金流兑现都摆到了桌面上。

第四条，Bloomberg 披露头部云厂未来数据中心租赁承诺超过 8500 亿美元。Meta 单季新增 790 亿美元，Microsoft 新增 410 亿美元以上。这个数字听起来像资本开支，其实更像未来付款义务和租赁融资的集合。它说明 hyperscaler 已经把大量 AI 数据中心需求交给长期 lease、第三方开发商、项目融资和信用市场来承接。

这条新闻的价值，不在一个巨大的总数本身，而在资产结构变化。过去看云厂 AI 投资，大家主要看 capex 指引，问买了多少 GPU，建了多少数据中心。现在越来越多容量会通过租赁、take-or-pay、capacity reservation 和开发商融资出现。对供应链来说，这些承诺可以提前支撑变压器、开关柜、UPS、液冷、机电施工、服务器、光纤和网络订单。对投资者来说，它也提高了识别难度，因为 future lease commitments 不等于已经通电的 MW，也不等于已经确认的收入。

真正要看的，是四个问题。第一，项目有没有拿到 active power 和并网时间。第二，租约什么时候起租，客户是否有延期或退出条款。第三，开发商融资成本和利率环境会不会侵蚀回报。第四，AI 负载的真实收入能否覆盖折旧、租金、电费、运维和芯片更新。8500 亿美元说明需求强，也说明财务杠杆更高。未来 AI 基础设施的风险不会只在股票市场，它会进入信用市场、项目债、租赁负债和资产估值。

第五条，电力侧同时出现两个方向相反但能互相解释的变化。Sunrun、Renew Home 和 Tesla 要汇聚 16GW 家庭侧灵活资源，包括家用电池、智能恒温器和车网互动资源，面向 hyperscalers 和 utilities 提供可调度能力。另一边，美国国会推进 Ratepayer Protection Act，要求 100MW 以上大负荷承担相关电网升级费用，避免把成本转嫁给普通居民和小企业。

这两条放在一起看，很清楚地说明 AI 数据中心已经进入电网政治。数据中心需要 24 小时高可靠电力，居民和监管者会问：新增变电站、输电线路、备用容量和峰值成本由谁付？如果由全体电费用户承担，地方阻力会越来越大。法案推动的方向，是让大型负荷为自己的接入和升级成本买单。这会提高一部分项目的显性成本，也会鼓励数据中心自带电源、自带储能、接受可中断负荷条款，或者和电网签更复杂的需求响应合同。

16GW 家庭侧资源的意义，在于它提供了另一种缓冲方式。家庭电池、恒温器、电动车、热泵和屋顶光伏单个都很小，但聚合之后可以在高峰时段削峰，在可再生能源波动时提供灵活性，在电网拥塞时释放容量。它不能直接替代一座全天候数据中心电源，也不能把名义 GW 直接换成可靠容量，但它可以让 utility 和数据中心在部分时段更容易达成交易。未来 AI 电力投资的重点，会从“多建发电”扩展到“谁能提供可调度、可验证、可结算的灵活资源”。

第六条，水资源和气候风险继续上升为许可变量。Microsoft 强调新 AI 数据中心在正常冷却中不消耗水，Axios 写到水正在成为 AI buildout 的主争议之一，First Street 估算全球 79% 数据中心容量面临急性气候风险。这里的重点很现实：一个 AI 数据中心即使拿到芯片、拿到客户、拿到资金，也还要面对当地水权、热浪、洪水、野火、风暴、保险、社区听证和环境披露。

液冷常被当成解决方案，但液冷本身有不同形态。闭环冷却可以减少现场耗水，dry cooling 可以减少水依赖，但可能提高电耗、设备成本或极端天气下的工程难度。用更多电换更少水，最后又会回到电网和间接水足迹问题。未来项目选址会越来越细：湿球温度、用水权、污水处理、备用水源、冷却塔限制、极端天气、保险费率、PUE 和 WUE 披露都会影响融资和许可。水处理、闭环冷却、干冷、热管理、气候模型和数据中心保险，都会变成 AI 基础设施的配套预算项。

最后几条低分或中等分新闻快速过一遍。

AWS 宣布追加 130 亿美元投资印度 AI 和云基础设施，使 2026 到 2030 年 Amazon 在印度的总投资升到 480 亿美元。印度的意义在于区域云、主权 AI、本地语言、金融和政府上云。它也会考验海缆、城市电力、土地许可、备电、冷却和本地施工。今天这条排在后面，是因为方向很强，但新增信息主要是投资规模，还需要看具体 region、AI accelerator 配置、电力和冷却方案。

Cerebras 今天的新增 delta 是股价在首份财报后下跌约 20%，全年毛利率指引降到 38% 到 41%，并且公司提到数据中心容量紧张，需要临时从客户处租回部分自有系统，同时部署自己的容量。昨天已经讲过 Cerebras 首份公开财报和 OpenAI/AWS 相关信息，今天只保留这个新增信号：非 NVIDIA AI 芯片即使避开 HBM、CoWoS 和 3nm 的部分瓶颈，也会卡在数据中心空间、电力、容量成本和云服务毛利上。特色架构要同时证明芯片效率和低成本交付能力。

OpenAI 发布 Codex 经济潜力研究，给 Jalapeno 和推理 ASIC 补了一层需求侧证据。OpenAI 称截至 2026 年 5 月，抽样 individual users 中 80.6% 至少提交过一次估计超过 30 分钟人工工作量的 Codex request，70.2% 至少提交过一次超过 1 小时，25.6% 至少提交过一次超过 8 小时。OpenAI 内部 output tokens 中，Codex 占比已经从去年 8 月前的平均低于 10% 上升到超过 85%，公司每周 output tokens 中 Codex 占 99.8%。非开发者用户增长也很快。这个研究的直接投资映射有限，但它解释了为什么推理芯片、CPU 控制面、沙箱、存储、网络、权限治理和 token 成本优化会越来越重要。
