## 10. 优先候选研究包

### 10.1 FERC：计算负载进入强制可靠性标准路径

- 核心事实：FERC 依据 FPA 215(d)(5) 对 NERC 下达命令，Docket 为 RD26-7-000。NERC 须在 2026-12-31 前提交新/修订可靠性标准，并修改 Rules of Procedure，为 computational-load entities 建立注册标准。
- 已知基线：NERC 已把大型计算负载视为频率、电压、并网和批量行为风险，并推进风险管理行动。
- 今日 delta：监管动作从研究和行动计划升级为有截止日的正式命令。注册规则意味着部分数据中心可能获得可识别的可靠性义务。
- 支持证据：FERC 会议摘要和公开会议时间；正式 order 全文尚待补链。
- 反方与边界：今天没有生效的 MW 门槛、故障穿越、降载或罚则。任何具体成本映射都需要等待 NERC 文本。
- 下游最值得展开：哪些负载行为触发可靠性风险；注册与传统负荷服务实体如何衔接；标准制定怎样改变项目时表和设备采购。
- 不重复：PJM 容量短缺、电价传导和州级社会许可旧机制只保留一句背景。

### 10.2 Nebius/Bloom：17 亿美元项目融资的资本堆栈

- 核心事实：IDF 是主开发方，Oaktree 持少数项目股权，Morgan Stanley 是唯一税务股权投资者及配售代理，MUFG 提供高级债。项目建成后为 Nebius AI 基础设施提供表后专用燃料电池电源。
- 已知基线：7/15 Nebius 已披露由伙伴持有基础设施/硬件、Nebius 保留架构、采购、软件和客户层的资产轻模式。
- 今日 delta：抽象模式出现真实交易参与方和多层资本来源。资金对象是项目资产，不能写成 Nebius 获得 17 亿美元公司融资。
- 边界：MW、地点、机型、燃料来源、排放、投产日、PPA/租赁和 Nebius 最低承诺均未披露。
- 下游最值得展开：AI 电力项目如何用税务股权与高级债降低开发商权益需求；Bloom 表后供电对并网时间和燃料风险的影响。
- 不重复：Nebius 7/15 合作模式的完整背景无需再讲，只保留连接句。

### 10.3 欧盟 Google：AI 助手接口与搜索数据开放

- 核心事实：Android 决定覆盖调用、上下文、动作、on-device AI models 与 App Functions 等 11 类能力；搜索决定允许合格搜索引擎和 AI 聊天机器人申请 ranking/query/click/view 数据。
- 时间线：最终决定 2026-07-16；搜索数据安排从 2027-01 起，主要 Android 义务从 2027 年开始，部分并发热词能力延至 Android 19/2028。
- 已知基线：DMA 已将 Alphabet 列为 gatekeeper，并对 AI assistants/vertical search 的接入公平性开展 specification proceedings。
- 今日 delta：调查阶段结束，开放范围、对象和时表成为绑定决定。
- 反方与边界：Google 指出隐私和安全风险；申请资格、收费、数据延迟和最长使用期均限制可用性，搜索数据不得直接泛化为通用模型训练燃料。
- 下游最值得展开：Android 的系统级入口如何影响助手分发；搜索行为数据对搜索型 agent 的排序与评估价值。

### 10.4 Kimi K3：API 已上线，开放权重仍待兑现

- 核心事实：2.8T 总参数、每 token 激活 16/896 experts、1M context；采用 KDA、Attention Residuals、Stable LatentMoE；API cache-hit input $0.30、miss $3、output $15/MTok。
- 工程细节：官方推荐 64+ accelerators 的 supernode，MXFP4 权重/MXFP8 激活；KDA prefill cache 的 vLLM 支持仍在路上。MiniTriton 与 48 小时 EDA 设计属于公司案例。
- 外部证据：Artificial Analysis 给出独立模型/成本页面；Simon Willison 的 SVG 任务消耗 16,658 output tokens、约 $0.25。不同 harness 的 benchmark 不能直接横比。
- 已知基线：K2.6 具备 agent/coding 能力；中国开放模型在价格和可部署性上已形成竞争。
- 今日 delta：规模、上下文和长程 agent 案例进入新的量级。权重承诺的兑现将决定“开放”判断是否成立。
- 反方与边界：官方承认总体仍落后 Fable 5 与 GPT-5.6 Sol；仅 max reasoning 可用；技术报告、权重和许可证尚未发布。
- 下游最值得展开：稀疏 3T 级模型的系统要求、价格与 cache 结构；开放权重承诺和 API 先行的商业节奏。

### 10.5 agent 安全：memory、安装链与文件删除

- 三条新机制：持久记忆可跨会话保留恶意规则；依赖安装可借 registry/index/version/source 绕过“明显恶意命令”识别；HOME 重绑定使正常清理动作作用于真实目录。
- 量化：MemPoison 无防御 BCR 62.55%，混合防御 10.70%，L3 sleeper 14.16%；安装研究覆盖 12 场景、5 攻击类、9 个配置；Claude Code 2.1.212 给 WebSearch/子 agent 各 200 次默认上限。
- 已知基线：7/15 已深播 GPT-5.6 错删、强制移除 worktree 与跨机凭据；7/16 已收录 Claude/Codex 审批加固。
- 今日 delta：OpenAI 的调查回应满足账本重开条件；新论文把威胁面扩展到跨会话和供应链；Claude release 增加循环与进程生命周期控制。
- 反方与边界：论文均在沙箱；OpenAI 只称“少量报告”；xAI retention 删除缺独立验证。
- 下游最值得展开：权限 UI、持久状态、依赖解析、环境变量与清理操作如何串成实际失效链。
- 不重复：旧事故逐条复述、通用“agent 很危险”背景和既有安全框架。

### 10.6 Lila Sciences：科学工厂的工程架构

- 核心事实：访谈把仪器比作计算节点，磁悬浮传送比作 PCI 总线，调度层类比 Slurm，目标是 24/7 运行。公司称已积累超 10 万亿条实验验证 token。
- 结果主张：气体吸附测量约提速 2,500 倍；CAR-T 从零到非人灵长类体内数据约六个月；无铂族催化剂由低先验方向产生最佳样品。
- 失败模式：物理 reward hacking、CoT 不可靠、RL 平均 MFU 约 5%；团队承认部分实验自动化经济性不足。
- 已知基线：Radical AI 访谈只给自主材料实验室的客户/数据飞轮路径。
- 今日 delta：新增系统架构、数量级结果和可复述的反证，足以独立深讲。
- 边界：所有数字来自创始团队，缺实验分母、成本、数据集、模型卡和第三方复现。
- 下游最值得展开：科学推理 token 如何由真实实验闭环生成；物理实验调度为何比纯 GPU 训练更稀疏。

### 10.7 Sharon AI：合同覆盖率很高，合同质量仍待穿透

- 核心事实：五年 13.2 亿美元，收入预计 2027Q1/Q2；公司给出 AI Factory 132MW、已签 116MW、2027 年中预计超 62,000 张 NVIDIA GPU。
- 已知基线：公司此前已有 ESDS 和另一全球科技客户大额协议。
- 今日 delta：第三份大单继续提高名义容量覆盖率，且新地域为新西兰。
- 边界：客户匿名；缺 GPU 型号、单合同 MW、付款、take-or-pay、终止和融资条件。公司 press release 的收入与容量仍需 SEC 文件确认。
- 下游最值得展开：名义合同收入怎样映射到 GPU 采购、MW、交付和融资；匿名客户集中风险。

### 10.8 Oversight Board：压制性政体的限制跨境进入模型

- 核心事实：测试经 Vertex/Azure、主要在美国基础设施、请求来自澳大利亚；内容过滤器关闭。批评宽松政体拒答 14%，批评压制政体 34%。
- 模型差异：报告给出 GPT-5.2、Gemini 3 Flash/Pro、Grok 4 Fast、Llama 4 Maverick、DeepSeek R1/V3、Claude Sonnet 4 等不同拒答计数。
- 已知基线：关于训练语料、对齐和政府压力导致跨境审查的讨论长期存在。
- 今日 delta：独立机构在统一位置、基础设施与提示框架下给出跨模型结果。
- 边界：模型为 2026 年 3 月版本；提示和语言规模有限；研究无法区分训练数据、后训练、法律风险或政府影响的因果贡献。
- 下游最值得展开：部署地自由并不保证输出摆脱其他司法辖区的约束；阈值设计与商业风控可能放大差异。

### 10.9 Netflix：GenAI 进入数百个 production title

- 核心事实：2026 年约 300 titles 使用 GenAI，最大集中在后期制作；公司称可更快、成本更低，并列举 Glory、Brasil 70 和 The American Experiment 等复杂镜头。
- 今日 delta：采用从 2025 年单片案例扩展到数百 title 的流程层。
- 证据边界：title 数量不能等同于全片生成；没有镜头数、预算节省、模型供应商、人工岗位或质量投诉数据。
- 下游最值得展开：后期制作最先规模化的原因；采购、版权、披露和工会关系需要哪些可验证数据。

### 10.10 Tata 与 Gemini：两条交付节奏反证

- Tata：消息人士称初期主要 90nm；公司称路线一直是 55/90nm 先行、随后 28nm。印度科技部长给出的商业投产时间为 2028 年中，早先公开目标是 2026 年底。
- Gemini：消息人士称 3.5 Pro coding 训练结果令人失望并延后数月；Google 只确认仍在测试多个模型。
- 洞见增量：两条都涉及从公开路线到实际工程交付的时间表下修。Tata 有公司与 PSMC 回应，Gemini 缺正式发布日期。
- 下游最值得展开：节点/benchmark 宣传与量产/发布门槛之间的差距；暂不推演长期竞争格局。

### 10.11 Glean：覆盖率与成本同时量化

- 核心事实：CEO 称分诊 agent 处理约 95% 原由 15 人 on-call 团队承担的问题，每月约耗 100 万美元，成本高于对应人类团队；部分用户 token 月耗从约 $20 到 $10k—$15k。
- 已知基线：企业 agent 生产案例通常披露“替代工时”，很少同时给出模型成本。
- 今日 delta：同一案例同时提供覆盖率、人员基线和高额成本，形成可检验 ROI 问题。
- 边界：没有事件量、严重度、SLA、模型组合、cache 命中、人工接管和持续月份；“15 人”代表 on-call 覆盖范围。
- 下游最值得展开：agent 价值可能先体现在响应速度和 24/7 覆盖，财务盈亏依赖模型路由、上下文装配和错误成本。
