## 9. 优先候选研究包

### 9.1 NVIDIA 资本栈：权益、担保与分销

- **事实与时间线**：6/30 的 13F 显示 $63.44B 权益持仓；8/14 据报 Ohio 初始 backstop 降至 <$120B；Goldman 同日开始接触保险、资管和银行。
- **新增机制**：权益持仓反映资本集中，担保反映或有信用，融资平台反映资产分销。三类敞口需要分别跟踪。
- **支持/反证**：13F 为法定原件；Ohio 与 Goldman 为匿名信源。13F 不给成本或商业合同，MOU 不给承诺资本。
- **下游展开**：最值得讲集中度、项目融资缺口与风险保留；不要重复 NVIDIA 合作公司清单和 >$500B 旧目标。
- **验证问题**：下一季增减仓、担保最终上限、首个项目 close、LTV/期限、残值和第一损失承担者。

### 9.2 SpaceX—Cursor 交割

- **核心事实**：8-K 确认交易完成、389.29M 股对价、$60B 隐含股权价值、RSU/期权承接。
- **洞见增量**：签约风险消失，整合、留才和并表风险开始计时。
- **边界**：无现金支出结论、无协同数字、无模型供应与产品路线。
- **下游展开**：股权对价与人才锁定；不重复 SpaceX 旧算力经济和 6 月签约背景。

### 9.3 Project Jupiter 供能时间表

- **核心事实**：媒体转述的新投运日为 2027-02-01；FERC 原件确认 17.8 英里、24 英寸、400,000 Dth/d 和 9/4—12/3 审查日程。
- **因果链**：州土地/文保/环境审查延长管线授权，燃料到位推迟限制燃料电池上电。
- **反证边界**：项目可用其他临时燃料或分批上电；2.5GW 和 $165B 是规划上限。
- **验证问题**：新日期原始附件、通行权、EA、最终令、Bloom 模块和首批负载。

### 9.4 Anthropic 与 OpenAI 经营分母

- **核心事实**：Anthropic 据报 Q2 >$11.5B 且 adjusted operating income 转正；OpenAI 据报企业收入超过消费、总 run-rate $40B。
- **判断变化**：两家从采用叙事进入可量化收入结构；盈利质量和现金成本仍空缺。
- **反方证据**：私企 investor material、run-rate、adjusted profit 与远期 forecast 都可能受季节性、算力折扣和排除项影响。
- **下游展开**：收入来源、毛利和估值假设；不要把 2028 预测写成订单或把 run-rate 写成审计收入。

### 9.5 Anthropic Model 2、内部自动化与控制缺口

- **核心事实**：Model 2 无外发计划；Claude authors a large majority of merged production code；整体研发提速 <2×；misalignment 等级上调。
- **事故分母**：约 50,000 人、133M exchanges 曾无阻断生物分类器；报告称已修复、未发现滥用。另有 median 约 40 tail tokens 未评分、客户豁免席位约为批准数 4 倍。
- **证据边界**：公司自查、删节报告、任务评测饱和；无法从中推导 AGI 或外部事故率。
- **下游展开**：能力释放闸门、内部生产依赖与控制覆盖的张力；不要重复旧 Mythos 模型介绍。

### 9.6 GLM-5.3 与开放权重治理

- **核心事实**：同 base 的 post-training 增益；CyberGym 84.5、ExploitBench 54.4；权重延后两周；漏洞账本 2,436 项。
- **政策连接**：Pax Silica 排他信和开放模型可能纳入 frontier 审查都来自匿名媒体信源，尚无正式执行文本。
- **边界**：服务已可用与权重已开放要分开；公司 benchmark 和漏洞数量需要严重度、重复项与披露质量复核。
- **下游展开**：post-training 的能力扩展速度、权重发布治理与地缘准入；不要用“开源”概括当前 artifact 状态。

### 9.7 推理正确性：生命周期、launch 与 artifact

- **Mooncake**：free/reallocate 后异步 store 读错 block，形成跨请求 KV 污染；修复 PR 为 save sequence 持有 block-pool reference。
- **SGLang/FlashInfer**：gridDim.z 65,535 的硬阈值、错误只写 stderr、Python 继续；benchmark 因核心算子没跑而变快。
- **Triton cache**：共享 Lustre 上并发 JIT 的非原子 artifact 写导致 aligned/unaligned binary 串用与全 NaN。
- **Qwen/H3**：量化 loader 和 CPU staging 暴露模型交付跨 runtime/主机资源分叉。
- **证据边界**：issue/PR 原件强于新闻，但多为单环境、开放修复；需要 stable、跨硬件和长时 soak。
- **下游展开**：用“语义正确性认证”串联，不重复每个模型的旧规格或低精度常识。

### 9.8 Agent 权限与事故传播

- **Claude Code**：报告者的 USN 时间窗与 120.192s 命令吻合，命令文本已丢失；classifier unavailable 后仍放行是最重要的控制面线索。
- **OpenAI Agents**：sticky 与 exact-call decision 的优先级可让明确 rejection 被忽略；最小 Python repro 和开放 PR 提供可验证路径。
- **边界**：前者缺独立复现，后者未进 stable；两者都不能外推平台事故率。
- **下游展开**：fail-closed、审批状态形状与恢复链；不要重复“agent 有危险权限”的泛化常识。

### 9.9 科研与编码评测：任务分数的组成

- **Faraday**：专门 post-training 的 27B 模型在复现任务胜通用大模型，说明任务分布和 harness 可重排规模优势。
- **QuoteBench**：parser 损伤与 boundary disclosure 补偿可以相互抵消，matched final score 会隐藏系统级脆弱性。
- **CAPRI**：证明通过仍可能修改 protected text；restricted interface 消除越界。
- **边界**：均为作者 benchmark；Faraday 未证明 novelty，QuoteBench/CAPRI 任务规模有限。
- **下游展开**：分别报告生成能力、接口合同、执行语义与最终状态。

### 9.10 Irving 与 Lindy：阶段跃迁和单位经济

- **Irving**：监督外推可能在超人阶段失效；这是理论风险与研究路线，不是新实证。
- **Lindy**：85%→65% cache hit 令成本近翻倍、当前负毛利、3—6 月工资/推理线交叉是 CEO 口径。
- **共同价值**：一条解释能力治理的阶段性风险，一条量化 agent 商业化对缓存/CI/人类补洞的依赖。
- **不应重复**：旧时间线名单、Teammate 架构和笼统的“AI 提升效率”。
