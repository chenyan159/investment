## 1. Anthropic / Samsung：Claude 的成本压力开始外溢到 2nm 代工、先进封装和 HBM 生态

### 核心事实

TechCrunch 2026-07-02 报道，The Information 称 Anthropic 已与 Samsung 接触，探索围绕自研 AI 芯片的合作。Anthropic 对 TechCrunch 的回应很克制：公司称由 Google、Amazon 和 NVIDIA 芯片组成的多元硬件栈仍然是算力战略核心，对潜在 Samsung 合作没有更多评论。报道同时强调，该芯片的用途、功耗、服务器形态和性能级别尚未确定。

量产芯片仍未确认；更值得跟踪的是前沿模型公司在商业化高压下继续寻找更深层的成本控制权。OpenAI 上周刚与 Broadcom 推出定制推理芯片 Jalapeño；Anthropic 此前已经深度绑定 AWS Trainium、Google TPU 和 NVIDIA GPU；现在 Samsung 被放进潜在自研芯片路径，说明 frontier lab 的算力采购已经从单纯买 GPU 转向组合拳：租 GPU、签云长约、用云厂自研芯片、找 ASIC 伙伴、锁定先进制程和先进封装。

### 新增 delta 和去重

过去日报已经写过 OpenAI/Broadcom Jalapeño、Google TPU、Amazon Trainium、Anthropic 与云厂算力绑定、AI 芯片短缺和 HBM 紧张。今天新增 delta 是 Anthropic 自身进入“可能自研芯片 + Samsung 代工/封装”的讨论。

这与 2026-06-26 的 “Anthropic / Alibaba 蒸馏指控” 和 2026-07-01 的 “Fable/Mythos 恢复”不同。那两条落在模型访问、政府监管和 IP 防护；今天这条落在算力成本、芯片供应权和 Samsung Foundry 的潜在大客户突破。

### 历史和前因后果

Anthropic 的商业增长非常快。CNAS 在 2026-05 报告中引用数据称，Anthropic 年化收入从 2025 年末约 90 亿美元升至 2026-04 的约 300 亿美元。收入越快，推理调用、企业 coding、agent 工作流和安全评测的算力消耗越快。模型公司收入增速高时，GPU 采购、云折扣、容量预留和 token 成本都会变成毛利率核心。

NVIDIA GPU 仍是最稳妥的通用训练和推理平台，优势在 CUDA、网络、系统软件、客户部署经验和 Blackwell / Rubin 迭代。问题在于顶级模型公司很难接受长期只做价格接受者。OpenAI 用 Broadcom 做 inference ASIC，Google 用 TPU 支撑 Gemini 和 Cloud，Amazon 用 Trainium/Nova/Anthropic 绑定 AWS，Meta 自研 MTIA 并继续购买 GPU。Anthropic 若探索 Samsung，会把模型公司、云厂、代工厂和内存厂之间的关系再拉紧一层。

Samsung 的动机也清楚。过去两年 AI 代工叙事主要集中在 TSMC CoWoS、NVIDIA、Broadcom 和 Google TPU。Samsung 同时拥有 foundry、HBM、先进封装和系统制造资源，但在顶级 AI accelerator 代工客户上的市场心智弱于 TSMC。拿到 Anthropic 这样的客户，即使先是早期合作，也能改善 Samsung 2nm、先进封装、HBM4/HBM4E 和系统级协同的外部叙事。

### 产业链影响

第一，模型公司自研芯片会继续推动 ASIC 设计服务和先进封装需求。Broadcom、Marvell、MediaTek、Alchip、GUC、世芯-KY、创意电子、芯原股份这类 ASIC/IP/后端设计链条会持续被市场重估。Anthropic 若最终走 Samsung 路径，还会让 Samsung Design Solution、EDA、IP、封装基板和 HBM 生态获得更高关注。

第二，HBM 的角色继续从标准内存升级为客户定制资产。大模型公司如果设计自己的 inference accelerator，就会围绕上下文长度、batching、KV cache、MoE routing、agent 长会话和低延迟需求去决定 HBM 容量、带宽、堆叠高度和 base die 逻辑。HBM4 起 base die 和逻辑工艺结合更深，内存厂与芯片设计方的共同定义会增加。

第三，Samsung 与 TSMC 的竞争点从制程节点扩展到“2nm + HBM + packaging + thermal + customer co-design”。单看逻辑代工份额，TSMC 仍强；但模型公司需要的是能把芯片交付到 rack 里的供应链。如果 Samsung 能把自家 HBM、interposer、hybrid bonding、封装和系统制造整合成低摩擦路径，它有机会用“全栈制造便利性”争取第二供应商地位。

第四，NVIDIA 的护城河短期不会被直接削弱。自研芯片往往先切入高确定性推理负载，尤其是 ChatGPT/Claude/Copilot 这类内部可控流量。训练、post-training、research 和不确定 workload 仍更适合 GPU。投资上要避免把“Anthropic 探索自研芯片”理解成 NVIDIA 需求马上见顶。更合理的判断是：高价值模型公司会同时扩大 GPU 采购和定制芯片投入，区别在于 GPU 用于高弹性和新模型，自研 ASIC 用于规模化、可预测、毛利率敏感的推理。

### 业内评论和反对观点

反对观点集中在三点。

1. 自研芯片项目周期长，Tape-out、验证、封装、系统、软件栈和量产都可能拖延。OpenAI/Broadcom 的案例已经显示，原型到规模化部署之间至少还有多个硬件代际和数据中心配套问题。
2. Anthropic 的云伙伴复杂。AWS 是重要投资方和 Trainium 供应方，Google 提供 TPU 和云资源，NVIDIA 仍是核心 GPU 供应商。Samsung 路径如果推进，需要处理云厂、模型公司和代工伙伴之间的利益边界。
3. 自研芯片的优势取决于 workload 稳定性。Claude 的企业 coding、agent 和安全能力仍在快速变化，模型架构如果变化太快，芯片规格可能追不上软件需求。

### 投资映射

- **权重上调：先进封装和 HBM4/HBM4E。** 关注 HBM、interposer、基板、hybrid bonding、测试、热管理和电源完整性。相关方向包括 SK hynix、Samsung、Micron、TSMC、ASE、Amkor、Ibiden、Unimicron、Shinko、KLA、Applied Materials、Lam、Tokyo Electron。
- **权重上调：ASIC 设计服务和定制芯片 IP。** Broadcom 仍是最大受益方向；Marvell、Alchip、GUC、世芯-KY、芯原股份等要继续跟踪客户结构和先进封装能力。
- **权重中性偏上：Samsung Foundry。** 需要验证是否拿到正式客户、节点、封装方案和量产窗口。单条早期洽谈不能等同于确定订单。
- **权重谨慎：纯“反 NVIDIA”叙事。** GPU 需求、NVIDIA 网络和软件平台仍在扩张。更好的表达是“GPU 之外的第二层利润池扩大”，而非 GPU 链条崩塌。

### 后续验证点

1. Anthropic 是否确认芯片团队规模、芯片用途、Samsung 节点、封装方案和目标上架时间。
2. Samsung 是否披露与 Anthropic、Google、OpenAI 或其他 frontier lab 的 foundry / advanced packaging 进展。
3. Anthropic 与 AWS Trainium、Google TPU、NVIDIA GPU 的容量分配是否改变。
4. Samsung HBM4E、HBM thermal、interposer 和 hybrid bonding 良率是否能支撑外部大客户。
5. OpenAI Jalapeño 和 Anthropic 潜在芯片是否都偏推理；若训练芯片也出现，先进封装容量压力会更强。

## 2. NVIDIA neocloud 收入分成：GPU 销售开始嵌入云收入回收

### 核心事实

NVIDIA 2026-07-01 官方博客由 CFO Colette Kress 和 Raj Mirpuri 发布，称公司正在与 AI clouds 合作建设大规模、多租户 AI factories，并通过 revenue-sharing 和 credit-support model 对齐经济利益。AI cloud 公司销售 NVIDIA-powered cloud services；NVIDIA 同时获得标准产品收入和被支持容量上的 cloud revenue share。NVIDIA 称这会给公司带来 recurring、usage-linked earnings stream。

首批被点名的合作方包括 Sharon AI 和 Firmus：

- Sharon AI 计划部署最多 40,000 张 NVIDIA Grace Blackwell GB300 GPU。
- Firmus 在印尼 Batam 建设 DSX AI factory campus，预计可扩展至 360MW 和最多 170,000 张 NVIDIA GPU。
- NVIDIA 点名 Baseten、Fireworks AI、Together AI 等 AI-native 客户，说明需求来自模型训练、post-training、fine-tuning 和高频 agentic inference。

### 新增 delta 和去重

2026-06-29 日报已经深写 Firmus / NVIDIA / DayOne Batam 的 17 万 GPU、360MW 和 250-300 亿美元收入目标。今天保留这条，是因为新增 delta 已经从“单个项目”推进到“NVIDIA 官方定义的商业模型”。本节聚焦 NVIDIA 如何正式把硬件、信用支持、云收入分成、多租户 AI factory 和 usage-linked earnings 放到同一套模板里。

### 历史和前因后果

过去 neocloud 的核心问题是资本开支太重。GPU、网络、机柜、电力、机电、租约和客户预付款都需要融资，但客户多是高增长 AI-native 公司，传统银行和资产融资方很难直接给足信用。CoreWeave、Nebius、IREN、Nscale、Crusoe、Lambda、Applied Digital 这类公司不断用 GPU 资产、长期租约和 hyperscaler 合同融资。融资结构越复杂，市场越担心循环融资、客户集中和 GPU 折旧。

NVIDIA 的收入分成模型把供应商从“卖设备的人”变成“参与容量回收的人”。这有三层影响：

1. NVIDIA 帮 neocloud 获得设备和信用支持，降低前期资金压力。
2. neocloud 更快上线，给 AI-native 客户提供可用 GPU 容量。
3. NVIDIA 在硬件收入之外拿云服务收入分成，把一部分周期性硬件销售变成和利用率挂钩的收入。

### 产业链影响

第一，GPU 供应权开始变成金融工具。过去锁 GPU 意味着拿到稀缺硬件；现在还意味着拿到供应商信用支持、客户引荐、NVIDIA DSX 架构、系统调优和市场背书。neocloud 的竞争不只看谁买到卡，还要看谁能拿到 NVIDIA 认可的商业闭环。

第二，AI compute 的估值指标会变化。传统数据中心看 MW、RFS、租约、客户、PUE、CapEx/MW；AI neocloud 还要看 GPU 代际、利用率、token workload、客户 churn、NVIDIA 分成比例、融资成本和折旧。NVIDIA 收入分成可以提高设备可融资性，也可能让利润池向上游转移。

第三，NVIDIA 在防守 custom chip。Google、Amazon、OpenAI、Anthropic、Meta 都在做或考虑自研 ASIC。NVIDIA 的应对不只靠 GPU 性能，还靠融资、软件、网络、云伙伴和客户生态。收入分成把中小模型公司和企业客户继续留在 NVIDIA 云生态内，降低他们转向云厂 TPU/Trainium 或自研 ASIC 的速度。

第四，地方电力和项目交付仍是硬约束。Sharon AI 和 Firmus 都需要真实的电力、机电、散热和网络。收入分成能改善资金结构，无法缩短变压器、开关设备、许可、水资源和社区沟通的物理周期。

### 业内评论和争议

市场担心“循环融资”。NVIDIA 投资或支持客户，客户再采购 NVIDIA GPU，表面上会放大收入。这个风险需要按合同拆解：是否有真实第三方客户、客户预付款比例、容量是否已签约、GPU 所有权归属、NVIDIA 是否承担最低收入担保、设备折旧由谁承担。

另一类担心来自 GPU 价格和代际折旧。GB300 和 Rubin/Verin 迭代越快，旧 GPU 云容量的价格越容易下行。若 neocloud 客户签短约、模型推理价格下降、Meta 这类巨头开始转售过剩容量，neocloud 的利用率和价格会承压。NVIDIA 的收入分成提高了参与上行的空间，也让它更暴露于客户云收入质量。

### 投资映射

- **权重上调：NVIDIA 平台控制层。** GPU、NVLink、Spectrum-X、InfiniBand、CUDA、NIM、Triton、AI Enterprise、DSX 设计和云伙伴融资共同构成控制层。
- **权重上调：可交付 neocloud。** 优先看已上电 MW、客户 offtake、GPU 交付、融资结构和 NVIDIA/云厂背书。CoreWeave、Nebius、IREN、Applied Digital、Crusoe、Lambda、Sharon AI、Firmus 的可比指标需要统一成 MW、GPU、合同年限和收入确认窗口。
- **权重上调：电力和机电设备。** GPU 金融模型再复杂，最终都要落到变压器、开关设备、UPS、液冷、泵阀、冷却塔、母线槽、rack power 和施工周期。
- **权重谨慎：只靠远期 GPU pipeline 的故事。** 没有客户、没有电、没有 financing close、没有 RFS 时间表的 GPU 规划，应打折。

### 后续验证点

1. NVIDIA 是否在财报中单列或解释 revenue-sharing 收入。
2. Sharon AI 和 Firmus 的合同是否披露最低购买、收入分成比例、信用支持条款和客户 offtake。
3. Baseten、Fireworks AI、Together AI 等 AI-native 公司是否公开采购这些容量。
4. Batam 360MW 的电力、并网、机电和冷却建设进度。
5. 市场是否把该结构归类为高质量 recurring revenue，还是高风险供应商融资。

## 3. 数据中心地方反弹：AI factory 的社会许可开始进入估值折扣项

### 核心事实

Guardian 2026-07-03 报道，美国多地居民正在推动数据中心 moratorium，并尝试罢免批准项目的地方官员。Lenox Township, Michigan 的案例中，居民通过公开记录请求发现开发商曾联系乡镇主管寻求支持，随后居民挤满公众会议，并提交 petition 要求 recall 四名 board trustees。Guardian 还列举 California、Florida、Michigan、Missouri、Oklahoma、Oregon、Texas 等州在 5-6 月出现围绕数据中心提案的 recall 努力。

同一天，FT 报道 Blackstone 旗下 QTS 结束了 Virginia Prince William Digital Gateway 数据中心项目，背景是公民抗议和诉讼。Barron's 也把数据中心 public backlash 写成股票风险因素。Data Center Watch 的数据库显示，过去两年约 640 亿美元美国数据中心项目受地方反对而被 blocked 或 delayed，其中约 180 亿美元 blocked、460 亿美元 delayed；该组织还跟踪到至少 142 个 activist groups，分布在 24 个州。

Guardian 引用 Data Center Watch 的最新口径称，2026Q1 至少 75 个、价值约 1300 亿美元的数据中心项目被 blocked 或 delayed，接近 2025 全年规模。DataCenterBans.com 的州级跟踪显示，约 19 个州已经在限制或考虑限制数据中心，8 个州有 active bans/moratoriums，11 个州有 advancing legislation，15 个州仍在讨论。

### 新增 delta 和去重

过去日报已经多次覆盖 Henrico 25% 电价涨幅、Connecticut 禁令、Imperial Valley 水权、Queensland 拒绝能源计划、Exelon 停电警告、PJM/FERC 大负荷并网和地方 ratepayer protection。今天的新增 delta 是反对力量开始进入选举、召回和项目退出层面。地方政治从许可摩擦升级到官员个人政治风险。

### 历史和前因后果

AI 数据中心的早期地方叙事主要靠投资额、税收和“高科技就业”。随着项目规模从几十 MW 扩到几百 MW、甚至 GW，地方看到的账单变得更具体：

- 电网扩容和容量成本是否转嫁给居民和学校。
- 水消耗、冷却、排热、噪音、柴油备用发电和空气污染。
- 绿地、农地、房价和交通。
- 税收减免是否大于地方长期收益。
- NDA 是否让居民在关键投票前看不到真实客户和项目规模。

Guardian 报道里提到，31 个 Virginia 有现有、批准或拟建数据中心的 locality 中，80% 与项目背后的公司签过 NDA。这个数字会成为未来社区运动的抓手，因为数据中心许可最怕“先投票、后披露”的不信任感。

### 产业链影响

第一，数据中心开发商会从“拿地抢电”转向“拿社会许可”。没有 public engagement、community benefit agreement、ratepayer protection 和透明客户披露的项目，即使有土地和并网申请，也可能被地方政治拖慢。

第二，自备电源和 large-load tariff 权重上升。开发商需要证明不会把输配电扩容、容量市场费用和备用电源成本推给居民。天然气自备电、燃气轮机、燃料电池、储能、核电、地热、可中断电价、需求响应和 utility-side special tariff 会继续抬升。

第三，QTS/Prince William 这种项目退出会改变数据中心 REIT、私募基建和 hyperscaler 租约估值。土地储备和潜在 MW 不能直接按满额折现；市场会要求已获许可、已上电、已签 PPA/utility agreement、已签客户长约的项目获得溢价。

第四，AI 模型公司会被迫更多披露基础设施责任。OpenAI、Microsoft、Google、Amazon、Meta、xAI、Anthropic 不能只用国家竞争叙事推进数据中心。地方社区会要求知道谁是最终客户、谁付电费、谁承担水和噪音成本、谁负责退役和环境修复。

### 业内评论和反对观点

支持数据中心的一方会强调税收、施工就业、长期地方财政和美国 AI 竞争力。反对者会强调低长期就业、资源占用、居民电价和透明度。更复杂的是，反对阵营跨党派。环保人士关注水、电、排放；保守派居民关注税收减免、政府秘密谈判和财产价值；公共部门关注学校和市政用电账单。

也要区分“项目被反对”和“AI 需求下降”。地方阻力说明可交付 capacity 更稀缺，可能提高已获许可、已上电数据中心的价值。对 Equinix、Digital Realty、QTS/Blackstone、CoreWeave、Applied Digital、TeraWulf、IREN、Nebius、NextDC、DayOne 等公司，分化会更明显：能交付的资产溢价上升，只有远期 pipeline 的资产折现率上升。

### 投资映射

- **权重上调：已上电、已许可、客户长约数据中心。** RFS MW、PPA、utility agreement、社区协议、税务协议和客户 offtake 是关键。
- **权重上调：ratepayer protection 相关电力资产。** 变压器、开关设备、储能、燃机、微电网、需求响应软件、公用事业资本开支受益。
- **权重上调：低水耗和可解释冷却。** Warm-water liquid cooling、closed-loop cooling、direct-to-chip、waste heat reuse、再生水和空气冷却替代方案更有商业价值。
- **权重下调：依赖 NDA 和地方税收减免的项目。** 透明度不足会提高政治尾部风险。
- **权重谨慎：小型 neocloud 的大额远期建设。** 如果项目靠少数客户、少数县和高负债融资，地方延迟会快速影响现金流。

### 后续验证点

1. QTS/Prince William 项目是否正式披露取消范围、客户和资产减值。
2. Data Center Watch 2026Q2 数据是否继续显示 blocked/delayed 项目加速。
3. Virginia 数据中心电力税、销售税豁免和 county-level NDA 规则是否变化。
4. Microsoft、Google、Amazon、Meta 是否推出更明确的 community-first 条款。
5. 项目融资文件是否开始把 local opposition 写成更高风险因子。

## 6. 封装和冷却：AI 瓶颈继续下沉到 HBM4E interposer、microfluidic cooling 和光互联

### 核心事实

SemiAnalysis 2026-07-03 对 ECTC 2026 技术进行汇总，核心信息集中在 HBM4E、hybrid bonding thermals、microfluidic cooling 和 photonic interconnects：

- Samsung 展示 HBM4E interposer 方案。HBM4E 数据速率达到 12Gb/s 以上，I/O pin 数翻倍，routing complexity 和 power consumption 抬升；SemiAnalysis 汇总称 HBM4E 可能需要相对 HBM3E 两倍的 interposer layers，功耗相对 HBM3E 增加约 86%。
- Samsung 对 HBM hybrid copper bonding 的热阻改善做了测试。2.5D GPU package 中，HCB 相对 TCB 可降低内部 HBM thermal resistance，stack-level 改善在更高 pad density 下更明显。
- TSMC 展示 CoWoS-R 上的 direct-to-silicon micropillar cooling。测试车有 3.3x reticle interposer、4 个 SoC dies、8 个 HBM stacks。micropillar 设计在更高流量下超过传统 lidded/lidless cold plate，8 LPM 下可 dissipate 5.3kW。
- Microsoft 在实际 NVIDIA GH200 GPU 上测试 direct-to-silicon microfluidic cooling，报告 GPU junction-to-inlet thermal resistance 在 1 LPM 下下降 51-60%，整体 package thermal resistance 下降约 50%。
- Marvell 展示 OMIB / Photonic Fabric，目标是用局部光互联和 embedded PIC 降低 chip-to-chip hop count，并提出 1.8Tbps/mm² bandwidth density 概念。

Houston Chronicle 2026-07-02 报道 University of Houston Hadi Ghasemi 团队用 AI 搜索冷却微结构，发现 branched/tree-like shapes 的冷却效率约为传统尝试的三倍。该研究由美国 Office of Naval Research 100 万美元 grant 支持，发表在 International Journal of Heat and Mass Transfer。

### 新增 delta 和去重

7 月 1 日已写 Omen AI 液冷监测融资，7 月 2 日已写 Qnity 半导体材料。今天的新增 delta 不在“数据中心装液冷”，而在更底层的封装热阻、HBM base die、interposer routing、direct-to-silicon 和 chip-to-chip optical interconnect。冷却议题从机柜和 coolant 运维推进到 package 内部。

### 历史和前因后果

AI 加速器功耗从 Hopper 到 Blackwell 再到 Rubin 持续提高。过去靠空气冷却和冷板，今天则要同时处理：

- GPU die 自身热密度。
- HBM stack 高度、base die power 和 GPU-to-HBM crosstalk。
- Interposer routing、power delivery network、decoupling capacitor 和 voltage noise。
- Rack 级液冷的流量、泵、泄漏、腐蚀和运维。
- 光互联和 co-packaged optics 的温漂、封装热隔离和制造良率。

HBM4E 的困难尤其值得看。I/O 翻倍和更高数据率提升带宽，也把 interposer layer、SI/PI、热阻和电源完整性变成系统瓶颈。先进封装过去被看作后段产能，正在成为 AI 性能路线图本身。

### 产业链影响

第一，封装材料和设备的重要性继续提高。Hybrid bonding 需要铜、dielectric、CMP、清洗、表面处理、低温 bonding、检测和良率控制共同优化。Applied Materials、EV Group、ASMPT、Tokyo Electron、KLA、Onto、Camtek、DISCO、Advantest 等都在瓶颈周边。

第二，HBM 供应商竞争点更复杂。SK hynix、Samsung、Micron 不能只拼堆叠层数和带宽，还要拼 base die、hybrid bonding、thermal resistance、UHC capacitor、interposer co-design 和与 GPU/ASIC 客户共同调试能力。

第三，液冷供应链会分层。机柜级 direct-to-chip 已经进入商业扩散；direct-to-silicon / microfluidic 仍需要可靠性、污染、堵塞、密封、保修和数据中心运维验证。投资上应区分近期订单和远期技术路线。短期订单仍在 CDUs、冷板、quick disconnect、泵、阀、管路、manifold、leak detection 和监测；远期增量在微流体、硅加工、密封材料和封装协同。

第四，光互联会从 rack/network 继续向 package 靠近。Marvell、Broadcom、Coherent、Lumentum、Applied Optoelectronics、Innolight、中际旭创、新易盛、光迅科技、Celestial AI/Marvell、Lightmatter、Ayar Labs 等都在相关链条。当前更接近工程验证和高端网络先行，package 级规模化还要解决热、良率和组装。

### 投资映射

- **权重上调：先进封装设备和材料。** Hybrid bonding、CMP、清洗、低温 bonding、inspection/metrology、temporary bonding、underfill、thermal interface materials。
- **权重上调：HBM thermal 和 interposer co-design。** Samsung、SK hynix、Micron、TSMC、ASE、Amkor、Ibiden、Unimicron、Shinko、Kinsus。
- **权重上调：液冷中长期路线。** 近期看 Vertiv、nVent、Modine、CoolIT、Asetek、Boyd、Delta、台达电、双鸿、奇鋐、AVC；远期看 direct-to-silicon 的材料、密封和硅加工。
- **权重上调：CPO/硅光。** Marvell、Broadcom、Coherent、Lumentum、Innolight、中际旭创、新易盛、光迅科技、Ayar Labs、Lightmatter。
- **权重谨慎：只说“液冷概念”的公司。** 需要验证客户、功率密度、可靠性、交付节奏和毛利率。

### 后续验证点

1. TSMC direct-to-silicon micropillar cooling 是否进入客户评估或 CoWoS roadmap。
2. Microsoft GH200 microfluidic cooling 是否扩展到 Blackwell/Rubin 或 Azure 数据中心。
3. Samsung HBM4E interposer 和 HCB thermal 数据是否对应真实客户量产。
4. Marvell OMIB / Photonic Fabric 是否拿到 XPU 客户和量产封装路径。
5. UH tree-like microstructure 是否有产业合作、专利授权或冷却厂商验证。

Reuters 转引 FT 2026-07-02 报道称，OpenAI 曾讨论给予美国政府 5% 股权，作为让公众分享 AI 经济收益、缓和监管压力的一部分。报道称，OpenAI 还提议其他美国 AI 公司也向类似公共投资工具贡献股权；结构可能参考 Alaska Permanent Fund。GV Wire / Reuters 报道称，按 OpenAI 2026-03 估值 8520 亿美元计算，5% 股权约 426 亿美元。

报道同时指出，该提议仍属早期概念，可能需要国会批准。背景是美国政府近期开启更主动的 AI 工业政策：GPT-5.6 受限预览、Anthropic Fable/Mythos 一度被限制、Intel 和 MP Materials 等关键供应链公司中出现政府股权安排。

### 新增 delta 和去重

2026-07-02 日报把 OpenAI 政府股权讨论放在“未纳入或只作背景”的主题中，原因是产业链映射还不够清晰。今天补充保留为背景跟踪，因为 Reuters 转引和更多细节让投资含义更明确：政府股权可能成为模型公司 IPO 前降低监管不确定性的一种交易结构。

### 产业链影响

第一，frontier lab 的融资和监管开始融合。OpenAI、Anthropic 这类公司都需要持续融资建设算力、采购芯片、签长期云合同并准备 IPO。监管方则关心 cyber capability、就业冲击、国家安全和公众收益。股权提议把这些目标放进一张谈判桌。

第二，如果政府持股成为模板，AI 公司估值会同时获得政策背书和政治折价。背书来自监管不确定性下降、政府采购和基础设施支持；折价来自治理复杂、外国市场复制要求、股东稀释和政治周期变化。

第三，其他国家可能提出类似要求。Forrester 分析师在 Reuters 转引报道中提到，其他司法辖区可能把类似安排作为市场准入条件。这会影响美国模型公司在欧洲、亚太、中东和中国相关市场的数据主权与中立性假设。

### 投资映射

- **权重中性偏上：前沿模型公司 IPO 生态。** 政府股权若推进，OpenAI/Anthropic 上市窗口、披露规则和估值锚会变化。
- **权重上调：合规和模型安全。** 评测、red-team、cyber benchmark、governance、model release workflow 预算会增加。
- **权重谨慎：将股权提议视作确定政策。** 该方案仍处概念阶段，需国会、企业和投资者多方接受。
- **权重谨慎：国际收入。** 若其他国家要求类似 public stake 或本地数据主权安排，模型公司全球毛利率和市场准入会更复杂。

### 后续验证点

1. OpenAI 是否正式回应 5% 股权结构。
2. Anthropic、Google、Meta、xAI 是否接受类似公共股权或数字红利方案。
3. 美国国会是否提出相关立法。
4. GPT-5.6 和 Fable/Mythos 的放行框架是否与股权/公共收益讨论产生交叉。
5. IPO 文件是否披露政府股权、监管审查和模型发布限制。

## 今天的产业链权重变化

### 权重上调

1. **模型公司自研芯片和 ASIC 设计链条。** OpenAI/Broadcom 后，Anthropic/Samsung 传闻把自研芯片扩散到更多 frontier lab。Broadcom、Marvell、Samsung Foundry、TSMC、ASIC design service、EDA/IP、HBM 和先进封装继续受益。
2. **NVIDIA 平台金融化能力。** Revenue-sharing 和 credit-support 让 NVIDIA 不只赚硬件收入，还能参与 AI cloud 使用收入。该结构提高平台粘性，也带来客户信用和循环融资争议。
3. **已许可、已上电、高透明度数据中心。** 地方政治阻力越大，真实可交付 MW 越稀缺。RFS MW、客户长约、电力合同和社区协议会获得更高估值权重。
4. **API 安全、模型访问控制和 agent governance。** Anthropic 打击中国绕道访问，Claude Code 禁用传闻，说明模型服务正在进入 KYC、跨境访问、蒸馏防护和 agent 审计阶段。
5. **封装热管理、HBM interposer 和 microfluidic cooling。** ECTC 2026 把 AI 瓶颈直接画到 HBM4E、HCB、CoWoS-R、direct-to-silicon 和光互联。

### 权重谨慎

1. **只靠远期数据中心 pipeline 的公司。** 召回、禁令、税收、电价和项目取消会推迟现金流。
2. **未经公开 benchmark 验证的模型追赶叙事。** Meta Watermelon 需要公开模型、第三方评测和产品落地确认。
3. **缺少客户和良率验证的自研芯片故事。** Anthropic/Samsung 当前仍是早期洽谈，不能直接折算量产订单。
4. **高度依赖海外单一 frontier model 的企业流程。** 跨境访问和政策限制会让开发工作流中断。
5. **只讲概念的液冷/硅光标的。** AI 封装和冷却需要可靠性、量产、客户和服务能力验证。

## 新闻口播稿

今天 AI 产业链最值得看的变化，是模型公司、GPU 平台和数据中心地方政治同时进入新阶段。

第一条是 Anthropic 和 Samsung。Claude 的增长太快，推理成本和芯片供应会越来越影响毛利率。OpenAI 已经用 Broadcom 做 Jalapeño，Anthropic 现在也被曝和 Samsung 接触，探索自研 AI 芯片。这个项目还早，规格和时间表都没定，但方向很重要：模型公司正在把竞争推进到 2nm 代工、HBM、先进封装和系统软件栈。NVIDIA 仍然强，但 GPU 之外的 ASIC 和封装利润池正在扩大。

第二条是 NVIDIA。公司把 Sharon AI 和 Firmus 这种 neocloud 合作正式写成 revenue-sharing 和 credit-support model。它卖 GPU，也参与云收入分成。这个模型解决 neocloud 融资难的问题，也让 NVIDIA 的收入更像和 token 用量挂钩的平台收入。风险也明显：客户信用、循环融资和 GPU 折旧都要重新审视。

第三条是数据中心地方反弹。美国居民已经不只是在听证会上抱怨，开始推动召回选举、moratorium 和项目取消。QTS 在 Virginia 的项目被报道终止，Data Center Watch 跟踪到数百亿美元项目被延迟或阻断。AI 数据中心估值以后不能只看多少 MW 和多少 GPU，还要看电费谁付、水从哪里来、社区是否接受、地方官员敢不敢投票。

第四条是 Meta Watermelon。Alexandr Wang 据称告诉员工，Meta 新模型追平 GPT-5.5 的关键 benchmark。没有公开 benchmark 前不能直接下结论，但这至少说明 Meta 高额 CapEx 仍有模型追赶逻辑。对产业链来说，Meta 仍会继续消耗大量 GPU、网络、HBM、电力和数据中心资源。

第五条是 Anthropic 打击中国绕道访问 Claude。模型 API 正在进入身份识别、跨境合规、蒸馏防护和 agent 审计阶段。中国公司如果禁用 Claude Code，会加速本土 coding agent 和私有化模型工具替代。

最后是封装和冷却。ECTC 2026 的信号很清楚：HBM4E、hybrid bonding、direct-to-silicon microfluidic cooling 和光互联都在向工程验证推进。AI 基建瓶颈已经从机柜、园区和电网继续下沉到封装内部。未来真正值钱的环节，会越来越多出现在 HBM、interposer、热阻、电源完整性、光互联和封装可靠性里。
