## 优先候选研究包

### 10.1 AMD—Anthropic：第二条具名 Helios 大客户路线

- 时间线：7/20 Microsoft 公布 Azure Helios 路线；7/22 Anthropic 与 AMD 公布最高2GW、2027H1首个1GW；同日二手报道补充最高50亿美元、与部署里程碑绑定的 AMD 投资。
- 新洞见：hyperscaler 产品支持已经得到 frontier model company 的独立大规模需求验证。首个1GW和时间表提高可执行性，股权与部署挂钩也显示 AMD 愿意承担客户集中和生态迁移成本。
- 支持证据：AMD 原文列出 MI455X、Venice、Pensando、ROCm 和时间；Anthropic 为具名客户。
- 反证与边界：“最高2GW”是上限；最低采购、站点、功耗、价格、取消权和投产验收未知。50亿美元条款来自二手报道。
- 最值得展开：与 Microsoft 的区别、股权换需求机制、ROCm 迁移成本、2027H1供应链倒排。避免重复 GPU 市占和通用 AMD 公司史。

### 10.2 Georgia 3.2GW 与 PJM 3GW：合同控制和真实扰动

- Georgia 协议用25年期限、全额基础设施成本、担保、最高1GW中断和年度独立审计配置风险；PJM 同日事件显示故障下逾3GW负荷可在短时间内退出。
- 新洞见：大型 AI 负荷既是需要专用容量的刚性需求，也可能成为电网必须显式建模的快速可变负荷。两份材料让“可调度”从政策口号变成合同条款和事件轨迹。
- 边界：Georgia 的设计、融资和 PSC 文件未完成；PJM 称可靠性未受损，设施数量与保护设定未公开。不能把两事件写成同一系统或直接因果。
- 下游验证：中断触发权属于谁、恢复斜率、备用发电排放、费率保护、负荷注册门槛、PJM 正式事件报告。

### 10.3 Alphabet：需求、TPU 商业化与现金转换

- 核心数字：Cloud 248亿美元、+82%；营业利润约88亿美元；backlog 5,140亿美元；Q2 capex 449亿美元；全年1,950—2,050亿美元；Reuters 计算 FCF -59亿美元。
- 产品 delta：TPU 首次直接销售，公司称客户承诺使用量增加50%以上，500家 Cloud 客户年用量超过1万亿 tokens、2,000多家企业超过1,000亿 tokens。
- 争议：backlog 与 token 用量不能直接映射毛利；TPU 对外销售的硬件收入、云收入和交付节奏没有拆分；资本开支和折旧会跨期。
- 下游主线：Cloud 增长是否足以覆盖新增资本、TPU 是否改变 NVIDIA/自研芯片边界、2027 capex 与供给约束。

### 10.4 企业 agent 生产控制面、变现和组织重配

- OpenAI Presence 将权限、政策、审批、仿真、评测、人工升级与 FDE/SI 交付打包；内部英语电话支持提供75%无需人工解决和10天 handoff 降15个百分点的公司 KPI。
- ServiceNow 给出10亿美元 AI ACV 与利润率成本；Leidos 的60%自主、8万 tickets 是目标。Manulife 的3万多席位和 Agent365 治理规模真实，10亿美元价值目标属于公司测算。
- monday.com 提供组织成本与利润目标。材料支持资本和岗位重新配置，当前证据无法识别每个裁员岗位的替代机制。
- 下游机制：控制面为何需要现场交付、合同 ACV 与实际推理成本、组织重配和客户采用的时差。避免把试点、目标、ACV、已实现结果混为一组。

### 10.5 开放 agent 模型：权重效率与发布后可靠性

- Solar Open 2：250B/15B 激活、1M context，最少4张H200；SWE-bench Verified 70.4，Terminal-Bench Hard 28.3、τ3 Banking 19.6。
- Laguna S 2.1：118B/8B激活、1M；发布后24小时内修 FP8 agentic looping、恢复 thinking 配置并替换两套量化权重。
- Poolside Model Factory：公司称少于70名研究员、约35名工程师每月1万—2万实验，agents承担代码、启动、评估和数据修改。
- 新洞见：模型参数效率、量化工件可靠性和实验自动化必须一起评估。独立 benchmark、版本哈希和实验定义是下一步。

### 10.6 Agent 与推理软件栈：权限、供应链和组合故障

- OpenSkillRisk 的263个 skills/13模型测试与 Claude Code 2.1.218 的分类器裁决，分别对应上游 skill 风险和下游权限控制。
- Twin-Agent 提出 Explore/Safe 分权，可作为架构反证；仍需验证 handoff、泄漏和成本。
- TensorRT rc22 在 H200、GB300、多GPU编译和分离式KV上列出多个已知问题；PyTorch 只在主干识别 `sm_107`。新硬件支持应按 commit、RC、稳定版、生产验证分层。
- 不应重复：通用“agent有风险”和“新GPU需要软件”。重点保留默认控制变化、具体组合故障和版本边界。

### 10.7 Genesis Mission 与 Ascend：科研/训练平台的执行证据

- Genesis 增量是超过50亿美元、278个项目、15个以上机构和 Microsoft 6,000万美元投入。旧基线的17个国家实验室和统一平台只需一句。
- Ascend 论文给出 DeepSeek V4 全参数后训练、34.22% MFU 和2.93倍开放基线，形成训练软件栈证据。
- 两项都需要交付验证：Genesis 查实际拨款、项目清单和科研产出；Ascend 查集群规模、稳定时长、通信占比和独立复现。

### 10.8 企业与硬件周期：延迟、追回和收入爬坡

- IBM 正式触发旧主题：约三分之一延迟交易在 Q3 成交，全年指引仍下调。Pega 给出产品变化/tokenomics 导致采购延迟的另一解释。
- ST 首次给出 AI 数据中心收入的2026/2027阶梯；Tesla 以生产节点换来更高 capex 和负自由现金流；Intel/AMD 长约与 server DRAM 预测显示上游供给外溢。
- 下游应保留“公司解释”标签。订单、合同、收入、现金流和独立交付不能互相替代。
