## 重大新闻

### Qwen3.8-Max：预览推进到正式 API，开放权重仍在交付前

7 月 20 日已讲过 2.4T 预览和开放权重承诺。今天可重开的事实有四类：95B active 参数、正式 API 与两套兼容协议、完整价格表、权重交付周次。QwenCloud 还给出 1M context、最高 131K 输出，thinking 模式最高 262K reasoning tokens，以及 2M TPM、15K RPM 的当前配额。

### MiniMax H3：原生音视频联合生成进入可下载权重

H3 的新增价值集中在模态组合和开放交付：同一 33B dense 模型接收文字、图像、视频与音频，并生成带立体声的短视频。SGLang 文档已覆盖 NVIDIA B200/H200/H100/B300、AMD MI300X/MI355X 和 RTX 5090；B300 8 卡在 1344×768、5.17 秒、50 steps 条件下，FL2VA FP8 用时 18.03 秒、峰值约 51.9GB/GPU，2×5090 layerwise offload 同规格约 560 秒。

## 前沿人物、X与技术讨论

- **MoE 数值正确性：** FlashInfer 的 routing cancellation 可把选中专家权重降为零；vLLM 的 Kimi correction bias 也暴露初始化 dtype 不可逆。前者有端到端修复验证，后者只有 4/1,319 题变化且不显著，优先级应区分。

- **运行态资源：** TensorRT-LLM 的 workspace 估算受 prefix reuse 后总 KV 长度影响；vLLM DeepStream 的请求边界同时涉及像素、GPU codec、显存与进程池配置。
- **Agents 护栏：** Realtime 文本 delta 曾漏出输出护栏覆盖，相邻恢复路径还可能遗忘已发生工具副作用。该 delta 合并到 8 月 2 日身份、thinking 与审计状态主题，旧背景不重复。

## 优先候选研究包

### 研究包 A｜Qwen3.8-Max 正式发布

- **核心事实：** 2.4T 总参数、95B 激活、1M context、API 与价格表已上线；权重承诺下周交付。
- **能力材料：** 公司提供编码、论文复现、数学竞赛、芯片设计和多代理量化案例；benchmark 表内测试 harness 不完全同源，部分对手结果来自各自公布数字。
- **新增洞见：** 预览主题首次获得 active 参数、标准 API 单价和具体权重周次，产品与开放部署的时间差缩短。
- **反对证据：** 权重、许可证、量化、硬件需求和独立等预算评测均缺；首日用户反馈正反混杂。
- **产业关注：** 中国开放权重竞争、云 API 价格、推理硬件与量化、Anthropic/OpenAI 协议兼容、coding agent 分发。
- **最值得验证：** checkpoint hash、许可地域/商业条款、95B 激活的实际显存与吞吐、1M 长任务正确性、单位成功任务成本。
- **口播应省略：** 7 月 20 日已讲过的 2.4T 预览背景和一般性中国模型名单。

### 研究包 B｜MiniMax H3 开放音视频权重

- **核心事实：** 33B dense、四类输入、带原生立体声的视频输出；开放权重和多硬件运行文档同日出现。
- **工程分母：** BF16 单任务约 144GB；B300 8 卡 FP8 案例 18.03 秒，2×5090 offload 约 560 秒。
- **新增洞见：** 联合音视频生成开始进入可下载、可本地修改和多硬件验证阶段。
- **边界：** 768p/full attention 与商业 2K/sparse/Context-IR 分层；许可排除多个主要市场并设 $20M 收入门槛。
- **最值得验证：** 画质、同步、人物一致性、长 prompt、安全、FP8/量化损失、授权客户与推理成本。
- **口播应省略：** 未经独立评测的“领先”排名和宽泛视频生成产业史。

### 研究包 C｜推理与训练正确性四条主线

- **FlashInfer：** bias 加减在 FP32 中发生 catastrophic cancellation，选中专家权重可能为零。
- **TensorRT-LLM：** prefix reuse 后的 KV 长度扩大 Context-MLA workspace，启动估算失真；修复还需控制 KV 池缩水。
- **Unsloth：** 转义语义把格式层错误推进到训练 token 污染，246 个跨引擎用例提供可审计分母。
- **vLLM DeepStream：** 客户端请求曾能越过服务端像素、codec、显存与进程池配置。
- **共同判断：** 正确性风险集中在代数重排、运行态状态、字符串序列化和请求级控制面，单一“请求成功”指标无法覆盖。
- **最值得验证：** 受影响 release、默认路径、生产分母、历史任务重放、独立复现与稳定修复版。

### 研究包 D｜Agents Realtime 护栏与副作用

- 文本 delta 与音频 transcript 走不同事件类型，原实现只覆盖后者。
- 迟到的 guardrail 检测若不绑定 response ID，可能中断下一条响应；修复加入精确取消。
- 流式恢复前若未记录批准工具调用与输出，tripwire 后的重建状态会遗漏已经发生的外部动作。
- 本次新增机制与昨日身份、thinking 和审计数组问题形成控制面链条，材料应合并。
- 待验证 stable、历史 state 迁移、工具幂等、补偿事务、监控告警和跨语言一致性。

### 研究包 E｜DeepSeek V4 本地 runtime 与回归控制

- llama.cpp b10228 打包 DSpark/MTP，证明第三套 runtime 进入可下载状态。

### 研究包 F｜中国 AI 安全实访

- **组织信号：** 清华 hub 主动参照欧美安全机构；Concordia 数据库给出论文数量上升的代理指标。
- **正面证据：** 两周现场访问、可定位章节、公开机构与数据库交叉线索。

### 研究包 G｜World Labs R2S2R

- **边界：** 无论文、代码、成功率曲线、误差条、客户名和第三方复现。
