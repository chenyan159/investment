- **证据边界：** “计划举行”与“实际完成”分开；活动覆盖、到场人数和对具体项目的因果结果需后验确认。

### 5.2 算力基础设施开始多路径变现

- **Meta—Anthropic：** 上限 100 亿美元/两年、按月付款、双方可提前退出；早期谈判且双方未确认。若落地，Meta 会从自用 hyperscaler 进入算力转售。

- **判断变化：** 算力过剩/紧缺争论出现可验证中间层：自用设施外租、国防采购、专用芯片资产融资。三者的证据强度依次不同，禁止合并成“交易已完成”的统一结论。

### 5.3 工业与机器人商业化出现命名客户和物理节点

### 5.4 AI 内存挤占的终端代价获得市场分母

- 印度 Q2 手机出货 -10%、低价档 -45%、季度末平均价格约 +15%，提供了面向消费者的量化分母。
- 先前 IBM 与 Ericsson signal 只证明企业采购和元件价格受到 AI 硬件需求挤压。今天的数据补上换机周期、价格带和品牌结构。

## 6. 前沿人物、X与技术讨论

- **编码代理安全：** Claude Code 2.1.214 的 PowerShell、路径通配和解析器绕过是 P0；Gemini CLI 将间接注入与无限循环/配额耗尽连起来，并给默认 15 turn 上限。两者可合包，前者是权限正确性，后者是资源预算与 sandbox 默认拒绝。

- **推理与训练栈：** FlashInfer 把实验性 MoE EP 放入默认安装；vLLM draft MLA bridge 提供接近 native 的合成结果；NeMo×Diffusers 解决格式迁移；Ray 修复 router hang 和 cgroup memory pressure。
- **人物/公司评估框架：** OpenAI 的 Useful Intelligence per Dollar 把人审、重试和返工纳入成本。其 benchmark 数字属于公司选择的比较，应与 Bernstein 的预算封顶和 Glean 高成本反证同场呈现。
- **定价与可用性：** Fable 5 从临时开放改为 Max/Team Premium 长期纳入，但最多占每周限额 50%；Kimi K3 获得三项 agent 测试的独立成本/质量锚，权重仍待 7/27 前兑现。
- **归档级修补：** llama.cpp b10067 和 Codex 0.144.6 都是明确修复，洞见窄；前者解决路由表误量化，后者只是 272k context metadata 对齐。

## 9. 反向信号与争议

1. **数据中心需求可能受社会许可约束：** 全国抗议计划、Palm Beach 否决和低社区支持率共同提高许可/建设节奏风险。反方是活动尚未完成，且既有审批可能保留部分建设权。
2. **agent 自主性会放大操作错误：** Vertu 实测同时出现更主动的跨 app 行动和错误提醒/行程日期；Gemini 的澄清策略在同一测试里更慢却更准确。
3. **agent 架构复杂度未必带来生产收益：** Rippling 放弃 multi-agent；Factory 强调持续增加规则/validator；ToyotaGPT 则给出规模化正面案例。三者的产品、任务和评测不同，适合呈现条件差异。
4. **token 成本可能先触发预算治理：** Bernstein 汇总预算耗尽、封顶和降用，与 OpenAI scorecard 的 outcome-per-dollar 框架形成可检验对照；二手材料需公司确认。
5. **资本事件仍有完成风险：** Databricks 是 term sheet，Valar/Meta/SpaceX 仍在谈。金额、估值和收入不能当作已到账或已签合同。
6. **厂商 benchmark 需复现：** Siemens、FlashInfer、Sunday、Nemotron、Joyson 的数字来源、任务和运行环境不同，综合评分没有把公司主张当作独立事实。

## 10. 优先候选研究包

### 10.1 全国数据中心抗议：社会许可从项目阻力进入组织基础设施

- **核心事实/时间线：** 6 月 Reuters/Ipsos 建立低支持率基线；7/15 Palm Beach 5—1 拒绝 Project Tango 扩展；7/18 HumansFirst 计划在至少 125 处行动。
- **为什么是新洞见：** 已播 NY 暂停是单州监管动作。新增全国组织者、场次数和跨党派低支持率，改变风险的范围与可复制性。
- **支持/反方：** 125处计划和州分布支持“协调化”；活动尚未完成、既有项目权利可能继续，削弱对实际建设量的即时推断。
- **最值得展开：** 项目融资与许可概率如何吸收社会许可；哪些政策结果会影响 MW、COD 和资本成本。
- **待核：** 实际到场、对应项目、持续组织、州/县决定、诉讼或费率条款。
- **不应重复：** NY 50MW 门槛、电费/水/噪音的一般背景只需一句基线。

### 10.2 Siemens Eigen：中国工业工程 agent 首次给出商用与客户 KPI 组合

- **核心事实：** 中国 GA；19国/100+企业；可规划、执行、验证 PLC/HMI/驱动配置；中科摩通披露开发和调试各 -30%。
- **新增机制：** 工程 agent 的价值链从代码建议扩到设备配置、现场调试和验证；同日合同包提供泵站节能和具身工厂入口。
- **边界：** 2—5倍、效率+50%、质量+80%及客户 KPI 均为公司自报，未给任务分母、失败率和对照。
- **最值得展开：** EDA/工业自动化 agent 的收费单位、工程师审批、错误代价、与 Siemens 软件/控制器的绑定。
- **待核/重开：** 付费客户、续费、事故、独立 benchmark、泵站实际节能和金麦特/钛虎投产。
- **不应重复：** 通用“工业 AI 提效”口号和 Siemens 产品线清单。

### 10.3 编码代理安全：权限正确性与资源预算同时收紧

- **核心事实：** Claude 2.1.214 修补 PowerShell、路径通配、超长命令和 parser mismatch；Gemini CLI 明示间接注入可触发无限 ReAct/配额 DoS，并设 15 turn 默认上限。
- **今日 delta：** 7/15 已讲 GPT-5.6 删除风险，7/17 有 2.1.212 循环/symlink 修补。今天新增具体绕过类和 fail-closed 设计，满足重开条件。
- **支持/反方：** 正式 release/PR 可核；没有 CVE、事故率、稳定版 Gemini 或跨平台验证。
- **最值得展开：** 一个审批系统如何同时面对语义欺骗、shell 解析分歧、路径作用域、远程确认和成本耗尽。
- **待核：** 默认权限、企业策略、利用样本、Win/Linux测试、长命令误报和稳定版落地。
- **不应重复：** agent 可以删文件、需要 sandbox 等已播常识。

### 10.4 AI 内存挤占：从元件通胀到大众手机需求破坏

- **核心事实：** 印度 Q2 -10%、低于₹15,000档 -45%、均价约 +15%；换机周期拉长、部分机型价格大幅上调。
- **新增机制：** HBM/服务器内存优先配置压缩消费内存供给，价格上涨在最薄利润的低端档形成出货弹性。
- **支持/反方：** Counterpoint 直接 tracker 支持出货/价格；宏观、通胀、产品节奏和渠道库存也是原因。
- **最值得展开：** AI 资本开支的赢家/受损者如何通过 DRAM/NAND 产能转换、品牌议价和价格带传导。
- **待核：** 单机内存 BOM、各品牌库存和配置降级、Samsung/SK Hynix/Micron 产能、2027恢复时间。
- **不应重复：** HBM 高毛利和内存短缺的一般背景。

### 10.5 General Compute：推理芯片成为可抵押资产

- **核心事实：** Upper90 贷款4亿美元；SambaNova SN50 作为采购和抵押核心；交易方称可能是首例；公司称16×推理速度且无需昂贵水冷。
- **为什么新：** CoreWeave 路径证明 GPU 可融资。今天的资产从标准 GPU 扩展到专用推理芯片，残值、软件生态和客户锁定风险不同。
- **支持/反方：** 交易方和创始人具名访谈；贷款文件、LTV、芯片数量、利率与客户合同未公开。
- **最值得展开：** 非 NVIDIA 芯片的二手流动性、抵押折扣、推理成本优势能否覆盖软件迁移和客户集中。
- **待核/触发：** facility close、芯片交付、客户收入、违约保护、独立 TCO 与利用率。
- **不应重复：** neocloud 定义和 GPU 供不应求历史。

### 10.6 算力外租：Meta 与 SpaceX 的基础设施可能变成云产品

- **核心事实：** Meta/Anthropic潜在100亿美元两年、月付可退出；SpaceX/DoD潜在数十亿美元，且公司内部讨论低价竞争 neocloud。
- **新增判断：** 大型自用设施的可选价值从“备用/过剩”变成可销售容量；客户横跨 frontier lab、政府和开发者。
- **证据边界：** 两项均未签；SpaceX为WSJ匿名→Reuters转述，Meta仅单一知情人士。
- **最值得展开：** 容量能否从同一机房/网络/安全域交付给外部客户；合同退出权如何影响收入确定性和项目融资。
- **待核：** MW、芯片、机房、安全认证、定价、合同、双方确认或谈判终止。
- **不应重复：** Meta/SpaceX 已有基础设施规模和 CoreWeave 商业模式的长背景。

### 10.7 MHI 冷却：10MW 实物发运让认证成为下一关

- **核心事实：** 测试机已发运、7月预计抵港、MCP做UL认证、闭环和free-cooling设计、NVIDIA DSX适配。
- **新增判断：** 3月的北美引入意向已进入实物和合规节点，冷却供应链可观察信号从计划变成到港/认证/订单。
- **边界：** 没有商业客户、设备价格、实际PUE/WUE或认证结果。
- **最值得展开：** 10MW级模块化冷却如何减少现场集成，800VDC与液冷参考架构如何共同影响建设周期。
- **待核/触发：** 到港、UL、首单、MW、DSX参考设计、PUE/WUE和800VDC联调。
- **不应重复：** 液冷需求增长和高密度机柜的一般背景。

### 10.8 机器人真实化：Agility、Sunday、KEENON 的证据层级

- **Agility：** 命名部署、里程碑订单、训练中心和客户管线；最接近商业层。
- **Sunday：** 778/785陌生家庭折衣；场景窄、公司自评，最接近泛化实验层。
- **KEENON：** WAIC无遥操酒店洗衣；展会演示，无持续吞吐和接管分母。
- **新增判断：** 三条不能用同一“已商业化”标签。分别跟踪交付/订单、跨家庭独立复现、真实酒店运营。
- **待核：** 交付数/单价/事故率、ACT-2 beta长尾、KEENON接管率和单位经济。
- **不应重复：** 人形机器人 TAM、劳动力短缺和客户名单泛讲。

### 10.9 Vertu 实测与 Fable 5：agent 使用权和可靠性分开看

- **Vertu：** Hermes 更愿意行动，日期和提醒错误；本地文件上下文会丢失；测试中途服务端修复。
- **Fable 5：** 高阶订阅获得长期访问，配额上限50%；标准计划仍依赖 credits。
- **新增判断：** 产品价值同时受模型/agent正确性、澄清机制、订阅层和容量限制决定。
- **边界：** Vertu为单设备数日测试；Fable配额的真实拥塞、API价和企业使用量未知。
- **待核：** 错误复测、关键动作审批、隐私/数据处理、限额兑现和降级策略。
- **不应重复：** 模型能力榜单和手机硬件规格。

### 10.10 企业 agent 生产经济：正面规模、架构反转与预算封顶并存

- **正面证据：** ToyotaGPT称50+生产agents、交付周期大降；Abridge称250家医疗系统和更快评测发布。
- **反向证据：** Rippling放弃multi-agent；Factory持续增加validator；Bernstein汇总预算耗尽、封顶、降用与低ROI。
- **为什么新：** 既有 Glean 案例给出高覆盖和高成本。今天增加不同企业的组织、架构和预算响应，显示生产化路径存在多解。
- **最值得展开：** task类型、风险等级、eval质量、人工规则和token成本怎样决定 flat/multi-agent、模型和harness。
- **待核：** 命名客户确认、A/B、成本、成功率、事故、医生override和报告原文。
- **不应重复：** agent会提高效率或需要人审的抽象结论。

### 10.11 Dreams 与 MCP Tunnels：Anthropic 把记忆和连接做成平台控制面

- **核心事实：** Dreams 异步整合 transcript+memory、写新store并报告token；Tunnels管理CA、connector token、hostname和归档。
- **新增机制：** 一个处理长期状态，一个处理企业私网可达性；两者都把agent运行基础设施变成可计量、可生命周期管理的API对象。
- **边界：** 仅 SDK/research preview；未见产品公告、访问证明、定价、SLA和客户。
- **最值得展开：** memory poisoning、数据留存、CA轮换、旧连接和多租户审计。
- **待核/触发：** GA、定价、权限模型、日志、延迟、隔离和生产客户。
- **不应重复：** MCP定义、向量库记忆和企业私网的一般介绍。

### 10.12 推理栈：FlashInfer 与 vLLM 在兼容性和专用化之间找平衡

- **FlashInfer：** 实验性MoE EP进入默认安装，覆盖dispatch/GEMM/combine与两种transport；B300、SM12x能力扩展。
- **vLLM：** generic backend已接近native；MLA draft在合成负载达native约91.8%，KV concurrency大增。
