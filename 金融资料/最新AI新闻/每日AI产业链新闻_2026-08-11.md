## 8. 反向信号与争议

- **5000 亿美元融资口径**：长期动员目标不能按已到账或已承诺资本统计。独立承销可降低 NVIDIA 直接信用暴露，也会扩大 GPU 残值、客户承购和关联融资的共同风险。

- **Riemann 结果边界**：外部专家短审提高可信度，完整公开同行评审仍未发生；67.2% 也不等于证明 RH。
- **开放与安全的政策冲突**：Zuckerberg 的分布式制衡与 Hassabis 的发布前测试在时延、监督主体和开放范围上分歧明确。双方都没有交付可比较的法律约束与阈值。
- **稳定版语义风险**：vLLM 0.27.0 个案说明 stable release 可通过 import/health 测试仍损坏输出；当前证据只有一套生产配置。
- **指标选择偏差**：kernel hill-climb 会自然产生 benchmark fingerprint；SGLang prefill TFLOPS 漏 prefix 会制造错误效率趋势。性能数字需同时给 held-out 与计算模型。
- **应用经营数字**：Neural Frames、Turo 和 NdotLight 均以公司或供应商口径为主；没有审计收入、对照或客户侧确认时，不升级为行业平均。

5. CoT 可监控性的性能代价和适用范围。

**证据边界**：均为高身份一手观点，未形成法规、章程或可审计产品。下游避免把政策建议写成已经执行。

### 研究包 D｜reasoning envelope 与 skill chain：上下文外状态的组合安全

**reasoning blob**：攻击依赖历史 API 对 opaque block 的绑定不足；公开仓库出现凭证与 PII。作者称厂商已缓解，当前主攻击不可复现。验证重点是历史 token 撤销、跨用户/模型/会话/区域绑定、日志清理与披露时间线。

**ColluSkill**：攻击把意图拆成 individually benign skills，通过 artifact 和 execution handoff 恢复。ChainGuard 只把作者自报 ASR 降到 22.5%，并未归零。验证重点是 scanner 清单、代码、安装图、运行时权限、误报和跨产品独立复现。

共同机制是安全判断需要覆盖对象关系与生命周期。不要重复 prompt injection 通用背景。

### 研究包 E｜vLLM：stable、候选守恒和 batch metadata

| 子信号 | 失效面 | 可见症状 | 当前证据 |
|---|---|---|---|
| 0.27.0 Kimi K3 | 正式版本组合语义 | 乱码，health 正常 | 单生产配置，回滚恢复 |
| persistent_topk | 稀疏候选守恒 | 部分行漏真实 Top-K | 真实张量抽检，未有 patch |
| mixed logprobs | batch 请求隔离 | 旁请求 -inf/pad:-9999 | 两请求复现，PR open |

**验证清单**：模型/精度/backend 矩阵；语义 golden tests；candidate overflow counter；per-request metadata assertions；stable tag 前后同硬件回归；历史 RL/eval 数据是否受污染。

### 研究包 F｜attention 与 GPU dispatch：空行、极端 logits 和架构门槛

FlashInfer 的有限 sentinel 在三 API 产生错误 0、LSE 或 NaN；TensorRT-LLM 在全 masked row 把 exp(-FLT_MAX-(-FLT_MAX)) 计算为 1；SGLang 把 sm103 按 major gate 送入 SM100 kernel，引出 Xid/hang。共同验证需要：

- 明确定义 empty/all-masked row 的 output 与 LSE；
- 极端负 logits 不使用有限值模拟负无穷；
- dispatch gate 同时检查 major/minor、cluster/ISA 与已验证硬件；
- 单 rank kernel failure 能终止其他 collective；
- correctness tests 覆盖 sequence-length 分带和低频行。

### 研究包 G｜agent 控制面：release、schema、secret parameter 与 URL

**OpenAI Agents 0.20.0**：durable input、审批绑定、mount credential 合同已发布；strict schema 的 accept-set 反转和递归崩溃也在同日修复。升级需检查 MCP transport breaking change。

**SEP-3221**：secureArguments 由 host 注入，目标是让 project/tenant 参数不进入模型上下文。草案尚未采纳，仍需完整性、审计和服务器兼容设计。

**Google ADK**：JS 已合并 path encoding/origin hardening，Python 修复 open；Go 的 MaxLLMCalls=100 没有 enforcement，thought-only 窄修覆盖不了 tool loop。共同判断是声明、schema 与 budget 字段都要追踪到执行路径。

### 研究包 H｜agentic hardware search 与 benchmark 真实性

ArchAgent v2 在 DPC4 held-out 上只比 BertiGO 高 0.3%，优势小却提供了可实现性反馈和逐级冻结方法；kernel fingerprinting 显示 30% 的 in-distribution wins 不迁移；SGLang TFLOPS 漏 prefix 可造成 33×—129× FLOP 低估。

**最值得展开**：搜索系统需要隐藏评测、语义正确性、资源成本和计算模型四重约束。模型生成 12,000 候选的一半失败/无增益，也是自动研究真实成本分母。

### 研究包 I｜训练与分布式状态：trajectory、allocator、recurrent state

- SGLang diffusion rollout 将 output0 trajectory 复制给所有 samples，使 GRPO advantage 抵消；
- paged KV 在容量检查前 launch，OOM 路径先读取逻辑 free-list 外 page id；
- TensorRT-LLM auto route 可选不会搬 KDA recurrent state 的 C++ 通道。

三条均要求在合并、分配和跨节点传输时保存对象身份与状态类型。当前分别处于 draft/open PR，不能表述为稳定版已修。验证应包括 checkpoint 重训、allocator failure injection、跨 route 同输出和稳定版本回补。

### 研究包 J｜应用与 physical AI：付费单位、工作流和交易执行

Neural Frames 给出 12 人/约 500 万美元 run-rate 的公司主张，真实产品价值集中在长视频编排；Trimble 首次把 agent 套餐明确为 10 个工作小时；NdotLight 把 3D 资产推进为带物理属性的仿真数据；Archer—Boeing 增补全股票与 Insitu 现金流试验台。

这些信号可说明应用层和 physical AI 的交付单位正在具体化。收入、毛利、客户确认、任务成功率、股份数量和监管节点仍是下一轮验证重点。
