## 新闻口播稿

今天是2026年6月17日，今天有十条AI产业链新闻。最值得先听的主线很清楚：AI基础设施的竞争，正在从“谁有GPU”扩展到“谁有光互联、谁能本地制造、谁能把MoE训练跑稳、谁能把企业agent的成本和权限管住”。

第一条，先看今天综合评分最高、投资链条最清楚的一条：Coherent 和 NVIDIA 在美国 Texas Sherman 的 6 英寸磷化铟工厂扩建开工。Coherent 同时宣布，已经签署最高 5000 万美元 CHIPS Act 直接资助意向书，用于扩建这座 6 英寸 InP 半导体制造设施。NVIDIA 也把这件事放在 AI optical backbone 的位置上讲，重点落在 AI 集群扩大后的数据移动成本：它正在成为新的成本中心。

为什么一个磷化铟工厂值得排在今天最前面？因为大模型集群的形态变了。Vera Rubin Ultra NVL576 这类系统，把多个 NVLink rack 连成一个大域，跨机柜、跨走廊、甚至跨数据中心传数据。铜线在短距离内便宜好用，但距离拉长后，需要 retimer 和信号调理，电力预算会被耗在传输上。光互联先付一次电光转换成本，后面的距离成本低得多。AI 数据中心每一瓦电都要争给 GPU，网络传输少耗一点，token 成本就会跟着变。

Coherent 的价值就在这里。它做的 InP 激光器、光组件、收发器、pluggable optical module、external laser source，正好卡在 NVIDIA AI networking 的上游。过去很多人看光模块，习惯盯 800G、1.6T、交换机端口、模块 ASP。今天这条新闻提醒我们，还要往更上游看：有没有稳定的 InP 外延和激光源，有没有高良率的 6 英寸产线，有没有美国本土制造，有没有来自平台公司的长期采购承诺。

这对投资链条很直接。美国侧，Coherent、Lumentum、光模块、激光器、硅光、CPO、交换机、测试设备、连接器都会被重新估值。中国侧，光芯片、EML、薄膜铌酸锂、硅光、CPO封装、光模块液冷 cage、高速测试、InP 和化合物半导体设备也要提高权重。更远一点看，光互联还会影响数据中心的电力模型。未来客户采购 AI cloud，除了 GPU 小时价格，还会看网络架构能不能让大规模训练和推理少掉通信损耗。

后面要跟踪三个细节。第一，CHIPS 意向书能不能转成正式拨款。第二，NVIDIA 20 亿美元承诺最终落到哪些产品，激光器、外置激光源、CPO 交换侧光引擎还是传统可插拔模块。第三，CPO 和外置激光在 Rubin 后续平台上的真实出货节奏。如果这三个问题给出明确答案，光互联这条线会从“概念受益”进一步进入订单验证。

第二条，Microsoft Copilot Cowork 改成按算力计费，并考虑在 Azure 上托管 DeepSeek V4 或其他开源模型作为低成本选项。这条新闻看起来是软件定价，实际是在告诉市场：企业agent的商业模式开始正视 token 成本了。

普通聊天机器人可以按座席收费，因为用户问一句，模型答一句，成本大致可控。agent 完全不同。一个 agent 接到任务以后，会反复调用模型、工具、浏览器、代码执行、数据库、文档检索和上下文压缩。一次任务可能拆出几十步，用户看见的是“帮我完成这个工作”，后台消耗的是一串持续运行的模型调用。Axios 报道里，Microsoft 直接说，测试显示 Copilot Cowork 很难用无限使用套餐提供，因为有用户一周跑几百个任务，成本会非常高。

这个信号很重要。第一，企业 AI 软件的毛利率以后不能只看订阅收入，要看扣掉推理成本后的真实毛利。第二，模型路由会成为标配。高价值、强推理、强安全任务用 OpenAI 或 Anthropic 这类前沿模型；大量重复、格式化、低风险的流程任务，用低成本开源模型、本地模型或小模型。第三，企业客户会要求看得见成本。谁在烧 token，哪个任务超预算，哪个 agent 调用工具过多，哪个模型足够便宜又足够稳，这些都会进入采购和审计。

DeepSeek 出现在 Microsoft 候选列表里，也有产业含义。它说明开源模型的竞争力既体现在模型榜单，也体现在企业成本结构。Microsoft 的缓冲方式是把模型完全托管在 Azure 内，客户数据留在 Microsoft 云中，并套上 Azure 的安全、合规和数据驻留控制。地缘政治争议仍会存在，但企业会接受一件事：如果高端模型成本太高，低成本模型就会被包装成可选、可控、可审计的企业服务。

投资上，受益的方向包括模型路由器、AI gateway、token cost observability、agent sandbox、权限审计、低成本推理芯片、开源模型托管、企业数据连接器。受压的方向是只卖“无限 agent 套餐”的软件公司，因为用户一旦真用起来，推理成本会快速侵蚀毛利。后续最关键的是 Copilot Cowork 的正式价格页、低成本模型最终选择、客户是否接受 DeepSeek 这类选项，以及 usage-based pricing 会不会扩展到 Microsoft 365 Copilot 更大的产品面。

第三条，Bull 和 Foxconn 宣布在欧洲生产基于 NVIDIA Vera Rubin NVL72 的关键 AI 系统，流程是先在 Foxconn 捷克工厂制造和初测，再到 Bull 法国 Angers 工厂完成组装、集成和完整验证，并以 Bull 品牌商业化。目标客户包括欧洲和欧洲以外的 neo-cloud provider、cloud service provider，以及新一代 AI factory。

这条新闻和前两天写过的 Schneider Electric + Foxconn 要放在一起看。Schneider/Foxconn 解决的是电力、冷却、AI rack 和模块化交付包；Bull/Foxconn 解决的是欧洲本土 AI 服务器制造、系统集成、验证和软件层。Foxconn 站在中间，把全球 EMS 能力同时接到电力热管理、服务器制造、NVIDIA Rubin 平台和欧洲主权 AI。

欧洲主权 AI 过去常讲三件事：模型要本土，数据要留在本土，云服务要受本土监管。今天这条新闻把第四层补上：硬件系统也要尽量在本土制造和验证。对金融、政府、医疗、国防、工业客户来说，只把数据放在欧洲还不够，供应链、维保、系统验证、软件运维也要能接受审计。Bull/Foxconn 的价值就体现在这个位置。

产业链可以拆得很细。计算层是 Vera Rubin NVL72，牵涉 CPU、GPU、NVLink、内存、DPU、网络、存储和液冷。制造层是捷克生产、法国集成，牵涉机柜、线束、电源、冷却、测试、运输、备件和现场服务。软件层是 Bull 宣称的 AI software layer、embedded AI use cases 和 data science 能力。客户层则是欧洲云、欧洲主权 AI 项目，以及需要区域内交付的企业客户。

投资含义是，欧洲 AI 基础设施不能只看数据中心土地和电力，还要看服务器系统集成商、EMS、液冷、电力设备、测试验证、合规运维和本土云。Foxconn 的 AI server 角色继续上升，Bull 则把欧洲 HPC 和 AI 品牌资产接到 NVIDIA 最新平台。后续要看首批客户是谁、出货时间、单机柜功耗、液冷方案、欧洲本土零部件比例，以及是否接入法国或欧盟更大的 sovereign AI 资金。

第四条，MLPerf Training v6.0 发布，把 DeepSeek-V3 和 GPT-OSS 20B 加入标准训练基准。DeepSeek-V3 是 6710 亿总参数、每 token 激活 370 亿参数的大型 MoE benchmark；GPT-OSS 20B 是 210 亿总参数、每 token 激活 36 亿参数，给资源较小的组织一个入口。本轮有 95 个独特系统、13 种硬件加速器、19 种 host processor，60% 是多节点系统，提交方包括 AMD、Azure、CoreWeave、Dell、Google、HPE、Lambda、Nebius、Oracle、NVIDIA、Supermicro、Vultr 等。

这件事的意义在于，MoE 训练从各家自说自话，进入公开可比的标准考场。MoE 模型的难点覆盖矩阵乘法、token routing、expert load balance、all-to-all communication、网络拥塞、checkpoint 和长时间稳定性。DeepSeek-V3 被纳入 MLPerf，相当于把开源权重大模型、稀疏激活和生产级训练效率放到一个全球厂商都能提交结果的框架里。

CoreWeave 的结果尤其抢眼。公开材料显示，CoreWeave 在 NVIDIA GB300 NVL72 上训练 DeepSeek-V3，8192 个 GB300 GPU 达到目标质量只用 2.02 分钟；2048、4096、8192 GPU 对应时间分别是 5.54、3.09、2.02 分钟，扩展性非常强。NVIDIA 也披露，GB300 NVL72 在同规模下相比 GB200 NVL72 有最高 1.6 倍提升，来自 NVFP4、更高计算密度、更大内存和更高功率上限。

对客户来说，AI 云的差异化开始从“有多少张卡”进入“同样规模能不能把 MoE 稳定跑满”。CoreWeave、Azure、Nebius、Lambda、Oracle 这些 AI cloud 和 hyperscaler，未来面对大客户时会用 benchmark、SLA、网络、存储、调度、故障恢复和真实 workload 复现能力说话。对供应链来说，GB300、NVLink、Spectrum-X Ethernet、InfiniBand、存储、冷却、RAS、CUDA 和 NeMo 软件优化都会一起决定有效吞吐。

需要提醒一句，MLPerf 是标准 workload，不等同于真实 frontier training 的全流程。真实训练会有数据清洗、长期 checkpoint、多周运行、试错、故障恢复和客户隔离。但 MLPerf 的价值在于提供一块可比地板。客户先看谁能跑过标准题，再谈真实生产任务。投资者也可以用它筛选 AI cloud、服务器、网络和软件栈的真实能力。

第五条，HPE AI Factory with NVIDIA 扩展到 agent 时代。HPE Private Cloud AI 增加 NVIDIA Vera CPU、NVIDIA Agent Toolkit、NVIDIA Confidential Computing、HPE Zerto 回滚能力，以及更完整的 NVIDIA full-stack integration。HPE ProLiant Compute DL394 Gen12 搭载 Vera CPU，计划 2027 年随 HPE Private Cloud AI 提供。HPE 还会提供 Vera Rubin NVL72 rack-scale system，以及基于 NVIDIA HGX Rubin NVL8 的 HPE Compute XD700。

这条新闻的核心在控制面。NVIDIA Agent Toolkit 包括 Nemotron open models、OpenShell secure runtime、NemoClaw blueprints，用来监控 agent 行为、执行治理策略、运行长周期 multi-agent systems。HPE Private Cloud AI 增加本地 agent registration，让客户在 agent 运行前审批模型、skills 和 tools，并绑定集中治理策略。HPE Zerto 则加入识别 rogue agent actions，并通过 continuous data protection 回滚到 clean state 的能力。

企业 agent 进入生产以后，客户买的是可治理、可审计、可回滚的生产系统。金融、医疗、制造、政府客户会问：这个 agent 能调用哪些工具，谁批准的，访问了哪些数据，执行中有没有越权，出错后能不能回滚，敏感数据在执行时有没有加密，日志能不能审计。HPE/NVIDIA 给出的组合，就是 CPU、DPU、存储治理、机密计算、模型网关、agent registry、回滚和私有部署。

这和昨天写过的 Arcade.dev 形成呼应。Arcade 是 agent action layer 和授权审计，HPE/NVIDIA 是私有 AI factory 的底座。大型企业会把 agent 生产化拆成两个预算：一个是模型和应用，一个是治理、审计、回滚、安全、数据准备和基础设施。受益方向包括 HPE、NVIDIA、DPU、企业私有云、存储治理、备份恢复、IAM/GRC、agent gateway 和数据安全。后续要看 NYSE 这类早期客户是否进入生产、Vera CPU 的实际规格、Zerto 对 rogue agent 的检测效果，以及 agent registration 能不能接入企业现有权限体系。

第六条，TSMC 再次强调 CoWoS 仍有很长的路线空间，panel-level packaging 短期不会替代 CoWoS。Tom's Hardware 报道称，TSMC 在 European Technology Symposium 上表示，CoWoS 可以通过 wafer-level processes 扩展到 14X，并集成 58 个 large reticle-sized dies。CoPoS 作为 panel-based path 会继续推进，第一条 pilot line 预计 2026 年 6 月完成，但高量产更合理的时间点落在 2029 到 2030 年附近。

这条新闻对先进封装投资很重要。市场喜欢提前交易 CoPoS、panel-level packaging、玻璃基板和超大封装，因为 AI ASIC、GPU、HBM、chiplet 都需要更大的集成面积。但 TSMC 的表态说明，2026 到 2028 年确定性最高的主线仍然是 CoWoS、SoIC、RDL、interposer、HBM stack、ABF/BT 高端基板、检测量测、临时键合、underfill、TIM、探针卡和 HBM 测试。

面板级封装的尺寸优势真实存在，310mm 甚至更大的 panel 未来会有空间。但它面临工具成熟度、互联密度、翘曲控制、良率、热管理和生态爬坡。CoWoS 已经在量产中承载高端 AI 芯片，客户、工艺、设备和设计流程都更成熟。短期投资不宜把 CoPoS 当成 CoWoS 的替代品，更适合把它看成长周期期权。

第七条，Microsoft 据报放弃 30 亿美元 Oracle 容量租赁谈判，原因指向 FedRAMP 和安全合规缺口。这条新闻分数没有前面几条高，但信号很实用：AI compute 拿到机房和服务器以后，还要通过客户合规门槛才能卖给高要求客户。政府、金融、医疗、国防和大型企业的工作负载，需要 FedRAMP、数据驻留、隔离、审计、加密、SLA 和安全运营。容量如果缺少认证，就会在大客户面前打折。

这和 Microsoft 前一天向 AWS 借 GitHub AI 容量的新闻连在一起看。AI coding、agent、Copilot 这类负载正在把云厂容量推到紧张状态，Microsoft 会寻找外部容量。但外部容量能不能用，取决于合规等级、网络、数据边界和客户负载类型。未来 AI capacity trade 会分层：普通训练和推理是一类，政府和受监管企业是另一类。Oracle 如果能补齐公有云 FedRAMP，容量价值会明显提高；如果补不齐，部分大客户只能把它当成低合规负载的补充。

第八条，Google Cloud London 给出零售 agent 的收入指标。THG Ingenuity 和 Google Cloud 推出 AI Shopping Assistant，基于 Gemini Enterprise Agent Platform，Myprotein 早期数据披露，AI assistant 的转化率达到全站平均的 8 倍，first-time buyer conversion rate 提升 5.5 倍，average basket size 提升 22%，AOV 也有两位数提升。Deloitte 还在伦敦推出 AI Studio，计划培训 1000 名英国 AI 和 data workforce 成员获得 Gemini Enterprise 认证。

这条新闻的价值在 ROI。企业 AI 过去常用“节省时间”“提升效率”来讲故事，收入模型不好算。零售 agent 给出 CVR、AOV、first-time buyer conversion、basket size，就能进入 GMV、广告投放和毛利模型。Google Cloud 也在用咨询公司做落地渠道。Deloitte 的 AI Studio 本质上是行业方案、系统集成、数据治理、培训和 change management 的销售放大器。后续要看 Myprotein 样本量、促销因素、流量结构，以及能不能跨更多品牌复制。

第九条，上海联通在 AIIC 2026 披露 UniAI 智联申城算力网络参数：临港智算中心 160MVA 供电能力，可承载 10 万卡集群，PUE 低至 1.18，算力枢纽 400G 高速互联，并称完成跨千公里双数据中心单任务联合训练，效率超过 95%。这条新闻对国内算力网络有参考价值，因为它给出了供电容量、卡数、PUE、布线距离、400G、跨域训练效率和入算时延。

如果这些数据后续能被客户案例和复现实验验证，运营商算力网络会有一个清晰卖点：把不同城市、不同中心、不同国产卡和 GPU 资源调度成可训练、可推理、可交付的政企算力。受益方向包括运营商算力、国产 AI 芯片、液冷、储能、400G/800G 光网络、供配电、DCIM、AI cluster 调度和国产模型适配服务。需要继续看真实客户、利用率、卡型结构、价格、PUE 是设计值还是全年运行值，以及跨千公里训练的 workload 类型。
