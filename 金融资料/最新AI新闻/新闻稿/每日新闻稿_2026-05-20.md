## 新闻口播稿

各位早上好。今天 AI 产业链最值得盯住的，不是一条孤立的新模型消息，而是 Google 在 I/O 2026 上释放出的一个更大的信号：AI 正在从“帮你回答问题的聊天框”，进入“替你持续执行任务的 agent 层”。

这句话听起来像产品口号，但背后其实是产业结构的变化。过去一年，大家最容易比较的是模型参数、跑分、上下文长度、价格表。但今天 Google 的动作不是只发一个 Gemini 3.5 Flash，也不是只展示 Gemini Omni 视频生成，而是同时把 Gemini 放进搜索、Gemini App、开发者工具 Antigravity、企业 API、科研工作台、订阅体系、内容溯源和 Google Cloud 里。换句话说，Google 想证明自己不是一家只有模型的公司，而是拥有入口、工具、数据、云和算力的全栈 agent 平台。

先看第一条主线：Google 正式把这次 I/O 定义为 agentic Gemini era。Gemini App 月活已经超过 9 亿，覆盖 230 个国家和地区、70 多种语言；Search AI Mode 月活超过 10 亿；Google 每月处理的 token 规模被提到大约 3.2 quadrillion，高于一年前的 480 trillion 和两年前的 9.7 trillion。这个数字真正重要的地方，不是它有多大，而是它说明推理需求已经不是实验室流量，而是被搜索、移动端、办公、开发者和消费者产品持续拉动的基础设施流量。

Gemini 3.5 Flash 在这个体系里的角色很清楚：它不是为了在演示里慢慢思考，而是为了高频、低延迟、可调用工具的 agent 场景。Google 强调它在 coding、agent、terminal、视觉推理和长任务里有 frontier 级表现，同时输出速度约为其他 frontier models 的 4 倍。对产业链来说，速度本身就是商业模式。一个 agent 如果要监控新闻、改代码、生成报表、安排预约、跑实验、反复调用工具，它消耗的是大量小步推理。模型越快，越便宜，越能把 agent 从“偶尔试一下”变成“全天候开着”。

所以今天第一层投资含义是：AI 竞争正在从“谁有最强聊天机器人”，转向“谁能把 agent 嵌进默认工作流”。Alphabet 的优势不只是 Gemini，而是 Search、Gmail、Calendar、Android、Chrome、YouTube、Workspace、Cloud 和 TPU/GPU 混合基础设施。这里的风险也同样清楚：agent 越主动，权限、隐私、误操作、审计、成本控制就越难。未来真正有价值的，不只是模型公司，还会包括 agent sandbox、企业权限治理、可观测性、日志审计、数据隔离、安全扫描和推理成本优化。

第二条主线是开发者工具。Gemini 3.5 Flash 和 Antigravity 2.0 的组合，说明 coding agent 的竞争已经从“IDE 里帮我补一段代码”，升级到“云端替我跑一个可恢复、可隔离、可审计的开发任务”。Google 这次推出 Antigravity 2.0、Antigravity CLI、Antigravity SDK 和 Gemini API Managed Agents。开发者可以启动远程 Linux sandbox，保留文件状态，调用工具，执行代码，也可以让多个 subagent 并行处理复杂工作流。

这个变化很关键。过去的 AI 编程助手，主要价值是写得快；今天的 coding agent，价值是能不能长时间处理真实代码库。真实代码库的问题不只是语法，而是依赖安装、测试失败、权限边界、私有凭证、团队规范、CI/CD、回滚和安全审计。Google 强调 terminal sandboxing、credential masking 和 hardened Git policies，说明它知道企业客户真正害怕什么。企业不是不想要 agent，而是不想让一个 agent 带着凭证在生产环境里乱跑。

这里的竞争对手也非常明确：OpenAI 有 Codex，Anthropic 有 Claude Code，Cursor 正在把 Composer 做成更强的长任务工具，GitHub Copilot 也在向 CLI 和 agent 方向推进。Google 的不同点在于，它想把 AI Studio、Gemini API、Firebase、Cloud Run、Android Studio、Workspace 和 Antigravity 接成一条线。如果这条线跑通，开发者 agent 就不只是一个编辑器插件，而是一个 agent IDE 加 agent runtime 加 agent deployment platform。

这会怎么影响产业链？第一，推理 token 会增长，而且增长来自高频工程任务，不只是消费者聊天。第二，云端 sandbox、对象存储、日志、身份权限、代码安全和供应链安全会成为配套支出。第三，只有本地插件、没有云端执行环境的 coding assistant 会被平台型公司挤压。第四，企业会更愿意为“可控的自动化”付费，而不是为“会写代码的玩具”付费。

第三条主线是搜索。Google Search 的变化可能比模型发布更影响互联网商业。Search AI Mode 默认升级到 Gemini 3.5 Flash，并推出 information agents。用户可以创建多个 24/7 agent，让它们持续监控新闻、购物、体育、金融和网页变化，在满足条件时推送综合更新。Search 还会用 Antigravity 生成可交互的小界面，比如模拟器、dashboard、tracker 和定制化 mini app。

这意味着搜索正在从“你问一次，它答一次”，变成“你交代一个目标，它持续盯着”。过去搜索的核心指标是 query、点击率、广告展示和转化；agent 化之后，可能出现新的指标：一个任务被运行多久、监控了多少来源、触发了多少行动、最终完成了多少交易。对用户来说，这很方便；对出版商和内容站来说，这可能更痛。因为如果 Google 直接把信息整合成持续更新的面板，用户点击原网页的需求会下降。

这也是 Google 的防守和进攻同时发生。AI-native 应用如果绕开搜索、浏览器、邮箱和 YouTube，Google 的广告与分发优势会被侵蚀。Search agents 是 Google 把防守转成进攻的一步。它把搜索从网页入口，升级成信息监控入口、购物入口、本地服务入口和行动入口。未来要关注的不只是 AI Mode 有多少用户，还要看它如何变现：广告是继续按点击卖，还是按任务完成、线索、购物佣金和本地服务转化来卖。

这条线对投资的启示很直接。Alphabet 的搜索护城河不能简单用“AI 会不会替代搜索”来判断，而要看 Google 能不能把搜索变成 agent control plane。受益的可能包括结构化库存、实时价格、预订 API、本地商户数据、广告自动化和品牌安全；受压的可能是依赖自然搜索点击的低护城河内容站、低质量 SEO 和没有结构化数据接口的中间页。

第四条主线是 AI for Science。Google 发布 Gemini for Science，并在 Nature 发布 Co-Scientist 研究。这个方向短期不一定像算力链那么容易兑现收入，但它的开创性很高，因为它把 AI 从“读论文、总结文献”，推向“提出假设、组织争辩、排序验证路径”的科研工作台。

Co-Scientist 是一个多 agent 系统。它不是一个 agent 说了算，而是让不同 agent 生成、聚类、反思、排序、进化和 meta-review。听起来抽象，但可以把它想成一个永不疲惫的研究组：有人负责提出新假设，有人负责找反例，有人负责整理相似路线，有人负责打分，有人负责复盘。它不能替代湿实验，也不能保证临床成功，但它能扩大候选假设空间，把人类实验资源集中到更值得验证的方向。

今天材料里有几个很有冲击力的例子：Science Skills 连接 30 多个生命科学数据库和工具；超过 100 家机构参与验证；在肝纤维化案例中，一个候选方向在实验中阻断了 91% 的 scarring-linked response；衰老研究案例把大规模筛选数据分析从数月缩短到数日。这里必须谨慎：从一个实验信号到药物收入，中间还有漫长的验证、知识产权、法规和商业化周期。但产业意义已经足够明确：AI for Science 正在从 DeepMind 的明星论文，变成 Google Cloud 面向制药、化工、能源、国家实验室和工业优化客户的垂直产品线。

这条线的投资链条要分清短期和长期。短期，最确定的还是云端科学计算、专有数据接入、实验自动化、生命科学数据库、科研工作台和企业 R&D 软件。中期，要看 BASF、Klarna、Daiichi Sankyo、Bayer、美国国家实验室这类客户是否给出真实 ROI。长期，如果 AI 能持续压缩假设生成和早期验证周期，制药、材料、能源、电网和工业设计的研发效率会被重估。但不要把“AI 提出候选机制”直接等同于“药物商业化成功”，这是今天最需要避免的叙事陷阱。

第五条主线是 Gemini Omni 和 SynthID/C2PA。Gemini Omni Flash 主打从文本、图像、音频、视频等输入生成和编辑视频，强调物理直觉、场景连续性、角色一致性和多轮编辑。它会进入 Gemini App、Google Flow 和 YouTube Shorts。与此同时，Google 扩大 SynthID 和 C2PA Content Credentials：SynthID 已经用于超过 1000 亿张图像和视频，以及 6 万年音频水印；验证能力扩展到 Gemini、Search 和 Chrome；Google Cloud 还推出 AI Content Detection API。

这组消息应该放在一起看。视频生成越强，内容生产成本越低，广告素材、短视频、电商展示、游戏预演、影视预制和品牌营销都会更自动化。但同一件事也会放大 deepfake、版权、诈骗和品牌安全风险。所以生成媒体的下一阶段，不会只有“谁生成得更像”，还会有“谁能证明来源、谁能检测、谁能被平台和监管接受”。

这就是 SynthID 和 C2PA 的商业价值。水印不是万能的，可能被转码、压缩、截屏、再生成破坏；检测也会有误报和漏报。但如果平台、手机、相机、云 API、广告客户和监管逐步接受内容凭证，内容溯源就会变成基础设施。Google 提到 OpenAI、Kakao、ElevenLabs 会把 SynthID 技术用于更多 AI 生成内容，NVIDIA Cosmos world foundation models 也与 SynthID 水印合作。这个生态如果做起来，AI 内容检测、品牌安全、广告素材管理、媒体合规和反欺诈都会出现新支出。

第六条是 NVIDIA 和 Google Cloud。今天这条新闻的分数不如 Google I/O 主线高，但它能帮助我们校准算力判断。NVIDIA 宣布与 Google Cloud 的联合开发者社区超过 10 万人，并新增 JAX on NVIDIA GPUs、Dynamo inference optimization、开发者直播和 Blackwell VM 相关路径。这不是一个大订单新闻，但它说明一件事：即使 Google 强推 TPU 和 Gemini，Google Cloud 仍然需要 NVIDIA GPU、JAX 优化、Dynamo 推理、GKE、Cloud Run 和 Blackwell 生态来服务更广泛的开发者。

未来 AI 云不会是单一硬件宗教。大客户会在 TPU、NVIDIA GPU、自研 ASIC、CPU、on-prem、neocloud 和区域云之间组合。Google 有理由推 TPU，因为它能降低成本、掌握供应链、服务自家模型；NVIDIA 也有理由继续绑定 Google Cloud，因为开发者工具、推理优化、容器、Kubernetes 和模型生态可以帮助它守住入口。对投资者来说，这不是“TPU 会不会马上替代 GPU”的简单题，而是要看不同工作负载如何分层：训练、批量推理、低延迟推理、agent 长任务、科学计算、视频生成，各自可能选择不同硬件组合。

把今天几条新闻合在一起看，结论其实很清楚。AI 产业链的重心正在从单点模型能力，转向长期运行的 agent 工作负载。agent 一旦进入搜索、代码、科研、视频、办公和本地服务，底层需求就会从一次性聊天变成全天候推理，从模型 API 变成运行时、权限、审计、sandbox、数据访问、内容溯源和云端基础设施。这个变化会继续拉动算力，但算力之外的价值链会变得更厚。

今天低分和重复消息可以快速过一遍。NVIDIA Vera CPU 首批交付 Anthropic、OpenAI、SpaceXAI、OCI，昨天已经讲过，今天没有实质新增。Dell、NVIDIA、OpenAI 的本地 AI Factory 和 Codex 接入企业数据层，昨天也已经深挖过，今天不再重复。Anthropic 收购 Stainless、Cursor Composer 2.5、IBM 和 Hugging Face 的 Open Agent Leaderboard、CrossMPI 多模态 prompt injection，这些主题都仍然重要，但今天没有新的关键事实，只把它们作为 coding agent 和 agent safety 背景。

接下来最需要跟踪五个问题。第一，Gemini Spark 和 Search information agents 夏天推出后，用户是否真的会把长期任务交给 Google。第二，Gemini 3.5 Flash 的第三方基准、API 价格和真实代码库表现能否支撑今天的高预期。第三，Antigravity Managed Agents 的企业安全细节能否经受私有代码、凭证和审计的考验。第四，Gemini for Science 的外部案例能不能继续复现，并转化成企业付费。第五，Google Cloud 里 TPU 与 NVIDIA GPU 的相对角色如何变化。

如果只用一句话总结今天：Google 正在把 Gemini 从模型产品升级成 agent 操作层，而这会把 AI 产业链的关注点，从“谁的模型更聪明”，进一步推向“谁能安全、低成本、长时间地替用户完成真实任务”。这也是今天最重要的产业信号。
