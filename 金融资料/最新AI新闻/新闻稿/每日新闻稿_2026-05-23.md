## 新闻口播稿

各位早上好。今天的 AI 产业链新闻有六条主线，但真正值得深挖的是前三条：Anthropic 的 Mythos 把漏洞发现推到新规模，DeepSeek 把低价模型服务变成正式价格并牵出 CATL 的电力设备线索，Reflection AI 进入美国能源部 Genesis Mission，让 AI for Science 的开放模型路线变得更具体。后面三条也重要：Codex 从功能发布进入企业治理和容量管理，Physical AI 从论文和 demo 走向工业与医疗场景，AI 数据中心继续把电力、储能、液冷和治理推到投资主线前排。

先看今天最重的一条，Anthropic 的 Project Glasswing。官方在 5 月 22 日披露，约 50 个合作伙伴已经用未公开的 Claude Mythos Preview，在全球关键软件里发现超过一万个高危或严重漏洞。Cloudflare 在关键路径系统中发现约两千个 bug，其中四百个是高危或严重；Mozilla 用 Mythos 测 Firefox 150，发现并修复 271 个漏洞，是此前用 Claude Opus 4.6 测 Firefox 148 的十倍以上。Anthropic 自己扫描一千多个开源软件，模型估计有 23,019 个候选漏洞，其中 6,202 个可能是 high 或 critical。公开披露仪表盘显示，截至 5 月 22 日上午，已披露 1,596 个漏洞，覆盖 281 个开源项目，97 个已被上游修补，88 个已有 CVE 或 GitHub Security Advisory。

这条新闻的关键不在于“AI 能找漏洞”这个结论。这个结论过去一年已经被很多安全实验和产品验证过。今天真正重要的变化是规模和瓶颈同时被量化了。以前软件安全最大的限制是找不到足够多的高质量漏洞；现在限制变成谁来复现、谁来确认严重程度、谁来通知维护者、谁来写补丁、谁来测试补丁、谁来把补丁部署到真实系统。Anthropic 自己也说，维护者已经开始感到披露节奏太快，一些人要求放慢速度，因为他们没有足够时间设计和发布修复。

这会让安全产业进入一个很微妙的阶段。防守方终于有了更强工具，可以在攻击者大规模使用类似模型之前先扫关键软件。但同一件事也说明，一旦 Mythos 级模型或类似能力扩散，攻击者发现漏洞和构造利用链的成本也会下降。漏洞披露传统上有 90 天窗口，目的是让维护者有时间修补、用户有时间更新。现在发现速度被 AI 加速，修补速度还被人类流程限制，中间这段时间就更危险。

投资上，AI cyber 不能只看谁的扫描器发现更多告警。真正有价值的是从发现到修复的闭环：高置信排序、可复现证据、自动补丁、回归测试、资产暴露优先级、补丁部署和审计记录。代码安全、SCA、SBOM、漏洞管理、CNAPP、SIEM/SOAR、端点检测、DevSecOps 平台都会受到影响，但客户愿意付费的会是“减少真实风险”，不是“生成更多报告”。这也解释了为什么 Anthropic 同时在做 Claude Security beta、Cyber Verification Program 和给合格安全团队开放更强的工具链。未来的安全预算很可能从单点扫描，转向“模型能力加验证流程加修复流水线”。

第二条是 DeepSeek。官方 API pricing 页面显示，deepseek-v4-pro 现在的 75% 折扣价，会在 2026 年 5 月 31 日 15:59 UTC 促销结束后正式调整为原价的四分之一。也就是说，这个低价不再只是短期补贴。V4-Pro 的 cache-miss input 是每百万 tokens 0.435 美元，output 是每百万 tokens 0.87 美元，cache-hit input 低到 0.003625 美元；上下文长度 1M，最大输出 384K，并发限制 500。V4-Flash 更便宜，input 0.14 美元、output 0.28 美元。

同一天，CnEVPost 援引 The Information 报道称，CATL 计划参与 DeepSeek 的初始融资轮；这轮目标约 500 亿元人民币，若完成，DeepSeek 估值可能超过 3,500 亿元人民币。报道还提到京东、网易等也在洽谈，DeepSeek 正考虑提高模型发布频率，并计划在内蒙古乌兰察布建设大型数据中心。CATL 的动机也很有意思：它希望向大型 AI 数据中心销售电力供应设备。

把这两件事放在一起看，DeepSeek 的新闻已经不只是“中国模型价格低”。它更像是中国 AI 基础设施栈的一次组合信号：模型服务用极低价格抢开发者和企业负载，模型据称面向国产推理硬件优化，数据中心选址考虑低电价和低温，电池和电力设备巨头尝试从储能、电源、配电设备切入 AI 数据中心。这条链条从模型、芯片、服务器、数据中心、电力设备一直延伸到资本。

对全球模型公司来说，0.87 美元每百万输出 tokens 会继续压低客户对 API 价格的心理锚。OpenAI、Anthropic、Google、Mistral 等公司可以凭生态、企业合规、工具链和高端模型能力保持优势，但大量价格敏感型应用、创业公司和批量推理负载，会不断把 DeepSeek 当成成本基准。低价也会迫使其他模型公司解释自己的溢价来自哪里：更强能力、更低延迟、更高稳定性、更好企业控制，还是更完整工具生态。

对投资链条来说，DeepSeek 和 CATL 这条线索要谨慎但值得盯。融资和估值现在还只是报道，参与方和金额都可能变化；低价能否持续，也取决于硬件折旧、利用率、限流、服务稳定性和是否有资本补贴。可如果 CATL 入局坐实，AI 数据中心电源设备、储能、UPS、液冷和配电就会从“机房配套”变成模型公司资本故事的一部分。中国 AI 栈可能走出一条不同路线：较低单芯片性能，搭配更便宜模型服务、自建数据中心、电力优化和国产供应链协同。

第三条，Reflection AI 与美国能源部 DOE Genesis Mission 合作。Axios 报道称，Reflection AI 将成为美国国家实验室的 AI model provider，并为 DOE 17 个国家实验室提供所谓 foundational intelligence layer。Reflection 的定位是先进 open-weight 模型实验室，它会向 DOE 提供可按 DOE 数据定制的 AI 模型，并使用 DOE 算力参与 Genesis Mission 科研项目部署。DOE 自己对 Genesis Mission 的定义，是把国家实验室、产业、大学、超算、实验设施、AI 系统和独特数据集连接起来，服务能源、材料、量子、核安全、关键矿物、生物技术和先进制造等国家级科学挑战。

这条新闻和前几天的 AI for Science 主线有关，但路线不同。前几天我们看过 OpenAI 的离散几何突破、Google Gemini for Science、Co-Scientist、DeepMind 和 Isomorphic Labs。那些新闻强调前沿模型能在数学、药物、材料或科学推理里产生新结果。Reflection 和 DOE 的重点是制度化科研平台：国家实验室拥有高价值私有数据、实验装置和超算环境，科学家希望能完整访问、理解和定制模型，而不是只通过黑盒 API 调用。

这会把 AI for Science 的竞争标准改掉一部分。科学模型要能被拆开、复现、微调、审计，还要能和实验设施、仿真软件、HPC 作业系统、数据治理流程连接起来。开放权重在这里有天然吸引力，因为国家实验室和关键科研任务不愿意把长期能力完全锁在某个闭源商业 API 里。Reflection 还没有公开发布 frontier open-weight 模型，这是最大风险点。它今天获得的是战略入口，不等于模型能力已经被充分验证。

投资上，Reflection 本身是私有公司，公开市场更应该看上游和配套：HPC、GPU 和其他加速器、存储、科学数据平台、实验自动化、材料仿真、EDA、量子软件、私有部署和模型微调工具。政府项目会带来长采购周期和合规约束，但一旦形成标准，相关平台的切换成本也会很高。未来要盯的是 Reflection 何时公开模型、是否真开放权重、DOE 哪些实验室先部署、有没有明确科研成果或周期缩短指标，以及 OpenAI、Google、Anthropic、Meta、Mistral 会不会针对国家实验室给出相应开放或私有部署方案。

第四条，OpenAI Codex。今天的新信息有两面。好的一面是，OpenAI 称 Codex 被 Gartner 评为 Enterprise AI Coding Agents 的 Leader，每周有超过 400 万用户使用，企业客户包括 Cisco、Datadog、Dell Technologies、NVIDIA 等。OpenAI 强调的能力包括 agentic software development、企业治理、sandboxing、灵活部署、approval gates、RBAC、customizable policies、OS-level sandboxing 和可审计 workspace governance。Cisco 案例里，OpenAI 说 Codex 帮助开发其 AI Defense 安全平台的大部分，把交付时间从几个季度缩短到几周。

另一面是 OpenAI Status 显示，5 月 22 日下午到 5 月 23 日上午，Codex 出现“更多用户触及 rate limits”的降级事件，影响 5 个 Codex 组件，后来恢复。把这两件事放在一起看，很像 coding agent 的成熟转折点：它已经进入企业采购和治理评价体系，同时也开始承受容量、配额、排队和稳定性压力。

昨天我们已经讲过 Codex 的 Appshots、Goal mode、浏览器标注和锁屏远程运行。今天就不重复功能清单。更值得看的，是企业为什么在意治理。coding agent 会读代码库、跑命令、改文件、访问测试环境、调用浏览器、可能触碰密钥和客户数据。企业真正要问的是：权限怎么隔离，失败怎么回滚，谁批准变更，agent 执行记录怎么审计，多 agent 并发成本怎么控制，能不能在私有环境里运行，能不能接入现有工单、CI、代码审查和安全流程。

这条线的投资含义是，开发者工具竞争会继续从 IDE 插件升级到完整工程操作层。OpenAI、Anthropic、Microsoft/GitHub、Google、Cursor、JetBrains、Atlassian、ServiceNow、GitLab 都会争这个入口。基础设施也会被拉动，因为长任务 coding agent 是高 token、高工具调用、高沙盒、高日志、高存储访问的工作负载。短期要盯 Codex rate-limit 是否再次出现，OpenAI 会不会推出专属容量、企业 SLA、更细用量计费或私有部署方案。

第五条是 Physical AI。Kawasaki Heavy Industries 宣布在 San Jose 成立 Kawasaki Physical AI Center，合作方包括 NVIDIA、Analog Devices、Microsoft 和 Fujitsu。第一阶段聚焦 healthcare 和 elder care，提出从到院、检查、诊断、治疗、手术到术后护理的一站式医院方案，后续还会扩展到半导体、汽车和新型移动出行。NVIDIA 负责 AI 与机器人方案，ADI 强调 sensing 和语音识别，Microsoft 提供云和 AI 平台，Fujitsu 侧重医疗业务系统、机器人系统和 AI 整合。

同一天，TechXplore 报道 Science Robotics 论文，香港中文大学、浙江人形机器人创新中心等团队提出 Retrieval-Augmented Manipulation，简称 RAM。这个框架把 VLM 和显式 3D object representation 结合起来，让机器人能把复杂语言指令转换成空间上可执行的子目标，并在真实机器人场景中 zero-shot 执行和重规划。

这两条放在一起，说明具身智能的叙事正在从炫目的 humanoid demo，转向更务实的系统工程。真实机器人要解决的不是会不会听懂一句话，而是能不能把语言落到三维空间里的位置、方向、尺寸、碰撞、抓取顺序和失败重试。医疗、护理、半导体、汽车这些场景的门槛高，但 ROI 和责任边界也更清晰。NVIDIA 的 Physical AI 叙事、ADI 的传感器、Microsoft 的云平台、Fujitsu 的医疗系统和 Kawasaki 的工业机器人经验，组合起来比单个 demo 更接近可部署产品。

投资上，可以看机器人本体、伺服、减速器、工业相机、力控、边缘 AI 模块、传感器、仿真、数字孪生、机器人 OS、现场安全监控和系统集成。风险也很明确：医疗和护理合规周期长，责任边界复杂；RAM 仍是研究进展，真实环境中的遮挡、反光、柔性物体和人群动态会让难度明显上升。后续要看 Kawasaki 是否公布首批医院、半导体厂或汽车客户，RAM 是否开源并被主流机器人平台复现。

第六条，AI 数据中心的电力和冷却约束继续扩散。今天没有单一新闻超过前几天 Nebius/Bloom 或 Google/Blackstone 的规模，但多个线索连起来很有用。Enbridge 和 Meta 的 Cowboy Project 第一阶段包括 365MW 太阳能和 200MW / 1,600MWh 电池储能，Enbridge 预计投资约 12 亿美元，目标 2027 年底投运，通过怀俄明的大负载 tariff 支持 Meta 数据中心。Telborg 的数据中心 briefing 还提到 Dallas 被 Cushman & Wakefield 评为全球头部数据中心市场，2025 年在建容量接近 31.7GW，AI 让 power availability 和 scalability 成为选址核心。

液冷这边，Schneider Electric 讨论 PFAS 监管对两相浸没和两相 direct-to-chip cooling 的影响，并强调 75% water 加 25% glycol 的 single-phase direct-to-chip 路线。治理这边，Harvard Law School Forum 摘要显示，NYSCRF 的 2026 proxy policy 新增对 data center growth environmental risks 和 responsible AI governance 的关注。换句话说，AI 数据中心已经不只是工程问题，也会进入股东投票、董事会监督、地方许可和社区冲突。

投资框架需要继续外扩。GPU、HBM、CoWoS 仍然关键，但现在还要一起看并网、变压器、开关设备、UPS、母线槽、储能、燃料电池、备用电源、液冷 CDU、冷板、泵阀、冷却液、施工周期、地方电价和水资源。未来数据中心运营商的估值，不能只看 MW backlog，还要看这些 MW 的电力确定性、许可风险、冷却路线和社区阻力。对公用事业和电力设备公司来说，AI 负载是巨大机会，也会带来 ratepayer politics 和监管压力。
