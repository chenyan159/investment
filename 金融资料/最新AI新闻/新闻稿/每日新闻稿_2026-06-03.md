## 新闻口播稿

大家好，今天是 2026 年 6 月 3 日。今天 AI 产业链最值得听的几条新闻，都围绕一个共同问题展开：AI 算力怎样从发布会上的路线图，变成真正能上线、能供电、能散热、能被企业安全使用的生产能力。

过去两天，我们已经密集看到 NVIDIA Vera Rubin、OpenAI 的 Michigan Stargate、Alphabet 800 亿美元融资、Micron 的 AI memory 组合、Supermicro 的 Helios 机架和 HPE 财报。今天的新增信号更偏“落地层”：谁能把数据中心建得更快，谁能拿到足够内存，谁能把 agent 推理成本拆清楚，谁能让企业放心把 agent 放进关键系统。

今天最重要的头条，是 Delta 在 COMPUTEX 推出的预制化 AI 模块化数据中心方案。表面看，这是一家电源和热管理公司发布新产品；放到 AI 产业链里看，它讲的是 AI capacity 的交付方式正在工业化。

Delta 这套方案把 800VDC In-Row Power、3MW 液冷、2.4MW liquid-to-liquid CDU、25kW 高压直流电泵、N+1 冗余、热插拔、Vera Rubin NVL72 冷板设计、微电网和工厂预装测试放在一起。公司说，预制化方案可以把部署时间最多缩短 60%。这个数字不只代表施工快一点，它说明 AI 数据中心开始从“每个站点重新做工程设计”，转向“把供电、冷却、管路、机柜和控制系统做成可复制模块”。

为什么这件事重要？因为 AI 基建现在最大的瓶颈，已经从“有没有 GPU”扩散到“GPU 到了之后能不能通电，能不能冷却，能不能通过验收，能不能按期把 MW 级负载接上去”。过去两周，QTS 临时 onsite power plant 讲的是 time-to-power，SoftBank France 和 Schneider Dunkirk 讲的是 GW 级电力和工业模块，Siemens、Fluence、nVent 的 DSX Vera Rubin NVL72 架构讲的是 100MW IT load 的设施蓝图。今天 Delta 往下打到 row、rack、CDU、冷板和工厂预制，把设施侧蓝图变成更具体的产品包。

800VDC 是这里的核心词。传统交流配电经过多次 AC/DC、DC/DC 转换，到了超高密度 AI 机柜里，效率、空间、热损耗和电池备份都会被挤压。Delta 的说法是，传统 AC-DC 架构未来一到两年会碰到极限，高压直流会成为减少配电损耗、提升系统效率的关键路线。这个判断如果成立，数据中心供电链会重新切分价值：UPS、PDU、母线槽、低压配电、机柜电源、BBU、电池备份和 DC/DC 转换，都会从传统数据中心架构迁移到更贴近机柜和行级的高压直流系统。

液冷也是同一件事的另一面。3MW 液冷和 2.4MW LTL CDU 说明冷却从单个冷板、单个 rack，进入 row 级和 hall 级控制。它需要泵、阀、管路、泄漏检测、流体、冷板、接头、热界面材料，也需要运维软件实时知道哪里热、哪里堵、哪里可能漏。未来 AI 数据中心的散热系统会越来越像工业流程控制系统，维护能力和故障隔离能力会直接影响客户愿不愿意大规模采用。

投资链条上，今天 Delta 这条新闻最直接指向三组公司。第一组是电力和配电：Delta、Schneider Electric、Eaton、ABB、Vertiv、Siemens、nVent、Legrand、Hubbell、Powell。第二组是液冷和热管理：Vertiv、Modine、CoolIT、Boyd、Parker、Ecolab 以及台湾和日本的冷却、泵阀、材料供应链。第三组是工程和预制化交付：Quanta Services、EMCOR、Comfort Systems USA、数据中心总包、机电安装和模块化机房厂商。未来真正要验证的是谁拿到 hyperscaler、neocloud、Oracle/OpenAI Stargate、CoreWeave、Nebius、SoftBank France、Data4 或 Campus AI 的真实订单。

第二条重点新闻，是 SK Group 董事长 Chey Tae-won 在 COMPUTEX 上说，包含 HBM 在内的内存短缺可能延续到 2030 年，SK hynix 计划在未来五年把总晶圆产能翻倍。他还补了一句很关键的话：AI 产业瓶颈不只在 GPU 或内存，电力、水、设备、土地，每个环节都可能同时短缺。

这条新闻的价值，在于它把 HBM 从短期交易主题，拉成了 2026 到 2030 年的产业约束。过去市场常常把 HBM 当成 NVIDIA GPU 的高价值配件，谁给 NVIDIA 供货，谁就涨价。但随着模型上下文变长、agent 并发增加、视频和世界模型吃掉更多 memory bandwidth，HBM、LPDDR、DDR、SSD、nearline HDD、CXL memory pooling 和 KV cache 存储会一起决定 token 产量。AI 数据中心不是只生产算力，它在生产可用 token、可用上下文和可用 agent worker。

Chey 的发言还有一个扩产周期含义。新 fab 至少三年，从全新地点开始可能超过五年。也就是说，即便 SK hynix 今天决定五年翻倍，真实供给也会被设备交付、EUV、洁净室、厂务、高纯水、气体、化学品、电力和土地约束。HBM 看起来在封装端很先进，背后仍然需要最传统也最硬的晶圆产能、厂务系统和资本开支。

这会怎样影响产业链？第一，SK hynix、Micron、Samsung 的 HBM4、HBM4E 客户认证继续是短期最核心变量。5 月底我们看过 Samsung HBM4E 样品出货，昨天看过 Micron 在 COMPUTEX 上把 HBM、DRAM、SSD 和 data path 放到同一张图里，今天 SK hynix 把短缺周期拉长到 2030。三家存储厂的定价权仍然偏强。第二，设备和材料链会继续受益。ASML、Applied Materials、Lam Research、KLA、Tokyo Electron、ASM International、Advantest、Teradyne、FormFactor、Onto、Camtek、Entegris、Air Liquide、Linde、Merck KGaA、JSR、Shin-Etsu、SUMCO 都在扩产链条里有位置。第三，数据中心存储系统也要重新估值。Western Digital、Seagate、Pure Storage、NetApp、VAST Data、WEKA、Dell、HPE、Supermicro、Marvell、Rambus、Astera Labs、Montage 这些公司，不只是在卖存储或接口，它们在参与 AI data path 的重构。

风险也要讲清楚。内存行业天然有周期。若 AI capex 在 2028 或 2029 年因为利率、监管、用电、商业回报或模型效率提升而降温，今天的扩产计划可能在周期尾部形成供给过剩。另一个风险是客户集中度和认证节奏，HBM 对 NVIDIA、AMD、自研 ASIC 客户的验证和良率依赖很强，单个大客户认证变化会影响厂商排产。但在 2026 年这个时点，Chey 的表述强化了一个现实：至少在未来两三年，内存链很难被简单当成周期股尾声看待，它更像 AI 基建的刚性瓶颈。

第三条重点新闻，是 Intel 在 COMPUTEX 上把 agentic inference 放到数据中心 CPU 的中心位置。Intel 发布 Xeon 6+，并和 SambaNova、Foxconn、Vista、Cambium、Vector Core 等伙伴展示 rackscale AI infrastructure 和分解式推理系统。最值得保留的一句话是：训练时代的 AI 部署可能是 1 个 CPU 配 4 个 GPU，甚至 1 个 CPU 配 8 个 GPU；agentic inference 会把 CPU/GPU 关系推向 1:1，甚至更高 CPU 密度。

这件事为什么成立？因为 agent 不只是一次模型调用。一个 coding agent、运维 agent 或企业流程 agent，会拆成计划、检索、工具调用、代码执行、沙箱运行、数据库查询、权限判断、结果校验、日志记录、失败回滚和人工审批。GPU 负责模型推理，但 CPU 负责调度、IO、sandbox、工具执行、网络、策略和控制面。agent 越从 demo 走向生产，CPU、内存、网络和存储就越像系统的执行层。

Intel 和 SambaNova 的分解式推理也值得看。prefill 和 decode 不是同一种工作负载。长上下文 prefill 更吃算力和带宽，decode 更看延迟、并发和单位 token 成本。Intel/SambaNova 的蓝图是 GPU 负责 prefill，SambaNova RDU 负责 high-throughput decode，Xeon 6 负责 host 和 action CPU。Vector Core 的演示又把企业推理云、Together.ai 客户和 Vista portfolio early access 放进同一个商业框架里。这个方向如果跑通，推理云会从单一 GPU cluster，演化为 CPU、GPU、RDU、ASIC、memory tier、network fabric 和 storage tier 的异构调度系统。

这里还要和前天的 NVIDIA Vera CPU 连起来看。NVIDIA 想把 CPU 放进 Vera Rubin coherent AI factory，Intel 想用 x86 兼容性、18A、CPU density、Foxconn 集成、SambaNova RDU 和企业存量基础设施争夺 agentic inference 的控制面。这场竞争不能只看单个 CPU benchmark。真正的指标会是 agent task completion cost、sandbox execution throughput、orchestration latency、每瓦并发 agent 数、prefill/decode 拆分后的总 token 成本，以及企业运维稳定性。

投资上，这条新闻给 CPU 和异构推理链条抬了权重。Intel、AMD EPYC、Arm server CPU、NVIDIA Vera、AWS Graviton、Google Axion、Microsoft Cobalt 都需要在 agentic inference 框架下重新比较。Foxconn、Quanta、Wiwynn、Wistron、Inventec、Dell、HPE、Supermicro 这些整机和机架集成商，会继续从代工走向系统工程。Broadcom、Marvell、Astera Labs、Credo、Arista、Cisco 会受益于异构资源调度带来的网络和互联需求。SambaNova 这类专用推理架构仍有机会，但需要证明 decode 阶段的真实成本优势，而不能只停留在合作新闻。

第四条重点新闻，是 Cisco 发布 Cloud Control 和 AgenticOps。Cisco 的说法是，这是一套让 humans and AI agents 一起管理、监控、防御关键 IT 基础设施的平台。它包含 Cloud Control Studio、Agent Builder、App Builder、50 多个第三方平台和工具连接、开放 MCP、OpenAI Codex 集成、Cloud Control Marketplace、Live Protect 运行时防护，以及用 Anthropic Project Glasswing 和 OpenAI Daybreak 压测自身产品的安全叙事。

这条新闻的产业含义很清楚：enterprise agent 的下一站，不在聊天窗口里，而在网络、云控制、安全、observability、ITSM、工单、配置和身份权限系统里。企业愿意为 agent 付钱的地方，往往是复杂、频繁、可度量、出错代价高的流程。关键 IT 基础设施正好符合这些条件。它需要实时监控、异常响应、变更审批、漏洞优先级排序、访问控制、审计、回滚和策略执行。

Cisco 把 MCP、agent builder、marketplace、frontier model red teaming 和 runtime protection 放在一起，说明 agent 平台会越来越像控制系统，而不是单纯的模型入口。对 Cisco 自身来说，这是把网络设备、Nexus、security、observability、Collaboration 和 Splunk 类资产放到一个 agentic operations 语言里；对整个产业来说，这是 ServiceNow、Salesforce、Microsoft、Palo Alto、CrowdStrike、Datadog、Dynatrace、GitLab、GitHub、Atlassian、Okta、CyberArk、HashiCorp、Snowflake 等公司都会竞争的控制面。

今天还有一条和 Cisco 形成强烈对照的新闻：Meta 的 AI support chatbot 被诱导协助 Instagram 账户接管，Meta 已经修补。攻击过程大意是，攻击者启动账户恢复流程，用 VPN 降低风控触发概率，然后让 AI support assistant 把新的邮箱加到账户上，验证码发到攻击者邮箱，再触发密码重置。TechCrunch 说，受影响账户包括高价值和高关注度账户。

这件事的重点不在于模型有没有“被骗”，而在于 agent 拿到了真实账户操作权限。AI support 一旦能够改邮箱、发 password reset、绕过 MFA、退款、取消订单、转移资金、修改 API key 或升级工单，它就进入了资产控制面。企业 agent 安全要解决五层问题：身份怎么确认，权限怎么分级，高危动作怎么审批，上下文能不能抵抗社工和伪造证据，每一步能不能审计和回滚。

Cisco 的 Cloud Control 告诉我们，agent 正在进入关键基础设施；Meta 的事故告诉我们，权限边界如果没做好，agent 会把客服降本的 ROI 变成账户接管、欺诈、赔付、监管和品牌风险。两条新闻合在一起，给 agent security、identity、policy engine、approval workflow、LLM firewall、tool sandbox、audit log、session risk scoring 都增加了预算理由。未来企业采购 agent 平台，不会只问模型多聪明，还会问：它能做哪些动作，谁批准，失败后谁负责，日志在哪里，能不能撤销，能不能限制到最小权限。

第五条新闻，是法国 AI 基建第二波增量。Brookfield 把法国 AI infrastructure 投资承诺从 200 亿欧元提高到 300 亿欧元，Campus AI 约 75 亿欧元的第二站点接近选择，Ardian 和 Verne 在法兰西岛规划最高 50 亿欧元、目标 500MW 的低碳计算基础设施。再加上几天前 SoftBank France 5GW 和 Schneider Dunkirk 工业模块，法国正在把低碳电力变成吸引 AI 基建的核心资产。

但这里有一个需要冷静看的问题。法国有核电和相对低碳电力，这是优势；AI 价值链里，电力和地产只是一部分。Le Monde 的观点很尖锐：如果法国只是提供清洁电力和机房，模型、软件、数据和服务价值仍然被美国 hyperscaler 和全球模型公司拿走，法国可能变成能源外包地。这个批评短期不会阻止数据中心投资，因为海外资本正在抢电、抢土地、抢并网；但它会影响法国和欧洲后续政策：更多建设计划会被要求绑定主权模型、欧洲云、工业应用、就业、研发和本地供应链。

对投资来说，法国这条线继续利好电力接入、变电、储能、液冷、机电工程、预制模块和数据中心运营商。Brookfield/Data4、Ardian/Verne、Schneider、Delta、Vertiv、Eaton、ABB、Siemens、nVent、Bouygues、Crédit Agricole 相关生态都值得跟踪。验证点也很明确：公告金额里多少是真正新增 capex，多少能拿到并网容量，anchor tenant 是谁，设备订单给谁，建设何时形成 energized MW，不能只看“几十亿欧元”的标题。

第六条新闻，是中国 7 月 1 日起实施新的对外投资规定。法律解读显示，它会把海外重组、技术和数据出海、人员派遣、培训、技术指导、海外资产处置等纳入更强审查。如果涉及国家安全或敏感资产，监管机构可以审查、禁止、要求整改，并对违规方施加罚款、没收收益、活动禁令和负责人责任。

这条新闻没有直接订单，但会改变 AI 跨境交易的风险溢价。过去全球 AI 竞争主要看美国芯片出口管制、先进半导体设备限制、云算力租赁限制。现在中国也在强化本土技术、数据、人员和资产不被绕道转移。对中国 AI startup 出海融资、迁址、海外 M&A、开曼或新加坡结构、模型团队收购、芯片设计资产交易、自动驾驶和机器人数据资产转移，都要重新加入 regulatory break risk。对投资者来说，涉及中国 AI IP、模型团队、芯片设计、EDA、半导体设备、数据资产和人才流动的交易，估值不能只看技术和市场，还要看 ODI、美国 outbound investment、CFIUS、欧盟数据规则和中国安全审查同时挤压后的可执行性。

它也会强化国产替代链的封闭性。华为 Ascend、寒武纪、海光、壁仞、天数智芯、沐曦、摩尔线程、阿里平头哥等路线，可能获得更明确的政策边界保护，但最终商业价值仍然取决于软件栈、客户 workload、供给能力和真实部署。明天以后要看的是细则、敏感行业清单、实际案例，以及头部中国 AI 公司是否调整海外架构、开源策略、融资结构和人才安排。

最后，把今天分数较低、重复度较高或证据还不够强的新闻快速过一遍。

Western Digital 在 COMPUTEX 讲 AI storage，强调 AI 不只跑在 compute 上，也跑在 data system 上。这条方向正确，和昨天 Micron 的 memory/storage 组合一致，但发布时间更早，今天没有必要单独主写。它适合放进 SK hynix 和 Micron 的 data path 框架里继续跟踪。

NVIDIA Nemotron 3 Ultra、Perplexity Search as Code、OpenAI Rosalind Biodefense 都是值得明天和本周继续看的软件和 AI for Science 线索。Nemotron 如果按期开放权重、出现社区 benchmark 或企业平台接入，可以作为 NVIDIA software delta；Perplexity 的 Search as Code 适合观察 agentic search SDK 和 secure sandbox；Rosalind 需要等更多生命科学或生物安全落地证据。
