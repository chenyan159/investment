## 10. 优先候选研究包

### 10.1 LiteLLM：绿色迁移任务如何留下空数据库

- **时间线：** v1.90.0 的 Docker allowlist 改动丢失迁移目录；PR #33592 恢复目录并验证 135 个 migrations/66 表；随后 PR #33853 复现非 root、HOME 改写、零外网和 Wolfi `libatomic.so.1` 失效；7/19 四个稳定分支集中回补。
- **失效机制：** `prisma migrate deploy` 在 schema 附近没有 migrations 目录时 exit 0；另一条路径会在运行时通过 nodeenv/npm bootstrap Prisma，Wolfi 缺库后迁移失败。代理继续启动，DB endpoint 才暴露 500。
- **支持证据：** 官方给出前后容器截图和真实 Postgres：修复前0表/HTTP500，修复后75表/HTTP200；覆盖 uid12345、internal-only network 与 read-only rootfs。
- **证据边界：** 未披露生产客户受影响数量；“所有部署故障”会夸大，默认 root/HOME 路径可能正常。
- **新增洞见：** AI gateway 的部署检查需要验证 schema/table 与关键控制面 API，单看 migration exit code 或代理进程不够。
- **下游最值得展开：** fail-open 的两层原因、为什么默认 CI 未捕获、四分支回补、对企业 air-gapped/Kubernetes 安全基线的影响。
- **验证问题：** 受影响版本、重跑迁移方法、是否加入启动前硬失败、旧数据库升级与数据完整性。
- **避免重复：** 不展开通用“企业需要 AI gateway”背景；安全签名、SSRF 和 API key hash 只作同版旁注。

### 10.2 社会许可：142点协调行动与 Saline 法律约束

- **时间线：** 7/18 凌晨稿只确认至少125处计划；16:02 PDT 后续稿给142点/42州及局部人数；Saline 在7/17晚特别会议恢复最大减免，7/18 01:09/06:37出现地方报道。
- **支持证据：** Reuters 的跨州分布和三个现场人数；WEMU/Saline Post 的会议照片、5—0票决和律师对 consent judgment 的说明。
- **反对观点：** Data Center Coalition称行业正在与社区合作并减轻影响；抗议组织者自身不支持纽约式全面 moratorium。局部 turnout 不能支持全国群众规模结论。
- **新增洞见：** 社会许可风险需要同时看组织覆盖、参与深度、法律/合同锁定和正式政府动作。Saline 显示前期 settlement 可在后期限制地方反转。
- **下游最值得展开：** “行动发生”与“政策结果”之间的距离；为何同一天出现全国动员和地方政府退回最大税惠。
- **验证问题：** 后续听证/拒批、选举议程、Saline诉讼、IFEC证书、最终应税基数与工程里程碑。
- **避免重复：** NY moratorium、PJM电价与水耗常识只做最短基线。

### 10.3 Amazon 宾州：备电规模与水许可接口

- **核心数字：** PNE100 为 280×4,287hp 天然气机及3台柴油机；官方限制 NOx/VOC 各低于25tpy。PHL100 为36英寸冷却排水、6英寸供水、8组电力和9组光纤 duct bank、0.11英亩湿地影响。
- **证据边界：** PNE100 机械额定换算约895MW，不代表净发电或 IT load；PHL100 未给取排水量和热负荷。两项均处许可流程。
- **新增洞见：** “备用”分类可以容纳极大设备阵列，环境许可会通过燃料消耗/排放上限约束可运行小时；水许可同时暴露电力、网络和安全围栏等项目接口。
- **下游最值得展开：** backup 与 onsite baseload 的监管差别；许可条件如何影响数据中心可用性、CAPEX和时间表。
- **验证问题：** 设备电气输出、年测试/紧急小时、并网可靠性、取排水量、附带条件、公众听证和COD。
- **避免重复：** xAI 59台临时燃机只作对照，禁止重新展开整段排放争议。

### 10.4 编码代理控制权：验证、指令、网络与权限状态

- **Claude：** 自动 `/verify` 与 `/code-review` 改为用户显式调用；功能仍存在。
- **Copilot：** 审查读取 head-branch 指令并允许自定义 setup；GitHub-hosted runner 默认防火墙，self-hosted 暂无。
- **Codex：** 权限指令用稳定哈希进入 world state，在模型可见片段缺失/改变时重新注入，覆盖压缩和重建。
- **新增洞见：** 生产控制面正在拆成四个可单独验证的层：谁触发检查、谁提供指令、运行时能访问哪里、长会话后权限是否仍在模型上下文。
- **正反证据：** 显式控制减少意外行为和成本；默认检查减少后可能出现漏跑。head-branch 提高规则迭代速度，也提高了需要说明的信任边界。
- **验证问题：** fork PR 的指令/YAML信任模型、Claude变更原因与漏检、Codex稳定版和冲突优先级、企业审计日志。
- **避免重复：** 2.1.214 权限绕过、Sol 删除事故和通用最小权限原则只作一两句背景。
