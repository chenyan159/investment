- Tower 的“fully spoken for”、Ameresco 的 awarded、onsemi 的 design win、Palantir 的 TCV、CoreWeave 的 contracted power 各自代表不同约束强度，均未自动等于当期收入。
- 开放视频即使推理价格大降，质量、全注意力 token 数与长时漂移仍可阻止客户迁移；该判断来自单一服务商访谈。
- Rebellions 50m calls 未提供 token、模型、精度、SLA 或电表数据；不能据此得出 1/6 功耗或 1/3 成本的已验证结论。
- Solution Hacking 显示 anti-hack prompt 会同时降低表面分数和真正正确率；评测修复存在能力损失与弃答权衡。

## 优先候选研究包

### 1. Texas 全队列审计：名义负荷先过真实性闸门

- **事实与时间线**：8 月 3 日州长指示 PUCT/ERCOT 对约 474GW 接入请求做全面审计，并要求任何在队项目继续推进前完成核验；官方称约 90% 新请求来自数据中心。审计范围含电、水、现场发电、税惠、社区措施与所有权。
- **最短基线**：Texas 先前已讨论自带电、可中断负荷和居民费率保护。今天新增的是覆盖全队列的项目级核验和拒绝并网后果。
- **支持与边界**：州长原文可确认命令与口径；474GW 未给出项目去重、阶段分布和可交付比例。Axios 的“halt”属于执行效果概括，永久冻结并无官方依据。
- **判断增量**：队列数字的可投资含义下修，成熟项目的稀缺性与既有站点/电源/许可价值上修。关键变量转向审计节奏、豁免和 Batch Zero 项目处理。
- **下游展开**：解释名义 GW、studied load、可签约容量和实际上电的转换漏斗；追问何时完成、谁承担研究成本、拒绝与复审程序。避免重复美国数据中心耗电总量和居民电费的一般背景。

### 2. NRG 1.2GW BYOP：专用电源交易进入主要商业条款

- **事实与时间线**：8 月 4 日 04:28 PDT 的 SEC 材料披露，NRG 与一家全球 cloud/AI hyperscaler 就 Texas 1.2GW 联合循环燃机项目达成 principal commercial terms，客户支持 BYOP 投资；最终文件和必要批准尚未完成。
- **最短基线**：Georgia 等地已经出现大负荷客户承担增量电源成本的合同设计。NRG 今天给出更大规模、单一客户、专门燃机的交易推进层级。
- **支持与边界**：SEC 披露为 A 级证据；客户、燃气来源、并网、土地、COD、电价、资本支持结构、退出权和残余公用事业风险均缺失。
- **判断增量**：hyperscaler 自带电从政策原则推进到 1.2GW 商业谈判后段，燃机、燃气、电气设备和 EPC 的可兑现概率上升。最终协议前仍按条件性项目处理。
- **下游展开**：重点讲 BYOP 如何分配资本、燃料、可靠性和居民费率风险；核对 Texas 审计是否覆盖该项目。避免重讲“AI 缺电”及通用天然气受益名单。

### 3. Tower 与 FCC：光互连的收入兑现和政策供给风险同时出现

- **事实与时间线**：Tower Q2 收入 $460m、同比 +24%；SiPho 年化 run-rate $680m，去年同期 $180m，目标 Q4 超 $1bn，Q3 收入中点 $520m。约 22 分钟前，Reuters 披露 FCC 正起草限制中国新型号数据中心光收发器的措施，目标年内生效。
- **最短基线**：Tower 的 $1.3bn 2027 SiPho 合同、$290m 预付款和日本扩产已播；美国对中国数据中心内部光模块的型号级限制尚无既有正式规则。
- **支持与边界**：Tower 数字来自 SEC；run-rate 不能与季度总收入相加，“spoken for”不代表不可撤销收入。FCC 只有四名匿名信源，正式文本、法律路径、存量、豁免和适用型号缺失，草案仍可能修改或搁置。
- **判断增量**：Tower 满足“订单/扩产转为收入”的重开条件；FCC 若落地会改变供应商认证、价格和产能约束。需求兑现和供给冲击可同稿，证据等级必须分开。
- **下游展开**：核 SiPho 客户集中、良率、晶圆与最低承诺；核中际旭创 27% 份额口径、Coherent/Lumentum 可替代产能和云厂商转换周期。避免重复 CPO/SiPho 原理和完整光模块公司名单。

### 4. Cipher 与 Ameresco：项目从开发叙事走向起租和授予积压

- **事实与时间线**：Cipher 8 月初把 Black Pearl 较原计划提前约两个月交付并开始首笔租金，纠正 8 月 2 日基于后续时表形成的否定性判断。Ameresco 披露数据中心相关 awarded backlog 约 $1.2bn；award 尚待合同和收入确认。
- **最短基线**：Black Pearl 的租约、建设和租户质量已有记录；Apollo 900MW 只有购地期权和 ERCOT studied-load 申请。Ameresco 过往只有项目组合和能源基础设施方向性需求。
- **支持与边界**：Cipher 的 SEC 新闻稿和演示相互支持实际交付/起租；已交付 MW、数据厅、验收和租金未披露。Ameresco 的 awarded、contracted backlog 和 revenue 是三个层级。
- **判断增量**：Black Pearl 出现明确状态跃迁，短期兑现概率上修；Ameresco 提供工程服务获授规模，合同转换概率仍需折扣。
- **下游展开**：用“土地/研究→合同→建设→验收→起租/收入”漏斗对照两家公司。Apollo 不写成已签 900MW；Ameresco 不把 award 写成订单或收入。

### 5. 发电、电源、功率器件与工程：收入兑现组合

- **核心数字**：Cummins Power Generation Q2 销售 $1.536bn、同比 +27.5%；Caterpillar Power Generation $3.098bn、+29%。AEIS Data Center Computing $191.5m、+35.2%，H1 +62.2%。Sterling 收入 $1.17bn、+90%，signed backlog $4.33bn，E-Infrastructure backlog 中 mission-critical 占 92%。onsemi 给出 AI 数据中心 power design wins，Palantir 披露美国商业增长和大合同，Powell 的 >$400m 数据中心订单进入 backlog。
- **证据边界**：各项分别代表销售、分项收入、signed backlog、design win、TCV 和正式订单。Caterpillar/Cummins 还覆盖非 AI 发电需求；Sterling 的 mission-critical 含数据中心、制造和半导体；onsemi 未给量产收入分母。
- **判断增量**：同日多层级数据支持基础设施开支正在向设备和工程收入转换。强度上修，AI 归因和持续时间仍需分公司核验。
- **下游展开**：优先比较转换层级、organic 增长、利润率、lead time 与客户集中；不要把不同口径求和成“AI 收入”。旧内容只保留电力设备需求的一句基线。

### 6. CoreWeave 与 Palantir：签约容量和企业合同的兑现边界

- **核心事实**：CoreWeave 正式宣布 Indonesia 3 个设施、合计 360MW contracted IT power，预计 2028 上线；截至 3 月 31 日公司称 >1GW active、>3.5GW contracted power。Palantir 的财报提供美国商业收入、合同和 TCV 增量。
- **证据边界**：CoreWeave 未披露站点、地主/电力方、GPU、客户承购、融资、许可和分期；contracted power 与已部署算力、收入相距多个节点。Palantir 的 TCV 与当期收入、净新增 ARR 也需分开。
- **判断增量**：CoreWeave 的亚太数据驻留和容量时间表从意向进入正式合同口径；Palantir 继续验证企业 AI 合同速度。两者都缺同日客户级产出或 ROI 数据。
- **下游展开**：一条讲算力供给的地域和融资漏斗，一条讲企业合同到使用量/收入的漏斗；避免用合同总额代替实际采用。

### 7. 治理与社会许可：发布前送测、地方暂停和并网承诺金

- **核心事实**：白宫官员称自愿发布前模型送测框架已完成，最多 30 天访问，覆盖保密、网络安全、内部人、IP 和 trusted partners；文本、参与者及启用日未公开。Salem 与 Lakeland 同日推进数据中心暂停，Lakeland 以 4:3 通过 12 个月暂停。Ofgem 据报拟收 £237,500—£712,500/MW 可退承诺金，以融资、终端客户和 switchgear 采购筛选并网申请。
- **证据边界**：白宫框架主要来自 Axios，缺公开正文；Salem 的追溯适用和正式决议待核；Ofgem 本轮咨询原文尚未取得，保留 B+。
- **判断增量**：治理工具开始落到发布前访问、地方受理暂停和并网申请资金约束。政策可执行性略升，实际覆盖和法律后果仍未确认。
- **下游展开**：核原文、适用阈值、豁免、复审和生效时间；避免把三个制度并成统一“监管收紧”结论。

### 8. Benchmark 与窄域小模型：表面正确率的测量失真

- **核心事实**：Solution Hacking 在 3,528 份答案中由常规题 2.2% 升至 HLE 37.4%，模型答对样本里 8.2%—44.1% 依赖无效捷径；检测器召回 61.2%。Antares‑3B 在作者 500 个漏洞定位任务中 File F1 0.223，接近 GPT‑5.5 xhigh 的 0.229，作者估算单 H100 约 15 分钟、<$1。
- **证据边界**：Solution Hacking 有 21 位 PhD 盲审锚点，部署检测仍可能漏检。Antares 使用自建任务/harness，最强 3B 权重和 RL 数据未开放；成本为作者估算。
- **判断增量**：同日给出两个方向：前沿 benchmark 的“答对”可能高估目标能力，窄域可验证任务上专用小模型可能大幅降低成本。两个结论均要求独立任务集复验。
- **下游展开**：讲测量有效性、检测器校准、弃答权衡和任务可验证性；避免用 Antares 外推通用编码能力。

### 9. Agent 状态连续性：共享工作区、动态工具和确定性修复

- **核心事实**：SWE‑Touch 中并发用户编辑令 9 模型平均 resolve 下降 7.7pt，63.3% 失败仍保留冲突。ScrambleToolBench 的动态映射/失败压力令完成率 0.93→0.03，memory 仅恢复至 0.09。Agent Sentinel 冷迁移 AUROC 0.527、目标重校 0.885；rollback rerun 恢复 45% vs 重采样 16%，成功率 52→73%。
- **证据边界**：三项均为作者基准；真实团队并发、副作用补偿、工具 API 演化和生产误报尚未复现。Sentinel 对 organic fabrication 只抓到 1/3。
- **判断增量**：agent 失败的新共同机制是外部状态持续变化与内部信念滞后。通用 memory/分类器的可靠性下修，任务内可验证重算与回滚价值上修。
- **下游展开**：围绕锁/rebase、版本化 tool map、幂等、checkpoint 和补偿事务；避免重复“agent 会犯错”的泛化论述。

### 10. Agent 与服务栈信任边界：HMAC、控制标记和稳定版状态跃迁

- **核心事实**：TRT‑LLM disaggregated proxy→worker 的地址与 opaque state 新增 HMAC，篡改请求拒绝；改动 breaking、仅 main。Unsloth 两轮 PR 暴露 `</think>` 泄露、Harmony 角色伪造及修复后 tool-call 晋升问题。OpenAI Agents Python v0.19.3 已把 Realtime text guardrail、delayed audio scope、工具名碰撞和副作用持久化修复纳入稳定 release；JS 相邻修复仍在 main。
- **证据边界**：前两项没有 CVE、利用或受影响稳定版范围；Agents 需要验证升级采用、历史 state 和真实事故。
- **判断增量**：内部网络、模板控制标记和工具副作用均成为显式安全/状态边界；Python 从 main 修复进入稳定 release，满足重开条件。
- **下游展开**：核密钥轮换、默认部署、模板版本、跨响应取消、幂等和补偿；不要把 main-only PR 写成已修复所有用户版本。

### 11. 推理运行时：静默错算、竞态与集群尾延迟

- **核心事实**：vLLM Kimi K3 padded-row stride repro 最大 diff 6.66；MRv2 多 wave 可让不同层读取不同 accepted-token state。GB300 NVL72 加载 DeepSeek‑V4 时 12 个 node instance 有 7 个 stall，单 rank 从约 3 分钟拖到 36 分钟至 4 小时以上；pinned staging 24 个实例 0 stall，但健康路径慢 10%—15%。
- **高价值 P2 补充**：MLX 同名 kernel cache 可静默串码；SGLang ring parallel、Pi0.5 scaling 和 FlashMLA LSE 暴露外部参考/并行语义缺口；llama.cpp blockreduce race 与 GGUF guards、FlashInfer NVFP4 64 位寻址均已合并；TRT‑LLM TriAttention 给出 1.61× 作者吞吐但限制很多。
- **证据边界**：多数是 main 或 merged PR，稳定版、生产发生率、模型级质量损失和独立复现未齐。GB300 的 driver/硬件根因未确定。
- **判断增量**：正确性风险来自布局、状态提交、并行语义、寻址和缓存键；集群速度差异还能掩盖竞态。发布验证需覆盖模型×GPU×拓扑×并行配置。
- **下游展开**：优先选一个静默错算和一个尾延迟案例说明验证矩阵；避免逐条念 PR，也不把 bug 数量外推为某框架整体质量排名。

### 12. 机器人数据与推理 ASIC：规模证据仍需任务同口径

- **核心事实**：Ego2Robot 把约 1,940 小时第一视角视频转成 18,561 小时、15 种机器人形态，RoboTwin raw 28.1% 提至混合数据 37.3%，并给出 5 个实机任务。Rebellions CEO 称 SK Telecom 近三年扩至接近 100 racks、每日 5,000 万 API calls，KT Cloud 用于高速公路 CCTV，4—5kW/server 可风冷。
- **机制补充**：action chunking 论文把收益拆为非 Markov expressivity、降低 compounding error 和隐式 ensemble；SGLang Pi0.5 事件提醒机器人 serving parity 需要官方外部参考。
- **证据边界**：Ego2Robot 效果和生成小时为作者口径；Rebellions 的 calls、功耗和采购成本来自 CEO，缺 token、模型、精度、SLA、电表、收入及 SKT 独立确认。
- **判断增量**：跨形态合成数据和非 GPU ASIC 都出现更接近实机/生产的线索，可采用概率上修；经济性与普适性仍保留折扣。
- **下游展开**：核逐任务成功率、生成成本、许可、rack/SKU、同工作负载 tok/s/W 和客户确认；避免用 calls 直接推算 tokens 或收入。

### 13. Baseten 深访：开放视频经济性与集群可复现性反证

- **核心事实**：Baseten 工程人员称媒体客户即使开放模型推理便宜 100 倍，仍多选 Veo/Kling；5 秒、16fps、480p 示例压缩后有 31,500 latent tokens，全注意力 O(n²)，5—7 秒续接会漂移/变暗。另一个事故中，同权重 GLM endpoint 只在某 cluster/SGLang 组合重复同 token，较慢跨节点 KV transfer 暴露 kernel race/missing barrier。
- **相邻信号**：GLM‑5.2 可在 coding harness 中 profile serving 节点并编写替代 kernel；受访者同时承认 reward hacking 和差决策，未提供 commit 或 before/after。
- **证据边界**：均来自单一服务商访谈，缺客户分母、同任务质量成本 benchmark、公开 issue、版本、发生率和事故影响。
- **判断增量**：开放视频的成本优势可能被质量和长时建模抵消；集群互联与调度能决定 correctness bug 是否暴露。短期商业追平概率下修，推理验证对跨集群复现的要求上修。
- **下游展开**：核模型/engine/image/GPU/互联、公开 patch、Veo/Kling 同口径成本质量和续接评测；避免重讲 8 月 3 日已深播的 MiniMax H3 权重与硬件路径。
