- **agent 运行与安全：** Azure Agora 量化工具时间和资源错配；LoginTrap、CoT 隐式影响、requester-aware authorization 分别覆盖认证、监控和权限来源。
- **研究机制：** latent-KV 因果审计警告共享 cache 可能被误读为通信；skill benchmark 把触发和合规拆开；AFD Ledger 把 attention/FFN 拆分收益限定在硬件互补条件。
- **开放模型：** K-EXAONE 2.0 的新内容来自 8/4 技术报告，权重并非当天首次发布。Kimi K3 的新内容来自跨 runtime 修复和挂起复现，旧模型发布与 8/5 KDA signal 不再重复展开。

## 优先候选研究包

### 1. Sandisk + Western Digital：存储景气的量、价与合同

- 核心事实：Sandisk 数据中心收入 $2.977bn、QoQ +103%，总收入环比增长约三分之二来自 pricing；NBM 累计 10 份。Western Digital 收入 $3.747bn、FCF $1.28bn，下一季非 GAAP 毛利率指引 55%—56%。
- 支持证据：两家公司同日一手财报、现金流/毛利与长期协议同步改善。
- 反证与边界：Sandisk 84.6% 毛利率可能包含周期性供给紧张；NBM 的最低量、期限和取消条款未披露；WDC GAAP EPS 含 $2.05bn 非现金收益。
- 新洞见：AI 存储链的当日增量集中在价格和合同结构，不能只用出货量解释。任务二可比较“单位 bit 价格、协议覆盖、实际 bits”三条验证线。
- 不应重复：HBF 架构、HBM/HDD/NAND 公司名单和“推理会产生更多数据”的通用背景。

### 2. SciCode-Verified：基准缺陷造成能力判断反转

- 核心事实：263 个缺陷、192 个压分项、91% 主问题受影响；78% 缺陷需领域知识。修正后主问题通过率跃升 42—65 个百分点。
- 支持证据：论文与公开代码，包含逐题修订和 12 个模型重跑。
- 反证与边界：模型可能接触修正内容；“修正后变容易”也可能来自删除不合理约束；尚缺独立科学家复核。
- 新洞见：科学 coding agent 的能力瓶颈需要把模型错误、任务规范错误和 evaluator 错误分离。旧 SciCodePile 仅作科学代码难度基线，不作被推翻结论。
- 最值得验证：缺陷类型分布、模型排序是否变化、修复题能否进入盲测、第三方领域专家一致性。

### 3. Azure Agora：agent 服务的资源模型变化

- 核心事实：逾 27% 请求的工具时间不低于推理；GPU SM 多低于 55%，CPU 6%—31%。角色池化使 CPU demand 降 46%；GPU 调度可释放约三分之一设备并提高吞吐 82%。
- 支持证据：24 小时 Azure 生产 trace 与四框架、96-core EPYC/8×A100 实验。
- 反证与边界：公开论文无法说明 Azure 全网代表性；工具任务的隔离、安全、I/O 和客户 SLO 可能限制共置。
- 新洞见：agent 基础设施容量规划需要同时预测工具、协调、CPU burst 与 GPU 推理阶段；只按 token throughput 采购会高估持续 GPU 需求或低估 CPU 峰值。
- 最值得验证：单位请求成本、峰值并发、隔离开销、GPU 代际、浏览器/代码执行占比和生产 rollout。

### 4. 推理运行时静默失真：五种不同根因

| signal | 根因 | 可观察结果 | 当前边界 |
|---|---|---|---|
| Qwen3.5 / SGLang | padded position 与 DCP KV slot 冲突 | HTTP 200；GSM8K 112/128→126/128 | PR 已合并，stable 与跨任务待核 |
| DeepSeek V4 / SGLang | SWA/hierarchical cache 位置与 default depth | NaN 或少量错算；部分配置 26k+ 零错 | 用户生产复现，缺正式 RCA |
| Kimi K3 / 多 runtime | RoPE OOB、page lifecycle、误量化、低并发挂起 | 静默污染、质量风险、hang；另有 +58% 性能主张 | 多 PR/issue，需统一质量矩阵 |
| llama.cpp / ROCm | 异步执行顺序 | Qwen3 perplexity 约 88 vs 9.4 | b10293 已修部分路径，Jamba 遗留 |
| vLLM backend/offload | 并发数值分簇、state 重复 | logprob 三簇或精确边界后分叉 | 单/小规模复现，维护者结论待定 |

共同的新判断：上线验收至少需要固定模型权重、后端 commit、kernel/quant、并行拓扑、batch/cache 分布和任务级质量；HTTP 状态、进程退出和单一吞吐 benchmark 均不足。旧的 NVFP4、KDA、DeepSeek 可运行性背景只保留一行。

### 5. Netlist—Samsung：上限、最低量与现金实现

- 已确认：五年交叉许可、首付款、20 季季度上限、五年许可上限、年度/五年供货上限、低价股权认购和 ITC 信息协作。
- 边界：合同披露的是多个“最高”金额，不能直接当最低现金流或采购承诺；$1m/1,000 万股带来稀释与治理问题。
- 新洞见：专利争议开始改变 Netlist 的现金、供货和诉讼资源约束。投资映射应跟踪实际收款、采购毛利和库存周转。
- 禁止外推：Micron、Google 或其他对手必然跟随；Samsung 供货等于 Netlist 高毛利 AI 内存收入。

### 6. Solaris：AI 现场电力合同的交付链

- 已确认：三项合同扩围新增预期年化调整 EBITDA 超 $100m；Hatchbo 约 660MW，含电厂 BOP、BESS 和 workload EMS，十年基础期加八年 option。
- 边界：950MW 是已运行总量，660MW 属未来 Hatchbo 交付；八年属于选择期；EBITDA 为公司预期。
- 新洞见：现场电源价值从设备租赁扩到电厂、储能与 workload 能源管理，合同期限更长，执行与资本风险也更集中。
- 最值得验证：客户信用、设备采购、燃料与并网、融资、阶段验收、取消/最低支付和首批收入。

### 7. PCB、时钟、封装与测试：横向确认但口径不统一

- TTM 给出收入占比、同比和 book-to-bill；SiTime 给出 CED 增速；Amtech 给出 AI 相关收入、订单和 backlog；MKS 给出分部收入与管理层 AI 归因。
- 支持：四条信号覆盖高速 PCB、同步、回流焊/服务器板组装和半导体/封装设备，均来自窗口内公司材料。
- 反证：SiTime organic bridge 为推断；Amtech/MKS 的 AI 定义不透明；VIAVI 含并购，KLIC 未量化 AI。
- 写稿机制：比较“收入已确认、订单/积压、管理层主张”三层证据，避免把不同口径相加成行业增速。

### 8. Agent 安全与能力边界：监控、认证、权限、skill

- CoT monitor 在隐式影响下掉 41—46pt，真实 system prompt 设置检出仅 5%。LoginTrap 在认证边界报告平均 86% 成功率。requester-aware 测试把同一操作从 26/32 降至 0/32。Skill benchmark 最佳 0.613，触发与合规独立。
- 新洞见：风险控制需要覆盖信息影响是否显式、谁发起动作、skill 是否被调用以及调用后是否遵守四个环节。
- 证据边界：均为作者实验，尚无统一真实产品事故率；不同 task/harness 不能直接横比百分比。
- 验证问题：默认权限、用户确认、prompt injection 传播、false positive、审计工件、side effect 与跨 harness 复验。

### 9. AFD、latent KV 与 K-EXAONE：架构收益须带因果和部署条件

- AFD Ledger 把拆分收益限定在硬件互补性和流量组合；latent-KV 审计显示 cache 效应可能来自共享计算状态；K-EXAONE 报告提供训练与 DSpark 细节，但性能来自作者配置。
- 新洞见：架构创新的可用结论应同时给出质量、硬件拓扑、流量、因果干预和单位成本。
- 待核：K-EXAONE 训练数据/污染与独立 serving；AFD 网络/SLO；latent KV 的位置对齐与更多任务。

### 10. Aeva 与 Sunrun：商业化证据层级的正反样本

- Aeva 有正式 JDA、产品对象和 2027H2/2028 时间表，仍缺订单与收入承诺。
- Sunrun 的 16GW 为非约束 LOI，pilot 无新客户/MW/经济性，核心经营指标同时收缩。
- 新洞见：AI 产业链映射应把技术合作、试点、非约束意向、正式合同、交付、收入依次分层；当前两者分别停在 JDA 与 LOI/pilot。
