# 金融资料目录说明

本目录保存每日新闻、会议纪要、产业事件、行情估值、期权、成交量、财务日历和其他随时间变化的事实资料。

## 边界

- 本目录是可更新的上游资料库，不是公司调研、行业调研、分析报告或特征量化的正式结论目录。
- 默认不得用 `../基本面/特征量化/` 的评分、Signals、模型或筛选结论解释和改写金融事实。
- 只有用户明确要求量化复核或冲突检查时才读取下游结果，并把验证结论与日度事实分开标注。

## 工作规则

- 新闻、会议和金融数据必须标明日期；行情、估值、期权和财务数据必须标明采集日、收盘日或报告期。
- 新增日度文件优先使用完整日期命名，不覆盖既有日度文件；补充内容新建补充稿，除非用户明确要求追加。
- 公司和行业背景只从 `../基本面/公司调研/`、`../基本面/行业调研/` 及项目级资料读取。
- 执行中的筛选和计算写入 `../tmp/`；需要保留的一次性研究成品执行项目根目录规则。
