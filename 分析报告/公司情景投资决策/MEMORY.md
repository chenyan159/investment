# 公司经营评估与情景投资决策：方案迭代与跟进记忆

最后更新：2026-09-01

## 1. 文件定位

本文件用于记录 `研究方案.md` 的设计原因、重要迭代、已确定边界、运行反馈和后续验证事项，方便以后继续改进。

本文件不是单家公司研究的正式输入，不提供公司事实、估值参数或投资评级，也不应由 research runner 注入单家公司任务。当前有效研究规则始终以同目录下的 `研究方案.md` 为准；若本文件与研究方案冲突，应先核对最新用户要求，再更新研究方案和本文件，不能直接用历史记录覆盖正式方案。

维护时遵守以下顺序：

1. 先阅读最新 `研究方案.md`，再阅读本文件；
2. 用新结果或明确失败案例说明为什么需要修改；
3. 只修改真正影响条件判断质量的规则，避免不断增加外围章节；
4. 修改研究方案后，在本文件追加日期、原因、改动和待验证结果；
5. 历史结果用于发现方法问题，不反向作为新公司报告的上游投资结论。

## 2. 本方案在整体研究系统中的职责

本方案针对单一公司，先独立完成经营评估和价值传导，再从当前价格出发建立“经营情景 × 市场状态”的条件决策地图。它回答的是：公司如何从行业价值池中捕获收入、利润、现金流和股东价值，以及在某种完整经营结果和市场状态成立时，该股票的合理市值、每股价值、回报区间和条件建议强度是什么。

本方案不承担以下职责：

- 不进行公司之间的比较、排序或候选池选择；
- 不综合技术面、公司情绪、交易窗口或组合约束；
- 不给出仓位、买卖执行、止损或退出动作；
- 不把二十个格子、可选概率层或当前定位汇总成单一总体投资评级；
- 不替代公司调研、行业调研及其他独立研究方案；原独立公司评估职责已并入本方案。

因此，本方案的报告是整体投资研究系统中的一个独立输入，而不是最终投资决策。

## 3. 当前稳定设计

| 设计项 | 当前口径 | 主要原因 |
| --- | --- | --- |
| 核心结构 | 四种纯经营情景 × 五种市场状态，共二十个条件格子 | 保留条件判断，不依赖难以辩护的概率预测 |
| 经营情景 | 悲观、基准、乐观、突破均为完整、自洽的公司状态 | 防止只调收入或倍数而忽略利润、现金流、融资和稀释 |
| 基准情景 | 先从公司与行业上游资料建立不受当前股价影响的未来需求、供给、公司捕获、量价成本和再投资路径 | 防止把当前增速静态外推，也防止把历史均值当成未来必然结果 |
| 价值传导主轴 | 外部需求与行业供给 → 公司份额、交付能力与实现价格 → 收入 → 单位经济与利润 → 再投资、自由现金流与未来经营能力 → 股东可得价值 → 完全稀释每股价值 | 同时防止前端机会跳过公司捕获，也防止后端财务项目在未计算成长回报时截断价值 |
| 当前经营定位 | 当前证据向量默认归入最接近的纯经营行；只有达到实质差异门槛才使用复合定位 | 避免把普通区间差异写成缺乏可比性的混合状态 |
| 复合定位边界 | 至少有独立决定性环节冲突，且相对纯行造成约 10% 每股价值中点变化、建议跨级或新增融资/永久损失风险；只连接当前证据与纯矩阵，不成为第五行 | 既保留真正重要的混合状态，又抑制复合定位泛化 |
| 经营行与建议 | 先计算完整价值链和每股价值，再标记建议；悲观不预设负面，突破不预设正面 | 消除“悲观全不投、突破全可投”的模板化对称 |
| 市场状态 | 同一市场范围、截止时间、来源和规则版本形成唯一快照身份；同身份报告必须使用相同主状态、相邻状态与记分板 | 防止单家公司反向选择有利市场列 |
| 板块轮动 | 作为市场状态内部修正，不成为第三个平权维度 | 保留公司和行业差异，同时避免维度爆炸和重复计价 |
| 状态联动 | 纯格子之外列出二至四条重要经营—市场迁移路径 | 区分“经营行不变时怎样”与“现实中可能向哪一行移动” |
| 再投资处理 | 区分维持性、已承诺成长性和可选成长性投入；报告现金流负责现金与融资，估值现金流必须同时纳入成长投入及其未来回报 | 避免只扣成长投入不计未来能力，或只计增长不扣投入、折旧、融资和稀释 |
| 估值方法 | 反向估值、近端兑现、中长期经营路径、现有经营与再投资分解、分部或期权估值从价值传导链接续；收入倍数必须桥接单位经济、再投资、现金、净债务和稀释 | 估值方法是约束同一价值区间，不是独立投票维度或绕过现金的捷径 |
| 建议标尺 | 先声明研究要求回报，再按永久损失、区间低端、模型一致性和区间中高部依次判断 | 减少相似回报区间得到随意不同建议的问题 |
| 不确定性 | 状态证据强度与估值置信度分开 | 区分“情景目前多可达”和“情景成立后估值多可靠” |
| 非概率解释 | 报告价格距离、经营证据距离、市场依赖、正面区域宽度、基准稳健性、压力韧性、突破依赖和最弱传导环节，不合成分数 | 在不伪造概率的前提下说明当前到正面区域的路径与脆弱性 |
| 概率层 | 可选；无可辩护联合概率时写 `NA` | 避免用主观精确概率掩盖矩阵边界 |
| 报告收束 | 输出当前条件定位与矩阵摘要，不输出总体投资结论 | 本方案只是众多研究方案之一，不越权完成综合决策 |

## 4. 迭代记录

### 2026-09-01：合并公司评估与公司情景投资决策

- `company-investment-decision` 成为唯一正式的单公司经营评估与情景决策任务；原 `company-evaluation` domain、命令和独立输出退出活动链路。
- 方案直接读取公司调研、行业调研和金融事实，不再把旧公司评估报告作为上游答案。
- 增加公司经营类型与重要业务池识别，并把披露事实、可复核推断、情景估算和关键未知分开表达。
- 明确允许对模糊的收入、产能、订单、价格、份额和价值池作机制驱动的区间或数量级估算，同时要求推断链、敏感性和反证，避免因缺少公开单点数字错过重要 insight，也避免伪精确。
- 保留既有四种经营情景、五种市场状态、共享市场快照、价值传导、完全稀释每股价值和条件建议边界；合并后的单公司任务量不高于原公司情景任务量。
- 旧公司评估目录和结果改为淘汰历史区；公司对比的新运行改读本目录结果，历史排序方案原文不改。

### 2026-07-13：建立第一版方案与 runner domain

第一版确立了以下核心框架：

- 从当前价格反向求解隐含收入、利润率、现金流和长期要求；
- 建立悲观、基准、乐观、突破四种经营情景；
- 建立宽基风险扩张、窄幅主题上涨、震荡均值回归、有序风险收缩、流动性信用压力五种市场状态；
- 在每个格子内部使用适合公司的多种估值方法；
- 重大利好和利空通过事件树改变经营路径、时间或估值条件，不单独重复加分；
- 概率汇总置于完整矩阵之后，并允许直接写 `NA`。

同时明确删去或不采用以下内容：

- 不读取 `技术面/` 和 `情绪面/公司情绪/`；
- 不加入繁琐的投资资格与数据质量闸门；
- 当前价格和资本结构只保留股东价值计算必需信息；
- 不加入投资动作、仓位尺度和交易执行；
- 不在正式报告中加入独立审计检查与失效模式章节；
- 不在研究方案末尾写死输出目录和 runner 文件操作说明，输出路由由 runner 负责。

research runner 新增 `company-investment-decision` domain，正式方案来源为本目录 `研究方案.md`，结果范围为本目录 `结果/`。

### 2026-07-13：首批十一家公司运行与复核

首批样本为：

`ADBE`、`AMD`、`ETN`、`GLW`、`HPE`、`MU`、`SMCI`、`SMR`、`STM`、`VST`、`WOLF`。

首批结果证明了框架的主要价值：

- 能区分“公司经营优秀”和“当前价格值得投资”；
- 能识别高增长但已经透支估值的股票；
- 能把融资、稀释、优先索取权和普通股残值纳入高风险公司；
- 能显示同一经营结果在不同市场状态下的建议变化；
- 没有为了得到单一结果而强行赋予概率。

同时暴露出五个重要问题：

1. `MU`、`SMCI` 等公司的现实状态横跨多个经营行，单一“当前最接近基准”会丢失重要信息；
2. 同一日期、相近市场数据下，不同公司报告可能把当前市场分别判断为宽基上涨或主题上涨；
3. 相似甚至更宽的回报区间可能得到不同建议强度，缺少统一校准顺序；
4. 单一“置信度”混合了情景可达性与估值可靠性；
5. 市场恶化可能同时改变估值和公司经营，纯矩阵需要与现实状态迁移分开表达。

### 2026-07-13：第二版核心修订

根据首批结果，研究方案增加并贯通了以下规则：

- 增加“当前证据向量与复合经营定位”；
- 规定同一时点、同一市场范围使用统一市场快照；
- 明确纯矩阵中同一经营行的经营变量不能随市场列悄悄变成另一行；
- 增加少量重要状态联动，并禁止与纯格子重复计价；
- 增加研究要求回报和六档条件建议的统一判断顺序；
- 将状态证据强度与估值置信度分开；
- 要求报告把当前定位和紧凑矩阵放在前部，减少二十格之间的重复叙述。

这些修改重点解决矩阵解释和当前定位，不增加技术面、情绪面、仓位、资格闸门或独立审计章节。

### 2026-07-14：192 家全量结果复核与第三版核心修订

对 192 份新版结果和 3,840 个主矩阵格子的复核表明，第二版的结构比第一版完整，但仍有四个系统性问题：

1. 当前条件建议高度保守：47 家为“强烈不建议”、69 家为“不建议”、53 家为“中性 / 等待”、22 家为“谨慎建议”、1 家为“建议”，没有“强烈建议”。这不必然错误，但需要用价格边界和传导瓶颈说明保守来自哪里；
2. 约七成公司使用复合经营定位，说明第二版把复合状态从必要例外变成了常用表达，削弱纯经营行的可比性；
3. 同一美国市场范围和相近截止时间仍出现 167 家宽基风险扩张、11 家主题主导上涨、14 家震荡的不同当前分类，证明仅在文字中要求“统一快照”不足以形成真正共享输入；
4. 悲观行没有任何正面格子，而每家公司突破行至少有一个正面格子；各行正面格子占比分别约为 0%、9.7%、53.8% 和 81.9%。这显示经营情景名称仍在暗中预设建议方向；
5. 多家公司在需求、订单或收入环节已经很好，但价值链在利润率、FCF、净债务、融资、稀释或每股价值环节被截断。旧方案虽要求这些数字，却没有把它们组织成每个情景和估值共同使用的强制传导链。

本次只修改 `研究方案.md` 和本文件，没有修改 runner、队列、上游资料或正式结果。研究方案不是零散追加规则，而是沿“目标—情景—事件—估值—矩阵—解释—报告结构”重新贯通以下核心口径：

- 将 `需求 / 订单 / 项目 → 收入 → 利润 → FCF → 股东可得价值 → 完全稀释每股价值` 设为当前证据、四种经营情景、事件树和估值的共同主轴；每家公司和每个情景都要给出桥接表与最弱传导环节；
- 纯经营行恢复为当前定位默认值。复合定位只有在独立决定性环节冲突，且相对最近纯行造成约 10% 每股价值中点变化、建议跨级或新增融资/稀释/永久损失风险时才成立，并必须给出纯行至复合价值桥；
- 市场状态改为带身份的共享外部输入。同一“市场范围｜截止时间｜来源日期｜规则版本”必须产生完全相同的记分板、主状态和相邻状态；没有共享快照时只能并列两列降级展示，不能由公司报告自行挑选；
- 经营情景与建议方向完全解耦。悲观行可因价格或资产保护而正面，突破行可因价格透支、资本投入或稀释而负面或 `NA`；先计算每股价值，再赋建议标签；
- 事件必须写明首个受影响环节和到每股价值的下游路径；收入或订单倍数必须桥接利润、FCF、净债务、融资和稀释；

### 2026-07-15：未来经营基准与再投资传导的第四版升级

第三版代表性结果复核暴露的不是某一家公司的个股问题，而是可跨行业重复出现的方法缺口：

1. 报告会引用公司调研和行业调研，却不一定把未来行业需求、供给与价格逐步桥接到公司份额、合格交付能力、实现价格和收入；
2. 对当前高增长或高利润公司，容易在“不能静态外推”之后直接采用历史均值回归，缺少未来季度的量价成本机制；涨价速度放缓可能被误写成价格或毛利率下降；
3. NTM、目标期与 3—5 年稳态容易成为三组独立数字，近端指引与 NTM 平均利润率之间没有分期加权勾稽；
4. 高资本投入公司可能在报告现金流中被完整扣除成长性投入，但其形成的未来产能、产品、客户、效率和增量回报没有同步进入估值；
5. 现金、债务、资本开支或稀释位于价值链后端，容易因字段明确而比证据更不确定但决定性更强的未来需求、价格和份额获得过高叙事权重。

第四版没有增加新的外围评分、总体结论或投资动作，而是重构现有核心口径：

- 研究顺序改为先建立独立未来经营基础，再反向求解当前价格；基准吸收上游资料中已可见或有较强证据支持的未来增长、下降、量价、供给、产品和再投资，不等同于当前经营外推或历史平均；
- 每个主要业务池建立“未来需求单位—行业供给与价格—公司份额与交付能力—数量与实现价格—收入与利润确认”的对应表，行业 beta 与公司 alpha 分开；
- 明确区分价格水平、价格变化方向和价格变化速度。利润率上升或下降必须由价格、组合、单位成本、良率、利用率、折旧或履约成本解释；历史异常本身不能决定未来方向；
- 当量价或利润率快速变化时，要求建立 NTM 分期路径并与年度收入和毛利润加总一致，禁止近端指引与显著不同的 NTM 平均值之间没有过渡机制；
- 将投入分为维持性、已承诺成长性和可选成长性；报告口径现金流用于现金积累和融资，估值要么在逐期现金流中同时纳入全部投入与未来回报，要么用维持性现金收益估值现有经营并另加风险调整后的成长项目净现值；
- 新增供给同时考虑公司交付能力上升和行业价格可能承压的反馈，禁止只保留有利一端；
- 现金、债务和资本结构按每股价值及相对重要性处理。没有融资、到期、履约或重大价值影响时保持算术正确但简化叙述；足以改变普通股价值时才作为决定性瓶颈；
- 中长期“正常化”改为有供需、合同、竞争、产能、成本和再投资机制支持的稳态路径，不再默认等于历史均值。

## 5. 不应轻易破坏的边界

后续迭代默认保留以下边界，除非有明确的新证据或用户要求：

1. 每次只研究一家公司，不读取其他公司的投资决策结果；
2. 不读取公司对比、公司排序、特征量化结论、技术面、公司情绪、备份和临时文件；
3. 四种纯经营情景和五种市场状态仍是唯一主矩阵；纯经营行是当前定位默认值，复合定位必须达到实质差异门槛且不能扩展成第五行；
4. 经营情景名称不预设建议方向；条件格子的建议也不能因为该情景当前证据低而机械降级，情景可达性单独记录；
5. 当前定位不能借用低证据乐观或突破格子的上行，也不能因近期强劲而跳过长期单位经济、再投资、资本结构和每股稀释；反过来，也不能用历史均值或短期成长投入在缺少因果机制时抹去上游未来证据支持的经营改善；
6. 市场状态由共享快照决定；同一快照身份必须得到同一主状态和相邻状态，公司和板块相对表现只进入板块修正；
7. 当前定位、四种经营情景、事件树和估值必须使用同一条从外部需求与行业供给、公司捕获、量价成本、再投资和现金到完全稀释每股价值的传导链；
8. 经营变量、成长投入与未来回报、市场估值影响、事件影响、资本桥和状态联动不得重复计价或只处理一端；
9. 概率层不能替代完整矩阵，也不能为了得出正期望而强行赋权；
10. 本方案不输出总体投资评级，不承担排序、仓位或组合决策；
11. 方案完整性依靠逻辑链和边界，不靠增加大量外围章节。

## 6. 第四版结果的重点验证事项

下一批第四版结果完成后，优先验证以下问题：

| 优先级 | 验证事项 | 通过标准 |
| --- | --- | --- |
| P0 | 基准是否真正面向未来 | 基准从公司与行业上游资料中的未来需求、供给、价格、公司捕获和已承诺再投资建立；不以当前季度增速静态外推，也不以历史均值直接替代 |
| P0 | 行业判断是否到达公司结果 | 每个决定性业务池都有需求单位、行业供给与价格、公司份额与交付能力、数量与实现价格、收入与利润确认的对应关系；行业 TAM 不直接变成公司收入 |
| P0 | 量价成本与利润率是否因果一致 | 区分价格水平、变化方向和变化速度；利润率变化由价格、组合、成本、良率、利用率、折旧或履约解释；近端指引与 NTM 平均值有分期加权桥 |
| P0 | 再投资是否避免单边惩罚或免费增长 | 维持性、已承诺成长性和可选成长性投入分开；成长投入与投产、增量利润、ROIC、回收期、融资和稀释同时进入同一情景；没有只扣投入不计回报或相反情况 |
| P0 | 价值传导链是否真正决定估值 | 当前定位和四个经营情景均有外部供需至完全稀释每股价值的可复核桥；最弱环节进入价值低端和转正条件，订单、收入或财务字段不再直接跳到目标价 |
| P0 | 复合定位是否恢复为必要例外 | 每个复合定位都有最近纯行、实质差异门槛和价值桥；未达到约 10% 中点变化、建议跨级或非线性资本风险时使用纯行 |
| P0 | 同身份市场快照是否完全一致 | 同一范围、截止时间、来源和规则版本的五块记分板、主状态、相邻状态及证据强度一致率为 100% |
| P0 | 经营行与建议是否独立 | 不再机械出现“悲观必负面、突破必正面”；若仍呈现该形状，每家公司均有价格、资产或资本结构的独立解释 |
| P0 | 企业价值是否完整到达每股价值 | 经营价值、现金、债务、优先索取权、融资和完全稀释股数的桥可复核；未盈利公司明确现金跑道与融资稀释 |
| P1 | 财务字段权重是否符合重要性 | 现金、债务、CapEx 和稀释均有正确算术；无重大融资或每股价值影响时保持简洁，足以改变普通股价值时才成为决定性瓶颈 |
| P1 | 转正距离是否可操作但不伪装成概率 | 价格边界、最少经营里程碑和市场依赖分开列示，不加权成总分或总体评级 |
| P1 | 条件建议是否按统一标尺生成 | 相似回报区间的建议差异能由永久损失、区间低端、融资稀释或模型分歧解释 |
| P1 | 状态联动是否避免重复计价 | 纯格子保持经营行定义，联动写明首个受影响环节并只描述向另一经营行迁移 |
| P1 | 当前部分是否仍保持职责边界 | 只输出当前条件定位与格子建议，不出现综合投资评级、排序、仓位或交易动作 |

建议继续按不同经营类型选代表性公司做回归检查，而不是围绕单一公司调参：

- `MU`、`STX`、`WDC` 等周期与资本密集公司：行业未来需求、供给和价格能否先到达公司量价成本；高利润率变化是否有因果桥；成长性建设投入是否同时计入未来回报；
- `SMCI` 等营运资本密集公司：收入订单、单位经济、营运资本、融资与稀释是否被同一条传导链处理，且不会因前端增长强而跳过现金风险；
- `ADBE` 等资产较轻公司：R&D、获客和产品投入不会被机械当成全部损耗，也不会在缺少收入化证据时免费资本化；
- `ETN` 与其他产能扩张公司：行业需求、backlog、产能、价格、投资、投产爬坡和增量 ROIC 是否处于同一基准；
- `WOLF`、`SMR`、`RKLB`：突破路径的项目价值是否先扣除融资、资本投入、优先索取权和稀释，且允许突破行仍不正面；
- 低估值、净现金或资产保护公司：悲观行是否能够在事实支持时出现中性或正面格子，而不是被情景名称压成负面。
