## 主要结构变化及理由

| 研究环节 | 本版安排 | 需要解决的问题 |
|---|---|---|
| 研究主线 | 六个一级章节，以业务经济判断和发展进程展开，资本、定价和选择承接同一模型 | 避免围绕输出矩阵反复建立相似计算与说明 |
| 业务研究 | 具体研究客户付费与采用、竞争及价值捕获、商业化与复制、利润现金及持续性，形成最强替代解释 | 量价拆分能解释收入构成，却未必约束收入预测；潜力业务不能仅因当前体量小被忽略 |
| 时间 | 业务使用自身阶段、财季和事件窗口；四情景股价采用研究员选定的共同主要目标日 | 取消固定一年／三年／七年，但保留现金发生时点和可比较的股价预测时间 |
| 概率 | 允许情景内部尚未解决的高风险业务计算状态期望，明确概率对象、覆盖、条件、失败成本与延期；不对四种公司情景赋权 | 避免阶段成功混同规模盈利、代表点冒充均值，以及精细加权超过证据能力 |
| 公司情景 | 原样保留四种经营情景定义，以最少必要成功构造突破，可补充重要尾部压力 | 不要求所有业务同时取最好或最坏，也不把四行视为完整概率分布 |
| 资本权益 | 保留再投资、资金缺口、融资可得性、稀释和原股东权益；集中检验关键资本假设 | 业务成功不保证当前股东获益；融资价、分配和回购不能静默决定结果 |
| 估值与选择 | 将价值、目标日市场定价、敏感性、反求现价和当前选择集中到第五章 | 区分条件经济价值与预计股价，不用DCF滚动充当独立市场预测 |
| 情景证据 | 新增“情景证据支撑度”：强／中／弱／不足，评估关键前提覆盖、可信度、独立性、规模时间及反证 | 接纳产业消息、社区研究、未证实线索和有依据推断，但不按消息数量或正式程度机械判断，不转换成情景概率 |
| 最终输出 | 四行情景分别展示经营资本状态、预计股价区间、涨跌百分比、证据支撑度；只形成一次当前投资选择 | 去除十二格和逐行情景条件评级，减少估值、回报、矩阵和理由重复 |

## 保留的边界与研究自主权

- 三个本地输入目录不变：`基本面/公司调研/结果/`、`基本面/行业调研/结果/`、`金融资料/每日金融数据/`；独立联网取证保留。
- 正文保持独立，不介绍项目、执行工具或方案迭代历史，不引用历史决策作为研究依据。
- AI研究员自主划分业务、选择调查顺序、节点、模型、必要分支及报告顺序；要求解决经济问题，不要求所有业务套同一清单、同等篇幅或复杂随机模型。
- 保留未知事项查证、现价不能唯一识别经营假设、未量化机会不自动归零、重大机会独立成功、最强反证、等待成本、终值与更新投入等研究细节。
- 股价输出保留真实预测边界：四行需形成有时点与假设的涨跌估计；薄弱机会可以作明确条件下的宽区间探索，无可辩护机制时不得编造精确股价。

## 后续实际效果的检验问题

本版尚无实跑报告。后续观察应跨多家公司和商业阶段，并与固定的历史报告比较，分别识别事实、行情、参数选择、模型随机性及方案结构的影响：

1. 业务收入和利润是否由真实客户、支付、交付、竞争及成本约束推导，是否仍有先定规模再构造量价解释的情况。
2. 新兴业务是否区分首次收费、规模盈利、复制及更新，延期和融资是否真实改变路径；正文是否把重要机会讲深而非只给多组数字。
3. 四行情景是否都有清楚的目标日、价格与百分比，能否解释目标日信息及市场定价；是否仍将DCF时间滚动误标为预计股价上涨。
4. 情景证据支撑度能否区分直接证据、推断、传闻与反证，是否被误用成概率、投资评级或第二次风险折扣。
5. 四种公司情景是否确实没有概率加权；业务风险期望是否保留失败成本、阶段依赖及非线性资本权益。
6. 是否减少重复展示而保留必要复核信息。篇幅短、推荐数量增加或运行成功均不单独构成质量提高的证明。

后续研究执行记录、实际质量发现及预测兑现应追加到本文件，当前不预填结果。
