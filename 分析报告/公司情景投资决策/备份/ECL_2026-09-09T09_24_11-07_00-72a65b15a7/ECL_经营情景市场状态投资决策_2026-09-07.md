## 1. 当前判断、研究时点与最重要的限制

**按279.28美元买入，当前判断为：短期不建议投资，中期不建议投资，长期中性／等待。** Ecolab有真实的定价、现场服务和客户资格优势，CoolIT也已是有规模收入的业务；问题在于收购成本、后续投入和当前支付的增长溢价。当前证据最接近本报告基准经营路径，尚不足以证明低资本成本、高再投资回报和十年以上强增长可以同时实现。

**短期合理价值回报不是六个月股价跌幅预测。** 主矩阵采用扣足投入的目标日剩余现金价值，回答“这条经营路径能否支持今天的买价”；另用目标日NTM盈利倍数研究可能的市场定价及复利投资理念。两者差异很大，不能把主矩阵的负回报当作已证明会发生的交易损失，也不能把市场可能继续维持溢价当作现金安全边际。

| 期限 | 当前实际选择 | 主要预期差与独立理由 | 最少新增证据 |
|---|---|---|---|

长期“等待”保留有经营证据的复利理念，并非主现金法已经支持买入。若必须在今天的279.28美元立即作二元选择，本研究三个期限均选择**暂不买入**。等待可能错过技术认证、长期合约使市场迅速提高估值的上涨；这项代价在事件表和盈利倍数分歧中显式保留。

## 2. 公司全貌、上游证据与财务质量

ECL的基础商业模式是化学配方、投加设备、现场服务和客户生产资格的组合。客户买的是合格清洁、减少停机、提高产品良率和可靠运转；节水及减少人工可以支持价格，却不自动成为ECL收入。对客户创造100美元价值，也可能只收取几美元。新增液冷硬件提高可触达预算，但增加了OEM采购集中、库存、质量责任和换代风险。[年报][S01]

### 2.4 会计、现金、治理和资本质量

1. **利润调整不等于经济成本消失。** Q2 GAAP营业利润0.7579与调整后0.8090相差0.0511。One Ecolab重组、整合、法律等费用需看是否持续；并购无形摊销已有部分留在公司调整后EPS中。本文分部利润扣集团摊销与费用C，再在现金桥留X，不把分部利润直接全部分给股东。
2. **现金季节性明显，H1并未全面改善。** H1 FCF 0.5868低于上年同期约0.6166；应收、库存、其他资产合计消耗现金，部分由应付增加抵销。H1股息0.4241加回购0.6693=1.0934，超过H1 FCF 0.5066。Q4通常释放现金，不应年化Q1低谷，也不能忽视这项资金竞争。
3. **收购现金已花。** 6月底净债13.1762−5.1353=8.0409；7月2日支付4.75后机械净债12.7909。发债已在6月底负债中，不能再加一次；47.5亿美元并购也不能在未来FCF中再扣一次。实际取得现金、交割调整及购买价分摊未完全获知，资本桥留±0.25十亿美元敏感性。
4. **债务有成本但不构成基准融资断点。** 2026年5月50亿美元新票据分别2029／2031／2033／2036到期，票息4.60%／4.80%／5.15%／5.35%，加权约5.01%；另有未提用循环额度。基准先付股息、保留成长投入并限制回购。约3倍交割杠杆、两年回到2倍是管理层目标，不能由一张现金表自动证明。[10-Q债务附注][S03]

6. **合同质量有局部未知。** 集团2025没有单一客户或经销商超过10%收入，不代表CoolIT没有共同AI预算集中。未取得毛取消、最低采购、完整验收／质保／赔偿上限；合作、NVIDIA具名评价和“backlog”不可改写为take-or-pay。

经营价值最弱的两段传导是：**客户增长到净收费／真实新增利润**，以及**并购和成长投入到资本回报／每股现金**。正常债务并非唯一问题；即使无股权融资，付出过高经营资产价格也会压低股东回报。

### 3.2 新机会：跨品牌持续冷却管理的状态树

CoolIT现有硬件与服务、传统3D TRASAR、已经商业化树脂继续按经营驱动预测。唯一足以显著改变集团结构、又尚未证明稳定独立收费的新路径，是**设备保修之外、跨品牌且覆盖冷却健康和现场响应的净新增服务E**。它可能减少客户的停机、维护和能耗，但ECL必须取得净收费和可控责任范围。已有设备部署及监测技术使“有限采用”比纯概念项目有更高机会；免费保修、自有运维、多源排斥及设备商捆绑使“规模持续收费”不能接近必然。

### 4.3 主估值选择、参数与时间一致性

主方法采用**逐期扣全部投入的FCFF-DCF**。理由是ECL已花费高额资本把业务扩展到设备、工程和平台服务，调整后EPS、EBITDA率和收购ROIC差异足以改变买入选择；现金法可以显式处理再投资、失败投入与减债。成熟消耗品的复利盈利法仍有解释力，见下一节，不被删除。

这项选择不声称DCF适合预测3个月市场成交价；短期交易采用程度没有可校准分布，**可能交易回报为条件区间而非主矩阵回报**。主矩阵价值可量化，价格何时采纳则置信较低，两者独立列明。

支持复利理念的证据是成熟业务现场网络与客户续购；支持现金纪律的证据是CoolIT初始29倍EBITDA收购、H1现金转换及工程／设备占比提高。现阶段不能证明整个平台未来持续获得约27%的资产增量回报，因此**裁决为主矩阵采用现金法，保留盈利倍数法对可能价格及另一投资理念的正面条件判断**，而不是向上平均以跨过推荐门槛。

若投资者坚持把短期“值得”定义为可以卖给维持30多倍PE的市场，乐观／突破行可以得到正面条件建议；这与主矩阵现金纪律不同，风险来自价格采纳而不仅是业务失败。没有可辩护的四情景联合发生率，本研究不把这种卖出机会称作精确正期望交易。

## 5. 条件建议矩阵与十二格明细

**预先使用的要求回报：** 短期6个月总回报8%，中期12个月12%，长期普通复利年化10%；高风险突破长期年化至少12%。这是研究的机会成本与风险补偿准则，不是收益预测。短期更高年化要求补偿事件窗口和估值采纳误差；普通长期10%约为承受权益和再投资风险的工作门槛。局部失败已经在经营现金中计入，评级不再机械加一次失败概率罚分。

## 6. 当前路径、价格边界、敏感性与最强反证

### 6.1 当前最接近哪条路径

当前最接近基准：Q2真实有机增长、价格落实和现场利润支持经营正常发展；CoolIT出货与收购前高增长使技术“无商业价值”的解释不成立。但Water利润尚落后收入、H1 FCF弱于股东支出、跨品牌净收费未充分披露，使乐观或突破不宜成为默认整股预测。没有从不同情景挑高增长、低投入、少稀释组成新“当前情景”。

主矩阵基准短期为强烈不建议投资，而当前实际短期用“不建议投资”，是因为当前并非已确定基准纯行，且存在有信息窗口的重估机会；并非把现金估值抬高。长期当前保留“中性／等待”，是对有独立依据的复利理念保留选择权，不把主现金法的不建议掩盖掉。

### 6.3 反向估值：今天买价要求什么

1. **一年盈利要求。** 若一年要求12%总回报、分红约3.01，退出价格需约309.79美元。30倍需NTM EPS10.33，28倍需11.06；基准9.81不足。提高倍数、盈利或两者组合都能解释价格，不代表真实市场共识唯一如此。
2. **三年盈利要求。** 10%年化、分红约9.57，退出价需约362.15。30倍需EPS12.07、28倍需12.93、25倍需14.49；基准12.23只在较高持续倍数下勉强足够。若要求突破理念12%年化，所需退出价更高，不能沿用10%门槛。
3. **现金隐含要求。** 当前稀释股数口径经营价值约91.41十亿美元，而D2基准约65.62。保持2026—2036显式现金不变、WACC8%、g3%、增量ROIC18%，要由终值弥补差额，2037FCFF约需7.45十亿美元，模型约4.60，需高约62%。这可以来自更大收入、更高可持续利润、更少有效资本需求，或更低贴现率，不是唯一解。
4. **低贴现组合。** 保持g3%、ROIC18%，基准今天WACC7%估值约248美元，7.5%约214，8%约188；279美元需要更低WACC或其他经营改善。不能因为公司优质就默认为7%以下资本成本，尤其收购硬件业务后。
5. **4.0十亿美元目标本身不足以解锁全部估值。** 相比基准2030 High-Tech3.20，多0.80收入、以25%营业贡献率估算，税后约0.158、每股约0.56；28倍约16美元，尚未扣新增再投资。只实现40亿美元，不自动填平现金价值与买价的约90美元现值差额。

敏感性保留状态内费用、CapEx、WC、退出与三年以前已付现金；三年后剩余现金和终值按D2折现。这里用年度内均匀分配近似敏感性差额，未迭代很小的二阶债息变化；仅用于数美元重要性比较，不替代季度主矩阵。前三列由精确状态转移重算，并非按统一乐观系数缩放。

若商业化整体延迟一年，2027保留必要开发费用但新增收费不发生，2028才按原2027状态展开，后续规模也顺延；当前值不因一年过去自动提高。基准E整体价值只有数美元量级，因此即使把成功概率提高到几乎全部成功，也不足以把基准现金法从约231推到满足长期门槛的362美元。最重要的等待证据是**净收费＋续约＋现场交付成本**，而非重复宣布合作。

**指定组合检验：新机会成功、原有业务普通或受损。** 保持基准W/I/P/L/H/O/C，只把E换成突破的完整经营及概率路径，则三年DCF提升约20美元量级，约到251美元，仍未达到10%年化门槛；如果再让核心集团利润率损失100bp，其改善可大幅被抵销。不能把E成功与全公司提价、硬件份额、资本效率全部同时无条件上调。反过来，E失败而核心复利保持，ECL依然有大额经营价值，并非股权归零。

### 6.5 最强反证及研究选择的限制

最强反证不是“股票可能涨”，而是**本报告低估了成熟客户网络与新硬件入口结合后的可持续收费和新增资本回报**。若ECL连续披露：交割满一年后High-Tech有机增长接近或超过25%，真实订单转交付且WC不过度增加，设备／服务毛利达到目标，2028—2029 FCF显著高于基准且净债下降，同时未以削减必要研发或质保换取现金，那么D2需要上修、DCF与复利法分歧会缩小。

另一反证是现金法对终值投资负担偏高：若服务和已安装设备持续收费，资本更新需求低于4%核心收入、增量ROIC长期超过20%，当前价格可能合理。这需要批次设备寿命、维护费用与净服务数据；仅以“轻资产”标签不足以反驳。

反向风险同样明确：附加费随原料下降回吐、客户产量不恢复，工程验收慢、硬件每MW降价超过吞吐增长，服务无法独立收费，或持续收购／回购挤占减债，会使当前基准偏高。由于未取得完整客户取消权、独立CoolIT财务和服务净收费，**本报告对整股现金价值的判断比对细分早期业务的点值更有把握，但对市场何时采纳没有精确预测能力**。

没有给四种完整情景分配总发生概率。上行格数量、E的S状态概率与公司胜率完全不同；不据此计算整股精确期望收益、CVaR或仓位。当前选择依赖可验证的经营、价值与价格边界，不依赖一个编造的综合胜率。

可用以下简短算法复算目标日估值；年度与季度参数均已在正文完整给出：

```text
p[2026] = [1,0,0,0]
for y in 2027..2036:
    p[y] = p[y-1] @ T[scenario]           # F吸收，允许S退化为P
    E_revenue[y] = sum(p[y,k] * revenue[y,k])
    E_EBIT[y] = sum(p[y,k] * EBIT[y,k]) - new_exit_probability[y]*0.020
    E_capex[y] = sum(p[y,k] * capex[y,k])
    E_WC[y] = 0.10 * (E_revenue[y] - E_revenue[y-1])
    E_FCFF[y] = 0.79*E_EBIT[y] - E_capex[y] - E_WC[y]

group_EBIT = sum(segment_revenue * segment_margin) - corporate + E_EBIT
net_income = (group_EBIT - net_interest + 0.030)*0.79 - 0.018
CFO = net_income + DA + SBC - WC - X
FCF = CFO - all_capex
FCFF = FCF - SBC + 0.79*net_interest

f = days_elapsed_in_target_quarter / total_days_in_quarter
f_next = days_elapsed_to_same_date_next_year / days_in_that_quarter
NTM = (1-f)*current_quarter + next_3_quarters + f_next*same_quarter_next_year
ND_target = ND_at_2026_07_02 - completed_cash_retention - f*current_retention
EV_target = sum(remaining_quarter_FCFF / (1+WACC)**years_to_quarter_end)
            + terminal_value / (1+WACC)**years_to_2036_end
equity_target = EV_target - ND_target
price_target = equity_target / diluted_shares_target
holding_return = (price_target + cash_dividends_received)/279.28 - 1
```
