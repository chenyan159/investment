### 2.3 哪些行业事实真正进入模型

正式行业报告L2将2026/27/28美国新增净可用主供电工作值估为3.2/5.5/7.7GW，属于研究估计。SOFC额定站点验收供给范围为0.7—1.1/1.2—1.8/1.5—2.5GW；Bloom核心设备收入确认、美国站点额定容量和可靠IT供电是不同单位。L3宏观资本开支与IT建设资料只用于检查预算量级，没有把产业链总资本支出乘份额直接当BE收入。

基准2027核心设备1.55GW、DC工作分配1.15GW，若80%当年完成站点验收、90%可靠功率折算，则对应0.83GW净主供电，约占行业5.5GW的15%；这是对供需的检查，不是已披露份额。2028基准DC分配1.55GW，同式约1.12GW，对7.7GW约15%。剩余设备可在随后季度投运，历史交付也可进入当年，故这个比例不是完整行业市占率。

制造供给比TAM更先限制2027。2GW是年底制造目标，5GW是现有设施扩展空间；供应商MTAR的分期扩张部分在2027年释放，公开文件未给足够换算GW。[L1][L2][S22][S23] 本次MTAR原PDF在线抓取失败，使用正式公司报告已经注明页码和日期的证据，未把失败访问冒称二次独立核验。

独立竞争约束来自Wärtsilä的790MW订单，计划2028交付、2029末运行；Ceres/Doosan授权生态和发动机扩产也在跟进。[L1][L2][S31] 因此基准设备ASP从2027的3.0降至2031的2.65，突破也从3.1降至2.7：扩产同时提升产量和客户议价权，没有免费保持最高售价。

### 2.4 电站单位经济性与护城河

厂家Energy Server规格为约53%—65%净交流电效率（LHV），并有低当地污染物、模块化、少运行耗水等优势；天然气运行仍排放CO₂。外部缓冲电源、电力电子、燃气与开关设备共同决定园区SLA，不能拿裸堆效率替代整个站点可靠性。[L1][S18][S19]

独立成本算例：全站5,000美元/kW、15年寿命、10%资本成本、85%利用率、热耗6.4MMBtu/MWh、气价5美元、维护22美元/MWh，则约142美元/MWh；假设80%成本合格且30%抵免，约121美元/MWh。无抵免路径保留；具体资格未确定，不给任何具体项目提前确认税收收益。气价每增加1美元/MMBtu，电费约增加6.4美元/MWh；利用率降到65%，资本项增加约27美元/MWh。税收条款核查来自正式报告[L1]的法典与IRS差异说明，仅用于两种经济假设，不作具体法律资格判断。

客户时间价值足够大时愿意买；如果电网提前可用、GPU利用率低、气价高或服务换堆贵，愿付价格会下降。护城河是工艺、合格制造、客户认证及运维组合；原生直流/800V和Power Connect优先体现为成本、份额与安装效率，未另造一笔“800V收入”。用100MW、85%负载、净节电2%、100美元/MWh计算，客户年省电费仅约1.49百万美元，说明节能价值不能无限支持系统溢价。

创始人兼董事长/CEO，激励重视产品增长和调整毛利；应同时盯合同资产、售后与股数。Plansee/GTP争议仍有未解决事项，未擅自认定禁令或赔偿；破坏性知识产权裁决作为额外失败分支。韩国关联渠道、印度供应链、氧化钪质量与来源、贸易政策、项目燃气和美国许可都是具体传导项，不统一写成一个宏观折扣。[L1][S36]

### 4.3 主估值方法、风险补偿与长期残值

经过设备盈利倍数、现金复利和里程碑交易三种方法比较，主矩阵选择**目标日剩余经营现金DCF加资本桥**：设备有较多维护和扩张义务，调整营业利润与自由现金差距明显，现金方法能统一处理新机会、资本占用及十年后的持续经营。选择发生在方法适配层面，不因为某种方法给低价就宣称它唯一正确。短期仍单独研究交易采纳；无可核验净流入及稳定倍数时，不把高倍数边界充当合理价值。

事前要求回报：短期6个月20%，中期一年25%，长期每年16%（三年累计56.1%）。它们是选择门槛，非收益预测、非精确校准资本成本。依据是BE集中的项目/制造风险、现金与股价波动、以及等待信息的价值；系统性时间价值在DCF折现率，局部商业失败已在状态现金，不再乘成功率或额外罚分。高风险里程碑交易可接受不同损失分布，但仍要求一条能在窗口内实现的正期望证据链；大上限本身不足。

折现参数：悲观14.5%—11.5%、基准13%—10%、乐观13%—10%、突破13.5%—10.5%；低价值使用较高折现率。终值增长悲观2%、基准3%、乐观3.5%、突破4%，终段新增资本ROIC分别12%/20%/24%/28%。这些是名义美元工作参数，不冒称当日市场WACC或无风险利率报价。较高折现率补偿未建模系统性和经营现金波动，不再折同一SOEC失败事件。

逐季折现至目标日，季中现金按天数；2026—2036全部成长、维持CapEx及营运资金逐期扣除。2037起核心现金：`2036核心调整营业利润×78%×(1+g)×(1−g/终段ROIC)`。这不是2036净利简单永续，增长必须再投资；早期机会按当年仍存续状态的期望现金进入终值，没有全成功加成。终值分母为`r+1%−g`，1%是长期新员工奖励的索取权；2027—36已通过股数逐期增长处理，不重复加1%惩罚。

稀释调整经营价值：每期现金乘`目标日员工股权分母/该期员工股权分母`；目标日前实际现金不再折现。目标日股权价值=`稀释调整经营价值+现金+有条件期权行权款−相容债务−融资义务−少数股东权益`。每股值除目标日完全稀释股数；大转债分段配对，无法假定本金和转股股份同时扣。DCF明细舍入可能出现0.1差异。

### 4.4 保留会改变选择的理念分歧

现金安全边际理念在三个期限均拒绝现价。短期里程碑交易更关心财报/指数买盘使投资者接受前瞻利润，长期平台投资者更愿意为标准化和多年客户复制提前付款。后两者不应被主DCF自动否定；但要辨明其收益来自已建模现金还是届时仍有人支付更高倍数。

下表是**可能交易回报的条件边界，不是主矩阵合理价值，也不是概率置信区间**。方法为目标后NTM核心调整营业利润×倍数×一年稀释因子，加已计风险的独立早期现金现值与资本桥。早期利润从核心乘数基数排除，避免新业务乘一次倍数再加一次期权。倍数为研究参数：6个月悲观22—32、基准30—42、乐观34—48、突破40—56；12个月依次20—30、28—40、32—46、38—54。依据是核心前瞻利润增长、产品稀缺与同日工业/数据中心公司高估值的量级；不存在能证明未来一定采用该倍数的合同或一致预期。

这里保留真正的方向分歧：**突破路径的高风险里程碑交易，一年可以建议；同一经营路径的现金复利主矩阵，一年仍不建议。** 不是给突破路径低发生概率所以降级，而是两种理念对退出估值和价值采纳的要求不同。现金模型否定的是当前路径下的现金回报优势，不是证明市场无法以高倍数交易。对于仅凭未知净买量的指数套利，当前无法给有统计基础的胜率、买量或收益区间，不能借其他突破倍数替它补一个目标价。

同样，高倍数并非新增价值来源：基准一年约34倍前瞻核心调整利润的工作值已经明显高于现金DCF。让两者一致，必须有更高长期利润、更久高增长、较低风险补偿或更少资本消耗中的至少一项；在没有新增证据时，不能把两种方法平均成更好看的目标价。长期复利若坚持8%资本成本，突破三年价值会显著上升，第6节明确给出翻转参数；这是保留的条件理念，不是主方法默许的风险折扣。

## 6. 当前路径、价格边界、敏感性和最强反证

### 6.1 三个期限各自需要等待什么

当前选择不从悲观的低投入、乐观的高毛利和突破的销量各挑一个端点。完整采用基准工作路径作为当前现金估值参照，同时承认订单/产品收入证据可能向乐观迁移；在新增合格产能和多客户现金证据出现前，不另造一套有利组合。

3个月与6个月：12月7日前可见Q3和部分大项目进度，未必看到AEP月底条件结论或全年/2027指引；3月7日前一般可见年报和新年度规划。两窗口当前方向同为不追价；若3个月出现实际交付能力显著超过2GW目标、多个付费客户及不依赖预付的现金转强，才会提升6个月的里程碑交易判断。指数纳入只解决资金需求事件，不自动提升2027营业利润。等待可能错过高倍数的第一段上涨，因此不把“等财报”说成没有成本。

3个月辅助估值直接重算至2026-12-07，悲观约0—0.55、基准43.07—63.33、乐观91.88—139.41、突破150.99—228.59美元/股，均为与主矩阵同口径的条件现金价值；不能把6个月价格按二分之一缩成3个月。它们仍不支持当前现金价值买入优势，但没有刻画指数资金推动的短线交易峰值。

中期：真正差异是2027核心1.55GW与1.85—2.15GW之间的合格供给、净价和现金。利润增长、库存/合同资产及付款进度要同时观察。仅超过2026旧指引而2027供给不增加，不能支撑一年回报。延后200MW会移动约0.6bn设备收入；若该收入对应30%—38%毛利而费用短期固定，税前经营利润可少0.18—0.23bn，现金还取决于预付是否退回。

长期：要求2029之后仍能在竞争扩产、电网接入逐步改善时获得大量复购，服务利润真实而非未来赔付不足计提。最有价值的证据是多年度堆体寿命、服务费与成本桥、成本下降快于净价下降，以及已投入产线的现金ROIC。量产平台成功和日本渠道改善比SOEC在三年内成为主要盈利池更可见，但氢的更远机会已经纳入十年概率现金。

### 6.4 最强反证与结论覆盖边界

对不建议现价的最强反证不是股价又涨，而是：2027已形成超过2.15GW核心净交付且售后现金安全；2029前多区域客户复制证明全球市场明显超出本模型；净价格下降慢于单位成本，长期FCF率稳定高于25%；扩产无需本文估计的WC/项目资金，仍不损害未来能力。若这些出现，应上调核心路径并重估，不能为了维护旧结论拒绝新证据。

对看多的最强反证是：大客户设备提前采购后终端利用率不足、服务堆体寿命拖累已售设备利润、预付款消失而合同资产增加、扩产与许可错配，或快速扩张后净价下降超过降本。经营已发生的好消息不等于现价未支付；同样，接网改善不意味着已部署SOFC立即报废。

本报告不提供精确胜率、CVaR或四情景总概率。主矩阵点值来自一套可复算的条件现金路径，但估值区间只覆盖所列r及资本规则，不是所有模型误差的外包络。突破超过2036仍长期高速成长、未披露的技术跃迁或具体资产重组可改变价值，未获得金额约束的部分不被默认为不存在；当前拒绝的是在现有证据和给定买价下声称已具充分优势。

### 7.3 最小复算说明与参数

季度参数在第1/3节，核心年度量价、毛利、费用、现金及远期表共同构成底稿；早期路径状态转移、逐年P/S收入和投入规则在3.4。以下为核心计算逻辑，单位保持bn/百万股。它不是用代码替代正文解释。

```python
# 早期机会：概率与收益相关，先状态内核算
p = [1, 0, 0, 0]                  # U,P,S,F
for year in range(2027, 2037):
    old = p
    p = old @ T                   # F是吸收态；P/S均可能退出
    expected_revenue = sum(p[k] * revenue[year,k] for k in states)
    tax = sum(p[k] * max(op[year,k],0) * .22 for k in states)
    # 对每一状态转移算新WC-可回收旧WC；进入F只回收旧WC的一半
    dWC = sum(old[a]*T[a,b]*(WC[year,b]-WC[year-1,a]*(.5 if b==F else 1))
              for a,b in transitions)
    FCF = sum(p[k]*(op[year,k]-capex[year,k]) for k in states)-tax-dWC-exit_cost

# 公司现金及稀释：每份员工奖励只承担一次经济成本
OCF = GAAP_EBIT + SBC + DA - cash_tax - dWC - cash_interest
FCFF = OCF - all_capex - project_equity + cash_interest
EV_target = sum(FCFF_t * target_employee_shares / employee_shares_t
                / (1+r)**years_to_t for t in remaining_cash_dates) + PV_terminal
terminal_core_cash = core_EBIT_2036*.78*(1+g)*(1-g/terminal_ROIC)
terminal_total_cash = terminal_core_cash + max(early_FCFF_2036,0)*(1+g)
terminal_EV = terminal_total_cash/(r+.01-g)  # 终段持续新奖励的1%索取权
equity = EV_target + target_cash + eligible_option_proceeds - compatible_debt - other_claims
value_per_share = max(equity,0)*1000 / compatible_fully_diluted_shares
total_return = value_per_share/252.87 - 1
annual_return_3y = (value_per_share/252.87)**(1/3) - 1
```

在终值前的DCF计算中，季度内现金按剩余实际日数切分，折现到该剩余段中点；每个目标日重新计算其后现金，不能把今天现值当退出价。2036之后采用上述剩余价值，既没有把2036收入直接加到2029利润，也没有用多年营收求和充当估值。

工作资本/费用表中，基准核心D&A为`0.035+0.015×核心GW`；核心现金税以GAAP营业利润正值乘2026/27/28/29后3%/10%/18%/22%，不把当前税损永久化；早期状态损失不跨项目提前抵税。核心净利息2026—29每年0.005，2030后悲观0.205，其余0.005。融资义务本金按每年0.018付现并等额减少索取权。税率及股权奖励由未来申报改变时应同时重算现金与股数，不能只挑有利一端。

### 7.4 交付核对

已按本次计算程序核对：历史事实四行一致；2026实际H1+预测H2等于全年；2027以后四季权重合计100%；分产品+早期期望收入等于集团；OCF/FCF/FCFF与投入桥闭合；各状态矩阵非负且每行合计100%、F不恢复；120个机会/情景/年度状态分布合计100%；每股资本桥和十二格回报以同一252.87买价计算；所有目标日一致；长期累计与年化换算相容；资本桥没有同时扣可转债本金与转换股数；新机会没有另加全成功价值；未把交易边界混进主矩阵。

必须保留的限制：缺乏实际季度MW/ASP、合同取消与收款条款、长期服务寿命分布、完整一致预期口径；目标日if-converted没有建立完整债券期权模型；早期概率为主观机制参数；季度内均匀交付及终值假设造成较大模型误差。上述限制降低估值置信度，但不妨碍检验现价到底需要怎样的现金路径。唯一正式交付文件为用户指定路径，未创建第二份正式报告。
