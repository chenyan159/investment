# DD：经营情景、价值传导与分期限投资决策

**研究日期：2026-09-07；目标证券：DuPont de Nemours, Inc.（NYSE：DD）普通股；唯一正式交付文件：`分析报告/公司情景投资决策/结果/DD_经营情景市场状态投资决策_2026-09-07.md`。**

## 一、当前选择与研究口径

### 1.1 先给三个期限的实际判断

**按131.59美元买入：短期中性／等待，中期中性／等待，长期不建议按稳健现金复利逻辑投资。** 这不是否认医疗、水处理或直接提锂的价值，而是当前可支持的正常经营与真实再投资成本，尚不足以同时支持买价和所需回报。高风险突破投资者可以研究提前参与，但当前证据不足以把它升级为本报告的实际买入建议。

- **短期，主计算到2027-03-07：等待。** 正常路径的条件每股价值约126.9—147.3美元，含期间现金及应收股息的总回报约-2.7%—12.8%。上沿需要市场愿意给约12倍目标日NTM经营EBITDA；下沿几乎没有安全余量。未来两个财报窗口可以证明医疗的持续需求和2027现金转换，但既有指引上调本身已经公开。三个月窗口到2026-12-07更短：在只有Q3、尚无完整2027指引时，正常路径价值约117.7—140.5美元，按目标日NTM经营EBITDA1,807.3、10—11.7倍、负2,189.7资本桥与134.95百万稀释股计算；尚无实收股息、另有0.60应收股息，总回报约−10.1%至+7.2%，作为事件价值边界，置信度低；不能把六个月上沿提前当作必达价格。
- **中期，到2027-09-07：等待。** 正常路径约132.8—153.9美元，含股息总回报2.7%—18.8%，尚不能在合理不利参数下稳定超过15%的研究门槛。投资理由必须是医疗增长、两分部利润与现金同时兑现；单看调整后EPS约18倍，忽略再投资与遗留支出，会高估便宜程度。
- **长期，到2029-09-07：稳健复利理念下不建议。** 主方法为在三年目标日折现2036年之前剩余经营现金及其后终值，正常路径约103.6—121.8美元，累计回报-15.8%至-1.9%，年化-5.6%至-0.6%。它与“用目标日EBITDA乘10—12倍”得到约153—186美元存在实质分歧。前者严格计入持续更新、成长资本和终值ROIC，后者允许资本市场持续给予增长溢价；本报告对长期选择采用现金方法，未将两者平均。

**主要预期差不在“DD是不是AI材料公司”，而在“分拆后利润改善究竟能留下多少股东现金”。** 市场可能低估医疗资格积累及水处理产品组合的价值，也可能把去除一次性交易费用后的高现金季度，当成无需持续投资的现金常态。公司上半年医疗收入增长8.9%，但水处理仅增长约0.7%；“医疗加速、水恢复、建筑企稳”仍需分开验证。新产品发布提供研究入口，尚未证明DD拥有大额不可取消的多年收入。

当前最接近**基准／正常兑现**，路径证据强度中等。没有可校准的四情景联合概率；不把十二格的正面数量当胜率。两类早期扩张机会分别按行内年度状态概率纳入，其中净新增医疗平台和DLE均非基准100%成功。完整成功收入作为参照，未与期望收入相加。

利润质量有三项决定性差别：

1. **分部提升与总部项目不是同一来源。** H1 EBITDA增长79，其中HWT增加31、DI增加29、Corporate & Other改善19；不能将全部增加视作需求扩量。总部项还含权益收益。本模型从集团Operating EBITDA再统一扣20／年非并表收益代理，得到估值用经营EBITDA；非经营股权另估，避免重复。
2. **调整后EPS不能直接当股东现金。** H1无形资产摊销136、总折旧摊销309、SBC 27；重组、历史法律成本和非现金票据利息另有影响。并购摊销不是本期现金，但收购的资格、客户和技术并非永久免费资产。未来集团账面利润、报告式FCF与经济UFCF分列。
3. **现金改善不完全等于更高常态现金率。** H1 CFO632、CapEx178，实际FCF454；交易调整后473，多19。相对上年，应收、库存、应付现金变动合计改善约258；出售业务净现金1,158不能年化。另有终止经营净现金流出167，必须在资本桥处理。模型没有把473×2自动当成稳态现金，也没有再把出售所得加入起点现金。

### 2.3 资本、诉讼与治理

6月底现金1,740仅约每稀释股12.72美元，且受债务和其他索取权约束；它不是131.59美元买价的资产底。债务3,125，简单净债务1,385；2028年约1,350本金到期。未动用循环额度合计2,750是借款能力，非股东净资产。正常模型假定2028到期债务按当时条件续借、总本金基本不变，未将再融资视作利润。悲观行现金低于800时动用额度，额外借款按6%税前利率计入资本滚动；若评级或契约使续借失败，应进入独立融资尾部，而不是继续沿正常折现价推演。

非经营资产包括Arclin约16%股权账面325、票据账面188（面值300），Delrin／Derby约19.9%股权132、票据297（面值350）。合计账面942并非立即可取现金。本模型正常、乐观、突破仅给750可归属净价值代理，悲观450，均含回收时点与税费折让；没有加票面差额，没有再计其未来权益收益，未假定新增股权注资。最终可售价值未知，750→450使每股少约2.2—2.3美元。

现金公式：现金税＝24%×max(0,经营EBITDA−物理折旧−净利息)，主动放弃未验证的收购摊销税盾；核心营运资本增量＝16%×核心收入同比增量，另加M／D状态周转；2026集团周转90、其他一次性现金75，随后40／25／15。净利息2026为105，以后125代理，包含债务票息与普通现金利息的净额；卖方票据非现金利息不当经营回款，特殊股权收益剔除。额外借款的税后利息另在资本桥扣。

`报告式CFO=经营EBITDA−净利息−现金税−ΔNWC−一次性现金+SBC−额外养老金`；
`报告式FCF=CFO−全部CapEx`；
`经济UFCF=经营EBITDA−24%×(经营EBITDA−物理折旧)−ΔNWC−一次性现金−全部CapEx`。

未来持续SBC已经在经营费用中：报告式CFO加回非现金SBC，资本现金桥用相同金额补偿回购／现金替代报酬，**不免费加回后又保持股数不变**；经济UFCF不加回SBC，因此终值不再单独扣未来同一授予。起点136.8百万包含存量稀释代理，此后仅自主回购减少股份。若实际授予超出假设或股价下跌导致员工奖酬补发，应下调每股值；没有转换债和ATM融资的公告依据，不凭空加入工具。

报告式CFO是可对照报表的预测桥，不保证未来公司分类完全相同；H1实际CFO632、CapEx178和FCF454固定，2026H2是全年预测减实际。法律计提本身不等于付款：终止经营付款另列，账面利润代理不能用来倒推出其现金时间。

- **现金安全边际投资者**：即使近季盈利改善，也可因9%—10%资本成本、更新支出、遗留责任和终值占比拒绝现价。其买入理由要来自更低价格或可复核现金上修；不是要求所有短期投资者接受同一损失上限。
- **盈利增长／里程碑重估投资者**：如果相信医疗水处理持续增长、资本市场在两个财报窗口接受11—14倍前瞻经营EBITDA，可支持乐观、突破短中期条件建议；但须承认同现金底稿DCF的拒绝，不能声称所有合理方法均支持买入。
- **高风险技术／平台突破投资者**：可以接受较大的中间损失以获得医疗平台和新型分离流程的长期价值。突破三年DCF回报约36%—63%，年化约11%—18%，对12%门槛有条件，对18%高风险门槛并不充分。当前没有完整四情景概率，因此不能凭突破上限推导正期望，更不应把DLE行业成功率直接当DD股票成功率。

方法差距的主要来源是高质量利润可以持续多久、自由现金占EBITDA多少、维持／成长投入何时下降，以及终值ROIC。辅助盈利倍数上沿不是新增经营事实。能裁决的部分是SBC、法律支付和非并表收益必须真实扣除；不能裁决的部分是十年后的竞争、资本效率及市场对增长的支付意愿。本报告将后者保留为条件，而非通过取60%或75%区间位置跨越评级门槛。

## 六、当前价格的反向要求、敏感性与选择边界

### 6.1 不把反向门槛冒称市场共识

基准六个月经营EBITDA约1,831、股数134.6、净资本桥约−2,138。要从现价得到10%总回报，股票退出价需约143.55（已扣合计1.20股息权益），反解约**11.73倍NTM经营EBITDA**；若只给11倍，则需要NTM经营EBITDA约1,951，比基准高约120、6.6%。两者也可用中间组合实现，不能说市场唯一要求就是某个收入。

基准十二个月要15%总回报，除息股票退出价约148.93，反解约**11.65倍NTM经营EBITDA**；若倍数不超过11倍，需要经营EBITDA约1,992，比基准约1,881高111、5.9%。以35%增量贡献率粗推，单靠收入需多约317（4%左右），或者核心利润率提高约1.4个百分点，或者非经营资产／法律现金改善与增长组合。若额外收入同时需要更多资本和周转，门槛还会提高。

这些多组组合说明：当前价格不要求DLE立即赚大钱，但要求正常盈利具有较长持续期，且估值不能显著压缩。本报告2027正常EPS／EBITDA并没有比指引滚动产生巨大上修，因而不把下跌8%本身当买入证据。

基准三年DCF按中间经济参数WACC9.5%、g2.25%、ROIC13%，目标日价值约111.9。当前131.59要12%年化，需要退出股票价值约177.7，其余当期现金和资本保持基准时，2036终值NOPAT须约3.0十亿美元，显著高于模型1.53十亿美元，接近翻倍。这个反解只放大终值利润、尚未增加其前期投入，是**有利于买方的门槛下界**；若用真实扩产实现，需要连同更多资本重建，不可把差额称作尚未计价的免费机会。

达到该目标的替代组合可以是长期更高现金率、显著更低WACC或更高且可持续ROIC，亦可较低买价；并非一定要收入翻倍。当前基准M、D的期望贡献已入DCF，不能再加一张“未来技术期权”填足缺口。

早期机会的概率敏感性以**状态有效分布**检验：例如基准2031 D为约9.2% U、27.6% L、27.1% S、36.2% F；把S降低10个百分点、全部移入L，合计仍100%，当年收入减少 `10%×(330−55)=27.5`，相应状态利润、产能投资和周转一起改变，不能只减少收入而保留原来成功后的低成本。M同样把S的10个百分点移到L，当年期望收入减少26.5。该单年计算是敏感度，不是把某年分布变化孤立套到所有未来年度；完整重估要用新转移矩阵重跑后续分布。

基准在WACC9.5%、g2.25%、13%ROIC下，按增量族自己的状态现金、目标日前净投入和终值贡献分解，三年每股净贡献约M4.2、D2.4美元。其中M目标日前累计期望现金约−28.8，D约−23.7；远期终值贡献比近期现金更重要。这是模型归因，**不是在主DCF之外再加6.6美元**。

把DLE在现有状态规模上推迟两年，同时U阶段继续支付验证费，会降低三年时已能确认的商业证据，并把正现金推迟；在这种假设下，D的2.4美元贡献可能减少约0.5—1.5美元，取决于是否能及时压低前期费。若两年后实际上永久丧失先发资格，应当转F，损失接近整项贡献并含额外退出费。该0.5—1.5为时间与继续费用的敏感范围，不是重新校准的概率结果。M部分成功规模减半，会减少收入、毛利和周转／CapEx，但固定验证费不会减半，净值可能损失数美元。两族同时变差不会单独使正常路径破产，原因是已有业务现金规模较大；若与重大法律支付共同发生，仍须使用资本尾部分支。

反过来，即使把基准两项机会净贡献翻倍，也只大约增加6.6美元／股，远少于正常DCF约112与满足12%三年回报所需约178的差额。要改变当前长期结论，需要**成熟医疗水处理本身的长期现金和资本效率**显著改善，而非只把早期局部概率调到更乐观。市场利率、医疗持续期和维持资本的误差，对整股比小额DLE首单更重要。

### 7.3 可复算参数与检查

主要复算关系可用下列短伪代码复现，金额和状态参数见正文。证券股数采用现金补偿持续授予后的完全稀释代理；实际现金股息按基本股数（稀释代理减1.76）近似支付。

```text
for scenario:
    p_M = p_D = [1,0,0,0]
    for y in 2027..2036:
        p_M = p_M @ T_M
        p_D = p_D @ T_D
        assert sum(p_M)==sum(p_D)==1
        expected_revenue = dot(p, [0, partial_revenue, scale_revenue, 0])
        expected_EBITDA = dot(p, state_EBITDA) - new_failure_probability * exit_cost
        expected_CapEx = dot(p, state_CapEx)
        GroupRevenue = sum(four_core_pools) + E_M_revenue + E_D_revenue
        OperatingEBITDA = core_segment_EBITDA - corporate + E_M_EBITDA + E_D_EBITDA - 20

    for target in [2027-03-07,2027-09-07,2029-09-07]:
        NTM = sum(quarter_amount * overlap_days(target,target+12months) / quarter_days)
        cash += report_FCF - legacy_cash - SBC_replacement - NCI_dividends
        cash -= discretionary_buybacks + actual_common_dividends
        diluted_shares -= discretionary_buybacks / execution_price
        if cash < 800: debt += 800-cash; cash=800
        capital_bridge = cash + nonoperating_assets - debt
                         - PV(remaining_legacy) - remaining_pension - NCI_value
                         - declared_unpaid_company_dividend
        equity_value = operating_value_at_target + capital_bridge
        stock_value = equity_value / diluted_shares
        total_return = (stock_value + received_dividends + dividend_receivable)/131.59 - 1
        annualized_return = (1+total_return) ** (1/years_held) - 1
```

DCF用季度末折现，最后2036Q4的期末为2037-01-01；与2036-12-31差一天属统一计算约定。报告式FCF已扣追加养老金，经济UFCF未扣未来养老金／遗留支出，因此剩余责任仅在资本桥扣一次。额外借款利息、季度实际分红日、回购执行价、2026H1实际值与之后预测分开；最终显示取一位小数，有少量显示层舍入差。

交付前检查：四行H1实际一致；四核心收入加两新族等于集团；分部EBITDA与总部合并闭合；季度对年度与目标日NTM按固定规则滚动；80条机会年度分布均闭合、F为吸收态、存续成功收入持续计入；12格价值、市值、股数、分红与累计／年化回报按公式核对。主矩阵三年选DCF、盈利倍数留作理念对照，没有把较高的方法平均成买入优势。

仍有实质限制：工厂合格产能／良率、净产品收入与毛利拆分、新族付费合同和真实基础率未披露；PFAS最终净责任未知；2027一致预期缺同口径；跨分拆12个月真实总回报未完整还原；当前股权奖励库存以平均稀释股数代理。它们限制结论精度，但未被静默记作零，也没有以任意成功上限取代现金约束。
