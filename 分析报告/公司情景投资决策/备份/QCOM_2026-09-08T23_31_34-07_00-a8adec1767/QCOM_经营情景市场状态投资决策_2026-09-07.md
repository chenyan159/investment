>
> **当前判断：短期不建议立即买入，中期不建议投资；长期按现金与每股经济收益理念不建议投资，按高风险平台成长理念为中性／等待。** 汽车和定制 ASIC 的增长值得承认，但在 168.74 美元买价下，正常兑现路径不足以提供要求回报。若净价恢复、客户续代和新平台经济性共同达到乐观或突破路径，条件建议会转为正面。不能把这些条件正面格理解为当前胜率。

## 1. 当前选择、研究时点与关键限制

表中的金额为模型工作值，不是公司指引或一致预期。当前最接近**基准的成熟业务＋定制 ASIC 有实质商业起点、HBC/CPU仍分支化**的路径；不从悲观手机、突破服务器等不相容端点拼出“最优当前组合”。

最重要的研究差异有三点：

1. **多元化的收入替代速度快于股东现金替代速度。** 定制设计、制造管理与服务器平台研发的经济性不同，新增1美元收入不能默认等同于退出的苹果芯片收入。
2. **调整后EPS能描述经营趋势，却不能直接当无稀释股东收益。** 本文在利润中保留持续SBC经济成本，在现金和股数中同时处理抵消授股的回购；否则会把同一笔报酬变成“免费资金”。
3. **新平台不是零价值。** 所有重要早期机会逐年加权至FY2036；三年退出仍包含以后剩余价值。基准的限制在成功规模、利润和付出成本，而非把未来删掉。

### 2.4 财务、合同、资本与共同风险

库存从FY25年末6.526B升至8.379B，约增28.4%；九个月库存经营现金占用1.798B，应收4.668B，客户激励负债2.762B。战略备货、新项目WIP与客户减产可以同时存在；总库存不提供产品库龄。粗略多30天库存覆盖可能多占约1.5B现金，**不是可立即提取的现金储备**。本年九个月研发7.523B和SBC2.579B说明转型并非免费。分红2.868B＋回购6.806B超过同期FCF6.827B，不能无限外推返还速度。上述为[正式公司报告财务质量章节](../../../基本面/公司调研/AI计算芯片_EDA_IP_custom_ASIC/QCOM_Qualcomm_公司调研_2026-09-07.md)的披露重建。

芯片客户合同的取消补偿、验收时点、坏片责任、NRE补偿和预付款未完整公开。模型采用交付后收入、净营运资本18%及失败时回收库存的有限假设；不写成take-or-pay。汽车管线、合作意向、开发者数量不作为现金订单。Adobe／HUMAIN宣布的AI工作负载合作有具体用途，但没有足够已收款规模；Adobe面向用户的免费权益不等于高通收入。[高通合作公告](https://www.qualcomm.com/news/releases/2026/08/adobe-becomes-first-global-software-company-to-migrate-ai-worklo)、[Adobe客户公告](https://news.adobe.com/news/2026/08/adobe-mcit-and-humain-expand-partnership)

资本方面，Modular约3.1B主要股票对价、Alphawave会计购买价约2.274B，现金／股权／服务条件不能混为同一“收购支出”。本文将已完成对价放进起始股本或现有资产，**不在未来现金再扣一次，也不把商誉加到DCF**。未来保留团队的报酬在持续费用中；后续大收购未假定必然发生。递延报酬计划资产与对应负债约1.293B／1.289B相抵，不当自由投资资产加价。未上市QSI余项的税后可变现净值未能可靠分离，主表不加，另保留0—2B即约0—1.9美元／股敏感范围；因此不能宣称远期投资权益毫无价值。

公司没有已披露流通优先股；模型不假设ATM或可转债融资。现有租赁及正常履约负债的现金成本留在经营费用／营运资本，避免再减一次完整租赁债务。债务按账面本金15.270B桥接，2027年约2B及2028年约0.962B到期偿还；固定息票债券市值约14B与本金口径的差异，不当即时可实现收益。债务偿还日前后在季内近似，资本压力须看分支最低现金。

Arm许可与诉讼是多产品共同风险，不能拆成手机、PC、车、CPU四个独立失败概率。最新10-Q披露的案件排期2026-10-05仍是未来安排；既有有利裁判和终止通知撤回不代表全部上诉结束。主四行情景假设公司保有可商业交付的核心权利；重大禁令、台湾长期制造中断、关键出口权限丧失可能使普通股价值低于P行，**P行不是最坏情形或资产底价**。这些法律和供应离散事件不再以一个任意数值重复扣进所有现金与折现率。

治理上，研发复用、汽车量产记录为执行能力提供支持；收购后的系统软件能力、hyperscaler续代和资本纪律尚需单独证明。收入与调整后盈利激励可能鼓励扩规模，必须用实际现金与净股数检验。本文未发现可据以断言虚假财务的直接证据。

### 4.3 要求回报与方法

主理念及门槛预先固定为：短期6个月**8%累计**，一年**15%累计**，三年**15%年化／52.1%累计**。这些是选择门槛，绝非预期收益；现金充裕、分散配置的投资者可用12%长期门槛，集中技术期权投资者可要求20%年化。不同门槛的结论在第6节保留，不改动经营数据。

无风险利率参照为[美联储H.15](https://www.federalreserve.gov/releases/h15/)2026-09-04发布表中**9月3日**6个月国债常期限收益率3.95%、10年4.77%，不误标成9月4日的实际收益率。公司资产DCF采用9.5%—11.5%折现率、中央10.5%，由约4.8%长期利率＋权益系统风险溢价、少量便宜债务融资构成研究区间；不是估计已知精确beta。项目失败已在现金路径加权，不再给HBC另乘成功率或加同一失败折价。投资者15%门槛是相对替代资产及集中持股的择时要求，不在DCF再扣一次相同损失。

**E1：短／中期用目标日后NTM经济EBIT的企业价值倍数。**P10—13、B14—18、O16—20、X17—22倍，均保留SBC，加入对应目标日现金和非经营证券、减债务、除FD股数。倍数来自能维持的利润期和剩余成长，不来自同业目标价：14倍EBIT约对应以16%税率计算、未考虑再投资前5.99%税后经营收益率；18倍约4.67%，必须有更强的增长与现金转换才能相对约4.8%国债合理。P衰退和低回报投入降低持续期；O/X的技术验证、重复客户和扩量支持更长持续期。倍数上下界是有条件价值区间，非统计置信区间。

**D1：三年采用2029-09-07之后剩余经营现金DCF。**逐季折现到该目标日，模型延伸FY2036；目标日前现金通过实际积累、股息和回购处理一次。终值以FY36经济EBIT税后收益，乘(1−g/ROIC)处理再投资后按(r−g)资本化，g下界2%、上界3%，中央2.5%；终值增量ROIC P/B/O/X为15%/20%/22%/25%。这些是包含持续费用后的条件回报，不是免费永续增长。终值假设维持性CapEx与经济D&A基本相抵，额外增长投入按g/ROIC扣减；若资产更新成本持续高于折旧，需要下调终值。显性期以后仍需研发与硬件更新，终值现金不能用“收入继续涨而资本不变”推导。

### 4.6 反向估值：168.74美元隐含什么

不能把反求结果冒称市场真实一致预期。按研究日起可归属EV约190.2B，多组等价要求为：

- 若仅给14／16／18倍NTM经济EBIT，现价分别需要约13.6／11.9／10.6B经济EBIT；本模型NTM约9.1B。
- B一年后经济EBIT约10.2B，若要一年15%总回报，目标股票价值约190.37美元（已取得股息权益另算），所需EV/EBIT约20倍，明显超出B14—18倍主范围；或在16倍不变时需要约12.9B经济EBIT。
- 三年15%年化要求总权益约256.63美元，扣正常11.04美元股息权益，要求除息股票约245.59美元。B中央约141.8；O中央约235.8仍略低于该门槛，X中央约340。需要成功规模、利润持续期或买价发生实质变化。
- 按当前EV/当前FCFF约6.32B，简单现金收益率约3.3%；若资本成本10.5%、终值增长2.5%，成熟稳态现金需要约15.2B才能独立支撑190.2B经营价值。B到FY36才接近15B现金，等待期间也有现金，但“已经低估成熟稳态”的说法不成立。

苹果退出大部分已进入本模型，不再从当前估值额外扣另一笔“苹果业务价值”。HBC／CPU期望现金已进入DCF，也不在反向估值另加完整成功机会。

若仅把B／X两个完整路径作为条件赌局，保持各自资本和早期局部概率，中央价值跨三年15%门槛约需X权重52%；B／O两路径则需O超过100%。这只是门槛展示，未给X实际52%概率，不可再把X内部60% J1概率乘到整个X价值。投资者若以“突破概率很小但赔率大”为理由提前参与，必须证明这个门槛或另一个有依据的收益规模能成立；本次证据尚不能证明。

**概率范围用有效分布而非独立端点：**B乐观权重50/30/10/10、保守20/30/25/25都合计100%，对应约153与131美元；不是把每个状态概率上界相加。不同J分支的量价与成本相关，所以状态收入先在各分支计算后才平均。没有新证据时，概率不因到了2029年就自动升为100%。

简短复算式：

```text
对每一情景 s / 联合路径 j / 机会 i / 财年 t：
  p_j 固定在整条路径上，只抽取一次；sum_j(p_j)=1
  R_i,t,j 来自年度路径；状态按 U/L/S/F 定义映射
  EBIT_i,t,j = R × 毛利率(state) - R × 变动费用率 - 固定开发/退出费
  CF_i,t,j = EBIT × 0.84 + 0.025R - CapEx - 0.18(R_t - R_t-1)
  E[R_i,t|s] = sum_j(p_j × R_i,t,j)
  E[CF_i,t|s] = sum_j(p_j × CF_i,t,j)
  [共享SBC在集团层扣；项目现金中不再扣第二次共享SBC]

集团：
  EBIT = 所有分支毛利 - 分支费用 - 早期开发 - 公司费用 - SBC
  CFO = (EBIT - 0.5)×0.84 + D&A + SBC - ΔNWC
  报告FCF = CFO - CapEx
  估值FCFF = 报告FCF - SBC + 0.5×0.84
  现金_t = 上期现金 + 报告FCF - 抵SBC回购 - 股息权益
           - 净回购 - 到期债务偿还 + 新融资
  FD_t = 上期FD - 净回购/假设均价
  [当期授予与抵SBC回购相抵；存量奖励已在起始FD]

NTM = sum(每季度预测 × 与指定12个月重叠天数/该季实际天数)
目标日经营价值E1 = 目标日后NTM经济EBIT × 对应倍数
目标日经营价值D1 = 目标日后逐季FCFF折现值 + 终值折现值
终值 = FY36经济EBIT×0.84×(1-g/增量ROIC)/(r-g)
显性现金使用该剩余季度的中间日折现，终值从FY36末折现到目标日；
时间指数用实际天数/365.25。

目标日除息股权价值 = 经营价值 + 可用现金 + 0.926证券 - 债务
目标日除息每股价值 = 股权价值 / 对应FD
总回报 = (除息每股价值 + 期间已付股息 + 已取得未付股息应收)/168.74 - 1
三年年化 = (1+总回报)^(1/3)-1
```

资本桥在每一J联合分支单独运行：每季留足5B后才执行净回购，4B为融资缓冲线；2027年5月偿还2B，2028年约0.962B安排在6月季偿还（季内日期为模型近似，非重新声明证券条款）。主四行情景各J均不触及新融资，FD在同一行情景内相同，因此加权分支股权／股数等于主表；交叉受损组合发生融资时，先算分支资本再加权。当前资产平移误差、股息日、税及实际授股价格均列敏感性。
