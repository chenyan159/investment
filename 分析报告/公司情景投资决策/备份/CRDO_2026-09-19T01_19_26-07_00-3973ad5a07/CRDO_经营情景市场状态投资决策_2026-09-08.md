**本次对上游预测作了实际调整。** 公司报告较可见FY27约2.50、FY28核心约3.42只是候选解释，不直接继承。本次从Q2指引、模块交付时间和滚动量价重建，FY27较低，研究Y1=2.81左右；而Y2=3.92含局部概率加权新机会，与上游FY28期间不同，不可直接比较两数字差额为“上修”。行业AEC报告的CY2026整缆收入19亿—33亿美元、CY2028约1,310万条基准只是未证实行业范围，且部分商业锚本身来自Credo，**不能作为独立第二证据循环确认Credo份额**。

以共同单位检查：基准AEC Y3=28.5亿美元，若混合净价365美元需781万条，约为上游CY2028基准条数的60%，研究期晚约一年；若该行业当时只交付800万条，则相同公司预测要求近98%份额，难以成立，应压低公司量而非强行保留。若行业达到1,500万—1,800万条，则43%—52%的公司份额更可容纳二供。这是行业约束进入公司收入的位置，不是“行业增长×任意市占率”。突破Y3 AEC=43.5亿美元，按450美元需967万条，需要更高总量、组合价值和合格测试能力共同成立。

光模块Y3基准0.85若净价850美元，约100万只；突破1.90若1,050美元，约181万只。相对数千万只高速模块的大市场，数量不离谱，但**可服务子市场、客户资格及产线分配比全球总量更紧**。低份额算例不能证明轻易进入；需要专门光耦合、老化、测试与现场支持。所有内置DSP/PIC已经包含在模块净价内。

更远的规模也须过数量和预算检查：突破Y10核心30.70、集团净收入35.75。AEC的11.0若混合净价约350美元，需约3,140万条；模块9.65若长期混合净价650美元，需约1,485万只；外售DSP与PIC合计6.25若每组件组合净内容150美元，需约4,170万个当量，且必须剔除自用。它要求现有覆盖边界之外的新平台和更大连接预算；Y3及Y5的客户数、交付和净价必须持续逼近路径，才能继续保留这个十年尺度。若集团可捕获的独立连接支出份额约15%—25%，35.75对应相关可服务支出约1,430亿—2,380亿美元。这是**远期必要预算门槛而非行业预测**，现有资料不能证明其必然形成，因此突破证据强度低，不能拿当前AI总CapEx直接宣称已覆盖这一市场。

### 2.4 合同、资本配置、治理与法律经济权益

产品销售主要按采购订单，部分允许较短通知期内调整或取消且无罚金；10-Q的约420万美元剩余履约义务只覆盖特定未履约合同，并非完整硬件backlog。[S2，Risk Factors；S1，Revenue Recognition] 没有披露取消率和客户最低采购量，因此不把供应商承诺当成客户订单。

供应侧截至08-01制造采购承诺约212.7百万，制造加许可跨期承诺约222.2百万；已有可抵用押金88.4百万，合同期2—6年；期后另需在FY27支付102.4百万押金。押金是有条件通过采购抵用的经营资产，不是随时可用现金；取消供应商采购仍可能承担已经发生的成本。模型把新增押金进入现金支出，采购进入成本与库存；没有把同一款项再作为有息债务扣除。[S1，Commitments and Contingencies]

Dust于2026-05-28完成收购。初始收购会计对价约1.251，包括现金769.6百万、已发行股169.1百万、替代奖励2.5百万、或有对价公允价值310百万；后者中权益300百万、负债10百万。**公允价值不是最高支付承诺**：FY26年报期后事项列明额外对价上限约280万股和31.6百万现金，以财务里程碑及协议条款为条件。详细里程碑阈值、逐批支付时点和未披露免责条款仍未知；模型分别列股数与现金，不能从已计权益300百万再扣一笔“负债”。[S1，Business Combination；S2，Subsequent Events]

这项交易的回报门槛很高：对1.251经济对价要求10%—15%税后现金回报，需要每年0.125—0.188新增现金；按25%—35%现金利润率，对应约0.36—0.75**新增外部收入**。整个光业务0.60目标包含原有DSP和模块物料，不能全部归于Dust。历史对价已经支付，不从未来DCF再扣；未来研发、模块支持和收购或有支付仍扣。商誉和无形资产不能作为与经营价值相加的资产底价。

股权激励具有正反两面。CEO特别PSU共约143.7万股，六档门槛同时含收入和股价，业绩期至2031-06-30；收入门槛25亿至75亿美元、股价244.70至489.40美元。它激励做大业务，但股价条件与并购扩张也可能强化短期目标动机；这些价格不是公司估值意见。相关存量奖励属于PSU池，不再另加一遍。[S2，Special PSUs表]

截至最新季报未列重大有息借款；经营租赁负债约26.2百万，租赁现金已包含经营成本，因此不再从EV重复扣除。公司披露当时没有重大诉讼，并不等于未来赔偿或知识产权风险为零；一般业务赔偿部分没有明确上限。TSMC与亚洲封测／线缆供应、Dust的以色列团队，使台海、贸易规则和中东冲突能够通过供给、保险、人员及交期直接影响现金。未核验到具体新增禁令适用于本产品，模型不把宏观风险名称当作已发生事件。

## 四、早期机会：阶段、年度概率和经济结果

### 4.1 三种不同进入路径

**NPO／靠近封装的光引擎。** 解决高密度scale-up的电通道损耗和封装周边带宽问题，Credo先靠PIC设计进入，也可能升级为完整光引擎。管理层称有两个主要参与者的设计定点，预计FY28、可能FY27末爬坡；这排除了“完全没有入口”，尚未排除系统热设计、维修与光装配良率失败。电话会某段将财年误转为“2018”，本报告只用同一发言其他段落明确的FY28及前后产品背景定位，保留转录误差，不当作新事实。[S4][S9]

NPO规模状态Y3收入0.40、Y5收入1.20。按每套净内容800/700美元，约需50万／171万套；Y5与行业2030交换侧光学子系统20亿—96亿美元范围相比，份额约13%—60%，低端行业下难以成立。且该行业口径含整子系统，Credo只售PIC时可得比例更低。因此这不是基准必然结果；高成功规模必须伴随扩展到更多平台或更完整引擎，而非用设计定点直接外推。部分成功Y3只有0.07、Y5为0.18，保留低份额器件供应商形态。

**OmniConnect／Weaver。** 通过内存扇出gearbox及接口IP进入计算芯片架构，客户愿付钱的来源是同成本下更多可用内存和推理吞吐；它不出售DRAM，不按模型token收入抽成。已具名Positron设计合作提供入口；Positron的2.3亿美元融资、Atlas在售与Asimov规划是不同阶段。原始融资材料称Asimov计划2026年底流片、2027年初生产，不能把Atlas客户实测挪为Weaver已经量产验证。[S10][S11]

宣传的6.4TB与16TB/s是多器件系统配置，不是一颗gearbox。按12×112Gb/s÷8约168GB/s的单向原始通道量级检查，可避免把系统带宽变成单芯片收费。规模成功Y3=0.30、Y5=1.60，若每采用加速器净内容2,000美元，需要15万／80万颗；Y10=6.0，若内容降至1,500美元，需要400万颗。**单一创业客户融资不能支持全部规模，须增加大型芯片／云客户，付出共同开发、软件和认证成本。** 这保留了真正非线性的经济空间，也说明今天设计合作只支持机会存在，不支持多年销量。更大本地内存减少外部通信的替代在净贡献中扣5%。

**ALC／microLED。** 以大量并行低速光通道换取短距延伸和功耗表现，目标覆盖约10—30米，是现有AEC与激光模块之间的新路线。核心未知是多通道装配、老化、良率、连接器和客户运维；激光模块降价可能抵消优势。2026年10月OCP演示及FY28初始收入是计划，未发生。竞争者Avicena于08-18宣称交付1Tb/s客户评估套件，支持路线具备工程可能性，并非Credo已达到相同状态。[S14][S15]

规模成功Y3=0.15、Y5=0.80，按500/450美元净价，约需30万／178万条；Y10=3.0按350美元需857万条。需多家客户与制造测试扩量，不能仅靠单次展会。ALC成功会替代较长AEC和短光模块，净收入只保留75%，并扣其原有毛利。汽车、消费、未建立接口／客户入口的其他用途只保留能力联想，当前无可辩护金额，不纳入可估值覆盖；本文不声称穷尽所有十年机会。

### 4.2 状态、概率依据与依赖

每个机会每年定义U=尚未商业化、P=有限／部分商业成功、S=达到该年规模状态、F=失败／退出。四状态在当年互斥且合计100%；F为吸收态。S可以因竞争退至P或F；“当年处于S”不同于“截至当年曾达到S”。下表逐年概率是当前信息下、条件于对应经营情景的局部概率，不是四行情景发生率，也不是整个股票成功率。

采用可复算的一年阶段转移：U→P、U→F、P→S、P→F、S→P、S→F。第一年NPO不能直接到规模，OmniConnect和ALC在前两年不进入规模；这给芯片／系统认证和制造留出时间。每年度状态先转移，再按当年状态收入确认；因此没有将累计成功率每年连乘。四行情景改变进入／扩量／退出概率，**没有把突破行新机会全部设为100%**。

共享资源依赖的处理：核心经营费用与扩张CapEx已经随经营行上升，各机会另付专属研发；替代收入显式净额处理。基准三机会边际已反映共同认证与人才约束，线性期望可相加；**不将三个局部S概率相乘作为整股成功率**。检查全部早期机会失败时前三年现金仍为正，故这些路径没有被平均现金掩盖的融资断点；极端核心受损另作联合融资检验。

### 5.3 估值理念、目标日资本桥和剩余价值

主矩阵短期采用**经营信息修复的条件经济价值**，中长期采用**可持续更新平台的股东现金价值**；方法均用同一分产品、状态与资本底稿的DCF，不把短期改成随意倍数后再将方法差异当成趋势。主矩阵回答条件合理价值，不预测届时股票一定成交于该区间。

参考持有要求：主矩阵采用15%年化，邻近12%—18%；3个月约3.6%、6个月约7.2%、一年15%、三年52.1%。强正面还要求合理不利敏感性保持优势；高风险平台论点采用20%年化、邻近18%—25%，三年要求72.8%，允许重大失败损失但不依靠杠杆或被迫融资。稳健投资另要求普通偏差有明显余量，不能将结构受损的−80%当可承受普通波动。标准是研究参考，不因某行情景算得好就临时降低。

美元现金机会成本用约4%工作值：09-08国债3个月3.94%、6个月4.00%、1年4.15%、10年4.80%。DCF统一股东风险补偿工作值11.5%、范围10.5%—13%，由美元利率加约6—8个百分点未进入现金的系统和资本市场风险表示；机会失败与经营损失已进入状态／现金，不再另乘失败折扣。投资者要求20%不等于把公司经营改差，也不要求机械把DCF折现率改成20%。[S16]

估值在目标日计算**目标日以后**的剩余现金，目标日前FCF只经现金积累计一次。由于采用逐期稀释，先将未来每期可分配现金乘目标日股数/未来股数，再折现，得到“归属于目标日股份集合的经营权益价值”；它是直接股权法，不能与未稀释企业EV混用。无重大有息债务，故加现金、扣尚未支付或有现金即可。公式：

```text
V经营(目标日t)=Σ[FCF经营(y)×N(t)/N(y)÷(1+r)^(y-t)]＋剩余经营权益
V股权(t)=V经营(t)+现金及短期投资(t)−未支付或有现金(t)
每股V(t)=V股权(t)×1000/N(t)
总回报=V(t)/167.75−1；年化=[V(t)/167.75]^(1/t)−1
```

第一年季度现金用各季中点；后续年度用存续期间中点。所有情景无现金分红，故不存在分红再投资假设。股数与未来CF按相同时间轴，不用今天折现现值冒充未来退出价。

**持续更新尾部：** Y10后基准集团现金名义增速2.5%、乐观／突破3%、受损−5%；同时继续2.5%／3%／3.5%净授股，基准每股现金尾部基本不增长。核心研发、更新CapEx和周转需求已扣，不能再把维持支出加回。基准末期收入增速已降到低个位数，现金剩余增长不超经营增长。将末年净新增资本投入与2.5%长期增长匹配，需维持约20%—30%以上的增量回报；若只能10%，须降低现金或增长，不能兼得。Y10机会分布不重新归一到成功者；退出路径仍为零。

**有限寿命替代：** 相同前十年后，竞争／平台内置使现金每年衰减15%，延续十年至Y20后为零，并保持未来稀释。这不是“公司只活三年”，而是对2036年以后更新能力不同的经营解释。该解释足以改变乐观行的强度，必须与主矩阵同时保留，不能说用另一种工具就消除了不确定性。

尾部再投资校验：基准Y10税后、SBC前经营现金能力约4.453，现金CapEx减普通折旧加增量周转／押金约0.309，再投资率约6.9%；匹配2.5%增长，对**研发已当期费用化的新增固定／营运资本**要求约36%的表观增量回报。乐观相应约38%，突破约29%。这不是包含资本化研发和历史收购的公司会计ROIC。若基准这些新增资产只能取得15%，为同样增长需约0.742投入，较现有多0.433/年，尾部现金必须下修，不能靠改工具保留原价值；若维持现有投入，则只支持约1%增长。这样的反馈正是平台解释需要跨代盈利和投入数据支持的原因。

### 6.2 高风险平台论点的当前裁决

高风险理念可以容忍50%以上失败损失，不能因此只看420美元成功上沿。先固定同一三年目标日、现金模型和20%年化要求：167.75需要约289.87美元退出值。仅OmniConnect独立完整成功约200.6，低于要求；只有更广泛平台成功或更低买价才能提供高风险补偿。

为说明可信范围与门槛的关系，另定义三年整股决策分支，**不直接赋权四个代表情景**：H=核心及光平台持续扩张、目标日前获得足以支持相应定价的证据；D=出现重大持久核心损伤；O=除H和D以外的普通兑现／小幅偏差／模糊路径。按“先判断D，未D再判断H，其余O”使其互斥并覆盖本模型相关路径。H参考价值287—420，O约144—158，D约30—60；上下限不是分布分位数，路径内部更极端事件仍有覆盖误差。

当前研究对H给30%—50%、D给10%—20%的**主观探索范围**，O取剩余；不是将NPO的37%或三个新机会相乘挪来。H机会存在由AEC商业规模、多产品能力和客户预算支撑；要把H上端当高确定性，仍需跨客户实际光收入、下一代复购、稳定净价及现金。这些尚未披露，故当前不采用“成功几乎已锁定”的解释。D不是因为收入差就必然发生，当前盈利和现金也不支持将其当多数路径。这些宽概率没有足够项目样本校准，**5—10个百分点不能视为已裁决差异**。

即使选H=420、O=158、D=32和D概率10%，为达到289.87，H概率也需约55%；若H仅287，门槛超过100%，该三个值的组合本身无法满足要求。相反，15%年化门槛约255美元，对H=420的所需概率约42%，落在探索范围内部。因此：**15%且能承受重大损失的激进投资者可以形成有条件的参与论点；20%以上要求下当前证据尚不足，且主观概率误差足以翻转边际结论。** 不能宣称所有高风险投资都错误，也不能以50%是工作上界就断言55%不可能。本文当前选择为高风险“中性、优势暂不可辨认”，而非将不确定性伪装成精确期望收益。

最小的有效新增证据不是股价上涨：需要将H内部从“可能规模”推进到“多平台付费复购＋现金率保持＋下一代资格”。在核心普通时，单一新机会的成功参照已不足，故仅多一张设计合作公告不会翻转当前结论。价格改变时可沿相同H/O/D损益重新计算，不能另选更有利概率。

def cash_at(m,t):

        if y==1:

                    v=flow*(n/shares(si,mid,extra))/(1+r)**(mid-t);pv+=v

            if y>5:future+=v
    last=m['records'][-1]['vcf'];terminal=0
    if tail=='renewal':
        # Post-Y10 cash grows at the stabilized rate; future dilution continues.
        g=[-.05,.025,.03,.03][si]
        # full capex/R&D already deducted; terminal reinvestment check in report
        ge=(1+g)/(1+gshares[si]+extra)-1
        tv=last*(1+ge)/(r-ge)

    else:

        for z in range(11,21):

    cash=cash_at(m,t)
    claim=earncash[si] if t<2 else 0
    ev=pv+terminal; eq=ev+cash-claim
    return {'ev':ev,'eq':eq,'cash':cash,'claim':claim,'n':n,'price':eq*1000/n,'terminal_pct':terminal/ev,'remote_pct':(future+terminal)/ev}
