**概率是有机制约束的主观工作分布，无可直接套用的可比成功基础率。** U=当年未商业化、P=有限/部分成功、S=当年处于规模商业状态、F=该路径失败退出。U/P/S/F互斥且合计100%；F吸收，不能复活；S可退回P或退出。并非“累计曾成功”概率，不能每年再连乘一次累计成功概率。规模收入仍逐年爬坡，达到S不等于立即获得最终TAM。

### 4.3 三种有解释力的投资论点

现金安全边际：回报来自可持续现金与可实现资产，对所有期限都缺少现价保护；净债务和专用工厂意味着账面资产不是现金底价。经营复利：利润和现金可成长，但高价要求未来收益长时间以高ROIC延续，必须扣全部维护和成长成本。平台/里程碑期权：可以在收入前获重估，最少条件是客户架构采用、康宁收费份额及可重复量产，不要求玻璃、电池全部成功；失败可带来50%以上价格损失，须有相应上行，不能只展示10.0市场目标。

## 5. 条件矩阵与十二格明细

### 5.1 标准和读法

### 6.4 高风险标准下的成功门槛与证据取舍

以普通结果三年约82、持续平台突破约256作**两分支决策算例**，两分支必须假定覆盖其余中间结果才可赋权；现实四行及遗漏的极端成功/失败并不自动满足该条件。忽略更差损失已对上行有利：计3.08股息，达到零名义回报所需上行分支权重约46.5%；达到12%年化所需退出价值230.08，上行权重约85%。若采用20%年化高风险要求，所需退出价约283.69，高于此算例成功端256，即便100%也不足；15%年化要求约249.33，所需接近全部落在成功端。用269.71作成功上端会缓和，但仍要求很高的联合可达性。这里反求的是**整股联合路径门槛**，绝不是Photonics2031 S概率59.3%。

当前证据支持客户入口、核心增长和投入配套，尚不支持“2036年集团收入超过1,000亿美元、且净收费和资本回报长期保持”的必要经营组合作为接近确定事件。多来源供应、客户议价和产品替代是具有实际证据的反面机制。因此，在15%—25%年化高风险参考标准下，本研究也不形成当前参与建议；不是因失败概率较高就自动拒绝，而是可验证成功规模与失败代价配对后补偿不足。

若某投资者只要求零至低个位数回报、能承受大额亏损，并对更大平台规模有独立信息，当前优势仍可能属于不可判定，而非本文证明买入必错。最小新证据组合是：至少两个不同客户平台的可重复付费规模、每平台康宁净内容与质量成本、配套新增资本ROIC，以及跨代资格/续约净价；更大TAM或第三份同源宣传不能替代这些观察。

### 6.5 等待的价值和损失：相同资金、原目标日

比较初始165.96美元、原退出日2029-09-09，观察日设2027-03-09，现金机会成本年化4%。两策略均可在观察日读取相同证据；以下先比较立即买入并持有与持现金后条件进入，允许立即买入者也卖出时，其早期价格涨跌已实现，不能假设无成本撤销。机会成本4%是算例，源于近半年国债量级，不保证未来三年再投资利率固定。

强支持观察假设最后退出255，观察日交易价格190/210/230（**情景成交价算例，非预测**）。立即买入持有者末期财富258.08；等待者先获得约169.25资金，再按相应价格买入并取得剩余2.80股息，末期财富约229.64/207.77/189.70。确认后更贵与持有期缩短可以使等待显著落后，不能说有信息总是等待更好。按剩余2.5年12%要求，255+2.80对应最高可付约194；若确认价210—230，纪律性等待者会继续不买、可能错过涨幅。

反对观察假设退出75，立即持有末期约78.08；等待者若识别后继续持现金，三年末约186.68。若下跌同时经营受损，70美元可能已不便宜，不能机械执行旧基准买价。仍模糊观察：季报只确认已知收入而不能区分跨代持续性，继续持现金要承担上涨机会损失；不能宣传“再等一季就解决”。确认有误或披露延后，两策略都承受信息噪声。

这些分支揭示损益，**没有可核验的观察结果联合概率与成交价分布，故不能声称等待策略的期望收益严格更高**。当前较有依据的是：基准与乐观主路径的经济回报不足，稳健资金保留现金/其他机会；把等待某次季报作为更优择时策略，证据尚不足。候价边界需与经营同步更新。新信息若能够把持续平台收入、收费与ROIC的范围收窄，才有理由沿本模型改变当前选择。

        origA=dt.date(b.year-1,10,1) if b.month==1 else dt.date(b.year,b.month-3,1)
        frac=(b-a).days/(b-origA).days
        time=((a+(b-a)/2)-target).days/365.25
        ev+=d['FCFF']*frac/(1+wacc)**time
    end=dt.date(2037,1,1);last=rows[2036]
    # terminal profit belongs to current shareholders after NCI; SBC stays expensed
    nop=last['EBIT']-last['tax']-last['NCI']
    term=nop*(1+g)*(1-g/ROIC[s])/(wacc-g)
    tv=term/(1+wacc)**((end-target).days/365.25);ev+=tv
    # postretirement and incremental non-debt lease/contingency reserve, equity affiliates not separately capitalized
    equity=ev+cap['cash']-cap['debt']-.65
    shares=cap['shares'];exercise=False
    # expiry May 6 2029: exercise only if same path intrinsic value supports it at expiry
    if target<dt.date(2029,5,6):exercise=equity/shares>180
    else:
        pre=value(s,rows,dt.date(2029,5,5),wacc,g)
        exercise=pre['exercise']
    if exercise:equity+=2.7;shares+=.015
    p=equity/shares
    div=sum(.28 for y in range(2026,target.year+1) for m in [3,6,9,12] if START<dt.date(y,m,29)<target and dt.date(y,m,29)>dt.date(2026,9,29))
    ret=(p+div)/PRICE-1
    return dict(price=p,equity=equity,EV=ev,TVpct=tv/ev,shares=shares,exercise=exercise,div=div,ret=ret,annual=(1+ret)**(365.25/(target-START).days)-1,**{k:v for k,v in cap.items() if k not in ['shares','div']})

def ntm(s,rows,target):
    end=target.replace(year=target.year+1);res={k:0. for k in ['R','EBIT','FCFF']}
    for a,b,d in blocks(s,rows):
        n=max(0,(min(b,end)-max(a,target)).days)/(b-a).days
        for k in res:res[k]+=d[k]*n
    return res

def renewal(s,extra=.12):
