## 2. 当前条件定位与矩阵摘要

> **当前条件定位：** 当前证据指向“**基准收入与利润、悲观现金转换与融资、基准—乐观长期负荷期权**”的复合经营定位，当前市场状态为“**宽基风险扩张**”；对应复合定位格子的建议为 **中性 / 等待**，目标期稀释后股权市值 **25.6—36.2**、每股价值 **117.6—166.0 美元**、15 个月总回报 **-18.1%—+14.1%**。当前复合经营路径证据强度为 **中**，市场状态证据强度为 **中**，估值置信度为 **低**。相邻“震荡 / 均值回归”状态下建议减弱至 **不建议投资**；最接近的纯格子是“基准 × 宽基风险扩张”，其条件建议为 **谨慎建议投资**。最小增强条件是 Oracle 2027Q1 的平均已计费负荷达到或超过 250MW、且新增权益融资没有高于已披露的年度 5—6 亿美元计划；最小减弱条件是 2027Q1 末仍无实质 Oracle 计费或首电延迟超过一个季度。概率层为 **NA**，原因是经营情景与市场状态的联合概率没有可辩护基础率。

### 2.3 当前价格到建议边界的距离

- 在复合经营定位和当前市场列不变时，使价值区间**中点**达到 12% 总回报所对应的买入价约为 **131.8 美元**，比当前价低 **12.5%**。
- 若当前价升至约 **153.4 美元**而经营证据不改善，则连复合估值高端也不能达到 12% 要求回报；该价格只比当前价高约 **1.8%**。
- 不需要价格变化，只要全市场从宽基风险扩张转为震荡 / 均值回归，复合条件建议即由中性 / 等待减弱为不建议投资。
- 在当前价不变时，经营证据上移到“乐观 × 宽基风险扩张”，条件建议才增强为建议投资；相反，Oracle 计费延迟或融资超计划会把复合定位结束在悲观方向。
- 当前定位最依赖的经营变量是 **2027H1 Oracle 实际已计费 MW 与融资额的联动**；最依赖的市场变量是 **公用事业可获得的退出 P/E / 股权资本成本是否因长期利率与风险偏好变化而收缩**。

## 3. 核心投资逻辑与最强反证

| 方向 | 最强逻辑 | 对股东价值的传导 | 最强反证 |
| --- | --- | --- | --- |
| 正面 | DTE 的核心是具有费率回收和长期资产基础的受监管 Electric / Gas，而 Oracle 合同把新增大型负荷从叙事变成有 19 年期限、80% 最低计费需求、母公司担保和退出保护的可执行项目 | 负荷、储能、配电和发电投资进入受监管或合同化资产，形成长期需求费、成本回收和获准回报；若 Oracle 按期爬坡并且 Google 获批，2027 以后 EPS 增长可高于传统公用事业 | Oracle 的收入起点在 2027，储能、输电、客户设施和 GPU 上架必须同步；法律上诉仍未终局，Google 也没有获批、场址和送电闭环 |
| 负面 | 目前增长先表现为资本开支和融资，而不是自由现金流；当前股价又已经给予约 19.7 倍 2026 指引中值 EPS 和约 14.4 倍 TTM EBITDA 代理 | 2026—2028 每年 0.5—0.6 权益融资、净债务上升、利息和折旧可在收入兑现前压低每股价值；高利率或信用收紧时，经营增长与股东回报可以背离 | 若客户预付、合同保护、监管回收和项目进度使 FFO/debt 维持目标、每年权益发行不超计划，同时 Oracle 负荷早于预期，则负 FCF主要是高回报 rate-base 建设而非价值毁损 |

决定胜负的不是“数据中心 GW 是否很多”，而是下列完整链条能否同时成立：

1. 合同容量转为按时、可计费的 MW；
2. 成本由客户或监管机制充分回收，而非留给普通客户或股东；
3. 获准回报高于新增资本的真实融资成本；
4. 经营收益增长快于完全稀释股数、利息和折旧增长；
5. 退出市场仍愿意为这种每股增长支付至少中高十几倍 P/E。

### 5.4 复合定位如何上移、下移或结束

- **上移到乐观：** Oracle 2027Q1平均已计费负荷 ≥250MW，且公司不提高年度 0.5—0.6 权益融资计划；若再有 Google 最终批准并保留客户成本承担与信用保护，乐观路径更稳。
- **回到纯基准：** CFO达到或超过约 4.4、年度权益融资不超 0.6、目标完全稀释股数不超约 218 百万，同时 Oracle 按 2027-01起点计费。这里最小变化是现金 / 融资驱动由悲观转为基准。
- **下移到悲观：** 2027Q1末仍无实质 Oracle 计费、首电延迟超过一季，或年度权益融资需求高于约 0.8；任一项都足以改变每股价值。
- **不能用短期强收入证明长期突破：** Trading gross revenue、燃料价格或一次性费率补记即使推高合并收入，也必须同时出现 operating earnings、CFO和每股收益改善才可上移。

### 6.2 事件树与去重

**Oracle路径：** 合同与MPSC批准 → 储能 / 输电 / DTE设施与客户园区同步 → 2027-01起首次计费 → H1实际平均MW → 2027-12满载。合同事实已进入所有经营情景；只有计费MW与时间变化才使情景迁移，不再额外增加一份“Oracle价值”。

**Google路径：** contested case批准 → 成本、MBD、退出费和信用保护不被削弱 → 场址FID → 清洁资源、储能、需求响应与输电闭环 → partial power → 2028满载。仅获批不能跳过后续节点；主矩阵基准行不计Google主体收入。

**融资路径：** Capex承诺 → 客户出资 / CFO → 债务、次级债与权益组合 → FFO/debt和评级 → 每股稀释。高增长情景的更高收入和更高Capex是同一因果链，不能只计收入、再把融资当成独立利空重复扣减。

### 8.4 DDM参数与模型分歧

- 当前年化股息 D0＝4.66美元。
- 第一阶段为10年：悲观增长3%—5%、基准6%—8%、乐观8%—9%、突破9%—10%。
- 终值增长：悲观2.5%—3.0%、基准3.0%—3.5%、乐观 / 突破3.5%—4.0%。
- 股权资本成本随市场状态变化：宽基8%—9%、主题8.5%—9.5%、震荡9%—10%、有序收缩9.5%—11%、流动性压力11.5%—13.5%。
- DDM在高增长 / 低折现率组合下极敏感，因此只作长期边界，不能用一个Gordon目标价覆盖融资风险。

当前复合定位 × 宽基风险扩张的三种结果展示了分歧：

| 方法 | 每股价值 |
| --- | ---: |
| 主P/E | 143.1—166.0 |
| DDM | 93.2—142.0 |
| EV/EBITDA | 91.3—138.8 |
| 综合条件区间 | **117.6—166.0** |

综合区间不做等权平均：高端由主P/E的可交易市场结果约束；低端取“P/E低端”与“DDM / EV交叉检查中较强的中点锚”两者较低值。这样既保留主方法，又不让高P/E掩盖负FCF和净债务的模型分歧。分歧越大，区间越宽、估值置信度越低。

### 8.5 计算公式与去重

- 目标期股权价值＝目标EPS × 市场状态P/E × 目标完全稀释股数。
- EV交叉价值＝目标EBITDA × EV/EBITDA；股权价值＝EV - 目标净债务。
- 每股价值＝稀释后股权价值 / 情景固定股数。
- 15个月总回报＝（目标每股价值 - 150.64 + 5.825）/ 150.64。
- Oracle、Google、费率案和融资只通过其改变的EPS、EBITDA、净债务、股数、资本成本或情景迁移处理一次。

邻域从建议投资到不建议投资跨越多个强度，说明当前条件判断**不稳健、且同时对经营兑现与市场状态敏感**。最容易造成方向反转的经营假设是Oracle已计费MW能否在不增加融资超额的前提下转为每股收益；最容易造成方向反转的市场假设是退出P/E能否守住约18.5—20.5倍。

### 12.2 全矩阵形状

本矩阵的中性形状标签是：

- **条件正面区域：** 正面建议主要集中在乐观 / 突破与宽基 / 主题状态，不是广泛正面区域。
- **经营兑现敏感：** 同一宽基状态下，悲观为强烈不建议、基准仅谨慎、乐观为建议、突破为强烈建议。
- **市场状态敏感：** 同一乐观经营下，主题为建议、震荡仅谨慎、有序收缩为不建议、信用压力为强烈不建议。
- **突破价值集中但非唯一价值：** 突破行上行最大；然而乐观×宽基 / 主题也有正面条件建议，因此价值并非只剩一个突破格子。

建议最稳定的区域有两个：悲观行在全部市场状态均为强烈不建议；流动性 / 信用压力列在全部经营情景均为强烈不建议。正面区域中，突破×宽基 / 主题最稳定，但其当前经营证据强度最低。

最脆弱边界是：

1. 基准×宽基的谨慎建议，一旦市场转为震荡即变为不建议；
2. 乐观×震荡的谨慎建议，一旦转为有序收缩即变为不建议；
3. 突破×有序收缩仍为谨慎，但若融资状态进一步恶化至信用压力即变为强烈不建议。

最坏格子是“悲观×流动性 / 信用压力”，每股54.9—95.0、总回报-59.7%—-33.1%。损失来自盈利受损、目标净债务仍高、再融资和稀释优先于普通股、退出倍数降至10.5—12.5倍的共同作用，而非单纯倍数压缩。

### 12.4 重要状态联动

| 原纯格子 | 传导变量 | 更可能迁移的格子 | 解释 |
| --- | --- | --- | --- |
| 基准 × 有序风险收缩 | 客户预算放缓、Google审批 / FID延迟、融资成本上升 | 悲观 × 有序风险收缩 | 原格子回答“经营仍保持基准”；现实若预算和融资同时传导，则经营行也下移，不能在原格子先完整下调一次 |
| 基准 × 流动性 / 信用压力 | 0.5—0.6权益计划失效、债务成本跳升、FFO/debt下降 | 悲观 × 流动性 / 信用压力 | 融资和稀释直接改变每股经营路径，压力列只是外部条件 |
| 乐观 × 主题主导上涨 | Google未获批、Oracle计费低于250MW、headline GW缺少收入 | 基准 × 主题主导上涨 | 主题溢价不能替代经营证据；经营回落而市场列不变 |
| 突破 × 宽基风险扩张 | 额外GW无合同 / 信用 / 资源，或Capex融资未闭环 | 乐观或基准 × 宽基风险扩张 | 市场仍扩张，但公司自身非线性路径失效 |

纯格子回答“若经营行保持不变会怎样”；上述联动回答“现实中状态可能怎样推动公司换行”。两者没有重复计价。
