## 一、当前选择与研究时点

**当前证据最支持“正常兑现”的经营解释，但99.57美元买价对增长持续期和现金回报支付过多。按本报告的参考标准，短期、中期、长期当前均不建议新投入。** 这不是判断ABB经营将变差，也不是预测三个目标日必然跌到DCF值。短期市场可能继续给予高倍数；突破经营路径在一年和三年格中可以有条件正面建议，但当前证据尚不足以把这条路径当作实际买入依据。

## 二、公司全貌与决定性证据

### 2.1 ABB股东实际拥有什么

ABB出售安全分配电力、将电能转为运动、控制工业过程的设备、工程和生命周期服务。客户愿意支付的核心是可靠性、按期交付、全寿命成本和停机风险降低。公司捕获收入依赖设计定点、合格设备、渠道、工程责任和装机服务，并不拥有电网、数据中心租金或客户全部节能收益。

必须固定的组合边界：原Power Grids/Hitachi Energy已不属于ABB；服务器Power Conversion旧业务已经出售；Robotics列为终止经营并拟售SoftBank；B&R机器自动化继续保留在Automation。Rotork尚未并表，不能把其收购称为2026有机增长。集团的机器人AI长期权益若交割，将属于买方，不能再加在ABB出售所得之上。[ABB公司调研L1，来源附件；原始财报的业务分部说明和终止经营附注](https://library.e.abb.com/public/a15cd116ef994addbaa55c542d490d18/ABB%20Q2%202026%20Financial%20Information.pdf)

### 2.2 共用已实现财务基线与质量检查

2025年持续经营收入33.220；三大分部电气17.357、运动控制8.247、自动化8.084；其他与抵销净额−0.468。2026H1三分部收入9.813、4.359、4.340，其他和抵销−0.303，恰好对应集团18.209。2026Q1/Q2集团收入8.734/9.475，运营EBITA2.049/1.925；Q1含0.377地产收益，正常化后分别1.672/1.925，H1共3.597。2026H1毛利7.233、GAAP营业利润3.365、归属持续经营净利润2.529；后者也仍包含不动产及其他非经常项目。[Q2财报p.5、8及Q1对照](https://library.e.abb.com/public/a15cd116ef994addbaa55c542d490d18/ABB%20Q2%202026%20Financial%20Information.pdf)

2026H1持续经营CFO2.315、CapEx0.417，因此**持续经营CFO−CapEx=1.898**。公司定义FCF再加固定资产出售回款0.462为2.360；再计终止经营FCF−0.229，才是公司总FCF2.131。这些数字不能相互替换。下文估值现金进一步扣除股份报酬经济成本、必要更新、少数股东份额，排除出售收益；资本桥才处理并购、出售、融资、分红和回购。[Q2财报p.11、47](https://library.e.abb.com/public/a15cd116ef994addbaa55c542d490d18/ABB%20Q2%202026%20Financial%20Information.pdf)

Q2集团运营EBITA和GAAP营业利润差0.340，除购买价摊销外，还含重组、历史义务、投资重估、外汇/商品衍生品时间差等。约0.100历史索赔及整改准备、0.030投资公允价值费用足以使“全部调整都是非现金、全应加回”的做法失真。电气Q2毛利率约40.3%，同比下降1.4个百分点，而运营EBITA率约24.9%上升；改善主要还依赖数量和费用摊薄，不是净价格无限提高。[Q2业绩原文p.4、6](https://library.e.abb.com/public/c585b474e3f44783bd99eb5c5ba56039/ABB%20Q2%202026%20Press%20release%20English.pdf)

历史现金桥发现一个不影响结论但必须保留的差异：财报p.47 TTM桥将Q1 CFO列1.011，季度公布总CFO为1.029；前者接近持续经营CFO。两种TTM相差0.018。本报告采用半年逐项现金桥，不拿该差额解释经营趋势。

收入确认方面，标准产品一般在控制转移时确认，项目满足条件时按履约进度；成本到成本法受总成本估计变化影响。订单、设备交付、客户上电与收款不同时发生。合同负债由2025年底3.221增至2026H1的3.545，同时库存由5.862增至6.471、合同资产由1.090增至1.189，说明现金改善包含预收与应付支持，不能称为简单去库存。针对性检索未取得集团毛取消率、数据中心客户合同取消条款和独立回款队列；保留这一未知，不把全部积压视为不可取消take-or-pay。

### 2.3 决定性分歧：证据如何改变经营假设

**争议A：AI订单是真交付，还是前置采购？** 财报Note 8把30.007积压定义为未满足履约义务，预计47%在2026、33%在2027履约。约14.103可支持当年H2目标19.841的71%，余下需短周期新增订单、服务等。Q2实际收入强增长与微软当季新增约1GW、31个数据中心的客户披露，足以反对“全部只是意向”的解释；却不能排除部分采购前置。微软同时提高既有容量吞吐，说明计算增长不等于同幅度设备MW增长。[Note 8](https://library.e.abb.com/public/a15cd116ef994addbaa55c542d490d18/ABB%20Q2%202026%20Financial%20Information.pdf)、[微软FY2026Q4电话会](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q4)

据此采用2026DC4.45、2027为5.55的工作路径，未采用电气订单+58%直接预测收入+58%。集团积压桥25.282+23.340−18.209=30.413，和30.007差−0.406；汇率、组合、取消和调整都可能解释，不能称之为取消率。进入受损路径需订单释放延期、预收下降、库存/合同资产上升共同出现，而不是单季订单同比下降。

**争议B：设备数量增加会不会被每MW价值减少抵消？** 2025事实手册电气数据中心占比17%，17.357×17%=2.951；该比例是管理层估算，且2024从12%修订为14%，不能拿旧分母夸大增速。已目视核对事实手册第6页饼图及脚注。[FY2025事实手册](https://library.e.abb.com/public/db886de614374ba19a8856e6f1a730e7/Factsheet%20FY%202025.pdf)

本地低压行业研究给2026核心设备池8—16，但该池不含中压、UPS，不能用ABB全部DC收入除它求市场份额。本地800V研究估2030受支持IT容量4.76—32GW、设备池1.051—10.200；它是验收口径，ABB可提前按履约确认，亦存在旧品替代。上述范围进入的是**产品边界、时间和上限检验**，没有直接乘“ABB占10%”成为收入。

对基准2027DC增长约25%，采用等价交付量+24%、每MW内容+0.5%、净价+0.3%的相容工作拆解（乘积约+25%）；2028/2029增约17%/15%，更多由数量而非不断提价贡献。对突破2029核心DC13.5，以假设ABB已供货项目净内容0.3—0.6百万美元/MW核对，需要约22.5—45GW同范围供货，对比2026仅约7.4—14.8GW。该路径要求合格出货能力、跨区域客户以及系统供货份额都明显增加；高端难度远高于“AI总投资上升”。这里的等价MW是可审查预算检验，不是已披露物理产能。现有原文尚不能支持22.5—45GW为高可信经营预测，因此不选突破为当前主路径。

**FCFF计算：** 核心=(核心EBITA−现金重组)×74%−少数份额+非购买价摊销折旧−全部CapEx−Δ营运资本；再加第四节状态加权机会FCFF。少数份额工作率为核心收入0.25%。折旧/非购买价摊销约核心收入1.8%；已扣除固定资产折旧的EBITA并非EBITDA。购买价摊销在利润口径扣除，但不是第二次现金支出；为避免高估税盾，现金税不依赖全部购买价摊销可抵税。税率26%与实际H1税率约25.6%邻近。

**报告现金与估值现金的桥：** 估值FCFF保留股份报酬的经济成本。现金报表可加回非现金股份报酬，模型以约0.10/年现金回购匹配该新增股份，净股数不变；这是按H1股份支付权益变动约0.048建立的工作预算，不是已经承诺回购。用于融资的经营净现金，再减约0.24/年税后债务成本、加现金余额约3%税后利息，含交割前机器人现金消耗；另加回0.10非现金报酬并在融资端支付等额反稀释回购。两项互相抵销，不能既永久扣成本又任凭同一报酬重复稀释。

基准2027 FCFF约5.353，约0.24债务成本后约5.113，再加现金收益及0.10报酬报表调整，构成模型报告FCF数量级。若实际选择用净发股支付奖励而不反稀释回购，则加回现金、同步增股，不能保留两种方式的有利端点。存量奖励的0.003十亿股储备已经在初始分母内。

### 4.2 状态、转移与概率依据

从2027起逐年到2036。状态U=尚未形成所定义增量商业收入；P=局部付费、项目/客户有限；S=取得可复用资格并规模扩张；F=该条路径失败/退出。**四状态对同一机会、同一年互斥且合计100%；四经营情景不构成概率全集。** S的收入随实际年度能力增长，2028的初始规模销售不等于2031的成熟规模。

初始分布U=100%。每年按下表转移，F吸收；U不能一步跳S，P/S可失败，S可以退化P。表列六项分别为U→P、U→F、P→S、P→F、S→P、S→F，剩余概率停留原状态。不存在失败后无条件复活，也没有把累计成功概率逐年连乘。

|---|---|---|
| 悲观 | 16% / 18% / 12% / 13% / 10% / 5% | 22% / 12% / 14% / 10% / 7% / 4% |
| 基准 | 30% / 10% / 28% / 8% / 5% / 2% | 32% / 9% / 25% / 8% / 5% / 2.5% |

这是**机制约束的主观工作分布，没有可适用的官方成功率或同质统计基础率**。不能称作实证估计。基准U退出等待时间约2.5年、P完成/退出约2.8—3年，反映产品到多个客户验收、复制交付、付费续用通常跨若干年度。直流产品已有工程入口，仍受设施架构与保护认证约束；软件可较早局部收费，但工艺停机/数据权及净收费限制规模转化，故转移和收入路径不同。

较高如2029接近100%规模成功的假设，与缺少实收净价、反复独立客户验收及竞争开放接口不相容；较低如所有年份均近零，与已有转换/保护能力、工业装机和产品化不相容。直流基准2031规模状态约33.2%，工业数字约32.2%，这是“当年仍处规模状态”，不是截至该年曾成功比例；2036直流约42.9%、失败约47.1%。

允许U→P和P→S各±5个百分点、其余概率及自循环相应保持合法，基准2031直流S约25.7%—40.4%、工业数字约24.5%—39.5%，三年每股价值约75.56—76.63。这个区间不是概率置信区间，只是有效分布敏感性。它没有跨越99.57买价，更没有跨越8%年化要求，故本次选择不依赖把早期成功率调低到某个点。

### 4.3 状态内单位经济、投入与现金

所有收入为该年的**净增可确认收入**，而非最终市场空间。P/S收入序列、状态概率和现金见附件完整80行。状态成本先算后加权：

- 直流P/S在追加固定研发前的EBITA为收入18%/28%；U每年研发0.035，P研发0.030+0.005j，S研发0.040+0.008j，j=0对应2027。
- 工业数字P/S对应32%/48%；U研发0.025，P为0.020+0.003j，S为0.035+0.006j。软件成功的高利润也保留工程/销售成本。
- 直流折旧2%收入、CapEx3.5%收入+P状态0.008/S状态0.025年度工具/测试资本；工业数字折旧1%、CapEx1.5%收入+同类状态固定工具资本。
- 营运资本直流15%、工业数字6%收入，**逐个前后状态配对**计算余额变化。新进入F只回收一半原营运资本，并处理相应损失税效；另一次性退出费0.025×当年新进入F概率。F存续年不重复收退出费。
- 税率26%，早期损失在集团其他利润充足时取得税效；若未来核心受损到不能利用税损，需另算联合融资分支，不能机械沿用本表。

部分成功因此可以收入为正、利润/现金仍负；规模成功也可能在爬坡阶段先耗资。基准2029两条早期机会加权收入合计约0.216、EBITA约0.0035、FCFF仍为负；潜在远期能力已有价值，不能用当期亏损把它简单归零。

两机会共享客户预算和部分技术，转移中已包含相应资源限制；本次所有主要联合分支仍有充足现金，无破产或被迫大规模增股断点，线性期望可以相加。资源互斥的DC旧产品替代已经在净收入边界扣除，不能在集团再减一遍失败率。

### 5.4 一年兑现与三年剩余成长

一年后基准NTM EPS约3.50，比研究日起约2.99高约17%；现金和股数也改善，但买入价格约33倍近期盈利，经营进步的很大部分已支付。按28—32倍未来EPS，可能交易价格约98—112，加1.25股息，约0%至14%；达到12%回报需要约31.5倍，位于较高端。现金DCF和高PE并非“两种方法投票”，后者必须代表较长成长、较低风险补偿或短期愿意继续支付溢价。

三年后基准收入约49.51、EBITA约10.84，后续NTM EPS约4.33。用23—30倍定价可形成约100—130美元交易价，含分红的累计回报约4%—34%，年化约1%—10%；需要高端倍数才能满足较高复利要求。若认可如此高的持续倍数，必须说明2030后的收入、更新资本和定价权，而不是因为持有了三年就选择30倍。

三年内较有辨别力的长期证据包括：第二/第三代产品仍获客户资格、DC净每MW收入与毛利没有随着开放架构下降、服务续用确有增量收费、工厂成熟后资本回报稳定。三年时的收入不是全部价值；DCF显式预测至2036并计算之后剩余现金，而成功机会仍以届时可能的信息更新，不按日历自动成功。

## 六、估值、反向检验与理念分歧

### 6.1 主要投资论点与选择标准

主矩阵统一采用与现金权益相容的目标日DCF作为**条件合理价值**。同一经营行各期限不换预测，不为某一格临时选择更高PE。

| 理念 | 可辩护收益来源 | 参考要求与约束 | 当前取舍 |
|---|---|---|---|
| 可见经营预期差 | 新信息提高前瞻现金或揭示市场过度损伤定价 | 6个月约8%总回报，相邻6%—10%；不将30%永久损失换取个位数预期收益 | 现价已反映强增长，拒绝；高倍数延续交易优势仍不可辨认 |
| 一年经营兑现 | 订单交付、利润、周转和股数共同提高股东权益 | 12个月12%，相邻10%—15%；普通执行偏差须有风险补偿 | 基准即便兑现仍回报不足，拒绝 |
| 质量复利 | 持续资格、渠道、装机更新和资本回报 | 三年最低年化8%，优选10%，检验8%—12%；不要求所有合理结果盈利，但不能靠单个估值上沿 | 普通和更持久平台解释都不足，拒绝 |
| 高风险技术/核心突破 | 核心系统价值跃迁与新产品规模收费 | 年化15%—20%作为高损失承受的回报补偿示例，允许30%—50%亏损但需可信非对称上行 | 量化范围内突破上沿三年约15.1%，连20%目标都达不到；单一机会完整成功不支持买入 |
| 现金安全边际 | 现金、可实现资产和稳态现金提供保护 | 需低价与较坏合理结果仍有余量，不能仅靠品牌 | 净现金保护很薄，现价无此论点 |

这些是研究参考，非声称用户真实风险偏好。要求更高回报不表示公司经营更差；9%折现率是美元现金的经济定价参数，与投资者8%/12%等持有要求分属不同层次。

### 6.2 目标日DCF与资本桥

逐季度现金仅在目标日后进入经营价值；目标日前现金通过真实分配规则进入余额。对跨目标日季度按剩余天数分配，并按剩余期间中点折现。公式如下：

```text
经营价值(t) = Σ[目标日后各季度剩余FCFF / (1+WACC)^剩余中点年数]
            + TV(2036年末) / (1+WACC)^剩余年数
TV = 2036年归属NOPAT × (1+g) × (1-g/成熟ROIC) / (WACC-g)
股权价值(t) = 经营价值 + 现金/短投 - 金融债务 - 0.30其他净索取权
            + 尚未交割出售净回款现值 - 尚未支付收购净成本现值
每股价值 = 股权价值 / 目标日完全稀释股数
总回报 = (每股价值 + 期间每股现金分红) / 99.57 - 1
```

经营现金采用已扣少数经营份额、股份报酬经济成本的口径，经营租赁作为费用，故不再将全部0.805经营租赁负债加债。债务8.177只在股权桥扣一次；模型FCFF没有再扣其融资利息。待收机器人回款以扣税/交易成本后的4.8计，不再同时给该出售业务剩余DCF；Rotork在经营价值中有并表后利润，故收购未支付时也必须扣成本现值。

主区间统一：WACC9.75%、成熟ROIC15%为低端；WACC9%、ROIC18%为工作点；WACC8.25%、ROIC22%为高端；终值增长g=2.5%。不同情景共用这组未固定的经济误差范围。美元长期国债约4.8%，再考虑股票系统风险及很低债务权重，8.25%—9.75%可作工作范围；不是声称已估计出稳定CAPM beta。低端参数组合只是合理敏感性，不是发生概率。

较高增长的研发、扩产、周转已进入现金，终值再投资与18%成熟ROIC相容。2036年的期望NOPAT仍保留第四节失败状态；成熟更新只延续仍活动的经营，不恢复失败业务。全部机会价值已在现金内，不额外加“AI期权”。

### 6.3 现价反向要求

研究日基准经营价值约116.83；99.57×约1.8161稀释股数，再扣/加同一资本桥，要求经营价值约183.47，约为基准的**1.57倍**。固定时间、风险与资本比例，意味着整条可持续现金路径须提高约57%；如只通过收入且利润/再投资结构不变，2036量级要从75.7提高到约119，而非只提高一季利润。实际增长与投入非线性，这只是展示要求的反求尺度。

固定全部基准现金和2.5%尾部增长，满足现价的WACC约**6.69%**，相对当时10年美元国债约4.8%的补偿偏薄。它不是市场真实折现率；一个价格也可能由更快增长、更持久利润或短期拥挤定价产生。独立事实支持增长，却尚不能支持“所有这些高端都成立”。

另一可复查的现价组合是28倍×3.56美元盈利、或32倍×3.11美元盈利。供应商forward EPS3.67显示市场数据并不一定缺少近期EPS上修；本研究主要分歧更偏向**利润的持续年数、现金税/周转/更新成本和承担风险的补偿**，不把当前高价全归为市场没看财报。

### 6.4 更持久的平台解释：保持普通三年经营，单独改变生命周期

替代实验保持2026—2030基准及资本完全不变；2031—2036一般核心增长持续8%而非衰减，DC仍略快，2030分业务利润率延续；尾部g提高至3%，成熟ROIC20%—25%。这代表“多代技术/客户平台持续复用”，而非换一个估值工具。

在8.25%—9.75%风险补偿下，三年合理价值约**85.44—112.73**，含3.902分红累计约−10.3%至+17.1%，上沿年化约5.4%。该实验2036收入约89.7、EBITA约20.6，已经明显强于原基准尾部，但仍不足满足现价8%年化。若再把WACC压到更低、长期增长再提高，就进入需要额外证据的更强联合解释，而非已证实的普通复利。

因此证据不支持在现价用“平台”一词把30倍盈利自动合理化。平台解释仍保留条件价值和更新入口，结论限于本次有机制约束的规模与持续期，不对无限未知机会作断言。

### 6.5 普通偏差、持续期误差与最小翻转组合

普通不及预期实验：基准2027—2030核心DC分别少0.5/0.8/0.8/0.6，其他电气收入少2%，两项利润率各少1个百分点；2027/28营运资本率由12%升至14%，2029恢复12%；费用和投资不即时等额下降。三年价值约**73.60**，相对基准76.16减少约2.56，总回报约−22.2%。2029的FCFF可阶段性高于主路径，是前两年库存/周转释放，利润与价值仍较低；没有将去库存现金误称为经营更好。

独立直流和软件成功、普通偏差与生命周期实验均在第四节同一表列出。普通偏差并非严重受损，不能拿悲观极端代替；本次基准本已无优势，普通偏差再次证实结论不是薄边界。

对于突破条件正面格，真正边际的是**一年回报仅约12.4%**。只把WACC从9%提高25bp、经营完全不变，一年每股价值从约110.65降至106.32，总回报约8.0%，低于12%标准；三年从128.58降至123.94，年化从约10.0%降至8.7%。若提高75bp、ROIC保持18%，三年年化约6.3%，也低于最低8%。因此主矩阵仅“谨慎建议”，不是靠突破名称给予强评级。

近似量级检查：电气净价下降1%，2027约22.85电气收入对应税前利润潜在减少约0.23；如果仅25%可由采购成本补偿，税后仍约0.13减少。总营运资本率提高2个百分点，以约42收入计额外占款约0.84，若永久占用，每股约0.46；其后释放只收回本金，延后仍损失时间价值。美元折算使全部美元现金永久低5%的单变量实验主要降低经营价值约5%，基准当前每股减少约3美元量级；若汇率影响需求、成本和价格，必须联合重算。

主估值三年目标日终值占经营价值约64%—65%，说明关键误差来自长期持续性；现有现金扣债后并不足构成高价安全边际。基准9% WACC时，成熟ROIC15%/18%/22%的三年每股价值约74.64/76.16/77.55；同为18% ROIC，WACC8.25%/9%/9.75%约85.73/76.16/68.59。±1个百分点长期风险补偿的影响远大于很多小机会的全部成功增量。

已入现金的订单延期、净价、成本、投入和局部失败不再追加同一“风险折扣”。折现率表达时间与未逐项进入现金的系统性风险，持有回报要求表达选择标准。两者的差异不能靠简单平均多个估值消失。

## 八、当前路径、行动比较及等待代价

### 8.1 当前经营选择和最强反证

当前取基准的理由是：已有收入、订单、客户真实建设和预收同时支持近年交付；这比“全部前置采购”的解释强。保留受损路径，是因为订单质量、净价格、项目按期上电及产能合格速度尚未完全可见。没有证据证明核心DC能在2029达到13.5，也没有证据证明自动化软件已经形成大规模独立收费。因此当前不把突破当成必然，也不将多个机会的小概率简单相乘成整股胜率。

相反，最强看多证据是数据中心客户真实扩容、ABB已有配电/控制技术、长期装机资格，以及新架构可能把收费从元件移向系统。它们提高增长范围，却未证明实现高价所需的**规模×持续期×净捕获×资本回报**组合。单独新产品成功与更长平台生命周期均已重算，当前拒绝由这些路径下仍不足的回报支持，而不是由“缺少官方点值就当零”支持。

最强看空反证若被推翻，会改变判断：连续多个季度订单与收入同步扩张、预收稳定、净价格保持、第三方客户对新架构重复采用、增长后的资本回报仍高。只看到新的GW合作或一家客户正式投运，能提高机会存在的可信度，尚不足以证明最需要的持续净利润。

例如基准原目标合计价值68.17，立即买1股得到68.17；若等待后以110买、投入100.01，终值约61.98，确认后买入反而更差。两者若均可在相同新信息后调整，必须给立即买入者同样卖出/持有选择，不能把静态买入持有与动态等待择时混称公平胜负。上表主要比较本题买入持有和观察后有条件首次进入，策略差异已明确。

相反，在足够强的突破结果下，立即买入的原一年经济价值约111.90，回报12.4%；完全保持现金只有约103.55，错失约8.35。若后来仅出现价格修复而长期机制仍难确认，这笔错失也可能发生。因此**没有证据证明“等一季财报”在所有相容路径优于立即买入**，也不能由无法证明等待更好推出应该买入。

当前选择更准确地说是：以证据最支持的普通经营和可辩护生命周期衡量，现价缺少足够回报，保留资金；Q3是较早的更新节点，不是承诺等完就买。需要能区分长期捕获和持续性的证据，或足够大的价格变化，才会改变行动。

### 8.4 高风险理念与覆盖边界

允许30%—50%损失并不会自动使所有低概率机会值得买。直流独立成功三年仍约79.78、工业数字独立成功约78.33；核心也突破的工作路径三年总回报约33.1%、年化约10%，上沿约15.1%。在15%—20%高风险回报标准下，只有接近全部高端才能勉强满足最低一端，任何普通结果/延期都会削弱经济性。这个结论无需把四行情景强行赋权为概率全集。

对只要求8%且能够承担大波动的投资者，突破路径本身可以参与，主矩阵因此保留条件正面；当前尚缺的是支持该完整核心路径的证据，不能拿直流局部规模概率33%或56%套到整股成功。未完成进入权利/金额界定的更远SST、工业自主平台仍有研究空间，当前结论不声称这些未知机会永远无法使股票值得投资。

 return {cash,debt,shares,div:divSince,fcfe:totalFCF,buybacks:totalB,divCash:totalD,sale:totalSale,mna:totalMna,netdebt:debt-cash};
}
function value(s,date,w=.09,g=.025,roic=.18){
 const t=day(date),end=Date.UTC(2037,0,1);let pv=0;
 for(const q of quarters[s]){
  if(q.en<=t)continue;
  const st=Math.max(t,q.st),x=(q.en-st)/(q.en-q.st),mid=(st+q.en)/2;
  pv+=q.fcff*x/Math.pow(1+w,(mid-t)/DAY/365.25);
 }
 const n=annual[s][10].nopat;
 const terminal=n*(1+g)*(1-g/roic)/(w-g);
 const tv=terminal/Math.pow(1+w,(end-t)/DAY/365.25);
 const pending=quarters[s].filter(q=>q.en>t).reduce((a,q)=>a+(q.sale-q.mna)/Math.pow(1+w,(q.en-t)/DAY/365.25),0);
 const cap=capital(s,date),eq=pv+tv+cap.cash-cap.debt-.30+pending;
 const price=eq/cap.shares,ret=(price+cap.div)/99.57-1;
 return{price,ret,eq,pending,ev:pv+tv,pv,tv,tvShare:tv/(pv+tv),annualized:t>start?Math.pow(1+ret,1/((t-start)/DAY/365.25))-1:null,cap};
}
function ntm(s,date){
 const t=day(date),e=new Date(t);e.setUTCFullYear(e.getUTCFullYear()+1);
 const end=e.getTime();let r=0,p=0,f=0,eb=0;
 for(const q of quarters[s]){
  const x=Math.max(0,Math.min(q.en,end)-Math.max(q.st,t))/(q.en-q.st);
  r+=q.rev*x;p+=q.profit*x;f+=q.fcff*x;eb+=q.ebita*x;
 }const sh=capital(s,date).shares;
 return{rev:r,profit:p-.24,fcff:f,ebita:eb,eps:(p-.24)/sh};
}
const values=names.map((_,s)=>targets.map(d=>({date:d,lo:value(s,d,.0975,.025,.15),mid:value(s,d),hi:value(s,d,.0825,.025,.22),ntm:ntm(s,d)})));

console.table(values.flatMap((xs,s)=>xs.slice(1).map(x=>({

 shares:x.mid.cap.shares,cash:x.mid.cap.cash,debt:x.mid.cap.debt
}))));
