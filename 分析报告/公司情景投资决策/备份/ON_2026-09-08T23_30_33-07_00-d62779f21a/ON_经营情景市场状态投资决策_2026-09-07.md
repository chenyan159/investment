### 2.3 行业输入如何进入模型

三份2026-09-06正式行业报告支持“先混合800V、后更广泛SST”和“局部AI紧张可以与汽车SiC过剩并存”。功率报告估计2030广义AI电源半导体基准9—15B，SiC器件7—11B；这是行业研究假设，不是ON订单。机柜报告2027扩展电源设备15—27B，包含设备与板上供电，不能全部乘一个ON份额。中压报告2027核心设备0.264—1.842B，和前者的高压子集因产品边界不同不能相加。

本模型只把这些输入用于三处：限制AI相关采购功率与器件金额的数量级；约束800V/SST的早期采用时点；要求扩产同时带来ASP和资本压力。2027 ON AI900大部分来自已存在架构，不能由仅数亿美元的800V细分器件市场支撑全部增长。若将900全部解释成新800V收入，即与允许的上游研究产生数量级冲突，必须否决这种解释。[NVIDIA的分阶段路线](https://blogs.nvidia.com/blog/800-vdc-power-architecture-ai-factory/)

2027新800V可归ON工作贡献约30—100，已包含在AI900之内，其余来自既有PSU、板级供电、保护及不同代际升级；2030相关新架构约200—500仍在AI1700内。其依据是上游设备收入乘器件占比、ON插槽和采用时差的联合约束，低置信度。把该部分全部砍掉，2027收入少30—100、税后利润少约8—33、对应约0.4—1.7美元的20倍利润价值；主要风险是全部AI电源的份额／净价，不只是一个架构标签。

### 2.4 合同、会计、资本与治理

截至Q2，分销占收入约59%，最大客户是一家未具名分销商、约14%；不能将其当成单一最终车厂。标准产品在约定窗口内可能无罚取消，定制产品通常需要补偿已发生成本。RPO约6.1B、其中37%预计未来十二个月确认，约2.257B，仅覆盖约七十多亿美元前瞻收入的一部分；较年末7.1B减少1B没有披露完整订单桥，不能直接称“取消1B”。合同负债76.0并非同等金额的现金订单锁定。

### 3.2 早期机会的经济规模与状态定义

X是**尚未稳定商业化的先进功率产品组合：垂直GaN、未验证的横向GaN与Vcore新平台插槽的净新增收入**。不含核心AI行中现有硅/JFET和已验证控制型号的扩量；核心AI900没有额外假设这些未验证平台必然量产。P允许组合内一条材料或控制路线部分成功，S代表一组形成规模的收费插槽，F表示本次覆盖的开发组合退出，不是宣称公司永远不能再开发其他技术。因此X概率不是单一vGaN材料的成功率。Y是**SYNA与ON联合物理AI产品的净新增收入**，超出SYNA既有连接/接口自然增长，包含新增传感、边缘处理和功率组合，排除同一设备的重复BOM。联合新产品内采用X时，收入分配给X后从Y剔除，不能一笔器件计两次。

状态为U未商用/未扩展、P部分成功、S规模成功、F退出。四状态互斥且合计100%；P并非模糊“有一些成功”，工作收入为S的25%，对应少量付费平台／设备量；U与F当年新增收入为零，仍可有研发、退出和售后成本。这里的零是状态定义，不是将整条未知技术当零价值。

**X数量级收敛（组合总额，不是全部由自制vGaN贡献）。** 基准规模成功净收入2027—2031为30／90／200／350／500；到2036为1500。若新产品替代原器件收入约30%，500净增对应约714新品发票收入，平均15美元约4,760万颗；P为其四分之一、约1,190万颗。强成功2031净增750，突破1200，需要约0.7—1.1亿颗15美元等效交付，或更多低价件。客户必须从专业电源/保护扩大至多个数据中心、工业和交通平台，不能只靠一项汽车设计。基准2031工作期望仅244，明显低于全成功500。更高规模需要vGaN分支跨过原生衬底、良率与成本，也需要GaN/Vcore分支赢得客户稳压/功率插槽；路线有替代，不能把它们的各自上限加在组合规模之上。不以厂房面积代替能力；更低规模则反映技术停留于专业小市场。到2036突破S为3600，已要求侵蚀SiC/硅的更大任务池，属于低证据远期边界。

**Y数量级收敛。** 基准S净增20／100／300／650／1000，到2036为3000。2031的1000可由约5000万台付费设备×20美元净新增内容构成，P为1250万台；设备可来自工业视觉、家庭/医疗、物流、可穿戴与机器人，不能假设5000万人形机器人。每台20美元是硬件组合净增价，已扣原有SYNA/ON内容，不是假造订阅收入。2031突破S为2200、P550，需要约1.1亿台等效设备或更高价工业设备；软件生态和认证瓶颈比总设备TAM更重要。现有设计活动支持研究，但不能证明份额；基准工作期望2031只有308。

这两个工作范围采用“已存在的器件/设备预算＋可付费单位量＋合理净内容＋资格时间”约束。它们不是官方概率或统计基础率；无充分同口径产业基础率，本研究明确采用主观转移概率并在第6节检验，不宣称已校准胜率。ReRAM存内计算、医疗SPAD/SWIR、某些SST专用方案可能带来额外价值，但缺收费权、具体架构和规模边界，保留成立门槛：付费产品、单位成本、重复客户与资本预算；不将它们另加为免费期权，也不据此宣称所有未命名路径无价值。[vGaN技术机制](https://www.onsemi.com/download/tutorial/pdf/tnd6495-d.pdf)；[Treo/ReRAM工艺进度](https://www.weebit-nano.com/news/press-releases/weebit-nano-expands-licensing-agreements-with-key-customers-three-customer-chip-designs-taped-out-to-date/)

## 4. 三种期限、估值方法、事件与反向检验

### 4.1 统一日期、滚动NTM与要求回报

主研究理念在计算建议前规定为：短期“经营证据促成周期盈利重估”，六个月要求总回报至少10%，三个月至少6%；中期“利润兑现与现金转换”，十二个月至少15%；长期“股东现金与持续竞争优势”，三年年化至少12%（累计40.49%）。这些是研究筛选门槛，不是实际预期收益或无风险收益率。高风险技术投资者宜要求更高的回报空间，例如三年年化20%约72.8%累计，同时接受更大永久损失；门槛本身不会创造正期望。

10%—12%的无杠杆折现率为名义美元模型假设，工作值11%；它补偿时间价值和系统性风险，不额外复制X/Y状态模型中的项目失败概率。没有声称该区间来自已估计CAPM beta或最新国债点值。短期倍数区间是经营持续期的研究判断，不能冒称同业实时中位数；未取得会计口径一致、具有明确日期的同业估值集合，故不用供应商静态forward PE横比制造优势。

### 4.3 三个月与六个月：何时知道，何时可能被定价

### 6.2 早期概率、规模和延期会怎样改变结论

基准三年X/Y剩余现金现值约1272/1828，共3101、约7.37美元/股；其中约67.9%来自2036以后延续价值，远期依赖高。长期主DCF已包含这些数的经济影响，以下只替换原贡献，绝不另加同一期权。

“完整S成功”是极强条件参照，假设2029后不再退化；约89.30并非现实可达概率等于100%，也未把历史早期费用返还。达到104.50所需的这一额外成功溢价比例约203%，超出0—100%概率范围，说明**在给定规模与原业务基准下，单调高局部概率无解**。真正翻转需要提高收费/可得规模、现金转换、核心利润持续期，或降低买价。若同时采用高风险20%年化门槛，要求更高，不能说放宽损失承受能力就解决预期收益。

最早有价值的证据并不一定是收入最大的一季。付费试产可排除“只有样片没有客户”；独立寿命测试可排除“性能优值无法工程化”；第二个客户复购可排除“一次性定制”；净ASP与良率可排除“卖得越多亏得越多”。这些分别改变U→P、P→S或S存续，不能用一个新闻标题统一抬升所有年份概率。

### 7.3 可复算参数与最小公式

运算内部保留完整精度，正文经营表大多取整到百万、价值到0.01美元、回报到0.1%；因此用展示整数复算可能有小额差异。倍数区间固定改变估值持续期，DCF区间固定改变折现率；不同时拼接所有有利经营参数。

- 原ON未来终端收入工作值、毛利/费用、并表SYNA、协同、CapEx、周转与特殊费均列于第3节。2031后延伸规则见第4.4节；不另外选更有利长期业务。
- 自由回购平均价2027—2031：悲观48/45/48/50/52，基准75/85/95/105/112，乐观90/110/130/145/155，突破105/140/180/210/240美元；2026H2均74.38。未来SBC按现金等效回购抵消，因此年度股份变化仅计自由回购、存量稀释、交易与净权证；并非未来员工无报酬。
- 股数模型：`N末=N始−Σ自由回购现金/成交价＋交割新增54＋历史权证净股`；估值额外权证近似`14.44×max(0,1−156.78/P)+9.30×max(0,1−211.54/P)`，与P联立迭代；本金仍按现金/负债处理。后续条款调整/实际结算价格会改变该近似。
- 现金：`C末=3864.5+Σ报告FCF−ΣSBC抵消支出−Σ自由回购−已偿本金＋取得标的现金−Aura付款−适用终止费`；债务同减偿还、同加取得或续作的标的债务。
- 估值：`目标日股权=经营价值＋现金短投−债务本金−未另计的优先索取权`；`P=股权/完全稀释股`；`总回报=P/74.38−1`；`三年年化=(P/74.38)^(1/3)−1`。
- 状态：`p_t=p_(t−1)×转移矩阵`；`E收入=Σp_k R_k`；`E现金=Σp_k[O_k×83%+D_k−K_k−W_k]`。阶段成功后未来仍有销售与退化；失败同一组合不自动恢复。

        frac = (b - a_used).days / (b - a).days
        years = ((a_used - T).days + (b - T).days) / 2 / 365.25
        ev += cf * frac / pow(1 + r, years)
    years_tv = (date(2037, 1, 1) - T).days / 365.25
    ev += fcfs[2036] * 1.02 / (r - .02) / pow(1 + r, years_tv)
    price = (ev + net_capital) / diluted_shares
    return price, price / P0 - 1, pow(price / P0, 1/3) - 1

for discount in (.12, .11, .10):
    print(discount, value(base, discount, 1071.578, 420.72363))
