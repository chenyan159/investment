## 1. 当前选择与研究口径

**当前结论：短期、中期均为中性；长期的经营修复论点值得保留，但在本文采用的12%年化回报要求下，现价尚不足以支持明确买入，仍为中性。稳健现金投资不参与；降低回报要求、能够承担较大损失的修复投资者可以得到不同选择，但这不是已确认的交易优势。** 最有依据的经营工作路径是成熟业务小幅改善、既有半导体材料继续增长、CDMO逐渐修复。最强反面解释是资本密集业务持续低回报，技术优势不足以穿透集团的更新投入和少数股东权益。前一种解释在近期交付上证据较强，在五至十年资本回报上尚未排除后一种解释。

本文不把四条代表路径当作概率全集，不统计正面格数量。表内区间是**给定经营路径的条件合理价值回报**，不是股价预测、置信区间或当前期望收益。最终选择另检查信息何时出现、市场采纳、普通偏差和投资要求。

### 4.3 投资理念与估值方式

**现金／安全边际。** 收入分散、0.75倍P/B和约3.9%毛股息率存在吸引力线索，但上半年严格FCF仅2.168、净债务升、资产资本回报偏低，清算保护不足。该理念目前不参与，缺少合理不利结果下的现金价值余量；即使愿意持有三年也不变。

**周期和经营修复。** 已投入产能利用率上升、汽车成本修复、CDMO亏损收敛可提高现金，而不要求玻璃芯成功。此论点在三个期限均有经济依据，主工具为目标日集团FCFF DCF及资本桥；前瞻营业利润/EV只检查一致性。短期要求实际信息能触发定价，中期要求现金兑现，长期要求改善能持续更新。采用DCF不是因为长期，三个期限用同一经营底稿和方法。

**材料平台与高风险技术增长。** 既有毛坯、CMP和高性能材料跨代资格有价值；要从基准到突破，需要扩大合格能力并维持较高单位回报，不能靠未取得的玻璃封装整机权利。低证据高上行允许条件估值；单一新机会独立成功参照作为完整经济实验，不能顶替主矩阵已加权收入。风险偏好较高只改变可接受损失和回报要求，不改变资格或净售价事实。

主DCF全部扣真实经济投入，未来收益亦全部进入，不额外叠加项目NPV。集团WACC主工作值7.5%、范围7.0%—8.5%，以日元现金为对象；它高于公司战略材料曾估计约5%的集团WACC，用于反映本研究采用的市场风险补偿、业务分散中的周期暴露及估计误差，不把12%投资者要求硬塞进经营折现率。7%—8.5%并非本次以可交易资本市场工具精确估计的事实，因此连同持续性替代路径一起展示，不由工作7.5%赋予结论特权。四行共用同一WACC范围，已进经营概率的特定失败不再另外打折。

2037稳定期g依次0%、1%、1.5%、2%，ROIC为7%、8%、9.5%、11%。稳定FCFF=`2036税后营业贡献×(1+g)×(1−g/ROIC)−持续调整现金`，要求持续R&D、替换投入和客户更新，不能把末期利润无成本永续。核心高增速在2031后已下降，机会按当年仍成功状态继续并加权；2037以后续存概率不自动恢复到100%。稳定阶段把成功组合视为持续更新的统计经营组合，而非同一产品无限寿命；不接受该解释时，必须使用下述弱持续性路径。

## 6. 敏感性、当前取舍与等待代价

### 6.1 最接近当前的普通不及预期

普通偏差不复制严重受损行：2027—2029每年收入比基准低35、营业利润低15，2030以后只修复一部分、残留利润差8；2027额外占用周转10，2028释放，不虚构永久损失。经济分解为东南亚净价差较弱约6—8利润、汽车/电子额外成本约3—4、CDMO延期及固定成本约3—5；不同时把同一原料涨价和价差变化扣两遍。没有无成本立即削减维护投入。它对应较轻但持久的利润误差，而非公司崩溃。

### 6.3 实际选择：门槛、可信范围与不能裁决的部分

可见证据使基准修复比“所有站点和全部材料永远不恢复”更有依据，但这不等于满足回报门槛。三年普通修复中枢的终值加已收/应收分配约9.62美元，相比7.01、12%年化要求所需约9.85美元，本身尚有缺口；无需精确给受损行概率，就可判定**普通修复这一单独论点在主要求下不够**。纳入受损分支只会使它更弱，不能以“基准最可能”绕过要求。

若参与者要求10%年化，需要三年终值约9.33；普通修复中枢略够，差约0.29，普通偏差便失效。用“普通修复得到9.62”与“受损约2.03”的两分支筛查，即使把除此之外机会先放置，约需96%权重在前者才能达到9.33；该二点实验不是整股概率预测，而是说明薄余量无力承担较大失败风险。现有约一半2027计划订单、毛坯恢复及横滨合同均不能证明如此高的整股三年好结果概率。

高风险平台论点可以得到不同损益：若三年兑现乐观中枢，含分配约14.98；受损约2.03；满足12%要求9.85的二点门槛约60%。该分支既未穷尽中间路径，也不是“玻璃芯成功概率”；它要求材料持续领先、成熟业务现金和CDMO共同表现。客户预算、跨代份额、资本回报的当前资料不足以把这样定义的联合结果概率可靠限定在60%以上或以下。因此本文对“以高风险换平台上行”给出**当前不可判定优势**，而非以没有订单否定技术价值，也不拿局部成功概率为整股下注背书。

相反选择的最强依据是：周期股在利润尚未确认时才便宜，等待可能买贵，且业务修复有订单支持。本文接受该成本，但现价的普通修复余量很薄，且弱持续性解释并未被排除，因此不作明确当前买入建议。当前不参与的原因主要是**相反经济解释会翻转价值且尚无可辨认优势**，不是断言公司注定受损；稳健现金投资另有下行余量不足的独立拒绝理由。

资本模拟的年少数股东现金分配假设为悲观8、基准12、乐观15、突破15；2026H1已发生的26.576不简单年化，期后按上述年率分配。非经营投资分配为每年3；利息按每季初总债务乘该行年现金利率再按天数计算，税后支出乘70%。股息按登记权和支付日独立处理，运营现金下限80、超过100的部分还债。这些现金/资本参数都是研究假设；本报告不假装取得最新银行授信或逐子公司汇回安排。

```text
集团收入 = Σ核心业务收入 + Σ机会 E[当年收入] + 已列抵销
集团营业利润 = Σ核心营业利润 + Σ机会 E[当年营业利润]
现金税 = 30%×max(核心营业利润,0) + Σ机会 E[30%×max(状态营业利润,0)]
FCFF = 营业利润 - 现金税 + 折旧摊销 - 经济CapEx - Δ营运资本
       - 经常调整/退出现金 + 仅2026H1其他现金桥
经济CapEx = 现金CapEx + 新使用权资产（核心每年16，2032起随规模增长）
期后CFO预测 = FCFF + 经济CapEx - 税后现金利息 + 非经营分配
报告FCF预测 = CFO预测 - 现金CapEx
资本可用流量 = FCFF - 税后现金利息 + 非经营分配
              - 实付母公司股息 - 少数股东分配
现金先保持80—100；不足增加债务，多余偿债（债务含租赁）
EV_T = Σ[目标日后季度剩余FCFF / (1+WACC)^(季度剩余中点距T年数)]
       + FCFF_2037 / (WACC-g) / (1+WACC)^(2037-01-01距T年数)
股权_T = EV_T + 80非经营资产 - 净债务_T - 情景NCI - 49.462退休福利负债
         - 目标日已除息未付的公司股息负债
股票ADR价值_T = 股权_T / (0.21272×5×153.855)
持有终值 = 股票ADR价值_T + 本次买入享有的已收现金股息 + 未收股息权
总回报 = 持有终值/7.01 - 1
几何年化展示 = (1+总回报)^(365.25/持有天数) - 1
```

年化展示是把未再投资的分配按目标日合并的等效几何回报，**不是在各股息支付日再投资的IRR**；如需现金时点IRR，应将4月/9月实付分配分别列负/正流，末日另含剩余应收权。参考现金收益未加进主矩阵股息。
