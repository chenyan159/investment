# CLS：经营情景、价值传导与分期限投资决策

## 1. 当前判断、研究时点与口径

**以312.35美元买入：短期中性／等待；中期谨慎建议投资，仅适用于愿意承担成长估值回撤的经营兑现策略；长期按稳健现金复利理念不建议投资，高风险突破理念仍应等待更明确的收费权和资本回报证据。** 公司经营向上与买价有安全边际是两件不同的事。本研究没有否定AI基础设施的巨大空间，也没有把近期股价回落当作经营见底的证明。

最重要的预期差有三项。第一，市场免费报价显示的低前瞻PE没有逐字段年度和增发后股数说明，不能直接作“便宜”的依据；本模型按融资后股本、现金和目标日NTM重算。第二，收入的快速扩张确有证据，但材料转售、供应商信用和增长投入显著影响其变成股东现金的速度。第三，远期新机架、CPO和开放scale-up可能创造额外价值，不过CLS能够收取的是设计、系统和交付收入，不能拥有整个GPU、TPU、云服务和网络软件的利润池。

基准路径下，6个月合理价值约**306—377美元**；12个月约**362—445美元**；36个月现金流估值约**289—356美元**。前两者采用扣持续报酬后的前瞻经营盈利估值，后者采用扣完全部投入的剩余现金流。它们的分歧不是三年后的公司倒退：基准收入由2027年约320亿美元增至2029年约484亿美元；分歧来自一年期投资者可以接受的成长估值，与长期现金投资者对再投资、竞争和剩余增长的不同定价。第4节保留完整裁决及同方法交叉结果，不把高估值方法平均进现金价值。

## 2. 公司全貌、经营质量与上游证据

**收入质量。** 定制且无替代用途、可获迄今履约补偿的产品可能按生产进度确认，其他商品看控制权转移；生产、开票、验收、投运与收款未必同日。Q2应收内合同资产约325.4百万，不是自动等于坏账。订单及客户预测可延期或取消，长期合同可能有降价条款；未取得全面take-or-pay、不可撤销backlog和厂房利润赔付，故管理层能见度不能等于法律保底。

**利润质量。** Q2 GAAP营业利润458.3百万包括104.1百万TRS公允价值收益。勾稽为：458.3＋SBC19.3−TRS104.1＋指定摊销9.9＋重组2.9＝调整后386.3。Q2调整后毛利率11.5%，低于上年11.7%，而调整后营业利润率从7.4%升到8.2%；当前更支持规模／费用摊薄，不能用“稀缺涨价”解释全部利润增长。模型不延续TRS收益，也不把SBC永远排除。

**现金质量。** H1公司FCF285.0百万扣去当期奖励归属代扣税支付326.3百万为−41.3百万，这只是跨期奖励结算后的当期现金观察，既不是另一个GAAP FCF，也不能把326.3百万机械年化为未来常年企业所得税。同期TRS没有现金结算收入；向员工交付以前取得的库存股不能再扣一次当期回购现金。未来模型使用经常性报酬成本＋存量奖励准备，分别处理。

### 2.3 周转、资产负债、治理与永久损失风险

6月末现金0.5357 bn；应收3.3382、存货3.4017、应付3.8197 bn；负债与融资租赁账面合计0.8104 bn，养老金等0.0902 bn。存货较年底增加1.2137 bn，其中约79.5%是原料。Q2库存67天与一年前相同；现金周期从66降至47天，关键是应付由54延至73天，不能称为库存出清。客户存货押金0.4814 bn仅约占存货14.2%，但这也不是未覆盖损失率，因为还可能有合同赔付。

循环额度6月末可用1.7396 bn；450百万应收出售安排及客户供应商融资计划并非银行必须接单的承诺额度。期间出售应收是季内流动性工具，期末未结余额为零，不能把H1出售总量0.879 bn再加为期末债务或永久现金来源。多数资产及子公司担保受信贷担保安排约束，违约可能使到期提前；目前披露合规。融资后债务不是主导风险，**营运资金抽走、客户项目损失与资本回报不达标更重要**。

经营租赁的租金与更新已经进入成本／现金路径，所以不在企业价值桥再扣一次经营租赁本金；融资租赁列入0.8104 bn。账面债务与合同本金有小差别，不影响本模型等级；估值桥四舍五入误差应低于每股1美元。未发现需单列的重要少数股权、优先股、ADR或在外转债；本模型未臆造它们。相反，尚未识别的新并购／额外权益融资保持为压力分支。

管理层多次上调指引并实际完成交付，执行证据较强；2026年大额募资也意味着不能沿用过去轻资本的分母。董事长与CEO由Rob Mionis兼任，设首席独立董事；CCS在7月由资深内部人士接任，需观察扩张期交接。前三大客户Q2合计63%、前十83%，匿名客户不得猜成具体公司。ATS分散不能消除共同AI资本预算风险。重大风险是全球供应链、关税转嫁时差、客户转厂、品质赔付与出口限制；已知小额税争议不足以压过主营增长／现金风险，模型不把假设诉讼结果写成事实。

### 4.3 主方法与理念分歧

**6个月与12个月：EV／经济NOPAT。** 先扣经常性股权报酬，用无杠杆税后经营盈利估经营资产，再加净资本桥，避免净现金企业用含利息EPS后又加现金收益。基准倍数16—20；悲观6个月13—17、12个月12—16；乐观均19—23；突破6个月21—26、12个月21—27。参数为研究假设，不是券商目标价或可比中位数。基准工作倍数18对应5.6%的经济NOPAT收益率，需后续较快盈利增长弥补低初始收益及再投资；16对应6.25%并减少增长溢价，20对应5%且更依赖持续交付。工作值由这项收益要求选择，不是为让回报跨过门槛而取区间某个分位。高增长且已有盈利的制造／设计企业可以承受高于低增长EMS的倍数；同时远低于软件体系倍数，保留回报质量折价。

可比事实仅作约束：[Jabil 2026Q3一手公告](https://investors.jabil.com/news/news-details/2026/Jabil-Posts-Third-Quarter-Results/default.aspx)给出FY2026核心EPS12.70、利润率5.8%、调整FCF至少1.4 bn；其9月4价310.57对应约24.45倍这一**截至8月31日财年**指引。CLS按融资加权后的FY2026粗算约28.7倍，较高增长也已索取溢价。Jabil本年核心利润和公司式FCF约2.03／1.4 bn，转换明显不同；其“core”也排除SBC，不能直接当CLS现金等价基准。

不把可比方法和DCF简单平均。对一年期成长投资者，估值依赖退出时市场仍愿意为高速经营期支付16—20倍经济NOPAT；对长期现金投资者，既定现金与竞争路径并不支持永久同倍数。**在同一经营路径下，基准2027-09-07的DCF只有约238—301美元，显著低于主盈利法362—445美元。** 这是中期建议只能“谨慎”、且现金理念拒绝买入的决定性原因；盈利法不是现金法被“高端区间”纠正。若要求所有主格均为严格DCF现值，应采用交叉列而非盈利法格，三个期限基准均没有清晰买入优势。

同样，三年时如果市场仍给基准16—21倍NTM经济NOPAT，会得约507—651美元；这是一种**可能交易估值及理念分歧**，没有取代主矩阵的289—356美元现金价值。要使更高交易估值可持续，需更久的高增长、更高现金转换或更低风险补偿；缺这些证据时不可称必达合理现金价值。

### 4.4 每个期限为何可能发生价值确认

**短期3个月。** 基准同口径盈利估值约277—341美元，买价回报约−11.2%～+9.1%，低于10%门槛。Q3财报可以证明5.4 bn交付，但未必证明2027各项目和全年现金；9月初反弹也已经支付部分信心。不建议仅因离高点三成就追求修复。3个月转为积极，需要早于常规FY2026披露获得可核验的量产／复购、融资后2027盈利口径，以及现金没有被库存和应收吞掉；只是新闻发布不够。

**短期6个月。** 相比3个月，多了FY2026、融资后股本与2027指引窗口。基准NTM滚动从约28.25 bn上升到34.26 bn，经济NOPAT从1.834至2.238 bn；即使倍数不扩张，利润滚动也提供价值，但主格下沿仍略低于买价、工作值约342美元仅约9%回报，15%门槛未充分满足。等待代价是公司若提前确认乐观项目，可能直接跨入约482美元以上的条件价值区间。

**中期12个月。** Q1—Q2 2027会揭示1.6T、计算、项目验收和现金；主NTM约39.47 bn、经济NOPAT2.661 bn。基准按18倍工作值约403美元、回报约29%，增长型制造商退出逻辑可以成立。关键不是一年后盈利数字单独上升，而是市场仍信任其转现金和续代能力。若届时投资者改用全投入现金估值、2027增长低于路径或供应商收回信用，盈利法优势会消失。现金安全边际理念在同期限仍为“不建议”；不能把它说成适合所有投资者。

**长期36个月。** 基准期末NTM收入约50.98 bn与经济NOPAT3.664 bn，经营规模显著增长；但持续投入后的DCF工作值约319美元，年化约0.7%。要实现15%年化，三年后须至少约475美元；这更接近乐观现金路径，要求较高份额、利润和资金效率延续。技术领先若只表现为代际制造资格，客户可以继续二供和议价；若演变为跨客户的可靠性设计、测试平台及持续收费，才有突破空间。三年后剩余七年以上现金已经计入，因此长期不建议不是把未来只截成三年。

### 6.3 整行情景概率与高风险选择的反向边界

没有为四行分配精确总体概率。它们跨客户预算、份额、合格能力和资本条件，不应从三项局部项目概率或正面格数量制造整股胜率。为检验高风险理念是否可能改变结论，使用**门槛事件树**：三年DCF的11%工作值约悲观91、基准319、乐观547、突破851美元。

如果只在基准319与突破851之间做二分，15%年化要求475美元，所需突破概率约(475−319)/(851−319)=29.3%；20%年化要求约540美元，所需约41.5%。这都是没有计入受损路径的有利门槛；若另设20%受损91美元，余下基准与突破分配，要达到475，突破无条件概率需约37.9%，达到540约50.0%。这些20%和概率结果**是检验假设，不是本研究判断的实际概率**。

只在基准与乐观间切换，要达到475，乐观概率约68.4%。目前没有证据把跨业务、跨客户、跨代际的强成功概率可靠推至上述门槛。因此保留突破机会，仍不给当前长期高风险策略直接正面建议；最早能提高可信度的证据是2027H1多个客户复购、CLS净可收费内容和付款条件。若只出现工程样机，主要排除“技术不可行”，不能排除“量不大、付费少、客户预算不持续”。

### 6.4 最强反证与结论覆盖范围

对本报告偏谨慎观点最强的反证，是CLS确实以比模型更少的增量资本取得跨客户平台复用，已有计算与1.6T的规模成长持续更久，2027之后FCFE迅速跟上经济利润，而不仅是应付天数延长。公司多次超指引的历史、实际产品和募资后资源，为这种反证提供了可认真研究的基础；不能因为当下现金低便把成长项目净现值认定为零。

对中期买入逻辑最强的反证则是“行业仍繁荣、CLS收入仍增长，但公司捕获和股东收益下降”：客供材料与代际替代降低可开票内容，二供侵蚀设计利润，新增库存与测试设施先占现金，客户支付或供应商信用同时收紧。若经济EBIT率少1个百分点，中期主要回报门槛已经被击穿；不需要AI总需求崩溃。

本报告覆盖可识别的制造、设计、系统交付及相关服务价值。未来独立软件、重大并购、全新专利收费或战略收购溢价没有可信金额时，只保留成立门槛，未把它们一律认定为不存在，也未加一笔无成本“其他期权”。新的重要合同应重做经营与资本路径，而不只是给当前估值多添一个上沿。

单位：经营与股权价值为bn USD；股数为百万；每股=股权价值×1000/股数。

R_t,s = legacy + newgen_gross - 0.4×E[C收入] + compute + other + ATS
        + E[R收入] + E[H收入] + E[C收入]
核心调整EBIT = Σ(净收入分支×对应经营利润率)
调整EBIT = 核心调整EBIT + Σ机会状态经营贡献 - 悲观额外重组
持续报酬B = 0.006×集团收入
经济EBIT = 调整EBIT - B
NOPAT = 经济EBIT×0.80
经济净利润 = NOPAT - 年利息0.055×0.80
CFO代理 = 经济净利润 + 折旧 + B - Δ经营周转
公司式FCF代理 = CFO代理 - 全部CapEx
FCFE = 公司式FCF代理 - B
FCFF = FCFE + 0.055×0.80

现金_d = 6/30现金0.5357 + 8月净增发3.39 + 7/1至d的FCFE
股权_d = 经营价值_d + 现金_d - 债务0.8104 - 养老金0.0902 - 奖励准备0.150
FD股数 = 126.111117 + 1.188883 = 127.300000
期间股息及主动回购均为0；不重复加现金或扣租金已覆盖的经营租赁。

盈利法经营价值_d = d后NTM NOPAT × 表4.3对应倍数
DCF经营价值_d = Σ[d后每季剩余FCFF/(1+WACC)^τ] + TV2036/(1+WACC)^T
每个未来季度现金放在该剩余季度的中点；τ按实际天数/365.25。
TV2036 = NOPAT2036×1.025×(1-0.025/ROIC)/(WACC-0.025)

2026Q3／Q4的CapEx、周转与利润率在季度表及3.5可复算；2026H1的公司FCF为0.285 bn。2027所有年度数字已列在3.4／3.5。未来奖励真实结算与GAAP税盾可能跨期，0.6%成本及0.15 bn准备是经济估值代理；没有把它们标成可精确预测的法定报表。

状态内毛利率已包含相应生产折旧，FCFF再加回折旧并扣实际资本开支。F为该路径停止新增销售，并不意味着所有存量应收不能收回；基础状态表假设可收回原料／应收的主体价值，0.025 bn为额外净退出成本工作额，合同若不支持追偿必须改用3.6的坏料／信用联合分支。以2029基准R的周转余额约0.603 bn为例，若另损失30%，需少回款约0.181 bn，单纯资本损失每股约1.42美元；若伴随原有计算项目及工厂一起失效，影响会远大于此。未把F退出直接解释为普通股破产。

机会转移的简短复算方法：对每个机会，保存上一年状态概率p和状态收入r；当年p'=p×T；各状态收入为[0,部分比例×S,S,0]。每条i→k路径概率为p_i×T_ik；成长CapEx用max(r新_k−r旧_i,0)乘资本系数，而不是简单对期望收入差额计算成功资本。新增失败费用只对i≠F→F计算。周转余额是当年收入×周转率，集团无融资断点时变化的期望可线性相减；断点联合分支见3.6。

到2032—2036，收入从2031数逐年乘1+g_阶段；经济EBIT率从2031率线性移到2036的目标率。NOPAT×阶段增长/新增ROIC是成长再投资；Δ周转=7%×增量收入，CapEx=折旧＋max(0,上述再投资−Δ周转)。因此未来增长和资本一致，且未把多年的收入相加当价值。2031后的机会不再另设一轮首次成功概率，存续系列进入集团续代能力；长期失败率和竞争已在前述状态与利润收敛中，额外独立机会须另建模型。
