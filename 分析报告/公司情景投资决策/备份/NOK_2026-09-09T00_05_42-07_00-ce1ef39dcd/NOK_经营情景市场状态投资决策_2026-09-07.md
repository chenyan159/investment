标准硬件一般按控制权转移确认，复杂系统可能等待验收；维护按期间确认；软件许可与订阅不等同；持续提供IP的授权和无后续义务的一次性许可确认也不同。没有公开证据支持把28亿AI/云订单视为take-or-pay、不可取消收入或已收现金。以管理层预计一半在随后十二个月转收入为基准线索，再扣供给、验收及收款风险，而非将订单乘四年化。

### 3.5 早期机会：十年逐年状态、净增收入与现金

**最重要的两项**为ICE-D机房内光器件外销，以及AI-RAN净增软件/平台收费。既有相干系统升级和普通IP交付在成熟表内，不能同时进本节。ICE-D计对外器件/PIC净收入，不计内部自用；AI-RAN计相对旧无线合同的净增收费，旧硬件/软件被替换后的净损益已在其低于毛利率的贡献率中扣除。完整成功金额只作条件参照，不加到期望值上。

ICE-D的机制是InP集成、驱动和光引擎使Nokia进入新的外部BOM；替代为硅光、其他InP供应商、CPO与客户自研。真实验证需要第三方外销设计定点、可比功耗/可靠性、合格出货及净售价。AI-RAN机制是无线软件实时性及升级算法形成持续净收费；GPU、云平台与运营商自研可拿走大部分价值，忙时收益与额外电力/冷却必须相抵。T-Mobile已有真实频谱演示，但两家设备商都在参与；它没有证明大规模付费或独立现场TCO。[T-Mobile材料](https://www.t-mobile.com/news/network/why-physical-ai-begins-with-intelligent-networks)、[Nokia 2026-07-15平台公告](https://www.nokia.com/newsroom/nokia-defines-the-next-era-of-radio-with-the-industrys-first-ai-native-ran-platform/)

“尚未商业化U、有限成功P、规模成功S、失败退出F”是当年互斥状态，F吸收且不能无条件复活。2026末以[1,0,0,0]为起点：这不是说技术不存在，而是尚没有本模型所定义的**可重复净增商业收入**。每年按转移矩阵更新，表中是当年仍在某状态的概率，不是首次成功概率，也不是累计成功率；首年成功者继续转移、复购或退出。首次进入S的概率可由上一年U/P→S计算，不能把累计成功率逐年再连乘。

**短中期方法A：成熟经营B×前瞻倍数＋独立早期期权净现金价值。** B定义见3.4，取目标日之后NTM成熟营业利润、加回未来SBC、扣0.150经常重组。悲观倍数10—13；基准短期14—17、中期14—18，工作点16；乐观16—20/16—21；突破18—23/18—24。倍数反映正常化利润可维持的年数、资本回收及盈利增长持续期，并包含此后约0.5%年度奖励稀释的影响。10—13倍不适合永远下滑资产，14—18倍需要订单/利润持续，18倍以上需要更强增长与资本回报；不是外部一致估值，也没有把股价下跌自动当倍数回归理由。

这些短中期值是本路径下的**盈利持续性合理价值判断**，不保证目标日市场采纳。若现金法与倍数法冲突，以期限相应证据保留分歧，不平均。基准短期工作点约11.17，中期约11.74；低端和合理不利敏感性都不稳健，因此没有“强烈建议”。若只是资金把NOK重新叫成AI纯硬件、经营未变，不能提高合理价值。

**长期方法D：目标日之后逐期现金折现。** 从2029-09-08起，只把其后成熟业务现金折到目标日；已经产生的现金只在净现金桥一次体现。2029剩余现金取本模型余下年度份额，2030取3.4成熟FCF扣租赁；2031—2036成熟现金年增速悲观/基准/乐观/突破为0%/4%/6%/8%，分别要求存量下降止住/温和扩张/强客户复购/平台捕获。增长不由当前市值倒推。

这段后期现金增长不是免费Capex：成熟研发、Capex、周转和正常重组已经在2030现金基线内，2031以后这些投入与经营规模同步增长，业务收入/利润也按同一增速延伸，维持现有资本强度。终值名义增长0%/2%/2.5%/3%，主折现9%—11%；终值增长需要成熟增量ROIC约10%/14%/17%/20%时，至少分别再投0%/14.3%/14.7%/15%的税后经营收益，后期现金基线保留的资本/研发强度足以覆盖；若ROIC达不到，应降低终值。低端不称资产底价。

**持续稀释不能在退出日停止。** 目标日后每期现金先乘`目标日股数/该现金期预测股数`，再折现；股数继续按每年0.027增长。终值分母使用`r−g＋δ`，δ为2037年度新增股数/当时股数的近似比例。这样既保留报告现金里SBC加回，也扣了以后持有人权益下降，未把“目标日前稀释”误当一切稀释。终值r、g是按年复利的工作假设，范围不是概率置信区间。

早期ICE-D及RAN采用第3.5节**状态内现金→概率加权→目标日后剩余DCF**，统一10%系统性/时间折现率；未对同一失败风险再乘成功率。每年现金年中折现，截取目标日以后部分；2036后按存续净现金8倍保留残余，近似反映更新、2%—3%自然衰退/退出及时间成本，而不是把2036收入永久年金化。残余还以`8/(1+8δ)`处理其后稀释，且全段有目标日/未来股数权益比例。新机会现金与成熟表已隔离，因此不在成熟倍数中再付一遍。

当前视角对目标日的不同信息结果使用同一状态树的条件期望，满足全期望关系；没有假定日历走到2029便自动把成功概率提到100%。真正新订单、客户续费、合格良率证据出现时才更新转移概率。若能形成某成功状态，完整条件成功现金可单列，不能替换主格期望。

这不是将不同模型任意平均。**现金法与倍数法的分歧来自投资者愿意为每单位利润支付多少持续期，以及资本、重组和奖励稀释会吞掉多少利润**。基准2030成熟估值现金约2.476，远低于约4.00前瞻B；B×16给成熟经营约64，而10%现金DCF仅约32.35。要求将新增能力最终转成现金的长期理念采用后者；认为更新投入将在2030后大幅释放、或软件经常收费使资本效率跃升的投资者可以采用较高方法A，但必须证明释放机制，不能仅因方法A上沿较高就提高主评级。

基准长期成熟终值占成熟经营DCF约53%—60%，早期剩余价值也有大量来自2036后。当前净现金每股约0.56美元、扣租赁债的静态净现金约0.36美元，保护不了10.03买价；商誉和递延税不是低价可卖资产。即使完全不计早期价值，不能据此宣布远期机会无价值，主结论只是：当前可辩护现金范围与价格要求仍有距离。

反向估值提供多组组合，不声称知道真实市场共识：

1. 一年要求15%回报时，需退出价约11.372美元（已扣约0.163分红）。在16倍、其他桥不变下，所需B约3.189，本模型3.304，仅有约3.6%利润余量。若倍数仅14，需要B约3.645；若B停留3.00，则需约17.01倍。这三组均可支持相同价格，不等于市场唯一押注。
2. 三年要求12%年化，需终点加期间股息约14.091美元。基准10%DCF终点加分红仅8.559。维持同一远期增长与折现参数，成熟现金需约为基准的1.87倍，2030成熟现金由2.476升至约4.62；以约24亿级欧元十亿成熟收入底盘计，这要求明显更高利润或更少再投资。仅减少0.15年度重组不足以填补。
3. 只在“基准”与“突破”两种完整联合路径之间作决策边界，而不指定实际概率：达到三年12%要求，需要突破权重约57.7%；若技术投资者要求20%年化，约91.5%。加入悲观损伤会进一步提高门槛。现有材料无法证明如此高的整股联合突破概率。门槛不是实际胜率，不把局部ICE-D/RAN概率替代它。
4. 对当前市场经营价值约46.88，用可持续现金收益率解释：4%/5%/6%分别要求每年约1.88/2.34/2.81现金；但永久维持与继续增长还须分配再投资，不能只看到未来某一高峰年就认定已满足。短期倍数可因确认而抬升，长期现金若不能保留，价值仍会回落。

**完整成功参照。** 在2029后两机会都持续处于S且不退出的极强条件下，基准规模的早期剩余价值约11.80，替代主表2.95后每股多约1.75；突破规模完全成功的早期剩余约27.08，替代19.11后每股多约1.58。这些算例已经扣状态内研发、Capex及周转，但人为锁定未来成功，不能与期望值相加、不能称当前可信上行。即使两个早期项目在基准规模下完整成功，也不自动解决成熟现金释放不够的问题。

## 6. 当前路径、价格边界、概率敏感性与最强反证

### 6.1 当前最接近基准，但投资价值不是经营改善的同义词

不对四种整股经营情景编造精确概率。当前最支持的是“既有光/IP兑现较强、无线普通、现金改善尚待证实、早期机会非确定”的基准行；早期逐年状态已有行内概率，不能把乐观/突破正面格数量当胜率。基准2026H2现金略低于指引下限，也没有为制造好看的结论强行提高回款。

短期的主要差异在**信息是否来得及被确认**：2026-12-07可能只知道Q3结果、部分工厂/试点，尚无Q4软件利润与全年回款。没有可靠数据给3个月独立窄价值范围，故仍为中性/等待，不拿6个月值假冒3个月目标价。若Q3即给出明显上修的全年利润与有条款的交付/收款证明，可提前提高判断；若仅重复平台新闻，没有转变。到2027-03-07全年事实和2027展望可使分歧收敛，但“可确认”仍不等于股价必涨。

一年期谨慎正面来自可验证的光/IP增长、许可与软件组合、重组付款下降；它是一个约19%工作回报、误差只需几个百分点就消失的机会。若基准能实现但市场只付14倍，回报仅约5.5%；因此不能把12个月现金增长等同确定获利。即使在该期限参与，也应以2027H1现金及届时前瞻经营重新决策。

三年期现金理念拒绝的核心是买价要求高，不是否认技术。高风险理念可以预先承担技术损失、等待巨大回报，但现有整股概率证据不足以满足4.4反求门槛；这类投资者的当前判断仍为等待更多收费证据，而非自动跟随突破格买入。

### 6.2 经营不变时的价格边界

价格不是精确买点。表内“价值低端对应要求回报”=（目标价值低端+股息）÷期限要求倍数；工作边界短中期取明确16倍、长期取10%折现，而非区间60%/75%位置。低端并不覆盖所有悲观情景。

长期稳健边界与短中期修复边界不同，源于价值理念与退出证据不同，不是把同一路径收入改写。采用长期16倍方法A的人可得到明显更高的进入价，但需证明资本/研发最终释放；本研究不因这个高端存在就提高长期实际评级。当前价格距离基准现金边界很大，也意味着等待可能错过超出基准的真实平台跃迁。

### 6.4 最强反证及下一次更新顺序

最强的正面反证是：Nokia在不同比例增加总研发、Capex、售后与稀释的情况下，把光/IP、无线软件和标准许可变成更高的可持续现金；2027—2028现金转换改善并非应收出售或压库存的一次性行为；2029后的核心现金能接近反求的约4.6而不是2.5数量级。这会使长期DCF及当前不建议真正翻转。

最强的负面反证是：AI/云长单只是供给恐慌下的提前排队，已投入的光厂在2027遭延期或价格下降；授权追补掩盖Radio低回报，重组没有真实终结，新增软件又被GPU/云平台收费挤压。这样收入仍可增长而普通股现金回报下降，不能用“行业大方向正确”抵消。

最早有用证据依次是：2026Q3实际收入/库存/合同资产与现金桥（排除订单完全虚增的部分解释）；2026末厂房良率与试点现场TCO（排除仅有名义产能/实验室收益）；2027全年展望及H1回款（确认或否定一年B/现金）；具名外部ICE-D付费出货、AI-RAN净订阅/续费（改变P→S及持续S概率）。新的客户Logo、MW目标或未披露金额的合作不能独立解除这些限制。

### 7.3 复算约定、样例与覆盖限制

计算以未舍入参数进行，完整复算参数和算法列在本报告中，显示数值四舍五入；不提供第二份模型或正式报告。用3.3收入/利润率、3.4现金参数及3.5转移/状态参数即可重算所有现金和价值。简化伪代码：

```text
p_2026 = [1,0,0,0]
p_t = p_(t-1) × T_s
new_fail_t = p_t[F] - p_(t-1)[F]
ERevenue_t = p_t[P]*R_t[P] + p_t[S]*R_t[S]
EOp_t = sum(p_t[k]*(R_t[k]*contribution_margin[k]-fixed_cost_t[k]))
        - new_fail_t*exit_cost
ECF_t = EOp_t*(1-0.26) + EDep_t - ECapex_t - working_capital_rate*ΔERevenue_t
GroupRevenue = MatureRevenue + ERevenue_ICE + ERevenue_RAN
GroupOp = MatureOp + EOp_ICE + EOp_RAN
GroupFCF = MatureFCF + ECF_ICE + ECF_RAN
NetCash_target = 2.776 + Σafter_2026H1(FCF - lease_principal - cash_dividends)
Shares_target = 5.80 + 0.027*ACT365.25(2026-09-08,target+1day)
Equity_target_A = B_NTM * multiple + EarlyPV_target + NetCash_target + 0.400
Equity_target_D = MatureCFPV_target + EarlyPV_target + NetCash_target + 0.400
USD_per_ADS = EUR_equity*1.1622 / Shares_target
TotalReturn = (USD_per_ADS + USD_cash_dividends - 10.03) / 10.03
```

季度时间函数使用目标日下一天的零时为现金/NTM边界；这等于包含目标日当日。经营现金按季度日数切割，早期年度DCF按年度剩余日数与年中折现近似，微小跨日舍入不应影响建议。2036后股数稀释持续，终值与显性段分开；纯行总概率没有输入。

补充精确现金参数：令j=自然年−2026，2026—2030成熟常规折旧为0.550+0.015j、SBC为0.200+0.010j、租赁本金为0.210+0.005j。年度现金股息在2026按5.60×0.14近似；2027起按当年每股股息×(5.650+0.027j)估计，每季四分之一用于资本桥。这是领取分红的普通股数量代理，和包含尚未归属奖励的目标日完全稀释股数不同；不把所有潜在股数当已领现金股息。与8月最新流通股微小差异作为舍入/未来授予误差处理，不影响矩阵方向。2026Q3、Q4 FCF分别分配全年FCF加0.104后的20%/80%，Capex分配全年Capex减0.283后的35%/65%；由此与H1共同事实完整闭合。
