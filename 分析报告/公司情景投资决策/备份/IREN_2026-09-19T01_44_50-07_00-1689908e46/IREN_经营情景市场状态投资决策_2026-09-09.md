# IREN：经营情景、价值传导与分期限投资决策

研究日：2026-09-09。信息截止：**2026-09-09 13:32:32 PDT（纽约16:32:32）**。买入基准 **45.37美元／普通股**，采用当日正式金融快照的常规交易时段收盘字段；Yahoo历史接口同值，Stock Analysis与ChartExchange的逐日表为45.36美元。1美分差约0.022%，不影响任何标签，全文固定45.37，不混用盘后价。

**当前判断：短期不建议以确定重估为理由追入；一年期不建议作为经营兑现型投资；三年期不建议作为稳健复利投资，高风险突破投资暂不能辨认足够稳健的优势。**最后一种结论不是远期价值为零：持续高价、可复用设施和资本效率共同改善，条件上行很大；难点是现价需要其中多项共同成立，当前证据没有把必要持续期和融资后的股东回报锁定。

IREN已有可核验的AI客户交付，不能继续按“只有矿场与土地”解释。另一方面，8月27日披露的FY2027资本计划是250亿—300亿美元；本研究中较普通的业务兑现路径，即使收入迅速增长，仍会产生大量新增债务和股权融资。这使“AI需求正确”与“今天买普通股正确”成为两个问题。

本报告采用独立构建的十年经营、机会状态与资本模型。四行不是概率全集；矩阵是给定路径的条件合理价值回报，**不是未来交易价预测**。区间、融资价格、成本和概率均为研究假设，不是统计置信区间。金额以十亿美元（bn）为主，1bn＝10亿美元；股数以十亿股为主，另注明百万股（m股）。

## 1. 当前选择、时点与研究限制

### 1.1 三个期限分别为什么这样选择

### 2.3 四项上游输入怎样进入模型

1. NeoCloud行业报告的2027独立算力池45—75bn、2028为75—125bn是预测，不是事实。本研究基准FY2028核心云7.5bn并非用其乘份额得到，而是合同加可计费容量。换自然年CY2027约5—6bn，意味着可能占该池约7%—13%；这是对增长速度的约束，不是已取得份额。2028以后进入竞争正常化，不能把行业预算都分给IREN。
2. 电力接入报告说明申请、送电、可持续负荷和客户接受有不同阶段。9月8日新公告削弱“Sweetwater完全无法推进”的解释；仍保留审批和工程风险。**2GW为gross管线，公告当前在建首批为300MW gross、目标2027 Q4交付**，没有给它新增2GW即期收入。[S4]
3. 液冷报告支持集成测试、漏液控制、水质、维护与平台兼容是重要门槛；不支持IREN拥有独占冷却技术。首批验收提高复制概率，但不能证明数万GPU多租户软件和长期SLA全部成熟。
4. MEP报告和Applied Digital原始项目披露支持设施约每MW IT一千万美元量级；IREN可复用场地，故设施成本工作值9—10m/MW，范围8—13m。GPU与配套取30—36m/MW，来自微软5.8bn／200MW及其他采购的量级；不同配置不能直接视为同一GPU价格指数。

### 2.5 公司优势、竞争、治理与非财务损失

CoreWeave 2026 Q2收入2.575bn、active power 1.5GW、调整EBITDA率59%，净利息0.640bn；Nebius同期AI云收入约0.575bn、ARR 3bn、AI云调整EBITDA率50%。这证明真实市场和强竞争同时存在，也说明规模和高EBITDA不能免除利息与设备更新。[S6][S7] 不采用它们的评级、目标价或不同口径收入倍数。

IREN的可保留优势是园区开发、合格供电、交付组织、客户资格与跨代设施复用；GPU、CUDA和大量开源软件并非其独占。微软既是客户也是潜在自建替代者；ASIC、效率改进和客户内化会压制裸金属收费，异构管理也可能扩大IREN的服务范围，两种机制应同时保留。

两位创始人的B类投票安排增强控制影响，但2026-08-14合计投票权低于50%，不写成现有绝对控制。7月新授18.199m RSU分四年归属、随后锁定，主要是留任而非每股ROIC门槛。6月末14.990m服务条件RSU及5.726m绩效RSU，不能与当年加权稀释证券混同。[S1 Note 25]

安全事故、跨境设备／数据合规、得州电网与用水审批会先影响交付与可计费量，再影响扣款、抵押和融资。加拿大GST争议约27.6m未确认为很可能损失，规模不主导本估值；以公司全部税争议未知金额任意扣值也不合理。重大服务终止和再融资同时发生才是普通股尾部风险；没有证据称该尾部已经发生。

### 3.3 早期机会：十年状态路径和概率

### 4.3 估值方法与股份权益口径

三个期限共用“经营与资本回收”主方法：在每个目标日折现其后剩余未杠杆现金，加入目标日现金，扣本金债务、融资租赁与优先索取权，再解稀释后每股价值。每个联合分支独立算完后加权。短期主要理念为里程碑导致的风险解除；中期为经营兑现；长期为可持续更新的高风险成长。工具一致，不因期限切换工具制造结论。

显式期为FY2027—FY2036。年内剩余现金按相应剩余期间和中点折现；季度收入用于近期NTM，目标日现金和资本按季度付款权重插值，插值误差另披露。目标日前现金进入资本桥一次，目标日后流量进入EV一次。已扣完整成长支出，不再给土地、5GW、GPU或“AI期权”加第二份价值。

各行工作WACC为14%／11.5%／10.5%／10.5%，不是因投资者要求高就把业务改差，而是现金没有覆盖的系统性风险、资本成本和经营组合不同。现金机会成本采用4%研究假设、3%—5%邻域，**不是本次核验的实时国债报价**。条件估值包络用GPU经济寿命±0.5年、WACC上调1.5／下调1个百分点同时重算经营、更新资本和融资；不再追加同一个执行失败折价。

终值从FY2036经营接续：四行长期增长0%／2.5%／3%／3%，成熟新增ROIC 10%／15%／19%／22%；终值NOPAT扣维持更新后的经济折旧，成长再投资率g/ROIC。这代表可持续跨代平台解释，不能证明它必然成立。限期回收解释及终值取消另作反证，不把两种解释平均。公式：

`TV_2036 = NOPAT_2036 × (1+g) × (1-g/ROIC) ÷ (WACC-g)`。

### 4.4 现价反向检验：真正要买到什么

当前17.88bn基础市值不是只买2026年4bn ARR，而是为未投产批次、后续设备、再融资和可持续更新支付价格。基准早期混合价低有合同组合依据；乐观高价也有新约依据。决定性分歧是高价格能否覆盖整个新增池并维持到更新后，而不是最新一次订单是否存在。

最终选择由同一证据链导出：短期没有识别到足够定价优势；一年普通兑现的股东经济价值不足；三年稳健复利缺保护。高风险平台论点已保留并估值，未决的是高收费和设施复用能否共同持续到足够规模，不能用一个工作点代替对该分歧的裁决。

### 7.2 计算结构和核验范围

核心公式：

```text
集团收入 = 核心云 + G状态收入 + 0.14存量软件 + S新增软件 + 矿业退出收入
毛利代理 = 云收入×(1−直接成本率) + 软件×78% + 矿业×60%
EBIT代理 = 毛利代理 − 现金OpEx − 经济D&A − 股份报酬
报告CFO = EBITDA − 现金利息 − 现金税 − Δ非现金营运资本 + Δ预收
报告FCF = 报告CFO − 全部资本开支
估值FCF = EBITDA − 未杠杆税 − 全部资本 − Δ非现金营运资本 + Δ预收 − 未来股份报酬现金等价
期末现金 = 期初现金 + 报告FCF + 新债 − 还本 + 新权益
期末债 = 期初债 + 新债 − 还本
期末股数 = 期初经济股数 + 新权益/发行价 + 持续授予
目标日EV = 目标日后剩余显式FCF现值 + 更新后终值现值
股权 = max(0, EV + 现金 − 债务及租赁)
净转股增股 = Σ[(本金/转换价)×未被capped-call抵销的价内溢价/每股价]
最终每股 = 逐分支先解(股权/净摊薄股数)，再按行内联合权重加权
累计回报 = 每股目标价值/45.37 − 1
三年年化 = (每股目标价值/45.37)^(1/3) − 1
```
