## 1. 当前选择、预期差与研究口径

**在274.80美元买入的当前判断：短期不建议、中期不建议、长期按稳健复利标准不建议；高风险平台突破有条件上行，但当前尚未识别出足以补偿失败代价的优势。** 主要原因是可见增长与长期股东现金价值之间仍有较大距离，而不是否认公司成长。普通兑现路径的收入从未来一年约18.2亿美元增至第三年25.8亿美元，仍不足以支撑现价所要求的持续利润。

### 2.3 决定性争议：哪些证据改变了判断

**争议A：终端扩张，还是重复下单？** Cignal AI在6月18日对自然年Q1估计约2,000万只400G以上模块出货，并预计全年1.6T超过1,000万只；这是机构原始统计/预测，不是合同。公司收入、毛利和实际交付共同增长，比仅有book-to-bill更能支持近期扩张。相反，采购单和长交期同样可以产生提前备货。10-K的Backlog and Inventory及客户风险段明确：主要是采购单，通常无长期最低量承诺，可取消/减量/延期，定点后到批量也可能超过一年。因此接受可见增长，拒绝把1.6倍book-to-bill当不可撤销收入。真正分辨证据是连续复购、出货之后的回款、客户库存及订单延期，而不是又一个订单纪录。[Cignal AI原始统计](https://cignal.ai/2026/06/datacom-optical-component-revenue-doubles-to-7-7-billion-in-1q26/)、[10-K原文](https://www.sec.gov/Archives/edgar/data/1493594/000149359425000054/mtsi-20251003.htm)。

**争议B：线性化让模拟器件更值钱，还是让平台商收走价值？** MACOM的448G Driver面向多种调制材料，能延长可服务架构；Semtech的224G TIA/Driver也覆盖线性架构。Marvell Ara T简表则明确把Driver集成进平台。这些资料支持两种机制同时存在，但明确推翻“去掉DSP后所有节约均归MACOM”。独立模拟功能不可缺不等于独立器件不可替代。基准允许出货增长而同规格净价下降；乐观需要多代BOM外购仍保留；突破还需要原来走铜的连接变成付费光内容。[MACOM 448G公告](https://www.macom.com/updates/news/2026/macom-announces-two-new-448g-per-lane-drivers-for-3-2t-data-cent)、[Semtech产品公告](https://www.semtech.com/company/press/semtech-launches-224-gbps-ic-family-for-linear-optics-era)、[Marvell Ara T原始简表](https://www.marvell.com/content/dam/marvell/en/public-collateral/dsp/marvell-ara-t-1-6t-transmit-retimed-pam4-product-brief.pdf)。

**争议C：CW进入规模已经确定吗？** 8月6日管理层原话仍在锁定生产工艺，并提出自然年2027年末潜在投产。正文与问答中的“2028”相容：初始投产可在2027末，规模放量在其后。2025发布产品与可靠性设计目标不等于量产采购。当前证据偏向“有客户牵引、但工程尚未封闭”，所以Y1无新CW收入，Y2少量试商业，Y3才可能规模。Lumentum计划2028年中爬坡6英寸InP工厂，且有NVIDIA客户关系，对MACOM同一扩量窗口形成具体竞争。[管理层完整转录，定位Daly的CW工艺段而非网页摘要](https://www.fool.com/earnings/call-transcripts/2026/08/13/macom-mtsi-q3-2026-earnings-call-transcript/)、[Lumentum新设施公告](https://investor.lumentum.com/financial-news-releases/news-details/2026/Lumentum-Announces-New-U-S--Manufacturing-Facility-to-Produce-Advanced-Lasers-for-the-Worlds-Largest-AI-Data-Centers/default.aspx)。转录未逐字核录音，因此技术日期保留M级误差，模型检验延期，不把第三方摘要当第二份证据。

**争议D：自有制造是高资本回报平台，还是下一轮固定成本？** 已实现交付、在建工程和设备投入支持能力扩大；100mm到150mm面积增加2.25倍，但良率、设备、测试、客户资格可能抵消。上游特种代工报告只用于识别这些约束，不移植其他公司的产能利用率。345的五年资本计划及最高约180的政府支持，原公告是初步、非约束安排；未核得全部最终拨付。本模型按毛投资支付。研发、资格与设备同时投入，只有合格输出和复购产生ROIC。RF自制又是实质竞争：RTX的GaN制造资料支持主承包商可内化器件价值。[资本计划原文](https://ir.macom.com/news-releases/news-release-details/macom-announces-strategic-capital-investment-plan/)、[RTX制造资料](https://www.rtx.com/news/2025/05/12/where-radars-are-born)。

**争议E：IQE投资是可靠供应锁定，还是相关尾部风险？** 4月27日协议及5月28日完成公告确认£30m股权、£15m零息可转贷款和长期供货；7月3日股权与贷款公允价值方向不同，不能把净收益当供应商经营分红。公开说明支持担保贷款存在，但没有足以完整复算担保资产价值、优先顺位及执行回收的条款，故不视为无风险债权。IQE全年2025收入下降17.6%，光子业务却增长15%，说明好行业与供应商财务脆弱可并存。其又向Tower签多年InP外延供货，明确否定MACOM独享全部产能。模型非经营资产仅按30/65/90/100计值，悲观再付50用于供货迁移或支持；既有60.6现金投入不再重扣。[融资条款](https://www.iqep.com/media/press-releases/2026/conclusion-of-strategic-review/)、[完成融资与经营数据](https://www.iqep.com/media/press-releases/2026/full-year-2025-results/)、[IQE—Tower协议](https://www.iqep.com/media/press-releases/2026/iqe-and-tower-semiconductor-announce-multi-year-inp-epiwafer-supply-agreement/)。

### 2.4 客户、管理层与失败风险

FY2025两个转售客户占比12.4%、11.2%，无单一直客超过10%；“直客分散”不等于云端最终预算分散。Q3中国按账单地址约占39.1%，不是最终安装地。出口限制或中国模块供应链换单会经过客户资格、交付和定价传导；基准不假定自动无损迁移，普通偏差与悲观路径已容纳部分订单/价格损失。国防预算扩张有利，也可能伴审批、原材料和费用上升。

管理层近期指引执行与RF资产整合提供正面证据；新CW发布到稳定量产的间隔是反面约束。CEO兼董事长、激励偏调整后利润/EPS，要求额外检查现金和资本投入。未发现截止资料内足以改变主估值的重大待决诉讼，但供应质量、IP赔偿和资格损失可能影响整批出货。这里没有给诉讼一个凭空准备金，也没有据此断言风险不存在。治理历史参照[2026代理说明书](https://www.sec.gov/Archives/edgar/data/1493594/000149359426000007/mtsi-20260116.htm)，持股时点不冒充9月最新实益持股。

### 3.2 三项早期机会：进入、规模与现金边界

**CW**：客户是模块/光引擎供应链，产品为合格激光裸片或阵列；主工作规模不是完整光源模块。Y3规模成功收入130，对应净价10—25美元、约520万—1,300万颗年交付；Y5规模380对应约1,900万颗×20美元。进入需锁定工艺、可靠性和批量订单；更高功率、竞争者大尺寸产线会影响净价。Y10规模700需要多客户与阵列复用，不能靠少量首发平台撑起。

**NPO/CPO新插槽**：只计既有可插拔池之外、由近芯片架构获得的新增模拟器件净收入，已减对原核心器件的替代和资源争夺。Y3规模200可由约1,000万个800G等效端×20美元净芯片内容形成；Y5规模650需约3,250万等效端×20美元，或相容的更多端/更低净价。不是按完整光引擎售价。行业2028交换侧等效端范围较小，因此规模路径须延伸到更多平台及其后的scale-up；不能把2028行业上沿提前用在Y2。Semtech/平台自研是主要失败机制，客户定点和复购是关键验证。

**新卫星项目**：将新进入的D2D、特定星载RF/光通信设计形成一个采购平台组合，已在核心电信/I&D的存量销售不再计入。组合内部不同产品并非一个芯片，但商业规模主要共同依赖获得少数新增组网项目及批量采购；没有假定Elve整台TWTA收益都归MACOM。Y3规模100可由约5,000个系统当量×2万美元MACOM芯片/组件净内容形成；“系统当量”涵盖不同卫星/地面终端，不能误读为已公布发射数。Y5规模190需多项目复制、组网预算和可靠性。该数量级有器件目录入口，但缺客户BOM，金额置信度低。[卫星产品原公告](https://www.macom.com/updates/news/2026/macom-ims-2026-product-announcements-for-satellite-communication)。

这些价格和数量是有商业边界的工作假设，公开未披露真实ASP、客户采购量、单厂合格吞吐。上游未提供此数据；本次追查公司产品、财报、管理层发言、IQE交易和竞争者产品后仍无足够点值，属于“针对性检索后未披露”，不是已知为零。规模范围以工作值的约0.5—1.5倍检查；超过它需要更多付费客户、不同收入边界或新资本方案，不能靠提高概率完成。

其他重大用途保留：400G/lane、3.2T可插拔、相干与ACC更新已在核心；反无人机/高功率微波、光学跨机架/封装内I/O、汽车激光雷达可在5—10年扩大用途。MACOM进入条件分别是客户设计权、可靠性与付费接口，当前无法给独立金额边界，未在主估值再加“隐藏TAM”。对于公司进入整机/软件收费等尚无经济权利证据的跃迁，结论覆盖不足；本文拒绝的是现有可建模路径的现价吸引力，不宣称所有未知用途均无价值。

### 3.3 年度状态、主观概率与不重复计值

每个机会每年四个互斥状态：N未商业化、P部分商业成功、S当年仍规模成功、F失败/退出。初始N=100%；F为吸收态。N→P为a，N→F为f；P→S为b，P→F为h；S→F为e，其余留原状态。**S列是当年占有率，不是首次成功概率或累计曾成功率**。概率转移先算，随后按该年状态的当年收入/成本加权，不能逐年把累计成功率再乘一遍。

CW/NPO在Y1不能N→P，Y2才开放；卫星从Y1开放，反映工程与项目时间不同。突破条件固定的是更好的进入/工艺与客户协作环境，不固定“规模销售已成功”，所以余下商业扩量继续加权。独立成功实验才把某个机会S置100%。本模型没有适用且可取得的统计基础率；这些是**主观工作转移概率**，不是估计的真实胜率。其依据是现有供应关系/产品能力为正、CW工艺未封闭、NPO采购界面未固定和卫星项目周期为负。把CW在Y1设高概率量产与披露相冲突；将卫星与CW完全同速也不合理。

参数合理邻域：a上下约8个百分点、b上下10个百分点、退出率上下2个百分点，每一敏感路径仍用转移矩阵完整重算并归一。概率区间不是置信区间，也不以中点当P50。高端不能同时把收入规模、ASP和毛利全取最大：高a可能要求更多前置投入；表内收入乘数悲观0.6、基准1、乐观1.25、突破1.6包含各自供给与客户规模约束。

状态内经济性：P收入＝S的25%，P毛利比S低10个百分点；CW/NPO/卫星S毛利53%/64%/56%。N研发支持12/18/8，Y6后降半；P、S固定支持同额再加收入15%，不是把部分成功按规模利润率直乘。CapEx：N前三年9/6/4，P收入6%，S收入8.5%；折旧为P/S收入2.5%；营运资本为收入25%。F收入零，新进入F时支付固定支持的一半作为退出费用，存量F不每年再次支付退出费。税按18%在状态内计算，亏损税盾限于同一集团持续正核心应税利润；极端核心税盾失效另检验。先加权WC余额再取跨年变动，等价于联合转移路径线性期望，不会让失败路径无条件恢复。

现金=EBIT−税＋折旧−CapEx−ΔWC。研发已在费用，CapEx是额外资产，不再把研发资本化加一次价值。三个机会的净增量已扣替代边界，核心资本计划保留资源；下表现金可线性相加。没有拿“相关性”额外乘折扣；出现破产、融资或共享供给排他时须用联合分支，本报告已以全失败/大规模投入组合检查现金安全，见3.7。

### 3.5 持续期、再投资与增量资本回报

每一代TIA/Driver的定点寿命有限，跨代资格须再争取；RF目录与国防资格通常可跨更长时间，但预算、产品更新和维护成本持续。核心研发是维持平台和开发新代的费用，不能在终值时取消。现有经营并非有限三年生命；我们显式预测至Y10，再估剩余。

投资分配（H）：核心设备/软件支出约40%用于维持和更新，约40%用于已在推进的产能/已定点成长，20%是根据复购与合格产出执行的可选增长。比例不是公司承诺额。基准Y1核心112，包括设备100、软件12；新机会另付自身状态投资。Y2—Y3核心245设备及24软件，加机会投资，与持续研发、周转共同买未来收入。悲观Y2核心支出降到77，不是假定管理层立即完美停止；Y1仍支付97并承受库存/退出成本。

用基准核心Y1→Y3作批次审查：增量经济税后经营利润约200—210的数量级，设备软件、净周转和新增研发经济投入合计约400—550；条件增量回报约36%—52%，简单回收约2—4年（含爬坡），**不是IRR**。拆不开产品批次且含共享资产，因此不称为已实现ROIC。该较高回报依赖已有厂房和产品复用；若多付100设备、净价降低或客户只买一次，回收会明显延长。成熟阶段ROIC向10%/16%/20%/22%收敛，反映竞争和更新，而不是永久保留初始高增量回报。

### 3.7 资本断点与可行应对

四条主路径无分红、无并购对价、无ATM/配股；不因此假定这些资本动作永远不会发生。继续新股报酬已按现金成本等价扣除；公司如果选择保留该现金、直接稀释，应逐期调整股数与现金，而不是额外奖励估值。本模型采用公司有能力实施的反稀释经济路径，不声称董事会已经承诺回购。

最差早期联合分支是三项均失败并失去亏损税盾；第一年未商业化研发40、前置CapEx19、退出成本最高20，合计不足80，核心自身经营现金和预留本金后的流动性可覆盖。另一端三项同时进入规模需更多投资，但S/P状态先扣全部CapEx和周转，结合核心同年现金仍没有融资断点。逐期最低现金不能低于100且须留足到期本金；悲观Y1仍有正FCFF。若核心停产、IQE需要数亿美元支持或非计划大收购，结果超出上述安全范围，应新建资本分支，不能用期望现金掩盖破产。为核验尾部，额外300现金损失本身约每股3.8，若伴永久丢失核心毛利，后者远比单纯现金损失大。

### 4.4 三个有经济依据的论点

1. **可见经营上修交易。** 回报来自FY27利润上修与市场采纳；最少条件为交付继续超过已知起点、现金未恶化，可以不需要CW成功。失败是已支付改善、季度只达标或高倍数收缩。短期估值可能偏离现金价值，必须另作交易算例，不能把DCF推进几个月当交易收益。
2. **跨代模拟平台复利。** 回报来自持续定点、制造和研发复用，股东现金长期高增长；CW可以缺席，但必须有核心获配及足够更新ROIC。基准允许复用而不过度延长高增长，平台替代解释把前三年固定、Y4—Y10数据中心每年增25%、I&D增12%、电信增5%，Opex增12%，资本随收入增加至约7.5%。这是实质不同的经营解释，不是换一个倍数工具。
3. **高风险技术突破。** 回报来自未充分获得经济权利的CW/NPO/卫星扩量及核心协同；可以承受较多失败，但完整成功所得、失败现金与原始买价必须配对。我们同时算单机会、平台与突破主路径，避免把所有成功叠到一起才显示上限。

现金清算/资产安全边际论点在现价缺乏解释力：扣本金和融资义务后的净现金及IQE价值仅几美元/股，账面厂房和商誉不是20多十亿美元市值的保护。周期租金可解释短期高利润，但如果利润寿命短，其价值只会低于平台复利，不能用高峰PE倒推安全。

### 4.5 主估值：目标日剩余现金流，所有期限使用同一经营理念

主矩阵为**条件合理价值回报**。用目标日之后的经济FCFF做企业价值DCF，目标日前现金只经资本桥加一次。显式到Y10，剩余部分按期中折现；第十年后的现金按持续更新与再投资机制计算。目标时点仍沿“从今天看”的状态分布，概率不因为过了半年自动变100%；未来真的观察到成功/失败应再条件更新，这与主矩阵是不同计算。

公式：EV_T＝Σ剩余期FCFF/(1+w)^(现金中点−T)＋TV_10/(1+w)^(10−T)；TV_10＝EBIT_10×82%×(1+g)×(1−g/ROIC)/(w−g)。股权价值＝EV＋现金−100最低营运现金＋IQE−344.316本金−67.225其他融资。价格与转债溢价股数联立。FCFF采用经济税率和所有成长/维护投入，没有额外把同一CW/NPO期权加在DCF上。

每行区间保持经营和机会概率不变：下沿w11.5%、g比工作值低0.5个百分点、成熟ROIC低2个百分点；上沿w9.5%、g高0.5个百分点、ROIC高2个百分点。三项组合分别表示持续经营较弱/较强的可辩护资本解释，不是统计区间；共用w范围避免对已入现金的特定失败重复惩罚。工作值w10.5%。区间未包尽全部经营误差，普通不及预期另算。

## 5. 条件建议矩阵与十二格明细

### 5.1 统一评级标准

没有提供个人资金成本或亏损约束，因此采用可复用参考：3个月预期差要求累计8%（邻域6%—10%）；6个月12%（10%—15%）；一年18%（15%—20%）；三年平台复利15%年化（12%—18%），对应累计52.1%（40.5%—64.3%）。不是把一年18%乘3，也不把累计52%叫年化52%。现金机会成本约4%仅是起点，额外要求补偿集中单股、模型误差和持有不可控性，区别于DCF的经营资本成本。

三列主理念分别为预期差但受现金权益约束、经营兑现与现金转换、平台持续复利；每列四行完全一致。高风险技术期权另用三年20%年化（邻域15%—25%）、能承受约50%—80%损失做比较，不给它套安全边际要求。主格不按行情景发生概率或短期市场是否采纳压级。

强烈正面需主要不利敏感性仍明显超过要求；建议投资需可支持范围有足够余量；谨慎建议用于工作值达到但合理边界或邻近标准翻转；中性表示该条件行内经济优势与误差难分。强烈负面用于整个条件范围明显亏损或回报严重不足，并不意味着公司将破产。乐观长期最高年化约11.9%，接近但低于邻近12%要求，在主要15%标准下不建议；若个人要求10%，同一路径可谨慎正面，不能改写经营。

所有主格包含第3节行内概率加权机会，未使用单机会100%成功替换。估值置信度是条件于路径的价值可靠度；第3.1的情景证据强度是当前对路径的支持，二者不是胜率。

### 6.3 成功的可信范围与整股选择

三项机会逐年概率是**条件于经营行的局部状态概率**，不能套作整股成功概率。本报告没有给四行加总为100%，也不计算伪精确胜率或CVaR。

用基准三年184和突破483作最简损益门槛算例：要从274.80满足15%年化，期末需要约418；如果只有这两种互斥结果，成功权重需约78%。若放宽到仅跑赢4%现金，门槛约42%；若用突破上沿596作成功值，15%要求门槛降至约57%。这些是**门槛而不是事件概率估计**；真实结果包括普通偏差、平台延续、更强/更弱路径和价格采纳差异，不能把该二点模型当覆盖全集。

证据判断仍可明确：已有季度交付、产品组合和国防需求支持近期核心放量；它们不支持以超过一半、更不支持接近八成把整股价值归到多年跨代突破。CW仍在工艺资格阶段，NPO外购接口未固定，竞争者有明确集成和扩产路径；这些不是小概率噪声。相反，长期平台的可能性不能排除，上沿也能翻转选择，故不能宣称任何高风险参与都错误。**在本报告15%复利与20%高风险参考标准下，现价选择不建立新仓更有依据；“技术期权存在”与“期权买价合适”分开。** 这是证据和损益形状的权衡，不是由无法证明买入推出现金必然更优。

若投资者只要求约10%年化、可承受一半以上回撤并能提供跨代BOM持续复用的新证据，持久平台工作值附近可能支持谨慎参与；目前可核资料不足以把这个组合升级为主要判断。重要转变证据是连续的多代净价/获配与更新后现金回报，不是新TAM或单季non-GAAP EPS。

        assert abs(sum(pr)-1)<1e-9 and min(pr)>=0 and (force or pr[3]>=prev[3])
        scale=o['scale'][i]*S[s]['mult']; rev=[0,.25*scale,scale,0]
        # state cash includes full level of WC (25% revenue); subtract previous state WC only after expectation.
        # F includes one-time exit cost only on newly failed probability; no recovery of failed business.
        vals=[]
        for k,r in enumerate(rev):
            prep=o['prep']*(1 if yr<=5 else .5)

            op=prep if k==0 else (prep+.15*r if k in [1,2] else 0)
            eb=gp-op

            da=.025*r
            tax=.18*eb # consolidated group has positive taxable core earnings
            vals.append(dict(rev=r,gp=gp,op=op,ebit=eb,tax=tax,da=da,cap=cap,wc=.25*r))
        row={key:sum(pr[k]*vals[k][key] for k in range(4)) for key in vals[0]}
        row['exit']=max(0,pr[3]-prev[3])*o['prep']*.5
        row['ebit']-=row['exit'];row['op']+=row['exit'];row['tax']-=row['exit']*.18
        row['dwc']=row['wc']-(rows[-1]['wc'] if rows else 0)
        row['fcff']=row['ebit']-row['tax']+row['da']-row['cap']-row['dwc']
        row.update(p=pr,state=vals,scale=scale,year=yr)
        rows.append(row);prev=pr
    return rows
def model(s,force=None,ordinary=False):

def periods(m):
    return [(i/4,(i+1)/4,q) for i,q in enumerate(m['quarters'])]+[(i,i+1,r) for i,r in enumerate(m['rows']) if i>=1]
def integrate(m,key,t0,t1):
    return sum(r[key]*max(0,min(t1,h)-max(t0,l))/(h-l) for l,h,r in periods(m))
def cash(m,t):
    # 3% after-tax cash return on opening and mean operating accumulation; small explicit approximation
    f=integrate(m,'fcff',0,t)
    extra=50 if m['s']=='悲观' else 0 # supplier rescue/requalification, cash outflow once
    return STARTCASH+f+.03*t*(STARTCASH+.5*f)-extra*min(t,1)
def value(m,t,w=.105,g=None,roic=None,fade=1):
    a=m['a'];g=a['g'] if g is None else g;roic=a['roic'] if roic is None else roic
    # midpoint convention applied only to remaining part of each period
    pv=0
    for start,h,r in periods(m):
        l=max(t,start)
        if h>l:pv+=r['fcff']*(h-l)/(h-start)/(1+w)**((l+h)/2-t)
    r=m['rows'][-1]
    tv=r['ebit']*.82*(1+g)*(1-g/roic)*fade/(w-g)
    tvpv=tv/(1+w)**(10-t)
    ev=pv+tvpv;ca=cash(m,t);equity=ev+ca-100-DEBT-LEASE+a['iqe']
    # debt premium is shares, while face principal remains deducted/reserved
    price=equity/N0
    for _ in range(60):
        ds=max(0,CONV-DEBT/max(price,.01));price=equity/(N0+ds)
    ds=max(0,CONV-DEBT/max(price,.01))
    return dict(t=t,ev=ev,equity=equity,price=price,shares=N0+ds,cash=ca,netcash=ca-DEBT-LEASE,ret=price/P0-1,annual=(price/P0)**(1/t)-1 if t else 0,tvpct=tvpv/ev,ntmrev=integrate(m,'rev',t,t+1),ntmebit=integrate(m,'ebit',t,t+1),ntmfcff=integrate(m,'fcff',t,t+1))
def bands(m,t):
    # operating scenario fixed, common dollar discount range; same risk is not re-haircut
    return [value(m,t,w=.115,g=max(0,m['a']['g']-.005),roic=max(.08,m['a']['roic']-.02)),value(m,t),value(m,t,w=.095,g=m['a']['g']+.005,roic=m['a']['roic']+.02)]

def platform():
