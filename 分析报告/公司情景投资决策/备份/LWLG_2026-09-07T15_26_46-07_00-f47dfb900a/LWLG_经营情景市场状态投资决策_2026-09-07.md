### 2.2 上游预测怎样进入本公司的数字

统一结算单元采用“完整 PIC 等价单元”，把同一产品所有 LWLG 材料和绑定授权收入合成单位净收入。每个 PIC 所含 lane 数不再乘第二遍。I1 的 800G 等效端点与本报告 PIC 单元不同，不能直接把两种数量相加。

```text
公司可确认单元数
 = min(被客户分配且可服务的生产需求、各环节合格交付能力、合同/关键投入允许量)
量产收入 = 不重复单元数 × LWLG 每单元净收费
总收入 = 量产收入 + 未包含的固定/最低费净额 + 当期验收 NRE
```

I1 基准以 2030 年 2.6 亿个 800G 等效端点、1%—6% 有机方案渗透、每等效端点 2—3 美元材料/授权价值，形成行业 5—50 百万美元的工作区间；**这是行业模型，且包含竞争者。** 本报告基准 2030 年收入 10—25 百万美元，要求在行业区间中上部取得约 20%—50% 以上份额；行业仅到 5 百万美元时不能同时使用本公司 25 百万美元端点。基准低端亦须行业池至少约 20 百万美元或本公司份额较高，未把行业低端与公司高端混配。

I2 的模块基准从 2026 年约 5,400 万只交付上升到 2027 年约 7,800 万只，供应能力约 8,300 万只；1.6T 单价参考从 2026 年 900 美元降到 2028 年 500 美元。这里价格是行业研究估计，不是 LWLG 材料成交价。它对 LWLG 的约束是：数量机会扩大但成熟替代供给增加，客户能要求更低每比特成本，单位净费率不能无限跟随模块性能上涨。

乐观 2030 年 LWLG 收入 55—90 百万美元已超出 I1 行业基准的大部分范围，**需要行业向 100—300 百万美元上行区间迁移**，并由本公司实际设计赢单支撑。突破 2030 年 140—220 百万美元则要求行业上行池接近 200—300 百万美元、本公司捕获约 47%—73% 的 300 百万美元池；这极为苛刻，但在有公司特定工艺平台与五个工程入口的前提下可作为低证据条件路径。行业停留基准时，乐观高端及突破不能成立。

2031 年突破 220—360 百万美元继续需要相干/CPO 与更多合格料号扩展；360 百万美元相当于 2030 行业上行高端再增长至少 20% 且相当高份额，不能称为上游已经支持的市场上界。它是对“平台型胜出”的显式条件估算，未为了贴近股价提高基准。

### 2.3 最有依据的近端基础及价格—成本桥

正常兑现首先是：完成既定流片、后段和器件可靠性工作，旧收费持续、新开发阶段逐步验收，领先新客户仍主要指向 2027H2 生产。C1 的 2026 全年收入 0.12—0.40 百万美元、2027 约 0.10—1.20 的工作预算进入基准，未来两个研究季度不假设量产爆发。依据是已知开发阶段 0.20 百万美元、五个 Stage 3 的工程阶段、尚未公开不可撤销量产数量。

收入变化主要来自“新工程阶段验收/少量试产 → 首个料号交付 → 复购和第二个料号”，并非延长当期收入同比增速。若单元净费由 5 降至 3 美元，相同收入要多交付 67%；若 400G/lane 令同等带宽所需调制单元减少，必须在 PIC/lane 换算中降低内容量。基准中后期单元费 3—5 美元、乐观 5—8、突破 6—10 均需合同验证；高端来自 IP/工艺锁定而非化学品公斤数。

当前账面高毛利主要因为最低费/NRE，而工程履约投入进入研发。未来从这种“近乎全为许可费”的收入转成量产，销售成本会包含批次 QC、良率、报废、工艺维护与外包服务，所以近端毛利率下降具有产品组合和成本归属机制；它不代表材料售价必然下降。远端授权占比提高、工艺复用使毛利率再改善，也须同时扣除持续研发与扩产费用。

## 四、反向估值：当前价格需要什么

独立经营表先于本节形成。取研究日潜在股数 164、价格 5.35、模型现金 89、无有息债：隐含经营价值约 **788.4 百万美元**。以 2031 年底正常化 FCF 为关键变量，假设研究日之后至该时点的净负现金流现值为 50，永续增长 4%，反向公式为：

```text
所需2031 FCF = (当前经营价值 + 前期净消耗现值)
                × (1+r)^5.3178 × (r-g)/(1+g)
```

| 长期正现金流折现率 r；g=4% | 所需 2031 年 FCF | FCF 率 35% 所需收入 | FCF 率 25% 所需收入 |
|---|---:|---:|---:|
| 12% | 117.8 | 336.6 | 471.3 |
| 16% | 213.0 | 608.6 | 852.0 |
| 20% | 340.1 | 971.7 | 1,360.4 |

这不是唯一市场共识，而是**给定费用、资本结构、持续期的定价边界**。前期净消耗 30—80 会改变所需 FCF 约 -2.4% 至 +3.6%；关键不是多几个百万现金，而是数百百万收入能否产生高比例现金。按 12% 这一较宽松折现率，117.8 的 FCF 已需要接近突破高端；16% 则超过本报告突破的 145 高端。若采用更高退出倍数或更低资本成本，门槛可降，见估值分歧；不得因此声称市场“必然”预期 336.6 的收入。

## 七、估值方法、现金流口径与统一建议门槛

### 7.1 主估值：完整现金流项目净值加金融资产

LWLG 没有稳定利润，NTM 收入不足以独立承担估值。主方法采用“**完整经营路径现金流、可持续终值、资金桥与总额法稀释**”。负现金流代表必须筹备的资金，不是要额外扣除第二次的风险折价；正现金流和终值才按市场对久期的价格折现。所有成长投入及其未来回报已进入同一现金流，**不再加 IP、CPO、相干、收购或其他项目期权**。

为避免市场利率越高反而把确定支出折得越小，负现金流资金准备按 4.8% 的国债收益率近似贴现，正现金流按对应市场列的资本成本贴现。4.8% 是 9 月初 10Y 4.77% 的取整模型，并非已锁定全部年份的融资利率。这个双贴现口径是项目资金准备法，**不是单一 WACC 企业 DCF**；若以统一高折现率处理负现金流，会使早期亏损公司价值略高，本报告不采用该有利误差。

```text
目标日 T = 2027-03-07
2027剩余期间权重 u = 299/365 = 0.819178
t_y = u + (y-2027)，y=2027,...,2031
2027现金流只取全年模型×u，2028—2031取全年
经营EV = Σ[负FCF / (1+4.8%)^t_y]
       + Σ[正FCF / (1+r)^t_y]
       + 2031FCF×(1+g)/(r-g)/(1+r)^4.819178
股权价值 = max(0, 经营EV + 目标日现金证券 − 尚未在现金流处理的优先索取权)
每股 = 股权价值 / 同行目标日完全稀释股数
六个月条件总回报 = 每股/5.35 − 1，分红=0
```

2027 日历年现金流乘剩余天数是**年度预算向目标日后的资金近似**，不是将工程合同收入逐日确认；季度资金高峰可能使现金偏离约 2—5（每股约 0.01—0.03）。NTM 收入使用第三节的验收分段，不采用该比例替代收入确认。

| 悲观 | -24 / -20 | -24 / -20 | -18 / -14 | -10 / -8 | -3 / -2 | 退出；终值 0 |
| 基准 | -24 / -24 | -22 / -20 | -16 / -10 | -8 / 0 | 2 / 10 | 0% / 2% |

### 7.2 交叉验证及不可平均的分歧

1. **反向估值**检验现价所需收费和远端利润，不用于移动基准。
2. **近端 NTM/收入估值**只作排除检查：即便对 NTM6 给 20 倍收入的高边界，基准 EV 2.2—29、乐观 40—204、突破 200—640；加入对应现金并除股数后，约分别 0.44—0.66、0.63—1.71、1.49—4.28 美元。微小 NRE 不具可复购性，20 倍不是推荐估值，更不能乘 2031 年收入后不折现。
3. **远期 FCF 退出倍数边界**把上表倍数替换永续公式，其余现金流/投入/股本不变，二十格表单列结果。宽基突破可达约 5.32—15.32，但主 DCF 为 2.25—8.79；差异来自终值支付意愿，不是不同客户数量。
4. **为何主方法优先：**在 12% 折现率下，28 倍永续 FCF 等价于约 8.1% 长期增长（由 g=(Mr−1)/(M+1)），远高于本报告高端 5%。主题高端 32 倍与 11% 相配也隐含约 7.6%。它可描述市场阶段性高价，不能作为技术许可几十年持续高增长的基准。报告保留两套结果、估值置信度低，**不把它们平均成主目标价**。
5. 悲观无终值，现金储备减资金准备的结果与各列相同；它不因此具有资产保底。若停止投入、更早清算或出现正式收购报价，必须建立新的经营/清偿路径，而不是临时加 IP 市值。

### 7.3 统一六个月要求回报与价格边界规则

六个月研究要求回报设 **+25%**；三个月若作定量检查设 **+15%**。同期无风险收益仅约 2%—3%/约 1%，远不足以补偿早期收费未知、长期价值模型误差和不可逆支出。上述门槛是研究者需要的安全边际，不是概率预期，也不再作为现金流折价重复扣除市场风险。

全矩阵使用同一建议词义。为让“首次转正价格”可复核，在没有额外清偿风险时，本报告对最低正面级别“谨慎建议”采用共同价格筛选：**主价值中点达到 +25%，价值低端损失不超过 40%，高端上行至少 50%**；还须经营与资本路径成立、适用边界方法不构成决定性反证。40% 是对该早期公司在“谨慎”级别容忍的明显低端风险上限，不适用于“建议”或“强烈建议”。

因此机械初筛最高价为：
`P正面=min[(V低+V高)/(2×1.25), V低/0.60, V高/1.50]`。
这不是公司排名或综合评分，也不表示价格跌至该值即可无条件买入。若低价来自新技术失败、融资约束或未来路径失效，要先重新建模；永久损失不能用足够低价格自动消除。

“强烈不建议”用于主价值区间显著低于现价且资本损失严重；乐观宽基/主题虽主 DCF 显著低于价格，但退出倍数边界方向有分歧，因此标“**不建议投资**”、估值置信度低；突破宽基/主题虽然高端可观，低端约损失 58%，又依赖长端假设，保留“中性/等待”。未以经营行名称或当前证据强弱决定条件标签。

条件事件树（各节点需要独立确认，未赋概率）：

```text
代工/BEOL器件达到客户验收要求？
├─ 否 → 返工/项目退出 → 支出和时间增加 → 基准低端或悲观
└─ 是 → 是否签署可约束数量和收费的生产合同？
   ├─ 否 → 继续小额工程/样品 → 基准，不自动获得量产终值
   └─ 是 → 首个料号是否按计划交付并复购？
      ├─ 否 → 订单/收入递延 + 现金占用 → 基准或悲观
      └─ 是 → 第二独立客户能否复用合格工艺、净费率可保留？
         ├─ 否 → 乐观的单客户规模路径，买方议价/集中风险保留
         └─ 是 → 突破条件路径；再检验长期FCF、资本回报和当前买入价
```

验收、合同和复购并非三项独立可相加利好；它们是同一收入链的不同前置环节。五个项目存在共同材料/封装失效风险，不能用五次独立试验的二项概率推导成功率。

### 10.2 当前邻域与最近的可观察边界

当前邻域采用基准、乐观两行 × 宽基、震荡两列。基准两列均强烈不建议；乐观宽基不建议、乐观震荡强烈不建议。没有因一次普通市场列切换或从小额工程进入首个复购，就出现正面反转。方向稳定不是说股价稳定；它只表示现价与这四条条件现金价值不匹配。

若客户确认了一条足以约束到 2031 年每年数千万 PIC、较高净授权费且无需重资产资本投入的路径，当前经营应向突破移动，估值低端可显著上移；但那是量、价、可靠性和资本桥共同变化，不能用一份无最低量的合作协议代替。相反，单个关键客户终止、生产窗口推迟超过一年并维持高支出，会先破坏收入时点和现金跑道，把定位下移。

由于当前条件建议已在最低级别，减弱边界体现为资本损失范围扩大/残余价值降低，不再虚构第七级评级。相同路径下更强建议首先需价格下降；若证据只是一次 0.20 开发验收，对每股经济量太小，不足改变级别。

### 10.3 全矩阵形状与价格边界

形状为 **当前价格支持不足、经营兑现敏感、市场状态敏感、突破仍未覆盖足够安全边际**。没有“广泛正面区域”。建议最稳定的是悲观与基准的负面区域；最脆弱的是突破×宽基/主题，从远期高倍数边界看很有吸引力，但主现金流低端仍损失约58%，而同一突破移到震荡后价值上端也略低于现价。

最坏格子为悲观行：约 0.03 美元低端，相对 5.35 每股损失约 **5.32 美元（-99.4%）**。首个原因是采购/路线失败后多年现金消耗与退出，而不是当前已经发生信用危机。低端不构成保证，额外法律义务、不可停止支出或更严重稀释可使残余归零，模型未声称排除这类尾部。

悲观全负面由现金消耗后的资产残余与当前约8亿以上股权基数差距解释；突破没有正面由低端现金流规模、长端折现及模型分歧解释。不是在行名上预设标签，也没有把格子数拿来投票。

## 十一、三个月与六个月本方法投资判断

### 11.1 三个月：不建议投资，技术确认本身不足以建立现价优势

目标日 **2026-12-07**。NTM3 已滚动到 2027-12-07，基准收入 0.10—1.20，而非重复使用 NTM0 的 0.10—1.03。本窗口可能取得 Q3 财务、专用晶圆/BEOL 器件结果、开发第二阶段验收；这些可以证明工程继续，但金额本身很难支持当前约 788 百万美元经营价值。

关键预期差是：当前价格与低 NTM 收入并不矛盾，但它**需要近期证据证明未来能够拥有大规模、可保护的收费权**。本报告没有看到足以锁定这种规模的公开客户条款。仅把阶段数从五增到六、报告高带宽眼图、收到晶圆或确认 0.20 开发款，均不能独立证明数百百万长期收入。现价在较宽松 12% 折现下已经需要约118的长端 FCF，是比“2027H2开始生产”高得多的经济门槛。

可能的正面路径是客户同时给出产品资格、可约束量价的正式合同、后段交付责任及明确生产时间；即使三个月内收入尚小，也可因信息含量而提前重估。若信息仅由公司单方面表述、客户身份和量价都不可核对，技术改善仍可能没有足够投资优势。三个月的最强反证是这种高信息量合同提前出现，而不是股价先上涨本身。

三个月合理价值与交易价不强行量化：**可能交易价格区间/预期交易回报=NA**，因为缺少能约束投资者对平台期权支付程度、以及合同公开时点的证据。没有以六个月基准的0.11—0.60当三个月目标价。方向性判断是在5.35缺少可支持的经济安全边际；并不等同于做空建议或断言未来三个月下跌。若建立可复核的三个月价格模型，要求回报为15%，当前证据尚不支持其实现路径。

### 11.2 六个月：不建议投资；信息可能更完整，成熟商业兑现大多仍在窗口外

目标日 **2027-03-07**，主矩阵全部格子使用该日。NTM6 滚动到 2028-03-07，基准收入 0.11—1.45，乐观2—10.2，突破10—32。相比三个月，市场更接近领先客户2027H2的生产窗口，定型和合同可能对下一年的收入提供更强约束；这是真实的时间价值，不是把远期收入提前全部确认。

正常工程兑现仍主要对应基准；主矩阵在两候选市场列均强烈不建议，退出倍数边界也不能支持5.35。**六个月本方法总体保留“不建议投资”，没有机械复制最低格子的“强烈”标签**：原因是期间有可能出现当前尚未公开、足以改变长期路径的新合同；当前条件格只回答基准保持时的价值，本方法判断还考察信息可达性和价格采纳时点。此保留不赋予未知事件正期望，也不以突破高端抵消基准风险。

本窗口最有价值的新增证据，是客户侧生产料号、明确净收费权、至少两段可复核发货，以及第二独立客户的工艺复用。若这些形成，六个月经营可由基准上移；但第八节说明，即便移到突破，在5.35仍需较高现金流端或更长持续期才获得充分安全边际。单凭工程进展把市场列改成主题上涨，不构成合格的判断翻转。

六个月**可能交易价格区间及预期交易回报=NA**。主矩阵给出的是同期限条件价值回报，不能冒充股价将被市场采纳的分布。2026全年业务更新可能在2027年3月，10-K或完整信息可能晚于3月7日；因此没有把完整年度确认确定地放入六个月窗口。若主要合同/器件确认推迟到此后，六个月相对三个月的吸引力改善会消失，长期价值还要扣递延和额外投入。

### 11.4 12—18个月与3—5年的校准

研究日后12—18个月（2027-09-08—2028-03-07）恰为 E+F：基准收入约 **0.07—0.90**，乐观 **1.50—8.00**，突破 **8—25** 百万美元。它用于检验“2027H2生产”究竟只是试产、首个有限收入，还是足以改变规模的运行提成。这个窗口的经营不能当作2027-03-07已经实现；如果客户较早披露不可取消采购和可复用工艺，信息可以提前进入估值。

3—5年校准由第三节2029—2031完整量价、费用、税和净投入构成；2029—2030处于该窗口内。为统一使用完整年度现金流，终值辅助端点取2031年12月31日，距研究日约5.32年，比严格五年晚约四个月；这一辅助延伸对所有经营行一致，未延长六个月主矩阵目标期。基准不是永远停在0.1收入：它允许从工程转到20—50的年收入，同时计算费用收缩和再投资后2—10 FCF。乐观和突破则允许高经营杠杆，但要与行业上行池、交付单元、净收费和股本一起成立。若今后采用量只有10百万PIC、单位净费2美元，即使技术全部可用，20收入仍更接近基准，并不足以为现价提供现金流支撑。

改变本方法判断的充分方向条件是：**经营低端被客户证据显著抬升，同时价格/资本成本不继续透支**。在本矩阵参数保持时，突破宽基/主题的首次正面价格约3.75，震荡约2.65；当前基准仅价格变化的门槛是0.19/0.17。它们针对不同经营条件，不可互换为“分批买点”。

## 附录：二十格的可复算数值底稿

以下仅依赖Python标准库，使用本文同一参数输出20格EV、股权、每股、回报和转正边界；不读取其他报告、不联网、不写文件。2027年以前的现金流已进入目标日现金，不在EV再次扣除；同一行参数在五列保持不变。实际显示保留两位小数，计算使用未取整数。


```python
import math
from datetime import date

P0 = 5.35
u = (date(2027,12,31)-date(2027,3,7)).days/365
markets = [["宽基风险扩张",[0.12,0.16],[22,28]],["窄幅/主题主导上涨",[0.11,0.16],[24,32]],["震荡/均值回归",[0.16,0.2],[18,23]],["有序风险收缩",[0.21,0.26],[14,18]],["流动性/信用压力",[0.28,0.36],[9,13]]]
rows = [{"name":"悲观/受损","cash":[73,79],"shares":[164,168],"fcf":[[-24,-24,-18,-10,-3],[-20,-20,-14,-8,-2]],"terminal":[0,0],"g":[0,0]},{"name":"基准/正常兑现","cash":[72,80],"shares":[164,168],"fcf":[[-24,-22,-16,-8,2],[-24,-20,-10,0,10]],"terminal":[2,10],"g":[0,0.02]},{"name":"乐观/超预期","cash":[68,78],"shares":[165,171],"fcf":[[-28,-20,-5,8,22],[-25,-12,8,28,50]],"terminal":[22,50],"g":[0.02,0.04]},{"name":"突破/非线性","cash":[60,74],"shares":[167,175],"fcf":[[-32,-18,15,45,78],[-30,-8,35,85,145]],"terminal":[78,145],"g":[0.03,0.05]}]

def value(row, market, end, use_exit=False):
    r = market[1][0 if end else 1]
    total = 0.0
    for k, annual_fcf in enumerate(row["fcf"][end]):
        fcf = annual_fcf * (u if k == 0 else 1)
        discount = .048 if fcf < 0 else r
        total += fcf/(1+discount)**(u+k)
    g = row["g"][end]
    multiple = market[2][end] if use_exit else (1+g)/(r-g)
    total += row["terminal"][end]*multiple/(1+r)**(u+4)
    return total

cells = []
for row in rows:
    for market in markets:
        ev = [value(row,market,k) for k in (0,1)]
        equity = [max(0,ev[k]+row["cash"][k]) for k in (0,1)]
        price = [equity[0]/row["shares"][1],equity[1]/row["shares"][0]]
        ret = [x/P0-1 for x in price]
        positive_price = min(sum(price)/2/1.25,price[0]/.60,price[1]/1.50)
        assert ev[0] <= ev[1] and price[0] <= price[1]
        cells.append((row["name"],market[0],ev,equity,price,ret,positive_price))
assert len(cells) == 20
assert sum(P0 <= c[-1] for c in cells) == 0
for c in cells:
    print(c)
```
