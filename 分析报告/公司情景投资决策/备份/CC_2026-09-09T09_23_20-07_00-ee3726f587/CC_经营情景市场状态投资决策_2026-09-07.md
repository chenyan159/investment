#### 3.3.1 状态、时间衔接和成本规则

U=未形成重复商业收入（包含验证延期）；P=有限持续销售；S=规模持续销售；F=退出。F为吸收态、不能回生；S可退到P或F。**表内是当年仍处于该状态的概率，既不是当年首次成功率，也不是累计曾成功率。** 首次P/S之后的下一年销售由转移继续计入，不每年重新从零打一次最终成功折扣。突破只把2027冷却P态确定化，不把2028以后S态确定化。

冷却每年转移矩阵按行U/P/S/F、列U/P/S/F：悲观 `[.45,.10,0,.45; 0,.65,.05,.30; 0,.10,.70,.20; 0,0,0,1]`；基准 `[.55,.30,.05,.10; 0,.72,.15,.13; 0,.08,.88,.04; 0,0,0,1]`；乐观 `[.30,.50,.12,.08; 0,.55,.38,.07; 0,.04,.94,.02; 0,0,0,1]`；突破2027为`[0,1,0,0]`，此后P转`[0,.35,.60,.05]`、S转`[0,.03,.95,.02]`、F不动。电化学悲观用悲观矩阵；基准U/P/S转移分别`[.70,.18,.02,.10] / [0,.78,.10,.12] / [0,.10,.85,.05]`；乐观和突破为`[.60,.28,.04,.08] / [0,.73,.18,.09] / [0,.06,.91,.03]`。

这些是**有机制约束、未经过历史样本校准的主观工作概率**。设备资格和供应商投入支持基准2027至少形成P/S的35%，不足以支持80%；用途许可和持续订单缺口也不足以断言0%。基准冷却到2031仍S约24.8%，体现多层采用摩擦和客户退出；乐观更快扩量是因为客户复用成功、预算可持续，而非统一乘概率系数。年份推进本身不带来确定性：2036的成功存续概率可以低于2031，F累计上升。

每个状态内先算成本：冷却U/P/S EBITDA为`−8 / 30%×P收入−12 / 42%×S收入−25`；电化学为`−3 / 30%×P收入−4 / 42%×S收入−10`。这些固定项涵盖专属研发、支持和商务费用；失败当年另付8/4×当年新增F概率，后续已退出不再付同一失败费。CapEx分别为U态2/1，P态`8%收入＋2/1`，S态`10%收入＋2/1`。P/S D&A=4%收入；现金税为各状态`22%×max(EBITDA−D&A,0)`，损失不假定即时税退款；净营运资金为收入的12%。先权重EBITDA、税和CapEx，再扣连续存量变化；这与对期望收入直接套成功后利润率不同。

前期U支出按仍在研发的状态发生，未乘最终成功概率；已承诺供应合作成本在CapEx和失败费预算内。2026已有新应用费用保留在共同/近期经营，2027起另列的是相对既有基础研发的新增专属预算，2026已有基础研发仍留在核心利润率内，避免把同一研发扣两次。核心947是本研究的核心工作锚；扣新增预算后集团约935，相对上游集团947约保守12，并非声称两者仅是同口径会计重分类。制造成本包含合同加工费；NFIL自行承担的工厂投资不再作为CC全额CapEx。未来额外采购保底若超过失败费，应按实际条款增补，属于尚未消除的尾部风险。

### 4.2 估值选择与要求回报

**事先适用的风险补偿规则：** 6个月主修复策略要求约12%总回报，并需要窗口内信息可验证；12个月要求约25%；36个月现金能力策略要求约18%年化，即三年累计64.3%。这不是统计预测、国债收益率或精确资本成本，而是针对近8%新债融资成本、业务周期和普通股尾部损失所要求的研究门槛。稳健现金投资者会额外要求在现金法保守参数下有余量；高风险修复投资者可以承受更宽回撤，但不能因最大上行很大就认定正期望。门槛不重复乘进已经概率加权的新业务收入或法律现金。

6/12个月：主方法是**核心经营前瞻EV/调整后EBITDA＋早期项目净现值**。悲观4.5—6倍，基准6.25—7.75倍，乐观6.5—8倍，突破7—8.5倍。倍数差异来自核心盈利稳定性、资本转换及增长持续期，均不包含另列新机会。区间不是实时同业中位数：基准约45%—55%的可持续税后未杠杆现金转换，配合约7%—9%净折现差，支持约5—8倍的机制范围；采用6.25—7.75仍需要周期修复被认可，下面用完整现金法检验它是否过于宽松。未核到同日期同会计口径的一致预期和可比公司EV表，因此不以来源模糊的“行业平均8倍”裁决。

36个月：主方法改为**目标日剩余核心FCFF折现＋早期项目净现值**。核心2027—2036经营由同一底稿延续；FCFF＝(核心EBITDA−核心D&A)×76%＋D&A−全部核心CapEx−核心Δ周转。使用规范化24%现金税，持续SBC保留经济成本，不将CFO加回当永久免费收益。报告现金税是在利息后的现金负担，FCFF则对扣利息前的经营利润规范化计税；两者差额主要含融资税盾，不能全部冒称未计税损资产再加回，WACC已反映融资结构。剩余地域/税损差异未取得完整可用凭证，规范化口径不把它永久资本化。核心贴现率10.5%—12.5%；终值g基准/乐观/突破2%、悲观0%，增量ROIC9%—12%，终值FCFF＝NOPAT×(1−g/ROIC)，替换资本和成长资金相容。债务新融资约8%提供资本成本底部参考，但这些WACC是模型参数，不是市场观测精确点值。

早期机会用2027—2036状态内现金的期望值逐年折现，区间13%—10%，终值增2%。2037正常现金＝次年EBITDA−22%×max(EBITDA−4%收入,0)−4%收入−0.65×2%×收入−12%×2%×收入；后两项为成长固定资本与新增周转。0.65是固定资本／收入工作比，非CC已披露资产周转率。失败概率已在现金中，不再给NPV乘一遍成功率。折现率仅补偿等待和未入状态表的共同市场风险；主区间未将每种毒理/法律失效再额外罚分。

目标日估值均只计**该日后**剩余现金；所在自然年按实际剩余天数计入、现金保守放在年末。目标日前现金已进入现金／净债务。12/36个月目标日不等于年底，不拿全年现金重复加进余额。日内资本插值和年末现金支付是估值近似，事件真实集中到期时应按交易时点重算。

三年退出可以保留2032—2036及终值的剩余机会，但只用今天信息对应的届时状态分布。没有新信息时，概率不会因到了2029而变成100%。新的客户认证可能改变届时分布，本报告从当前视角权重这些信息结果；主格不是全成功价值。凡已计早期NPV的利润均从核心倍数和核心DCF排除，避免双计。

### 4.4 三种期限各自的实现路径

**3个月：等待价值较高。** 可看到Q3提价兑现、NFIL投运目标是否实现、许可期限和循环承诺缩减。即使Q3达190，只证明一个季度，尚不能证明全年FCF219和2027全年盈利935。新技术资格可能先重估，但缺净价、吨数和重复采购，不能由新闻标题给涨幅。当前3个月判断与6个月均中性，理由不同：3个月证据不足，6个月则证据可能更完整但主要修复工作回报约12%，优势很薄。若到12月已有Q3现金≥50、TT≥70且无新增重大责任，3个月可以向谨慎切换；若只发合作公告不披露部署，则不切换。

**6个月：FY26和2027指引确认窗口。** 最可能改变风险认识的是全年净债务接近3,000、现金目标真实实现、2027指引支持900以上且APM稳定。价值不是把三年目标折成六分之一，而是市场重新估计未来利润持续期。好消息不涨的机制包括市场此前已要求更高利润、H1渠道补货不持续、法律现金再次吞噬收益。缺乏可辩护的投资者采纳模型，因此“可能交易回报”记NA，主矩阵只给条件合理价值回报；不会将合理价值机械等同于半年实际股价。

**12个月：谨慎经营修复。** 两次旺季与连续APM交付可排除“一次性释放库存”解释。基准2027约935 EBITDA、137 FCF，2028进一步约1015/212，预计目标日核心NTM约1000。回报来源以盈利持续性被认可为主，去杠杆其次，早期业务现金尚不能主导。若EBITDA达到900以上却FCF不足100、净债务仍超过3,100，倍数支撑会下降，谨慎正面翻为等待/不建议。等待的代价是财报前就被重估到19以上，但未证实采纳概率，不能称提前买入一定占优。

**36个月：现金能力仍不能完全支持现价要求回报。** 基准2029收入约6817、EBITDA约1096、FCF约287，确有改善；但不是足以无条件支撑稳健复利的自由现金。核心材料优势面对多供、专利周期、合规和资本更新，三年后还需投入。DCF基准13.76—23.76，对应年化约−1.3%至17.3%，连高端也未达到本报告18%要求，因此当前长期中性。周期投资者若相信市场长期保持较高EBITDA倍数，可得不同的谨慎正面判断，但那是利润持续性与资本寿命假设的分歧。突破冷却及高纯新材料确有巨大条件价值，现有证据尚不能令它成为当前完整主路径。

### 7.2 精简复算附件

以下公式和第3节参数足以复原矩阵，内部运算保留未舍入数，正文显示1—2位：

```text
核心收入 = Opteon + Freon + TSS其他 + TT + APM-AM + APM-PS + 其他
核心EBITDA = TSS收入*mTSS + TT收入*mTT + APM收入*mAPM + 其他利润 - 总部
年度状态分布 p[t] = p[t-1] * 转移矩阵
早期E收入[t] = Σ p[t,k]*收入[t,k]
早期E EBITDA[t] = Σ p[t,k]*状态EBITDA[t,k] - 新增F概率*一次退出费
早期E现金[t] = E EBITDA - E现金税 - E全部CapEx - 12%*(E收入[t]-E收入[t-1])
集团EBITDA = 核心EBITDA + 两项早期E EBITDA
报告型FCF = EBITDA + SBC - 现金利息 - 现金税 - 责任付款 - Δ周转 - 全部CapEx
期末净债务 = 期初净债务 - FCF + 公司分红 - 税后资产处置 - 股权融资净额
新增普通股 = 实际股份报酬发行 + 股权融资净额/发行价
目标日NTM = Σ 每季度经营流量 * 与[目标日,目标日+1年)重叠天数/季度天数
净责任PV = Σ 目标日后非受限现金净责任付款 / 1.08^剩余年数
6/12个月经营价值 = 核心NTM EBITDA*核心倍数 + 两项项目剩余NPV
36个月经营价值 = 核心剩余FCFF DCF + 两项项目剩余NPV
股权价值 = max(0, 经营价值 + 非受限现金 - 债务 - 剩余净责任PV)
每股价值 = 股权价值 / 目标日完全稀释股数
累计回报 = (每股价值 + 有权取得且实际在窗口支付的现金股利)/15.30 - 1
36个月年化财富回报 = (1+累计回报)^(1/3)-1
```

年度核心D&A：2027悲观340、基准350、乐观355、突破360，之后每年+0/+5/+10/+15，另加状态内新项目D&A；2026Q3/Q4各85。核心CapEx递增规则及利息、税、SBC、周转规则见3.4—3.5。核心其他收益和租赁不额外加资产；资本桥使用本金口径，与现金一致。2026H1 GAAP事实与下半年现金预算不能因情景改写。
