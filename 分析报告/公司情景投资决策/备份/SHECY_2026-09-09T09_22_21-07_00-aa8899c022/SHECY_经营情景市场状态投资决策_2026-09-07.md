### 2.2 财务质量与股东索取权

FY3/2026经营现金流712.651，固定/无形资产现金购买355.950，自由现金流356.701；现金分红203.162与回购500.006合计703.168，明显高于当年FCF，并伴随230.010长期借款流入。**回购提高EPS不等于经营产生同量现金。** 最近季度130.7的经营现金流和90.5现金CapEx仅为公司附录的非正式现金表，不能称完整季度审计现金流。经营现金流包含现金税与收息时差，季度FCF40.2不能简单年化。[F01][F03]

FY3/2026现金及存款约1,660，6月底1,654.2，而现金等价物仅457.8。定期存款是可到期金融储备，期限变化不等于经济损失，也不能全部视作即刻母公司自由现金。6月底应收572.5、库存769.0、应付168.0；没有足够产品库存库龄与可取消采购数据来证明不存在积压。年度净利润含非控制权益31.830；合并子公司和上市信越聚合物的经济权益不能全归母公司。[F01][F03]

本模型不把经常利息、证券出售收益或重组损益混成核心利润。年度利息收入62.927、证券出售收益10.572及重组费用10.365说明非经营项存在；核心企业价值采用营业利润现金桥，现金与可变现证券在资本桥处理。正常研发和持续股权报酬留在费用，不无限加回“调整后利润”。[F03]

治理与失败风险首先看实际资本配置：伊势崎第一期按期投运支持工程执行，设备验收延迟和原料业务重组也提供反例。客户集中度、逐项长约取消权、QST许可费率和排他性未充分披露，列为未知，不能宣称全部合同take-or-pay或技术独占。日本及美国生产缓冲部分地缘风险，但自然灾害、能源/海运、贸易措施、重稀土许可及化工安全可同时影响合格交付与现金；本报告没有证据支持当前生存危机。

### 3.2 产品驱动如何约束分部预测

由于公司未公开完整产品收入、片数、ASP和产品毛利，本报告以可复核分部为金额锚，以产品指数作约束，**不伪造可以精确加总的产品收入事实**。工作基期电子销售构成仅用于检验相容性：硅片55%、光刻及掩模相关22%、磁体/石英/预制棒等23%；合理替代权重为45%～65%、15%～30%、余项补足100%，各权重是E而非披露。

对FY3/2029电子收入，基准硅片量1.25×净价1.02、光刻相关净销售1.60、余项1.50，得到加权指数1.419，与分部1450/1015.765＝1.428接近；误差约0.6%可由具体组合解释。乐观用1.35×1.05、1.90、1.70得到1.589，接近1640/1015.765＝1.615；突破需1.45×1.10、2.25、1.95得到1.821，接近1850/1015.765＝1.821。**突破要求远高于仅硅片面积增长的结果**，更多收入必须来自光刻层次/资格/组合，而不是凭空扩大行业面积。悲观约1.05×0.94、1.20、1.05得到1.048，与1070/1015.765＝1.053相容。

净单价含规格组合，不意味着全部原硅片涨价10%。份额扩张需要客户认证、交付和新增资本；基准不假设全球硅片份额显著增加。将光刻基期权重从22%降至15%、差额给硅片，而其他驱动不动，会使基准电子收入约少23，营业利润少约8；这个识别误差有影响，但小于PVC净价差和长期资本效率的误差。

### 3.8 联合早期机会群的逐年状态与现金

为避免共享客户预算、衬底设备、技术人员和材料替代造成独立概率误加，机会`i`定义为**新衬底与封装工艺联合项目群**。它不是三项独立赌注之和。状态为U=尚未规模商业化，L=有限/部分成功，S=达到当年规模商业采用，F=放弃该批商业计划；这是**当年仍处于某状态的概率**，不是累计曾成功概率。S可退回L，F吸收、不会无条件复活；其他尚未定义新一代项目不因原计划失败而被永久判零。

以研究起点p=(1,0,0,0)，每年`p_t=p_(t−1)×M_s`。未来FY3/2027的S=0，FY3/2028以后才可能规模成功；规模定义随年份由小规模重复采用逐渐扩大，状态年内收入是当年收入，不是最终市场空间。四行不另配置总体发生概率。

### 4.4 估值方法：同一现金路径在各目标日重估

### 4.5 同期限的理念分歧与反向检验

**M2：前瞻归母盈利的直接股权资本化。** 保持目标日与基准NTM利润不变，使用18～24倍作为理念压力范围；18倍接近盈利收益率5.6%，24倍约4.2%。18～20倍需要核心恢复后现金转化正常；22～24倍需要再投资保持高回报、利润持续增长约7%～9%至少十年并有稳定客户资格，或者较低的股东要求回报。公司历史材料技术壁垒支持研究这种理念，但PVC周期及Shintech回报未知使上沿不能作为主估值。它是股权整体倍数，已包含净财务收益和现金配置预期，**不再加现金、不另扣债务/少数权益**。

倍数不是“同业目标价平均”；没有使用任何同业评级。其经济含义可用`P/E=(1−增长/增量ROE)/(股东要求回报−增长)`做稳态反向筛查：例如增量ROE20%、增长6%、要求回报9.5%，约20倍；要求回报提高至11%、增长仍6%，仅14倍。这不是把6%永久增长当作本报告DCF终值；它解释为什么20～24倍包含很长持续期或较低风险补偿。将暂时周期峰值利润也资本化为同样倍数会高估。

## 六、当前选择、稳健性与等待的价值

### 6.1 当前路径不对四行强配概率

电子材料已实现改善，PVC地域分化，技术资格与规模已有基础，因而采用基准而非悲观作为比较锚点；但其与乐观之间尚有净价和资本效率的实质证据缺口。四行不是互斥且完整的所有未来结果，也无法从行业报告校准整股概率，因此没有强配25%/50%等权重、没有制造P50或精确胜率。条件回报大的格子不等于当前更可能的格子。

本报告以全部现金法保留三个期限的“中性/等待”，同时明确长期复利理念可在更强客户/回报条件下提前小规模承担风险。等待并非零代价：若下次财报同时确认量价、现金并使价格跃升至乐观区间，会错过部分上涨；但若只是继续满足已知指引，付更高价格没有信息优势。

### 6.2 最接近当前路径的普通不及预期

不是灾难情景：基准电子收入各年少5%、营业利润率少1个百分点；PVC所在基础设施营业率少3个百分点；前四年核心现金CapEx多30/年。它表达客户放量稍慢、可保留净价较低和付款先于回款，变量互相相容。其他核心业务、税、股数和终值方法不变。因这是从研究日出发的前瞻偏差，已披露Q1仍通过季度桥固定，不改写历史实绩。

        ev+=q['fcff']*w/(1+r)**((mid-t).days/365.25)
    a=annual(d)[-1];tv=a['op']*.72*(1+g)*(1-g/roc)/(r-g)
    pv=tv/(1+r)**((END-t).days/365.25) if terminal else 0
    c=capital(d,t);eq=ev+pv+c['bridge'];p=eq/SH/(2*FX)
    return dict(p=p,eq=eq,ev=ev+pv,tvshare=pv/(ev+pv),ret=(p+c['dist'])/P0-1,dist=c['dist'],**{k:v for k,v in c.items() if k!='dist'})
def summary():

        print(n,'today',[(round(value(d,T0,r,g)['p'],2)) for r,g in [(d['wacc'][1],d['g'][0]),(sum(d['wacc'])/2,sum(d['g'])/2),(d['wacc'][0],d['g'][1])]])

            print(t,[(round(x['p'],2),round(x['ret']*100,1)) for x in [lo,mid,hi]],'cash',round(mid['cash']),'TV',round(mid['tvshare']*100))
        print('annual',[(a['year'],round(a['r']),round(a['op']),round(a['fcff'])) for a in annual(d)[:5]])
if __name__=='__main__':summary()
