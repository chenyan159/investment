# SpaceX：经营情景、价值传导与分期限投资决策

目标公司标识：SPACEX；实际证券：Space Exploration Technologies Corp. A类普通股，Nasdaq / Nasdaq Texas：SPCX。输出日期：2026-09-08。

## 一、当前选择、研究时点与主要限制

**当前选择：短期不建议投资；中期不建议投资；长期在稳健复利理念下不建议投资，在高风险技术与平台突破理念下中性／等待。**这里评价的是以147.95美元取得集团普通股。Starlink的经营优势、AI的真实需求和现价是否值得支付，是三个不同问题。

- **3个月，2026-12-08：不建议投资。**主要理念是里程碑与预期差。Q3结果、Cursor供模变化和分批解禁可能带来显著价格变化，但从8月初低点起的反弹已支付了一部分改善预期；没有足够证据估计新增好消息的交易采纳程度。最强相反选择是提前买入Starship与AI产品事件，其缺口在于“值得关注”尚不能证明147.95美元有价格优势。
- **6个月，2027-03-08：不建议投资。**将有机会观察Q4收入、续期及现金转换，也更可能识别Cursor整合的净效果。基准条件合理价值约14—24美元，乐观约60—104美元，均不足以支持现价。突破路径约109—211美元，但它要求比“Starlink继续增长”多得多的商业成功；这不是对未来半年交易价格的预测。
- **12个月，2027-09-08：不建议投资。**主要理念是经营兑现与再投资回报。现有云合同和网络扩张支持收入提高，却不能把短期算力租金长期化。基准价值约15—25美元，普通不及预期会同时提高融资需求；更高收入而更低现金余额是模型的正常结果。只有资本支出转向可验证的高回报、客户续期与净收费得到证实，才应提高估值。
- **36个月，2029-09-08：稳健理念不建议投资；高风险理念中性／等待。**基准约19—31美元，乐观约77—125美元；突破约135—245美元，累计约−9%至+66%、年化约−3%至+18%。突破经营本身很强，但在本研究20%年化的高风险要求下，主要参数仍缺少余量。将要求降至15%会让突破上端具备参与价值，工作参数对应约178美元、约6%年化，尚不能据上端作当前正面建议。

**真正的分歧在利润持续性、成长成本及资本配置。**当前约2.0万亿美元的基础股权价格，已经远超只靠可见网络利润和一轮GPU合同能解释的规模。长期多头可以合理地认为SpaceX将同时成为全球连接平台和高利润AI应用平台；本报告没有把这些可能性设为零，而是把它们拆成付费数量、净收费、交付、再投资及行内状态概率。当前最难跨越的是：巨大新增资本能否产生持续自由现金，以及少数股东是否保留足够的每股权益。

**数值是研究条件值，不是市场一致目标价。**模型较高的基准现金消耗和十年以上持续期使估值对资本回报极敏感；报告不能据此保证股价将向14—24美元回落。安全边际判断与短期做空判断没有等号。亦未为完整四行情景强配发生权重或制造整股胜率。

**上游采用与拒绝。**商业航天报告[L2]用于约束合格外部任务及可售区域容量，不将686B“太空经济”作为火箭收入。NeoCloud报告[L3]用于检验GPU时间、利用率、租约及更新，基准15B对外云收入已经占其2027独立运营池的较大部分，故没有额外套行业高端增速。企业Agent报告[L4]支持真实付费与责任边界；其2028全球应用基准约76B不能全部分给SpaceX，突破所需数千亿美元新Agent收入必须依赖2030年代市场进一步扩大。广告报告[L5]只提供广告预算与流量变现机制。上述行业预测彼此存在云—模型—应用的上下游支付关系，未将其总量相加。

管理层的快建纪录、Starlink财务和客户侧算力声明分别支持工程、利润和需求，不能把三个维度合成“所有新业务必然成功”。相同预测由不同媒体重复转述不增加证据权重。

### 2.4 尚不可金额化的重大机会

Terafab及自研芯片可能节省采购并改善供给，进入门槛是实际IP／权益、合格良率、资本上限、全成本与合作分配。每年20B可替代采购若净节省15%，制造前节约约3B；若新增投资30B，仅此节约即对应10年简单回收，尚未扣研发和合作分成，不能称高IRR。没有最终投资权益与合格单位成本，主模型不记外售收入；核心研发与可选资本预算容纳早期探索，若宣布额外大型工厂必须新增扣款。

月面物流及NASA运输按已有任务计入Space；民用火星城市、地球点对点客运、月面制造等没有足以界定商业支付与资本回报的合同，保留进入条件和潜在研发损失，未为它们强配收入或整体成功概率。这限定了本报告覆盖：**现价缺少本模型支持，不等于所有尚未定义的远期价值都已被证明不存在。**

轨道热与资本约束提供一个可复核门槛：1MW地面IT负载、PUE1.2、电价60美元/MWh，每年电费约0.631M；五年约3.15M。若轨道系统10—30吨/MW、运价200—1,000美元/kg，仅发射就需2—30M/MW，另有计算、电源、散热与替换。参数为工程压力算例，不是公司披露设计。轨道路线需要显著更低总质量／运价、缩短客户等待或高价值特殊任务，才能取得相对于地面的收费优势。[L1][E10]

融资断点的决定因素目前主要是**已经规划的核心建设**，不是小规模轨道试验。即使早期机会全部成功或全部失败，Y3融资仍分别处于约6—12B、26—35B、42—57B范围。假设三年发行价减半，新增权益数量及报酬稀释增大，但本任务最主要的风险仍是长期现金回报不够，而非单纯短期支付不了债。

### 3.6 早期机会：逐年状态、联合路径与期望贡献

定义U＝尚未商业化，P＝有限／部分成功，S＝规模成功，F＝失败／退出。它们为同一年互斥状态，概率合计100%。Mobile已存在基本商业服务，起点在P；轨道计算和新增跨职能Agent从U起步。Starship的部署能力是情景共同前提及约束，不再作为一个重复收入机会独立相加。

每年状态转移如下，F为吸收态：

- U→P概率a，U→F概率b，余下留U；
- P→S概率c，P→F概率d，余下留P；
- S→P概率e，S→F概率f，余下留S。

### 4.4 主估值方法、终值与风险处理

主方法为分业务经营驱动形成的FCFF、目标日剩余DCF，再经过现金／债务／其他索取权与完全稀释股数。原因是集团当前混合早期研发、前置设备更新、现有盈利网络和亏损应用；统一当前PE或EBITDA倍数会把费用与资本寿命差别藏掉。

核心FCFF＝EBIT−现金税＋D&A−全部CapEx−营运资本增量。早期业务先在状态内计算相同桥再加权。目标日只折现其后现金；之前经营现金、SBC和融资进入真实资本桥，分红为0。未来固定频谱现金尚未支付时另折现扣除，权益对价计分母，不再按历史收购价另扣一笔。

r为名义美元经营资本要求、不是给早期成功概率再打折；成功失败已经在现金状态里，r补偿时间价值、宏观风险和未独立列出的资本价格不确定性。参数为研究者经济要求，没有伪称精确市场WACC。以4%现金机会成本算例加成熟权益与较大系统性风险补偿，可以理解9.5%—13%的选择；4%只是比较假设，不是声称核验了当日国债成交收益率。

TV15＝EBIT15×(1＋g)×78%×(1−g/ROIC)÷(r−g)。

### 4.5 同一经营路径下的工具与理念交叉检验

当前完全稀释价格对应约2,102B股权，加39.5B债务、减88B研究现金，约2,054B经营价值。若这是立即进入稳定期、r10%、g3%、ROIC20%的公司，则需约144B稳定FCFF、约169B税后经营收益、约217B EBIT；30%经营利润率意味着约723B年收入。**这是现价相容组合，不是市场真实一致预期**，且未付出的成长建设会让实际需要更高。

基准Y3集团收入约84B、EBIT约11B，与这个反向门槛相距很远；突破Y10收入已超1,000B、EBIT逾400B，才开始在部分参数下支撑现价。这不是认为所有投资者都按2036财报定价，而是说明现在支付的远期权益要求。

若只看Starlink／Connectivity，基准Y3非Mobile收入约31.4B、EBIT约11.6B；将其作为独立高增长网络给25—35倍税后经营收益，可形成约226—317B的经营价值参照。但集团还有AI与研发资金需求，不能用这个参照加上已经含相同网络现金的DCF。这个网络价值也非清算底价，出售限制、税、债务划分和控制股东决定会改变可实现额。

“网络单独上市或严格止损AI”属于资本配置修复论点：它可能提高悲观路径下普通股残值，主悲观值约1—2美元并非Starlink单独出售估值。假设能实现150—250B净经营资产回收、扣全部优先索取权与退出支出后，即使留下100—200B股权，也只有每股约7—14美元量级。没有已授权出售／分拆计划，不把此路径加入主格；它说明悲观主模型包含持续资金消耗，并不声称卫星网络没有价值。

没有采用同业最终评级、目标价或行业排名。公司结构没有直接可比，未取得同一截止、同一分部口径的完整市场一致预期，故Forward PE及一致预期偏离幅度为NA。可复核的原始经营比较来自客户及行业上游：NeoCloud设备租约不能等同高利润软件，通信网络不能套纯航天制造倍数，Cursor的席位与用量不能套全企业软件预算。

### 6.2 普通不及预期、独立新机会与完整成功参照

不是只拿极端受损反驳投资。与基准最接近的一条普通偏差：平均服务线少10%、ARPU再少3美元、云收入少15%，且前三年每年多10B核心CapEx，其余路径不变。该组合表示地区扩张较难、云价格让利及设备先付款，并非世界末日。三年条件值约16.6—27.1美元，累计融资约43.7B，股数约15.44B；基准对应19—31美元、约10B融资。它使现金问题明显提前，而对当前价格的负面选择保持稳定。

“新机会成功，核心普通”的独立贡献检验：保留基准全部核心经营及其他机会，仅把新增Agent采用机制与条件规模换成突破参数。三年价值约48.7—75.1美元。新工作流可以创造大量额外价值，但单独这一个机会仍不足以支撑147.95美元及要求回报；主突破因此需要网络／现有AI规模和新Agent共同成立，而不要求火星或Terafab也成功。

再看极端完整成功上行参照：保持突破各年状态收入与成本尺度，取消三项机会的后续失败与升级等待、都按S态计算。三年价值约150.6—274.2美元。它是人为的充分成功参照，早期工程全部顺利、资本正常化也顺利，不能代替主格已加权135—245美元。按147.95美元买入，高端约85%累计、23%年化，的确存在足够高风险回报；但这还不是所有合理条件下都具有优势。

### 6.3 最决定性的反向门槛

突破工作估值参数r10.5%、g4%、成熟ROIC26%，保持同一经营与资本路径，三年约177.6美元、累计约20%、年化约6.3%。这是选择经济参数得到的工作锚，不是区间中点。

在147.95美元买入并要求20%年化，三年目标需255.66美元。只提高新增Agent的条件规模、并同步按同一状态经济性增加成本和投入，所需规模系数约3.65，较突破原1.5约2.43倍；对应Y10规模态新增收入约729B，而原突破为300B。按4,000美元年净增预算，需要约1.82亿等价工作预算。现有证据支持付费助手和部分生产编码，但不足以支持这一级净增工作付费作为主要判断；不能把工资总额或免费使用量转成收费依据。

此门槛并不意味着唯有Agent可解决差额。更低资本消耗、更高网络净价、更长超额利润持续期或其他尚未定义的机会也可改变价值，但必须组成经济相容的组合。反向值用于识别当前价格的要求，没有将它回写为研究预测。

1. 数据节点小数只为了复算；评估精度为数量级和条件范围。
2. 资本表逐季融资，普通股价值设零下限；未来无条件债务融资未被假设为免费可得。

function early(o,index,val){
let prob=o.start.slice(),prevFail=0,out=[];
let [a,b,c,d,e,f]=o.params[index],m=o.mult[index];
for(let t=1;t<=10;t++){
 const [u,p,s,z]=prob;prob=[u*(1-a-b),u*a+p*(1-c-d)+s*e,p*c+s*(1-e-f),z+u*b+p*d+s*f];
 let rp=val(o.p,t)*m,rs=val(o.s,t)*m;
 const state=(r,k)=>{let gp=r*o.gm[k],ebit=gp-r*o.op[k],da=r*o.da[k],cap=r*o.cap[k],wc=r*o.wc,tax=Math.max(ebit,0)*.22;return {r,gp,ebit,da,cap,wc,tax,fc:ebit-tax+da-cap-wc}};
 let P=state(rp,0),S=state(rs,1),newFail=prob[3]-prevFail;prevFail=prob[3];
 let row={t,prob:prob.slice(),rp,rs,r:prob[1]*rp+prob[2]*rs};
 for(let k of ["gp","ebit","da","cap","wc","tax","fc"])row[k]=prob[1]*P[k]+prob[2]*S[k];
 const pre=o.pre*m*prob[0],failure=o.exit*m*newFail;
 row.ebit-=pre+failure;row.fc-=pre+failure;row.pre=pre;row.failure=failure;
 out.push(row);
}
return out;}
