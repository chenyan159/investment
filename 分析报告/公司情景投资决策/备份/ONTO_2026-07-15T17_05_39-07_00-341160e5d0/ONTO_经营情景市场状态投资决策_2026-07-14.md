## 二、当前条件定位与矩阵摘要

> **当前条件定位：** 当前证据指向“**基准收入与利润率、悲观现金转换、基准资本结构与长期增长**”的复合经营定位，当前市场主状态为“**宽基风险扩张**”，相邻状态为“**震荡 / 均值回归**”；复合定位 × 当前主状态的条件建议为 **不建议投资**，稀释后市值 **$11.7bn–$16.2bn**、每股价值 **$233–$325**、目标期总回报 **-23%～+7%**。经营与市场状态证据强度均为 **中**，估值置信度为 **中低**。相邻市场状态下仍为 **不建议投资**，每股价值 **$197–$285**、回报 **-35%～-6%**；最接近的纯格子“基准 × 宽基风险扩张”为 **中性 / 等待｜-17%～+24%｜中**。最小增强条件是 G5 或 Atlas 出现新增客户 / 多站点 copy order，且 NTM FCF 提升至至少 $360m；最小减弱条件是 Q2 收入低于 $320m、non-GAAP 毛利率明显低于 56%，或 VPA / backlog 延迟与营运资本恶化同时出现。概率层 **NA**：缺少可辩护的经营—市场联合基础率，不能用主观概率替代条件矩阵。

## 三、核心投资逻辑与最强反证

### 3.1 最强正面逻辑

ONTO 的增长不是只靠 AI 主题映射。G5 已在 HBM4 和领先 2.5D 客户完成资格，3Di 已在两家主要 HBM 客户通过认证；>$240m VPA、双位数订单、Atlas 第二家 GAA 客户、Q2 指引和约 $2bn 年化制造能力共同构成 A/B 级收入传导。行业侧，HBM4、GAA、先进 DRAM 和大尺寸 2.5D 同时提高量测层数、采样密度和单次漏检损失，检测量测强度有望快于一般 WFE。[项目内公司调研](../../../公司调研/封测_检测_计量_光罩/ONTO_Onto_Innovation_公司调研_2026-07-12.md)与[半导体检测量测设备行业报告](../../../行业调研/晶圆制造_设备_材料_测试/行业调研_半导体检测量测设备_2026-07-10.md)提供了产品、订单与行业交叉证据。

### 3.2 最强负面逻辑

当前价格并非只要求 2026 指引达标。按基准 NTM 收入和营业利润计算，当前经营性 EV 已约为 8.9–9.8 倍收入、27.8–33.2 倍调整后营业利润；若还要求 15%–20% 的持有期回报，基准经营必须在目标日继续获得约 11 倍收入或 32–36 倍营业利润的高端定价。五年 DCF 更严格：即使 WACC 仅 8.5%、正常化 FCF margin 达 28%，仍需约 20% 收入 CAGR 才能支持当前经营性 EV。Q1 弱现金转换、客户集中、精密光学交期和 $710m Rigaku 资本配置使这种长期要求缺少足够冗余。

### 3.3 决定胜负的变量

最重要的经营变量是 **Dragonfly G5 / 3Di 与 Atlas G6 的收入化速度能否在不牺牲现金转换的情况下持续**；最重要的市场变量是 **美国 10 年期收益率与半导体风险溢价是否允许 ONTO 在基准兑现时继续获得约 30 倍以上营业利润倍数**。收入达标但库存、应收和早期产品支持成本继续吞噬现金，仍会维持当前复合定位；现金改善但 G5 / Atlas 未形成多客户复制，也只够回到纯基准，不足以进入乐观。

- 悲观经营即使收入仍高于当前 TTM，也无法支持当前价格，因为“悲观”是相对已经很高的 NTM 预期受损，而不是收入绝对下降。

### 5.2 悲观 / 受损

核心路径是 VPA / G5 / Atlas 的收入确认后移、精密光学或验收形成 1–2 季度错位，且传统业务与营运资本抵消高端产品增长。收入仍可比当前 TTM 高，但相对 $1.58bn 的 NTM 当前预期少约 15%，non-GAAP 营业率降至 23%–26%，FCF 显著弱于利润。

- **进入条件：**Q2 或 Q3 至少一季收入低于当前路径；G5 出货未继续爬坡；backlog / VPA 延迟超过约 20%；GM 与现金转换再给出一个负面确认。
- **最早确认：**2026Q2 财报与 Q3 指引。
- **失效条件：**收入回到至少 $1.52bn NTM 路径、GM ≥56.5%，且库存 / 应收不再快于收入。
- **永久损失风险：**不是近期破产，而是高预期资产在增长和现金质量同时失守后发生长期倍数重置。

### 5.3 基准 / 正常兑现

Q2 指引、VPA、G5 / 3Di、Atlas 与 common films 正常确认；EchoScan、panel / glass 和完整 Rigaku hybrid metrology 不承担主预测。软件、服务和产品组合令 non-GAAP GM 接近 57%，营业率约 30%–32%，但增长期营运资本使 FCF低于调整后净利润。

- **进入条件：**Q2 $320m–$330m 与 56.0%–56.5% GM 大体兑现；VPA 约按当前 2026/2027 分布；G5 / Atlas 按期出货；Q4 营业率接近 >30%。
- **最早确认：**2026Q2；现金质量至少需 Q2—Q3 两季。
- **失效条件：**两个核心环节同时弱于路径，或单一客户 / 供应问题令 NTM 收入少于 $1.45bn。

### 5.4 乐观 / 超预期

Dragonfly 或 Atlas 至少一个平台出现新增客户 / site 的 repeat 或 copy order；软件、传感器配置和服务附着使收入增长真正留在利润与现金流中。JetStep / EchoScan 可贡献部分上行，但不要求全面 HVM。

- **进入条件：**新增客户 / 多站点订单金额可验证；NTM 收入至少 $1.75bn；non-GAAP GM ≥58.5%；FCF ≥$360m。
- **最早确认：**2026Q3—2027Q1。
- **失效条件：**上行只来自单一客户 pull-in、低毛利急单或营运资本堆积；任一情况把收入上修降为“基准价值、乐观收入”。

### 5.5 突破 / 非线性

HBM4/4E、2.5D、GAA / DRAM 需求和 ONTO 份额同步超预期；Dragonfly 与 Atlas 至少两条核心线多客户复制，EchoScan / panel / Rigaku license 中至少一项进入可量化 HVM，且供应体系从公开约 $2bn 能力扩至 $2.7bn–$3.0bn。高端 mix 与软件令每股价值增长快于收入。

- **进入条件：**至少两个核心平台多客户 / 多 site L3—L4；供应商扩容与客户验收有独立证据；收入、GM、FCF 三项同时突破。
- **最早确认：**2027H1，完整确认更可能在 2027H2。
- **反证：**只有行业 TAM、论坛、demo 或一个大客户；产能超过 $2bn 却无精密光学 / 应用服务扩容；高收入来自低毛利新品。
- **证据结论：**存在可信商业路径，因此不标 NA；但当前支持程度为低，不能借给当前条件定位。

## 八、多估值理念、参数与模型分歧

### 8.1 主估值与交叉估值

**主估值是目标期 NTM non-GAAP 营业利润 × 条件 EV/营业利润倍数。** 原因是 ONTO 在目标期从收入加速进入利润杠杆阶段，同行日度数据也主要按 forward P/E / EV/EBITDA 定价；单纯 P/S 会忽略 23%–39% 的情景营业率差异。主方法使用 non-GAAP 经营口径，但以较低倍数、FCF和 GAAP DCF边界反映真实摊销、股权激励、营运资本与资本配置，不把调整项当免费。

交叉方法：

- **EV/收入：**要求与同一情景营业率一致，不能用突破倍数配悲观利润；
- **五年 FCF DCF：**作为长期现金边界，使用状态 WACC、情景正常化增长 / FCF margin，不与主方法机械平均；
- **资本结构桥：**现金、Rigaku、债务、capped call 与股数只处理一次；
- **反向估值：**用于判断当前价格门槛，不作为第五种目标价。

截至 7 月 13 日，同口径原始市场事实为：ONTO P/S 14.68 倍、forward P/E 30.59 倍；CAMT 12.79 / 30.23 倍，FORM 10.24 / 39.52 倍，TER 14.10 / 34.68 倍，KEYS 9.01 / 27.00 倍。该比较只使用市场与财务事实，不读取或继承同业投资评级。ONTO 的 P/S 高于多数可比，forward P/E 看似接近同行，是因为市场已预期其利润率和 EPS 快速爬升。

### 8.3 DCF 边界与模型分歧

DCF使用同一经营行的 3—5 年增长和 FCF margin；WACC区间分别为：主题 8.0%–9.0%、宽基 8.5%–9.5%、震荡 9.5%–10.5%、有序收缩 10.5%–12.0%、流动性压力 13%–16%。下表是目标期每股 DCF边界：

## 十一、板块轮动修正

半导体板块的正式判断是 **中性 / 分化**：SMH 过去 3 个月 +34.0%、显著领先 SPY，说明中期仍是领导板块；但 7 月 13 日单日 -4.2%、跌破 50 日均线且距一年高点 -12.5%，短期是资金退出 / 均值回归。行业订单与盈利证据仍强，价格趋势却转弱，因此不满足“盈利预期与相对价格共同改善”的完整领导条件，也没有足够证据认定持续退出。

本报告 **不机械调整主矩阵建议**：

- 若 SMH重新站上 50 日均线、相对 SPY恢复并且 ONTO / 同业订单与盈利继续上修，可在对应价值区间取高端，建议最多增强一级；
- 若 SMH相对趋势与设备盈利预期连续一个月共同恶化，则采用更高安全边际、区间低端，建议最多减弱一级；
- 7 月 13 日单日下跌已经进入相邻“震荡 / 均值回归”证据，不在板块修正中第二次扣减。

### 12.2 全矩阵形状

中性标签为：

- **条件正面区域：**正面建议主要在乐观 / 突破行和有利市场列；
- **经营兑现敏感：**同一宽基列从悲观的 -63%～-43% 跃迁至乐观的 +13%～+73%，公司执行比格子数量更重要；
- **市场状态敏感：**同一基准经营从主题列 -11%～+34% 变为压力列 -61%～-32%，久期和风险溢价不可忽略；
- **当前价格支持不足：**纯基准只有主题列出现谨慎正面，宽基列只是中性，震荡及更差状态均不支持当前价；
- **价值并非只集中于突破：**乐观 × 宽基 / 主题已出现正面区域，因此不是“只有突破才有价值”；但基准无法提供广泛安全垫。

建议最稳定的区域是：

1. 悲观行五列均为强烈不建议投资；
2. 突破 × 宽基 / 主题 / 震荡三格的主方法低端均达到或显著超过要求回报；
3. 基准 × 有序收缩 / 压力两格明确不支持当前价格。

最脆弱边界是 **基准 × 宽基 / 主题**：轻微倍数、现金转换或买价变化即可让建议在不建议—中性—谨慎建议之间移动。最坏格子为 **悲观 × 流动性 / 信用压力**，每股 $55–$96、损失 -82%～-68%；原因是经营兑现受损、客户 capex / 验收延迟和风险溢价跳升同时发生，而不是近期清偿危机。
