## 1. 当前判断、研究时点与关键限制

**当前证据最接近“基准／正常兑现”，短期与中期为中性／等待，长期按现金流回报理念不建议以318.36美元新买入。** 公司经营正在改善；问题在于改善已经被相当程度定价，而足以支撑更高长期价值的收入增长持续期、先进封装净捕获和并购回报尚未得到同等强度的证明。这不是对经营恶化或未来股价必跌的预测。

## 2. 公司全貌、上游证据与财务质量

### 2.1 八种经济机制，不能统一叫“AI设备”

Nordson捕获的是精确施加、控制、加工和检查材料所减少的停机、材料浪费、缺陷及重新验证成本。公司卖系统、模块、OEM组件、耗材和服务；不是把客户节约的全部成本按比例分成。FY2025约60%收入被公司归为部件／耗材，只说明复购属性，不能等同不可撤销合同或软件ARR。FY2025没有单一客户占销售10%以上，也不排除某个小分支集中于少数电子客户。[L1，第三、五节][S3]

### 2.3 盈利质量、资本与失败成本

- **现金不是由调高EPS创造。** 滚动FCF＝661.1＋530.2−467.3＝724.0百万；9个月现金流受营运资产负债贡献影响，CapEx较去年同期少8.7也帮助FCF。模型没有将Q3 FCF乘四。应收648.827、库存469.310、客户预收69.618百万；收入增长伴随应收和库存上升，仍要观察收款和取消。
- **非经营项目必须隔离。** Q2养老金结算费用24.049、Q3少数投资未实现损失14.892会扭曲GAAP净利；收购无形资产摊销剔除用于观察经营，却不能抹去收购现金成本。原申报中九个月少数投资收益／损失文字有表述不一致，模型完全不预测这项交易性收益，不以其解释核心盈利。
- **不把商誉叫安全垫。** 7月底商誉3,315.820超过股东权益3,269.059百万。现金只有约2.0美元／稀释股，扣债后不构成正的净现金保护。债务用本金1,744.698而非账面1,731.005；账面差异来自费用、折价与互换。
- **其他索取权单列。** 初始融资租赁18.678、养老金及退休后义务85.275、衍生净负债58.344、递延报酬14.046，合计176.343百万。经营租赁68.529不再扣，因为租金保留在经营费用中。衍生品不能只看巨额名义本金；模型未另外预测存量合约终止损益。少数上市投资账面6.636且2028年12月前禁售，保守计可归属非经营价值5，不视为流动现金。
- **债务风险可管理但不是零。** 2028年350、2029年600、2033年500百万公开债券为主要批次；短债商业票据192另有循环授信支持。12亿美元授信与同额商业票据上限不是两笔独立流动性。坏情景2029年仍须滚续约269百万，而不是假定所有现金都足够偿债。
- **资本配置是第二弱环节。** ARAG交易时EV约9.60亿欧元、16.5倍预计EBITDA，Atrion实际收购净现金约790百万，CyberOptics约380百万。它们可提高经营质量，但高价买入后剔除摊销的EPS增厚不等于高ROIC。约12%的FY2025公司口径ROIC亦说明30%以上EBITDA率不能当投入资本收益率。
- **治理与尾部事件。** NBS Next分权运营、应用工程和直接销售支持执行，但跨医疗、农业、电子并购整合存在能力边界。产品质量／召回、工艺资格丧失、出口限制及亚洲客户资本预算都能穿过收入、费用与现金；本次未识别可核实、应单列金额的新增重大诉讼损失，不宣称完成全球全部案件排查。新增大额并购、可转债或对价股不预埋；发生时必须重做资本桥。

### 4.3 估值参数与时间一致性

**六个月／一年：** 经营价值＝目标日之后NTM EBITA×倍数。悲观14—17、基准17—21、乐观19—23、突破21—25倍。EBITA已扣正常折旧、研发及股份报酬，未扣收购摊销，不把EBITDA倍数错套到EBITA。悲观较低倍数对应订单永久受损、较低ROIC；基准17—21对应约0.74—0.77 FCFF/EBITA转换、约3.5%—4.5%前瞻经营现金收益率与中个位数成长。乐观／突破的上移必须有更长高回报增长持续期，不能单凭新产品名称。当前约20.24倍处在基准高侧，因此基准没有明显未支付的估值提升空间。

倍数是有限窗口下质量企业合理重估的判断区间，不是统计置信区间或今天可兑现的清算价值。低端／高端来自不同资本化假设，**工作值取明确的19倍基准资本化**，不是从区间任意挑60%或75%位置推荐。长期现金方法随后明确裁决这一溢价能否自给。

**三年DCF：** 在2029-09-07计算此后尚未发生的FCFF；前三年现金通过资本桥积累／还债／回购／分红计一次。FY2027—31取第3节，FY2032—36既有业务收入及EBITA在2031基础上分别按下列减速增长；O仍按逐年状态期望现金，不新增期权。2032以后CapEx按既有收入比例增长、Δ周转＝收入增加额18%，正常折旧84/88/92/96/100；存量可见摊销50/40/30/20/10的税盾逐步消退。

事件树：`参考工艺付费验证→有限复购P→多厂扩量S→持续S／退化P／退出F`；若技术验证失败直接F，若预算延期留U并继续必要验证支出。混合键合／预成型材料既可增加检查需求，也可删除旧底填；两端在同一净收入路径处理。医疗与EFD／ATS的预算相关性、工业与农业的周期相关性由完整场景共同改变，不把它们当分散掉的独立风险。

**可能交易回报限制：** 财报日历史+8%只能说明有一次信息重估，不能估计下一次必涨8%。本报告无法得到可复核的价格采纳概率或短期交易分布，因此可能交易回报为NA；方向仍可判断为“基准好消息已有支付、乐观上修或实质付费里程碑才形成新增重估理由”。主矩阵全部是条件合理价值回报，实际价格可在任何一个目标日继续偏离。

### 4.5 当前价格隐含要求，不冒称唯一市场共识

1. **短期以19倍资本化获得8%回报**，六个月退出至少341.95美元；除资本桥外，需目标NTM EBITA约1,088百万，较基准994高约9%—10%。不是只兑现11.90年度EPS就足够。
2. **一年获得12%回报**，退出至少352.803美元，19倍下NTM EBITA约1,105.4百万，较基准1023.7高约8.1%；或盈利不变而倍数约20.54。相当于需要更接近乐观的经营，或继续保留估值高侧。
3. **基准现金流解释今天318.36**：若只调整折现率、其他路径不变，隐含WACC约6.83%，明显低于本研究8%—10%要求；若WACC9%不变，需要经营现金现值约为基准的1.50倍。这不是市场真实共识的唯一解，也可能由更快增长、更高现金转化、较晚减速等组合实现。
4. **三年要获得10%年化**，2029退出需412.46美元（另收11.28股息），高于基准9% DCF249.63，也高于乐观9% DCF373.01，低于突破9% DCF476.94。全公司从基准走向突破比一个小型新产品公告重要得多。

不能把终值低端叫作资产底价：基准目标DCF终值占EV约63%，10% WACC依然有约59%；错误主要来自增长持续期、再投资／竞争与折现率，而不是现金保护。给到“精确1美元买点”没有可信度。

## 6. 当前路径、买价与证据边界、敏感性和最强反证

### 6.1 为什么当前选基准，而不是按四行投票

当前事实是ATS很强、IPS利润转换偏弱、MFS有机恢复而组合复杂。基准将这些组合起来：增长真实，电子恢复不永久维持30%，不预埋下一笔大额并购。乐观需要“量增＋净价／获选＋利润＋现金”进一步共同兑现，突破还需付费参考与跨客户平台化。未获得足以估计四种完整经营情景总概率的统计或市场数据，**不赋予四行各25%、不据正面格数算胜率，不计算伪精确CVaR**。

最强反对本研究谨慎判断的证据是：Q3高增长、backlog增加、现金强且新平台已有客户演示，这可能意味着本模型过早减速。如果2027—29的既有半导体捕获和医疗复利接近突破、且O净新增而非替代，现金DCF也能支持良好收益；报告并未用悲观行否定这条经济机制。

但最强支持等待的事实同样具体：EPS正常增速不足解释既有涨幅，IPS没有展示对应经营杠杆，PLP多客户收入未披露，公司现金约2美元／股不能吸收几十美元的估值误差。价格已经需要超出“好公司继续正常经营”的东西。

### 6.2 经营不变时的买价范围

以下按**明确工作路径**反解，不是区间中点挑选买点；短／中期固定19倍，长期固定9% WACC。公式为`买价上限=(目标工作价值+分红)/(1+要求回报)`，长期分母为1.10³。端点误差、价差与正常波动可能大于几美元，故只提供宽工作带。

以上是估值条件，不是技术支撑或保证可以买到的价格；经营恶化时不能沿用原买价带。180—200的现金理念带距离现价较远，说明投资理念差异实质性存在，不是强制预测股价会跌到那里。若等待期间出现多个客户复购及持续强现金，买价带应随新增经营证据重新上移，而不是机械等旧数字。

等待代价：可能错过2027 Q1指引与付费验证带来的向乐观／突破重估；六个月突破条件回报约27%—52%。提前参与的代价：如果只是恢复且长期现金要求不兑现，基本价值余量薄；如果电子周期转坏，悲观条件损失远大于股息。没有整行可信概率，不能用上行巨大直接宣称正期望。

**O机会专项敏感性：** 下面全部保持基准既有业务和集团资本政策，以基准9% WACC的2029每股249.6为参照；先重算各状态利润和现金，再计算目标前累计现金差及目标后剩余现值。忽略二阶利息／微小股数反馈，误差估计不足0.5美元。高低概率不是对收入统一乘系数，而是分别用第3.4节悲观／乐观转移矩阵替代基准转移、保留基准状态规模与投入；各年概率仍闭合。

延期路径明确定义：2027留U，2028恢复基准转移时将当年所有存续分支的20%移入F（错过客户设计窗口），以后按原矩阵。首年验证投入照付，F不能复活。**若只是无限延迟且同时推迟失败，却继续使用更晚年份的更大市场规模，会人为提高远期存续价值；本次延期检验避免了这种免费等待。** 20%丢窗口为主观敏感参数，不是观察到的取消率；零至40%丢窗口需随真实客户采购计划更新。

概率要求的反向边界也很清楚：仅把基准O规模成功概率升至100%，本模型三年每股最多约269.6，仍低于获得10%年化所需412.46。因此不存在“把这个机会成功概率稍微调高”就能使整个基准股票成为有吸引力投资的有效概率门槛；甚至100%都不够。若其余经营不变、沿完整成功曲线按比例扩大规模，需远超过基准350百万的2031量级，接近数十亿美元级机会经济现值，必须重新证明客户池、交付和资本，不能超出上面0.5—1.6十亿美元采购池仍原样宣称合理。

**最能改变判断的组合检验：新平台突破、旧业务只正常。** 把突破O状态现金和规模移入基准既有业务，保持原有业务正常、O投入同步，三年每股约249.6＋37.3＝286.9美元；仍达不到318.36买价所需回报。这说明完整突破行的477美元工作值不仅来自PLP，还需要既有半导体、医疗／EFD、工业与农业持续捕获和高资本回报。若旧半导体再因混合键合／吞吐自我蚕食受损，组合价值更低。此检验保留新机会的巨大条件价值，同时防止“一项技术成功＝全股成功”的偷换。

无需为O期望现金虚构能穿越融资断点的平均公司：其基准前期年净现金消耗约8—10百万，完整失败退出费约6加周转损失，明显小于成熟业务数亿美元年度现金；主要成功分支的高CapEx和周转已纳入状态公式。正常资本政策下这组机会不单独触发股权融资。坏行情景2029滚续则是真实集团资本约束，已单列；若未来出现更大并购或质量损失，现有线性期望近似需改成联合融资分支。

### 6.4 下一次更新只需要抓住的关键证据

1. **订单到现金**：连续两季把新增、取消／延期、出货和收款分开；若backlog增长伴随交期拉长、客户预收回落、应收／库存占用增加，不能继续用其证明增长质量。
2. **PLP真正收费**：独立客户身份或可审计客户数、同材料／基板条件下持续可靠性、首次付费、第二次采购、实际净价和旧品替代。最早的真实复购能排除“只是演示”“没有收费权”两种失败解释；仅换一版产品公告不能上调转移概率。
3. **IPS／医疗利润来源**：IPS增长能否转成利润，MFS是否既有医疗量增又有EFD改善，而非仅剥离低毛利业务；若这两块不能支撑现金底盘，ATS单点强劲不足。
4. **再投资与资本回报**：新增CapEx／研发与可交付能力配对；新并购价格、净债务、对价股和回收年限逐项核对。没有实际合同或融资条款时，不把未来并购的EPS增厚当作免费上行。

三期限的选择各有依据：短期等待确认窗口与新的预期差；中期等待盈利、订单和现金共同超过已支付要求；长期在足够低的买价或足够强的全公司成长持续期出现之前，拒绝以现金流理念替高估值持续性下注。

### 7.4 必要公式与资本桥复算

历史起点：现金113.431、债务本金1744.698、稀释代理56.027、基本股代理＝稀释−0.313、融资租赁18.678，单位百万。FY2026 Q4四行分部收入、EBITA和现金见第3.5；共同折旧16、收购摊销24、CapEx18、Δ周转0、SBC6、回购35／318.36。其余年度输入见第3节。

```text
成熟收入[j,y] = 成熟收入[j,y-1] * (1 + 本行该分支增长率)
成熟EBITDA = Σ(分支收入 * 分支EBITDA率) - 总部费用
集团EBITA = 成熟EBITDA - 成熟折旧 + O期望EBITA
成熟折旧(FY2027..31) = 60,64,68,72,76
收购摊销(FY2027..31) = 78,73,68,63,58
集团折旧 = 成熟折旧 + O收入 * 2%
GAAP营业利润 = EBITA - 收购摊销
季度净利息 = max(0, 期初债务*r/4 - max(期初现金-125,0)*3%/4)
r = 悲观5.3%；其余4.8%（模型，不是未来锁定借款报价）
GAAP净利 = (EBITA - 摊销 - 净利息) * 80%
调整净利代理 = (EBITA - 净利息) * 80%
CFO = GAAP净利 + 摊销 + 折旧 + SBC - Δ周转
报告FCF = CFO - 全部CapEx
估值FCFF = 报告FCF + 净利息*80% - SBC
季度分红总额 = (期初稀释股数 - 0.313) * 0.94
新增净股数 = (SBC - 回购金额) / 该期假设回购价
期末现金 = 期初现金 + 报告FCF - 分红 - 回购
           - 融资租赁本金 - 还债 + 新借款
新借款 = max(0, 125 - 未融资前期末现金)
期末债务 = 期初债务 - 还债 + 新借款
期末其他索取权 = 157.625 + 尚未偿付融资租赁
```

季度末现金和债务严格闭合；期中目标日一般经营流量按实际天数分摊。**股息单独按1／4／7／10月2日支付处理**：期中现金加回尚未支付的日均分摊股息，已支付则扣实际模型金额。这样目标日前累计股息与主矩阵1.88／3.76／11.28不重复；今天估计现金也没有提前扣10月2日才支付的股息。已宣布2026-10-02是真实日期，其余为预测支付代理；节假日几天移位对本次目标日归属不构成差别。债务在季度内的精确月份不足时采用均匀到期代理，现金与债务等额变动不改变净债务，相关利息误差由资本成本敏感性覆盖。

从2026-07-31到研究日尚未公布的38天经营亦按本行情景Q4分摊，不将模型现金余额当作当日已披露财报。新借款机制在悲观2029年触发；并不意味已签未来融资合同，授信条件变化须更新。没有回购与净债务同时全额获益，也没有分红后继续把同一现金留在股权价值中。

```text
目标日经营价值(V1) = 目标日之后NTM EBITA * 本行情景倍数
目标日经营价值(V2) = Σ目标日后FCFF/(1+WACC)^距目标日年数
                    + 2036末终值/(1+WACC)^距目标日年数
股权价值 = 经营价值 + 目标日现金 + 非经营资产5
           - 目标日债务本金 - 其他优先索取权
每股价值 = 股权价值 / 目标日完全稀释股数
持有总回报 = (目标每股价值 + 期间实际模型股息 - 318.36) / 318.36
三年年化回报 = (1 + 三年总回报)^(1/3) - 1
```

用基准一年例：NTM EBITA1023.709×19，加现金291.706和非经营5，减债务1542.698、其他索取权167.477，除55.523百万股，得324.854美元；含3.76股息回报约3.22%。用基准三年9% DCF例：经营EV14,264.217＋现金463.429＋5−债务944.872−其他157.625，除54.605，得249.615；含11.28股息累计约-18.05%，年化约-6.41%。EV是未来目标日剩余经营现值，绝非把今天折现值直接当未来退出价。

### 7.5 交付核对与结论覆盖范围

已按底稿核对分支／分部／集团、季度／年度、GAAP／调整利润、报告FCF／估值FCFF、现金／债务／股数及12格目标日回报；显示四舍五入可能产生0.1尾差，内部不靠舍入后的数连乘。O四状态每年合计100%、F吸收、成功后持续现金和失败支出已计入；完整成功参照不与期望值相加。没有把行业TAM、终端资本预算、已有PLP、旧点胶与新检查重复相加；未识别收费权的独立软件、CPO远期路径保留机制和门槛，不以未知零值宣称排除所有上行。

**结论覆盖：** 这是对318.36美元买价、上述经营和资本政策的条件研究。最稳健的判断是“正常经营改善本身不足以支持有吸引力的长期现金回报”；最需要保留的不同意见是“公司可能持续维持高估值，或全公司进入更强的捕获路径”。能裁决它们的是未来付费、复购、利润与再投资现金证据，而不是报告中的正面格数量。
