三个最重要的判断限制：

1. **本地公司研究遗漏了已经公开的290亿美元兜底上限。** SEC 2026-06-09提交的10-Q附注11及Item 5披露：6月8日安排的客户五年租赁义务兜底，随部署增加、随付款减少，最高29；接管租赁或处置机架可降低损失。该数不是目前应付现金、不是最终损失，也不是所有未来XPV安排合计上限。本报告采用原始申报，拒绝继承“上限完全未知”的表述。[SEC 10-Q][S02]
2. **软件、XPU与AI网络的经济性差异很大。** HBM等外购内容增加可能同时推高收入、压低毛利百分比；软件季度收入增长也可能快于持续收费基础。采用收入倍数会掩盖这些差异。[本地公司事实底稿][L01]
3. **长期结论主要受核心AI业务持续期影响。** OpenAI与光学扩展的早期期望贡献已计入；即使两项机会更顺利，也不能单独填平全部现价回报门槛。不能把公司未来所有成功都压缩成一项“技术成功率”。

### 4.3 目标日估值方法与时间一致性

**主方法：目标日剩余FCFF折现，再作资本桥。** 各行情景的早期贡献已按年度状态加权。对短、中、长三个目标日，使用相同经营路径和同一套远期规则；只改变目标日前后现金归属和剩余折现期。

公式：

```text
FY27—31 FCFF = (经营利润¹ − 经济SBC) × (1−17%)
                + 有形折旧 − 全部CapEx − ΔNWC − 信用净现金损失
公司FCF估计 = FCFF + SBC − 税后利息
目标日EV = 目标日之后剩余季度/年度FCFF现值 + 终值现值
股权价值 = EV + 目标日现金 − 目标日债务
每股价值 = 股权价值 / 4.940
总回报 = (每股价值 + 期间每股分红) / 357.90 − 1
```

目标日前的研发/成长成本已实际减少留存现金；目标日后的成本继续进入DCF。没有把今天现值当作三年退出值，也没有只计算未来三年现金就让企业消失。主模型没有额外加OpenAI、CPO或“AI平台期权”。报告FCF与估值FCFF的税、利息、报酬口径保持匹配。

| DCF参数（A，顺序为悲观/基准/乐观/突破） | 数值与依据 |
|---|---|
| WACC区间 | 11%—13% / 10.5%—12.5% / 10%—12% / 10%—12%；工作12% / 11.5% / 11% / 11%。以约4.8%的长期无风险锚加经营系统性风险补偿，权益占比极高，债务税盾影响较小；不是精确CAPM估计 |
| FY2032—36正常税后经营利润增长 | 悲观3/2.5/2/2/2%；基准8/7/6/5/4%；乐观12/10/8/6/5%；突破18/15/12/10/7% |
| 2032以后增量ROIC | 15% / 25% / 30% / 35%；低于初期新增研发批次高回报，考虑供应宽松、客户议价、更新和资金责任 |
| 年度净再投资 | NOPAT×当年增长率/ROIC；该阶段的FCFF＝NOPAT−净再投资。不与FY27—31逐项CapEx模型重复使用 |
| 永续增长 | 2% / 3% / 3.5% / 4%；每年终值现金仍扣增长所需再投资g/ROIC |
| 终值 | FY36末NOPAT×(1+g)×(1−g/ROIC)/(WACC−g)；终值建立于已加权规模，未令局部成功率自动等于1 |

WACC的行间差异来自条件于经营路径之后的客户、利润稳定性与剩余系统性风险；已扣的信用损失不再按同一违约率折一次。突破仍取11%工作WACC，未因为高增速而把资金成本压到无风险水平。

**主区间是同一工作经营路径下的WACC敏感范围，不是统计置信区间，也不覆盖所有量价误差。** 主要经营误差、普通延期和状态敏感性另列；矩阵估值置信度因此最高只给“中”，远期/突破多为“低”。基准三年终值占EV约56%—63%，突破约68%—75%；高端价值高度依赖2036以后持续回报，不能称有资产底价保护。

### 4.5 三个期限各自的投资逻辑

**短期3个月与6个月。** 基准3个月DCF约267—346，加一期.65分红仍约−25%至−3%；完整Q4财报可能尚未公布。6个月可增加一期股息并推进经营，但基准约274—354仍无足够回报。三个月等待的理由更偏向信息窗口，六个月等待更偏向现价风险补偿。二者方向相同，不用“3—6个月区间”掩盖差别。转为正面需要更强路径的证据或更低买价；“下一次财报一定催化上涨”没有得到最近两次事件支持。

**中期12个月。** 当前基准NTM收入154与一年后NTM约227之间有明显经营扩张；但未来供应付款、现金税正常化、奖励中和和持续投入一起吸收现金。基准工作每股由当下约294升至一年后约325，源于现金积累、偿债及剩余现金的时间推进；投资者从357.90买入仍没有15%回报。若按乐观行经营，一年合理价值481—643，回报约35%—80%，需要同时看到可持续毛利与现金，并非把短期和长期目标价平均。

**长期36个月。** 定制架构、网络/IP复用与企业软件可以持续产生重大价值。基准FY29集团收入296左右、经济FCFF117；三年后NTM收入约324、FCFF134，说明本报告长期不支持买入的原因不是假设AI停止。关键是今天支付的价格、五至十年的剩余增长以及客户/供应资本责任。三年内应验证跨代设计留存、客户在同质量/时延下的系统成本优势、软件续约、净内容、回款与新增兜底范围；仍难在三年内完全解决2036后的竞争形态和硬件更新回报。

## 六、当前路径、价格门槛、敏感性与等待代价

### 6.1 现价究竟要求什么

现价不是只要求Q4收入34.8。它还要求当前高增长能延续为远期可分配现金。以下均为反向条件，**不是市场唯一共识**：

基本面不变时的230—285观察区域也不是自动买入区域：一次普通量价下修会改变整个现金底稿；若下跌来自更高追索义务或永久份额丧失，应按受损路径重算，而非照旧执行基准限价。

### 6.3 高增长提前参与是否合理

管理层FY28 AI约230及客户部署证据让乐观路径有现实支撑，当前并非只能选择悲观或无限等待。但“路径存在”还要转成足够的回报补偿。以三年工作退出价值作一个**门槛算例**：

- 仅比较基准约393与乐观约667，若其余条件不变，要在现价达到15%年化，需要乐观分支的主观权重超过约52%。这是两分支简化下的门槛，不是本报告预测。
- 若另有10%的受损分支、对应三年约99，乐观分支需约63%的总权重，其余为基准，才能达到同一门槛。10%也是压力设定，不是校准概率。
- 原始资料尚不足以证明这两组权重中的有利一侧。也不能用OpenAI的局部S概率、管理层目标、六个正面条件格或估值置信度代替整股成功概率。

因此，**当前主判断保持三期限等待**。愿意承担大幅永久损失、并有独立理由相信高规模、多代收费和客户融资持续性的投资者，可采用“谨慎建议投资”的高增长理念；其依据应是整条乐观经营/现金路径，不是基准DCF本身。该分歧公开保留，不强行用一个标签覆盖所有投资理念。

### 6.4 等待的价值和成本

最早值得等待的证据是：FY26Q4实际收入和现金、FY27交付排程、新客户生产验收、下一份申报的采购/兜底责任，以及软件持续收费与确认差异。精确财报日未核实，3个月目标日前不能预设全部到齐。

现在买入可获得超预期重估：若一年退出价值采用乐观工作约551，现价含一年2.6股息回报约55%；若等确认后股价升到450、剩余股息约1.3，则到同一目标日回报约23%；若已升到520，只剩约6%。这些是给定未来买价的算例，不是交易价预测。等待能够排除一部分技术/信用失败，代价是确认成功后更贵或买不到。

等到260且基准经营保持，三年工作393加7.8约54%累计、年化约16%，开始满足要求；若价格降到260的同时路径变为受损、三年价值99，则仍可能损失约59%。等待价格与等待证据必须一起执行。

最强反证有两个方向：**对本报告等待选择的反证**是FY27/28交付、毛利和现金共同证明管理层远期量级可持续，客户自行承担资本风险，届时继续沿用低规模基准会犯保守错误；**对提前参与选择的反证**是客户利用/融资弱化、不可取消采购和担保敞口扩大，而利润表尚靠前置确认和硬件外购内容维持增长。后者一旦出现，DCF与资本桥应同时改写。
