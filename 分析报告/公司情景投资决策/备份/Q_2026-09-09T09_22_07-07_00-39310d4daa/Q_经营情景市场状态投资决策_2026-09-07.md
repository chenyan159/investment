## 一、当前选择、研究时点与限制

### 1.1 三个期限分别怎么选择

| 期限 | 当前主判断与投资理念 | 当前最重要的预期差 | 最少翻转证据与等待代价 |
|---|---|---|---|

| 长期，36个月 | **不建议按稳健复利立即买入**；稳定倍数的长期成长理念可给“谨慎建议投资”；单独押注早期N为“中性／等待” | 基准路径到2029仍高速增长，股东收益改善；但三年后仅维持当下价格也需要更长持续期或更低资本成本。突破路径可产生显著收益，不能直接当当前期望收益 | 2027—2028连续维持约20%或以上的集团增长、合格能力同步扩张、实际现金不被投入吞噬，才明显提高突破可达性。等待可能错过材料平台资格获确认时的提前重估 |

主判断采用现金模型的**明确经营工作路径**，不取价值区间的任意百分位。中期和长期对成长理念的讨论并不要求它先认可现金模型；其独立成立条件与不同价值计算完整保留。没有给四种整公司情景分配发生概率，不宣称整股有已校准的胜率或正期望。

**最弱传导环节是“持续增长与再投资 → 普通股可得现金 → 当前买价”**，并非眼前债务到期。第二约束是材料资格和技术改进能否转成净量价，而非仅提高客户良率。历史责任会影响现金，但不应压过业务增长持续期这一更大的价值变量。

### 2.4 资本、治理与永久损失

2026年6月末现金0.961、账面有息债4.020、未提款承诺循环额度1.25十亿美元；主要债务到期在2032—2033，年度摊还约0.024。7月降低定期贷款利差25bp，年节息约0.006，只约0.03美元／股税前，不能成为主要重估理由。[S3]、[L1]

其他索取权逐项处理：HDM短借0.079在应付中另扣；债务本金高于净账面，资本桥另预留0.070；养老金0.080、优先股0.0015另扣。经营租赁约0.507，其租金已经进入经营费用，主模型不再全额重复扣租赁负债。少数股东经营收益包含在集团预测，估值另扣其权益价值；合资收益从主经营EBITDA剔除，合资权益单独估值。不能既保留HDM全部利润又加其投资价值。[S3]、[L1]

**机会篮子N：下一代混合键合／有机中介层／玻璃和面板工艺的新增收费。**包含新界面的CMP、清洗、介电和金属化材料，涵盖ST和ICS经济位置；会计集团收入中单列N，避免未披露分部归类制造精度。主模型没有把Stackplane已有TSV等销售重新计入N。热管理已规模销售，继续按核心驱动增长，不强造商业成功概率。物理AI没有独立收费模式时只计相关材料内容；AI辅助研发没有独立软件收入，保留缩短资格周期的可能性，但不与转型节省重复相加。

技术机制是：更细、更平整、更大面积的界面提高配方和工艺窗口价值；可支付者仍为晶圆／封装／载板厂。替代有机路线、减少重做、降低每合格包材料面积和竞争者获资格，会减少可收费空间。因此将互斥架构放在同一客户预算篮子中，不按各条TAM独立叠加。

**可辩护规模与量价边界（均为E）。**

- 基准2030“部分成功”净收入0.075：约1,000万当年合格等效封装×15美元该篮子材料预算×65%获配×77%净增量比例。规模成功0.380：约3,000万×25美元×65%×78%。65%是**获资格项目内**份额，非全球份额；等效封装用于统一面积／工序，不冒称芯片颗数统计。
- 2030规模成功0.380中，工作分配约混合键合0.200、有机中介层0.150、纯玻璃0.030；它不是把窄玻璃成品市场放大十倍。以玻璃材料占成品5%—10%、Q在相关份额30%—60%计算，上游玻璃成品0.15—0.60可对应Q约0.002—0.036；0.030已偏向有利一侧。

### 4.3 主方法：目标日剩余现金流，不把今天现值当未来价格

Q已有成熟盈利与再投资历史，适合以逐期扣全部投入的经营DCF检验现金价值；三个期限使用同一公司路径。6个月DCF仅表示该路径成立时的合理价值，是否在半年被价格采纳另行判断；12个月关注真实转换，36个月强调剩余能力与2030以后价值。主方法并不推定半年一定向DCF收敛。

对目标日之后逐季估值现金流折现至目标日，再加资本桥；目标日前现金只通过实际积累处理一次：

```text
经营EV = Σ[目标日后核心FCFF季度余额/(1+WACC)^剩余年数]
       + 2036年末核心终值在目标日的折现值
       + N逐年状态加权FCFF及有限后续衰减现金的折现值
核心终值 = 核心2036 EBIT(不扣收购无形摊销)×(1−税率)×(1+g)
           ×(1−g/终值ROIC)/(WACC−g)
股权 = 经营EV + 目标日现金 + 合资权益 − 债务 − 其他索取权
每股 = 股权/0.2102
总回报 = (每股价值+投资者期间现金分红)/120.47−1
三年年化 = (1+三年总回报)^(1/3)−1
```

**低端参数**WACC11.5%、g2.5%、终值ROIC15%；**工作参数**10.5%、2.75%、16.5%；**高端参数**9.5%、3%、18%。工作参数有明确经济含义，不是区间中点。9月4日发布的联储H.15覆盖至9月3日，10年名义收益率4.77%；股权风险与业务周期、约债务一成多的资本结构支持比无风险显著更高的加权成本。本范围是研究要求，不是假装已观测到公司WACC，也不是用行业涨幅回归出稳定beta。[联储H.15][S17]

终值以再投资率g/ROIC约16.7%保持增长，避免免费增长。N在2036后只延续五年、每年现金下降15%，2041后不再给予该代具体机会价值；不是认定公司2042归零。已兑现为普通平台的更新能力由核心终值承担，未发现可独立估值的下一代路径暂保留未知，不重复加期权。此项设定偏向有限技术寿命，完全永久更新的替代理念需要额外研发和收费权证据。

现金FCFF包含全部成长投入，合资单列；持续SBC在经济费用中，没有再用高折现率扣同一局部失败概率。N失败已在状态中加权，DCF里不再乘“最终成功率”。WACC只补偿时间及未显式纳入的系统性风险，不追加“玻璃失败折价”。

### 4.5 现价隐含要求：多组组合，而非唯一市场共识

1. **公司当年盈利口径。**120.47／4.50≈26.8倍2026调整后EPS；金融快照的43.18倍TTM PE基于EPS2.79，22.40倍“forward PE”基于EPS5.38。供应商未给5.38明确季度范围和会计调节，本报告不把它冒充2027可比一致预期；也没有用不同口径PE“下降”证明低估。[金融快照][L6]
2. **保持现行倍数。**基准12个月NTM EBITDA2.070，只要继续给约14倍左右就接近现价；若目标要求一年15%回报，需要约15.7倍（用同一资本桥，见附录）。这是一种倍数／增长持续的组合，不是已经确定的市场预测。
3. **现金路径不变、改变资本成本。**按本基准核心与N现金序列，今天支持120.47约需WACC **7.50%**，其他参数保持工作值；对照4.77%十年国债，风险补偿很薄。它是反向门槛，不是公司真实资本成本。
4. **资本成本不变、延长强增长。**要支持更高价值，可以延迟2030的增速收敛、提高既有项目回报或压低维持外的投入，但必须配对新的合格产量与收益；若市场实际上相信乐观／突破路径延续，本研究对2030后增长的看法不同。
5. **只提高利润率。**不改变销售与CapEx，基准全预测期EBITDA率+2个百分点，三年价值约97.48；−2个百分点约79.25。即使+8个百分点，三年约124.83，刚接近现价，仍不满足充分的三年回报。该算例刻意保持其他成本不变，是利润率边界，不是合理预测全部组合。

没有取得严格同口径同期限的同业一致预期，因而没有伪造Entegris、MKS等可比倍数平均。竞争判断来自产品与客户原始事实；估值倍数是本公司现金／市场的明确理念假设，不声称为“同行中位数”。

主矩阵短期采用“以现金合理价值约束的事件投资”，要求6个月累计至少约8%；中期采用“经营兑现与现金转换”，要求一年约15%；长期采用“持续再投资后的复利现金”，要求年化约12%，三年累计约40.5%。这是投资筛选门槛，不是收益预测，也不在概率加权后再加一个风险罚分。稳定倍数成长理念可接受不同现金收益结构，独立结论已在4.4保留；高风险突破投资者宜要求更高的路径可达性证据，不能仅靠放宽损失承受度得到推荐。

### 6.3 早期机会概率、成功参照和等待价值

基准2031的N期望收入0.193，而完整规模状态为0.600；2036期望0.689、完整规模1.650。完整规模参照不与期望收入相加。基准2029目标日N剩余现金价值约0.371十亿美元，仅约**1.77美元／股**；突破为1.225、约5.83美元／股。其研发与资本支出在集团现金表中已付，不额外扣一遍。

从2029的信息状态出发，单独计算**2030以后**N剩余价值，保留同样后续退化／退出转移：若2029已处U／P／S／F，其工作现值约0.225／0.553／0.802／0十亿美元。这是不同信息结果的条件分支，不把S永久设100%。若把当时10个百分点概率从F转到S、其他概率不变，分布仍闭合，每股约增加**0.38美元**；不是把累计成功率每年再连乘。即使把未来分支推到S，也不足填平基准现金价值与现价的差，更不足填平三年要求回报后的退出门槛约168—169美元。

另给不加权的完整成功参照：若2029已经处S、2030—2036始终实现本表S收入、不再退化退出，逐年仍支付研发、CapEx和周转，2030以后现金在2029目标日的现值约1.068十亿美元、5.08美元／股（仍保留2041后该代技术不续存的边界）。它是净项目的上行参照，不能与已计入的0.371期望剩余值相加，也不意味着现在已经成功。

这说明独立N成功可能值得研发投入，但**仅提高玻璃／混合键合的局部成功率，很难使当前整股现金理念翻转**。要达到突破行的大收益，还需要现有CMP、PCB、TIM等平台规模同步跃升。这一结论没有把未知远期路径按零：物理AI的超大单位量、全新热接口或技术授权收费仍保留成立门槛；当前未找到可识别收费权和预算边界，不给虚构现金，研究结论仅覆盖已建模路径。

延期两年需继续支付未商业化研发／试验费，不能把收入向后移而成本不动。以N工作剩余值0.371进行仅时间近似，折现两年减少约0.067十亿美元；再加延长验证支出约0.03—0.06，共约0.10—0.13、每股0.48—0.62。这是边界算例，非重新校准的整条概率路径；两年后竞争规模也可能变小，完整重新估计会更差。对当前集团方向影响仍小于核心增长持续期。

联合“核心受损而N成功”下，早期机会不能成为隐蔽的平均公司救援；四行都拥有成熟现金业务且N研发规模可负担，故主分支概率加权没有跨越融资断点。额外2.0赔付若在2027-03-07立即发生，基准现金1.215，保留运营缓冲0.6需新增资金约1.385；即使承诺额度扣已用信用证可用约1.238，仍有约0.147缺口。可停止可选投资／回购，但即时可释放金额和提款契约不保证满足；若需按60美元融资0.15，约增2.5百万股，并有新增利息。该联合尾部应按真实条款重算，不视为已发生或主模型融资预测。

**最早有价值的证据**是付费重复批次及净单价，而不是实验指标小幅改善。等待会失去部分提前重估；提前买入能获得高端路径暴露，却同时支付了主模型尚未支持的持续增长。两者代价不对称，不能仅用“错过十倍股”或“有下行”裁决。

### 7.3 足以复算的参数与公式

**年度核心。**2026分部ST／ICS：悲观2.940／2.480、基准3.000／2.600、乐观3.040／2.680、突破3.060／2.740。2026 EBITDA对照1.560／1.700／1.780／1.830，剔除权益法0.048后为核心；其余产品分布比例与3.1一致。2027—2029按3.2各产品增速相乘。2030—2036每产品增速：

```text
g(product,year) = 0.025 + [max(0.025, g(product,2029)×0.60)−0.025]
                         ×(2036−year)/7
核心EBITDA = ST销售×ST利润率 + ICS销售×ICS利润率 − 总部费用
权益法收益对照 = 0.048×1.05^(年−2026)
集团EBITDA对照 = 核心EBITDA + N期望EBITDA + 权益法收益
实体DA = 核心销售×3% + N的期望DA
无形摊销A = max(0.030, 0.200−0.018×(年−2026))
```

税率悲观27%、基准24%、乐观23%、突破24%；年度现金利息0.240；SBC=集团销售1%；2026增量周转0.130，其后核心ΔNWC=18%×核心销售同比变化，加N周转。2026CapEx0.480，其后用3.6销售比例及N投入。历史现金每年悲观0.100、基准／乐观0.060、突破0.070；转型现金取3.6逐年序列。没有把历史费用全部计提与全部支付当同年。

```text
B = 核心EBITDA + N期望EBITDA                 # 剔除权益法、保留SBC费用
CashTax = 税率×(B−实体DA−利息−无形摊销A)
CFO估计 = B−利息−CashTax−ΔNWC−转型现金−历史现金
          +SBC−首次退出现金
报告FCF估计 = CFO估计−全部CapEx
估值FCFF = (B−实体DA)×(1−税率)+实体DA−全部CapEx−ΔNWC
           −转型现金−历史现金+税率×无形摊销A−首次退出现金
```

此税桥允许当年持续研发亏损抵集团利润；不额外计转型／历史支付的税盾，属于保守工作处理。无形摊销的现金税盾在2026—2036保留，核心终值不假定靠新收购永久续补摊销税盾。若未来税务性质不同，直接修改CashTax，而不是把GAAP税率和non-GAAP税率混用。

**季度。**2027起核心ST按全年24%／25%／26%／25%，ICS23%／25%／27%／25%，N按四季各25%。核心CFO／CapEx／FCFF按核心收入的季度比重分配，N单独等分；2026保留H1实绩，Q3分部见四季表、Q4为全年减H1减Q3。2026下半年EBITDA／CFO／CapEx／SBC分别将全年减已披露H1的余额按H2季度收入分配。季度内以覆盖日数／季度总日数计目标日前现金及目标日后NTM；DCF剩余季度现金统一在季末折现，不假设精确月度回款。

**资本桥。**从2026-06-30现金0.961、账面债4.020开始，债务按每年0.024摊还；主路径不主动加杠杆。现金增加累计报告FCF，减累计SBC抵消、每季普通股分红0.08×0.2102、少数股东实际分配每年0.030和本金摊还。合资不发现金股息，仅通过留存权益价值处理；不得再加一次合资现金。

**概率转移。**使用3.5的每行情景转移率a=U→P、b=U→F、c=P→S、d=P→F、e=S→P、f=S→F：

```text
U' = U×(1−a−b)
P' = U×a + P×(1−c−d) + S×e
S' = P×c + S×(1−e−f)
F' = F + U×b + P×d + S×f
首次退出现金 = 0.015×(U×b + P×d + S×f)
E[收入] = P'×当年部分收入 + S'×当年规模收入
```

从2026末[1,0,0,0]开始逐年计算。当年存续研发预算按U'/P'/S'状态支付；已有退出不会重生。N的净经营现金在状态内算税、研发、CapEx、退出，再加权；期望营运资本差可在线性、完全回收假设下用期望收入差复算。若改成失败库存不能回收，必须在F转移时另扣，不能隐匿在成功利润率中。
