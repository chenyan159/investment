## 二、真正需要判断的是每代系统中ALAB保住多少可收费内容

### 2.1 付款链、业务单元与利润归属

云厂/加速器平台团队决定架构与资格；ODM、分销商或模组厂可能下单付款；系统厂完成硬件集成，最终云客户判断工作负载和稳定性。ALAB主要按芯片、板卡与模组交付收费，控制权转移才确认收入；设计定点、客户验收、终端算力上电、收款并非同一个时点。因此出货领先客户使用既可能是正常备货，也可能形成后来订单消化。COSMOS帮助调试、诊断和跨产品管理，尚无可核验的独立重大订阅收入，估值只反映其对硬件中标与净价的支持。[年报，Business及Revenue Recognition][S3]

| 经济单元 | 公司实际可捕获收入 | 决定增长的机制 | 不能自动计入的邻接价值 |

### 2.2 强需求与客户控制权同时成立

客户侧的[Amazon Q2公告][S6]披露AWS收入42.2十亿美元、同比增长37%；集团TTM CFO161.4十亿美元、FCF−7.6十亿美元。这是需求和支付能力的独立支撑，也是投入消耗资本的证据。不能把Amazon全体资本开支乘一个固定百分比直接变成ALAB收入。

AWS的[Trn3商业发布及Trainium4路线][S7]与[NVIDIA的Trainium4合作说明][S8]共同显示，客户正在部署加速平台，但下一代也可采用NVLink Fusion。**“自研加速器更多”既可增加ALAB订单，也可把交换、PHY或配套内容分配给其他方案。** ALAB已有客户联系和共设计能力提高保留资格的可能，采购方仍控制协议、机架拓扑和订单时点。2025年超过70%的最终客户集中度不能直接替代2026年未知的比例，也不能无披露将该客户正式命名；Amazon权证证明双方合作，未公开证明每一个匿名财报客户的身份。

Amazon新权证原始8-K的关键限定是“**up to a total of $6.5 billion**”。其经济对象是采购付款达到条件后的股权激励：最多3.262299百万股，行权价142.82美元，可无现金行权，期限至2033-02-05。具体产品分档部分删节；交换相关归属还受旧Scorpio权证条件次序约束。**65亿美元不是存续不可撤销订单、最低承诺、预收款、融资额度或ALAB可追索的应收款**。目前公开文件不足以计算剩余确定采购余额。它支持长期合作范围和买方议价的判断，不能保证情景收入。[2026-02-10 8-K，Item 1.01][S9] [2月5日权证，Vesting Event/Vesting Payments条款][S10]

## 四、从经营机制独立形成四条连续路径

### 4.1 共同事实、不同经济条件

四行都固定已实现2026H1，未来采用不同客户采用、竞争和投入路径。**四行没有先乘发生概率，亦不构成互斥穷尽分布。** 主表没有另加“Leo期权价值”“光学TAM价值”或软件ARR；每个机会只进入一次收入、费用、现金及股权模型。

### 5.2 持续SBC与权证只付一次代价

`V_T = B_T × P_T + Σ[路径权证数量 × Call(P_T,行权价,剩余期)]`

`FD等价股数_T = B_T + 权证价值_T/P_T；P_T = V_T / FD等价股数_T`

其中V是目标日经营归属值＋可用现金＋员工低价期权行权等价资金1.507M；**客户权证没有额外加入假定行权现金**。FD表是期权价值等价摊薄，非会计EPS库存股法的报告股数；与全部客户权证现金行权的法定最大股数有所不同。权证期权价值按本行内生合理价求解，不拿303.25固定计算所有行。股票期权简化忽略复杂加速条款/不可转让折价；对总值影响很小，披露而不制造精确法律定价。

### 5.3 目标日DCF与每股归属

主方法为逐期股东可归属现金DCF，先算行内经营和资本，再算每股，**没有平均收入×平均毛利率**。未来既有股东份额下降用`B_T/B_t`调整，在目标日口径形成“归属经营价值”。这不是未经稀释调整的传统EV；若用常规企业价值比较，必须加回被未来新奖励分走的权益。

`EBIT = Σ产品收入×产品毛利率 − 现金口径费用 − SBC`

`FCFE = EBIT − 正常化现金税 + SBC + 客户权证非现金抵减 + D&A − 全部CapEx − Δ经营营运资本 − 并购现金`

`经营归属值_T = Σ(T后FCFE_t × B_T/B_t ÷ (1+r)^(t−T)) + 按相同股本归属的终值`

历史6月末现金作为起点，目标日前FCFE逐期留存一次；目标日后DCF只含其后现金。没有分红、回购或额外现金收益率假设；不把目标日前累积现金再作为未来经营流量。现金利息不计，略低估流动资产回报；即使在4—6B上多计若干年利息，量级也不足以填补基准缺口。正EBIT现金税H2用12%、2027后18%，受损可抵当年亏损，未计无限期负税或递延税资产释放，25%另检验。

终值下一年正常现金先重算成熟营运资本投资，再按每股增长`g_s=(1+g)/(1+d)−1`资本化，不能用公司3%增长替代每股约1%增长。折现率10%—12%区间形成十二格价值上下沿；**这些区间只覆盖同一经营路径下的资本价格误差，不是经营全部可能范围或统计置信区间**。费用、收入、持续时间的独立误差见第七节。

### 8.2 条件合理价值不是可能成交价

在高增长硬件股中，短期市场可以继续按很高的远期利润倍数交易。作为A的定价压力检查：若2027-09市场给“正常化现金口径经营收益（税后、扣持续资本并考虑股权代价）”高达40—60倍，而这些收益每股仅4—6美元，就可形成约160—360美元的交易区间；若预期迅速上调到8美元且倍数不降，可能达到320—480美元。这些收益/倍数组合是**算例，不是已核验的一致预期或预测概率区间**，不进入矩阵合理价值。

其用途是说明：财报好、价格上涨和经济价值不足可同时存在；不能仅凭DCF给出可执行的短期跌幅预测。由于无法可靠确定市场会何时接受哪种持续性解释，本报告对6/12个月**可能交易价格的定量预测为NA**；可辨认的是回报高度依赖更强预期及高倍数留存，正常达标可能仍不足。长周期DCF的时间推进也未被当成股价必涨11%的保证。

### 附录B：复算公式与简短代码

将附录A及季度表转成`periods`（每项含start/end/fcfe），下列核心可复核任一目标日；单位全部百万美元和百万股。现有奖励184.733104、低价期权资金1.50677来自第五节。`cf6`是历史6月末之后截至目标日的现金，`last`为最终显式年度。主表末年2035；延长解释末年2040。日期差/365.25用于连续时间，现金分摊按实际季度天数。

```python
from math import log, sqrt, exp, erf
def call(p, k, tau, rf=.045, vol=.55):
    if tau <= 0: return max(p-k, 0)
    N = lambda z: (1+erf(z/sqrt(2)))/2
    z = (log(p/k)+(rf+vol*vol/2)*tau)/(vol*sqrt(tau))
    return p*N(z)-k*exp(-rf*tau)*N(z-vol*sqrt(tau))
def core(T, r, d, g, periods_after_T, cash_T, last,
         years_to_end, old_tau, new_tau, old_n, new_n, elapsed):
    B = 184.733104*(1+d)**elapsed
    op = sum(cf/(1+d)**dt/(1+r)**dt for cf,dt in periods_after_T)
    R, margin, sbc_ratio, cap_ratio, wc_ratio = last
    Fnext = R*(1+g)*(margin*.82+sbc_ratio+.012-cap_ratio)-R*g*wc_ratio
    gs = (1+g)/(1+d)-1
    terminal = Fnext/(1+d)/(r-gs)/(1+d)**years_to_end/(1+r)**years_to_end
    V = op+terminal+cash_T+1.693*.89
    lo, hi = .0001, V/B
    for _ in range(80):
        p=(lo+hi)/2
        W=old_n*call(p,20.34,old_tau)+new_n*call(p,142.82,new_tau)
        if B*p+W > V: hi=p
        else: lo=p
    p=(lo+hi)/2
    return V, p, V/p   # FD权益总额、每股价值、FD等价股数
```
