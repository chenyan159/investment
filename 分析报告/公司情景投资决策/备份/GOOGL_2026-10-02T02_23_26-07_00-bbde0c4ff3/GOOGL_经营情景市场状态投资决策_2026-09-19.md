## 一、先解决两项会让估值失真的问题

### 1.1 低市盈率含有投资重估，不能代表核心业务便宜

2026Q2收入119.796B、经营利润40.770B；净利润112.193B，股权证券收益对税后净利润净贡献77.1B。减去该项仅得35.093B，仍不是完整正常化净利润。估值从经营利润和现金开始，已持有证券只在非经营资产中计一次，不把重估收益永续化。[S02]

本地9月18日快照的TTM EPS为19.94、PE为17.53；forward EPS为14.86、forward PE为23.53，但接口未提供该前瞻字段的精确财年及一致预期更新时间。因此这些只是当日市场字段，不作为本模型的经营预期。349.54×12.230约为4,274.9B；快照中的“市值重算bad(52%)”主要来自类别股数不匹配，不能据此将全公司市值减半。[L03；C]

### 1.2 Cloud已不是一种收入，一笔TPU不能同时卖两次

Q2 Cloud收入24.768B、分部经营利润8.814B。本季首次确认交付客户机房的TPU系统收入。硬件及软件控制权转移、安装支持履约的时间不同；部分安排存在按退货权处理的选项。服务合同、系统合同、库存及Google自用服务器不能混为同一现金模式。[S03，Notes 1—2]

管理层明确未披露TPU独立利润率；并称剔除系统销售后Cloud仍加速、现有系统协议绝大多数收入预计在2027年实现、第三方过渡容量将压低近期利润率。它支持需求存在，不能证明系统的净价、毛利或回款质量，也不能将82%的季度增速永久外推。[S04]

本模型合并披露Cloud总额，再以**Cloud服务／TPU外销**两个研究单元预测。消费者Gemini收入在订阅平台设备，企业Gemini在Cloud，AI搜索在搜索；TPU自用体现成本和资本效率，**不另列自供收入**。不再给“Gemini”“TPU平台”“AGI”加一个与这些现金重复的独立市值。

## 四、最决定价值的业务路径

### 4.1 搜索：商业意图能保住，AI仍可能把单位利润压低

Q2搜索付费点击+13%、CPC+3%，乘积约+16.4%，接近收入+16.8%；搜索尚未发生收入层面的结构坍塌。AI广告工具的采用与管理层转化改善说法支持可用性，但同源案例不等于独立增量销售实验。[S03][S04]

收入机制为“有效商业任务×可售互动／任务×净互动价格”。基准从2026参考约265B到第一年290、第三年350、第七年460B；相当于第一年量增长约7%与净价／组合约2%，随后减速。长期并不需要总查询数都商业化。第七年460B相当于参考期收入1.74倍；若全球相关预算年均增长6%—8%，份额无需跃升，关键是保持商业参与及收费权。这里的全球预算增速是检验假设，不是引用行业报告的预测结论。

基准搜索营业利润率46%→46%→45%，至第15年43%，已经计入AI回答更贵、分发与监管成本；这一研究分配不是公司公布搜索利润率。历史Services41.8%包含低／高毛利多种产品，无法唯一识别搜索利润：合理搜索起点约46%—52%，与其他单元搭配可接近分部利润。因此本报告用利润率敏感性处理不可识别性，不把财务残差当产品收入。

受损机制是高意图预算向购物代理／零售媒体转移，默认分发竞争更开放，推理和内容成本上升；搜索收入第七年240B、利润率32%。这是**永久收费能力受损**，不只是一次季节失速。乐观570B、48%来自高转化的新商业任务与成本摊薄；突破620B、49%来自代理式商业入口，但仍保留TAC和研发。

最强反解释是用户更少点击外链却给出更多商业意图，Google获取每次成功交易的价值上升。Pew的观察样本显示有AI摘要时外链点击较低，但样本查询不完全同质，不能将点击下降直接等同Google收入下降。[S10] 能裁决的指标是搜索收入、商业点击、净价／组合及成本同时改善，而不是单看Gemini月活。

2026-09-16公布的广告技术救济涉及Prebid整合、数据导出、AdWords非歧视投标和六年监督；搜索案也限制特定排他分发并要求数据及联合供给安排。已知措施不等于立即拆分，但会改变竞价连接和渠道租金。本模型让Network持续缩水，并在搜索受损路径压利润；不凭监管新闻标题机械扣一笔“分拆折价”。[S07][S08]

### 4.2 Cloud：先兑现合同，再证明跨代资本回报

客户侧Anthropic确认新一轮多GW TPU容量安排预计从2027年上线；HSBC公告验证金融工作流采购，Apple的Private Cloud Compute说明则提醒：采用Google技术不等于全部计算都在GCP付费运行。这些是不同合同和部署边界的证据，不能把同一家客户需求沿供应链重复相加。[S11][S12][S13]

**Cloud服务研究模型**包含传统计算、存储、数据库、Workspace、Wiz及企业AI；系统销售另计。第一／三／七年服务收入基准120／195／340B，TPU外销35／55／80B，总Cloud155／250／420B。前两预测年Cloud合计约357.5B；6月末RPO约260B以上在其后24个月确认只是重叠日历窗口的一部分，两者不能精确对齐，但数量级要求可由既有合同、期间新增及非承诺用量共同支持，绝非把全部RPO当第一年收入。

第一年120B服务收入可以理解为参考约87B的服务量增长45%与有效单位价下降5%左右共同作用；第三年前需要持续新增部署。第七年340B要求其后服务量中高双位数扩张、价格按任务而非token单价考察，不能把token翻倍直接换成收入翻倍。基准Cloud服务利润率31%→32%→34%，TPU20%→19%→17%；硬件利润率随规模和竞争成熟下行。共用研发另扣32／43／60B，不把服务利润当完全独立云厂利润。

**TPU外销的数量级校验〔H〕：**第七年80B若每个加速器等价系统单元可实现2万—4万美元的含系统净价，需要约200万—400万个单位／年；若以更大集群合同为单位，必须保持相同总额。Google没有披露可据此验证的交付单价，此算例仅检查供应、库存和售后压力，不是芯片出货预测。模型库存与其他营运资本按增量收入6.5%—9%配置，自用系统计CapEx，外销系统采购通过营业成本／库存处理。

基准资本开支第一／三／七年245／255／260B，折旧55／100／165B。2026指引195—205B且2027显著上升，是首年245B的约束；并非继承本地公司报告的255B预测。新增服务器、建设爬坡和会计折旧存在滞后，经济上采用服务器约4—6年、机电约10—15年、建筑更长的更新周期工作范围。折旧不是维持投入的精确估计：第七年仍CapEx>折旧95B，不能把增长全部视为无资本的软件利润。

用增量回报检查：基准第三至七年归属经营税后利润增长约92B，四个年度净设备投入与营运资本增加约503B，粗略税后增量回报约18%，尚需成熟容量的可用性和续约支撑；它不是已经实现的ROIC。若服务器每四年必须全部高价替换、利用率低于约60%或客户净价下降快于成本下降，资本回收会明显劣化。相反，TPU平台复用、推理效率提升和使用率超过约75%可把建设高峰后的现金释放提前。

**突破的最少必要成功**是：企业工作流形成持续付款而非试用；Google有足够电力与交付能力；任务成本下降快于净价；搜索现金池未同时崩坏。无需药物、量子、所有机器人业务一起成功。突破Cloud服务第七年700B、外销180B，全部Cloud880B；共享研发125B、CapEx495B，故突破前三年自由现金更低。原始客户合同证明路径入口，尚不证明如此大的最终客户预算。因此只给低权重和低估值置信度。

### 4.3 YouTube、订阅与Network：组合变化不能凭标签加价

基准YouTube广告51／65／95B、利润率28%／30%／32%；视频供给、CTV使用和效果广告共同扩大，创作者分成随收入增长。订阅平台设备62／85／135B、利润率23%／25%／28%，包含消费者AI；净增来自付费人数、净ARPU及硬件组合，不能将完整AI套餐收入再加给Gemini。用户在Premium免广告与广告层迁移，两种路径不会各按全部用户量计算。

第七年订阅平台设备135B比参考55B多80B；若其中一半由AI套餐净增贡献，以每月10—15美元**净增**收费需约2.2亿—3.3亿等效全年付费用户。该量级很大，不能由9.5亿免费月活直接推定。若套餐主要蚕食原One收入，合并收入和利润率都应下修。Network基准28→25→20B，因流量及监管长期承压，不为“AI广告”标签恢复历史高速增长。

### 4.4 Waymo：真实商业化，仍需证明车队现金回收

2月融资16B、投后估值126B为私人融资交易，Alphabet为重要支持方但本次未查得足以精确复原持股的完整资本表。9月14日拉斯维加斯向首批公众乘客开放，9月17日公告新加坡2027准备、2028商业推出计划：前者是进入运营，后者仍是目标，不提前确认为收入。[S14][S15][S16]

基准一／三／七年Waymo合并收入2／6／22B，营业利润−2／−2.1／2.64B；第七年按每次18美元净收入需约12.2亿次全年出行，约2,350万次／周。若每车每天25次、每年有效运营330天，需约14.8万辆活跃车；6万—10万美元全套部署成本对应约9—15B车队资产，另有闲置、场站及地域爬坡。第七年资本预算按收入40%约8.8B、折旧15%约3.3B，因此即使营业盈利，仍可现金为负。数量、价格及车辆成本全部是研究假设，不能把公众测试人数当付费常客。

合并范围上在集团表保留100%Waymo收入和营业利润；价值与资金表按70%经济归属工作值，另30%现金由外部权益方按比例承担，50%—85%为合理权益敏感范围。**这不是查明的持股比例。**若外部股东不继续出资，Alphabet必须多承担现金或允许稀释；未来亏损不因少数股权存在自动消失。第七年前亏损仍保留，成熟路径的盈利计入七年后DCF，未用126B融资估值替代内在价值。

本模型为跨城扩展保留偏高的车队及设施投入，至第15年仍以收入40%计CapEx，之后成熟增长回落时改用终值再投资约束。在这种资金路径下，Waymo归属净现值约**−9B**，尽管未扣资本前的税后经营收益现值为正。这个结果首先说明车队资本假设很重要，不是认定Waymo技术没有价值：投入若长期只需收入20%且保持所需车辆、覆盖和服务质量，净值会明显改善，需相应重算。较低持股比例在当前负净现金路径反而减少出资负担，50%—85%权益单项变化约影响+0.2至−0.2美元／股；不应机械认定持股越多每股价值必然越高。

受损为城市扩展和运营规模受限；乐观为更低车辆成本和更高密度；突破为跨城市复制与车队使用率跃升。安全与监管中断会同时降低收入、提高保险／维护并延迟资金回收。车辆投放数、每车付费里程、每次全成本和更新周期，比新增城市名单更接近股东价值。

### 4.5 药物、机器人、量子与其他期权的覆盖边界

Isomorphic 2024两项药企合作前付款合计82.5百万美元，约3B潜在总值包含大量有条件里程碑，并非现有收入；2026融资2.1B进一步支持研发但不验证临床疗效。进入路径为候选物设计→临床安全和疗效→监管→销售分成，不能跳过十年左右的药物商业周期。机器人能力到工业采购还需可靠性、集成、责任分配和售后；量子需客户任务的全成本优势及容错扩展，技术论文不等于可规模收费。[S17][S18][S19][S20]

本模型“其他探索”每年费用4—15B继续计入，未可靠识别的远期正现金**不强行填入中心估值**，也不声称这些业务真实价值为零。覆盖误差给出明确门槛：即使额外归属净现值100B，也仅约8.1美元／股；基准与现价差约2,047B，需约2万亿美元额外净现值才独立补足。若一种未识别机会真能贡献这种量级，必须重建模型。融资新闻或药企里程碑上限远不足以坐实该金额。

## 五、连续路径、概率与年度资本闭合

模型以研究日为t=0，t=1／3／7分别为**2027-09-19／2029-09-19／2033-09-19**。年度流量是前一周年至该周年的完整12个月，不是日历财年，也不是目标日期末运行速度。t=15为2041-09-19，之后进入成熟更新状态。四行同一分期规则，中间年份按相邻节点线性插值收入与利润率，再逐年相乘；不插值价值，不把平均收入乘平均利润率。

行内基准Waymo等已固定为该路径的商业结果，不再次乘同一成功概率。若读者对其把握较低，应移动整体路径权重或替换该业务的现金序列；不能先把收入打成功折扣，再给该行乘一次失败概率。不同日期未新增证据时，累计商业化机会可以增加，持续盈利概率并不会机械增加。

### 5.2 从利润到现金、融资和股数

主模型税率20%作用于经营利润，未来需持续研发的成本已扣。集团FCFF为“营业利润×80%＋折旧−资本开支−经营营运资金增加−额外现金项目”。额外项目包含未重复计入正常成本的历史法律支付、信用损失、未来外部投资资金；保守不追加对应投资资产价值。Waymo再扣30%少数权益对应的FCFF，而不是扣其全部私人融资估值。

营运资金系数为增量收入的悲9%、基7%、乐／突6.5%，再加必须经营现金增加：`M_t=40+2%×max(收入_t−495,0)`。M的增加在FCFF扣除，但只是在公司现金中保留，融资表加回这项内部现金转移；目标日仅把现金减M后的部分作为非经营资产。正常税率20%不代表每年现金税完全相同，提前税盾和递延差异用贴现／现金敏感范围承接，不把H1税务流入永续化。

股权薪酬采用**现金替代成本法**：各营业利润率保留持续员工股权报酬的经济费用，不在FCFF加回SBC；假设未来奖励以等值现金或同步经济对冲支付，故不另增加同一奖励的股数。不是声称公司已选择现金发薪。6月末未归属奖励294百万股、未确认费用59.1B已是未来报酬成本的一部分；不再将294百万股全加分母同时保留全部现金替代费用。若市价涨幅使置换成本超预算，需提高费用：每年多10B经济薪酬、持续15年，至少减少约60—80B现值，约5—7美元／股，若永久持续影响更大。[S03，Note 13]

优先股以19.25百万股×每股1,000美元清算额计算年股息1.203125B，至2029年5月强制转股。A类转换率2.2520—2.8160、C类2.2740—2.8420，约43.56—54.46百万股总新增；模型采用54.458百万上限并从今天使用经济稀释分母12.284458，2029年后转为实际模拟股数。**既然按转换稀释处理，不再扣19.25B本金。**转换前的未来优先股现金股息另留现值。最后年度用8个月近似；严格日计差不足0.01美元／股。[S03]

### 6.2 现价要求什么

同一模型反求：保持基准业务和再投资，需将贴现率从9.5%降到约**6.69%**才使当前价值接近349.54美元，距离10年国债只约1.7个百分点风险补偿。它是数学等价，不证明市场真的使用6.69%。或者固定9.5%及其他业务，将Cloud服务规模按约**4.52倍**提升，同时增加相应共享研发、资本开支和折旧，才大致补足；对应第七年服务收入约**1,538B**，另加TPU外销80B。该路线依赖极大终端预算及供给，明显强于本报告基准。

这两条反求均不是唯一解释。市场还可能假定更低资本支出、更多硬件外销而非自建、可收费代理的更高利润、证券投资升值、或本模型没识别的期权。仅凭现价不能声称某项机会“未被定价”。本次只认定：用已查实的入口和本研究独立现金假设，现价没有显示足够的可辨认优势。

Waymo独立采用突破规模并增加车辆投入及折旧，其他业务不变，当前每股只增加约2.4美元。原因是需要大量车队资金，归属70%，且大额盈利较晚；这与126B私人融资估值并不矛盾，后者包括投资者对更大、更快及更低资本路径的判断。若Waymo转为高毛利授权、由伙伴承担车队，本模型须改变收费、分成与资本三项，而不是只把CapEx删掉。

**延迟的量级。**若基准2028—2033六年增量现金各后移一年，且没有减少必要维持成本，仅按9.5%折现就损失被延迟现金现值的约8.7%；另有外租、合同及融资成本。延期后能追回血量与永久降价不同。若延期的是突破Cloud，前三年负现金持续更久，不能同时保留原债务峰值。

概率替代分布（悲／基／乐／突）采用15/40/30/15的积极版、35/45/17/3的审慎版，均归一并先算每条路径权益。积极版一年／三年／七年期末财富约237／284／407美元，对应年化约−32.3%／−6.7%／2.2%；审慎版约167／200／285美元。**只重新分配目前四条路径的概率，仍不足令中心值达到10%持有要求。**这说明关键翻转是规模、资本效率或贴现，而不是争论突破概率到底7%还是10%。

在只含基准与突破的二分算例中，达到10%持有回报所需突破概率约102%／102%／102%，无可行解；这不是实际概率估计，只说明最强行中心本身仍略低于该标准。若要求8%，突破行可满足，且行内估值高端也可支持更积极参与。但没有证据让今天整个股票等同已经确认的突破路径。

### 参与、等待与错过上涨的代价

一年：资本开支兑现比单位回报验证更快，缺乏可信一年价格优势，**不建议投资**。三年：将经历TPU交付及资本高峰，基准的价值释放不足补偿349.54美元买价，**不建议投资**。七年：重大机会有时间出现，但基准几乎不能提供正实质持有回报，当前选择为**中性／等待**；它表示等更好价格或更有辨别力的现金证据，不表示已经证明择时策略占优。

按当前工作分布的目标日期末财富与10%要求反算，一／三／七年可付价格约**180／178／174美元**。这是模型条件下的参与线，不是未来一定能买到的限价；8%—12%要求会使七年阈值约153—197美元。经营证据显著改善可以提高阈值，而不必坚持旧价格。

同初始资金349.54美元、同一2029-09-19目标日的等待算例：等一年持现金按4.44%变为365.06美元；若确认后买价为400美元，只能买0.913股，相比现在持有一股和首年分红，约少9%的股票数量；若届时250美元可买1.460股，但可能是业务永久受损而非同等资产打折。两策略之后均可根据相同公开信息调整，示例未建交易价格概率，因此不声称等待收益确定更高。高风险投资者若强信突破与低资本路线、能承受受损行的大额损失，可小额参与；这属于不同证据／要求，不是本报告一般选择。

## 九、局限、反证与交付核验

本研究明确未解决的决定性变量为：TPU客户级经济条款及毛利、Cloud服务／系统收入精确拆分、AI搜索全成本、Waymo持股与每次完全成本、未公布的季度现金和ATM执行、外部股权投资实时税后可售额。已先查原始披露与指向材料，再用范围承接；不能把“未分拆利润”说成“没有相关收入／合同”。

中心模型最大的可争辩处是持续资本强度、共享研发及长期收益风险。若Google能在不损失未来能力的前提下长期减少建设／更新，或将大量资本责任转给采购方并维持服务定价，本报告可能低估价值；反之，若客户贷款与云采购相互支持却没有终端现金，模型可能仍高估。1930年代式宏观崩溃或不可预见法律清偿没有逐一建模；四状态是宽结果区间的决策近似，不是穷尽现实。

交付前已核验：七单元收入和利润到集团桥接；分红从现金扣且只给持有人一次；优先股转换不再扣本金；SBC保留成本不再重复稀释；Waymo100%经营到70%现金归属；经营储备增加与现金账户内部转移；四条路径融资后不低于储备；当前与目标日DCF现金切分；全部十二格股权／股数／总回报／年化一致。对重要结果以反向递推DCF独立于直接求和复核，误差低于1e-8 B。资本超支、利润率下降、贴现率上升的价值方向均符合经济机制。**年度流动性模型不等于已经核实每季度融资可得，未来市场成交价格也未被验证。**

### 附件：集中模型与复算代码

以下Python只用标准库。参数矩阵依次为搜索、YouTube广告、Network、订阅平台设备、Cloud服务、TPU外销、Waymo；四个节点为t=1、3、7、15。现金、债务、分红、稀释和目标日估值都从这份模型计算。可复制为临时脚本运行；不需要另一份正式报告。代码输出结果比展示表保留更多数位，不能据此提高预测置信度。

def interp(a,t):
    if t<=1:return a[0]
    for i in range(1,len(ANCH)):
        if t<=ANCH[i]:
            z=(t-ANCH[i-1])/(ANCH[i]-ANCH[i-1])
            if isinstance(a[0],list):return [x+(y-x)*z for x,y in zip(a[i-1],a[i])]
            return a[i-1]+(a[i]-a[i-1])*z
    return a[-1]

def run(name, override=None, dr=0,dg=0):
    q=copy.deepcopy(PARAM[name]);q.update(override or {})
    cash,debt,shares,inv=120.,101.1,N0,175.
    out=[]; cumulative=0.;sold=0.; prevrev=495.
    for t in range(1,16):
        rev=interp(q['rev'],t); mar=interp(q['mar'],t)
        # Full consolidated operating result, then parent cash attribution for Waymo.
        profit=[a*b for a,b in zip(rev,mar)]
        common,other=interp(q['common'],t),interp(q['other'],t)
        ebit=sum(profit)-common-other
        attributable=ebit-.30*profit[-1]
        total=sum(rev); da=interp(q['dep'],t);cap=interp(q['cap'],t)
        minimum=40+.02*max(total-495,0)

        dminimum=minimum-oldminimum
        dnwc=q['nwc']*(total-prevrev)+dminimum
        # Net future portfolio funding / litigation / guarantees: zero salvage, no duplicate asset addition.
        extra=interp(q['extra'],t) if t<=7 else 0
        if name=='悲观' and t==2:extra+=20
        wprev=interp(q['rev'],max(t-1,1))[-1] if t>1 else 1.
        wda=rev[-1]*.15; wcap=rev[-1]*.40; wnw=.03*(rev[-1]-wprev)
        wfcf=profit[-1]*.80+wda-wcap-wnw
        groupfcf=ebit*.80+da-cap-dnwc-extra
        fcf=groupfcf-.30*wfcf
        interest=debt*q['rate']*.80
        pref=1.203125 if t<3 else (1.203125*8/12 if t==3 else 0.)
        if t==3:shares+=.05445825 # upper conversion bound; capped call upside sensitivity disclosed
        div=.88*1.05**(t-1)
        if name=='悲观' and t>=2:div=.44
        cash+=fcf+dminimum-interest+max(cash-oldminimum,0)*.03-pref-div*shares
        borrowing=issuance=sale=repay=0.
        inv=interp(q['inv'],t)-sold
        if cash<minimum:
            borrowing=min(minimum-cash,max(0,1.5*(max(attributable,0)+da)-debt))
            cash+=borrowing;debt+=borrowing
        if cash<minimum:
            sale=min(minimum-cash,max(inv,0)*.5); cash+=sale;inv-=sale;sold+=sale
        if cash<minimum:
            issuance=minimum-cash
            issueprice=PRICE*.60*(total/495)**.5
            shares+=issuance/issueprice;cash+=issuance
        if cash>minimum+50 and debt>20:
            repay=min(cash-minimum-50,debt-20);cash-=repay;debt-=repay
        cumulative+=div
        out.append(dict(t=t,rev=total,byrev=rev,byprofit=profit,ebit=ebit,attr=attributable,
          da=da,cap=cap,dnwc=dnwc,extra=extra,fcf=fcf,groupfcf=groupfcf,wfcf=wfcf,cash=cash,debt=debt,
          shares=shares,inv=inv,div=div,cumdiv=cumulative,borrow=borrowing,
          issue=issuance,sale=sale,repay=repay,interest=interest,pref=pref,minimum=minimum))
        prevrev=total
    r=q['r']+dr;g=q['g']+dg
    # Remaining assets need replacement; terminal reinvestment g/ROIC, including working capital.
    terminal=out[-1]['attr']*.8*(1+g)*(1-g/q['roic'])/(r-g)
    vals={}

        n=z['shares']+(.05445825 if h<3 else 0)
