# SpaceX：经营情景、价值传导与分期限投资决策

> 研究标识：**SPACEX**；实际证券：**Space Exploration Technologies Corp. A类普通股，NASDAQ / Nasdaq Texas：SPCX**。研究日期：2026-09-08。唯一正式交付文件：`分析报告/公司情景投资决策/结果/SPACEX_经营情景市场状态投资决策_2026-09-08.md`。
>
> **当前选择：短期不建议以经营价值为依据买入；中期不建议投资；长期的稳健复利与高风险突破两种理念，目前均以不参与、等待重新核验为主。**这不等于预测股价即将按模型下跌。主要限制是当前约2万亿美元股权价格与可验证现金权益之间的距离，以及远期成功、融资和折现率的共同敏感性。长增长、低风险补偿的最强相反路径可以支持参与，但它需要的证据尚未形成。
>
> F＝已披露事实；G＝管理层目标或未来合同安排；E＝本研究推断／情景假设；U＝未知。财务数据为美元；**B＝十亿美元，M＝百万；股数B＝十亿股**。预测小数只用于复算，不表示相应精度。报告内全部未来年度与目标价值均为E。

## 1. 当前三个期限的判断、时点与价格口径

### 1.1 当前行动及真正的理念分歧

| 期限及目标日 | 当前实际选择 | 主要理念、预期差与窗口内证据 | 最强相反选择及为何未采用 |
|---|---|---|---|
| 3个月：2026-12-08；短期主矩阵6个月：2027-03-08 | **不建议基于经营价值立即买入；里程碑交易等待** | 市场已支付网络扩张、AI商业化和远期平台价值。三个月可观察Cursor供模转换、Q3现金及Starship工程；六个月多一个完整财报窗口，较有机会观察续约和支出。仅确认高增长，未必改变价格所要求的十年以上收益 | 新飞行成功、模型进步可能快速推高远期定价，这是有效的交易论点。但现有公开事件不足以辨识价格采纳幅度；不能把短期现金折现滚动当成可能成交价。若新增付费及低成本证据共同形成且价格未先大涨，才重开交易判断 |
| 12个月：2027-09-08 | **不建议投资** | 经营兑现与现金转换。基准研究年收入50.25B、CFO25.21B、CapEx55.45B，仍消耗现金；期末约52.56B流动性来自融资储备消耗后的余额。前瞻下一研究年收入约60.78B，不能单独支撑约2.1T完全稀释工作市值 | 乐观路径收入、利润改善明显，但新增AI资产仍要支付、更新。即使乐观条件成立，现金价值区间也低于买价；需要商业模式和长期资本回报一起跃迁，而非只达到一年交付目标 |
| 36个月：2029-09-08 | **稳健理念不建议；高风险突破理念目前亦不建议，保留有条件参与** | 网络壁垒、开发者入口和计算基础设施确有巨大机会；本研究把十年内商业化及其后十年成长衰减都纳入。主突破行三年价值约96—200美元，工作参数点约123美元；即使上端约35%累计回报，年化约10.6%，对该路径不稳健 | 同一突破经营、把长期资本风险补偿降至8%—8.5%、终值增长取4%—4.5%，三年价值约249—326美元，可以支持高风险参与。但目前无可撤销性低的长期算力回款、成熟快速复用和成果收费的联合证据，不能以该有利参数端裁决现价 |

**最少关键条件不是“所有愿景都成功”。**最强上行只需要：Starship/V3把热点容量及部署成本显著改善；地面AI不止过桥租赁而能覆盖多轮设备更新；Cursor/Grok取得可持续成果收费。轨道AI可以只部分成功，Terafab、火星城市及点对点客运可以缺席。反之，只有轨道AI、Mobile或Agent中一项按本报告定义完整成功，而核心维持普通，仍不足以支撑147.95美元买价（第6节）。

**当前更支持“核心接近基准、AI资本回报尚未验证”的路径。**这不是统计P50，也没有把四行分配成精确发生概率。Starlink事实较强；长期AI复利、资本纪律和不同业务之间的资本竞争，仍有足以翻转选择的分歧。

**集团边界改变了投资对象。**SPCX普通股不能隔离领取Starlink现金。SpaceX已经包括xAI/X及Cursor；Tesla的汽车、Optimus和Robotaxi不在合并模型。Mesh Optical可提供光互连能力，但没有可分离收入证据。Terafab合作的权益、资金和IP尚未清晰，不能默认全部制造利润归SpaceX。[S1][S3][S5]

**最有证据的协同**是制造—发射—卫星—网络收费：更低的内部部署成本可以留在网络利润中。最弱的现成协同是“火箭领导地位直接保证地面GPU租赁定价权”。地面云仍面对客户自建、TPU/ASIC、其他云和硬件更新；让Colossus服务第三方也会与Grok自训争用资源。

### 2.2 共用财务事实及现金质量

以下事实四行共用；没有为悲观行改写已经披露的收入。年度共同控制追溯口径来自招股书，中期来自10-Q；B。[S1][S3]

|---|---:|---:|---:|
| 收入 | 18.674 | 12.508 | 7.814 |
| 经营利润 | -2.589 | -2.086 | -0.143 |
| 净利润 | -4.937 | -4.817 | -0.541 |
| 经营现金流 | 6.785 | 3.466 | 2.419（H1减Q1） |
| 购建固定资产 | 20.737 | 28.476 | 18.369 |
| CFO减上述CapEx | -13.952 | -25.010 | -15.950 |

Q2分部收入Space/Connectivity/AI分别0.962/4.291/2.561B，经营利润分别-0.542/+1.656/-1.257B。Connectivity是盈利锚；集团尚未取得持续自给现金。Q2调整后EBITDA3.538B与经营亏损之间，包括2.848B折旧摊销、0.831B股份报酬等，不能以EBITDA倍数绕开设备更新。[S2]

财务质量有四个实质检查：

1. **收入质量。**47.461B backlog与14.1B云“contracted sales”嵌套，前者约56%预期一年内确认；它们不能与15B/年合同标价重复相加。客户A/B占Q2收入18.3%/19.5%，不能因消费用户数多就认为集团无大客户风险；匿名客户不强行映射名称。
2. **现金转换。**应收余额由1.579增至3.596B；H1应收现金占用2.003B、递延收入现金贡献2.169B。新云合同和政府进度可解释，缺少逐客户账龄，不足以认定坏账，也不足以认定回款无风险。
3. **资产经济寿命。**服务器及网络原值34.771B，账面常见5—6年寿命；假定经济寿命缩至4年，仅该原值静态年更新消耗就可能多约2.4B；缩至3年约多5.3B。这是压力算例，不是认定财报错误。未来投入不能全部称为可自由停掉的成长投资。
4. **资本权益。**受限现金0.830B不加入流动性；债务本金39.512B已含融资租赁与不满足出售条件的设备融资。27.955B承诺混合现金、设备与股票，不能再全部作为债务从估值扣掉；相应实际投入和频谱付款已经进入现金路径。数字资产1.098B不当等额现金，正面估值暂不加回，影响约0.08美元/股。[S1][L1]

当前净现金工作值约46.5B，只有约3.3美元/完全稀释工作股；还须支付投资与频谱。它提供执行时间，不构成147.95美元的资产底价。债务主要长期固定票息，眼前风险是投资消耗及续期，未来新融资仍受利率影响。

**频谱与并购。**EchoStar主体交易19.6B与另行过渡债务服务不能混同；最多约261.8M股按合同42.40美元计价，这不是现价。最终收购仍以2027年11月30日为目标。模型在Y1扣0.8B、Y2扣10.5B现金，在Y2加入0.2618B股，不再以媒体“20B”整笔额外扣除。[S9] Cursor主要换股，不能再假设现金流出60B。购买价分配未完成部分的摊销取工作参数，不冒充披露。

治理方面，B类10票、创始人控制权使普通股无法强制将Starlink现金分配；关联采购、模型合作及探索工程可能有战略收益但不必等比例惠及少数股东。没有证据在此认定舞弊。监管、AI版权/数据诉讼、对政府网络的地缘依赖，分别通过准入、客户预算、研发法务及折现风险进入模型，不另叠一项无来源的“治理折价”。

### 3.4 三项早期机会：先定义客户经济性和状态

**A：Mobile升级净增量。**基础补盲收入留在EG。P为少量运营商升级付费，S为多个地区和运营商的可重复批发容量收入，F为退出升级扩张、只保留现有补盲。基准Y10 S收入14B，对应约292M可收费等价用户×4美元/月；突破乘2.2为30.8B，约513M×5美元/月。它们是收费等价量，不是连接过的免费设备数。基准S收入路径Y1—Y10为0/0.3/1.2/2.5/4/6/8/10/12/14B；P只达同年S的28%。当前V1与MNO合作支持高于纯实验的进度，频谱、V2和吞吐仍使完整扩量远未确定。[S9][L1]

**B：Agent成果收费净增量。**只有超过既有Cursor、Grok、套餐和内部API的新增合同净对价进入。P是有限代码审查、维护、迁移或企业流程；S是可重复、大规模交付成果。基准Y10 S收入140B，可由约14M“全年付费工作等价量”×1万美元构成；客户须从每个等价量取得至少数倍的经验证节省、速度或新增业务。这里不是140B已经存在的编码软件市场，也不是将每个席位涨到1万美元。突破乘2.2为308B，需要跨出普通代码助手、进入更多生产工作，且客户总预算至少达到数千亿美元。基准S逐年0/0.5/2/6/14/25/45/70/100/140B；P只有18%。大额远期规模来自可解释的人力/工作预算迁移，**并无SpaceX专属订单证明**。微软等平台、其他模型、开源及客户自研可夺取收费权。[S7][S8][L4]

**C：轨道AI外部收入。**N为原型/工程，P为少数在轨工作负载客户，S为可重复销售和更新的系统。基准S逐年0/0/0.1/0.5/2/6/14/28/50/80B；P只有12%。Y10 80B相当约8GW可收费IT等价负载×10B/GW年。突破S120B约12GW；这不是直接照用当前高价GPU合同，而是需要保留一部分交付时间、能源和分布式任务价值。

轨道数量级必须过物理检验：若10—30吨/MW，8GW需要80,000—240,000吨在轨系统，100吨有效商业载荷需要800—2,400次累计任务；还未加替换。五年更新一次，成熟后仅更新就约160—480次/年。当前Boca Chica评估25次/年远不足够，需要新许可、多场地、显著降质量和高频复用。1MW地面IT在PUE1.2、电价60美元/MWh下年电费约0.63M；五年省电约3.15M。如果轨道质量10—30吨、运价200—1,000美元/kg，单发射费2—30M/MW，低质量低运价端才有接近机会，尚需支付散热、太阳翼和设备。规模上界因而是**大胆条件实验，不是当前工作预测**。[FCC申请][S12]、[Google原始系统研究][S13]

三年内主要能够确认子系统、客户试验、质量、寿命和场地批准；不能证明十年后全系统成本。政府在轨处理可能先商业化，但其预算和现有Starshield合同重叠部分不在轨道AI再记收入。

Terafab、火星城市、月面工业和地球点对点运输仍保留机制：公司可能取得合作股权、IP许可或按成本采购权；必须先确定权利和资金上限，再谈制造成本节省或外售利润。本模型不虚构这些正面现金，逐年0.5/1/2/4B探索费用提供有限失败预算。**不覆盖不限额建设晶圆厂或火星城市的财务后果**；若作出超过该预算的承诺，需重建资本路径。这一覆盖限制既可能漏掉上行，也可能漏掉更大烧钱，不能据此宣称所有未知远期价值都已被否定。

短期最有竞争力的买入解释是：市场仍低估正式云客户、网络增长和生产型V3部署，少量新证据即可改变十年后的认可程度。反解释是：反弹已把这类改善付了钱，且完全稀释市值超过2T，短期收入无法辨认最关键的长期利润持续性。

本研究没有市场一致预期的同口径经营底表，不能声称“比一致预期高多少”。真实可观察的是公开价格和已披露财务；“市场要求多年高资本回报”是反向推断。基准合理价值远低于买价，并不使短期交易价必然向该值收敛。**可能交易回报不提供伪精确区间**：支持性工程/模型事件可带来显著上涨，融资、续约或供应冲击可带来双位数下跌，方向都曾在上市后价格出现，但无法把历史幅度当本次事件胜率。

3个月主要看到服务转换和一轮财报，尚难看年度留存；6个月可多看一轮回款与资本预算。当前两者均不支持价值买入；若11月服务平稳但未公布留存，3个月仍等待，至3月若连续财报同时显示净收费、回款和CapEx效率改善且价未上冲，6个月判断才可能不同。两个日期不以一个模糊“3—6个月”掩盖。

### 4.3 中期与长期经营兑现

基准未来四段收入从约11.06B爬坡至14.07B，一年约50.25B；同比、环比对比必须处理Cursor并表和云计费起点。即使现金运营改善，全年约55.45B CapEx仍高于25.21B CFO。基准Y2收入约60.78B及现金转换较Y1改善，是中期独立论点；但Y2末流动性降至约24.55B、Y3约20.80B，频谱及设备付款使回报很难只靠现金积累。

三年基准当年收入71.43B、经营利润5.43B，三年后NTM约84.31B；长期现金收益更大部分仍在Y4以后。突破Y3当年收入约165.86B、经营利润25.99B、CapEx131.13B，三年后NTM约233.08B。公司前景明显更强，却要新增约70B股权资本才维持模型15B流动性下限。**经营规模、条件合理价值和未来市场是否认可，是三件不同的事。**

网络壁垒需要长期卫星补网、终端制造、光链路及客户服务维持；不是一代卫星永续。发射壁垒来自可靠性、认证、场地周转及成本，竞争供给增加后仍可能保留份额而降低利润。软件壁垒来自生产接入、验收和企业关系，模型排行榜可变；地面云若只卖通用资产，不能按软件平台持续期估值。轨道AI如果成立，可以在三年退出时获得对后十年的价值，但概率不会仅因三年过去自动升为100%。

### 4.4 估值工具、经济理念与资本桥

**主方法：分业务经济驱动的全投入现金流折现，目标日在未来。**采用这一方法因为集团利润受研发、折旧及融资结构影响大，普通PE和高EBITDA不能表示股东现金。主矩阵是条件合理价值，不是目标交易价。

每条联合分支在目标日h的计算为：

```text
企业经营价值_h = 目标日后Y1—Y10剩余估值FCF现值
                + Y11—Y20分业务衰减增长现金现值
                + Y20后稳定阶段价值现值

目标日股权价值_h = max(0, 企业经营价值_h + 可用现金_h - 债务本金_h)
目标日每股价值_h = 该分支股权价值_h / 该分支目标日完全稀释工作股数_h
条件行每股价值_h = Σ联合分支概率 × 分支每股价值_h
总回报 = 每股价值_h / 147.95 - 1
年化回报 = (每股价值_h / 147.95)^(1/h) - 1
```

max(0,·)仅反映普通股有限责任，不表示零值路径没有损失。悲观低端出现负经营净值时，不能报告负股票价格；其管理调整、可出售资产或新机会的额外价值另行讨论。目标日公司市值表列E[股权价值]、股数列E[股数]，**E[V/N]一般不等于E[V]/E[N]**，因此联合分支下每股和平均市值/平均股数略有差异不是算错。

现金规则：目标日前CFO加回SBC并真实增加股数；目标日后估值FCF不加回未来新增SBC，按同等现金报酬处理，避免无限发行看似免费。目标日后资本缺口已在FCF中扣除，主DCF按公平获得资本的等价现值处理；模型列出的实际发行价主要用于目标日前稀释。未来折价发行额外转移价值的风险另以低融资价与条件奖励压力呈现，**不把未知折价融资的精确效果当已解决**。经营租赁正常费用在利润内，融资租赁已计债务，不重复资本化。

税采用状态内正经营利润×21%，不假设跨主体、跨地区亏损可立即全抵扣，不计不确定递延税资产；债务利息税盾暂不另加。这使盈利兑现不足时保留税损利用限制，但不是将同一失败再乘一遍概率。

| 情景 | 下端WACC／稳定g | 上端WACC／稳定g | Y11最初增长：核心/Mobile/Agent/轨道 | 持续期及资本回报依据 |
|---|---|---|---|---|
| 悲观 | 14%／1.5% | 12%／2.5% | 0%/2%/4%/6% | 核心低回报、部分增长抵不过更新；后稳定ROIC按10%/12%/25%/12% |

Y11—Y20各业务增长线性衰减至相应g，使用存续状态税后经营收益×(1−当年增长/ROIC)形成扣再投资现金。稳定阶段也用同式；更高增长同时要求更多资本，不能只提高g。核心已把维持更新保留在净经营经济性，成长资本由增长/ROIC追加；这不是把全部CapEx删掉。Y10末失败状态不恢复，有限成功维持其自身经济结果。完整代码列出四个桶，并未把所有机会同一天商业化。

**稳定化仍是重要估值假设。**基准Y10前后需核心投资增长明显放缓并释放一部分现金，突破则需更高ROIC支撑持续增长；模型不是从Y10最后一期FCF直接永续。保留Y11—20，是因为Agent/轨道在Y10尚可能扩张；也不能以这十年延伸证明这些高回报一定可以保持。

折现率的锚：9月4日公开H.15中，最近对应日**9月3日**的3个月、6个月及10年国债固定期限利率分别3.89%、3.95%、4.77%；文件发布日期不是收益率对应日。[S15] 约10%—12%的工作资本成本包含美元时间价值、与资本市场/客户预算同向的系统性风险，以及并未进入商业状态概率的融资和长期回报波动。不是把同一工程失败重复打折。全部早期失败概率已经进入状态现金，未再加统一“科技风险折价”。

基准工作点取WACC11%、g3%，三年每股约13.58美元；突破工作点取WACC11%、g3.5%，三年约123.15美元。工作点来自名义美元风险补偿和长期资本回报判断，**不是将四行、两种工具或价值端点做平均**。

### 4.6 现价反向要求与重要误差

当前完全稀释工作市值约2,102B，扣估计净现金46.49B后经营价格约2,056B。若是一家今天已经成熟、11%资本成本、3%增长的企业，约需164B年可持续现金收益，尚未考虑为远期成功等待的折现。它不是本公司明年预测，而是展示现价量级：当前23.044B TTM收入和长期基准现金仍远小于这个要求。

三年15%年化持有要求对应退出价值**225.01美元/股**。在**固定突破经营及机会权重、g3.5%**时：
- 要支持三年不亏本金，WACC约需降至**10.19%或更低**；
- 要支持三年10%年化，约需**9.05%或更低**；
- 要支持三年15%年化，约需**8.57%或更低**。

这是反求，不是证明这些折现率正确；也不将它倒推成基准。现价的真正争议同时在大幅扩张路径可达性及长期系统性风险补偿，绝不只是“差一个百分点折现率”。

基准核心普通、Agent单项完整成功的三年价值约30—46美元。因此把成功概率从15%调到100%本身仍不够；必须把规模、核心或持续期再明显提高。Mobile和轨道单项亦如此。现价所需并非“任意一个机会存在”，而是至少一条能产生大额归属现金并支付资本的联合经营路径。

远期占比见附件C。基准三年经营价值约82%来自Y11以后；突破约96%。短期一些比例超过100%，原因是近十年净投入抵销远期现值，不是计算概率超过100%。悲观经营价值接近零或负时该比例无解释力，列NA。现金、厂房、卫星和频谱不能按账面原值充当普通股清算保护。

## 6. 当前选择、敏感性、独立成功与等待代价

### 6.1 普通偏差、融资及估值敏感性

“普通偏差”在基准核心中同时体现Consumer收入少10%、云收入少20%、每年CapEx多3B：网络价格/采用较弱、云重议而建设不能同步取消。为避免把毛利随销量同比下降过分乐观，该冲击还应留意固定折旧及研发；这里核心毛利预算按收入变化，是较温和版本。即便如此，三年累计融资已约8.5B、结论仍不建议；更刚性的成本不会制造投资优势。它不是用严重事故替代普通不及预期。

新增5B/年更新资本表明经济寿命的重要性；D&A只是会计加回，并不会凭空产生现金。若按基准设备预算继续扩张却更快换代，三年需约9.7B新资本。反过来，若与同等可靠性、付费规模相容地节省5B/年，三年价值约13.77—19.82美元，是有意义经营改善；不能只删CapEx却保持所有收入和永久高增长。

起点现金80—92B相对86B，直接资本桥影响约±0.42美元/股，另有小额利息与融资变化；它不足以跨过基准与147.95美元之间的差额。13.5728B基本股数代替14.21B也只提高每股价值约4.7%，不能消除数量级分歧。1.331B条件奖励若全部触发，突破三年价值下移至约88—184美元；未在主区间偷藏该风险。

融资按联合分支而非平均余额检验：前三年基准主64分支无新增融资；乐观约11.6—14.9B；突破约69.3—73.2B。突破十年累计约113.7—133.4B，工作期望约120B，**不含新增SBC发行的报酬股数**。悲观少数后期高投入/低收入组合仍可能融资，不能因平均年末现金为正就说绝无资金风险。若融资价格减半，新增融资和SBC股数显著增加；若融资通道关闭，应削减增长或进入损伤路径，本报告高行不再成立。

低WACC替代成立的最少经济变化，不是“大家情绪更好”：需用多轮设备更新后的长期现金稳定、低取消合同、更低客户集中或内部应用稳定付费，证明系统性现金波动和再融资风险下降。仅一次试飞或季度收入增速不足以同时支持这些变化。

### 6.4 当前拒绝与最强相反选择的门槛

最强相反选择是“以有限仓位承担突破，等待可能错过巨大重估”。必须承认：它可以在合理条件下胜出，不需要将所有失败归零才讨论。

用两个**决策参照结果**展示门槛，而不是给四行情景制造权重：普通结果三年14美元，低资本成本的突破结果287美元；同一买价147.95，15%年化所需退出225.01，则二结果线性期望达到门槛所需突破权重约：

`p* = (225.01−14)/(287−14) ≈ 77.3%`。

若持有要求只10%年化，门槛约67.0%；只要求不亏本金，约49.1%。这里的p是**整股联合结果**，不是轨道5%、Agent15%或任何局部现金保留率。两结果遗漏中间路径、更大上行和不同估值状态，因此仅说明在此参照下现价要求很高，不能当实际胜率。

当前证据证明Starlink已有利润、外售云已有客户、Cursor已有生产采用；尚未证明近八成概率可以同时达到大规模平台经济和低资本风险补偿。也不能仅凭无校准概率就否定所有高风险参与：真正拒绝当前买价的依据，是普通、乐观乃至主突破工作路径的现金价值不足，**只有大规模经营与有利资本成本的联合变化才能使有利回报成立**。如果后续证据显著提高联合可达性而价格仍约148，结论可以改变。

### 6.5 等待的信息价值与错过成本

比较使用相同初始资金1美元、同一2029-09-08退出日、现金按3.9%年化近似。以下价格是**策略算例，不是市场预测或概率校准**。假设六个月后观察云续约、Cursor留存及两轮资本披露；它们能辨认一部分近期失败，不能消除轨道十年经济性。

| 六个月观察与价格算例 | 现在买入并持有到原目标日 | 等待六个月后决定，到原目标日 | 等待的收益与代价 |
|---|---:|---:|---|
| 支持性证据，确认后180美元，原目标价值250美元 | 250/147.95＝1.690美元，+69.0% | 1.039^0.5×250/180≈1.416美元，+41.6% | 等待者少约27.4个百分点；证据不免费，上涨后可能错过。若250仍可靠，180买价剩余2.5年年化约14%，是否买取决于要求 |
| 反对性证据，价100美元，但原目标价值降到80美元 | 80/147.95≈0.541美元，-45.9% | 判断无优势，继续持现金至原目标日，1.039^3≈1.122美元，+12.2% | 信息识别失败的价值很大；不能把下跌100美元当原突破价值不变的便宜货 |

上表比较纯持有与有选择的等待，策略不同已明示。**若允许现在买入者也在六个月使用同样信息退出**：失败观察下按100美元卖出，再持有2.5年现金，末值约`100/147.95×1.039^2.5＝0.744美元`，仍亏约25.6%，但优于被强制持到80美元。等待者也可能误判噪声为失败而错过恢复；没有证据将辨别准确率设为100%。

所以报告并不宣称算例证明“等待必胜”。当前选择等待/拒绝，是因为现价尚无足够支持的经营价值优势，等待至少保留资本和获取可区分证据的机会；其主要代价是遇到真突破时以更高价格买入或完全错过。短期交易论点尚未判定具有优势，长期低资本成本论点仍有条件保留。

### 6.6 交付前回查结论

- 已公开收入、资本余额、收购权益四行共用；研究年与自然年、事件日期与公开日期分开。
- 七个核心收费池、三个增量机会、集团收入与现金加总一致；未加入内部发射、内部模型/云、Tesla收入或套餐内免费功能的重复收入。
- 三个机会每年状态概率100%，固定路径有退出和停留时间；64联合分支先计算融资和每股，再加权。独立成功替换原贡献，非叠加。
- 三个主目标日一致；DCF仅计目标日后现金，目标日前留存仅入资本桥。回报以147.95买价和目标股数计算；中长期累计/年化分开。
- 条件矩阵和当前实际选择不同；没有用四行正面格数量、区间长度、概率中点或评级多数决定建议。
- 重要限制没有被“计算闭合”消除：准确9月股数与现金、条件奖励、资本预算/设备寿命、期后融资条款、长期客户和轨道质量仍需新证据。模型极低的普通路径价值是所列资本纪律与经济持续期下的条件判断，不是无条件市场目标。

 let cfo=eb-tax+da+sbc-wc+op.eb-op.tax+op.da-op.wc-interest;
 let totalCap=cap+op.cap,fcf=cfo-totalCap;
 let spec=t===2?10.5:t===1?.8:0,repay=[2.4,2.867,2.5,2,5,3,3,3,3,3][t-1];
 let net=fcf-spec-repay;
 let startCash=cash,startDebt=debt,startShares=shares;
 cash+=net;debt-=repay;
 // SBC cash is retained only with actual pre-target dilution, future DCF keeps SBC expense
 let issuePrice=[50,90,150,200][s],newShares=sbc/issuePrice;
 shares+=newShares+(t===2?.2618:0);
 let financing=0;
 if(cash<15){financing=15-cash;cash=15;shares+=financing/issuePrice;raised+=financing;}
 let valfcf=eb-tax+da-wc+op.fcf-cap-(t===1?.8:0)-(t===2?10.5:0);
 rows.push({t,rr,gm,gps,coreRev:rev,rev:rev+op.rev,gp:gp+op.gp,rd,sga,amort,eb:eb+op.eb,da:da+op.da,sbc,tax:tax+op.tax,wc:wc+op.wc,cap:totalCap,coreCap:cap,cfo,fcf,valfcf,interest,op,or,cash,debt,shares,startCash,startDebt,startShares,financing,spec,repay,raised,explore});
 }return rows;
}
function capAt(rows,h){if(Number.isInteger(h)){let x=rows[h-1];return {cash:x.cash,debt:x.debt,shares:x.shares};}
 let row=rows[0],f=h===.5?.46:.22;
 return {cash:86+f*(row.cash-86),debt:39.512+f*(row.debt-39.512),shares:14.21+f*(row.shares-14.21)};}
function valuation(s,h,wacc,g,override={}){
 let rows=build(s,override),c=capAt(rows,h),pv=0; c.shares+=(override.extraShares||0);
 for(let row of rows){if(row.t<=h)continue;let fraction=row.t===1?(h===.5?.54:h===.25?.78:1):1;pv+=row.valfcf*fraction/(1+wacc)**(row.t-h);}
 // Year 11 normalizes capital to D&A + growth/ROIC; equity SBC kept as cash expense.
 let last=rows[9],roic=[.10,.15,.20,.25][s];
 let nopat=Math.max(0,last.eb-last.tax);
 
 let buckets=[Math.max(0,last.eb-last.op.eb-last.tax+last.op.tax),...last.or.map(o=>Math.max(0,o.eb-o.tax))];
 let roi=[[.10,.12,.25,.12],[.15,.20,.35,.18],[.20,.25,.40,.22],[.25,.30,.45,.25]][s];
 let initial=[[0,.02,.04,.06],[.06,.08,.12,.14],[.10,.10,.16,.20],[.14,.12,.20,.25]][s];
 let tailPV=0,tail=[];
 for(let u=11;u<=20;u++){
  let cf=0;
  buckets=buckets.map((v,j)=>{let gr=initial[j]+(g-initial[j])*(u-11)/9;
   let n=v*(1+gr);cf+=n*(1-gr/roi[j]);return n;});
  tailPV+=cf/(1+wacc)**(u-h);tail.push(cf);
 }
 let termCF=buckets.reduce((a,v,j)=>a+v*(1+g)*(1-g/roi[j]),0);
 let tv=termCF/(wacc-g),termPV=tailPV+tv/(1+wacc)**(20-h);

 let ev=pv+termPV,eq=Math.max(0,ev+c.cash-c.debt); return {p:eq/c.shares,ev,eq,pv,termPV,termCF,c,rows};
}
const ranges=[[.14,.12,.015,.025],[.12,.10,.025,.035],[.115,.095,.03,.04],[.12,.095,.03,.045]];

function joint(s,h,wacc,g,over={}){
 let vals=[],probSum=0,p=0,eq=0,ev=0,pv=0,termPV=0;
 let c={cash:0,debt:0,shares:0}, avgRows=[];
 for(let a=0;a<4;a++)for(let b=0;b<4;b++)for(let d=0;d<4;d++){
  let paths=[a,b,d],pr=paths.reduce((v,k,i)=>v*(over.forceOpp===i?(k===3?1:0):over.failAll?(k===0?1:0):opps[i].weights[s][k]),1);
  if(!pr)continue;let v=valuation(s,h,wacc,g,{...over,paths});
  probSum+=pr;p+=pr*v.p;eq+=pr*v.eq;ev+=pr*v.ev;pv+=pr*v.pv;termPV+=pr*v.termPV;
  for(let k of Object.keys(c))c[k]+=pr*v.c[k];
  v.rows.forEach((r,i)=>{if(!avgRows[i])avgRows[i]={};for(let k of Object.keys(r))if(typeof r[k]==="number")avgRows[i][k]=(avgRows[i][k]||0)+pr*r[k];});
  vals.push({paths,pr,p:v.p,shares:v.c.shares,raise3:v.rows[2].raised,raise10:v.rows[9].raised});
 }if(Math.abs(probSum-1)>1e-9)throw Error("prob sum");
 return {p,eq,ev,pv,termPV,c,avgRows,branches:vals};
}
const results=names.map((n,s)=>({n,rows:build(s),vals:[.25,.5,1,3].map(h=>{let z=ranges[s];return {h,lo:joint(s,h,z[0],z[2]),hi:joint(s,h,z[1],z[3])};})}));

function assert(ok,msg){if(!ok)throw Error(msg);}
for(let s=0;s<4;s++){
 const rr=results[s].rows;
 rr.forEach(r=>{
  assert(Math.abs(r.coreRev+r.op.rev-r.rev)<1e-8,"segment revenue");
  r.or.forEach(o=>{
   assert(Math.abs(o.pr.reduce((a,b)=>a+b,0)-1)<1e-10,"annual state probabilities");
   assert(Math.abs(o.pr.reduce((a,p,k)=>a+p*o.statesRevenue[k],0)-o.rev)<1e-8,"state revenue mapping");
  });
  assert(Math.abs(r.cfo-r.cap-r.fcf)<1e-8,"reported FCF");
  assert(Math.abs(r.startCash+r.fcf-r.spec-r.repay+r.financing-r.cash)<1e-8,"capital bridge");
 });
 for(let v of results[s].vals){
  assert(v.lo.p>=0&&v.hi.p>=v.lo.p,"valuation interval");
  assert(v.lo.branches.length===64,"joint branch coverage");
  assert(Math.abs(v.lo.branches.reduce((a,b)=>a+b.pr,0)-1)<1e-10,"joint probability");
 }
}

 return:[v.lo.p/147.95-1,v.hi.p/147.95-1],equity:[v.lo.eq,v.hi.eq],capital:v.lo.c}))}))},null,2));
