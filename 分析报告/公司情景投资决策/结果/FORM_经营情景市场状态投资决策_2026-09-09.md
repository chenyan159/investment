## 一、当前判断先行：公司改善成立，现价要求更高

**短期3个月和6个月：当前不建议买入。** 采用“可见经营改善带来的预期差回报”理念。Q2实绩、GPU开始生产交付和Q3收入指引已经公开，7月财报后发生了显著上涨；不能把再次确认这些信息视为新的低风险利好。基准6个月条件价值约53—71美元，而当前价格接近需要乐观增长和较低风险补偿共同成立的位置。3个月内一次财报有能力检验退款剔除后的毛利与交付，尚不能证明跨代份额和2028年产能回报。参与里程碑交易可能赚钱，但当前无法识别足够清晰的交易定价优势。此结论不是预测股价必然跌至DCF值。

**中期12个月：当前不建议买入。** 采用“订单、合格产能与现金兑现”理念。独立工作路径预计2027年收入约12.16亿美元、经济口径营业利润约3.26亿美元，已给予很强增长与成本改善；一年后基准价值仍只有约56—75美元。最大分歧不在于AI是否增长，而在于公司获得多少可重复的新设计份额，以及收入增长需要支付多少资本与持续研发。若2027年前瞻收入走向14.5亿美元以上、无退款经济毛利保持中高50%区间且新厂认证兑现，需要转向更强经营路径重新估值；仅完成270百万美元季度指引不够。

**长期36个月：稳健复利理念下当前不建议买入；高风险突破理念下暂不参与，保留条件吸引力。** 基准三年价值约67—88美元，乐观约114—160美元，突破约167—239美元。突破行确有经济上行，不要求量子业务同时成功；主要依赖GPU/新CPU/ASIC份额、HBM高价值测试与跨厂合格能力共同跃升。单独CPO规模成功、或单独量子产业化的条件实验，三年价值上沿仍约101—102美元，不能单凭其中一个故事支付整股溢价。高风险投资者真正未解决的是“大幅核心扩张及其持续性”能够获得多大可信权重，而不是公司有没有新技术。

上述三个“当前不参与”主要源于**当前证据最支持的现金权益不足以覆盖买价**；对技术突破交易另有信息与定价不可识别问题。本文未证明“等下一季财报”一定优于立即买入，等待比较见第六节。也不把四行情景当成互斥概率全集，不能用正面格数量计算胜率。

## 二、完整经营图与决定性证据

### 2.1 价值如何到达普通股

FORM提供探针卡、探针头、晶圆探测/表征系统、光学和低温测试方案。付费人是存储IDM、晶圆代工/封测环节、设计公司指定采购体系与研发机构。基本经济单位是**合格设计对应的卡/探针头、维护与升级、系统交付和服务**；公司不按GPU销量、HBM字节或AI推理次数自动抽成。

客户总测试成本取决于设备占用、可用吞吐、维护、误杀及漏检。昂贵GPU与HBM封装前筛除坏器件，能够创造真实经济价值；FORM只捕获其中的接触、定位和测量部分。提高并测数、延长探针寿命、DFT/自测试及测试插点迁移，都可能使测试更重要而探针收入增长更慢。

### 3.4 CPO与新增量子：逐年状态、收入、费用和现金

N=验证/尚未形成可重复量产；P=有限的持续商业收入；S=当年达到本节所定义规模；F=退出本条新增机会。**N不是所有收入均为零**：CPO仍可能有8的试制/验证销售；量子新增N为零，已有科研销售保留在其余Systems。F吸收，不再自动返回成功；P与S可以降级，S概率是当年仍处于规模状态，不是累计曾成功概率。

2026起始状态分布为CPO N/P/S/F=30%/70%/0/0，新增量子98%/2%/0/0；这是当前信息对可重复性阶段的判断，并非抽样统计。每年先按转移矩阵更新，再按当年规模计算。CPO基准从P转S每年30%、S继续88%；依据已开始量产和约数千万销售，但客户仍不提供细化2027季度预测。若几乎尚无商业采用，不应给此速度；若已全面规模化，不应保留这么多P/N，当前证据位于两者之间。量子P转S基准仅10%、N转P6%，反映量产经济性与采购未证实。乐观/突破都不给量子额外的“AI顺风”概率，使用同一分布。

**3个月与6个月的选择：** 当前两者都不买。3个月最可能只新增一个季度信息，无法有依据地预测价格必须向DCF收敛，故条件交易回报记为NA；不是全部估值NA。若Q3只达到指引、无退款毛利约51%，不改变拒绝；若同时披露新HPC大量持续订单、跨厂认证提前与2027收入能力至少约14.5亿，可改变经营解释，6个月判断先于长期现金发生转强。6个月多一次全年展望，证据更有辨别力但也可能已跳涨；不能把时间增加本身当重估催化。

**中期独立逻辑：** 2027H1有机会检验库存、收款、资本付款和复购；基准2027报告式FCF约173、扣新增报酬抵消后的估值FCF约155，现金转换比当前H1简单年化弱，原因是140核心CapEx及机会投入。这是中期收入增长不等于同幅股东现金增长的关键，而非短长目标价平均。

**长期独立逻辑：** 到2029可观察跨代资格和新厂真实单位成本，仍不能知道2032—2036每代竞争结果；因此远期毛利逐步压缩，且终值敏感性很大。基准在研究三年后已形成约16.3亿年收入及4.83亿经济EBIT，不等于公司只剩三年寿命。突破则必须在2029实际经营与2029对后续市场认知两条线都更强，才能支持167—239美元的条件剩余价值。

### 4.3 投资理念、目标日DCF与工具一致性

主方法统一为目标日剩余经营现金DCF，三个期限不改工具去追求想要的结论。短期理念是预期差，中期是经营现金兑现，长期主理念是具有更新能力的成长复利；高风险突破另用更高持有要求评价同一损益。

`目标日EV = 目标日后至2036剩余季度FCF的折现和 + 2036末剩余价值的折现`。

`2036末剩余价值 = 2036税后经营利润 × (1+g) × (1−g/增量ROIC) ÷ (r−g)`。

这里的再投资率g/ROIC替代成熟阶段显式CapEx−折旧+周转净投入，不在终值中重复扣一次。2036以前已经扣全部项目成长投入。2036后存活机会保持当前概率权重后的现金基座并按更新机制维持，不恢复失败状态；本处理要求持续投资能抵消产品退出，不能视为无需更新的专利永续。

`股权价值 = EV + 目标日可用现金 − 债务 + FICT价值 − 18补助准备`；除80.0得到每股价值。目标日前FCF只进现金，目标日后FCF只进EV。无分红，累计回报=P目标/109.86−1，12个月与36个月分别按1年、3年计算年化；没有中途分红再投资假设。

美元风险补偿参考信息截止前可见H.15：9月8日发布页最新已公布交易日9月4日，10年国债4.78%、6个月3.98%；9月7日假日不可错当9月8日实际收益率。模型以约4%现金机会成本和4.8%长期无风险锚，加股权系统性/周期性风险形成9%—12%条件折现率范围。已计入状态现金的产品失败不再额外乘同一失败概率；不同情景r差别主要是现金波动、规模与仍未消除的周期风险，不是该行情景发生率。[美联储H.15][R1]

### 4.4 现价反向要求

价格不唯一识别增长、利润率和风险溢价。以下不是“真实市场一致预期”，而是现价需要的几组经济组合。

* 基准2027—2036经营保持不变，r由11.5%降低到8.5%、g固定2.5%、ROIC20%，三年价值仍不到100美元。仅靠较便宜资本不能轻易造出15%年化回报；需要实质更高现金或更长超额回报期。
* 以一年后NTM基准税后经营利润约304、现金约415、净其他桥约38，现价对应经营价值约8,336，即约27.4倍NTM税后经营利润。DCF必须用相匹配的长增长和高资本回报解释这个倍数，不能只引用同行也贵。
* 15%一年要求退出126.34；基准即使上沿74.54仍不够。15%三年要求167.09；乐观上沿160.07尚差约4.4%，突破下沿166.86几乎等于门槛，因此突破三年评级不能忽视很小的负向扰动。高风险20%三年要求189.84，突破中枢附近才可能满足。
* 如果现金完全维持基准资本桥，三年退出167.09对应股权13,367，扣约984净非经营桥，EV约12,383。基准同日EV仅约4,390—6,013；需要现金规模/持续性组合显著超过基准，而非只多一季度退款或把CPO多算十几百万。

### 6.3 当前路径与投资标准的真正分歧

本研究当前更支持基准，最强替代是乐观，而非直接受损：Q2多业务增长、成本执行、客户HBM4量产和新GPU资格都是正证据。相反，尚未提供GPU采购量/份额、CPO持续系统经济性和新厂合格产出，不足把突破成为默认。基准2029收入1,631，已近似提前达到管理层2030旧目标；估值仍低于现价，所以拒绝不是由任意悲观增长工作点制造。

稳健复利与高风险理念的事实相同：目前不能称有资产安全边际；周期租金有实际来源，但经过当前报价后收益不足；长期平台值得继续跟踪，但买入价已预支更多。高风险突破之所以保留，并非“高风险就可以买”，而是条件收益确实存在。判断其当前优势需要对核心联合成功、未成功时剩余价值与退出价格形成可辩护的权衡；公开资料尚不能把这三者同时收窄。

**完整整股决策的边界实验，非四行情景赋权：** 对三年20%年化要求，需终值189.84。如果仅作为两类互斥结果的简化实验，把规模且持续成功的退出设为200、其它结果平均75，则成功权重需要91.9%；成功239、其它结果平均100则需64.6%。15%年化下两组门槛分别约73.7%和48.3%。这些是“其它结果条件平均价值”假设，不是把非成功都认定为归零，也不是局部CPO概率。其它结果中可能有普通、受损、接近乐观及尚未揭示的新路径，若其平均改变就必须重算门槛。

已获资格与首交付支持“机会存在”，不能直接支持整股必须以约49%—92%权重进入满足该损益设定的核心长期成功分支。没有客户采购/份额基数，就不能将上述门槛反过来当研究成功率。本报告因此对高风险突破的**当前定价优势不可判定，行动暂不参与**；不声称已统计证明真实成功率低于门槛。愿意只要求约12%且能承受50%以上损失的投资者，在更强平台证据与乐观估值上端可以作不同条件选择；目前仍不能靠同一批资格信息独立裁决那个更强持续性解释。

def cash_at(ps,t):
    cash=345.64;debt=11.69
    for p in ps:
        days=(min(t,p['end'])-p['start']).days
        f=max(0,min(1,days/(p['end']-p['start']).days))
        cash+=p['fcf']*f
    yrs=max(0,(t-START).days/365.25);paid=min(debt,1.18*yrs)
    # no credit taken for securities interest: conservatively zero return on corporate cash
    return cash-paid,debt-paid

def dcf(s,arr,ps,t,w=.105,g=.025,roic=.20,asset=65.89,claim=18):
    pv=0
    for p in ps:
        b=max(t,p['start']); e=p['end']
        if e<=b:continue
        f=(e-b).days/(p['end']-p['start']).days
        yr=((b-t).days+(e-b).days/2)/365.25
        pv+=p['fcf']*f/(1+w)**yr
    # Stable FCFF from NOPAT and economically required reinvestment, no fixed capex shortcut.
    nopat=arr[-1]['ebit']*.8
    tv=nopat*(1+g)*(1-g/roic)/(w-g)
    tvpv=tv/(1+w)**((ps[-1]['end']-t).days/365.25)
    cash,debt=cash_at(ps,t);eq=pv+tvpv+cash-debt+asset-claim
    return dict(p=eq/SHARES,eq=eq,ev=pv+tvpv,cash=cash,debt=debt,tvp=tvpv/(pv+tvpv),tv=tvpv)
