# Bloom Energy（BE）：经营前景、四情景股价与当前投资决策

## 0. 当前结论、口径与四情景总表

**当前判断：BE已具备真实的大客户需求与设备盈利能力，但200.40美元尚不适合作为核心仓位的买入价。对能承受大幅回撤、愿意跟踪工程与现金里程碑的成长投资者，可用组合净值0.5%—1%的观察仓参与；一般资金等待价格改善或未来两次财报把经营路径上修。** 基准经营兑现并不能自动提供满意的股票回报。乐观与突破路径有商业机制和实际客户入口，值得保留参与权；它们尚未形成足以支持重仓的证据闭环。

决定胜负的三个变量是：①已签采购转为取得许可、可交付并能收现的批次；②扣除旧机队换堆及SOEC占用后的**合格新机产出**；③产品净价、服务完整成本和股本变化共同决定的每股留存。下一次财报尤其看Q4收入能否达到14.0亿—15.3亿美元、普通FCF能否回到正数，以及合同资产是否真正开票回款。

## 1. 业务经济本质与竞争位置

### 1.1 客户究竟买什么，利润归谁

Bloom用固体氧化物燃料电池（SOFC）在现场把天然气等燃料转为连续电力。核心价值是较早取得可用电力、模块化部署、较低局地污染、场地与可靠性优势。它仍消耗天然气并产生CO₂；气源、许可、冗余、保护和维修共同决定电力服务质量。设备能发电已有多年商业机队证明，大型园区的建设复制、全站可用率和完整更新成本仍需更多跨期证据。[S03][S10]

本研究划分四个经济单元，并把早期机会分别放在它们真正影响的收入或成本中：

| 经济单元 | 谁买单、怎样形成收入 | 能创造利润的机制及失败条件 |
| --- | --- | --- |
| **新设备与系统配置** | 最终企业、公用事业、渠道或融资平台采购；产品控制权按具体合同在交付、机械完工或运行等节点转移 | 专有电堆、功率密度、批量制造和时间价值支持设备毛利；竞争降价、材料涨价、低良率、客户股权让利和过度保修承诺会侵蚀它 |
| **长期服务与更新** | 资产持有人/用户为维护、监控和性能支付费用；合同可能有便利终止权 | 安装机队形成后续收费入口，运行数据和专用部件增加转换成本；但高温堆更新、驻场、物流及性能补偿均是真实成本。大设备收入不等于同步产生高毛利服务收入 |
| **安装、部署支持和存量售电** | 用户支付施工/咨询费，存量项目支付电费或租赁费 | 大型项目转向第三方安装可以提高资本效率，但现场责任仍在。保留资产的旧售电业务要承担融资与更新，不能按轻资产服务理解 |
| **新入口和平台延伸** | 800VDC、热回收与CCS先提高主机采用或配置价值；SOEC和独立系统才可能另行收费 | 共用制造、客户和服务平台可以非线性放大收入；必须证明多出的净对价与利润归Bloom，不能把全部客户节省或项目电费再加为一份收入 |

公司财报只有一个可报告经营分部，四类收入并非四套独立资产负债表。组合合同的收入分配也有估计成分，不能把产品毛利与服务毛利当成完全独立的报价。[S01][S03]

**融资方采购不等于又增加一个终端客户。** Bloom对Brookfield相关Bolt US两家JV各持6.2%、ORC HoldCo持15%，采用权益法；项目资产及全部售电利润不并入Bloom。韩国JV则并表，并有少数股东。新设备只计一次，JV利润只按真实归属；模型把持续JV现金投入列为再投资，不把项目融资框架算成母公司现金。[S01]（附注7、11）

### 1.3 客户支付上限：提前供电值得花多少钱

本次独立算例为净负荷100MW、名义模块130MW，20年、税前9%折现率；初始现场系统3,900美元/名义kW；前两年净负荷率55%、80%，以后85%；到站气价4.5美元/MMBtu、热耗6.2MMBtu/MWh；全包维护130美元/名义kW年，**已经包含换堆，不能再加同一笔更新资本**。它不是Bloom报价，也不包含两方案共用的IT设备、建筑及未确定的远距离气管支出。

| 条件扰动 | 本次计算的全周期成本（美元/MWh） |
| --- | ---: |
| 基准，无税收抵免 | 129.3 |
| 到站气价8美元/MMBtu | 151.0 |
| 成熟利用率50% | 183.1 |
| 项目折现率12% | 147.6 |
| 假定80%合格税基获30%ITC、首年兑现 | 112.2 |

若比可取得的电网方案贵40美元/MWh，100MW净负荷、85%利用率每年多付约2,978万美元。提前运行所增加的经营现金、避免的违约损失及可靠性价值要超过这个差额和追加资本，客户采用才合理。Oracle与Nebius的投资量级能够容纳部分供电支出，却不能保证它们每个园区的回收期都相同。

与允许使用的行业报告123美元/MWh算例相比，本次改变了资本成本、气价和服务收费边界；行业算例单列堆更新，本次全包服务已包含更新。因此差异不能解释为两份独立“市场报价”冲突。[L03]（第6节） 更值得警惕的是把两套成本都加一次，或默认气价、满负荷和税收利益永远取最优端点。税收抵免只作为合格项目条件，模型不无条件叠加ITC与45Q，也不把项目持有人的税务利益全算给设备制造商。[S21]

预算相容性的进一步原始检查是Oracle FY27 Q1（截至2026-08-31、09-10公开）：季度CapEx约285亿美元，CFO约230亿美元、FCF约-50亿美元，且当季完成200亿美元ATM股权融资。[S24] 其预算可以容纳多期燃料电池支出，但扩张亦依赖资本市场与客户预付；不是全部由已有云利润即时自筹。Nebius的17亿美元电力项目融资解决部分资产资金，不能保证其最终算力客户永远按计划爬坡。Bloom的营运资金压力测试因此保留客户付款滞后，不以客户名气替代现金约束。

### 1.4 壁垒、竞争和长期价值分配

电堆材料、印刷/烧结良率、系统控制、制造经验、机队服务数据和专有更新部件具有累积性；它们可以降低单位成本、提高客户复制速度和服务粘性。大型客户融资组织亦有价值。Q3设备盈利已说明优势能变为收费，而非仅停留在实验室。[S01][S03]

但低局地污染和较快交付的溢价并非永久垄断。电网扩容、客户迁址、燃机与往复式机组供给、成熟排放治理、线性发电机及其他SOFC路线共同限制净价。GE Vernova 10月28日披露气电设备积压加排期预留122GW，说明短期交期仍紧，也说明替代供给在扩张；其中预留不能当成全部硬订单。Mainspring与AEP于10月13日公布最高1.6GW框架，**首批190MW已采购，2027起交付**，直接证明同一大客户会发展第二技术路线。[S15][S16]

800VDC原生输出、热回收和CCS可能把客户价值从“提前有电”拓展到系统架构和低碳电力。公司9月模型声称1GW可减少36亿美元非计算资本支出，这是厂商配置模型，尚非独立审计的普遍净节省。[S17] 本次把它主要反映为较好的采用、ASP和服务能力，不单独再添加36亿美元收入。故障隔离、气源共因风险、保护、储能缓冲和客户SLA仍须工程验证。[L04]

### 1.5 服务、材料与制造是三道不同瓶颈

服务可能成为复利来源，也可能把早期设备利润还回去。本模型2029基准服务收入8.2亿美元，按115美元/受保kW年，需约7.1GW平均付费覆盖；27%服务毛利意味着全成本约84美元/kW年。若每年约0.65GW需要更新、每覆盖kW年现场等成本20美元，允许的更新部件成本约700美元/更新kW。若实际需1,000美元/更新kW，费用多约1.95亿美元，税后少约1.56亿美元。该测试是**反推可承受门槛，非公司披露的寿命或实际更换率**。性能支付、优惠续约和保修损失须同时进入净服务收入与成本。[S01]（附注12）

制造需区分厂房面积、已安装产线、合格电堆、旧机队FRU和新机交付。2025年10-K的明确阶段目标是2026年底约2GW；5GW场地承载和25GW材料“可见度”不是已验收产量。[S03][S18] 本研究按新机、FRU及SOEC共用资源测算后，2029基准需约4.5GW年均电堆等效名义能力，乐观约6.1GW、突破约8.2GW。后两者必须超出当前5GW场地阶段，费用和资本已同步上调。

钪供应存在实质信息分歧。Bloom 7月9日8-K称供应不依赖中国、可支持25GW；USGS 2026资料估计2025全球氧化钪产量约80吨、消费60吨，并明确直接进口统计不含中间品与制成品内含钪。[S18][S19] **裁决：不能用直接进口量证明即将断供，也不能用工业尾料储量或管理层声明证明全部扩产已获合格材料。** 本模型不采信未公开的固定吨/GW参数。示例8GW电堆产出，在5吨/GW与20吨/GW强度下分别需40与160吨，尚未处理回收和良率；这一未知足以决定扩张速度。已实现设备收入反驳“当前完全不能生产”，对2029突破供给仍不能提供锁定保证。

## 4. 公司财务、融资与每股归属

### 4.1 从经营利润到现金：SBC只处理一次

本次选用**现金经营利润+显式股份稀释**路线。预测分业务毛利率为剔除SBC的模型口径；含SBC可比营业利润在汇总处扣全额SBC，不声称将制造人员SBC全部列为报表销售管理费用。因此模型毛利率与历史GAAP毛利率比较时需先对齐口径。

`EBIT* = 分业务毛利润 − 现金研发/销售/管理费用 − 现金处置/重组费用`；

`含SBC可比EBIT = EBIT* − 当年SBC费用`（用于会计利润诊断，不是DCF再扣一遍的起点）；

`NOPAT* = EBIT* − 现金所得税`；

`FCFF* = NOPAT* + D&A − 现金CapEx − ΔNWC（含供应商预付） − JV权益投入`。

这比标准仅含并表资产的FCFF多扣JV现金出资，属于本次统一的可分配企业现金口径。每年现金再加净利息、扣融资义务本金与普通债偿还，才得到期末现金。租赁的日常费用保留在成本中，经营租赁负债不再在EV桥重复全额扣；存量融资义务按债权处理，FCFF不扣其本金、现金桥则扣。现金股息和回购均为零假设。

本次不沿用上游报告的“Owner FCF”计算结论。上游扣损益表SBC的口径适于经济成本诊断；本次为了同时清楚展示2030可转债，改用上式、未来逐年股数及终值期每年1%净稀释。二者若未经桥接，不能直接拿数值比较。SBC费用与实际授予/归属时点本来不同，净新增股数是研究假设，见附录；股价下跌导致相同薪酬价值需要更多股份的压力另行测试。

### 5.2 为什么统一固定28倍，而非当前约百倍

### 5.3 最终交易倍数为何不同，DCF为何没有机械封顶

悲观16—22倍低于28倍，必须同时对应永久性受损的条件：项目延误演变为客户转向二供/替代、ASP下行、产能闲置、服务成本及融资窗口变差。Mainspring/AEP、替代供给扩大及现有营运资金风险说明机制存在，**没有证明它们已经造成Bloom永久丢单**。若只是短期错位、净价格和服务回报保持，悲观的结构性低倍数不适用，应向基准修复。

基准30—36倍高于固定28倍：2029仍有约16%的下一年收入增长、新项目复制和服务覆盖上行，且累计现金使融资约束缓和。乐观34—42倍需要非Oracle多客户验证、39%左右产品毛利和超过5GW阶段的新厂产出；突破38—48倍需要公共电力/CCS和800V配置形成重复收费，并非仅在官网出现合作名称。它们分别含不同长度的后续成长期，不应自动按成熟衰退设备倍数交易。

**价格溢价不能用一句“市场会给高倍数”解释。** 目标区间中点相对剩余DCF分别约2.8x、2.6x、2.5x、2.5x。基准约193美元对DCF73美元的差额约120美元，若完全靠2029后现金实现，而无期权和未来资金成本下降，相当于资本化约33倍NOPAT*，而本次保守现金路径对应仅约12倍经营资产NOPAT*。在前述10%/35%ROIC框架中，约21%—22%的十年利润增长或较长的高增长延续，才接近33倍；仅按基准显式路径中后段的较低增速并不足以兑现全部溢价。

由此作出明确取舍：**允许2029仍处成长期的股票提前交易新市场选择权，但不把这部分溢价当成今天的安全垫。** 当前真实采购、资金平台、800V技术结合和CRC公共电力入口，使更长成长机制有依据；它们尚未锁定，所以DCF保留低速成熟过渡，而市场区间反映验证后可能给出的期限与选择权。若届时这些机会未跨门槛，预计价格应靠近DCF/固定倍数参照，不机械维持30—48倍。这一差距正是小仓位与核心仓位决策不同的原因。

再用含SBC可比利润交叉检验：2029基准含SBC可比EBIT18.67亿，按20%税后约14.94亿，市场中点隐含约40倍上下的每股经营收益；乐观和突破在更高规模、较好资本回报和新市场下可保持成长溢价。服务不是无成本软件、现金FCFF又显著低于NOPAT*，故本次没有以P/S或平台名义再抬一层估值。附录C列敏感性，市场价格持续高于DCF是需要后续证据兑现的条件判断。

### 5.4 证据支撑与商业可实现性分别评价

**悲观弱（weak）**：延期申请和现金占用已有事实，但主悲观的永久压价、规模受损和高成本再融资尚未发生，不能把压力测试包装成确定下行。**基准中（medium）**：既有需求、设备盈利与主要客户真采购扎实，但2029核心新客户增量和服务更新利润尚未锁定。**乐观中（medium）**：客户批次、现有技术和供应扩张有正面线索，新增场地、非Oracle队列及高毛利复制仍需跨期证明。**突破弱（weak）**：多个未完成门槛同时成立，包含新公共电力钱包与大规模供应扩张。

本标的没有将任何情景评“强”，原因是决定2029规模的核心增量未被现有不可撤销净订单、生产与服务队列充分覆盖；也没有评“不足”，因为情景未与已知物理或客户预算形成必然矛盾，且各有可检验路径。证据等级不随价格由低到高自动排列。较弱证据的突破仍可有商业实现性与大赔率，不能简单删掉；同样不能据赔率大就把证据升级。

## 6. 现价隐含要求、仓位与动态验证

### 6.1 200.40美元究竟在押注什么

固定基准2029资本和股数，200.40美元附近使0%债转换具有稀释性。若目标年市场给30—36倍NOPAT*，仅达到同样200.40美元名义价格需约**17.2亿—20.6亿美元NOPAT***，约对应本次基准18.06亿附近。故现价大体已经提前支付**基准兑现并保留成长溢价**，尚未完全付掉乐观/突破收益。

但投资者还有三年时间成本。若要求每年10%，2029需约**270.75美元**；在相同30—36倍及资本桥下需约**23.7亿—28.4亿美元NOPAT***，明显高于基准，接近乐观29.92亿。若税后利润率18%、其他收入约15亿、产品净价2.70美元/W，对应总收入约132亿—158亿、约4.3—5.3GW新机量级，需高于基准的产线、预算与客户兑现。这是现价对满意回报的真实要求，不能只比较远期总收入增长。

若只在基准/乐观市场区间中点193.05/361.40美元之间做阈值运算，要达到10%年化所需的270.75美元，乐观状态的条件权重约46%；加入悲观会提高所需权重，加入突破会降低。**这只是回报门槛，不是本研究给出的46%发生概率。** 不用未经校准的概率加权目标价掩盖左尾。

### 6.2 可执行的参与方式

1. **当前200美元附近：观察仓0.5%—1%，普通股、以现金投入为限。** 依据是真实大客户订单、既有产品盈利和跨市场右尾；接受主悲观约85%—90%股价损失对应约0.4%—0.9%组合损失。此处是成长选择权仓位，组合能否承受须由投资者自身约束决定，不把它当稳定现金底仓。
2. **价格回到145—165美元，经营并未下修：可分批提高到1%—2%。** 以基准中点193美元，对应约17%—33%目标期名义回报；乐观中点约119%—149%。这仍依赖后续交易溢价，不宣称已经跌到保守DCF现值。
3. **若价格先升到230—260美元：只有在模型同步上修时才加。** 需Q4普通FCF至少1.5亿、Q1收入至少14.5亿且FCF不再明显负、2027收入指引/有证据工作路径至少70亿、平均合格产能连同FRU分配支持约2.2GW新机，并出现非Oracle重复订单。达标后按上修模型重算，最高先到1.5%—2%；不因单个MOU提高到核心仓。
4. **在300美元以上而经营仍停留本次基准：不新增。** 此时即使实现乐观325—398美元，剩余上行对时间和左尾的补偿已明显下降。已有观察仓可随里程碑保留，价格先走而现金验证没有跟上时应降低风险。

等待的机会成本是实在的：若未来两次财报验证，市场可能先到260美元；再买入对本次乐观区间只余约25%—53%上行，而当前是62%—99%。但信息改善会降低部分执行不确定性，并可能上修经营数字，不能只看买贵了多少；若升到300却没有模型上修，追涨赔率变差。小观察仓保留部分右尾参与，其余资金等待证据与价格共同改善。
