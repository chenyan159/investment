# Ichor Holdings（ICHR）：经营情景、市场定价与当前投资决策

## 0. 当前结论与四情景总表

**当前判断：33.71美元具备小仓位参与价值，仓位属性是半导体设备景气与部件转型的观察仓。可在31—35美元分步建立约0.5%—0.8%的组合仓位；达到后文现金与毛利验证条件后，再考虑提高至1.5%—2.5%。** 当前现金流折现安全边际只有约一成，尚不足以支撑重仓；正常化经营利润的交易定价则提供明显上行空间。投资成立依赖盈利和现金质量逐步兑现，不能仅凭流控愿景或历史高股价。

## 2. 业务经济与竞争位置：关键产品如何形成收入和利润

### 2.1 OEM购买完整交付能力，Ichor争取更多制造价值

晶圆厂是最终使用者，Lam、Applied等设备OEM通常决定模块规格、供应商资格和采购，亦是主要付款方。Ichor按气液输送系统、焊接与精密零件收费；没有随客户晶圆收入持续抽成的公开模式。2025对Applied销售371.697、对Lam351.418，合计占76.3%；这是历史客户组合，不冒充2026实时权重。[10-K Note 10][S08]

本研究按经济机制保留以下业务。

| 经济单元 | 客户买到的价值、收入机制 | 利润来源与主要约束 |
|---|---|---|
| 气体输送系统集成 | 为刻蚀、沉积等整机提供高纯、可重复、可维护的气路；按系统交付收费 | 平台资格、装配测试和响应速度保护采购入口；外购BOM占比较大，OEM采购议价强，齐套和在制品消耗资金 |
| 自有被动部件、焊接与精密加工 | 阀、接头、基板、焊件与特定加工能力；既可内供也可对外销售 | 内供节省外购利润；外销增加合并收入和制造增加值。机加工良率、工时、耗材、质保和新增设备均是真实成本 |
| 主动流控与下一代气箱 | 通过流量、压力、关断和控制集成改善配方执行、体积或维护 | 有跨代替换与跨平台复制机会；必须完成OEM和终端工艺资格、可靠性、复购及可盈利批量生产。内部替代不会另造收入 |
| 化学品输送、湿法及其他精密制造 | 混配、分配清洗/电镀等化学品；航空航天等客户购买精密制造 | 应用可扩展至先进封装等环节，仍按硬件交付收费；采购节奏、腐蚀兼容和加工排产不同，现有披露不足以单列可靠规模 |
| 制造迁移、退出与整合 | 从部分高成本厂区向马来西亚、墨西哥等承载点重配 | 有固定费用节约，也发生搬迁、库存、机器、培训和退出代价；不能只计节约 |

单一可报告分部缺乏各产品收入和利润披露。模型因此采用“原有采购篮子＋新资格带来的外销增量”去重，未补造历史产品分部。集团合并范围未识别重大少数权益、优先股、可转债或需另行扣减的JV分成；资产、子公司和内供销售按合并归属处理。[10-Q Notes 1、10及资产负债表][S01]

客户支付上限应由经济结果约束：`可接受溢价≤可归属的报废减少＋停机减少×每小时贡献利润＋维护节约−验证/换型成本`。对比公开规格可以发现机会，尚不能给出已证实的客户TCO节省金额。晶圆污染或停机损失使质量资格重要，OEM仍能通过二供、指定元器件、年度降价和重新设计分享节约。因此，本次预测中原有系统业务长期毛利显著低于专有外销部件。

### 2.2 内供、外销与自我替代必须分别计算

假设气体系统收入为Rg、BOM占收入b，自有含量提高Δc，内供相对原采购价的全成本优势s，则集团毛利增量约为`Rg×b×Δc×s−新增报废/质保−客户分走的降价`。含量提高5个百分点，不能直接写成集团毛利率提高5个百分点。

以集团2027收入约1,586为条件，若气体系统占65%—80%、BOM占系统收入60%—75%、自有含量提高5个百分点、全成本优势15%—30%，毛利改善约**4.6—14.3**，约为集团收入0.3—0.9个百分点。以上比例均为研究边界，尚无产品明细验证。它揭示被动部件内供有用，但不足以单独解释集团从16%—17%直接跳至20%以上。

管理层称Q3末自有含量超过30%、Q4末目标35%，并称六个新平台定点位于气箱以外。后者提供新的外销入口；“Q1至Q4外销增长250%”的基数未披露，且Q4仍是展望。模型只给新资格带来的**新增对外收入**，没有把内部部件收入、原有气箱和外销三次相加。[11月2日准备讲话及问答][S03]

主动流控可以替换原外购控制器，亦可能替代自身旧平台。基准给2029新增外销25，乐观120，突破300；内部替代的收益仅进入原有业务毛利。突破的300是待验证的采购钱包假设，没有已公开合同锁定。它需要多平台正常价格复购和可靠生产，且不能以低价测试出货冒充可盈利商业化。

### 2.3 需求与供给必须在同一个产业链预算内成立

Lam 10月披露2026系统收入预计增长超过40%，12月季收入指引8.6十亿美元±0.4；同时承认洁净室与部分部件约束。Applied 8月预计下一财季Semiconductor Systems约7.9十亿美元；服务收入没有全算成新气箱钱包。TSMC 10月重申全年资本预算60—64十亿美元，体现终端付款能力，但其预算包含土建、多个工序和安装时滞。[Lam第3、7页][S05]、[Applied第7页][S06]、[TSMC第4页][S07]

竞争者UCT的2026Q3产品收入681.9、服务77.1，产品GAAP毛利率15.6%、集团16.9%。同行同样增长，支持真实需求，也反证Ichor增长全部来自抢份额。其服务和其他业务不可全当气箱竞争规模。[UCT当季附件及分部表][S12]

气路精度、洁净与客户资格具有持续价值；某一类短缺却可能被新增供给缓解。HORIBA已启动福知山工厂，公告称未来日本MFC产能可扩大至约三倍，未表示当期合格出货已经三倍。故**短缺帮助Ichor争取验证窗口，长期利润仍须靠质量、成本和复购保留。**[HORIBA原始公告][S13]

管理层称2027所需设备已下单，计划六个月内安装；洁净室转换约3—4个月，并使用已资格认定的第三方制造。厂房空间、安装设备、合格良率、员工训练和订单是不同阶段。约30亿美元的潜在收入承载能力是管理层对厂房转换的判断，不能替代逐产品合格产能。突破路径2029收入约29.22亿美元已接近该口径，需要接近满额的有效转换能力，另计更高CapEx和第三方制造成本。[公司产能说明][S03]

### 4.1 统一桥接方法与SBC处理

本节仍不引入估值倍数。全模型采用**股份分配法计入SBC**，避免与扣费法混用：

```text
核心EBIT = 经济桶毛利合计 − 核心OpEx（均在SBC、收购摊销前）
GAAP近似EBIT = 核心EBIT − 现金重组费用 − SBC − 收购摊销
净利润 = (GAAP近似EBIT − 债务利息 + 现金利息) − 现金税近似
CFO = 净利润 + PP&E折旧 + 收购摊销 + SBC − Δ经营NWC
银行FCF = CFO − CapEx
期末现金 = 期初现金 + 银行FCF − 本金 + 股权计划净现金
可分配FCFF = 银行FCF + 净融资费用×(1−税率) + 股权计划净现金
核心NOPAT = 核心EBIT×(1−正常化税率)
```

可分配FCFF中的股权计划净现金为员工代扣税支付减期权/ESPP收款，经济上是现金薪酬结算的一部分，尽管会计列融资；2027—29基准、乐观、突破每年−4，悲观−3。未来完全摊薄经济权益再净增：悲观2.5%、基准1.8%、乐观1.6%、突破1.8%/年。GAAP近似EPS是法定利润对模型平均股数的折算；估值不再把SBC费用从核心NOPAT和FCFF重复扣减。DCF在2029之后继续减少原股东的现金流分配比例，终值也计入净稀释。

09-25未归属奖励包括服务条件RSU0.854827百万、业绩条件0.145644百万、市场条件0.138629百万，合计1.139100；当日期权在外为零。实际在外加上述目标奖励为38.696145，模型取38.70。已计奖励日后归属只是在潜在股和流通股之间转列，**不会再加一次**；未来净增率代表新增授予、ESPP及PSU结果差异，扣除没收与代扣税现金结算后的新增经济权益。未授予的计划授权额度没有全部计成已经稀释。未来股权计划现金与净股数假设需随实际授予/结算更新，目标兑现不是最大PSU兑付保证。[Note 9奖励活动表][S01]

## 5. 估值转化、倍数解构与目标股价

### 5.1 为何固定12×正常化核心NOPAT

本章才将前文经营结果映射为价格。按38.70百万共同完全摊薄起点，当前股权价值约1,304.6，加入本金120.3、扣现金213.5，EV约1,211.4。TTM法定净利约3.515，P/E约371×；当日快照的481.57×使用供应商EPS0.07，股数和更新时间亦不同，不直接继承。TTM核心EBIT约52.845，以18%税率计算EV/核心NOPAT约28.0×；Q3单季年化则约13.0×。分母所处周期明显影响估值。

据此选择**12×**作为四行情景共用的行业正常化基准：接近已实现同行与ICHR最近运行率，同时对Ichor盈利质量保留约束。它不是强行维持当前失真的TTM P/E，也没有预先给新流控赋软件式倍数。当前同口径Q3年化NOPAT按固定12×并加净现金约对应31.2美元/摊薄股，接近现价；因此到2029基准68.7的主要贡献确实来自经营和现金，而非先把当前锚抬高。

### 5.2 DCF：目标日剩余经济价值，终值单独受资本约束

2029目标日DCF从2030起计剩余现金流，**不把2027—29已积累现金再重复折现一次**。显式期为2030—2039，期间核心利润率在五年内过渡到跨周期中枢。固定资产折旧底为收入2.2%，初始增量固定资本约新增收入12%；再用逐步下降的增量ROIC限制增长所需投资。若物理CapEx与NWC给出的再投资低于`NOPAT×增长率/增量ROIC`，提高CapEx/生产能力投入补足，避免高增长免费获得资本。

WACC共同取12%，敏感性11%—13%。研究日美国10年期名义国债收益率4.90%；采用研究设定的正常化权益beta约1.45、股权风险溢价约5.25%，股权要求回报约12.5%，加上约8%—9%债务权重及6%左右债务成本，WACC约12%。参数用于跨周期资本成本，并非回归beta实测。已在情景现金中反映执行、需求和竞争，未再对弱情景额外加一遍主观折现惩罚。[财政部当日收益率表][S15]

所有情景永续增长3%。稳态增量ROIC分别12%/15%/17%/18%，对应再投资率约25%/20%/17.6%/16.7%；增长越快或ROIC越低，资本支出越多。SBC未来仍有净稀释，终值每股增长低于公司总量增长。2030后的SBC会计代理为收入1.2%，股权计划净现金为其20%的支出，税盾单列；其余报酬分配通过股数实现。股数以近期净发行纪律作压力外推，没有依据远期高股价自动压低授予成本。

目标日DCF每股为**16.0、50.5、81.0、113.7美元**；显式期与终值占比、完整年度序列见附录。终值占EV约36.4%—44.9%，没有把大多数价值藏在一个遥远年份。基准长期ROIC约束和净稀释均已计入；它是有条件的经济价值参考，不是市场交易价硬底。

### 5.4 证据支撑度与商业可实现性分别判断

**基准为中（medium）。** 成熟交付、实际需求、加工设备、部件入口均有事实，但该路径仍需要持续周期增长、毛利和周转修复；PO缺乏最低量约束、指引历史存在偏差，不能把它当作高锁定合同型白马。

**悲观为弱（weak）。** 当前现金压力和缺件真实存在，但模型中的多年客户缩单没有直接锁定，主要客户最新实际交付仍强。压力的经济机制合理，发生证据弱；不能因为用于下行测试就自动评中或强。

**乐观为中（medium）。** 六个平台入口、当前外销贡献和客户预算提供初步商业线索，尚缺跨期金额和复购，足以支持合理超预期推演，未达到高锁定。**突破为弱（weak）。** 技术与既有OEM渠道使其商业上可实现；外销300的规模和高毛利要跨过多个未证实门槛。没有识别违反预算/物理约束的事实，故不因未知一律评“不足”，也不伪造强证据。

本公司两档出现重复来自证据性质本身，不为凑四档而把未锁定路径硬评强，或把有现实入口的突破硬评不足。证据定级不等于发生概率，本报告不强行赋予四情景主观概率加权值。

## 6. 当前投资选择与动态验证

### 6.1 现价在押注什么

当前价格**没有按突破定价**。在保守现金流方法下，它接近基准当前价值、略低于基准；在正常化交易倍数方法下，它处于悲观与基准之间。两种判断说明市场愿意承认近期复苏，但对盈利持续期、备货现金和部件转型尚未充分支付。

用同一经营模型反推，保持基准收入1,993、费用、税率、资本开支、营运资本与股数规则，把2027—29各经济桶毛利同步下调约3.37个百分点，重新滚动现金后，2029集团毛利率约**15.8%**、期末现金约**315**；固定12×目标价折回12.5%股权要求回报，接近当前33.71。反推并非维持高利润现金余额再随意压EPS。它表明正常化交易法允许一定盈利修复落空；保守DCF法给出的缓冲则小得多。

最核心的分歧变量是**全成本毛利、营运资本强度、部件外销采购持续性**。行业WFE总量重要，却不能替代这三项。与现金牛相比，Ichor对单一客户预算和库存变动更敏感；与完全无收入叙事相比，它已有真实交付、现金和可复用制造资产。当前应以小仓位获得后续验证权。
