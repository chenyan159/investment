## 1. 当前选择、主要分歧与时点

**当前结论：以 225.56 美元买入，短期、中期和稳健长期投资均不建议参与。对能够承担大幅损失的长期技术突破投资，机会值得研究，但当前证据尚不足以支持现价建仓。** 这不否定 Besi 的技术价值或经营上行：Q2 的增长与利润已经兑现，问题是买价要求把相当规模的未来成功提前兑现给卖方。单独让 HBM、CPO 或消费端混合键合中的一项充分成功，在普通核心经营下也未给出有吸引力的三年回报。

这不是“等一季必然更好”的结论。公开信息尚不足以估计确认后能以什么价格成交；等待可能减少错误，也可能错过重估。本文选择不按现价建立仓位，理由是经营证据支持的价值不足及突破组合尚缺规模证据，**没有把无法证明买入占优，偷换成已经证明择时占优**。

### 2.3 上游预算、数量边界与竞争反馈

SEMI 2026-07-14预测2026全部封装组装设备67亿美元、2028为86亿美元；这是预测且包含传统设备，并不包括所有前道式封装设备。TSMC 7月16日业绩会把资本预算提高至600～640亿美元，其中先进封装、测试、光罩及其他合并为10%～20%，对应60～128亿美元宽桶。这些事实支持客户有预算，不能把宽桶直接乘Besi份额，也不能与OSAT转包支出重复加总。[S14][S15]

数量校核采用：`新增所需机台＝新增可服务良品连接量／(良品UPH×年度有效小时)−可复用闲置设备＋必要更新`。以1500UPH、6000小时为上限基准是900万次/年；按70%综合开动、良率及换线有效系数约630万次，3000UPH平台可接近1260万次。因口径可能重叠，综合系数只扣一次。实际客户良品UPH未公开，故用400万～1200万次/台年工作范围，不能声称已测量。

HBM完整成功参照2030新增180台×2.6＝468收入、2031为230台×2.6＝598；对应新增0.72～2.76十亿次连接产能（分别按180×4与230×12百万），若一堆叠需15个相应界面，约4800万～1.84亿个堆叠的产能量级。不是预测当年实际HBM产量：界面定义、裸片配置、存量复用、选择性HB和客户占比均可缩小范围。它说明该收入需要主流客户产线采购，几套研发设备远远不够。

HBM早期上限、逻辑核心、CPO及EDGE按互不重叠用途计设备。基准2030逻辑165台，HBM加权约76台、消费端约5台；CPO为多产品综合系统，其中假设约一半收入属于HB，折合约12台，合计约258台。突破2030相应约300＋180＋17＋23＝520台，已超过420名义年率；需要2028前确认扩建并在2030达到约600台有效HB交付能力，最强联合分支约700台。额外有形、研发及周转已随路径增加，供给不能无限扩张。五至十年后更大台数还需继续扩容，模型不是冻结2026厂房。

对传统与光学设备，基准2027约510～733和219～350台并存，仍需装配工位、精密组件和应用人员。公司没有披露逐机型合格工时，不能把厂房面积当已验证交付能力。基准上限以客户采用和产品复购为约束，突破同时加入扩大供应和服务组织的成本。

行业金额还构成突破路径的第二道约束。若仅以SEMI 2028年的86亿美元为基点、研究假设2030再增长8%～15%/年，得到2030传统统计边界约100～114亿美元；Besi基准19亿欧元约22亿美元，突破34亿欧元约40亿美元，相当于该宽设备池约19%～22%与35%～40%。因为HB/整线中的前道式设备、服务与统计归属不同，这不是精确市场份额，却说明突破需要显著扩大可服务工序和夺取预算，不能靠一个细分市场小幅增长解释。管理层40%+目标是其可服务市场口径，不可偷换为全球所有封装设备份额。本研究没有把SEMI预测直接乘40%生成Besi收入；这里用它否定“突破不需要份额/用途跃迁”的解释。

Applied于2025-04-14通过市场交易持有约9%Besi，表明合作承诺，不是Besi收到融资，也非全面收购。Kinex把表面制备、精密贴装、洁净传输与过程控制合并；整线商业化提高进入门槛，也可能让整合商掌握客户入口。合作净收费、排他性和模块替换条款未完整公开，因此不假设Besi拥有整线全部收入或永久收费权。公司收购传闻不计入对价、成功概率或估值加项。[S16][S17]

## 3. 四套连续经营、机会状态与资本底稿

### 3.1 情景机制及连续路径

悲观是可存续的受损路径：传统复苏回落、HB客户延长旧工艺、净价受竞争压制，2027收入下滑，费用调整落后，随后缓慢恢复。它不是破产极端情景。基准由订单增长、广泛逻辑/光学需求和已商业化产品支持，维持HB逐步扩散，但不要求HBM全面采用。乐观解除更多客户资格和供应限制、净价和组合较好，2030收入高于管理层目标区间；这需要公司特定份额与新客户，不是行业预测直接外推。突破的最低核心条件是HB/2.5D跨多家平台扩量、N50/后续更新成功、整线合作维持合理净收费及供应服务同步扩容；三类早期机会仍按各自概率，EDGE可以失败，不要求所有机会全胜。

### 3.3 早期机会：逐年状态、成本和期望贡献

三类机会都从“增量商业扩散尚待验证”的U状态起算，**不是把已经存在的试验机收入抹成零**；已有用途已留在核心。状态U为尚未增量商业化、P为有限/部分成功、S为当年达到定义的规模成功、F为该路径失败退出。每年四状态互斥、加总100%，F吸收、不无条件恢复；S可以退化至P或退出，故表内S是当年仍成功概率，不是累计曾成功概率。

年度转移矩阵为：U→[1−a−f,a,0,f]；P→[0,1−b−f,b,f]；S→[0,d,1−d−h,h]；F→[0,0,0,1]。每年分布p(t)=p(t−1)T；禁止把“累计曾成功”每年重新相乘。EDGE在2027—28的a、b均为0，继续验证或退出，2029才开放商业转移。

这是**机制约束的主观工作分布**，不是行业统计基础率。本次未取得可比客户逐年完整认证、退出样本，不能伪造频率。高端工具交期6～9个月，加客户工程验证，U到P通常需要至少一个年度；已有逻辑量产和存储复购提高进入机会，但MR-MUF延续与客户两阶段验证使P到S不能与U到P同样容易。CPO路线多、可先做小额扩散，进入率高于HBM；消费广泛采用最受单位成本和客户产品周期限制，起步更晚。

### 4.3 投资论点与主方法

**现金回报／安全边际。** 高毛利、轻资产和分红是真实优点，但起点净现金仅约2美元/股，不能给225.56提供资产底价。模型全部研发、扩容、周转和SBC成本已扣，DCF表达可归属现金。当前基准和乐观现金回报不足，较低买价或强得多的经营路径才可能成立。

**周期修复与一年兑现。** 2027盈利比2025低谷显著增加，是合理的盈利恢复逻辑；但TTM约75倍、基准当日起NTM约48倍经济利润，买方已经支付大量恢复。盈利增加只有在退出倍数不充分收缩时才变成交易收益。该论点用同一经营底稿的NTM盈利倍数作交易范围检验，不自动改变内在合理价值。

**跨代复利／高风险技术突破。** Besi若从少数高端客户延展至多家逻辑、存储及光学产线，规模和更新需求可很大；条件突破2030约34亿收入，2036约58亿，需逐年投入且仍有竞争。主估值采用目标日后现金流DCF，保留五至十年的机会，未用三年现金流封顶。独立HBM、CPO、EDGE完整成功参照保持核心普通，检验“只成功一件事”是否足够。

折现参数范围：欧元名义企业现金折现率9%～11.5%，工作10%；对应现金时间价值和未进入经营现金的系统性资本风险，**不是各情景发生概率的替代折价**。2025审计减值模型披露Die Attach税前折现13%、无风险3.3%、权益溢价5.3%，可作历史数量级参照，但并非2026-09-09实时市场资本成本，税前13%也不能直接套税后FCFF。[S1]（印刷页213） 本文保留8%的强资本成本替代解释，明确它对投资结论的影响；投资者12%或15%持有要求是另一个选择标准，不能反过来改写公司经营。

低端价值用r=11.5%、g=1.5%；工作用10%、2.5%；高端用9%、3%。同一行的三期限都沿同一生命周期和ROIC，不能每个期限另挑倍数。区间是参数组合的条件价值包络，既非价格置信区间也非四行情景概率分布。

### 4.5 盈利交易论点、相同权益下的方法差异与反向估值

主方法和交易倍数不能简单平均。同一现金路径下，基准三年工作DCF约153.5，对目标NTM经济EPS约9.50只相当于约16.2倍；直接给40倍会得到约380。差异不是“DCF保守、PE成长”几个字，而是40倍在当前经营路径下隐含更低风险补偿、更长高增长或更大的2030后利润。若这些经营假设相同，两个工具必须回到相容值。

这些倍数是**交易行为边界算例**，不是可核验概率预测。2026-09-08项目快照同业AMAT/KLAC报价字段的forward PE约25.6/28.25，但源未提供逐字段预测截止和会计调整日期，ASML还存在明显EV/EBITDA异常；本研究不把这些不完全可比字段当精确估值锚，也没有继承任何同业评级或目标价。[L3] Besi毛利、研发结构和HB集中度不同，不能只凭同业一组倍数裁决。

反向DCF固定基准经营和g=2.5%：让现价仅保本，6个月需r约7.06%、12个月7.21%、三年7.92%；让三年达到12%年化则需约**6.28%**企业折现率。相较工作10%，差异不能由0.10美元报价误差解释。8%/3%强替代解释使基准三年每股约220，加分红仅约4%累计回报；即便明显降低风险补偿，稳健长期的12%年要求仍不成立。

反向经营门槛更直观：三年12%要求需要退出价加股息约316.9美元；基准约167.6、乐观约247.7、突破约338.9。沿乐观与突破的**相容整体驱动**插值，约76%的跨度才达到门槛，2030收入需约32亿欧元、EBIT约15.6亿及相应2036增长、产能和再投资；不能只把2030某一年净利润调高而保留其余基准不变。该反求用于检验独立范围，预测来源仍是第2节需求、量价、竞争及第3节底稿。

最小重要分歧不是“有没有HB”，而是Besi能否持续拿到足够多的**新增可收费设备**，且在吞吐提高、客户复用、竞品认证、整线分利和扩容成本之后仍保持利润。当前证据足以支持收入显著高于2025低谷，尚不足以支持三年回报门槛所要求的约32亿2030收入及其后成长具有主导地位。

## 5. 条件建议矩阵与十二格明细

以下矩阵固定每行经营路径，**不因该行情景目前罕见而下调主格**，也不把市场能否及时采纳混入标签。三类增量机会已在第3.3节按行情景内部状态概率加权；突破行假设核心技术与供应服务实现跨代扩量，并未假设HBM/CPO/EDGE全部成功。单一完整成功参照不能代替主格。

投资标准为本研究参考而非用户真实偏好：短期采用经营价值兑现/里程碑理念，6个月目标总回报至少8%（邻近5%～12%）；12个月采用兑现/现金转换理念，目标至少15%（邻近12%～20%）；36个月采用跨代复利理念，目标12%年化、约40.5%累计（邻近10%～15%，对应33.1%～52.1%累计）。允许波动，但稳健参与要求普通合理误差下有余量。高风险突破可承受40%～70%的实际损失，不要求每个结果盈利，但必须有可信的上行和相称概率；失败不是靠“长期持有”消除。

相同理念和期限四行用同一标准。显著超过要求且合理不利敏感性仍成立才给强烈建议；工作值超过但低端/参数分歧会翻转时只给谨慎。突破三年工作年化约14.5%，在12%标准下条件正面、在15%下翻转，因此不是强烈建议。乐观三年高端累计约31%，仍低于12%标准40.5%，故经营更好也可以不建议。

### 6.3 当前路径、风险承担与高风险论点的取舍

当前证据最支持基准经营机制：订单/收入上行、逻辑和光通信已有商业落点、研发和资产负债可支持扩张。最强替代解释是乐观机制开始展开：更多客户采用以及2.5D多工序增长可能令收入超过现有预测。两者都比“经营已严重结构损坏”更有当期支持；然而**基准乃至乐观路径的三年回报均不足主标准**，因此无需伪造四行情景概率来拒绝稳健现价买入。

高风险突破不能只看386美元区间上沿。用已经算出的同一工作底稿做一个限定的两分支门槛实验：普通结果三年价加股息约167.6，突破约338.9。如果仅有这两种互斥结果，保本需要突破权重约34%，达到12%年要求需要约87%。**这不是四行情景的发生概率模型**：现实还包括乐观、中间路径、严重失误和更大未知成功，本实验只说明上行/失败补偿的形状。不能拿HBM当年规模成功概率23%或42%替代整股组合权重。

为什么当前仍拒绝高风险建仓：所需约32亿2030收入及相容长尾，需要超出35台/月准备量的有效扩产、多家逻辑重复量产、可守住的净收费，以及较早存储扩散共同实现；现有生产/评估混杂、客户数口径冲突、MR-MUF与TCB竞争以及N50尚在beta，使这些条件尚不足以成为当前占主导的经营解释。现价已不允许“机会仅存在且可能成功”就获得充分补偿。该取舍是证据权衡，不是声称已统计证明突破概率低于某个精确数字。

若投资者采用显著较低收益要求，接受大幅亏损，或持有期超过三年并能承受多年商业化延后，高风险选择可不同。但当前未建立收费规模的HBF/量子等不能被用作任意兜底。能改变本报告的最少新证据是：至少两个新增独立终端平台进入可重复生产采购、有效机台交付能力越过约500/年门槛并能继续扩张、单位产能净收费与集团现金回报不被竞争抵销；或在经营基准不受损时，买价降到约100～125美元的研究边界。这些不是每项独立必需的法规式清单，而是对应模型收入、利润和资本的最短可观察解释链。

### 7.3 复算参数、公式与逐期对应

1. 第3.1表给2027/2030/2036核心锚点；之间按年份线性插值，先算数量×价，再加六项核心收入。核心毛利与费用公式在3.1；三类增量机会依3.3的状态转移、量价及成本独立计算后相加。四季度按23/24/25/28分配，Q3/Q4 2026用单季假设。
2. 2027核心Δ营运资本＝24%×(2027核心收入−2026全年集团收入工作值)，以后＝24%×核心收入年增量。2026作为已有经营比较锚，试验业务未独立披露；未来新机会营运资本另按其增量状态处理。这个分配误差可影响首年FCF，不改变事实现金起点；不能用调整营运资本去强行凑目标估值。
3. 每类机会状态收入`[0, partial×Q×ASP×scale, Q×ASP×scale, 0]`，状态先算毛利、费用、税、CapEx、DA及NWC；对上一年至当年的转移`p[j]×T[j,k]`计算ΔNWC和首入F损失。期望集团EBIT、现金不是把成功净利粗乘一个累计概率。
4. 2026H2季度DA各10、租赁现金各1.1；当期SBC为收入1.8%。2027后核心DA＝收入2.5%＋8，加增量机会DA；集团租赁现金＝4＋集团收入0.2%，SBC＝集团收入1.8%。CapEx及资本化开发全部扣一次。
5. 企业FCFF不加SBC；经济FCFE＝FCFF−(4.5%×债务−2%×现金)×83%。资本桥按每个实际日累计，年度股息=上年净利×40%或80%，5月15日支付；净利润计入税后净财务成本。2031-07-17还350票据，未来债息同时归零。
6. 目标日只折目标后现金；2026H2及2027后季度内FCFF按天均匀。剩余季度的中点折现天数除365.25。终值按第4.4式在2036-12-31计算。资本桥加现金减债及其他权益，股数81.15、汇率1.1614，股息只计研究日起持有者可获得部分。

DCF可用下面短代码从本报告的年度FCFF、目标日资本表和EBIT终值复算到小数舍入附近。季度细分和2026H2取3.2表，状态模型沿3.3复算。因公开产品利润不足，任何复算只能验证假设传导与一致性，不能把等式成立称作预测已被证明。

from datetime import date, timedelta
def remaining_value(target, quarters, r, g, ebit_2036, roic,
                    cash, debt=350, shares=81.15, fx=1.1614):
    ev = 0.0
    for start, end_exclusive, fcff in quarters:
        a, b = max(target, start), end_exclusive
        if b <= a:
            continue
        weight = (b-a).days / (end_exclusive-start).days
        midpoint = a + (b-a)/2
        ev += fcff*weight / (1+r)**((midpoint-target).days/365.25)
    terminal_cash = ebit_2036*0.83*(1+g)*(1-g/roic)
    ev += terminal_cash/(r-g)/(1+r)**((date(2036,12,31)-target).days/365.25)
    equity = ev + cash - debt + 5 - 18.6
    return equity, equity/shares*fx
