## 一、先给当前选择：现价不足以补偿普通兑现，高压突破保留条件价值

**当前三个期限的主判断均为“不建议按 50.46 美元新建仓”。理由是独立模型支持的普通经营价值不足，并非认定公司没有技术价值，也不是用悲观情景代替全部未来。** 汽车、工业驱动和高压集成是有经营依据的增长来源；但从当前收入到高毛利、扣除投入后现金、再到稀释后每股价值，还需跨越数个独立门槛。股价下跌不能代替这些门槛的验证。

**理念分歧需要保留。** 现金安全边际目前不成立；一年经营修复可在乐观条件下参与；三年稳健复利目前回报不足。高风险技术投资可以容忍较多失败，但本文定义的“主功率规模成功”不是足够大的独立赢家；放大到更大商业规模后确有正价值，然而相应成功程度、存续和三年退出定价尚不能由目前证据支持。对于无法建立金额边界的更远期平台跃迁，结论限于本文覆盖的商业路径，不宣称所有远期可能性已被否定。

在经营不变时，基准中枢与参考要求对应的买价约为**短期32.6、中期32.6、长期29.2**；采用12%估值折现率端点，则约为**28.4、28.5、26.1**。这些是有条件的价值边界，绝非基本面恶化后仍有效的限价单。当前拒绝参与主要来自价值不足；第六章说明为何还不能声称“等一季财报”具有可证明的策略优势。

### 3.5 投入回报、经营寿命与三年以后的剩余价值

核心技术是一组持续更新的产品系列和客户设计能力，不是某一款芯片的有限专利期限。多年客户、隔离/控制与测试资产支持跨代复用；竞争方案、价格年降和持续研发意味着下一代利润不是免费续约。本研究较支持“可更新平台”，但不支持不经投入地永续保持突破毛利。

对项目投入，M/A/P/H/V的2027基础现金预算合计20，外加试产/测试与状态触发的量产资金。以普通P的2030规模100为例，其毛利56，固定工程支出约11.3、持续费用16，GAAP经营贡献约28.7；税后约24.4，再支付CapEx与周转。100规模并不等于100利润。若新投入累计达到70—110，税后贡献24左右对应粗略成熟收益/投入22%—35%、简单回收约3—5年；这只是项目现金容量检查，既非实测ROIC也非IRR，且不含尚未成功年份的持有时间损失。延期一年仍支研发，使回收变慢。

2032—2036核心增长按产品池逐步降至1%—5%，上行毛利也受竞争压缩。2037起核心名义增长分别1%/2.5%/3%/3%，新增经营资本回报假设12%/18%/22%/24%，增长再投资为税后经营利润×增长率/ROIC。已失败机会保持失败；存续早期项目的U/P/S/F转移继续运行，P/S条件收入与维护资源以该行低速增长，直至衰减。复算以2037—2096离散延伸近似其余现值，不能在2036把剩余机会概率恢复为100%。把延伸增加到2136年复算，十二个工作值的最大每股差约0.14，低于主要经济误差；这也是有限数值截断的实际精度边界。

与此相反的“缺乏跨代更新、2032起现金逐渐萎缩、2036后无剩余价值”见第六章。它是独立经济解释的压力试验，现有客户平台与产品迭代证据使其弱于持续更新解释，不是把两种方法简单平均。另一方面，持续更新也不足以证明2036高利润可无条件永久化，故远期权重和折现敏感性必须留在评级中。

### 4.3 投资标准与主估值方法

用户没有给定个人资金约束，本报告使用可复用研究参考：短期盈利修复**6个月累计10%**，邻近8%—15%；中期兑现**12个月15%**，邻近12%—20%；长期复利**年化15%**，三年累计52.1%，邻近年化12%—18%。三个月若单独投资，参考累计5%—8%，不把半年目标简单减半作为价格预测。均要求未杠杆持有、能承受正常价格波动；稳健理念另要求合理偏差不造成不可承受永久损失。高风险技术理念参考三年年化20%（邻近18%—25%），容许较多失败，但要求可信上行及概率足以补偿失败。参考标准不是投资者真实偏好，也不因某格结果更换门槛。

现金机会成本取约3.9%/年，参考截止前H.15披露的3个月国债收益率约3.9%、10年约4.8%。估值要求的9%—12%、工作10.5%则是美元长期经营现金的风险补偿区间，约由长期国债加股权周期/经营风险构成；它不是“15%持有要求”的另一种写法。已进入状态概率的商业失败不再额外乘失败折价。[美联储H.15，2026-09-08发布，最近可用交易日口径](https://www.federalreserve.gov/RELEASES/H15/default.htm)

主方法为**对目标日现有普通股的逐期稀释现金流折现**。这是直接每股权益法；为便于勾稽，把每股经营价值乘目标日股数列为稀释等效经营价值，再加归属该日股东的超额现金。它不把未扣股份薪酬的企业FCF全给今天固定股数。

`Vop_T = S_T × Σ[FCFF_u ÷ S_u ÷ (1+r)^(u−T)]，u>T`

`P_T = (Vop_T + C_T − 50 − D_T − L_T) ÷ S_T`

这里FCFF已加回SBC，但每期除以包含未来奖励的S_u；S_T只用在对应目标日资本桥。D为借款，L为未付诉讼/已除息应付股利，租金已作为经营费用；现金投资利息不在经营现金流重复折现。目标日前流量累计到现金，目标日后剩余流量才进入经营价值。可归属超额现金按可分配权益计值；若管理层长期低效囤积，另做10%超额现金价值损失敏感性，而非假设它永不稀释也永远免费创造超额收益。

持有期经济总回报=(目标日除息每股价值＋期间已收现金分红＋目标日应收股利−50.46)/50.46。主矩阵统一为**条件合理价值回报**，不是确定的成交价格预测。市场在目标日只采纳部分信息、要求更高回报或错误提前定价时，实际交易回报可不同；本次没有足够证据给其无条件概率分布。

### 4.4 反向检验与理念分歧

价格50.46对应基本市值约2.82B，净现金只覆盖约9.3%；扣经营缓冲和现有索取权后保护更小。本研究基准研究日后NTM收入约511、经营利润约60、经营FCFF约92（含SBC加回）。将未来股数固定、再给未扣SBC现金很高倍数，会误把员工报酬变成股东收益。

以12个月参考回报15%计，目标除息价格至少**57.17**，明显高于基准工作约36.6；以三年15%计，目标至少**74.16**，高于基准41.9，也略高于乐观中枢70.8。三年20%技术投资则要求至少**84.61**。这些是回报门槛，不是从现价倒推出的收入预测。

反求不是唯一解。更高的成熟核心利润、主功率更大规模、维持更久的竞争优势、更低的资本需要或更低投资者要求，都可能解释50.46。分别修改单个主要机制：基准核心长期增长从2.5%改4%仅使三年价值增加约2美元；不计50经营现金保留增加不足1美元；新增股数年增再多0.5个百分点则使基准三年价值减少约2.6美元。仅在小参数上取好端点，无法填平正常路径的价值差异。

同一理念跨期限：乐观经营可在一年内修复价格与盈利，累计回报中枢约21%；三年中枢累计约45%、年化约13.3%，却低于长期15%参考。这来自初始估值恢复集中在早期、以后成熟增长和稀释限制年化，不是更换估值方法制造矛盾。同一期限跨理念：如果投资者三年只要求12%，乐观中枢可谨慎参与；要求15%时经济优势未清晰，要求18%时不足。事实和经营现金不因偏好改变。

现金安全边际理念与技术期权理念亦未简单平均。前者由普通/受损现金和现价比较，当前拒绝；后者须完整评价单一机会成功后的集团价值与失败代价，见第六章，不能直接用突破上沿作为其当前买入理由。

## 六、当前选择、敏感性、独立成功与等待代价

### 6.1 当前最支持的解释与价格边界

证据更支持基准附近的工业/汽车恢复：渠道正常化和已有生产业务反对全面结构性衰退；主功率尚处产品定义和较晚商业化阶段，反对已经可以把大幅跃迁当作普通经营。基准不代表所有早期机会必然成功，它已经包含逐年加权贡献，也已给持续更新平台保留长久价值。

最强反方是高压系统供电正在从局部节能器件走向更大主功率BOM，POWI可能占据高价值的设计与工艺位置。该机制可信，不能以“未有订单”直接判零；但从系统需求到公司250—400规模销售、再到较久竞争优势，尚缺可复核商业条件。综合选择是不按现价参与，而不是要求读者自己填一个足够高的信心系数。

### 6.5 更新优先级与结论覆盖边界

真正可改变当前选择的最少证据，是下列之一形成相容经营路径：核心收入和GAAP利润升入乐观并可持续；P取得能支持更大净内容与合格数量的量产客户证据；或股价下降到更新后普通经营的风险补偿范围。单个技术电压纪录、未具名管线和较低账面PE都不是充分条件。

公开缺口包括新业务净BOM、客户分配、车用单车内容、高压节点良率/产能、未满足条件股份奖励的未来实现和产品利润分摊。针对性原始材料检索后仍缺，报告没有将其填成历史事实。未来需求、替代、定价与现场可靠性本身不可知，故保留完整状态与相反路径。模型精度不足以支持狭窄买点，但已足以辨别现价对正常兑现的要求偏高；这两种结论可以同时成立。

def core_inputs(si,ti):

def capital(model,date):
    si=model['si'];cash=CASH0;interest=0;divs=0;lit=0

        q=model['quarters'][qi]
        it=cash*.033/365.25;cash+=q['fcf']/q['n']+it;interest+=it
        if day.month in (3,6,9,12) and day.day==calendar.monthrange(day.year,day.month)[1]:
            dv=shares(si,day)*divrate(si,day.year);cash-=dv;divs+=dv
        if day==dt.date(2027,6,30):cash-=11.3;lit+=11.3
        day+=dt.timedelta(days=1)
    # Dividend already ex at the valuation date but payable at quarter end.
    pending=divrate(si,date.year)*shares(si,date) if date.month in (3,6,9,12) and date.day<calendar.monthrange(date.year,date.month)[1] else 0
    claims=(0 if date>=dt.date(2027,6,30) else 11.3)+pending
    return dict(cash=cash,interest=interest,paid_div=divs,lit_paid=lit,claims=claims,excess=cash-50-claims,shares=shares(si,date),debt=0)

def investor_div(si,date):
    paid=0;day=START+dt.timedelta(days=1)

def value(model,date,r=.105,g=None,roic=None,fade=False):
    si=model['si'];g=([.01,.025,.03,.03][si] if g is None else g);roic=([.12,.18,.22,.24][si] if roic is None else roic)
    cap=capital(model,date);pv=0;earlypv=0
    for q in model['quarters']:
        lo=max(q['start'],date+dt.timedelta(days=1));hi=q['end']
        if hi<lo:continue
        frac=(hi-lo).days+1;frac/=q['n'];mid=lo+(hi-lo)/2
        dilution=cap['shares']/shares(si,mid)
        t=(mid-date).days/365.25
        fcf=q['fcf']
        if fade and q['year']>2031:fcf*=max(.35,1-.13*(q['year']-2031))
        v=fcf*frac*dilution/(1+r)**t;pv+=v
        if q['year']>=2032:earlypv+=v
    last=model['annual'][-1];end=dt.date(2036,12,31);tt=(end-date).days/365.25
    # 2037 reinvestment equals NOPAT*g/ROIC; future SBC is represented by dilution.
    # Mature core renewal is a perpetual franchise, while each early programme
    # keeps its own absorbing failure path. A successful family may update, not
    # resurrect a failed programme. Continue that chain for 60 further years.
    _,lastgm=core_inputs(si,9)
    core_ebit=last['core_ebit']+.1*last['opps'][0]['rev']*lastgm[4]
    terminal_fcf=(core_ebit*.85*(1-g/roic)+last['sbc'])*(1+g)
    gps=(1+g)/(1+DIL[si])-1
    term=terminal_fcf/(1+DIL[si])/(r-gps)*cap['shares']/shares(si,end)/(1+r)**tt
    op_tail=0
    for oi in range(5):
        p=last['opps'][oi]['p'].copy()
        if model.get('experiment') and model['experiment'].get('success')==oi:p=[0,0,1,0]
        if model.get('experiment') and model['experiment'].get('no_opps'):p=[0,0,0,1]
        if model.get('experiment') and model['experiment'].get('fail_opportunity')==oi:p=[0,0,0,1]
        tr=TRANS[si][oi][-1]
        previous=[x['rev'] for x in last['opps'][oi]['states']]
        if model.get('experiment') and model['experiment'].get('success')==oi:
            previous=[x*model['experiment'].get('success_mult',1) for x in previous]
        for step in range(1,61):
            joint=[[p[j]*tr[j][k] for k in range(4)] for j in range(4)]
            pp=[sum(joint[j][k] for j in range(4)) for k in range(4)]
            rr=[v*(1+g) for v in previous]
            dev=DEV[oi]*[.7,1,1.3,1.6][si]*1.025**9*(1+g)**step
            cf=0
            for j in range(4):
                for k in range(4):
                    rv=rr[k]
                    gp=rv*(OGM[oi]-(.10 if k==1 else 0)) if k in (1,2) else 0
                    ex=dev*[1,1.3,1.5,0][k]+(.20 if k==1 else .16)*rv
                    if k==3 and j!=3:ex+=.5*dev
                    eb=gp-ex
                    # Net expansion investment at stated capital return; plus
                    # discrete state changes in inventory/receivables.
                    invest=max(eb*.85,0)*g/roic
                    wc_jump=.2*(rv/(1+g)-previous[j])
                    if k==3:wc_jump=-.1*previous[j]
                    c=eb*.85-invest-wc_jump
                    if oi==0:c-=.1*rv*lastgm[4]*.85
                    cf+=joint[j][k]*c
            future=dt.date(2036+step,12,31)
            op_tail+=cf*cap['shares']/shares(si,future)/(1+r)**((future-date).days/365.25)
            p=pp;previous=rr
    term+=op_tail
    if fade:term=0
    op=pv+term;equity=op+cap['excess'];price=equity/cap['shares']
    paid,rec=investor_div(si,date);total=(price+paid+rec)/P0-1
    ann=(1+total)**(365.25/(date-START).days)-1 if date>START else None
    return dict(price=price,equity=equity,op=op,total=total,annualized=ann,terminal=term,terminal_pct=term/op,far_pct=(term+earlypv)/op,paid=paid,receivable=rec,**cap)
