**当前判断：持有；新资金可用小仓分步配置，把320—340美元作为更合适的增配区间，363.95美元不适合作为依赖基准情景的重仓买点。** CB仍是有承保纪律、投资收益及多地区业务支撑的成熟保险平台。当前没有迫使普通股融资或大幅收缩的信用事实，但股票的下行保护远弱于“账面资产很多”给人的直觉：现价约为最新有形账面值的2.87倍，不能把全部投资资产视作股东净现金。

## 1. 业务经济本质、竞争位置与干净经营起点

### 1.1 保险的收入是风险承诺的价格，浮存金带有赔付义务

CB提供的核心价值是：让企业、家庭及保险公司把无法自行承担的损失转移给有牌照、有理赔组织、有长期支付能力的承保人。客户买的是合同约定的风险承担、抗辩与理赔服务；支付意愿受贷款及商业合同、风险承受能力、保障限额和免赔额约束，不是无限扩张的技术预算。

年度财险通常先签单、收款，再随保障期间赚取收入。**净签单保费NWP是当期新增/续签流量；净已赚保费NPE是当期确认收入；未赚保费是尚须履约的负债。**9月末28.608的未赚保费不能当作不可取消RPO，存量保额也不能当作新订单。寿险还要区分传统保费和投资合同存款：2026Q3国际寿险保费加存款2.441中，0.837为存款，不计当期收入。[S1，Balance Sheets、Life Insurance][S1]

### 1.2 客户预算、价值捕获与竞争壁垒

商业险的使用者、采购者和受偿者经常不同。经纪可以帮助客户拆分风险塔、换承保人、提高自留额；“客户仍投保”并不保证CB维持原份额和原净保费。客户衡量的是保费、自留损失、现金波动和理赔争议的总成本。大型项目价格降到缺乏回报时，拒保和多分保是理性的资本配置，不能自动认作失去竞争力；但如果只能通过不断减少自留维持报表利润，其投资浮存金增长也会随之变慢。

个人险的护城河来自复杂高价值资产的风险资料、服务和代理关系，而非客户永不比价。客户的房屋重建价值上涨可以推高保费，却不等于CB提价能力增强。农业险受政府方案影响较大，不能像普通消费品一样自由提高价格。海外消费者险和寿险的银行及平台伙伴拥有流量，CB掌握核保、理赔和资本；数字化节省可能被更高渠道佣金或客户降价吸收。

CB的优势是跨险种风险资料、当地牌照、长期理赔经验、经纪及代理关系和财务实力的组合。评级汇总截至9月24日列主要美国承保实体A++/AA/Aa2、展望稳定；这支持赢得要求长期支付能力的客户，不能证明所有风险都定价正确，更不能代替当前债券成交利差。[S10]

保险扩张的关键产能是**愿意在评级资本、单体偿付能力、限额、地域聚集和人才约束下承诺的风险额度**。没有工厂CapEx洪峰，不代表增长不占用资本。维持巨灾模型、核保、反欺诈、理赔人员和本地合规，以及软件资本化投入，都是持续交付成本。把费用率降到理想水平却不保留这些支出，会高估单位经济性。

### 1.4 对决定性分歧的裁决

**“行业降价”与“公司还在增长”相容。**Marsh三季度样本显示全球商业财产续保定价下降10%、美国责任险上涨6%；CB披露北美商业财产总定价下降4.2%，其中共享/重大账户财产约下降11%，中小商业财产略升。经纪大客户样本与CB的混合业务并非同一总体。本研究采用CB实际分部组合，把大型财产缩量、中小商业及个人/海外增长分开，不把行业−10%套到全部保费。[S3，第4—5页][S3] [S7]

**“组合变差”不能单独解释所有未来成本率。**北美商业基础成本率上升，公司归因于减少低损失率财产险后的组合变化，有商业道理；同时管理层指出竞争正扩散至责任险、部分价格追不上损失成本。基准因此保留缓冲逐步消耗，而不是假设公司突然丧失全部核保能力。乐观路径则要求同险种、同风险的价格充足度和事故年发展证明组合解释占主导。[S2] [S3]

**亚洲“收款快增”不等于全部收入和利润同速增长。**国际寿险Q3保费加存款增长15.7%，剔除上年新西兰一次性闭锁保单交易后，保费增长7.9%、固定汇率10.8%；存款、当期保费、新业务价值和可上划现金分别处理。华泰及其他存在少数权益的业务虽并表，普通股只能获得归母部分；模型不把所有寿险统一按集团某一持股比例折算，也不把第三方资管AUM加到自有投资资产。[S1，Life表脚注][S1] [S4，业务及合并附注][S4]

**高利润不是CB独有的供给稀缺证据。**Travelers Q3综合成本率86.8%、基础84.1%，前者同比改善0.5点、后者恶化0.2点，且获益于准备金及投资收入。这是竞争者实际经营数据，支持“成熟保险利润仍好、边际缓冲却未继续扩大”，不采用其评级或目标价。[S8]

### 2.2 先从风险暴露与净单位保费约束收入

公开资料不足以拆出全集团客户数、每份保单净价格和续保队列。本研究不用倒凑的“保单当量”冒充已知订单，而以**有效风险暴露指数×每单位净保费**约束分部增长，再考虑保障限额、自留/分保、渠道及汇率。暴露包括受保资产、工资、营业额和实际保障范围，并非单纯物理客户数。

| 业务 | 基准2027/2028/2029 NPE增速 | 使增长成立的业务路径及边界 |
|---|---|---|
| 北美商业 | 1% / 3% / 4% | 2027暴露及中小客户约3%—5%的名义增长，被大型财产降价和自留减少部分抵销；之后退出影响减弱。依赖盈利保费重新增长，不依赖承保全部低价项目 |
| 北美个人 | 7% / 7% / 6% | 重建价值、净提价和新增高净值保障合计中高个位数；灾区聚集和州审批限制放量，不能无限提高价格 |
| 农业 | 4% / 3% / 3% | 种植面积、价格基数、保障参与和联邦安排共同约束；不把政府付款当无风险永久利润 |
| 海外一般 | 7% / 7% / 7% | 暴露/客户扩展约3%—5%，净价格与渠道组合约1%—3%；基准不预测额外外汇红利，大型财产竞争仍存在 |

| 寿险 | 9% / 9% / 8% | 亚洲保障及续期、美国工作场所福利增长；新增渠道佣金、准备金和产品组合使利润不必同比例变化，存款不计NPE |

以上分解为研究区间及合成增速假设，不是公司披露的物理量价数据。分部年度数列在附录A。基准不是简单延续2026盈利增速，而是**更多已赚保费、较薄单位承保利润、更多投资与寿险利润**的组合。

### 2.3 为什么利润率会这样演化

短尾财产降价通常先影响新签单，再逐季赚取；责任险损失成本则可能在数年后完成。基准北美商业CY由2027年的88.0%至2029年的89.5%，不假定公司失去核保能力，只反映减少高利润财产、持续赔款成本及新增保单费率缓冲减少。个人险由2026异常有利基数回到78.5%—80.0%的正常灾损及较少准备金释放状态，仍保持非常可观的承保利润。

集团合成成本率的基准核验为：2027约**83.73% CAY＋4.8%巨灾－1.2%净有利发展＝87.33% CY**；2028约84.10%＋4.9%－0.9%＝88.10%；2029约84.55%＋4.8%－0.8%＝88.55%。这些是与分部结果相容的预算分解，均为预测；未把准备金释放归零，也未永久维持Q3较大的释放。

乐观情景允许较好的风险选择和数字化把2029集团CAY保持在约82.55%，在4.7点正常巨灾和1.5点释放后得到约85.75% CY。突破情景进一步约80.69%＋4.5%－1.4%＝83.79%；**其收益不是靠假设没有巨灾取得的**。较乐观路径额外约2点的基础成本率改善，要由获取、行政、理赔处理及风险选择共同贡献；保险竞争可能将节省返还客户，这是突破情景证据仍弱的原因。

### 2.4 第二曲线：允许非线性，但逐项计入获取成本与资本

**亚洲与嵌入式保险已经有商业闭环，不是零收入期权。**Nubank在2024年6月确认合作有效保单200万、其中寿险超过100万，这是来自渠道端的付费存量证据；没有取得2026同口径更新，不将它当当前保单数或集团新增利润。[S11] 要把渠道能力变成集团级利润，必须跨平台复制、提高续保与客均净保费，同时管理赔付、佣金及当地偿付资本。

突破2029年相对乐观路径增加经常性收入约**5.43**、财险承保利润约**1.69**、财险投资收入**0.40**、寿险分部利润**0.60**，扣税及其他差异后增加归母正常化利润约**2.10**。其中海外/个人及亚洲寿险量价与渠道改善是主体；不把一项未披露规模的AI保单硬写成数十亿美元收入。

用容量边界校验：若多渠道最终要贡献额外3—4十亿美元年净保费，以每份持续付费净保费50—100美元计算，相当于新增约3,000万—8,000万份有效保单，或更少但保费更高的保障组合。**这是条件规模门槛，绝不是已披露保单或订单**；分批获客只按实际保障期间赚取，不以期末年化规模充当全年收入。全球牌照与伙伴基础使它有商业可能，当前证据还不足以锁定这个量级。

**数据中心与AI责任险是增量任务，也是新风险。**数据中心需要工程、设备运输、保证及运营保障，但管理层明确部分项目尚未动工，电力、许可和劳动力会延迟bind。已宣布CapEx不能乘一个统一费率当CB收入。AI责任险可能先暴露于旧合同的静默责任，再形成独立收费。HSB已在3月推出小企业AI责任保障，证明需求与竞争同时存在，CB没有独占产品窗口。[S3，第8及11页][S3] [S12]

基准没有单列AI保险巨额利润；少量工程/保证险增长已在分部中。乐观、突破通过更高有效保费和净费用效率体现，不能再额外叠加同一笔“AI利润”。以2029基准财险NPE约57.4衡量，每改善0.5点且未被竞争返还的成本率，税前利润约增加0.29，这是比任意AI TAM更能约束股东收益的数量级。

突破的最少成功条件是：两个以上主要地区出现可重复的新增付费渠道；新队列续期及赔付在跨年后仍好；渠道分成后基础费用率实降；新增偿付资本能由内部利润覆盖。若其中一项延期，管理层应减少获客补贴、限制低回报新单和软件项目，保留已有亏损及退出代价。本模型不会假设公司为了维持远期规模持续毁灭现金。

## 3. 公司经营情景、现金、资本与每股基本面

### 3.1 四条经营路径与整体递进

**悲观/受损**：商业财产价格压力扩散，长尾事故年补提和费用刚性使2029集团CY升至95.68%；减少新风险、加分保、基本停止回购，保留成熟投资及寿险盈利。它是承保利润受损而非默认破产，已经计入管理层止损；现有降价和损失成本给压力机制提供直接依据，完整幅度及额外OCI冲击尚未发生，因此证据为中，不能标成已锁定危机。

**基准/正常兑现**：既有商业模式继续运行，保险规模按前述约束扩展，承保缓冲逐步消耗，投资与寿险补位。关键前提无需未商业化新品或大额并购成功，故证据为强。强指向机制及主要利润池可见度，不代表2029每一项成本率都已写进合同，也不等于其高股价回报概率很高。

**乐观/超预期**：主动缩量主要是优化组合，同风险责任险费率充足；数字化节省未全被渠道和客户拿走，亚洲利润快于保费增长。2029 CY约85.75%、寿险利润2.20；这些跨期增量尚待实证，证据为中。

**突破/非线性**：在乐观核心底盘上，亚洲与消费者渠道跨市场复制，数据、理赔和销售平台改善风险选择及净费用。2029 CY约83.79%、寿险利润2.80；增加软件、获客及评级资本预算，回购低于乐观。利润、每股收益及价值均递进，现金FCFE略低于乐观，差额来自更高当期再投资，不是价值倒挂。证据为弱，但商业机制可以成立。

### 3.2 保险股适用的利润与现金桥接

公司正常化利润采用：

`归母正常化利润 =（各财险承保利润－Corporate承保消耗＋财险调整投资收入＋寿险分部利润＋财险其他经营收入－分销等保留摊销－调整利息）×（1－税率）－核心少数权益。`

寿险分部利润含寿险投资，集团模型只另加财险投资，避免双计。正常化税率基准/乐观/突破20%，悲观21%；不把2026百慕大递延税资产收益或巨大历史NOL假定为永久免税。未来其他经营费用、常态退出业务、SBC均在承保及集团成本内。[S1] [S3]

2025年GAAP经营现金流12.816，剔除并表投资产品影响后的保险业务调整值13.906；2026年前九个月调整值12.829。它们包括保费与赔款时差，**不能直接作归母可分配FCFE**。最近完整披露2025 SBC约0.399、2026H1约0.197。现金CapEx与融资租赁本金没有取得足以还原2026Q3全套精确数的披露，不补造历史零值或精确Owner FCF。[S4，现金流及SBC附注][S4] [S5，现金流及权益表][S5] [S1]

预测现金FCFE按以下方式闭合：

`FCFE = 已扣SBC的归母正常化利润＋SBC现金加回＋行权现金＋D&A－现金CapEx－融资租赁本金－支持增长及风险的新增权益资本留存。`

2027—29年显式模拟每年净新增发行1.7百万股及3.8百万股未发行/其他稀释池，SBC因此只加回一次，不再从现金中扣同一笔SBC。会计利润保留SBC费用，股数反映实际所有权变化，二者承担不同核算功能。模型不是在已含SBC的利润后再次扣完整SBC。未来2030年以后的DCF切换为费用法，届时不再加回SBC，也不重复增加同一笔稀释。

CapEx预算按情景约0.95—1.45起步并增长，普通路径净CapEx高于D&A约0.20、突破约0.35；融资租赁本金每年暂设0.02、突破0.03。它们是现金预算参数，不是公司披露值；租赁利息和经营租赁租金已在利润/费用中，不另扣一次。若未披露融资租赁本金实际更大，现金FCFE应等额下修。

资本留存公式为：**0.45×正的财险NPE增量＋0.65×正的寿险NPE增量＋风险缓冲补充**。系数是研究采用的边际权益资本强度，不是法定RBC计算式；缓冲年度约0.3—1.0，悲观初期2.5。收缩时不自动释放全部存量资本，因为旧赔款尾部仍在。突破由2027到2029累计留存更多资本，保持共用资金池守恒。

模型可分配现金仍须受单体偿付、评级和上划权限约束。年报列2026年子公司无需事前监管批准可上划股息合计9.6，是法律容量参考，不能假定此额度等于每年必须派给普通股的现金。预测普通股现金分红与回购合计均低于模型FCFE，其余留在投资组合及资本缓冲中；未将新增浮存金再派给股东。[S4，Note 22][S4]

相同极端事件下，扣掉正常悲观已经预算的约3巨灾负荷，新增经营损失仍足以把单年利息覆盖压至1.5倍以下，甚至令当期经营亏损。因此“净值契约尚有余量”不等于没有信用事件风险。管理层应停止回购，必要时暂停增息/分红、减小自留和新增承保、出售高流动性资产并寻求有条件流动性；若评级下调与再保违约同时持续，债权、混合债和保户权利优先，普通股可能进一步受损。没有证据支持目前已需要困境重组，也不把强制清算当中心路径。

## 4. 估值转化、倍数解构与目标日市场定价

至此先锁定经营、资本和每股结果，以下才加入折现率与市场倍数。保险资金本身是经营要素，选择**归母股权现金流DCF**，不套用工业企业EV/EBITDA减净债方法。

### 4.1 2029年末剩余DCF，及其终值约束

`DCF₍2029₎ = Σ2030—2034 FCFEₜ/(1+kₑ)^(t−2029) ＋ TV₍2034₎/(1+kₑ)^5`。

四情景共同使用**kₑ=10.5%**，是跨周期名义美元股权要求回报率的研究输入，不是声称已观察到某一瞬间的WACC。可理解为约5%的长期美元利率工作锚加约5.5%的股权风险补偿；不把该5%写成已核验的当日国债收盘。悲观现金流已经包含受损，不再额外加任意危机折现率重复惩罚。

显式期利润增速：悲观每年3%；基准5%/5%/4.5%/4%/3.5%；乐观7%/6.5%/6%/5%/4%；突破10%/9%/8%/6.5%/5%。显式期新增权益留存按上一年经营账面权益×增长率，另留0.20净软件/租赁等现金再投资预算。未来SBC保留为利润费用、不加回，冻结目标日完全稀释股数；没有一边把回购当FCFE分给股东、一边再缩分母的双重计价。

### 4.2 固定当前倍数，只看业务与股本贡献

## 5. 当前投资选择、仓位属性与动态验证

### 5.1 现价已经要求什么

363.95对应可比核心TTM约12.31倍、最新BV约1.90倍、TBV约2.87倍，估值分母没有亏损失真，但承保利润处于较好区间。若只要求未来保持类似倍数、接受基准约3%—7%的含息年化，现价与基准可以相容；如果要求**10.5%**年化，简化终点回推需要2029交易价约**487.1美元**，在M₀不变时需要运行EPS约**39.58美元**，已接近乐观而非基准。回推把现金股息不再投资，因此只是透明的终点要求，不是隐含概率估计。

因此市场状态判断是：**当前已充分反映成熟高质量利润池，并要求相当程度的经营韧性；按本研究股权回报门槛看，介于基准与乐观之间，尚未按完整突破定价。**不能因为12倍看起来不高就自动判断便宜，也不能把它与只靠远期融资的叙事股等同。

### 5.2 执行动作与机会成本

1. **已有底仓：持有。**只因商业财产降价就退出全部仓位，会失去投资收益、亚洲及后续风险选择改善的参与权。持有前提是正常化承保仍盈利、资本充足、增长不靠持续放宽条款。经营防御性不等于股价没有40%以上压力跌幅。
2. **新资金：可先用约0.5%—1%的组合观察/防御配置，主要增配放在320—340美元。**这个仓位是研究组合示例，并非假定用户的实际资金约束。在该区间且经营证据未坏，基准终点及约13.5美元股息对应的总回报明显改善，按统一3.19年口径年化约5%—11%。希望以10%以上回报作为硬门槛的资金，当前应更耐心；不需把所有成熟保险资产一律归为回避。
3. **不能把下跌自动当买点。**若价格低于300却伴随长尾大额补提、费用节省失效或评级资本恶化，先重估准备金和每股资本，不能沿用旧TBV加仓。无事实变化、纯市场波动造成的折价，才改善赔率。
4. **基本面确认可以替代低价等待。**若未来两季显示商业险恢复盈利增长、CAY稳定且寿险利润加速，乐观EPS路径的证据会增强。即使届时价格400—420，仍可能有参与价值，但更高买价会降低赔率：用乐观目标及约14美元股息估算，统一3.19年口径含息年化约7%—12%，低于当前对应的约12%—16%。实际晚买持有时间更短，应重算剩余年化，不能照搬这组比较。

等待的代价是真实的：若公司连续证明风险选择和亚洲平台有效，股价可能越过400而不回到320—340，且会损失期间约1%左右年现金股息。小仓参与保留跟踪和增配权；大仓仍需价格折让或更强利润证据。若价格在430以上而经营仍只支持基准，新增资金的回报要求更难满足，宜停止追价，而非上调收入或倍数迎合行情。
