## 一、三个期限的当前判断与研究口径

**当前选择：短期3个月与6个月均不建议以参考价新买入；一年不建议投资；三年在稳健复利标准下不建议投资，在高风险技术突破标准下也尚不足以支持当前参与。** 这不是判断公司没有增长：数据中心和LoRa增长已有实际收入支持。分歧在于当前买价需要多大、多久的股东现金，以及是否值得为尚未证明的跨代捕获能力提前付费。

本研究最支持“正常兑现，伴随部分更强交付”的经营解释。乐观路径是真正有依据的替代解释；不能从高增长季度直接跳到突破路径。当前路径没有把四行情景平均，也没有根据现价反向抬高经营预测。未来实际交易价可能长期高于现金价值；对这种定价延续，现有公开信息不能建立足够可靠的正向预期差。

财务质量检查有四个结论。

1. **税与现金。** 112.4税收益是递延税资产估值备抵转回，不是现金流入。未来税盾有价值，但时间、辖区和可用所得决定变现；模型用前两年核心现金税率18%、此后22%，机会分支20%/23%，不把139.6递延税资产账面值再加成现金。
2. **存货与应收。** 7月表内存货170.8还原待售32.7后约203.5，比年初195.7增长；应收169.9加待售25.9后195.8，比年初160.6增加。上半年现金表的应收占用35.0、库存占用6.0支持“增长需要周转资金”，并不支持无成本扩张。没有发现足以指认虚构收入的原始证据；渠道库存与客户取消率未知，不能据此认定收入质量已经无风险。[10-Q附注2、现金表][S2]
3. **报表FCF到股东现金。** 上半年CFO105.071，净固定资产支出15.617，标准FCF89.454；另有无形购买5.986、收购36.306、员工报酬税款结算37.213、期权收入1.133和融资费用2.287。可见“FCF89.5”不等于现金余额增长89.5，实际现金仅增加8.872。股权结算支出必须进入资本桥。
4. **处置。** 卖价62为有调整的合同对价；董事会批准和签约是事实，监管条件满足和收款仍未发生。待售净账面资产约61.5既非清算价值，也不证明处置损益为零。按模组毛利率10%—25%的假设反解，Q2模组收入约36—51；工作值约45而非官方拆分。主模型移走对应成本，不另给“毛利率升5个百分点”的额外利润。[出售协议公告][S4]

### 2.5 管理、供应、治理与失败风险

现有外包晶圆/封测加HieFo自有InP制造，带来不同资本结构：前者需预订、备货与资格支持，后者还需外延良率、设备、洁净室和可靠性。公司设备交付与新增洁净空间说明投资正在进行，未披露绝对合格产能；本研究拒绝将名义扩产倍数当成可交付倍数。扩产同时增加竞争供给与客户第二来源，正常化利润率来自这一机制，非任意均值回归。

Sierra大型收购后仍出现减值与模组出售，说明资本配置并非一直成功；较小HieFo交易和聚焦高毛利业务支持现任团队正在修复，但无法抹去CopperEdge预期下修记录。研发人才、客户联调和跨代资格是更重要的资产；高利润会引发竞争，必须每年继续支付研发与应用工程成本。

公司FY26约74%销售经授权分销、中国含香港约47%为客户/交付相关地区口径，并非47%最终中国需求；它同时意味着真实出口、结算与客户集中风险。标准订单可以调整/取消的范围、backlog与净取消率无充分量化，不能把记录订单写成take-or-pay承诺。最新10-Q中的CopperEdge诉讼仍在进行，集体诉讼认证不是责任判决；Harman约16的主张不是已确定赔款。正常现金调整每年10，严重判赔另作资本冲击；未知诉讼不能用一个虚构点概率冒称解决。[L1][S2]

### 3.3 集中年度底稿

以下所有表来自同一个程序。核心费用取显式年度预算与收入比例要求的较大者，防止增长只加收入不加工程支出：悲观33%、其他三行30%；另加早期机会状态内研发。核心费用中研发及工程工作分配60%、销售/管理40%，这一分配仅供投入检查，不是公司未来披露。业务毛利率见附件；机会毛利、费用与现金先状态内计算后加权。

持续新报酬成本B=48+2.4%核心收入，35%现金支付、65%为新股权授予对应的经济补偿。本模型采用**等额发行并以现金抵消新授予稀释**的资本工作路径：报表FCF之后支付65%B的反稀释预算，因此未来新增授予不再重复扩大分母。它是可比较的资本假设，不是公司已宣布的回购计划；若管理层保留现金并发股，应同时提高现金与股数，不能只改变其中一项。现存奖励的2.714百万经济稀释已计股数，不再以其未来会计摊销扣一次；前两年另留15/年的历史结算现金。报酬成本总量接近当前年度量级，未来新授予与历史奖励的区分未有完整公开明细，±30/年敏感性保留。

### 3.5 生命周期、投入回报与资本应对

Y1—Y5核心业务由量价和产品组合决定；Y6—Y10基准总核心增速降为4.5%、3.5%、3%、2.5%、2.5%，乐观8%、6.5%、5%、4%、3%，突破10%、8%、6%、4.5%、3.5%，悲观0%。同代降价、第二来源与400G/lane更新使第六年起核心毛利每年下行0.3个百分点（悲观0.1），工程费用增长并保留收入比例底线。平台价值需反复更新，不能以某一颗TIA永续销售解释终值。

早期三条机会延伸至十年，规模上限和当年存续概率仍各自演进。终值不是将第十年最高利润永久延长：用该年已经计入状态失败、维持研发和报酬的经济利润减现金税，按长期增长g和再投资回报率ROIC配对，追加再投资比例g/ROIC。终局ROIC分别10%、18%、22%、25%，对应受损组合、可更新平台、较强IP和突破后仍受竞争的资本回报；不是公司的历史ROIC事实。主区间g=2%—3%，不能与不再投入的新平台同时成立。

核心研发60%的费用分配中，工作上约70%用于维持/跨代更新、30%用于扩量及可选新设计；这是经济分类，已经在费用中。H新增设备和客户验证占其投入主要部分；N以工程研发为主，资本开支较轻；L主要为SDK、协议和认证支持。不存在公司必须每年花同一资本额的合同证据，“成长预算”不能冒称已承诺采购。

H基准全成功参照Y3收入160、毛利96，扣可变研发/支持费用24（S状态实际15%收入），再扣固定约18.9，营业贡献约53.1；20%税后约42.5。Y3 CapEx约24.4，较前一年营运资金增加16.2，D&A4，现金约5.9。研发/设备/周转先于成熟收益，不能用42.5利润直接当可分配现金。Y5收入400时固定约19.9、变量60、毛利240，税前160.1，现金转换改善。用累计新增现金投入及回收累计现金判断回收，不能把简单利润/当期CapEx叫IRR。

### 4.2 三个期限为何可以不同

**短期。** 10月会和11月财报可能改变认知，收入不必在当季全部发生才重估。但市场已知道Q3收入/利润跃升，普通达标并无明显新增优势。三个月技术说明可能导致先涨后回落；六个月可能开始看到处置后的收入基数和FY28交付，但截至3月9日不能假设全年业绩会已经举行。本研究未找到与具体事件相匹配、可稳定估计交易倍数更新的公开样本，因此不把DCF日历增值当股价必然走势。

**一年。** 一年可验证多个季度的光铜产品结构、LoRa终端回款、模组退出费用和转债资金准备，现价需要的不是一次季度beat。集团基准收入约1,565、经济营业利润364、FCFF218，下一NTM收入1,745、经济营业利润468；股东现金比调整EPS小，现金桥则可能由净负债转到接近平衡。中期回报来自经营与现金，而非短长目标价平均。

**三年。** 核心平台必须跨过至少一次重大代际/拓扑更换，同时形成更多设计位置和可重复收费；H/N/L到时的剩余机会比当年收入更大，因而Y4—Y10现金可以进入2029年价值。概率不因过了三年自动成为100%。如果三年只证明1.6T一代领先，生命周期替代估值明显降低；如果证明跨代资格与高资本回报，才有理由采用更新平台的余值。

### 4.3 主方法、理念分歧与现价要求

主方法为**扣全部研发、维持/成长投入和经济报酬的剩余FCFF DCF**。短期主要理念是经营证据触发的重估，中期是兑现和现金转换，长期是技术平台复利；同一现金权益使用同一方法，仅改变目标日已过/剩余现金。短期合理价值与可能交易价严格区分。

工作折现率10.5%、g=2.5%；主区间低端12%/2%，高端9.5%/3%。三行较好经营的长期ROIC由平台复用/认证能力支撑，较高风险容忍者可以要求20%持有回报，但**不能因此把经营折现率机械改成20%**。条件已限定的产品失败由状态现金体现，折现率用于剩余系统风险及资本成本。

相同现金和生命周期下，盈利倍数只是DCF的另一表达。本研究不将一个40倍PE与较短现金生命周期平均：高倍数实际要求更长增长、少投入或更低风险。基准从Y1经济利润扣实际现金税所得约284、Y2约370的经营收益，不能与未核验的5.84 EPS混用。若报价隐含更高盈利，须在收入/利润表明确实现，不得把倍数当经营证据。

反向边界不唯一。下面只改变基准Y2起光电子核心和CopperEdge数量×净价规模、保留同一GM、机会与其他业务，并将核心费用至少保持收入30%，同时重算周转/CapEx/报酬。第一年保持不变；反算是需求门槛，不是本研究预测。

生命周期的最强分歧保留两个解释：A，持续更新平台（主表）——已有多代TIA及客户关系支持，但新架构IP可捕获尚未知；B，产品系列在第十年后被集成和竞争逐步侵蚀——其后五年现金每年下降15%，不设永续。B并非零残值。基准三年价值约44，主路径约80；当前证据支持可继续更新多于彻底消失，但不足以把所有NPO/CPO成功与无限高净价同时兑现。无论A/B，基准现价选择均不翻转；长期分歧没有被假装消除。

### 4.4 目标日价值参数与回报标准

以下为研究参考标准，不冒充投资者实际偏好：半年主要要求累计10%（邻近8%—15%），一年15%（12%—20%），三年12%年化（10%—15%，对应累计40.49%，邻近33.1%—52.1%）。稳健投资还要求合理不利敏感性有余量；高风险技术期权另检验20%年化（15%—25%）及能否承受50%以上永久损失。三个月事件交易参考累计5%—8%，需要有新增信息的辨别力，不能把6个月要求简单除二。

主矩阵四行在同一期限使用同一主要理念、同一要求，不因某个格子数值漂亮切换到“只要不亏就买”。主标签评价**给定经营路径的合理价值**：未发生该行的可能性不压入主格；目标日前市场不采纳是当前交易选择的问题。主格早期机会已使用H/N/L当年概率贡献，不用完整成功参照替代。

估值置信度：悲观中（受损机制固定后价值数量级低，实际严重程度仍有误差）；基准中；乐观与突破低（尚未由情景本身固定的净价、长期资本回报、对冲和余值误差较大）。这与前述“情景证据强度”不同，均不代表发生概率。

### 6.3 当前权衡与局部概率的意义

基准到第五年H/N/L仍处规模成功状态的概率约42.5%/26.5%/43.9%，对应当年加权收入186.1/140.6/58.9；第十年也不是100%。这些局部概率不能套成“整家公司突破概率”。主矩阵的四个名称也不是互斥全集，不能数三个正面格说25%胜率。

对当前整股高风险选择，先看有利到不需要伪精确概率的边界：若三年普通结果约80、非常有利突破约240，参考12%年化要求228.47，二点检验的成功权重门槛约92.8%；即便把成功值取283，门槛也约73.1%。只求三年保本的门槛分别约51.6%和40.7%。这些是**收益门槛算例**，不是给完整世界赋权；普通结果并未覆盖极坏结果，遗漏严重损伤会提高所需成功率，遗漏远超283的成果会降低所需成功率。

当前证据支持“需求与技术路径存在”，并支持提高近期收入估计；它尚不支持把集团跨代份额、约1亿只1.6T行业端点、30%以上长期经济利润和多客户资格共同视为70%—90%以上的确定结果。即使投资者允许大幅失败，成功上限与买价之间的距离也不大。**因此在20%年化的高风险标准下拒绝当前买入更有依据；在12%标准下亦缺乏可辩护的优势。** 对不要求这些回报、以事件价格跳升为目标的交易者，定价过程尚不可判定，不能据此替他们断言等待或买入一定更优。

反过来，在相同普通经营下约50—60美元买价，会把核心价值与部分成功选项的损益关系明显改善，但必须同步复核是否因真实订单损伤而下跌。价格本身不决定经营基准，当前低DCF也不说明股价应立即回归。

### 7.4 核心公式与可复算程序

`E(R_i,t)=Σ p_k R_k`；`E(税)=Σ p_k max(营业贡献_k,0)×税率`；`ΔWC=E(WC_t)−E(WC_t−1)`；成本、税、投入均先状态内计算。

`报告FCF=CFO−全部固定CapEx`；`估值FCFF=报告FCF+净利息4−无形购买−新奖励反稀释预算`；`资本留存=报告FCF−无形购买−新奖励反稀释预算−前两年历史结算15`。

`目标EV=Σ目标日后FCFF/(1+r)^(流量日−目标日)+终值/(1+r)^(10−目标日)`；`终值=(Y10经济营业利润−Y10现金税)×(1+g)×(1−g/ROIC)/(r−g)`。年度流量按年末折现，第一年目标前现金按明确季度权重剔除，不把半年现金重复折现/加回。终值税口径未预支未来股权报酬的全部抵税好处，属于偏谨慎现金税处理。

`现金=234.051+目标前资本留存+已假定完成处置净款55−已到期本金+新融资`；目标前不分红。最低现金150仅触发融资，不成为额外可加价值。

  if mid*fd(mid,uncapped,wfixed)>eq:hi=mid
  else:lo=mid
 return (lo+hi)/2

def valuation(m,h,r=.105,g=.025,lifetime=False,bridge=0,uncapped=False):
 rows=m['rows']; ev=0.; tail=0.
 for y,row in enumerate(rows,1):
  if y<=h:continue
  frac=min(1,y-h)
  flow=row['fcff']*frac
  # Year 1 uses exact quarterly weights, cash credited to balance once.
  if y==1:flow=row['fcff']-cumulative(m,'fcff',h)
  ev+=flow/(1+r)**(y-h)
 # Mature reinvestment consistent: explicit growth is capped at g/ROIC from operating NOPAT.
 roic=[.10,.18,.22,.25][m['s']]
 finalnop=rows[-1]['economicop']-rows[-1]['tax']
 reinvest=g/roic
 terminal=max(0,finalnop)*(1+g)*(1-reinvest)/(r-g)
 if lifetime:
  # Product-franchise attrition alternative: 5 years of declining cash, no perpetual terminal.
  terminal=sum(max(0,rows[-1]['fcff'])*(.85**k)/(1+r)**k for k in range(1,6))
 tail=terminal/(1+r)**(10-h);ev+=tail
 c,d,net=balance(m,h,bridge)
 # Unsettled legacy cash awards: 15m rounded mark at reference quote, not cash freely distributable.
 eq=ev+net-15
 wfixed=None
 if h>=1.5:
  settlement=valuation(m,1.49,r,g,lifetime,bridge,uncapped)['p']
  wfixed=N27*max(0,1-51.15/settlement)
 p=solve(eq,uncapped,wfixed)
 return dict(ev=ev,tail=tail,eq=eq,p=p,ret=p/P0-1,ann=((p/P0)**(1/h)-1 if h>0 else None),cash=c,debt=d,fd=fd(p,uncapped,wfixed))
