以40年资本回收、90%容量因子计算，$10,000/kW、8%融资成本仅资本回收约$106/MWh，再加假设$25—40/MWh运维燃料为$131—146/MWh，尚缺建设期利息等；$6,000/kW、5%约$69—84/MWh。全包电价必须得到有信用客户接受。税惠或国家融资首先降低项目负担，不能整笔成为设备毛利。关税、韩国制造／欧洲出口、利率、气价和政策经造价、采购与付款条件进入模型，不另叠加一次统一风险折扣。

### 2.5 工业热和更远机会

NuScale／Ebara计划2027年完成蒸汽压缩机，现场测试候选仍待寻找。ORNL/TM-2025/3938使用化工厂负荷和模拟配置，约$5,500/kWe、每台$423M的研究造价不是NuScale已签售价；其正文第29—33页、Figures 16—19与讨论表明：余电外售限100MWe且气电价为基准时，核能组合不及锅炉参照。若气价高、可售余电多或低碳价值得到长约补偿，较小匹配规模可以胜出。**升温技术可行、园区采用、成套融资和NuScale盈利是四个不同问题。**[ORNL全文][ORNL]、[Ebara 2026-03-19公告][HEAT]

因此工业热单列最早4台商业项目与其后2—12台年采购上限；并没有因当前收入小而删掉机会。它可能部分替代电站项目的制造槽位，模型按共享年度容量顺序安排、将超额推迟；不能把不同用途的热、电、氢按各自极限产量叠加。

氢／氨与淡化保持五至十年以上的进入路径：需要具体客户、工艺包、核热／电力配比、长期承购和项目出资；NuScale通常获得模块或集成费，不能先计氢或水的终端销售。假设电解耗电50kWh/kg，电力机会成本$60—140/MWh，仅电费已$3—7/kg。当前没有足以建立独立售氢／售水收费权的证据；未来若用相同NPM，将进入r/u/h之一并替换或增加有容量支持的订单，不再额外叠加行业TAM。对于额外专利授权或项目股权，经济边界尚无法可靠估计，报告不宣称已否定其全部可能性。

AI工程工具为NuScale自身效率投入，不是已建立的外售AI软件业务。管理层监管执行能力有记录，商业交付缺少记录；2025奖金表“12台新采购承诺”的实际为0，现金收入内部目标247.5M、实际51M，与GAAP口径不同；总体奖金80.5%不能替代商业兑现。[2026 Proxy绩效表][PROXY]。证券／衍生诉讼截至Q2属指控和程序状态，损失无法估计，未当作已判欺诈；费用进入固定开支，重大判赔在单独下行边界处理。[Q2 Note16][Q2]

## 3. 四条连续经营路径、局部概率与资本底稿

### 3.1 四行的定义与证据强度

资本回报不是由低CapEx自动推出。一个12台、基准价250／成本170的批次，2026币值收入3,000M，完整PMA577.5M，制造2,040M，质保版税67.5M，工装36M，剩余约279M，需历经约4年且尚未负担固定组织。它可能连两年的新增固定支出都覆盖不了。突破同批剩余约775M，规模复制才可能回收研发；这只是生命周期贡献／简单回收逻辑，未冒称项目IRR。新增能力投资与未来收益在同一条现金流里逐项计入。

### 3.3 三个早期机会：年度状态、概率及依赖

定义三条**终身路径**：F=开发失败／退出，不恢复；L=有限成功，仅一个首批项目；S=达到所定义规模的重复采购路径。它们不是“当年状态”。每年另映射为U未商业化、P部分商业成功、S规模商业成功、X失败退出：尚未首个OEM为U，已有首批但未出现第二批为P，已有第二批为S；F路径到预定项目裁决年度转X。成功状态指商业合同与履约，**不冒充已经投运**。因此同一L路径交付完成后某年设备收入可以为零，同时仍处于部分成功并有集团服务收入。

这些是**证据约束的主观工作分布**，不伪称核电项目统计基础率。UAMPS取消提供失败机制，SNN开发投入支持罗马尼亚有有限成功机会；美国需要更多相互依赖的商业门槛，工业热还增加工艺验证与客户经济性。相较把首站或工业热规模成功都设为70%以上，当前缺少必要合同证据；相较全部设为零，设计批准、真实业主投入及供应准备又支持保留非零路径。基准可辩护范围：r规模约5—25%，u规模约5—30%，h规模约0—10%；移动S时由F补足，L固定，不把单项区间端点任意拼接为不合计100%的分布。概率不是由目标价或现价反推。

联合权重一半使用上述边际分布独立组合，一半使用共同均匀因子的同向状态组合；总和为1，每个机会边际保持不变，用来表达共享监管、融资和供应商依赖。共享年度签约／启动槽位由18台起爬升，四行最终上限12／24／42／66；优先已有公用事业路径，再安排工业热，超额推迟一年。该排序假设可检验，不能当成客户优先权已获保障。**先在每个联合分支算税、融资与股数、分配现金，再加权每股价值**；不把平均现金余额当全公司不会融资的证据。

### 4.2 投资理念、统一估值和资本桥

参考标准并非用户真实偏好：短期里程碑交易要求6个月至少20%条件回报（邻近合理10—30%）；一年订单兑现要求30%（20—40%）；三年高风险平台要求年化25%（15—30%，主要求累计95.31%）。高风险资金可以承担50%以上甚至接近全部损失，但不能只比较成功上限。稳健资金另要求合理较差路径有现金保护，$11.18显然不满足。估值折现率与这些“值得持有”的门槛分开。

美元现金机会成本取3.9%年化，与9月8日发布的H.15中最近可交易日9月4日3个月CMT 3.91%、6个月3.98%接近；并非声称9月8日发布就等于9月8日报价。估值股权折现工作值12%、范围10—14%，用于已在机会现金中计入项目失败后，仍存在的时间价值和系统性风险；不再乘一次全公司失败率。高持有要求不等于把公司经营改坏。[美联储H.15][RATE]

**主方法采用逐联合分支的直接股权现金流法**。先从研究日资金出发计算每季经营、全部投入、税、融资和股权报酬；在持续经营时保留1,000M储备及正客户预收负债，最早Y7末开始分配超额资金，停止开发后保留100M服务储备，无存量服务则退出分配。Y60剩余现金分配。每个目标日只折现其后的每股可分配现金：

`V_branch(T) = Σ_{q>T} 分支q可分配现金 ÷ 分支q FD股数 ÷ (1+r)^((q−T)/4)`

`V_s(T) = Σ_branch 联合权重 × V_branch(T)`

目标日前现金没有遗漏：它已经是现金滚动的起点并影响未来融资及分配；**不能再把目标日全部现金额外加到上述价值上**。为了展示资本桥，定义该方法导出的净经营／持续投入权益`EV_equivalent = 目标日股权价值−目标日可用现金`。早期亏损企业该数可以为负，表示未来持续投入消耗现有现金，而非负债。主模型无债务、无项目股权、无未获权利的非经营资产加值。

由于每股先在不同融资分支计算再加权，`E[股权价值]/E[股数]`一般不等于`E[每股价值]`。后者是主矩阵；集团资金、股数和稀释后总权益表分别为路径均值。不能强行令均值相除相等来“修复”非线性。区间为同一经营解释下P下调5%、C上调5%、固定费上调5%、r=14%的较弱组合，到P上调5%、C下调3%、r=10%的较强组合；概率、时间及渠道不另换行，不是统计置信区间。

维持性收益与成长项目没有重复计值：PMA、材料资金、研发、工装在同一全部现金路径扣除，其后盈利和服务现金计一次。未来股权报酬加回现金，同时增股；起点期权/RSU已经计入，不再次作为全部现金费用扣去。SBC现金等价预算24M／年并非归属人数预测，授予价格敏感性须随实际股价更新。

### 4.3 现价要求及理念分歧

资产安全边际论点：研究日现金约$4.21／FD股，尚需研究和已触发合同履约。即使以较低关闭成本作“立即缩减并有序变现”的条件实验，金融资产可归股东约$3.0—4.2／股，加上并未确认的500M额外处置权益也只增加约$1.14。该假设不与继续研发、未来平台价值同时相加；控制权变化TRA还可能减少回收。因此当前不是现金保护型买入，也不是因为股价跌了80%就完成困境修复。

里程碑重估论点：PPA/OEM把技术资产转为可融资设备履约，可能先于收入带来交易利润。它最有力，且无需等首站商运；但9月8日跳涨后没有可以复核的交易价格采纳分布。当前“技术进度真、商业净价未知”两者可同时成立；不能从缺少交易优势推断必跌，也不能从存在公告窗口推出值得追涨。

平台期权论点：同样PMA下，突破P=280、C=158的工作路径三年约$15.33，累计约37.1%、年化约11.1%，低于25%参考要求。把**单模块P提高到305M、其余突破经营／资本假设固定**，三年约$23.28，累计约108.2%、年化约27.7%；$320M约$28.22。这是有经济机制的分歧：更强报价提高净捕获和自筹能力，减少稀释，非换一套估值方法。$305M只比280高8.9%，未被证据排除，却也未被合同支持；对应业主全站预算分摊与净电价须重新确认。以$305M路径单独作条件判断可达**谨慎建议投资**，对仅5%的净售价误差即敏感，不能升级为当前买入。

同一三年目标的持有标准也会翻转选择：突破主值在25%年化下买价上限约$7.85，在15%年化下约$10.08；$11.18仍高于二者，但相差幅度不同。若投资者仅要求约11%年化，该工作点接近边界，余量小于OEM净价未知和正常股价波动。四行主矩阵统一用前述标准，未临时把某格的要求改低制造正面结果。

本次没有为现价反求一个“市场真实成功概率”。如用三年$27.87的强条件成功价值，与其他结果的平均终值$0—8作**仅含成功／非成功的门槛实验**，要满足$21.84，成功概率须约70%—78%；若要求15%年化，须约45%—61%。非成功均值需包含全部其余路径，不能以单个乐观格代替。现有资料只支持机会存在和部分工程进展，无法支持如此高的“高净价＋规模复制＋资金配对”联合成功率；这不是把u的15%局部规模概率直接套进整股公式。新的平台或收购若提供更高成功价值，门槛会下降，但须补足权利、支付和可达路径。

主矩阵之外更差的责任分支包括PPA大量先触发、采购融资不成、材料减值、重大判赔、额外担保；在相关融资断点普通股可趋近零。没有以“无债务”排除这些风险。相反，投入缩减或资产出售可以比继续研发主路径保住更多现金，但无法在保留全部平台机会的同时免费做到。

12个月目标前，12台按2026基准只触发M2约202M，M2/M3合计约491M；与现金1,848M比较不会立刻破产，但足以改变首站后的资本配置。24台加三年基础消耗和自动上调，则可能接近全部资金。风险已经进入PMA时序、低收益／失败路径、融资股数及现金储备，不再统一追加“核电风险打五折”。利率与股票折现率也分开：前者改变现金利息、客户资本成本，后者反映未进入分支现金的系统风险。

### 附件B：模型复算代码与核验口径

以下Python仅依赖标准库。输入量价与概率均在代码中，单位M／M股；运行生成各行季度／年度及目标日值。它不访问旧报告、行情或外部网页。源码保留资本断点和逐分支每股计算，避免用平均股数代替。融资关闭、延期、没有复制、价格／成本变化和独立成功实验可用`bundle(name,variant,force)`复算。

复核重点：每行联合概率总和100%；每个年度状态合计100%；状态加权收入等于集团对应机会收入；季度加总等于年度；现金桥与股数融资桥逐季成立；三个目标日期后NTM与对应季度切片一致；股权总额与现金／净经营权益等价桥成立；三年累计与年化用同一价值；单位经济、延期与融资敏感性方向有经营解释。股东直接现金流法的末期现金不再加回第二次。

def prob(s,ks):return math.prod(s[key][k] for key,k in zip(['r','u','h'],ks))
def bundle(name,variant=None,force=None):
    paths=[]; s=S[name]; weights={ks:.5*prob(s,ks) for ks in itertools.product(range(3),repeat=3)}
    # Half common financing/regulatory state, half idiosyncratic adoption.
    # This copula preserves each opportunity's marginal path probabilities.
    cuts=sorted(set([0,1]+[sum(s[key][:i]) for key in ['r','u','h'] for i in [1,2]]))
    for lo,hi in zip(cuts,cuts[1:]):
        mid=(lo+hi)/2
        ks=tuple(next(i for i in range(3) if mid<sum(s[key][:i+1])) for key in ['r','u','h'])
        weights[ks]+=.5*(hi-lo)
    if force:
        # Independent-success experiment, not conditioning all other opportunities on a correlated event.
        op,state=force; weights={ks:prob(s,ks)/s[['r','u','h'][op]][state] if ks[op]==state else 0 for ks in weights}
    for ks in itertools.product(range(3),repeat=3):
        p=weights[ks]
        if p==0:continue
        paths.append((p,ks,run(name,ks,variant)))
    assert abs(sum(p for p,_,_ in paths)-1)<1e-9
    return paths
def value(rows,tq,rate=.12):

    # Direct equity valuation: follow each joint branch's cash, dilution and actual
    # available distributions. No cash or financing proceeds are added a second time.
    ps=sum(row['div']/row['shares']/(1+rate)**((row['q']-tq)/4) for row in rows[tq:])
    total=max(0,ps*n)
    return dict(price=ps,ev=total-cash,eq=total,cash=cash,n=n)

    return {key:sum(p*vv[key] for p,vv in out) for key in out[0][1]}
