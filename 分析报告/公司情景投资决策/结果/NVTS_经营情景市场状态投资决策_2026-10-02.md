### 2.2 为什么客户愿意采用，为什么收益不会全部归NVTS

同样1MW，理想54V母线电流约18,519A，800V约1,250A。相同导体电阻下，铜损比例约0.456%；真实工程同时会改变导体尺寸、距离、绝缘和保护，不能据此宣称整座机房耗电减少99.5%。

以某转换级100MW持续输出为条件，效率由96%升至97%，输入功率下降约1.074MW。若负载率70%、电价$60—120/MWh，年节电约$0.40—0.79M；五年、10%折现的价值约$1.5—3.0M，即约$15—30/kW。**这是C/E工程经济算例，不是NVTS产品实测效果。** 它证明存在支付空间，同时约束只靠节电可索取的溢价。空间、散热及可用供电容量可以额外增值，但不能与同一节电收益重复相加。

近芯片供电的逻辑不同：2kW、0.8V芯片约需2,500A；若有效供电路径电阻减少20微欧，理论I²R损耗减少125W。实现这一收益仍受封装、热、瞬态响应、可维修性及控制方案限制。每颗xPU相关净器件内容$80—130在昂贵计算平台中可能只有小比例成本，商业上并非明显不可承受；但净采购价必须由客户TCO和竞争报价决定，不能把整座数据中心的节省全部转成供应商利润。

客户预算并非空白支票。Meta已公开2026年CapEx指引$130—145B，Q2经营现金$31.862B而自由现金约$0.784B。它说明主要买方有真实投资能力，也说明建设吞噬现金、融资与回报约束正在加强；Meta数据不是NVTS客户订单。本模型不把任何云厂全部CapEx按比例分配给NVTS。[Meta 2026Q2公告](https://investor.atmeta.com/investor-news/press-release-details/2026/Meta-Reports-Second-Quarter-2026-Results/)。

### 2.3 已兑现优势、尚待证明的护城河与技术替代

NVTS的优势是GaN功率与驱动保护集成经验、GeneSiC高压器件及聚焦高功率的研发组织。资格认证之后，电源厂改变器件会重新承担可靠性和工程验证成本，存在粘性。无晶圆厂模式也允许跨材料选择工艺，而不是为自有低利用率工厂承担全部固定制造费用。

但这不是独占架构。TI于2026-03-16展示完整800V链路，包括800V→6V GaN转换及6V→低于1V的多相方案；其参考设计披露97.6%峰值效率和超过2,000W/in³。Infineon于2026-09-07发布使用OptiMOS硅器件及双相驱动的VPD功率级工程样品。技术资料中的峰值、满载、输入电压及测试边界不同，不能简单比较百分比后裁定NVTS领先，也不能把竞争者工程样品当量产收入。它们足以证伪“GaN或NVTS垄断近芯片供电”的说法。[TI官方架构](https://www.ti.com/about-ti/newsroom/news-releases/2026/2026-03-16-ti-unveils-complete-800-vdc-power-architecture-for-future-generation-ai-data-centers-with-nvidia.html)、[Infineon技术发布](https://www.infineon.com/technology-news/2026/inftn202609-136)。

大厂可以把控制、保护、功率级、现场支持和长期供货组合报价。客户也可能通过开放接口和二供降低单一器件溢价。800V直达6V还可能淘汰旧的中间转换级；本报告只计最终架构中NVTS留下的净内容，不把所有历史级数叠加。结构性电力密度需求有依据，器件价格长期单向上涨和高利润永久不受竞争侵蚀没有依据。

### 2.4 商业时钟、制造迁移与交付的实际瓶颈

NVIDIA于2026-08-11区分现有交流设施的混合800V power rack、2027年行级方案及更远期原生架构。因而NVTS可以先从现有AC/DC、过渡电源及保护得到收入，不必等待整座原生800V机房建成；SST不是采用800V的必要前提。[NVIDIA原始路线图](https://blogs.nvidia.com/blog/800-vdc-power-architecture-ai-factory/)。

GaN供应迁移则是独立门槛。NVTS年报披露TSMC拟在2027年7月退出GaN制造。GF于2026-09-01公开的Gen 5计划为：9月晶圆、10月内部样品、年底前战略客户样品，采用Vermont 200mm路线。合作方背书比单方叙事强，但“计划9月发货”不会因日历进入10月就自动变成“客户认证完成”。生产资格、良率、封装、动态电阻及长期失效记录都可能延后收入并增加工程库存。[NVTS年报供应风险](https://ir.navitassemi.com/node/11451/html)、[GF原始披露](https://gf.com/news-and-events/news/navitas-delivers-latest-gen-5-ganfast-manufactured-in-the-u-s-through-globalfoundries-partnership-to-accelerate-ai-infrastructure/)。

以11GW交付功率、20kW板、每板16颗高压GaN的**条件工程算例**，需要55万块板、880万颗器件。假设每片200mm晶圆产出3,000—6,000颗最终合格裸片，对应每年约1,500—3,000片，封装损耗或更大裸片会增加需求。16颗及晶圆产出仅作算例参数，未当作本次已验证BOM／良率；技术演示链接未能取得可解析正文。因此这里仅裁定“不能仅凭全球晶圆面积断言该规模物理不可能”；它不证明GF已分配这些配额。真正需要证明的是合格工艺、客户认证和持续交付。

Claros于2026-06-16披露Samsung Foundry制造合作；Citi会议上管理层所说的领先xPU客户和2028年放量仍是M，不是客户直接确认。需要从芯片、封装和客户验证走到可复制销售。模型把2027年Claros收入设为零，研发现金成本则从整合开始发生。[Claros原始合作发布](https://www.businesswire.com/news/home/20260616694597/en/Claros-Announces-Strategic-Manufacturing-Collaboration-with-Samsung-Foundry-to-Produce-Integrated-Voltage-Regulators-for-AI-Data-Centers)、[2026-09-08管理层转录，第10—11页](https://ir.navitassemi.com/static-files/4511e3f5-3c0a-4f7b-bbf0-0e8206fdb66b)。

### 2.5 利润与现金的门槛

Q2现金费用口径的非GAAPOpex15.510除以39.5%毛利率，意味着固定费用不变时约 **39.3/季度**的SBC前经营盈亏平衡收入，为当季的3.73倍。收购团队、客户支持和新工艺投入会使这一门槛继续变化；它既不是GAAP盈亏平衡，也不是计入全部股权成本后的经济盈亏平衡。

现有器件具有正毛利，集团仍远低于覆盖固定研发和销售成本的规模。自由现金自给还需覆盖测试设备、工程投入、库存预付和回款。fabless并不等于只需要当前不到1M的半年CapEx：上半年库存与预付的现金消耗已经远大于设备支出。

基准路径中SBC前经营利润于2029年转正，FCF于2030年转正；累计收回2026年下半年经营、整合、Claros现金对价和Magnachip投入，需到2035年前后。乐观约2032、突破约2031，悲观至2036仍未收回。这里是本轮现金配置的简单回收期，不含股票对价的经济价值，也不是自2014年创立以来的全部历史投入回收日；后者缺少完整现金台账，不能用累计会计亏损代替。

### 3.4 四条经营演化为什么成立，以及为什么会失败

**悲观／受损：** 既有高功率业务只维持小规模，客户二供和工艺迁移使净内容受压；Claros到2028仍无有效量产，集团自2028开始收缩研究项目、减少团队和非核心支持。2029现金经营费用降到42，2030降到33，但仍保留已发生收购支出、2027—2028研发亏损及后续维持研发。收入之后随可存续器件平台温和增长，没有假设董事会持续按乐观预算烧钱直至破产。永久损伤主要是Claros未形成平台收益、NVTS未取得新架构的充分份额；不是假定整个功率半导体需求消失。

**基准／正常兑现：** 现有高功率增长及过渡电源需求延续，GF经历正常资格和爬坡；Claros2028小规模收费、2029形成一个有意义的平台并逐步扩大。2027收入72，2028收入126，2029收入211，2030收入302。它已经包含很快的增长，而非把所有未知都置零；但更多资格、研发和现场支持使费用随规模上升，不能提前画出高净利润率。

**乐观／超预期：** 现有客户更快进入持续采购、多个转换和保护位置被采用，Claros形成不止一个可复制平台。2029数据中心覆盖6.5GW、Claros90M收入，集团401M；2030集团606M。解除的是资格、平台数量和内容量约束，不是给同一台机器无限提高售价。价格在后期逐步下降，毛利改善依靠制造成本、组合和集成，而非永久短缺溢价。

**突破／非线性：** 核心工业、电网、GaN／SiC业务都较乐观更强，Claros跨多个xPU平台并获得封装和控制中的持久位置；2029约200万颗搭载，2030约320万颗。新增现金经营费用、测试CapEx和备货均高于乐观，没有压低核心业务来孤立显示新技术。最少必要条件是：量产性能和可靠性达标、客户付费采用、Samsung及封装供应可复制、至少多个平台的净内容得以保持，以及没有重大侵权禁售或资源争夺导致原业务掉队。

突破2036的Claros条件量达到约1,370万颗xPU；若每颗约3kW，相关IT功率约41GW，低于同年数据中心器件覆盖52GW，两者可以在同一设备中出现，**功率不能相加为93GW**。但这一远期分支仍要求全球高密度设备持续扩张和NVTS长期较高份额；若远期相关采购池只有50GW或客户有效搭载池无法容纳此规模，必须削减终值前收入。它属于需要平台跃迁的边界路径，不是当前“中标量”。

## 5. 估值转化、倍数解构与四情景股价预测

本章才将前面的经营与每股现金结果转为价格。2029年收入、利润、现金和股数已经由业务路径锁定；没有为了得到某个目标价再反向修改业务规模。

### 5.1 内在价值方法、折现与终值约束

采用**多阶段、逐年股数摊薄的经营现金流DCF**。NVTS几乎没有财务债务，经营FCF与普通股可得现金之间的利息／债务桥较小；模型仍分别偿还融资租赁，未把普通应付和经营租赁重复当净债。每个预测年度的公司FCF先除以该年经济摊薄股数，再折现到观察日；这相当于在现金创造之时计入为员工和条件对价转出的权益，而不是用2026股数永久分配远期现金。

目标日每股剩余经济价值为：

\[
V_{2029}=\frac{C_{2029}-D_{2029}+A_{2029}}{S_{2029}}
+\sum_{y=2030}^{2036}\frac{FCF_y/S_y}{(1+k)^{y-2029}}
+\frac{FCF_{2037}/S_{2037}}{k-g_{ps}}\frac{1}{(1+k)^7}.
\]

其中\(S_{2037}=S_{2036}(1+d)\)，\(g_{ps}=(1+g)/(1+d)-1\)，\(FCF_{2037}=EBIT_{2036}(1-22\%)(1+g)(1-g/ROIC)\)。\(A\)只在正常三条路径计Magnachip独立资产5M、悲观为零，其他未验证投资不计入。2030—2036现金创造不会在DCF中再次叠加为未来现金余额；目标日之前已留存现金才进入现金项。此处是现金可合理返还或投入的经济价值，不代表董事会已承诺分红。

统一股权要求回报率\(k=12\%\)。美国财政部2026-10-02十年期名义国债曲线为5.28%；以约1.5的跨周期系统风险系数、4.5个百分点股权风险补偿作**E参数**，得到约12%。这里没有声称1.5是本次已估计的NVTS历史beta。亏损、延迟、份额不足和失败成本已直接放入不同现金路径，不再对悲观、乐观分别随意加一层主观折现惩罚。10%、14%仅作敏感性，不宣称是未来无风险利率预测。[美国财政部2026年每日收益率，10月2日行及10-year列](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?field_tdr_date_value=2026&type=daily_treasury_yield_curve)。

显式期保留到2036，避免把2029首轮商业爬坡直接当成熟稳态。2036收入分别107、907、1,930、3,673M；综合毛利约43.7%、54.3%、58.2%、61.4%，SBC前经营利润率约9.1%、21.4%、31.2%、31.7%。乐观／突破的高毛利主要要求Claros集成内容、许可与成熟GaN成本共同支持，纯分立器件竞争不足以单独支持该利润率。2036集团研发和支持费用仍分别37、298、523、1,090M，未靠取消研发生成终值。

终值公司名义增长\(g\)取悲观2%、其余3%，不是实物销量固定3%；若单位售价每年下调约1%，需要出货／净内容约4%的增长来维持约3%收入增长。经济现金ROIC取15%、20%、25%、25%，包含维持平台和研发能力的经济投入；再投资率分别13.3%、15%、12%、12%。在现金利润之后留足这部分投入，不用“fabless”取消再投资。净新增股数持续增长0.75%后，每股终值增长只约1.24%／2.23%。税盾不进入永续期，现金税率统一22%。

终值正常化没有人为给业务设置断崖：2037正常化FCF分别约6.7、132.8、425.1、823.4M，与2036的6.4、124.0、408.6、805.8M相近。增长放缓会降低新增库存和设备需求，但不免除维护投入；若长期价格／份额不足以保持上述组合毛利，应改现金路径和ROIC，不能仅用一个高\(g\)弥补。

### 5.2 固定倍数的纯业务参照：24x如何使用

当前GAAP、正常化经营和FCF均为负，正P/E、EV/NOPAT、EV/FCF没有可用当前值。不能把亏损的倒数或负倍数硬接到2030正利润。本研究固定一个**正常化前瞻现金NOPAT的24x参照锚**，其用途是隔离每股基本面与倍数变化，不是声称市场当前正以24x定价，更不是继承同业目标价。

24x属于E定价基准：纯成熟现金经营在\(k=12\%,g=3\%,ROIC=20\%\)时，稳定经营价值／NOPAT约\((1-g/ROIC)/(k-g)=9.4x\)；24x显著高于此，已经允许2030之后数年的真实高增长和平台复用。该溢价只有前述年度量价、再投资和利润路径才能支撑。反过来，同一DCF对应的2029前瞻NOPAT倍数约基准25.3x、乐观20.4x、突破17.3x，说明24x在基准附近有现金流支持，在突破端则需要更低资本成本或更强后续增长。不能把24x永久赋予所有阶段，也不把它包装为有精确同业统计支持的“行业均值”。

固定锚价格为：

\[
P^{pure}_{2029}=24\times\frac{NOPAT_{2030}}{S_{2030}}
+\frac{C_{2029}-D_{2029}+A_{2029}}{S_{2029}}.
\]

这保留期间现金积累和股本变化，不只是收入乘倍数。选择2030股数作为前瞻利润分母，是为了连下一年现金创造前发生的普通激励也扣除。若改用2029股数，模型目标价格会偏高；本报告所有市场倍数价格采用同一口径。企业价值桥以\(EV=M\times NOPAT_{2030}\times S_{2029}/S_{2030}\)再除2029股数，与上式完全等价。

因此基准纯业务参照3.58、乐观12.19、突破27.31美元。悲观2030仍亏损，24x不能使用；用统一折现参数的剩余DCF1.17作替代，明确不与正利润倍数直接比较。

**基准纯业务参照相对现价−71.1%，并不表示业务萎缩71%。** 基准收入从2026工作值48.2增长至2029的211，再至2030的302，已经高速扩张；只是未来股东可得现金NOPAT与当前付价要求相距很大。乐观收入增长至401／606，固定24x参考价仍约12.19，回答了“收入爆发是否必然带来股票爆发”：固定研发、资本投入、稀释和现价预付共同决定回报。突破的27.31来自每股现金NOPAT达到1.085及现金权益，未加一个更高的突破倍数。

### 5.3 目标市场价格及倍数重估的增量

目标交易区间采用基准20—28x、乐观18—26x、突破18—24x前瞻现金NOPAT。基准刚走向自给，比例上仍有较长扩张期；乐观／突破的2030利润底数大、商业质量更好，但当前前瞻利润已包含更多爬坡成果，未来资本占用、二供与增长换挡仍须计价。较低的突破倍数**不代表突破整体经营较差**，只是不能既按更大的次年利润收费，又把同一远期成长重复放进极高倍数。每条路径都有相同折现假设与现金桥支撑。

倍数对价格的增量为\((M-24)\times NOPAT_{2030}/S_{2030}\)，和纯业务参照对现价的差额分开：

| 估值拆解 | 基准 | 乐观 | 突破 |
| --- | ---: | ---: | ---: |
| 固定24x纯业务价 | 3.58 | 12.19 | 27.31 |
| 目标倍数区间 | 20—28x | 18—26x | 18—24x |
| 倍数变化带来的美元增量 | −0.42至＋0.42 | −2.75至＋0.92 | −6.51至0 |

基准负回报绝大部分在固定锚下就存在，主要由当前价格预付成功程度造成，而非依靠大幅“杀倍数”制造低回报。乐观低端比固定锚再少约22个百分点，来源是18x端的资本回报与后续斜率压力，属于市场定价风险，不能误说业务受损。突破上端维持24x，低端18x带来约52个百分点回报差，但仍有正回报；上行没有依赖估值扩张。

悲观采用剩余DCF的75%—125%，得到0.88—1.47美元。25%上下幅度是亏损公司在现金分配、法律／客户不确定及市场情绪下的定价带宽E，不是统计分位数；低端低于现金/股反映市场可能对继续消耗与现金不可立即返还打折，不等于立刻取得清算现金。

### 5.4 交易价格与剩余DCF的自洽性

基准3.16—4.01相对剩余DCF3.72约低15%至高8%；乐观9.44—13.11相对10.52约低10%至高25%；突破20.80—27.31相对20.05约高4%至36%。没有一行靠设定高出DCF数倍的交易价来创造上行。

突破上端仍比中心DCF高36%，须明确承认这是较强增长持久性／较低资本成本的市场溢价，而非内在价值无条件等于27.31。将同一突破现金路径的\(k\)改为10%、\(g\)保持3%，目标DCF约25.69；10%与4%组合约27.47。它可以说明市场上端在怎样的定价状态下成立，但不能把更低折现率当已证事实。中心DCF没有强迫2036利润率骤降，也没有刻意压低\(g\)惩罚未实现业务，因此不宜无理由把上端继续提高至40—60美元。

若目标日市场仍为更远的VPD大平台买单，交易价可能超出这里范围；必须对应更强客户规模、内容量、竞争持续性或资本条件。仅凭NVIDIA生态名单、技术样片或宏观用电预测不能升级价格。反过来，若库存和测试资本远高于模型，现金转化变差，即使收入达到乐观数，市场18x也可能仍偏高。

### 5.5 敏感性与本模型最脆弱处

在同一现金路径中，\(k=10\%—14\%,g=2\%—4\%\)的2029DCF：基准约3.12—4.83、乐观8.44—14.33、突破15.98—27.47。终值净稀释从0.75%升至2.5%，中心目标DCF变为基准3.42、乐观9.51、突破18.08。终值股权成本持续存在，不能把未计SBC的现金指标当无稀释收益。

更决定性的经营压力是：基准数据中心净售价下调20%、直接成本只降10%，目标DCF约2.73；Claros延迟两年、2027—2029每年额外10M现金费用，则约2.54；额外50M现金预算损耗约降至3.54。**商业节奏和价值捕获比终值增长率小幅调整更重要。** 对净内容$/kW、客户搭载数量及控制／封装分成的独立公开证据，目前仍不足。附录将全部敏感性和发生代价列出，不用一个“安全折扣”替代这些未知。

### 5.6 两个维度的情景评估

证据支撑度评价现在已经证实多少前提；商业可实现性评价剩余门槛在需求、物理、预算与竞争上是否能够跨过。两者都不等于发生概率，本次投资选择没有用“弱”自动判定“不可能”。

- **悲观：证据中；商业机制可实现性高。** 历史收入下降、集团亏损、取消风险及制造迁移已有事实。客户份额受压、Claros失败后收缩在商业上相容；但没有证据证明失败已经发生，也不把巨额法律赔偿当主情景事实。
- **基准：证据中；商业机制可实现性中高。** 现有高功率产品和客户选型提供起点，资本足以支持迁移及研发；4GW覆盖和一个Claros有效平台并不违反预算或物理容量。具体搭载与净价尚需验证，基准已包含快速增长，其每股价值低不是对增长机会归零。
- **乐观：证据弱；商业机制可实现性中。** 多客户采用、成本成熟和平台复用在技术及预算上可以成立，但需要几项尚未完成的资格同时推进；当前没有足够连续采购证据支撑401M收入和90M Claros收入。
- **突破：证据弱；商业机制可实现性中、执行门槛高。** 核心更强、Claros多平台复制、200万颗xPU采用有真实技术和制造路线，并非因缺少远期合同就不可发生；11GW覆盖却要求约24%—44%的本次采购池、较多器件位置和稳健净内容。$30/kW高于管理层约$25/kW的内部GaN+SiC机会，额外约$5需更高密度或保护内容，当前尚无确定采购证据。任何一项未达标都会降低右尾，不能把宏观AI需求当成全部门槛的替代证据。


## 6. 当前投资决策、仓位属性与动态验证

### 6.1 当前价格隐含什么经营要求

行情供应商的262.56M基本股数乘12.40得参考基本市值约3,255.7M；以6月末现金及融资租赁扣算，参考EV约2,699.0M、EV/36.53M TTM收入约73.9x。股数与现金日期不同，此计算只是**C／条件横截面**，不是精确当前EV。金融行情工具另一市值字段约2,984.0M反推240.6M股，接近Q2平均EPS股数，不能拿它代替期末资本结构。本报告不在负利润上使用其P/E。

在交易完成、H2现金和经济摊薄条件状态下，12.40对应约3,079.7M经营价值，约为2026收入工作值的63.9倍。这些收入倍数只反映需要很大兑现，不被用来推导目标价。

更有解释力的是**同一DCF现金模型反向解**：在乐观至突破之间联动插值年度各分支收入、毛利、费用、CapEx、营运资本、税和股数，以使现时DCF等于12.40。得到约位于该区间的74.7%处；这仅是路径插值参数，**不是突破发生概率或概率加权估值**。相容的要求约为：

- 2029收入 **653M**，其中数据中心约292、Claros约187、电网约88；SBC前EBIT约160、FCF约52、经济股数约292.6M。
- 2030收入 **1,030M**，SBC前EBIT约309、现金NOPAT约272、FCF约169；现金NOPAT率约26.4%。
- 之后收入仍增长到2036约3,232M，并保持约31.4%SBC前经营利润率，不能在2030达到一个收入点后停止增长。

这并非说市场投资者都建立了同一模型，也不是收入达到653就必然有12.40现值；价格、毛利、再投资、稀释和后续持续性需要同时成立。其含义是：**12.40主要处在乐观以上、接近突破的经营期待层，而近期13.5M季度指引单独不足以证明这一级别。** 降低要求回报率、赋予更高永久增长会降低隐含收入门槛，但也意味着接受更昂贵的远期风险和较弱安全余量。

### 6.2 非对称风险收益与仓位选择

NVTS应归为**有实物产品和客户线索的高风险第二曲线公司**。现有现金支持研发与多次尝试，无近期债务到期墙；不是工程和融资都无闭环的空项目。Claros的VPD／IVR逻辑也不因暂无大额公开订单就归零。问题在于当前价格已经提前支付多个成功门槛，且基本盘尚不能自行覆盖集团费用。

本次选择**暂不按12.40新建仓位；已有持仓仅按观察／事件风险仓管理**。理由是：基准对应约68%—75%下行，乐观约−24%至＋6%，突破约＋68%至＋120%，悲观约89%—93%下行。突破中心DCF现值仅14.16，相对12.40的经济折价约12%，而非对高不确定执行有丰厚缓冲。现金充足降低“不得不立即破产”的风险，却不减少为了取得高增长而转出的权益与投入。

没有给四情景强行赋予主观概率；即使不赋概率，**只在突破且保持较好市场定价时提供显著回报，而基准已有深损失**的结构，也足以支持当前不新开仓。这个结论会随业务硬证据或价格改变，不是永久回避GaN、NVTS或未盈利股票。

仓位界限用来表达研究风险属性，不假设已知用户的总资产、负债或已有配置：已有观察仓宜按“若其大部损失也不影响组合计划”的规模处理；如需量化，风险资产的约0.5%可作为最高观察仓示例，不以此替代个人约束。只有对两条主业务的量产采用、净内容与现金转化得到更强证据，并重算价格后，才讨论进一步增加。仅单条公告、短期股价上涨或季度指引小幅上调不构成加仓依据。

等待有机会成本：若近两季数字及客户证据迅速强化，价格可能在未给出$4—6机会前升至15或18。保持**同一模型不升级**时，在15买入的突破目标回报只剩约＋39%—＋82%，在18只剩约＋16%—＋52%；乐观分别约−37%至−13%、−48%至−27%。这些是同一2029观察日的价格回报，不是之后买入的精确年化回报。

因此，等待不是赌一定会有低价：其代价是可能错过公告后的第一段涨幅，所换取的是更少未完成商业门槛。如果更高价同时伴随真实连续采购、Claros付费平台和更强净内容量，须升级现金模型，再判断较高买价是否仍合算；若只是Q3收入从13.5到14，远不足以把653M／1,030M的隐含多年规模证实。避免以旧买点拒绝所有更高价，也避免以“踏空”取消每股回报约束。

按当前模型及约3.25年持有期，若希望取得12%年化价格回报，目标价至少需约 **17.92**。乐观上端13.11达不到；突破满足。无现金分红假设下，价格回报等于条件总回报，不另附一个虚构股息。

### 7.7 复算核心步骤

给定本附录的逐年收入、毛利、Opex、税、CapEx、D&A、缓冲和激励，可用以下伪代码复算；完整现金表已经是可核对的数值底稿，不依赖另一份正式报告或未交付文件：

```text
cash = 370; shares = 278.1807984516; nwc = 35
for y = 2027 ... 2036:
    revenue = sum(business_revenue[y])
    gross_profit = sum(business_revenue[y] * business_gm[y])
    ebit = gross_profit - opex[y]
    tax = ebit > 0 ? ebit * tax_rate[y] : 0.15
    nopat = ebit - tax
    next_nwc = 0.20 * revenue + supply_buffer[y]
    fcf = nopat + ordinary_da[y] - capex[y] - (next_nwc - nwc)
    interest = cash * 0.035
    cash = cash + fcf + interest - finance_lease_principal[y]
    shares = shares + ordinary_net_grants[y] + conditional_shares[y]
    nwc = next_nwc

g_per_share = (1 + g) / (1 + terminal_net_dilution) - 1
fcf_2037 = ebit_2036 * 0.78 * (1 + g) * (1 - g / cash_roic)
shares_2037 = shares_2036 * (1 + terminal_net_dilution)
terminal_per_share = (fcf_2037 / shares_2037) / (k - g_per_share)

target_dcf =
    (cash_2029 - finance_debt_2029 + separate_asset) / shares_2029
    + sum_y2030_2036((fcf_y / shares_y) / (1 + k)^(y - 2029))
    + terminal_per_share / (1 + k)^7

pure_price = 24 * nopat_2030 / shares_2030
             + (cash_2029 - finance_debt_2029 + separate_asset) / shares_2029
market_price = target_multiple * nopat_2030 / shares_2030
               + (cash_2029 - finance_debt_2029 + separate_asset) / shares_2029
price_return = market_price / 12.40 - 1
```

悲观盈利倍数不适用，改为剩余DCF×75%—125%。当前条件DCF的观察点换为2026年末，显式折现期为2027—2036，再除以\(1.12^{90/365}\)。模型反向插值是联动整条经营与资本路径，不能把74.7%插值参数当概率，也不能只插值目标价来声称市场隐含了某个收入。
