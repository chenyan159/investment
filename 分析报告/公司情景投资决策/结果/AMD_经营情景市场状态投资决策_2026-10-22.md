## 1. 业务经济本质与竞争位置

### 1.1 六个经济单元和收入归属

AMD 的价值来自为客户完成任务节省的全周期成本，并取得其中一部分芯片与平台对价；客户的模型收入、电力资产、整机制造和全部网络支出不属于 AMD。研究采用下列经济单元，而不把财报的 Data Center 当成一种利润率完全相同的产品。

| 经济单元 | 谁采购、为何采用 | 扩张与利润约束 |
| --- | --- | --- |
| EPYC 服务器 CPU | 云基础设施、企业和 OEM；看性能、能耗、x86 兼容、内存/I/O 及软件许可总成本 | 高端产品组合和份额有利；晶圆、认证、Arm/Intel 竞争及客户自研约束净价 |
| Instinct GPU、Helios 计算平台 | 云厂、实验室、主权算力等；看模型可用性、吞吐、时延、显存与投运时间 | HBM、封装、系统良率、电力、客户工程和资金缺一不可；二供采用不自动产生一供利润 |
| Pensando 网络与平台器件 | 云网络部门和系统商；以卸载、连接和系统效率换取器件对价 | 开放接口有利进入，也允许买方混用竞争产品；只记 AMD 内容 |

AMD 主要按控制权转移确认标准产品收入；半定制和部分研发服务另有随履约进度确认安排。芯片发运、OEM 完成整架、机房通电、终端用户持续付费，是不同节点。2026H1 原期限超过一年的 RPO 约 222M，披露豁免了短期合同，不能将它误认为全部 GPU 订单，更不能和 30.276B 上游采购承诺相减，推导“订单缺口”。[10-Q Note 3、10][F3]

所有权也须分开：AMD 控制芯片设计、软件与系统设计能力，外部晶圆厂、HBM 产能和客户机房并非 AMD 所有。封装 JV 采用权益核算时，JV 利润不是把 JV 全部营业额并表。ZT 制造业务已出售，终止经营收入与出售款不纳入持续经营起点；保留系统设计能力可以改善交付，但不会让整个 ODM 机架销售额都归属 AMD。HUMAIN 等项目的总投资、AMD 器件销售和 JV 权益收益不相加；未取得完整分成与资金调动条款的项目，不先加一份 JV 分红。[10-K，收购和权益投资附注][F1]

### 1.3 EPYC：高质量利润池，但代理增长必须落到采购

EPYC 的经济优势并非“核心越多，价格就能同比提高”。客户比较的是完成同一任务需要多少整机、内存、电力、按核软件许可和运维资源。芯粒复用和 x86 兼容降低一部分开发与迁移成本，但数据库授权、OEM 认证和组织惯性仍可能抵消硬件优势。云厂内部采用、公开实例扩充和企业复购，强于单纯发布型号；公开实例数本身不是物理芯片出货量。

管理层 08-04 称 CPU 已连续五季创收入纪录，云与企业同比均超过 70%；把 2026H2 CPU 增长预期提高至超过 80%，并表示 2027 全年超过 70%、DC 收入翻倍以上。这些是 G，兑现记录支持方向，尚未变成未来审计收入。[官方业绩会，第 2—4、11—12 页][F9]

三种预算分别建模：传统云/企业更新，GPU/ASIC 主机，以及独立代理执行、工具调用和数据准备。Helios 每 72 GPU 配 18 CPU，基准 2027 新代 GPU 75 万颗仅对应约 18.75 万颗机架内 CPU；假设净价 4,000 美元，约为 0.75B。它只能解释本次 28.5B EPYC 预测中的很小部分，不能靠 GPU 配比推高整个 CPU 业务。[Helios 规格][T2]

10-12 Helion 是独立代理 CPU 机架的新入口，伙伴配置目标 11 月可用，截止日仍须等待实际交付。满配 32,768 核、按 256 核 CPU 作条件换算约为 128 颗 CPU/架；5,000 架×128×4,000 美元仅约 2.56B 芯片收入。它可以成为有意义增量，却不是整架销售总额。基准 EPYC 中容纳的独立代理相关贡献约为 2027/2028/2029 年 0.8/2.0/4.0B，均为 I；突破路径相应扩大到约 2/6/14B，仍包含在 EPYC 总额内。[Helion 公告][T4]、[CPU 行业机制][L3]

竞争同样真实：Arm 云自研降低外购 x86 需求，NVIDIA 将 CPU 与整套 AI 系统组合，Intel 改善供货与企业产品。Microsoft 10 月原文同时强调 Cobalt、Maia 和开放伙伴。采购人引入 AMD，可以为了真实 TCO 优势，也可能为了取得二供议价能力；研究不能默认二者利润归属相同。[Microsoft 基础设施说明][T14]

对“代理需求必然由 EPYC 捕获”的最新反证，是 Arm 10-13 发布的七组代理负载测试与机架模型：其称 AGI CPU 对 EPYC 9755 平均机架性能约 1.99 倍，服务器测量经 Signal65 核验后用于机架建模。必须保留两个限定：机架结果包含功率/密度模型，并非一颗芯片的直接吞吐倍数；对比对象是 Turin，不能直接替代尚需重新测试的 Venice。它支持 Arm 在独立代理任务上的竞争是真实的，尚不足以直接证明 AMD 新代订单已流失。本研究据此要求 EPYC 的新增代理收入经过实际复购验证，未因 agent 数增长就自动授予 AMD 全部预算。[Arm 原始方法与结果，2026-10-13][AR1]

### 1.4 Instinct：生产可用已有实证，大规模净收益仍有门槛

MI350/MI450 的大显存可能减少模型切分和通信，提升长上下文、推荐模型或高并发推理效率。Helios 将 GPU、CPU、网络和 ROCm 的协同从器件层推到系统层，扩大 AMD 可解决的问题。但大显存也增加 HBM 成本；迁移、故障恢复和有效利用率决定买方愿意付多少。

Meta 10-15 的论文给出十组 8—128 GPU 生产推荐训练工作负载，MI350X 对 B200 在同 GPU 数和 batch 下吞吐几何均值为 101.2%。这使“AMD 能承担生产训练”具有买方工程证据。其 MI350X/B200 部署功耗为 1,000W/750W，且不是万卡前沿大模型测试，不能推出等功耗领先、所有模型无迁移成本，或推断 60% 算力已经购买 AMD。[Meta/AMD 论文 §II-B、VI、表 III][T5]

软件能力的经济门槛，是新模型上线延迟、算子与通信覆盖、跨节点可靠性、客户复购和驻场成本。代码可移植减少了入口摩擦，却不会把研发和客户支持费用自动降到零。NVIDIA 的生态、互联、系统规模和原生优化仍有优势；其 FY2027Q2 总收入 96.221B、GAAP 毛利率 75%，说明对手有竞争投入与定价回应的财务能力，不能作为 AMD 能取得同样毛利率的证据。[NVIDIA 原始财报][T13]

一个纯机制算例（A）：若 AMD 年度系统成本为对手的 80%、吞吐相同，但可销售利用率只有 45% 而对手为 60%，单位有效产出成本比为 0.8×60/45≈1.07，反而高约 7%。相反，大显存和软件优化若使机器数量与可用率同步改善，才可能把客户节约转化成 AMD 持续净价。厂商“更多 tokens/美元”的特定模型化测试，没有被当作可收取的等额溢价。

### 1.5 其他业务和早期路线：既保留机会，也保留投入

Client 的 Q2 单位出货 +34%、ASP −6%，收入 +23%，已不同于早期高端组合推动 ASP 的阶段。基准未来收入依靠份额、移动和商用采用温和扩大，不同时叠加行业销量暴增与高端提价。Gaming Q2 −31% 已反映旧代半定制压力；下一主机代际可恢复收入，但设计定点、开发者硬件和消费机量产不是一个时点。Embedded Q2 收入 0.977B、分部利润率约 39.5%，恢复有利润价值，仍要扣集团研发与共享成本。[Q2 经营与分部数据][F5]、[正式公司报告相应单元][L1]

### 2.3 关键分歧裁决：有供给，不等于有同样成本的供给

**第一组分歧：HBM 总量。** 本地加速芯片报告的 2027 合格 HBM 模型为 6.72EB，HBM 专题为有效供给约 5.72EB、实际可售约 5.62EB。追到参数后，前者采用 DRAM 晶圆约 1.6M/月、HBM 分配 27%、良品裸片 600、3GB/裸片、综合良率 72%；后者采用分代需求、供给与客户资格错配，5.62 还是销量，不是供给。不能直接取两个数的均值，也不能把 6.72 与 5.62 当作两个独立实测值。[行业模型附录 C1][L2]、[HBM 专题 §7、附录 A][L4]

本次裁决：全球可用于交付的宽资源压力以约 **5.7EB 有效供给**作为较严格检查参照，保留 6.7EB 为更顺利供给条件；两者绝对值都低可信，不证明 AMD 已有某个配额。基准 AMD 2027 约需 0.382EB，约为严格参照的 6.7%；这在全球尺度可容纳，但仍需约 0.324EB 新代 HBM 的客户级合格配额。突破 2027 约需 0.619EB，约 10.9%，必须取得更高份额，不能使用基准配额却同时交付更多 GPU。2028—2029 新品容量未公开，附录统一用 432GB 等价资源；若实际容量高三分之一，资源和成本须同步提高，不能只保留性能收益。

**第二组分歧：价格和毛利。** AMD 表示供给可支持增长；Micron 09-30 明确称绝大部分 2027 HBM 位元已签协议且同比显著涨价。前者是买方资源可见性，后者是原厂价格方向，可以同时成立。[AMD Q2 问答，第 8—10 页][F9]、[Micron 准备发言，第 3—4 页][S3]

公开资料未揭示 AMD 逐客户净价、HBM 到厂价或完整 BOM。本次 2027 基准成本明确使用 **432GB×34 美元/GB＋9,000 美元其他制造、封装、板级、测试和正常损耗＝23,688 美元/新代 GPU**，净价 44,000 美元，直接毛利约 46.2%。34 美元是本次工作假设，不是声称 AMD 得到特殊低价合同；它低于 HBM 专题约 37 美元/GB 的混合价格，原因只允许来自产品结构、合同重定价时点和等级差异，未经验证须承受 28—40 美元/GB 敏感性。采用 34 而不是直接沿用公司报告 30 美元参数，是对存储涨价证据的明确成本约束。

若 HBM 到 40 美元/GB且无法提价，新代单颗成本升至 26,280 美元、直接毛利率降至约 40.3%；2027 基准现金 FCF 少约 1.65B。若净价同时下降 10%，每颗直接毛利由 20,312 减为 15,912 美元，数量至少增加约 27.7% 才能保持直接毛利，且占用更多资源和现金。不能在同一情景里免费叠加更低售价、更高份额、更高毛利和更少营运资本。

**第三组分歧：新增需求与替代。** 代理和推理量增大，可能同时推动 EPYC/GPU，也可能被自研 ASIC、任务专用架构和更高软件效率吸收。故基准 2029 GPU 净价低于 2027，费用与客户支持继续上升；乐观靠跨客户复购、较强组合和更高利用率，突破则要求平台复用与独立代理 CPU 同时扩大。没有因远期没有合同而机械令业务消失，也没有用一个 TAM 增速给所有产品无差别加成。

### 2.4 产能与交付约束怎样进入模型

TSMC 10-15 表示 N2 家族 2027 年产能预计超过 2026 年两倍，支持先进节点扩供方向；这不是 AMD 的可自由调用配额。CPU 与 GPU 共享先进晶圆、后段、工程人员和资金。条件工程检查：若 EPYC 平均净价 2,800—3,800 美元，2027 基准需约 750—1,020 万颗 CPU；按每封装 6—10 个计算芯粒、每片 500—800 个合格芯粒，需约 5.6—20.4 万片计算晶圆/年。75 万 GPU 若每颗使用两大计算 die、每片合格 60—90 die，则再需约 1.7—2.5 万片/年，尚不含 I/O 与 HBM 晶圆。这些是假设带，不是 AMD 真实 die/良率或配额披露，不同节点不能简单相互挪用。[TSMC Q3 与电话会，第 5 页][S1]、[S2]

基准必须同时拿到 CPU 与 GPU 对应资源，不能把同一份先进节点余量分别全给两者。若配额只能满足一方，先调低另一方销量，再重算费用、库存与现金。突破 2029 的新代 350 万颗、约 48,600 架等价机架、约 8.9GW IT 和 1.54EB 等价 HBM，是必须达到的容量门槛，尚未证明已经锁定。其资金和支持成本也明显高于乐观路径。资源需求完整列在附录，缺少可审计上限之处保留条件性，没有将未知填成无限供给。

## 3. 四种经营情景与公司财务闭合

### 3.1 情景分水岭与管理层动态应对

**悲观／受损：** 新 GPU 软件、交付或客户回报不足，2027 新代仅 30 万颗、净价 32,000 美元；CPU 仍扩张，但低于当前快速增长目标。假设不是 AMD 全业务消失。公司停止可选回购、削减可选项目、放慢新增设备投入、尝试转租容量，同时保留核心 CPU、ROCm 和下一代研发。采购罚金、客户赔付与租约无法立即消失，2027 净支持负担比基准高；后续库存正常化、控费改善现金。没有让管理层无视亏损持续扩张。

**基准／正常兑现：** 2027 新代 GPU 75 万颗、EPYC 28.5B，DC 66.0B；总收入 86.4B。CPU 预测依托管理层超过 70% 的增长方向，但 2026 EPYC 基数 16.5B 是研究拆分而非官方披露。2026 全年统一工作连接点约 49.8B，分配为 EPYC 16.5、GPU 13.4、网络 0.7、Client 12.4、Gaming 2.8、Embedded 4.0B；仅为当年尚未结束的可比桥接。若已披露 H1 加未来两季不支持该连接点，须一并修改未来基数，不能把研究拆分包装成真实销量。

**乐观／超预期：** 新代 GPU 2027/2029 达 110/240 万颗，多云与实验室连续复购，EPYC 的企业、通用云和独立执行需求共同扩大。HBM 与制造成本更高，仍依靠较强组合和净价获得更好利润；研发、支持、营运资本与自有设备投入同步提高。

**突破／非线性：** 保持乐观级核心底盘，进一步实现跨模型的软件复用、机架级协同、年度产品复制与独立代理 CPU 放量；2029 新代 GPU 350 万颗、EPYC 68B。专用推理与模型协同的收益只体现在平台销量、净价、网络内容或效率里，不独立重复增加未验证服务收入。最少必要条件是：至少三类大买方跨代复购；新工作负载无需每次大规模定制；供给和电力达到附录门槛；客户无需持续靠 AMD 融资才能采购；每股现金改善能够超过新增权益让渡。任何一项不成立，应退回较低路径，并保留已经发生的研发、收购与退出成本。

### 3.2 利润至现金流：口径、税和资本一致

每年先计算各产品收入及直接毛利，再减集团现金口径经营费用和净租赁/信用支持负担。CPU、Client、Gaming、Embedded 和网络的直接毛利率是研究假设，不等于财报分部利润率；所有共用研发与集团费用只扣一次。正式完整参数、量价及各年现金桥见附录 A、B。

本次模型的定义为：

`现金 EBIT = 分业务直接毛利 − 现金口径研发/销售/集团费用 − 净租赁与支持负担`

`现金 NOPAT = 现金 EBIT × (1 − 现金税率)`

`利息后 FCF = (现金 EBIT − 现金利息) × (1 − 税率) + 非并购 D&A − 现金 CapEx − ΔNWC − L`

L 是未进入 CFO/现金 CapEx 的融资租赁资本付现准备，2027—2029 基准为 0.35/0.50/0.65B；这是 A，不是已披露本金。经营租金已在费用中，不再全额扣合同总值；模型对未明确归类租约留出额外资本付款，避免缺失即填零。历史并购无形资产摊销未进入未来现金费用，因此不会再加回一次。现金利息不含臆测的未来股权投资收益，现金留存也没有额外资本化证券浮盈。

税率使用悲观/基准 15%、乐观 16%、突破 17%；不同于 Q3 公司 13% 的非 GAAP 税指引。2025 不确定税项释放、研发抵扣及 NOL 不被永久重复使用；递延税资产不是当期可用现金。未取得逐国未来应税利润与可用税盾排期，故不伪造精确税盾消耗表。基准税率每升 2 个百分点，2029 FCF 约少 0.81B。

营运资本不是收入增长的免费配套。基准 2027/2028/2029 增量 NWC 为 8/5/4.5B，现金 CapEx 为 4/5/6B；突破分别为 16/17/20B 与 7/10/14B。后者虽是 fabless，也需设备、开发基础设施、测试与自有投入；外部晶圆/HBM/ODM 资产代价已进入购货成本与预付占资，不能再把客户整座工厂的 CapEx 扣成 AMD 自己的投入。

### 3.3 SBC 与每股归属：明确选择显式稀释法

### 5.2 固定 30 倍的 business_price：先去除当前低分母失真

统一公式为：

`business_price = [30 × 2029现金NOPAT + 目标日可分配净现金] / 目标日期末完全稀释股数`

`可分配净现金 = 现金及短期证券 − 有息债本金 − 必要经营现金`

必要经营现金分别为悲观/基准/乐观/突破 6/8/10/12B，不是再扣一遍 NWC；它是必须留在企业维持经营的流动性底座。公式已计入此前的再投资、战略支出、到期偿债和股票分配，不靠目标倍数去掩盖现金缺口。

选择 M_norm＝30 的依据是：作为已有高质量 CPU 利润池、仍有长期平台增长能力的 fabless 企业，给出高于单纯稳态零增长资产、低于当前转型低分母倍数的统一参考。它是本次估值假设，不是声称行业统计中位数恰好 30，也未继承同业评级。以 10.5% 资本成本、约 32% 增量 ROIC 做现金检查，若观察日后仅增长五年便回落到 3.5%，支撑不了 30 倍；若约 20% 的增长延续约十年，则接近该参考。本次正把这种持续期要求公开，而非将“合理倍数”当无条件常数。

正常化锚和现价须进一步拆开。以 Q2 现金经营利润 3.094B、统一 15% 税率年化，NOPAT 约 10.52B；用约 1.660B 稀释股和 6 月净现金扣 8B 经营留存，现价对应现金 EV/NOPAT 约 **80x**。这只是低基数季度运行率代理，不能混称 2027 一致预期倍数。因为分母处在放量与投入转换期且超过 50x，本次按方案改用 30 倍；若机械维持约 80 倍，基准 business_price 会被抬到约 1,476 美元，失去有用的比较意义。

30 倍作用于当前同口径运行率，只得到约 **191 美元的正常化起点**。因此“目标 business_price 相对 507.93 的涨跌”包含起始估值正常化的影响，不能口头全部说成业务衰退或增长本身。更准确的三段是：现价到正常化起点、业务和股本从起点增长、最后再叠加目标日市场倍数。基准业务从约 191 走到约 572 美元，接近三倍；相对实际较高买价的业务参考回报却仅约 13%。这解释了“收入大增”与“普通股回报有限”可以同时成立。

### 5.3 目标交易倍数及倍数贡献

2029 悲观保有约 23.25B 净现金，其中留 6B 经营底座，可分配部分约 9.61 美元/股。作为并购/重建收益参照，若只承认 CPU/Embedded 等成熟底盘 6—8B 正常化 NOPAT、采用 12—16 倍资本化，企业经营值为 72—128B，加同一可分配净现金后约 **50—81 美元/股**。这是 I/A 的买方承受能力带，不是已经获得行业收购报价，也不是把历史研发支出逐美元当资产。x86 许可、国家安全审查、客户关系和系统软件难以自由拆卖，因此无法核实一个法律可执行的“保底收购价”。

### 5.6 证据等级与商业可实现性分开

悲观为 **weak**：当前 CPU 和 GPU 采用稳健，全面失速是用来检验底线的压力路径；Gaming 的已发生衰退不足以使公司级悲观评为 strong。基准为 **medium**：现有 CPU 可信，决定性公司增量却依赖 Helios 新代大规模交付和资金回收，尚未跨期锁定；没有因为“AMD 是龙头”就忽略增量验证门槛。乐观为 **medium**：初始约束采购、真实生产使用及多客户工程提供可定位证据，数量与净价仍有较大条件性。突破为 **weak**：需要软件、资源、客户付费与跨代复制数步同时成功。

没有机械把四种情景全部塞进 medium，也没有为凑齐四个标签而把尚待验证的商业路径抬为 strong 或降为 insufficient。当前资料不足以将公司级大规模 AI 放量评 strong，但突破并未与已知物理极限发生硬冲突，故不用 insufficient。其商业可行性是“有机制、需里程碑、容量和资本门槛高”，与纯幻想不同；weak 也不等于先验概率很小，更不等于可以直接凭高目标价买入。

## 6. 当前投资决策与动态验证

### 6.1 现价隐含要求

若要求约 10.5% 年回报，507.93 美元到目标日需约 **699 美元**，已高于本次基准市场上沿约 662 美元。在基准目标净现金与股数下，若仍按 30 倍现金 NOPAT，需目标 NOPAT 约 **43B**，比本次基准约 34.9B 高约四分之一；保持基准直接毛利结构和费用时，大致需要再增加约 **14—23B** 收入，具体取决于高毛利 CPU 与 GPU 的组合，或明显提高净价/现金利润率。这里是反向要求，不是将其重新写回预测。

不要求持有回报、只把现价平移到 2029，看起来还低于基准 business_price；加入三年多时间成本，现价就更接近**基准高端至乐观边缘的定价**。这不是说市场已完整按 276.5B 的突破收入定价，而是说已经支付了对基准之外持续增长的预期。基准现金流增长很强，仍不等于股东能在今天价格获得同样强的回报。

### 6.2 当前动作、仓位属性和等待代价

**动作：以小仓位参与产品验证，核心资金等待更好的价格或现金证据。** 对能够承受单股大回撤、希望保留平台上行敞口的组合，以约 0.5% 初始验证仓作风险预算示例；尚未跨过两次财报与连续客户批次之前，不以突破情景为由超过约 1%—1.5%。这属于高成长、产品与资本兑现驱动的仓位，不能承担现金牛核心底仓角色。已有较大仓位应先核对承受能力和共同 AI 客户风险，不因单日下跌直接加满。

理由是双向的：真实采用、CPU 盈利与客户工程投入使它具有参与价值；基准年化回报约 2%—9%、悲观可能损失约八成、DCF 持续期差异与未知信用责任，使当前价格缺乏重仓所需的保护。乐观目标约为买价的 1.9—2.3 倍、突破约 3.0—3.6 倍，但较高倍数和利润都需验证。没有赋予主观概率后再宣称正期望；小仓位表达的是有限成本保留上行，而不是证明所有投资者都应承担该风险。

价格触发与基本面条件配套：

- **360—420 美元：** 若 CPU、交付和现金逻辑保持，本次基准交易区间对应更好的持有回报，可考虑将验证仓逐步提高；在 400 美元买入，基准目标年化约 10%—17%。价格进入此区间若伴随永久受损，不能机械加仓。
- **约 500 美元附近：** 保留小仓位，等连续交付、毛利与回款；不把一天回撤当作估值已便宜。
- **约 600—650 美元或更高：** 若模型未上调，基准上行被大量消耗，暂停加仓；若新增事实把路径推向乐观、对应新基准目标至少约 850—950 美元，再按更高买价重算，可以接受确认后付出更高价格。
- **退出/减仓触发：** 多季无法交付、毛利持续落到 54% 以下且无法解释、客户支持显著扩大而终端回款没有同步、公司撤回关键 2027 CPU/DC 目标，或普通股稀释/资金承诺超过本模型边界。届时先下调经营与现金，再谈买价。

等待有实际成本。若未来两季验证后价格从 508 升至 650，而模型仍是原基准，目标 536—662 只剩约 −18% 至 +2%，追入赔率变差；若同时证实乐观路径、目标仍可达 975—1,173，650 买入仍有约 +50% 至 +81% 的三年量级空间。提前小仓位降低踏空成本，确认后加仓则用更高价格交换更低经营不确定性。相反，单纯错过短期涨幅不构成在模型未变时追高的理由。

### B.5 资本投入与 ROIC 的经济检查
