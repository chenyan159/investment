## 2. 当前条件定位与矩阵摘要

> **当前条件定位：** 当前证据指向“**乐观需求与收入动能 + 基准经营利润 + 悲观至基准现金转换和资本强度**”的复合经营定位，最接近纯基准行；当前美国市场主状态为“**宽基风险扩张**”，相邻状态为“**震荡 / 均值回归**”。复合定位 × 当前市场状态的条件建议为 **谨慎建议投资**，经营性企业价值约 **$2.81–3.46T**、稀释后股权市值约 **$2.82–3.50T**、每股价值 **$376–472**、目标期总回报 **-3%～+22%**。当前经营证据强度为 **中**（近端需求事实高、长期现金回收中），市场状态证据强度为 **中**，估值置信度为 **中**。相邻震荡状态下为 **不建议投资**，每股价值 $322–414、回报 -17%～+7%；最小增强条件是 Cloud 毛利率在 64%–65%止跌且 FCF 年化回到 $50B 以上，最小减弱条件是容量释放后 Azure 增速低于 30%或 Cloud 毛利率跌破 62%。概率层为 **NA**，因为缺少可辩护的经营 × 市场联合概率。

## 3. 核心投资逻辑与最强反证

### 3.1 最强正面逻辑

微软同时控制企业身份、办公、代码、数据平台和全球云基础设施。FY2026 Q3 Azure 增长 40%，AI 业务年化收入运行率超过 $37B、同比增长 123%，Commercial RPO 达 $627B；约 25%预计在未来 12 个月确认。M365 Copilot 已超过 2,000 万付费席位，Fabric、Foundry、GitHub、Security 和 Dynamics agents 可把低毛利算力收入向高毛利软件、数据和治理收入传导。若每季约 1GW 新增容量按期上线并保持高利用率，分发与交叉销售能够让收入增长留下来。

### 3.2 最强负面逻辑

公司正在以成熟软件企业从未经历过的速度增加短寿命资产和租赁义务。FY2026 Q3 capex 为 $31.9B，Q4 指引超过 $40B，管理层给出的 CY2026 capex 约 $190B；Microsoft Cloud 毛利率从五季前的 69%降至 Q3 的 66%，Q4 指引约 64%。即使收入保持双位数增长，折旧、电力、租赁、GPU 代际淘汰和组件价格仍可能让 FCF 长期低于传统软件时期。OpenAI 在 FY2026 Q2 约占 RPO 的 45%，且现协议允许其使用其他云，进一步放大容量利用率和合同节奏风险。

### 3.3 决定胜负的变量

决定胜负的不是“AI 收入是否存在”，而是：

**可计费 AI 收入 / active MW × 软件与数据 attach − 折旧、租赁、电力和代际淘汰成本。**

若 Azure、M365/GitHub Copilot、Fabric/Foundry 的高毛利 attach 令 Cloud 毛利率在约 64%附近止跌，当前复合定位可上移；若收入继续增长但 Cloud 毛利率跌破 62%、FCF 低于 $30B，股东价值路径会下移到悲观行。

### 4.2 反向倍数要求

以纯基准情景 NTM 经营利润 $165–176B、18%标准化现金税率计算，NOPAT 约 $135–144B。当前隐含经营性企业价值对应：

- **EV / NTM NOPAT 约 19.6–21.2 倍**；
- 调整后净利润 $137–146B 对应 **NTM 调整后 P/E 约 19.9–21.3 倍**；
- 这大体处于“基准 × 震荡”倍数区间上部与“基准 × 宽基扩张”区间下部之间。

因此当前价格不要求突破情景，但要求至少接近基准收入与利润路径，并要求 3–5 年现金转换显著恢复。

## 5. 经营四情景与当前复合定位

### 5.1 共同驱动与口径

四条纯经营路径都由同一组驱动构成：

1. Azure / Server cloud 的可部署容量、利用率与收入确认；
2. M365、GitHub、Fabric/Foundry、Dynamics 和 Security 的付费采用与软件 attach；
3. Microsoft Cloud 毛利率、经营费用纪律和自研芯片/运行时效率；
4. 现金 capex、营运资本、租赁和 FCF；
5. OpenAI 集中度、合同兑现和股权价值；
6. 股份回购、SBC 和完全稀释股数。

AI ARR、Commercial RPO、Azure、M365 Copilot、Fabric/Foundry 与 GitHub 存在重叠，任何情景都不把它们横向相加。

### 5.5 当前复合经营定位

当前不能强塞进单一纯行：需求和收入已出现部分乐观证据，经营利润更接近基准，而 FCF和资本强度落在悲观至基准之间。这些变量都足以改变股东价值，因此采用：

**乐观需求与收入动能 + 基准经营利润 + 悲观至基准现金转换。**

相互一致的复合模型为：

| 复合模型输入 | 区间 |

| NTM 收入 | $382–395B |
| 毛利率 | 64.5%～66.0% |
| 经营利润率 / 经营利润 | 43.0%～45.0% / $164–176B |
| NOPAT | $134–144B |
| 调整后净利润 | $136–147B |
| FCF | $25–45B |
| 目标期净非经营桥 | +$5–45B |
| 稀释股数 | 7.42–7.50B |

最小上移变化：Cloud GM 在 64%～65%止跌、Azure仍 35%+且 FCF 年化超过 $50B。最小下移变化：Cloud GM <62%、FCF < $30B或容量释放后 Azure <30%。当收入、利润和现金三者重新落入同一纯行时，复合状态结束。

### 6.2 两棵不能简单相加的事件树

**容量树：**

项目建设 / 租赁签约 → 电力与冷却可用 → GPU/网络到货 → production acceptance → 可计费利用率 → Azure收入 → 软件 attach → 毛利和 FCF。

只有最后三步同时成立，容量事件才是股东价值利好。若项目只完成建设但没有高利用率，事件先增加租赁、折旧和电力成本，反而把公司推向“悲观 × 风险收缩”。

**Copilot / Agent树：**

合同席位 → 活跃使用 → 工作流深度 → 续费/扩席 → credits与安全治理 attach → 推理成本下降 → 高毛利净收入。

付费席位、AI ARR和 Azure消费可能来自同一客户链，不能各加一次价值。

## 8. 多估值理念、资本桥与模型分歧

### 8.1 方法选择

| 方法 | 本报告用途 | 为什么适用 / 限制 |

### 12.2 全矩阵形状

本矩阵可同时标记为：

- **条件正面区域**：只有乐观经营或突破经营，或基准经营叠加风险扩张时，才出现正面建议；
- **市场状态敏感**：同一基准经营从主题上涨的 +3%～+30%，可降到信用压力的 -41%～-20%；
- **经营兑现敏感**：同一宽基扩张状态从悲观行 -28%～-9%，可升到乐观行 +26%～+58%；
- **部分突破价值集中**：当前价格不要求突破，但广泛高回报主要集中在乐观与突破两行。

建议最稳定的区域：

- 悲观行在所有市场列都稳定为强烈不建议；
- 乐观 × 宽基/主题与突破 × 非信用压力均是稳定正面区；
- 基准行不是稳定正面区，结论高度依赖市场列和买入价。

最脆弱边界是 **基准 × 宽基扩张 → 基准 × 震荡**：经营不变，仅估值状态下降一列，建议从谨慎建议转为不建议。

最坏格子是 **悲观 × 流动性/信用压力**：每股 $154–219，总回报 -60%～-43%。损失来自三项同向作用：经营利润/FCF受损、租赁与资本承诺优先级上升、EV/NOPAT降至 10–13x；并非只做倍数压缩。
