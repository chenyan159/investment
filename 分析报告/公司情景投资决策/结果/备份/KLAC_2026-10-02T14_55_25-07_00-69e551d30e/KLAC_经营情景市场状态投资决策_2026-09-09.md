研究日期：2026-09-09。信息截止：**2026-09-08 23:59 美国东部夏令时（EDT）**；价格基准为同日常规交易收盘 **188.98 美元**。本报告评价从该买价新建仓并持有的经济吸引力，未假设读者已经持仓。

## 一、当前判断、研究时点与重要分歧

**当前取舍：短期不建议投资；中期不建议投资；长期按现金回报与可验证复利标准不建议投资。** 主要原因是价格相对于本研究可支持的现金权益偏高，而不是判定 KLA 的技术领先已经丧失。已有客户扩产、先进封装增长和装机服务支持经营继续增长；真正没有被证据充分解决的是，2030 年以后的高增长持续期能否长到足以支撑现价。

需要保留的最强相反观点是：KLA 是跨代更新的平台，2030 年之后仍可能增长十多年，或市场长期采用高于现金模型的前瞻倍数。下文把这两件事分别做成连续经营替代路径和交易定价算例，不能把它们混成同一个“目标价”。**报告中的低现金价值不是预测股价将在六个月内跌到该数值。**

量价的独立约束示例：2027晶圆池从6.95增至8.25，增长18.7%。一组相容驱动为合格处理负荷+14%、需检查任务+10%、吞吐效率+10%、净配置价+4%、合格份额/新用途+0.1%，合成约18.7%；这是工作假设分解，不是五个已经观察的事实。较弱组合（负荷+10%、任务+6%、效率+10%、净价+2%）只支持约8%，会使晶圆池比基准少约0.74十亿美元。Patterning增长26.2%另需新设计、掩膜及新参数量测，不能重复套晶圆量增速。若新节点爬坡强、成熟工艺和中国偏弱，可以同时成立。

预算交叉检验：KLA 7月将包含先进封装的CY2026设备市场预期提高到150十亿美元出头，是管理层预测。基准2026两个前道池加封装11.1，相当于该预算约7.3%；2030对应18.45，相当于投资者日215十亿美元行业工作目标的8.6%。这要求内容量提升但未超出管理层约9%的方向；**行业预测和公司预测同源部分只算一次证据**。突破2030对应29.6，在215行业预算下占13.8%，需要行业设备预算约270—300、且KLA系统强度约9.9%—11.0%，或更极端的份额/内容量提升。因此突破不能被描述为“行业保持常态、一个新产品成功”就能达到。[S2][S4]

同口径量价未公开，所以模型六池点值是预算、技术任务和交付能力约束下的推断。分部毛利和研发分摊是计算假设，不是公司披露。服务毛利假设高于混合系统，以反映公司所说较有利服务组合；没有沿用“软件零成本、服务全是增量利润”的解释。

### 4.5 现价反求与主要脆弱环节

在一年目标采用12%持有要求，含股息后退出每股需约210.7美元；相对基准目标NTM EPS，要求约35倍以上持续前瞻PE。三年10%要求，含股息前退出价格需约248.3美元；若按2030目标附近的本研究NTM利润，则要求约33倍前瞻PE，而主现金价值所表达的是之后增长正常化。相同现价可以由更高利润、较长增长或较低风险溢价共同支持，反求不是市场真实共识。

最弱价值传导环节依次是：长期增长持续期及退出定价；备货/客户应收到现金的转换；新技术从资格到重复采购；高价回购对每股价值的影响。现金证券毛额折合每股仅约3.7美元、债务高于现金，不能形成188.98买价的资产安全垫。高毛利不是清算底价。

def capital(qs,s,t):

        price=[160,190,210,230][NAMES.index(s)]*(1+[.02,.08,.10,.12][NAMES.index(s)])**max(0,q['year']-2026)
        cash+=cf-dividend-buy;shares-=buy/price;buys+=buy;comp+=q['sbc']*f
        # The pre-purchase September 1 dividend is not investor income; future dates use actual quarterly schedule approximation.
        if T0<pay<=t:divps+=annualdiv/4
    if t>=dt.date(2029,3,15):cash-=.8;debt-=.8

    # Distinct product-generation runoffs; no failed-path resurrection or separate option premium.

    tvpv=tv/(1+r)**((dt.date(2036,12,31)-t).days/365.25)
    ev+=tvpv;eq=ev+cap['cash']-cap['debt'];price=eq/cap['shares']
    h=(t-T0).days/365.25;ret=(price+cap['div'])/P0-1
    ntmend=t.replace(year=t.year+1)
    return dict(price=price,eq=eq,ev=ev,ret=ret,ann=(1+ret)**(1/h)-1 if h>0 else None,tvshare=tvpv/ev,cap=cap,ntmrev=total(qs,'rev',t,ntmend),ntmni=total(qs,'ni',t,ntmend),ntmfcff=total(qs,'fcff',t,ntmend),r=r,g=g,roic=roic)
