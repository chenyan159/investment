## 一、当前选择与研究时点

**当前证据最支持“先进计算增长、传统产品拖累、盈利与现金逐步修复”的基准方向，尚不足以支持公司已经成为持续高回报的 AI 电源平台。25.51 美元对普通修复并不便宜。按下述参考投资标准，3个月、6个月、12个月和36个月均不建议现在买入；能承受较大损失的技术突破投资者，也尚没有可辨认的定价优势。** 后一个判断来自必要的联合成功规模和证据不足，不是把稳健投资者的零亏损要求套给高风险投资。

**重要理念分歧。** 周期修复交易可能在长期现金能力还未证实时上涨；本报告不否认这条路径，但尚未识别足以把它从“可能”提升为当前优势的预期差与价格采纳证据。资产安全边际论点不成立：低于账面净资产并不等于低于可实现资产。高风险突破论点保留：条件突破价值很大；本报告定义的800V独立成功规模仍不足以支持现价所需回报，但更大的单一机会规模，或者核心份额与利润持续性共同改善，均可能改变选择。第六节分别重算单一机会扩至两倍、三倍以及联合改善的结果，不将一个偏小算例作为整个机会的上限；同时比较立即参与和等待，不把“不买”自动写成“等财报更好”。

## 二、公司全貌、决定性证据与独立经营判断

### 2.1 收入权利、制造边界与真正的客户

AOSL销售功率分立器件、功率IC及少量封测服务。整机OEM、ODM、模块厂定义资格，分销商承担大量采购与物流，最终使用者支付计算、手机或工业设备预算。**设计采用、采购订单、发货、确认收入和回款是五个不同环节。** FY2026两家分销商占收入72.3%；客户名单不是某一AI平台的采购金额。大部分订单可以取消、变更或延期，未获得可复核的长期不可撤销backlog。收入通常按控制权转移确认，并估计价格补差与库存轮换；不能用目录ASP直接乘渠道发货就认定终端实现价。[原文：Business、收入政策及客户风险][S01]

集团经营Oregon晶圆厂和中国封测设施，同时使用第三方代工。重庆JV仅持股18.9%，权益法核算且不并表；它既是投资又是重要供应商。月度晶圆能力保证是供应合同，不是AOSL对JV债务的财务担保，也不表示所有工艺和客户资格均可通用。Kaynes印度封测是合作方设施，不能把工厂全部产能、收入或资本开支归属于AOSL。供应商预付款、押金和贷款说明外包也需要资本。[原文：附注1、2、6、15；本地公司输入I01][S01]

一个会计分部掩盖了多种经济驱动。下表的业务可相加；“分立器件/Power IC”是另一交叉分类，不与终端分类相加。

本研究把先进计算作为一个收入约束池，并在池内分别检验中压器件与核心控制/功率级。公司没有披露两者金额，不能给各自“已实现收入”或净利润。模型可复核范围是：FY2029基准先进计算285M中，中压/IBC约35%—55%，控制/功率级及其他约45%—65%；两端配对合计100%。如果中压被架构替代、控制器又不能提高附着率，应整体下调该池，不能在另一个未披露子项中补回收入。这是分配约束E，不是隐藏的公司分部数据。

**证据偏向的裁决：**“AI尚无商业贡献”已经不成立；“增长会自然变成高利润和高现金”也不成立。更可信的是先有局部份额和产品组合改善，随后经历制造及研发杠杆验证。影响当前选择的最大未知是第二步能否持续，而不是公司能否发布更多产品。

9月8日αMOS E2新品具有顶部散热封装，目标涵盖服务器、工作站、通信整流及工业等；目录价分别6与3美元，公告交期16周。它支持硅器件持续迭代和电源/工业收入不被宽禁带材料一次性淘汰的解释，但没有客户订单金额，不额外创造一条独立收入曲线。数千万美元收入仍需数百万至千万器件，并经历客户资格、折扣及替代旧品。[S04]

### 2.5 新机会、持续性与覆盖边界

**H＝800V相关新材料/新转换方案的净新增收入。** 既有48V和已经销售的控制/功率级仍属核心；H只计算新的高压/宽禁带及相关方案扣替代后的增量。AOS可凭工艺、保护和封装进入电源ODM，再取得平台资格；多级与直降路线互斥的部分已在“净收入”内处理，不把Si、SiC、GaN各自满额相加。进入前要付研发、样品、可靠性、工艺转移成本，进入后也必须扩合格能力。对客户的价值来自可用功率、热管理、密度和故障控制，不等于芯片厂能收走客户全部节电价值。

**G＝下一代主机的净新增周期。** 有原有客户接触和功率产品基础，比完全陌生市场更接近采用；但管理层给的是2028年以后更明显影响的时间判断，没有最低购买量。部分成功与规模成功各有净增收入、支持费用和投入，2031年前后到平台高峰，之后衰减；不会与H共用永久高增长终值。[原文：Consumer讨论][S06]

**更远的模块/基板集成、垂直供电机会。** AOS的AmpStack是MOSFET堆叠，不等同处理器垂直供电平台。要获取新经济权利，可能需要与磁件/基板/封装厂合作、取得接口资格，或收购设计团队；这些都可能花费数千万至上亿美元，股东并未自动拥有整套系统收费权。本次查阅年报、公司新品、NVIDIA伙伴页、TI及竞争者技术线索，仍没有AOS独立模块平台的量产客户与收费条款。可以保留“年收入100—300M、税后利润10—45M、前期新增投入40—120M”的条件探索包络，但它不是可可靠赋权的现有项目NPV，不加入主格。三年内若出现合作经济条款、两代产品采用及实际模块毛利，应重新打开覆盖范围；本报告不能据未计值断言所有五至十年远期机会均无价值。

SiC重复许可、剩余JV出售与公司被收购是其他离散事件。已经履约的旧许可不能成为永久版税；没有新合同便不恢复许可收入。JV出售可改变现金形态与税费，不能同时保留全部投资价值并加出售款。没有受约束收购报价，不给公司收购溢价或发生概率。印度量产与αMOS E2按原有工业/供给池处理，避免把地点或产品名当作另一整个市场。

### 3.3 报告现金流、股东经济成本与资本桥

模型同时保留两种现金口径：

`报告CFO代理＝GAAP经营利润−现金税+DA+SBC−Δ经营营运资本`；

`简单报告FCF＝上述CFO−全部现金CapEx`；

`估值现金流＝简单报告FCF−新增奖励的现金等效成本−供应商净资金占用`。

“代理”表示预测中未另设汇兑、其他非经常损益和递延税流量，历史CFO仍使用公司实际报表，不能混称二者完全相同。现金税在核心亏损年保留4—4.8M，不假定美国、中国等辖区的亏损可以即时互抵；机会在各状态内按正经营利润的20%计算税、亏损不立即获现金退税，避免先平均利润造成免费税盾。20%是中期税假设，非管理层指引。

存量未归属TRSU/PRSU/MSU分别为1.628969/0.448438/1.037M，合计3.114407M。主模型将其全部预留，**经济完全稀释股数33.367407M**；不把它冒充当日流通股或GAAP加权平均股。存量奖励未确认费用41.9M按未来三财年22/16/3.9M加回估值现金，使同一旧奖励仅通过股数收费一次。未来SBC超出这部分的成本，以现金报酬或等额抵消发行的现金成本处理。因此主路径净股数保持不变，但现金减少；这是一条明确的经济等效资本路径，不是公司承诺回购。若实际留现金而发更多股，必须同步提高股数，第六节列出等效偏差范围。亏损不意味着人才成本消失，8月降低奖励门槛又削弱了“不会发行”的论点。[原文：附注10][S01]

增长行不会因为账面SBC较低而自动提高估值：主模型未来SBC随能力与人员规模增长；现金替代部分作为股东成本。取消全部3.114M预留、其他不变仅能提高每股价值约10.3%，而非数倍；已授奖励的费用冲回与是否最后归属仍需分别研究。

### 3.4 H/G逐年状态、概率和现金

四个状态：U＝仍在工程/商业化准备；P＝有限采用；S＝达到本年所定义的规模状态；F＝退出该机会。P可以有销售但未达到规模；S是当年仍在商业成功状态，**不是“截至当年曾经成功”**。F吸收，不会第二年无条件复活；S可以退回P或退出。两个机会都有各自状态，不能把主机采用当成800V采用。

### 4.3 估值逻辑、生命周期及资本勾稽

主方法是目标日剩余经营现金流折现，加可归属非经营资产和多余现金，扣有息债务，除经济完全稀释股数。采用它是因为当前亏损、毛利修复慢且有较大研发与制造投入，现期PE和市销倍数会漏掉决定性资本成本。**主矩阵表示条件合理价值，不是目标交易价。**

`股权价值_T＝经营DCF_T＋max(现金_T−60,0)＋JV净值_T−4.9`；

`每股价值_T＝股权价值_T/完全稀释股数_T`；

`总回报＝每股价值_T/25.51−1`。

不假设分红；留存现金只进期末一次，现金分配再投资为NA。期限一年累计和年化相同，三年年化按三次方根计算。目标日前已经产生的FCF只进入现金桥；目标日之后未发生的部分才折现，季度跨日按实际天数拆分。未来税、研发、全部CapEx、周转、供应商资金及新增薪酬均已扣；H/G的成功价值不再另加“期权价值”。

折现率四行统一11.5%—13.5%，属于USD经营资本对系统性和流动性风险的工作补偿；不是按某一行的失败概率再扣一次。12.5%仅为复算中枢，不宣称市场正确资本成本。改变投资者要求回报不改变公司经营预测。使用更高系统性补偿的15%压力另列。

### 4.4 现价要求与可裁决的价值分歧

按经济稀释口径，现价对应的经营价值要求高于用30.26M基本股、全部现金和JV账面值计算的“便宜EV”。以基准研究日现金桥、95M JV工作值及60M经营现金核定，隐含经营价值约**647.6M**。一个价格不能唯一识别增长、份额与寿命；下列是相容的反求门槛，不能称作真实市场共识。

1. **现金回报要求。** 若以后无增长、可持续现金收益率8%—10%，该经营值需要约51.8—64.8M年度股东经营现金；基准FY2029估值现金仅约1M，FY2031约39M。现价支付了较远的改善，而非只支付FY2027不再恶化。
2. **正常化盈利要求。** 以20—25倍可持续税后经营利润表达同一经营值，大致需要25.9—32.4M利润；这种倍数要求可持续增长与相应资本回报，不能套用非GAAP EPS。若下一阶段集团销售约850M、总费用约220M，仅形成上述利润就需约30%—31%甚至更高的毛利，明显高于当前23.8%指引；费用/税口径不同会改变门槛。
3. **三年投资标准。** 15%年化需要三年后38.80美元；20%高风险参考需44.08美元。基准上沿24.86美元不够。800V单独按定义完整成功、核心普通、主机沿主路径时，上沿也只有33.23美元；不能把“800V成功”当成足够的整股收益论点。
4. **更高利润还是更长寿命。** 乐观三年35.10—63.35美元，低端年化仅约11%，高端约35%；相同前三年经营可以因剩余寿命得到不同选择。突破65.43—126.59美元则有较厚条件优势，但其规模和份额要求远高于当前证据。

对资产论点另做不与DCF相加的收缩/清算检验：现金180.8M、应收回收约38M、库存回收100—150M、厂房设备100—190M、JV35—115M、供应商等资产回收10—25M，减全部账面负债约165.7M、关闭及其他处置税费50—90M（不再次扣JV估值已含税费），对完全稀释普通股约**6.2—17.5美元**。这些回收率均为E，专利买家、跨境审批及资产处置时点尚未验证；净资产账面26.37美元不是清算价。主悲观DCF低于此算例，是因为主路径继续经营并消耗资本，资产退出是另一管理行动。不存在公开约束性出售或强制分配催化剂，不能把清算上限当短期交易底价。

可让选择改变的最少新增证据组合是：先进计算季度收入持续超过约45—50M并提高，而非一次渠道备货；集团毛利进入26%—28%且费用不按同速增加；成品库存与CFO支持终端转化。它足以提高乐观路径权重，却还不足以解决十年利润持续性。要支持三年稳健复利，进一步需要至少两代平台复购、可核实功率级附着与正常化资本回报。800V仅增加新伙伴或演示板，不够。

### 6.4 高风险突破理念：不偷换整体概率

四条主情景不是互斥穷尽事件，不能给它们随意加权成“胜率”。为观察20%年化标准，用一个独立的、覆盖全部结果的二分事件：A＝到三年时跨客户的高性能电源捕获与持续盈利得到足够确认；非A＝没有同时做到。这里不是H的局部成功，也不是“四行中的乐观”概率。A内仍有普通乐观、巨大突破及融资被分走收益；非A也包括普通修复、延期、受损和其他未列情形。

若只用AOS最有解释力的“乐观平台”作为A的代表，三年持续更新工作值约53.84美元；普通基准工作值约21.70美元。20%年化对应44.08美元，所需A概率约**69.6%**；若非A包括更深损伤，门槛更高。若把A改成巨大突破而使用更高成功价格，所需概率会降低，但事件也更严格，不能沿用较宽A的可信程度。

当前事实证明平台机会存在，尚没有证明维持该联合规模/持续性的频率。若必须给用于决策的主观工作范围，本报告只支持宽泛的**25%—45%**作为“达到普通乐观等级且资本传导未明显受损”的探索区间：支持因素是已有收入、连续导入与制造投入；压低因素是GAAP和现金尚未转正、PC抵消、无客户BOM、强二供竞争及奖励稀释。没有可复核样本校准，不能把45%当严谨概率上界。即使用成功63.35和未成功24.86两个有利端点，达到44.08仍需约50%的概率；用更接近工作值或包含受损的失败代价，要求更高。

因此，高风险资金当前也**暂不参与，理由是未辨认出风险补偿优势，而非已经证明所有技术期权为负值**。最强相反选择是少量投入押巨大突破：其条件价值确实支持高回报，但需要对更严格联合事件建立独立概率依据，目前没有。若投资者拥有可靠客户资格/份额信息，或者仅要求12%年化且愿意承担大额永久损失，结论可以不同；不能把偏好改变写成经营更好。H单独成功的参照已经排除了“只要800V成功就一定够”的简化论点。

### 6.5 立即参与与等待：相同资金、原目标日

以2029-09-09为共同终点、25.51美元初始资金、现金年回报4%作算例；等待到2026-12-09，现金约25.76美元。假设这一观察出现可区分的正面、负面或模糊结果，双方都能看到相同信息；为便于比较，先比较立即买入持有与等待后买入/保留现金。若允许立即买入者在节点卖出，必须承认它可同样纠错，等待优势会缩小。

**结论是当前不参与更符合所采用的基本面现金回报标准；未证明“等一季再买”具有普遍策略优势。** 可以跟踪最早有辨别力的节点，但不能承诺它会解决长期未知或给出更低成交价。普通基准的价值不足支持现在买入，这一判断不需要把等待包装成必胜；若后来证据达到乐观/突破要求，应沿同一模型重新定价，接受错过最初上涨的代价。

MULT={'悲观':.65,'基准':1,'乐观':1.25,'突破':1.6}

def transition(o,s,t):
    # Four states U,P,S,F. Failure is absorbing; commercial success can decay.
    speed={'悲观':.6,'基准':1,'乐观':1.3,'突破':1.55}[s]
    if o=='H':
        if t==0: up,us,uf,ps,pf,sp,sf=.08,0,.03,0,.05,0,.03
        elif t==1: up,us,uf,ps,pf,sp,sf=.24,0,.06,.16,.06,.03,.04
        else: up,us,uf,ps,pf,sp,sf=.25,.04,.09,.27,.07,.035,.04
    else:
        if t==0: up,us,uf,ps,pf,sp,sf=.06,0,.03,0,.03,0,.02
        elif t==1: up,us,uf,ps,pf,sp,sf=.30,.03,.05,.30,.05,.02,.03
        elif t<5: up,us,uf,ps,pf,sp,sf=.35,.08,.10,.36,.06,.04,.03
        else: up,us,uf,ps,pf,sp,sf=.10,.02,.20,.10,.12,.15,.10
    up*=speed;us*=speed;ps*=speed
    risk={'悲观':1.5,'基准':1,'乐观':.8,'突破':.65}[s]
    uf*=risk;pf*=risk;sf*=risk
    return [[1-up-us-uf,up,us,uf],[0,1-ps-pf,ps,pf],[0,sp,1-sp-sf,sf],[0,0,0,1]]

def opp(o,s,force=False,delay=0):
    p=[1.,0.,0.,0.]; prevR=0; out=[]
    for t in range(10):
        M=transition(o,s,t);old=p[:]
        p=[sum(old[j]*M[j][k] for j in range(4)) for k in range(4)]
        if force=='fail':
            p=[1,0,0,0] if t<5 else [0,0,0,1]
        elif force:
            # Earliest scale FY2029. Engineering before that still incurs cost.
            p=([1,0,0,0] if t==0 else [0,1,0,0] if t==1 else [0,0,1,0])
        assert abs(sum(p)-1)<1e-9 and min(p)>-1e-9
        assert force or p[3]>=old[3]-1e-9
        factor=MULT[s]; revenues=[0,PART[o][t]*factor,SCALE[o][t]*factor,0]
        if delay and t<delay: revenues=[0]*4
        if o=='H':
            ug=[4,6,7,7,5,4,3,2,2,2][t]
            gm=[0,.29,.38,0];ex=[ug,4+.12*revenues[1],7+.08*revenues[2],0]
            cap=[1.5 if t<5 else .5,1+.10*revenues[1],3+.08*revenues[2],0]
            dep=[.3,.04*revenues[1]+.3,.04*revenues[2]+.6,0];nw=.18
        else:
            ug=[1.5,2.5,2.5,1.5,1,1,.5,.5,.3,.3][t]
            gm=[0,.25,.32,0];ex=[ug,1.5+.08*revenues[1],2.5+.06*revenues[2],0]
            cap=[.3 if t<3 else 0,.3+.03*revenues[1],.5+.03*revenues[2],0]
            dep=[.1,.02*revenues[1]+.1,.02*revenues[2]+.1,0];nw=.14
        failcost=(2 if o=='H' else 1)*max(0,p[3]-old[3])
        gp=sum(p[k]*revenues[k]*gm[k] for k in range(4))
        ebit=[revenues[k]*gm[k]-ex[k] for k in range(4)]
        tax=sum(p[k]*max(ebit[k],0)*.20 for k in range(4))
        rev=sum(p[k]*revenues[k] for k in range(4));cost=sum(p[k]*ex[k] for k in range(4))+failcost
        dnw=nw*(rev-prevR)
        d=sum(p[k]*dep[k] for k in range(4));cp=sum(p[k]*cap[k] for k in range(4))
        out.append(dict(p=p,Rk=revenues,rev=rev,gp=gp,op=cost,ebit=gp-cost,tax=tax,da=d,cap=cp,wc=dnw,fcf=gp-cost-tax+d-cp-dnw))
        prevR=rev
    return out

def build(s,force=None,ordinary=False,gmshift=0,opshift=0,extra_cap=0,oppzero=False):
    ob={o:opp(o,s,'fail' if force=='FAIL' else force==o) for o in OPPS}
    result=[]
    for t in range(10):
        if t<5:
            br=[CORE[s][j][t] for j in range(6)]
            gm=[GM[s][j][t]+gmshift for j in range(6)]
            cop=OPEX[s][t]+opshift;cap=CAP[s][t]+extra_cap;da=DA[s][t];wc=WC[s][t];sbc=SBC[s][t]
        else:
            prev=result[-1];g=TAILG[s][t-5]
            br=[x*(1+g) for x in prev['br']]
            # Mature platforms keep updating; post-2031 gross margin fades modestly.
            gm=[x-.001 for x in prev['gm']]
            cop=prev['cop']*(1+g*.8);sbc=prev['sbc']*(1+g)
            if s=='悲观' and t==5:cop=146 # 12 savings less 4 restructuring cash cost
            if s=='悲观' and t==6:cop=142
            da=prev['cda']*(1+g);cap=da+sum(br)*g*.30
            wc=(sum(br)-sum(prev['br']))*.18
        if ordinary:
            # First two years AI shipment shortfall, recovery thereafter; enduring net price/GM pressure.
            reduction=br[1]*([.15,.12,.06,.03,0,0,0,0,0,0][t])
            br[1]-=reduction
            if t<5:gm=[x-.01 for x in gm]
            cop+=3 if t<2 else 0;wc+=8 if t==0 else -4 if t in (1,2) else 0
        cr=sum(br);cg=sum(a*b for a,b in zip(br,gm));ce=cg-cop
        ct=max(ce*.20,4.8 if t==0 else 4)
        legacy=[22,16,3.9,0,0,0,0,0,0,0][t]
        sup=[5,3,1,0,0,0,0,0,0,0][t]
        x={k:sum(ob[o][t][k] for o in OPPS) for k in ['rev','gp','op','ebit','tax','da','cap','wc','fcf']}
        if oppzero:x={k:0 for k in x}
        rev=cr+x['rev'];gp=cg+x['gp'];op=cop+x['op'];ebit=gp-op;tax=ct+x['tax'];dep=da+x['da'];cx=cap+x['cap'];nwc=wc+x['wc']
        cfo=ebit-tax+dep+sbc-nwc
        reportfcf=cfo-cx
        replacement=sbc-legacy
        fcf=reportfcf-replacement-sup
        result.append(dict(s=s,t=t,fy=2027+t,br=br,gm=gm,cr=cr,cgp=cg,cop=cop,cda=da,rev=rev,gp=gp,op=op,ebit=ebit,tax=tax,da=dep,cap=cx,wc=nwc,sbc=sbc,legacy=legacy,sup=sup,cfo=cfo,rfcf=reportfcf,rep=replacement,fcf=fcf,opp=x,detail={o:ob[o][t] for o in OPPS}))
    return result

def quarters(rows):
    out=[];s=rows[0]['s']
    for r in rows:
        t=r['t'];starts=[date(r['fy']-1,6,30),date(r['fy']-1,9,30),date(r['fy']-1,12,31),date(r['fy'],3,31)]
        ends=[date(r['fy']-1,9,30),date(r['fy']-1,12,31),date(r['fy'],3,31),date(r['fy'],6,30)]
        rv=QREV[s] if t==0 else [r['cr']/4]*4
        # Preserve exact annual sum for modified paths.
        rv=[v*r['cr']/sum(rv) for v in rv]
        if t==0:
            original_gp=sum(CORE[s][j][0]*GM[s][j][0] for j in range(6))
            cg=[QREV[s][i]*QGM[s][i] for i in range(3)];cg.append(original_gp-sum(cg))
            cg=[x*r['cgp']/original_gp for x in cg]
            co=QOP[s][:3]+[OPEX[s][0]-sum(QOP[s][:3])]
            co=[x*r['cop']/OPEX[s][0] for x in co]
        else:cg=[r['cgp']/4]*4;co=[r['cop']/4]*4
        for q in range(4):
            z={k:r[k]/4 for k in ['tax','da','cap','wc','sbc','legacy','sup','rep']}
            z.update(start=starts[q],end=ends[q],fy=r['fy'],q=q+1,rev=rv[q]+r['opp']['rev']/4,gp=cg[q]+r['opp']['gp']/4,op=co[q]+r['opp']['op']/4)
            z['ebit']=z['gp']-z['op'];z['cfo']=z['ebit']-z['tax']+z['da']+z['sbc']-z['wc'];z['rfcf']=z['cfo']-z['cap'];z['fcf']=z['rfcf']-z['rep']-z['sup'];out.append(z)
        for k in ['rev','gp','op','ebit','fcf']:
            assert abs(sum(x[k] for x in out[-4:])-r[k])<1e-8,(s,t,k)
    return out

def fraction(q,T):return min(1,max(0,(T-q['start']).days/(q['end']-q['start']).days))
def bridge(qs,T,raise_gross=0):
    cash=180.771;fund=0;shares=FD
    for q in qs:
        f=fraction(q,T)
        if not f:continue
        # Constant 2% after-tax net cash yield, sensitivity separately. No net debt growth assumed.
        dt=(q['end']-q['start']).days/365.25*f
        cash+=q['fcf']*f+max(cash-4.9,0)*.02*dt
        if raise_gross and q['end']==date(2026,9,30) and f==1:
            cash+=raise_gross*.95;fund+=raise_gross;shares+=raise_gross/10
        if cash<60:
            need=60-cash;cash+=need;fund+=need;shares+=need/10
    return dict(cash=cash,debt=4.9,fund=fund,shares=shares)

def value(rows,T,r=.125,g=.02,roic=.15,jv=95,finite=False,raise_gross=0):
    qs=quarters(rows);b=bridge(qs,T,raise_gross);pv=0
    for q in qs:
        if q['end']>T:
            pv+=q['fcf']*(1-fraction(q,T))/(1+r)**((q['end']-T).days/365.25)
    last=rows[-1]
    # All prior failed branches remain failed. Growth applies to probability-weighted surviving platform cash.
    game=last['detail']['G'] if last['opp']['rev'] else dict(ebit=0,tax=0,fcf=0)
    nopat=max(0,last['ebit']-last['tax']-game['ebit']+game['tax'])
    fnext=nopat*(1+g)*(1-g/roic)
    terminal=fnext/(r-g) if not finite else nopat*sum((.90/(1+r))**k for k in range(1,9))
    runoff=sum(max(0,game['fcf'])*a/(1+r)**k for k,a in enumerate([.7,.4,.1],1))
    tv=(terminal+runoff)/(1+r)**((qs[-1]['end']-T).days/365.25)
    ev=pv+tv
    equity=ev+max(0,b['cash']-60)-b['debt']+jv
    return dict(**b,ev=ev,eq=equity,price=max(0,equity/b['shares']),tv=tv,pv=pv,terminal_pct=tv/ev if ev else None)

def ranges(rows,T,raise_gross=0):
    s=rows[0]['s'];j={'悲观':(35,70),'基准':(75,115),'乐观':(95,140),'突破':(95,140)}[s]
    gs={'悲观':(0,.005),'基准':(.015,.025),'乐观':(.02,.03),'突破':(.02,.03)}[s]
    rc={'悲观':(.10,.12),'基准':(.13,.17),'乐观':(.16,.20),'突破':(.18,.22)}[s]
    low=value(rows,T,r=.135,g=gs[0],roic=rc[0],jv=j[0],raise_gross=raise_gross)
    fade=value(rows,T,r=.135,g=gs[0],roic=rc[0],jv=j[0],finite=True,raise_gross=raise_gross)
    return [min([low,fade],key=lambda x:x['price']),value(rows,T,r=.115,g=gs[1],roic=rc[1],jv=j[1],raise_gross=raise_gross)]

def ntm(rows,T):
    end=date(T.year+1,T.month,T.day);qs=quarters(rows)
    return {k:sum(q[k]*(fraction(q,end)-fraction(q,T)) for q in qs) for k in ['rev','ebit','fcf']}
