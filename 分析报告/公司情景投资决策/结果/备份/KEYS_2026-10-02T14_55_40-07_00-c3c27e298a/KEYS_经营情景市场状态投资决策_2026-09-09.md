# KEYS｜经营情景、价值传导与分期限投资决策

## 1. 当前选择、时点与真正的分歧

**在 333.42 美元买入，短期和一年期的当前判断为“不建议投资”；三年期按可持续现金复利的主标准也为“不建议投资”，但进取型“跨代平台长期扩张”论点存在会翻转选择的真实分歧，当前不能据现有证据认定有明确优势。** 这不是判断公司经营转坏：最新实际增长很强，证据最支持下文基准的持续扩张。问题是当前价格对后续规模和持续期要求高，而股份报酬、正常税率、研发与周转投资限制股东现金增长。下文所有金额、建议和成功参照来自同一模型，四个经营情景不赋整体权重。

| 期限／主要理念 | 当前选择与最强相反解释 | 经营不变时的边界、最少新证据及代价 |
|---|---|---|

Keysight出售从电路设计、精密测量到系统仿真和维护的工程能力。护城河主要是高频模拟前端、校准和可重复测量、跨物理与协议层故障定位，以及客户脚本、夹具、认证和工程师工作流。经济收费权属于具体仪器、通道、端口、能力许可、订阅与服务合同；不享有GPU销售或推理token收入的自动分成。软件与服务跨多个分部，不能再与硬件分部收入相加。

突破FY29有线约5.895，对狭义市场的要求更高，必须出现更广的系统层验证、跨速率/多架构项目与规模扩张；不能只靠1.6T光模块生产线数量解释。按0.5—1.0百万美元的年度新增采购等价预算，集团有线从2.2到5.9的增量相当于每年增加约3,700—7,400个这样的预算单位，或较少大客户更高支出。该预算单位并非客户清册，暴露了突破所需的广度；当前证据只支持方向，尚不能证明规模。

成熟平台不存在免费复利：核心EBIT已扣SBC、维持研发、软件开发与现场支持。GM为剔除收购会计摊销、仍含生产报酬的经济毛利分配；Opex=经济毛利−经济EBIT。GAAP EBIT近似再扣已披露收购无形摊销序列，不能与公司完整非GAAP调节表等同。历史收购总资本已体现当前现金债务；未来价值不再加回历史收购价格，新增研发和真实维持费用持续扣除。

固定研发不能随收入即时下降。悲观FY27核心研发分配仍约1.26，基准1.34，乐观1.40、突破1.46；之后各按2.5%/7%/10%/13%增长至FY31。它们是总Opex的分配说明，**不额外再扣一次**。悲观经营率下调5.5—6个百分点，同时采购增加周转0.18，模拟成本刚性与物料错配；FY28只释放0.10，并不免费恢复所有损失。

维持性CapEx工作值约收入1.7%—1.9%；Q4全部CapEx0.063，使FY26全年达到最新10-Q预计0.160。FY27—31总核心CapEx率悲观1.9%、基准2.6%、乐观3.1%、突破3.9%；超过维持部分用于产能、计量和研发基础设施。核心周转占增量收入18%—20%，悲观23%且另加库存压力。费用化研发中约75%用于现有能力迭代、25%用于扩展是分析分配；不能只扣维持研发、又全享成长收益。[10-Q资本支出说明][S1]

增量资本回报需包括研发、并购和周转，不能用低厂房CapEx推导无限ROIC。以基准FY27—29的新增资本支出超过维持部分约0.22、增长研发约1.08及增量周转约0.50合计约1.8为粗分母，相对FY27至FY29新增税后核心营业利润约0.49，只是约25%—30%的成熟年度收益/分批投入参照；不是完整IRR，且收益并非全由这些新批次产生。考虑延迟、失败和更新，模型稳定增量ROIC基准采用20%，邻近15%—25%。研发已费用化，不能再将这1.08从FCFF另扣。

### 4.3 估值理念、方法和资本桥

主矩阵三期限均用同一经营权益的剩余现金DCF。短期主理念为捕捉可见经营与价格的差异，一年为增长兑现和现金转换，三年为持续现金复利；理念侧重点改变，经营路径与工具不切换成互相矛盾的预测。

主估值系统性风险补偿WACC工作值9.5%，合理范围8.5%—10.5%；各行相同，不因“悲观”再对已损失现金加一次失败折价。美元长期利率4.5%—5.0%与权益风险补偿约4%—5%是校准假设范围，不宣称为精确当日国债或公司CAPM估计；本次国债当日官方接口未成功返回，明确不填伪精确点值。投资者的8%半年/12%一年/10%年化要求是下一节选择标准，不能代替WACC。

每个目标日：先只折现**之后**剩余季度/年度FCFF，季度内按实际日数和剩余期中时点折现；2036年后按更新后的税后利润与`1−g/ROIC`生成剩余现金，折回目标日。目标日以前现金只通过实际资本积累或分配一次。早期贡献已包含在FCFF及终值，不再另加“AI/量子期权价值”。

### 4.4 现价要求与投资理念分歧

本研究不把现价反推作为增长预测来源。以下门槛只在完成独立模型后比较：

| 论点 | 现价需要什么 | 当前证据裁决与期限 |
|---|---|---|
| 现金安全边际 | 现金和已可持续经营足以在较坏合理结果提供价值 | 净现金保护约0.32美元/股；未来大部分价值为经营持续性。现价不成立，三个期限均拒绝 |
| 周期恢复及一年盈利重估 | 持续盈利上修且一年价值至少373.43美元（12%要求） | 恢复本身已经发生；基准目标245.8，乐观中枢358.7仍略不足。需要更好经营或更长持续期，不能凭价格回调声称周期便宜 |
| 普通长期复利 | 三年价值至少443.78（10%年化），若12%则468.43 | 基准和乐观中枢不足。即使基准中枢增长已经较强，也不等于有好买价 |
| 跨代平台长寿命 | 保持FY27—29后，有线FY30—36每年16%，其他业务7%—13%，仍持续投入；加较低风险补偿才越过443.78 | 有技术复用的依据，缺十年预算/跨代付费证据。与短寿命相反解释难完全裁决，故当前“暂不可判定优势”；不是由某工具名称压过另一工具 |
| 高风险非线性核心扩张 | FY29有线约5.9、集团约13.7，FY31集团约19.1并可持续更新；三年条件中枢568.1 | 当前可以辩护其机制，却不能证明必要规模与持续期；可承受50%以上失败损失也不自动产生定价优势。高风险取向必须接受本文剩余不可判定范围 |
| 量子／光子／推理单项重大成功 | 核心普通时，某一机会的净现值补足整股买价与要求回报 | 本文三项独立完整成功均不足；因此不以某个漂亮技术新闻作为单项买入依据。更远且更大未知机会未被证明为零，但不能据此填补价值差额 |

当前不是“仅差一两个百分点”的便宜基准；真正边际的是长平台加较低风险补偿的联合解释。

## 5. 四行三列条件建议矩阵

## 7. 当前行动比较、等待代价与最强反证

### 7.1 当前证据最支持哪里

当前最支持**近期基准，远期存在平台持续性分歧**。收入和核心增长已实现、技术产品和客户使用可查，使纯悲观并非工作锚点；但毛取消、净价、同客户复购和设备利用率缺失，又使“FY26高增速可以跨十年”的解释证据较弱。我们据此拒绝现金安全边际和单项量子买入论点；短中期没有识别足够价值优势，长期普通复利亦不满足主标准。

对于进取型平台，当前不能把有依据的替代持续性判成无价值，也不能用452美元的联合有利点值宣布已经便宜。可证实的技术复用支持机会存在；跨代预算广度、收费权和十年更新ROIC的公开证据尚不能支持所需精度。结论为**现价暂不可判定有优势，研究行动上不据此给出无条件买入建议**。这与“因承受不了风险拒绝”不同：即使允许高损失，价格与路径的权衡仍有未决机制。

以三年目标作透明二分压力实验：突破中枢568.1，非突破价值若为普通偏差277.0，达到10%年化所需整股突破权重约57.3%；如果所有未突破结果都已达到乐观中枢426.4，所需权重约12.2%。对12%年化要求，相应约65.8%与29.7%。**这些是相容损益门槛，不是估计概率。** 中间、延期和受损分支对“未突破平均价值”影响很大，四代表情景不是概率全集，因此不能选有利的失败价值反推漂亮胜率。本次没有足够公开资料把未突破联合路径及突破持续性概率收敛到能够稳定跨越门槛的范围；高风险整体选择保留不可判定，不能套用量子的局部S概率。

无需精确整体概率也能稳定判断的部分是：核心普通时三项独立成功仍达不到现价要求；现金底价不足；一季指引兑现不能解决平台持续期。会翻转的部分是更长核心平台增长与风险补偿联合变化，对此已完整保留经营、现金、价值和选择，而非列作未经评估的辅助上限。

def period(m,a,b):
    out={f:0 for f in ['r','core','early','op','gaapop','tax','dep','cap','wc','sbc','fcff']}
    for q in m['quarters']:
        days=max(0,(min(b,q['end'])-max(a,q['start'])).days)
        w=days/(q['end']-q['start']).days
        for f in out:out[f]+=q[f]*w
    return out

def value(m,t,wacc=.095,gshift=0):
    s=m['s'];g=TERMG[s]+gshift; tvdate=date(2036,11,1)
    pv=0; corepv=0; oppv=0
    for q in m['quarters']:
        a=max(t,q['start']);b=q['end']
        if b<=a:continue
        weight=(b-a).days/(q['end']-q['start']).days
        tau=((a-t).days+(b-a).days/2)/365.25
        discount=(1+wacc)**tau
        pv+=q['fcff']*weight/discount
        corepv+=q['corefcff']*weight/discount;oppv+=q['earlyfcff']*weight/discount
    y=m['years'][-1]
    coreterm=y['coreop']*(1-TAX)*(1+g)*(1-g/ROIC[s])
    # At terminal, no fresh success probability; U ceases. P/S retain renewal costs, F stays zero.
    earlyterm=0
    for name,oo in m['opps'].items():
        z=oo[-1];u,fp,fs,gp,gs,vp,vs,cap,wc=ECON[name]
        rf=1.03**9*(1+.25*(SCALE[s]-1))
        opP=z['rp']*(gp-vp)-fp*rf;opS=z['rs']*(gs-vs)-fs*rf
        earlyterm+=(z['p'][1]*opP+z['p'][2]*opS)*(1-TAX)*(1+g)*(1-g/ROIC[s])
    tau=(tvdate-t).days/365.25
    term=(coreterm+earlyterm)/(wacc-g)/(1+wacc)**tau
    opt=earlyterm/(wacc-g)/(1+wacc)**tau
    c=capital(m,t);ev=pv+term;eq=ev+c['net']+c['nonop'];v=eq/c['shares']
    return dict(v=v,ev=ev,eq=eq,termshare=term/ev,earlyshare=(oppv+opt)/ev,**c)
