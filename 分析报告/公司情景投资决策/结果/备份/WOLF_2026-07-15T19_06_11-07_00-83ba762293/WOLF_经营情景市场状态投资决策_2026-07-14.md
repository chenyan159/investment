## 3. 核心投资逻辑与最强反证

### 3.1 最强正面逻辑

Wolfspeed 拥有可验证的 200mm SiC 垂直制造、650–1200V 现售器件、3.3kV 模块和可采样 10kV MOSFET。成熟 AI PSU、UPS、BBU 的 SiC 需求已进入行业财务收入而非纯概念，公司自身 AI 收入也连续环比增长。由于当前制造固定负担高，一旦季度收入稳定跨过 $220m、GAAP 毛利率超过 15% 并且高毛利 AI / 200mm mix 足够大，增量毛利和现金流可能呈现明显非线性；这就是突破行存在的公司特定依据。

### 3.2 最强负面逻辑

当前 $34.31 对应的不是 $1.78bn 的简单股权赌注，而是约 $3.93–3.97bn 的完全稀释股权价值和 $3.68–3.72bn 的隐含经营性企业价值。该价格在 TTM 收入仅 $712.5m、Q3 毛利率 -27%、单季 OCF -$84m 时已支付约 5.2x EV/TTM sales；同时，三批价内可转债、权证和股权激励使经济性股数约为基础股的 2.2 倍。若经营只正常兑现，风险扩张市场也无法让普通股达到当前价格。

### 6.2 事件树与去重

1. **近端经营树：** Q4 收入是否在指引内 → 毛利改善是否来自真实利用率 / mix → OCF 是否低于 $60m/Q 消耗。只有三步共同改善，基准才上移乐观；仅第一步改善不增加完整每股价值。
2. **AI / 高压树：** pipeline 或 MOU → 资格 / AVL → 有金额不可随意取消的 production order → 验收收入 → 产品毛利 → 现金。当前成熟 AI 位于收入早期，高压位于资格 / 订单前；不能把两个市场机会相加为突破价值。
3. **资本树：** 经营性企业价值跨越转换价 → 可转债转股 / 权证行权 → 债务或现金变化 → 稀释股数变化。矩阵每格只在这一步处理一次；注册转售导致的二级供给不再额外从内在价值扣减。
4. **压力树：** 市场信用恶化 → 客户资本预算或公司融资条件受压 → 收入 / FCF 下移 → 现金跑道缩短 → 新优先资本或低价股权。纯格子先保留原经营行；现实迁移另在第 12 节的状态联动中展示。

## 8. 格子内估值方法与资本桥

### 8.1 方法优先级

1. **主方法：目标期收入 × 条件 EV/Sales。** WOLF 在全部可见情景中 NTM 经营利润和 FCF 大多仍为负，收入是近端唯一可同口径测量的经营量；但收入倍数只能在完成目标现金、非可转债、租赁、可转债转换和完全稀释股数瀑布后形成每股价值。
2. **中长期 DCF / 正常化 FCF：** 用 3–5 年收入、FCF margin、13%–18% WACC、2%–3% 终值增长约束倍数高端。过渡期仍负 FCF，因此 DCF 对 ramp 时点高度敏感，不作机械平均。
3. **资产 / 清偿顺序边界：** 悲观和压力格优先检验现金、债务、租赁与持续经营资金。专用晶圆厂的账面或重置成本不是普通股保护；缺买家、低利用率和清偿优先级使低端可为零。
4. **项目 / 期权：** AI、高压、800V 与 300mm 只通过已进入情景的收入、利润和现金计入；不在 SOTP 再加一次。

### 8.3 企业价值到每股价值

每个端点按以下顺序：

1. 目标期经营性 EV = 目标期收入 × 条件 EV/Sales；
2. 加目标期现金和可确认非经营资产；
3. 扣约 $925.9m 非可转债、约 $110m 租赁，以及在该端点未转换的可转债；
4. 若端点每股价值越过 $12.23、$18.35、约 $20.14 或 $23.95，则相应移除债务或增加权证现金，同时增加转换 / 行权股数；
5. 加入预付权证、已授予 RSU / PSU 及情景 SBC，求解稀释后每股价值。

因此低价值格可能“股份较少但债务保留”，高价值格则“债务较少但股数大幅增加”。这是同一索取权的两种状态，不能取两者各自有利端点。对最大转换率、未来 SBC、现金烧损和 terminal margin 的敏感性使多数格子的估值置信度为低；这与经营路径当前证据强度是不同概念。

### 8.4 方法分歧与边界

- 收入倍数对突破行最友好；DCF 会因前 2–3 年负现金流和 13%–18% 资本成本给出更低的中位价值。因此突破格不使用单一 8x 高端形成建议。
- 资产法对普通股不提供可靠下限：截至 Q3 的流动性很强，但债务、租赁、最低经营现金和专用资产折价位于普通股之前。
- 同日原始市场数据中，成熟功率 / 模拟公司 P/S 约 5–7x，强成长半导体更高；WOLF 当前经济稀释 EV/Sales 已约 5.2x，却仍为负毛利和负 FCF。可比值只约束高端，不直接移植。
- 若模型结果分歧超过约 30%，本报告扩大价值区间并降低估值置信度，不用平均值掩盖。

## 12. 不依赖概率的矩阵解释

### 12.1 当前锚点、纯行与复合定位必要性

### 12.4 全矩阵形状

适用的中性形状标签是：

- **条件正面区域：** 只有突破经营且市场不差于震荡时才出现正面格；
- **经营兑现敏感：** 当前宽基列从基准的 -90%～-38%到突破的 +9%～+89%，变化主要来自公司是否跨过利润和现金断点；
- **市场状态敏感：** 同一突破行从主题列 +21%～+115%降到信用压力列 -70%～-10%，久期和融资条件会放大结果；
- **突破价值集中：** 3 个正面格全部位于突破行；
- **当前价格支持不足：** 乐观行五列也没有达到研究要求回报；
- **无下行情景价格保护：** 悲观行所有格子的普通股低端为零，且最多也仅 $9.4/股。

最稳定区域是悲观和基准两行的负面区域；最脆弱边界位于 **突破 × 震荡**，因为价值区间跨越现价、建议仅为谨慎正面。最坏格子为悲观 / 基准 × 信用压力，普通股每股价值低端和高端均为 $0；首个经营原因是收入无法覆盖固定制造成本，继而现金消耗穿过融资与优先索取权到普通股。

最能改变当前条件定位的组合是：**连续两季达到突破阈值，同时市场维持宽基风险扩张或主题上涨。** 单纯主题切换只能把基准价值高端从 $21.2抬到 $23.7，不能改变方向。

### 12.5 重要状态联动

| 联动 | 首个受影响环节 | 下游传导 | 纯条件格与更可达迁移格 |
| --- | --- | --- | --- |
| 有序风险收缩压低工业 / EV客户预算与 Materials ASP | 需求 → 收入 | 收入下移 → 利用率 / 毛利恶化 → OCF消耗扩大 | 基准 × 有序收缩（纯条件）→ 悲观 × 有序收缩 |
| 信用压力抬高融资成本、客户推迟园区项目 | FCF / 融资，同时可能影响需求 | 现金跑道缩短 → 保留债务或发行新优先资本 / 低价股 → 每股价值下移 | 乐观 × 信用压力（纯条件）→ 基准或悲观 × 信用压力 |
| 窄幅 AI主题上涨且公司披露多客户绝对收入 | 需求 → 收入 | 只有收入、毛利、OCF三步同时穿透才上移；否则只留在同一经营行的主题列 | 基准 × 主题（仅估值溢价）→ 突破 × 主题（需经营证据） |
| 宽基扩张延续但实际利率保持高位 | 折现率，后续可能影响融资 | 正常市场功能支持倍数，但高实际利率限制亏损久期资产；不会自动修复毛利 | 基准 × 宽基保持原格；只有公司里程碑才上移乐观 / 突破 × 宽基 |

这些迁移不在原格子中重复下调经营变量。原格回答“经营行不变时怎样”，联动回答“现实可能沿哪条路径移动”。
