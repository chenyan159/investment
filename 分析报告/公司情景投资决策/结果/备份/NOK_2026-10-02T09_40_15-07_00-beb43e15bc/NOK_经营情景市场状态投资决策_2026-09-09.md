## 一、当前判断、研究时点与关键限制

**现价10.65美元下，短期与中期不建立新仓，长期普通复利标准下亦不建议买入；能够承受大幅亏损、以核心业务突破为依据的投资者，存在值得研究的条件上行，但目前尚不能辨认足以支持实际参与的优势。** 这不等于公司经营转坏，也不等于等待一季财报必然胜过立即买入。

公司已经受益于AI与云网络需求。真正的问题是：投资者支付的价格，是否已经需要光/IP业务持续增长、费用杠杆兑现和部分新收入模式成功同时成立。当前证据支持“增长与重组继续兑现”，强于“增长完全虚假”的解释；但也支持每比特降价、竞争者扩产、无线设备低利润以及股东现金转换较慢这些约束。

### 2.3 决定性主张、相反解释与独立范围

**争议一：28亿欧元AI/云订单是不是硬现金承诺？** 半年报第一页CEO段落给出Q2订单2.8，预计约半数随后12个月转收入，并解释供给限制促使客户订更长期订单。它支持需求延续，不支持把2.8乘四年化，也不支持把1.4全部加在旧收入上。取消权、逐单预付款、收款及验收条款未公开。2025年报第72页和收入附注第210页的19.5是年末固定合同未履约义务，57%在一年内、28%两至三年、15%更远，包含多年授权；与Q2客户分类新增订单不是可直接相加的存量。

相反解释是订单前置与重复排队；真实光/IP收入增长反驳“全是排队”，但供给紧张和期限延长仍支持部分前置。基准不把订单全额硬化，而以2026H2交付、2027带宽/净价和营运资本共同建模。约1.4待转化只是订单池中的一部分，2027光/IP合计8.1还需要既有运营商销售、旧单与后续新增采购；不能用它单独证明8.1。

**争议二：光学需求扩张能否持续变成诺基亚利润？** 本地行业报告支持数据中心光连接和合格InP供给偏紧，同时明确硅光、线性架构、CPO、端口合并和每比特价格下行。Ciena的2026财年Q3（截至8月1日）收入1.6711十亿美元、同比+37%、调整后营业利润率22.5%，说明需求和竞争者供给都强；期间及产品口径不同，不能由两家增速直接算份额。[Ciena原始业绩](https://investor.ciena.com/news/news-details/2026/Ciena-Reports-Fiscal-Third-Quarter-2026-Financial-Results/default.aspx)

独立数量/价格工作假设如下。量是**相同服务边界下已验收等效带宽指数**，不是公司披露晶圆/端口数；用以约束机制而非伪造出货点值。2026各行情景先扣已发生H1，再按H2不同交付形成起点；新高带宽产品同时压低单位带宽收入。

| 情景 | 2027光有效交付量因子 | 每比特净实现价因子 | 光收入推导及约束 |
|---|---:|---:|---|
| 悲观 | 约1.23 | 0.80 | 2026约3.769×1.23×0.80≈3.71；模型3.70。客户仍增带宽，降价及组合使收入不增。 |
| 基准 | 约1.37 | 0.86 | 2026约3.989×1.37×0.86≈4.70；新厂/资格逐步放量、同规格价格下降。 |
| 乐观 | 约1.44 | 0.89 | 2026约4.129×1.44×0.89≈5.29；模型5.30。交付资格改善、系统价值保留较多。 |
| 突破 | 约1.52 | 0.91 | 2026约4.189×1.52×0.91≈5.79；模型5.80。大客户扩展与较好系统/软件含量共同成立。 |

这些量价是依据交付增长、订单期限和技术周期选择的一组**可辩护主观路径**，不是两组独立实测结果；物理晶圆投入、die数及良率未披露，仍不能证明供给恰好足够。基准2027所需约37%等效带宽增量与新产能时序相容；突破约52%要求更强的合格供给与客户验收，证据弱于基准。

IP基准2027收入3.40，以2026约2.925为起点，工作解释为付费有效端口/系统交付增长约25%、净系统价值下降约7%（乘积约1.163），同时云增长抵消部分运营商预算弱势。无线基准7.80较2026约7.73接近平稳，必须靠欧洲、日本和新客户抵消份额流失；它没有被赋予光学增速。Fixed基准1.88以OLT升级抵消终端优化，Core 2.38以成熟软件续用和容量升级为主，标准授权1.65不依赖反复追补。

**争议三：集团2026利润兑现还差多远？** 基准全年收入20.698、可比营业利润2.400，与8月4日公开共识20.695/2.400相近。H1利润0.735，加Q3估计0.440，Q4仍需1.225；明显高于上游重述2025Q4的1.067。Q4软件/专利确认、NI交付和费用杠杆不可缺席。采用指引中部来自这条利润桥，不是因“中点看起来稳健”；下沿路径考虑年度经营低于指引。不能把全年的正常兑现称为新的超预期。[Infront共识原表](https://www.nokia.com/sites/default/files/2026-08/nokia-post-q2-2026-consensus.pdf)

**争议四：AI-RAN是新增利润池还是替代旧采购？** 7月15日平台原文包含订阅模式、年底试点和2027可用。客户T-Mobile的原始演示文章实际为2026-02-17；正文确认GPU承载无线Layer 1与视频字幕共同运行，并有Ericsson相关演示。该文章日期修正了本地上游将其概括为3月材料的口径。证据证明工程路径成立，尚未证明跨网络忙时TCO、软件净费或规模续约。[平台公告](https://www.nokia.com/newsroom/nokia-defines-the-next-era-of-radio-with-the-industrys-first-ai-native-ran-platform/)、[客户原文](https://www.t-mobile.com/news/network/why-physical-ai-begins-with-intelligent-networks)

客户愿付增量软件费受实际节省约束。例如某部署域每年避免扩容/运维100,000欧元，额外计算硬件年成本30,000、能耗支持20,000，才剩50,000可由客户收益与诺基亚分配；若实际节省只有40,000，就没有同样的付费空间。这是机制算例，不是报价。模型净增收入已扣旧无线/软件替代，不把“AI-RAN设备销售”全数相加。

**争议五：现金与扩厂能否协调？** San Jose计划2026Q4后段爬坡，Allentown封测扩张，Chandler计划2027先租产能、2029Q1取得厂区。这些进度均不同于满产。封测十倍不能推导晶圆、集团销量或利润十倍。最新CapEx假设0.8—0.9，重组现金0.7—0.8；因此报告现金转换和维持性能力都要检查，不能只调营业利润倍数。

### 2.5 仍须保留的五至十年以上可能性

ICE-D可由器件销售扩大到光引擎平台；AI-RAN可由算法收费扩展至多运营商持续订阅及6G更新；DC软件可以由自有设备附属收入变为跨硬件渠道责任平台；API/智能体可进入医疗验证、网络自治等新客户预算。这四项足以影响每股价值，下一节分别建状态现金。

防务、通感一体化、边缘AI与NestAI需保留独立进入条件：采购资格、抗干扰/加固验证、频谱、主承包商渠道、保密与交付能力。若新增年度防务销售0.30、增量毛利30%、专用研发/交付0.04，可比营业增量约0.05，普通价值数量级约0.6—0.9十亿欧元，约0.12—0.18美元/ADS；若五至十年扩至1.0、营业率15%，相应价值才可能约0.35—0.55美元/ADS。当前未有可复核的大额重复采购支持，主模型这部分仅留在NI/MI普通客户扩展，不重复加独立溢价。若出现收入数十亿的新军工平台需重开模型，而不是因第一个小算例就宣布其不重要。

PON OOB要达0.10年度销售，在每站点净收入0.10—0.30百万欧元下需约333—1,000个验收站点/年；进入条件是故障域隔离、运维可恢复性和实测TCO。Enscryb需验证受管能源资产、调度带来的实际收益和平台收费权；若每客户净年费0.1—0.5百万，要达0.10收入需200—1,000名同等付费客户。两者可部分成功，并存在更大用途，但当前不足以赋予高额现值；列明规模门槛不等于假定价格已获合同证明。

Zankore约200MW/长期1GW是建设目标，不是诺基亚拥有的电厂、GPU资产或收入；必须得到网络BOM、验收以及合同净收费。Nscale融资、NVIDIA入股与NestAI合计融资分别是客户资金来源、诺基亚资本与合作方资本，不能计为诺基亚网络收入。NVIDIA投资已进入既有股本和现金，不另加“合作期权”；NestAI的全部估值不归诺基亚。

Bell Labs的基础研究、6G标准、量子安全、通感与边缘计算可能在2030年代创造尚不能界定的价值。其进入路径可通过设备更新、许可、合资或技术授权，但没有明确股东经济权利与预算边界的部分**不在本报告金额覆盖内**。这限制对极端远期收益的否定范围；不能以本文测算证明所有尚未知技术期权都无价值。

## 三、四套连续经营、机会与资本底稿

### 3.1 四条完整路径及进入/退出条件

四行是代表性解释，**不是互斥、穷尽的概率分布**。基准是本次独立研究的工作锚点，不是统计P50。事实优先支持基准附近的经营兑现，仍不能排除普通失速；乐观和突破有技术与客户入口基础，但对规模、净价和持续性要求更强。矩阵不把这种路径证据强弱混入条件回报。

| 情景 | 核心路径与资本应对 | 必须观察到的条件 | 情景证据强度 |
|---|---|---|---|
| 悲观/受损 | 光每比特降价快、云项目延期、无线份额/授权正常化偏弱；研发和工厂投入先付，逐步削减可选投入及分红 | NI增长不能转换成毛利，库存和回款差，核心亏损虽不致破产却长期消耗竞争力 | 中低；风险机制有事实，尚未观察到全面共振 |
| 基准/正常兑现 | 光/IP交付增长、整合费用率下降；无线接近平稳；专利现金维持；早期机会允许多数路径尚未成功或失败 | 2026全年约2.4可比利润，2027约22.1收入/2.8营业利润，现金回收逐步改善 | 中；最符合当前经营证据，但利润/持久性仍待验证 |

| 突破/非线性 | 光/IP成为更大AI互联平台，系统责任和制造效率共同提高捕获；核心NI与后续更新获得持续回报 | 2029核心NI约18.0、营业率约22%；合格产出、跨客户部署和净费保持同时成立 | 低；可辩护条件实验，不是所有早期机会均100%成功 |

突破最少必须具备的是**核心光/IP大规模交付及较高利润持续性**。AI-RAN、API等可以只部分成功；模型并未把它们都设为成功。反过来，单一早期机会成功也不能替代核心的价值创造。

I与核心光学共享供给，R与核心无线共享运营商预算，D与A共享销售/软件支持人员。本模型的各行情景已通过规模乘数、投入和速度反映这些约束；增量线性期望可以相加，但并不假设四机会独立，也不提供由边际概率相乘得出的整股胜率。主要四条路径均没有现金融资断点；更严重联合失败另在3.5检验，不能让平均现金掩盖融资压力。

### 3.4 维持投入、成长投入、更新周期与剩余价值

2027—2031核心CapEx、重组和机会CapEx均实际扣现金。核心CapEx区分：维持/改代约0.45—0.60每年；已承诺光产能和客户适配占余量；突破额外扩产随更高量增长。2029核心CapEx预算含厂区取得/改造的工作占位，**Chandler未公开最终现金价格**，不可把占位当合同金额；额外0.5支出敏感性约减少0.10美元/ADS，投入延迟影响生产和收入时损失会更大。

研发与获客虽然大部分费用化，仍是经济再投资。核心产品持续研发由毛利至营业费用桥保留，早期阶段单独预算，不以会计CapEx规模小声称轻资产。2027—2029基准核心CapEx约2.70、机会CapEx约0.15，另有重组约0.85；不能把这些全部视作新项目资本，再将总利润除以它们冒充ROIC。

增量批次检验：若普通光/IP增长需要新增0.6—1.0专用设备、周转和研发，成熟后产生0.15—0.25税后年收益，增量ROIC约15%—42%、简单回收约2.4—6.7年；这是投入/收益配对范围，不是IRR。I规模1.8收入时44%毛利，扣约0.2持续研发及现金税、约0.29年度净新增再投资，仍可产生正现金；但2027—2028的合格供给和客户净费不过关，继续扩产可能毁损价值。失败分支会止损并有退出损失，不能默认管理层永远满额机械投入或能无成本完美纠错。

核心生命周期：光/IP的单位型号通常经历数年代际，但研发、软件、客户资格和服务可复用；现金延续来自更新成功，不能把当代器件视作永远不衰减。无线硬件及专利也需要标准更新；授权利润率在远期逐步回落。2032—2036按逐渐下降的增长率和轻微营业率正常化延伸，不将2029高增长永远外推。2037稳定增长g按悲观0.5%、基准1.5%、乐观/突破2.0%，新增资本回报按10%/15%/18%/20%；用g/ROIC计算稳定阶段再投资比例，扣除持续重组维护支出。它是一项关于平台可更新的经营解释，而非任意终值按钮。

早期机会显式至2036，不把尚未成功的路径到期重置为成功；以后以2036已加权经济现金为起点，I每年衰减12%最多8年、R衰减6%最多10年、D衰减5%最多12年、A衰减10%最多8年。差别来自器件替代速度、无线/标准周期、跨硬件软件可复用性和API开放竞争。这是当前可辩护的剩余特许经营范围，现金已扣维护研发；并非断言企业在这些年必然关闭。

替代解释保留：若各早期平台的更新均能比上述寿命多延续十年、维持相同衰减，基准三年工作价值从12.19升至约12.41；再配合7%折现率约14.25，年化约11.4%，仍略低于12%主标准，但足以改变10%年化标准下的选择。若6G或新光架构带来另一轮超出该范围的跃迁，必须重建对应经营支线，不能在终值中免费加一个“永续技术期权”。

### 3.5 现金、股权报酬、资本桥与融资断点

采用**经济现金扣股份报酬、未来净股数稳定**的路径：核心营业费用和机会研发中含正常员工报酬；报告FCF估计加回非现金股份报酬，经济FCF再扣其等价现金，代表现金薪酬替代或为未来授予进行等额稀释中和。完全稀释股数5.82已经预留存量潜在奖励，之后不对同笔未来报酬再次机械增股。这是估值约定，不是公司已宣布等额回购。

核心年度SBC等价成本为0.42×核心收入/22，已在经济现金中负担；若公司实际不做现金替代、以增股支付，应改用更高未来股数、保留相应现金，不能两边只挑有利。若三年额外净稀释3%、现金不变，基准三年每股价值约下降0.36美元；若同时留存相应员工现金成本，净影响小于该上限。库存股交给员工是稀释，不是无成本回购效果。

租赁处理采用**经营成本法**：现金流加回包括使用权折旧的可比D&A，再扣全部经营租赁现金，资本桥不再扣0.959租赁负债。公司定义净现金中已扣计息债务，桥中不第二次扣债，也不加回5.176现金两次。应收/库存、保修及日常养老金服务成本在经营现金内；养老金净资产不作为自由现金另加。

主方法始终为**分核心与机会的现金流折现**，三个期限使用同一经营和资本底稿；盈利倍数只作约束和反向检验，不与DCF平均。理由是专利、设备、软件、新制造能力的现金转换和持续期不同；单一集团P/E容易抹平这一差异。

- 对目标日后的季度经济现金按季度剩余比例和期中日期折现；目标日前现金仅在资本桥/分配中出现一次。
- 核心显式到2036，2037稳定现金为“2036核心营业利润×(1+g)×78%×(1−g/ROIC)−持续重组维护”，其后按g增长。
- 四机会使用逐年状态加权现金及各自剩余更新寿命；不再另加成功期权或行业TAM。
- 股权价值＝核心经营价值＋机会经营价值＋目标日净现金＋可实现非经营资产−少数/其他权利；除完全稀释5.82，再按1.1614换为美元。
- 持有回报＝（目标日价值＋研究日后每ADS现金分配）/10.65−1。

低/工作/高合理价值统一对应9%/8%/7%欧元名义折现率，经营路径不变。该范围是2%—3%左右长周期欧元无风险机会成本与约4%—6%股票系统性风险补偿的研究假设组合，并非声称查得单一当前WACC报价。已建入现金的失单、退出和资本成本不再重复乘失败率。未给定持有回报要求时，DCF折现率与投资者要求回报仍是不同参数：前者表达现金定价，后者决定买入是否合算。

**合理价值区间不是可能股价区间。** 矩阵中的6个月高回报尤其不意味着市场半年后已经确认全部2030年代成果；它是给定完整核心路径下、仍保留行内早期概率的条件经济吸引力。没有新增信息时，机会概率不随日历自动升到100%。目标日的估值是从当前视角对该路径与机会信息结果的期望参照；届时若只知道某一实际状态，应以该状态更新以后转移，而不是继续机械沿用平均状态。

折现率/标准的最小翻转：基准三年9%/8%/7%折现下，年化约2.1%/5.9%/10.7%。若投资者只要求10%，7%贴现端可以谨慎参与；12%要求下仍不足。要在同一基准现金与12%标准下翻转，还须更低风险补偿、更多持续现金或约9美元的更低买价。7%与十年额外更新共同出现仍只约11.4%，薄弱边界不能包装成精确买点。对这类差异，先承认资本持续性与定价参数未完全可识别，再根据实际投资标准选择。

风险定位：订单兑现/客户预算进入核心收入；竞争与价格进入量价和毛利；R&D、扩厂、退出、失败周转进入现金；早期商业失败进入状态概率；股份报酬进入经济现金和存量稀释；汇率单列；7%—9%补偿时间与未建入的系统性风险。未再对同一现金损失附加任意“风险折价”。0.01报价差、约0.55的净现金保护和正常单日波动，远小于长期持续性造成的每股估值差异。

## 六、当前证据下的行动、等待代价与更新边界

### 6.1 主要选择与最强相反选择

目前最支持的是基准附近的完整路径：AI/云收入与光/IP交付已发生，制造投入和资本结构可支持继续发展；无线与专利提供缓冲。最强相反解释是光/IP能够持续接近乐观规模并提高利润率，进而使今日较高价格仍便宜。支持它的证据是长单、客户入口、自有光电和软件能力；反证是同业扩产、每比特价格、云硬件组合低利润、客户可替换供应商、尚未披露的外销净费与现金。

对普通复利标准，工作/普通偏差的损益与当前选择一致：不需要精确分配四情景概率，也能判断基准现价回报不足且余量不厚。对高风险标准，不能因悲观亏损很大自动拒绝；应检验必要上行的规模与可信程度。单项成功参照给出明确限制，较强回报依赖核心多因素共振，当前没有足以把该共振当作高可信工作路径的证据。

作为**赔率门槛算例，而非整股真实分布**：若终值财富仅在普通偏差约11.61美元和乐观约19.53美元两点之间，满足20%年化所需上行权重约86%；若上行改为突破约25.09、普通仍11.61，所需约50%。这两个实验互不兼容，不能把86%与50%平均，也不能把I/R/D/A的局部成功率直接放进去。被省略的中间路径、严重损伤和更大远期成果会改变门槛，算例本身不提供可达性证据。

已有产品、客户和供给计划足以支持上行机会存在，却不足以支持“核心持续高利润联合突破的可信程度至少约一半”这类整股主张；本报告没有可靠基础率去证明相反的精确概率。因此高风险当前选择是**暂不参与、保留条件论点**，理由是未辨认必要优势，不是已经证明其期望回报为负。能够用独立客户采购、净费、良率和跨代复购支持更强持续性的投资者可以得出不同选择；差别应落到这些事实，而不是偏好越激进经营就越好。

价格更新边界来自同一模型：若经营保持基准，约9美元附近才接近三年12%工作要求，约8.1美元对应更高折现率端；若报价在9美元但NI资格或现金已受损，应先替换核心路径。若2027—2028证据显示NI更接近乐观规模/利润，允许上调价值，不必机械坚持候价。对未知远期巨大机会，本文保留覆盖限制，并未否定所有更大胆理念。

### 6.3 最少更新证据与失败代价

1. 光/IP：连续披露真实验收与现金回收，分清长期订单前置；新产能的合格产出、关键客户资格与净价，而非仅建厂进度。
2. NI利润：收入增长时研发/销售费用仍足以维持产品，毛利和营业率改善来自真实成本及组合；至少跨两个确认期，而不是Q4一次性授权混入。
3. AI-RAN：具名付费域、现场忙时TCO/SLA、净年费与续订；技术演示只能改变进入概率的一部分。
4. I/D/A：外销客户、第三方收费设备、净API调用及平台费，明确替代和经济权益；不能用内部自用或伙伴融资补量。
5. 股东现金：报告FCF转成扣租赁、股份报酬和必要成长投入后的现金，分红/新厂/承诺支出相容；若净现金逼近最低缓冲先检查融资分支。
6. 长期：至少一轮跨代复购和价格/资本回报保持；6G与未知Bell Labs应用仍是未决条件，不把它们自动归零也不提前收全价。

实质取舍是：经营增长已有证据，现价下普通回报不足；核心平台突破有条件吸引力，但必要联合规模和价格采纳的优势尚未被现有证据清晰识别。本文给出模型可更新的价格与证据边界，而不是凭正面格数量判断胜率。

 return sum(M.quarters.map(q=>q[key]*Math.max(0,Math.min(date,q.en)-Math.max(from,q.st))/(q.en-q.st)));
}
function val(M,target,r=.08){
 const s=M.s;
 let corePV=0,oppPV=0;
 for(let q of M.quarters){if(q.en<=target)continue;
 const frac=(q.en-Math.max(target,q.st))/(q.en-q.st),cashDate=(Math.max(target,q.st)+q.en)/2;
 corePV+=q.coreCF*frac/(1+r)**yrfrac(target,cashDate);
 oppPV+=q.oppCF*frac/(1+r)**yrfrac(target,cashDate);
 }
 let last=M.annual[9],g=C.tailGrowth[s],roic=C.tailROIC[s];
 const tailDate=day("2037-01-01");
 const termCash=last.coreOP*(1+g)*.78*(1-g/roic)-last.restructure;
 const tv=termCash/(r-g)/(1+r)**yrfrac(target,tailDate); corePV+=tv;
 let oppTail=0;
 O.forEach((o,i)=>{for(let z=1;z<=o.life;z++){const cf=M.opp[i][9].fcf*(1-o.decay)**z;oppTail+=cf/(1+r)**yrfrac(target,day((2036+z)+"-07-01"));}});oppPV+=oppTail;
 const paid=sum(M.dividends.filter(d=>d.date<target).map(d=>d.d*C.shares));
 const cash=C.startCash+accum(M,target)-paid-(target>=day("2027-06-30")?.222:0); // net cash, debt already netted
 const distributions=sum(M.dividends.filter(d=>d.date>=start&&d.date<target).map(d=>d.d));
 const equity=corePV+oppPV+cash+C.assets[s]-C.claims;
 const perShare=equity/C.shares*C.fx;
 return {target,r,corePV,oppPV,tv,oppTail,cash,debt:2.4,grossCash:cash+2.4,assets:C.assets[s],equity,perShare,div:distributions*C.fx,
 ret:(perShare+distributions*C.fx)/C.price-1,ann:target>start?((perShare+distributions*C.fx)/C.price)**(1/yrfrac(start,target))-1:null};
}

const models=C.names.map((_,s)=>build(s));
for(const M of models){
 for(const rows of M.opp) for(const a of rows){
  if(Math.abs(sum(a.p)-1)>1e-10 || a.p.some(p=>p<0)) throw Error("Invalid probability");
 }
 for(const a of M.annual){
  if(Math.abs(a.revenue-a.coreRevenue-sum(a.opp.map(o=>o.revenue)))>1e-9) throw Error("Revenue mismatch");
  if(Math.abs(a.fcf-a.coreCF-sum(a.opp.map(o=>o.fcf)))>1e-9) throw Error("Cash mismatch");
  const qs=M.quarters.filter(q=>q.y===a.y);
  for(const key of ["revenue","op","fcf","cap","reportFCF"]){
   if(Math.abs(sum(qs.map(q=>q[key]))-a[key])>1e-8) throw Error("Quarter mismatch: "+key);
  }
 }
}
const output=[];
for(let s=0;s<4;s++)for(const d of ["2027-03-09","2027-09-09","2029-09-09"]){
 const lo=val(models[s],day(d),.09),mi=val(models[s],day(d),.08),hi=val(models[s],day(d),.07);
 if(!(lo.perShare<mi.perShare && mi.perShare<hi.perShare)) throw Error("Discount direction");
 output.push({scenario:C.names[s],date:d,low:lo.perShare,mid:mi.perShare,high:hi.perShare,
 returnLow:lo.ret,returnMid:mi.ret,returnHigh:hi.ret,annualLow:lo.ann,annualMid:mi.ann,annualHigh:hi.ann});
}
console.log(JSON.stringify({matrix:output,validated:true},null,2));
