# BWXT：核级工业扩张、价值传导与分期限投资决策
研究日期：2026-09-07｜唯一正式报告｜金额除特别注明外均为**百万美元**，股数为**百万股**，每股价格为美元。

## 1. 当前判断、研究时点与最重要的限制

**当前判断：短期中性／等待；中期不建议投资；长期不建议按稳健复利逻辑在现价买入。** BWXT 的核级制造资格、海军燃料地位和可见合同有真实价值，正常经营路径仍支持收入和利润增长。但从 **157.59 美元**买入，投资者支付的价格明显超过本报告在完整扣除再投资后得到的正常兑现现金价值。短期可能出现盈利或合同驱动的交易性反弹；这与按未来股东现金衡量是否便宜是两个不同判断。

本报告最重要的预期差不是“核电没有前途”，而是**核电资本支出增长不一定以同样速度转成 BWXT 每股可分配现金**。海军、国防材料工程、翻新服务和商业重型部件有不同利润率；BWXT 同时扩大产能、探索燃料新厂和承包商自持微堆，需要先支付人员、设备、研发和周转资金。零息可转债降低当期利息，却没有消除本金。医疗出售有助于融资，但不能当作经常收益。

**条件突破行不受“目前不是最可信情景”压低评级。** 在突破经营路径成立、早期项目仍按该行情景内概率计入的条件下，三个期限均可“谨慎建议投资”；其工作回报分别约 15%、20%、43%，对折现率、远期资本效率和规模依赖大。不能把这一行直接当作当前期望收益。本报告不为完整四行情景分配缺乏校准依据的总概率。

**财务调整。** Q2 调整后营业利润约 126.5，GAAP 114.1；差额主要为重组转型、并购费和收购无形资产摊销。模型不预测养老金重估和交易会计收益；未来 NI 表为“经济调整后净收益”，另给 GAAP 桥，不冒称审计预测。经常性的 IT、整合和流程费用不能永远免费，本模型每年预留现金调整 12，其中约 10 为此类费用、约 2 为权益收益现金转换差额的净工作值；区间 0—25 单列敏感性。

### 2.3 资本、治理与能改变价值的风险

6 月可用循环额度约 1,248.6，受杠杆／利息覆盖契约约束；环境负债约 103.9、养老金 69.3、其他退休福利 77.9，部分义务有客户补偿或长期支付特点。估值资本桥扣除 170—220 的**未在持续经营现金内处理的净经济索取权工作值**，不是把约 251 的三项账面负债都当即付现；另以全额 251 或加租赁作敏感性。正常租赁费用留在经营成本中，主模型不再把全部租赁本金重复扣除。

管理层的历史订单与交付记录支持执行资格，但医疗出售和 PCG 收购的最终资本回报仍未证明。薪酬兼有营业利润、FCF、ROIC 和 TSR；没有把“激励有 ROIC”当实际高 ROIC。核安全、材料管理、质量或重大网络事故会同时损害许可、交付、资格和信用；悲观行是可修复但持久受损路径，**不是最坏事故损失上限**。严重许可丧失、无限责任或资本承诺失控可使普通股损失接近全部，不能用下表最低价宣称止损保障。

### 3.3 新曲线：逐年状态、成功规模与期望贡献（2027—2036）

**计入对象与阶段。** 此处只计相对既有政府研发、Pele 合同和现有部件业务的增量，不把尚未商业化等同没有既有技术价值。TRISO 已有燃料实物和试验客户；BANR 已获 Janus 选定，但商业资产经济性未证实；mPower 有新许可，却无完成融资与实堆采购证明。概率是受工程、客户和资本约束的主观工作值，**没有足够同口径统计基础率，不能称已校准胜率**。

采用 U（尚无本新增业务外部商业收入）、L（有限／部分付费成功）、S（规模商业成功）、F（失败／退出）四个互斥状态。2027 年开始前本新增商业路径为 U=100%；当年状态在年初转移，按进入后的全年工作状态确认收入，年中时点的不确定性已由部分成功收入与延期敏感性吸收，不冒称精确合同开票日。已存在的 Janus 入选、燃料制造和 mPower 获许可均为共用事实，不再重复打折。

转移式：

`U' = U(1-a-b)`

`L' = Ua + L(1-c-d) + Se`

`S' = Lc + S(1-e-f)`

`F' = F + Ub + Ld + Sf`

F 为吸收态；没有失败后自动重生。S 可降为 L，也可退出；曾成功与当年仍成功不同。期望收入为 `L'×当年部分收入 + S'×当年规模收入`，不会把累计成功概率再次相乘。四行对 a/b/c/d/e/f 的取值如下，顺序分别表示 U→L、U→F、L→S、L→F、S→L、S→F：

| 情景 | 基础转移率 a/b/c/d/e/f（每年） | 情景含义 |
|---|---|---|
| 悲观 | 12/9/10/8/6/3% | 预算慢、材料或客户退出更频繁，成功规模还更小 |
| 基准 | 25/4/22/3.5/3.5/1.5% | 能力有验证，但后续客户、扩量和合同仍逐步过关 |
| 乐观 | 38/2.5/32/2/2.5/1% | 客户和认证较快、产线利用率较高；不是无失败 |
| 突破 | 45/2/40/1.5/2/1% | 核级平台与付费工作支持更快转化；独立早期技术仍有退出分支 |

### 4.2 主估值为什么使用现金与资本路径

本公司不是纯资产清算或高利润软件。成熟政府合同给经营持续性，新工业平台需要长期资本，医药交易改变资本桥，早期核技术存在离散成功和退出。因此主方法选为 **核心经营 FCFF 折现＋早期机会净现值＋非经营资产－资本索取权**，三个目标日保持同一口径。没有把今天 DCF 现值冒充六个月／三年后目标价。

核心 FCFF＝核心经济 FCF＋30×(1−22%)，消除对资本结构的净利息依赖；股东现金用于积累现金，FCFF 用于经营价值。目标日前现金只在资本桥出现一次。目标日后尚未结束的年度按季度／天数切出，未来流量按季度权重分配并在季度中点折现；2027年3月之前现金不再进入其后 DCF。2026H2 价值不另重复加到未来经营价值。

### 4.3 各期限的逻辑与替代理念

**短期三个月。** 到 2026-12-07 更可能知道 Q3、首版下一年评论和部分材料里程碑；医疗未必交割，完整 2027 指引也未必发布。常规财报窗口按历史节奏估为 11 月和次年 2 月，未取得确切发布日期，不写为已宣布事件。这个窗口不足以证明 BANR 售电或 TRISO 大厂利润；可以确认技术／商业条件，但不应兑现完整规模估值。三个月当前仍中性等待；若医疗净现金明确且 Q3 现金与政府任务同步变好，可提前转向有条件的事件参与。否则六个月的价值采纳可能推迟。

**六个月。** 至2027-03-07，更可能取得全年财报与2027指引、PCG对价和医疗净现金。正常路径提供“盈利增长得到确认”的证据，但不足以保证高倍数回升。本报告不能可靠估计未来交易价在 DCF 与盈利溢价之间落在哪里，故只给交易价格情景参照，不给精确获利胜率。即使合理现金价值低于现价，也不预测半年内一定下跌相同比例。

**一年。** 需要未来四季真实交付、现金回款和增长 CapEx 后的资本结果。材料工程增加要转成后续生产／运维收费；部件扩厂要增加合格输出而非在制资产；医疗出售不能在 EPS 中重复形成经常收益。可见收入超过40亿不难，难点是让充分扣投入后的现金收益显著高于当前买价隐含要求。

**三年。** 护城河是核级认证、工艺、人力、长期客户及信誉，不是所有未来核电项目的收费权。突破有可能让商用部件成为多 OEM 平台，TRISO 接入多个核设计、mPower 用较少资产输出 IP；同时 Doosan 等合格供给和客户自制可能压低远期租金，电源方案也会竞争客户预算。三年后仍有更远价值，但必须在三年内看到付费证据和资本效率，不能仅见到建设面积和合作意向。

## 5. 条件建议主矩阵与十二格明细

**评级前置门槛。** 主矩阵采用“核级工业现金与资本回报”的理念，6个月要求约10%总回报、一年约15%、三年约12%年化（累计40.5%），用于补偿约4%—5%无风险利率之外的集中、执行与估值误差；这是投资要求，不是模型预期。技术失败已进入早期状态概率，门槛不再扣同一失败成本。对把此视作纯技术期权的投资者，要求18%—20%长期年化也合理，其更高门槛会使突破长期格降为等待；对现金安全边际投资者，低端和实际回款比高端更重要。所有门槛在计算评级前按期限设定，不根据结果重新调整。

早期 TRISO、BANR、mPower 均已在各行内概率加权，成熟部件／海军／材料按本行路径；突破仅明确假设核级部件平台商业捕获成立，其他独立技术不100%成功。主矩阵是**条件合理价值总回报**，不是四行情景加权期望，也不是未来市场交易回报的统计区间。当前情景证据强度见3.1；下面置信度只讨论“假设本行成立之后，金额估计是否可靠”。

## 6. 当前路径、价格边界、反向要求与最强反证

### 6.1 当前最接近哪一行，以及如何选择

当前经营证据最接近基准，部分材料与核级部件机会向乐观移动；尚未取得支撑突破规模的多客户合同、合格产能和高ROIC。没有从基准取低投入、从突破取高收入拼一条“当前组合路径”。正常2027—2028模型与正式上游收入范围相符，经营判断并非衰退预测；主要异议是**买价要求的资本回报与增长持续性**。

|---|---|---|
| 现金／资本回报，6个月 | 公式工作上限约 77.4 | 正常合理工作值加股息再除1.10；不是预言股价会到该买点。估值误差很大，不对77附近机械下单 |

短期实际“中性／等待”与主矩阵基准“现金理念不建议”的区别来自投资目的：目前既没有立即买入的稳固事件优势，也不能排除在下次指引前发生交易反弹；等待不代表现金价值已经支持现价。中期需要自身的交付和现金证据；长期需要可重复资本回报，而不是短、中期标签平均。

### 6.2 现价反向要求：不是唯一市场共识

以当前市值14,439和交易前EV约15,880为起点，允许多组组合：

- 以核心EV/EBITDA **20倍**衡量，需约794 EBITDA；以25倍则约635。当前价格可以同时表达“2027—2028盈利增长、倍数回落”或“增长较慢但长期溢价维持”，不意味着市场只押注一种核技术。
- 以2026EPS4.75，价格约33.2倍；若未来退出只给25倍且希望一年15%回报，所需EPS约 `(157.59×1.15−1.08)/25≈7.21`，高于本研究正常一年后NTM约5.06，也高于正常三年后NTM约6.38。可用更高倍数替代部分EPS要求，但那是风险源。
- 若用成熟期9%资本成本、3%增长粗看现金，约15.9B EV需要约0.95B的次年持续FCFF数量级；本研究正常2027核心FCFF约321、早期增量仍负。正常2030年代增长提高现金，折现与再投资却会削弱它对今天的支持。0.95B不是精确市场一致预期，是反向永续量级。
- 要在三年获得12%年化，2029退出价须约 `157.59×1.12³−3.24≈218.2`。正常工作价仅约103；即使把三项早期业务改成完整成功，仍须更多核心价值、资本回报或显著更低折现率补足。

**方法冲突裁决。** 现价约23.8倍2026 EBITDA并非不能交易，而是要求后续投资带来很长的增长／高回报。主DCF给正常三年约87—116，倍数法约197—240；差距不是舍入造成。现金法并没有否定行业需求，而是计入全额投入、SBC、采购期限及终值再投资。谁若支持200以上的正常长期价值，应给出对应资本现金路径或更低合理回报要求，不能只引用另一个目标价。

### 6.4 最强反证与最终选择边界

对本报告谨慎判断的最强反证是：**资本比模型更轻、订单预付更好、盈利增长更持久**。例如主要新厂由客户或合资伙伴提供资本，BWXT 保留技术、制造与净收费权；核心2029以后FCFF可持续超过本模型数亿美元，同时无等额稀释，9%成本下价值会明显提高。这比又一个核电市场规模预测更能推翻本报告。

对乐观投资论点的最强反证则是：backlog持续增加但合同期限拉长；商用部件收入增长而单位工时、返工、CapEx和合同资产增长更快；材料工程完工后没有生产费续接；BANR技术达到里程碑，却需要BWXT承担高额自持资本和成本担保。它们会先伤现金和资本回报，未必立即使营业收入下降。

当前不把四行正面格数量当作胜率。主结论对PCG对价±150、医疗净现金±100这类误差相对稳健，对**长期ROIC、增长持续期、终值及投资模式**不稳健；因此提供能翻转结论的参数和证据，而不是装作拥有整股精确胜率、CVaR或市场必达价格。

### 7.3 紧凑复算说明

所有精确计算用未四舍五入工作值，表格一般显示1位小数；由于显示舍入，分部／现金相加可差0.1—0.2。输入变量均在正文收入池、利润率、投入、季度权重、转移参数和资本桥中；不需要其他既有报告的隐藏参数。

1. 读入2027—2031各业务池，按第3.4节增长率延伸2032—2036；政府=N+M+O，商用=C+V+P，集团核心收入=二者之和−8。
2. 核心EBITDA=政府×政府率+商用×商用率−公司费；从核心现金公式推导FCF和FCFF。用第3.3节递推每个机会，按当年状态分别算成本、研发、退出费、税、CapEx、D&A与周转。
3. 将核心与早期现金按季度14/30/22/34%分配；目标日前现金进资本桥，目标日后部分按实际剩余天数、季度中点折现。这是现金时间分配假设，不是价值按持有期缩放。
4. 核心终值与早期状态终值在2036末计算、折现至目标日；加非经营资产和现金、扣本金和其他净索取权，再除经济稀释股数。
5. 股息只进入投资者总回报一次；完整成功价值只替换该机会的期望值，并重算前期资本，不作为额外加项。

概率和时间切分的最小可复算代码（Python标准库；数据取正文表，不依赖隐藏文件）：

```python
from datetime import date

def step(p, a, b, c, d, e, f):
    u, l, s, fail = p
    nxt = [u*(1-a-b),
           u*a + l*(1-c-d) + s*e,
           l*c + s*(1-e-f),
           fail + u*b + l*d + s*f]
    assert abs(sum(nxt)-1) < 1e-10
    assert min(nxt) >= 0 and nxt[3] >= fail - 1e-10
    return nxt

def cash_state(p, old_fail, old_wc, r_l, r_s, u_dev,
               l_margin, l_fixed, s_margin, s_fixed,
               u_cap, l_cap, s_cap, exit_fee):
    u, l, s, fail = p
    revenue = l*r_l + s*r_s
    ebitda = (-u*u_dev + l*(r_l*l_margin-l_fixed)
              + s*(r_s*s_margin-s_fixed)
              - (fail-old_fail)*exit_fee)
    capex = u*u_cap + l*l_cap + s*s_cap
    da = l*l_cap*.25 + s*s_cap*.40
    wc = revenue*.12
    tax = (ebitda-da)*.22
    cash = ebitda-tax-capex-(wc-old_wc)
    return revenue, ebitda, capex, da, wc, cash

def future_quarter_pv(annual_cash, year, target, rate):
    pv = 0.0
    for q, w in enumerate([.14, .30, .22, .34]):
        start = date(year, 1+3*q, 1)
        end = date(year+1, 1, 1) if q == 3 else date(year, 4+3*q, 1)
        if end <= target:
            continue
        remaining_start = max(start, target)
        fraction = (end-remaining_start).days/(end-start).days
        years = ((remaining_start-target).days
                 + (end-remaining_start).days/2)/365.25
        pv += annual_cash*w*fraction/(1+rate)**years
    return pv

def total_return(exit_price, dividend, buy_price=157.59):
    return (exit_price+dividend)/buy_price-1
```
