# DD：经营情景、价值传导与分期限投资决策

研究日期：2026-09-09。信息截止：**2026-09-09 00:00 PDT（03:00 EDT）**。价格基准：**2026-09-08 NYSE 正常交易收盘 131.32 美元**。此后盘中行情与公开信息均不进入判断。

金额除每股数字外均为**百万美元**，股数为**百万股**。研究对象为 DuPont de Nemours, Inc. 普通股（NYSE: DD），交易及模型币种 USD，无 ADR 换算。本报告是依照指定方案独立形成的研究判断；下文的经营假设、局部概率、资本安排和估值区间均不冒充公司指引或统计分布。

## 一、三个期限的当前选择与研究边界

**以 131.32 美元新买入，短期和中期不建议投资；长期以现金复利标准也不建议投资。** 理由是支持最充分的普通经营改善，尚不足以兑现现价所需的增长持续性和现金回报。这个结论不等于公司经营恶化，也不等于预测股票一定向 DCF 值下跌。较乐观的持续经营解释与市场维持较高盈利倍数，确实可能支持正回报；但目前没有足够证据把它们当作普通兑现。

最重要的预期差不是“DD 有没有医疗、水处理或 AI 产品”，而是**医疗和水处理能否持续提高合格交付、每客户净内容量和投入回报，抵消建筑替代、工业周期和遗留责任，使经营价值穿透到每股**。短期信息难以验证十年持续性；一年现金披露可以验证部分利润质量；三年才有机会观察跨客户、跨代产品复购和扩张资本回报。

- **3个月，2026-12-09：不建议投资。** Q3 业绩可以检验医疗、水交付及法律支出，但很难确认跨年复利。当前价格已相当于 2026 指引中点约 18.1 倍调整后盈利；一次普通达标不足以建立重估优势。6个月多出全年现金和 2027 初始展望，信息改善真实，但基准经济价值仍不足。若医疗与水处理同时进入更强持续路径，6个月结论可以改变，3个月不会因一个新品发布自动翻转。
- **一年：不建议投资。** 本研究 NTM 的收入、利润与现金增长均为正，却不足以为当前买价提供 12% 参考回报。重点不是等一季“好财报”，而是核查水处理有机量价、医疗持续耗用和法律净现金支出。相反解释是市场仍愿意用 18—20 倍前瞻调整 EPS 定价；其可能交易回报与现金合理价值须分开。
- **三年：普通现金复利不建议投资；高风险突破目前也不参与。** 乐观路径可支持有条件参与，突破路径回报更高；但独立 DLE 或 Liveo 完整成功并不能单独支持现价下的高风险回报目标。需要医疗与水处理核心经营共同扩大，且增量资本回报较高。核心普通、只赌一个新产品的投资逻辑目前较弱。平台长期更新能力仍有不可判定部分，不能据此否定所有五至十年机会。

经营不变时，三个期限的工作买价大致落在 **95—97 美元**，纳入主估值合理差异后的边界约 **87—107 美元**。这是当前模型的回报门槛，不是机械挂单指令；若价格下跌伴随医疗、水处理或法律现金变差，必须同时下修底稿。当前行动是保留资金和持续跟踪，**尚不能证明“等下一季后择时”一定优于立即持有**；第六节给出相同资金、相同目标日的比较和错失成本。

## 二、公司全貌与决定性证据

### 2.1 四个经营池、两种披露分部

DD 的收费权主要来自合格材料及部件交付。客户为减少污染、停机、重新验证及施工错误而选择产品，但这些客户收益不会全部变成 DD 收入。集团主要在产品控制权转移时确认销售，通常为发货；采购资格与主供应协议不等于不可取消多年最低采购。没有足够公开订单、验收及取消条款建立全集团 backlog 桥，本研究直接用终端使用、等效交付量及实现价建模。

### 2.3 共用证据底稿：机制、竞争解释与独立范围

**A．医疗：接受增长，拒绝把每个客户项目都当净新增。** Olympus 的 2025-09-30 公告指向日本、越南生产的百余类一次性器械自 2026 年采用可再生归属 Tyvek；这是类别，不是百家新客户。客户包装更新首先替代旧材料，只有净价、份额或新用途才增收。Spectrum 已有洁净制造扩张，支持可交付能力的方向，但平方英尺不是合格产能。Sartorius H1 生物制药耗材经营改善提供终端侧支持；它不是 DD 的订单。[Olympus 原公告](https://www.olympus-global.com/news/2025/nr02905.html)、[Sartorius H1 2026](https://www.sartorius.com/en/company/newsroom/corporate-news/2026-half-year-results-sartorius-group-1845854)、[Spectrum 哥斯达黎加扩张](https://www.dupont.com/news/dupont-expands-healthcare-manufacturing-site-in-costa-rica--adding-sterile-packaging-capacity.html)

独立工作范围：医疗常态等效量／内容增 3%—6%，净价格／组合 0%—2%；基准合计 6%，其中普通新品已含在核心。悲观 1% 反映补库消退、客户排产和份额压力；乐观 9%、突破 13% 要求复杂组件内容与合格制造持续提升，而非单纯手术量上涨。更高增速必须持续增加验证、人员和资本。最强反证是收入增速与终端消耗脱钩、Donatelle 客户条件下降，或质量事件导致已批准材料被重新替代。当前证据偏向增长真实，但还未证明双位数持久增长。

**B．水处理：性能优势与供应商议价并存。** 本次直接取得 OCWD 2026-01-14 采购议程，提取 PDF 第85—88页并视觉核对第89页报价：DD 原膜税前每支470美元、税41.13、运费包含，总额511.13；推荐采购1,060支。报告同时推荐购买 Toray 及 WaterSurplus 改性 DD 膜作整列比较。前者证明可竞争替代，后者也说明同一 DD 基材与下游涂层不能重复计营收。28%节能比较仅针对该客户的既有工况，不是2026对所有新竞争产品的领先幅度。采购建议不是本次已经核实的付款。[OCWD 原始采购议程，第85—90页](https://www.ocwd.com/wp-content/uploads/WIC_20260114.pdf)

### 4.2 投资论点与主估值

主理念在三个期限均为**现有现金权益支持的经营改善与持续复利**；短期额外要求信息有机会被采纳，一年核对现金兑现，三年核对更新后的资本回报。这保证主矩阵不会为了制造短期利好临时换成较高市盈率、长期又突然改较低DCF。

主方法为目标日剩余FCFF折现，显式预测至2036，核心剩余价值由已建立的生命周期、增量ROIC和再投资决定。核心折现率8.5%—9.5%，工作9%；对同一组经营条件不因情景标签自动下降。基准终态名义增长2%—2.5%、工作2.25%；悲观0.5%—1.5%，乐观及突破2.5%—3%。低/高端配套使用较高/较低折现率、较低/较高持续增长及非经营资产值，是条件估值外界，不是有相应概率的置信区间。

机会已逐期扣全部研发、资本、周转与失败费用；2036后的价值逐路径计算，保留已经下降的成熟贡献率、研发/支持及收入5%的维持CapEx，以零名义收入增长延续，因此不再占新增周转或成长CapEx。若有限路径在停止成长投资后仍为负现金，2037年支付8退出成本后停止，不能让管理层永久机械投入，也不能免费退出。X及其他已失败路径始终为零；日历推进不会让其概率恢复。没有在加权现金上再任意打一次期权折扣。另有核心平台衰退路径作替代，不把无期限持续作为无争议事实。

### 4.3 同事实下的相反理念：盈利定价与现金复利

本地2026-09-08快照给DD前瞻EPS7.96、Forward PE16.49、EV/EBITDA12.21；源接口没有逐字段预测期与更新时间，因此7.96不作为已核2027一致预期。2026管理层指引中点7.245则可明确计算131.32/7.245＝18.13倍。快照TTM EPS2.33及56.36倍PE受重组、无形摊销、终止经营与期间变化影响，不用于直接估目标价。

**盈利倍数修复论点**：若一年后市场仍认可18—20倍，并把可持续调整EPS认到约8美元，交易价可为144—160；加一年分红对应约11.5%—23.7%回报。这是以明确假设作的**可能交易算例**，不是真实共识或已核同业公允倍数。回购、利息减少和摊销调整可能使EPS快于收入，所以不宜只凭集团3%—4%增长否定它；反过来，EPS未扣遗留现金、再投资与部分调整成本，不能让高倍数自动证明现金安全边际。

该论点当前的选择：短期未能识别重估优势；一年“市场维持倍数且盈利确认”的交易参与只具条件吸引力，当前不作为正面建议。因为需要的不只是业绩达标，还需要市场继续为长期持续性支付价格；近三个月相对市场疲弱与财报上涨回吐，没有给出其必然性。持有要求降到一年8%会使144附近交易实验有吸引力，但不解决普通现金路径低于买价的风险。所需事件是可核的更高经营指引、真实现金增加且法律回款正常；这些能强化论点，仍不能仅用下一季好消息证明18—20倍永久合理。

**较强平台持续性解释**：同基准2036以前现金，若剩余增长改3.5%、折现8.5%，但仍按相应ROIC扣再投资，价值上升。这个实验用于定位长期分歧，不是把“更乐观参数”叫独立估值工具。4.2已有客户资格和组合支持持续更新，水多源报价、建筑替代、收购回报透明度又反对永久高增长。证据目前偏向中速更新；更强持续性仍可辩护，但单独不足以让基准在131.32下达到10%三年年化要求。若要求降低到约5%，部分较强持续性解释可翻为谨慎参与，须明确接受其假设与机会成本。

### 4.4 现价究竟要求什么

研究日起基准NTM收入约7,397、经营EBITDA1,817、FCFF958；用约17,733市值＋1,385简单净债务得到EV约19,118，约10.52倍这一NTM经营EBITDA，FCFF/EV约5.0%，尚未另扣遗留现金及养老金。该EV只是用于价格要求的标准化粗桥，不能当精确实时经营价值。

一阶稳态反求：假设FCFF可以持续增长且无需额外削减现金、折现9%，5%的现金收益率需约4%持续增长才支持同量级EV。真正模型还要付出再投资和法律净支出，因此现价可以由“更高增长、较高资本效率、较低风险补偿、较多非经营资产”等不同组合解释，不能唯一识别市场真实共识。基准预测短期成长存在，但到成熟期减速至2%—2.5%；乐观／突破依靠更大的合格交付和内容量拉高整个未来现金基座，这才是主要分歧。

在当前131.32买价下，一年12%总回报要求目标权益加现金147.08左右；三年10%年化要求174.79左右，扣基准累计分配7.20后需股价约167.59。基准工作三年价值明显不足；乐观工作值接近这一门槛，故其评级对价格、资本成本及利润持续性敏感。单一新机会是否足够，见第六节独立实验。没有把现价反求规模用作正向经营预测来源。

季度、状态与价值核心复算式：

```text
集团收入 = 医疗核心 + 水核心 + 工业 + 建筑 + E[Liveo净增] + E[DLE净增]
核心EBITDA = (医疗+水)*HWT率 + (工业+建筑)*DI率 - 总部 - 15投资收益
机会状态EBITDA = 状态收入*对应贡献率 - 状态专门费用
机会状态现金税 = max(状态EBITDA - 状态折旧, 0)*25%
机会状态FCFF = 状态EBITDA - 状态现金税 - 状态CapEx - 状态Δ周转
E[机会FCFF] = Σ(同一路径概率 * 路径FCFF)
核心FCFF = 核心EBITDA - 25%*max(核心EBITDA-折旧,0)
             - 全CapEx - Δ周转 - 其他现金调节
成熟核心CapEx = 折旧 + 核心NOPAT*g/增量ROIC - Δ周转
TV_core_2036 = 核心NOPAT_2036*(1+g)*(1-g/增量ROIC)/(r-g)
TV_op_2036 = Σ(路径概率 * 成熟维持FCFF/r)，负现金有限路径改为2037退出成本现值
目标日EV = 目标日后季度FCFF现值 + (TV_core+TV_op)折现至目标日
资本现金 = 1740 + 累计FCFF - 税后净利息 - 法律净支出 - 养老金填补
           - NCI分配 - 普通分红 - 额外回购
完全稀释股数 = 135.038855 + 0.9 - Σ(额外回购金额/成交假设价)
股权价值 = EV + 非经营资产 + 现金 - 债务 - 养老金剩余 - NCI价值
           - 尚未支付法律净现金PV - 公司已除息未付股息
总回报 = (股权价值/稀释股数 + 买方已收现金 + 买方已除息应收)/131.32 - 1
```

季度FCFF按有效剩余日数分配，折现至该段中点；终值置于2036年末。法律现金在2036以前按季度、2037—2050每年20按年中支付，统一6%折现。已有年度法律负债不另加重复扣项。养老金工作负债每付一笔减少同额剩余，偿债同时减债/减现金；未来股薪已费用化，CFO加回后以中性回购冲销，不再让股数额外永久增长。
