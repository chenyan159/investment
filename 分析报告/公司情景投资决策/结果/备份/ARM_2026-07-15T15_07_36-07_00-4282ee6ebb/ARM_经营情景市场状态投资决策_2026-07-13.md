| 方向 | 逻辑 | 为什么决定价值 |
| --- | --- | --- |
| 最强正面逻辑 | Arm 从 ISA / CPU IP 收费站向 CSS、系统 IP 和自有 AGI CPU 连续提高单颗 / 单机架收费内容量；数据中心 royalty 已经多季翻倍，Armv9→CSS 的费率阶梯具已实现证据 | 若 IP 收入维持约 20%增长，同时 AGI 证明 40%—50%毛利与真实订单，FY2031 收入 / FCF 可跨入乐观或突破区间 |
| 最强负面逻辑 | 当前约 $316.2B 经营性企业价值已经把管理层 FY2031 目标之后的多年高增长也资本化；AGI 尚无硅片收入、非标准 backlog，SBC 和营运资本又削弱每股现金转换 | 小幅低于预期不只是少赚一季，而是压缩 40×—60×收入倍数和长久期终值，价值损失可远大于收入下修 |
| 决定胜负的经营变量 | **AGI 可验收收入对应的毛利与现金，而不是生态名单或需求口径** | 它决定 Arm 是扩大高质量利润池，还是以低毛利、库存和渠道冲突交换表观收入 |
| 决定胜负的市场变量 | **10 年实际利率 / 长久期风险溢价** | 当前估值主要依赖 2031 年之后现金流；信用正常时仅利率上升也足以让同一经营结果从主题列迁移到震荡或有序收缩列 |

最强反证必须分层：数据中心 royalty 与 CSS 已经证明 IP 上行并非纯叙事；但它们不能证明 AGI 的客户采购量、产品毛利、供给和验收，也不能证明 50×以上 NTM 收入倍数可持续。反过来，AGI 初期毛利较低也不自动否定公司价值；如果绝对毛利、现金回收和每股 FCF 快速增长，综合毛利率下降可以是健康的业务混合变化。

### 4.3 反向 DCF：增长与利润率的隐含边界

以下只是边界求解，不是假装唯一答案。统一从 NTM $6.2B 收入、18% 起始 FCF 率出发，逐年爬坡到 FY2031 正常化 FCF 率，并在 FY2031 进入稳定终值。求使当前经营性企业价值 $316.2B 成立的 FY2031 收入：

| 边界 | WACC | 终值增长 | FY2031 FCF 率 | 隐含 FY2031 收入 | NTM→FY2031 收入 CAGR | 隐含 FY2031 FCF |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 极宽松 | 9.0% | 4.0% | 45% | **约 $47B** | **约 66%** | 约 $21B |
| 中性 | 10.5% | 3.5% | 40% | **约 $78B** | **约 88%** | 约 $31B |
| 审慎 | 12.0% | 3.0% | 35% | **约 $120B** | **约 110%** | 约 $42B |

这些数值不是说 Arm 必须在 FY2031 达到 $47B—$120B，而是说明“FY2031 立即进入稳定期”的五年 DCF 与当前价格不相容。若先采用管理层 $25B FY2031 收入目标、42% FCF 率，再把高增长期延长五年，当前 EV 大致要求：

- WACC 约 9%：FY2032—FY2036 收入仍需约 20% CAGR，FY2036 收入约 $62B；
- WACC 约 10%：延续期需约 27% CAGR，FY2036 收入接近 $85B；
- WACC 约 11%：延续期需高于 30% CAGR，且终值仍不能迅速成熟。

因此当前价格隐含的组合接近：

1. NTM 至少处于乐观上沿或突破路径；
2. FY2031 接近或超过公司 $25B 目标，AGI 接近 $15B 且产品毛利向 50%靠拢；
3. IP 收入仍保持约 20%增长，不能被 AGI 渠道冲突、architecture license 绕开 CSS 或 RISC-V 明显侵蚀；
4. FY2031 之后至少再维持五年 20%—30%增长；
5. SBC / 股数增速显著低于收入和 FCF，且净现金不被库存、预付款和应收吞噬；
6. 长期资本成本维持低位，主题溢价没有回到成熟 IP / 半导体公司的正常水平。

前两项接近乐观 / 突破经营行；第三至第六项目前证据不足。尤其“生态支持”“可见需求 >$2B”和“约 $1B supply-backed”均不能替代不可取消订单、可验收收入、产品毛利和现金回收。

### 5.2 悲观 / 受损

核心破坏路径不是只有倍数压缩，而是 RPO 与新 license 补充继续弱、数据中心 royalty 正常化过快、移动量与收费内容量同时低于预期、AGI 延迟且先形成预付款 / 库存、费用和 SBC 刚性压低现金转换。资产负债表仍避免近期融资危机，但每股永久损失来自长期收入池缩小、渠道冲突和持续稀释。

- 进入条件：FY2027 Q1 收入低于 $1.21B；ACV 增速低于 10%且 RPO 连续两季同比低于 -10%；数据中心 royalty 连续两季低于 25%；AGI 推迟至 2027 年。
- 最早确认：2026-07-29 可确认 license / RPO 方向；2026Q4 可确认 AGI 是否延迟。
- 失效条件：RPO 恢复增长、数据中心 royalty 保持高于 50%、AGI 生产系统按期且现金占用受控。
- 永久损失观察：客户转 architecture license 减少 CSS 内容量、RISC-V 高端采用、SBC 长期高于收入增长、Arm China 回款恶化。

### 5.3 基准 / 正常兑现

IP 是基准锚，AGI 只占 NTM 收入约 4%。Royalty 约 $3.20B、license $2.75B 与 Q1 约 +20%的指引一致；AGI $0.25B 对跨 FY2027—FY2028 的约 $1B 供应支持已经作大幅折扣。毛利率下降来自业务混合，绝对毛利与营业利润上升。

- 进入 / 维持条件：Q1 指引兑现；ACV ≥15%、RPO 企稳；数据中心 royalty 明显快于全公司；2026Q4 AGI 系统可用。
- 最早确认：2026-07-29；AGI 需要延后到 2026Q4。
- 失效条件：收入达标但 FCF 低于约 $0.8B 年化、应收 / 合同资产继续快于收入增长，或股数增速超过约 3%。
- 关键限制：基准经营并不等于基准估值；在当前价格下，基准现金流仍明显不足。

### 5.4 乐观 / 超预期

至少三个公司特定传导同时强于预期：数据中心 royalty / CSS 内容量、license / RPO 补充、移动高端 mix，以及 AGI 具名客户、供给和验收。AGI $0.65B 需要多 OEM SKU 和更多具名部署，而不只是生态支持。

- 进入条件：ACV >25%、RPO 恢复同比增长；数据中心 royalty 继续接近 100%；AGI 退出年化供给 >$1.4B、至少 8 个部署客户、产品毛利 40%—45%。
- 最早确认：Q1 可验证 IP；2026Q4—2027Q1 才能验证 AGI。
- 失效条件：AGI 无独立 TCO / benchmark、客户验收后移、毛利低于 35%，或 AGI 增量同时导致 CSS 客户流失。
- 经济量级：FY2031 大体达到公司 $25B 目标，但当前价格仍要求窄幅主题溢价或更长高增长期。

### 5.5 突破 / 非线性

突破不是把所有好消息相加，而是 IP 与 AGI 两条经济链同时完成：IP 收入继续高增且不因渠道冲突受损；AGI NTM 超过 $1B、毛利趋近 45%—50%、多云 / 多 OEM 量产；FY2031 收入显著超过 $25B，FCF率进入 40%以上。

- 前置条件：新增可交付供给使 AGI 年化 >$2B；不可取消订单 / 预付款可验证；独立性能 / TCO 达标；多云实例上线；第二代路线明确；IP royalty 仍保持约 20%增长。
- 时间表：最早 2026Q4 出现产品证据，2027H1 出现财务证据，2028—2031 才能确认非线性规模。
- 反证：AGI 高于 $1B 只靠渠道库存、产品毛利低于 40%、IP 客户减少 CSS 采用，或 FY2031 后增长迅速成熟。
- 证据结论：商业路径存在，因此不写 NA；但当前支持程度低，不能用于当前定位。

### 5.6 当前复合经营定位

复合模型统一使用收入 $6.0B—$6.3B、GAAP 营业利润率 18%—22%、FCF $0.75B—$1.10B、净现金 $2.6B—$3.5B、完全稀释股数 1.11B—1.14B，以及 FY2031 收入 $16B—$19B、FCF率 30%—36%。它不是从基准行取收入上端、再从悲观行取有利现金端，而是对高应收 / 合同资产、SBC 和 AGI 营运资本作一致下调。

- 最小上移：Q1 指引兑现、RPO 企稳，同时 SBC / 收入降到 20%以下或 FCF 年化超过 $1.1B；若再出现 AGI 具名订单与供给，结束复合状态并上移到纯基准 / 乐观。
- 最小下移：Q1 低于 $1.21B且 RPO 再次两位数下降，或 AGI 推迟到 2027 年并形成 >$0.3B 库存 / 预付款占用。
- 最接近纯行：基准；最重要冲突变量是每股现金转换，而不是收入确认本身。

### 6.2 事件树与不重复计价

**AGI 主树：**

1. 订单质量通过 → 供给锁定 → OEM / 软件认证 → 独立性能 → 客户验收；五步都通过才进入乐观 / 突破 AGI 收入。
2. 订单存在但供给 / 认证延迟 → 收入由 FY2027 后移，不等于需求永久消失；进入悲观 NTM，但远期路径未必损毁。
3. 供给到位但性能 / 毛利不达标 → 可能形成库存、折价和渠道冲突，是永久价值风险，不只是时点后移。

**IP 主树：** ACV / 新签 → RPO / 履约 → 客户 tape-out → 系统量产 → royalty。RPO 恢复只上修 license 可见度，不能同时再加一份未来 royalty；royalty 出货证据出现后才迁移收入桶。

| IP + AGI 分部估值 | 交叉验证 | IP 是近纯软件收费站，AGI 是低毛利 / 高营运资本的新硅片业务，不能用同一倍数；同时检查渠道冲突和内部 IP 不重复收费 |
| 当前定价 / forward EPS | 市场门槛检查 | 说明当前 97× forward PE、51×基准 NTM EV / 收入已经要求何种兑现；不作为价值锚 |

参数纪律：

- 同一行的收入、利润、FCF、净现金和稀释区间在五列不变；市场只改变风险溢价和目标倍数。
- 主题列只在 ARM 有真实收入传导时给予高端；悲观行因“高预期失误”反而略低于宽基列。
- 有序收缩和流动性压力不把客户预算下修偷偷塞进原格子；若预算真的改变，另用状态联动迁移到悲观行。
- 格子估值按 经营性企业价值 + 净现金 − 其他优先索取权，再除以对应完全稀释股数。净现金区间已包含 DreamBig、AGI 占款和 FCF，不再次加现金。

统一计算式为：

- 股权价值 = 经营性企业价值 + 现金及非经营资产 − 债务及其他优先索取权；
- 每股价值 = 股权价值 ÷ 情景下完全稀释股数；
- 目标期股东总回报 =（目标期每股价值 − $298.99 + $0 分红）÷ $298.99。

| 条件正面区域 | 正面不是广泛区域，而是经营突破、真实 AI 收入传导和主题风险偏好同时存在的窄区域 |

最稳定区域是基准及以下三列：不论宽基、主题还是震荡，条件价值均显著低于现价。最脆弱边界位于突破行的主题 / 宽基 / 震荡三列：主题列谨慎正面，宽基和震荡转为中性。最坏格子为悲观 × 流动性压力，每股 $25—$45、损失 85%—92%；原因是 license / AGI 兑现受损、费用和现金占用刚性，加上长久期倍数失效，而不是近期破产。

### 12.3 每个市场状态的关键价格边界

下表用每个纯格子价值中点除以 1.18，求“中点刚好达到最低 +18%研究回报”的当前价格。它是敏感性边界，不等于自动评级；若要求价值低端也达到门槛，价格还需更低。

| 市场状态 | 基准价值中点 | 基准中点 +18%价格 | 乐观中点 +18%价格 | 突破中点 +18%价格 | $298.99 下的含义 |

### 12.4 最小可观察变化

**使当前建议增强：**

1. 价格因素：在当前复合 + 宽基 / 板块退出条件下，价格先降至约 $156 才触及价值上沿；约 $120—$132 才形成最低研究回报的初步不对称。
2. 经营因素：Q1 指引兑现、RPO 企稳、数据中心 royalty >50%，同时 AGI 出现 8+部署客户、年化供给 >$1.4B、毛利 40%—45%和按期系统；这会把复合定位上移至乐观 / 突破。
3. 市场因素：10 年实际利率回落、信用稳定，且主题重新聚焦有已确认收入传导的 AI 公司；只有突破路径下才足以在现价形成谨慎正面格。

**使当前建议减弱或价值继续下降：**

1. FY2027 Q1 收入低于 $1.21B、ACV <10%、RPO 连续两季低于 -10%；
2. AGI 推迟到 2027 年、缺少独立 benchmark、产品毛利 <30%或形成显著库存；
3. 10 年实际利率升破约 2.5%，同时 HY OAS 向 4%扩张；市场由宽基 / 震荡迁移到有序收缩；
4. Arm China / 关联方应收继续上升或 SBC / 收入持续高于 22%，把基准收入转成更弱的每股现金流。

### 12.5 重要状态联动

| 状态联动 | 传导变量 | 原纯格子 | 更可达的联动格子 | 不重复计价规则 |
| --- | --- | --- | --- | --- |
| 实际利率上升但信用正常 | 只改变长久期风险溢价 | 基准 × 宽基扩张 | 基准 × 震荡 / 有序收缩 | 经营收入不变，只迁移市场列 |
| 有序收缩延后云厂 / 企业预算 | AGI 采购、license 新签、客户 tape-out | 基准 × 有序收缩 | 悲观 × 有序收缩 | 原格先回答“经营不变”；只有订单 / 指引下修才迁移经营行 |

最能改变当前条件定位的组合是 **AGI 从非标准需求转成可验收高毛利订单 + 市场由当前半导体退出转回真实收入驱动的主题上涨**。相反，最危险组合是 **RPO / AGI 同时下修 + 实际利率和信用利差共同上升**。
