# BE：经营评估、价值传导与市场情景投资决策
研究日：2026-09-07；唯一正式报告；金额除每股价格、特别标注外均为**十亿美元（$B）**，股数为百万股（M），容量为 GW。表内小数用于复核，不表示预测精度。

## 1. 冻结时点与本方法结论

**三个月：不建议以 252.87 美元建立依赖经营价值兑现的新多头头寸；短期指数纳入资金可能支持价格，不能据此推导三个月会下跌。六个月：不建议投资，且基准经营正常兑现时的价值支持明显不足。** 两个期限的判断均允许被更强的公司捕获、产能、单位经济和回款证据推翻，并非把缺少完整概率分布当作无法判断。

当前经营定位采用**基准 / 正常兑现，状态证据强度中**，无须复合定位。当前市场为**边界 / 未锁定**，并列**宽基风险扩张、震荡 / 均值回归**。本报告没有把 BE 的强势表现改写为全市场主题上涨。完整矩阵中只有“突破 × 宽基扩张”和“突破 × 主题上涨”达到**谨慎建议投资**，两者低端仍分别有约 35%、29% 损失；它们不代表当前证据已经支持突破。

核心预期差不是“有没有 AI 电力需求”。公司已有真实增长，独立基准支持 2026 年收入约 39.7亿—41.9 亿、2027 年 50亿—58 亿。难点是：现价对应的约 744.8 亿基本市值、约 818.7 亿现时全转换稀释权益参照，要求远大于正常兑现的持续经营结果。最弱传导环节是**项目交付与持续利润能否支持长期多 GW 的公司捕获及其终端现金收益**；制造、终端许可和售后责任共同限制这个转换。净债务细项和正常扩产支出不是本结论的首要原因。

**上游不是来源装饰。** 行业基准的主要发电设备资产完成价值2027年约9.6—11.3B、2028年12.5—14.7B，BE的2027 DC设备收入中枢约3.45B，已经需要在SOFC适用项目取得较强捕获。两者会计确认期、地域和设备范围不同，不能称为经核实30%左右份额，只能发现BE增长对大项目依赖的数量级。行业2027年悲观仅2.8GW新主供投运，足以容纳BE交付受损行；行业乐观加国际渗透才容纳更高行，不能沿用基准5.5GW却让BE无限增加份额。[L2]

公司供给的独立约束来自年末2GW目标及供应商MTAR分阶段扩产，而不是把收入除以假定价格所得的量再称“产能证明”。2027年2GW平均名义能力，乘85%—93%有效系数、减0.15—0.25GW维护占用，约容纳1.45—1.71GW新设备。基准1.55GW在其中；乐观1.9—2.1GW及突破2.15—2.4GW都要求提前增加合格能力或存在可核验库存支持。[L1]

净设备价中枢3.2→3.0→2.9百万美元/MW的下降，来自大客户折让、客户对价摊销、产品组合和2028年起竞争供给增加。不是因为“涨价慢了”等同价格下降；价格缺少独立MW披露，因此保留区间和敏感性。安装减少可降低收入却改善集团毛利，不能机械延长历史安装占比。

### 4.5 3—5年供需与终值前放缓机制

悲观由项目延误、低利用率与售后压力导致2028年收入先降；其后有限增长来自既有客户维护和工商业替代，不假设技术消失。基准2029—2031需新增产线、保留美国时间溢价并逐步扩国际，设备净价下降由成本下降抵消；新燃机/发动机供应、成熟接网和大客户自建削弱加急溢价，因此增速有具体放缓原因。乐观是更多地区持续缺电、客户复购、服务密度提高；突破还须国际渠道和大客户采购分散，超越现有厂房空间，不能只依赖美国单一项目。

2032—2036仍逐年增加收入，并按增量ROIC计入净再投资；终值增长只是这段过渡后的结果。增长下降机制的先行证据为竞争者设备交期缩短、已建园区转网/降低SOFC利用率、设备净价与服务续约下降；反证为多地区仍连续签长约、竞争产能延期且客户愿付更高净价。反证成立时可延长成长，不能机械沿用本次渐降参数。

## 7. 估值方法、资本桥与二十格参数

### 7.1 主方法及现金流勾稽

**主估值：完整逐期经营FCFF折现。** 前五年逐项扣除全部成长及维持投入，并把形成的收入、成本下降、服务和资本效率全部纳入；2032—2036继续建模；2036后才用稳定增长。成长项目不另外加NPV，SOEC/CCUS没有独立期权金额。净营运资本已反映客户预付款，最低运营现金只作存量资本扣留，后续增量仍按表投入。

目标日为2027-03-07。2027年度FCFF只计目标日后299/365的部分，之后各年全计，按各年末相对目标日折现；目标日前积累已在现金桥，不再计入经营EV。季度现金集中度会造成时点误差，采用年末而非年中折现；不是把长期目标价按半年比例压缩。

2032—2036计算：
- 收入按下表增长；
- NOPAT=当年收入×2031经济利润率×78%；
- 净再投资=当年新增收入×2031经济利润率×78%÷增量ROIC；
- FCFF=NOPAT−净再投资。此处净再投资包含净CapEx、净营运资本和项目资本；不再扣前五年的整组投资数，維持性支出与折旧在净口径中抵销。
- 2037稳态FCFF=2036收入×(1+g)×经济利润率×78%×(1−g/ROIC)。

### 10.2 顺序事件树

```text
已知：真实采购/收入增长 + 高现价 + 指数纳入公告
├─ 指数生效/资金提前交易 → 短期供求改善或兑现后回吐（不改经营行）
└─ Q3/项目进度的信息确认
   ├─ 交付延迟但采购/回款仍保护 → 基准低端；等待AEP/全年确认
   ├─ 多项目接收+毛利/合同资产共同恶化 → 悲观（融资收紧时与收缩列联动）
   └─ 交付与净成本、现金同时改善
      ├─ 2027仅约5.0—5.8B、2GW能力 → 基准；高股价仍缺价值支持
      ├─ 新有效能力和多客户支撑6.2—7.0B → 乐观；当前价格仍要求更长成功
      └─ 7.2—8.0B且2028扩线/合约/ROIC闭合 → 突破候选
          ├─ 宽基/主题且买价≤P+ → 谨慎正面
          └─ 震荡/更高折现或股价已透支 → 中性边界以下，当前仍不建议
```

AEP、Oracle、基金和制造里程碑相互依赖，不把各自“成功”当独立可相加概率。指数事件可与任一经营分支并存，不能自动给突破概率。

**三至六个月如何变化：** 三个月可能由指数纳入和首轮信息推动，市价与合理价值之间可以继续有大幅溢价；六个月的新增信息更接近决定现金价值的采购、合格能力、利润和营运资本。基准在三至六个月继续增长，因此不能把“没有投资安全边际”写成“公司停止成长”。若更强采购和真实回款逐步确认，吸引力可以增强；若只有日立合作、设备框架和单季超预期而无单位经济/能力闭合，短期价格吸引力可能随着配置完成而消失。反之，若市价大幅下降而经营仍按基准兑现，吸引力也可改善，无需先等到突破。

**最强反面解释：** 本模型可能低估数据中心缺电的持续时间、制造学习曲线和国际扩散；若BE具有比25%—30%更高且可持续的新增资本回报、能在2031后维持更长高速增长，完整DCF会显著上升。市场可能已经较本报告更准确地看到了该路径；现有公开证据尚不足以把它作为基准。以突破高端替换基准不是正确处理，应该获得新客户/产能/服务证据后显式改整条路径。

**判断失效的优先触发：** 不是某个股价上涨百分比，而是2027交付能力超过约2.2GW且对应非重叠采购、毛利及回款可信、2028继续扩张所需资金与ROIC闭合；反向是多个项目/季度延期、调整毛利连续低于32%或现金义务显著扩大。三个月不建议不等于做空建议，也不表示借券/期权交易已研究。

def cell_value(R, margin, capex, wc, project, cash, shares_m,
               fade_growth, terminal_g, roic, discount):
    tax = [0.10, 0.15, 0.20, 0.22, 0.22]
    t = 299 / 365  # 2027-03-07 to 2027-12-31
    cf = [
        R[k] * margin[k] * (1-tax[k]) + 0.015*R[k]
        - capex[k] - wc[k] - project[k]
        for k in range(5)
    ]
    pv = sum(cf[k] * (t if k == 0 else 1)
             / (1+discount)**(t+k) for k in range(5))
    revenue = R[-1]
    for k, growth in enumerate(fade_growth):
        previous = revenue
        revenue *= 1+growth
        nopat = revenue * margin[-1] * 0.78
        net_reinvestment = (revenue-previous)*margin[-1]*0.78/roic
        pv += (nopat-net_reinvestment)/(1+discount)**(t+5+k)
    terminal_cf = (revenue*(1+terminal_g)*margin[-1]*0.78
                   * (1-terminal_g/roic))
    ev = pv + terminal_cf/(discount-terminal_g)/(1+discount)**(t+9)
    capital_add = cash - 1.045
    diluted = shares_m/1000
    value = (ev+capital_add-2.5)/diluted
    if value >= 194.97:
        diluted += 0.0128225
        value = (ev+capital_add)/diluted
    value = max(0, value)
    return ev, value*diluted, value, value/252.87-1

def first_positive_price(low, high):
    v60 = low+0.6*(high-low)  # range position, not a probability
    return min(v60/1.15, low/0.60, (high+1.4*low)/2.4)
