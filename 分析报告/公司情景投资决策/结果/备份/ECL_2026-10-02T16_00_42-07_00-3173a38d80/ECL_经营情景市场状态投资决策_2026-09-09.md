## 1. 当前判断、价格口径与适用范围

**当前价格278.11美元下，短期和中期不建议按现金回报逻辑新增投资；长期同样缺乏现金安全边际，但必须保留“长期维持优质复利溢价”的实质分歧。** 最有依据的经营路径是成熟业务改善、High-Tech持续扩张、Life Sciences正常化增长；不是业务全面失速。问题在于收购取得增长的成本、后续资本投入，以及市场为持续性支付的价格。本文基准2027年调整后EPS约9.09美元、2029年约11.34美元，已经包含利润率改善，并非把公司按零增长估值。

主估值DCF-A按相同美元现金权益、全部投入和7.5%—8.5% WACC计价。下列价值是**目标日条件合理价值，不是预测届时一定成交的价格**。没有证据表明ECL的长期溢价会在半年内消失，因此不能把DCF差额写成确定下跌空间或做空收益。

## 2. 公司全貌与决定性证据

Ecolab以化学品、设备、检测和现场人员，解决客户清洗、卫生、水质及生产可靠性问题。收费基础是处理批次、使用强度、设备安装和实际服务，不是全球缺水价值或AI算力总额。它拥有可重复消耗和服务网络，但收购液冷及超纯水后，更多收入受设备更新和项目交付影响。Nalco属于集团工业水能力；Purolite属于Life Sciences；High-Tech从Water内拆出建模；Digital已分配在使用它的业务中，不再追加一个“数字化市值”。

### 2.3 决定性主张、相反解释及独立范围

**A. CoolIT是实际业务；它是否是好收购仍未证明。** 3月交易材料第11—13页给NTM收入约0.55、调整EBITDA率约30%、对价4.75及29倍NTM/24倍2027 EBITDA。隐含初始EBITDA约.165、收益率约3.5%，尚未扣税和投入。这里NTM是3月交易时的滚动期间，不能当9月NTM或2026审计收入。[交易演示](https://s204.q4cdn.com/218790897/files/doc_downloads/2026/03/Ecolab-to-Acquire-CoolIT-Systems.pdf)

2月CoolIT公布月产数百CDU、数千歧管和数万冷板回路，支持工程化供给的数量级；这种“数百”不能反算精确单价。以年CDU约2,400—9,600台、每台净系统份额5万—15万美元作范围试算，单CDU收入可达.12—1.44；跨度说明配置差异太大，必须与.55收入锚同时约束，不能把所有端点相乘。冷板回路亦已包含在组合收入，不能再将整机预算加一遍。主路径因此用可观察销售锚加交付/净价值指数，独立给2027收入.58/.70/.80/.85四行，再受后续增长、利润与现金约束。[CoolIT制造披露](https://www.coolitsystems.com/resources/news/coolit-25-years-liquid-cooling/)

相反解释是客户双供、单位MW器件数减少和硬件净价下降。实际制造反驳了“技术尚未可用”，却不能反驳“规模增长但资本回报低”。这使基准收入方向偏增长，但没有照单全收高利润永久持续。

**B. “High-Tech 40亿美元”是目标，不是合同权益。** 7月2日公告确认交割，并将组合年化销售描述为接近1.5、2030目标4.0及25%营业利润率。2026确认收入还受CoolIT半年度并表约束。1.5至4.0约需四年28%复合增速；本模型基准2030的三项既有High-Tech加增量服务约3.16，乐观约3.99，突破约4.95。基准与目标的差异主要来自CoolIT净价及合格交付、Ovivo项目节奏和服务净收费，没有再对同一行业供电约束重复扣一次增速。[完成收购公告中Global High-Tech段](https://investor.ecolab.com/news/news-details/2026/Ecolab-Closes-CoolIT-Acquisition-and-Expands-AI-Cooling-Platform-as-Global-High-Tech-Business-Targets-4-Billion-by-2030/default.aspx)

## 6. 投资理念、目标日价值与方法分歧

### 6.1 主理念与统一估值DCF-A

主论点是**有持续更新能力的经营现金复利**：低单项采购占比、现场服务及工艺嵌入支持留存，增长投入可以形成经济利润；但必须在收购债务、维持/成长资本、SBC之后补偿普通股买价。无需DAC或PFAS重磅成功；失败机制主要是净价/使用量受压、并购回报低和增长持续期不足。三个期限均使用该现金权益框架，短期补充信息重估机制，不能到某一格改用更有利的PE。

### 6.3 最强相反理念：长期溢价复利

长期机构可能接受较低当期现金收益，要求未来仍有市场买方为品牌、服务网络、客户嵌入及增长支付28—32倍滚动盈利。该论点有商业基础：客户采购并非只看化学品单价，重要现场服务和质量能够持续存在。它不是“PE工具比DCF好”，而是对更新期和未来风险补偿作了更强假设。

共用完全相同的经营和股数，只改变目标日估值解释：

| 目标日 | 同一基准NTM EPS | 28—32倍退出价 | 含分红总回报 | 达到10%年化所需PE |
|---|---|---|---|---|
| 2027-03-09 | 9.27 | 259.6—296.6 | -6.1%至+7.2% | 31.29倍 |
| 2027-09-09 | 9.80 | 274.3—313.5 | -0.3%至+13.8% | 30.91倍 |
| 2029-09-09 | 12.05 | 337.5—385.7 | +24.8%至+42.2% | 29.91倍 |

三年30倍对应约361.6美元，加分红后的总回报约33.5%、年化约10.1%；29倍则约349.5美元、年化约8.9%。所以这不是稳健的10%复利承诺，**约1倍PE足以翻转选择**。若目标日只给25倍，同一EPS仍有约11.8%累计正回报，但年化仅约3.8%；有盈利增长也可能明显跑输资金机会成本。

为检查方法一致性，另将基准2032—2046真实收入增长保持6%、利润率21%、新增ROIC20%、每期足额扣资本：8% WACC下三年价值约276.7美元，7.5%约314.8、8.5%约245.8。即使多保留十年增长，仍不能自动得到30倍对应的361.6。要接近后者，还须更高现金转换、更长/更快更新、或明显更低折现率。高PE不能在保持同样现金和风险假设时凭工具切换平白创造价值。

**当前取舍：** 保留溢价复利条件参与逻辑，但不将其纳入主矩阵中枢。若投资者愿接受8%而非10%年化、能够承受30%及以上估值回撤，并判断29—30倍可延续，长期参与有经济解释；本研究认为经营护城河的证据强于该倍数可持续的证据。在10%要求下尚无明显优势，优先不新增。这里的不参与既包含价值不足，也包含尚不能区分的持续性解释，不能简单宣称“市场一定错”。

## 7. 反向要求、敏感性、成功参照与等待代价

### 7.1 现价并不唯一识别市场共识

278.11美元约对应78.48十亿美元稀释市值、加研究净债与其他权益后约91.28经营价值。保持各行现金完全不变，反求今天价格所需WACC：悲观约4.4%、基准约6.57%、乐观约7.33%、突破约8.07%。它说明“8%左右资本成本+接近突破的更长增长”与现价相容；不是说市场真实给突破100%概率。另一个相容组合是普通经营加长期极低风险补偿，或现金转化远超本模型。必须用新增证据区分，而不能把反算结果再作为收入预测来源。

基准模型2026—2030 EPS由8.14增至12.41，约11.1%复合；公司12%—15%长期算法更高，但差距尚不夸张。主要差异来自High-Tech未完全到4.0、利息和转化为现金的投入。若2030达到4.0且25%分支利润率，相对基准High-Tech约3.16及自身组合利润，会增加经营利润而非等比例提高全集团估值；还须扣投入和现金桥。

### 7.4 高风险突破的概率要求与证据

不能把四行当成概率全集。就“本文已量化的突破规模”这一条件实验，三年8% WACC中值29.6%总回报，甚至7.5%上端约47.2%，仍低于15%年化对应52.1%、20%对应72.8%。因此采用15%—20%要求时，**无需编造整体成功概率，也能拒绝把此规模当有吸引力的高风险押注**。更大的成功不是逻辑上不可能，但需另有超过当前4.95 High-Tech规模、持续净收费或更长更新期的证据；现有制造规模和产品演示只证明机会存在，不足证明该更高成功程度。

对于10%年化的溢价复利逻辑，主要未知并非局部服务S概率。基准2031局部S概率约38%，不能拿来作为整股“是否保持30倍”的概率。若进行市场倍数分支的期望决策，需要有可辩护的利率、盈利和定价联合分布；本次未取得足以支持精确概率的历史同口径事件样本，故不报告胜率、P50或CVaR。

### 7.5 立即买入与等待：同一资金、同一2027-09-09目标日

选择11月17日投资者日后的首个观察窗口，算例以2026-11-18执行。双方初始资金278.11美元，现金4%年化约70天增至280.21；先持现金并不保证能以更好价格成交。立即买入一股，到目标日获得模型每股价值与约3.05分红。等待方只在证据/价格匹配时买入，可买股数=280.21/届时股价，并取得观察后约2.32分红；若不买则现金至原目标日约289.23。以下价格均为**策略算例，不是市场预测**。

## 8. 条件建议矩阵与十二格明细

主矩阵固定采用现金价值复利理念：半年参考总回报要求6%（邻近4%—8%），一年10%（8%—12%），三年年化10%、累计33.1%（邻近年化8%—12%、累计26.0%—40.5%）。这些是本研究参考标准，不冒充投资者真实偏好；与DCF的资本成本不同。没有使用杠杆，能够按期限持有；稳健资金关注普通偏差与永久损失，不能承受20%—30%正常估值回撤的资金应提高参与边界。高风险15%—20%参考标准只用于第7.4节，不在各格临时替换主标准。

所有格已经包含第4节行内概率加权新服务，核心里程碑按第3节固定。条件评级不因该行发生概率低而压级，也不因短期价格尚未采纳而压级。评级只检验固定路径下资本/价值参数及回报要求。悲观各格严重不足；基准/乐观仍缺主标准回报；突破半年和一年虽中值略过门槛，但余量小于合理估值误差，三年中值年化9.0%又低于10%，因此均“中性 / 等待”。这里的等待只表示经济优势不清晰，不代表事件等待策略已经被证明更优。

情景证据强度：悲观中低（有压力机制但尚非主路径）；基准中高（近期量价和现金基础支持，持续期仍有不确定）；乐观中低；突破低。估值置信度另看条件价值：悲观中，其余低，主要来自终值、服务净收费及未来资本回报。二者都不是概率。

### 9.3 复算方法与已完成的核验

已核验H2收入与指引桥、收购前后净债不重复计发债、四行情景年度/季度收入与EBIT及各现金项一致、所有机会状态每年合计100%、F吸收、状态现金先算后加权、目标日只折现其后现金、分红/现金/回购各一次、每股总回报及长期年化同口径。普通偏差、完整服务成功和长更新期已按同目标日重算，未以平均现金掩盖所建路径的融资断点。

没有把“算式闭合”冒称预测已被验证：分支收入/毛利分配、主观转移概率、季度季节和2030以后持续性仍是模型假设。最可能改变选择的未知是新服务实际净收费与长期资本效率，不是小数尾差。若这些证据改变，应从第2—4节修改同一经营底稿，再联动所有目标日和标签。

以下为本报告实际使用的纯Python复算代码（金额十亿美元）；运行可重建四套年度经营、机会状态及目标日DCF，不需要读取任何既有投资报告。`model()`是年度底稿，`opportunity()`是状态现金，`periods()`完成季度滚动，`value()`重算目标日资本桥。`ordinary/full/platform`分别对应三个独立实验。未来分红日期为假设，税后经营损失可抵税、反稀释回购及固定股数等限制已在正文披露。

def model(s,full=False,ordinary=False):
 c=cfg[s]; opp=opportunity(s,full); rows={}; prev=r0[:]
 for y in range(2026,2037):
  if y==2026:
   r=r0[:]; op=dict(r=0,ebit=0,cap=0,da=0,nwc=0,fcff=0)
   eb=3.284; da=1.25; cp=1.18; nw=.22; special=.18
  elif y<=2031:

   if y==2027:r[6]=c['ci']

   op=opp[y]
  else:

   gy=c['tail']+(c['tg']-c['tail'])*(y-2031)/5
   r=[v*(1+gy) for v in prev]

   margin=prior_margin+(c['tm']-prior_margin)/(2037-y)
   eb=sum(r)*margin

   cp=da+max(0,eb*(1-TAX)*gy/c['roic']-nw)
   special=.025;op=opp[y]
  prevbase=r[:];unshocked=eb

   # Delayed CoolIT and 50bp persistent net pricing/cost miss in ordinary core.
   lost=r[6]*.15
   r[6]*=.85
   eb-=sum(r[:4])*.005+lost*.25
   cp+=.03 if y==2027 else 0
  total=sum(r)+op['r']; ebit=eb+op['ebit']; da+=op['da']; cp+=op['cap'];nw+=op['nwc']
  interest=max(.25,.58-.025*(y-2027)) if y>=2027 else .38
  if s=='悲观' and y>=2027:interest=.62
  if s in ['乐观','突破'] and y>=2027:interest=max(.22,.58-.04*(y-2027))
  ni=(ebit-interest+.025)*(1-TAX)-.018
  fcff=ebit*(1-TAX)+da-cp-nw-special
  ecf=fcff-interest*(1-TAX)-.018 # excludes noncash other gain, SBC treated as cash equivalent
  sbc=.17*(1.04**(y-2026)); fcf=ecf+sbc
  div=.73*4*(1.06**(y-2026))*SH
  rows[y]=dict(r=r,revenue=total,unshocked_ebit=unshocked,core_ebit=eb,ebit=ebit,da=da,cap=cp,nwc=nw,special=special,interest=interest,ni=ni,eps=ni/SH,fcff=fcff,ecf=ecf,sbc=sbc,fcf=fcf,cfo=fcf+cp,div=div,opp=op)

def periods(rows):
 out=[]
 for y,row in rows.items():
  for q in range(1,5):
   a=dt.date(y,3*q-2,1);b=dt.date(y+1,1,1) if q==4 else dt.date(y,3*q+1,1)

   for key in ['revenue','ebit','da','cap','nwc','special','interest','ni','fcff','ecf','sbc','fcf','cfo','div']:

def integrate(ps,key,a,b):
 return sum(p[key]*max(0,(min(b,p['b'])-max(a,p['a'])).days)/(p['b']-p['a']).days for p in ps)

def dividends(a,b):
 return sum(.73*1.06**(y-2026) for y in range(2026,2037) for month in [1,4,7,10] if a<dt.date(y,month,15)<=b)

def value(s,target,wacc=.08,g=None,full=False,ordinary=False,platform=False):

 if platform:
  # Alternative economic explanation: sustained 6% group growth to 2046, funded at 20% incremental ROIC.
  for y in range(2032,2047):

  ps=periods(rows)

  a=max(target,p['a']);b=p['b']
  if a>=b:continue

  ev+=p['fcff']*(b-a).days/(p['b']-p['a']).days/(1+wacc)**t

 nopat=rows[max(rows)]['ebit']*(1-TAX)

 tv=tf/(wacc-g)/(1+wacc)**((end-target).days/365.25)

 ntm={k:integrate(ps,k,target,ntmend) for k in ['revenue','ebit','ni','fcff']}
 return dict(ev=ev,tv=tv,eq=eq,price=price,netdebt=nd,cash=1.0,debt=nd+1,other=other,div=div,ret=(price+div)/P0-1,ntm=ntm,eps=ntm['ni']/SH)
