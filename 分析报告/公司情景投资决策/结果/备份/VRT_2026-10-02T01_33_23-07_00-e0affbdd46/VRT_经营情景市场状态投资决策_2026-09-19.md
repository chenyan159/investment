## 二、客户买什么，价值留在哪些业务

VRT出售电力转换与分配、热管理、机架和集成设施、工程及生命周期服务。云厂和托管商通常定义规格；直接客户也可能是EPC、OEM或分销商；最终使用者是计算设备运营者。按设备、系统工作包和服务义务收款，不按GPU销售、token生成、园区租金或电厂发电收入抽成。供应商的出厂、送达和控制权转移，与整个数据中心联网、客户接收算力和最终客户开始计费是不同事件。

### 2.1 三条决定性证据链

**需求存在，但订单到收入之间有条件。**2025年底backlog为15.0bn，上年7.2bn，多数预期12—18个月交付；其中是采购单或采购承诺，不是同额不可撤销应收。年报明确客户有时可延期、减少或取消，通常伴有罚则或其他后果。同时收入政策明确，一般短期销售合同的取消、终止或退款条款通常限于违约，历史上未被触发。两段针对的合同范围不同：既不能说全部订单可随意取消，也不能把所有预付款当无追索资金。新收购业务条款可能不同。[2025年10-K，Backlog、风险因素及收入政策][S01]

Q2 10-Q、7月29日新闻稿以及本次检索到的公司季度材料中，未查得可替代2025年底数字的2026最新backlog、毛取消率或最终预算方集中度。没有用15bn冒充6月或9月订单，也没有以“上期订单＋假定订单增速－收入”制造当前余额。已收客户预付款证明部分真实承诺，不能另加到backlog扩大总需求。

**液冷的真实采用与议价压力同时存在。**CoreWeave于2025-07-03确认与Dell、Switch和Vertiv合作部署GB300 NVL72，支持VRT进入实际交付链；没有给VRT合同额或独家份额。AWS则公开披露自研CDU、控制和液冷系统，说明客户可以采用更多液冷，同时减少对供应商整体架构溢价的依赖。Eaton于2026-03-12完成Boyd Thermal收购，电力竞争者也在补齐热管理组合。三个事实共同支持“业务增长但利润持续性需要折让”，不能只取第一个事实。[CoreWeave原始部署公告][S05]、[AWS自研液冷][S06]、[Eaton完成收购][S07]

**客户预算充足，但不能把算力资本开支全部映射到VRT。**Microsoft在7月29日业绩会上披露当季资本开支41bn，其中约三分之二为CPU/GPU等短寿命资产；2026年资本开支预期因租赁会计变化调整至约175bn，而投资意图不变。这既提供支付能力和实际投入的证据，也说明把190降到175理解成真实削减、或把175全部乘设备份额，都不成立。[Microsoft FY2026Q4业绩会][S08]

### 2.2 800V、预制与微电网：什么成功可以缺席

NVIDIA在2026-08-11公开的800VDC演进包括机架、列级和设施级路径。高密度不要求所有园区立即采用固态变压器；保留交流配电、增加直流sidecar同样能支持采用。VRT在电力系统、测试和客户设计入口已有基础，但没有公开足以估出其800V收入／利润的独立合同。模型中的电力增长已经包括架构迁移净效果，没有再把800V行业TAM叠加一次。[NVIDIA架构说明][S09]

预制的价值来自把现场工时、接口和测试前移，而不是获得地产或全部总包收入。要突破，至少需要多个客户采用重复模块、工厂合格产出跟上、现场返工不吞掉节约；不要求VRT同时垄断芯片、冷板、电源和施工。液冷独立成功则可以在传统电力正常增长、UIG一般表现下创造增量，后文分别重算。

7月21日Tognana扩产公告目标为年底将**区域冷机产能翻倍**、2027年初完成新测试实验室；它不是全球热管理产能翻倍，也不是已交付IT MW。扩产、工厂面积和铭牌MW无法单独证明全年收入上限，因此本研究用实际收入基线、资本开支和必要交付增速共同约束。[Tognana扩产原始公告][S10]

### 3.1 预付款到底改善了什么

H1净利润与非现金调整在营运资本前形成1.1878bn；应收占用0.6442、库存占用1.0480，应付贡献0.6853、递延收入贡献1.8227，其他营运资本净占用0.1370，合计OCF1.8666。若机械删去递延收入增量而保持其他项目不变，FCF会变为−0.2446bn。**这只是现金来源敏感性，不是合理正常化预测**：预付款减少时，备料和采购也会调整。

6月末递延收入共3.7563bn，其中流动3.6337、非流动0.1226；后者主要涉及维护、延长保修等。成品0.941bn和原料1.259bn同时上升，既可能是为旺季准备，也可能是接收变慢。模型不抹去客户融资价值，而是将其优势与反转风险一起处理：基准新增经营营运资本占增量收入10%，受损14%；前两年另加预付款／回款退坡压力。已收钱但未履约的负债不在估值中再次全额当债务扣除，因为履约的成本和收入已在未来经营现金中；退款、违约及库存损失只在受影响分支额外体现。

## 四、UIG：新机会、尚未完成的交易和明确的成功成本

2026-09-01签约、9月2日披露，预计Q4交割，需满足包括HSR等待期等条件。买方为VRT全资体系内Vertiv Corporation，交割后取得UIG全资权益。**1.45bn现金首付款**按营运资本、债务和交易费用作常规调整，公司称使用现有资源；最高另付**1.15bn**，分两期各0.575bn。截止日没有查到已完成交割公告。[9月2日8-K，Item 1.01][S12]

公告称首付款约为UIG 2027预期EBITDA的13倍，直接计算约**0.1115bn**。这是管理层预期推导，不是审计利润或保证收益；以全部潜在2.60bn成本除以同一个0.1115bn，会忽略对价与业绩联动，同样不恰当。[UIG收购公告][S13]

协议第2.09节披露的条件不能因缺少目标点值而被删除：

- 第一期考核2026-10-01至2027-09-30；第二期为2026-10-01至2028-09-30，**累计两年**，不能当成第二个单独年度。
- 每期支付额＝0.575bn×实际调整后EBITDA／对应目标；低于目标50%则支付零，最高0.575bn。因此触及50%时支付额会跳到约0.2875bn，不能用从零连续到封顶的任意线性支付代替。
- Included Business排除协议定义的Storm和UtilityInfrastructure业务；它是业绩对价核算范围，不能推断这些业务一定不在收购法律边界中。
- 2027／2028目标EBITDA及详细会计原则引用Schedule 2.09。8-K说明附件有省略，本次完整公开协议未包含目标金额；这是有证据的未公开字段。买方最迟在第一期结束90日内、第二期结束60日内给出计算；卖方有45日异议窗口，金额最终确定后5个工作日付款，存在争议延期。
- 买方须善意经营，不得以阻碍达标／降低支付为目的处置业务；不能假设增长一旦不好就可无代价撤回投入。[收购协议，§2.09(a)—(f)][S14]

因此模型将0／0、0.30／0.40、0.50／0.575、0.575／0.575bn分别作为受损、基准、乐观、突破两期**条件支付代理值**，均符合单期零或至少0.2875bn的已知区间；分别在P2/P3支付。它们不是根据未知合同目标精确反算的应付款。将两期全部置零或封顶会改变基准现值约1—2美元／股，不能解释本次超过100美元的现价差距。1.45bn首付和0.04bn费用在P1扣除；既有收购0.2346bn或有负债亦在P1预留支付。首付实际可能在2026Q4，比年度模型期末早，现值偏差另列在敏感性边界。

**业务的最小成功条件。**需要客户为控制、微网专用开关、能源协调及工程入口付费，交付通过，核心团队留任，并使设计入口变成净增客户钱包。燃气轮机产能、燃料供应和电网审批不是UIG自己控制；技术不限定单一发电来源增加兼容性，却不自动产生能源套利利润。基准P1收入0.35bn、EBIT率22%，P3收入0.70bn、EBIT率25%，其中P1包含交割前不并表的时间折减；该分解只是使约0.1bn早期EBITDA数量级和后续能力衔接，不是未披露收入的还原。

本次以95%交割、5%未交割作为工作判断，范围90%—98%。依据是确定协议、现有融资资源和互补业务，反面是监管及其他交割条件未满足；没有可直接用于此交易的统计基础率，95%不是精确频率。四行条件表固定成功交割；今天的加权模型另算“未交割、无UIG利润、无首付和业绩对价、支付0.02bn沉没费用”分支。两个结果先各自计算股东权益，再加权。

## 五、连续经营路径与概率如何形成

以2027、2029、2033和2040年9月19日为经营节点。**每个节点收入／利润均为截至该日的连续12个月流量**；P1—P14每一期间都实际计一次现金，P14后继续经营，不在七年截断。节点之间收入按复合增速插值，利润率按阶段线性变化；这种年频近似不能定位季内验收，但可防止每一期重新挑选有利状态。

基准条件是客户合格交付量继续扩张、VRT保持资格和通常份额、竞争使净价逐步减弱、服务随装机滞后成长。乐观解除更多交付约束、提高综合钱包和执行效率，2030附近已经高于本次基准和管理层约26bn收入目标。突破的主因是预制工作包和液冷热链的大规模复制，并有电力架构升级、UIG工程入口协同；服务增长跟随装机，无须另假定软件垄断。受损是2027—2029延期叠加客户自研／多供压价和产能低效，随后仅部分修复，仍持续投入研发和服务，不是把失败成本归零。

### 5.2 数量、价格与资本怎样限制这些节点

**电力。**基准P1至P3从5.25升到6.90bn，年复合约14.7%；可由合格交付容量每年约14%—17%、每MW净内容量／净价合计约−2%至+1%支撑。到P7降为约8.1%复合增长，允许800V蚕食旧变换层。突破P3到P7也只从8.2升到13bn，没有把所有电源部件收入按AI算力等比例放大。达到更高端点，必须在开放标准下仍保留高可靠保护、控制及系统测试收费权。

**热管理。**基准P1至P3增速约17.9%，随后约10.7%。P7的9.9bn可粗分为传统与更新4—5bn、液冷相关系统和排热约4.9—5.9bn；后者若VRT可获净外部钱包为0.25—0.60百万美元／IT MW，对应约8—24GW年度交付当量。这是**必要规模算例**，不是市占率或公司已公布MW；含排热，不能与行业“仅CDU／管路”池直接比较。突破P7的18bn则需要约22—52GW的液冷相关年交付当量（其余约5bn传统／更新），或更高净钱包。如此大的增量需要全球客户重复采用和实际供电／施工，不可能仅凭某个实验室或一个Logo完成。AWS自研、温水少用冷机及竞争供给是这些钱包下调的具体依据。

**IT与预制净额。**基准P7为5.8bn，可用约2.2bn IT与机架、约3.6bn预制净工作包做范围检验。若每MW扣掉已在电力／热管理确认的内容后仍有0.5—1.5百万美元净对外收入，需要2.4—7.2GW年度预制工作包。突破12bn可由约3bn IT加9bn净预制组成，需要6—18GW。上述单位钱包未公开，是适用边界清楚的数量级假设；单价下移一半就要翻倍交付，不能假设工厂和营运资本不增加。业务利润率由18%向22%上升包含工程复用，突破28%要求显著减少返工、提升自有价值含量，属于低概率端点。

**服务。**按2025约2bn组合校准，基准P1的3bn到P7的6.65bn需约14.2%年增长，低于机械延长管理层20%+。若以约3/4生命周期、1/4项目服务作研究分配，生命周期来自可维护装机×外包附着×净年费，项目部分来自新增验收量×首次调试净费；保修、自维和关闭旧机房会降低附着。基准P7可维护装机和服务收入的扩张接近原有规模数倍，利润率32%要求班组利用率与备件价值，而不是纯软件边际成本。受损仍保留服务增长，体现装机缓冲，避免把全部业务一起归零。

**UIG。**基准P7收入1.25bn，若每个100MW级项目年内确认的控制／专用设备／工程净额10—30m，对应约40—125个项目年度当量，可能含多年项目及既有服务，不能理解成每年新建同等数量完整园区。突破5bn要多区域复制和显著扩大钱包，需留人、制造和客户资金同时到位。该单位项目金额同样是未披露的范围假设，收入拆分精度低于集团；后文独立成功测试不把这一机会忽略。

上述业务分解用于约束而非证明端点。关键未知仍是公司各产品真实价格、合格MW和客户付费附着。模型保留宽经营分支和普通偏差，没有用财务残差伪装液冷已实现收入。资产投入方面P1至P7采用3.5%／4.0%／4.5%／5.5%的CapEx收入比，突破投入最高；全球扩产、测试和租用厂房才能支撑规模。比例法无法证明具体工厂能按时合格出货，所以交付风险在状态分布里仍占重要位置。

### 5.3 概率对象、依据与可替代解释

概率对象是**从当前信息出发，2026—2040整条经营路径所属的主导状态**，不是每年的新抽签，也不是液冷技术成功概率。四个状态作为工作离散近似被定义为互斥的主导结果：持续受损、正常兑现、明显超额兑现、跨产品非线性扩展，近似覆盖主要经济结果。每个节点始终使用同一整条路径权重，因此业务状态与现金时间相容。行内点值是代表路径，未获证实是条件均值；加权结果是决策工作量，不是精确数学期望。真实状态内部的进一步破产、极端繁荣和延迟恢复通过宽范围／尾部检验承接，四个代表点本身不穷尽尾部现金分布。

### 6.2 统一现金公式与资本政策

`FCFF = EBIT×(1−23%) + 有形折旧／软件摊销 − CapEx − Δ经营营运资本`

模型EBIT不含历史购入无形摊销，所以加回项只用收入1.4%的有形折旧等；不能把无形摊销再加一次。CapEx含软件，P1—P7为各行收入的3.5%—5.5%，P8—P14逐步降至3.2%。将约1.4%视为折旧对应更新、另留约0.6个百分点更新／可靠性余量，剩余为扩产研究分配；公开资料不支持逐工厂精确分割。新增营运资本＝增量收入×各行10%—14%＋前期一次性现金压力；不是永久外推H1预付款增长。

`估值现金 A_t = FCFF_t − Δ最低经营现金_t − 收购／或有对价现金_t`

`期末现金 = 期初现金 + FCFF − 收购等付款 − 税后利息 + 超额现金税后收益 − 分红 − 到期本金 + 新借款`

最低现金单独在期末超额现金中剔除，增量最低现金也在估值流量中扣除，表示这些钱持续被经营占用。两者分别对应存量和新增投入，不是重复扣同一存量。现金台账不再额外减一次最低现金，否则会少计资产。现有本金在目标日权益桥减除，目标日前偿还则同时减少现金与本金。

现金分红假设每年0.25美元／股，延续当前年化量级，不是董事会对未来七年的承诺；累计分红按现金留存、不再投资。超额现金税后收益3%（对应约4%税前短久期收益），不将未来利率固定视为事实。没有无依据假设大规模回购或未宣布收购；有机增长的投入已全部扣除，剩余钱进入现金。若未来收购，应同时减现金并加所买业务的净价值，零NPV交易不凭空创造收益。本模型保留现金会使持有回报低于简单按WACC滚存DCF的结果，这是资本闲置代价而非计算错误。

股份报酬使用**未来现金替代成本法**：业务利润内保留每年员工报酬经济费用，FCFF不再加回，未来不另增同一笔奖励股数。393m包含当前已存在奖励的稀释近似；不再给它们增加现金行权收益。该简化偏保守且不是精确期权估值。若股数变为405m而其他不变，价值约低3%；无新增融资的各行股数相同，因而先算每股再加权与固定分母等价。融资压力分支不能沿用这个等价关系。年报明确2025及2024年底均无存续权证，6月末优先股授权但未发行，Q2债务表未列可转债；因此没有凭历史SPAC结构额外添加当前权证或优先股索取权。2026H1股份报酬30.8m、实际股份增加约2.38m，也说明员工报酬和现存稀释不能忽略。[2025年10-K，Warrants；2026Q2权益及现金流表][S01]、[S02]

## 七、同一模型中的今天价值与目标日价值

### 7.1 折现基础、生命周期和终值

9月18日美国国债1／3／7／10年收益率分别4.44%／4.83%／4.93%／5.01%。本次美元名义FCFF使用**10.5%企业资本成本**，参考结构是约5%长期时间价值加约5.5个百分点经营和系统性风险补偿、低债务权重；这不是以当天高beta机械精确估计。相容9.5%—11.5%作为条件估值区间，另测9%和12%。已经在路径中计入失败损失，不另加一次“失败折扣”，但AI资本开支的共同周期风险仍需风险溢价。[美国财政部9月18日收益率曲线][S15]

**12%投资要求与10.5%WACC不同。**前者是本研究对集中持有单一周期性基础设施股票的参考补偿，后者用于估经营现金。7年即使可以承受波动，也要支付相对约5%国债／其他资产的机会成本。若投资者只要求8%，可得到不同条件格，但事实、现金和权益不变。

预测至2040年，让当前超常建设阶段过渡到设备跨代更新。2033至2040基准电力和热利润率从27%／28%降至24%／24%，服务32%降至29%；突破也不把峰值32%热利润率永续。长寿命电力设备与厂房需要维护替换，CDU、控制与服务器架构接口更新更频繁，原产品报废不等于系列业务结束。现有设计和服务网络可以延续，但需研发、扩招、备件和再投资。

终值为：

`TV_P14 = EBIT_P14×77%×(1+g)×(1−g/长期增量ROIC) ÷ (WACC−g)`

受损g=2%、ROIC=15%；基准g=3%、ROIC=20%；乐观／突破g=3%、ROIC=22%。增长全部扣再投资，g/ROIC占NOPAT约13%—15%；维持性更新已经通过正常经营、利润率及净再投资边界反映。ROIC是终值新增资本回报，不是用含历史商誉的账面ROIC直接套用；保持其他不变，基准终值ROIC从15%到25%使今天价值约125.39—130.65美元、七年价值239.48—250.07美元。竞争压到资本成本附近会进一步削弱终值。P14之后并非无成本永续峰值。

现金税率从23%单独改为21%／25%，不改变资本路径的一级现值敏感性约为132.68／124.67美元每股。模型没有另加历史购入无形资产的税摊销盾，若未来每年额外有0.1bn现金税盾、持续十年，其现值约1.53美元每股；这是税盾上限算例，不是已核实的税务资产。该保守简化和对价时点误差不足以支持把129美元直接提高到249美元。

`EV_T = Σ_{t>T} A_t/(1+WACC)^(t−T) + TV_P14/(1+WACC)^(14−T)`

`权益_T = EV_T + 现金_T − 最低经营现金_T − 债务本金_T`

`每股价值_T = 权益_T / 0.393bn股`

目标日前现金已经形成现金、还债或分配；目标日DCF只含之后的现金。待付业绩对价在未来A中扣，不再从权益另扣一个同名负债。当前DCF不当作一年目标价，且所有目标日都使用同一后续经营路径。年度末现金折现对首付、半年利息和季度分红有时点近似；UIG首付前置造成不到约0.3bn／0.8美元每股现值误差，不能改变建议。

## 八、现价要求、最强反方与等待的代价

### 8.1 从同一买价反求，不从股价倒推研究中心

249.39美元约相当于2026公司调整后EPS指引中点6.70的**37.2倍**；依据模型经济稀释股数对应约98bn权益。对照不是说37倍必然贵，而是要知道后面收入、利润和投入需如何兑现。

保持基准P1收入15.7bn、各期业务利润率、资本效率和10.5%WACC，允许P3收入增幅是P7／P14追加增幅的一半，反求当前249.39美元，需要P3约**33.73bn**、P7约**68.41bn**、P14约**91.01bn**，即长期基准收入约**2.07倍**。这是一个有明确自由度的相容解，不是现价唯一隐含预测。此时更多产能和营运资本也按比例增加；没有免费获得增量利润。

## 十、仍会改变结论的缺口及完成核验

1. **未查得最新订单余额／毛取消率／产品净钱包。**已核验年报backlog定义、退款政策、2026Q2财报及公开季度材料；它们不能确定9月未交付订单的逐客户质量。改进变量是交付量、价格与收款时间，而不是把全部订单归零。
2. **UIG目标金额有依据地未公开。**已经读取8-K、Exhibit 2.1及第2.09节，保留50%门槛、每期封顶、累计期间、异议和付款程序；缺失Schedule 2.09中的点值。现在用相容支付区间，未来财报购买会计、对价重估和被收购业务结果可约束它。
3. **产品收入／利润与长期资本回报不可直接识别。**公司提供地域分部和取整组合，未提供液冷、800V、预制净工作包的独立利润表；本研究的节点分配与单位钱包均为有机制的研究范围。若后续真实净钱包明显高于这里假设，必须提高业务贡献；独立机会测试给出了量级。
4. **目标日市场定价本身不可知。**条件DCF、当前投资要求和市场可成交价分别处理。没有证据证明市场将在一年或三年内采纳本估值，也没有将现价自动校准成模型中心。
5. **尾部与资本配置。**已模拟受损仍可存续的现金路径和季内融资压力；未掌握所有客户违约、保修和诉讼极端损失的联合分布。若未来资金被持续投入低回报并购，留存现金不能再按原值与原业务并存。相反，高回报回购或收购可能改善每股结果，但必须实际付钱和取得价值。

def interp(nodes,t,geometric=False):
    for j,k in enumerate(KNOTS):
        if t<=k:
            if j==0:return nodes[0][:]
            f=(t-KNOTS[j-1])/(k-KNOTS[j-1])
            return [a*(b/a)**f if geometric and a>0 else a+(b-a)*f for a,b in zip(nodes[j-1],nodes[j])]
    raise ValueError(t)

def run(spec,r=.105,gshift=0,close=True,revscale=1,marginshift=0,capshift=0):
    rows=[];cash=CASH0;debt=DEBT0;minimum=MIN0;prev=sum(REV0)
    for t in range(1,15):
        rev=[x*revscale for x in interp(spec['rev'],t,True)]
        if not close:rev[4]=0

        total=sum(rev); hq=total*spec['hq']; re=spec['restruct'][t-1] if t<=3 else 0
        ebit=sum(op)-hq-re
        dep=total*.014
        caprate=spec['cap'] if t<=7 else spec['cap']+(0.032-spec['cap'])*(t-7)/7
        cap=total*(caprate+capshift)+sum(a*b for a,b in zip(rev,spec.get('extra_cap',[0]*5)))
        nwc=spec['nwc']*(total-prev)+(spec['shock'][t-1] if t<=3 else 0)
        fcff=ebit*.77+dep-cap-nwc
        newmin=max(.8,total*.05);dmin=newmin-minimum
        pay=((1.45+.04 if close else .02) if t==1 else 0)+(.2346 if t==1 else 0)
        if close and t in (2,3):pay+=spec['earn'][t-2]
        flow=fcff-dmin-pay
        coupon=.85*.04125+.6*.0485+.5*(.0565+.058+.0595)+.0172*.03
        if t==3:coupon-=.85*.04125*(308/365)
        if t>=4:coupon-=.85*.04125
        if t==10:coupon-=(.6*.0485+.0172*.03)*(188/365)
        if t>=11:coupon-=.6*.0485+.0172*.03
        principal=(.85 if t==3 else 0)+(.6172 if t==10 else 0)
        div=.25*SHARES
        cashyield=max(0,cash-minimum)*.03
        cash+=fcff-pay-coupon*.77+cashyield-div-principal
        debt-=principal
        borrow=max(0,newmin-cash)
        cash+=borrow;debt+=borrow
        rows.append(dict(t=t,rev=rev,op=op,R=total,E=ebit,hq=hq,restruct=re,dep=dep,cap=cap,nwc=nwc,F=fcff,pay=pay,flow=flow,cash=cash,debt=debt,mincash=newmin,borrow=borrow,div=.25,coupon=coupon,cashyield=cashyield))
        minimum=newmin;prev=total
    g=spec['g']+gshift
    term=rows[-1]['E']*.77*(1+g)*(1-g/spec['roic'])/(r-g)
    vals={}
    for t in [0,1,3,7]:
        rem=sum(x['flow']/(1+r)**(x['t']-t) for x in rows if x['t']>t)+term/(1+r)**(14-t)
        c=CASH0 if t==0 else rows[t-1]['cash'];d=DEBT0 if t==0 else rows[t-1]['debt'];m=MIN0 if t==0 else rows[t-1]['mincash']
        eq=rem+c-m-d;v=eq/SHARES;wealth=v+.25*t
        vals[t]=dict(EV=rem,equity=eq,V=v,cash=c,debt=d,mincash=m,distribution=.25*t,total=wealth/PRICE-1,cagr=(wealth/PRICE)**(1/t)-1 if t else None,terminal_fraction=(term/(1+r)**(14-t))/rem)
    return dict(rows=rows,values=vals,terminal=term,r=r,g=g)
