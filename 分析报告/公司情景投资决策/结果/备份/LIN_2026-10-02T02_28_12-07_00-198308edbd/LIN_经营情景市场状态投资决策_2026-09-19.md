## 三、决定增量价值的三道门

### 3.1 电子气体：签约、可供气、晶圆厂付费是连续但不同的节点

7月31日公告确认凤凰城新增投资1.0、建设两套ASU；台湾合资另拟投0.8。[凤凰城及台湾项目公告](https://www.linde.com/news-and-media/2026/linde-to-invest-%241-billion-to-support-major-u%2C-d-%2Cs%2C-d-%2C-semiconductor-facility-expansion)。Q1官方电话会明确台湾为50%非并表合资；所以0.8既不是集团新增收入，也不是集团全额资本开支。[Q1官方文字稿，第2页](https://assets.linde.com/-/media/global/corporate/corporate/documents/investors/quarterly-earnings/investor-call-transcript-1q26.pdf)

客户厂房完成不等于气体设施验收，更不等于全年满负荷。TSMC Arizona页面给出的第二厂量产目标为2027H2，第三厂为本十年末；它支持当地长期产能需求，但Linde公告未指名客户及逐座对应关系，本文不把两份公告拼成已确认的单厂收入。[客户项目说明](https://www.tsmc.com/static/abouttsmcaz/index.htm)。三星平泽第八ASU的2025公告预期2026年中启动，本次在所核公告及电话会中**未查得该装置单独验收证明**，因此不因日历到期便认定完成。[三星供气公告](https://www.linde.com/news-and-media/2025/linde-to-expand-supply-of-industrial-gases-to-samsung-in-south-korea)

独立数量机制是：有效收费能力×合格负荷×每单位综合净收费，加特气/材料销售。研究把全球电子收入从起点3.5推至2033年的5.1、7.5、9.0、12.0，分别对应约5.5%、11.5%、14.4%、19.2%的七年复合增速。基准需要已有项目增加供气、先进工艺增加气体强度、林德保持资格，并不断赢得新厂；不是只靠凤凰城1.0投资。突破需要多个地区扩建同时形成实际负荷，复用现场资产和纯化/备份系统，使单位固定成本下降，电子利润率升至37%；它不要求核心业务也达到乐观行的35%利润率。

把基准7.5还原成量价约束，可用有效收费能力及负荷1.70倍、每单位气体强度/产品组合1.12倍、名义净价1.125倍解释：3.5×1.70×1.12×1.125≈7.5。突破12.0约需2.50×1.20×1.143倍。以上是相容分解而非已获订单，净价含设备/特气组合的不确定性；能力应以合格、可计费负荷衡量，不能用客户晶圆厂名义资本预算代替。基准电子前七年另列增长投入6.85，突破14.90，另有基础更新；因此本研究没有假设电子规模可以用很少资本翻数倍。若新装置只能获得上述项目算例较低端回报，基准利润率和终端ROIC就应下修。

**标准化项目算例（A，不是合同报价）：** 对总建造成本1.0、20年经济寿命的供气设施，成熟年销售0.30—0.45、EBIT率30%—35%，税后EBIT为0.068—0.120，对初始投资税后经营回报约6.8%—12.0%；若设备更新每年0.03—0.05、营运资金另需0.02—0.04，真正现金IRR还受开工期和起付条件影响。以成本1.0、销售0.40、EBIT0.132、D&A0.05、年维持0.035计，稳态经营现金约0.115（税率24%）；建设期三年和逐年爬坡后，回收不会等于简单的1/0.115＝8.7年。保底起付、成本转嫁和邻接客户可改善结果；超支20%、推后两年、未售出的伴生气体会显著变差。

例如建设付款在t=0/1/2为0.20/0.45/0.35，t=3/4净现金0.04/0.08，t=5至22每年0.115，最后另有0.05残值，税后项目IRR约**7.70%**，8.5%贴现NPV约**−0.063**，未折现回收约11.65年。这组数说明即使项目看似有十年左右回收，计入建设时间后仍未必创造价值；它不是凤凰城真实IRR。高于该回报需要实际收费、网络外售或资本效率支持，不能只凭长约名称断定。

价格、最低采购比例、具体取消/延迟赔偿和剩余工程付款均未在所核项目公告、10-Q及官方问答中查得逐项数值；**不能写成没有保护**。Q2电话会已说明部分工程在可补偿LOI下先启动，这是一项已披露保护；它不等于全部未披露利润已有担保。Air Liquide披露2026H1电子投资决策约10亿欧元，说明客户愿意采购，也说明竞争者同步建设，不能由总需求大直接推出林德份额上升。[Q2官方文字稿，第2页](https://assets.linde.com/-/media/global/corporate/corporate/documents/investors/quarterly-earnings/investor-call-transcript-2q26.pdf)、[Air Liquide半年结果](https://www.airliquide.com/group/press-releases-news/2026-07-28/h1-2026-results-acceleration-second-quarter-air-liquide-combines-growth-continuous-performance)

### 3.2 新增低碳氢：收费权可以较强，时间和资本仍有损失

氨厂100%属于Woodside，林德拥有供气权益而非氨销售额。110万吨氨按化学计量最多对应约19.4万吨氢/年，考虑实际负荷和氮气、能力费及能耗联动，本文将Beaumont相关成熟收费收入的工作量级设为0.4—0.8、EBIT0.12—0.25。此范围需要实际条款验证，不能把市场氨价乘产量当林德收入。2027首期只记部分期间收费，不把年底运行能力提前计全年。

### 3.3 成熟网络、护理、氦和航天：决定公司价值的大头仍在这里

基准核心收入到2033年39.5，约3.8%复合增长，可由2%—2.5%名义净价、约1%基础量及小型新增能力/并购共同组成。净价先用于覆盖工资、运输、能源和维护；只有超过成本的部分才提升利润率。核心利润率从31%逐步至33%意味着路线密度、效率和业务选择持续改善，已经包含执行成功。

受损路径2027核心收入29.8、利润率28.5%，之后虽恢复增长，到2033仍仅33.5/29.5%；代表客户迁厂、工业低迷、护理回款/成本压力留下持续损伤。乐观路径2033核心44.0/35%，要求制造需求、净价和密度都改善。突破行核心43.0/34%低于乐观，防止把所有好端点相加。

本模型核心增长已容纳航天扩张。即使额外增加0.5成熟年销售、35%EBIT率，也只有约0.13税后经营收益，且需要液化、储运和供给资本；不足以单独改变两百多十亿美元市值的长期回报判断。真正有意义的跃迁是多客户网络复用并持续获得高回报，而不是给新用途贴标签。

## 五、资本闭合：经营增长不等于当前股东得到同样多

### 5.1 起点流动性与到期责任

### 5.2 从EBIT到可归属现金的唯一桥

```text
FCFF* = 调整后EBIT × (1−24%) + 调整后D&A
        − 全部经营投入（资本开支与本模型所需小并购） − Δ经营营运资本
        + JV实际分配减注资 − 少数股东现金份额 − 特殊现金支出
```

FCFF*是已校正普通股归属、但尚未付母公司债务利息和普通股分配的现金。集团层共同费用已在单元EBIT内，不再扣第二遍；长期JV和少数项随规模演进。非服务养老金会计收益不当永久现金；购买会计税盾、现金税时差未另资本化，可能低估数美元，以现金税率±2个百分点作检验，不把这种小误差夸大为主要价值解释。

前七年的基础投入为调整D&A×1.04，包含维持和小项目增长，**不是声称公司披露的纯维持资本开支**。内部按75%维持、25%基础小增长分配用于可削减性评估；维持比例检验70%—85%。此外逐单元列增长投入；核心增长中约0.30/年为小并购预算，其余为区域能力和效率，包含收益就保留支出。电子和新增氢的增长预算不与8.1总项目成本再相加。研发已费用化，不重复作投资。

基准第一年总投入5.733中，基础约3.083、另列增长2.650；纯维持参照约2.31、小增长约0.77。现金用途按约束可近似分为：维持2.31、已签项目和必要收尾约1.65、可选扩张/小并购约1.77，**后两者为研究分配，非披露剩余承诺**。不能在压力下删掉1.77后保留所有基准收入。已核8.1 backlog的原文定义为“total estimated capital cost of large plants under construction”，是全部估计资本成本，不是尚未支出额、采购担保或一年收入。[10-Q，Investing](https://www.sec.gov/Archives/edgar/data/1707925/000162828026051289/lin-20260630.htm)

### 5.3 分红、回购、利息、股数的联动

四行未来每股年分红从6.40出发，年增长分别为2%/5%/7%/8%；只是资本配置参照，不是董事会承诺。年末支付作为简化，期间分红不再投资。净现金利息用期初净债务×1.6%，以后每年增加0.2个百分点，至第七年2.8%；这是考虑存量低息多币种债、利息收入和资本化后的**净现金成本**，不是新增美元借款票息。新融资成本的风险另在资本成本及压力检验体现；资本化部分不在总投入外再加一次。

```text
余款 = FCFF* − 税后净利息 − 当年总分红
回购 = max(余款,0) × 60%；余下40%还债
目标债务 = 期初债务 − 余款 + 回购
目标股数 = 期初经济稀释股数 − 回购/假设成交价
```

总债务降至10时，多余现金转为回购，避免出现负债为负的虚假状态。回购成交价为460.40×(1+路径价格增长假设)^(t−0.5)，四行增长0%/5%/7%/9%；它只是检验资金能买回多少股的交易参数，**不充当目标价**。不假定管理层按DCF价格成交。基准成交价±20%使七年每股价值约405.34—416.58，相对中值409.74变化有限。未来股份报酬按现金付薪等效处理，保持起点奖励稀释与后续现金成本互不重复。

前七年基准净债务从23.5降至13.33、股数降至435.72百万。第一年所有行FCFF*为正，受损最低4.49；受损七年净债务16.92。模型主动将回购限制在剩余现金内，因而没有“靠无限增债维持EPS”的隐含条件。这是可行政策路径，而非声称公司一定采用。取消未来回购、保持同样经营投入并还债，今天经营价值不变，七年每股价值418.82，略高于回购路径；原因是按高于本研究内在价值的价格回购不创造价值。

### 5.4 能否到达成功：近端季度压力与极端清偿

第一年基准5.555的FCFF*按20%/23%/27%/30%分配为1.11/1.28/1.50/1.67，分红约3.11、税后净利息约0.29；在年度内分配均匀时，季度经营余款约0.26—0.82。受损4.487按相同季节拆分，分红约3.02、税后利息约0.29，即便第一季度再前置0.4诉讼现金，临时占用约0.3，仍小于非经营现金2.9。上述是现金季节压力算例，不是公司季度指引；全年特殊款不重复扣除。

真正风险是项目现金差与融资冻结重叠。若年经营现金降至8.0、资本开支6.0、分红3.0、回购4.0、并购0.5且额外法律现金1.2，缺口6.7；先停回购4.0、停可选并购0.5仍需2.2。若同时全部短债4.861（其中商业票据4.531）和当前长债2.474都无法滚动，现金4.898加额度6.5扣上述到期及2.2，只余约**1.86**，比2.0经营底线少约0.14，需要进一步筹资、减少可选投入或调整分红。1.5额度在2026年12月到期；年报披露可选择把已提款转成再延长一年的定期贷款，该选项有真实价值，但不是新增1.5额度，也不是永久资金。应对是更早锁定融资、保留现金、延期尚未承诺扩张并同步降低收入；下一轮仍不改善时才涉及更多出售或股息削减。贷款额度有合同来源，新增市场融资仅是有条件可得，未当实际到账。

四个经营展示路径均无需普通股增发；这不构成所有极端状态无稀释的保证。若进入重组，处置所得先付有担保/法定及实体层债权、普通债权与其他优先索取，再到少数及普通股，不能把新主体继续经营利润全给旧股。没有可靠分资产清算报价，因此不编造保底回收价；对普通股完全损失保留0边界，上述2%尾部试验检验其影响。主要投资风险在本案是买价过高和资本回报不足，现有证据不支持把破产列为中心情景。

## 六、统一价值模型与现价反求

### 6.1 贴现、寿命与远期资本

全部预测为名义美元。2026-09-18美国国债1/3/7/10年收益率分别为4.44%/4.83%/4.93%/5.01%，作为期限时间价值参照，而非直接用于风险现金贴现。[美国财政部当日曲线](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?field_tdr_date_value=2026&type=daily_treasury_yield_curve)

中央企业资本成本**8.5%**：例如约90%股权、9%股权成本和10%债务、5.5%税前边际债务成本，24%税率，得约8.52%。权重是长期参照，股价下跌后不应机械固定当前市值权重。9%股权成本约为5%长期美元时间价值加4%系统性权益风险补偿，是本研究要求，非公司给定。真实概率加权不消除工业、半导体和利率的系统性风险，故不改用国债收益率。四行用相同8.5%，已进入现金的项目失败不再另加相同风险折扣。

持续经营显式预测到2041年。第8—15年各业务增速和利润率向长期节点平滑收敛，新增净投资逐步从增量NOPAT/业务资本回报转为NOPAT×g/ROIC。第15年核心/电子/新氢/工程基准收入50.8/11.8/2.4/3.6，利润率33%/33%/29%/16%，合计EBIT21.93。电子在2033年之后仍扩张，但不保留37%峰值到永远。

```text
第15年剩余经营价值 = [NOPAT15×(1−g/ROIC) + JV净现金15 − 少数现金15]
                      ×(1+g)/(WACC−g)
目标日EV = 目标日后各年FCFF*现值 + 第15年剩余经营价值现值
目标日普通股价值 = EV + 现金4.9 − 必要经营现金2.0 − 目标日债务
每股价值 = 普通股价值 / 目标日经济稀释股数
```

受损/基准/乐观/突破长期g＝2%/2.75%/3%/3.25%，ROIC＝12%/16%/18%/18%。它们是持续更新的新资本回报，不是公司剔除商誉后的历史ROC。终值对应净再投资率16.7%/17.2%/16.7%/18.1%，并非资本开支为零。装置20—30年寿命、合同续期及压缩机/罐车/瓶体更新通过持续基础投入处理；不把某一永久不更新的装置永续。ROIC持续高于资本成本依赖区域密度、认证和合同能力；若这些消失应降低ROIC和利润率，而非保留无限定价权。

所有价值区间来自同一现金路径的组合参数：低端WACC9.25%、g减0.5个百分点、ROIC减2个百分点（最低10%）；高端WACC7.75%、g加0.5个百分点、ROIC加2个百分点。它们是透明压力边界，**没有统计置信水平**；不通过估值方法平均得目标价。高端包含有利长期折现和持续性共同成立，不能当基准概率很高的预测。

### 6.3 现价要求、最强相反解释与普通偏差

固定基准现金，只反求WACC需约6.40%才支持460.40。相比10年国债5.01%，股权和经营系统性风险的剩余补偿很薄；公司确有防御性，但成本、客户生产、信用与大型建设仍有风险。另一种相容解是在8.5%下扩大所有业务规模：第1/3/7年逐步达到原来约1.108/1.325/1.759倍，七年前增长预算也乘1.759，后续投资按同样ROIC计算，2033收入约90.83、EBIT约29.12。该试验是**现价要求**，不是本研究的实际预测；一个价格不能唯一识别增长与折现率。

普通的核心利润率−1个百分点、前七年每年超支0.5、电子/氢进一步延后都不能单独推翻拒绝；它们使价值更低。反方向同等大小的改善也不足填差。将现金税从24%降至22%并同步重算现金、资本和股数，今天每股价值约增加**9.33美元**；不据此宣称今天具有投资优势。

**最强相反选择有真实经济含义：持有者接受较低回报，且市场持续按约26倍现金化经营收益定价。** 用本模型NOPAT加JV净现金、扣少数和税后利息作为收益代理（非GAAP或管理层调整EPS），基准2029/2033约20.82/27.84美元；维持26倍再加分红，三年/七年年化约6.9%/7.8%。乐观路径相同倍数得到约11.3%/10.8%，可以满足10%要求。这是有利的**市场定价路径**，不与DCF取平均，也不证明倍数必然保持。收益代理含JV出资，较会计EPS更严格；未披露的养老金或JV会计调整不足作为永久高倍数的充分证据。

因此，不能把矩阵中一年−38%的基准条件回报称为“预测明年跌38%”。市场可能继续资本化远期低资本成本，也可能仅部分修正。当前拒绝的依据是自有现金价值缺乏回报支撑，而非已经证明未来短期交易价格。若投资者要求仅6%—8%、认可长久高估值且接受出现30%以上回撤，七年可成为有条件参与；这是偏好与定价持续性共同改变后的选择，不是经营事实改变。

## 七、四种经营情景 × 三种期限的条件建议

矩阵的同一问题是：**假定该行经营与资本路径成立，并在目标日按该条件合理价值退出，现价买入的回报是否够？** 每格总回报包含期间每股分红、不再投资；区间来自第六节统一参数。路径概率不在格内再乘。条件价值不保证市场采纳；尤其一年时，投资者无法观察完之后十四年的经营。估值置信度表示条件价值精度，不是路径发生概率。

评级标准在三列四行一致：参考年化10%，邻近8%—12%。中央财富较买价损失20%以上且有利端仍不能提供稳健10%回报，使用“强烈不建议投资”；其他中央回报低于8%且无足够补偿用“不建议投资”；8%—10%且证据分歧大用“中性/等待”；达到10%但敏感用“谨慎建议投资”；达到要求并经普通不利检验仍合理才用“建议投资”，具有明显额外余量才“强烈建议投资”。没有为了让矩阵好看而强制出现六档。

### 8.3 等待不是已经证明更优的交易策略

拒绝当前买价不等于保证将来有更低价。确认后可能更贵，等待还可能错过上行；现金可获得收益，但未来回报不可锁定为今日国债利率。以同样初始资金460.40、原七年目标日2033-09-19、等待一年获取4.44%且之后买入为**算例**：若2027成交570、以后走基准，剩余每股终值加六年分红约457.73，最终财富约386；若成交350，则约629。立即买入基准条件财富约464。该比较没有延长等待者期限，也未给其额外信息优势；570/350是交易价假设，不是预测。等待者还可能错误地不买或在坏消息后高估价值。

当前可支持的是“这笔新增投资缺乏足够现金价值优势”；不能从中推出一套择时策略已经在相同期初资金、信息和调整机会下严格占优。持有者的税务、组合角色与替代资产不同，也不能由新增买入结论机械推导必须立即卖出。

        buyprice=P0*(1+z['buyg'])**(t-.5)*buy_multiplier
        newshares=shares-buy/buyprice
        newdebt=debt-surplus+buy
        newcash=cash
        if newdebt<0:
            newcash-=newdebt
            newdebt=0
        cumdiv+=dps;cumrep+=buy
        ans.append(dict(t=t,debt=newdebt,cash=newcash,netdebt=newdebt-newcash,shares=newshares,interest=interest,
                        div=div,dps=dps,cumdiv=cumdiv,buy=buy,buyprice=buyprice,cumrep=cumrep,
                        capital_residual=newdebt-debt-(newcash-cash)-(div+buy+interest*(1-TAX)-row['fcff'])))
        debt,cash,shares=newdebt,newcash,newshares
    return ans

def valuation(z,rows,caps,h=0,w=WACC,g=None,roic=None):
    if g is None:g=z['g']
    if roic is None:roic=z['roic']
    end=rows[-1]
    terminal=(end['nopat']*(1-g/roic)+end['jv']-end['minority'])*(1+g)/(w-g)
    near=sum(r['fcff']/(1+w)**(r['t']-h) for r in rows if r['t']>h)
    pvterm=terminal/(1+w)**(15-h)
    debt=caps[h-1]['debt'] if h else D0
    shares=caps[h-1]['shares'] if h else S0
    cash=caps[h-1]['cash'] if h else CASH
    equity=near+pvterm+cash-RESERVE-debt
    divs=caps[h-1]['cumdiv'] if h else 0
    price=equity/shares
    wealth=price+divs
    return dict(h=h,ev=near+pvterm,equity=equity,price=price,divs=divs,wealth=wealth,
                total=wealth/P0-1,cagr=(wealth/P0)**(1/h)-1 if h else None,
                terminalshare=pvterm/(near+pvterm),pvterm=pvterm,terminal=terminal)

def calc(name,overrides=None,buy_multiplier=1,repurchase=True):
    z,rows=operations(name,overrides)
    caps=capital(z,rows,buy_multiplier,repurchase)
    vals=[]
    for h in [0,1,3,7]:
        central=valuation(z,rows,caps,h)
        low=valuation(z,rows,caps,h,.0925,z['g']-.005,max(.10,z['roic']-.02))
        high=valuation(z,rows,caps,h,.0775,z['g']+.005,z['roic']+.02)
        vals.append(dict(central=central,low=low,high=high))
    return dict(parameters=z,rows=rows,capital=caps,values=vals)

if __name__=='__main__':
    allresults={n:calc(n) for n in PARAM}

### 9.3 核验结果及仍不能裁决的变量

数值底稿已完成**228项算术检查**：单元利润到集团汇总、逐年资金恒等式、股数与债务可行性、目标日之后现金折现、另一路逐年逆推DCF、累计/年化恒等式及区间方向。随后做了利率/长期增长网格、延期、超支、利润率、独立机会成功、回购价及替代分布的经济检验。检验说明计算内部一致，不把假设验证成事实。

仍未裁决的主要事项具体为：

1. **逐项目最低付款和延期补偿。** 已核10-K/10-Q、凤凰城公告及2024Q4/2026Q1/Q2官方问答，知道存在固定付款/终止保护和部分可补偿LOI；逐项收费率、起付门槛、剩余投入及追索限制未查得。现有保护不能忽略，金额用收入/资本路径承接。
2. **电子及Lincare独立经营利润。** 终端收入/区域结果不足以精确拆利润；本模型电子起点及31%利润率为估计。核心与电子的利益归属、实际盈利质量和资本回报若发生系统性偏差，应重建单元，而非把残差当事实。
3. **合资现金调回、少数分配和现金税盾。** 台湾50%非并表已确认，具体新增项目融资与逐年分红未查得；模型前期净注资、后期分配均是范围内的代表值。现金可调回限制通过2.0经营准备和净现金参数承接。
4. **长期资本成本与竞争后ROIC。** 7.75%—9.25%、各行ROIC及g是本研究估值假设；这是能够改变合理价值最多的未解决变量。市场维持约26倍收益的相反解释单独保留，不能用财务计算否定其可能性。
5. **目标日真实股价。** DCF可复算，未来市场采纳时间无法从现有证据精确识别。因此报告交付条件价值、市场定价对照和当前选择，不把计算出的条件损失当已证实的价格路径。
