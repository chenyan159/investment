## 3. 核心投资逻辑与最强反证

### 3.1 最强正面逻辑

1. **需求已从 TAM 进入签约义务。** 6,380 亿 RPO 是 FY2026 收入的 9.5 倍，Q4 单季新增 850 亿，Q4 另有 670 亿 AI 基础设施新签；这不是销售 pipeline，但只有可在目标期交付的部分才有价值。
2. **OCI 已有收入与物理交付验证。** FY2026 IaaS 181.01 亿、+77%，Q4 +93%；公司披露 FY2026 交付超过 1.2GW、FY2027Q1 计划接近 1GW，GPU 利用率 97.5%，到期 GPU 数量留存 92%。
3. **Oracle 不只是通用 GPU 转租。** Database、Exadata、Multicloud、Fusion/NetSuite 和 support 形成高切换成本与高毛利利润池；Multicloud AI Database Q4 +404%，有机会提高 OCI 的数据库/网络/存储 attach，而不是只赚 30%–40% AI capacity 毛利。
4. **127.94 美元不再要求突破情景。** 当前普通股价格约为 FY2027 管理层 non-GAAP EPS 指引的 15.9 倍；反向估值显示，宽基风险扩张中基准上半段即可覆盖要求回报，震荡中才需要基准顶端或乐观下端。

### 3.2 最强负面逻辑

1. **订单到现金之间隔着一条重资产链。** 只有约 12% RPO预计一年内确认；电力、机房、GPU整架、网络、液冷、burn-in、客户验收和开始计费缺一不可。RPO 久期远长于普通软件订阅。
2. **利润尚未变成股东可得现金。** FY2026 收入 +17%、OCF +54%，但 CapEx 556.63 亿使 FCF 为 -236.86 亿；FY2027 仍需约 400 亿外部融资。调整后 EPS 不能替代现金回报。
3. **租赁久期和客户合同久期错配。** 2,600 亿尚未起租承诺多为 15–19 年，而 GPU经济寿命和许多客户合同更短；若大客户延迟或重谈，租金、电力和机房义务仍继续。
4. **每股分母不是静态 28.8 亿股。** 200 亿 ATM 按 127.94 美元全额发行约为 1.56 亿股；再加年度 SBC、期权和强制可转优先股，基准完全稀释股数可能达到 30.7–31.8 亿股。企业价值增长未必同幅到达每股价值。

### 4.2 要求回报反求

15 个月达到 18%总回报、并收到 2.50 美元股息，目标日除息每股价值至少需要：

`127.94 × 1.18 − 2.50 = 148.47 美元`

按基准中点 31.0 亿完全稀释股、目标期债务和确认租赁等优先索取权约 1,900 亿美元，所需经营性企业价值约为 **6,500 亿美元**。由此得到三组等价边界：

| 目标市场给出的租赁调整 EV/EBITDA | 为达到 148.47 美元所需的租赁调整 EBITDA | 对经营情景的含义 |
| ---: | ---: | --- |
| 12× | 约 **542 亿美元** | 超出基准 415–490 亿，进入乐观区间；典型于震荡下半部或有序收缩上半部 |
| 14× | 约 **464 亿美元** | 位于基准中上部；要求 FY2027 900 亿正常兑现、利润率靠近上端、资本桥不恶化 |
| 16× | 约 **406 亿美元** | 基准下端即可；但只适合广泛风险扩张或真实主题领导、且信用与波动稳定的状态 |

若完全稀释股数取 31.8 亿、优先索取权取基准高端 2,100 亿，则 14×所需 EBITDA 上升到约 **487 亿**，几乎是基准顶端；这说明当前价格最缺的不是订单，而是“资本投入和稀释可被控制”的证据。

## 6. 重大利好、利空与事件树

### 6.1 事件树：事件先进入传导链，不直接跳到目标价

```text
FY2027Q1及后续站点交付
├─ active MW、客户验收和计费达到/超过计划
│  ├─ AI capacity GM ≥35%，Database/SaaS attach上升
│  │  └─ 收入 → 利润 → FCF亏损收窄 → 净债务/稀释下降：基准上移乐观
│  └─ 收入高但GM仍约30%、CapEx继续前置
│     └─ 只提高收入，不提高每股价值：仍在基准，价值区间扩大
└─ 上电、整架、网络、液冷或验收延迟
   ├─ 客户继续履约且站点仅错期：基准下端/短期悲观，长期价值部分保留
   └─ 客户重谈、预付不足或融资收紧
      └─ FCF → 债务/租赁 → 低价ATM：悲观，流动性状态下存在永久损失路径
```

相互依赖的结果不相加：例如“1GW按期 + 收入上修 + 毛利改善”是一条连续传导，不是三份独立期权；“客户预付 + 减少债务 + 降低利息”也是一条资本桥，不重复加值。

### 8.2 主估值公式与去重

`租赁调整 EBITDA = GAAP营业利润 + 折旧 + 无形资产摊销 + 经营租赁成本`

`普通股股权价值 = 租赁调整经营性企业价值 − 净财务债务 − 已确认经营租赁负债`

`每股价值 = 普通股股权价值 ÷ 情景下完全稀释股数`

处理规则：

1. 经营租赁成本加回后，已确认经营租赁负债作为索取权扣除；若不加回租金，就不得再全额扣同一负债。
2. 尚未起租的2,600亿租约不整笔扣除。目标期预计起租部分进入租赁负债；未起租部分通过未来租金、FCF、倍数和低端风险体现。
3. Series D 目标估值使用 if-converted 股数，因此不另扣50亿；当前EV桥尚未转换，使用50亿优先额。ATM发行增加现金并增加股数，现金减债与稀释同时进入，不能只算其中一边。
4. 客户自供GPU不属于Oracle资产或Hardware收入；真实现金预付才减少净资本需求。

### 12.3 当前邻域

当前纯经营行是基准；为观察最近正面经营变化，选取相邻乐观行。市场邻域采用共享边界的宽基扩张和震荡两列。

| 经营行 \ 市场列 | 宽基风险扩张 | 震荡/均值回归 |
| --- | --- | --- |
| 当前基准 | **谨慎建议投资｜-12%～+52%** | **中性/等待｜-27%～+33%** |
| 相邻乐观 | **强烈建议投资｜+29%～+112%** | **建议投资｜+17%～+98%** |

- 邻域最弱为 **中性/等待**，最强为 **强烈建议投资**。
- 只发生一个合理的市场变化——宽基扩张回到震荡——基准建议就从正面转为等待，说明当前条件结论 **市场敏感**。
- 只发生一个经营行上移——active MW、GM和资本桥共同进入乐观——两列都转为正面，说明改善必须穿过收入、利润和FCF，而不是只增加RPO。
- 下行虽未放进这一“最近正面”邻域，但若Q1交付/Cloud失速并进入悲观，宽基和震荡两格都为强烈不建议；这是非对称尾部边界。

### 12.4 全矩阵形状

适用的中性标签为：

- **条件正面区域：** 基准只有风险偏好较好的两列正面；震荡需要更低价格或更好经营。
- **市场状态敏感：** 基准同一经营结果从谨慎正面一路变为强烈不建议，1×倍数约影响14–15美元/股。
- **经营兑现敏感：** 同一震荡列从悲观的强烈不建议，经过基准等待，到乐观建议、突破强烈建议。
- **当前价格在下行情景缺少保护：** 悲观行五列均为强烈不建议，没有净现金或资产保护形成的正面格。
- **非突破价值集中：** 正面区域不是只在突破；基准/乐观已经有六个正面格，但当前证据不能借用乐观和突破。

建议最稳定的区域是 **乐观×宽基/主题/震荡**以及整个突破行；不过这些格子的估值置信度仍低，不能把条件回报高误写成当前可达性高。最脆弱边界是 **基准×主题 ↔ 基准×震荡**以及 **乐观×有序收缩 ↔ 乐观×流动性压力**。

最坏格子为 **悲观×流动性/信用压力**：每股0–50美元、总回报-98%～-59%。首个传导原因不是“股价下跌”，而是 active/计费收入和毛利受损后，负FCF不能覆盖票据、融资/经营租赁和低价稀释，普通股成为最后残余索取权。

### 12.5 最重要的状态联动

纯格子回答“经营行保持不变时怎样”；以下联动回答现实可能沿哪条路径移动，不在原格子重复下调经营数字。

| 状态联动 | 首个受影响环节 | 下游传导 | 对应纯格子 → 更可达格子 |
| --- | --- | --- | --- |
| 有序收缩使模型客户融资/预算放慢，站点验收推迟 | 需求/项目 → 收入 | active MW下降 → 收入偏离900亿 → 固定CapEx/租金压低FCF | **基准×有序收缩 → 悲观×有序收缩** |
| 流动性压力使Oracle债务/ATM成本上升，即使客户需求未变 | FCF → 资本结构/稀释 | 低价ATM、债务利息和租赁清偿顺序 → 每股价值下降 | **基准×流动性压力 → 悲观×流动性压力** |
| 主题上涨伴随真实OCI交付、Database attach和GM验证 | 项目 → 收入，再到利润 | 不是只扩倍数；active MW、收入和GM同时上修，资本桥改善 | **基准×主题 → 乐观×主题** |
| 实际利率继续上行但信用/宽度正常 | 折现率 | 经营行不变，只从高倍数端移向中性倍数；不重复下调收入 | **基准×宽基扩张 → 基准×震荡** |
