## 2. 当前条件定位与矩阵摘要

### 2.1 当前条件定位

> **当前条件定位：** 当前证据指向 **“乐观收入/订单、基准利润兑现、悲观现金转换/资本强度”复合经营定位**，当前美国市场主状态为 **宽基风险扩张**、相邻状态为 **窄幅/主题主导上涨**；复合定位 × 当前市场状态的建议为 **中性 / 等待**，稀释后市值约 **`$1.84–3.95T`**、每股价值 **`$165–359`**、18 个月总回报 **`-33%～+45%`**，经营与市场状态证据强度均为 **中**，估值置信度为 **低**。最接近的纯格子是 **基准 × 宽基风险扩张**，其建议同为 **中性 / 等待**，每股价值 `$140–339`。相邻主题状态下复合定位仍为中性 / 等待；若进一步转入震荡状态则降至不建议投资。最小增强条件是 AWS 保持 `≥25%` 增长的同时，现金转换出现不靠削减必要产能的改善；最小减弱条件是 AWS 增速降至 `<22%` 而全年 CapEx 仍接近 `$200B`。概率层为 **NA**，原因是没有可审计的经营—市场联合基础率和相关结构。

这个区间很宽不是结论缺失，而是当前争议的直接表达：基于 AWS 与广告目标期营业利润的 SOTP 支持 `$244–359/股`，但基于 3—5 年正常化 FCFF 的 DCF 只有 `$165–301/股`；当前价格位于两种价值创造口径的交叉区，而不是两者共同给出明显安全边际的位置。

## 3. 核心投资逻辑与最强反证

### 3.1 最强正面逻辑

1. **高质量增长引擎同时存在。** Q1 2026 AWS 收入 `$37.6B`、同比 `+28%`、营业利润率 `37.7%`；广告收入 `$17.2B`、同比 `+24%`；第三方卖家服务同比 `+14%`。AWS 提供利润池，广告提供资本轻利润，Marketplace/Prime 提供流量、数据和履约利用率。
2. **AWS 多年需求可见性显著增强。** 10-Q 披露长期客户合同未确认履约义务约 `$364B / 5.5 年`；管理层另称 Trainium 收入承诺超过 `$225B`，OpenAI 扩大 AWS 协议 `$100B / 8 年`并预订约 `2GW` Trainium 容量。这些口径可能重叠，但足以证明需求不是纯叙事。
3. **自研芯片可能把规模转成单位经济。** Trainium2 基本售罄、Trainium3 接近满订，Bedrock 大部分推理运行在 Trainium；若 Neuron 迁移、利用率和价格保持，自研芯片能同时降低单位资本成本并提高 AWS 软件附加值。
4. **资产负债表仍能承受前置投入。** 3 月末现金与证券 `$143.1B`，且 Amazon 能在 7 月以长久期发行 `$25B` 新债；当前风险是投资回报率和固定承诺，而不是近期清偿能力。

### 3.2 最强负面逻辑

1. **利润没有等价转成自由现金流。** TTM 经营现金流 `$148.5B`、净资本开支 `$147.3B`、公司口径 FCF 仅 `$1.2B`；2026 年 CapEx 计划约 `$200B`。当前价格要求市场相信这一低现金转换是过渡期，而不是新常态。
2. **订单到现金之间有多道物理与软件闸门。** 电力、园区、HBM、先进封装、网络、液冷、Neuron 迁移、客户验收和利用率任一延迟，都会让折旧和利息先发生、收入和现金后发生。
3. **多年承诺不能线性年化。** `$364B` RPO、`>$225B` Trainium 承诺、OpenAI 与 Anthropic 合同互有重叠，且期限为 5.5—10 年；客户集中、价格阶梯、终止条款和真实消耗未公开。
4. **融资规模正在上升。** Q1 2026 已发行约 `$53.8B` 美元/欧元长期债，7 月又发行 `$25B`；若 AWS 增速回落而 CapEx 与模型公司投资不降，股东价值会先被利息、净债务和低回报资产稀释。

### 3.3 决定胜负的变量

决定胜负的单一变量不是 AWS 收入，也不是 CapEx，而是：

`新增 AI 资产的折旧后、资本开支后现金回报率`

它需要同时满足：可计费容量按时上线、AWS 增速保持、AWS 利润率不因低价大单或低利用率下滑、广告/Marketplace 提供资本轻缓冲，并且 TTM FCF 在 2027 年前后恢复。只要收入强而 FCF 长期停留近零，当前 SOTP 与 DCF 的分歧不会消失。

## 4. 当前价格隐含要求

### 4.1 从股价反推经营价值门槛

按完全稀释 10.9B 股，当前股权价值约 `$2.696T`。采用当前非经营资产桥 `+$70–95B` 后，市场隐含的核心经营性企业价值约为：

`$2.696T − $0.070T～$0.095T = $2.60T～$2.63T`

在当前宽基风险扩张格子的估值参数下，这个经营价值需要下面的组合之一，而不是唯一精确答案：

| 隐含要求 | 可行边界 | 与纯情景的关系 |
| --- | --- | --- |
| NTM 收入 | **约 `$830–870B`** | 覆盖基准中高端至乐观低端；明显高于悲观 `$793B` |
| NTM 营业利润 / 利润率 | **约 `$100–120B / 12%–14%`** | 基准 `$104B` 只到低端；要保持当前倍数需利润继续改善 |
| 18 个月目标收入 | **约 `$900–960B`** | 基准目标区间上部至乐观低部 |
| 18 个月目标营业利润 | **约 `$120–145B`** | 需要 AWS 与广告共同兑现；传统零售收入增长本身不足 |
| AWS 目标期营业利润 | **约 `$65–85B`** | 当前状态下约 `24–30x` EV/EBIT；基准上沿或乐观低端 |
| 非 AWS 目标期营业利润 | **约 `$40–60B`** | 约 `18–22x`；需要广告和服务 mix 留下利润 |
| 3—5 年正常化 FCFF | **宽基状态 `$93–132B`；震荡状态 `$109–148B`** | 宽基状态接近基准区间；震荡状态需要基准上沿至乐观 |
| 3—5 年收入增速 | **约 `9%–12%`** | AWS/广告必须持续高于集团；不能靠一次性汇率或投资收益 |
| 正常化营业利润率 / FCFF 率 | **约 `14%–17% / 9%–13%`** | 高于当前 TTM 11.5% 营业利润率；FCFF 要从近零显著恢复 |
| 终值 / 资本成本 | **WACC `8%–9%`、终值增长 `2.5%–3.0%`** | 若 WACC 升至震荡区间，经营要求相应升高 |
| 稀释与资产桥 | **目标期稀释股数最好不高于约 `11.1B`，非经营资产桥保持正值** | Globalstar 股份对价、员工股权和新增融资不能显著侵蚀每股价值 |

### 4.2 隐含事件成功条件

当前价格不要求所有突破事件同时发生，但至少要求：

- Q2 指引大体兑现，随后 AWS 增速在多数季度维持约 `25%` 或更高；
- AWS 营业利润率大致保持 `35%–38%`，不因低价锁定大客户、折旧先行或低利用率持续跌破约 `33%`；
- AI 年化收入从 `>$15B` 向 `$20–25B` 以上爬坡，且 RPO 的短期确认比例没有继续后移；
- 广告保持高双位数增长，3P/FBA 不出现卖家流失和费用反噬；
- 2027 年正常化 FCF 至少向 `$75–105B` 基准区间靠拢，而不是依赖持续发债维持 CapEx；
- OpenAI/Anthropic 容量建设、Trainium3/4 和电力园区没有出现足以把收入延后两个以上季度的系统性失配。

### 4.3 哪些要求接近哪一情景

- **接近基准：** NTM 收入约 `$839B`、营业利润约 `$104B`、AWS `+25%`、广告 `+22%`，足以在宽基风险扩张下让当前价格处于合理区间，但没有低端安全边际。
- **需要乐观：** 在震荡或更高折现率环境中仍支撑 `$247.31`，需要目标营业利润约 `$140B+`、正常化 FCFF `$110B+`，以及 AWS/广告同时超预期。
- **不要求突破但借用了部分长期可选性：** 当前价格没有要求突破行全部成立；然而若市场从宽基扩张切换到有序收缩，只有乐观上部或突破路径才能维持明显上行。
- **证据尚不足：** 正常化 FCFF 率能否长期达到 `12%+`、Trainium 大单折旧后回报、客户实际消耗和 2027—2028 可计费 GW 均没有直接披露。

### 6.2 事件树与防重复计价

最重要的事件链不是可相加的十个催化剂，而是：

`发债/CapEx → 园区、电力、芯片、网络、液冷完成 → Neuron与客户验收 → 可计费利用率 → AWS收入 → 折旧后利润 → CapEx后现金`

- 若在“可计费利用率”之前失败，进入悲观路径；其价值影响只在收入时点、利润和资产桥中处理一次。
- 若容量按时上线但低价合同使利润率下降，只调整 AWS EBIT 和正常化 FCFF，不再把同一大单当成额外利好。
- 若 Q2 财报超指引只是汇率或 Anthropic 估值收益，不升级经营行。
- OpenAI、Anthropic、Trainium承诺与 `$364B` RPO存在重叠；报告从未把它们相加为独立 backlog 或项目价值。

| **当前定价/反向估值** | 检查股价已经要求的营业利润、现金流率和终值 | 不独立给目标价；用于说明基准是否已被价格吸收 |
| **近端核心盈利倍数** | 检查目标期 EBIT 和剔除股权重估后的核心净利润是否相容 | 广告/3P独立利润率未披露，机械TTM PE被非现金投资收益美化 |
| **项目/期权价值** | 只处理Globalstar、Trainium/Bedrock和非经营投资的边界 | OpenAI/Anthropic合同已进入AWS路径；不把合同金额或芯片部署再额外加一份项目价值 |

最终格子区间采用 **SOTP 与 DCF 的外包络**。SOTP 与 DCF不重叠时，不把两者平均成一个“精确目标价”：低端保留现金流模型的资本强度惩罚，高端保留分部利润模型的业务质量价值，并把估值置信度降为低。

### 8.4 公式与模型分歧

主估值：

`经营EV = AWS目标期EBIT × AWS倍数 + 非AWS目标期EBIT × 非AWS倍数`

`股权价值 = 经营EV + 目标期非经营资产桥 + 市场列资产桥修正`

DCF：

`经营EV = Σ[FCFF_t ÷ (1+WACC)^t] + 终值 ÷ (1+WACC)^5`

`终值 = FCFF_5 × (1+g) ÷ (WACC−g)`

最主要的分歧来自：

1. SOTP把目标期 AWS/广告利润资本化，隐含市场愿意继续为高质量利润支付溢价；
2. DCF要求这些利润在扣除维持和扩张资本开支后真正留下现金；
3. Amazon 未披露 AWS AI 独立毛利、可计费GW、利用率、广告利润率、合同价格和项目级ROIC，无法把两种模型的差异缩成窄区间；
4. 非经营投资账面值 `$96.5B` 对私募估值、税和流动性敏感，不能按现金等价物高置信加回。

## 11. 板块轮动修正

### 11.1 当前板块相对状态

Amazon 在GICS中属于消费可选，但经济利润同时暴露于云/AI、广告和电商。2026-07-13：

- XLK 约 YTD `+26.2%`、近3个月 `+27.3%`，显示AI/科技领导；
- XLY 约 YTD `-2.4%`、近3个月 `+3.0%`，明显落后SPY；
- AMZN 约 YTD `+7.1%`、近3个月 `+3.8%`，没有完整跟随科技领导，也没有与消费可选一起明显下跌；
- Q1 AWS和广告增长证明AI/数字化主题与真实收入存在传导，但FCF近零说明市场不能只按主题映射。

因此板块相对状态为 **中性 / 分化**。不机械改变任何格子的建议等级：AWS相关估值可在主题列使用区间中高部，消费/零售部分仍使用较低倍数；两者已经在主题列的分部倍数中一次性体现，不再进行第二次上调。

### 11.2 何时改变修正

- 升为“领导/流入”：AWS/广告盈利预期与相对价格共同改善，AMZN相对SPY/RSP转强，且FCF预期不恶化；建议最多增强一级。
- 降为“退出/流出”：AWS/广告盈利修正和AMZN相对价格同时恶化；采用更高安全边际，建议最多减弱一级。
- 单纯科技ETF上涨、社交媒体AI叙事或AMZN一日涨跌，不触发修正。

| 有序风险收缩 | `$105–248` | **约 `$150`** | 约 `$89` | `>$248` |
| 流动性/信用压力 | `$82–189` | **约 `$115`** | 约 `$69` | `>$189` |

相对当前 `$247.31`：

- 在当前宽基/主题状态，基准行若只靠价格而不靠证据改善，要到约 `$203`（下跌约18%）才让区间中部达到研究门槛；
- 对当前复合定位本身，联合区间中点约 `$262`：价格约降至 `$220`（约 `-11%`）时，中点才达到18%门槛，最多支持从等待上移为谨慎；若证据不改善而价格升至约 `$262`以上（约 `+6%`），区间中点转为负回报，建议容易减弱为不建议。低端达到18%需约 `$140`，说明价格单独带来的“强建议”边界很远；
- 当前复合定位转为谨慎正面，更现实的路径是正常化FCFF低端从 `$90B`向 `$110–120B`抬升，而不是只等倍数继续扩张；
- 若市场进入有序收缩，当前价格几乎等于基准高端 `$248`，轻微估值或盈利下修就会使全区间转负；
- 若进入信用压力，当前价格已经高于基准和乐观行高端，只有突破经营或市场状态解除才能改变方向。

### 12.3 全矩阵形状

中性标签为：**条件正面区域 + 经营兑现敏感 + 市场状态敏感 + 突破价值集中**。

- **稳定负面区域：** 悲观行全部五格；基准 × 有序收缩/流动性压力；乐观 × 流动性压力。
- **稳定正面区域：** 突破 × 宽基/主题；突破 × 震荡仍为建议投资，但证据强度低且不是当前定位。
- **最脆弱边界：** 乐观 × 震荡与突破 × 有序收缩；两者都因低端仍有损失而只能谨慎。
- **当前价格支持不足的地方：** 基准行只有宽基/主题格子的高端提供较好上行；一旦市场状态不利，基准经营不足以支持现价。
- **建议最稳定的区域：** 悲观行的负面结论最稳定；正面结论只有在突破经营配合非压力市场时稳定。

最坏格子是 **悲观 × 流动性/信用压力**：每股 `$36–136`，相对当前损失 `-85%～-45%`。原因不是假设Amazon立即破产，而是增长/利用率不达资本承诺、投资资产折价、融资与折现率跳升、经营租赁和采购承诺限制缩表速度，导致常规高倍数失效。

### 12.4 重要状态联动

| 起始纯格子 | 传导变量 | 更可达的联动格子 | 不重复计价说明 |
| --- | --- | --- | --- |
| 基准 × 有序收缩 | 企业IT预算、广告ROI、客户容量消耗下降；AWS `<22%`且CapEx不降 | **悲观 × 有序收缩** | 原基准格子只压倍数；经营下移后才改变收入/利润，不能两边同时完整扣减 |
| 基准 × 流动性压力 | 私募投资折价、融资成本和客户信用恶化，RPO期限拉长 | **悲观 × 流动性压力** | 原格子先保留基准经营；联动格子再计需求/现金破坏 |
| 当前复合 × 宽基扩张 | AWS `≥30%`、利润率 `≥37%`且FCF跨 `$20B` | **乐观 × 宽基扩张** | 只在现金转换真正改善后结束复合状态，不因合同标题上移 |
| 乐观 × 主题上涨 | AI收入增长但降价、折旧和客户集中使FCFF不升 | **基准 × 主题上涨** | 主题倍数仍在市场列；经营行只下调利润/现金质量 |

这些联动说明“纯格子若保持不变会怎样”和“现实可能沿哪条路径移动”是两个问题。主矩阵保留纯条件，联动只描述迁移，不分配概率。
