- 目标期前瞻收入大致 $11.5–13.0bn；
- 非 GAAP OPM 从 FY2026 约 41% 提升至约 44%–47%；
- 利息和税后调整后净利润率约 31%–34%；
- 目标期年化 FCF 至少约 $3.0–4.0bn，或市场持续接受低于 3% 的股权 FCF yield；
- 净债务降至约 $4.5–5.5bn，稀释股数不显著超过 198m。

### 4.3 DCF 反向边界

以当前 EV $90.62bn、起始 FCFF 约 $2.6bn、五年显性期、WACC 8.5%、终值增长 3.0%–3.5%反向求解，当前价格要求前五年 FCFF 复合增长约 **16%–18%**，第五年 FCFF 约 **$5.4–5.9bn**；若 WACC 升至 9.0%，要求约 **18%–20%**。这不是唯一解，但清楚表明：当前估值不能只依靠 8%–10% 收入增长，必须同时依靠利润率、现金转换和较低折现率。

## 5. 经营四情景与当前复合定位

### 5.1 共同驱动与建模纪律

四条纯经营情景都使用同一组六项驱动：核心 EDA 与 HAV、Ansys 续约及交叉销售、Design IP 里程碑、backlog / 新签、经营杠杆与现金转换、净债务及稀释。Agentic、3DIC、Ansys AI 子集、HBM 和 UCIe 是横切技术，不与会计产品收入重复相加。

目标期前瞻收入指 2027-10-31 时点未来 12 个月收入运行率；目标期 FCF、EPS、净债务和股数也是同一时点口径。ROIC 指含 Ansys 收购资本的近似税后经营回报，显著低于剔除商誉后的增量 ROIC。

### 5.3 情景条件、确认时间与失效条件

#### 悲观 / 受损

- **破坏路径：** backlog 新签持续弱于收入确认，Design IP win 延迟转成 NRE / royalty，HAV 验收跨期，Ansys Fusion 只有整合成本而没有合同 uplift；费用削减又影响客户支持。
- **现金与永久损失：** FCF 仅 $1.75–2.0bn，净债务在目标期仍高于 $6bn；2027 / 2028 到期债务可偿付，但高利率环境下资本配置空间收窄，股东主要损失来自经营与倍数双杀而非近期破产。
- **进入条件：** 连续两个可比季度代理 B2B 明显低于 1、backlog 继续下降；到 FY2026 Q4 Design IP 仍同比为负或利润率再次恶化；FCF 低于约 $2.0bn。
- **最早确认：** FY2026 Q3（收入 / backlog / IP）到 FY2026 Q4（全年 FCF / 利润率）。
- **失效条件：** IP 同比转正且利润率 30%+、backlog 稳定、FCF 高于 $2.2bn。

#### 基准 / 正常兑现

- **经营路径：** 核心 EDA 高个位数至低双位数增长；Ansys 续约和少量 cross-sell 正常；Design IP 在 FY2026 H2 / FY2027 恢复；ZeBu-200 按期交付；约 $4.51bn 普通 backlog 在 NTM 正常确认。
- **现金与资本：** 非 GAAP OPM 42%–43.5%，目标期提升至 44%–46%；FCF 使净债务降至 $4.6–5.6bn，回购主要抵消 SBC。
- **进入条件：** backlog 稳定、代理 B2B 接近 1；IP 收入同比转正；公司维持 / 上调 FY2026 及 FY2027 现金和利润目标。
- **最早确认：** FY2026 Q3 可确认方向，FY2026 Q4 / 2026-09-30 Investor Day 可确认中期现金和利润框架。
- **失效条件：** backlog / IP / FCF 任两项持续低于门槛，或 Ansys 有机增速降至低个位数且无 cross-sell。

#### 乐观 / 超预期

- **经营路径：** Design IP 同比和利润率明显修复；HBM4、PCIe7 / 224G、HAV、3DIC / Fusion 至少两个方向从技术 win 转成可确认金额；AgentEngineer 至少出现小规模付费生产 attach。
- **利润为何留下：** 上修主要来自软件、IP 与 bundle，而不是低毛利 HAV 硬件 pass-through；目标期 FCF $3.2–3.8bn，净债务降至 $3.5–4.5bn。
- **进入条件：** backlog 重回增长、代理 B2B >1；IP 双位数增长和分部利润率 30%+；Fusion / Agentic 披露 ACV、付费客户或续约；FCF 路径 $2.5bn+。
- **最早确认：** FY2026 Q4 至 FY2027 Q2。
- **失效条件：** 只有 demo / logo / tapeout，没有金额、生产和现金；或收入上修主要来自 HAV 硬件且利润率不升。

#### 突破 / 非线性

- **经营路径：** AI ASIC design starts、HBM4 / 224G / 64G UCIe、Agentic 付费和 Ansys 多物理场需求同时加速；SNPS 凭 full-flow、foundry port、controller + PHY + VIP 和统一数据面提高份额与 ASP。
- **前置条件：** Agentic 成为规模化付费模块；Fusion 有双向 cross-sell 和可量化 uplift；多客户 HBM4 / PCIe7 / 224G 进入 early production / royalty；64G UCIe 不再停留于 tapeout；交付与人员支持无瓶颈。
- **时间表：** 最早 FY2027 H1 看到多项前置证据，完整目标路径更可能在 FY2027 H2 至 FY2028；本报告没有把更远期量产强行放进 NTM。
- **反证：** Agentic 仍免费捆绑，64G UCIe 量产仍指向 2028 后，Fusion 无合同 uplift，或 backlog / 人员 capacity 不支持同步放量。
- **证据判断：** 商业路径存在，因此不标记 NA；但当前缺少足够 A/B 级金额和时间证据，状态证据强度为低。

## 8. 多估值理念与格子参数

### 8.1 方法职责

| 方法 | 本报告职责 | 取舍原因 |
| --- | --- | --- |
| 目标期 EV / 前瞻收入 + 资本结构桥 | **主估值方法** | 收入与产品路径比并购后的 GAAP 利润稳定；通过情景利润率约束倍数，并显式扣除目标期净债务、除以稀释股数 |
| 目标期调整后 P/E | 上沿 / 近端兑现交叉验证 | 能反映软件经营杠杆，但排除了无形资产摊销且容易低估 SBC、债务与并购资本成本，因此不单独定价 |
| 10 年 FCFF DCF | 下沿、久期和现金转换约束 | 直接惩罚低 FCF yield、净债务和高实际利率；对 WACC、终值及收购后正常化现金流高度敏感 |
| 反向估值 | 当前门槛检查 | 已在第 4 节说明当前价格需要的收入、利润、FCFF 增长和退出条件 |
| 分部 / 期权 | 乐观和突破的合理性边界 | EDA / Ansys / IP 的利润属性不同；Agentic、UCIe 等未形成独立披露，不能伪造精确 SOTP，故只作为上沿约束 |

最终价值区间不是方法平权平均。EV / 收入给出中心，P/E 常形成上沿，DCF 常形成下沿；当二者分歧大时，区间向两侧扩展并把估值置信度降为低。尤其在基准行，调整后盈利法忽略的收购摊销 / SBC / 债务，与 DCF 强调的低现金收益率，是当前估值分歧的主要来源。

### 8.4 模型分歧与最终区间纪律

- 基准 × 宽基的 EV / 收入中心约给出 $421–518 / 股；10 年 DCF 的全敏感性约为 $298–559，调整后 P/E 约为 $426–588。最终区间扩为 $360–560，估值置信度降至低。
- 乐观与突破的 P/E / DCF 上端很高，但路径中含未披露 ACV 和量产节奏；条件建议不因“当前可达性低”机械降级，估值置信度仍为低。
- 悲观行三种方法虽然区间也分散，但都指向当前价格以下，方向一致性更高，因此正常市场列的估值置信度可为中。
- 流动性压力下市场功能和可比倍数可能失效，所有行的估值置信度均低。

- **增强一级的必要条件：** SNPS / IGV 相对 SPY 持续转强，同时 Design IP、backlog 和 FY2027 EPS / FCF 预期上修；只看到 SOXX 上涨不够。

当前邻域的建议从“强烈不建议投资”到“谨慎建议投资”，说明条件判断 **不稳健且经营兑现敏感**。单纯从宽基扩张切到主题上涨，只能把当前复合结论从“不建议”提高到“中性 / 等待”；真正使方向出现正面条件建议的是经营证据上移至纯基准，而不是市场叙事。最容易改变建议的经营假设是 Design IP / backlog 是否修复，最容易改变估值的市场假设是实际利率和宽度能否共同维持。

### 12.2 全矩阵形状

矩阵可用三个中性标签描述：

1. **条件正面区域：** 基准行只有在宽基 / 主题列出现谨慎正面；乐观行在正常市场出现正面；并非广泛正面。
2. **经营兑现敏感：** 同一宽基列从悲观 -59%～-23% 跳到基准 -17%～+29%、乐观 +15%～+89%，执行对价值的影响大于轻微市场变动。
3. **市场状态敏感 / 部分突破价值集中：** 同一乐观行从主题 +15%～+107% 降到压力 -45%～+4%；在不利市场中，只有突破行仍保留明显上行区域。

建议最稳定的区域有两个：

- **稳定负面区：** 悲观行全部五列均为强烈不建议投资；经营损害不能靠市场上涨补偿。
- **稳定正面区：** 突破行在宽基、主题和震荡三列均为强烈建议投资；但这只是假定突破已成立后的条件结论，当前证据强度仍低。

最脆弱边界是：

- **基准 × 宽基 / 主题 ↔ 基准 × 震荡：** 由谨慎建议转为中性；决定变量是 10 年实际利率与宽度。
- **乐观 × 有序收缩 ↔ 乐观 × 流动性压力：** 由谨慎建议转为不建议；决定变量是信用和市场功能。
- **当前复合 ↔ 纯基准：** 一组 Q3 / Q4 IP、backlog 和 FCF 证据即可上移一级；反向下移则造成大幅价值缺口。

最坏格子为 **悲观 × 流动性 / 信用压力：$80–195 / 股，-82%～-55%**。损失来自收入 / FCF 受损、净债务不能快速下降、2027 / 2028 到期债务需要优先处理，以及常规软件退出倍数失效；不是简单把同一倍数压缩重复计价。
