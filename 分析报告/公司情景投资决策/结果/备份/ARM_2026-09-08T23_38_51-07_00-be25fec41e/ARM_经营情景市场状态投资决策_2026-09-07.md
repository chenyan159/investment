# ARM：经营情景、价值传导与分期限投资决策

## 1. 当前判断、研究时点与结论覆盖范围

**以252.09美元买入，短期不建议投资，中期不建议投资，长期在稳健复利理念下不建议投资；高风险技术突破理念下保持中性／等待。** Arm的生态与数据中心采用并不弱，问题是现价要求比“IP持续增长＋自有CPU初步成功”更强的盈利、资本效率和增长持续期。对公司技术地位的正面判断，不能替代对买价的判断。

本研究最重要的预期差有三项。第一，云端采用增长既可能通过IP版税变现，也可能被客户自研和平台整机供应商捕获；Arm AGI CPU是另一条毛利、投入与风险不同的路径。第二，前期增长较多来自关联授权，手机数量恶化又要求更高的有效单机版税，不能把总收入增速视为广泛独立需求。第三，最新监管文件披露的尚未确认股权报酬，比简单延续历史SBC运行率更沉重，但这不等于要在现金流和完全稀释股数中扣两次。

|---|---|---|---|

ALA允许客户自行设计兼容核心，客户“自研”不必然免版税，却可能减少购买Arm实现IP的金额。CSS争取更完整子系统收入，也承担更多交付责任。许可中的版税买断、最低承诺可能计入固定授权；因此不能把授权与潜在版税都视为独立增量。版税按客户出货所在季度估计确认、后续调整，不应统一说固定滞后一季。[L1][S2]

**最弱传导环节**依次是：客户采用能否转为足够的Arm净收费；巨大远期收入能否覆盖真实研发和资本；昂贵每股买价是否已把剩余空间预付。短期债务不是目前的主约束，不能让“净现金”掩盖收费和价格问题。

## 3. 四种完整经营与资本路径

### 3.1 场景定义与共同模型规则

四行是完整公司发展路径。各行先建手机、数据中心、其他成熟版税、许可/服务、软银服务，再加入AGI和早期CSS增量。早期机会使用**条件于本行情景的局部状态分布**；不赋予四种完整情景整体概率。基准不是最常出现的每一项结果拼接，而是一套当前事实较能支持的资源和需求组合。

### 3.2 AGI CPU：逐年互斥状态、量价与现金

U＝当年仍在工程/认证或延期、无重大可确认收入；P＝有限商业成功，有付费客户但规模较小；S＝当年规模成功且仍在销售；F＝退出/永久失败。**F为吸收态**。S可以退化到P或F，P可以暂退U；后者表示曾销售但某年没有可确认新一代收入，不抹掉过去成功。各行每年概率合计100%，表中四舍五入可能差0.1个百分点。没有统计基础率可校准，以下是证据约束的主观工作分布，不是官方概率或精确胜率。

从已具备Meta共研、OEM产品与初始交付出发，FY27进入P的概率高于纯研发芯片；F不设为零，因为量产验收与商业条款仍未知。基准FY28约27%处S、50%处P，反映供给美元锚点强于多客户持续复购证据。乐观与突破提高的是验证速度、客户扩量规模和生存持续性；不是同一概率乘一个统一系数。长期S概率也不趋于100%。[S3][S6]

状态内量价：P/S当年收入列于下表，以**净ASP 4000美元**换算时，收入R bn对应0.25R百万颗。FY28基准P为0.70 bn，约2—4个客户、合计17.5万颗；S为1.50 bn，约4—8个客户、37.5万颗。该客户数与ASP是研究假设，非订单清单。到FY31基准P为2 bn、50万颗；S为6 bn、150万颗；后者需要复购及OEM扩张，不能只靠一个试点。

每年状态现金先算再加权。P毛利率从36%逐年加1.5个百分点、上限43%；S从40%逐年加2.5个百分点、上限50%；悲观分别30%/35%。P专属现金费用＝0.32＋12%收入，S＝0.40＋10%收入；U费用＝max(0.08,0.45−0.04×年序)，F仅在新退出时支付关闭成本。所有股份报酬在平台公共费用列一次。P/S资本支出为0.07＋4.5%收入／0.10＋4%收入；U也要支出0.09，**成功前投入不乘最终成功概率**。P/S占用营运资本为收入24%/20%。新失败损失包括0.15＋上年S收入3%的关闭支出与前状态营运资本50%损失，其余回收；存量F不无条件重新开发同一路径。

### 3.4 集团财务、再投资与股份支付的处理

经营底稿先建立未被蚕食的IP收入，再扣AGI期望收入2.5%作为原外部版税/授权损失；内部自用IP完全抵销。IP毛利率四行分别96.5%/97.2%/97.5%/97.5%；以下手机/云/其他/许可/软银五列为蚕食前收入。**其他列包含3.3早期增量**；平台费用包括共用技术、分摊服务、雇主税及相关研发补贴净额，不能称为公司披露的分部成本。

存量与持续薪酬分开。6月30日已存在约2400万份预计归属奖励，**起点全部加入经济稀释股数**，同时把对应尚待计入损益的旧奖励成本，从未来估值现金中加回，避免计两次。尚未确认3.6219 bn按FY27剩余1.650、FY28 1.700、FY29 0.272 bn确认；加上已披露FY27Q1的0.343，全年旧SBC为1.993。是按披露确认期设的研究节奏，不是公司未来季度指引。

新授予/持续留才成本另外预测：基准FY27—31为0.20/0.70/1.40/1.50/1.70 bn，长期随业务扩大。目标日后的这部分**不从估值现金加回**，相当于按现金替代报酬计价；目标日前报告现金中的新授奖励通过完全稀释股数体现。新奖励股数近似为授予经济成本/情景结算价；员工代扣税假设为全部SBC的30%，既扣现金又减少用于缴税的奖励股数。这是可复核经济股数模型，不是未来法定股本或GAAP EPS精确预测。

现有24m奖励已经预留，未来归属不再重复加股。员工代扣税造成现金流出和奖励股数减少，因此短期经济稀释股数可略下降，即使普通股法定已发行数仍增加。未计入新的ATM、转债或股权并购，因为未取得此类已确定条款；压力融资另列。未来授予时点与归属条件未知，股数±2%压力比报告小数精度更有意义。

### 3.6 投入批次、ROIC与融资压力

强成功也会先占钱：按芯片收入20%营运资金，完整FY31突破17 bn需要约3.4 bn营运资本；从FY28开始逐年投入而非全留到FY31。若占用从20%升到35%，额外约2.55 bn；本行的IP现金可覆盖一般爬坡，若IP受损则融资压力明显上升。不能用同一平均余额给失败和成功两个分支同时担保。

### 4.2 各期限为何会出现不同的信息与建议

**3个月**只有一次完整财报窗口。11月可能确认手机组合、关联许可交付和下一季费用；尚不足以证明2027年1—3月CPU大规模验收。即便2 bn需求再被重述，也不解除订单取消/制造/现金三个失败解释。当前不建议投资。

**6个月**覆盖拟于2月3日公布的Q3财报。管理层明确说届时提供AGI收入与毛利更详细更新；该事件可能在收入完全出现前降低商业失败风险。因此本研究并不排除先于利润重估。由3个月转为可考虑参与，至少需：可确认交付能力超过原1 bn两年规模、有约束的客户验收与回款条件、初代毛利仍约40%，并说明新增工程支出。只有出货计划标题，不足以改变评级。财报日为公司暂定日期，未当已完成事实。[S3][S9]

**12个月**会看到FY27Q4首批大规模商业收入和FY28Q1。重点是外部客户复购而非展示样机、收入与应收/库存/制造预付款相容、non-GAAP到GAAP差额与后续薪酬可解释。利润增长如果靠省略研发或添加关联服务，而净现金没有积累，就不能以完整成品收入乘IP倍数。基准目标日后NTM收入约7.75 bn、GAAP EBIT约1.10 bn，无法独自承接约270 bn股权价值。

**36个月**的关键不是当前产品能否卖，而是多个产品代际能否形成可重复平台收费。强竞争者也会扩产，供给解除有利于交付却可能削弱ASP；本模型没有让成熟硅毛利超过50%。退出时仍计入FY31—36及终值的剩余机会，不把2031收入直接当2029收入。正常路径在三年后仍有增长，但相对现价回报不足；技术突破投资者真正争论的是FY31之后能否继续扩大到很高的现金规模。

### 4.4 主估值与理念分歧

主矩阵采用**目标日剩余股东经济现金折现＋资本桥**。选择理由：从授权转成芯片后，销售额与毛利不可互换；GAAP近期受到旧奖励摊销影响，non-GAAP又忽略持续报酬；简单P/E或P/S会遗漏重要成本。短期同时单独讨论里程碑交易方法，但缺少可核验采纳模型，所以不能把其任意上沿放进主格。

各目标日只折现其后的现金，目标日前报告现金经真实积累模型加到资本桥。旧奖励以股数计成本；新持续报酬在目标日后的估值FCF中扣除。股权投资处置值0.45 bn另加；现金净利息不资本化进经营价值。普通有息净债务主桥为0，租赁/EDA按前述经营支出处理；现金只加一次。

终值在2036-03-31后的起点计算：`TV = FY36税后经营利润×(1+g)×(1−g/增量ROIC)/(r−g)`，随后折现回目标日。不是将FY36高增长无限延续；终值增长必须配对再投资。终值假设是长期行业稳定/更新竞争已经形成的稳态，不是确认2036后无失败风险。失败概率已进入AGI逐年状态分布，未再给同一项目乘第二次“成功率”。

| 悲观 | 13.0%／2.0% | 11.5%／2.5% | 15% | 经营受损后的合理风险补偿与稳态，不是资产底价 |

### 4.6 现价隐含的经营门槛

以1.092 bn经济股数，现价对应约275.28 bn经济稀释市值；普通股口径快照市值约269.23 bn。此差额只是不同股数口径，不是行情错误。按6月净现金并扣收购、另加0.45 bn资产，现价大约要求**271 bn经营价值**。以下都是反向组合，不冒称唯一市场共识。

FYE31管理层250亿美元集团目标由IP100亿与AGI150亿构成。本文基准集团约126亿，乐观约206亿，突破约314亿；差别不是统一把收入打折，而是云收费、许可增长、AGI当年成功状态与费用路径不同。即使经营达到其目标，若盈利口径排除持续报酬、营运资本升高、市场回报要求提高，股东投资仍可不理想。[L1][S11]

## 5. 条件建议矩阵与十二格明细

### 5.1 先定风险补偿与主理念

主矩阵短期采用可确认经营支持的价值及里程碑逻辑，中期采用兑现/现金，长期采用可持续复利现金。要求回报工作门槛在评级前统一设定：6个月累计**12%**、12个月累计**18%**、36个月年化**15%**（累计约52.1%）。相较美元短债约4%，这些门槛反映集中单股、不确定交付和机会成本；不是预测收益，也不在估值FCF上再乘折价。高风险突破理念要求三年年化**20%**（累计72.8%），不采用“下限损失必须小”的稳健约束，但仍要有可辩护的正期望。

主值已经纳入各行情景内AGI与CSS增量的局部概率。突破行明确假设FY27有限商业收入成立，后续扩量仍用其本行分布；没有因为突破“当前不太可信”而降低它的条件评级。它中长期仍等待，是**即便按该路径，工作值及合理不利估值敏感性回报仍不足**。完整成功参照不替换主格。

估值置信度：对悲观未来收缩力度与资产可实现性低，对基准固定现金框架和方向中、精确点位仍低，对远期乐观/突破低。与3.1“路径证据强度”是两个维度；“中”不表示价格会按期达到此值。

## 6. 当前路径、价格边界、概率敏感性与最强反证

### 6.1 当前路径与分期限价格边界

当前证据更接近基准：外部版税和云量产方向有支持、Q2经营指引明确；大客户芯片采购、第二代净利润与关联服务持续期证据仍不足。本研究没有足够证据给四行总体发生概率，也不从基准手机、突破芯片、乐观费用中挑有利项拼出所谓实际路径。

按**基准11%折现、3%终值增长**的明确工作值计算下表，绝非区间60%或75%位置。买价上限＝对应目标日价值/要求回报；低端约束价＝本行低端价值/相同门槛。这些边界以经营不变为前提，表示财务模型可支持的再评估价格带，**不表示股价会跌到或此价有必然买点**。价差如此大时，等待的主要价值是避免预付尚未证明的规模。

最早的有信息价值证据是2027年2月可核验的制造配置、付费验收和毛利，而不是又一份没有取消条款的需求管线。它会先排除U中的供应/工程延期解释，并决定P能否更快进入S；后续复购才排除“一次性试用”失败解释。等待可以损失第一段交易涨幅，却避免为全部远期S结果预付；没有足够采纳概率和条件股价分布，不能精确算等待期权价格。

### 6.3 “新机会成功而原有业务普通”组合检验

将AGI维持突破行，但手机、云版税、其他IP、许可/软银及核心现金费用改为基准；新芯片的资金、持续报酬仍承担突破扩张预算，不从两行挑更低成本。结果三年价值约**125—184美元**。其经济含义是：自有CPU大成功仍可能不足以弥补原IP捕获普通及高买价。若原业务再因客户竞争受损，价值只会更弱；不必先假设Arm技术失败。

这也限定本报告最重要的分歧：最强多头需要**自有CPU大成功和原IP收费能力保持很强**，或者出现尚未纳入、净现值足以补足差额的新商业模式。后者不是按零处理，而是尚缺独立收费对象、合同和资金边界。若Arm获得在软件/调度/完整平台上的新收费权，应重建模型；当前不能按整个客户节省的CapEx计Arm收入。

### 6.4 最强反证与结论撤销条件

对本报告谨慎判断的最强反证，是FY28之前就出现多个独立客户有约束、多代、重复的大额采购，同时Arm IP净费与外部许可继续加速，实际芯片毛利接近目标而库存/预付不吞掉现金；其意义是突破规模与持续性不再只靠主观假设。若该证据成立，本报告应上调路径和价值，而不是因现有结论坚持低目标。

对多头的最强反证，是Arm生态仍扩张但增长主要体现在客户自研/云服务，Arm净收费增长慢；成品芯片收入增长却需更多费用和占款，关联服务同时失去增量。它直接削弱“行业需求→收费→现金→每股”的多个关键环节。当前现金不会自动保护252美元的买入成本。

结论覆盖边界：本研究完成的是当前证据下的条件经营/现金估值与实际分期限选择；没有取得完整AGI合同、精确晶圆/封测排产、同口径逐财年市场一致预期、未来诉讼判赔额或未来价格采纳分布。相关NA只限制精确交易价格、订单约束和法律索取权点值，未被用来省略AGI、CSS长期机会或把它们静默当零。

### 7.3 公式、参数和闭合规则

```
AGI状态分布 p[t+1] = p[t] @ T；F为吸收态
E_AGI_R[t] = pP[t]*RP[t] + pS[t]*RS[t]
IP_net[t] = 手机+云+其他(成熟+CSS期望)+其余许可+软银 - 2.5%*E_AGI_R[t]
集团收入 = IP_net + E_AGI_R
集团毛利 = IP_net*IP_GM + E(状态内AGI毛利)
EBIT = 集团毛利 - 现金平台费用 - 旧SBC - 新SBC - E(AGI专属费用及失败损失)
OCF_model = EBIT+全部SBC-现金税+D&A-Δ营运及其他+非现金减值+净现金利息
FCF_report_model = OCF_model-CapEx
FCF_value = FCF_report_model-新SBC-净现金利息

目标日现金 = 3.888-0.265 + 从2026-07-01起累计FCF_report_model - 累计员工代扣税
目标日FD = 1.068+0.024 + 累计(新奖励经济成本/结算价 - 员工代扣税/结算价)
EV(target) = Σ目标日后剩余季度FCF_value/(1+r)^年数 + TV2036/(1+r)^剩余年数
TV2036 = FY36 NOPAT*(1+g)*(1-g/增量ROIC)/(r-g)
Equity(target) = EV(target)+目标日现金+0.45（持有股权投资）
每ADS价值 = Equity/FD
累计回报 = 每ADS价值/252.09-1
36个月年化 = (每ADS价值/252.09)^(1/3)-1
```

每年净现金利息工作额0.10 bn；FY27Q1实际净利息0.031 bn不随情景改变。年度现金税的20%为研究正常化、不是公司法定税率指引。历史季度现金桥中递延税、其他非现金项目并入“Δ营运及其他调节”，历史D&A0.075 bn；由此完整桥闭合，但该复算残差不能独立解释为存货或纯营运资本。
