## 4. 当前价格隐含的经营要求

### 4.1 当前资本结构桥

普通股估值统一使用：

经营性企业价值 = 完全稀释普通股价值 + 债务及其他优先索取权 − 现金

| 项目 | 金额 |
| --- | ---: |

| 长期债务含当期 | +$19.163bn |
| 应收账款融资 | +$0.750bn |
| Vistra Vision 剩余购买义务 | +$0.641bn |
| 优先股清算优先权 | +约 $2.500bn |
| 现金 | -$0.634bn |
| **普通股调整后经营性企业价值** | **约 $76.47bn** |

以当前 NTM EBITDA $7.55bn—$8.35bn 计算，当前普通股调整后 EV/EBITDA 约 **9.2×—10.1×**；以 NTM FCFbG $4.4bn—$5.0bn 计算，完全稀释普通股价值相当于 **10.8×—12.3× FCFbG**，即表面 FCFbG yield 约 8.1%—9.3%。后一个口径高估普通股可分配现金，因为 FCFbG 之前的“G”表示尚未扣除全部成长资本、交易和资本配置。

### 4.2 为达到 18% 要求回报，目标期必须实现什么

15 个月累计现金分红按基准 $1.20/股估算，则当前买入价要达到 18% 总回报，目标期每股价值需约：

目标价 = $158.12 × 1.18 − $1.20 = **约 $185.4**

按目标期 340m 稀释股数，所需普通股价值约 $63.0bn；加基准普通股优先索取权 $21.5bn—$24.0bn，目标经营性企业价值需约 $84.5bn—$87.0bn。

| 目标期退出 EV/EBITDA | 为达到要求回报所需 FY2027 EBITDA | 对应经营含义 |
| ---: | ---: | --- |
| 8.0× | $10.6bn—$10.9bn | 接近突破下沿；不能只靠正常兑现 |
| 9.0× | $9.4bn—$9.7bn | 乐观路径；需交割、可用率、容量/价差和现金流同步较强 |
| 10.0× | $8.5bn—$8.7bn | 基准上半区；仍要求债务不恶化 |
| 11.0× | $7.7bn—$7.9bn | 基准下半区即可，但依赖主题/质量溢价延续 |

这说明当前价格不是只隐含一个精确经营结果，而是隐含一组互相替代的条件：**若退出倍数维持 10×以上，基准上沿可以满足要求回报；若市场只给 9×，则需要乐观 EBITDA；若倍数压到 8×，几乎需要突破经营路径。**

## 8. 多估值理念与统一参数

### 8.1 主方法与交叉边界

| 方法 | 本报告用途 | 关键处理 |
| --- | --- | --- |
| EV / 正常化 EBITDA | **每格主估值方法** | 最贴合一体化发电、零售、核电/燃气高折旧与资本密集特征；目标期使用FY2027 EBITDA |
| FCFbG 倍数 / 收益率 | 普通股现金边界 | 防止 EBITDA 忽略利息、维护资本和现金转化；因 FCFbG 尚未扣全部成长资本，倍数上沿从严解释 |
| 反向估值 | 当前预期门槛 | 计算不同退出倍数下达到18%回报所需 EBITDA、FCFbG和优先索取权 |
| 分部 / 项目边界 | 并购和远期期权复核 | Cogentrix约 $4.0bn、约7.25×隐含2027 EBITDA；Lotus约7×。新核电PPA、AWS、433MW增容在未进入经营情景前不另加 |

没有简单平均两种方法。最终普通股价值区间取主 EV/EBITDA 结果与合理 FCFbG 边界的保守包络；两者分歧扩大区间并降低估值置信度。经营性企业价值仍由 EV/EBITDA给出，FCFbG只约束普通股市值。

### 8.2 市场列的折现与估值作用

| 市场状态 | DCF / 资本成本边界 | 估值处理 |
| --- | --- | --- |
| 宽基风险扩张 | WACC约8.5%—9.5%，终值增长1.5%—2.5% | 质量增长和正常兑现获得支持，但不超过可比和现金流边界 |
| 窄幅 / 主题主导上涨 | WACC约8.0%—9.0%，终值增长1.5%—2.5% | 真实AI电力传导可取高端；未兑现题材对失误更敏感 |
| 震荡 / 均值回归 | WACC约9.5%—10.5%，终值增长1.0%—2.0% | 现金流与买入价主导，久期溢价回吐 |
| 有序风险收缩 | WACC约10.5%—12.0%，终值增长0.5%—1.5% | 倍数压缩但市场功能正常，资产负债表权重上升 |
| 流动性 / 信用压力 | WACC约12.5%—15.0%，终值增长0%—1.0% | 生存、再融资、保证金和普通股剩余价值主导；常规倍数只作上界 |

同一经营行在五列中保持该行的收入、EBITDA、FCFbG、优先索取权和稀释股数区间；市场列只改变资本成本、退出倍数和该行区间内的融资取值。若市场状态会进一步改变客户预算或融资并使公司迁移到另一经营行，另在状态联动中表示，不在原格子重复计价。

### 8.3 模型分歧与不重复计价

- 当前普通股价值对优先索取权高度敏感；因此不能只把数据商EV除以 EBITDA，也不能用完全稀释股数后再次加 stock compensation。
- ARO、Moss Landing与退役现金已经进入情景 FCF和终值，不把 $4.231bn ARO全额再扣一次。
- Meta PPA属于现役核电合同 mix，不增加6.448GW现役铭牌；Cogentrix只有交割后才进入 EBITDA。
- 主题列不自动加“AI溢价”。只有该经营行已经包含可验证的客户、起供、利润和现金路径时，主题状态才允许使用更高端参数。

### 12.2 全矩阵形状

中性标签为：

- **经营兑现敏感**：同一市场列从悲观到乐观，建议跨越强烈不建议至强烈建议；执行与现金传导是第一主轴。

- **条件正面区域**：正面区域需要至少乐观经营，或基准经营同时配合风险扩张和更低买入价；不依赖突破的广泛正面区域尚未形成。
