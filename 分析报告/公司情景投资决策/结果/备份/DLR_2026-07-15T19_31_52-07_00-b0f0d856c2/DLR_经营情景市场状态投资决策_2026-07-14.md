### 2.3 当前价格与条件边界

- 当前复合价值区间要在 $177.92 买入价上产生 12% 总回报，目标价需达到 $194.39；这位于复合价值区间 $126–196 的最上端约 3% 范围内。
- 以最接近的“基准 × 宽基风险扩张”合并价值中点 $179 和 $4.92 分红计算，**中点达到 12% 回报的最高买入价约 $164.2**；当前价格高约 $13.7，或 8.3%。
- 若要求该格子价值低端 $145 也提供 15% 回报，最高买入价约 **$130.3**。
- 不依赖降价的最小增强路径是 Core FFO/share 升至约 $9.0、净债务 / EBITDA 不高于 5.5x、单位数增长不超过约 3%，即进入“乐观 × 宽基风险扩张”。
- 最容易使当前条件进一步转弱的单一经营变量是 **每股 Core FFO**；最容易使估值转弱的市场变量是 **10 年实际利率 / 数据中心 REIT 资本化率**。

### 6.2 事件依赖关系

事件不能简单相加，主要树状关系为：

1. **强 bookings → firm power / MEP → commissioning → 客户验收 → lease commencement → NOI / FFO/share。** 只有最后两步发生，订单才进入目标期经营价值。
2. **Blackstone / Columbia / Teraco → 新股与现金先发生 → 资产 / fee 后兑现 → 总 FFO → 每股 FFO。** 股数已纳入当前桥；不能在乐观情景再次加一份“交易价值”。
3. **利率 / 信用 → 资本成本与资产循环 → 开发速度 / 稀释 → 经营行迁移。** 原格子先保留同一经营行的纯条件价值；若融资实际改变交付，再迁至相邻经营行，不能在两个格子重复扣减。

## 8. 多估值理念与参数

### 8.1 方法角色

| 方法 | 本报告角色 | 原因 |
|---|---|---|
| **P/Core FFO** | 主估值方法 | DLR 为 REIT；Core FFO/share 能直接体现经营、利息、交易和稀释后的普通股价值 |
| **NOI / NAV 资本化** | 独立交叉估值与区间边界 | 捕捉资产资本化率、开发净值、fee platform 和净债务；对利率 / cap rate 最敏感 |
| EV / Adjusted EBITDA | 一致性检查 | 检查 P/FFO 结果是否要求异常企业倍数；不直接平均 |
| AFFO / 分红边界 | 现金质量检查 | AFFO 已扣 recurring CapEx，但不扣开发 CapEx；用于检验股息覆盖和长期 per-share 增长 |
| 反向估值 | 预期门槛 | 说明当前价格需要基准上沿、乐观经营或持续高倍数中的哪一项 |

P/Core FFO 与 NAV 不平权投票。每格价值区间取两种适用方法的包络；若 NAV 明显低于 P/FFO，则扩大区间并降低估值置信度，不用平均值掩盖开发净值和资本结构分歧。

NAV 公式为：

每股价值 = 普通股等价价值 ÷ 目标期完全稀释普通股等价单位

### 8.4 模型分歧与置信度边界

- P/FFO 给已签增长和每股兑现更高权重；NAV 对实际利率、cap rate、剩余 CapEx、JV ownership 和未预租容量更严格。
- 当前最大分歧不是 2026Q1 收入，而是交易后净债务、目标期单位数、开发净值以及 25–75bp cap-rate 变化。
- 流动性压力下，常规目标倍数可能短期失效；该列区间是有市场功能但融资显著收紧的边界，不是假定破产。DLR 近端债务到期和投资级评级降低生存风险，但不能消除资产折价与稀释。
- 估值置信度与情景证据强度分开：突破情景证据低；即使假定突破成立，开发净值与资本结构不确定仍令估值置信度低。

## 13. 可选概率层

**经营 × 市场联合概率：NA。**

原因：

1. 四条经营行是为 DLR 构建的完整状态，不存在可直接引用、时点一致的公司基础率；
2. 五个市场状态与经营行显著相关：流动性压力会改变融资、开发和稀释，不能默认独立后相乘；
3. 突破、backlog 取消、融资断裂和 cap-rate 跳升是离散尾部，少量主观点概率无法支持 P10 / CVaR；
4. Q2 交易后资产负债表将在九天后发布，此时强行分配精确概率会制造虚假精度。

因此以下均为 NA：低 / 中 / 高联合概率假设、期望回报、P10 / P50 / P90、亏损概率、CVaR、达到零回报或研究要求回报所需的联合盈亏平衡概率。报告保留可验证的 **价格盈亏平衡边界** 和完整条件矩阵，不用概率汇总替代条件判断。
