## 一、当前选择：业务成功的可能性高于现价提供足够回报的可能性

**以 559.82 美元买入，按年化 12% 的参考要求，一年、三年和七年均不建议新增投资。** 这不是判断 AMD 的业务没有前途：基准路径已经包含收入由未来十二个月的 77.8 增至第七年的 209.7，且 EPYC、Instinct 均形成大型利润池。问题是当前约 9,139 亿美元的普通股市值，要求的规模、持续利润及普通股现金收益，比这条高速成长路径更高。

## 三、真正决定价值的两项扩张，以及不能遗漏的小业务

### 3.1 EPYC：增量代理工作可能改变规模，但“有任务”不等于“有同样多的新插槽”

支持成长的证据已经超过跑分：管理层 08-04 报告服务器 CPU 增长超过70%，并预计 2026H2 超过80%、2027全年超过70%；Microsoft 07-20 宣布未来 HDv2、HXv2 与 MI455X 实例，具体对应数据处理、芯片设计及推理，支持多种采购用途。[S04][S12] **这是需求和产品定位证据；未披露的 AMD 专属采购金额仍是 U。**

必须纳入 9 月的新解释：CFO 在 09-08 官方文字稿中把 2030 年服务器 CPU TAM 描述为超过 **220**，对比2025年的25，并称代理沙箱将超过该市场一半；09-11 IR 高管谈到超过50%的份额及千亿美元级服务器业务。前者是市场目标，后者是公司长期企图，**不是审计收入、不可取消订单或独立基础率**。[Citi，CPU TAM 问答][S22]、[Goldman Sachs，服务器增长问答][S23]

机制可以成立：模型调用工具、执行代码、数据库访问、隔离沙箱和仿真都会占用 CPU；高核心密度、x86兼容、可用平台与软件经验使 EPYC 能转化需求。但最强相反证据也来自客户：AWS 已将 Graviton5 商用，并披露 Meta 先以数千万核心支持代理工作。这说明代理 CPU 市场扩大与 AMD 份额下降可以同时发生；新工作负载也未必受旧 x86 软件迁移成本保护。[AWS 06-10 产品及客户公告][S28]

**独立量价约束（E）：** 基准 Y1 的24可由约800万颗×3,000美元实现；Y3的44约1,250万颗×3,520美元；Y7的70约2,000万颗×3,500美元。它们是混合封装等价量，不是披露销量，包含核心数和SKU变化。乐观Y7的140需要约3,500万颗×4,000美元，或同额其他量价组合。若平均净价只有2,500美元，后者需要5,600万颗，供给和客户年度支出负担明显更高。研究不以“代理数×一颗CPU”推收入。

基准并未全额接受2030年220 TAM和AMD过半份额：Y4（至2030-09-19）的CPU收入50.5，Y7为70；乐观Y4为98.75、Y7为140，允许沙箱带来结构性扩张。基准营业贡献率从36%到38%后随竞争回落至34%，并非假定技术领先永久扩大。改善成立需至少跨过：2026H2/2027供给交付、2028/2029代理实例付费复购、2030后更新采购不被核心密度/Arm替代。若任务增长主要表现为利用率提升，CPU数量路径应向受损行移动，即使代理应用很成功。

### 3.3 被大叙事遮住的现金池与新机会

Client 的Y1/Y3/Y7基准为13.2/16/20，可由约6,000万颗×220美元逐步到8,000万颗×250美元实现。工作点允许商用、工作站改善，贡献率20%—22%；受损行保留ASP和消费周期压力。NPU增强功能不自动创造额外订阅。Gaming基准3/5/5，约为年交付2,000万—3,000万颗主机SoC、80—110美元内容量，加独显等1—2收入的量级；它包含换代爬坡及之后回落，不把未来主机发布时间当作已知。因采购模式不同，独显份额改善可以部分抵销主机衰退，但不能消除周期。[Q2 Client/Gaming经营描述][S01]

Embedded基准4.4/6/9，贡献率38%附近，来自库存正常化、既有设计更新和少量新增工业/汽车用途；低情景Y7只有5.5，乐观12。机器人量产资格通常需要多年，现有FPGA和嵌入式收入不能再与“物理AI市场”相加。网络基准Y7为5、突破为12，伴随CPU/GPU增量采购并保留20%上下的费用后贡献，而非取得整套交换网络的钱。

Taalas的8月公告是收购最终协议，附交割条件；9月官方会议出现团队整合表述，增强业务整合方向证据，但本次未查得单独交割日期、最终价格和新增普通股对价。HC1展示的是特定Llama 3.1 8B模型，不能证明所有前沿模型均可无损固化。最少成功是：质量与模型升级成本可控、足够长的稳定调用、至少数个付费生产客户，且固定权重/芯粒路线的收入超过对自家GPU的蚕食。[AMD交易公告][S18]、[Taalas产品页][S19]、[Citi推理问答][S22]

### 5.2 从业务营业贡献到股东现金

主模型统一采用：

```text
经济EBIT = Σ(各业务收入×相应贡献率) − 未分配共同费用 − 新服务SBC现金替代成本 − 特殊现金损失
现金税 = max(经济EBIT,0) × 税率
经营FCFF = 经济EBIT − 现金税 + 正常折旧摊销 − 资本开支 − Δ经营营运资金 − Δ最低经营现金
估值现金F = 经营FCFF − 战略股权投资 − 收购现金 + 战略投资税后回收
```

## 六、今天与目标日的价值：必须支付远期经营所需的资本

### 6.1 估值方法与长尾

主模型是名义美元FCFF/企业价值法，逐年预测至2038-09-19，之后进入成熟更新。企业剩余价值加非经营现金和税后其他权益，减债务，再除路径经济股数。租赁费用已在经营现金里，不再把相同经营租赁总承诺作为额外债务重复扣除。

```text
V运营(h) = Σ(t=h+1…12) F_t/(1+w)^(t−h) + TV_12/(1+w)^(12−h)
TV_12 = EBIT_12×(1−20%)×(1+g)×(1−g/ROIC)/(w−g)
股权价值(h) = V运营(h) + 非经营现金(h) + 其他权益2.0 − 债务(h)
每股价值(h) = 股权价值(h)/该路径最终经济股数
```

尚待发行的救助权益融资，在发行前按未来新增资金现值加到对应全稀释股权价值，以便与新增股份配对；发行后资金已在现金里，不再加一次。普通借款增加现金同时增加债务，本身不创造净价值。

中央w＝11%；范围为9%—13%。2026-09-18美国国债1/3/7/10年参考收益率约4.44%/4.83%/4.93%/5.01%，不是AMD贴现率。低债务资本结构下，约5%的长期美元时间价值加4—8个百分点的系统性/股权风险补偿构成上述研究范围；不把真实概率加权后的风险现金用无风险利率折现，也不在估值后再扣同一个失败概率。[美国财政部逐期限表][S20]

长期g为受损0.5%、基准2.5%、乐观和两种突破3%、尾部0；条件区间各±0.5个百分点，尾部下限−0.5%。成熟新增资本回报ROIC分别12%、20%、25%、25%、10%、25%，以`g/ROIC`扣再投资。未来研发、软件维护、渠道及租赁已在成熟利润中持续存在；终值不是把单代MI450利润永续。GPU贡献率在基准Y7的30%回落至Y12的27%，乐观37%降33%，突破43%降37%，主动允许竞争侵蚀。

因此不同路径的价值差异主要来自实际规模、净利润和长期持续性，不靠给每一条路径任意换一套估值倍数。11%是资本市场风险要求，12%是本报告投资者持有回报参考，二者用途不同。

## 七、现价要求、最强反面解释和当前参与/等待选择

### 7.1 559.82美元要求什么

参考投资标准是**名义美元、未使用杠杆、可持有至目标日、年化12%**；邻近范围10%—15%。依据是美元国债约4%—5%的机会成本，加单股集中、经营兑现和大额永久亏损所需补偿。高风险取向可接受8%及较大失败概率，但这是另一个明确偏好，不能偷偷替换主标准。12%要求的一/三/七年期末财富分别为627.00/786.51/1,237.58美元；8%要求604.61/705.21/959.43美元。

本地快照的forward EPS 15.57和forward PE 35.95没有逐字段对应期间、共识更新日期，**不作为本次“市场一致预期”**。有日期公开预期使用08-04财报指引与09-08、09-11管理层发言；行情能说明价格，不能唯一识别买方预期的GPU收入、CPU市场或远期利润率。

### 7.2 三种最强相反解释确实进入模型

**相反解释A：代理CPU需求比基准更强，GPU只正常发展。** 单独把CPU换成乐观路径，其他业务保留基准，并提高资本开支至收入4%，当前每股价值约**269.3**，Y7约**531.6**。这是对管理层千亿美元CPU目标的有意义参照，仍不足独立支持现价下12%的回报。其可证伪变量是付费沙箱的实际CPU采购、AMD净价和Arm份额，不是代理产品下载数。

**相反解释B：AMD形成强GPU平台，但其他业务只是正常。** 四行中的突破就是这个独立成功试验：当前495.4、Y7为994.3，比基准当前189.7增加约305.7美元。增量包含更大库存/应收、软件/系统投入、战略投资及更高权证预留；不能把两者收入差乘一个PE冒充净价值。该机会有足够量级改变选择；在9%折现、3.5%终值增长时Y7升至1,308.3，主标准下该**条件路径**能够成立。

**相反解释C：CPU和GPU都达到强状态，且平台长期风险低。** 联合路径提高共同费用、资本开支至收入5%，中央当前561.9、Y7为1,128.5；当折现9%、g为3.5%时，当前827.1、Y7为1,485.5，七年年化约15%。它确实可翻转建议。支持它的证据是具体客户、软件进步和管理层新增CPU可见性；反对把它作为主要结果的证据是未披露的最终验收/净价、ASIC/Arm竞争、资本责任及仍在起步的整柜爬坡。联合成功不是不可能，研究判断是**不能在当前信息下赋予足以覆盖现价要求的高权重**。

等待并非已经被数学证明优于持有。相同初始资金559.82若持有九个月现金，按4.44%年化算例到2027-06-19约578.36，仍在原2027/2029/2033目标日评价。届时确认后若成交价700，只能买0.826股；若为450，可买1.285股。假设此后共同目标日价格为X，提前持有财富为X，等待后为股数×X，等待优势的买入价边界为578.36，尚未计税费和后续再决策。这些未来成交价是A，**并非DCF价格预测**。等待避免坏证据后的投入，也会付出确认更贵、错过跳涨或误判后的代价；本次结论是现价参与优势不足，未声称设计出可确保跑赢的择时策略。

利率共同冲击通过w及现金收益体现；出口限制通过可售数量、库存/费用进入受损路径；客户融资收紧通过验收延期、回款和保证责任进入资本路径。本文没有预测这些冲击必在某个日期发生。

## 附录C：集中模型与可执行复算代码

Python 3，仅标准库。金额十亿美元、股份十亿股。代码包含全部六路径收入、贡献率、资本、季度融资、经济预留股份、未来价值、概率与区间参数；复制到临时脚本即可重算，无需读取任何既有研究结果。四行/十二格取damaged、base、upside、breakthrough，其余两条只用于整股分布和反证。输出小数是计算结果而非预测精度。

def interp(points,t):
    if t==0: return points[0]
    for j in range(1,len(ANCHORS)):
        if t<=ANCHORS[j]:
            a,b=ANCHORS[j-1:j+1]; f=(t-a)/(b-a)
            if isinstance(points[0],list): return [x+(y-x)*f for x,y in zip(points[j-1],points[j])]
            return points[j-1]+(points[j]-points[j-1])*f

        nwc=s['nwc']*R
        # Tail inventory cannot be released immediately when demand collapses.
        if k=='tail' and t==1: nwc=max(nwc,nwc0+3)
