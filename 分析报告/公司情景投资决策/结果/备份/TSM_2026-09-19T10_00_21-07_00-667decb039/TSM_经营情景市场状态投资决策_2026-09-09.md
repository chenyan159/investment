### 2.3 订单、资本结构与治理

2025年前两大客户匿名收入占比19%和17%、前十合计78%；不能根据常识给匿名客户贴名字。不同芯片客户仍可能依赖相同云平台预算。年底约1,898.6亿新台币客户临时收款，是保留产能付款，满足条件后退款或双方同意抵应收；另有约499.5亿合同负债。**已披露余额是真实融资/履约线索，既不是零，也不是全部不可取消backlog。** 本次核对20-F正文“Advance Payment by Customers”、附注22及合同义务表，未找到覆盖2027预测的不可撤销订单、退款和取消的完整桥。因此不设凭空的订单保障率。[20-F，PDF第23、40、152页][F20]。

Q2现金与有价证券3.518万亿新台币，计息债务1.03168万亿，净额2.48633万亿；按期末汇率约为110.22、32.32和77.90十亿美元。简表只加流动借款与长期债券会遗漏其他非流动借款，故债务取营运报告债务服务表，不取错误残差。少数权益账面约13亿美元；未来估值以15亿美元归属索取权工作值处理，非清算精确价。[营运报告第4页][MR]。

截至2025年末，未入账资本/采购承诺1.534575万亿新台币，其中一年内1.220393万亿；合同债务付款表还包括本息、租赁、客户临时收款，不能全部再加到债务本金与2026 CapEx。美国CHIPS直接资金上限66亿美元、贷款额度50亿美元，母公司对相关金融义务提供不可撤销、绝对、无条件保证；实际可追索额取决于Arizona已发生义务及条款触发，额度不等于已提款余额。德国补助上限50亿欧元。模型对未确认增量补助取零新增现金，对已进入成本的补助不重复加回。[20-F，PDF第31、40页][F20]。

海外投资同时是客户本地供应选择权与资本回报压力。Arizona多年总投资规划2,650亿美元不是2026现金支出；8月董事会294.425亿美元项目预算是批准事项，也不是全年CapEx之外新增一笔。德国/日本厂不用于填补2027台湾N2即时产能。索尼新JV与既有受控JASM不是同一实体；新JV由索尼控制，TSMC拟分期出资2,820亿日元，2029量产目标不能转成TSMC全额合并收入。[Arizona项目页][AZ]、[董事会][BOARD]、[索尼正式协议][SONY]。

魏哲家兼任董事长与CEO、台湾政府相关股东的少数持股、跨地区受控实体与联营公司，共同影响治理和资本配置。较强执行证据是N2商业化与具名客户投产；尚不能据此豁免海外厂增量回报审核。TSMC纯代工中立性降低客户竞争顾虑，但出口许可、知识产权访问控制、供电水务、地震和台海物流仍能直接损伤交付。台海长期中断单列离散压力，不伪装成普通周期下行或用任意概率隐藏。[20-F风险与治理][F20]。

### 4.4 同期限的理念分歧：高盈利倍数究竟在购买什么

持续更新平台的P/E论点有现实依据：跨代PDK、客户资格、中立性和大规模研发使TSMC可反复获得新产品；因此简单给单一工艺五年寿命会遗漏价值。但P/E必须解释留存利润的再投资、现金转换与下一代回报。基准2029目标日NTM EPS约26.78美元，22—28倍对应约589—750美元；加分红三年约38%—74%，年化约11%—20%。这个区间有可能改变投资选择，不能简单称辅助上限后忽略。

当前更支持基准附近的高增长经营，最强替代是乐观的较快量产/制造内容增加；尚无足够客户原始规模证据支持立即采用突破为主路径。另一方面，强平台持续性解释不能因为尚未提供完整订单而被直接赋零；同样没有证据把它与较低r、高终值g联合认作确定结果。

以下为经营固定、从当前起持有至原目标日、恰好达到参考回报要求的最高买价；工作值用r10%，范围r11%—9.5%。不是自动买单条件；普通偏差发生时应使用重算后的边界。

|---|---|---|---|
| 2027-03-09 | 272.3—344.5 | 316.6 | 287.0 |
| 2027-09-09 | 268.7—338.0 | 311.3 | 282.1 |

若投资者采用8%—10%长期年化标准、可容忍大幅回撤，且对强平台持续性有额外经营证据，价值解释可能支持较高买价。但439美元不是现金安全边际位置；短中期窗口中可见增长已很强，新增证据需要改变未来收入/资本效率，而非重复确认今天已知的好消息。

对需要概率的整股选择，本报告不把四行当全集。一个仅用于反求的两端实验：普通持续偏差三年财富约387美元，乐观经营约639美元；要达到约617美元目标，需要乐观端的权重大约91%。它不代表真实91%胜率或所需“局部N2成功率”，且遗漏基准、突破、战争及其他路径，不能拿来作完整期望收益。其意义是：**普通与乐观之间的小幅乐观倾斜不够满足高持有要求。** 如果上端改成突破约1,044美元、下端仍约387美元，门槛降到约35%；这要求的是整股多代规模、资本回报、估值和按期采纳的联合路径，不是光I/O单项S状态概率。

现有证据能支持机会存在和2027较强需求；不足以为这种整股联合突破建立可复核的35%以上工作概率。客户已有销售不约束十年持续期，路线图不约束净收费和全球预算，因此不把高风险参与包装为已证实优势。也不把“未证实35%”等同“概率一定低于35%”：**高风险突破的当前优势暂不可判定；主标准下不参与普通路径，是价值不足；对较低长期要求的强平台论点，则是经营/风险补偿分歧。** 三种原因各有不同更新条件。

单独SoW充分成功只能增加约10.5美元；即使把其局部成功权重调到100%，仍无法填上述整股门槛。到2031基准SoW的S状态约26%，光I/O约41%、新存储约33%，这些只用于各自增量现金，不可拿其中任一数字与整股35%门槛直接比较。要改变当前选择，最少证据更可能是核心跨代订单/产出、单位制造收费和海外投资回报改善，而不是小机会多一份合作新闻。

### 6.3 等待信息：相同资金与原目标日比较

选择2027年1月的全年结果/2027展望作为一次有辨别力观察，算例等待日2027-01-20（**模型日，不宣称已公告业绩会日期**）。它可区分2027交付、资本和利润组合，不能一季解决2030后平台持续性。双方初始资金439美元、原目标日2029-09-09；等待现金年化4%，期内约积累至445美元，保持现金到三年末约494美元。双方只用当时公开信息，若允许后续调整，也同样允许先买者卖出；以下先列易复算的“立即买入持有”与“等待后按12%标准决定”差异。

若等价持有者在2027年1月也可卖出，双方应拥有相同信息和后续选择，等待的价值只剩此前避免暴露与资金机会成本，不能把等待策略免费赋予择时能力、同时禁止已买者调整。若改成确认后再持有三年，目标日已改变，不属于本报告主比较。候价也可能一直不成交，不能只计算避亏不计算错过。

**最终行动解释。** 短期3个月缺少可识别事件价差，中性；6个月及一年按主要标准不买，是基准价值不足且可见增长已被较强定价要求包围。三年保留中性/默认不新增，是普通复利与联合强平台解释会翻转且证据未充分区分；不是已经证明买入、现金或等下一季有统一优势。最强反面选择是以较低长期风险补偿购买跨代平台；它有真实技术与客户依据，也需要接受资本密度、价格及永久损失。价格或证据变化应沿本底稿更新，不能一边公司受损一边沿用原低价边界。

```python
NAMES=['悲观', '基准', '乐观', '突破']
TRANS={'光I/O': [(0.15, 0.16, 0.18, 0.13, 0.08), (0.3, 0.08, 0.35, 0.07, 0.035), (0.38, 0.045, 0.45, 0.035, 0.02), (0.43, 0.03, 0.52, 0.02, 0.015)], '大型3D/SoW': [(0.1, 0.18, 0.15, 0.15, 0.1), (0.22, 0.1, 0.3, 0.09, 0.045), (0.32, 0.06, 0.42, 0.045, 0.025), (0.4, 0.035, 0.5, 0.025, 0.02)], '新型存储逻辑': [(0.12, 0.15, 0.16, 0.12, 0.08), (0.25, 0.08, 0.3, 0.07, 0.04), (0.34, 0.05, 0.4, 0.04, 0.025), (0.39, 0.035, 0.46, 0.025, 0.02)]}
SCALE={'光I/O': [0.1, 0.4, 1.0, 2.0, 3.0, 4.5, 6.0, 8.0, 10.0, 12.0], '大型3D/SoW': [0.0, 0.0, 2.0, 6.0, 12.0, 18.0, 24.0, 30.0, 35.0, 40.0], '新型存储逻辑': [0.05, 0.2, 0.6, 1.4, 2.5, 4.0, 5.5, 7.0, 9.0, 12.0]}
DISP={'光I/O': 0.1, '大型3D/SoW': 0.3, '新型存储逻辑': 0.15}
RD={'光I/O': 0.1, '大型3D/SoW': 0.2, '新型存储逻辑': 0.12}
def opportunity(s,k,forced=None):
    si=NAMES.index(s); a,b,c,d,e=TRANS[k][si]; probs=[1.,0.,0.,0.]; rows=[]; prevR=0.
    size=[.65,1.,1.35,1.7][si]
    # Failing state is absorbing. SoW cannot scale before 2029.
    for y in range(2027,2037):
        u,p,v,x=probs; trans_c=c if not(k=='大型3D/SoW' and y<2029) else 0.
        newfail=u*b+p*d+v*e
        probs=[u*(1-a-b),u*a+p*(1-trans_c-d),p*trans_c+v*(1-e),x+newfail]
        if forced is not None:
            probs=([1,0,0,0] if y<forced-1 else [0,1,0,0] if y<forced else [0,0,1,0]); newfail=0.
        assert abs(sum(probs)-1)<1e-10 and min(probs)>=0
        scale=SCALE[k][y-2027]*size; gross=[0,.22*scale,scale,0]
        disp=DISP[k]; R=[g*(1-disp) for g in gross]
        # Unit margins reflect lost existing service gross profit at 55%.
        gp=[gross[z]*([0,.38,.58,0][z]-.55*disp) for z in range(4)]
        rd=RD[k]*(1.06**(y-2027))
        ox=[rd,rd+.12*gross[1],.09*gross[2],0.]
        eb=[gp[z]-ox[z] for z in range(4)]
        # Failures incur a one-time exit expense; not charged each year forever.
        exitcost=newfail*rd*1.5
        da=[0,.10*gross[1],.12*gross[2],0]
        cap=[.5*rd,.25*gross[1]+.5*rd,.22*gross[2],0]
        vals={key:sum(probs[z]*v[z] for z in range(4)) for key,v in [('rev',R),('gross',gross),('gp',gp),('opex',ox),('ebit',eb),('da',da),('capex',cap)]}
        vals['ebit']-=exitcost; vals['opex']+=exitcost
        # Trade working capital state is 12% of net sales. Difference of expectations is valid here.
        vals['wc']=.12*(vals['rev']-prevR);prevR=vals['rev']
        vals['nopat']=.82*vals['ebit'];vals['fcff']=vals['nopat']+vals['da']-vals['capex']-vals['wc']
        vals.update(year=y,p=probs,scale=scale,state_rev=R,exitcost=exitcost)
        rows.append(vals)
    return rows

for s in NAMES:
    for k in TRANS:
        for row in opportunity(s,k):
            assert abs(sum(row["p"])-1)<1e-9
            print(s,k,row["year"],row["p"],row["rev"],row["fcff"])
```
