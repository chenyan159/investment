## 三、AWS的决定性分歧：交付更多，还是为同一收入付更多资本

### 3.1 证据已经支持规模采用，合同仍有条件

Q2 AWS收入42.232B，同比约36.8%，营业利润率39.4%。AI和芯片业务各超过25B年化运行速度，是管理层对某一时点速度的描述，不能各计25B全年收入后相加，更不能认为全部AWS都以AI速度增长。核心云的续用、数据层和跨产品销售仍是大利润池。Q2的增量营业利润率约56.9%是存量组合和折旧时点的结果，不是新AI投资未来永久回报率。[财报业务指标](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx)

6月底长期服务承诺496B、平均剩余6.4年；其中OpenAI原38B安排增加100B/8年，Anthropic增加超过100B/10年。10-Q明确芯片性能义务、客户实际用量及Amazon履约影响收入确认，履行可能超过最初期限。496/6.4约77.5B仅是粗略规模检查，不能当每年保证收入，更不能把这些合同再加到预测收入之外。[10-Q，Unearned Revenue](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

客户侧，Anthropic 4月公告确认使用超过100万颗Trainium2，并计划扩展至最多5GW；5月28日Series H公告把自报收入运行速度更新至超过47B，融资65B中包括15B此前承诺的超大云厂资金，不能全算新现金，更不能把Amazon重复计算。[4月客户计算安排](https://www.anthropic.com/news/anthropic-amazon-compute)、[5月融资与收入口径](https://www.anthropic.com/news/series-h)。同一客户还向Google/Broadcom和其他平台买容量，[多供应商计算安排](https://www.anthropic.com/news/google-broadcom-partnership-compute)是AWS不拥有独占份额的直接反证。

9月18日出现Anthropic运行速度超过100B的媒体报道，已追查其新闻原载链接（纽约时报页面本次无法打开）、Anthropic新闻/融资原件和Amazon截至截止日申报；本次没有取得对应审计报表、月度收入明细或原始投资者材料。保留为需求上行线索，不把“运行速度”写成2026全年收入或已证明净利润。可读转述来自[Axios的有日期报道](https://www.axios.com/2026/09/18/anthropic-100-billion-revenue)。这属于**未查得原始支持**，不是断言公司未披露任何收入信息；47B这一较早原始披露仍保留。新增用量很可能改善AWS机会，但其在AWS确认多少收入、被投企业留多少利润仍不明确。

### 3.2 数量、净价、预算与供给的约束

AI收入以可交付的标准化工作负载×有效净价建模，GPU/Trainium和Bedrock净收入只计一次。基准T1→T3从48到100B，等于用量指数每年约增长70%、净价每年下降15%的两年复合结果；T3→T7从100到220B，相当于用量约36%/年、净价约−10%/年。不是要求每token价格上升，而是有效吞吐、使用频率和企业生产任务增长快于单价下滑。基准T7→T10从220到290B，降至约10%收入增速，体现竞争和成熟。

突破T7 AI收入650B要求T3→T7净收入约34%复合增长；若净价仍每年降10%，可计费工作量需约49%增长。按全球可归属AI计算/平台支出2.2—3.3万亿美元、AWS获得20%—30%份额才容纳650B，这是**门槛检验M，不是已验证行业TAM**。其客户必须从软件、流程效率、消费者付费和研发等真实预算中获得足够回报；只靠投资者继续注资实验室无法永久支持。基准220B也需要约0.9—1.5万亿美元可归属支出及15%—25%份额，绝非无条件保守值。

供给侧，用10—20B全栈在用资本对应1GW的宽量级假设检验：集团基准七年累计资本投入1,672.5B，若约70%投向AWS、其中包括旧设备更新和非AI云，则最多支持数十GW的新增/更新计算系统，绝不是所有资金都转成新增AI GW。650B收入需要更大有效容量或更高每GW净产出，突破七年累计资本投入2,837.5B承担了这一代价。全栈资本/GW不是公司报价，受功率密度、HBM、土地和电力差异影响；范围用来约束数量级，不冒充交付底表。

核心云基准T1/T3/T7收入160/195/290B，利润率40%/40%/38%，靠持续迁移、数据库和存储需求；AI吞噬部分传统计算、开源数据库和客户自建压价。DuckLabs加入AWS的公告明确DuckDB等仍保持开放许可，收购开发团队不等于拥有独占数据库租金。[标的方2026-08-26公告](https://www.ducklabs.com/press/ducklabs-to-join-amazon-web-services/)

### 3.3 从硬件回本推向股东现金

7月30日管理层称服务器及网络平均不到三年回本、寿命至少5—6年、许多AI容量合同至少五年，并把2026现金资本开支提高到约220B，解释增量主要来自内存成本。这是管理层条件经验，不能与公司披露的全部项目实际IRR等同。[财报电话会原发言转录载体](https://stockanalysis.com/stocks/amzn/transcripts/657334-q2-2026/)

本次以一批100B全栈投资检验其可实现性：70B计算/网络按4—5年更新、30B场地设施按20—30年，维持能力年更新约15—19B；若年收入50B、运行和人员成本25B，税前现金贡献25B，扣维持更新后只有6—10B税前持续现金。若利用率/净价使收入降至40B而运行成本仅降至22B，则持续现金接近−1至3B。收入增长或管理层“回本”说法不能取消下一代投入；本模型9.5%资本成本要求正常化税后增量资本回报至少高于该数，基准长期16%、受损10%，突破18%，而不是永远沿用早期云业务高回报。上述50B收入算例本身不满足16%：若年更新17B、现金贡献率50%、税22%，100B资本要取得16B税后持续回报，年收入需约75B。基准必须依靠较高计费利用率、每单位资本吞吐及广告等较轻资本业务才能靠近长期16%，不能称该参数已由管理层回本数字证实。仅把基准成熟期增量ROIC从16%降至10%，当前每股价值由193.7降至174.7美元；升到20%则为200.1美元。

模型纯固定资产折旧T1为75—81B，高于2026H1年化53.4B，原因是大量已取得但尚未完全投产设备开始折旧；到T7为117—370B。设备经济更新以4—5年、设施以20—30年为检查带。期末PPE从研究起点480B按“资本投入−折旧”滚动，不能只提高利润率而不计相应折旧、维护和服务器替换。成本率中还保留电力、员工、模型分成和研发。若经济寿命缩短但费用确认滞后，报告EBIT可能短期更高，本模型价值反而更低。

## 四、商业生态、广告与探索业务的独立裁定

### 4.1 商业生态：密度改善存在，服务更快也会增加成本

Q2全球付费商品件数增长17%，运输费用27.873B、同比约19.3%；粗略运输费/件数指数约上升1.9%，但覆盖地域、Whole Foods、货品和订单结构不同，不能当公司披露的同质单位履约成本。证据支持配送和采用增强，也同时支持即时配送、日用品低客单价吃掉效率节省的替代解释。机器人主要改变每件劳动、搬运和错误成本，不独立创造内部收入。[Q2经营附表](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx)

基准不含广告的商业生态T1/T3/T7收入610/725/970B，利润率2.6%/3.1%/3.5%。它包含一方收入总额、商家服务净额、Prime及医疗/药房的不同确认口径，所以不虚构统一GMV或统一客单价。T1→T7约8%的收入复合增长，可由交易件数增长约8%—10%、组合和净收费约−2%至0%构成；竞争促销、关税和快速配送预算决定净留存。受损利润率降至1.5%左右，来自更低价组合与配送竞争，仍保留正经营现金，不等于清算。

药房、One Medical、Amazon Business、外售物流和Just Walk Out具有采用路径，但独立贡献利润不充分公开，合并在上述收入和费用内。数百万新增客户、GMV、媒体观看量、购物助手采用率与合并新增利润都不同。Alexa自动购物可能提高转化，也可能减少用户看到广告的机会；基准广告长期增速已降低，不同时预设购物入口迁移和广告位无限扩张。

### 4.2 广告：增量销售能支持出价，定价权也可能受损

Q2广告19.809B，同比增长约26.2%。基准T1/T3/T7收入99/132/215B；由可变现触达/点击增长及净收益变化共同形成，T1→T3约15.5%复合、T3→T7约13.0%，低于最近季度速度。条件营业利润率42%/43%/42%已扣渠道、技术、销售、内容与共同费用归因；不是公司披露利润率，也不把Prime视频会员费再次加到广告。

2026-08-31 FTC与州政府提出广告竞价附加机制诉讼，是已经发生的诉讼，**不是已裁定赔偿**。Amazon以出价调整、CPC和转化改善反驳。两方针对不同反事实：广告主获得销量不自动证明定价告知充分，受到指控也不证明广告已失去经济效果。[FTC起诉说明](https://www.ftc.gov/news-events/news/press-releases/2026/08/ftc-states-sue-amazon-over-secret-ad-surcharge-scheme)、[Amazon回应](https://www.aboutamazon.com/company-news/amazon-ftc-sponsored-ads-lawsuit-response)

### 6.3 从利润到现金的统一公式

`FCFF_t = EBIT_t × (1−22%) + 纯固定资产折旧_t − 资本投入_t − 0.8% × 收入增量_t`。

ΔNWC的首期上年收入取795B研究估计：截至6月TTM约775.7B，加Q3指引中点199.5B、减2025Q3的180.169B得到约795B；不是2026全年收入或已公布9月实绩。22%是长期经营现金税率M，不继承投资重估造成的GAAP有效税率，也不把H1低现金税率永续。加速折旧可能使前期实际现金税更低，后期转回；税收时点是小幅上行而非额外永久价值。研发、内容、租金和员工现金替代报酬已在EBIT扣除，不重复资本化。现金资本投入表采用“实际现金购置＋等价当期取得融资租赁资产”的全投入近似，未来新增资产统一视为现金购买；原有融资租赁归债务处理，避免未来以租赁免费扩产。

**SBC边界**：模型把未来员工股份奖励换成等经济价值现金薪酬/抵消性回购成本，已在利润率内，不加回SBC，亦不再按1%/年额外摊薄。现有未归属奖励244.4M股的未来服务/结算成本纳入现金薪酬路径，没有再将其全部加在分母上。T1按约32B奖励结算/替代成本检查，之后约30B起并随规模变化，高于H1 SBC年化20.14B，以覆盖市值与授予日公允值差异；不是声称公司承诺以现金结算。未来实际奖励仍可能发股，若不以现金抵消，必须改用“加回奖励成本＋路径稀释”整套方法，不能只挑加回项。

T10以后“成熟更新”是近似，尤其突破仍可能快速扩張：因此区间把g±0.5个百分点与r∓1个百分点联动作为估值包络。终端FCFF与T10现金流并非相同数，表示逐步停止超额成长建设；该简化误差在终值敏感性中保留。若资本开支必须永久维持更高水平，须下调ROIC或提高再投资，不能同时保留高终值。

## 八、现价究竟要求什么，以及哪些普通误差会翻转

### 8.1 同一模型的逆向要求

保持基准核心云、广告、商业生态、探索、证券投资和g/ROIC不变，只沿“基准AI→AI独立成功”同时插值AI收入/利润率与必要资本/折旧。使今天每股价值恰等于253.71美元的插值位置为57.98%，要求T1/T3/T7/T10 AI收入约59.6/158.0/469.3/730.6B，利润率28.7%/35.5%/39.2%/35.9%，对应全集团资本投入约264.0/315.4/402.3/479.8B。

这不是市场唯一隐含预测：更高广告利润、更少更新投入或较低r也能产生相同价格。它说明在本次正常商业生态与9.5%资本成本下，现价相容AI要求明显高于基准T7的220B。逆向条件不反过来成为本报告基准预测，也不能由此断言市场未认识某项机会。

按10%持有回报要求，工作分布给出的最高买价约一年197.7、三年197.8、七年196.0美元；这只满足中值财富要求，未加入额外安全边际。价格降到约195—200美元是重新评估区，而不是无条件买单；若经营证据同时变差，这个边界也下降。

保持两组内部相对权重不变，把“乐观＋突破”合计概率从30%提高，现价与当前价值相等需约62.8%，七年达到10%财富增长需约64.7%。这是反求的门槛，**不是实际成功概率**。单独提高突破概率不能忽略其需要的更高资本与融资。

### 8.2 独立机会成功：不强迫所有业务同时最好

**AWS AI单独成功**：只把基准的AI收入/利润率、相应资本与折旧改成突破路径，其他业务、证券投资、长期g＝3%和ROIC＝16%均保持基准。当前每股306.8美元，相比基准193.7美元增加113.1美元；T1/T3/T7为336.5/406.7/592.9美元。这一参照已经逐年扣新增投入，并非给AI收入乘一个倍数。可见不需要卫星、Zoox或广告同时突破，单独AI平台足以改变选择，但条件较现有采用证据遥远。

**探索组合独立成功**：其他业务保持基准，探索T1/T3/T7/T10收入改1/5/40/80B、EBIT改−9/−5/8/20B；每个相应节点额外资本5/10/25/35B、折旧0/2/15/30B。当前价值198.7美元，仅比基准多约5.0美元，T7为383.5美元。这已经是很大的独立经营成功，仍不能单独证明253.71美元值得买。更大且资本更轻的机会未被排除，但目前缺少支持，不能随意填补54美元价值缺口。

        rows.append(dict(t=t,revenue=rev,ebit=ebit,ebits=e,nopat=ebit-tax,da=da,cap=cap,nwc=nwc,fcff=f,cash=cash,debt=debt,shares=shares,borrow=borrow,repay=repay,interest=interest,invest=invest,acq=acq,ppe=ppe,cumfcff=cum))
    g=s['g']+g_shift
    tv=rows[-1]['nopat']*(1+g)*(1-g/s['roic'])/(r-g)
    results={}
    for t in [0,1,3,7]:
        future=sum(z['fcff']/(1+r)**(z['t']-t) for z in rows if z['t']>t)
        ev=future+tv/(1+r)**(10-t)
        asset=s['asset']*asset_mult/(1.11)**(10-t)-sum(z['invest']/(1.11)**(z['t']-t) for z in rows if z['t']>t)
        # Acquisition cash is paid only once; acquired operations are already forecast.
        acqleft=sum(z['acq']/(1+r)**(z['t']-t) for z in rows if z['t']>t)
        z=rows[t-1] if t else dict(cash=98,debt=162,shares=10.816)
        eq=ev+asset+z['cash']-35-z['debt']-acqleft
        per=eq/z['shares'];total=per/PRICE-1
        results[t]=dict(ev=ev,asset=asset,equity=eq,per=per,total=total,annual=(per/PRICE)**(1/t)-1 if t else None,tvshare=tv/(1+r)**(10-t)/ev)
    return dict(rows=rows,values=results,tv=tv)

def run():
    out={k:model(v) for k,v in S.items()}
    for k,v in out.items():
        print(k,'values',[(t,round(q['per'],2),round(q['total']*100,1),round(q['tvshare']*100,1)) for t,q in v['values'].items()])
        print('cash',[(q['t'],round(q['ebit'],1),round(q['fcff'],1),round(q['debt'],1),round(q['cash'],1)) for q in v['rows']])
    print('weighted',[(t,round(sum(p*out[k]['values'][t]['per'] for p,k in zip(P,S)),2)) for t in [0,1,3,7]])
    return out

if __name__=='__main__':run()
