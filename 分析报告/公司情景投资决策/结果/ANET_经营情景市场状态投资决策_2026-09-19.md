## 2. 谁付款、公司保留什么经济收益

Arista销售的是可部署和持续运维的网络系统：交换/路由硬件、EOS、诊断与自动化、软件订阅和支持。大型客户的架构团队选择，采购部门议价，云运营商或企业付款，网络及工作负载团队验收。模型使用方不必是直接付款客户；客户致谢既不是独供协议，也不是订单金额。2025年两个未具名终端客户占收入26%和16%，合计42%；客户预算和资格验证共享，不能让AI、常规云和路由各自独立取得客户最乐观预算。[10K] 公司与全资子公司并表，内部交易抵销；本次未发现需要单列分成的重大少数股东权益、已发行优先股或有息金融债务。[10Q]

公司没有按AI、园区、软件披露可独立审计的分部损益，因此采取四个**研究经济单元**，而非伪造分部财报：

竞争优势来自统一软件行为、调试经验、支持体系和与客户共同设计；商用交换硅及代工降低固定资产负担，也使芯片带宽本身难以成为排他壁垒。Broadcom是主要商用交换芯片供应方；采购承诺是为锁定供给承担的风险，不是拥有晶圆厂产能。[10K]

园区和分支有独立利润潜力：公司已收购VeloCloud，原始公告包含现有生产用户及渠道评价，能够复用EOS、CloudVision和渠道。但客户总数不等于ANET新增客户，未披露的独立ARR不以残差填充。已付并购款不在未来再扣一次；未来模型以内部研发和渠道扩展为主，不假定免费收购新平台。[VeloCloud]

没有识别到需要单列的大规模退出业务。老代际交换产品以更新、降价、存货报废和研发维护体现在C/A利润及资本路径中；受损行并不假定旧设备无限续卖。

### 3.1 合同表明什么，仍不知道什么

10-Q Revenue附注明确区分：递延收入6.8659；可取消合同项下预收合同负债0.2784；其他履约义务1.3029，其中未开票支持/服务0.4278、主要对应未来产品的具约束力承诺0.8751。前三者合计约8.4472；约91%预计两年内确认。不能把合计再与递延收入相加，不能把0.8751以外所有余额都称作固定产品订单。已发货但有验收条件的合同可推迟收入；未来释放递延收入并不必然产生同额新现金。[10Q]

采购一侧，9.7是**尚未列入资产负债表的不可取消采购承诺**，不是借款，亦不是销售订单。9.4为预计一年内收货，不是公司有权选择延期的上限；改期或调整需供应商同意。预付代工商0.1244已在资产内，不能再当额外采购义务。客户、料号、代际、跨客户转用性和供应商逐项索赔表未披露。[10Q]

后续针对性查证找到9月10日Citi会议管理层逐字发言（第三方承载）：CFO说明产品递延对应设备已发货、开票并收款但未满足验收，部分部署可能需18—24个月。它补充了已收款机制和部分项目时间，不能被总体递延余额混合而抹去；但仍没有给出所有客户平均验收期、各产品余额或返款条款。管理层口头所述采购承诺9.6与10-Q的9.7不同，本次账面/合同量取申报值9.7，口头发言只作供应提前期说明。其对第三、第四个大客户的预期仍是目标，不能先当已实现分散。[九月会议]

已核验10-Q的Revenue、Inventories、Commitments、Liquidity和风险因素，以及10-K收入确认与采购政策。它们没有提供毛取消率、逐客户验收排期或承诺逐代际拆分；这属于**在上述披露范围未找到**，不是断言公司任何渠道都未披露。合同已披露的约束仍然有效，不能因这些字段未知而将采购义务归零。后续季度的库存/递延成本周转，是公开渠道最可行的继续核验线索。

## 4. 决定预测的证据与最强相反解释

### 4.1 生产资格已过关，单位价值仍受架构制约

Meta在2024年3月公布24,576 GPU规模的RoCE集群使用Arista 7800，并用于模型训练；同文另有InfiniBand集群，说明资格和竞争共存。OpenAI于2026年5月公布MRC在大型GB200训练集群部署，并确认Arista参与大规模部署；它没有给出ANET直接合同金额。[Meta集群][MRC]

同一MRC证据也约束牛市叙事：800G接口拆为多个平面后可用更少交换层级连接大集群。增长模型必须把端点数、带宽、拓扑和净价分别处理。MetaRoCE进一步将部分流量控制放到端点，支持“网络仍重要，但整机软件租金未必同比增长”的替代解释；这是机制推断，不等于ANET已经丢失这些客户。[MRC][MetaRoCE]

需求和竞争都在扩张。IDC于2026-09-11公布Q2数据中心以太网交换市场123亿美元、同比64.5%；NVIDIA为其口径下第一大品牌厂商，份额20.4%。该定义与ANET投资者材料的高速市场/端口口径不同，不能因排名文字不同判定一个数字错误。Cisco 8月12日披露FY2026超大客户AI基础设施订单93亿美元；这是订单、是不同财年和产品范围，不能与ANET的年度确认收入直接相减算份额。[IDC][Cisco]

NVIDIA 7月21日Spectrum-6公告把交换机、NIC、软件与计算平台共同设计，并列出早期/未来采用客户；其性能倍数是厂商主张，不作独立基准。它说明ANET面对的竞争不仅是InfiniBand，还包括同样采用Ethernet的整栈供应商。[NVIDIA]

### 4.2 scale-up值得建模，但不能提前授予全部市场权益

OCP ESUN 1.0于2026年3月发布，说明标准/网络侧进展；本次没有查得可将ANET独立scale-up规模收入、净价格和批量验收台数固定为事实的原始披露。公司1.6T产品及开放NOS支持证明进入准备，不能证明未来12亿美元或120亿美元归属。6月9日公告将1.6T风冷版供应计划放在2026Q4、液冷版和128×800G版放在2027Q1；这是产品可供时间，客户验收和确认收入仍可更晚，因此首年模型不把它当年初即全面供货。[ESUN][1.6T]

U单元保留零收入研发、有限采用和突破三个幅度。基准首次小额收入放在第二个滚动年度，第三年仍约2亿美元；突破要求第三年15亿美元、七年120亿美元。XPO与可维修光学方案提高系统适配能力，其价值进入系统收入/成本，未另加一个光模块公司。U失败后保留维护/退出研发，不能用“未成功”自动消去已投入费用。

### 4.3 9月安全披露已经落地

9月9日更新的0148公告汇总多项EOS/VeloCloud漏洞，含Critical项。0158涉及启用gNPSI的特定配置；默认禁用，厂商称尚未知客户网络恶意利用，并提供修复版本。0156为DHCP Relay问题，CVSS 3.1为9.6，而CVSS 4.0为6.5，两个体系不能混报成一个统一严重性分数。[安全总览][安全0158][安全0156]

这些证据足以提高持续安全研发/支持的必要性，但尚不足以量化客户流失或赔偿。基准费用中持续投入，不追加无证据的重大赔款；受损路径包含支持、重新认证和客户转向造成的利润压力。若出现客户确认的生产损失/索赔，再同时下调收入和现金，不能只改变抽象风险标签。

## 5. 业务路径、规模约束与完整路径概率

所有预测从研究日开始，**第t年指9月19日至下一年9月19日的流量**。例如第1年止于2027-09-19，第3年止于2029-09-19；不是2027/2029自然年财报，也不是目标日期末运行速度。2026全年锚与第1年重叠，二者不相加。第8—15年逐步成熟，终值从2041-09-19之后开始。

### 5.1 量、价与可获得规模

没有足够公开端口净ASP和归属台数，因此不虚构设备逐台预测。A采用可复核的相对驱动式：

`A收入倍数 = 可服务新装/重配端点倍数 × 每端点带宽倍数 × 单位带宽所需网络资源倍数 × 单位资源净价倍数 × ANET归属份额倍数`。

以2026约3.5的AI目标量级作研究锚（8月4日CFO发言给出至少3.5，非审计分部；本次以该明确发言约束锚值）：第1年基准倍数约1.65×1.30×0.86×0.82×0.95＝1.44，对应约5.0。七年基准约7×3×0.65×0.42×0.75＝4.30，对应约15。突破的数量级约12×4×0.62×0.40×0.864＝10.29，对应36。以上均为E、相关的条件组合；较少层级和每比特降价已经扣入，不能再另减一次。数字不是对客户实际GPU台数和净售价的声称。[本地公司][目标转写]

七年C基准14.4，约为7.85初始分配锚的1.83倍；体现普通云、企业更新和支持增长，不要求重新创造一个AI后端市场。E由1.25量级增至5.1，约22%年复合，要求多年渠道份额提升。C/E的锚是分配假设，尤其C中的7.85是为统一模型边界设置的剩余池，**不是公司披露的常规网络收入**。支持分配无法精确识别，C/A之间移动0.5而集团总收入不变是分类误差，不应产生大量新价值。

## 6. 从经营到普通股：采购、税、现金与股数闭合

### 6.1 起点和年度现金公式

研究日起点现金采用6月末13.3433，加7月1日至9月19日**估计**净增1.20，减最低经营现金2.00，得到可归属非经营现金**12.5433**。桥接不是披露的9月资产负债表；净增合理范围0.5—1.8、最低经营现金1.5—3.0，合计每股价值影响约−1.35至+0.87美元，不足以解释现价与模型的差距。不得把这段已计起点的现金再记入第一年。

年度现金为：

`可供普通股体系的经营现金 F_t = EBIT_t − 20%×max(EBIT_t,0) + SBC_t + D&A_t − CapEx_t − Δ经营营运资本_t − Δ最低经营现金_t`。

使用**稀释法**处理SBC：业务EBIT已扣SBC，现金中加回SBC（4%收入的研究近似），未来股数每年增加1%；不再额外用回购现金抵销同一奖励。税率20%对扣SBC后的利润计算，隐含实际可抵扣股份报酬接近费用基数；若税扣除较低，现金价值下降。起点用普通股、而不再加入Q2的15.9百万股稀释增量，防止现有奖励与未来发行双计。6月末24.6百万未归属RSU、约1.5十亿美元未摊销费用和3.9年服务期约束早期稀释；其中每年约0.5%现有奖励归属、另约0.5%新授予/其他净发行，是首四年1%工作假设的量级解释，不是获批发行安排。[10Q]

第五年以后仍按净增1%，并在终值中持续稀释。名义股数为2027约12.738亿、2029约12.994亿、2033约13.522亿。0.5%—1.5%的稀释敏感性保持现金加回处理不变。本次不同时扣除“现金替代SBC”再增加股数。股份授予公允价值、股票价格与未来发股量不严格一一对应，是模型误差来源；若股价长期更低、员工奖励要求固定美元补偿，必须提高稀释，不能沿用便宜股价和少发股的组合。

D&A=收入0.7%；CapEx=收入1.5%，首年另加0.12物业建设（6月末披露剩余0.110—0.135）。持续研发已在EBIT内，不再次资本化。正常营运资本增量按收入增量的16%/18%/22%（基准/乐观/突破），受损20%；最低经营现金额外随收入增量按12%调整。负增长允许资金释放，但受损行先有存货冲击，不能凭收入下降立刻释放全部库存。[10Q]

额外营运资本占用/释放（第1—7年，十亿美元）：受损[3,1,−1,−1,−0.5,0,0]；基准[1,0.5,−0.5,−0.5,−0.5,0,0]；乐观[1.2,0.5,−0.4,−0.5,−0.8,0,0]；突破[1.5,1,0.5,−0.5,−0.5,−1,−1]。它们代表验收/备料相对正常周转的额外资金占用，释放不得再计收入。受损行第一、二年另扣0.8、0.4现金性供应商和客户处理成本；不是已经通过库存占用扣过的非现金减值再扣一次。

所有路径不需要新债、优先融资或增发融资；奖励发行已计。公司2026H1没有执行回购，剩余回购授权0.8179不是必须执行的现金负债。管理层的系统工程执行记录支持跨代更新，但大量留存现金也有资本配置风险：若第七年基准超额现金被永久减损20%，该时点每股价值约减少11.47美元，降至167.25；不能一边假定收购花掉资金，一边保留全额现金价值。基准不假定机会主义回购创造价值，分红为零；未来可分配现金以税后3%收益留存，现金账户为`C_t=1.03×C_(t−1)+F_t`。3%是长期资金管理假设，不是公司已锁定收益率。经营租赁继续作为费用/经营负债处理，不在股权价值中重复减一次；2025年末披露租赁付款总额约0.0905，不能冒充2026年6月的新期债务。[10Q][10K]

### 6.2 必须经过的流动性压力

模型前七年受损行最低年末**超额**现金仍约13.21，但这不证明年内从未缺钱。以6月末事实余额作更严的半年停收压力：可动用13.3433，减假设94亿一年内收货承诺全部提前付款9.4、半年现金运营费用1.0、物业0.135、已知可取消预付款全部退款0.2784，余**2.5299**；若另1.0验收退款且客户完全不回款，则低于2.0最低现金约0.4701。全额预付比披露的收货条件更严，退款与运营费用是压力假设，**不是已披露付款日程**。

正常情况下采购形成产品成本和库存，上述9.4不得再从DCF扣一遍；该瀑布仅检验极端前置支付。可行应对顺序是停止可选回购、暂缓新增采购/可选项目、回收应收、谈供应商排期，再考虑融资；不能假定已承诺订单可单方取消。披露未提供可作为确定到账的授信，模型不凭空填授信。

若尾部发生更大退款、存货不可转用与客户流失，必须放弃四行的收入路径并重做重组现金。清偿顺序是经营/担保或其他优先债权、融资债权、普通股剩余；新主体未来利润不能自动算给旧股东。本次以**将工作分布中5个百分点基准权重改为旧普通股最终价值0**作保守尾部测试（不是估计破产概率），当前加权价值减少约4.92，七年期望价值减少8.94，结论不变。这一测试不能证明尾部概率就是5%。

### 6.3 为什么高利润还需要资本

高回报来自无晶圆厂资产、研发和安装基础复用，而非完全零资本。基准总新增现金投入包括16%经营周转、12%经营现金、净固定资产0.8%收入及已费用化研发；AI高速增长和验收延后会先占用资金。七年基准收入35.9、营业利润14.30，但FCF为11.59；突破收入67.5、营业利润27.96、FCF21.94。没有用利润代替现金，也没有把未花的研究投入当免费扩张。

## 7. 今天价值与目标日剩余经营

### 7.1 估值方法与尾部约束

公司无重大有息债务，采用**稀释调整的直接普通股现金估值**，与经济上的经营现金加非经营净资产相接。每个目标日先计算以后年度现金对该日股份的归属，再加当日现金；目标日前累计现金只进现金账户一次。

以N_t表示股数、r表示普通股风险折现率、d表示年稀释率：

`每股剩余价值_h = Σ(t=h+1..15)[F_t/N_t/(1+r)^(t−h)] + [F_16/N_15 / ((1+r)(1+d)−1−g)]/(1+r)^(15−h)`；

`每股价值_h = 每股剩余价值_h + C_h/N_h`。

这不是未经调整的企业FCFF/WACC估值：未来发股造成的现有普通股份额减少明确进入每期分母，终值亦含稀释；由每股数×N_h得到表内**稀释调整后普通股总值**。现金加回SBC正是这种方法的一部分。终值资本投入继续按相同现金公式扣除，不把第15年FCF简单乘一个倍数。

美元名义r中央值10.5%，范围9%—12%。9月18日美国财政部1/3/7/10年国债参考收益率为4.44%/4.83%/4.93%/5.01%；约5%长端时间价值加约4%—7%股票系统性风险补偿支持该范围。这里不是机械CAPM点估计；完整路径发生概率处理经营结果，而r保留共同AI资本周期/市场风险，不再次通过另一个“失败折价”重复扣同一现金损失。[美债]

P0=199.39

R0=12.6
PROBS=[.25,.45,.23,.07]
NAMES=['受损','基准','乐观','突破']

    if up_from: rr[3]=list(R[up_from][3])

    fixed_pair=FIX[up_from] if up_from else FIX[name]
    if delay:
        rr[1]=[3.5]+rr[1][:-1]
        rr[3]=[0]+rr[3][:-1]

        reserve=.12*(sales-prevR)

        shares*=1+d
        seq.append(dict(t=t,business_rev=rev,business_op=op,rev=sales,op=operating,sbc=sbc,tax=tax,da=da,capex=capex,dwc=dwc,reserve=reserve,fcf=fcf,cash=cash,shares=shares,fixed_up=fix))
        prevR=sales
    # normalized year 16; growth capital retains same sales intensity.
    z=seq[-1]; r16=z['rev']*(1+g);op16=z['op']*(1+g)
    f16=op16*(1-taxrate)+.04*r16-.008*r16-(wc+.12)*(r16-z['rev'])

    out={}
    for h in [0,1,3,7]:
        nh=N0*(1+d)**h
        rem=sum(x['fcf']*(nh/x['shares'])/(1+r)**(x['t']-h) for x in seq if x['t']>h)
        tv=terminal*(nh/z['shares'])/(1+r)**(15-h)
        ch=C0 if h==0 else seq[h-1]['cash']

    return dict(seq=seq,values=out,terminal=terminal,f16=f16)

def weighted(results,probs=PROBS):
    return {h:sum(p*results[n]['values'][h]['price'] for p,n in zip(probs,NAMES)) for h in [0,1,3,7]}


for n in NAMES:
