## 2. 排序规则

| 维度 | 权重/处理 | 含义 |
|---|---:|---|
| 基准兑现 | 34% | 基准收入增速、基准经营利润率、基准可信度。 |
| 估值合理 | 24% | Forward PE、EV/EBITDA、P/S；高增长公司对 P/S 容忍略高，但极端 P/S 仍扣分。 |
| 悲观不崩 | 24% | 悲观收入增速、悲观经营利润率、基准可信度；悲观情景仍能增长或维持正经营利润率则加分。 |
| 乐观弹性 | 12% | 乐观相对基准的增量完整计入；极度乐观只按折扣因子计入。 |
| 证据可信度 | 6% | 使用公司评估中对应情景的可信度，避免把远期叙事误当基准。 |
| 风险扣分 | 直接扣分 | 负 EPS、高 IV、Forward EPS 非正、P/S 极端、EV/EBITDA 异常、估值校验缺口。负 EPS + 高 IV 触发额外降档。 |

极度乐观折扣因子：默认最高 `0.35`；校准动作为“下移”通常压到 `0.18`；“移入附录/仅作跟踪”压到 `0.10`；极度乐观可信度低封顶 `0.12`；若需要客户、供应链、政策、融资、电力/液冷/产能等多条件同时突破，封顶 `0.18`。因此，极度乐观可以留下备注和少量弹性分，但不能直接决定排名。

分档：`A >= 75`；`66 <= B < 75`；`56 <= C < 66`；`46 <= D < 56`；`E < 46`。

## 3. 总览

- 分档数量：A `2`；B `7`；C `45`；D `49`；E `77`。
- 极端上限被折扣且仍有明显右尾缺口的公司：`108` 家。
- Top 公司多来自两类：一类是基准增速和利润率都可兑现的 AI 核心链条；另一类是估值、现金流和悲观情景更稳的电力/机电/软件底盘。
- Bottom 公司不是简单“业务差”，而是在本方案中被高 IV、负 EPS、估值极端、基准亏损或悲观情景失稳压制；极度乐观叙事在这些公司里基本只能写备注。
