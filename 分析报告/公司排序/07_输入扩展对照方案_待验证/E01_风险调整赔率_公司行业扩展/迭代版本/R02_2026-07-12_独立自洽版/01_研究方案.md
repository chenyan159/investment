## 研究目标与唯一输出

对统一截止时点下的全部公司做连续排名，优先寻找可验证上行、估值缓冲和下行边界同时成立的公司。高质量但没有赔率、赔率很大但缺少兑现证据、或近期下跌仍未解释的公司均不得机械进入前列。

完整结果只能写入：

不得创建或修改其他文件。

## 输入边界与时间截止

只能读取：

- `D:\drive\Investment\基本面\分析报告\公司评估\结果\`
- `D:\drive\Investment\基本面\日度资料\每日金融数据\`
- `D:\drive\Investment\基本面\公司调研\`
- `D:\drive\Investment\基本面\行业调研\`

不得读取任何排序结果、效果验证、特征量化、备份资料、外部网页或未列出的本地资料。

1. 选择执行时点以前日期最新、覆盖完整的每日金融主文件；“补充字段校验”文件只能与同日主文件合并。
2. 以主文件生成时间作为研究资料截止时点，以主文件披露的最新价格日期作为价格截止日，两者必须分别记录。
3. 样本池为主文件列出的全部公司。每家公司使用截止时点以前最新的一份正式公司评估、最多一份最新正式公司调研，以及一份与主营收入传导直接相关的最新正式行业报告。
4. 公司评估是全样本标准化主输入；公司和行业资料只补充更新事实、证据链和反证。每家公司执行相同选择规则，禁止只深读预选前排公司。
5. 同一事实只计一次。资料冲突时列明文件和日期，采用截止时点以前更新、更直接且可量化的证据，并降低置信度。
6. 缺少公司或行业资料不等于经营差，样本仍保留；资料数量不直接加分。
7. 区间价格和估值变化只能由价格截止日及以前的每日金融文件计算，并采用可确认的复权口径。

## 统一评分

八项分数均为0–100分，并附一句可追溯证据：

| 分项 | 权重 |
|---|---:|
| 上行质量 | 18% |
| 下行边界 | 16% |
| 财务韧性 | 12% |
| 估值缓冲 | 15% |
| 负面触发控制 | 12% |
| 催化兑现 | 13% |
| 假设稳健性 | 9% |
| 资料完整性 | 5% |

`基础分 = 0.18×上行质量 + 0.16×下行边界 + 0.12×财务韧性 + 0.15×估值缓冲 + 0.12×负面触发控制 + 0.13×催化兑现 + 0.09×假设稳健性 + 0.05×资料完整性`

## 价格确认调整

- 20日复权收益位于全样本前40%、5日收益不在后30%，且有可验证经营改善或催化兑现：加6分；两类证据同时成立再加4分。
- 20日收益位于后30%：扣6分；没有可验证的风险出清、错杀解释或经营缓释时再扣4分。
- 价格上涨但没有基本面桥梁，或价格下跌已有充分量化的暂时性解释：调整为0并标记冲突。
- 数据不足、疑似拆股或复权不明：调整为0并降低资料完整性。

`综合分 = 截断到0–100的（基础分 + 价格确认调整）`

## 前排门槛与冲突处理

- Top20要求下行边界不低于55、负面触发控制不低于50，且不能同时存在两项未解除核心风险。
- 基准情景需要紧急融资、重大稀释或多个未验证客户条件同时成立时，最高进入中段。
- 同一事实造成多个风险项时，只保留一个主导扣分。
- 近期下跌只有在来源、传导、时间窗口和出清证据都清楚时才可视为赔率改善。
- 不得按公司名称、代码、行业标签或资料数量直接加减分。

## 输出要求

先逐公司形成评分卡，再做横截面排序和相邻名次复核；不得根据结果改变权重或门槛。

输出输入审计、公司调研与行业调研覆盖率、主快照、价格截止日、Top20、Bottom20和完整连续排名。每行至少包含：排名、代码、公司、综合分、八项分数、5/20日收益、价格状态、估值、上行证据、下行边界、核心反证、实际使用文件、资料冲突、缺口、置信度和一句理由。

文末列出全部输入文件、价格覆盖、复权口径、资料新增/反证事实和规则检查，以便按生成时点开展后续验证。
