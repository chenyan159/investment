# S02 R06 独立验证结果

验证日期：2026-06-10
验证对象：`S02_预期兑现概率 / R06`
验证窗口：`2026-05-29` 收盘至 `2026-06-09` 收盘

本报告只验证 `R06` 排名结果，不修改研究方案正文，也不生成下一轮研究方案正文。统计覆盖基准采用收益验证输入中的 `## 全公司明细`，前轮 `R05` 验证结果只用于判断本轮是否相对前轮改善。

## 结论摘要

`S02 R06` 覆盖层面合格，排名方向显著正确，且相对 `R05` 明显改善；但改善主要来自综合分与“离散价格状态”对同一验证窗口的吸收，`基本面预期兑现概率` 单项仍然很弱。因此，本轮可以判定为“排名统计效果继续改善，但独立基本面信号仍未充分证明”。

- 覆盖结论：收益验证文件解析到 `180` 家公司，排名文件解析到 `180` 行、`180` 个唯一股票代号，排名 `1-180` 连续；重复股票 `0` 个，无法匹配收益股票 `0` 个，收益文件中有但排名没有的股票 `0` 个。
- 排名方向：有效方向应为“排名越靠前，验证期收益越高”。由于排名序号越小代表越靠前，所以“排名序号 vs 验证收益”的有效相关方向应为负值。R06 Pearson `-0.7420`、Spearman `-0.8072`、Kendall tau-b `-0.5995`，三项方向正确，强于 R05 的 `-0.5901 / -0.6316 / -0.4529`。
- 综合分方向：有效方向应为“综合分越高，验证期收益越高”。R06 综合分与收益的 Pearson `+0.7057`、Spearman `+0.8216`、Kendall tau-b `+0.6345`，强于 R05 的 `+0.4468 / +0.6280 / +0.4578`。
- 基本面单项：`基本面预期兑现概率` 与收益的 Pearson `+0.1262`、Spearman `+0.0847`、Kendall tau-b `+0.0584`。其中 Pearson 弱于 R05 的 `+0.1437`，Spearman/Kendall 只是小幅高于 R05 的 `+0.0776 / +0.0484`，整体仍属于弱信号。
- Top-Bottom 结论：Top10、Top20、Top30、Top50 相对对应 Bottom 组均为正差值；Top10-Bottom10 为 `+23.53pct`，组内双侧去极值后为 `+21.72pct`；Top50-Bottom50 为 `+15.34pct`，去极值后为 `+14.89pct`。四个层级均强于 R05。
- 分位结论：十分位和五分位的平均收益均严格单调递减，没有平均收益层面的破坏点。相比 R05 的中段破坏，R06 分层明显更清楚。
- 极端样本结论：最大涨幅为 `MRVL +30.19%`，排名 `36`；最大跌幅为 `RKLB -24.58%`，排名 `167`。剔除两端极端样本后，排名相关性为 `-0.7540 / -0.8032 / -0.5965`，综合分相关性为 `+0.7181 / +0.8179 / +0.6312`，结果仍然成立，不是由单个极端样本独立驱动。

## 下一轮修改建议

本节只给抽象方法方向，不生成下一轮研究方案正文。

主要有效机制：

- R06 的头尾分离显著增强，Top-Bottom、去极值 Top-Bottom、十分位和五分位平均收益都给出方向正确的结果。
- 综合分排序明显强于单一基本面预期兑现概率，说明“基本面证据 + 冲突处理 + 上限规则 + 价格状态粗校验”的组合比单一主观兑现概率更接近短窗收益。
- 尾部压制更有效，拒绝、强回撤、资料缺口和期限错配样本集中在后段，使 Bottom 组平均收益显著弱于 Top 组。

主要失效机制：

- 基本面预期兑现概率单项仍然很弱，Pearson 甚至低于 R05；这说明 R06 的统计改善不能简单归因于基本面兑现概率本身增强。
- 离散价格状态与同窗收益高度一致，状态分组从拥挤确认到强回撤形成明显收益阶梯；这会提高验证统计，但削弱独立验证含义。
- 前排虽然绝对收益改善，但仍依赖价格状态过滤；若未来禁止使用同窗价格状态，当前排名强度可能下降。
- 中后段少量正收益样本显示，方案仍可能把“已有确认但被估值或长期质量折扣压低”的样本放得过低。

覆盖问题：

- 本轮无覆盖缺口：收益文件 `180` 家、排名文件 `180` 行全部匹配，排名序号连续。
- 排名文件自报 `AMPX` 缺公司评估材料但仍保留在连续排名中，这个覆盖处理方向正确；后续仍应要求缺材料样本保留在全样本排名中，并明确缺口类型、受影响字段和置信度折扣。
- 独立验证不能证明生成过程是否真的只读允许文件，只能证明排名文件的可见声明和输出结果没有明显越界文本证据。

下一轮抽象修改方向：

1. 将“预期兑现概率”进一步拆成可审计的短窗事件链：订单、指引、交付、验收、收入确认、利润率和现金流，每个环节必须说明验证窗口内为何能或不能传导到股价。
2. 降低同窗价格状态对排序本身的权重：价格状态可以用于冲突解释、置信度折扣和事后诊断，但不应成为决定头尾分层的主要变量。
3. 对负面价格状态增加抽象解释门槛：若高基本面样本出现拒绝或强回撤，必须区分经营可解释回撤、估值压缩、期限错配和兑现假设被否定。
4. 对中后段确认样本增加修复质量判别：区分一次性反弹、估值修复、订单/业绩催化和真实预期兑现，避免既机械追涨又系统性低估短窗催化。
5. 继续禁止按公司名、股票代号、目录分类或具体行业标签制定硬规则；所有修正规则应围绕资料新鲜度、证据强度、兑现路径、价格冲突解释和置信度折扣等抽象变量。
