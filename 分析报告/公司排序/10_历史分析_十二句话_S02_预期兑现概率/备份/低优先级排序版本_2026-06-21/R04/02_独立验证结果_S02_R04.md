# S02 R04 独立验证结果

验证日期：2026-06-10

验证窗口：`2026-05-29` 收盘至 `2026-06-09` 收盘

本报告只对 `R04` 排名结果做独立验证，不修改研究方案正文，也不生成下一轮研究方案正文。统计口径以收益验证输入中的全公司明细作为覆盖基准；前轮 `R03` 验证结果只用于判断本轮是否相对前轮改善。

## 结论摘要

`S02 R04` 覆盖层面合格，排名方向正确，综合分与验证收益的相关性相对 `R03` 有所改善；但改善不全面，主要体现在综合分相关性和 Top10/Top20 头尾差，Top30/Top50 头尾差反而弱于 `R03`，分位单调性也仍然被中段和后段反弹破坏。因此本轮可以判定为“局部改善”，不能判定为稳定、全面改善。

- 覆盖结论：收益验证文件解析到 `180` 家公司，排名文件解析到 `180` 行、`180` 个唯一股票代号，排名 `1-180` 连续；重复股票 `0` 个，无法匹配收益股票 `0` 个，收益文件中有但排名没有的股票 `0` 个。
- 排名方向：有效方向应为“排名越靠前，验证期收益越高”。由于排名序号越小代表越靠前，所以“排名序号 vs 验证收益”的有效相关方向应为负值。本轮 Pearson `-0.3098`、Spearman `-0.3661`、Kendall tau-b `-0.2496`，方向正确，强度为弱到中等。
- 综合分方向：有效方向应为“综合分越高，验证期收益越高”。本轮综合分与收益的 Pearson `+0.2844`、Spearman `+0.3687`、Kendall tau-b `+0.2519`，方向正确，且三项均高于 R03 的 `+0.1984 / +0.3360 / +0.2343`。
- 机制拆解：基本面预期兑现概率与收益的 Pearson `+0.1738`、Spearman `+0.2065`、Kendall tau-b `+0.1385`，方向正确但仍偏弱；说明基本面主分对短窗口收益的解释力有限，综合分改善主要来自价格状态限位、冲突处理和排序约束，而不是基本面主分本身已经足够强。
- 价格验证列：排名表中的“价格验证”列可解析出 `180` 个涨跌幅，且与收益验证文件完全一致，因此其相关性为 `+1.0000 / +1.0000 / +1.0000`。这只是因为该列直接复述验证窗口收益，不应被视为独立预测因子。
- Top-Bottom 结论：Top10、Top20、Top30、Top50 相对对应 Bottom 组均为正差值；Top10-Bottom10 为 `+9.15pct`，组内双侧去极值后为 `+9.63pct`；Top20-Bottom20 为 `+9.49pct`，去极值后为 `+9.72pct`。但 Top30 和 Top50 的差值低于 R03，说明改善集中在更窄的头尾层。
- 分位结论：十分位不满足严格单调，主要破坏点为 `D2->D3`、`D3->D4`、`D6->D7`、`D8->D9`；五分位破坏点为 `Q1->Q2`、`Q3->Q4`。中段和后段出现强反弹样本，说明排序仍不能稳定压住短窗强修复个股。
- 极端样本结论：全样本最大涨幅为 `MRVL +30.19%`，最大跌幅为 `RKLB -24.58%`。剔除两端极端样本后，排名相关性为 `-0.3490 / -0.3795 / -0.2590`，综合分相关性为 `+0.3192 / +0.3822 / +0.2612`，反而略强于全样本；因此本轮正向结果不是由极端样本单独驱动，极端样本更多是在破坏分位单调性。
- 相对 R03：综合分相关性全面改善；排名序号 Pearson 从 R03 的 `-0.3500` 变弱到 `-0.3098`，但 Spearman 和 Kendall 从 `-0.3300 / -0.2280` 改善到 `-0.3661 / -0.2496`；Top10/Top20 差值改善，Top30/Top50 差值下降。综合判断为局部改善，但稳定性仍不足。

- 覆盖和连续排名执行合格，收益基准中的 `180` 家公司全部进入排名，没有重复、缺失或无法匹配样本。
- 综合分相对 R03 的相关性全面改善，说明 R04 的冲突处理、价格状态限位和资料缺口折扣比 R03 更能与验证窗口收益同向。
- Top10/Top20 相对 Bottom10/Bottom20 的差值改善，且去极值后仍成立，说明最头部和最尾部的分层更有效。
- 低排名区聚集了较多强拒绝、资料缺口、兑现期限错配或估值过满样本，使 Bottom 组整体收益较差，这是本轮 Top-Bottom 为正的主要来源。

主要失效机制：

- 基本面预期兑现概率主分与短窗收益仍只有弱相关，说明六项基本面分档更像质量和兑现条件评分，还没有充分转化为 `2026-05-29` 至 `2026-06-09` 这种短窗口收益排序因子。
- 高主分样本遇到“回撤”或“拒绝”时，仍能留在前 60 名甚至前 10 名，导致前排出现明显负收益反例。
- 中段和后段存在强修复样本，尤其“拥挤确认”被压到低排名后，可能在短窗验证里显著拉高后段分位。
- “估值反映较多/过满”标签使用较广，但约束强度不够稳定：有些样本被压得过低，有些高主分样本又没有被足够限位。

覆盖问题：

- 本轮没有覆盖缺口：收益文件 `180` 家、排名文件 `180` 行、有效匹配 `180` 家。
- 排名文件自报公司评估材料缺口为 `AMPX`，该样本被保留在第 `180` 名，并给出资料缺口和置信度折扣；覆盖处理合格。
- 后续仍应保留“缺评估材料也必须排名、不得剔除”的规则，避免样本选择偏差。

下一轮抽象方法方向：

- 保留 R04 对价格追随的约束，不回到直接复制短窗收益的做法；但应把“高主分 + 价格拒绝/强回撤”的前排限位做得更硬，例如使用分位上限、置信度上限或最高综合分上限，而不是只做小幅扣分。
- 将基本面主分拆成两层：一层是短窗口或 NTM 内可验证的收入、利润、订单、交付、验收桥梁；另一层是长期叙事质量和远期期权。验证窗口越短，第一层权重应越高。
- 对“估值已反映”做更结构化处理：区分已由价格确认充分反映、已由叙事估值反映但缺少兑现桥梁、以及价格回撤后预期被重新压低三种状态，避免统一贴上“较多/过满”后无法稳定排序。
- 对“拥挤确认”不要简单追涨，也不要一律重压；应要求其同时满足可验证桥梁、资料新鲜度和负面证据闭环，才允许从后段进入中前段，否则只进入观察区。
- 对分位单调性做训练后验检查：不仅看 Top-Bottom，也要检查 D3/D4、D7/D9 这类中后段反弹。如果中段均值高于前段，应回看抽象规则中是否存在过度惩罚短窗确认、过度奖励长期质量的问题。
- 继续在验证报告中分开披露排名序号、综合分、基本面主分和价格验证列的相关性，尤其要标明价格验证列直接复述收益，防止统计改善被误读为独立预测能力提升。

本报告不生成下一轮研究方案正文，也不评价其他方案。
