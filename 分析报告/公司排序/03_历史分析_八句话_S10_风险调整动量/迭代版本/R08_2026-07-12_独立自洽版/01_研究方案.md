## 输入边界与截止

只能读取 `D:\drive\Investment\基本面\分析报告\公司评估\结果\` 和 `D:\drive\Investment\基本面\日度资料\每日金融数据\`。不得读取公司调研、行业调研、任何排序结果、效果验证、特征量化、备份和外部资料。

选择执行时点以前最新且覆盖完整的每日金融主文件，同日补充文件只作校验。记录主文件生成时间与价格截止日；样本池取主文件全部公司，每家公司使用截止时点以前最新的一份正式评估。5、10、20日收益必须由价格截止日及以前的可确认复权价格计算；口径不明时动量项取中性。

## 固定评分

| 分项 | 权重 |
|---|---:|
| 价格动量 | 24% |
| 可交易弹性 | 18% |
| 风险调整动量 | 16% |
| 触发临近 | 14% |
| 下行支撑 | 10% |
| 质量底线 | 8% |
| 数据可信度 | 6% |
| 集中度约束 | 4% |

`总分 = 0.24×价格动量 + 0.18×可交易弹性 + 0.16×风险调整动量 + 0.14×触发临近 + 0.10×下行支撑 + 0.08×质量底线 + 0.06×数据可信度 + 0.04×集中度约束`

价格动量由5、10、20日收益按20%、30%、50%合成并转换为横截面百分位。风险调整动量等于动量百分位扣除IV拥挤、估值扩张、负FCF、融资和客户集中造成的固定折扣；单项最多扣15分，总折扣最多40分。

## 门槛与封顶

- Top20必须同时具备价格动量不低于60和可交易弹性不低于55，并有未来两个报告期内的明确触发。
- 低波动高质量但缺少上行速度的公司最高进入中段。
- 高IV、亏损或资料缺口公司在价格转强、触发明确且资金跑道可承受时可进入中前段，但必须给出封顶原因。
- EPS与FCF均为负、资金跑道不足24个月且IV处最高四分位：不得进入Top30。
- 后排主要保留价格破坏、触发遥远和下行解释不足的样本；风险标签本身不构成尾部条件。
- 同一事实只在一个主风险项扣分，不得按公司名称、代码或行业标签设置优先级。

## 输出要求

输出输入审计、Top20、Bottom20和全样本连续排名。每行至少包含：排名、代码、公司、总分、八项分数、5/10/20日收益、IV分位、动量来源、弹性依据、触发与日期、风险折扣、下行支撑、质量底线、数据缺口、封顶和一句理由。

文末记录输入文件、价格覆盖、复权口径、风险折扣分布、门槛触发和全样本覆盖，不得在看到结果后改变权重。
