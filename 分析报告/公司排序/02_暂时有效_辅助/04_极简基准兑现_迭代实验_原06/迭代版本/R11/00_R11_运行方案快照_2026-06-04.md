# R11 运行方案快照

方案版本：`类目中性版`

```markdown
# 极简投资排序研究方案

1. 只允许读取 `分析报告/公司评估/*.md` 和 `日度资料/每日金融数据/每日金融数据_*.md`。
2. 先在每个项目分类内部排序，再把各分类的高分公司合并，避免单一赛道垄断Top20。
3. 分类内仍看上涨空间、确定性、保护力和估值，不给行业标签无条件加分。
4. 若某分类整体高IV或高估值，只保留其中证据最强和悲观情景最好的公司。
5. Bottom20优先暴露各分类内部最差的风险样本。
6. 输出全表、分类Top名单、Top20、Bottom20和异常清单。
```
