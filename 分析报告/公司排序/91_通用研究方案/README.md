# 通用研究方案

本目录保存跨排序方法复用的评估模板、时间档案和执行说明。

当前操作入口为[公司调研输入与九方案使用说明](2026-09-10_公司调研输入与九方案使用说明.md)，未来研究文件以[待运行注册表](../00_待运行研究方案注册表.csv)为准。当前7个常规单元、2个限定实验全部采用公司调研独立输入，没有成对输入入口。

评估模板使用前复制到具体方案版本或评估日期目录，填入真实结果和独立输出路径；不覆盖历史模板。新研究未完成前，不能写进实际结果注册表或对外发布。

scripts/sync_company_sorting_management.py仍只同步真实结果注册与历史评估的展示字段，不管理未来输入契约，也不能用它把未运行新方案绑定旧结果。使用同步脚本后仍须检查历史结果与当前执行入口的语义边界。

带日期的旧使用说明只解释当时运行安排，不作为当前批次配置。合并与输入重构的证据和快照见项目备份中的“排序输入重构与合并_2026-09-10”。
