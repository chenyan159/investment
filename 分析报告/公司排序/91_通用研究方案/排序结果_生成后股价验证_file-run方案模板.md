# 排序结果生成后股价验证方案

## 使用方式

把本文件复制到待评估版本的以下位置，并命名为 `01_评估方案.md`：

`迭代版本/Rxx_YYYY-MM-DD_目的/回测/生成后样本外_截至_YYYY-MM-DD/01_评估方案.md`

然后填入本文件末尾的参数，用 research-runner `file-run` 运行。评估结果必须写到同目录的 `02_评估结果.md`；不得覆盖排序的 `01_研究方案.md` 或 `02_排序结果.md`。

## 目标

评估指定排序结果在生成后的未见股价窗口是否具有横截面区分能力。每家公司独立使用自己的复权收盘价计算涨跌，不能用大盘涨跌代替个股涨跌。

## 输入

1. 指定的 `02_排序结果.md` 或结构化排序结果文件。
2. 排序生成日期和生成时区。
3. 覆盖全部入榜公司的复权收盘价；若本地价格不足，可补充可靠外部价格源，并记录来源与抓取时间。
4. SPY、QQQ、SOXX 的复权收盘价，仅作为比较基准。

## 时间口径

- 起点：排序生成日期之后的第一个完整交易日；若结果在收盘前已固定，可在结果中明确使用当日收盘，否则默认从下一交易日开始。
- 终点：参数指定的最后完整交易日。
- 不得把排序生成前的价格变化混入生成后收益。
- 若同时提供六个月或压力窗口，只能单列为 `生成前回看`，不得与生成后结果合并计算胜率。

## 个股计算

对每个股票代码分别计算：

- 起始复权收盘价、结束复权收盘价、累计收益率；
- 5 日、10 日收益率（窗口不足时留空）；
- 窗口内最大回撤与年化波动率；
- 数据缺失、退市、代码变更或异常价格的处理记录。

必须保留全部公司的逐股明细，不能只保留 Top10。

## 排序效果指标

至少计算：

- Top10、Top20、Bottom10、Bottom20、五分位平均收益；
- Top10 相对全样本等权平均的超额；
- Top10-Bottom10、Top20-Bottom20、Q1-Q5 差；
- 排名与个股收益的 Spearman Rank IC；
- Top10 最大回撤、年化波动和正收益比例；
- Top10 相对 SPY、QQQ、SOXX 的超额，仅作为基准比较。

## 证据标签

每一行结果必须标注以下之一：

- `生成后样本外`：排序生成后从未被方案看到的价格窗口；
- `生成前回看`：排序生成前的历史窗口；
- `调参窗口`：曾用于选择规则、权重或版本的窗口；
- `重叠窗口`：一部分发生在生成前、一部分发生在生成后。

## 结果要求

`02_评估结果.md` 必须包含：

1. 评估对象、排序版本、生成日期、交易起止日和交易日数；
2. 数据源、复权口径、缺失值和异常处理；
3. 全部核心指标；
4. Top10 和 Bottom10 逐股明细；
5. 与历史验证是否同方向；
6. 证据限制，明确样本短、市场状态单一和多重试验风险；
7. 临时结论：保留、观察、冻结或退出，但不得宣称永久有效。

如同时生成 CSV，文件名使用 `03_全部公司股价明细.csv` 和 `04_评估指标.csv`。

- 待评估排序结果：`<填写绝对路径>`
- 排序生成日期：`<YYYY-MM-DD>`
- 评估截止交易日：`<YYYY-MM-DD>`
- 评估结果输出：`<填写同目录 02_评估结果.md 的绝对路径>`
- 可选本地价格输入：`<填写绝对路径或留空>`
