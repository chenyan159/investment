## 固定评分

| 分项 | 权重 |
|---|---:|
| 价格动量 | 24% |
| 可交易弹性 | 18% |
| 风险调整动量 | 16% |
| 触发临近 | 14% |
| 下行支撑 | 10% |
| 质量底线 | 8% |
| 数据可信度 | 6% |
| 集中度约束 | 4% |

`总分 = 0.24×价格动量 + 0.18×可交易弹性 + 0.16×风险调整动量 + 0.14×触发临近 + 0.10×下行支撑 + 0.08×质量底线 + 0.06×数据可信度 + 0.04×集中度约束`

价格动量由5、10、20日收益按20%、30%、50%合成。扩展资料只能改变触发临近、下行支撑、质量底线和集中约束；不得篡改价格动量。重复事实只计一次。

## 门槛与封顶

- Top20必须有价格动量不低于60、可交易弹性不低于55，以及未来两个报告期内有日期和量化标准的触发。
- 低波动高质量但缺少上行速度的公司最高进入中段。
- 高IV、亏损或资料缺口公司若价格转强且触发明确，可进入中前段，但资金与悲观情景必须可承受。
- EPS、FCF均为负、资金跑道不足24个月且IV最高四分位：不得进入Top30。
- 后排由价格破坏、触发遥远和下行解释不足决定；风险标签本身不机械后置。
- 公开资料冲突时优先采用截止时点以前更新、更直接且可量化的证据，并降低置信度。

## 输出要求

输出输入审计、公开检索覆盖、Top20、Bottom20和完整连续排名。每行至少包含：排名、代码、公司、总分、八项分数、5/10/20日收益、IV分位、动量来源、扩展资料解释、触发与日期、风险折扣、下行支撑、资料冲突、封顶和一句理由。

文末列出所有输入文件和URL、发布日期、价格覆盖、复权口径、检索覆盖与规则检查，保证信息截止和评分可复核。
