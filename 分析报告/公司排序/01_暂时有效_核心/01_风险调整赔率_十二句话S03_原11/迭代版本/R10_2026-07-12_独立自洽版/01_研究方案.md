# 风险调整赔率全公司排序研究方案

## 研究目标与唯一输出

对统一截止时点下的全部公司做连续排名，优先寻找可验证上行、估值缓冲和下行边界同时成立的公司。高质量但没有赔率、赔率很大但缺少兑现证据、或近期下跌仍未解释的公司均不得机械进入前列。

完整结果只能写入：

`D:\drive\Investment\基本面\分析报告\公司排序\01_暂时有效_核心\01_风险调整赔率_十二句话S03_原11\迭代版本\R10_2026-07-12_独立自洽版\02_排序结果.md`

不得创建或修改其他文件。

## 输入边界与时间截止

只能读取：

- `D:\drive\Investment\基本面\分析报告\公司评估\结果\`
- `D:\drive\Investment\基本面\日度资料\每日金融数据\`

不得读取公司调研、行业调研、任何排序结果、效果验证、特征量化、备份资料、外部网页或未列出的本地资料。

1. 选择执行时点以前日期最新、覆盖完整的每日金融主文件；“补充字段校验”文件只能与同日主文件合并。
2. 以主文件生成时间作为研究资料截止时点，以主文件披露的最新价格日期作为价格截止日，两者必须分别记录。
3. 样本池为主文件列出的全部公司。每家公司只使用研究资料截止时点以前最新的一份正式公司评估；缺失公司仍保留。
4. 区间价格和估值变化只能由价格截止日及以前的每日金融文件计算。禁止读取任何更晚文件。
5. 收益必须采用可确认的复权口径；不能确认时将相关价格项设为中性并降低置信度。

## 统一评分

八项分数均为0–100分，并附一句可追溯证据：

| 分项 | 权重 | 判定重点 |
|---|---:|---|
| 上行质量 | 18% | 基准与乐观情景的收入、利润、FCF及其证据链 |
| 下行边界 | 16% | 悲观情景、估值安全边际、流动性和资产负债表 |
| 财务韧性 | 12% | 毛利率、经营杠杆、现金转化、融资和稀释 |
| 估值缓冲 | 15% | 当前及基准情景下的P/S、Forward PE、EV/EBITDA和FCF收益率 |
| 负面触发控制 | 12% | 客户、订单、交付、验收、供应、监管及融资风险是否关闭 |
| 催化兑现 | 13% | 未来两个至四个季度可验证的订单、交付、产能、指引或财报节点 |
| 假设稳健性 | 9% | 上行路径依赖的未验证关键条件数量及相互依赖程度 |
| 资料完整性 | 5% | 日期、字段、币种、ADR、估值校验和证据可追溯性 |

`基础分 = 0.18×上行质量 + 0.16×下行边界 + 0.12×财务韧性 + 0.15×估值缓冲 + 0.12×负面触发控制 + 0.13×催化兑现 + 0.09×假设稳健性 + 0.05×资料完整性`

## 价格确认调整

从排序日前真实5日和20日复权收益构造价格状态，价格只验证基本面，不替代基本面：

- 20日收益位于全样本前40%、5日收益不在后30%，且存在可验证经营改善或催化兑现：加6分；两类证据同时成立再加4分。
- 20日收益位于后30%：扣6分；若评估中没有可验证的风险出清、错杀解释或经营缓释，再扣4分。
- 价格上涨但没有基本面桥梁，或价格下跌已有充分且量化的暂时性解释：调整为0分并标记冲突。
- 价格数据不足、疑似拆股或复权口径不明：调整为0分并降低资料完整性。

`综合分 = 截断到0–100的（基础分 + 价格确认调整）`

## 前排门槛与冲突处理

- Top20要求下行边界不低于55、负面触发控制不低于50，且不能同时存在两项未解除核心风险。
- 基准情景需要紧急融资、重大稀释或多个未验证客户条件同时成立时，最高进入中段。
- 同一事实造成财务韧性、负面触发和假设脆弱时，只保留一个主导扣分，其他项仅作说明。
- 近期下跌只有在来源、传导路径、时间窗口和出清证据都清楚时才可视为赔率改善。
- 不得按公司名称、代码、行业标签或目录分类直接加减分。

## 执行与输出

先逐公司形成评分卡，再做横截面排序和相邻名次复核。不得根据初排结果临时改变权重、门槛或价格规则。

结果必须包含：输入审计、主快照与价格截止日、输入资料覆盖率、Top20、Bottom20、完整连续排名，以及排名、代码、公司、综合分、八项分数、5/20日收益、价格状态、估值、上行证据、下行边界、核心反证、实际使用文件、资料冲突、冲突合并、资料缺口、置信度和一句排序理由。

文末记录所有输入文件、缺失比例、复权口径、封顶数量和规则执行检查，以便按该生成时点开展后续未见样本验证。
