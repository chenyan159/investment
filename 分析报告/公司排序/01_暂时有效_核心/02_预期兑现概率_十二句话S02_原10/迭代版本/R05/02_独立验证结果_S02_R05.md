# S02 R05 独立验证结果

验证日期：2026-06-10
验证对象：`S02_预期兑现概率 / R05`
验证窗口：`2026-05-29` 收盘至 `2026-06-09` 收盘

本报告只对 `R05` 排名结果做独立验证，不修改研究方案正文，也不生成下一轮研究方案正文。统计覆盖基准采用收益验证输入中的 `## 全公司明细`，前轮 `R04` 验证结果只用于判断本轮是否相对前轮改善。

## 结论摘要

`S02 R05` 覆盖层面合格，排名方向显著正确，且相对 `R04` 出现明显改善；但改善的主要来源不是“基本面预期兑现概率”本身，而是综合分、价格状态限位和尾部强惩罚。由于排名文件的 `价格状态校验` 列嵌入了验证窗口涨跌幅，且该列与收益验证文件 `180/180` 完全一致，本轮有效性应判定为“统计结果明显改善，但含同窗价格吸收，独立基本面信号仍偏弱”。

- 覆盖结论：收益验证文件解析到 `180` 家公司，排名文件解析到 `180` 行、`180` 个唯一股票代号，排名 `1-180` 连续；重复股票 `0` 个，无法匹配收益股票 `0` 个，收益文件中有但排名没有的股票 `0` 个。
- 排名方向：有效方向应为“排名越靠前，验证期收益越高”。由于排名序号越小代表越靠前，所以“排名序号 vs 验证收益”的有效相关方向应为负值。R05 Pearson `-0.5901`、Spearman `-0.6316`、Kendall tau-b `-0.4529`，三项方向正确，且明显强于 R04 的 `-0.3098 / -0.3661 / -0.2496`。
- 综合分方向：有效方向应为“综合分越高，验证期收益越高”。R05 综合分与收益的 Pearson `+0.4468`、Spearman `+0.6280`、Kendall tau-b `+0.4578`，方向正确，也明显强于 R04 的 `+0.2844 / +0.3687 / +0.2519`。
- 机制拆解：基本面预期兑现概率与收益的 Pearson `+0.1437`、Spearman `+0.0776`、Kendall tau-b `+0.0484`，低于 R04 的 `+0.1738 / +0.2065 / +0.1385`。这说明 R05 的整体改善主要来自综合排序、价格状态限位和尾部惩罚，而不是预期兑现概率主变量本身增强。
- Top-Bottom 结论：Top10、Top20、Top30、Top50 相对对应 Bottom 组均为正差值；Top10-Bottom10 为 `+20.51pct`，组内双侧去极值后为 `+20.27pct`；Top50-Bottom50 为 `+10.99pct`，去极值后为 `+10.91pct`。四个层级均强于 R04。
- 分位结论：十分位不满足严格单调，主要破坏点为 `D2->D3, D3->D4, D5->D6`；五分位破坏点为 `Q2->Q3`。相比 R04，破坏点减少，尾部分层更清楚，但中段仍有反弹样本破坏单调。
- 极端样本结论：最大涨幅为 `MRVL +30.19%`，排名 `94`；最大跌幅为 `RKLB -24.58%`，排名 `173`。剔除两端极端样本后，排名相关性为 `-0.6138 / -0.6314 / -0.4532`，综合分相关性为 `+0.4570 / +0.6276 / +0.4579`，结果仍然成立，因此不是由单个极端样本独立驱动。

全样本最大涨幅 `MRVL +30.19%` 排名 `94`，最大跌幅 `RKLB -24.58%` 排名 `173`。剔除两端极端样本后，排名相关性和综合分相关性仍保持方向正确，且排名 Pearson 从 `-0.5901` 变为 `-0.6138`，综合分 Pearson 从 `+0.4468` 变为 `+0.4570`。这说明 R05 的正向统计结果不是由单个极端点独立驱动；极端点更多体现为一个被低估的强反弹样本和一个被正确压低的强回撤样本。

## 下一轮修改建议

本节只给抽象方法方向，不生成下一轮研究方案正文。

主要有效机制：

- R05 对尾部风险的识别明显改善，强回撤、拒绝、资料缺口和价格重置样本被压到后段，使 Bottom 组平均收益显著低于 Top 组。
- 综合分比单一基本面预期兑现概率更有效，说明“基本面主分 + 冲突处理 + 上限规则 + 价格状态粗校验”的组合比单纯叙事质量更接近短窗口验证结果。
- 分位结构在大层级上更清楚，Q4/Q5 与 D7-D10 明显弱于前段，说明尾部排除机制有效。

主要失效机制：

- `基本面预期兑现概率` 本身与收益相关性很弱，且弱于 R04；下一轮不能只强化这个标签的主观评分，而要把它拆成更短期、更可验证的事件路径。
- `价格状态校验` 直接嵌入同窗涨跌幅，并与验证收益完全一致；这会提高回测统计，但削弱独立验证意义。下一轮需要把价格使用限制为离散状态和冲突解释，避免把窗口收益数值本身写入可排序字段。
- Top 组绝对收益不强，Top10 仅接近持平；当前改进更多来自压低 Bottom，而不是捕捉最高收益。下一轮应提升前排的正向催化辨识，而不仅是尾部排雷。
- 中段不单调仍明显，D2-D6 和 Q2-Q3 的排序需要更强的二级判别，尤其要区分“基本面看起来强但验证窗口无催化”和“基本面分不高但已有短窗确认”的样本。

覆盖问题：

- 本轮无覆盖缺口：收益文件 `180` 家、排名文件 `180` 行全部匹配。
- `AMPX` 缺评估材料但被保留，处理方向正确；后续需要继续要求缺材料样本保留在排名中，并明确缺口类型、受影响字段和置信度折扣。
- 独立验证不能证明生成过程是否真的只读允许文件，只能证明排名文件的可见声明和输出结果没有明显越界文本证据。

下一轮抽象修改方向：

1. 将“预期兑现概率”拆成更硬的短窗事件链：订单/指引/交付/验收/收入确认/利润率/现金流，每个环节必须说明验证窗口内为何能或不能传导到股价。
2. 对价格状态做去数值化处理：允许使用确认、拒绝、强回撤、边际修复等离散标签，但不要在排序表中写入或计算同窗具体涨跌幅，避免验证收益复述。
3. 对前排样本增加“负面价格解释门槛”：高基本面样本若出现预期重置或拒绝，需要有可验证经营解释才能保留前排，否则应触发更严格的前排上限。
4. 对中后段强确认样本增加“修复质量判别”：区分一次性反弹、估值修复、订单/业绩催化和真实预期兑现，避免机械追涨，也避免系统性低估短窗催化。
5. 把 Top 组目标从“少跌于 Bottom”升级为“有明确正向催化”：Top10/Top20 应要求更高的短窗兑现密度，而不是仅依靠尾部更差来形成差值。
6. 保持不按公司名、股票代号、目录分类或具体行业标签制定硬规则；所有修正规则应围绕资料新鲜度、证据强度、兑现路径、价格冲突解释和置信度折扣等抽象变量。
