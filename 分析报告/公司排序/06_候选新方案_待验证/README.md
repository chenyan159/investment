## 共同输入原则

1. 样本池以同一份最新每日金融数据为准。
2. 每家公司只选截止日之前最新的一份正式公司评估，不混用同一公司的多个旧报告；N03 例外，需要最近两份同口径评估做变化比较。
3. 正式运行要求至少90%的公司评估距行情截止日不超过14天，且任何公司不超过30天；否则仍可生成预览榜，但必须标记为“输入未齐预览”，不得进入正式验证。
4. 不读取旧排序、旧回测或本目录其他候选结果，不使用选择性外部搜索。
5. 缺失字段不补想象分，只降低置信度或限制最高排名。
6. 当前3个月和6个月评估是排序生成前历史回看，不能证明有效性；必须从2026-07-13以后另建生成后评估目录。
