# S06_R03 全公司投资排序：信息质量门控 + 短窗确认

报告日期：2026-06-10

资料边界：本轮只读取 `分析报告/公司评估/` 下的直属正式公司 Markdown 文件，以及 `日度资料/每日金融数据/每日金融数据_2026-05-29.md`。未读取 `备份/`、验证收益、其他方案、旧排名、特征量化或外部网页。

样本范围：公司评估直属正式公司 `179` 家；2026-05-29 日度金融数据覆盖 `172` 家；日度缺口 `7` 家，分别为 `ASMVY`、`BESIY`、`IESC`、`EME`、`AAON`、`ATEYY`、`MYRG`。

本排序不是长期护城河排名，也不是价格目标。它只回答一个问题：在当前报告证据和 2026-05-29 价格/估值/IV 线索下，哪些公司最适合进入下一轮投资优先级。

## 评分框架

| 因子 | 权重 | 本轮执行口径 |
|---|---:|---|
| 信息质量门槛 | 14% | 只给收入、利润率、现金流、订单/RPO/backlog、客户、产能、指引、资产负债表等数字支持的证据加分；资料完整本身不推高排名。 |
| 近端验证 | 24% | 奖励一到三个报告周期内能复核的触发，例如 Q2/Q3 指引、订单/RPO、backlog 转收入、deferred revenue、毛利率、库存、现金流转换；同时要求日度数据中已有价格/估值/IV确认线索。 |
| 价格确认 | 18% | 使用 2026-05-29 日度文件中的价格日期、Forward PE、EV/EBITDA、P/S、IV 和异常备注；估值异常不自动淘汰，但要进入不确定性说明。 |
| 情景差异 | 14% | 奖励基准到乐观有足够差异且触发可解释的对象；只靠极度乐观叙事、不具备收入确认路径的弹性降权。 |
| 估值可解释性 | 10% | 估值字段越完整、经营报告越能解释收入/利润/FCF与估值的关系，分数越高；异常估值需要单列风险。 |
| 财务承受力 | 10% | 正利润、现金流、资产负债表和库存/应收/债务压力共同判断；负 EPS 或 FCF 前置压力降低承受力，但不机械淘汰。 |
| 异常弹性保留 | 10% | 对高 IV、高情景差异、小市值或事件型对象保留观察分，但必须有明确触发、价格敏感性和可承受下行；依赖单一叙事的对象只进观察档。 |

## 排序结论

第一档不是“资料最厚”的公司，而是信息质量、短窗触发和价格确认同时过线的公司。`PSIX`、`VISN`、`PENG`、`SANM`、`ET`、`JBL` 位居前列，原因分别是估值/IV确认较完整、经营触发可在下一到三个周期验证，且下行情景不完全依赖单一 AI 叙事。

AI 主线大票没有被排除，但多数进入 B 档而非榜首：`NVDA`、`AVGO`、`CEG`、`FIX`、`MU`、`VST`、`AMAT` 等的经营证据强，但价格确认、估值弹性或短窗超预期幅度已经部分反映在日度估值/IV里。

日度缺口对象保留为观察档，不机械压到底部。`AAON`、`ATEYY`、`EME` 等经营报告证据并不弱，但缺少 2026-05-29 价格、估值和 IV 行，因此不能进入核心前排；补齐日度行后应重新跑价格确认项。

估值异常对象也不机械归零。`SNDK`、`ENPH`、`SMCI`、`HPE`、`POWL` 等仍在前半区，是因为触发清楚且价格敏感；`OKLO`、`SMR`、`POET`、`NVTS` 等更依赖远期期权或估值字段异常，留在事件观察或暂缓档。
