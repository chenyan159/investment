# S08 R04 修改记录：反脆弱弹性

## R03 独立验证摘要

- R03 相对 R02 明显改善，整体方向从反向修复为弱正向。
- 总分 vs 收益 Pearson/Spearman/Kendall 约为 `0.089 / 0.129 / 0.098`，排名序号 vs 收益约为 `-0.136 / -0.129 / -0.097`，方向符合预期但强度仍弱。
- Top20、Top30、Top50 相对对应 Bottom 组合分别为 `+2.46pct`、`+2.70pct`、`+3.22pct`，但 Top10 仍为 `-2.77pct`。
- 分位收益不单调，最高排名组表现偏弱，说明前排门槛仍容易被强事实和高波动弹性突破。

## R04 修改方向

- R04 保留反脆弱弹性主线，但提高最前档价格确认、拥挤风险和融资风险过滤，防止 Top10 被未确认弹性占据。
- R04 把尾部脆弱拆成致命风险和可交易期权两类，避免把缺口或亏损标签直接等同于低收益。
- R04 对数据缺口做可解释性分层，缺少估值、波动或日度字段时降低确定性，但不直接压到末端。
- 下一轮仍只用公司评估与指定日度金融数据重新排序，不读取验证收益、旧排名、其他方案或特征量化结果。
