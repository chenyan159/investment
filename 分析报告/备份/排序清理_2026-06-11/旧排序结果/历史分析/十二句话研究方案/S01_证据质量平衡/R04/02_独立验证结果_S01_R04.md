# 独立验证结果：S01_证据质量平衡 R04

验证日期：2026-06-10。验证窗口：2026-05-29 收盘至 2026-06-09 收盘。

本验证只读取题设允许的四个输入文件：R04 研究方案、R04 排名、全公司收益验证文件、R03 独立验证结果；未读取其他方案目录、其他方案排名、其他方案验证报告、公司调研、行业调研、日度资料、特征量化目录或外部网页。R03 验证结果只用于判断本轮是否相对前轮改善。

## 结论摘要

- R04 排名覆盖完整：收益覆盖基准为 180 家，排名表解析到 180 行，匹配有效样本 180 家；名次连续，重复股票 0 个，排名缺失收益 0 个，收益有但排名没有 0 个。
- 方向有效：名次数字越小代表越靠前，因此名次与验证收益的有效方向应为负相关。R04 名次与收益 Pearson -0.854、Spearman -0.915、Kendall tau-b -0.751。
- 综合分有效：综合分越高，验证收益应越高。R04 综合分与收益 Pearson 0.792、Spearman 0.916、Kendall tau-b 0.754。
- 相对 R03 明显改善：R03 名次三项相关性为 -0.733/-0.742/-0.558，R04 绝对值均提高；R03 综合分三项相关性为 0.634/0.742/0.560，R04 均提高。
- Top-Bottom 全部为正：Top10/20/30/50 相对 Bottom 组平均收益差分别为 +27.94、+25.70、+22.26、+17.43 个百分点；组内双侧去极值后分别为 +28.22、+24.98、+21.48、+16.22 个百分点。
- 分位结果强：十分位与五分位平均收益均按排名从前到后单调下降，未出现 R03 的后段分位反弹。
- 极端样本不是唯一驱动：剔除全样本最高收益 MRVL +30.19% 与最低收益 RKLB -24.58% 后，名次 Spearman 为 -0.915，综合分 Spearman 为 0.916，结果没有塌陷。
- 关键限制：R04 排名文件明确使用同一窗口价格作为验证、限高、置信度和异常标记输入，因此本轮统计更能证明“排序规则与同窗口价格确认/反证高度一致”，不能解释为独立样本外预测能力。

## 下一轮修改建议

1. 保留全覆盖、名次连续、抽象变量评分和资料缺口单独标记。R04 在覆盖、相关性、Top-Bottom、十分位和五分位上均表现强，说明基础框架有效。
2. 把同窗口价格从“排序校准”进一步拆成“验证标签”和“冲突诊断标签”。当前价格确认/反证进入分数和排序上限后，同窗验证会天然很强；下一轮若要检验预测能力，应引入滞后窗口、训练窗口或完全留出的验证窗口。
3. 降低价格档位对排序的机械拟合风险，但保留负向反证的抽象处理。可调整价格阈值、校准项上限、负收益连续惩罚斜率和观察层规则，不应使用公司名、股票代号、目录分类或具体行业标签补丁。
4. 对轻微负收益和中性负收益边界做更细的置信度处理。Top50 的负收益反例主要集中在 -3.57% 到 -0.12%，说明这些边界样本仍需要更清楚地标记“短期价格冲突未完全消除”。
5. 对后半段正收益反例，只从抽象变量复核资料缺口惩罚、估值约束折扣和价格确认可追溯性；不得要求下一版方案点名处理 PH、TMO 或任何具体公司。
6. 后续验证报告应继续固定输出覆盖匹配、名次/综合分相关性、Top-Bottom、组内去极值、十分位/五分位、剔除极端样本和相对前轮变化，确保迭代改动可比较。
