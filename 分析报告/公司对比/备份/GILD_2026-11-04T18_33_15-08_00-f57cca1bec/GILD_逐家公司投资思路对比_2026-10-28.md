# 吉利德科学（Gilead Sciences，GILD）：综合投资评估、上游复核与跨公司比较报告

## 0. 执行摘要：有独立价值，现价的配置顺位尚不足以支持核心建仓

**稳健基准定位：条件性等待。高风险高收益定位：小仓位／期权式参与候选。近端行动：等待价格或经营与支付双重验证；中期判断：HIV现金平台仍值得跟踪和有条件持有。** 以统一参考价159.08美元买入、持有至2029年末，基准预计交易价194.4～217.2美元，股价年化约6.5%～10.3%；加模型期间现金股息11.14美元，年化约8.4%～12.0%。这是一项可成立的股票回报，安全边际却不足以支持把尚待验证的LEN患者年、Medicare净价和肿瘤接续全部视为确定收益。谨慎长期DCF折回今日约139美元，悲观交易价仍可能造成约26%～41%的价格损失。

**GILD在13只证券的稳健配置研究顺位居第五，前面是MSFT、Visa、REGN、MCK。** 这是一项基于证据、现金与买价的研究取舍，不是加权评分或个人组合最优权重。在“成熟现金流＋创新药选择权”大类中，REGN是更优替代；跨行业核心资金优先比较MSFT、Visa。MCK在降低单药专利风险的稳健侧胜出。GILD仍有独特的HIV治疗及长效预防敞口，REGN或支付网络不能复制这一特定收益来源；但本比较集没有覆盖GSK的完整公司模型，不能据此宣布GILD是全市场所有HIV证券中的绝对首选。

**高弹性投资者可以保留小额普通股参与权，当前也没有必要为财报前高波动率支付过高的期权费。** LEN扩大此前未持续获得保护的人群、Trodelvy前移和anito-cel商业化，构成有机制的上行；突破交易价350.0～428.3美元尚需多步兑现，不能作为核心仓的基准收益。现阶段更好的稳健介入带是140～150美元且基本面未恶化；另一入口是Q3/Q4真实需求与MFP净影响同时得到确认、实际买价仍不高于约160美元。若先涨至175美元而经营路径未上修，基准含息年化会降至约5%～9%，等待确有机会成本。

核心证伪线是：**HIV治疗的份额和净变现共同持续受损；LEN增长未形成总PrEP净增且成熟回访恶化；持续外购资本使原本能够自给的现金平台转成结构性融资缺口。** 第四章把这三条转成可量化退出条件。一次库存调整或单项研发失败不等于三条红线已经触发。

**肿瘤交付与购入回报。** JNJ已披露Q3 Carvykti 0.710bn、同比35.5%，验证BCMA存在可付费市场，也提高anito的竞争门槛；GILD旧CAR-T下滑14%，不宜归因于全行业没有需求。[S12] anito临床制造的最终成功率不等于商业首轮放行率，初始四线标签也不等于早线自动获批。GILD收购前已经持有美国部分利润权益，新增约6.4bn净现金购入必须与**新增**权益回报比较，不能用全部未来销售证明这笔新增资本便宜。基准1.10bn规模可保留，突破3.10bn必须继续接受中心吞吐、商业成本与早线竞争检验。[S02][S15]

TMO的研发、临床和制造收费说明客户为创新还要持续支付服务资本；MCK控制大量分销与准入工作流但没有取得所有药物利润。未获得可证明GILD必须向某家供方购买特定数量的完整合同，因此不编造API产能配额、交期涨价或最低采购保障。TMO只是已覆盖的广义上游机会成本，不是已证实的GILD独家瓶颈供应商。

### 1.5 风险去重、DCF与交易倍数：本次为什么不把基准价上调

上游已经将医保净价写入治疗收入、内部替代写入PrEP、临床与商业成本写入费用，再预留未来外购现金；主DCF四行同用8% WACC，未对悲观额外任意加高折现率。**未发现行业、公司和情景层把同一竞争风险重复扣三次的具体证据。** 同样，已付收购、未来管线预算和正常研发是三个不同对象，不能为了“去重”把后两项一起加回。

本次不改变目标日交易倍数：悲观12～15x、基准17～19x、乐观19～23x、突破22～27x EV/NOPAT。独立商业理由分别是持续净价/份额受损、成熟现金与中个位数增长、已验证新产品形成更快增长、以及2030以后仍有接续的跨产品平台。横截面上，它们位于受LOE影响的MRK、成熟现金AMGN，与有较长增长窗的JNJ/创新平台之间；对REGN要先清理SBC与金融资产，不能直接把其12～15x SBC前目标倍数照搬GILD。**没有以DCF除目标利润倒推这组市场倍数。**

GILD的2029基准剩余DCF为167.6美元，低于194.4～217.2交易区间；差额对应约34～62bn企业价值，需要市场对专利后接续、超额增长持续期有更强判断。DCF并非硬封顶，但这份溢价也不是已经证明的经营现金。因此本次选择限制配置，而不是为保持“可买”结论去抬经营量或强压长期折现率。

固定当前19.336x的业务价约221.0美元，与基准交易价的差距明确显示：正常经营及降债创造上行，目标倍数回落17～19x会吃掉其中一部分。原固定18x业务价205.8也有参考价值，但它已经含起点向正常锚回归，不能把全部29.4%都叫严格“不变当前倍数”的纯业务收益。两种表达的变更是计算口径校准，未出现新的现金收入。

DCF的基准2030～2040显式现金及终值假设继续保留。8% WACC、2%终值增长下167.6；上游同一现金路径在7%／9%、g＝2%下约198.6／145.4，说明长期价值对资金要求敏感。新FOMC决定没有提供把WACC机械调低的理由；也没有理由在已受损的经营路径上重复施加利率惩罚。

MCK是GILD真实分销生态中的参与者。它不取得HIV分子的全部租金，却可从大量品类补货、专科诊所、准入及服务附着收费；药品货值收入不能当可留利润。FY2026收入403.430、调整利润6.465；Owner FCF5.127再扣向少数股东现金0.189，普通股经济现金约4.938。回购4.750和分红0.381已超过这一金额，收购另需融资，不能把每股增速全部叫经营复利。

MCK当前正常化归母P/E约21.7x，FY2030基准EPS62.6和Owner FCF5.94需要专科服务持续扩张、正常供应商信用与已购平台回报。相较GILD，单药失败不会击穿全部分销收入；相较普通低风险物流，它又承担极薄费率、客户集中、账期和少数权益。FY2030边界保留MMS权益而不假设免费分发新股，潜在IPO不能凭空加一笔收益。现金周转恶化时会放大融资需求，不能把负营运资本的高ROIC当永恒护城河。

**稳健：MCK占优；高弹：GILD占优；综合分视角各占胜场。** 用3.425年计算后，MCK基准CAGR仍较好、下行情景较浅；想降低专利接续风险的核心医疗资金优先MCK。若目标是LEN扩大覆盖、早线肿瘤乃至新ADC成功产生的边际利润，GILD保留更多分子权益，右尾略优。两者持有可分散价值链风险，不应把同一药费增长算成两家公司都无限提费。

### 3.11 GILD对UNH：支付方入口与制造商创新利润并非同向无风险

本节经营与条件模型底稿：[正式公司报告](../../../基本面/公司调研/结果/医疗器械_诊断_医疗服务/UNH_UnitedHealth_联合健康_公司调研_2026-10-28.md)、[正式情景报告](../../公司情景投资决策/结果/UNH_经营情景市场状态投资决策_2026-10-28.md)。

UNH能够通过保险预算、PBM及医疗组织影响患者选择与净价，这对GILD可支付采用的约束比制造吨位更直接。Q3医疗赔付率88.4%，含0.610bn有利准备金发展，剔此项约89.1%；Optum Health调整利润率2.6%，说明修复有实绩但尚未回到无需验证的稳态。GILD的长效预防若减少感染及后续治疗，有机会创造支付价值，但不能假设支付方将全部节约交给厂家。

UNH调整P/E按20.50指引下限约20.0x，不用EV/NOPAT把大量保险现金都当可自由分配资产。6月底28.6bn现金中可一般公司使用仅约1.1bn，9月底总债74.331；母公司资本约束显著。2029基准EPS31.18要求跨年价格—赔款差、风险医疗和药房收费结构共同改善，证据为中；高弹上行来自利润率修复，机制比单纯总会员增长更有力，也更易受精算和政策反噬。

**稳健：GILD占优；高弹：UNH占优；综合分视角各占胜场。** UNH的基准和突破数字很有吸引力，但同样数字的证据确定性、可用现金与已实现经营安全垫较弱。高风险资金可优先研究UNH修复；稳健资金不应把“下游更有议价权”直接等同更安全的资产负债表。若价格—成本差经两季验证、Health盈利可持续，它的稳健顺位可以提高。

### 3.12 GILD对MSFT：必须跨过的全市场机会成本

本节经营与条件模型底稿：[正式公司报告](../../../基本面/公司调研/结果/云算力_IDC_边缘云/MSFT_微软_公司调研_2026-10-22.md)、[正式情景报告](../../公司情景投资决策/结果/MSFT_经营情景市场状态投资决策_2026-10-22.md)。

微软不争夺药物市场，本比较检验的是相同资金能否买到更高的风险调整后经营复利。FY26经营利润155.237、NOPAT按20%税约124.190，成熟软件续约、企业采购与云交付是较强基础；当前正常化EV/NOPAT约31.9x高于GILD，但FY29基准NOPAT/股27.06相对起点增长更快，观察日还短至2029-06-30。将两者都说“三年目标”或只比较累计上行会掩盖这项优势。

微软的真实约束也更重：FY26 CFO182.935−现金PP&E115.948−SBC12.405−融资租赁本金3.101＝Owner FCF51.481，低于此前水平。AI采购义务、单位任务净收费、折旧与新设备周转，是它必须支付的增长成本，不能只看RPO。GILD的研发现金负担较稳定，近期现金收益率更高，持有它可降低AI资本周期敞口；但这项分散价值没有使GILD的基准总回报自动超过微软。10/28盘后FY27Q1尚未发生，不把预测当实际。

**稳健：MSFT占优；高弹：MSFT占优；综合对手占优。** 在531.33价格、约2.67年窗口，基准815.5～923.7的CAGR明显高于GILD；突破亦更高。该取舍以软件续约及完整资本回收不失效为条件。若AI再投资长期无法形成经济现金、净收费权持续受损，微软的比较优势必须撤销；当前资料仍足以让它排在GILD之前。

### 3.13 GILD对Visa：成熟收费复利更优，临床右尾仍归GILD

本节经营与条件模型底稿：[正式公司报告](../../../基本面/公司调研/结果/金融服务_支付_资本市场/V_Visa_维萨_公司调研_2026-10-28.md)、[正式情景报告](../../公司情景投资决策/结果/V_经营情景市场状态投资决策_2026-10-28.md)。

Visa不承担持卡人贷款的主要信用风险，核心是网络、处理、信任和VAS净收费。FY2026净收入45.903，VAS约14.0；支付量和新服务能形成持续收费，但客户激励18.317、Q4激励增长21%、FY27约25%支付额进入续约，说明银行和平台的议价是真约束。稳定币结算额不等于Visa收入，代理交易也可能只是旧交易改由机器执行。

FY2026 Owner FCF可核部分21.129减未知租赁调整L，而回购及股息合计25.563，不能当作所有资本分配都由当年自由现金流自给。净债约7.894、TBV负值也不能宣传现金硬底。即便如此，较低实物CapEx、可复制网络及净收费的证据仍强于GILD对未来部分新品量价的把握。按401.86前收而非393.49盘前买价重算，当前EV/NOPAT约31.45x，回报必须随实际更高买价下调。

**稳健：Visa占优；高弹：GILD占优；综合分视角各占胜场。** Visa基准534.7～592.7在约2.927年内对应较高年化，适合优先占用成熟复利仓位；GILD突破可达当前约2.7倍，临床与支付成功时的非线性上行更强。Visa也有反垄断、路由和续约净价红线，绝不是靠高ROE便可以忽视价格的无风险替代。

## 4. 六个视角收束为分层行动：等什么、买多少、何时退出

### 4.1 六个维度的边际权衡

**近期兑现与长期壁垒要分开。** HIV现金、已批准产品和真实临床路线支持中远期持有逻辑；Q3共识却并不低，本模型收入中心略低于公开预期。投资者不能把“公司会继续卖药”当作未来两季高把握上修催化。近端归类为**需等待净需求、指引及医保变量验证**，不是强正向催化，也不是已确认经营下滑。

**业务复利与价格回报也要分开。** 保持当前19.336x的基准业务参考价约221美元，经营增长与降债都在创造权益；17～19x交易定价回落，会使投资者最终只取得194～217。这种回落有目标日更接近专利接续、成熟治疗斜率与横截面依据，未假设无条件腰斩。若到目标日LEN与肿瘤仍在强增长，应转向乐观较高倍数，不能在好事实出现后机械坚持低价。

**右尾有价值，却不是最优进攻载体。** GILD的LEN首先需要更多付费保护时间，肿瘤需要更早线及可重复交付；实现后具有明显利润杠杆，突破不是题材泡沫。它也没有稀缺原料涨价、产能刚释放即可数倍利润跳跃的已锁定机制。REGN、VRTX、MSFT在不同证据边界下提供更强弹性，UNH/BNTX则更偏修复或临床期权。因此GILD适合小风险预算保留选择权，不适合以“临床可能成功”作为进攻核心的唯一论据。

**下行韧性足以避免融资成为中心风险，不足以保本。** 核心悲观2029仍有FCFE9.15、利息覆盖约12.6倍，没有迫近的生存型股权融资假设；但6月净债23.07、TBV约−10.52bn／−8.48美元每实股，说明保护来自药品现金而非清算资产。若持续做大收购，流动性判断会改变。不能同时假设股息、回购、并购都不受约束。

**相对配置不否认绝对价值。** 本次完整稳健研究顺位为：**MSFT、Visa、REGN、MCK、GILD、VRTX、TMO、ABBV、JNJ、AMGN、UNH、MRK、BNTX**。这是当前证据下的执行顺序；单公司情景既非完整概率分布，也不构成可据此计算的确定组合最优解。GILD相对MRK/JNJ/AMGN更好，不代表必须比它们更早买；有REGN等更优机会成本时，现金仍可等待更有补偿的GILD买价。

### 4.4 三条必须退出原投资逻辑的红线

以下是本研究框架中的退出条件，不是价格技术止损，也不是声称公司债券契约规定这些阈值。一旦满足，退出原“现金底盘＋可付费扩张”的投资论点，只有完成全新受损资产研究后才可重新进入。

- **核心现金租金永久侵蚀：** 连续两个完整季度HIV治疗可比净收入同比下降至少8%，同时公司/竞争者处方或份额证据确认持续流失，且无法由单季库存或已建模医保时点解释；或新的主要专利/支付决定使可留现金的损失远超现有压力模型。需要“量价机制证实”而非只观察一个收入差值。
- **预防净增逻辑被推翻：** 有足够分母的成熟队列六个月实际回访持续低于60%，同时总PrEP连续两季不增长、LEN增量主要是Descovy等额搬移，且准入改善未能修复。若发生适用于核心产品的重大安全或监管限制，直接重估，不能以其他早期管线掩盖失去的付费保护时间。
- **资本纪律转为结构融资依赖：** 经常性经济股东经营现金运行率降至年6bn以下，新增高额购入又使净债／正常化EBITDA超过3.5x，并出现为覆盖刚性资金缺口需要大幅低价股权融资或实质性债务/流动性违约。单独并购公告不自动等同毁损，三者的现金传导必须核实；一旦确证即退出，不能继续以历史现金牛身份豁免。

MFP年损失超过1.2bn但有部分量补偿，首先触发模型下修及暂停加仓；它不单独等同上述全部硬红线。anito延期6～12个月或单项ADC失败亦先删对应分支，不能自动将整个HIV平台估成零，也不能假装对突破概率没有影响。

### A1. 可复算公式及GILD关键调整

```text
T_i = (各公司目标日 - 2026-10-27) / 365.25
价格回报 = 目标交易价 / 统一参考价 - 1
CAGR = (目标交易价 / 统一参考价)^(1/T_i) - 1
GILD含息年化 = ((目标交易价 + 模型累计现金股息) / 实际买价)^(1/T_GILD) - 1

GILD固定当前倍数 M0 = (159.08×1.254 + 23.067) / 11.51 = 19.336x
business_price_s = (M0×NOPAT_2029,s - 净债务_2029,s) / 1.254
target_price_s = (目标交易倍数_s×NOPAT_2029,s - 净债务_2029,s) / 1.254
```
