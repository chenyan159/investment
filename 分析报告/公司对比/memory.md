# 公司对比研究方案迭代记忆

更新时间：2026-07-13。

本文记录 `研究方案.md` 的设计决策、迭代原因、验证结果、未解决问题和下一轮跟进事项。它不是正式研究方案，也不是公司对比任务的研究资料；执行公司对比时仍只以 `研究方案.md` 及其中列明的上游资料为准，不应读取本文形成投资判断。

正式方案必须始终保持独立、完整和连贯。历史原因、旧版规则、实验名称和验证过程只写在本文，不回填到正式方案。

## 1. 当前正式基线

当前正式文件：[`研究方案.md`](研究方案.md)

当前方案的核心结构如下：

- 对每个目标公司，逐一与公司全集内其他公司比较，形成完整横评表。
- 正反方向分别研究、分别保留，不复用反向报告的胜负判断，以保留未来测试与偏置分析所需的数据。
- 六个维度都是独立而全面的投资哲学，不是六项局部指标，也不通过固定权重、打分或多数票生成结论。
- 一家公司如果确实足够优秀，可以在多个维度同时获胜；维度差异不能靠人为制造。
- 六种投资哲学为：近端兑现驱动、长期复利质量、价格赔率、防守资本保全、爆发增长与产业突破、市场定价错位。
- 总体风险调整判断统一假设持有8—16个月，但不是第七个维度。
- 近端兑现仍可使用约6—18个月的经营兑现窗口；长期复利使用约3—5年窗口。不同哲学保留自己的时间逻辑。
- 日度资料只用于最新股价、最新估值和当前市场状态，不读取过去3个月或6个月的股价路径。
- 执行时只允许读取方案列明的公司评估、公司调研、行业调研和日度资料，不读取公司对比、公司排序、备份、tmp或其他未授权目录。

### 当前最新方法改动

每个维度先完成双方基础研究并形成初步判断，再找出真正决定胜负的一至两个变量，对双方使用相同问题、时间范围、定义、会计口径和证据层级进行成对补证，最后重新判断。

价格赔率、市场定价错位和总体风险调整判断共用盈利与现金流归一化基础。归一化聚焦未来8—16个月可持续、可归属于普通股股东并能转化为每股价值的经济成果，处理GAAP与non-GAAP、股权激励、一次性项目、稀释、周期峰谷、必要资本开支、净债务、融资成本和外部融资等差异。

这两项改动已写入正式方案，但尚未经过新一轮全公司结果验证。

## 2. 已确认的设计原则

### 2.1 保留六种完整投资哲学

维度的作用是让同一对公司分别接受六套完整投资逻辑，而不是把业务、估值、风险等拆成局部评分。六维之间允许相关，也允许同一家公司连续获胜；需要避免的是同一理由机械复制六次，而不是追求形式上的不同结果。

### 2.2 保留正反方向独立研究

同一对公司的两个方向必须继续独立生成和保存。不能把一个方向的结论直接投影到反向报告，也不建立只判断一次的 canonical pair ledger。完整的正反数据是识别目标公司偏置、挑战者偏置和证据解释漂移的必要条件。

共享同一事实口径、使用成对补证或盈利归一化，不等于共享胜负判断。前者用于减少无意义的输入噪声，后者仍由每份报告独立完成。

### 2.3 不把历史价格路径作为公司对比输入

过去3个月和6个月股价变动曾用于评价旧结果，但不应进入新的公司对比研究。历史价格容易把趋势、反转或事后表现混入基本面相对选择，也会使市场定价错位维度退化为价格路径解释。

公司对比只读取最新股价、最新估值和当前市场状态。过去股价表现可以在报告生成后的有效性验证中使用，不能成为报告生成时的输入。

### 2.4 不使用机械化补丁

不采用固定分数、固定权重、强制机器前缀、标签交换口号、提高挑战者获胜门槛或大量A/B位置说明。研究员被假设为高度专业，应提供清楚的目标、边界和判断结构，同时保留合理探索空间。

### 2.5 股东价值捕获是爆发逻辑的必要条件

收入、订单、TAM或产业瓶颈的爆发，必须继续传导到扣除资本开支、营运资金、融资和稀释后的每股利润、每股自由现金流或每股内在价值。业务规模爆发不自动等于股票具有爆发赔率。

## 3. 迭代历史

### 3.1 初始八种投资思路与首轮小样本

公司对比最初采用八种独立投资思路，并以少量公司测试。早期结果暴露出两个问题：不同思路的结论差异不够大；以某家公司为目标生成的报告容易围绕该公司组织证据，正反方向之间不稳定。

这一阶段确认了“逐家公司横评表”和“每种思路都给出最终投资选择”的基本产物，但八种思路存在重叠，方案随后重构为六种更完整的投资哲学。

### 3.2 2026-06-23：189家公司全量运行

旧版全量结果共覆盖189家公司、17,766个无序公司组合。综合分析记录：

- 最终选择双向冲突7,407组，占41.7%。
- 八种投资思路共有142,128个双向镜像单元，其中108,398个不一致，占76.3%。
- 结果可以作为偏好信号和排序素材，但不能把任一单向报告直接视为稳定的两两结论。

当时曾提出“同一对公司只判断一次再反向复用”的解决方式，后来明确放弃，因为它会消除正反方向实验数据，无法继续测量研究过程本身的偏置。

历史分析文件：[`全部公司对比结果_综合分析_2026-06-23.md`](全部公司对比结果_综合分析_2026-06-23.md)

### 3.3 六维重构

八种思路被重构为六种完整投资哲学，并完成以下调整：

- 用更中性的整体叙事替代不断追加A/B位置说明。
- 明确六个维度各自的主导问题，但不要求刻意产生不同胜方。
- 加入爆发增长与产业突破，并强化股东价值捕获。
- 删除过去3个月和6个月股价路径。
- 删除非核心的时间边界、推荐输出、质量控制、冻结、后续验证等冗余章节，使正式方案重新聚焦逐家公司横评。

### 3.4 2026-07-13：三版八家公司对照

对MU、TSM、ADBE、DHR、CEG、PNR、BABA和NVDA进行了三版对照。每版8份报告、每份191个对手，共1,528个有向比较行。

| 版本 | 主要差异 |
| --- | --- |
| V1 | 仍包含过去3个月和6个月行情路径的旧方案 |
| V2 | 删除行情路径，采用中性叙事、六维边界和股东价值捕获 |
| V3 | 在V2基础上增加同截止日、同口径、相当证据深度，不可比则降置信；总体期限固定为8—16个月 |

公司层级排名的Spearman相关：

- V1与V2：0.714。
- V2与V3：0.976。
- V1与V3：0.595。

V2到V3的逐行总体判断中，71.3%完全相同；如果两版都给出明确胜方，96.0%选择同一家公司；只有39/1,528行发生胜方直接反转。V3主要改变了结论强度和“胜方/接近”边界，没有随机重排公司。

### 3.5 六维差异化的改善

V2到V3：

| 观察项 | V2 | V3 |
| --- | ---: | ---: |
| 近端兑现与爆发突破选择同一胜方 | 88.7% | 86.4% |
| 长期复利与防守保全选择同一胜方 | 88.6% | 81.8% |
| 价格赔率与定价错位选择同一胜方 | 91.8% | 90.0% |
| 一行中出现不同维度胜方 | 67.7% | 73.2% |
| 六维全部选择同一胜方 | 20.1% | 12.8% |

这说明六维边界和8—16个月总体口径提高了维度分工，尤其拉开了长期复利与防守保全。当前没有证据支持继续删除或合并六维。

### 3.6 尚未解决的方向偏置

八家公司形成28个同时存在正反报告的无序组合。总体判断如下：

| 结果类型 | V1 | V2 | V3 |
| --- | ---: | ---: | ---: |
| 两个方向选择同一家公司 | 9 | 9 | 6 |
| 两个方向都选择对方 | 0 | 6 | 10 |
| 一个方向明确、另一个方向接近 | 18 | 12 | 12 |
| 两个方向都接近 | 1 | 1 | 0 |

V3的10组冲突全部是“两个方向都选择对方”，没有出现两个方向都选择目标公司。这表明早期目标公司倾向并未被真正的角色中性取代，而是演化成挑战者倾向。

价格赔率和市场定价错位最不稳定：V3中两者各有17/28组出现“双向都选择对方”。典型原因不是缺少同日价格，而是同一事实在不同报告中采用了不同解释，例如低Forward P/E有时被解释为安全边际，有时被解释为周期峰值陷阱。

## 4. 当前改动的选择与理由

### 4.1 已采用：决定性变量成对补证

本轮没有建立覆盖全部公司的统一事实卡，而是采用成本更低、改动更集中的方法：先形成初步判断，只对真正决定胜负的一至两个变量进行成对补证，再重新判断。

选择这一方法的原因：

- 保留正反报告完全独立。
- 不要求为每份报告重新制作191家公司的完整绝对判断。
- 直接针对“同一关键事实被两种口径解释”的问题。
- 可以自然融入研究流程，不需要增加大量角色中性措辞。

已知局限：研究员对“什么是决定性变量”的初步选择本身仍可能受目标公司叙事影响。因此，本轮必须验证决定性变量是否在正反报告中更趋一致；若无改善，再考虑更强的事实层统一。

### 4.2 已采用：盈利与现金流归一化

归一化同时服务价格赔率、市场定价错位和总体风险调整判断，但三者用途不同：

- 价格赔率：用归一化经济成果建立悲观、基准和乐观收益分布。
- 市场定价错位：比较当前价格隐含的归一化预期与证据支持的基准之间是否存在可纠正偏差。
- 总体判断：在统一8—16个月持有期下比较预期回报、兑现概率和永久损失风险。

归一化不是固定一条公式。研究员可以根据商业模式选择每股盈利、每股自由现金流或其他更合适的经济指标，但同一对公司必须使用经济含义相当的口径。

### 4.3 暂未采用的候选方法

| 方法 | 当前判断 |
| --- | --- |
| 统一公司事实基准卡，事实层统一、判断层独立 | 理论上最强，但维护和运行成本较高；如果成对补证无效，这是优先候选 |
| 每份报告先做双方完整绝对判断，再相对比较 | 能减少为比较而组织理由，但全量运行成本过高，适合小样本实验 |
| 对双向冲突进行第三次独立复核 | 可产生可用的最终结论，但只修复结果使用，不修复原始报告偏置；适合作为验证层 |
| 匿名标签或随机先后顺序 | 成本低但作用有限，不能解决证据深度和盈利口径差异 |
| 提高挑战者获胜门槛 | 明确排除；会把挑战者偏置反转为目标公司偏置 |
| 同一公司对只判断一次并反向复用 | 明确排除；会破坏正反实验数据 |

## 6. 本轮完成后的验证清单

### 6.1 结果完整性

- 是否生成192份正式报告。
- 每份是否覆盖191家公司，是否存在缺行、重复公司、错误Ticker或列数不一致。
- 是否全部使用当前研究方案生成，旧报告是否安全备份。

### 6.2 方向一致性

- 统计18,336个无序组合的总体正反一致、双方都选对方、双方都选自己、一边明确一边接近、双方接近。
- 六个维度分别统计同样的正反关系。
- 单独观察价格赔率和市场定价错位是否显著低于V3八家公司样本的17/28冲突。
- 在相同八家公司子样本中，比较本轮与V3的10/28总体冲突，判断改动是否产生真实改善。

不能只看冲突是否下降。如果冲突下降完全来自大量改判为“接近”，而明确判断的信息量明显消失，也不能视为成功。应同时观察明确结论比例、置信度分布和真正同胜方比例。

### 6.3 决定性变量成对补证是否真正执行

重点抽查正反冲突组合以及MU、ADBE、NVDA、TSM、CEG等盈利结构差异较大的公司：

- 正反报告是否识别了相近的决定性变量。
- 同一变量是否使用相同时间范围、定义、会计口径和证据层级。
- 足以改变胜方的单边新增证据，是否对另一家公司完成同问题复核。
- 结论变化是否来自证据，而不是目标公司研究更深、对手摘要更干净。

### 6.4 盈利归一化是否有效

- 周期型公司是否区分当前、基准和周期正常化盈利。
- 软件公司是否统一处理GAAP、non-GAAP和股权激励。
- 资本密集型公司是否把必要资本开支、融资成本和稀释纳入每股价值。
- 价格赔率和定价错位是否基于同一事实口径，但仍回答不同问题。
- 低估值是否仍被直接等同于安全边际，高估值是否仍被机械等同于昂贵。

### 6.5 六维独立性

- 继续统计三对高相关维度和六维全同胜方比例。
- 允许真正优秀的公司在多个维度获胜，不以降低相关性本身作为优化目标。
- 检查理由是否体现不同哲学的主导问题，而不是同一句公司质量判断重复六次。

### 6.6 结果稳定性和投资含义

- 在相同公司交集上比较旧版189家公司全量结果、三版八家公司实验和本轮192家公司结果。
- 比较公司净胜排名、前20名、主要行业和典型风格的稳定性。
- 区分方法改变导致的合理迁移与角色、证据口径或资料缺失导致的随机迁移。

### 6.7 runner读取边界

BABA报告曾连续出现通配符未命中后返回其他工作区目录片段的情况。正式方案已经明确禁止读取未列目录；如果本轮仍发生，属于runner文件系统隔离问题，不应继续向研究方案追加提示词。应在runner层使用明确可读文件清单或隔离工作区解决。

## 7. 下一步决策规则

本轮结果出来后，按以下顺序决定是否继续修改：

1. 先确认结果完整和输入边界合规。
2. 再判断成对补证是否降低方向冲突，并排除“全部改成接近”的假改善。
3. 再判断盈利归一化是否改善价格赔率和市场定价错位。
4. 最后才讨论是否调整六维定义、增加统一事实卡或加入第三方冲突复核。

如果总体方向冲突和价格类维度冲突明显下降，同时维度差异与明确判断信息量得到保留，则保留当前方案继续扩大验证；如果冲突没有改善，优先尝试“统一事实基准卡＋独立判断”，而不是继续增加中性措辞。

## 8. 本文件的更新规则

每次修改 `研究方案.md` 后，在本文追加一条记录，至少包含：

- 修改日期和触发问题。
- 采用、暂缓或明确排除的方法。
- 正式方案的实质变化。
- 用于验证的公司样本或全量批次。
- 结果完整性、方向一致性、六维独立性和排名稳定性。
- 最终保留、继续观察、回退或重构的决定。

只记录能影响后续决策的信息，不把每次措辞调整写成版本。正式方案仍应能被一名不了解历史的专业研究员独立使用。
