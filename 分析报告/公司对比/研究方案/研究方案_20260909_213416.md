# 公司A逐家公司投资哲学横评方案

公司A股票代号：`【公司股票代号A】`

使用时只替换上一行。公司A是本次横评的目标公司，公司B是公司全集内逐行进入比较的其他公司；这两种称呼只用于组织任务和表格，实际研究始终将两家公司视为地位对称的投资候选。

## 1. 研究目标

将公司A与项目内其他所有公司逐一比较，分别站在六种完整投资哲学下判断谁更值得投资。

六个维度不是六项局部指标，也不是同一套总分的不同权重。每个维度都应独立使用完整的业务、行业、财务、估值、风险和价格信息，只是投资目标、持有逻辑和证据优先级不同。因此，同一对公司在不同维度下得出相反选择是正常结果。

本方案的核心产物是“公司A逐家公司横评表”：每一行是一家公司B，每一列是一种完整投资哲学，每个单元格都给出该哲学下的最终相对选择。

本方案以每个目标公司为中心独立运行。当另一家公司成为目标公司时，重新完成该方向的研究，不复用反向报告的判断。两个方向分别保留，用于后续检验。目标与对比身份只决定结果如何排列，不提供任何先验优势；双方始终使用相同的证据结构、反证要求和结论门槛。

## 2. 公司范围与研究资料

### 2.1 公司全集

1. 从 `分析报告/公司情景投资决策/结果/` 根层读取全部 `*_经营情景市场状态投资决策_*.md` 正式报告；该报告已经合并经营评估、价值传导、经营四情景和条件估值。
2. 同一Ticker存在多个版本时，使用日期最新的一份。
3. 公司A必须在公司全集中；公司B为全集中除公司A外的全部公司。
4. 不因公司难以比较或资料不足而省略。无法形成可靠判断时，在表中明确标记。

### 2.2 研究资料

- `分析报告/公司情景投资决策/结果/`：经营评估、收入与价值传导、经营情景、估值和公司全集。
- `基本面/公司调研/`：业务、产品、客户、订单、竞争、经营风险和反证。
- `基本面/行业调研/`：产业链位置、需求池、技术路线、供需、瓶颈和竞争格局。
- `金融资料/`：只读取最新股价、最新估值及当前市场状态。

除本研究方案本身外，研究执行过程中只允许读取上述四个正式资料目录。不得读取 `分析报告/公司对比/`、`分析报告/公司排序/`，也不得读取任何 `备份/`、`tmp/` 或其他未在本节列出的项目目录。

上述资料不足或过期时，可补充公司监管文件、财报、投资者关系材料、正式公告以及其他可靠一手来源。

## 3. 比较方法

对每一对公司，先分别完整理解双方的业务、增长、财务、估值、风险、价格和关键反证，再进入六种投资哲学。

每个维度在完成基础研究后，先形成初步相对判断，再围绕真正决定胜负的一至两个变量进行成对补证，最后给出最终选择。成对补证不是把全面研究重复一遍，而是把最可能左右胜负的证据放到可直接比较的基础上。

每个维度都按同一思考顺序完成：

1. 以同一截止日、同一口径和相同字段整理双方最重要的证据；
2. 分别找出各自最强的投资理由和最可能破坏逻辑的因素，形成初步判断；
3. 识别真正决定本维度相对胜负的一至两个变量，以及什么证据足以推翻初步判断；
4. 围绕这些变量，对双方提出相同问题，并按相同时间范围、定义、会计口径和证据层级补证；
5. 用补证后的结果重新检验初步判断，再根据实际Ticker作出选择，并说明结论强度和置信度。

任何足以改变胜方的新增证据，只有在另一家公司也完成同一决定性问题的复核后，才能用于最终选择。决定性变量无法使用经济含义相当的口径比较，或者补证后仍存在实质证据落差时，应降低置信度或判为接近，不得把资料深浅本身当作公司优劣。

价格赔率、市场定价错位和总体风险调整判断共用同一套盈利与现金流归一化基础。归一化的目标，是估计未来8—16个月内可持续、可归属于普通股股东并能转化为每股价值的经济成果，而不是直接接受数据商的Forward P/E或单期盈利。研究员可根据商业模式选择正常化每股盈利、每股自由现金流或其他更有解释力的指标，但同一对公司必须采用经济含义相当的口径，并明确处理GAAP与non-GAAP差异、股权激励、一次性项目、稀释股数、周期峰谷、必要资本开支、净债务、融资成本和外部融资稀释。周期型或资本密集型公司应区分当前、基准和周期正常化水平，避免把峰值盈利误作永久盈利，也避免把必要投入之外的短期低现金流误作永久缺陷。

完整研究不意味着各维度平均使用所有证据。每种哲学应让与其目标最相关的证据主导决策，其他证据主要承担验证、约束或否决作用。不得把某一维度的结论直接带入另一维度，也不得以六列多数票代替最终投资判断。

## 4. 可比关系

每一行先判断公司A与公司B的关系，再决定证据权重：

| 可比关系 | 比较重点 |
| --- | --- |
| 直接同业 | 份额、订单、客户、产品代际、交付、利润率和相对估值 |
| 相邻替代 | 增长质量、投资赔率、催化可见度和风险 |
| 上下游 | 利润池、议价权、紧急瓶颈、资本开支、客户集中和成本转嫁 |
| 跨赛道 | 股东收益分布、增长持续性、估值、资本效率和永久损失风险 |

可比关系可以改变证据权重，但不能改变某种投资哲学本身的目标。跨赛道比较应更重视股东回报和风险的可比性，减少对产品细节的机械类比。

## 5. 六种投资哲学

六种哲学的边界用于明确各自的主导问题，避免用同一理由机械复制六次，并不要求刻意制造不同结论。一家公司如果同时具备优质业务、可靠兑现、稳健财务和合理定价，完全可以在多个维度获胜；维度之间的相同或不同都必须来自证据本身。

### 5.1 近端兑现驱动型

目标是在未来约6—18个月内，选择经营结果最可能兑现并推动市场预期向上的公司。

本维度优先判断订单、RPO、backlog、客户项目、管理层指引、产能、认证、交付和收入确认能否转化为利润与自由现金流。近期事件只有在能够改变经营结果或预期修正方向时才有意义。

判断由基准情景的兑现概率及其对未来6—18个月经营结果的影响主导。巨大的远期空间可以增加吸引力，但不能替代同期可验证的商业传导和执行证据。

估值和下行风险在这里主要承担约束作用：兑现能力更强的一方通常胜出，但如果当前价格已经要求近乎完美的执行，或者失败会造成不可承受的损失，另一方可以更值得投资。

最终选择应回答：谁的基准情景更可能在近端兑现，并形成足够有吸引力的股东回报。

### 5.2 长期复利质量型

目标是在未来约3—5年内，选择每股内在价值更可能持续复合增长的公司。

本维度优先判断竞争优势、市场空间、份额演变、增量资本回报、再投资空间、产品迭代、客户粘性、管理层资本配置和股本稀释。高增长只有在能够长期转化为每股现金流和内在价值时才有意义。

本维度由未来3—5年的每股价值复合速度和持续性主导。短期催化、价格波动和一般性回撤不是主要依据；但估值过度透支、竞争优势衰减、再投资回报下降，或者足以破坏长期生存与复利能力的风险，可以否决一家表面优质的公司。

最终选择应回答：穿越多个经营周期后，谁更可能以更高质量、更可持续的方式创造股东价值。

### 5.3 价格赔率型

目标是从当前价格出发，选择未来股东收益分布更有吸引力的公司。

本维度以未来8—16个月正常化后的每股盈利、每股现金流或其他经济含义相当的指标为基础，建立悲观、基准和乐观情景，并综合合理估值、发生概率、净债务、融资、股本稀释和资本开支。重点不在于谁的公司质量绝对更高，而在于当前价格分别要求什么，以及上行空间是否足以补偿判断错误。

兑现能力决定情景概率，下行风险决定损失幅度，但最终胜负由概率加权后的收益、风险不对称性和安全边际决定。

本维度直接从当前价格和当前可知事实出发，以归一化后的经济成果重新估计未来收益分布。低估值倍数只有在对应盈利具备相应持续性时才构成安全边际，高估值倍数也应结合增长、资本效率和期末合理预期判断。

最终选择应回答：现在投入同样资本，谁提供更好的预期回报和更有利的盈亏结构。

### 5.4 防守资本保全型

目标是在行业、市场或公司经营不利时，优先避免永久损失，同时保留合理收益可能。

本维度优先判断悲观情景下的损失幅度、自由现金流、净现金或负债、现金跑道、融资和稀释、客户集中、周期敏感、经营杠杆、竞争风险、恢复能力以及估值支撑。

低波动不自动等于安全，成熟公司也可能因债务、衰退或估值压缩而缺乏保护。增长前景可以提高恢复能力，但不能替代资产负债表、融资生存力和现金创造；高增长公司如果同时具备这些条件，也可能成为更好的防守选择。

最终选择应回答：如果主要假设没有按计划实现，谁更能保存资本并等待下一次机会。

### 5.5 爆发增长与产业突破型

目标是寻找因紧急产业瓶颈、新技术突然进入规模应用、关键产品突破或需求快速释放，而可能出现非线性收入、利润和股价重估的公司。

本维度优先判断：

- 新增需求相对公司现有收入和利润基数是否足够大；
- 瓶颈是否真实、紧急且难以被替代，公司是否拥有稀缺供给或议价权；
- 新技术是否已经从概念进入客户验证、采购、部署或规模收入阶段；
- 产能、供应链、交付和客户集中是否允许机会真正兑现；
- 收入增长能否形成毛利率、营业利润和现金流的放大；
- 扣除资本开支、营运资金、融资成本和股本稀释后，增长能否转化为每股利润、每股自由现金流或每股内在价值；
- 市场预期和当前股价已经反映了多少突破可能。

本维度由正向凸性主导：在现实概率下，基本面突破能否引起远大于常态的每股价值增量。稳定的基准情景是优点，但本身不足以构成爆发性；爆发力必须来自可以追踪的商业传导链和真实的股东价值捕获，而不是小市值、高波动、收入规模或宏大叙事本身。远期可选性、尚无客户采用的技术、无法交付的订单、依赖持续融资的扩张，以及已经被价格充分透支的热门公司，都应显著降低吸引力。

最终选择应回答：谁拥有更高的“突破概率 × 经济量级 × 兑现速度 × 股东价值捕获”，并且其资本结构和当前定价仍允许股东获得非线性回报。

### 5.6 市场定价错位型

目标是选择新增基本面证据、市场隐含预期与当前定价之间存在更有利错位的公司。

本维度优先判断：

- 当前价格隐含了怎样的未来8—16个月正常化盈利、现金流、增长、竞争和风险假设；
- 订单、需求、供给、技术、竞争或融资方面的新证据，是否足以改变这些假设；
- 市场对证据是否存在忽视、误读、线性外推或过度反应；
- 错位通过什么经营结果、信息披露或预期修正得到验证和纠正。

估值低、股价下跌或市场关注不足本身不构成低估，估值高或市场关注度高也不自动排除机会。必须指出哪一项重要预期错了、为什么错，以及什么证据可能使市场重新定价。

价格赔率型从当前价格出发估计未来绝对收益分布；市场定价错位型使用相同的盈利与现金流归一化基础，更关注当前价格隐含了什么判断、该判断为何与新增基本面证据不一致，以及什么事件可能促使偏差收敛。估值口径本身不同造成的表面差异不构成定价错位。

最终选择应回答：谁存在更重要、更可信且更可能被纠正的“基本面证据—市场预期—当前定价”偏差。

## 6. 结论表达

每个维度独立给出相对选择，使用实际Ticker而不是“A”“B”作为胜方名称：

| 结论形式 | 含义 |
| --- | --- |
| `<Ticker>明显更优（高/中/低置信）` | 优势显著，且对手存在关键短板 |
| `<Ticker>略优（高/中/低置信）` | 一方更值得投资，但优势或确定性有限 |
| `接近（高/中/低置信）` | 双方各有优势，无法可靠区分 |
| `资料不足` | 缺少形成可靠选择所需的关键证据 |

结论后附一句决定性理由，例如：

`NVDA略优（中置信）：近端交付更确定，但当前定价限制优势幅度`

`MU明显更优（高置信）：HBM供需瓶颈已经进入收入和利润释放阶段，预期仍未完全反映`

如果两家公司都不符合某种哲学，可以使用 `接近：双方均不具备足够吸引力`；仍能区分相对优劣时，则给出相对胜方并说明其绝对吸引力有限。

强结论应同时建立在胜方的明确优势和败方的关键限制上。资料较少不能自动成为败因，单一数字或估值倍数也不能自动决定胜负。

“总体风险调整判断”是对六种投资哲学的综合解释，不是第七个维度，也不能用多数票生成。它统一假设将同一笔资本持有8—16个月，不预设行业或投资风格，以归一化后的基准情景比较双方的预期回报、兑现概率和永久损失风险，并给出默认选择。双方分别适合不同目标时，可以在理由中说明条件；现有证据无法形成稳定选择时，则判为接近。

完成全表后，用简短文字概括：

- 公司A最占优和最吃亏的投资哲学；
- 明显优于公司A的主要公司B；
- 公司A最强的直接同业或配置替代；
- 公司A更接近稳定复利、近端兑现、爆发突破、防守资产还是定价错位机会；
- 下一项最可能改变横评结论的关键证据。

本方案的重点，是让六套投资哲学分别完成一次全面而独立的A与B最终投资选择，并保留不同方向、不同哲学之间真实存在的差异。
