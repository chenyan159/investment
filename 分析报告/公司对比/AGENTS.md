# 公司对比目录说明

- `结果/` 只存放正式公司对比报告，下游只读取此目录。
- `备份/` 与 `结果/` 同级，保存被替代报告和历史材料；runner 重跑前备份、失败时恢复。
- `tmp/`、`_work/` 存放临时材料，不得在 `结果/` 内建立备份或临时子目录。
- `研究方案/` 的现行入口按其 README 确定；历史方案保留原文。
- 公司、行业和情景决策报告从各自正式结果目录读取，索引仅用于定位；备份和临时材料不作为默认研究输入。
- 站点生成器仅为展示历史对比读取同级 `备份/`，放入独立的历史批次；当前结果始终来自 `结果/`。历史版本选择使用报告文件修改时间，不使用会因目录迁移变化的目录时间。
