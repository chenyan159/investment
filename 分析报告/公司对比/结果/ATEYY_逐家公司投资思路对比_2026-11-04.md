# 爱德万 Advantest（ATEYY）：综合投资评估、上游复核与跨公司比较报告

## 0. 执行摘要：有独立投资价值，核心仓位应先让位于更优载体

**稳健基准配置定位：条件性等待；高风险高收益定位：小仓位／期权式参与；近端行动：现价可以建立有限观察仓，稳健资金等待160—185美元或下一轮交付与现金验证。** ATEYY具备真实的平台壁垒、已经实现的高利润和正现金流，基准路径也能产生可观价格回报。但当前价格高于上游基准现金流现值，下一财年的公开汇总预期又高于本研究基准，不能把“行业继续增长”直接等同于“存在低预期超额收益”。未来2—4年值得跟踪和持有受限景气仓，现价的证据与估值组合尚不足以支持核心重仓。

**载体结论：ATEYY是先进计算ATE平台敞口的重要载体，但不是本比较集的综合首选。** 稳健AI制造配置优先TSM、KLAC；更高收益目标下，NVDA、MU提供更强价格赔率，但分别承担客户融资与存储重定价风险。ATEYY可作为上述持仓的测试环节补充，特别适用于看好CPU／ASIC测试复杂度、希望降低存储净价或GPU单一路线暴露的资金。直接竞争中，稳健视角略偏TER，平台扩展右尾偏ATEYY；这不等于TER已经夺取ATEYY核心份额。按本报告的资金用途排序，ATEYY为稳健第8/13、进攻第5/13；这是本次逐一比较后的顺位判断，不是打分或概率模型。

**三条核心证伪线：** 核心平台在重要生产客户被可核验的竞争方案替代；连续两个季度出现SoC交付、正常毛利和现金转化共同受损且查实为取消／需求消化；或者扩张与资本分配使原本自给的经营转为依赖困境融资。单季库存、汇率或股价波动不能独立触发上述结论。发生实质替代、重大收入不实或资本结构破坏时退出本研究所支持的持仓，而不是等待便宜价格自行修复逻辑。

### 1.5 决定性争议三：目标交易价格的较长成长溢价，是否独立成立

上游DCF先算目标日后现金流，再用独立交易倍数定价，**未发现用DCF除利润倒推合理市场倍数的循环**。统一10.5%美元WACC、3%永续增长，基准目标日剩余DCF225.1美元，远低于362.8—426.2交易价；其终值占经营价值65.8%，并非审计硬底。加入期间新买方可得股息再折回，基准约163美元，乐观约288美元；215.86介于两者之间。若只兑现保守现金路径、市场届时按225.1定价，价格年化约1.2%，不是表中16.5%—22.1%。

32—38倍目标NOPAT可由持续的跨代测试升级、CPU及ASIC数量、客户认证与较轻自有制造资本解释，但需要目标日之后仍有较长增长期。按现金转化约90%、要求回报10.5%、十年后3%永续的条件计算，约需16%—18%的十年现金增长；它比基准DCF逐步减速到个位数更强。**本次保留该交易分支，也明确把它作为价格风险。** 不因DCF较低就把已成立平台压成衰退倍数，也不凭“平台”二字认为长期高倍数自动成立。

横截面检查支持有条件溢价：ATE目标基准32—38倍高于TER24—28、TSM24—28，接近KLAC约34—40；更高营业利润率和HPC资格支持其较TER溢价，较薄的服务复购和较大采购周期又限制其接近最稳定的工艺控制平台。两家间8—10倍溢价不能无限扩大。只要经营、再投资与长期持续期分别写清，这里没有再用风险折扣重复惩罚同一事件。

| AEHR | 最新季收入33M、Owner FCF-4.983M；现金约105M主要受此前融资支持 | 极低资产投入与真实现金回报尚未同步；客户集中和容量重复采购决定回报持续期 |
| FORM | 九个月Owner FCF121M；投入发生口径另有约19M资本应付；新厂2027需继续支出 | 正常化毛利较强，建厂和逐设计资格限制短期回报；未来新增产能回报可改善但未锁定 |
| ASX | 九个月CFO减净PPE约-115.9 TWD bn；2027基准仍负FCF | 增量经营利润有价值，折旧、CapEx、借款及少数权益使每股资本回报弱于ATE |

| NVDA | H1 Owner FCF65.94B，低于含证券收益净利；279B供应承诺及场地信用支持需看回收 | 平台单位经济性高；客户资金、采购预付和信用损失可能扩大经济资本，不能只看无晶圆厂ROIC |
| MU | FY26 Owner FCF约60.2B，现金税同步化敏感性约46.7B；净CapEx继续扩大 | 当前ROIC含短缺租金；下一轮合格供给与合同净价决定是否高位持续，不永久化86%毛利 |
| KLAC | TTM扣SBC现金约3.714B，另有未单列小额融资租赁项；采购承诺8.87B | 多年服务与控制生态使增量资本回报较稳；工具／算法提效和设备预算仍有周期 |
| MSFT | TTM Owner FCF43.94B，进一步扣组件相关其他净投资为17.34B | 旧软件高回报与新AI资产回收必须拆开；账面高ROIC不能掩盖新增资本回收较慢 |
| V | FY26扣SBC现金约21.13B，正常化NOPAT24.69B；回购与股息合计25.56B | 网络轻资本、高转换；净负债和负有形权益不支持资产硬底，监管／续约决定增量收费 |
| ISRG | 九个月Owner FCF2.226B、回购现金4.419B；TTM Owner FCF2.749B | 医生／耗材复购强；租赁机器生产、SBC、降价和器械延寿让新增现金复利弱于单看手术量 |

该表实际期间与币种逐项保留，不把不同期间现金绝对额直接排名。统一比较依据是资本负担、转换方向、稀释和相同观察窗口的回报；没有足够可比投入资本和研发资本化资料时，不编造13个精确ROIC数字。未来经营与股本预测也不因表中历史现金为正而自动升级为确定现金。

### 3.2 ATEYY 对 TER：稳健略偏TER，平台右尾偏ATEYY

两家均有ATE程序生态、量产资格和现场工程壁垒。ATE的HPC主平台位置和当前利润率更强，TER存储、IST和互连分散了SoC客户时点，却需要新计算客户在2027H2转为生产采购。TER当前统一CY2027经营倍数低于ATE，悲观回撤约46%—54%也浅于ATE的56%—65%；其基准年化与ATE接近。反面是预付款和少数股权／FORM投资削弱可动用现金，机器人并未成为厚实利润池。[TER Q3原始结果](https://investors.teradyne.com/news-events/press-releases/detail/455/teradyne-reports-third-quarter-2026-results)。

**稳健复利：对手TER占优；高弹赔率：目标ATEYY占优；综合分视角各占胜场。** ATE的CPU第三轴与既有HPC主平台更直接，TER新增客户则有资格到采购的等待时钟。TER突破CAGR约49%—57%，实际略高于ATE约48%—56%；本次高弹偏好依据是ATE已处于规模位置、扩展所依赖的既有客户机制更连续，承认两者数值右尾接近。若TER在2027H2实现跨客户生产采购，这一证据优势会收窄。只押同一个客户资本开支不能靠同时买两家获得充分分散；优先顺位随TER新计算采购实证和ATE交付质量变化。

### 3.3 ATEYY 对 COHU：稳健买平台，高弹买小基数爬坡

COHU的Eclipse/T-Core已经有量产复购，约1B机会管线仍是漏斗；它主要掌握热、接触、处理和部分电测能力，未拥有完整HPC主ATE平台。2027基准收入833M、保留SBC正常化EBIT141M，较传统低谷有很大杠杆，但九个月Owner FCF极弱。高功耗业务认证失误、组件成本和可转债超过capped call后的稀释，会使同样一笔订单带来的普通股收益小于未经稀释的演示。

**稳健：ATEYY占优；高弹：COHU占优；综合分视角各占胜场。** COHU乐观／突破终值约3.2—5.9倍当前价，足够补偿进攻资金所承担的更弱现金证据，但不能由此称稳健更优。11月10日投资者日及后续认证转量产是它的分水岭，且尚未发生；在这些节点前只适合小里程碑仓。

### 3.4 ATEYY 对 AEHR：路线替代真实，当前买价仍选ATEYY

AEHR把部分早期失效筛选前移到晶圆，能避免坏die进入昂贵封装；这会影响后段SLT／老化预算，但不能替代所有结构电测。Sonoma也与TER Titan HP等发生插入点竞争。已知订单集中在少数客户与生产程序，新大客户2027年初先做生产环境验证，后续是否高量采用未知。最新利润为正、现金为负，说明融资余量与经营稳定性须分开。

**稳健、进攻均为ATEYY占优，综合目标占优。** AEHR基准到2029年6月价格约-13%至+6%，乐观约+76%至+109%；ATE在更宽业务底盘上提供更好的目标回报。统一保持AEHR当前高倍数会产生很高“纯业务参考价”，但目标价格需要在增长成熟后降倍数，不能把诊断参考当便宜证据。若新客户跨程序付费复制被证实且买价改善，再重做对决。

### 3.5 ATEYY 对 FORM：主平台目前优于接口扩张

FORM的探针接触、设计资格和Triton有真实价值；Q3增长主要还来自F&L与Systems，DRAM增长不能全部叫HBM，且HBM本季环比下降。非GAAP毛利56.5%含约10.5M非重复收益，去除后约52.75%；新厂期末400M年收入能力既不是2027平均产出，也不是净新增订单。TER300M投资必须同时加现金和2.234887百万新股，截止仍不能当交割现金或最低采购保证。

**稳健、进攻均为ATEYY占优。** FORM目标基准及右尾回报低于ATE，且逐设计竞争、新厂爬坡与较高SBC抵销接口复购的部分优势。若资金明确只押硅光子晶圆接口、希望弱化某一ATE主机平台份额暴露，FORM可作专项补充；这属于不同用途，不能据此改写当前总配置取舍。

### 3.6 ATEYY 对 ASX：设备收费权优于买方扩张的资本回收

ASX真实装机与LEAP增长强化ATE的需求，但其利润要经过厂房、设备、折旧、客户议价、借款及少数权益才能到普通股。2027—2028模型仍负FCF，目标净债务约16.5B；供给延期或客户预收回落首先压到股东现金。CPO客户合作与更完整封装路线提升右尾，也需要更多不可逆资本。

**稳健、进攻均为ATEYY占优。** 两者基准／乐观价格回报相近，ATE的经营产现、自有资本强度和受损韧性明显更好；ASX约69%—80%的悲观跌幅不能由高CapEx自动变成有形安全边际。ATE也受买方融资约束，故该优势不能无限外推成可以持续向ASX涨价。

### 3.7 ATEYY 对 TSM：同AI制造逻辑，优先台积电

TSM的节点、良率和设计生态决定客户能否拿到合格芯片，预算控制与不可替代性高于独立测试设备。新节点与海外厂增加资本负担，台湾共同尾部风险也更集中；但现价统一经营倍数低于ATE，基准证据更强，受损目标315.5—376.9距395.75明显较近。N2已经付费，基准无需押陌生新商业模式。目标基准年化约21%—27%，高于ATE；乐观／突破CAGR亦有竞争力。

**稳健、进攻均为对手TSM占优，综合构成同逻辑更优替代。** 不是因为历史涨跌或市值更大，而是当前价格、每股利润增长、再投资后现金和受损回报同时更好。ATE适合在TSM核心仓之外补充测试内容增长、CPU／ASIC换代，不能把这两项台湾相关暴露误当完全分散。

### 3.8 ATEYY 对 NVDA：终端平台截留更大利润，融资链是代价

NVDA的计算、网络和CUDA生态取得系统交付价值，ATE取得其中测试部分。NVDA自研替代、HBM成本、279B供应承诺和场地信用支持比简单无晶圆厂标签复杂；支持客户融资可能延后现金，不把相关客户／渠道收入计成独立最终预算。最新微软、AMD和内存原厂结果支持产业需求，仍不能锁定NVDA FY2030的883B基准收入。故本次将远期规模证据评为中，保留较大客户资金反证。

**稳健、进攻均为对手NVDA占优。** 基准交易价541—658、较保守目标日DCF约322，与200.13的关系均优于ATE相应关系；乐观和突破弹性也更高。基准大部分收益需要成长持续性，不能忽略目标市场价相对现金价值的溢价。ATE的独特作用是在看好整体芯片复杂度、但担心某一GPU平台被自研ASIC分流时，提供更路线中性的补充，而不是综合赔率全面胜过NVDA。

### 3.9 ATEYY 对 MU：存储重定价更有赔率，不能永久化峰值租金

MU是测试设备买方，也是设备部件存储成本上行的受益端。FY27Q1官方收入61.5±1.5B和2027 HBM协议支持近期兑现；但RPO最低价口径、SCA覆盖收入与全部公司高利润不是同一件事。基准FY2029收入325B、NOPAT约201B仍含极高稀缺利润，新增晶圆、堆叠、良率和客户降配会决定其持续性。10月末SK hynix关于LTA和扩产的新披露既支持需求，也加强2028后的竞争供给约束。

**稳健相对配置、进攻赔率均为MU占优；MU本身仍按周期成长仓管理。** 当前价格相对基准与受损目标、实际现金累积均更有吸引力，统一前瞻经营倍数也远低于ATE。需要特别纠正归因：原MU“12倍正常化纯业务价”相对于当前CY2027约4.5倍，含显著正常化重估；不能把其全部200%以上参考收益称作保持当前前瞻倍数的纯增长。本次统一后仍有业务和现金贡献，巨大交易右尾还需要市场不再把利润视作短暂峰值。若合同重议、同规格净价与回款同步转弱，MU优势会快速缩小。

### 3.10 ATEYY 对 KLAC：稳健选服务与良率控制，极端右尾选测试放量

KLAC卖的是把缺陷识别变成可靠工艺行动，算法、吞吐、应用工程和多年服务相互锁定；ATE卖的是生产测试能力，两者从同一制造钱包取得不同质量价值。KLAC基准不依赖actinic大规模成功，服务复购占比和受损现金路径更稳定。其客户设备池同样要求7月SEMI预测上修，不能因“质量控制”而豁免行业预算约束。

**稳健：KLAC占优；高弹：ATEYY占优；综合分视角各占胜场。** KLAC基准年化更高、悲观回撤约15%—33%明显更浅。ATE进攻优势只集中于更高合格交付、配置与跨客户测试平台突破的极端右尾；乐观CAGR与KLAC相近，不应把整条收益分布都说成ATE更高弹。若只需可靠分享先进制造增长，优先KLAC。

### 3.11 ATEYY 对 MSFT：软件续费较稳，但AI资本回收不免费

MSFT的软件、身份和工作流入口提供更分散续费，Azure也有真实增长。与此同时，TTM Owner FCF43.94B进一步扣组件相关其他净投资仅17.34B，融资租赁和最低采购条款令AI扩张具有重资本责任。把它当传统几乎零资本的软件估值标杆会高估其下行保护；11月4日250亿美元债券增加现金与债务，不凭发债创造经营价值。

**稳健：MSFT占优；高弹：ATEYY占优；综合分视角各占胜场。** MSFT较低需求集中与成熟续费使基准证据更强，受损回撤较浅；其目标日更近，年化已单列。ATE对新增算力变现没有直接经营责任、交易目标弹性更高。两者共享同一AI支出约束，不能把一端高CapEx和另一端设备高毛利同时当作没有资金成本的永久结果。

### 3.12 ATEYY 对 V：稳定收费权胜在下行，当前回报不再宽厚

V的受理、规则、身份与风控网络现金转换高，收入不靠新增设备采购；它是检验ATE是否值得占用核心仓的有效标杆。FY2027较多支付额要续约、激励提高和监管仍会限制净收费。全部B／C类与优先权益必须折成A股等价，不能只按公众A股推全公司经济市值。

**稳健：V占优；高弹：ATEYY占优；综合分视角各占胜场。** 用11月4日436.57重算，V基准价格回报约22%—36%、年化约7%—11%，明显低于旧报告买价393.49下的数值；这只是同日机会成本重算，不以此前上涨证明透支。V适合作为偏低周期的复利配置，现价不能再叫高赔率首选；ATE适合希望承担周期换更大上行的进攻资金。

### 3.13 ATEYY 对 ISRG：业务稳定不能弥补昂贵买价

ISRG在役手术工作流、医生训练和耗材复购比ATE采购流更稳定；但中国11月开始调价、2027H1部分器械延寿及按量定价，完全实施后固定组合I&A每例收入降3%—5%，会让数量增长向利润传导减弱。经营租赁机器也需要前置生产资本。GI、SP、Ion均有不同阶段证据，不能全当已成熟的耗材年金。

**稳健新资金、进攻资金均为ATEYY占优。** 以482.10计算，ISRG基准约+7%—20%、年化约2%—6%，不足以弥补估值及降价风险；ATE也不适合稳健重仓，但其基准价格回报、现价经营倍数和右尾更可取。此裁决针对当前证券价格，不是否定ISRG更平稳的经营质量；若ISRG价格显著回落或每例贡献改善，需重做比较。

## 4. 六维权衡后的配置与动态验证

### 4.1 把近期兑现、长期复利和买价收益分开

近期1—2季，公司已要求H2比H1增长约20%，公开年度预期也不低。按490收入、50%左右营业利润率兑现，主要是证明基准没有坏；收入超过505并伴随合格产能时间与现金改善，才有更清晰上修。当前宜定性为“有正向业务催化，也有高预期兑现风险”，不承诺下一季必然beat。

2—4年，V93000跨代程序、配置和客户验证值得持有，收益不依赖CPO另造一块同等大的市场。但采购是多年设备容量的边际流量，不能与芯片数量做同义复利。真正强的长期信号是旧平台升级与新平台付费复购可以连续跨代，客户每颗成本下降、ATE每套净收费仍上升，而不是只提高名义年产体制。

基准价格回报68%—97%和现金现值不足同时成立；上游业务锚标准化后基准参考回报约51%，其与目标交易回报的差值显示市场重估的重要性。乐观与突破分别提供约2.75—3.25倍、3.81—4.55倍终值，有真实产品机制，但多道门槛尚未锁定。下行方面，净现金保护公司存续，约9美元当前有形账面／ADS并不能保护215.86买价。**可以承担景气与持续性风险，不应把它包装成资产保护型核心底仓。**

相对机会成本上，ATE不是被一家标的在全部经济属性上彻底覆盖：TSM台湾制造尾部更集中、NVDA受GPU路线与客户信用、MU受净价。ATE的路线中性和量产测试控制具有组合补充价值。然而在本次价格与目标路径下，TSM／NVDA／MU的直接胜负足以使ATE让出优先资金；KLAC在稳健用途也优先。这是“有绝对价值、相对次优”，不是一律观望或零价值。

### 4.2 三层裁决、顺位和仓位属性

| 资金标准／行动层 | 本次裁决 | 执行解释 |
|---|---|---|
| 稳健基准配置 | **条件性等待** | 基准有正回报，但保守现金价值低于买价、受损回撤大；等待160—185或更强经营验证，不在现价配置核心底仓 |
| 高风险高收益进攻 | **小仓位／期权式参与** | 真实平台右尾值得保留，当前预期与机会成本使其达不到高优先级进攻；“期权式”指仓位属性，不是建议买不存在的ATEYY期权 |
| 近端1—6个月 | **现价可以分批建立有限观察仓** | 对进攻风险预算可先0.5%—1.0%总权益组合，分两笔；稳健资金保持等待，两个结论对应不同资金用途 |
| 验证后角色 | **景气配置补充仓，示例上限约1.5%—3%** | 需同时确认收入、现金、客户服务产出和1万台时间；已有较多AI硬件相关持仓时进一步降低 |

仓位数字是一般组合风险预算示例，没有用户实际账户、负债和其他持仓，未作最优权重求解，也未执行交易。按-56%至-65%的受损价格路径，1%仓位对应组合约-0.56至-0.65个百分点；更极端地缘／流动性事件可能超出情景区间。

**稳健顺位：TSM → KLAC → NVDA → MSFT → MU → TER → V → ATEYY → FORM → COHU → ISRG → ASX → AEHR。进攻顺位：MU → NVDA → COHU → TSM → ATEYY → TER → ASX → KLAC → FORM → AEHR → MSFT → ISRG → V。** 这是在当前价格和两种资金用途下的本次定性取舍；前列并不意味着相同绝对风险或可同时重仓。跨行业首选没有由13个机械分数加权产生；未来更新需要重做价格、证据和约束，而非维持名次。

### 4.4 1—3条硬证伪红线

1. **平台资格永久受损。** 核心HPC生产客户正式取消／退出V93000等主平台，或竞争方案在重要量产项目得到客户验证并造成可观收入／份额迁移；查明为结构替代而非正常双供时退出原逻辑仓。合作发布、匿名传闻或样机本身不够。
2. **增长与现金共同失效。** 连续两季SoC低于约350十亿日元且未见可信补交，正常化营业利润率低于约45%、合计现金FCF显著低于约200，同时确认客户取消、需求消化或库存减值；这组联合信号推翻正常兑现路径。普通季节性、税款时点、单季验收不作为同等证伪。
3. **资本与信息可信度破坏。** 发生重大收入重述／收款虚假，或经营现金连续不足、现金与可用金融资产无法覆盖已承诺支出，管理层仍以困境高成本融资／重大稀释维持低回报投入。该情形退出，不能靠原基准DCF“抄底”。
