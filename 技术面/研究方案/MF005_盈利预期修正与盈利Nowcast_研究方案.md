# MF005 盈利预期修正与盈利 Nowcast 研究方案

本方案独立研究指数盈利预期、分析师修正广度和宏观盈利 nowcast 对未来市场走势的影响。执行时只形成一份完整中文 Markdown 报告并写入 research runner 指定路径；除该报告外，不创建或修改其他正式文件。

## 资料边界

除本方案外，只可读取 `技术面/data/` 与 `技术面/scripts/` 的活动资料，不读取备份、旧 EPS 报告、既有因子结果或其他方案。外部资料优先使用公司公告、指数公司、监管文件、分析师历史数据库说明和原始研究。任何 consensus 或 revision 必须保存历史快照和可交易时间。

## 一、盈利预期研究问题

判断 forward EPS 水平、盈利增速预期、修正方向与广度、实际盈利 surprise，以及“宏观模型盈利预测与分析师 bottom-up 预测之差”能否预测五类市场未来 10/21/63/126/252 日收益、回撤和相对强弱。重点期限为 63/126 日，同时检查短期财报季和一年期效果。

## 二、分析师迟滞与现金流传导

- 股价取决于未来现金流和折现率；盈利上修若未被价格完全吸收，可能支持后续收益。
- 分析师预测存在迟滞、乐观偏差和逐步修正，宏观 nowcast 可识别指数盈利误差。
- 修正广度可能比少数巨头造成的指数级 EPS 上修更能描述整体盈利周期。
- 股价常领先正式盈利，因此必须检验盈利数据是领先、同步还是滞后。
- QQQ 与 SOX 对少数大公司和行业周期高度敏感，小盘则更受国内需求和融资成本影响。

## 三、Consensus、财报和指数权重的时点

为 NDX、SPX、美国全市场、Russell 2000 和 SOX 建立当时成分、权重和 consensus。区分本财年、下一财年及未来 12 个月 EPS；所有预测、修正和财报数据按发布时刻进入模型。周末或盘后公告最早用于下一交易日。

## 四、盈利预期状态表

- 指数 forward EPS、未来 12 个月 EPS、预期增长率及 1/4/13 周变化。
- 上修/下修公司数、净上修广度、加权修正幅度、修正扩散速度。
- 实际 EPS/revenue surprise、beat/miss 广度、指引上调/下调广度。
- Bottom-up consensus 与基于 GDP、美元、价格、工资、利润率和行业数据的 top-down nowcast 差。
- 盈利增长、利润率、销售增长、回购导致的每股增厚与真实经营增长分解。
- 指数价格变化相对 EPS 变化，拆分倍数扩张与盈利贡献。
- 头部权重股与等权成分的盈利贡献差异。

## 五、按财报季和修正周期研究历史

先重建点时间指数 EPS 与修正序列，再做领先滞后分析，确认股价、盈利修正和实际财报的时间关系。分别用单变量、误差修正、受约束回归和状态交互预测未来收益与相对收益，使用 expanding/rolling walk-forward，比较历史均值、价格趋势和只用估值的基准。

历史事件以净上修广度跨越分位阈值、连续数周上修/下修、bottom-up 与 top-down nowcast 差异常、财报季 beat/miss 广度拐点和盈利增速由负转正/由正转负为主。每次事件按真正可得日标记，列出原始触发周数、去簇事件数、有效成分覆盖和覆盖的财报季，研究之后五个窗口的股价变化，并检查价格是否已经提前反映。对季度低频数据，126/252 日重叠严重，必须报告实际独立周期数。

财报季与非财报季分开；高通胀、高美元、衰退风险和利润率拐点分层。对 QQQ、SOX、小盘分别建立经济上合理的 top-down 盈利驱动，不能用 SPX 模型简单平移。

## 六、最新盈利周期和历史相似季度

用最新可得 consensus 与财报计算五类指数当前 EPS 增速、修正方向、修正广度、nowcast 差和头部贡献。寻找历史上最相似的周或财报季度，列出当时之后五窗口的股价结果，并说明当前指数权重、利润率或宏观背景在盈利维度上的差异。

1. EPS 修正水平、变化还是广度最有样本外信息？
2. 宏观 nowcast 与 bottom-up consensus 的差异能否稳定预测 63 日收益？
3. 股价是否已经领先修正，加入过去价格后还有多少增量？
4. 头部公司上修能否代表整个指数，等权盈利广度有何不同？
5. 盈利上修在高估值、高实际利率状态下能否抵消倍数压缩？
6. 当前五类市场的盈利预期方向、广度和估值传导如何？

## 七、只基于盈利预期的未来股价预测

对五类指数分别给出 10/21/63/126/252 日单因子预测，包括方向、历史条件收益区间、上涨概率、回撤倾向和置信度。预测只能使用当前盈利状态与历史同类状态；10/21 日若历史研究显示无作用，应明确给出中性或“无法可靠判断”，而不是借助价格、利率或估值做结论。若缺历史 consensus、指数权重或小盘/SOX 覆盖，逐市场逐窗口列出样本起点、成分覆盖、去簇事件数、独立财报周期数和具体局限。

## 八、盈利数据的解释边界

今天看到的历史 consensus 不能代替当时快照。预测口径、成分权重、财年滚动和公司行为必须一致。盈利修正与收益的相关性不能自动解释为因果，也不能把价格先行后的滞后修正误当领先信号。
