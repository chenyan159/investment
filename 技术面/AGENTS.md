# 技术面目录说明

本目录当前用于研究可由历史信息检验的大盘预测因子。现阶段只运行独立因子研究，不建立组合模型或总预测方案。

## 正式入口

- `研究方案/`：18 份独立因子研究方案，编号 `MF001–MF018`。每个任务只读取与主题对应的一份方案。
- `因子研究/`：Research Runner 生成的正式研究结果。每份方案每次运行只生成一个 Markdown 文件。

## 支撑目录

- `data/`：当前可复用的原始数据、标准数据集和特征面板；历史 legacy 数据已移入备份。
- `scripts/`：当前数据构建与清单脚本；旧一次性模型脚本已移入备份。
- `tmp/`：执行中的临时计算，不作为正式结果或隐式长期依赖。
- `备份/`：重构前报告、消息、催化剂、利率专题、旧输出、旧临时文件和 legacy 资料；不作为正式研究输入。

## 站点发布边界

- `站点发布.json`：面向网页的稳定摘要、因子家族和可视化口径；不替代正式研究报告。
- `生成站点数据.mjs`：校验 18 个因子并自动选择每个编号的最新正式报告，将摘要和完整 Markdown 合并为单一发布快照。
- `站点数据/current.json`：`tools/site` 唯一允许读取的技术面输入。站点不得直接扫描 `因子研究/`、`研究方案/`、`data/` 或 `scripts/`。
- 依赖方向固定为 `因子研究 + 站点发布.json → 生成站点数据.mjs → 站点数据/current.json → tools/site`；不得建立反向依赖。

## 研究规则

- 每项任务只使用当前方案、`data/`、`scripts/` 和联网取得的一手/原始资料；禁止读取其他方案、`因子研究/` 的既有结果和 `备份/`。
- 每份方案独立研究一个因子家族，统一覆盖纳斯达克 100、标普 500、美国全市场、小盘股和半导体指数，以及未来 10、21、63、126、252 个交易日。
- 正式产物只有 Research Runner 指定路径的一份中文 Markdown 报告，不额外生成 CSV、JSON、图表文件、模型包或辅助报告。
- 输出建议命名为 `MFxxx_因子名称_研究结果_YYYY-MM-DD.md`；具体路径由 runner 注入，不在方案正文硬编码。
- 行情、估值、宏观、事件、成分股、权重和回测必须标明数据截止日期、首次公开时间与口径。收盘后信息最早进入下一交易日模型。
- 历史研究使用 expanding/rolling walk-forward，不得随机切分；长期重叠收益必须处理样本重叠和未来信息泄漏。
- 每份研究都必须以历史事件或历史数据为证据，分别研究该因子对未来 10、21、63、126、252 个交易日股价的影响；不能只讲机制、只做同期相关或从一个期限外推其他期限。
- 对每个市场与时间窗口都要说明历史覆盖、事件数、有效样本数和数据质量。某一窗口证据不足、历史太短、事件太少或数据不是 point-in-time 时，必须明确写出“无法可靠判断”及具体原因，不得以模糊措辞补结论。
- 每份报告都要计算该因子当前状态、历史分位、变化速度和数据截止时点，列出最相似的历史日期或阶段，并解释相似与不相似之处；历史类比只作该因子条件下的证据，不能假装其他环境相同。
- 每份报告最后都要给出严格只基于本因子的 10、21、63、126、252 日股价预测，至少包括方向、幅度区间或条件分布、置信度和主要依据。不得借用其他因子结论补强，也不得把多因子判断伪装成单因子预测。
- 不强制 18 份方案使用同一章节模板。价格、期权、宏观事件、新闻文本、仓位流量、季度财务等应按各自数据频率、事件定义、发布时间和样本结构选择研究路径。
- 允许研究得出无预测力、仅能解释风险或仅在特定期限有效的结论，不为形成看多/看空意见而强行选择模型。
