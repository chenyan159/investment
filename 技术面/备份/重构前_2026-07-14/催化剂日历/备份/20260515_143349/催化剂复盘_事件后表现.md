# 催化剂复盘：事件后表现

> 研究日期：2026-05-15 美西时间  
> 用途：记录事件前预期、实际结果、市场反应和研究修正。  
> 结论属性：复盘模板和事件档案，不构成投资建议。

## 复盘原则

催化剂研究如果不复盘，会变成只预测、不纠错。每个重要事件后都应该记录四件事：

1. 事件前市场预期是什么；
2. 实际结果和预期差在哪里；
3. 1 日、5 日、20 日价格反应是什么；
4. 原研究哪里对了、哪里错了、下次如何改。

## 复盘模板

| 字段 | 内容 |
|---|---|
| 事件名称 | 例如：2026-05-12 April CPI |
| 事件类型 | 宏观 / 财报 / AI capex / 政策 / 产品技术 / 订单 |
| 事件日期 | YYYY-MM-DD |
| 事件前预期 | 市场共识、项目内判断、关键阈值 |
| 实际结果 | 数据或公告 |
| 预期差 | 好于/差于/符合预期，差异有多大 |
| 影响标的 | QQQ、SOXX、SMH、相关个股 |
| 当日反应 | 1 日涨跌、相对强弱 |
| 5 日反应 | 若事件发生未满 5 个交易日，标记为“未到观察窗口”。 |
| 20 日反应 | 若事件发生未满 20 个交易日，标记为“未到观察窗口”。 |
| 结论是否验证 | 是/否/部分 |
| 研究修正 | 下次模型或判断怎么改 |
| 后续观察 | 下一事件和阈值 |

## 样例复盘 1：2026-05-12 April CPI

| 字段 | 内容 |
|---|---|
| 事件名称 | 2026-05-12 April CPI |
| 事件类型 | 宏观通胀 |
| 事件日期 | 2026-05-12 |
| 事件前预期 | 项目内 5/8 文件认为 3 月 headline 热但 core 尚温和，关键是 4 月 CPI 是否让 core 重新加速。 |
| 实际结果 | BLS：CPI-U 环比 +0.6%、同比 +3.8%；核心 CPI 环比 +0.4%、同比 +2.8%。 |
| 预期差 | 偏热，尤其核心 CPI 环比 +0.4% 把通胀风险档位上调。 |
| 影响标的 | QQQ、SOXX、SMH、长久期成长、半导体高 beta |
| 当日/随后反应 | 到 2026-05-15，SPY -1.20%、QQQ -1.51%、SOXX -4.06%、SMH -3.80%。 |
| 结论是否验证 | 验证了“hot surprise 压低 1-5 日收益、SOXX 左尾高于 QQQ”的框架。 |
| 研究修正 | 需要把 PCE 作为二次确认；单次 CPI 不是中期转空，但足以触发半导体去杠杆。 |
| 后续观察 | 核心 PCE、DGS10 4.60%、DFII10 2.10%、VIX 22。 |

## 样例复盘 2：2026-05-15 半导体下跌

| 字段 | 内容 |
|---|---|
| 事件名称 | 2026-05-15 SOXX/SMH 去杠杆 |
| 事件类型 | 市场价格 / 技术面 / 宏观传导 |
| 事件日期 | 2026-05-15 |
| 事件前预期 | 技术面研究 5/8-5/15 更新持续提示 SOXX 左尾风险高、涨幅和估值拥挤、宽度弱。 |
| 实际结果 | SOXX -4.06%、SMH -3.80%，QQQ -1.51%，SPY -1.20%。 |
| 预期差 | 半导体明显跑输大盘和 QQQ，符合高 beta 去杠杆。 |
| 影响标的 | SOXX、SMH、NVDA、TSM、AVGO、MU、ASML、KLAC、MRVL、CRDO、ALAB、CAMT、ONTO |
| 结论是否验证 | 部分验证。左尾判断正确，但尚未证明中期转空。 |
| 研究修正 | 需要区分“左尾兑现一段”与“风险完全释放”。SOXX 仍相对 50 日均线 +26.81%，不能因为单日跌幅就认为便宜。 |
| 后续观察 | SOXX 是否收复跌幅一半、DGS10/DFII10 是否回落、VIX 是否突破 22、龙头财报是否确认基本面。 |

## 复盘后的规则更新

每次复盘后都要问：

1. 事件影响是短线价格波动，还是改变了 6-12 个月基本面？
2. 影响是全市场的，还是只影响半导体高 beta？
3. 哪些公司被证明更强，哪些只是跟涨？
4. 哪些阈值需要调整？
5. 是否需要更新个股矩阵或总览风险灯？
