# 半导体财报催化剂：NVDA / TSM / AVGO / MU / ASML / KLAC

> 研究日期：2026-05-15 美西时间  
> 覆盖对象：AI compute、foundry、HBM、custom ASIC、AI networking、WFE、process control、advanced packaging/test。  
> 结论属性：财报事件研究，不构成投资建议。

## 一页结论

半导体暴跌后，财报催化剂比日线图更重要。技术面告诉我们 SOXX/SMH 已经去杠杆，基本面告诉我们 AI 主线仍强；但真正决定能不能加仓的是未来财报和指引是否继续证明以下四件事：

1. AI compute 需求没有降温：NVDA/AMD 订单、交付和 backlog 继续上修。
2. 共同瓶颈没有反转：TSM CoWoS/SoIC、ASML EUV/DUV、KLAC 过程控制仍被需求拉动。
3. HBM 和 memory 周期仍在上行：MU 价格、毛利率、HBM 认证和产能锁定继续改善。
4. custom ASIC 与 AI networking 不是一次性故事：AVGO/MRVL/CRDO/ALAB 等能把项目转成收入。

## 当前判断

5/15 的半导体下跌没有自动推翻基本面，但它提高了财报的门槛。接下来如果 NVDA/TSM/AVGO/MU/ASML/KLAC 继续给出上修或强确认，SOXX/SMH 的回撤可以被解释为拥挤交易释放；如果其中两到三个核心节点同时转弱，就要把问题从“估值杀”升级为“盈利预期修正”。
