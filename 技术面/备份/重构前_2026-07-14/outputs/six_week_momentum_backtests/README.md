# 六周动量回测目录

本目录保存 QQQ、SOXX 在六周快速上涨后的历史回测结果和复核数据。

## 关键文件

- `六周快速上涨历史回测_2026-05-11.md`：研究口径、回测结果和综合判断。
- `six_week_backtest_summary.csv`：2003 年以来的宏观条件分层回测。
- `current_six_week_state.csv`：当前六周涨幅和历史分位。
- `price_only_long_history_summary.csv`：长样本纯价格极端动量回测。
- `price_only_top_6w_events_declust.csv`：去簇后的历史极端事件。

研究结论必须与对应日期的数据文件一起使用；本目录结果不自动代表当前市场状态。
