## 结论摘要

1. 以 SPX 为主标的、使用 2001 年以来包含 P/S 的离散时间 hazard model 估计，当前状态下未来 5/10/21/63 个交易日内发生 5% 回调的累计概率约为 **4.5% / 10.4% / 21.5% / 42.0%**。
2. 同一模型下，未来 5/10/21/63 个交易日内发生 10% correction 的累计概率约为 **0.6% / 2.0% / 4.8% / 16.5%**。短窗口不是高确定性风险，但 3 个月窗口已经是需要管理的尾部风险。
3. 当前最主要的风险推升因素是 **P/S 极高** 和 **10Y 美债收益率偏高**。P/S 在本地 2001 年以来样本中处于最高位置，对 63 日 5% 回调概率贡献约 **+14.1 个百分点**。
4. 单独看高 PE 和高 1 个月涨幅，模型没有给出“立刻缩短到回调时间”的结论。强趋势和贴近 252 日高点在历史上往往有延续性，因此会压低短期 hazard；真正危险的是高估值、高利率和趋势过热同时存在。
5. EPS 上修不能用当前公共数据直接估计。项目 README 已列明 forward EPS / EPS revision 仍需要 FactSet、IBES、Bloomberg、LSEG 等点时数据。本报告不把 trailing EPS proxy 伪装成 EPS 上修信号。

## 事件定义

从每个交易日 `t` 的 SPX 收盘价开始，定义未来首次触及指定跌幅的交易日数：

```text
T_t(5%)  = min k>=1 such that SPX_{t+k} / SPX_t - 1 <= -5%
T_t(10%) = min k>=1 such that SPX_{t+k} / SPX_t - 1 <= -10%
Y_{t,h}  = 1(T_t <= h), h in {5, 10, 21, 63}
```

这里使用 close-to-close 调整后收盘价，不统计日内回撤；事件是“从起点价格跌 5%/10%”，不是从未来路径中的最高点回撤。

## 模型设定

主模型是离散时间 logit hazard：

```text
Pr(T = k | T >= k, X_t) = logistic(alpha_bucket(k) + X_t' beta)
```

`alpha_bucket(k)` 使用期限分段：1 日、2-3 日、4-5 日、6-10 日、11-21 日、22-42 日、43-63 日。解释变量在训练样本内标准化。

主模型样本：

| 项目 | 设定 |
| --- | --- |
| 起点样本 | 2001-03-01 至 2026-02-06，可观察完整 63 个交易日前瞻窗口 |
| 起点数量 | 6,272 |
| 5% 事件数 | 2,174 |
| 10% 事件数 | 1,020 |
| 变量 | trailing PE、P/S、SPX 21D/63D 收益、21D 年化实现波动、距 252D 高点回撤、VIX、10Y、10Y 21D 变化、10Y-2Y |

1999 对比单独使用 1990 年以来的长样本 PE 模型，因为本地 P/S 字段从 2001 年才可用。

这个校验说明两点：

1. 强趋势状态确实可能延续，短窗口不能简单因为“贵”和“涨多了”就判断马上回调。
2. 经验筛选样本很小，不能替代多变量模型；但它提醒我们，当前风险更像 1-3 个月的累积 hazard，而不是未来几天的高确定性下跌。

## EPS 上修问题

本研究暂不能回答“EPS 上修是否能延长高估值趋势”的实证版本，因为缺少点时 consensus EPS revision。正确的数据应包括：

- S&P 500 或 NDX forward EPS 的 1M/3M 变动；
- EPS revision breadth，即上修公司数占比；
- Mag 7 / AI 半导体权重股的 forward EPS 贡献；
- 公告日和分析师修正时间戳，避免 look-ahead。

方向上，若价格维持不变而 forward EPS 被上修，forward PE 会下降，hazard 应降低；若价格涨幅超过 EPS 上修，估值压力仍会累积。当前公共数据只能说明“价格和 P/S 已经很高”，不能证明“EPS 上修足以吸收估值”。

## 使用方式

把本模型当成“时间到风险”的工具，而不是单日方向模型：

- 未来 1-2 周：5% 回调概率不低但也不是主导情景，趋势延续仍有历史依据。
- 未来 1 个月：5% 回调概率约 21.5%，需要开始用仓位、期权或止盈规则管理。
- 未来 3 个月：5% 回调概率约 42.0%，10% correction 概率约 16.5%；对 QQQ/SOXX，实际组合回撤弹性可能高于 SPX。
- 若后续出现 EPS 上修扩散、VIX 不升、10Y 下行，hazard 应下修；若 P/S 继续扩张、10Y 上行、VIX 从低位抬升，则 63 日 correction hazard 会继续上修。
