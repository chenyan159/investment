# FuelCell Energy（FCEL）：综合投资评估、上游复核与跨公司比较报告

## 0．执行摘要：当前买价只能承担里程碑期权，不能承担核心配置

**综合裁决：FCEL 不符合稳健基准配置标准，应回避核心建仓；偏高风险高收益标准下，属于“可用极小股票仓位参与的里程碑博弈备选”，不是高优先级进攻首选。** 按统一参考买价 $17.25，复核后的 FY2029 基准交易区间为 **$13.43～17.99，价格回报 -22.1%～+4.3%，年化 -7.9%～+1.4%**；固定20倍当年正常化经营利润的业务参考只有 $8.26。基准目标日剩余DCF $15.01，按13%股权回报要求折回本研究日约 $10.33。当前价格必须取得比正常兑现更好的成本、订单或利润；现金多、行业缺电和股价波动大均不能代替这个条件。

乐观与突破分别保留 **$39.37～52.61、$66.57～88.94** 的条件交易带，机制来自产量、良率、单位贡献及工业捕集复制，绝非发生概率或保证收益。近端1～2季可能有首单收入催化，但仍预计经营亏损、扩产和营运资金消耗；10月6日客户公布具体园区有意义，却没有公布新增MW、追加定金或最终融资。**一般组合当前零仓；明确容忍永久损失的进攻账户，可一次性不超过组合0.25%的股票观察仓，新增进攻资金优先研究PSIX，其次GNRC。加仓必须等“可执行付款承诺＋100MW生产实绩＋单位成本改善”同时出现。** 2～4年持有逻辑以这些验证为前提，不能仅凭期权式叙事持有。

FCEL 不属于所选研究集的全市场最优载体：同类电力弹性下，PSIX在本组条件模型中拥有更好的基准、乐观回报与较浅左尾；稳健供电/供气配置更适合先比较CMI与ET；广义AI成长配置优先比较NVDA和MSFT。BE经营领先但现价基准赔率更差，不能把“同行更成熟”直接翻译成“应该买BE”。**硬红线为：首笔30MW的履约/客户付款实质失败；量产后重复的大额亏损合同显示单位贡献不能转正；现金约束被击穿或为维持同一业务路径实施至少20%的被迫低价稀释。** 详见第五章的操作定义。

### 1.4 产业守恒与跨公司份额：先对齐池子，才有加总资格

相关行业[自备发电与微电网报告][I-GEN]的2029美国持续自备主供电基准，是发动机3.2～4.8GW、燃机1.8～3.0GW、SOFC 1.2～2.2GW，共6.2～10.0GW，完整项目产值10.94～27.11B。**这些是E型工程/需求包络，不是全国成交统计；FCEL的MCFC没有被单列进SOFC子池。** 因而不能拿FCEL设备单价约3M/MW乘整个项目池，也不能把FCEL与BE加完后用SOFC容量直接判超额。

### 1.5 买方TCO、维护寿命与利润归属

Phase 0设备对价90.8M/30MW≈3.025M/MW，长期服务110.7M/30MW≈3.69M/MW；后者跨15～20年，不是一次性高毛利订阅。标准12.5MW Block约50% LHV电效率、含热回收的85%为另一口径；7.58MMBtu/MWh的HHV热耗对应天然气成本，不能将85%都用作电效率，也不能把低污染当零碳。[FCEL-C]

在20年、8%融资、90%利用率、整站4,000～5,000美元/kW、30%抵免和天然气4.5美元/MMBtu的条件算例下，资本费约36～45、燃气34、服务约23～31美元/MWh，核心电价约94～111，完整费用可能95～120美元/MWh或更高。天然气涨1美元/MMBtu，电成本增加约7.58美元/MWh；失去ITC的资本费约多15.5～19.4美元/MWh。相比便宜可接入电网或可迅速配置发动机，FCEL须用场址限制、噪声、排放、供电时间或有用余热证明溢价，而非全球统一更低成本。

燃料电池解决部分接网等待，不解除天然气运输、水、许可、冗余、UPS、保护和系统验收。[电力接入行业报告][I-GRID]及[机柜电源报告][I-RACK]均表明设备到货和可用功率不同。对100MW、90%负荷园区，多20美元/MWh的电价约多15.77M年成本，足以影响客户选择，而GPU厂商/云商资本支出增长不能直接证明愿意接受它。

服务基准以每MW年费0.21M、换堆1.0M/7年、现场费0.035M计算，直接成本0.178M，毛利仅约15.3%；不是软件式70%毛利。若寿命降至5年，直接成本升至0.235M、服务本身亏损。**同一耐久性风险先在寿命/维修现金里承担，估值处不再另用无依据腰斩倍数惩罚；相反，尚未证明的7年寿命也不应升级强证据。**

### 1.6 捕集许可、封存进度与右尾的法律边界

Rotterdam安装工业模块是技术验证线索，不等于连续可用性、每吨成本或全球复制获证。[FCEL-C] 第三方项目授权在[2024 Amendment No.5的8-K][F-JDA]中为累计年捕集能力不超过250,000吨，JDA到2026-12-31；允许继续履约已在期限内签下的项目，不等于以后新项目永久无限授权。已有2019非独占许可、共同开发的技术权利和新第三方许可不能混同。

以研究假设每MW日捕集20～60吨、90%利用率计算，20MW为0.131～0.394M吨/年；100MW为0.657～1.971M吨/年。**乐观20MW在高捕集强度下已可能超250kt，突破100MW明显超限；现行能力上限只相当于约12.7～38.1MW。** 目标年新订单必须有期满衔接/新许可或有效的存续项目权利。Porthos在2026-04-16宣布不早于2027年下半年启动，也使模块安装与运输封存现金兑现之间有实际时间差。[Porthos公告][F-PORTHOS]

裁决为：基准FY2029不依赖捕集收入，维持；乐观/突破保留**有新许可与工业客户融资的条件分支**。只剥离FY2029捕集设备、其余条件固定的局部敏感性：乐观20MW×(3.10－2.25)＝17M EBIT，税后约12.75M，20～28倍对应少$2.67～3.73/股；突破100MW×(3.25－2.35)＝90M EBIT，税后67.5M，22～30倍对应少$15.52～21.16/股。后者原交易带局部降至约$51.05～67.78。**这不是完整无捕集情景**：服务、营运资金释放、已投入厂房、以后现金及许可费用须联动再算，不能用单年差额伪造新的DCF。它证明两点：许可会实质影响右尾；核心设备若已盈利，也不能因许可未批就把全部公司价值归零。

### 1.7 风险去重、DCF与市场估值独立校准

复核没有发现基准同时“行业保守TAM→公司再砍份额→现金流再统一折半”的结构。基准230MW、成本2.25M/MW已保留有意义增长；0.73M/MW直接贡献、维护成本、CapEx/NWC和SBC逐项支付。12% WACC与13%股权回报门槛是资金/机会成本，不能另当发生概率再乘现金。若新事实证实更低成本，应先升经营利润，而非在收入、毛利、折现率和交易倍数四处各奖励一次。

上游基准以30～40倍FY2029仅30.9M的NOPAT交易，乐观反而用20～28倍158.3M。过渡年盈利分母能解释这个现象，但原文对市场交易倍数的论证较多依赖DCF一致性，**DCF校验成立不等于独立市场证据充分**。本次将基准交易锚改为FY2030 NOPAT66.6M、16～22倍：下沿参考已经有现金转化的发动机/电源供应商，较高上沿允许FY2031经济EBIT仍升至124.5M的后续增长，须维持订单质量；不宣称这是已观测同行平均。

采用同一目标净金融桥94.05M、股数85.993M和剩余4M客户权证：
**85.993×P＋4×Call(P，K=26.44，T=0.65年，σ=90%，r=3.5%)＝m×66.6＋94.05。**
m=16/22时解得 **P=$13.425/$17.993**，期权索取权5.190/11.990M。波动率/利率保持原长期估价参数，属于E；并不把11月6日IV、三年股权要求和权证剩余0.65年当成同一风险参数。

DCF采用上游经营与资本路径不变：目标剩余值2.64/15.01/51.39/85.25，回折本研究日约1.82/10.33/35.35/58.64；现金显式预测到2045年，终值并非全部价值，但远期真实商业假设仍决定大部分结果。乐观20～28倍、突破22～30倍在新证据不足以证明持久性升级时维持，不因需求远大就自动加倍估值，也不因未来竞争抽象存在就无条件腰斩。

现价取得13%股权回报，2029需约$25.08。按基准股数、净金融桥及同一权证，16～22倍FY2030需要正常NOPAT约95～131M，即经济EBIT约127～175M，明显高于66.6M/88.8M基准，但低于完整乐观路径。**“预付部分乐观，未预付完整突破”**因此是反推经营门槛的结论，不是根据过去几个月涨跌作出的标签。

### 2.4 期权市场：昂贵的近期波动，不能替代情景概率

[共同快照][SNAP]FCEL期权为2026-11-06到期、同一K=$17、快照日剩余29天，Call IV **98.6%**、Put IV **89.4%**，故同期限同strike的Put−Call＝**-9.2个百分点**。这支持看涨合约相对隐波较高的描述；不能仅凭单一近ATM点就称整条波动率曲面是上行偏度。

98.6%×√(29/365)≈27.8%的时间尺度显示近期波动风险很大，**不是股价保证上涨27.8%、不是正态68%置信区间、不是突破情景概率**。同strike Put/Call理论关系、借券费用、报价不同步与宽点差都可能影响供应商IV；快照缺bid/ask、成交量和OI，无法证明低摩擦可交易或建立可靠的全链偏度。部分比较公司如GEV、GNRC、ETN的call/put strike不同，本研究不计算这些公司的伪skew。

11月6日到期更靠近10月产能/客户消息，通常早于FCEL年报披露的12月窗口；不能当作未来两次财报的保险。用极小**股票**仓位承担“期权式”风险预算，不等于推荐买这些高IV短到期call；赌方向正确仍可能因期限、隐波回落而损失。没有公开报价足以比较具体期权权利金与目标收益，本研究不编造策略损益。

### 2.5 利率、政策、燃气与跨境敞口

[FOMC 9月16日声明][MACRO-FED]将联邦基金目标区间提高到 **3.75%～4.00%**；[财政部10月8日收益率表][MACRO-TREASURY]10年为 **5.22%**（10月2日5.28%）。短端政策与长端项目成本不能混为一个数；FCEL现有EXIM固定5.85%贷款已在申报中，未来工厂、项目和客户融资并没有同价自动承诺。本次不因10年下降6bp就更换12% WACC/13%权益门槛。

TCO的8%项目融资升到10%，20年资本回收系数约从10.19%升至11.75%；在前述整站成本/ITC/利用率下，资本项约再高 **5.5～6.9美元/MWh**。这是敏感性C，不是断言所有客户已付10%。FCEL前置CapEx、长合同回款和仍为负的运营现金，使融资窗口比CMI/LIN/MSFT更决定性；股权价格下跌会把相同资金需求转为更大股数，构成融资反身性。

法定抵免须按现行原文裁决。[Public Law 119-21 §70513(f)、(g)(4)][POLICY-48E]为合格fuel cell property规定48E适用百分比30%，不得再按该节其他条款调整，并适用于 **2025-12-31之后开工** 的相关设备；不能把生效年份延后一整年，也不能把“不燃烧”当成不用关注排放。项目资格、禁限实体/材料、抵免兑现/转让与客户纳税能力仍是具体项目条件。**30%是业主合格项目资本的税收安排，不是FCEL设备收入直接增加30%，亦不是所有项目无条件现金补贴。**

经营地理：9个月韩国收入56.255M/99.121M≈56.8%，美国约42.8%；Q3韩国约61.7%。长期资产主要在美国，韩国更新已提供实收/融资基础，但现有GGE更新批次结束后不可无限滚动。[F-Q3] 设备进口/境外零部件价格、贸易或韩方项目融资政策能改变设备利润和付款。官网称FY2025 carbonate制造使用的美国供应商约90%是供应商口径，**不等于90%材料价值国产，也不足以证明每一项目满足税法条件**。[公司技术/制造说明][F-WEB]

美国气源/场址、韩国收款、Rotterdam捕集/欧盟封存是三类不同暴露；没有查明直接适用FCEL的新增特定出口禁令，保留U，不能凭一般地缘新闻计全面禁售。US制造和已有韩国客户提供缓冲；没有证据把燃气成本、关税、补贴或许可风险视为已全额转嫁。Groton现停运及FY2027改造计划也必须按真实项目验证，不能仅凭集团生产加快把存量亏损抹掉。

## 第三章．跨公司逐一比较与最优载体检验

### 3.1 比较集、经济关系与资本成本

### 3.2 FCEL vs BE：同客户预算、不同技术与不同买价

[LIN-C]现场装置10～20年供气、配送密度和客户认证构成壁垒，能源转嫁减轻分子成本波动。Q2调整经营利润率29.5%，商业成熟度与FCEL完全不同；backlog售气8.1B是项目总资本成本，不是明年收入。电子气体有实际需求，Beaumont/Dow与居家护理也有延期/成本反证。调整ROC23.5%不等于新项目今天建设成本IRR。

[LIN-S]基准2029EPS22.60、普通股经济FCF7.09B、全部资本6.5B、股数444.5M，现金/净回购与利息联动。481.70的基准520～588加23.4股息年化3.8%～7.7%，尚无法满足高机会成本进攻标准。固定20倍权益利润约452说明现价含质量溢价，而不是现金无风险保障。

**裁决：本金韧性与长期业务复利，FCEL被LIN压制；追求多倍非线性，FCEL特定占优。** LIN作为持有质量标杆胜，不等于当前一定值得大量买；FCEL尚未证实的长期售后承诺不应冒充相同合同质量。

### 3.12 FCEL vs MSFT：客户预算壮大，先看谁已把价值留给股东

[MSFT-C]FY2026收入331.84B、经营现金182.935B、传统CFO减现金设备FCF66.987B，平台已大规模收费；但FCF较FY2025下降、融资租赁负债66.594B和FY2027资本获取不能藏在EPS增长后。30M以上Copilot付费席位证明商业阶段，不等于全按标价结算；RPO、模型伙伴与最终客户付款也不能重复证明数倍独立需求。

[MSFT-S]基准FY2029EPS26.31、经济FCFF85.2B、股数7.397B，逐年SBC、融资租赁和净回购闭合。522.61的671～778加11.59股息，2.724年年化10.3%～16.4%；其剩余DCF约530低于市场目标，市场25～29倍相对DCF仍有溢价，不说基准市场回报是现金保证。20倍NOPAT诊断约538接近现价，远优于FCEL8.26对17.25。

**裁决：一般成长配置FCEL被MSFT在现金、基准与融资韧性上压制；突破累计尾部FCEL局部占优。** 若进攻投资者只看AI预算增长，直接平台的预算控制权/获利更充分，不必经过FCEL供应商份额和成本两重不确定性；只有明确押注现场电力或捕集瓶颈时FCEL才有独立补充意义。

### 3.13 FCEL vs NVDA：高弹性不只存在于未盈利小公司

[NVDA-C]最新季度96.221B收入、75%GAAP毛利、63.734B经营利润证明极强已实现利润；CUDA、互联、完整系统交付提供复制壁垒，物理供应与客户回款约束也同时变大。应收63.059B、DSO60天、容量/担保支持不能当零风险；巨额采购承诺又不能一次性当债务损失。Rubin生产、Preview跑分与最终客户付费仍是不同证据。

[NVDA-S]基准FY2030正常NOPAT515B、FY2031 FCF*533B、目标股数22.948B；目标359～452用前瞻14～18倍投入后FCF*，SBC、代扣现金、战略支持和股本已支付，不能拿18.59倍FCF*直接比FCEL20倍NOPAT。230.48下基准价格年化14.3%～22.5%，乐观29.5%～37.8%；即使悲观有50%～61%损失，仍低于FCEL约83%～86%。

**裁决：广义AI高收益资金优先NVDA，FCEL在当前买价的基准、证据和资本底盘上被压制；更极端的制造/捕集突破上限FCEL仍特定占优。** NVIDIA虽市值大，利润/现金也大，不能因市值数万亿先验说弹性耗尽；其成熟经营也不保证买方资本回收率，不宜拿未经核实FY28增长70%作Consensus。FCEL如要获得同等配置顺位，必须在每股经济价值与可验证客户路径上提供新增证据。

### 3.14 最优载体结论与适用边界

没有公司在全部技术用途和全部极端情景上完全复制FCEL，捕集与某些非燃烧场址约束是其独特期权；但**独特不自动等于值得优先花钱**。本组现价下：

- **稳健电力/分子增长：CMI、ET优先于FCEL。** 两者基准含息年化约12%～16%，且已有普通股/单位现金基础；周期、LP税务、项目执行仍需各自纪律。
- **电力高弹性：PSIX优先，GNRC次之；FCEL为小额里程碑补充。** PSIX的客户自制/供给集中未消失，GNRC现价基准也不丰厚；选择是相对风险收益，不是大仓位无条件推荐。
- **全市场AI进攻：NVDA与MSFT先于FCEL。** 明确已有利润和现金也能产生很大右尾；需审慎其支持资本/租赁和买方付款。
- **BE、CAT、GEV、ETN、CEG、LIN：经营多数更强，现价基准回报受限。** 不能用FCEL很差反向证明这些公司任意价都是首选。它们在改善买价或验证强于基准后可提升顺位。

本次只对所选研究集作裁决，不宣称已对245家公司做完整实时估值排名。FCEL没有获得“首选载体”地位，亦不靠固定分数给出伪精确第几名。

## 第四章．六个正交角度的专项裁决

### 4.1 近端：收入进入财报，不代表成本拐点同时进入财报

近期真正可能改变预期的是三件相互关联但不可替代的事：交付控制权转移、单位成本/损失计提变化、客户追加付款。已知CGN剩余六模块与Phase 0首批提供收入可见度；拟达到100MW的产量目标若实现，固定费用吸收可改善，但订单价格固定而成本偏高的批次仍可能亏。57M收入相对49.33M有限共识高15.5%，只是收入预期差，不足以抵销正常EBIT仍负33M。

近端定性为 **“存在正向收入催化，需成本/付款验证，非高把握利润超预期”**。选到正确产业而买高IV、短期限、无验收的工具，依然会有负投资结果。已公布CFO交接对财务执行值得跟踪，没有证据把它当盈利加速或财务造假的证明。明后两次财报按FY2026 Q4年报与FY2027 Q1理解，实际日期尚未由公司确定；第三方12月16日预测不是正式日程。

### 4.2 中远期：有制造杠杆，但尚无不靠资本的每股复利

MCFC并不是无技术价值：稳定主供、场址排放/噪声、余热和捕集耦合在部分客户具真实机制。问题是这些差异有没有足够客户按能覆盖全生命周期的价格付费，且供应商能否承受多年服务义务。客户换设备困难既能保护服务收入，也可能把低价维护承诺锁在FCEL身上；不能单向称为护城河。

基准230MW及0.73M/MW直接贡献足以跨过约175MW的公司经济EBIT盈亏点，FY2029 ROIC却仅4.4%，FCFF/股0.209。FY2030 NOPAT66.6M、FY2031 EBIT124.5M才使产能进一步吸收/资本收益有机会改善。原模型前向累计FCFF约FY2033才补平Q4 FY2026以后的投入；这不是历史累积损失收回、也不是扣资本成本后的回收期。

中远期定性为 **“具经营杠杆的待验证制造成长，尚非成熟复利资产”**。如果独立重复采购、稳定成本、七年寿命及服务毛利兑现，上调正常路径有依据；如果仅多卖固定亏损设备，收入高增反而扩大损失。两条路径都以可观察单位经济性判断，避免把悲观定义为需求终将消失或把乐观定义为永远有融资。

### 4.3 基准买价：当前要求超过正常兑现

本次独立交易锚给予基准$13.43～17.99，已经比原区间11.82～15.36更有利；结论仍为不支持稳健配置。$17.25对$10.33条件DCF今值约67%溢价，反过来今值比买价低约40%。$15.01是目标日剩余价值；若拿它当今天DCF，还把三年的等待无偿送给买方，就会严重夸大安全边际。

| 局部敏感性，E/C，其他条件固定 | 对FY2029经营/资金的影响 | 以固定20倍当年NOPAT表示的每股影响 |
|---|---|---|
| 平台变动成本下降/上升0.10M/MW，230MW | EBIT±23M，正常NOPAT±17.25M | 经营价值约±$4.01，另有权证/现金反馈；不能说所有利润变化都是估值 |
| 在可用产能内多交付50MW，价2.98/成本2.25 | 增直接贡献36.5M，正常NOPAT27.375M；设备新增NWC约37.25M | 先增经营价值约$6.37，再减NWC价值约$0.43；不含新增固定费/服务/下一年资本，非完整预测 |

**价格触发须写成联合条件。** 保持校准后基准下沿13.425，要求15%年化，今天最高买价約 **$8.75**；高端17.993按同门槛回折约$11.73。不能用上端的11.73冒称下端也达15%。因此≤$8.75可重新评估进攻性价值，但须订单、成本、跑道仍完整；$10～11只达到中间/高端路径的较好回报，不是稳健标准的自动买点。甚至$8.75仍略高于当年固定20倍业务价8.26，远非清算保证。

### 4.4 右尾：来自成本与规模，不只来自题材拔倍数

乐观350MW新平台＋20MW捕集、2.05M/MW平台成本，使经济EBIT211M；突破420＋100MW、1.98M成本、750MW可用工厂，使EBIT356.6M。新平台ASP并没有翻倍，反而在FY2029约2.95；经营杠杆主要是每MW贡献与厂房固定成本吸收、成熟服务基础。乐观/突破分别每股NOPAT1.655/2.795，体现员工/客户权益之后的利润，不是总公司现金流直接除现在股数。

这是有物理与商业机制的右尾：模块路线可工作、已有大型站运行与工业示范、客户有首单定金。但 **“机制成立”与“这些规模/成本发生概率足够高”是两回事**。20MW工业复制的许可已需核查，100MW需多批客户、捕集净化/运输封存和融资；原12M权证本身还是客户支付与供应商摊薄的交换，不是无偿商业验证。

高风险标准定性为 **“可承担极小仓位的真实里程碑期权，证据不足以给高优先级”**。PSIX的基准和多数右尾端点更好，不能以FCEL有5倍目标就称同组最高赔率。短仓/高IV产生的交易挤压也可把价格推离价值；本报告不把挤压收益与经营突破累计算两次。

### 4.5 左尾：账上现金减轻即时破产，不能消除永久稀释

65M运营现金约束与项目贷款、优先股、客户履约费用具有不同优先级。658M非受限现金允许验证和分段建设，反对“马上破产”的无依据极端说法；但基准FY2027/28约-169/-119M企业FCFF，加利息、本金、分红和储备，现金到FY2029约247M，远不是把今天658M一直当未来普通股分红。

悲观有限资产价格2.40～2.98，对17.25损失82.7%～86.1%，是**停止/缩减扩张后的资本消耗、处置和低估值结果**，不是纯临时情绪。若管理层不能及时止损，季度错配、采购承诺或大额质量义务还可走到中心四景之外的更差尾部。低价再融资将资金缺口与每股损失连接，不能只看名义现金跑道多少月。

举一个不赋真实概率的赔率门槛：若只在悲观中点2.69与乐观中点45.99两个终值之间分化，要使期望终值达到13%要求的25.08，乐观概率约需 **52%**；若改为悲观与突破中点77.76，需约30%。这是两状态数学算例，非研究的概率估计；真实还有正常兑现、不同等待期、流动性与更差左尾。它说明“上行三倍”并不自动带来正风险调整收益。本研究无法用当前证据给这些成功概率强校准，因此以仓位/里程碑约束代替伪精确权重。

### 4.6 相对配置：用途独特，不足以压过资金机会成本

FCEL的低市值让小额利润跃迁可变成大比例股价变化，却同时让增发和固定履约损失更具破坏性。CMI/ET用已有现金池承担新项目，PSIX用已盈利设备与较低现价承担份额/供应风险，NVDA/MSFT用生态/收费平台承担高增长和资本风险；这些路径均省去FCEL的部分门槛。

相关[AI建设与订单映射报告][I-BUILD]对2027美国新增上电IT容量基准仅7～11GW、建设投入689～1,090B，都是E、且只覆盖美国2026～27。采购硬件、在建资产、全球云CapEx与已上电负荷不同，不能用该金额直接证明BE全球设备、FCEL全部订单或NVDA FY2030 1.009T收入。对NVDA/MSFT采用的是各自正式报告的条件路径，**并未把其全部远期供需自动升级为事实**；条件回报比较更强，依然需客户回款/有效部署验证。

相对定性为 **“有MCFC/捕集特色期权，但存在更优的基准与进攻载体”**。仅在某些非燃烧场址、可靠客户已付款、成本验证而价格没有提前资本化时，FCEL才应提高顺位；不能以不同用途没有完全重叠来逃避“普通AI电力资金买谁”的直接答案。

## 第五章．综合投资决策、仓位与动态验证

### 5.1 三层明确决策

| 投资标准/时间窗口 | 当前动作 | 何时改变 |
|---|---|---|
| 稳健基准配置 | **不符合稳健标准（回避），零核心仓** | 需要正常化经营/现金证据与显著更低买价共同出现，不因一季收入beat直接转核心 |
| 偏高风险高收益 | **值得≤0.25%组合股票仓的里程碑博弈；非高优先级**。同电力进攻先PSIX，GNRC次之 | 新可执行客户/定金、100MW实际生产与成本改善共同证实后，才讨论提高至0.5%；仍非主力底仓 |
| 未来1～6个月介入 | 若接受83%～86%受损回撤，可一次极小试仓；一般资金先观察，不追高IV挤压 | 收入/订单/成本三联证据；或跌至≤8.75且基本面红线未触发 |
| 未来2～4年持有 | **条件型持有价值**，不依赖仅一个故事长期不检验 | 230MW及2.25M单位成本的中心路径逐季闭合；完整许可/客户证据支持才使用右尾 |
| 绝对投资价值 | 存在独立非线性期权价值；当前基准/DCF不提供稳健正回报 | 看好特定MCFC/捕集机制且能验证，才有补充意义 |
| 相对顺位 | **不是本组最优载体**；基准次于CMI/ET，电力进攻次于PSIX/GNRC，广义AI次于NVDA/MSFT | 替代标的买价过高/证据受损，而FCEL现金每股价值明显改善时可轮动；不能只按相对涨跌轮动 |

仓位比例是一般风险预算示例，不由本报告代替个人账户约束。0.25%仓位在悲观损失85%时约损伤组合0.21%；1%仓位会约损伤0.85%，且四景外损失可更大。**“期权式仓位”指股票小风险预算，不是买11月高IV期权；不使用杠杆，不以亏损后无限加仓维持成本价。**

### 5.2 具体建仓、加减仓与兑现条件

1. **价格触发：≤$8.75**，且30MW付款/交付未失效、新增订单以可执行对价确认、现金按前置投入后仍有至少24个月模型跑道。此时复核后基准交易下沿约达15%年化；若低价来自新的亏损合同或资金恶化，必须先改模型再计算，旧目标区间不能机械复用。
2. **证据触发：Phase 1 100MW有效选购及初始定金，或独立第二信用客户的等量级可执行采购；同时连续至少4周实际生产率≥100MW/年、可审计批次单位直接成本降至≤2.60M/MW、无新增大额亏损合同。** Phase 1定金若按16%×100×3.025M估约48.4M，只有合同/银行实际收款能确认；公告“selected/reserved”不够。2.60为早期验证线，FY2029基准2.25仍需后续下降。
3. **加仓不超过0.5%的一般上限**仅在上述商业/成本验证且当前买价重新满足≥15%基准年化时讨论；否则即使好消息仍保留微量风险。更大的主力仓还需完整服务寿命、经营现金自给和资本回报证据，不能凭一项订单进入核心。
4. **兑现：若仅正常路径却价格≥$25**，而未来利润尚未升至所需约95～131M NOPAT，停止新买/减掉观察仓的大部分；若价格接近$39～53、而350MW/2.05成本/新许可仍未证实，优先兑现主题溢价。若利润真实升级，先按新每股现金/股本重估，不能把旧目标价作为无条件卖出机械线。
5. **权证、客户资本和现金先看条款**：行权增加现金必须同步摊薄；无现金行权和现金行权不同。没有确认客户融资闭合，不把合作方背后的资本机构当无条件担保。

等待的踏空代价明确存在。假设验证后股价从17.25升至25，维持同一2029乐观下沿39.37，累计价格回报从128.2%降至57.5%，按今天同一3.061年窗口年化从30.9%降至约16.0%；乐观上沿年化从44.0%降至约27.5%。这是固定起算时间的可比算例，实际右侧买入更晚会改变年数。等待付出赔率，换取可执行客户/成本证据；微量仓用于限制全程踏空，不构成把核心仓提前押到弱证据上的理由。

### 5.3 三条硬性证伪/退出红线

| 红线 | 需核实的客观触发 | 动作 |
|---|---|---|
| 客户/付款逻辑失效 | 首笔30MW被实质取消、应收/付款发生重大违约，且无同信用已付款替代；或原订单价格/资格不再可执行 | 退出该里程碑仓；先重建客户/现金路径，不能拿潜在10GW销售线索补洞 |

FCEL的Call使用常规Black–Scholes作经济索取权代理，SBC、客户权证归属条件及不可交易性并不由这个公式自动解决；用于基准条件分支，非权证市场报价。GNRC沿用其上游K200.9266、T3.71、σ45%、r5.28%、基础59.8M、权证1.693745M、NCI0.372M，20倍诊断解约331.19。BE含SBC NOPAT1.878B、现金6.436B减债务2.5/融资0.04/NCI0.029B，在不转股分支得约131.38；不能把232.3简单乘20/30。GEV20倍当年8.03B NOPAT加19.40−4.00−2.674B金融桥/257.58M股＝672.90。

所有打印价格到美分、百分比到0.1%；模型输入不少为上游四舍五入值，诊断价格不是审计精确目标。原参考价沿用上游完整计算结果，不能用表中已舍入盈利反推后要求逐美分完全一致。计算/结构自检使用以下方法：

~~~python
from datetime import date
from math import exp, log, sqrt, erf

def span(target):
    return (date.fromisoformat(target) - date(2026, 10, 9)).days / 365.25

def cagr(buy, end_value, years):
    return (end_value / buy) ** (1 / years) - 1

def norm(x):
    return (1 + erf(x / sqrt(2))) / 2

def call_value(stock, strike, time, vol, rate):
    d1 = (log(stock / strike) + (rate + 0.5 * vol**2) * time) / (vol * sqrt(time))
    d2 = d1 - vol * sqrt(time)
    return stock * norm(d1) - strike * exp(-rate * time) * norm(d2)

def fcel_price(mult):
    rhs = mult * 66.6 + 94.05
    lo, hi = 0.001, 1000.0
    for _ in range(100):
        p = (lo + hi) / 2
        lhs = 85.993 * p + 4 * call_value(p, 26.44, 0.65, 0.90, 0.035)
        if lhs > rhs:
            hi = p
        else:
            lo = p
    return (lo + hi) / 2
# fcel_price(16) ~= 13.42505; fcel_price(22) ~= 17.99286
# 其余公司使用A.3目标价、0.2统一买价和各自span()；股息用B表。
~~~
