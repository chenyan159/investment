## 1. 业务经济本质与竞争位置

### 1.1 五个经济单元及谁为价值付费

| 经济单元 | 客户、付款与创造价值的机制 | 利润与扩张约束 | 成功与失败的分水岭 |
| --- | --- | --- | --- |
| 手机及其他边缘计算 IP/royalty | 芯片设计商/OEM 为 CPU 架构、实现 IP、CSS、工具付授权费，并随芯片销售付 royalty；手机用户买的是整机体验，通常不是直接向 Arm 付款 | 生态和成熟设计复用使毛利很高；总设备销量较成熟，增长主要依赖 Armv9/CSS 内容提升、核心数量、产品组合 | 更高 IP 费能否以性能、上市速度与工程成本回收；客户是否改用自研实现或 RISC-V，低端销量是否抵消高端升级 |
| 第三方云端/服务器 IP | AWS、NVIDIA、云厂商、芯片商将 Arm 架构做成自研/销售 CPU；Arm 捕获授权与每颗芯片 royalty | 服务器份额、每颗核心数、IP 单价及定制程度共同决定收入；大量 CPU 核心不等于同等数量 CPU 芯片 | 架构份额增长可以很强，但客户选择架构许可还是 CSS 决定 Arm 费率；第三方 CPU 和自有 CPU 不可重复计量 |
| 汽车、工业、嵌入式/物理 AI IP | 长认证周期客户以安全、工具链、稳定供货和软件兼容换取低风险开发 | 设计周期长、单位 IP 收入较低但寿命长；汽车/机器人各自商业化时钟不同 | 设计赢单须变成终端产量；机器人原型、累计芯片数不能直接等于当年收入 |
| 授权/平台接入与 SoftBank 设计服务 | 一次性/多年授权、Total Access/Flexible Access、服务里程碑；许可签订和交付兑现先于后续 royalty | 大合约造成季度波动；关联客户预算、交付和回款必须单独验证 | 不能把当期服务收入、未来 royalty 与同一套 CPU 销售各自无条件叠加；合同资产不是自由现金 |
| 自有 AGI CPU/未来芯片平台 | 向云厂商、企业及服务器 OEM 销售 Arm 设计、外部制造的实体 CPU；客户采购现成产品以替代部分自研或 x86 采购 | 收入捕获范围扩大，毛利率下降；新增晶圆/封测、内存配套、库存、质保与软件适配责任 | 从多客户首批验证到可盈利标准化复制；良率、交付、可靠性、价格/功耗和客户总预算均需过关 |

授权与 royalty 是收费形式，不应再当作两个彼此独立的终端 TAM。软件和工具在本研究中归入 IP/服务支持；尚无足够独立收入披露，不另造订阅软件利润池。新芯片没有计入内部授权或内部 royalty。底层同一 IP 的共用研发只在集团费用扣一次。

ARM 解决的是“以可复用 IP、工具链和软件兼容降低设计复杂度、时间与风险”。成熟生态是现实壁垒：现有程序、开发工具、工程师能力及客户验证体系形成转换成本；但架构授权允许大客户自研 CPU 实现，不能把生态份额全部解释为公司对芯片售价的完全控制权。开放指令集替代不仅是芯片性能问题，还需可靠编译器、虚拟化、调试、数据库和大规模运维生态。其影响通常先出现在成本敏感、定制或特定工作负载，不必假定两季内全面替代。

### 1.3 关联收入、合同和现金可得性

### 1.4 支付意愿与客户总预算：新市场真实，但不会全部归 Arm

手机端高份额意味着销量上行空间有限；可持续增量主要来自内容和代际升级。MediaTek 2026-09-15 的 Dimensity 9600 Pro 采用 Arm C2/G2 系列并配自己的 NPU，证明先进 IP 产品在客户新品中落地；不证明 Arm 取得全部 AI 加速器价值，也不证明所有使用者会为任何费率涨幅买单。[MediaTek 原始公告](https://www.mediatek.com/press-room/mediatek-dimensity-9600-pro-sets-new-standard-for-flagship-smartphone-chips?hs_amp=true)

数据中心 CPU 因 agent 编排、网络、内存访问、安全、虚拟化和应用服务而重要，GPU 数量并不能直接推算 CPU 数量。Meta 3 月宣布与 Arm 共同开发多代 AGI CPU；4 月又公布 AWS Graviton 采购安排，单位为数千万 **核心**；Qualcomm 6 月宣布服务器路线图并预期 2028 年商业产品。这些材料共同支持 CPU 需求增加与多供应商策略，**不支持 Meta 给 Arm 独家预算**。[Meta/Arm，2026-03-24](https://about.fb.com/news/2026/03/meta-partners-with-arm-to-develop-new-class-of-data-center-silicon/)、[Meta/AWS，2026-04-24](https://about.fb.com/news/2026/04/meta-partners-with-aws-on-graviton-chips-to-power-agentic-ai/)、[Qualcomm 路线图，2026-06-24](https://www.qualcomm.com/news/releases/2026/06/qualcomm-unveils-comprehensive-data-center-roadmap-for-the-agent)

作为原始预算约束，Meta 7 月披露 2026 全年 CapEx 指引 **$130—145bn**；上半年 CFO 64.088、PP&E 49.113，另有融资租赁本金 1.805。预算能力很大，也已占用大量自有现金，且要购买 GPU、网络、建筑、电力、内存等整套系统。这支持 Arm 新产品的付费土壤，却不允许把“Meta CapEx×CPU 假定比例”当成其已经签给 Arm 的订单。[Meta Q2 原始财报，2026-07-29，现金流及 outlook](https://investor.atmeta.com/investor-news/press-release-details/2026/Meta-Reports-Second-Quarter-2026-Results/)

**TCO 的研究推断示例**：若 CPU 功耗节省 50W，电价 $0.09/kWh，满负荷运行三年，芯片电力差只约 $118（50/1000×24×365×3×0.09）；即便计入制冷，也不能单靠这项节省合理化高出数百美元的芯片售价。真正的收益应是同一机柜容量/可靠性下，更高的应用吞吐、更少服务器、节省自研团队与更快交付，扣掉 DRAM、迁移及运维。采购中应检验每个实际工作负载的 $/任务，而不是只看核心数或营销的每机柜性能倍数。

### 1.5 CPU 商品化的毛利放大与新增义务

AGI CPU 的第一代公司规格为 **136 个 Neoverse V3 核心、300W TDP**。公司的机柜性能和参考服务器是设计/营销信息，不是已实现客户 ROI。AWS 已商业推出的 Graviton5 是 **192 核心**；不能将两者核心数、每机柜密度当成无条件的同预算性能比较。[Arm 2026-03-24 产品公告](https://newsroom.arm.com/news/arm-agi-cpu-launch)、[AWS 2026-06-10 可用性公告](https://aws.amazon.com/blogs/aws/now-available-amazon-ec2-m9g-and-m9gd-instances-powered-by-new-aws-graviton5-processors/)

Arm 7 月业绩会称 FY27＋FY28 需求超过 **$2bn**，已有制造覆盖的初始规模约 **$1bn**，并预计 FY28 前芯片毛利在高 30%—低 40% 区间，经过设计内化等措施再争取约 50%。本报告将其定性为**管理层需求/供给陈述**；没有公开客户最低不可取消采购、验收付款、追索条款或晶圆厂独立确认，所以不把超过 2bn 全部当成 backlog 或已融资销售。[2026-07-29 业绩会，产品及供给问答](https://investors.arm.com/static-files/2ef5e3bf-f276-4a46-a4a2-2aadccd6710b)

在 $2,000 净 ASP、40%—46% 毛利率的条件假设下，每颗芯片毛利约 $800—920；被替代的 IP royalty 可能只是一部分。毛利额增加必须扣专用研发、软件支持、销售、质量与库存成本。若这类专用固定成本连同正常 SBC 合计每年约 **$0.9—1.4bn**，单元营业盈亏平衡所需芯片收入约 **$2—3.5bn**。这只是共享成本划分的机制估计，不能包装成公司的已披露分部利润；集团模型不另加一遍这些费用。基准需要 FY29—FY30 规模接近该带宽；收回初始累计投入和营运资金可能延至 FY30—FY32。

Fabless 不等于没有资本负担。COGS 支付晶圆/封测，NWC 沉淀预付款、原材料、在制品、成品与应收；本身 CapEx 则主要对应测试/验证、工程算力、设施及工具，不在模型中凭空建一座 Arm 晶圆厂。工程团队也不能同时用同一批人完成所有 CSS、客户定制及多个 CPU 代际；扩大芯片场景中费用增量随之提高。

### 1.6 竞争、渠道冲突与需要裁决的关键分歧

第一种分歧是“自有 CPU 完全增量”与“将与付 royalty 的客户争夺预算”。本报告裁决为**两者并存**：现成 CPU 扩大此前不愿或不能自研的企业/OEM 客户群，也可替代 x86；但云厂商自研及合作伙伴 CPU 被替代时，Arm 失去部分第三方 royalty，且可能减少合作深度。模型的第三方云端增长率是净替代后的路径，内部销售不产生 royalty。如果芯片销量主要从原有 Arm 客户转移，每颗损失 $30—100 royalty 的研究敏感区间，对突破 FY30 5.3 百万颗可涉及 $0.16—0.53bn；这不是官方费率，亦不再次扣已纳入净增速的基准迁移。

第二种分歧是“Arm 生态增长等于 Arm 自有芯片份额增长”。AWS、NVIDIA Vera/BlueField、Qualcomm 服务器计划说明架构胜出可同时支持不同 CPU 供应商。NVIDIA 9 月 28 日的 Agent Safety 公告提供的是开放软件与 Vera/BlueField 平台采用线索，并没有公开向 Arm 自有 CPU 下独家订单。9 月 8 日 N4/AGI 进展及客户合作增加产品可信度，仍需要采购批次、交付及回款证据。[NVIDIA 原始公告，2026-09-28](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Launches-Open-Agent-Safety-Platform-to-Secure-Agents-From-Testing-to-Deployment/default.aspx)、[Arm N4/AGI 更新，2026-09-08](https://newsroom.arm.com/news/arm-agi-cpu-neoverse-css-n4-agentic-ai)

第三种分歧是“RISC-V 马上摧毁壁垒”与“永远无法取代”。SiFive/AMD 9 月 15 日的 ROCm＋RISC-V 展示说明生态替代在推进，但它是展示与工程进度，不是已经发生的大规模服务器迁移。基准不设两季内崩塌；悲观路径纳入谈判压价、自研和局部替代；乐观/突破需要 Arm 的标准平台在交付和软件上继续领先。[SiFive/AMD 原始材料](https://www.sifive.com/press/sifive-amd-rocm-riscv-datacenter-servers)

第四种分歧是费用与提价是否相容。客户会承受性能/开发成本节省带来的价值收费，却不会无限接受授权费上涨。旧合约费率、架构许可、CSS 组合和客户产品 ASP 并不统一。3 月公司远期“芯片约 15bn、IP/CSS 约 10bn、调整后 EPS 超过 $9”的目标，只证明管理层的战略方向和资源投入意图；不能作为保证，更不能把其示意 $1,000 芯片价格当成真实 AGI CPU ASP。[Arm Everywhere 财务材料，2026-03-24，第 9、25 页；示意价格限制见第 9 页图注](https://investors.arm.com/static-files/11881690-3c08-4148-bf7f-1504442b4ec4)

金额为十亿美元。基准 FY28：一个锚客户约 17.5 万颗、四个其他客户各 6.5 万颗，合计约 43.5 万颗×$1,950≈0.85；FY29：两锚客户各 27.5 万、八个其他客户各 8 万，合计约 1.19 百万颗×$2,000≈2.38；FY30 2.20 百万颗的标准产品复制带来约 4.40。这条链是根据设计验证、采购分批及客户预算能承受的路径提出的**可证伪工作假设**，不是将收入预测倒算成订单证据。FY27＋FY28 基准芯片收入 0.95，约与公司所述初始 1bn 制造覆盖相容；乐观 1.55、突破 2.10，需要补齐制造及实付订单，不能无条件继承现有覆盖。

供应/预算硬约束的研究验算：突破 FY30 5.3 百万颗×300W≈**1.59GW CPU 芯片 TDP**；包括内存、主板、网络、制冷等，系统有效电力需求可能约 3—6GW，具体取决于负载和设备结构。若每颗 CPU 对应部署预算约 $8,000—15,000，总部署支出约 **$42—80bn/年**，须分布到多个有盈利/融资能力的客户，不能全落到 Meta。若每片晶圆约 80—120 个良品，则需约 **4.4—6.6 万片晶圆/年**；这是未披露 die 面积/良率下的条件产能测试，不是 TSMC 配额。

这些数量未违反多客户云端预算的数量级，但远未得到采购和制造合同证明。AGI CPU 的 DDR/内存、主板、电力及交付资源也有约束，不应机械套用 GPU 的 HBM/CoWoS 瓶颈。价格更低可以帮助放量，却同时压低毛利；本模型四情景将价格、复制规模、毛利、费用和营运资金联动。

### 2.5 不同商业时钟、失败成本与远期路径

FY27 是研发、初始制造/认证和成本确认年；FY28 是首个重要产品收入验证年；FY29—FY30 看跨客户规模复制与盈亏平衡；FY31 是多代平台能否达到公司远期愿景的分水岭。手机 IP 代际 royalty 有设计到销售的时滞，工业/汽车认证更长，云端部署取决于 CPU 配套与具体应用。一个发布会不会让所有业务同季兑现。

四情景芯片 FY27—FY30 收入分别为：悲观 **0.05/0.35/0.75/0.90**；基准 **0.10/0.85/2.38/4.40**；乐观 **0.15/1.40/3.70/7.14**；突破 **0.20/1.90/4.80/10.68**。相应芯片 FY30 毛利率 **33%/46%/50%/53%**，乐观/突破越过基准的供应、客户复制及设计内化约束，而不是无代价涨价。

失败分支保留已经发生的研发与 SBC、设备及存货/预付款风险。悲观管理层在 FY29 将调整后费用从 3.30 降到 3.20、现金 CapEx 从 0.72 降到 0.60，聚焦可交付的主要客户；不会在看不到单位回报时仍强行建无限产能。彻底停止 CPU 会回到更轻的 IP 模式，但损失工程人才、采购承诺和累计投入，不能把退出当成无成本高价值捷径。

完整预测延伸至 FY2045。基准 FY31 芯片约 6.0，FY40 约 21.35；突破 FY31 约 15.0，FY40 约 68.73。后者要求 Arm 成为持续多代、有广泛客户群的全球大 CPU 供应商；若长期净 ASP 约 $2,000，FY40 芯片量约 3,400 万颗，对应单年整机预算可达数千亿美元，是极强的容量假设。公司宣称 FY31 可拓展 CPU 市场超过 $100bn 是管理层估计，不是独立实现证明；本研究不设 Arm 垄断全部服务器、GPU 或其他计算预算。该远期右尾必须随客户、全市场预算和供给扩张逐年检验。

没有因远期缺乏现成订单就让 FY32 突然坍塌。FY31—FY40 云端、芯片和内容增速逐步下降，FY41—FY45 再过渡到成熟状态；高增长路径也保留设备更新、工程与库存资金。未来规模是前瞻机制推断，不是当前已有合同覆盖的事实。

## 3. 四种公司经营情景、现金流、资本结构与每股基本面

### 3.1 公司级经营分水岭与共同口径

**悲观／受损**：手机量低迷、内容升值减慢，第三方云端仍增长但客户议价、自研与部分生态替代压低费率；CPU 交付晚、客户复制弱，SoftBank 服务预算回落。公司止损控费、放慢 CapEx，不把所有坏条件叠加成永久破产。营业利润在 FY27—FY28 可为负，后续恢复为正；长期低估值下人才报酬带来的净稀释较高，现有股东每股增长弱于集团增长。

**基准／正常兑现**：手机体量成熟但 Armv9/CSS 内容增加，云端核心数/份额带动 royalty；第三方授权持续恢复，关联服务适度稳定；CPU 从锚客户进入第二轮复制，FY30 约 4.4bn、46% 毛利。调整后费用 FY27 3.17，FY28—FY30 3.58/4.04/4.55，另扣雇主税和 SBC；不是轻资产高利润率原封不动迁移到芯片销售。

**乐观／超预期**：更多可量产客户及更快部署，边缘升级与云端收费内容较强；芯片 FY30 7.14bn、50% 毛利，费用与资本投入同步增加。实现依赖供应覆盖、良率和产品组合，不能由客户名单独立证明。

**突破／非线性**：基础 IP 强于乐观，标准芯片平台跨客户复制，OEM 和大企业客户加入，FY31 芯片规模接近管理层 15bn 目标。FY30 芯片毛利 53% 是超预期假设，需内部设计减少外包、稳定良率和付费 TCO；集团调整后费用 5.90、SBC 3.40、CapEx 2.60及更高 NWC 是代价。FY31 IP/服务约 **15.21bn**，比公司 3 月所述 10bn 目标更强，集团约 **30.21bn** 也超过其 25bn 愿景；所以这行已包含较强的核心业务和非线性机会，不是把主业压回悲观来孤立展示芯片。基准 FY31 IP/服务约 10.37bn、芯片 6.0bn，主要区别是芯片兑现速度，并非把成熟 IP 中心人为压低。

### 3.2 从利润到股东现金的桥：SBC 只承担一次经济成本

定义 **EBIT_e** 为扣除 SBC、保留正常雇主税且剔除权益投资公允价值收益的正常化营业利润；正常化 **NOPAT_e＝EBIT_e×(1−正常税率)**。这一全成本指标用于每股经营成果，不是 GAAP 净 EPS。使用正常税率以便跨情景可比，不把短期税盾永久化。

用于实际现金桥的 **cNOPAT＝EBIT_e＋SBC−现金所得税**，仍包含折旧费用，且没有扣 CapEx/NWC；“c”只标识现金税与 SBC 调节，不表示自由现金。预计现金税为 `max(0, EBIT_e×情景税率−可用研发抵减)`，近中期税率 20%/22%/23%/23%、年度抵减约 0.10/0.12/0.12/0.12。其分司法区可用性与归属时点不明，因此早期零现金税只是条件估计，另做税额压力测试。

股东现金流桥为：

$$
FCFE_{owner}=EBIT_e+SBC-Tax_{cash}+D\&A-CapEx_{all}-\Delta NWC-LeasePrincipal-WithholdingCash
$$

`CapEx_all` 包含 PP&E、无形资产及 EDA 付款义务；经营租赁现金已包含在费用中，不再扣一遍；融资租赁本金单列。雇主股份薪酬税在经营费用里，员工归属代扣税在现金桥里，是两项不同义务。

DCF 使用这条现金流并对**未来净发股**显式稀释，不再从 FCFE 扣一次 SBC 金额。表中的完整成本 NOPAT 已扣 SBC，只用于盈利质量与正常化收益比较，不与现金法再相减。公司为净归属代扣税支出现金、少发行相应股份，故模型采用**净股份**加现金代扣税；不能用全部毛授予数量的稀释同时扣同一份扣股现金。

FY27—FY30 基准 SBC 为 **2.05/2.20/2.30/2.50**，代扣税 **0.90/0.95/1.00/1.10**。它们分别是损益确认与归属现金计划的研究假设，不能逐季按当前股价直接换算。起始 1.080 十亿 FD ADS 已含部分未归属奖项的稀释代理，后续增长代表未包含的归属及新授净增，**没有把 2,400 万份奖项完整再加一次**。缺少逐奖项归属/扣股数据，股本是估计，增加 0.5 个百分点稀释的压力结果见附录。

### 3.3 设备、营运资金与税盾的闭合

基准 FY27—FY30 全口径 CapEx 为 **0.82/0.95/1.10/1.25**，D&A **0.32/0.38/0.45/0.52**；突破 CapEx 为 **0.90/1.30/1.85/2.60**。测试/工程计算设备按约 3—5 年、设施较长寿命考虑，D&A 是资产逐步投运的简化代理，没有把所有当年新投资立即折旧。FY31 以后 CapEx 取“上年金额与收入×6.5% 的较高值”（悲观 7%），D&A 在扩张资产成熟后取 CapEx 的约 65%。这些是再投资带宽，不是已披露的公司设备计划，避免通过 FY31 突然砍 CapEx 人造现金跃升。

正常化 NWC 用 **IP/服务收入×20%＋芯片收入×情景系数**；芯片系数悲观 56%、基准 30%、乐观 28%、突破 30%。基准代表约 60 天 AR、约 100 天库存、约 45 天应付及部分预付款的净占用量级；悲观较长库存/认证和回款使占用明显更高。该初始 NWC 是机制化标准余额，不声称等同财报全部流动科目；ΔNWC 按同一年度序列相减。未来现金没有再加入历史合同资产下降带来的重复收益。

税盾核查：截至 FY26 年末美国联邦 NOL 约 0.420、英国交易亏损 0.3389、美国联邦研发抵减 0.2571、英国研发抵减 0.1207，是不同税务池，存在期限、使用和司法区限制，不能从全球所有利润直接扣。正常税率始终为正，长期税额随经营利润上升；短期研发抵减及股份税务扣除可能减轻现金税，但用不出时需下调现金。FY31 后的小额抵减代表当期新研发产生的抵免，不是无限继续使用同一历史余额。另测试 FY27/FY28 各多付 0.10bn 现金税，其影响主要是留存现金及每股价值约几毛钱，不能挽救当前价格。[FY26 20-F，所得税附注，p175—176](https://www.sec.gov/Archives/edgar/data/1973239/000197323926000097/arm-20260331.htm)

### 3.5 长期人才报酬与公平发行价格

IPO 后高股价可能暂时减少新奖项数量，长期不能依赖高估值窗口维持低稀释。FY31—FY40 的净稀释假设悲观 **5.0%**、基准 **1.6%**、乐观和突破 **1.2%**。悲观更高，因为股价受损时保持人才报酬需要更多净股份；管理层可以转现金薪酬或裁减项目，但前者降低 FCFE，后者降低业务规模，不能无成本消除这项负担。

终值再将净发股内生到公平经济价值。令年度净股权报酬预算 `B＝SBC−现金扣股支出`，稳态年度股东现金 `F`、公司增长 `G`、要求回报 `k`。在未来按公平价值发行、股份代扣税已现金支付的条件下：

$$
d=\frac{B(k-G)}{F-B(1+k)},\qquad g_{per\ share}=\frac{1+G}{1+d}-1
$$

这样可以核查发行新股的公平市值等于净人才报酬预算，不出现一边给很低经济价值、一边仍按高价低稀释发股的矛盾。FY41—FY45 从前期稀释率逐步过渡到该稳态。会计 SBC 到新授公平价值的等同只在稳态近似成立；近期仍按归属滞后分别建模。悲观集团仍能增长，但因人才股权占比较高，长期每股现金可能轻微下降；这是权益分配的代价，不是对业务无理由的收入坍塌。

### 4.2 纯业务增长参考：当前 153× 与正常化 25× 分开

为避免 GAAP 净利润受非经营投资/税项影响且近期完整成本营业利润接近零，本研究固定基准用 **EV/cNOPAT**。研究日起始全稀释估计市值 `$292.34×1.080≈315.73bn`，减模型现金 3.436 及权益资产 0.400，经营价值约 311.89；本研究 FY27 基准 cNOPAT 约 2.039，因此约 **152.99×**。公开普通股实际股数 1.068 计算市值约 **312.22bn**，与完全稀释研究口径的差异明确保留。153× 不是行情商直接提供的远期 P/E。

目标纯业务参考为：

$$
P_{growth}=153\times\frac{cNOPAT_{FY31}}{N_{FY30}}+\frac{Cash_{FY30}+OtherEquity_{FY30}}{N_{FY30}}
$$

这里用下一年经营产出与目标日股数，后续发股在 DCF 中继续扣；目标股数不是用未来加权 EPS 代替。保持 153× 会给出摘要的约 $322/$889/$1,340/$1,755；这只说明业务增长在高倍数不变的条件下可以很强，**不能说明这些价格可实现**。同一运营数据乘统一 25×，分别约 $57/$152/$227/$294；它剥离了当前特殊定价，但并不单独代表每一情景的公允价值。

在相同前瞻口径下，变化可以直接拆为：`业务贡献＝P_growth−P0`；`重估贡献＝P_trade−P_growth`。基准业务贡献约 **+$596/ADS**，目标倍数压缩贡献约 **−$783 至 −$742/ADS**，合计 **−$186 至 −$146/ADS**。这是大部分负回报由初始定价与目标倍数差带来的案例，绝非基准收入和利润倒退。

### 4.4 DCF 与市场价格自洽性，及高端溢价的明确条件

摘要并列的 DCF 是独立现金模型，不是将交易价折回来冒充内在价值。区间下沿通常贴近或高于 DCF，上沿包含市场可能保留的成长/流动性溢价。**基准上沿约比目标 DCF 高 51%**，乐观与突破约高 47%/49%；这些上沿必须有解释，不能叫作同等可靠的现金价值。

把经营现金和既定稀释计划固定，在目标日让上沿完全由剩余 DCF 支持，需要市场降低要求回报率到基准约 **7.77%**、乐观 **8.09%**、突破 **8.13%**；这是未来利率下降、风险溢价较低或市场接受较低回报的条件性定价。若名义股权回报仍为 10.5%，且没有更高现金/更低资本负担证据，应更靠近 DCF/区间下沿，不应把上沿拿来建核心仓。9.5% 利率及更高每股终值增长敏感性提供部分解释，剩余溢价仍需要真实业务上修或市场愿意额外付费。上沿不是将 DCF 后续业务人为压回低迷再任意拍出巨大倍数。

更大的自洽冲突来自保持当前 153×：它会使多数情景目标价格远高于同一经营路径的剩余现金价值，需要比本报告已经宽阔的远期增长更强、长期现金转换更高，或明显低于合理系统性回报的贴现要求。故固定倍数价保留为贡献解构，不作为交易预测。

## 5. 当前投资动作、证据评估与动态验证

### 5.1 证据支撑与商业可实现性分别评价

成熟 IP 收费、软件生态及第三方云端客户采用有相互印证的实证，可给较强业务机制支撑；但公司级基准还包含约 4.4bn 芯片与大量未来费用/归属假设，所以整体评价为**中**。悲观逆风有依据，也不代表永久重损已有证明，整体为**中**；乐观/突破的产品路线和客户信号使商业实现具备清楚机制，特定规模及毛利/资本效率仍为**弱**。

弱证据不等于不可能。标准 CPU 平台可以让研发在多个客户间复用，捕获更多芯片毛利额，自我替代也可能扩大客户覆盖。但必须有最少成功条件：至少数个非同一控股集团客户进入付费量产；制造覆盖与内存/系统配套匹配；客户在 TCO 验收后重复采购下一代；毛利提升伴随可控研发与 CapEx；股东现金/ADS 增长覆盖净发股。任一环节长期缺失，就不能把客户 logo 的数量等同于突破概率上升。

### 5.2 当前动作与条件价格：机会质量和买价分别判断

**现价 $292.34：不新增核心仓，较大持仓分步降低。** 此结论来自基准到乐观的绝对下行，以及突破上沿才接近合理年化回报，不是因任何公司都必须低于基准下沿才可买。ARM 缺乏足以抵消当前高估值的当期分红/回购托底，也不是一只可以仅靠成熟现金利润忽略第二曲线成本的防御股。

按同一截止日模型，研究日每股 DCF 约 **$15/$69/$121/$193**。这不是保证市场会跌至该处，更不是把公司资产清算值说成股价底线。控制股东、低自由流通股及长期平台溢价可令价格与现金价值偏离很久，不能据此建议不受约束的做空。

具体行动的条件为：

- **$55—70，至 $80 需更新事实支持**：若成熟 IP/第三方云端路径仍正常、资本和关联回款未受损，可作为基准附近的分批核心配置候选；仍应从小批开始，不能仅凭跌幅判断安全。
- **$100—150**：若两季 royalty 和外部授权达到强化阈值，自有 CPU 采购/回款与供给已使中心从基准向乐观转移，可考虑约 **0.5%—1%** 的主题/观察仓，随后按现金与毛利兑现增加。只有价格到位而业务未确认时，不自动买入。
- **$175—220**：需要多个独立客户量产、约 40% 以上芯片毛利、向下一代复购，净现金和每股现金改善，使突破路径明显更有支撑；此时可分步参与已验证成长，不能只凭新发布会把研究中心跳到突破。
- **超过当前价继续上涨**：不沿用静态上限盲目追入；先以新的已披露单位经济和采购规模重建现金模型，只有目标现金价值与收益区间同步大幅上移才改变动作。任何仓位扩张还须由组合的回撤承受能力约束，不使用借贷放大该长久期风险。

### 5.3 等待的机会成本与踏空风险

两季若出现强订单及更好毛利，市场可能先升至 $350，相对本参考价上涨约 **19.7%**，等待确实会错过这段收益。但用原突破上沿约 $408 计算，从 $350 买入仅余约 **16.6%** 总上行；即便粗用原 3.49 年窗口，年化约 **4.5%**，不足以补偿仍存在的执行和估值风险。用缩短后的实际窗口应重新计算，而不是把过去涨幅当成未来空间。

等待的价值在于以少量失去的早期涨幅换取采购、现金和成本的信息；如果经营验证同时支持更高的真实未来现金，接受更高买价并非错误。若只增加叙事确定感而模型仍是当前这条现金路径，则涨价会进一步恶化赔率。以极小主题仓保留参与感也应限定风险预算，不能把它逐步滑成没有证据的核心仓。

### G. 交付前五项核心自检

1. **业务与估值分层**：第 1—3 章先给业务机制、两期财报、客户队列与量价、完整成本利润、现金和股数；第 4 章才给折现、固定倍数、交易定价及隐含预期。摘要提前展示结论，未用股价反向设收入。
2. **四行情景递进**：FY30 收入、完整成本利润/ADS、目标及研究日 DCF、交易价均悲观＜基准＜乐观＜突破；FY30 突破的暂时较低现金已由新增 CapEx/NWC 解释，FY31 现金重新递进。集团共享研发、客户预算、内部 royalty 无重复。
3. **资本与融资闭合**：逐年核对收入合计、利润—现金恒等式、非负设备投入、股数及现金滚动；SBC 用现金加回＋净发股＋代扣税承受一次经济代价，终值发行价格与人才预算闭合。四主情景无需高价外部融资；尾部增发以受损价格测算。
4. **价值与交易价格自洽**：列出现金 PV、终值 PV 占比、equity bridge、统一倍数价、目标 DCF、交易价和年化回报；基准上沿约 51% 溢价须有更低市场要求回报或真实现金上修支撑，不能用作无条件内在价值。
5. **当前决策有区分度且可验证**：真实 IP/CPU 机会与当前买价分别评估，给不同价位和基本面触发、观察仓约束及错过涨幅的代价；两季 royalty、外部授权、SBC、净现金、CPU 制造/采购与毛利均有阈值。

模型限制集中在未公开客户颗数/ASP、royalty 终端拆分、晶圆良率/采购条款、逐奖项归属与税务扣除、长期市场容量。它们已作为条件假设、带宽和敏感性呈现；未来新证据应同时修正经营、权益分配与价格，不能把本次点估计当成永久目标。
