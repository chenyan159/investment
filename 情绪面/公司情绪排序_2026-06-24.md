## 排序方法

本排序不直接沿用每篇报告里可能存在的人工校准读数，而是用同一公式重新计算统一指标，保证 189 家可横向比较。

| 指标 | 口径 |
|---|---|
| 统一净情绪 | `未来消息方向 + 正面催化确定性 * 0.25 - 负面催化风险 * 0.25 - max(情绪拥挤度 - 7, 0) * 0.20` |
| 催化密度 | 未来消息频率、可复盘性、未来催化重要性和催化数量的组合。 |
| 催化质量 | 未来消息方向、正面催化确定性、未来看多/看空概率差、最近消息正面度和可复盘性，并扣除高负面风险。 |
| 右尾催化 | 消息频率、方向、正催化、社区传播和拥挤度；适合找短期高弹性，但风险也高。 |
| 低拥挤稳健 | 净情绪、方向、正催化、可复盘性、最近消息质量，同时奖励低拥挤和低负面风险。 |
| 风险热度 | 负面催化风险、拥挤度、社区传播和消息频率；分数越高代表越需要防守和复核。 |
| 综合情绪分 | 统一净情绪、最近消息正面度、未来看多/看空概率差、消息频率、可复盘性、社区质量和正催化的加权结果。 |

## 使用建议

1. 综合 Top 30 适合做下一轮“情绪驱动观察池”，但仍需和基本面、技术面、估值和流动性合并。
2. 低拥挤稳健榜更适合找可持续、赔率不完全被交易拥挤消耗的候选。
3. 右尾催化榜适合事件驱动和短期高弹性观察，但要同时读取高风险榜。
4. 高风险高波动榜不是简单排除清单，而是提醒这些公司更需要跟踪负面催化、做空报告、融资稀释、监管、业绩兑现和社区拥挤反转。
5. 任何单家公司进入正式投资决策前，至少要回读对应公司情绪报告的“反证与风险”和“后续跟踪清单”。
