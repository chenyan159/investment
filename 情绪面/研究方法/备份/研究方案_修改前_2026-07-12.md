# 公司情绪研究方案

本方法用于研究【股票代号】公司的消息面、市场情绪和未来 3 个月可能出现的情绪催化。研究必须独立完成，不使用项目内其他基本面、技术面、排序、特征量化或旧情绪报告作为判断来源。

## 研究目标

1. 回看最近 3 个月已经发生的公司相关消息，判断消息可靠性、重要性、情绪方向和意外程度。
2. 预测未来 3 个月可能出现的消息频率、消息类型和看多/看空方向。
3. 区分事实、推断和市场情绪，不把未发生的事件写成事实，不把社区、网红或社交热度当成公司基本面证据。
4. 给出可复盘的跟踪清单，后续能够检查预测是否兑现。

## 信息来源

优先从高可靠来源开始，再使用低可靠来源作为情绪温度计。

1. 公司 IR、Newsroom、SEC 8-K/10-Q/10-K、投资者日材料、业绩电话会转录。
2. 客户、供应商、生态主导公司的 IR，例如 NVIDIA、TSMC、Broadcom、Microsoft、Amazon、Google，以及与目标公司业务直接相关的客户/渠道伙伴。
3. 行业大会官网，重点看 keynote、special guest、agenda 变更、产品发布、客户演讲、技术路线图。
4. Reuters、Bloomberg、Barron's、The Information、SemiAnalysis、LightCounting、Dell'Oro、650 Group 等媒体或行业研究。
5. 卖方报告标题、评级、目标价、盈利预测、TAM 或设计赢单假设变化；如无法获得原文，必须标注为二级转述。
6. 高质量独立投资报告、投资社区长文、Substack/Medium/Seeking Alpha/Value Investors Club 等深度文章；必须标注作者、发布日期、是否付费/转载、是否有持仓披露。
7. 大流量投资网红、YouTube/Podcast/Newsletter 主理人、X 头部投资博主、Reddit 高流量投资讨论、Stocktwits 热门主题等；只作为社区和意见领袖情绪层，不作为事实来源。
8. 期权流、short interest、成交量异动、borrow fee、put/call、unusual options activity 等交易情绪数据；只作为交易温度计，不作为公司事实来源。

## 回看窗口

默认收集最近 3 个月消息。每条消息必须标注：

| 字段 | 要求 |
|---|---|
| 日期 | 使用消息首次公开日期；若只有转载日期，必须说明。 |
| 消息标题 | 简洁写明事件，不使用夸张标题。 |
| 来源层级 | SEC/IR、客户/生态、主流媒体、行业研究、卖方、独立投资报告、社区/意见领袖、交易情绪等。 |
| 事实/推断/情绪 | 明确该条是已披露事实、基于事实的推断，还是市场情绪。 |
| 可靠性 | 1.0-10.0，SEC/IR 最高；社区/意见领袖需要按证据密度、历史准确性和利益披露单独判断，不能默认等同事实来源。 |
| 重要性 | 1.0-10.0，衡量对收入、利润、订单、客户、产能、监管、融资、估值叙事或股价预期的影响。 |
| 情绪方向 | 看多、看空、中性、混合。 |
| 正面情绪 | 1.0-10.0，1 极负面，5 中性，10 极正面。 |
| 意外程度 | 1.0-10.0，相对市场原有预期的新信息强度。 |
| 情绪解读 | 解释为什么该消息改变或不改变市场叙事。 |

## 社区与意见领袖情绪层

高质量社区讨论、独立投资报告、大流量网红、Reddit 高流量讨论和 X 头部投资博主可以纳入调查范围，但必须单独成章，不得和公司事实、卖方原文、主流媒体报道混在同一证据层。

### 1. 纳入标准

优先纳入满足以下条件的材料：

1. 有清晰作者或账号，能看到发布时间、原始链接和上下文。
2. 有实质论点，而不是只喊目标价、短线口号或无证据情绪。
3. 能引用或链接到公司披露、行业数据、客户信息、交易数据或可验证事实。
4. 有足够传播量，例如高阅读、高转发、高评论、高 upvote、高订阅量或被多位投资者二次传播。
5. 对市场叙事有影响，例如改变讨论焦点、放大看多/看空理由、触发反驳、形成拥挤交易。

低质量内容也可以记录，但只能作为噪音或反向拥挤度，不得作为正面或负面证据。

### 2. 单独评分表

社区与意见领袖内容必须使用独立表格：

| 日期 | 平台/来源 | 作者/账号 | 内容类型 | 传播量 | 方向 | 证据密度 | 影响力 | 偏见/利益冲突 | 可验证性 | 情绪解读 |
|---|---|---|---|---:|---|---:|---:|---|---:|---|
|  | Reddit/X/YouTube/Podcast/Newsletter/独立报告 |  | 深度报告/长帖/thread/视频/访谈/评论 |  | 看多/看空/中性/混合 | 1.0-10.0 | 1.0-10.0 | 持仓披露/付费推广/空头/未知 | 1.0-10.0 |  |

字段口径：

1. `证据密度`：是否有可核验数据、原始文件、客户证据、财务模型或反证讨论。
2. `影响力`：账号粉丝、阅读量、转发/评论/upvote、二次传播、是否被其他大号引用。
3. `偏见/利益冲突`：是否披露 long/short、是否付费推广、是否卖课/带单、是否只做单边叙事。
4. `可验证性`：观点是否能被一级来源、财报、客户公告、行业数据或后续事件验证。

### 3. 使用边界

1. 社区和意见领袖内容只回答“市场正在相信什么、担心什么、传播什么”，不直接回答“公司事实是什么”。
2. Reddit/X/网红观点若没有一级来源支持，只能写成情绪或叙事，不能写成订单、收入、客户、利润、产能事实。
3. 大流量看多内容如果证据弱，应同时提高情绪拥挤度和反向风险。
4. 大流量看空内容如果证据弱，也要记录其传播影响，因为它可能影响短期波动和后续管理层回应。
5. 同一观点被多个账号转述时，要尽量追溯原始来源，避免把同一条信息重复计数为多条独立证据。
6. 如果社区观点与公司披露冲突，以一级来源为事实锚点，并把冲突本身作为情绪分歧记录。

## 未来 3 个月消息预测

必须增加前瞻预测模块，覆盖报告日期之后 3 个月。预测不是事实，只能写成概率判断。

### 1. 消息频率预测

按消息类型预测未来 3 个月的消息频率：

| 类型 | 预测内容 |
|---|---|
| 公司正式披露 | 财报、8-K、订单、客户合作、产品发布、产能、融资、管理层变动。 |
| 客户/生态消息 | 客户订单、供应商扩产、平台产品发布、生态公司 capex 或技术路线变化。 |
| 行业会议 | 目标公司参会、客户参会、主题演讲、产品展示、行业标准或监管讨论。 |
| 卖方变化 | 评级、目标价、盈利预测、TAM、设计赢单、估值框架调整。 |
| 主流媒体/行业研究 | 深度报道、负面调查、供应链验证、竞争格局变化。 |
| 社区/意见领袖 | 高流量 Reddit/X/YouTube/Podcast/Newsletter/独立投资报告是否可能继续放大某个看多或看空叙事。 |
| 交易/社交情绪 | 期权异动、short interest、Reddit/X/Stocktwits 热度和叙事变化。 |

输出必须包含一张频率预测表：

| 未来 3 个月消息类型 | 预计条数 | 频率判断 | 主要依据 | 置信度 | 需要复核的日期/事件 |
|---|---:|---|---|---|---|
| 公司正式披露 |  | 高/中/低 |  | 高/中/低 |  |

频率预测依据只能来自可核验线索，例如公司历史披露节奏、已公布会议日程、财报季、监管日程、客户产品周期、行业大会日历、卖方覆盖节奏、社区/意见领袖发文节奏、期权/社交热度变化。没有依据时写低置信，不得编造催化。

### 2. 消息方向预测

对未来 3 个月的关键消息给出看多/看空/中性/混合预测，并写清触发条件和反证条件：

| 可能消息/催化 | 预计窗口 | 方向预测 | 看多概率 | 看空概率 | 重要性 | 预测依据 | 反证条件 | 置信度 |
|---|---|---|---:|---:|---:|---|---|---|
| 下一次财报/指引更新 |  |  |  |  |  |  |  |  |

方向预测应至少覆盖：

1. 下一次财报或经营更新：收入、毛利、订单、backlog、现金、指引是否可能超预期或低于预期。
2. 客户/订单催化：是否可能出现新客户、续单、取消订单、交付延迟、客户预算变化。
3. 产品/技术催化：新产品、认证、良率、产能、路线图、竞争产品。
4. 监管/政策催化：出口管制、关税、补贴、国防采购、反垄断、审批。
5. 卖方/媒体催化：是否容易出现上调、下调、深度看多报告、做空报告或负面调查。
6. 社区/意见领袖催化：头部博主、独立研究、Reddit 高流量讨论是否可能继续放大看多或看空叙事。
7. 社交/期权催化：讨论热度是否可能放大波动，是否存在拥挤交易或 short squeeze 叙事。

### 3. 前瞻情绪评分

在报告中给出一个前瞻情绪读数，但必须拆成可解释组件：

| 维度 | 评分 | 解释 |
|---|---:|---|
| 未来消息频率 | 1.0-10.0 | 未来 3 个月预计消息密度，消息越多分数越高。 |
| 未来消息方向 | 1.0-10.0 | 未来消息净方向，1 极看空，5 中性，10 极看多。 |
| 正面催化确定性 | 1.0-10.0 | 正面消息出现的可验证依据强度。 |
| 负面催化风险 | 1.0-10.0 | 负面消息或反叙事出现的风险，分数越高代表风险越高。 |
| 社区传播强度 | 1.0-10.0 | 高质量社区、独立报告、头部博主和大流量讨论对叙事扩散的推动力度。 |
| 情绪拥挤度 | 1.0-10.0 | 社区、网红、社交、期权、卖方一致性和股价叙事拥挤程度。 |
| 可复盘性 | 1.0-10.0 | 未来是否有明确日期、事件和验证指标。 |

可选计算口径：

`前瞻净情绪 = 未来消息方向 + 正面催化确定性 * 0.25 - 负面催化风险 * 0.25 - max(情绪拥挤度 - 7, 0) * 0.20`

该分数只用于情绪面比较，不等同于基本面评分、技术面信号或投资建议。

## 反证与风险

报告必须单列反证，不得只写看多叙事。至少检查：

1. 是否存在消息多但基本面兑现弱的情况。
2. 是否存在公司只发布会议/奖项/宣传，但缺少订单、收入、客户或利润证据。
3. 是否存在卖方一致看多、社区/网红极热、社交极热、期权极端拥挤导致的反向风险。
4. 是否存在做空报告、监管调查、客户取消、融资稀释、管理层变动、审计或会计风险。
5. 是否存在行业大消息和目标公司收入之间传导不足的问题。

## 输出格式

报告必须包含以下章节：

1. `# 股票代号 / 公司名称 公司情绪研究`
2. `## 研究元数据`
3. `## 结论摘要`
4. `## 最近 3 个月消息评分矩阵`
5. `## 情绪分层`
6. `## 社区与意见领袖情绪`
7. `## 未来 3 个月消息频率预测`
8. `## 未来 3 个月消息方向预测`
9. `## 前瞻情绪评分`
10. `## 反证与风险`
11. `## 后续跟踪清单`
12. `## 来源与日期`

## 后续跟踪清单

每篇报告最后必须留下可复盘清单：

| 跟踪项 | 预计验证日期 | 预期方向 | 实际结果 | 是否命中 | 备注 |
|---|---|---|---|---|---|
|  |  | 看多/看空/中性/混合 | 待更新 | 待更新 |  |

后续复盘时，应比较实际消息数量与预测消息数量、实际消息方向与预测方向、实际市场反应与预期路径，并说明误差原因。
